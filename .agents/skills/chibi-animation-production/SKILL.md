# Q 版人物動畫素材自動接續流程

此 skill 負責從完整 Q 版來源圖一路推進到可交動畫工具切件的素材包。適用於使用者已提供、已選定或已核准的 Q 版人物圖，也適用於 Claude 戰場專家交接的角色來源圖。

## 不可變更的角色基準

- 以已核定的趙雲 Q 版全身圖作為共用比例標尺。優先讀取 `artwork/chibi-art-library/catalog.json` 指向的趙雲正式來源；若目錄缺少原始高解析度母圖，使用者已核定的趙雲全身參考圖作視覺基準，並在紀錄中註明來源。
- 比較角色本體從頭頂（保留完整頭髮、頭盔和髮飾）到鞋底的高度、頭部高度／全身高度、軀幹與腿部的相對長度、肩寬與站姿佔幅。長兵器、羽飾、披風和飄帶不計入本體身高，但保留完整並檢查不超出共用安全畫布。
- 對照圖必須讓角色以相同本體高度、腳底基線和畫布比例並排。使用像素量測或量測標線時記錄來源尺寸與量測值；不要憑縮圖感覺宣稱數值已驗證。沒有可比的趙雲正式來源時，標示 `pending-reference`，不可假稱已通過。
- 比例校正只允許對整張原圖等比例縮放、平移、置中到共用畫布；必要時調整畫布留白。不得非等比例拉伸、單獨放大頭或四肢、重畫臉／髮型／服裝／武器、刪除或裁掉頭冠、長髮、手足、武器、披風等造型元素。這些修改會改變人物身份，不能當作比例校正。

## 自動工作流程

1. **登記來源**：確認角色 ID、繁體中文名、武器、來源檔、來源版號及來源核准狀態；保留原圖和 SHA-256。姿勢比較板、帶 A/B/C 標籤的整頁或低解析度遊戲小圖不可當切件母圖。
2. **執行趙雲比例檢查**：製作同尺度並排檢視，檢查身高、頭身比、軀幹／腿長、左右肢體完整度、武器握持及安全留白。個別姿勢可以不同，但不得因透視或蹲跳造成角色本體比例與趙雲基準明顯不一致。臉、手、腳或武器有生成瑕疵時判定不通過。
3. **通過即自動接續**：依使用者已訂規則，Q 版人物比例與完整度檢查通過，就視為允許直接進入切件；不要再等逐張挑選或重複詢問是否開始。直接把母圖整理到 `artwork/chibi-art-library/source/`，更新來源 manifest 與 `catalog.json`，隨即啟動可用的切件工具或動畫素材流程。切件時以來源母圖為唯讀來源，沿用共座標畫布，依工具需要產生角色專屬遮罩和身體部件，保留原始輪廓及衣甲裝飾；不得套用其他人物的遮罩來湊進度。
4. **未通過才停止該角色**：不覆寫原圖、不擅自修臉或改造型。保留候選於 `artwork/temp/chibi/`，記錄不符合的量測／可見問題，產生明確的重繪或補件需求；可繼續處理其他角色。只有來源角色身分或選定版本無法辨識時才詢問使用者。
5. **切件後驗收與交接**：確認分件完整、手足與武器握點可用、接縫有足夠重疊、alpha 邊緣沒有錯切或殘片，並保存來源 hash、版本、分件清單及檢查結果至 `artwork/chibi-art-library/cutouts/` 與 `manifests/`。機器掃描通過不等於人工確認；缺少正式接點量測或角色動作預覽時，明確標示 pending。若本環境沒有可用的切件工具，仍自動完成來源登記、尺寸／比例檢查和切件需求包，整理給 Claude 接手，不把僅有母圖說成已切件或已完成動畫。

## 交付狀態

- `source-pass`：母圖可辨識、完整，且比例檢查通過。
- `cutout-in-progress`：已由合格母圖啟動切件；記錄所用工具與版本。
- `cutout-pending-tool`：檢查已通過，但本環境缺少實際切件工具；切件需求包已準備好。
- `needs-revision`：比例或母圖品質未通過；列出原因，不修改核准原圖。
- Rig、骨架、動作與遊戲內播放分別驗收；完成切件不可自動宣稱這些階段也已完成。

正式母圖與切件位置、命名和版本規則依 `artwork/chibi-art-library/README.md` 及 `catalog.json` 為準。此流程產生的是動畫製作素材，不會自行改動遊戲正式角色或替換既有遊戲貼圖。

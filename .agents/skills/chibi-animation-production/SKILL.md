# Q 版人物動畫素材自動接續流程

此 skill 負責從完整 Q 版來源圖一路推進到可交動畫工具切件的素材包。適用於使用者已提供、已選定或已核准的 Q 版人物圖，也適用於 Claude 戰場專家交接的角色來源圖。

## Claude 委託信箱的自動入口

- 每次開始處理 Claude 戰場專家的 Q 版需求前，先同步 `mailbox` 分支並列出 `mailbox/to-codex/` 中不在 `archive/` 的 Markdown；依信件時間讀取主委託與補充信，再照最新補充執行。附件目錄不是未讀信件。
- 先核對信中指定的角色、武器、比例基準、交付路徑和工作責任。角色武器以遊戲立繪為準；如果信件指定素材只留在私有管線，遵守私有邊界，不把它複製進公開遊戲庫。
- 每完成一位或一批可交付來源圖，就回覆到 `mailbox/to-claude/`：列明角色 ID、版本、檔案路徑、SHA-256、比例檢查狀態及阻塞原因。不要只在對話中口頭回報。
- 沒有未讀信件時，繼續處理已接手且仍未完成的來源圖；不要把空收件匣當成停止理由。

## 不可變更的角色基準

- 以已核定的趙雲 Q 版全身圖作為共用比例標尺。優先讀取 `artwork/chibi-art-library/catalog.json` 指向的趙雲正式來源；若目錄缺少原始高解析度母圖，使用者已核定的趙雲全身參考圖作視覺基準，並在紀錄中註明來源。
- 比較角色本體從頭頂（保留完整頭髮、頭盔和髮飾）到鞋底的高度、頭部高度／全身高度、軀幹與腿部的相對長度、肩寬與站姿佔幅。長兵器、羽飾、披風和飄帶不計入本體身高，但保留完整並檢查不超出共用安全畫布。
- 對照圖必須讓角色以相同本體高度、腳底基線和畫布比例並排。使用像素量測或量測標線時記錄來源尺寸與量測值；不要憑縮圖感覺宣稱數值已驗證。沒有可比的趙雲正式來源時，標示 `pending-reference`，不可假稱已通過。
- **自動切件的數值門檻**：角色頭部高度／本體高度與臉寬都必須落在趙雲基準的 `0.80–1.20` 倍，並記錄量測值。自動偵測器的 `WARN` 只代表要人工核對，不能單獨當作通過或否決；量測頭部時要包含原有頭髮、頭盔與髮飾，避免偵測器漏掉輪廓。人工量測仍超界或無法量測時才判定未通過並暫停該角色切件。
- 比例校正只允許對整張原圖等比例縮放、平移、置中到共用畫布；必要時調整畫布留白。不得非等比例拉伸、單獨放大頭或四肢、重畫臉／髮型／服裝／武器、刪除或裁掉頭冠、長髮、手足、武器、披風等造型元素。這些修改會改變人物身份，不能當作比例校正。

## 自動工作流程

1. **登記來源**：確認角色 ID、繁體中文名、武器、來源檔、來源版號及來源核准狀態；保留原圖和 SHA-256。姿勢比較板、帶 A/B/C 標籤的整頁或低解析度遊戲小圖不可當切件母圖。
2. **執行趙雲比例檢查**：製作同尺度並排檢視，檢查身高、頭身比、軀幹／腿長、左右肢體完整度、武器握持及安全留白。個別姿勢可以不同，但頭部高度／本體高度和臉寬必須通過上列 `0.80–1.20` 門檻。偵測器有警告時補做含頭飾的人工量測並留下證據；臉、手、腳或武器有生成瑕疵時判定不通過。
3. **通過即自動接續**：依使用者已訂規則，Q 版人物比例與完整度檢查通過，就視為允許直接進入切件；不要再等逐張挑選或重複詢問是否開始。把核准母圖登記至 `artwork/chibi-art-library/source/`，更新來源 manifest 與 `catalog.json`，然後立即啟動動畫切片／切件工具。切件只能以核准母圖作唯讀來源；比例修正只可對整張圖等比例縮放、平移或調整畫布留白，不能重畫或局部改動頭臉、髮型、服裝、武器、肢體，也不能裁掉任何造型元素。切件前確認角色專屬設定與遮罩，絕不可借用趙雲或其他人物的遮罩。
4. **未通過才停止該角色**：不覆寫原圖、不擅自修臉或改造型。保留候選於 `artwork/temp/chibi/`，記錄不符合的量測／可見問題，產生明確的重繪或補件需求；可繼續處理其他角色。只有來源角色身分或選定版本無法辨識時才詢問使用者。
5. **切件後驗收與交接**：確認分件完整、手足與武器握點可用、接縫有足夠重疊、alpha 邊緣沒有錯切或殘片，並保存來源 hash、版本、分件清單及檢查結果至 `artwork/chibi-art-library/cutouts/` 與 `manifests/`。機器掃描通過不等於人工確認；缺少正式接點量測或角色動作預覽時，明確標示 pending。若本環境無法直接執行切件工具，仍要完成母圖登記、比例證據與角色專屬切件需求包，立即交給 Claude 戰場專家接續；不可只回報「待處理」，也不可把母圖說成已切件或已完成動畫。

## 合格後自動啟動切件與動畫交接

- 使用者已挑選／核准來源，且來源通過人物比例、完整度、透明邊緣、武器握點與身分辨識後，**自動進入切件流程**；不再詢問「要不要切」、「要不要交給動畫工具」或要求再選一次。
- 以 `C:\Users\User\spine-trial\tools\pipeline.py` 作為目前共用動畫管線入口。先核對 `characters/<id>/char.json`、`work.png` 是否綁定核准來源版本與 SHA-256；再依序執行：
  1. `python tools/pipeline.py accept-source <id>`：來源與風格門檻。
  2. `python tools/measure_joints.py`（設定正確 `CHAR`）：量測該角色專屬關節、武器握點與切件座標。
  3. `python tools/auto_cut.py`（設定正確 `CHAR`）：以核准母圖建立角色專屬分件。
  4. `python tools/pipeline.py build <id> --preview`，再執行 `python tools/pipeline.py check --char <id> --stage cut,build`。
- 先確認工具實際支援該角色與武器，再執行對應階段。角色尚無 `char.json` 時，先用管線提供的 scaffold 建立空白設定，所有接點仍須依該人物原圖量測；禁止把範本角色的關節值、武器握點或遮罩直接複製成正式資料。
- 切件設定 `cut` 若為空、通用範本或尚未依該角色量測完成，不啟動 `auto_cut`、`build`；立刻整理角色專屬切件需求包交給負責動畫的 Claude，明確標記 `cutout-pending-tool`，不要以其他人物遮罩或範本接點代替。
- `face_scale`、`head_frac` 等自動偵測若受頭盔、髮髻、長髮或遮擋影響而警告，不可單憑警告拒絕，也不可單憑其他 PASS 宣稱合格。要以完整頭部外輪廓（包含原有帽冠、髮飾、髮型）和臉部可見範圍，跟趙雲核定圖同尺度量測並記錄數值；確認實際比例在規範內才自動切件。比例真的不合格時，保留來源原圖、停止該角色切件並提出重繪需求，不得為了過門檻單獨放大頭部或裁掉頭飾。
- 若工具只提供 source gate 而未提供當前角色可用的切件執行器，仍須自動完成來源版號／hash 綁定、角色專屬量測表、遮罩／clean-base 缺項清單和可直接執行的命令，並在同一輪把完整交接送到 Claude 戰場專家信箱；狀態標 `cutout-pending-tool`。不得把 gate 通過誤報為已切件，也不得只留一句「等後續處理」。
- 自動流程只處理已核准的來源和其比例／切件工作，不授權換臉、改髮型、改服裝、改武器或重畫身體。任何為了改善比例的修正僅能對整張人物圖等比例縮放、平移或調整畫布留白；人物局部一律維持原樣。
- 每完成一位角色便更新 manifest、來源 hash、量測值、各階段狀態與阻塞點，接著處理下一位已核准來源；不因單一角色缺遮罩、量測警告或工具失敗而停掉整批。

## 主動續作規則

- 使用者已選定或核准角色與姿勢後，依序完成比例檢查、來源登記、切件準備及動畫交接；不因使用者暫時離線、沒有再回覆「繼續」或沒有重複批准而中斷。
- 比例、完整度及武器檢查通過，即代表可以直接進動畫工具切片；這是本流程的預設自動動作，不必再問使用者一次。若缺少角色專屬遮罩、clean base 或接點資料，先自動產出該角色的切件需求包並交給 Claude；不可停下來等待使用者再次授權，也不可借用其他角色的遮罩。
- 一次處理一位可明確辨識的角色；完成或隔離該角色後接著處理下一位。只因角色身份或核准版本無法辨識時才詢問使用者。
- 比例不通過時，保留原圖並提出具體修正需求；比例校正只可等比縮放、平移與調整畫布留白，絕不改臉、髮型、服裝、武器或裁掉造型元素。

## 交付狀態

- `source-pass`：母圖可辨識、完整，且比例檢查通過。
- `cutout-in-progress`：已由合格母圖啟動切件；記錄所用工具與版本。
- `cutout-pending-tool`：檢查已通過，但本環境缺少實際切件工具；切件需求包已準備好。
- `needs-revision`：比例或母圖品質未通過；列出原因，不修改核准原圖。
- Rig、骨架、動作與遊戲內播放分別驗收；完成切件不可自動宣稱這些階段也已完成。

正式母圖與切件位置、命名和版本規則依 `artwork/chibi-art-library/README.md` 及 `catalog.json` 為準。此流程產生的是動畫製作素材，不會自行改動遊戲正式角色或替換既有遊戲貼圖。

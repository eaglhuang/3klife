# Q 版戰場人物來源與切片流程

適用於戰場專家委託的 Q 版武將來源圖、比例校準、武器圖與動畫切片交接。以目前使用者確認的角色候選作身份、服裝、配色、武器依據；不得擅自換角色設計。

## 開工與排序

1. 開始一批工作前先讀 `origin/mailbox` 中最新的 `mailbox/to-codex/` 指示，依時間順序讀補充信；回信及歸檔只依使用者已授權的 mailbox 流程辦理。
2. 留在使用者指定的 `C:\Users\User\3KLife` `master`，不切換分支或工作樹。只處理本委託檔案，不納入其他 dirty files。
3. 先遵循最新角色選擇與製作順序；本批 PROG-2-9316 優先順序為甘寧、夏侯惇、張郃，再曹操、張遼、于禁、諸葛亮。新玩家缺少的初始角色孫策、魏延排在七位之後。
4. 角色候選一經使用者選定，即視為設計核定。完成比例及來源圖檢查後直接進動畫切片，不再逐張等待重複確認；只在身份、武器或委託內容互相矛盾，或檢查有 FAIL 時停下回報。

## 主動連續執行（使用者已授權）

- 使用者已明確授權：人物比例對齊趙雲、來源圖通過後，就直接使用可用動畫工具切片；不得每位再詢問一次「要不要切」或要求重複選姿勢。
- **比例合格就是切片授權門檻，不是停下來等確認的節點。** 當標準畫布、下巴至腳底比例和完整性檢查都 PASS，立即執行可用的角色動畫切片流程；只做取景/等比校正不改造型。除非使用者明確要求只交來源圖，否則不可把「尚未確認切件」當成預設狀態。
- 每次收到「繼續／主動做／我去休息」等延續指示，先從最新委託、角色佇列、來源檢查及切片 manifest 找第一個未完成項，直接續作；不重問已核准姿勢，不重做已 PASS 項目。只有必要工具缺失或檢查 FAIL 才標記該角色阻塞，並立刻繼續其他可做角色。
- 按最新委託順序逐位完成「來源圖 → 比例/QC → 切片 → manifest/hash → 交付 Claude」，完成一位立即接下一位，直到清單完成或遇到真實硬阻礙。
- 若尺寸或比例不合格，先保留原稿並自動修正或重生候選，再重新量測；不得為了過門檻裁掉角色特徵、武器、帽冠、髮飾或四肢，也不得用拉伸變形蒙混。
- 一般 WARN（不影響身份、骨架接點、肢體完整性或武器握持）記錄後繼續；只有會造成切件/動畫無法使用的 FAIL、規格互相矛盾，或必要工具確實不存在時才暫停該角色，清楚回報原因並繼續其他不受阻的角色。
- 使用者已選定的姿勢及候選視為核准；切片屬已授權的後續製作，不代表使用者已核准最終遊戲整合或動畫效果。
- 每次交接必須附下一位待辦與其狀態，避免中斷後遺忘佇列；重新開始時先讀最新 mailbox、catalog、`source_check.json` 與 manifests，從第一個未完成角色續作，不重做已 PASS/已交付項目。

## 來源圖製作與比例校準

- 以凍結的趙雲 Q 版作唯一比例與品質參照，角色採共用動畫可用的中立站姿；選定的動態候選只供身份、服裝、武器與色彩參考，除非最新委託明確改成沿用動態姿勢。
- 來源圖使用委託指定的透明 PNG 畫布與尺寸。PROG-2-9316 使用 577×1250；主體腳底落在 y=1245 附近，四周留白，武器不得貼邊或裁切。
- **透明圖與色鍵圖不可混用預處理器**：`tools/prep_source.py` 是綠幕色鍵流程，只能用在平坦綠底輸入；透明 PNG 必須依 alpha >128 找主體範圍，再以等比縮放、置中及腳底基準定位到標準畫布。不要對透明圖呼叫綠幕色鍵，否則透明 RGB 可能被當成不透明背景，導致人物被錯誤縮小。等比縮放後須重新量測下巴至腳底並目視確認特徵、髮飾和四肢完整。
- 量測一律用 `C:\Users\User\spine-trial\tools\source_art_check.py`，並先確保圖檔已是同尺寸 577×1250、腳底基準列 y=1245；不可直接拿不同尺寸的生成圖跑此工具，也不可用視覺縮圖值替代。
- PROG-2-9316 比例以 Claude 2026-11-17 00:20 更正信為準：**不再放大頭、不用膚色自動框或 `head_frac` 當否決依據**；工具會低估鬍鬚、眼罩與頭盔角色。主判準是下巴（含鬍鬚最低點）至腳底 `622px ±5%`，即 `591–653px`；肩線約 y=650、髖約 y=950。使用 577×1250 標準畫布、腳底 y≈1245，且保留全身與四周安全留白。若角色本身辨識配件遮住下巴，需記錄人工覆核位置與量測依據，不得擅改標準。
- 不以舊版趙雲 `head_frac=0.413`、`face_scale=185px`、`chest_w=1.773`、`light_lr=1.005` 的自動結果否決最新更正信核可的候選。頭與臉只依趙雲參照保持視覺比例，不得再為迎合錯誤工具值而放大或裁切。
- 保持頭髮、五官、盔甲、服飾、身份特徵及武器造型。校比例時只調整尺度、取景或必要的局部重繪，不刪帽冠、髮飾、盔甲或角色特徵來假裝比例合格。不同畫布比例若需縮放會使人物變得明顯過小、或需裁切主體，該候選直接退回重生，不准硬塞進畫布。
- 依立繪選武器。武器直桿保持筆直、握點清楚、留安全邊界。雙持武器需分別輸出武器圖及握點；甘寧兩斧分近側手與遠側手，斧刃朝外且不遮臉與軀幹中線。羽扇、劍等依各自委託，不強行套用長槍槽。

## 自動 QC 與切片

1. 保存原始候選及核准版，不覆寫來源候選；工作稿放 `artwork/temp/chibi/`，核准來源放 `artwork/chibi-art-library/source/`，命名含角色 ID、繁體中文名與四碼版本。
2. 檢查畫布尺寸、RGBA 透明通道、主體 alpha 範圍、腳底位置、四周安全留白、臉部比例、武器直度/完整性、握點、左右受光及服裝遮擋。結果寫入 `source_check.json`，數值、判定與人工項目分開記錄。
3. 下巴至腳底比例符合 `622px ±5%` 且人工檢視未見肢體、握持、武器裁切或遮擋等硬性錯誤時，視為使用者已授權的切片門檻：直接用專案當前可用動畫工具切片，不等待逐張批准。若角色已由使用者選定，即不再要求重選姿勢。若指定工具不在 3KLife，檢查 `C:\Users\User\spine-trial` 的委託工具；工具缺失或檢查 FAIL 才暫停該角色，記錄錯誤後繼續佇列中其他人，不自行假稱切片完成。
4. 切片保持共同畫布座標，逐件檢查接縫、遮擋與武器穿插。缺少工具或量測資料時保留 `pending` 並立即回報 Claude，不填猜測座標。
5. 每位完成後立即交付 Claude：來源 PNG、武器 PNG、切片/握點資料、`source_check.json` 與來源 SHA-256；附 WARN 數值及尚未驗證項。不得把來源圖 PASS 說成 rig 或動畫已驗收。
6. 角色送交後續流程即接著做下一位；遇 FAIL 先修該角色，避免把錯誤累積到整批末尾。

## 交付狀態

只使用 `draft`、`source-pass`、`slicing`、`handoff`、`blocked` 等可追溯狀態。只有工具輸出和人工檢視證據齊備才可標示 PASS；切片、Rig、動作、遊戲整合各自記錄，不互相代替。

# 3KLife 武將立繪與頭像校準

## 核定畫風

參考 `assets/approved-male-comparison.png` **右半圖**及 `assets/approved-female.png`。兩圖是同一遊戲的風格與色調參考，不是人物臉型模板。臉部五官微動漫、輪廓乾淨精緻；皮膚明亮透潤、光影柔和；布料、金屬與頭髮具有細緻半寫實材質。避免灰濁髒褐陰影、泥污、過度做舊、照片毛孔、油膩磨皮及平面卡通服裝。依角色保留不同膚色、臉型、年齡和氣質。

## 比例校準

- 全身站姿以成年約 7.5 頭身為設計目標，參考區間 7.2–7.8；頭長以顱頂至下巴計，不含頭冠與羽飾。動態透視或蹲姿先校正姿態再判斷，不將畫面投影高度當成人體實際身高。按一致取景並排，避免頭部大小突然跳變。
- 臉部五官維持同一插畫尺度與清晰度：眼睛略帶動漫感但保留成熟臉部結構，兩眼位置、鼻唇與下顎自然；不以同一模板複製所有臉。依人物調整眉眼距、臉型、顴骨、鼻唇和表情，避免眼睛過大或幼態化。
- 眼型與眼神必須因人物而異：綜合調整眼裂長短與開合、眼尾方向、眼瞼厚薄、眉型眉距、視線和表情，不只更換虹膜顏色或睫毛。例如小喬可明亮活潑，黃月英可細長沉靜而專注；其他人物依性格設計，不將範例套成固定模板。生成前記錄角色眼部特徵，完成後與同系列頭像並排比較；若辨識主要依賴髮色或飾品，應繼續調整五官並複查。
- 每位武將都要由正式站立立繪另行製作兩種正方形頭像：大頭像 `avatar` 與小頭像 `small_avatar`。兩者分開取景與裁切，不可拿同一裁框放大／縮小充數，也不可把戰鬥立繪當頭像來源。輸出維持正方形（遊戲用 256×256 px），只等比例縮放，不拉伸臉或頭身。
- **大頭像 `avatar`（胸像）：** 以頭至胸甲上半部為構圖，頭頂／頭盔與主要髮飾完整，臉部五官完整；下緣落在上胸或胸甲中段，胸部／胸甲約佔畫面下方 35–45%，腰、腹部與腰帶一律不可出現。臉部量測框以額際至下巴為準（不含頭盔、髮飾、鬍鬚和脖子），高度約佔畫面 28–35%，視覺接近參考圖約 30%。保留肩線與適量頸部，不讓頭像變成全身縮圖。
- **小頭像 `small_avatar`（肩上頭像）：** 只呈現完整頭部、頸部及肩膀上緣；下緣停在肩線／鎖骨上方，畫面不得出現胸部、胸甲正面、腹部或腰部。頭部量測框由頭頂（含主要頭髮或頭盔）至下巴，高度約佔畫面 70–80%；長羽飾或飄髮不計入此比例，但必須盡量保留且不可切斷主要頭飾。完整保留五官、下巴與頭頂，不以切臉換取放大效果。
- **共同置中與驗收：** 臉部必須左右置中。以臉部外框（額際至下巴、兩側臉頰）中心作基準，中心線須落在畫布水平中線 ±3% 畫布寬度內；不得用偏置頭飾、髮流、肩甲或留白來假裝置中。正面或轉頭姿勢都以臉本身置中，保留自然頭部角度，不扭正五官。縮圖驗收逐張確認：大頭像有完整胸像且無腰，小頭像只有肩上且無胸，兩類臉部／頭部比例達標、左右置中、頭頂與下巴完整、五官未變形；並與同系列並排檢查視覺大小和眼線高度。未達標須重設裁框或重裁，不得保留大頭、半身混用的舊裁切。

## 女性身材與角色差異

女性須為成年身形：優先採成熟、健康、胸線明顯豐滿且有自然承托的商業遊戲插畫 S 曲線；腰線清楚，臀腿與肩背協調，重心及衣裝受力合理。胸甲、衣襟或內搭須有自然支撐與合身結構，避免普遍畫成胸線單薄或缺少成熟曲線；依角色身形協調，不做幼態、擠壓或誇張失衡。

女性角色一律不穿高跟鞋，依服裝設計平底鞋或平底靴，腳形與鞋底保持自然。

具武將或戰鬥身分的女性，至少配置可辨識的輕盔甲，例如輕型胸甲、肩甲、護腕或札甲；依角色、兵種和動作搭配，兼顧美感、活動性與合理防護。仕女、文士與樂師等非戰鬥角色依人物身分設計服裝，不強制穿甲。

按人物設定選高挑、中等或嬌小的成年身高，並選纖細、勻稱、結實、豐腴等體型；身高不同不任意縮放頭部。胸線預設由中等至成熟豐滿，不因角色個性或勢力配色一律弱化；只有明確角色設定需要纖瘦輪廓時才減弱胸線，但仍保持成年感。腰臀曲線可從俐落到柔和，須與肩寬、骨盆、服裝和動作相配。膚色可用亮象牙、暖桃、小麥、健康古銅或較深色，均保持明亮乾淨的光影，不把亮膚等同一律白膚。避免將某種身高、身材或膚色固定配給同一勢力。

## 角色、顏色與武器

- 每位人物設計前，先查《三國演義》原文及專案既定資料，記錄兵器種類、出處與版本；有明確兵器時優先忠於演義設定，勿為共用動作改成槍。無明確記載時註明資料不足，再按人物身份設計，不把推測當史實。Q 版動畫另行處理。黃蓋用鐵鞭、韓當用大刀、程普用鐵脊蛇矛；關興青龍偃月刀的使用依演義情節及版本。
- 盔甲需按角色、勢力、身份與武藝設計不同輪廓、護肩、層次、材質及紋飾。知名度高或遊戲屬性強的角色可用更豐富而有主題的雕紋、金屬飾件與鮮明層次；一般角色較克制，但不可只是同一套換色。優先人物辨識與美術完成度，保留清新半寫實風格，不必拘泥於純史實復原。

- 按名冊及現行台帳確定性格、臉型、髮型及綁法、髮飾、妝容、身形、膚色和專屬武器，再生成。每人容易辨識；男女同畫風但不可同臉、同髮或同一套換色服裝。
- 無特殊指定時，蜀綠、吳紅、魏藍為基底，搭配不同第二色與中性色；沿用既定特例：張飛紅黑、黃忠黃黑、呂布紫黑、諸葛亮黑白。女性服裝衣帶簡潔，男性亦避免大量飄帶，少數文人可有克制例外。
- 立繪造型及手持物優先依人物身分、歷史背景與既定角色設定設計。關銀屏、馬雲騄等女武將可持符合角色的兵器；女性文士、仕女、樂師等不應為了共用動畫一律持槍，可選扇、樂器、文具或其他符合人物的道具。史實不足時不要將創作設定冒稱史實。Q 版武器與動畫可另行設計，不強迫立繪配合現有動作。
- 女武將若史料與既定角色設定都未指定兵器，可優先考慮劍作為通用選項；有明確武器、使用者指定或更能表現人物特徵的道具時，依其設定，不把劍變成另一種一律套用的模板。
- 大喬以單扇呈現，小喬以雙扇、淺藍色系及活潑的非旗袍式服裝呈現；大喬的成熟胸線與身形曲線參考 `assets/da-qiao-reference.png`，並遵守既定清新五官與半寫實材質畫風。甄姬造型及身材比例參考 `assets/zhen-ji-reference.webp`。此為遊戲美術設定，非史實斷言。
- 諸葛亮保留黑白主色與羽扇等既定角色設定；若立繪與系列風格不一致，優先重校臉部五官的微動漫感、乾淨明亮的膚色及服裝半寫實材質，不改成髒灰寫實風，也不擅自更換角色武器。
- 貂蟬採紅髮及西方異域風的創作造型，仍維持專案核定畫風；不將此設計描述為史實。
- 孫尚香定位為可騎馬作戰的女武將，造型可用輕甲、長槍及騎乘攻防姿勢；「十八般武藝皆通」作為遊戲角色塑造，不冒稱史實。設計時保留她的女性氣質與靈活俐落感，不套用其他女武將的臉、髮型或盔甲模板。
- 設計適合持用長柄兵器的角色或另製 Q 版武器時，優先考慮能共用既有雙手長柄動作的類別：長槍、矛、丈八蛇矛、鎲、鉤鐮槍；方天畫戟、單耳戟、雙耳戟；青龍偃月刀、長柄大刀、長柄朴刀；長柄斧鉞；長棍、長柄狼牙棒或長柄錘。槍矛突刺最自然，戟可刺砍，長柄刀適合揮砍，斧鉞突刺較不自然，棍棒突刺視覺較像戳擊。用兵器頭形、紋飾、色彩和金屬質感區分人物，避免為每人發明新機械結構。
- 供共用動作的武器須另畫獨立透明武器圖：直桿、尖端朝上，傾斜角依專案現有標準實測參照。以工作畫布像素量測，後手握點往前至少留 340 px 無遮擋光桿、往後至少留 150 px；兵器頭不能侵入握桿範圍，桿上不可有飄帶或流蘇橫跨雙手握點。近側手畫實拳，遠側手畫空心拳以供桿穿過；手畫在人身，不畫在武器圖上。實際共用須驗證握點、尺寸、動作與遮擋；概念不等於已驗收。
- 目前單手劍、單刀、鞭、鐧、雙股劍、雙戟、雙鞭、弓、羽扇、流星錘等軟兵器及短柄錘／短斧不適用既有武將共用動作，需另做動作；不得聲稱已相容。角色既定特殊兵器可保留並標明動畫待製，不為套模板擅改諸葛亮羽扇等明確角色設定。辛憲英籌策尺、三枚滑籌和大喬雙鈴杖同樣須標記為特殊道具，待對應動作設計與驗證。

## 雙姿勢立繪製作與交付

### 核定姿勢庫與批次順序

- 長柄武器姿勢以使用者提供的 001–090 編號圖為準，內部代碼 LH-001–LH-090；其中 061–090 是新增續編。不得恢復先前自製且已作廢的 001–050 草稿，也不得自行補造 091–100。
- 刀劍姿勢共 60 個，使用者提供編號 001–060，內部代碼 SW-001–SW-060。刀、劍可共用人體動作骨架，但依單手、雙手或雙持及刃口方向校正武器操作。
- 選姿前先查索引，記錄角色、武器、姿勢代碼、方向和狀態；已核定姿勢不可要求重選，也不可與同系列其他角色重複。圖上沒有動作文字時只登記號碼，不推測名稱。
- 目前批次順序：先完成所有女性長柄武器武將，再處理其他男性長柄武器武將；五虎將與呂布已選定姿勢，保持原決定。之後才依刀劍、弓弩、拳腳、短兵及特殊道具系列續排。

- 氣流必須對應當下武器受力與運動方向：先判讀雙手施力、身體旋轉、矛尖或刀刃的瞬時運動軌跡，再規劃氣流；突刺可在前方表現受壓擾動、後方表現拖曳，迴旋揮斬沿刀刃弧形軌跡展開。氣流、衣袍與武器慣性方向須相互協調，避免方向衝突、無由來的環繞或固定模板；此為美術合理性檢查，不宣稱流體模擬。

- 戰鬥立繪的速度感優先用武器帶動的局部氣流擾動或短促氣爆：在矛尖、刀刃周圍沿實際運動方向繪製少量漸淡的半透明氣流、壓縮與擴散弧線，呈現破風層次；可搭配克制速度線，不以平行線取代氣流。透明、局部且不可遮住臉、眼神、雙手握點或武器輪廓，也不以效果冒充彎曲兵器。避免大面積背景、煙塵和不透明光環；檢查小尺寸可讀性及遊戲裁切，可行時分層以便調整。

- 兵器依材質與受力表現：先明確判斷雙手握點、施力方向、武器頭部慣性及是否接觸目標，再決定桿身能否彎曲及彎向；沒有清楚的受力依據時保持直桿，以身體旋轉、衣袍與姿勢傳達速度，禁止為裝飾任意加彎。若確有合理彈性變形，幅度須輕微且曲線連續，握點位置合理，刀刃和矛頭等剛性部件不彎折；視覺草圖不足以證明物理正確，須依角色材質及動作檢查。獨立 Q 版共用武器維持既定直桿與握點規格，立繪變形不代表動畫相容。

- 防止小頭小臉：動態圖的顱頂至下巴尺度、臉部寬度及五官清晰度要與同角色站姿在相同顯示框中並排比較；若頭臉相對身軀過小，優先調整角色頭身與鏡頭透視，不可只縮小身體或用頭盔髮冠充當頭部。手機尺寸仍須辨識雙眼和表情，並維持成年比例與角色既定身形。

- 動態姿勢的身高與體態須和同角色站姿一致：先以站姿約 7.2–7.8 頭身及既定角色身形建立骨架，再讓腰髖、肩與膝自然轉動；避免過深蹲姿、透視放大前腿或武器而讓角色看起來矮胖、腿過短。高大武將保有修長軀幹與有力長腿，但不要將所有人物統一成相同身高體型。
- 在手機尺寸預覽全身，並與同角色站姿以相同顯示框比較：臉部大小可辨、腿長和腰線清楚、人物不能因過度留白顯小，也不可為放大而裁掉重要部位。畫布安全區是起始參考，須再到實際 Cocos 顯示框驗證；遇到高大人物、長柄武器或迴旋動作，以調整透視、構圖或顯示框解決，勿壓扁、拉伸或縮小頭部。

- 每位角色製作戰鬥立繪前，先以同一張圖提供三個可辨識的低細節全身動作草稿（A／B／C）供使用者選擇；草稿要保留人物、武器、受力、鏡頭視線及畫面安全範圍。使用者選定後才精修、納入正式資源與推送；未選定的草稿不可當正式作品。
- 動作需由腰、髖、肩與步伐形成連貫受力，迴旋劈擊要畫出身體轉動及刀勢瞬間。可適量使用隨動作飛揚的披風或衣袍，表現速度、氣流與空間層次；衣物方向服從身體運動，不遮擋臉、握點或武器，避免大量無目的飄帶。

- 每位武將目標準備兩張獨立透明立繪：既有站立／介紹姿勢，以及戰鬥瞬間姿勢。先清點名冊及實際資產，分別記錄站立、戰鬥、裁切與遊戲顯示的狀態；缺圖不可標示完成。優先使用使用者指定人物及名將，逐位交付。
- 戰鬥圖以該角色已核定站立圖為角色參考，維持相同臉型五官、年齡、體型、髮型及飾物、盔甲結構、勢力配色與角色專屬兵器；變化的是符合身分的動作與表情，不能變成另一個人。文士、樂師或仕女可用扇、樂器、文具等既定持物呈現臨戰或施策，不為戰鬥姿勢改成長槍。
- 戰鬥姿勢須呈現正在交戰、揮擊或施策的動態停幀，不是靜止備戰擺姿；呈現明確重心、施力方向、自然肢體轉折和符合角色性格的生動表情；例如刺擊、格擋、施策或演奏。透視變化須保留自然頭臉與身體比例，檢查手指、握點、兵器結構和遮擋。動作可有少量動勢，但不要大量飄帶、場景、文字或預先合成特效，讓角色與武器輪廓在遊戲小尺寸仍清楚。
- 動態戰鬥立繪的臉部盡量約七成朝向鏡頭，保留自然的動作與透視；即使頭部側轉，眼神至少要看向鏡頭，讓五官及生動表情清楚可辨。此處七成為視覺方向的構圖指引，非臉部可見面積的硬性測量值。
- 站姿與戰鬥姿勢均以關羽正式立繪 `sprites/generals/guan_yu_portrait.png` 的直式 2:3 畫布為尺寸基準：標準工作畫布 1024×1536 px（同構圖輸出 512×768 px 可作相容版本），透明背景、等比例縮放，不拉伸。關羽現圖實測 512×768；不要把橫幅或方圖直接當作人物介紹框的正式立繪。
- 為適應人物頁放大顯示，人物、髮冠／羽飾和主要武器的可見輪廓原則上收在畫布中央 75% 寬度；1024×1536 畫布對應 x=128–896，兩側各保留至少 128 px 透明安全邊界。動作靠轉身、步伐及前後透視呈現張力，避免橫向大幅展開或以裁斷武器換取動勢。高帽、羽翎與槍戟亦需納入輪廓；無法同時容納時調整姿勢與取景，不把臉縮小或拉伸人物。
- 上下也要保留透明餘量，頭飾、手、腳與兵器端點不貼邊；頭臉及身體比例按本 skill 的站姿標準和動態透視校正。人物頁目前以邏輯圖框等比 fit 後將圖像放大 1.3 倍，且有遮罩及其他 UI，因此中央 75% 是構圖預算而非不裁切保證。每張必須在實際目標 UI、常用視窗與窄畫面檢查臉、身體和武器，必要時調整構圖或介面；戰鬥顯示區尺寸確定前不得聲稱已適配。
- 以同角色站姿與戰鬥姿勢並排檢查臉、顏色、服飾、武器和大小；若互相無法辨認、手腳／武器破損或重要內容被 UI 裁切，重做後才交付。依使用者最新批次順序，先完成女性長柄武器武將的姿勢挑選與戰鬥立繪，再處理其他男性長柄武器武將；其後依角色武器系列與名冊續排。五虎將與呂布的姿勢已選定，不重新要求選姿。逐位記錄核定姿勢 ID，避免同一名冊長柄動作重複；未核定草稿不算已使用或正式成品。
- 正式來源先保留既有 `sprites/generals/{file}_portrait.png` 站姿；戰鬥版採 `sprites/generals/{file}_battle.png`，其中 `{file}` 為角色 id 的連字號換底線。不得覆蓋站姿或以站姿冒充戰鬥圖；頭像仍依核定站姿等比例重裁，戰鬥圖不自動改寫頭像。相同角色別名須核對實際資料引用與資產同步。
- 每位戰鬥圖經視覺檢查後才放入正式資源，刷新正確 Cocos 專案 AssetDB，並依產品確定的戰鬥顯示時機接入載入路徑與介面，實際檢查遊戲顯示。資產匯入成功不等於遊戲介面已播放；未接線或未完成畫面驗證時明確標示。個別提交並推送，保留其他工作；Q 版動作相容性需獨立驗證。

## 製作及交付

1. 讀專案共識、任務卡和色票；檢查鎖定、現有素材與其他角色。優先名將，逐位對照核定參考圖及相鄰角色；使用 imagegen 編修或生成，保留透明背景與全身完整構圖。
2. 縮圖優先按專案規定檢查臉、頭身、手、武器、服裝、顏色與角色差異；不把候選圖或 Q 版動作構想當作遊戲內驗收。
3. 每位完成後覆蓋正式立繪，使用 `general-avatar-crop` 與 `node tools_node/generate-general-avatars.js <generalId>` 重裁頭像，核對 `sprites/generals/avatars` 與 `sprites/ui_avatars/cropped`；核對同一人物的別名資源，刷新正確 Cocos 專案 AssetDB，檢視人物頁及頭像。無法實際檢視時明確回報限制。
4. 批次整理既有頭像時，先按正式人物 ID 去重並列出缺少來源或裁切設定的名單，再由各人物最新正式站立立繪分別產出大頭像與小頭像；每張都依本節比例、置中線和可見範圍校正，禁止沿用大頭、半身混雜的舊裁框。先保留舊版與來源對照，再逐批更新遊戲引用；若目前生成器或 UI 尚未支援兩種尺寸／裁框，先明確記錄缺口，不可把同一張圖重命名充當兩種頭像。
5. 在已授權範圍內逐位提交並推送，保留其他人的工作；紀錄檔案、角色特徵、配色、武器、裁框與實際驗證。持續檢查全名冊，未完成時保持任務進行中。

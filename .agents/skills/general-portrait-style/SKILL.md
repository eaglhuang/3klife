# 3KLife 武將立繪與頭像校準

## 小頭像自動取景（大喬基準）

自動人臉偵測只提供臉框候選，不能單獨驗收或產生正式小頭像。裁切必須使用 `node tools_node/small-avatar-crop-guide.js crop`，並人工標記 `head`、`face`、`extent` 及左右 `shoulders` 錨點；`extent` 必填且須涵蓋原圖全部頭部內容，包括頭髮、耳朵、頭盔、冠飾、髮簪、羽飾及其他配件。肩點必須落在真實肩面，不得標在脖子、衣領或胸前。標記預覽須對照原圖，確認頭部完整並盡可能納入兩側肩線。頭高量顱部髮型／盔體頂至下巴，不把高聳裝飾計入；一般頭高目標75%，稀疏髮型男性最低與目標90%，可接受90–92%；臉高最低65%、目標70%、上限80%，男女共用。完整頭部、頭臉置中與比例為硬性條件；兩側肩線應盡量入鏡，但屬次要條件，不能為了納入肩膀而縮小頭部低於75%。若原圖無法同框，優先換用另一張正式來源；仍無法兼顧時保留合格頭部比例並記錄肩線警示，不可裁掉頭飾、旋轉或重畫人物。幾何通過仍須目視檢查標記預覽及候選圖；不合格候選留在 temp，不得寫入正式目錄或 catalog。
## 核定畫風

參考 `assets/approved-male-comparison.png` **右半圖**及 `assets/approved-female.png`。兩圖是同一遊戲的風格與色調參考，不是人物臉型模板。臉部五官微動漫、輪廓乾淨精緻；皮膚明亮透潤、光影柔和；布料、金屬與頭髮具有細緻半寫實材質。避免灰濁髒褐陰影、泥污、過度做舊、照片毛孔、油膩磨皮及平面卡通服裝。依角色保留不同膚色、臉型、年齡和氣質。

## 男女立繪品質基準（唯一有效版本）

所有新圖與既有圖均以 [`portrait-quality-baseline-v6.md`](../../../artwork/general-art-library/style-references/portrait-quality-baseline-v6.md) 為唯一有效品質線；舊版 v1–v5 僅供歷史追溯。女性參考為 `female-quality-baseline-v3.png`；男性服裝參考為 `male-quality-baseline-v2.png`，男性骨架仍以 `male-quality-baseline-v1.png` 校準。兩張新參考是使用者提供原圖的未修改副本。所有既有立繪須按 v6 逐張覆核，未完成覆核前標示「未依新基準覆核」，不可默認合格。每張新圖依 v6 八項逐項判定，必須全數通過；任一項退回就留在 temp 修訂。參考只定義成熟半寫實完成度、鏡頭、身體結構、工藝密度、材質和光影，不複製角色本身。

### 男女共通的渲染與構圖底線

- 維持同一款明亮、乾淨、半寫實的遊戲插畫：臉部有明確五官結構、自然眼神與表情；皮膚使用柔和但有方向性的光影呈現體積；頭髮、絲布、薄紗、皮革、金屬、寶石須各有不同高光、粗細與反射特徵。避免灰濁陰影、塑膠磨皮、平塗服裝、無層次金屬，以及只靠亮邊假裝精緻。
- 全身靜態圖不是證件照式直立：以略低、偏側的三分之四鏡頭建立空間感；人物姿勢可較克制，但須有自然重心、肩胯錯向、前後步或手勢。戰鬥／舞蹈圖沿用同一角色設計與服裝系統，改變動作，不另換人物造型。
- 遠看先讀得出角色剪影、主色與氣勢；中距離看得出剪裁、甲片或布料分區；近看才看到刺繡、雕花、鑲嵌與珠飾。細節須依服裝接縫、受力位置和身體動線配置，不得以均勻貼花或零散堆飾代替設計。
- 配色以人物身份、個人象徵、武器與性格為首要，勢力色只可作輔助，不再把蜀綠、吳紅、魏藍當作所有角色的預設主色。沿用明確特例，例如呂布紫金、小喬藍色水系；其餘角色逐人建立主色、輔色及金屬色，避免相鄰角色只換色。

### 基準圖並排驗收門檻

- 每張候選都要和對應性別基準圖以相同畫面尺寸並排檢視；依序看剪影與配色、人物比例和姿勢、服裝結構、材質及局部工藝。不能因新圖尺寸較大、背景更亮或裝飾更密而誤判完成度較高。
- 八項逐項判定「通過／退回」：①成熟成人臉孔、眼神與表情；②成人骨架與比例；③鏡頭、姿勢及空間；④角色獨立剪影與辨識；⑤可穿戴服裝剪裁與結構；⑥材質分離與乾淨立體光線；⑦由頭肩至腿足的全身工藝；⑧同角色靜態／戰鬥造型一致、不同角色彼此有別。八項必須全數通過，禁止用平均分數抵銷缺陷。
- 女性若胸腰剪裁扁平、胸衣沒有承托結構、腰胯線被直筒衣袍抹掉，或手臂／腿部／鞋履成為空白區，即退回；男性若只把細節集中在胸甲徽章、護具未形成完整肩胸臂腰腿系統，或身體像窄肩扁軀幹配膨脹手臂，也退回。男女都要從縮圖辨認獨立剪影與配色，放大後才讀到精細工藝。
- 角色身份和專屬造型優先於基準圖的具體元素：借用它的工藝密度、材質層次、姿勢張力與鏡頭，不照抄粉白飄紗、藍銀龍甲、臉型、髮型或飾品。比較結果未達下限就留在 `artwork/temp/` 修訂，不進正式目錄、不更新 catalog 為正式資產。
- 新圖與舊圖都要逐項對照 `portrait-quality-baseline-v6.md`；八項全部通過才可進正式庫。任何一項低於相同性別基準，就退回修訂；禁止用平均分、特殊角色設定或高解析度作為豁免理由。

### 女性立繪最低完成度

以女性基準圖的成熟女性輪廓、立體服裝工藝與華麗程度作下限：胸線須由合身且可信的衣裝結構承托，胸、腰、胯連成清楚而自然的曲線；用斜向剪裁、立體胸衣、收腰結構、不對稱領口、側腰分區或裙衩塑造空間，不畫成平板直筒或厚袍遮沒身形。性感應來自剪裁、姿勢、光影與材質，不靠裸露取代設計。

每套服裝先訂專屬主題與輪廓，再至少清楚區分三種材質，並在上身、腰胯、袖肩／披帛、裙甲／下襬及足部中至少四個區域做完整設計。胸衣與領口要有支撐結構；腰線須明確；腿部與鞋履不得成為無細節空白區。珠寶可大方使用髮飾、耳環、項鍊、胸針、戒指、臂環、腰鍊、垂飾、腳環及精緻鞋面，但須有主次。薄紗與飄布用於透光、層次與動勢，不可遮掉主要剪裁或淹沒人物剪影。允許把現代時裝的立體剪裁、拼接及不對稱結構融入古典韻味；各角色不得共用同款胸衣、腰封、髮型或飾品配置。

### 男性立繪最低完成度

以男性基準圖的成年男性體態、細節密度與材料層次作下限。體型需符合角色定位，可修長敏捷，也可厚實魁梧，不可把所有男性套成同一種巨漢；但肩胸、腰胯、腿足必須有可信成人結構與自然頭身比例。重甲角色的肩甲、胸甲、護臂、腰甲、裙甲、膝脛甲與靴具須各有清楚分片、厚度、固定與活動關係；浮雕、暗紋、鉚接、金屬包邊與鑲嵌沿結構配置，不能只在胸口放徽章。金屬、織物、皮革與披風須一眼可辨；工藝從肩胸延伸至手臂、腰腿及足部。

男性體態以肩線明確、胸背有體積、腰胯自然、腿部比例完整為準；避免小頭、窄肩、扁薄軀幹、腿短或只把手臂畫得膨大。披風、飄帶與長髮可加強力量和方向，但要服從角色、鏡頭及動作，不遮臉、武器或甲片結構。男性骨架依 `male-quality-baseline-v1.png` 校準；服裝可參考 `male-flowing-armor-reference-v2.png` 的全身分層、材質反差、沿結構延伸的雕飾與腰胯連接方式，不複製其特定身形、色盤、羽狀甲、頭帶或長槍。

男性服裝工藝參考 `artwork/general-art-library/style-references/male-flowing-armor-reference-v2.png`，並以 `male-quality-baseline-v1.png` 校準男性成人骨架。新參考的重點是甲片自肩胸、護臂、腰胯、腿甲至靴具形成完整分層；裝飾沿甲片邊緣、中心軸與關節節點延伸；金屬、織物、皮革、琺瑯色塊與寶石具有不同反射；腰封、扣具、垂片把上身與下身裝備接成可穿戴系統；斜向武器與衣料弧線增加縱深。只吸收工藝方法，不把修長剪影、銀白藍金比例、羽狀肩甲、頭帶、馬尾、長槍或垂布輪廓套給其他人物。每名男性仍要依身份另訂體型、主輔色、徽記、甲型、裝飾母題與武器；文士、策士和輕裝角色可將相同的材質分層、結構連接和細節覆蓋轉化為袍服、皮革或織錦，不必穿重甲。

### 重繪盤點與交稿驗收

開始批次重繪前，先按正式武將名冊建立盤點表，逐人查看現有靜態立繪並記錄「保留／需重繪」及具體缺項，不憑縮圖或目錄數量判斷品質。每一張候選至少依六項逐一核對：①角色臉孔、年齡與辨識特徵；②成人身體結構與自然比例；③姿勢、鏡頭角度與空間層次；④服裝剪裁、結構及覆蓋範圍；⑤材質、光影與細節分布達到對應男女基準；⑥個人配色、武器、飾物與角色設定一致。任一關鍵項明顯未達基準即退回重畫，不用其他項目的高分抵銷。

先核定全身靜態立繪的角色外觀，再以同一造型製作戰鬥／舞蹈姿勢；之後依使用者既定流程，從靜態立繪裁半身像，再從半身像裁大頭照。裁切只准平移及等比縮放，不改人物臉、頭髮、服裝或飾物。每位角色的四件資產須分別核對一致性並登錄；頭像另遵守小頭像尺寸、完整頭部、中線置中及肩線規格。
## 比例校準

- 全身站姿以成年約 7.5 頭身為設計目標，參考區間 7.2–7.8；頭長以顱頂至下巴計，不含頭冠與羽飾。動態透視或蹲姿先校正姿態再判斷，不將畫面投影高度當成人體實際身高。按一致取景並排，避免頭部大小突然跳變。
- 靜態全身姿勢是小幅度動勢中的定格，不是僵直原地站立；可安排自然前後踏步、重心轉移、轉身側傾、手勢或衣料隨動。不可一律正面、雙腳併攏、軀幹僵直。男女角色都預設採略低、稍偏側面的鏡頭，形成輕微三分之四視角與空間層次；依角色氣質可調整角度，但除非使用者指定，不使用呆板正面視角。女性以自然優雅曲線為主，男性以肩胯透視、身形力量與氣勢為主；所有角色都須保持臉、雙手、武器及全身比例清楚。鏡頭透視要克制，不以過度廣角放大手腳或壓短身體。
- 可借鑑使用者提供的柔美全身姿勢參考之構圖方法，不複製其人物或服裝：以一條清楚的身體斜線串連頭、肩、腰與腿；肩胯錯向、重心落在一腿，另一腿以前後步或輕交叉形成延伸；雙臂分別做收與放的反向弧線，並讓髮絲、披帛、裙片沿姿勢延續成大中小層次的流線。動勢要顯得從身體重心自然生出，兼具優雅、空間感與角色氣勢，不用僵硬對稱或無目的飄帶。
- 臉部五官維持同一插畫尺度與清晰度：眼睛略帶動漫感但保留成熟臉部結構，兩眼位置、鼻唇與下顎自然；不以同一模板複製所有臉。依人物調整眉眼距、臉型、顴骨、鼻唇和表情，避免眼睛過大或幼態化。臉部預設採自然三分之四角度或輕微側轉，讓近遠側五官、鼻樑、臉頰與下顎形成透視層次；側角必須來自臉部本身轉向，不可只斜視或歪頭假裝側臉。避免所有人物都正面直視鏡頭。只有使用者明確要求正面時才畫正面，視線依角色氣質與動作決定。
- 眼型與眼神必須因人物而異：綜合調整眼裂長短與開合、眼尾方向、眼瞼厚薄、眉型眉距、視線和表情，不只更換虹膜顏色或睫毛。例如小喬可明亮活潑，黃月英可細長沉靜而專注；其他人物依性格設計，不將範例套成固定模板。生成前記錄角色眼部特徵，完成後與同系列頭像並排比較；若辨識主要依賴髮色或飾品，應繼續調整五官並複查。
- 每位武將都要由正式站立立繪另行製作兩種正方形頭像：大頭像 `avatar` 與小頭像 `small_avatar`。兩者分開取景與裁切，不可拿同一裁框放大／縮小充數，也不可把戰鬥立繪當頭像來源。輸出維持正方形（遊戲用 256×256 px），只等比例縮放，不拉伸臉或頭身。
- **大頭像 `avatar`（胸像）：** 以頭至胸甲上半部為構圖，頭頂／頭盔與主要髮飾完整，臉部五官完整；下緣落在上胸或胸甲中段，胸部／胸甲約佔畫面下方 35–45%，腰、腹部與腰帶一律不可出現。臉部量測框以額際至下巴為準（不含頭盔、髮飾、鬍鬚和脖子），高度約佔畫面 28–35%，視覺接近參考圖約 30%。畫面必須同時看見左右肩部輪廓，且胸部／胸甲上半部入鏡；只見頭頸、單側肩膀或肩線完全消失都判退。
- **小頭像 `small_avatar`（肩上頭像）：** 頭部高度以顱部髮型／盔體頂至下巴量測；冠飾、羽飾不計入頭高，但仍須完整保留。一般頭高以75%為目標，稀疏髮型男性頭高最低與目標90%、上限92%。臉框量額際至下巴及左右臉頰，下巴不可切掉；臉高最低65%、目標70%、上限80%，男女使用相同標準；男性臉框及頭框必須與核可女性樣本同尺度並排比較，不能因頭髮少而降低尺寸要求；臉框垂直中線須對準畫布中線，256×256容許最多1px差異。頭部所有內容都須完整保留，包括頭髮、耳朵、頭盔、冠飾、髮簪、羽飾及其他配件；不得自行補畫或裁掉。保留來源自然的三分之四或輕微側轉角，不正面化、不旋轉、不扭正五官。頭部完整、頭高與臉置中是硬性條件；左右肩面上緣是次要條件，能保留便保留，無法同時容納時記錄肩線警示，不可縮小頭部遷就肩膀。保留頸部，不露胸部正面、腹部或腰部。來源頭部本身已被畫面邊界截斷即判退。女性角色的髮型輪廓、髮量、髮色、編髮方式、髮飾及服裝識別設計均為鎖定特徵；不得為了提高臉框比例而簡化、刪減、移位、改色或重設計。其他角色造型與專屬配色也不得為遷就裁框而改動。若現有來源無法達標，只能換同一造型的正式來源或判退，不能把改款重畫當成裁切修正。使用者刪除的參考圖維持刪除，可讀取版本庫內容做暫存比較但不得還原正式資產。

## 女性身材與角色差異

女性角色均須明確為成年人。商業遊戲立繪以成熟、明顯豐滿、圓潤飽滿且由服裝自然承托的胸線為預設，搭配清楚收束的腰線與協調的臀部曲線，形成優雅 S 型輪廓。群像不可普遍畫成胸線單薄、平坦或偏幼態；各角色可依身形呈現不同肩寬、胸型、腰臀與腿部比例，但都保有成熟豐滿的基調，不做擠壓、過度裸露或失衡誇張。胸甲、衣襟、內搭與布料張力須交代自然支撐及合身剪裁，並符合動作受力。

女性服裝的開放度與曲線表現以大喬為最低標準，不要用高領、長袖、厚重層疊或寬鬆袍服把女性輪廓與膚色全部遮住。依角色身份至少選兩種設計明確呈現肩頸／鎖骨、手臂、上胸、腰線或腿部肌膚；以合身領口、露肩、短袖／無袖、腰身剪裁或利落開衩表現明亮乾淨的肌膚與身體曲線。可用局部半透明的絲質薄紗輕覆肩臂、腰側或腿部，做若隱若現的層次；胸部支撐結構與主要內搭仍須不透、合身且自然。薄紗是少量材質點綴，不堆成複雜長飄帶。每人仍要有自己的服裝輪廓、材質、色彩和持物，不把大喬造型複製給所有人；服裝保持完整、可穿著並能自然承托身形，避免以厚重布料回到保守包覆。

1. 以正式站姿為首選，同一角色有多張核定原圖就一起列入。小頭像可加用已整合大頭照作備援。大頭像只用正式站姿。先確認來源未截斷頭髮、頭飾或肩部。
2. 先用同一量法量七張核准小頭像，保存各張像素座標與相對比例。分別量頭高和臉高，不把高冠、羽飾、鬍鬚或脖子算進頭高。新圖的頭臉尺度必須並排比較，不能只看通過訊息。
3. 每張來源只標記一次。JSON 的 references 放七個核准 PNG 路徑，entries 放角色清單。每筆角色含 id 與 sources。每個來源含 file，以及 head、face、extent、shoulders、chest。前三個框為 [x,y,w,h]，雙肩為 [左X,左Y,右X,右Y]，chest 為 [上胸開始Y,允許裁切最深Y]。所有座標用原始 PNG 像素。extent 必須涵蓋頭部所有可見內容：完整髮型與髮束、耳朵、鬢髮、帽冠／頭盔、羽飾、髮簪、花飾、垂飾、辮子及其他頭部裝飾；任何一項被畫布邊緣截斷或裁框切掉，該來源即不合格。肩點為選填診斷資訊；標記時須落在真實肩面，不得落在道具、髮束或立領上。缺省或不通過只留警示，不改變裁框。
4. 執行 node tools_node/batch-general-avatar-crops.js <manifest.json> <批次名稱>。候選、比較板和 report.json 位於 artwork/temp/avatar-batch-<批次名稱>。每個來源和尺寸都會嘗試，有效候選使用等比取景。小圖沿用既有裁切工具的標準，大圖優先選臉較大的可行裁框，大圖保留雙肩和上胸；小圖不得因肩膀縮小頭部。
批次 manifest 必須分開設定頭部與臉部比例：`smallHeadCalibration` 預設 `{ "minimum": 0.75, "target": 0.75 }`，接受頭高75–80%；`smallFaceCalibration` 預設 `{ "minimum": 0.38, "target": 0.44 }`。前者量顱部髮型／盔體至下巴，後者量額際至下巴。工具強制臉高最低38%、目標44%、臉寬最低27.6%、臉框中線與畫布中心線重疊（256px輸出容許1px），以及完整頭部內容。肩點選填並只作可見度診斷；不納入裁框尺寸計算、不作為收入門檻。輸出檢查 faceScaleAdvice 建議倍率及完整頭部可行性。若來源無法同時容納完整頭部、置中臉與75–80%頭高，換來源或記錄來源缺口；肩線不足則保留警示，不縮小頭部。

5. 每個小頭像候選都輸出 `--centerline-out <preview.png>`：青色虛線為畫布中線，洋紅虛線為臉框中線；兩線必須重合，並確認臉框沿額際、雙頰與下顎準確標記。再看等尺寸比較板；確認一般頭高目標75%（稀疏髮型男性最低與目標90%、上限92%）、臉高至少65%且目標70%、頭部配件完整、臉部置中，並確認裁切保留來源自然側角且未被正面化。兩側肩面盡量清楚入鏡並記錄可見度；肩線缺失不能推翻頭部核心條件或讓裁框縮小頭部。大頭像另外確認上胸入鏡、腰腹不出現。只有核心幾何與視覺驗收通過的候選才能收入正式目錄並更新 catalog。

批次交接時以 repo 相對路徑填寫 file 與 references，使用 UTF-8 JSON，並隨批次保留標記檔與 report.json。id 使用英數、底線或連字號，每次使用新的批次名稱。模型可以替換，像素座標和同一份原圖必須可重用。腳本不會辨識人臉或肩膀，也不需要模型 API。請先用一位已標記角色試跑，確認比較板後再擴至全名冊。

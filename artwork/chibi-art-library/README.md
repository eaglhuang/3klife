# Q 版人物圖庫

這裡是 Q 版人物圖的正式美術來源庫，位於 `artwork/`，不會被 Cocos `resources` 自動打包。

## 製作順序

1. 在 `source/` 保存完整、透明背景、全身的高解析度 Q 版原稿。檔名：`{id}__{繁體中文名}__chibi_{版本四碼}.png`。母圖先經人物辨識、比例、武器和透明邊緣檢查，核定後才切割。
2. 在 `cutouts/{id}/{版本}/` 保存從核定母圖切出的動畫部件；保留共同畫布座標與接點，不回頭修改母圖。
3. 在 `manifests/{id}/` 保存分件清單、來源版號、SHA-256、接點與驗收狀態。未量測或未人工確認的欄位保持 pending。
4. 草稿與未採用候選放在 `artwork/temp/chibi/`，不放正式 source，也不直接接入遊戲。

`references/runtime-existing/` 是從遊戲既有 `resources/sprites/generals/chibi/` 原樣複製的低解析度參考圖，只供造型對照，不是高解析度切割母圖。遊戲原檔保持原位。來源及切件狀態以 `catalog.json` 為準。

## 切割注意

- 一張完整原稿是一個角色，不要把姿勢板或角色比較圖當作母圖。
- 保持角色身份、色彩、比例、武器和安全留白；不可為了分件改造型。
- 只有已核定母圖才能切割；每次切件要綁定 source version 和 hash。
- 切件和 rig/動畫是不同階段；有 PNG 部件不代表接點、骨架或動畫已驗收。
- 趙雲既有 Q 版造型與 v4 靜態分件已核定；先保留既定設計，不重畫成新造型。其完整高解析度母圖位置尚待整理確認。

## 目錄

- `source/`：正式完整母圖
- `references/runtime-existing/`：舊遊戲貼圖參考副本
- `cutouts/`：由核定母圖產生的分件
- `manifests/`：版本、hash、接點與驗收紀錄
- `../temp/chibi/`：草稿與待選候選

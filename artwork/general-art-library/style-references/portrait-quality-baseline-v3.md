# 武將立繪品質基準 v3（已由 v4 取代）

> 舊版封存供查閱，不再作為新圖或舊圖的驗收依據。唯一有效標準為 [`portrait-quality-baseline-v4.md`](portrait-quality-baseline-v4.md)；若本檔與 v4 不一致，一律採用 v4。

本基準依兩張使用者核定的男女立繪重新設定品質下限。女性參考圖為本次提供的大喬粉白羽扇立繪，收於 `female-quality-baseline-v2.png`；男性參考圖為藍白銀甲武將立繪，與美術庫既有 `male-quality-baseline-v1.png` 位元完全相同。比較的是完成度、人體與鏡頭塑造、服裝結構、材質區分、細節覆蓋與光影，不複製參考圖角色、臉、髮型、服裝、武器、裝飾母題或主色。

若現有規格與本 v3 標準矛盾，以 v3 為準。這是最低品質線，不是要求每張套同一套造型。新圖與既有圖都須逐張檢查；入庫、曾使用或解析度較高都不構成豁免。

## 男女共通底線

- **有空間的鏡頭與姿勢：** 靜態立繪仍是小幅動勢定格，不是證件照式正面直立。優先使用略低、稍偏側的三分之四鏡頭；讓肩胯有自然錯向，重心落在前後腳或單側支撐，並用手勢、持物或衣料方向形成流線。鏡頭需讀得到身體轉折和服裝曲面，不以過廣角扭曲四肢。
- **三層細節閱讀：** 縮圖先讀角色剪影、主色和氣勢；中距離讀剪裁、甲片、層疊和配件位置；放大才讀刺繡、浮雕、鑲嵌、鉚接與微小珠飾。細節沿服裝分區、接縫、受力與身體動線配置，不能只在胸口集中或平均貼滿花紋。
- **材質可辨：** 至少清楚區分三種主要材質；絲布、薄紗、皮革、毛皮、金屬、玉石與寶石須有各自厚薄、粗糙度、反射與高光邊界。亮邊不能代替材質結構，不能用灰濁陰影、塑膠磨皮或平塗金屬充完成度。
- **角色個體性：** 為每位角色先訂主色、輔色、金屬色、衣裝輪廓、裝飾母題和持物，再看相鄰角色比較剪影。勢力色只能輔助；不得只換顏色複用甲型、胸衣或飾品佈局。維持成熟半寫實、清晰五官與乾淨方向光。
- **七項逐張驗收，不平均計分：** 角色辨識與表情、成人身體比例、鏡頭與姿勢、服裝結構、材質與全身工藝、個人配色及光影、與名冊相鄰角色的造型差異。任何一項明顯低於對應性別基準即退回；背景更亮、裝飾更多或圖檔更大不能抵銷缺陷。

## 女性最低完成度

以大喬參考圖的成熟柔美輪廓、精巧剪裁、材質豐富度與全身細節覆蓋為下限。胸、腰、胯須形成自然連續的立體曲線；服裝以可信承托、收腰、斜向分割、不對稱領口、側腰結構或裙衩塑造曲面。性感來自剪裁、姿勢、面光與材質，不以裸露取代設計，也不因職業或性格一律改成寬袍。

每套造型先建立專屬主題和可辨識輪廓，至少三種材質；上身、腰胯、肩袖／披帛、下身、腿足五區中至少四區有完整呼應的工藝。上身須有實際支撐和立體面；腰線清楚；手臂、腿部與鞋面不得留成空白。髮飾、耳環、項鍊、胸針、手飾、腰鍊、垂飾、腳環和鞋面裝飾可豐富配置，保留主次與佩戴合理性。可融合現代時裝的立體剪裁、拼接與不對稱設計，但保留角色身份和古典韻味。

## 男性最低完成度

以藍白銀甲參考圖呈現的成年男性體態、甲片層疊、拋光金屬、精細浮雕和全身工藝覆蓋為下限。體格依人物定位變化，不把「男性」一律畫成巨漢；無論精瘦、敏捷或魁梧，都要有可信肩胸結構、清楚腰胯、自然長腿與成人頭身比例，避免小頭、窄肩、扁薄軀幹、短腿或只把手臂畫得膨大。參考圖的修長精實體態、明確肩線與收束腰身可作一種成熟武者比例選項，不是所有武將的固定體型。鏡頭可由略低的側前方取景，讓肩甲、胸甲、腰胯和前後腿形成清楚縱深，姿勢需有重心、步幅及武器／手勢方向。

武將盔甲要形成完整穿戴系統：肩甲、胸甲、護臂、腰甲、裙甲、膝脛甲與靴具的分節、連接、固定和活動關係都可讀。金屬包邊、鉚釘、浮雕、暗紋、鑲嵌和磨光方向順著甲片結構配置；細節由肩胸延伸至雙臂、腰腿和足部，不能只靠胸口徽章或少數亮金線。文士、策士或其他非重甲角色可採袍服、輕甲或混合設計，但仍需達到相等的剪裁、材質和全身工藝完整度。

參考圖的藍、白、銀、金、龍形裝飾與武器只是這張角色的識別，不得直接複製給其他男性。按人物重新選主色、徽記、甲片形制、披風／布料、頭部造型與武器；盔甲可以華麗，但每件裝飾都要沿結構或角色象徵落位。

### 男性服裝工藝補充參考

使用者另指定 `male-armor-ornament-reference-v1.png` 作男性服裝造型的工藝參考；該圖與 `male-quality-baseline-v1.png` 是同一檔案內容，應以一張基準理解，不重複計成兩個標準。可轉用的設計優點如下：

1. **剪影與鏡頭：** 直向修長的身體、三分之四側轉和略低視角形成挺拔感；武器斜線與披布、髮束的反向流線互相平衡，讓輪廓有前後層次。可學這種斜線平衡與空間組織，不必沿用長槍、長髮或同一姿勢。
2. **護甲層次：** 肩、胸、護臂、腰胯、腿甲和靴具各自分片，再以包邊、接縫、固定件和重疊陰影交代如何穿戴、活動；胸甲不是一塊平板，護具也不能以貼花取代厚度。
3. **裝飾節奏：** 浮雕、鏤空、細線、鉚件和寶石沿甲片邊界、中心軸及關節節點分布；肩胸與腰胯可作視覺重點，腿足仍保留相同工藝語言但降低密度。裝飾有主次和節奏，不平均貼滿，也不把所有細節塞在胸口。
4. **全身材質：** 拋光銀白金屬以清楚的明暗面、窄亮邊和接縫暗部呈現硬度；冷色織物以較柔的折光、織紋和垂墜表現柔軟；金色包邊與刺繡較暖、較細；半透明披布保留透光層次。角色至少要讓三種主要材質在縮圖或中距離就能分辨。
5. **工藝覆蓋：** 細節必須從頭肩連續走到手臂、腰腿、膝脛及鞋靴。每個區域都要有明確剪裁或裝備功能，遠看有完整套裝，中距離看得懂結構，近看才讀到雕花與鑲嵌；鞋靴、護腕和腰側不可因上半身精緻而留白。

套用時先替角色另訂體型、服裝覆蓋、主輔色、徽記、甲片形制、材質和裝飾母題，再選符合其武器的動作。不得直接複製參考圖的藍白銀金比例、龍形裝飾、臉、髮型、身體輪廓、裝甲剪裁、披布配置或武器；男性文士、策士與輕裝角色也不必硬套重甲，但剪裁、材質和全身工藝須達到相同完成度。

## 生成與完整資產流程

每位角色先完成一張靜態全身立繪，定稿後以同一臉、服裝、髮型、配色、飾物和武器製作一張戰鬥／舞蹈姿勢；然後從靜態圖裁半身像，再由半身像裁大頭照。四張依序為靜態、戰鬥、半身、大頭；裁切只允許平移、等比縮放和透明留白，不重畫或改造來源人物。四張各自記錄版本、來源和審查狀態。

盤點全名冊現有四類資產，依 v3 基準逐張標為保留或重繪，附具體不合格項；優先重畫女性武將、五虎將、高武力武將及高智力軍師。工作可逐人交付，但不可把目錄有檔視為品質通過。新圖先留候選區，視覺驗收達標後才收入 `artwork/general-art-library/` 並更新 catalog。頭像仍另遵守該 skill 的完整頭部、臉部中線及肩線規格。

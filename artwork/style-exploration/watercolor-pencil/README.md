# 水彩色鉛筆風格探索

此目錄保存風格試畫，與正式美術庫分開管理。`portraits/` 存放人物立繪試畫，檔名採 `{角色 ID}__{繁體姓名}__portrait_{四位版本號}.png`。

`index.json` 記錄人物檔案、來源生成圖與 SHA-256；`storyboards/` 保存漫畫分鏡。這些素材包含草稿及已退回版本，須依使用者確認後才可接入正式遊戲。版本缺號可能是已去除重複圖片。

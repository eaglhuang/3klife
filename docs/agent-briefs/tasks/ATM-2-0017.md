> **ATM 演進規劃 v2 開卡** — 建立演化管線的不退轉 + 品質進步雙重閘門。

## 問題描述

在 Police plugin 之上提供 vOld fixtures 對 vNew code 的不退轉檢查 + quality metrics 比較；輸出 quality-comparison-report。

## INPUT_CONTRACT

- 依賴卡片已 done 或可作 stub
- ATM 演進規劃書 v2 附錄 A 已併入規劃

## OUTPUT_CONTRACT (acceptance)

1. vOld 全部 fixture 對 vNew code 必須全綠（不退轉）
2. metrics 比較：errorRate(new) <= errorRate(old)、coverage(new) >= coverage(old)、latency(new) 不退化超過容忍值
3. 違規時 promote 動作必須 hard fail，並輸出 quality-comparison-report.json 列出退步指標

### 2026-05-06 附錄 B 原子地圖補丁（追加 acceptance）

4. quality-comparison-report 必須含 `mapImpactScope`（被影響的 mapIds[]）與 `propagationStatus`（per-map 整合測試結果）
5. 若任一被影響的 map 整合測試 fail，promote 動作必須 hard fail

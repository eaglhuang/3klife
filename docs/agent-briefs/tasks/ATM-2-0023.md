# [ATM-2-0023] Atomic Map Schema & Registry

> **ATM 演進規劃 v2 附錄 B 開卡** — 把 Atomic Map 升格為 registry 一等公民，為 map-level 演化建立可機讀基礎。
> **定位**：ATM-2
> **前置依賴**：ATM-2-0014

## 問題描述

為「原子地圖」建立 schema 與 registry：mapId / mapVersion / members[] / edges[] / entrypoints / qualityTargets / mapHash；可獨立於單一 atom 升版。

## INPUT_CONTRACT

- 依賴卡片已 done 或可作 stub
- ATM 演進規劃書 v2 附錄 A 已併入規劃

## OUTPUT_CONTRACT (acceptance)

1. atomic-map.schema.json 定義 mapId / mapVersion / members[](atomId@version) / edges[] / entrypoints / qualityTargets / mapHash
2. mapHash = hash(sorted(members) + edges + entrypoints)；成員任一 atom 升版必須引發 mapHash 變更
3. registry 同時支援 atom entry 與 map entry；舊 atom-only registry fixture 仍綠
4. fixtures：minimal-map / multi-edge-map / quality-targets-missing 三種

### 2026-05-07 識別/行為提案追加（不重啟驗收）

5. atomic-map.schema.json 追加 optional 欄位 `semanticFingerprint`（map 行為指紋，由 entrypoint+qualityTargets 推導）、`lineageLogRef`（map 系譜 log URI）、`ttl`（map 自我毀滅時限）
6. hot map entry 欄位數 ≤ 10；lineage / evidence / TTL history 走外部 ref（cold artifact）

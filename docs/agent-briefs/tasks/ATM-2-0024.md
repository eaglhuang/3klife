# [ATM-2-0024] Map-Level Upgrade & Extract-vs-Bump Decision

> **ATM 演進規劃 v2 附錄 B 開卡** — 把「升版 vs. 拆原子」這個關鍵架構決策正式機讀化，避免演化階段隱性破壞 consumer。
> **定位**：ATM-2
> **前置依賴**：ATM-2-0020 / ATM-2-0023

## 問題描述

在 upgrade pipeline 加入 decomposition decision：判斷某次改動應走 atom-bump / atom-extract / map-bump，並落地對應 proposal 與 review path。

## INPUT_CONTRACT

- 依賴卡片已 done 或可作 stub
- ATM 演進規劃書 v2 附錄 A 已併入規劃

## OUTPUT_CONTRACT (acceptance)

1. CLI atm upgrade --target map --map <id> --to <ver> 可產出 map-level proposal
2. decompositionDecision 規則明文：API 不變→atom-bump；行為斷裂→atom-extract；跨原子改動→map-bump
3. atom-extract 模式下 proposal 必須同時列舊 atom 保留資訊與新 atom spec stub
4. map-bump 模式下 proposal members[] 必須含舊→新 atomId@version 對照
5. review queue 視 decompositionDecision 路由至對應 reviewer template

### 2026-05-07 識別/行為提案追加（不重啟驗收）

6. decompositionDecision enum 加入四個新值：`polymorphize`（多形變體；不改 atomId）、`extract-shared`（不同 map 抽出共用 atom）、`infect`（legacy 注入既有 atom；不創新原子）、`atomize`（legacy 抽出新原子）
7. 每個新增 enum 值對應 ATM-2-0029 reference behavior pack 的某個 behavior plugin；reviewer template 同步擴充

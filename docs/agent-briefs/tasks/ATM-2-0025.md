# [ATM-2-0025] Cross-Atom Integration Test Runner

> **ATM 演進規劃 v2 附錄 B 開卡** — 硬規則：任一 atom 升版必須跑所有引用 map 的整合測試；本卡是這條規則的執行器。
> **定位**：ATM-2
> **前置依賴**：ATM-2-0003 / ATM-2-0023

## 問題描述

提供 map-level integration test runner：當任一成員 atom 升版時，自動跑該 atom 所屬全部 map 的整合測試與 application-level smoke tests。

## INPUT_CONTRACT

- 依賴卡片已 done 或可作 stub
- ATM 演進規劃書 v2 附錄 A 已併入規劃

## OUTPUT_CONTRACT (acceptance)

1. CLI atm test --map <mapId> 跑 map-level integration tests 並輸出符合 metrics schema 的 report
2. CLI atm test --propagate <atomId> 自動找出所有引用該 atom 的 maps 並跑 integration tests
3. integration test report 含 perMapStatus[] / propagationDuration / failedDownstream[]
4. birth-mode atom test 與 map-level test 共用同一 metrics schema（ATM-2-0016）
5. fixtures：propagation-pass / propagation-fail-on-downstream-map 兩種

### 2026-05-07 識別/行為提案追加（不重啟驗收）

6. map integration runner 對下列 behavior 也必須觸發完整 propagation：`behavior.split`（成員被切開）、`behavior.merge`（成員被合併）、`behavior.atomize`（legacy 抽出新原子加入 map）、`behavior.infect`（legacy 注入點變動但 atom 本身不變，仍跑 smoke）

### 2026-05-07 ATM-2-0042 Map Generator 連鎖影響追加（不重啟驗收）

7. `atm test --map <mapId>` 須支援雙路徑解析：canonical `atomic_workbench/maps/<mapId>/` 優先，fallback legacy `atomic_workbench/atoms/<owner>/map/`（附 migration warning）
8. `atm test --propagate <atomId>` 須包含 generator registry 寫回的 map，不只 filesystem scan
9. Map integration test report 輸出到 canonical `atomic_workbench/maps/<mapId>/map.test.report.json`（三件套 convention）

# [ATM-2-0029] Reference Behavior Pack（10 內建行為）

> **ATM 識別/行為/狀態機提案開卡** — 10 個內建 behavior 的 reference plugin pack，含 Legacy 整合的 infect 與 atomize。
> **定位**：ATM-2
> **前置依賴**：ATM-2-0028

## 問題描述

提供 10 個內建 behavior reference plugin：split / merge / compose / dedup-merge / sweep / evolve / expire / polymorphize / infect / atomize。infect 與 atomize 是 Legacy strangler 的核心動作。每個 plugin 含 spec / code / dry-run snapshot。

## INPUT_CONTRACT

- ATM-2-0028 AtomBehavior SDK 已落地

## OUTPUT_CONTRACT

- [ ] 10 個 behavior plugin
- [ ] 10 份 dry-run fixture
- [ ] 不污染 core 的 layer-boundary 證據
- [ ] behavior.split 支援 demand-trigger：接受 caller-distribution report 作為 split 觸發 evidence
- [ ] `behavior.compose` 須委託 `generateAtomicMap()`（ATM-2-0042）做 map entry 建立；compose 只提供 member list + edges，generator 負責 ID allocation / scaffold / registry write-back
- [ ] `behavior.split` 若產出 map（atom 分裂為 sub-atoms map），也須使用 map generator
- [ ] `behavior.atomize` 建立新 atom 後若成為 map 成員，須用 canonical `ATM-MAP-{NNNN}` 格式記錄 membership
- [ ] `behavior.infect` 與 `behavior.atomize` 產生的 dry-run patch，必須包裝為 `ATM-2-0020` proposal；`decompositionDecision` 預設 `atom-extract`，經 `ATM-2-0021` 通過前不得 apply 到 host project
- [ ] `node scripts/validate-behavior-pack.mjs` 必須可獨立驗證 10 個 plugin 目錄、registry registration、layer-boundary 與 infect/atomize proposal wrapping
- [ ] exemplar 至少以 `fixtures/behaviors/behavior-pack.manifest.json` 列出 10 個 behavior 的 canonical dry-run fixture 與 expected outcome，供 validator 逐項重放

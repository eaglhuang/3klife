# [ATM-2-0032] Polymorphic Atom Template

> **ATM 識別/行為/狀態機提案開卡** — 廣義多形原子規範（multi-dimension polymorphism）：template + dimension-spec lazy 實例化，升版時所有變體自動繼承。
> **定位**：ATM-2
> **前置依賴**：ATM-2-0026 / ATM-2-0029

## 問題描述

為「廣義多形原子」建立規範（ATM-POLY-001）：不限於參數差異，任何高度相似 spec（差異可被維度參數解釋——包含參數/類型/語言/品質/輸出形狀/行為變體）皆為多形化候選。一個 polymorphic template + 多個 dimension-spec 各自一份，實例化結果 lazy 產生不寫進 registry。template 自身是 active；具體實例為 validated。與 behavior.evolve 整合：升版時 template 升 → 所有實例自動繼承新版邏輯。

## OUTPUT_CONTRACT (acceptance)

1. h2u-map v1.0 寫入 registry，含 qualityTargets
2. 路徑 1：normalizeCssColor v1.0→v1.1 觸發 map propagation 測試，全綠後 atom-bump 落地

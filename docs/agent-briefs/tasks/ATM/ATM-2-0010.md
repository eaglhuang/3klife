# [ATM-2-0010] RuleGuard Read-Only Validator

> **ATM self-hosting first** — 這張卡現在負責把 RuleGuardAdapter 的 read-only 邊界變成 deterministic gate，避免工具鏈偷偷走寫入路徑。
> **定位**：ATM-2 / RuleGuard read-only gate
> **依賴卡**：ATM-2-0007、ATM-2-0008

## 任務說明

本卡要建立 upstream RuleGuard 的 read-only deterministic gate：只允許讀檔與 read-only child process 檢查，不能直接碰 task card / lock / shard / doc registry / lifecycle status mutation path。這張卡只證明 preflight 是只讀的，不擴張成新的 task-router / lock 功能卡。

## INPUT_CONTRACT

- governance schema 與 local reference plugins 已定義
- guard 需同時涵蓋 code 與 docs surfaces
- `tools_node/run-rule-guard.js`、`tools_node/adapters/atm-3klife/rule-guard-adapter.js`、`tools_node/adapters/atm-3klife/rule-pack.json`
- 只允許 read-only child process 與讀檔檢查，不允許 mutation path

## OUTPUT_CONTRACT

- `rule-pack.json` 必須新增 `rule-guard-read-only`，並掛進 ATM profile
- deterministic validator 必須輸出 `trigger / scope / severity / action / routeClass / routeHint`
- RuleGuardAdapter 必須維持 read-only child process 與讀檔檢查
- report 與 finding 必須 machine-readable，且可穩定重跑

## 產出

- `tools_node/validate-rule-guard-read-only.js`
- `tools_node/adapters/atm-3klife/rule-guard-adapter.js`
- `tools_node/adapters/atm-3klife/rule-pack.json`
- read-only finding report

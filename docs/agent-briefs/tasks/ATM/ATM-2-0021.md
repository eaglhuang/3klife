# [ATM-2-0021] HumanReviewGate as reference plugin（000013）

> **ATM 演進規劃 v2 開卡** — 人類審核閘門以 reference plugin 形式落地，避免污染 core hard dependency。
> **定位**：ATM-2
> **前置依賴**：ATM-2-0020 / ATM-2-0008

## 問題描述

以 reference plugin + effect node 形式提供 human review queue；core 僅依賴 schema 不依賴實作。

## INPUT_CONTRACT

- 依賴卡片已 done 或可作 stub
- ATM 演進規劃書 v2 附錄 A 已併入規劃

## OUTPUT_CONTRACT (acceptance)

1. 實作位於 packages/plugin-human-review/*；packages/core 不可 import 此 package
2. .atm/reports/upgrade-proposals.json 為審核佇列；支援 approve / reject + reason 兩種 decision
3. decision log 寫入 evidence store（evidenceType=human-review-decision）
4. layer-boundary scanner 必須擋下 core → plugin-human-review 的任何 import
5. CLI 補 `atm review list` / `show <proposalId>` / `approve <proposalId> --reason` / `reject <proposalId> --reason` 四個子命令
6. approve / reject 必須同時落 evidence 與 `decision-snapshot.hash`，鎖定當下 `upgrade-proposal.json` 內容雜湊
7. `upgrade-proposals.md` 僅可作 audit projection，不得成為 source of truth；欄位固定為 `proposalId / atomId / fromVersion → toVersion / decompositionDecision / automatedGates / status`
8. `node scripts/validate-human-review.mjs` 必須可獨立驗證 review queue record、`decision-snapshot.hash` 與 evidence linkage，不依賴 full suite
9. exemplar 至少保留 approve / reject / snapshot-hash-mismatch 三組，可直接重放 CLI 輸出到 validator

# [ATM-2-0022] Rollback Registry Pointer & 三段 hash Proof

> **ATM 演進規劃 v2 開卡** — evolution 管線的最終安全網：失敗時可確定性回退，並留下可驗證 proof。
> **定位**：ATM-2
> **前置依賴**：ATM-2-0014 / ATM-2-0021

## 問題描述

提供 `atm rollback` CLI 與 `rollback-proof`：將 `currentVersion` 指回歷史版本，驗證 spec/code/test 三段 hash、status 與 semanticFingerprint 都與目標 entry 對稱回退，並支援 atom / map 雙模式安全網。

## INPUT_CONTRACT

- `ATM-2-0014` registry version history 可提供 atom / map history entry。
- `ATM-2-0021` review decision 已產生 approve / reject / rollback 來源。
- `ATM-2-0029` behavior pack 可提供 `behaviorId` 對應 reverse action。
- `ATM-2-0042` map generator 連鎖影響要求 canonical map workbench 路徑與 `mapGeneratorProvenance`。
- 附錄 C 治理補丁要求 rollback proof 同時驗證 hash、status、semanticFingerprint。

## OUTPUT_CONTRACT (acceptance)

1. CLI atm rollback --atom <id> --to <ver> --plan 先輸出 dry-run plan；--apply 才真正寫 registry
2. rollback 後 atm verify --self 必須顯示 spec/code/test 三段 hash 與目標版本完全一致；任一不符即 hard fail，產出 rollback-proof.failure.json
3. rollback-proof.schema.json 含 atomId / fromVersion / toVersion / hashesVerified / verifiedAt / proofId
4. evidence store 寫入 evidenceType=rollback-proof
5. CLI atm rollback 支援 `--target map`；map rollback 必須同時驗證所有成員 atom 的 hash 與目標 mapVersion entry 一致
6. rollback-proof 對 map 模式輸出 `memberAtomProofs[]`，逐一列三段 hash 驗證結果
7. rollback-proof.schema.json 必須含發起的 `behaviorId`（哪個 behavior 的 rollback；例如 `behavior.evolve` / `behavior.merge`）
8. rollback contract 對稱性：每個 behavior 的 forward action 必須有對應的 reverse action；rollback 引擎可從 behaviorId 查 reverse 規則
9. Map rollback workbench 路徑解析須支援雙路徑：canonical `atomic_workbench/maps/<mapId>/` 優先，fallback legacy `atoms/<owner>/map/`
10. `rollback-proof.schema.json` map mode 須含 `mapGeneratorProvenance` 欄位，標示 map 是否 generator-born
11. `rollback-proof` 必須含 `statusReverted` 與 `semanticFingerprintReverted` 兩個布林欄位；任一為 `false` 即 hard fail，不得宣稱 rollback 成功
12. `node scripts/validate-rollback-proof.mjs` 必須可獨立驗證三段 hash proof、`statusReverted` / `semanticFingerprintReverted`、map rollback 雙路徑解析與 `behaviorId` 對稱性
13. exemplar 至少保留 `proof-pass` / `proof-fail-hash-mismatch` / `proof-fail-status-not-reverted` / `proof-fail-semantic-fingerprint-not-reverted` 四組，供 validator 直接重放

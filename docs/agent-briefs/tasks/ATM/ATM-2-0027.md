# [ATM-2-0027] Atom Status State Machine

> **ATM 識別/行為/狀態機提案開卡** — 為原子建立無模糊地帶的狀態機，使每個原子任何時刻恰處一個 status，由特定 behavior 觸發轉換。
> **定位**：ATM-2
> **前置依賴**：ATM-2-0026 / ATM-2-0014

## 問題描述

收斂 status enum 為 draft/validated/active/transitioning/deprecated/expired/quarantined；把 governed 改為獨立的 governance.tier 屬性；定義合法 status transition 矩陣與 police hard-fail 規則。舊值（seed/active/experimental/deprecated/governed）有 migration map 對應。

## INPUT_CONTRACT

- ATM-2-0026 sf/lineage/ttl schema 已落地

## OUTPUT_CONTRACT

- [ ] status enum 收斂
- [ ] governance.tier 屬性
- [ ] legal transition 矩陣
- [ ] migration map
- [ ] 狀態機 transition 須檢查 `mutabilityPolicy`：immutable atom 拒絕非退役行為；frozen-after-release 只允許 evolve
- [ ] Status enum 與 transition matrix 須同時覆蓋 atom 與 map registry entry；map 經 generator 誕生時 initial status = `draft`
- [ ] Migration map 須包含 legacy map entry（如 ATM-MAP-NEUTRALITY-0001，目前無 status 欄位）
- [ ] `status-machine.ts` 須接受 atomId 和 mapId 兩種 entry type；legal transition 檢查不可假設 entry 只是 atom
- [ ] migration fixtures 必須覆蓋「`versions[]` 已存在 + 舊 status 值 `seed/governed`」的 entry，確保與 ATM-2-0014 的跨卡升級路徑可通過
- [ ] human review reject 後的狀態處置必須定義：approve → `active`；non-fatal reject → 維持原 status；fatal reject → 寫 `pendingQuarantineRequest`，再由 lifecycle police 異步決定是否轉 `quarantined`
- [ ] `node scripts/validate-status-machine.mjs` 必須可獨立驗證 atom/map legal transition、legacy migration 與 review reject disposition
- [ ] exemplar 至少保留 `legal-transition` / `illegal-transition` / `legacy-map-migration` / `review-reject-pending-quarantine` 四組，供 validator 直接重放

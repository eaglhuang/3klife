# [ATM-2-0030] Registry Version / Fingerprint Backfill Sweep

> **ATM Registry backfill sweep** — 用 deterministic reporter 檢查 `versions[] / semanticFingerprint` 的歷史回填，並把 RegistryIndex 與 registry catalog projection 的一致性一起驗證。
> **定位**：ATM-2 / registry backfill sweep
> **依賴卡**：ATM-2-0026、ATM-2-0029、ATM-2-0005

## 任務說明

本卡不再只做 dedup police 的原始構想，而是承接 `versions[] / semanticFingerprint` 的 backfill sweep：要能掃出 hot entry、歷史版本、RegistryIndex 與 registry catalog projection 的差異，並輸出穩定排序的 machine-readable report。upstream `validate:registry-core` 與 `validate:registry-catalog` 的結果也要被一起帶進報告。

## INPUT_CONTRACT

- upstream `atomic-registry.json` 是 sweep 的唯一 registry source of truth
- RegistryIndex / registry catalog projection 以 upstream helper 為準
- `ATM-2-0026`、`ATM-2-0029`、`ATM-2-0005` 已完成，作為本卡的前置規格背景
- 任何 sweep 結果都不能回頭修改 done 卡或新開 follow-up 卡

## OUTPUT_CONTRACT

- backfill sweep report 必須列出 `missing historical sf`、`pendingSfCalculation`、`catalog/index mismatch`、`legacy-no-sf allowlist` 四類結果
- hot entry `semanticFingerprint`、`versions[*].semanticFingerprint`、RegistryIndex 與 registry catalog projection 必須對齊
- upstream `validate:registry-core` 與 `validate:registry-catalog` 的 status 必須被包進同一份 sweep report
- report 輸出必須 machine-readable，且可重跑得到穩定排序

## 產出

- `tools_node/validate-registry-backfill-sweep.js`
- registry backfill sweep report
- catalog / index consistency summary
- upstream registry-core / registry-catalog status evidence

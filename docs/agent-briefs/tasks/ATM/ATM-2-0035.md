# [ATM-2-0035] Official Review Advisory Provider (AI Code Reviewer, non-blocking)

> **ATM advisory review 開卡** — 補上 deterministic validate 之外的語意式 code review advisory layer，但只作建議，不直接決定 pass/fail。
> **定位**：ATM-2（alpha1 companion / advisory review layer）
> **前置依賴**：ATM-2-0008 / ATM-2-0009 / ATM-2-0010 / ATM-2-0021 / ATM-2.5-0003

## 問題描述

補上 deterministic validate 之外的語意式 code review advisory layer，但只作建議，不直接決定 pass/fail。

## INPUT_CONTRACT

- review scope 可來自 changed file list、git diff、upgrade proposal、registry diff 或指定 atom/map 範圍
- provider 可以是 stub、agent-bridge、external-cli，core 不直接依賴 vendor SDK
- report / evidence 必須能映射到 .atm/reports/* 與 EvidenceStore contract
- deterministic validate chain 仍維持單獨可跑，不依賴 advisory provider 可用性
- host 端可以用 agent skill / subagent / editor tool 去接入，但那只是 adapter 實作，不是 framework semantic requirement

## OUTPUT_CONTRACT

- [ ] 落地 packages/plugin-review-advisory/*，packages/core 不可 import 此 package
- [ ] 新增 schemas/review-advisory/review-advisory-report.schema.json，至少定義 scope、findings[]、summary、providerKind、modelProfile、advisoryOnly
- [ ] review-advisory findings must preserve `trigger / scope / severity / action / evidenceRefs / routeHint`
- [ ] 官方 provider contract 使用中立詞，例如 ReviewAdvisorProvider / AgentReviewBridge，不把 skill 寫成 core vocabulary
- [ ] provider mode 至少支援 stub、agent-bridge、external-cli 三種
- [ ] agent-bridge 可由 host 端映射到 editor agent skill，但 upstream protected docs 不可硬寫特定 vendor slash command
- [ ] provider 缺席或失敗時，CLI 產出 advisory-unavailable 或 needs-review，不得讓 npm test、npm run typecheck、npm run lint、atm self-host-alpha --verify --deterministic 失敗
- [ ] advisory report 可附掛到 human review queue，但不能直接取代 approve / reject decision
- [ ] advisory report may ingest machine-readable police findings and preserve review-first routing hints for the human queue
- [ ] 3KLife 第一版直接消費這套官方 reviewer，不另建第二套 reviewer 邏輯
- [ ] fixtures 至少覆蓋 stub-pass、stub-warn、malformed-provider-response、no-provider-dry-run 四種情境

# [ATM-2-0037] Workbench Alias Drift Guard and Projection Alignment

> **ATM workbench alias guard 開卡** — 建立非 canonical alias 目錄的 drift guard，並統一 projection 對 atomId / logicalName 的呈現。
> **定位**：ATM-2（guardrail / projection alignment）
> **前置依賴**：ATM-2-0013 / ATM-2-0034 / ATM-2-0036

## 問題描述

補上自動驗證與展示層收斂，避免 logicalName 再被誤當成 atomId 或 workbench 目錄名，並在 human-readable projection 明確分開 atomId 與 logicalName。

## INPUT_CONTRACT

- canonical workbench layout 已定義為 atomic_workbench/atoms/<atomId>/
- logicalName 仍可保留於 registry/spec，但不得再當成 workbench folder name
- 至少存在一份 human-readable projection 曾把 logicalName 當成 id 呈現

## OUTPUT_CONTRACT

- [ ] 新增或擴充 deterministic validator，檢出 atomic_workbench/atoms 下非 canonical alias 目錄 drift
- [ ] 驗證規則需容許合法 canonical ATM-* workbench 與明確 adapter override，不可誤殺正式 sourcePaths
- [ ] registry catalog 與其他 human-readable projection 若呈現 atom 身分，必須明確區分 atomId 與 logicalName
- [ ] 補 fixture 或 snapshot，覆蓋 stray alias dir 與 projection 欄位對齊情境

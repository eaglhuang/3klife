# [ATM-2-0050] Framework Function Atomization Coverage Gate

> **ATM dogfooding coverage gate** - 建立 Framework Function Atomization Manifest 與 coverage gate，證明 ATM framework Layer 2 功能都有 atom / map / adapter facade 或正式例外。
> **定位**：ATM-2 / framework-wide dogfooding coverage
> **不重複範圍**：ATM-2-0038 / ATM-2-0041 / ATM-2-0042 已承接 AtomGenerator / MapGenerator / provenance；ATM-3-0015 只覆蓋 task card system atomic map。

## 問題描述

ATM 需要一個 framework-wide coverage gate：人類看得到 canonical manifest，機器讀得到 JSON inventory，validator 會把 inventory / fixture / task store 三者鎖在一起，避免 Layer 2 功能再長出第二份真相。這張卡負責把 gate 做成可重跑、可回寫、可追蹤的基礎設施，不重複 AtomGenerator、MapGenerator、task lifecycle atomic map 與既有治理卡。

## 固定路線

後續所有 framework-wide 原子化與 coverage gate 變更，固定依序：

1. `ATM-2-0048`：task-router / onboarding。
2. `ATM-3-0015`：task card lifecycle atomic map。
3. `ATM-2-0050`：framework-wide coverage gate。

補充規則：

- `ATM-2-0049` 已完成 task id reservation / lock hardening，視為已落地前置，不再占順序節點。
- 以上前置都已完成時，`ATM-2-0050` 直接承接 coverage gate，不能再回頭把 gate 降回純文件敘述。

# ATM-2-0057 actors.json 只差時間戳不寫檔

- owner: ClaudeCode_claude-haiku-5-5
- priority: P1
- status: done
- phase: ATM-2

## 問題

ATM 框架封裝 payload（`atm.mjs` 內嵌，hash 鎖定，本 repo 不能改源碼）的 `writeActorRegistry` 會在每次身分使用（上鎖、續租、adopt）時，無條件重寫 `.atm/catalog/registry/actors.json`，把 `generatedAt` 與該身分的 `updatedAt` 改成現在時間。內容實質未變，卻讓追蹤檔常駐未提交差異，擋住 `git merge --ff-only`，並造成多 Agent 衝突。

## 解法（repo 端，通用規則）

- `tools_node/atm-actor-registry-guard.js`：行程開始快照 registry 位元組；結束時若現況只差 volatile 時間戳（頂層 `generatedAt`、各 actor 的 `updatedAt`），寫回原位元組。
- `atm.mjs` 外層包一層，在啟動時掛上 guard，行程 `exit` 時執行還原；guard 載入失敗時不影響 CLI。
- 「最後使用時間」不寫進追蹤檔；框架既有 `.atm/runtime/identity/*`（已 gitignore）持續記錄。

## 驗收

- 單元測試 `tests/AtmActorRegistryGuard.test.ts`：同一身分重複使用、內容不變時，位元組完全不變。
- 實質變化（新增身分、改欄位）保留框架寫入結果。
- compute-gate standard 12/12、`tsc -p tsconfig.test.json --noEmit` 0 錯。

## 上游問題（ATM framework）

`writeActorRegistry` 應在序列化後與現有內容比對（忽略 `generatedAt` 與 `updatedAt`），內容無實質變化時不寫檔。詳見 PR 說明。

## 完整描述

- rule-pack.json must encode `trigger / scope / severity / action` plus `routeHint` for proactive police outputs
- check-task-scope.js 標 @deprecated 並加 stderr warning
- check-import-boundaries.js 標 @deprecated 並加 stderr warning
- ATM RuleGuardAdapter 從 rule-pack.json 讀取規則
- compute-gate atm profile 改走 ATM RuleGuard 執行規則

## 開單原因
MVP 驗收要求跑通「祖→父→子」三代循環，而結緣、開獎、培育、壽命都依賴「時間會前進」與「進度會被保存」。目前沒有遊戲時鐘，`SaveSerializer` 也沒有任何呼叫點。

## 範圍
- 新增不依賴 `cc` 的純 TypeScript 遊戲時鐘（季度 tick、年份、武將增齡事件）
- 玩家存檔快照（時鐘 + 名冊）可序列化 / 還原，接上既有儲存 adapter
- headless 測試：推進 4 季後存檔、重建、還原，年齡與季度正確

## 不在範圍
- 同步雜湊與 `/sync/*` 端點契約（另開同步契約卡）
- 結緣、培育等玩法本體

## 驗收條件
- 新增測試全過，既有 `npm test`、`run-cli`、`battle-skill-smoke`、`test:ucuf` 不退步

## 使用方式
```ts
const session = services().session;
await session.load();          // 開遊戲時讀檔（沒有存檔回傳 false）
await session.advanceSeason(); // 推進 1 季：增齡、退役候選、死亡判定、自動存檔
session.gameTime;              // { currentYear, currentSeason, totalSeasonsElapsed, currentMode }
```
事件名稱見 `GAME_SESSION_EVENTS`（換季、退役候選、死亡、存檔、讀檔）。

## 開單原因

## 範圍
- `buildTallyCards` 依 `IBattleEntryParams.selectedCardIds` 查卡片目錄（卡片 ID = tacticId），依序建立手牌
- 未知 ID 略過並警告；超過 4 張截掉；空卡組或全部無效時退回預設卡組
- headless 測試覆蓋上述規則

## 不在範圍

- 擴充卡片目錄（目前仍只有 demo 4 張）

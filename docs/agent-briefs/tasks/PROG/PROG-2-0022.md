## 開單原因
MVP 驗收要跑通「祖→父→子」三代循環。目前 `BloodlineGraph` 依賴 `cc` 無法 headless 測試，也沒有任何「兩位武將結緣產生子嗣」的邏輯；`BloodlineGenerator` 只是隨機假資料。

## 範圍
- `BloodlineGraph` 改為不依賴 `cc`，新增依位置（F/M/FF…MMM）的 14 人祖譜、共同祖先距離、子嗣登記
- `FactorInheritance`：G1 100% / G2 50% / G3 25% 進池、依世代決定星等，MVP 先開藍/粉/綠 3 色
- `BreedingSystem`：EP_MVP、受孕率、資格檢查（20 歲、精力、生育上限、待產、近親）、子嗣生成（0 歲）
- `BreedingService`：接 `RosterStore`，結緣成功後子嗣寫入名冊並登記進血統圖
- headless 單元測試

## 不在範圍
- 結緣 UI、名士預言、5 歲開獎、天命波動、同步

## 驗收條件
- 新增測試全過，既有 `run-cli`、`battle-skill-smoke`、`test:ucuf` 不退步

## 開單原因
使用者不想開 Cocos 編輯器。現有截圖與 QA 工具都依賴編輯器預覽（`localhost:7456`），需要一條「命令列建置 → 瀏覽器自動驗證」的路。

## 範圍
- `npm run build:web`：以 Cocos Creator 命令列建置 web-desktop（debug）到 `build/web-desktop`
- `npm run test:web-smoke`：靜態伺服器 + puppeteer-core 開頁、等引擎啟動、收集 console / pageerror / 失敗請求、截圖、輸出 `artifacts/web-smoke/report.json`

## 驗收條件
- 在使用者電腦上 `npm run build:web` 成功並產生 `build/web-desktop/index.html`
- `npm run test:web-smoke` 能開到 LoginScene（或啟動場景），錯誤數為 0，或錯誤清單可作為後續修復依據

## 不在範圍
- 大廳 → 抽卡 → 戰場的完整點擊流程（待冒煙跑通後另開卡擴充）

# [PROG-2-0024] 同步契約對齊：雜湊算法與 /sync 端點

## 開單原因
客戶端用自訂 FNV 摘要（16 字元），伺服器用 HMAC-SHA256（64 字元），非空行動紀錄無法通過驗證；客戶端呼叫的 `/sync/delta`、`/sync/full`、`/sync/actions` 伺服器不存在。

## 驗收條件
- 客戶端 Tx_Hash 與伺服器 smoke fixture 逐筆相同
- 真實 SyncManager 對 in-process 伺服器完成 /sync、/sync/delta（含 409 fallback）、/sync/full、/sync/actions
- 竄改紀錄被拒絕且客戶端保留佇列
- `tests/SyncManager.test.ts` 原 2 項失敗修好

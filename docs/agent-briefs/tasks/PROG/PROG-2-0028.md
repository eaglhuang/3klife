# [PROG-2-0028] 5 歲開獎 + 宿命分流 + 36 回合培育 + 教官（純邏輯）

## 開單原因
MVP 迴圈「結緣 → 開獎 → 培育」目前只做到結緣。子嗣出生後永遠停在 0 歲 Mystery，沒有 5 歲揭曉，也沒有 36 回合培育。

## 範圍
- `Unveiling`：年滿 5 歲自動開獎（揭曉五維、解鎖初始因子），產生武官 / 文官宿命建議；玩家接受或抗命
- `NurtureSystem`：36 回合狀態機（鏡像快照、固定 6 教官槽、5 種訓練 + 休息、精力 / 失敗率、教官加成 / 羈絆 / 爆發、TP）與畢業結算（評級、標籤、寫回本體）
- `NurtureService`：接 `RosterStore`，管理培育會話、教官鎖定、入學令、季度模式檢查
- 接上 `GameSession`：每季增齡後觸發開獎、存檔帶上進行中的培育會話
- headless 測試

## 不在範圍
- 培育 / 開獎 UI 與血脈命鏡演出接線、隨機事件、因子覺醒、戰法學習、自動培育、重修 3 槽位、世家保底
- 退役轉教官（教官卡由外部注入 `MentorCard`）

## 實作決策（規格缺口，已採預設）
- 開獎：滿 5 歲自動執行，五維與六維資質一次揭曉到 EXACT（MVP 規格 §E #2；培育系統 §F-8 的四段揭露留給後續）；只解鎖 discoveryLevel ≤ 1 的藍/粉因子，綠以上等覺醒
- 宿命建議：公式寫 Blue_STR+Blue_POW > Blue_INT+Blue_POL，但字典沒有分屬性的藍色因子，改為「偏武因子星等和 > 偏文因子星等和」，打平看 武力+統率 vs 智力+政治，仍打平給文官（公式 else 分支）
- 抗命大器晚成機率規格未寫，暫定 10%；順應天命不擲骰
- 宿命必須先選才能進培育；每位武將只能選一次
- 培育只能在培育季開場、每季入學令暫定 2 張；36 回合本身不推進時鐘（外界 1 季 = 36 回合）；進行中的會話可跨季續玩
- 教官：固定 6 槽、入學快照鎖定（採 Q48，取代「每輪可更換」）；Mentor_Bonus 為所有教官加成加總，同格多一人 +10%，站擅長格爆發 ×1.5（每回合依 burstRate 骰站位）；星等倍率套用教官系統 §F-4 的訓練效果
- TP：每次成功訓練 10×(1+教官 TP 加成)（採教官系統 §F-2；培育系統寫「固定 5 TP」，兩者衝突）
- 訓練失敗：不加屬性與 TP，仍扣精力，50% 機率得負面因子（挫敗 / 厭學，僅記錄，無效果）
- 實力層 Prowess 從 0 累積，上限 = 資質 × 20；評級用「實力層 ÷2、單項上限 100」換算成 0~100 尺度再套 S≥450 / A≥350 / B≥250（規格的實力層 0~2000+ 與評級門檻尺度不一致，換算係數為暫定，需平衡調校）
- 畢業標籤：實力層最高兩項（猛將/統帥/謀士/內政/魅力）+ 武官/文官路線；規格的「槍將預備」「夜襲適性」等需適性資料，後續再接

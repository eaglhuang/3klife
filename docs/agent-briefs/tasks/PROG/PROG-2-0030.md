# [PROG-2-0030] 玩家卡組存檔與大廳選卡

## 開單原因
戰場（PROG-2-0023）已依 `selectedCardIds` 發牌、大廳（PROG-2-0025）已接存檔，但玩家沒有卡組欄位，大廳進戰場一律傳空陣列。

## 範圍
- `PlayerSaveSnapshot.deck`：虎符卡片 ID（tacticId）有序清單，選填欄位（舊檔補 `[]`），schemaVersion 維持 1。
- `PlayerDeckRules`（純 TS）：normalizeDeck / toggleDeckCard，上限 4 張。
- `GameSession.deck / setDeck / toggleDeckCard`：變動即自動存檔並廣播 `DeckChanged`；讀檔還原。
- 虎符卡片目錄搬到 `core/config/TallyCardCatalog.ts`（battle 與 ui 共用，遵守 import 邊界）。
- 大廳最小選卡 UI：UCUF JSON `lobby-deck-select-screen`（執行期組裝，.meta 自產）；`selectedCardIds` 改傳玩家卡組。

## 驗收
- `tests/PlayerDeck.test.ts` headless：規則、存檔往返、舊檔相容、壞檔拋錯、存檔 → 讀檔 → 戰場發牌順序一致。
- validate-ui-specs 通過；run-cli 僅剩既有 SyncManager 2 個失敗。

## 不在範圍
- 目錄只有 demo 4 張，選卡畫面固定 4 個按鈕；多於 4 張時需改成捲動清單。
- 卡片取得 / 解鎖機制（目前全目錄可選）。

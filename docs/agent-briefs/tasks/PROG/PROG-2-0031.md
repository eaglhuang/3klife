# [PROG-2-0031] 退役教官卡接進培育教官

## 開單原因
PR #16 的 `LegacyService` 產生 `MentorCard`（退役當下的武將快照），PR #17 的培育有自己的 `MentorCard`（訓練加成參數），兩個同名型別。以 #16 為準，統一命名並讓退役教官能直接任教。

## 做法
- 併入 #16：`models/MentorCard` 是唯一的 `MentorCard`（資料）；培育內的型別改名 `TrainingMentor`（效果）
- `mentorFromCard(card)`：武官取武力 / 統率較高者、文官取智力 / 政治較高者為擅長科目；`tpBonus = EP ÷ 10`，擅長科目屬性加成 = 該項 ÷ 5；`burstRate` 預設 0.5、星等預設 0（皆暫定，可覆寫）
- `NurtureService.startWithCards(childId, cards)`
- `tests/Legacy.test.ts` 三代測試原本用「滿 5 歲就揭曉」的替身，改用 `GameSession` 的真開獎

# [PROG-2-0033] M5 戰場整合：培育武將出戰、結算寫回名冊

## 開單原因
培育畢業的武將（實力層、評級、因子、戰法）只存在名冊，戰場仍只吃 encounters/generals.json 的靜態武將，戰鬥結果也不回寫。里程碑 M5 要接通「名冊 → 出戰 → 結算 → 存檔」。

## 做法（純 TS，不 import cc）
- `core/systems/BattleRoster.ts`：出戰資格、名冊武將 → `GeneralConfig`（戰場用）、戰後結算、每季精力回補
- `GameSession.recordBattle()`：結算寫回名冊並存檔、廣播 `BattleSettled`；`advanceSeason` 加精力回補
- `BattleSceneLoader.createGeneral`：我軍主將若在名冊且可出戰，用名冊數值建立；`BattleUIBridge._onBattleEnded` 呼叫結算
- `tests/BattleRoster.test.ts`

## 規格缺口採的預設（皆暫定，常數集中在 BattleRoster.ts 上方）
- 戰場數值 = 實力層 ÷ 2（與畢業評級同一把尺）；血量 = 400 + 武力×3 + 統率×4；精力低於一半時血量最多打 7 折
- 攻擊加成 = 已解鎖因子星等 ×1%（上限 25%）+ 畢業評級（S 10% / A 6% / B 3% / C 0）− 負面因子每個 2%
- 精力：戰鬥 −30（規格），每季回補出征 +25% / 待命 +50%（規格），出戰最低精力 30
- 功勳 勝 10 / 平 5 / 敗 3；戰後不加實力層（成長只走培育）
- 畢業即可出戰，不設年齡門檻；退役教官、死亡、培育中、未畢業子嗣不能出戰；抽卡成年武將沒有實力層，直接用卡面數值
- 目前戰場是主將對主將，結算只處理我軍主將一位；主將由 GameSession.leadGeneralId 指定，失效退回遭遇戰預設

# [PROG-2-0038] 虎符品質分數與死亡結算產虎符卡（純 TS）

## 做法

- TRP-07：死亡產卡、隔季招降移交、勝利且無退路時封賞最高品質虎符。
- SPI-01：保守辨識史實名將及具正式模板的女性名將，不以稀有度判定。

# [PROG-2-0042] Q25 養成亂數狀態存檔

## 做法
- 新增純 TS、帶版本的種子偽隨機產生器，保存當前游標狀態而非只保存起始種子。
- GameSession 持有狀態與共用 randomSource；老化、ServiceLoader 的宿命選擇與培育使用同一序列。
- PlayerSaveSnapshot 新增選填 randomState；舊存檔使用固定遷移起點，下一次存檔補入。
- 結緣服務已有注入入口，驗證以 session.randomSource 注入；正式結緣 UI／季結接線另卡，不改戰場、轉蛋與視覺亂數。
- 保留 setRandomSource 測試替身；外部自訂 callback 的內部狀態不宣稱可序列化。

## 驗收
- 固定種子序列、狀態恢復、格式拒絕、舊存檔相容。
- 儲存後重建，老化、結緣與培育得到相同後續結果。
- headless 套件基底比較、standard 與編碼檢查。

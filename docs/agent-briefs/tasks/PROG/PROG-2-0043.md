# [PROG-2-0043] 英靈卡只給名將：歸檔快照與英靈卡分離

## 開單原因
spirit_cards 現為所有死亡者的生命週期快照库，但結算與事件也把一般子嗣當成正式英靈卡。

## 做法
- 保留 spirit_cards、L5 與 A/B/C/D 路由；SpiritCard 只加選填 isSpiritRelic。
- LegacyService 共用 isTallyEligible(toTigerTallyGeneral()) 判斷，結算分開 spiritCards 與 archivedSnapshots。
- GeneralArchiver.archive 原簽章與預設行為不變；僅新增獨立標記方法，無 TigerTally 耦合。
- 同 uid 已決定的 true/false 在重跑時保留；舊未標記資料不做批次遷移。
- GameSession 既有事件迴圈自然只廣播正式英靈卡。
- 僅變更工單允許檔案，不改 GC、存檔、資料或 .meta，不開 Cocos。

## 驗收
- 名將／子嗣分流、退役後死亡、冪等、舊歸檔行為、事件與 BranchCompactor 讀取。
- headless 全套、standard gate、UTF-8 無 BOM 與既有型別診斷比較。

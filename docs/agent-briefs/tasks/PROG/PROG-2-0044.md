# [PROG-2-0044] 因子覺醒：discoveryLevel 成長來源與事件接線

## 目標
- PROG-2-0037 只有覺醒規則（門檻 1/20/45、觸發方式白名單），本卡補上 discoveryLevel 的成長來源與三個觸發點。
- 純 TS、不依賴 cc；避開 LegacyService / GeneralArchiver。

## 規格來源
- 因子解鎖系統.md (doc_spec_0009) §F：培育窺探 `0.08 × (1 + Mentor_Rank × 0.1)`、戰場覺醒 0.05（特定動作 0.15）。
- 因子爆發系統.md (doc_spec_0010) §F 因子覺醒觸發：藍粉 = 培育窺探 / 戰場實戰；綠白 = 培育教官 / 戰場特定動作；紫紅 = 高等級戰場特殊條件。

## 做法（暫定值皆標註）
- 新增 `DiscoveryProgress.ts`：每級 100 經驗、上限 99 級（暫定）；戰勝 +30 / 平 +20 / 敗 +10、培育畢業 +50（暫定）。
- `FactorAwakening.ts` 新增擲骰：
  - 培育：只在訓練回合擲，機率 `0.08 × (1 + Mentor_Rank × 0.1)`，Mentor_Rank 暫定取本場教官最高星等；藍粉 = 培育窺探，綠白 = 教官站在所選訓練格時的教官觸發。
  - 戰場：基本 0.05；呼叫端回報「特定動作」的武將 0.15。敗 / 平只開藍粉；戰勝暫定視為「特定動作 / 高等級戰場特殊條件」，開綠白紫紅（紫紅仍需 discoveryLevel 45）。
  - 每位武將每回合 / 每場最多覺醒 1 個；沒有候選因子時不消耗亂數。
- `GameSession.recordBattle` 先加經驗再擲覺醒，回傳 `discovery` 與 `awakenings`，廣播 `DiscoveryLevelChanged`（只在升級時）與 `FactorAwakened`。
- `NurtureService` 新增選填 `awakening` 掛鉤與 `onGraduated`；未掛時回合結果與舊版相同。ServiceLoader 接上 GameSession。
- 存檔新增選填 `discoveryExp`，舊檔補 0；`setDiscoveryLevel` 會把等級內經驗歸零。
- 未動 LegacyService / GeneralArchiver。

## 後續
- 戰場「特定動作」偵測（如騎兵衝鋒 → 粉色騎兵因子）尚未接，BattleUIBridge 目前不傳 specialActionIds。
- 名士占卜（sage）觸發不在本卡。
- 經驗數值需要遊玩節奏驗證後再定案。

# [PROG-2-0045] 結緣正式介面接線

## 開單原因
結緣（BreedingService / BreedingSystem / BloodlineGraph）純邏輯已在 master，但大廳沒有結緣畫面可用，
MVP 迴圈「結緣→培育→戰場→世代傳承」的第一步無法從 UI 走通；母方待產倒數也沒有接進季度推進。

## 做法
- 新增 BreedingFlowController（純邏輯 Presenter）：挑父方 / 母方、顯示資格與 EP 預估、確認結緣、存檔。
- 以 UCUF JSON（breeding-flow-screen / layout / skin）執行期組裝，LobbyScene 從季度 HUD 開啟。
- ServiceLoader 提供 BreedingService；GameSession 每季推進母方待產倒數，讀檔後補回血統圖。
- 不改因子覺醒相關檔案。

## 驗收
- validate-ui-specs、headless 全套、compute-gate standard。

## 完成紀錄
- 基底 master dbd2ae1（含 #28）。
- 新增 BondingSetupController（純邏輯，不 import cc）與 bonding-setup 三層 JSON（layout / screen / `bonding-setup-screen.skin`），
  依 UI 規格書結緣列命名 `bonding-setup-main`、uiId `BondingSetup`；含 `bonding-lineage-mode-chip` 的模式摘要（一般 / 和平血統線）。
- 大廳季度 HUD 新增「結緣」入口；HUD 卡加高後把選卡、選主將卡片往下移，三張卡不再重疊（原本 HUD 與選卡重疊 34px）。
- ServiceLoader 新增 `breeding`（BreedingService）與 `prepareBreeding()`：載入因子字典與 person-registry，讀檔後把名冊子嗣補回血統圖。
  原本 `loadFactorDictionary()` 沒有任何呼叫點，現在開結緣畫面時會載入一次（也讓開獎宿命建議吃得到字典）。
- GameSession.advanceSeason 接上母方待產倒數；待產期間母方精力不回補（Pregnancy_Lock），滿期後恢復。
- NurtureFlowViewApplier 抽出通用 `applyFlowView`，`applyNurtureFlowView` 保留為別名，培育畫面行為不變。
- 未動因子覺醒相關檔案。未做 Web 建置冒煙（雲端無 Cocos Creator）。

# [PROG-2-0048] 戰場特定動作偵測 → 因子覺醒

## 目標
- PROG-2-0044 的戰場覺醒以「戰勝」代替規格的「戰場特定動作 / 特殊條件」，BattleUIBridge 不傳 specialActionIds。
- 本卡實作戰場特定動作偵測（純 TS、不依賴 cc），把偵測結果傳進覺醒判定。
- 名士占卜（sage）觸發不在本卡。

## 規格來源
- 因子解鎖系統.md (doc_spec_0009) §F：戰場覺醒 0.05，特定動作（如騎兵衝鋒 → 粉色騎兵因子覺醒）0.15。
- 因子爆發系統.md (doc_spec_0010) §F 因子覺醒觸發：綠白 = 戰場特定動作；紫紅 = 高等級戰場特殊條件。
- 子嗣系統規格書：三國傳承.md §第三階段：對應地形或特定動作（背刺、絕境反擊）。
- 三國遊戲模式串接與循環.md §戰場覺醒：特定動作如水戰、背刺。

## 做法（暫定值皆標註）
- 新增 `core/systems/BattleSpecialActions.ts`（純 TS）：`BattleSpecialActionTracker` 聽 UnitDamaged / GeneralDamaged，戰鬥結束時 `finish(result)` 回傳本場動作。
  - 騎兵衝鋒：我方騎兵（非主將）擊破敵方單位累計 2 次（暫定）
  - 水戰 / 山地作戰 / 林地作戰：我方單位站在河流 / 山地 / 林地格擊破敵方單位累計 2 次（暫定）
  - 背刺：我方單位從敵方單位側面或背後命中 1 次（暫定）
  - 絕境反擊：我方主將血量曾 ≤ 25%，最後戰勝（暫定）
  - 每個動作帶因子標籤（對應 gene-dictionary defaultTags），例：騎兵衝鋒 → cavalry / charge
- `FactorAwakening.rollBattleAwakening`：移除 `special`（戰勝代替）參數；`specialAction` 才開綠白紫紅並用 0.15；
  有動作標籤時優先挑標籤相符的因子，沒有相符才從全部候選挑。
- `GameSession.recordBattle` 新增 `specialActions`（武將 id → 動作），用 session 的因子字典查標籤；保留舊的 `specialActionIds`。
- `BattleUIBridge`：訂閱事件餵給偵測器，戰後把主將的動作傳進 `recordBattle`，並在戰報寫出達成的動作。
- 「高等級戰場特殊條件」暫定 = 任一特定動作；紫紅仍需 discoveryLevel 45。

## 後續
- 門檻、絕境比例、標籤需遊玩驗證後再定案；字典目前沒有水戰 / 山地 / 林地標籤的因子，這三個動作暫時只提高機率。
- 名士占卜（sage）觸發不在本卡。

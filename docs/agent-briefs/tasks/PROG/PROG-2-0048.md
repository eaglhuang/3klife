# [PROG-2-0048] 戰場特定動作偵測 → 因子覺醒

## 目標
- PROG-2-0044 的戰場覺醒以「戰勝」代替規格的「戰場特定動作 / 特殊條件」，BattleUIBridge 不傳 specialActionIds。
- 本卡實作戰場特定動作偵測（純 TS、不依賴 cc），把偵測結果傳進覺醒判定。
- 名士占卜（sage）觸發不在本卡。

## 規格來源
- 因子解鎖系統.md (doc_spec_0009) §F：戰場覺醒 0.05，特定動作（如騎兵衝鋒 → 粉色騎兵因子覺醒）0.15。
- 因子爆發系統.md (doc_spec_0010) §F 因子覺醒觸發：綠白 = 戰場特定動作；紫紅 = 高等級戰場特殊條件。
- 子嗣系統規格書：三國傳承.md §第三階段：對應地形或特定動作（背刺、絕境反擊）。
- 三國遊戲模式串接與循環.md §戰場覺醒：特定動作如水戰、背刺。

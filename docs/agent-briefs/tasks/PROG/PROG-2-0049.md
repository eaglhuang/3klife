# [PROG-2-0049] 男女精力上限與 ActionSystem 型別修正

## 開單原因
1. 規格決策題 Q17（推薦 A）採數值系統 Q46：男性精力上限 120、女性 100，武將缺資料時尚未依性別給基礎值。
2. `ActionSystem.ts` 的 `anim.play(step.clip)` 因 cc stub 的 `Animation.play()` 無參數而型別錯誤。

## 做法
- 新增 `core/systems/VitalityCap.ts`：`baseVitalityMaxOf(gender)`，男 120 / 女 100 / 未知 100。
- `BattleRoster` 與 `BreedingSystem` 的精力預設值改走性別基礎值；已存的 `vitality` / `maxVitality` 不覆寫。
- `tests/cc.mock.ts` 的 `Animation.play` 補 `_clip?: string` 參數（補 stub 型別，不改遊戲邏輯）。

## 驗收
- npm test、test:ucuf、compute-gate standard 通過。

## 完成紀錄
- 基底 master ddc30b3。新增 VitalityCap.ts，BattleRoster 與 BreedingSystem 缺資料時改走性別基礎值；已存 vitality / maxVitality 不覆寫。
- tests/cc.mock.ts：Animation.play 補 _clip 參數，getComponent 改為依建構子推型別，ActionSystem.ts:159 錯誤消除。
- 精力上限新增 headless 測試於 BattleRoster suite。
- 未開 Cocos 編輯器。

## 避開
- 戰場特定動作偵測（另一張卡）會改的檔案未碰。

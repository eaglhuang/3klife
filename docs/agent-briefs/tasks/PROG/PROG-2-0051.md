# [PROG-2-0051] 清掉核心子集剩餘型別錯誤

## 開單原因
PROG-2-0050 後，限縮 tsc（核心子集）剩 65 個錯誤：ResourceManager 的 AssetManager 命名空間、隱式 any 回呼、addComponent 推不出型別等。

## 做法
- `tests/cc.mock.ts`：`addComponent<T>` 依建構子推型別；新增 `AssetManager` 命名空間與 `AssetManager.Bundle`；`resources` / `assetManager` 補上有型別的 load 系列簽名；Button.node、Label.lineHeight 佔位。
- `SyncManager.ts`：`getItem(...) ?? ''`。原本 null 進來也會走 `!this.deviceId` 分支並重新指派，等價。
- `FamilyBranchSummary.ts`：`birthYear` / `deathYear` 型別放寬為 `number | undefined`，與 BranchCompactor 實際寫入一致。
- 不改遊戲流程。

## 驗收
- 限縮 tsc 錯誤 65 → 0。
- npm test、test:ucuf、compute-gate standard。

## 完成紀錄
- 基底 master bca8171（含 #33）。
- 全專案 `assets/scripts/**/*.ts` 的 tsc 仍有約 1435 個錯誤（battle/views、ui/components 等視圖層），不在本卡範圍。

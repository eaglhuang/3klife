# [PROG-2-0052] 名士占卜觸發覺醒＋因子字典地形標籤

## 目標
- 因子解鎖系統的第三種途徑「名士占卜」：消耗一次占卜，依名士偏好與準確率覺醒一個鎖住的因子。
- 因子字典補水戰 / 山地 / 林地適性因子，讓 PROG-2-0048 的地形特定動作能對應到因子。

## 規格來源
- 因子解鎖系統.md (doc_spec_0009) §A §B：培育窺探、戰場覺醒、名士占卜三種途徑；占卜可提前窺探未解鎖因子。
- 名士預言系統.md (doc_spec_0006) §F：名士偏好表（偏好面向、準確率）、預言生成邏輯（Random() <= accuracy_rate 為非扭曲）。
- 因子爆發系統.md (doc_spec_0010) §F：粉色 = 兵種 / 地形適性（山 / 水 / 林 / 平原）；[水戰適性]、[林地適性]。

## 做法（暫定值皆標註）
- 新增 `core/systems/SageDivination.ts`（純 TS）：六位名士（偏好面向、準確率照規格表）。
  - `Random() <= accuracy` → 非扭曲：從可覺醒的鎖定因子裡依偏好加權抽一個覺醒（偏好色權重 3、其他 1，暫定）。
  - 扭曲：不覺醒，回傳名士偏見方向的提示色（暫定）。
  - 諸葛亮「智力 / 政治」歸藍色、司馬徽不加權（暫定）。仍受 discoveryLevel 門檻限制。
  - 沒有可覺醒因子時不擲骰，`consumed: false`，呼叫端據此決定是否扣求籤令。
- `GameSession.divineFactor(generalId, sageId)`：擲骰就存檔（亂數狀態前進）；覺醒成功才寫回名冊並廣播 FactorAwakened。
- `gene-dictionary.json` 新增粉色地形因子：`gene_naval` 水戰適性（naval / river / water）、`gene_mountain` 山地適性、`gene_forest` 林地適性。

## 後續
- 占卜 UI（嵌入結緣畫面）與求籤令扣除尚未接；名士解鎖條件、名士等級提高準確率未做。
- 新地形因子目前沒有武將帶，需要資料管線或虛擬祖先生成時分派，才會在遊戲中出現。

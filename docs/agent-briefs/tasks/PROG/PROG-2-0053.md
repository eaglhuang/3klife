# [PROG-2-0053] 名士占卜畫面與求籤令扣除

## 目標
- PROG-2-0052 只有占卜覺醒邏輯，沒有入口也不扣道具；本卡補上 UCUF 占卜畫面（從結緣畫面開啟）與求籤令庫存 / 扣除。
- 一併把 PROG-2-0052 新增的水戰 / 山地 / 林地適性配給名將（血統登記表 gene_refs），讓子嗣能繼承。

## 規格來源
- 名士預言系統.md (doc_spec_0006) §C 求籤令每次 1 張、免費玩家日產 1 張；§E #2 占卜介面、#7 結緣介面嵌入；§G 劇本；§H 字串；§K 結緣介面嵌入方式。
- 道具系統（付費免費道具）.md：ITEM_ORACLE 求籤令。
- 因子爆發系統.md (doc_spec_0010) §F：粉色地形適性。

## 做法（暫定值皆標註）
- 新增 `core/systems/PlayerInventory.ts`（純 TS）：道具庫存；目前只有 `ITEM_ORACLE` 求籤令。
  - 新遊戲與舊存檔起始 3 張（暫定）；規格「日產 1 張」改成每推進一季免費 +1 張，持有 ≥ 5 張時不再免費發（暫定）。
- 存檔新增選填 `inventory`，舊檔補起始庫存；`GameSession` 新增 `inventory` / `itemCount` / `addItem`、`InventoryChanged` 事件，`SeasonAdvancedPayload.oracleTokensGranted`。
- `GameSession.divineFactor`：沒有求籤令回傳 `no-token` 不擲骰；有擲骰才扣 1 張（扭曲也扣）。
- 新增 `ui/core/SageOracleController.ts`（純 TS Presenter）與 `sage-oracle-screen` / `sage-oracle-main` / `sage-oracle-screen.skin` 三層 JSON。
  - 對象：在世、非教官、還有鎖定因子的武將；從結緣畫面開啟時預選父方。名士六位循環，顯示偏好與準確率、求籤令數量。
  - 名士批語依 §G 語氣改寫（暫定）。
- 結緣畫面新增「名士占卜」按鈕（btnOpenOracle）；LobbyScene 掛載占卜畫面並綁按鈕。
- 血統登記表配給地形因子：水戰（周瑜、甘寧、呂蒙、黃蓋、陸遜、周泰、徐盛、丁奉）、山地（鄧艾、姜維、張郃、魏延、王平）、林地（孟獲、祝融、兀突骨、陸遜）。

## 後續
- 商城購買求籤令、名士解鎖條件、結緣前「預測子嗣」的名士預言尚未做。
- 占卜畫面尚未 Web 實機驗收（需 build:web + Playwright）。

# [PROG-2-0054] Web 冒煙擴充：結緣確認 → 推進一季 → 出戰

## 目標
在 PROG-2-0056（PR #38，登入 → 大廳 → 結緣 → 占卜）之上擴充，不另造一套：補上關占卜、結緣確認、推進一季、出戰，並逐步截圖。

## 做法
- `tools_node/lib/web-lifecycle-flow.js`：既有 `runLifecycleFlow` 加 `onStep` 回呼；新增 `runFullFlow`。
  - 步驟：登入 → 開結緣 → 開占卜 → 關占卜 → 結緣確認（按鈕不可按則 skipped 並寫原因）→ 關結緣 → 推進一季（SeasonLabel 文字必須變）→ 出戰（等進 BattleScene 再停 3 秒收錯誤）。
  - 沿用 #38 的做法：公開 LoginScene.onClickStart 與 Cocos button event，不改遊戲程式。
- `tools_node/run-web-smoke.js`：`--flow lifecycle-full`，每步截圖 `<序號>-<步驟>.png`。

## 限制
- 不是滑鼠命中或排版驗收。
- 新玩家名冊為空，結緣確認與實際占卜扣令不會被驗到；等名冊問題處理後補。
- 出戰只驗進得去，沒有打完。

## 重跑
```sh
npm run build:web
node tools_node/run-web-smoke.js --flow lifecycle-full --settle 3000 --out artifacts/web-lifecycle-full
```

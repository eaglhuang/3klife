# [PROG-2-0054] 名士預言：結緣前預測子嗣與名士解鎖

## 目標
- 結緣前依父母祖譜的因子池，由名士給出帶偏見、不完全準確的子嗣預言（批語 + 色彩傾向 + 關鍵詞）。
- 名士解鎖條件：依累計占卜次數解鎖。商城不在本卡。

## 規格來源
- 名士預言系統.md (doc_spec_0006) §A §C（占卜 50 次解鎖龐統、左慈為 VIP 名士）、§E #4 #6 #7、§F 預言生成邏輯、§H UI_ORACLE_LOCKED / UI_ORACLE_CONFLICT、§K 批語 + 色彩傾向 + 關鍵詞，不顯示精準數字。

## 完成紀錄（2026-10-11）
- `BreedingSystem.previewFactorPool` / `BreedingService.previewFactorPool`：父母祖譜每個因子至少進池一次的機率（G1 100% / G2 50% / G3 25%，1 − Π(1 − 進池率)），不擲骰、不改資料。
- `SageDivination.predictOffspring`：先擲準確率；準確 → 依「進池機率 × 偏好權重 3」加權抽一個因子；扭曲 → 色彩改向（名士偏好色優先，否則六色順序下一色），關鍵詞換成字典中同色但不在池內的因子。
- 名士解鎖：`SageDefinition.unlockDivinations`，龐統 50（規格範例）、左慈 100（暫定，VIP 活動未做），其餘 0；GameSession 累計 `oracleCount`（占卜與預言都算），存檔往返，舊檔補 0。
- 占卜畫面：新增「預言子嗣」按鈕與父母標籤；未解鎖名士顯示解鎖條件；同一對父母兩位名士色彩傾向不同時顯示「兩位名士意見相左，真相待子嗣 5 歲揭曉。」；畫面不顯示是否扭曲。
- 暫定：解鎖次數、偏好權重 3、扭曲規則、預言也消耗 1 張求籤令並計入占卜次數。名士等級與商城不在本卡。

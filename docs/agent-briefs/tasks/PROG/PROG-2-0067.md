# [PROG-2-0067] BLT-02 虛擬祖先正式生成器

## 目標
- 以符合規格的純 TS 生成器取代舊的 `BloodlineGenerator`（Math.random、未接線），為初代名將補齊 14 位虛擬祖先。
- 祖先 ID 為 `V_PID_{GeneralID}_{Pos}`；祖先地域受出生地限制；因子依世代色系權重與星等分布分配。

## 規格來源
- 新手開場規格書 §7.2（14 人祖先、地域限制、地域人才庫）
- 血統理論系統 §F 虛擬祖先因子分配權重、§I 虛擬祖先 ID 命名
- 名將虛擬祖先生成器規格（doc_spec_0072）§2~§5：標籤映射、主屬性回溯、地域因子、變異位點、顯示名稱

## 範圍
- 不改 `GameSession.startNewGame` 相關檔案（Codex PROG-2-0058 起始名冊）。
- 不重寫 person-registry.json 既有的虛擬祖先資料。

## 完成紀錄（2026-10-11）
- `VirtualAncestorGenerator.generateVirtualAncestry(general, { dictionary })`：14 位祖先，ID `V_PID_{GeneralID}_{Pos}`，以武將 id 為種子，結果固定。
- 出生地：指定值 → 史料開頭 80 字最早出現的州名或郡縣名 → 勢力預設；六位初始名將與規格表一致（幽、荊、豫、冀、揚、益）。
- 地域六區；父系祖先只在本區，母系 70% 本區、30% 相鄰區。
- 主因子依世代色系權重（G1 藍綠各半、G2 藍 4 粉 3 白 3、G3 藍 2 白 8）與星等分布；父系一代 70% 承襲名將自身同色因子；祖輩粉色因子偏向地域因子。
- 武力 > 90 祖輩補勇猛、體魄；智力 > 90 補謀略；14 位中 1 位帶紫色變異因子。
- `BloodlineGraph.registerFounderAncestry` + `BreedingService.ensureFounderAncestry`：名冊裡沒有父母、血統圖也沒有祖先的初代名將，在結緣預覽 / 結緣 / 讀檔同步時自動補祖先；registry 已有祖先的名將不動。
- 暫定值見生成器檔頭註解。person-registry.json 既有的 VIRT_ 祖先資料未重產（Coordinator 決定先記待辦）。
- 名士預言的因子池預覽會一併算入初代名將的虛擬祖先因子；SageProphecy 的因子池測試改為替母方登記父母，維持原本的測試意圖。

## Q16=C 重訂適性表（暫定）
- S +20% 攻防、移動 +1、命中 +15%；A +10%、0、+10%；B 無修正；C -10%、-1、-5%；D -30%、-2、-15%。
- 理由：舊表 B「無修正」與 Q35「B -30%」矛盾且 B 比 C 痛。改為單調遞減，Q35 的 -30% 落在最低 D 級。
- 母規格超過分片門檻，裁決記在本卡與程式註解，待規格整併時回寫。

## 發現與取捨
- 對應暫定：河流=水域（兼容舊 RIVER）、城塞無適性=B、雪=雨天、沙暴=大風、盾槍醫歸步兵、器械=SIEGE/ENGINEER、缺欄位=B。
- 兵種適性沿用同一張表，不再另乘 1.2~0.8 效率，避免重複計算。
- 移動、命中修正已算出但戰場尚無命中系統、移動改動影響過大，先不套用；兵種×地形強弱（APT-04）與天氣禁火攻未做。

## 開單原因
REC-01/02/03、DEP-05、MVP 驗收「戰績與結果寫回養成資料」：名冊只記勝敗與功勳，沒有擊殺／傷害／守護力；出征戰損不回扣任何存檔資源。

## 完整描述
- BattleRecordStats：單場表現累加器、勝率、退役評分、里程碑、戰績面板 ViewModel。
- BattleRoster.settleBattle 累加擊殺／傷害／守護力並回報新里程碑（舊存檔欄位當 0）。
- MilitaryReserve + GameSession：城市兵源與糧草進存檔；出征設定讀儲備，戰後扣戰損與糧草，每季補兵與補糧。
- 戰後結果彈窗顯示出征六項結算與本場戰績。

## 如何驗證
1. ts-node run-cli（BattleRecordStats 8 項）；npm run test:ucuf；compute-gate standard。

## 交付物
- BattleRecordStats.ts、MilitaryReserve.ts、BattleRecordStats.test.ts、GameSession／PlayerSaveService／BattleRoster／BattleUIBridge／結果彈窗接線、本卡。

## 完整描述
- 自動推進：主將適性移動修正加到每回合移動格數（水攻戰法除外）。
- 一般攻擊：先擲命中，落空不造成傷害、不觸發反擊，發 `UnitAttackMissed` 事件；戰報顯示「攻擊落空（命中率 x%）」。

## 暫定值
- 基礎命中率 100%：規格只寫 final_acc = base + 地形 + 天氣，沒有 base；取 100% 讓 B 級以上必中、舊戰場不變。
- 命中率下限 50%。
- 移動修正後至少 1 格（原本會走的部隊），避免 C/D 級步兵整場不動；原本 0 格維持 0。
- 只套在部隊互打；打主將、技能傷害、反擊不擲命中。

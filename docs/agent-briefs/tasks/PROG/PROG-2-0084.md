# [PROG-2-0084] 戰場計謀點與參謀官加成生效

## 完整描述
參謀官加成（計謀點上限 / 開局補點）原本只在出征編制畫面顯示。本卡讓它進入戰場帳本：

- `createSortieState` 依 `strategistBonus` 計算 `tacticMax` 與開局 `tacticCurrent`。
- `spendTactic` 不足時回報 `TACTIC_SHORT` 且不扣；`regenTactic` 每回合回復到上限為止。
- `GameSession.getSortieInput` 把參謀官加成帶進戰場；`BattleController` 提供 `trySpendTacticPoints`，回合推進時自動回復。

## 暫定值（規格未定，需人工確認）
- 基礎上限 30、基礎開局 12：由 戰場部署系統 §I 範例（48 − 18、21 − 9）反推。
- 每回合回復 +2。
- 尚未有戰法實際扣計謀點，成本表待定。

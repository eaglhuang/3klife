## 規則
1. **不改機率、不改亂數、不加強制受傷開關**（0112 已確認 Web 沒有此開關，不新增）。
2. 在**同一個自然新局**內持續訓練，直到出現受傷或達到 20 歲為止；每回合讀取 IndexedDB 培育日誌的 `injured`、`skipped` 欄位作證據。
3. 受傷步驟：若觀察到，依日誌與畫面文字記錄並通過；若整局都沒有，**如實記為未通過**，但仍要繼續驗證其餘步驟（轉職、結緣壽命扣減、出征、存檔續玩）。這幾步不依賴受傷，不能因受傷失敗而跳過。
4. 其餘步驟的截圖與日誌證據照 0108 的規則附在 PR 上。
5. 全部步驟通過才能把 PR 轉 ready；有任何未通過，PR 維持 draft，並在 PR 說明逐步寫出結果。

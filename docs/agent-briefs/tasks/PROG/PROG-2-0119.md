1. `git fetch origin`，建置 Web 版。基底：master（含 #260）；#262、#265 用各自 PR 分支 head 另建一次。記下每次 HEAD。
2. 回歸（用 master）：
   - 開新局、進入大廳，畫面正常載入、無錯誤彈窗、無 console 報錯。截圖。
   - 用既有存檔（或舊版本存檔）讀入，確認可以繼續遊戲。
3. 收藏與指派（#260）：若大廳畫面沒有收藏或指派按鈕，寫「未接線，畫面無法驗收」，不要判為通過。

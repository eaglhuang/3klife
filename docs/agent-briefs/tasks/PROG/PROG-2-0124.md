# [PROG-2-0124] 實機驗收：虎符出陣成長、戰場 Set 標籤、首戰教學浮窗（#324、#329、#331）

## 為什麼做
以下三項已合併到 master，但還沒有人在 Web 版上實機看過：
- #324 出陣虎符改帶持有卡實例 uid：出陣面板選虎符後，戰後星級與經驗應該成長（修正前恆為 1★、經驗不累積）。
- #329 戰場 HUD 的玩家在場 Set 標籤：玩家陣營資訊下方一行小字，列出成立的 Set，沒有 Set 時清空。
- #331 大廳首戰教學旗標：玩家尚未通關任何關卡時，從大廳開戰會顯示首戰教學浮窗；通關後不再顯示。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 虎符：新手開場後在出陣面板選一張虎符，打完一場勝利，記錄戰後星級與經驗；再打一場確認經驗累積。截圖。
3. Set 標籤：在戰場中確認 HUD 玩家陣營資訊下方的 Set 小字可讀、位置不遮擋其他 HUD；沒有 Set 時標籤清空。截圖。
4. 首戰教學：未通關任何關卡時從大廳開戰，確認教學浮窗出現；通關一關後再開戰，確認浮窗不再出現。截圖。
5. 任何一項不符：停下來記錄步驟與截圖，回信到 `mailbox/to-claude/`，不要自行修改遊戲程式。

## 範圍
- 只新增驗收腳本、截圖與報告；PR 目標 `master`。
- 不改遊戲核心邏輯、版面 JSON、spec JSON、`generals.json`、存檔格式。

# [PROG-2-0125] 實機驗收：精力閘門與奧義扣精力（#336、#339）

## 為什麼做
以下改動已合併到 master，但還沒有人在 Web 版上實機看過：
- #336 戰法施放接入精力閘門：精力 10%~50% 擋奧義，低於 10% 擋奧義與種子戰法，被擋時不扣資源。
- #339 奧義扣精力與戰後基準：奧義生效後依精力上限 × 比例扣減（下限 0）；戰後結算以戰鬥結束精力為基準再扣 30。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 奧義扣精力與 HUD：出陣武將精力足夠時點選奧義，確認精力實際扣減、HUD 數字與條同步更新。截圖前後對照。
3. diao-chan 三個奧義：同一戰法的三個奧義成本應不同（依各自的成本比例）；逐一記錄扣減數字。截圖。
4. 戰後結算數字：戰鬥結束後，結算訊息中的精力數字應與「戰鬥結束精力 − 30」一致；記錄畫面數字與計算過程。截圖。
5. 低精力時戰法被擋：精力落在 10%~50% 時奧義應不能施放；低於 10% 時奧義與種子戰法都不能施放，且被擋時精力與資源不變。截圖。
6. 任何一項不符：停下來記錄步驟與截圖，回信到 `mailbox/to-claude/`，不要自行修改遊戲程式。

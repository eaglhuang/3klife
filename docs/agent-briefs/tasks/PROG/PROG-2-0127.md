# [PROG-2-0127] 實機驗收：補元散使用流程（PROG-2-0444、#392）

## 為什麼做
PROG-2-0444 與 PR #392 已合併到 master：GameSession 可使用補元散，扣道具、回復精力、寫回名冊並自動存檔；提示文字有純邏輯與測試。cc 背包的使用按鈕場景節點綁定尚未接線，需 Codex 在 Web 版接上後再驗收。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 接線：在背包的補元散項目綁定使用按鈕（場景節點）。若節點不存在，只記錄，不自行改核心程式。
3. 持有補元散、精力未滿：點使用，精力回復 50，道具數減 1。截圖前後對照。
4. 精力已滿：點使用，顯示「精力已滿，不需使用補元散」，道具數不變。截圖。
5. 高級補元散：回復 100，且精力被夾在上限，不超過上限。截圖。
6. 離開場景再回來：道具數與精力保留。截圖。

## 驗收標準
- 步驟 3 到 6 皆有截圖或錄影；PR 說明寫明 Before/After 與 HEAD。
- 任一步不符：記錄現象與 HEAD，不自行修改 `assets/scripts/core/**`，回報 PM 另開卡。
- 售價不在本卡範圍（PM 指示先不做）。

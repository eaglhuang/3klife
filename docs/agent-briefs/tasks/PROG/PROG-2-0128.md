# [PROG-2-0128] 實機驗收：天氣禁用計謀可點擊並彈出 Toast（APT-07、PROG-2-0597、#396）

## 為什麼做
PR #396 修正天氣禁用計謀的按鈕：天氣禁用時按鈕字色變灰但仍可點擊，點擊後由既有天氣檢查彈出「當前天氣不符合施放限制」Toast，不進入選目標、不扣計點與 SP。計謀點不足與 SP 不足維持不可點。目前只有 headless 守護測試，cc 畫面需 Web 版實機確認。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 雨天：火計按鈕應為灰色字，但可點擊。截圖。
3. 雨天點擊火計：應彈出天氣 Toast，不進入選目標，計點與 SP 不變。截圖與數值前後對照。
4. 晴天：同一計謀顏色與點擊行為正常，可進入選目標。截圖。
5. 計點不足或 SP 不足：計謀仍不可點，不彈 Toast。截圖。

## 驗收標準
- 步驟 2 到 5 皆有截圖或錄影；PR 說明寫明 Before/After 與 HEAD。
- 任一步不符：記錄現象與 HEAD，不自行修改 `assets/scripts/ui/**` 以外的檔案，回報 PM 另開卡。

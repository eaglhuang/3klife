# [PROG-2-0129] 實機驗收：自動培育整季與培育畫面按鈕（NUR-14、PROG-2-0548／0549、#399）

## 為什麼做
#399 已合併到 master：GameSession.runAutoNurture 會檢查解鎖與券數，沿用手動排程（沒有則平均分配到最低屬性），扣 1 張自動培育券後跑完整季並寫回存檔。培育畫面新增「自動培育整季」按鈕（btnAutoNurture），被擋下時顯示原因且不扣券。按鈕位置為暫定，需實機確認。

## 步驟
1. 進入培育畫面，子嗣在培育中時「自動培育整季」可按；未培育時不可按。截圖。
2. 未通過主線培育季時按下：提示「尚未解鎖自動培育」，券數不變。截圖。
3. 已解鎖但券為 0 時按下：提示「沒有自動培育券」，券數不變。截圖。
4. 已解鎖且有券時按下：券減 1，培育進入可畢業狀態，提示「自動培育完成（36 回合）」。截圖與券數前後對照。
5. 畢業後評級不得為 S（上限 A）。截圖。
6. 按鈕位置與文字在實機版面：是否擠到「放棄培育」。若擠到，記錄截圖並回報，由 cc 端調整。
7. 離開場景再回來，券數與培育狀態保留。截圖。

## 驗收標準
- 步驟 1 到 7 皆有截圖或錄影；PR 說明寫明 Before/After 與 HEAD。
- 測試存檔可用 `grantAutoNurtureTickets` 給券，或把 mainlineNurtureClearedOnce 設為 true，以加速驗收。
- 任一步不符：記錄現象與 HEAD，不自行修改 `assets/scripts/core/**`，回報 PM 另開卡。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 手動排程保存與亂數存檔（Q25）不在本卡範圍。

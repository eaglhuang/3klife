# [PROG-2-0133] 實機驗收：新玩家開場一路走通（PROG-2-0645、0646、0647）

## 為什麼做
新玩家開場的三段已接上 master：第一幕劇本（PROG-2-0646）→ 宿命轉蛋（PROG-2-0645）→ 首戰通過後第一次回大廳自動展示紅顏（PROG-2-0647）。三張卡各自的驗收步驟合併於此，依序走一遍，確認銜接正確。版面與台詞為暫定，需實機確認。

## 步驟（Web 版，依序，從無存檔開始）
1. 清除瀏覽器 localStorage／IndexedDB 後進大廳：先出現第一幕「1 / 4」黑底古文，按鈕「繼續」。截圖。（0646-1）
2. 依序翻 2 / 4（信件，按鈕「開始宿命轉蛋」）、3 / 4、4 / 4（按鈕「進入宿命」）。（0646-2）
3. 第 4 頁按下後 intro 面板消失，出現宿命轉蛋面板，只有「轉蛋」鈕可按。（0645-1、0646-3）
4. 按「轉蛋」：出現六列（張飛、魏延、夏侯惇、張郃、孫策、甘寧，順序隨機），「轉蛋」變灰、「重置」可按。截圖。（0645-2）
5. 按「重置」：回到未抽，右下「重置 1 次」；再按「轉蛋」可重抽，重複數次無上限。（0645-3）
6. 點任一列的「選擇」：面板關閉；進武將列表應為六位初始名將，主將是剛才點的那位。（0645-4）
7. 點選後進入大廳，3 段式引導接著出現。（0646-4）
8. 打贏第一場戰鬥回大廳：自動出現「紅顏池・展示」面板，可按「關閉」。（0647-1）
9. 關閉後重新整理或再進大廳：不再自動彈出；紅顏入口仍可手動開。（0647-2）
10. 另開一份新存檔打輸首戰回大廳：不彈。（0647-3）
11. 用已有通關紀錄的舊存檔進大廳：不彈。（0647-4）
12. 重新整理頁面：不再出現 intro 與宿命轉蛋，主將仍是所選。（0645-5、0646-4）
13. 版面：第一幕文字不溢出、六列與三顆按鈕不重疊、訊息文字在畫面內；phone-16-9、19.5-9、tablet-4-3 三種比例都在畫面內。截圖。（0645-6、0646-5）

# [PROG-2-0143] 實機驗收：出征編制「儲存預設」「套用預設」（PROG-2-0784、#538）

## 為什麼做
編制預設先前只存在記憶體，重開遊戲就不見。#538 把預設寫入存檔，並在出征編制畫面加上「儲存預設」「套用預設」兩個按鈕，大廳已綁定。程式與單元測試已過，但按鈕在 cc 畫面的點擊與存檔往返需實機確認。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 進入出征編制畫面，確認「儲存預設」「套用預設」兩個按鈕可見、文字正確、未遮擋其他控制項。截圖。
3. 調整一組編制後點「儲存預設」：無錯誤訊息。截圖。
4. 換成另一組編制後點「套用預設」：編制恢復成剛才儲存的內容。截圖。
5. 關閉遊戲分頁、重新開啟並進入出征編制：預設仍在，點「套用預設」可套用。截圖。
6. 舊存檔（沒有預設欄位）讀取後進入出征編制：不報錯，套用預設時視為空預設。記錄觀察結果。

## 驗收標準
- 步驟 2 到 6 皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 任一步不符：記錄截圖、按鈕座標與 HEAD，回報 PM 另開卡。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改存檔格式或 UI 程式；只回報現象。

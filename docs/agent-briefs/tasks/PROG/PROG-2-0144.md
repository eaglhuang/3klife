# [PROG-2-0144] 實機驗收：因子六角圖與解鎖特效（PROG-2-0721、#539）

## 為什麼做
#539（OPEN-08）把因子六角圖接上 cc 大廳畫面（`FactorHexGraphic`），並在因子解鎖時播放特效。資料與元件單元測試已過，但六角圖的繪製位置、比例與解鎖特效的實際表現需實機確認。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 進入大廳，找到因子六角圖區塊：六邊形正確繪製，六個頂點數值與標籤可見、未被裁切。截圖。
3. 若目前存有可解鎖的因子：觸發解鎖後應播放特效，特效結束後六角圖數值更新。錄影或連拍截圖。
4. 重新進入大廳：六角圖與已解鎖狀態一致（不因重新整理而回退）。截圖。
5. 在窄版視窗（手機寬度）檢查六角圖不超出畫面或與其他元件重疊。截圖。

## 驗收標準
- 步驟 2 到 5 皆有截圖或錄影；PR 說明寫明 Before/After 與 HEAD。
- 若無可解鎖因子可觸發，步驟 3 記為「無法觸發」並說明原因，不得視為通過。
- 任一步不符：記錄截圖、元件位置與 HEAD，回報 PM 另開卡。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改六角圖程式或解鎖邏輯；只回報現象。

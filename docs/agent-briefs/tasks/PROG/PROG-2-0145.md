# [PROG-2-0145] 實機驗收：命紋靈獸摘要與六角圖並存（PROG-2-0720、#542）

2. 進入大廳，確認靈獸摘要與因子六角圖同時可見，兩者都未互相遮擋或裁切。截圖。
3. 點開靈獸摘要的項目（若有互動）：內容正確顯示，關閉後回到大廳且畫面未停留在錯誤狀態。截圖。
4. 重新整理或重新進入大廳：兩個區塊仍同時存在，順序與內容一致。截圖。
5. 窄版視窗（手機寬度）檢查兩區塊不超出畫面、無重疊。截圖。

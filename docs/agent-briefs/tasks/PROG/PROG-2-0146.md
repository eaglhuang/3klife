# [PROG-2-0146] 實機驗收：年報畫面彈出與內容（PROG-2-0820、#563）

## 為什麼做
#563（TIME-07 年報畫面）讓大廳在年末收到 `YearEnded` 事件時彈出年報畫面，標題為「{Year} 年度總結」，顯示本年歿人數與本年屆齡退役候選人數，並有「關閉」鈕。程式與文字綁定測試已過，但彈出時機、版位與數字的實機呈現需確認。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 推進遊戲時間到年末，使 `YearEnded` 事件觸發。若無法在正常流程中推進到年末，記錄為「無法觸發」並說明原因，不得視為通過。
3. 年報畫面應自動彈出，不被其他視窗遮住。截圖。
4. 檢查標題為「{Year} 年度總結」，{Year} 已代入實際年份，無殘留佔位字。截圖。
5. 檢查本年歿人數與本年屆齡退役候選人數：與遊戲內當年的實際數字一致（以遊戲內可查的紀錄核對）。截圖並記錄兩個數字。
6. 檢查版位：標題、兩個數字與「關閉」鈕皆在卡片內、未被裁切或重疊；窄版視窗（手機寬度）同樣檢查。截圖。
7. 點「關閉」：年報畫面收起，大廳恢復可操作，且不會重複彈出。截圖。

## 驗收標準
- 步驟 3 到 7 皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 步驟 2 若無法觸發年末，整張卡記為「暫停驗收」，不得判通過。
- 任一步不符：記錄截圖、數字與 HEAD，回報 PM 另開卡。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改年報的數字計算或版面 JSON；只回報現象。
- 年報不含勝場，這是暫定設計，不列為缺陷。

# [PROG-2-0147] 實機驗收：BRD-09 批語面板（PROG-2-0822、#575）

## 為什麼做
結緣介面在父母配好後顯示 2~3 名士的批語，每則為「名士：色系（關鍵詞）」；不足 2 位已解鎖名士時顯示提示。批語面板位置為 PM 暫定，由實機驗收確認。

## 步驟
1. 用最新 master 建置 Web 版，記下 HEAD。
2. 解鎖 0 位、1 位、2 位以上名士各一次，進入結緣介面配對父母：不足 2 位時顯示提示；達標時顯示 2~3 則批語。截圖。
3. 批語格式為「名士：色系（關鍵詞）」，文字完整、未截斷、無佔位字。截圖。
4. 同一對父母離開再回來：批語內容不跳動。記錄兩次內容。
5. 檢查批語面板的版位與字級：未與其他控制項重疊，字級可讀。截圖。

## 驗收標準

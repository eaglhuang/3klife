# [PROG-2-0148] 實機驗收：BRD-09 天象異變通知（PROG-2-0823、#577）

## 為什麼做
結緣成功時，通知會加上「天象異變：流星／紫氣／鹿銜草」其中一項，只在子嗣出生當下顯示一次。天象抽選依出生季節與存檔亂數種子，PM 裁定三種等機率。

## 步驟
1. 用最新 master 建置 Web 版，記下 HEAD。
2. 進行一次結緣成功，觀察出生通知：應出現「天象異變：」加上三種之一。截圖。
3. 重複結緣數次（若可），確認三種天象都能出現，且每次只在出生當下顯示一次。記錄次數與結果。
4. 關閉通知後再進入其他畫面，天象異變不再重複顯示。截圖。
5. 檢查通知文字的版位與字級：未被裁切，字級可讀（窄版視窗也要檢查）。截圖。

## 驗收標準
- 每一步皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 任一步不符：記錄截圖、位置與 HEAD，回報 PM 另開卡。
- 版位與字級為暫定，若需調整，記錄座標與字級數值，不要自行改版面。

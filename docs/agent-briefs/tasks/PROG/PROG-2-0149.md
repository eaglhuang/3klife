# [PROG-2-0149] 實機驗收：精力劇本 toast 與補元散按鈕（PROG-2-0732、PROG-2-0733、#578、#583）

## 為什麼做
#578 把精力劇本句接到培育、補元散與結緣提示點：精力歸 0 時顯示 toast（不擋行動）、使用補元散後顯示劇本句、選中待產母方時顯示待產提示。#583 在培育畫面的訓練區加上「使用補元散」按鈕，對目前選中的子嗣使用一顆補元散。程式與 headless 測試已過，但按鈕位置、toast 的顯示與可讀性需實機確認。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 進入培育畫面，確認訓練區出現「使用補元散」按鈕，位置與大小與「休息」按鈕協調、未遮擋其他控制項。截圖。
3. 選一位子嗣，讓精力歸 0，再嘗試行動：應顯示精力劇本 toast，行動不被擋（規則不變）。截圖。
4. 點「使用補元散」：子嗣精力回復，toast 顯示劇本句（不再是舊的「精力回復 N」文字）。截圖並記錄 toast 文字。
5. 結緣畫面：選中一位待產的母方，應顯示待產劇本句 toast；若沒有待產母方，不應顯示。截圖。
6. 窄版視窗（手機寬度）檢查補元散按鈕與 toast 不超出畫面、不重疊。截圖。

## 驗收標準
- 步驟 2 到 6 皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 按鈕座標與 toast 位置為 PM 暫定，若需調整，記錄座標與數值，不要自行改版面。
- 大器線索的文字不在本卡範圍（維持既有 LateBloomClue 規格文字）。

# [PROG-2-0152] 實機驗收：武將詳情五階奧義提示行（PROG-2-0740、#600）

## 為什麼做
#600 在武將詳情的奧義子頁、解鎖條件區塊末尾加上一行血脈傳承五階奧義進度，例如「血脈傳承奧義：已點亮 1 / 5 階（上限 1），需先升星提高上限」。判定可點亮時顯示「下一階可點亮」。程式與 headless 測試已過，但文字的實際顯示、可點亮提示的判定與版位需實機確認。摘要文案與名聲、事蹟的來源為 PM 暫定，本卡只驗收顯示與版位，不驗收文案內容。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 進入武將詳情的奧義子頁，找到解鎖條件區塊末尾的五階奧義進度行。應有文字，未空白、未顯示佔位字。截圖。
3. 記錄該行顯示的完整文字與當下的點亮階數、上限，兩者應一致。
4. 若目前某武將符合可點亮條件：該行應顯示「下一階可點亮」。截圖。若無符合條件的武將，此步記為「無法驗收」並說明原因，不得視為通過。
5. 若目前某武將不符合條件（例如上限已滿）：不應顯示「下一階可點亮」。截圖。
6. 版位：文字行不與上下元件重疊，長文字換行或截斷的表現可讀；窄版視窗（手機寬度）同樣檢查。截圖。

## 驗收標準
- 步驟 2 到 6 皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 文案內容與名聲、事蹟來源不在本卡驗收範圍，只記錄觀察，不判定對錯。
- 版位與字級為 PM 暫定，若需調整，記錄數值，不要自行改版面。

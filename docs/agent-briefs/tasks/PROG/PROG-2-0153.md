# [PROG-2-0153] 實機驗收：退役回顧獎勵（虎符／竹簡）（PROG-2-0739、#605）

## 為什麼做
#605 讓武職退役發一張退役虎符，文職與雙職退役發竹簡，並在退役回顧面板顯示獲得的獎勵：「獲得虎符 ×1」或「獲得竹簡 ×1」。退役者之後死亡不再發第二張虎符。程式與 headless 測試已過，但獎勵句的顯示、版位與數量需實機確認。獎勵句文案與非中文譯文為 PM 暫定，本卡不判文案對錯。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 退役一位武職武將，進入退役回顧面板：應顯示「獲得虎符 ×1」，數量為 1。截圖。
3. 退役一位文職（或雙職）武將：應顯示「獲得竹簡 ×1」，且不顯示虎符句。截圖。
4. 退役獎勵句的位置：與面板其他文字不重疊，未被裁切。截圖。
5. 若可在遊戲內查看物品或名冊：確認退役武職後僅取得一張虎符；該武將之後若死亡，不應再多發一張虎符。無法查證時記為「無法驗收」並說明原因。
6. 窄版視窗（手機寬度）檢查獎勵句與版面。截圖。

## 驗收標準
- 步驟 2、3、4、6 皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 步驟 5 若無法查證，記為「無法驗收」，不得視為通過。
- 獎勵句文案與版位為 PM 暫定，若需調整，記錄數值，不要自行改版面。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改文案、獎勵數量或程式碼；只回報現象。

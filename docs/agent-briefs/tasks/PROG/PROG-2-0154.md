# [PROG-2-0154] 實機驗收：培育英靈循環與傳道按鈕（PROG-2-0871、#613）

## 為什麼做
#613 在培育畫面的訓練區右欄加上兩顆按鈕：「英靈卡循環」可依序切換英靈卡，「傳道」對目前選中的英靈卡執行傳道。程式與 headless 測試已過，但按鈕位置、字寬與可按狀態需實機確認。英靈卡清單目前暫用教官卡來源，正式來源待裁決，本卡不判清單內容。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 進入培育畫面，確認訓練區右欄出現兩顆按鈕，文字完整、未遮擋其他控制項。截圖。
3. 點「英靈卡循環」：目前英靈卡應依序切換，循環一圈後回到起點。記錄每次切換後的卡名。
4. 無英靈卡可選時：傳道按鈕應為不可按狀態。截圖。
5. 有英靈卡時：點「傳道」，應執行傳道流程，結果回饋可見。記錄結果。
6. 版位：兩顆按鈕與「休息」「使用補元散」等既有按鈕不重疊；窄版視窗（手機寬度）同樣檢查。截圖。

## 驗收標準
- 步驟 2 到 6 皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 按鈕座標與字寬為 PM 暫定，若需調整，記錄數值，不要自行改版面。
- 英靈卡清單來源不在本卡驗收範圍。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改英靈卡來源或程式碼；只回報現象。

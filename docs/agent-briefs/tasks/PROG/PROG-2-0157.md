# [PROG-2-0157] 實機驗收：武將血脈頁隱藏因子（PROG-2-0712、#638）

## 為什麼做
#638 讓武將血脈頁在覺醒卡下方顯示一行隱藏因子文字，例如「隱藏因子：不敗、鐵壁」；都未覺醒時顯示「隱藏因子：尚未覺醒」。程式與 headless 測試已過，但這行文字的版位與高度（暫定 40）需實機確認。非 zh-TW 文案為暫定譯文，本卡不判譯文內容。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 進入一位尚未覺醒隱藏因子的武將血脈頁：應顯示「隱藏因子：尚未覺醒」，文字完整。截圖。
3. 進入一位已覺醒隱藏因子的武將血脈頁：應顯示覺醒的因子名稱，同名不重複出現。記錄顯示文字。截圖。
4. 版位：隱藏因子行與覺醒卡、血脈頁其他元件不重疊，高度足以容納文字，未被裁切。截圖。
5. 切換語系（若可）：文字可讀，未出現佔位字；非 zh-TW 譯文不判對錯。截圖。
6. 窄版視窗（手機寬度）同樣檢查。截圖。

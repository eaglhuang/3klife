# [PROG-2-0158] 實機驗收：戰技 Tab 五階血脈傳承奧義操作區（PROG-2-0720、#647）

## 為什麼做
#647 在武將詳情的戰技 Tab 加上奧義操作卡（`UltimateStageCard`），有摘要、「點亮下一階」按鈕與「升星」按鈕。可點亮時按鈕開放，否則顯示原因；升星按鈕固定鎖定。階段摘要從奧義解鎖條件區移到新卡。程式與 headless 測試已過，但卡片高度、按鈕樣式與點亮後的刷新需實機確認。版面高度暫定為 142。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 進入武將詳情的戰技 Tab，確認奧義操作卡出現，摘要、兩顆按鈕可見。截圖，並量測卡片實際高度。
3. 按鈕樣式：「點亮下一階」與「升星」的文字、顏色、大小與其他按鈕一致，未被裁切。截圖。
4. 可點亮時：「點亮下一階」按鈕應開放，點擊後卡片刷新，摘要與階數同步更新，且不殘留舊資料。截圖前後各一張。
5. 不可點亮時：按鈕應不可按，並顯示原因。截圖。
6. 「升星」按鈕在所有狀態下都應鎖定、不可按。截圖。
7. 版位：卡片與戰技 Tab 其他元件不重疊；窄版視窗（手機寬度）同樣檢查。若高度 142 不足，記錄實際需要的高度數值，不要自行改版面。

## 驗收標準
- 步驟 2 到 7 皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 步驟 4 若無法找到可點亮的武將，記為「無法驗收」並說明原因，不得視為通過。
- 版面高度 142 與按鈕樣式為 PM 暫定，只量測並記錄數值，座標微調由 Codex 依實機結果做，不要改其他版面。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改奧義規則或程式邏輯；只回報現象與量測數值。

# [PROG-2-0160] 實機驗收：因子六角圖依層級遮罩（LUK-04、PROG-2-0883、#663）

## 為什麼做
#663 讓大廳的因子六角圖依玩家層級決定可見色。未解鎖色畫成灰點遮罩、不顯示色相；解鎖特效只對已解鎖色播放。規則為 Lv21 解鎖綠白、Lv46 解鎖紫紅。程式與 headless 測試已過，但灰點與灰軸的觀感、特效是否只播已解鎖色，需實機確認。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 以三種玩家層級檢查六角圖：Lv1、Lv21、Lv46。每種層級各截一張。
3. 未解鎖色：對應的點應為灰點，六角圖的軸線也應為灰色；截圖。
4. 解鎖特效：只有已解鎖色播放特效，未解鎖色不播放。每種層級各記錄一次（可用截圖或錄影）。
5. 量測與記錄：灰點是否清楚可辨、與已解鎖色是否易混淆。

## 驗收標準
- 步驟 2 到 4 皆有截圖或紀錄；PR 說明寫明 Before/After 與 HEAD。
- 層級切換後顯示應隨之更新，不殘留上一層級的顏色。
- 若無法切到某層級，記為「無法驗收」並說明原因，不得視為通過。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改程式碼與層級規則；只回報現象與截圖。

# [PROG-2-0161] 實機驗收：大廳官職區塊與官職詳情頁（PROG-2-0842、#670）

## 為什麼做
#670 在大廳官職區塊加「官職詳情」按鈕，打開後顯示目前階位與六項已解鎖權限：任務難度上限、任務欄位數、大廳熱點數、世界沙盤階段、聯盟文書、反霸權會盟。官職區塊卡高由 128 改為 168。程式與 headless 測試已過，但按鈕位置、權限行是否被裁切，需實機確認。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 大廳官職區塊：截圖，量測卡片實際高度（PM 設定值為 168），確認區塊內容未被裁切。
3. 「官職詳情」按鈕：確認位置在區塊內、不被遮住，點擊後可打開詳情頁。截圖。
4. 詳情頁：六項權限行是否完整顯示、未被裁切或溢出。截圖。
5. 關閉鈕：點擊後詳情頁收起，回到大廳。截圖。
6. 窄版視窗（手機寬度）重做步驟 2 到 4，確認無裁切。截圖。

## 驗收標準
- 步驟 2 到 6 皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 卡高 168 的實測值與是否裁切寫進回報。
- 座標微調由 Codex 依實機結果決定，但不改權限規則與文案。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改程式碼；只回報截圖、量測數值與 HEAD。

# [PROG-2-0162] 實機驗收：抽卡原子性（PROG-2-1003、PROG-2-1004）

## 為什麼做
抽卡扣款、保底、入冊已併成同一次存檔；教官卡日誌與入冊同批寫入，補寫後才移除。程式與 headless 測試已過，但要在實機確認強關時三者不會失去一致。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 進入支援卡抽卡，連抽十次；抽完立即強制關閉 app，再開啟。記錄錢包餘額、名冊武將數、教官卡數。
3. 每次強關後比對三個數字是否與強關前一致（扣款與入冊同時有或同時沒有；教官卡若有缺，下次進大廳應自動補齊）。
4. 重複步驟 2 至 3 共三次，每次截圖。
5. 只抽一次就強關的情境也測一次。

## 驗收標準
- 三次重複與一次單抽皆有截圖與三個數字的紀錄；PR 說明寫明 Before/After 與 HEAD。
- 若出現「已扣款、未入冊」或「武將已入冊、教官卡少一張且重進後未補齊」，記為不通過，附前後數字。
- 教官卡與武將入冊的一致性若有缺口，請回報現象，不要自行修改程式。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改程式碼；只回報截圖、數字與 HEAD。

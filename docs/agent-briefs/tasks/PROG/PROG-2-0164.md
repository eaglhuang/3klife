# [PROG-2-0164] 實機驗收：畢業紀錄畫面（PROG-2-0726、PROG-2-0746）

## 為什麼做
畢業紀錄畫面採固定格式列，每頁 5 列，並有上一頁、下一頁分頁。程式與 headless 測試已過，但版面、列的對齊與分頁按鈕需實機確認。注意：目前沒有按鈕打開這個畫面，入口位置待企劃或另卡指定；驗收前若無入口，改用測試用的方式開啟，並在回報中註明。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 開啟畢業紀錄畫面（若無入口，註明開啟方式）。截圖。
3. 確認每頁顯示 5 列、列的文字未被裁切、列與列對齊。截圖。
4. 資料超過 5 筆時，按下一頁、上一頁，確認頁碼與列內容同步更新；在第一頁按上一頁、最後一頁按下一頁，確認不會越界。截圖。
5. 關閉畫面，回到大廳。截圖。
6. 窄版視窗（手機寬度）重做步驟 3 與 4。截圖。

## 驗收標準
- 步驟 2 到 6 皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 分頁越界的兩個情境都要測。
- 若資料不足 6 筆無法測分頁，記為「無法驗收分頁」並說明原因。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改程式碼、版位與資料；只回報截圖與 HEAD。

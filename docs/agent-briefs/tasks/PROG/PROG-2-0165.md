# [PROG-2-0165] 實機驗收：委任開關按鈕 btnDelegate（PROG-2-0913、PROG-2-0908）

## 為什麼做
部署面板的委任開關接上玩家部署階段：開關開啟時，玩家部署階段開始會自動部署一隊，路由取我方部隊最少的路。按鈕 `btnDelegate` 由場景綁定，版面座標未寫進 layout JSON，需實機確認位置與點擊回饋。注意：驗收前先確認 `btnDelegate` 已綁定到場景；未綁定則記為阻塞，不要自行綁定。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 進入戰鬥的部署面板，確認 `btnDelegate` 出現在部署面板的功能按鈕區，位置不與其他按鈕重疊。截圖。
3. 點擊一次，確認吐司回報開關狀態，並確認按鈕文字或樣式有對應變化。截圖。
4. 開關關閉時進入玩家部署階段，確認不自動部署。截圖。
5. 開關開啟時進入玩家部署階段，確認自動部署一隊、路由是我方部隊最少的路。截圖。
6. 窄版視窗（手機寬度）重做步驟 2。截圖。

## 驗收標準
- 步驟 2 到 6 皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 若 `btnDelegate` 未綁定，記為阻塞並附截圖。
- 座標微調由 Codex 依實機結果決定；不改部署規則。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改程式碼與部署規則；只回報截圖與 HEAD。

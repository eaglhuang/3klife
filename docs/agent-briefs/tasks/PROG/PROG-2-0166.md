# [PROG-2-0166] 實機驗收：戰績排行榜畫面（PROG-2-0959、PROG-2-0960）

## 為什麼做
排行榜畫面分兩張 cc 卡完成：0959 做規格與 UIID，0960 做元件、掛載與入口。入口放在武將詳情的戰績分頁底部「全軍戰績排行榜」按鈕。程式與 UI Spec 驗證已過，但按鈕座標、文字換行與空列的顯示需實機確認。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 進入武將詳情的戰績分頁，確認底部「全軍戰績排行榜」按鈕出現、位置不與其他元件重疊。截圖。
3. 點擊按鈕，排行榜開啟。截圖，量測面板與 5 列的實際高度。
4. 切換三個指標（傷害、擊殺、守護力），每個指標各截一張，確認標題與列數值同步更新。
5. 文字換行：名稱較長或數值位數較多時，確認不換行溢出、不被裁切。截圖。
6. 空列：資料不足 5 筆時，確認空列的顯示方式與任務卡一致（空列以「—」佔位，若實機顯示與此不符，記錄實際畫面）。截圖。
7. 關閉按鈕：點擊後排行榜收起，回到戰績分頁。截圖。
8. 窄版視窗（手機寬度）重做步驟 2 與 5。截圖。

## 驗收標準
- 步驟 2 到 8 皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 按鈕座標與字級只回報，不要自行改版面；微調由 Codex 依實機結果決定。
- 若武將詳情無戰績資料可測，記為「無法驗收」並說明原因。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改程式碼與排序規則；只回報截圖與 HEAD。

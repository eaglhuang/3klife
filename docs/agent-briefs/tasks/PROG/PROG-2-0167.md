# [PROG-2-0167] 實機驗收：借將選擇畫面（PROG-2-0731）

## 為什麼做
養成中武將的教官區多一個「借將」按鈕，打開借將畫面。畫面每頁 5 位好友，每列顯示名字、星等、可借或擋下的原因，可用上一頁、下一頁翻頁。選擇可借的好友後會借用，成功或擋下都會顯示提示。按鈕位置是暫定，畫面與分頁未實機確認。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 進入養成流程，確認教官區出現「借將」按鈕。培育中時按鈕可按，非培育中時不可按。各截一張。
3. 點擊「借將」，借將畫面開啟，每頁 5 列。截圖，量測列高與面板範圍。
4. 分頁：有超過 5 位好友時，按下一頁、上一頁，確認列內容與頁碼同步；在第一頁按上一頁、最後一頁按下一頁，確認不越界。截圖。
5. 可借的列按下後，顯示借用成功提示；擋下的列按下後，顯示擋下原因提示。各截一張。
6. 關閉畫面，回到養成流程。截圖。
7. 窄版視窗（手機寬度）重做步驟 3 與 4，確認無裁切。截圖。

## 驗收標準
- 步驟 2 到 7 皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 按鈕位置回報實際座標與是否與其他元件重疊；微調由 Codex 依實機結果決定。
- 若無可借或擋下的好友可測，記為「無法驗收」並說明原因。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改借用規則與帳本；只回報截圖與 HEAD。

# [PROG-2-0168] 實機驗收：畢業紀錄入口（PROG-2-0736、PROG-2-1050，連同 PROG-2-0726 畫面）

## 為什麼做
畢業紀錄畫面（0726）先前沒有入口。現在有兩個入口：一是畢業結算後的報告區，「查看紀錄」按鈕（0736，位置暫定 left 800，在「關閉報告」按鈕右側）；二是借將畫面右上角的「畢業紀錄」按鈕（1050）。兩個按鈕的位置與點擊結果都需實機確認。畫面本身的分頁與版面由 PROG-2-0164 驗收，本卡請一併看。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 入口一：完成一次培育至畢業結算，進入報告區，確認「查看紀錄」按鈕出現、位置在「關閉報告」右側、不與其他元件重疊。截圖，量測按鈕座標。
3. 點擊「查看紀錄」，畢業紀錄畫面開啟；關閉後回到報告區。截圖。
4. 入口二：在養成流程開啟借將畫面，確認右上角「畢業紀錄」按鈕出現、文字未被裁切。截圖。
5. 點擊「畢業紀錄」，借將畫面關閉、畢業紀錄畫面開啟；關閉畢業紀錄後回到大廳。截圖。
6. 窄版視窗（手機寬度）重做步驟 2 與 4，確認按鈕未溢出或被遮住。截圖。
7. 畢業紀錄畫面的分頁與版面依 PROG-2-0164 驗收，本卡只確認兩個入口能到達畫面。

## 驗收標準
- 步驟 2 到 6 皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 兩個入口都能開啟畢業紀錄畫面，才算通過；任一入口打不開，記為不通過並附截圖。
- 按鈕座標只回報，不要自行改版位；微調由 Codex 依實機結果決定。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改程式碼與版位；只回報截圖、座標與 HEAD。

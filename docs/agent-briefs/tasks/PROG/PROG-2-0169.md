# [PROG-2-0169] 實機驗收：太守府入口、英靈圖鑑詳情、結緣求籤令（一批三區）

## 為什麼做
三組 cc 畫面接線已合併到 master，程式與 headless 測試已過，但按鈕位置、文字與版面需實機確認。依區域分三段檢查。

- 區域 A：太守府（#975 PROG-2-0986、#988）。大廳內政分類新增「太守府」入口；太守府畫面顯示等級與任務格數；升級按鈕可按並更新畫面；金錢不足時顯示提示（#988）。
- 區域 B：英靈圖鑑（#984 PROG-2-1142）。圖鑑每列有「詳情」按鈕，點擊開啟英靈卡詳情畫面，可關閉。
- 區域 C：結緣（#960 PROG-2-1140）。結緣面板顯示「求籤令 ×N」標籤；底部右側有名士占卜入口。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 區域 A：進入大廳內政分類，確認「太守府」入口出現並開啟畫面。截圖。
3. 區域 A：確認等級與任務格數文字正確顯示、未被裁切。截圖。
4. 區域 A：金錢足夠時按升級，畫面刷新；金錢不足時按升級，確認出現金錢不足提示。各截一張。
5. 區域 B：進入英靈圖鑑，確認每列「詳情」按鈕出現、位置不與列文字重疊；點擊後英靈卡詳情畫面開啟，關閉後回到圖鑑。截圖。
6. 區域 C：進入結緣面板，確認「求籤令 ×N」標籤數字與實際持有數一致；確認底部右側名士占卜入口可按。截圖。
7. 窄版視窗（手機寬度）重做區域 A 的步驟 3、區域 B 的步驟 5、區域 C 的步驟 6。截圖。

# [PROG-2-0170] 實機驗收：寶頁六格裝備、血統樹連線與主角區、道具背包（一批四區）

## 為什麼做
四組 cc 畫面接線已合併到 master，程式與 headless 測試已過，但版面、連線與按鈕需實機確認。依區域分四段檢查。

- 區域 A 寶頁六格裝備（#990，PROG-2-1037）：寶頁裝備分頁底部顯示兩列三欄六格，依序為武器、防具、飾品、坐騎、典籍、寶物；格子文字正確、未被裁切。
- 區域 B 血統樹父子連線（#1025，PROG-2-1300）：血統樹上父到子的連線為平滑貝茲曲線，不同螢幕比例下線條對齊節點、不穿過文字。
- 區域 C 血統樹主角區（#1034，PROG-2-1301）：主角區的稀有度與兩組詞條文字正確顯示；空資料時顯示佔位字。
- 區域 D 道具背包（#1038，PROG-2-1041）：大廳商城分類第四項「背包」可進入；清單、詳情與「使用→確定→取消」兩步確認可用。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 區域 A：進入寶頁裝備分頁，確認六格出現、順序正確、文字未裁切。截圖。
3. 區域 B：進入血統樹，確認父子連線為曲線、端點對齊節點。以至少兩種螢幕比例（例如 16:9 與 4:3 或直幅）各截一張。
4. 區域 C：選取一位主角，確認稀有度與兩組詞條文字顯示；選取無詞條的角色，確認佔位字出現。截圖。
5. 區域 D：商城分類中點「背包」，確認背包畫面開啟、清單有列；選一個道具，按「使用」，再按「確定」，確認使用結果提示與數量更新；另測「取消」不扣數量。截圖。
6. 窄版視窗（手機寬度）重做區域 A 步驟 2、區域 B 步驟 3、區域 D 步驟 5。截圖。

## 驗收標準
- 四個區域的步驟皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 任一區域的畫面打不開或文字錯誤，記為不通過並附截圖。
- 若背包內沒有可用道具，區域 D 記為「無法驗收使用流程」並說明原因。
- 座標與字級只回報，不要自行改版位；微調由 Codex 依實機結果決定。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改程式碼與版位；只回報截圖、座標與 HEAD。

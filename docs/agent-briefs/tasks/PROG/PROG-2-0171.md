# [PROG-2-0171] 實機驗收：開場信件面板大廳掛載與版面（PROG-2-1305、#1064）

## 為什麼做
開場信件面板（PROG-2-1302）原本只有元件，#1064 把它掛到大廳，並訂定版面。規則為新局首次進大廳時自動開啟一次，關閉後寫入已讀，之後再進大廳不再開啟。程式與 headless 測試已過，但座標、排版與自動開啟的時機需實機確認。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 建立新局，首次進大廳：確認開場信件面板自動開啟。截圖。
3. 確認面板標題、本文段落與關閉鈕的排版：文字未溢出、段落間距一致、關閉鈕可按。截圖，量測面板範圍。
4. 按關閉，面板收起。截圖。
5. 離開大廳後再進入（或重新開啟 app 讀同一存檔），確認面板不再自動開啟。截圖。
6. 窄版視窗（手機寬度）重做步驟 3。截圖。

## 驗收標準
- 步驟 2 到 6 皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 若重新開啟後面板又自動開啟，記為不通過並附前後截圖。
- 座標與字級只回報，不要自行改版位；微調由 Codex 依實機結果決定。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改程式碼與文案；只回報截圖、座標與 HEAD。

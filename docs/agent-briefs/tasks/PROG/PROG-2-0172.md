# [PROG-2-0172] 實機驗收：命頁左右兩欄版面（PROG-2-1267、#1098）

## 為什麼做
命頁改為左右兩欄：左欄為隱藏立繪層與祖先圖（2/4/8 人數不變），右欄為六塊（靈獸與奧義兩塊目前只有空殼標籤）。程式與 UI Spec 驗證已過，但座標、高度、字級與右欄捲動需實機確認。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 進入武將詳情的命頁分頁，確認左右兩欄出現，左欄為祖先圖，右欄為六塊。截圖。
3. 分別以祖先 2 人、4 人、8 人的武將檢查左欄祖先圖，人數顯示與規格一致。各截一張。
4. 量測右欄六塊的座標與高度，記錄文字字級；確認文字未溢出、未被裁切。截圖。
5. 右欄捲動：若右欄內容超出可視範圍，確認可以捲動到最後一塊，且捲動時左欄不跟著移動。截圖。
6. 英靈世家捷徑（右欄內）：點擊後能正確開啟英靈世家畫面。截圖。
7. 窄版視窗（手機寬度）重做步驟 2 與 5。截圖。

## 驗收標準
- 步驟 2 到 7 皆有截圖與量測數值；PR 說明寫明 Before/After 與 HEAD。
- 右欄無法捲動到最後一塊，或捷徑打不開，記為不通過並附截圖。
- 座標、高度與字級只回報，不要自行改版位；微調由 Codex 依實機結果決定。
- 靈獸與奧義兩塊為空殼，不列為不通過。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改程式碼與版位；只回報截圖、數值與 HEAD。

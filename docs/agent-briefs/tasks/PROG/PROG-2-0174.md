# [PROG-2-0174] 實機驗收：適性台詞全域 Toast（PROG-2-1311、#1108）

## 為什麼做
回合推進時會發出適性台詞事件，現在由全域 Toast 顯示給玩家。程式與 headless 測試已過，但 Toast 的出現時機、停留秒數、位置與文字可讀性需實機確認。獨立戰報行或飄字版面不在本卡範圍。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 進入戰鬥，推進回合直到觸發適性台詞。確認 Toast 出現，文字正確。截圖。
3. 量測 Toast 的停留時間與位置，確認未遮住戰場主要單位與行動按鈕。截圖。
4. 連續觸發兩則台詞，確認 Toast 依序顯示、不疊字。截圖。
5. 窄版視窗（手機寬度）重做步驟 2。截圖。

## 驗收標準
- 步驟 2 到 5 皆有截圖與量測數值；PR 說明寫明 Before/After 與 HEAD。
- 若無法觸發適性台詞，記為「無法驗收」並說明原因，不得視為通過。
- Toast 的秒數與位置只回報，不要自行改版位；微調由 Codex 依實機結果決定。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改程式碼與台詞文案；只回報截圖、數值與 HEAD。

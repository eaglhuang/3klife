# [PROG-2-0176] 實機驗收：血統樹樣式、父子連線與卡片位置（PROG-2-1353、#1129）

## 為什麼做
14 人血統樹過去沒有父子連線，樣式也沒有載入。#1129 新增共用模組 `BloodlineTreeLines`，畫面呼叫後會依卡片實際位置畫出父子連線，並依子代因子色上色。連線的端點與顏色正確與否，需實機確認。

## 步驟
1. `git fetch origin`，用最新 master 建置 Web 版，記下 HEAD。
2. 進入血統樹畫面（命頁血統分頁或底座 BloodlineTreeScreen），截圖整體。
3. 確認每對父子卡片之間有連線，且連線端點落在卡片邊緣，不穿過卡片本體。截圖。
4. 確認連線顏色與子代因子色一致（抽查三組）。截圖並記下色碼。
5. 窄版視窗（手機寬度）重做步驟 2。截圖。

## 驗收標準
- 步驟 2 到 5 皆有截圖；PR 說明寫明 Before/After 與 HEAD。
- 連線端點與顏色若不符，只回報截圖與座標，不要改程式。
- 若畫面目前沒有呼叫這兩個函式（命頁接線尚未完成），記為「無法驗收」並說明原因，不得視為通過。

## 不要做
- 不使用緊急授權、Quick Fix 或 backend import。
- 不改程式碼；只回報截圖、座標、色碼與 HEAD。

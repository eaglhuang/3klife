## 完整描述
PROG-2-0088 的地形查表中，弓兵站在水域射程 −1。本卡把它接進目標搜尋與武將攻擊判定的射程計算：在戰術修正後的射程上加上 `attackRangeDelta`，有射程的兵種至少保留 1，避免射程 0 變成無法攻擊。

## 隱蔽
- 弓兵林地隱蔽 +20%：規格只寫數字，戰鬥效果由 PM 暫定為「敵方對該弓兵命中率 −20%」，套在既有命中公式上，仍受 50% 下限。
- 反擊（tryTriggerCounterReaction）目前不擲命中，所以隱蔽不套用到反擊。

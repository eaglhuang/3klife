## 完整描述
數值系統 §F-4 的 predictBattleOutcome：攻守總戰力比值 ratio，勝率 = 0.5 + (ratio − 1) × 0.6，夾在 5%~95%，依勝率分「攻方優勢 / 勢均力敵 / 攻方劣勢」三段。本卡只做純函式，不改戰鬥狀態，像戰前的 Odds 顯示。

Unity 對照：像在 UI Label 上顯示 Odds，輸入兩邊 CP，輸出百分比與標籤，不碰 GameObject 的狀態。

## 尚未完成 / 暫定

- 守方戰力低於 1 時以 1 計，避免除以零：暫定做法，規格未寫。

## 完整描述
數值系統 §F-4 的總戰力公式，依 §F-5 的常數實作為純函式。F-5 已列出 AGE_MODIFIER、APTITUDE_EFFICIENCY、TALLY_QUALITY_MOD、SPIRIT_CARD_POWER_CAP、STRATEGIST_POWER_RATE、DEPUTY_* 等數值，本卡直接採用，不另外猜值。

Unity 對照：像 RPG 的 Combat Power 計算器，輸入一位主將的屬性、兵種、裝備與加成，輸出一個整數戰力，不碰場景物件。

## 設計選擇（我的判斷）
- 輸入採純資料結構（數字與字串），不依賴 GeneralUnit、TroopDef 等模型，維持 headless 可測。
- 地形與天氣只接收「攻防加總」數字，查表由呼叫端做，因為現有 TerrainTroopRules 只涵蓋弓兵與地形射程，尚無完整的主將 terrainAptitude 查表。
- 虎符的適性修正（地形、家族、性別）由呼叫端算好傳入 affinityMod。F-5 已給數值，但 getTallyAffinityMod 查表函式規格未定義，本卡不實作。
- 運算順序照規格偽代碼：加總後依序乘 aptitude、tallyMod、terrain、weather、reincarnation，最後 floor。

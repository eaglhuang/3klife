# [PROG-2-0210] 地形、天氣攻防與虎符適性修正（總戰力的呼叫端查表）

## 完整描述
PROG-2-0209 的總戰力把地形、天氣攻防與虎符適性交給呼叫端。本卡實作這三組查表：
- 地形與天氣攻防：沿用戰鬥既有的適性表（`APTITUDE_MODIFIERS` 經 `terrainGradeOf`、`weatherGradeOf`），與戰鬥判定一致。
- 虎符適性：地形等級查 TERRAIN_AFFINITY_MOD（規格 F-5 原值），加家族共鳴 1.08、史實羈絆 1.05、性別匹配 1.06。

Unity 對照：像 ScriptableObject 查表，地形與天氣直接共用戰鬥那張表，不另外複製一份數字。

## 設計選擇（我的判斷）
- 規格偽代碼用到 getTerrainMod、getWeatherMod，卻沒有定義查表。我採用既有的 `APTITUDE_MODIFIERS`，因為戰鬥判定已經用它，數值才會一致。
- F-5 寫 D 適性攻防 −0.25，現行程式表（Q16=C 暫定）寫 −0.3。本卡沿用程式表，兩者差異記入待辦，請 PM 決定以哪一個為準。
- 家族、史實羈絆、性別由呼叫端判斷後傳入布林值。規格的 hasClanBond 沒有資料來源定義。

## 尚未完成 / 暫定
- hasClanBond 的資料來源未定，呼叫端暫時傳入。
- D 適性攻防數值（−0.3 或 −0.25）待 PM 確認。

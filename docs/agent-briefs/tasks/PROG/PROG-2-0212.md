## 完整描述
把預判勝率接到出征編制畫面。攻方是目前主將，守方是大廳開戰時的第一個關卡敵將（大廳固定取 `_encounters[0]`）。文字格式「攻方勝率 X%（標籤）· 粗估」，放在出征摘要下方。

PM 決定（2026-10-13）：選粗估，先上線，記為暫定，之後另開卡接實際編制。

Unity 對照：像戰前 Odds 標籤，主將頭像旁顯示一行百分比，資料不足時顯示提示而不是假數字。

## 粗估的固定條件（暫定）
- 兩邊都用步兵（攻 40、防 20、移 3、射 1），適性依各自表。
- 地形平原、天氣晴天，兩邊都用同一組條件。
- 不接虎符、英靈卡、參謀、後勤。
- 年齡一律視為壯年（Prime），規格的年齡門檻在本卡沒有定義。

## 設計選擇
- 數值計算放在純邏輯模組 `SortiePrediction.ts`，控制器只傳入敵將設定、套文字。
- 敵將由大廳非同步載入後傳給控制器；載入失敗或找不到時顯示「敵將資料未載入」。
- 版面新增節點 `sortiePredict`，並同步 M5ViewSpec 的節點檢查。

## 驗收
- `tests/SortiePrediction.test.ts`：同能力 50% 勢均力敵；主將較強為攻方優勢；較弱為攻方劣勢；文字格式。
- M5ViewSpec 通過，確認新 view key 在版面 JSON 有節點。
- run-cli ALL PASS，無新增失敗。

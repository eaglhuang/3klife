## 完整描述
PM 指示：補上通關進度的存檔欄位與關卡的 chain 欄位，讓連環破真正生效。存檔 schema 需附舊檔遷移與預設值，舊存檔要能載入。

## 設計選擇（我的判斷）
- 存檔欄位 `clearedStageIds` 為選填，沿用 schemaVersion 1（與 deck、discoveryExp 等後加欄位相同做法），舊檔讀回補空陣列。
- 只有 `player-win` 才記通關；同一關重複通關不重複記入。
- 戰場結算的 `recordBattle` 以 `stageId` 指定本場關卡，由 BattleScene 的 `encounterId` 傳入。
- 大廳開戰關卡：主鏈上第一個「已解鎖且未通關」的關卡；全部通關時回到清單第一關。
- 主鏈資料為試作：encounter-001（虎牢關）順序 1、encounter-002（長板坡）順序 2，同屬 `changban-chain`。

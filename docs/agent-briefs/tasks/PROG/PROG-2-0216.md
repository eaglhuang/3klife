# [PROG-2-0216] 戰場整隊同血統檢查（SAME-02）

## 完整描述
名號限定制：同一 Bloodline_ID 的武將不可同場。出征編制（參謀、後勤）已有檢查，但戰場開戰時的整隊（主將 + 參謀 + 後勤）沒有再檢查，WBS v3 標為缺口。

## 設計選擇（我的判斷）
- 整隊血統檢查為純函式 `checkFormationBloodlines`，無血統者不參與比對。
- 在建立出征帳本（`createSortieState`）時檢查，重複則拋錯，不默默放行。
- 整隊血統由 `GameSession.getSortieInput` 帶入；支援武將已在 `getSortieSupportSummary` 過濾衝突，所以正常流程不會觸發拋錯。

## 驗收
- `tests/SortieDeploy.test.ts`：不同血統通過、無血統略過、同血統拒絕；`createSortieState` 同血統拋錯。
- run-cli ALL PASS，無新增失敗。

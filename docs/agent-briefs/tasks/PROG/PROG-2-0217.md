# [PROG-2-0217] 傭兵上場限制（MERC-06）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0217 |
| 負責 Agent | claude-code-haiku-5.5 |

## 完整描述
WBS v3 M5 缺口優先序第一名。傭兵可出戰，但數值不計入永久紀錄，戰場上不可被俘虜。

## 設計選擇（我的判斷）
- 「不計入永久紀錄」解讀為：不扣精力、不寫戰績與功勳、不產生結算條目（因此也不擲覺醒）。
- 判定沿用既有的試用傭兵旗標（`isMercenary`、`templateFlag` / `hiddenFlags` 的 `MERC_TRIAL`），與 POW 豁免共用同一函式 `isTrialMercenary`。
- 戰敗不被俘虜的規則已由 `isPowExempt` 實作，本卡不重做。
- 傭兵資料模型與獲取（MERC-01/02）屬於 M6，本卡只處理戰場規則。

## 驗收
- `tests/BattleRoster.test.ts`：傭兵出戰精力不扣、無戰績、不進結算清單、不算略過；MERC_TRIAL 旗標同樣生效。
- run-cli ALL PASS，無新增失敗。

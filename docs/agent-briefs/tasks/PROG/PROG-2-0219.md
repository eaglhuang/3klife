## 完整描述
WBS v3 缺口優先序 11、12、15 列出因子解鎖的 Discovery_Level 可見性、雙旗標分離與遮罩顯示。
既有的 FactorInheritance 已寫入 discoveryLevel 與 isLocked，但缺少「玩家等級 → 看得到什麼、生效什麼」的統一判定，畫面層無處取得遮罩文字。

## 設計選擇（我的判斷）
- 遮罩文字依規格 UI_GENE_LOCKED 採「??? (Lv N 解鎖)」。
- 看得到（revealed）只看 Discovery_Level；生效（active）只看 Is_Locked，兩者分開，符合規格 §I 的語義註記。
- 門檻沿用 FACTOR_DISCOVERY_LEVEL（綠白 20、紫紅 45），不另建門檻表。

## 尚未完成 / 暫定

- 畫面層套用遮罩（灰階、亮起動畫）屬 UI，留待後續卡。

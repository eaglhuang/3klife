# [PROG-2-0223] 讀檔後主動指令死亡進季結結算 (LIFE-09 續)

## 開單原因
PROG-2-0222 讓待季結死亡寫入存檔，但讀檔後季結前名冊基準為空，陣亡者會被當成「早就死了」，虎符卡不產生。

## 完整描述
- 新增純函式 preLifespanBaseline：把待季結陣亡武將還原為非陣亡副本，供 _settleDeaths 比對。
- GameSession.load 在還原待季結死亡後設定 _preLifespanRoster。
- 不改 advanceSeason、spendLifespan、_settleDeaths 呼叫處。

## 如何驗證
1. tests/LifespanDeathSeason.test.ts：基準還原正確；無待季結死亡為 null；讀檔後季結事件含主動死亡。
2. run-cli ALL PASS；compute-gate standard。

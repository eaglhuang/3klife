## 完整描述
WBS v3 TRP-09 缺口：純邏輯已在 TigerTallyLoyalty.ts，但沒有任何呼叫端，忠誠狀態也不會存檔。本卡把它接上 GameSession 與存檔。

## 設計選擇（我的判斷）
- 忠誠狀態以武將 id 為鍵，存在 GameSession 內並寫入存檔欄位 `tallyLoyalty`；舊檔讀回補空物件。
- 季次用 `totalSeasonsElapsed`（每季 +1，單調遞增），符合 TigerTallyLoyalty 的季編碼要求。
- 初始忠誠規格未定，暫定 50；轉蛋名將由呼叫端傳入旗標（武將模型沒有這個欄位）。
- 不接戰場拒令與叛變效果，也不做裝備/卸下 UI。兩者依規格都還未定，留待後續卡。

## 驗收
- `tests/TigerTallyWiring.test.ts`：忠誠記在武將身上、不在名冊回傳 null、每季一次限制、連續兩季 ×1.5、轉蛋鎖 100、存檔往返與舊檔相容、壞條目丟棄。
- run-cli ALL PASS，無新增失敗。

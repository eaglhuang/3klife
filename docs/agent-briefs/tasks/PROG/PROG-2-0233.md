## 完整描述
WBS v3 TRP-08 缺口：沒有虎符的持有者狀態，所以「一符一將」「陣亡退回君主」都無法檢查。本卡新增純邏輯持有模組。

## 設計選擇（我的判斷）
- 持有者以單一欄位記錄（武將 id 或 null 表示君主），唯一性由結構保證。
- 裝上時虎符必須先由君主持有，不能直接搶；要換手用轉交。
- 轉交只改持有關係，忠誠規則留在 TigerTallyLoyalty。
- 君主沒收與陣亡都退回君主，沒收的降忠不在本卡處理。

## 驗收
- `tests/TigerTallyHoldings.test.ts`：起始君主持有、一符一將、一將一符、卸下退回、轉交、陣亡與沒收只影響該武將。
- run-cli ALL PASS，無新增失敗。

## 完整描述
Data Schema 文件 §2-1 / §2-1a 規定讀取模型（Read Model）的形狀與約束：一名武將最多一枚虎符、最多一隻精神卡、出征編隊的軍師與副將不可與主將重複、戰鬥狀態的戰法與精銳數量有上限。目前沒有任何程式檢查這些規則。

## 設計選擇（我的判斷）
- 做成純函式驗證器，回傳 `ReadModelIssue` 陣列，不拋錯，方便 UI 與測試各自決定怎麼處理。
- 型別與常數依規格文件取值；戰鬥狀態的戰法與精銳上限照規格表，不另外發明。

## 驗收
- `tests/ReadModelValidators.test.ts`：6 條，涵蓋重複 key、ID 不符、來源型別錯誤、同武將雙虎符/雙精神卡、編隊角色重複、缺主將、糧草/戰法/精銳超上限。
- run-cli ALL PASS，無新增失敗。

## 完整描述
PROG-2-0234 的驗證器只有測試、沒有在戰前呼叫。本卡把出征編制（主將／參謀／後勤三角色不重覆）接到開戰流程，作為戰前的守門記錄。

## 設計選擇（我的判斷）
- 用 `getSortieSupportSummary` 的結果，所以只檢查實際生效的支援，失效的支援已被 session 過濾。
- 只記 warn、不擋戰鬥：驗證器是防回歸的保險，不應讓玩家卡在開戰前。
- 虎符表、英靈卡表、Battle_State 留待後續卡，本卡不改存檔格式。

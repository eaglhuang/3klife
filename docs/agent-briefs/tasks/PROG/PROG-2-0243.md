## 完整描述
可結緣女性來源系統 §I 規定女性武將帶 FemaleSource（Source_Type、Quality_Grade、Acquired_Season）。戰場俘虜女性的來源是 CAPTIVE，品質範圍 SR~N。四種處置（勸降／招募／釋放／無期徒刑）已在 PrisonerOfWar 實作，本卡補上女俘虜的來源標籤純邏輯。

## 設計選擇（我的判斷）
- 性別以資料欄位 `gender` 的「女」或 `female` 判斷，與 VitalityCap 相同寫法。
- 品質對應暫定：SSR→SR（封頂）、SR→SR、R→R，因為規格只寫「SR~N」而未給稀有度對照表。
- 試用傭兵與豁免者不帶來源。
- 寫入存檔與 UI 留待 FEM-01 落地後再接。

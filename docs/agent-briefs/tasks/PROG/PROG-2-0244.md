## 完整描述
可結緣女性來源系統 §I 規定每位女性武將帶 FemaleSource，並且要能存檔。本卡建立欄位模型與存檔欄位，讓後續的來源產生者（轉蛋、傭兵、俘虜、地下城）有統一的寫入點。

## 設計選擇（我的判斷）
- 存檔欄位是選填、以武將 uid 為鍵，舊檔讀回為空表，與虎符表的做法一致。
- 讀回時不合格的條目整筆丟棄，不擋整個存檔。
- Base_Conception_Mod 預設 1.0，數值由 FEM-02 決定。

# [PROG-2-0250] FEM-02 受孕率倍率接上結緣流程

## 完整描述
QA 發現 `femaleSourceConceptionMod` 與 `BreedingSystem` 的 `motherConceptionMod` 已存在，但結緣流程沒有呼叫。本卡在 BreedingService.breed 以母體 uid 從 GameSession.femaleSources 取來源，算出倍率後傳給 BreedingSystem。

## 設計選擇（我的判斷）
- 來源查詢用可選的 `getFemaleSource(uid)` 注入，與既有 `getDictionary` 同一模式；未注入時倍率為 1（舊行為不變）。
- ServiceLoader 把 `this.session.femaleSources[uid] ?? null` 接進去，母體來源永遠來自 GameSession。
- 安胎藥（fetalMedicine）的物品來源尚未定義，本卡不傳，維持預設 false。

## 驗收
- 測試：SSR 轉蛋母體 → 結果的 conceptionRate 等於 applyConceptionMod(base, 1.2)；無來源 → 與原本相同。
- run-cli 全部通過；compute gate standard 通過。

## 完整描述

## 設計選擇（我的判斷）
- 乘數用 getter 閉包（lane, depth）→ 乘數，不在移動時重算；每次結算都讀當下格子，移動後自然生效。
- 目錄欄位 affinity 全部選填；沒填時地形 B、無家族、無性別、無羈絆，乘數 1。
- 規格的 3 張範例虎符（白馬義從、藤甲兵、常山女騎）不在目錄 4 張卡裡，所以只當測試 fixture，沒有硬塞進目錄。
- 規格的「城市」地形對應遊戲的 fortress（城池／關隘）。
- 主將 clanID 目前沒有來源欄位，傳入的 commander 可以不帶，家族共鳴暫不生效。

## 驗收
- 測試：白馬義從平原 ×1.2、山地 ×0.8；藤甲兵森林 + 同家族 + 羈絆相乘；常山女騎女性 ×1.06；TroopUnit 移動後攻防即時變化；無虎符時攻防與原本相同。
- run-cli 全綠；compute gate standard。

# [PROG-2-0252] 連環破主鏈節點表（虎牢關→長板坡）

| 欄位 | 值 |

| 負責 Agent | claude-code-haiku-5.5 |
| 關聯卡號 | PROG-2-0214（LVL-02 順序解鎖判定，已合併）、WBS LVL-01 |

## 完整描述
關卡設計系統 C-2 規定每個子關卡有六欄：Stage_ID、Chain_ID、Boss、Theme、Required_Loadout、Preview_Intel。試作主鏈「虎牢關→長板坡」的 encounters.json 已有 chainId 與 order，但缺 Theme 與 Required_Loadout，Preview_Intel 也沒有。本卡把六欄組成節點表，並加上驗證。

## 設計選擇（我的判斷）
- Boss 直接用既有的 enemyGeneralId，不重複存。
- Preview_Intel 在程式裡由 Theme 與敵將推出（Enemy_Name、Core_Mechanic），Risk_Tags 暫為空；不把它存進 JSON，避免兩份資料不同步。
- Theme 暫定：虎牢關 = 攻城（battleKind siege），長板坡 = 夜襲（fog + ambush-attack）。規格沒有指定這兩關的值，之後由企劃改。
- Required_Loadout 暫定為空陣列，代表沒有強制要求，不鎖死進場（規格 D-2 第 4 點）。
- 順序判定沿用 StageChainProgress.isStageUnlocked，不另寫一套。

## 驗收
- 主鏈節點依 order 排序，虎牢關在前、長板坡在後，Boss 分別為呂布、曹操。
- 驗證：重複 order、同鏈混入其他 chainId、缺 Theme 時回報錯誤。
- 長板坡在虎牢關通關前不解鎖，通關後解鎖。

## 完整描述
武將系統規格 Server 端欄位表定義 UID、Template_ID、Bloodline_ID、Vitality、Vitality_Max、Role、Status。generals.json 的 235 筆資料都已有對應欄位（bloodlineId、templateId、vitality、maxVitality、role、status），缺的是「欄位齊全、型別正確」的檢查與 JSON 載入測試。

## 設計選擇（我的判斷）
- 純邏輯 validator，不改 GeneralUnit 類別與存檔格式；只檢查資料。
- WBS 寫的 Class 對應規格的 Role（資料欄位 role）。
- Status 採規格的 ENUM 四值（Active、Training、Retired、Dead），比 WBS 的三值多一個 Training，以規格為準。
- 名稱欄位對照：UID → id、Template_ID → templateId、Bloodline_ID → bloodlineId、Vitality → vitality、Vitality_Max → maxVitality、Role → role、Status → status。

## 驗收
- 235 筆 generals.json 全部通過 validator。
- 缺欄位、型別錯、精力超過上限、狀態不在 ENUM 內時回報錯誤。

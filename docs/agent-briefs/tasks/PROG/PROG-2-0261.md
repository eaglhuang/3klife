## 設計選擇（我的判斷）
- 觸發器只回答「這回合要不要觸發」，不改武將資料；寫入戰法與配對表由上層負責。
- 視窗外或沒有來源時不擲骰，亂數序列不變。
- 「不同領域」以 domain 字串比對：同領域或缺值都不觸發。

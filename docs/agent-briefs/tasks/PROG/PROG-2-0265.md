## 完整描述
PROG-2-0262 只有純函式 `rollNurtureRoundEvents`，沒有流程呼叫。PM 指示：純函式要接進實際流程。
本卡把受傷與好感接進 `executeRound`。

## 設計選擇（我的判斷）
- 訓練回合（非休息）在所有結算骰之後擲一次事件，既有亂數順序不變。
- 受傷：本回合實力與 TP 撤回（精力照扣），`session.skipRounds = 1`。
- 下一回合為跳過回合：不擲結算骰、不消耗精力、不恢復精力，動作不生效，回合數照計。
- 好感：未受傷才可能發生，`session.affection` +1，log 記 `affectionGained`。
- 休息回合不擲事件。
- 舊存檔沒有 `affection` / `skipRounds` 欄位時視為 0。

## 尚未完成 / 暫定
- 好感的效果（例如影響結業或覺醒）尚未定義，本卡只做計數。
- 受傷只跳過一回合，沒有治療或受傷狀態。

## 驗收
- `tests/Nurture.test.ts`「培育事件：受傷時訓練無效並跳過下一回合」與「培育事件：訓練回合有機會好感 +1，休息回合不擲事件」。
- 既有回合測試的亂數序列補上不觸發事件的第三個值（0.99），斷言數值不變。
- run-cli ALL PASS，compute-gate standard。

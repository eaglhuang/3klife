# [PROG-2-0266] 混種戰法父母來源自動推導（BLT-09 補強）

## 完整描述
PROG-2-0264 的父母戰法來源仍需呼叫端手動傳入。本卡由父母的繼承因子自動推導來源。

## 設計選擇（我的判斷，暫定）
- 每方取身上等級最高的綠色（tactic-seed）因子；同等級取較前面的；沒有綠色因子則該方無來源。
- 領域 = 因子字典 `defaultTags[0]`；沒有字典或沒有 tag 時退回因子 id。規格只寫「不同領域」，沒定義領域欄位。
- `NurtureService.start(childId, mentors, parents?)` 新增可選的父母因子參數；沒傳則行為與舊版相同（不擲混種）。
- `NurtureServiceOptions.factorDictionary` 可選，用來查 defaultTags。

## 尚未完成 / 暫定
- 父母繼承因子目前由呼叫端傳入，尚未從名冊上的父母關聯自動取得（武將模型沒有父母連結欄位）。
- 混種戰法的名稱與效果仍未接上。

## 驗收
- `tests/Nurture.test.ts`「混種來源：取最高等級的綠色因子…」與「混種來源：推導出的來源傳入會話後…」。
- run-cli ALL PASS，compute-gate standard。

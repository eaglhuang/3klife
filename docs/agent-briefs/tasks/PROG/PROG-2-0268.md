## 完整描述
WBS v3 指出：紅因子的壽命已落地（每級 +3 歲），但「精力回復」沒有。規格（因子爆發系統 §紅色）寫紅色因子管「壽命上限、精力回復速度」。
本卡讓開場時的紅因子總級數加成休息回合的精力回復。白因子（抗性／性格／被動）範圍太大，留待後續卡。

## 設計選擇（我的判斷，暫定）
- 紅因子總級數 = 未鎖定基因中，顏色判定為紅色的 level 加總（`redGeneLevelOf`）。
- 每級 +10% 休息回復（`RED_VIGOR_RECOVER_PER_LEVEL`），只影響休息，不影響訓練精力消耗。
- 顏色判定沿用 `resolveFactorColor`；`CreateNurtureSessionInput.factorDictionary` 與 `NurtureService` 的 `factorDictionary` 選項可選，沒提供時只認舊資料的色名。

## 尚未完成 / 暫定
- 紅因子加總方式（加總 vs 取最高）與 0.1 的數值，規格未定，暫定。
- 白因子效果未落地。
- 紅因子對 `resolveMaxLifespan` 的 `redGeneLevel` 讀取仍只有測試輸入，尚未由武將基因自動帶入。

## 驗收
- `tests/Nurture.test.ts`「紅色因子：未鎖定的紅因子總級數加成休息精力回復」。
- run-cli ALL PASS，compute-gate standard。

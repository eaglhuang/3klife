## 完整描述
規格：子嗣屬性依 HIDDEN → TENDENCY → RANGE → EXACT 逐層揭露（Data Schema Child_Preview.Revelation_Level）。
目前只有開獎時的 EXACT，沒有其他層級。本卡新增純邏輯 `StatRevelation.ts`，並由 `NurtureService.revealedStats` 提供 UI 可用的視圖。

## 設計選擇（我的判斷，暫定）
- TENDENCY 切分：0~39 低、40~69 中、70 以上高。
- RANGE 以 10 為一格。
- 屬性不設上限（Max_Potential 可超過 100）；負數與 NaN 拒絕。
- 沒給層級的屬性預設 HIDDEN，不洩漏數值。

## 尚未完成 / 暫定
- 每項屬性的揭露層級來源未定（規格只寫欄位）。本卡由呼叫端傳入，尚未接到培育窺探或教官等級。
- UI 尚未接上。

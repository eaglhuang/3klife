## 完整描述
MVP 驗證規格書 §E #12：基礎內政 5 大任務產出。驗收條件：每季選一任務產出資源。
5 大任務為農耕/商業/外交/軍備/偵查（名詞定義文件 Gov_Task）。

## 設計選擇（我的判斷）
- 資源對應依經濟系統：農耕→糧草、商業→黃金、外交→名聲、軍備→城市兵源。
- 規格未定偵查的資源，暫定為黃金 30（搜刮情報的小額收入）。
- 產出量（糧草 120、黃金 100、名聲 40、兵源 80、偵查黃金 30）為暫定值。
- 同一季重複選擇被拒絕；未知任務 ID 被拒絕。產出夾到上限，超過上限時不會砍回。
- 純函式，不改輸入、不用亂數、不寫存檔；尚未接大廳內政牆。

## 驗收
- `tests/DomesticTasks.test.ts`：5 項任務各自產出、同季重複被拒、下一季可再選、未知 ID 被拒、上限夾制。
- run-cli ALL PASS，無新增失敗。

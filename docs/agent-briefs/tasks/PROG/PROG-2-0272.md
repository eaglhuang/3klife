# [PROG-2-0272] 保留並重修與成績單定型接上 NurtureService（NUR-08 接線）

## 基本資訊
| 欄位 | 值 |

| 負責 Agent | claude-code-project-thread |
| 關聯卡號 | PROG-2-0271（ReportCardBook 純邏輯） |

## 完整描述
PROG-2-0271 只有保留與定型的純邏輯。本卡把它接進 `NurtureService`：
- `keepReport`：畢業結算後保留成績單（不寫入名冊）。
- `retake`：保留並重修，重新開一場培育。
- `commitReport`：從保留的成績單選一份定型，寫入名冊，其餘成績單與會話銷毀。

## 設計選擇（我的判斷，暫定）
- 成績單存在 `NurtureState.reportBooks[childId]`，舊存檔沒有此欄位視為空。
- 重修前檢查資格（沿用 `checkStart`），忽略「已在培育中」這一項，因為重修前會先清掉已完成的會話。
- 定型後書本與會話一併清除，之後不能再重修或定型。
- 補腦湯 ×1 的扣除未接庫存，由上層處理（`RETAKE_ITEM_COST`）。

## 尚未完成 / 暫定
- 補腦湯扣除未接庫存。
- 每次重修的培育結果是否真的不同，取決於亂數，規格未定。

## 驗收
- `tests/Nurture.test.ts`「重修接線」：未完成不能重修、保留不寫入名冊、重修重新開場、定型寫入名冊、定型後其餘銷毀且不得重來。
- run-cli ALL PASS，compute-gate standard。

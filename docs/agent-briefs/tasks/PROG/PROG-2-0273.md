# [PROG-2-0273] 20 歲轉職與轉職令（FATE-06 純邏輯 + FATE-07 畫面選項）

## 完整描述
轉職與宿命系統規格 §F：滿 20 歲且持有轉職令才能追加副職，副職能力 = 主職能力 × 0.6，扣令一枚。
FATE-07 驗收：20 歲成人禮畫面可選副職並顯示 UI_JOB_CHANGE 文案。

## 設計選擇（我的判斷）
- 檢查順序：年齡 → 是否已有副職 → 副職不可與主職相同 → 轉職令數量。
- 「副職與主職不同」規格沒寫死，依 §A「追加另一職能」採用；schema 允許同職，若 PM 要允許同職請告知。
- 副職能力向下取整，避免畫面出現小數。
- 轉職令數量由呼叫端傳入，道具庫存尚未接線。
- FATE-07 只提供選項與文案（`buildJobChangeChoices`、`formatJobChangeText`），Cocos 版面未做。
- 純函式，不改輸入、不寫存檔。

## 驗收
- `tests/JobChange.test.ts`：合法轉職、能力換算、未滿 20 歲、無轉職令、已有副職、同職被拒、檢查順序、UI_JOB_CHANGE 文案、FATE-07 選項。
- run-cli ALL PASS，無新增失敗。

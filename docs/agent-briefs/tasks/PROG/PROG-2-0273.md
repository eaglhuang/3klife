# [PROG-2-0273] 結緣畫面預設挑第一組可結緣的配對（QA 觀察）

## 完整描述
QA 長流程測試發現：結緣畫面預設挑名冊第一位父方與第一位母方。若第一位的親傳次數已用完，預設配對會一直被擋，玩家必須手動切換。

## 修正
- 雙方都沒選或選的已不在清單：挑第一組可結緣（`checkEligibility.ok`）的配對。
- 只選了一方：另一方挑第一位可與它結緣者。
- 全部不合格：才退回清單第一位，由資格檢查顯示原因（維持舊行為）。

## 尚未完成 / 暫定
- 無。這是預設選擇的修正，不改資格規則。

## 驗收
- `tests/BondingSetup.test.ts`「預設配對」兩條：略過不可結緣的第一位；已選父方時挑可配的母方；全部不合格時退回第一位並顯示原因。
- run-cli ALL PASS，compute-gate standard。

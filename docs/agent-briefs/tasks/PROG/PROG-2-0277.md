# [PROG-2-0277] 教官卡五來源標記與持有清單（MENT-02）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0277 |

| 規格來源 | 教官系統（支援卡）.md §I Schema（Source ENUM） |

## 完整描述
Schema 規定教官卡有 Source 欄位，ENUM 為 Gacha / Retire / Capture / Mercenary / Offspring。本卡：
1. `MentorCard` 新增 `source?: MentorSource`（舊存檔沒有此欄位）。
2. `MentorSources.ts`：`tagMentorSource` 貼上來源（已有來源則保留）；`addMentorToHoldings` 依 uid 加入持有清單，重複 uid 不新增。
3. 接線：退役轉化（`LegacyService.retireGeneral`）改為貼上 `Retire` 標記。

## 設計選擇（我的判斷，暫定）
- 同 uid 只保留第一次的來源，避免後來的來源覆蓋原始來源。
- 其餘四種來源目前沒有獲取入口，本卡只提供標記能力，不假裝已接線。

## 驗收
- 五種來源與 Schema ENUM 一致；未知來源拋錯。
- 退役後教官卡標記為 Retire（Legacy 測試）。
- 持有清單同 uid 不重複，保留舊來源。

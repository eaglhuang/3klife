# [PROG-2-0280] 戰法靈感事件觸發引擎（MENT-04）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0280 |
| 負責 Agent | claude-code-project-thread |
| WBS | MENT-04（P0，純邏輯） |
| 規格來源 | 教官系統（支援卡）.md §F-3 靈感事件觸發機率、§F-5 靈感事件表 |

## 完整描述
依規格實作靈感事件的觸發規則：
- 機率：`Base_Rate × (1 + Friendship_Bonus) × (1 + 子嗣_LUK / 200)`，封頂 1。
- 閘門：回合在 `Trigger_Window` 內（含端點）、教官星等達 `Min_Star`、子嗣具備 `Bloodline_Required`（家傳戰法）。
- 每回合對合格且未確認的事件擲一次；不合格的事件不消耗亂數。

## 設計選擇（我的判斷，暫定）
- `Friendship_Bonus` 由呼叫端傳入，換算方式待 MENT-01 schema 定案。
- 機率上限 1；LUK 為負或非有限數視為 0。
- 同一場培育只觸發一次（已確認的不再擲）。
- 本卡只提供引擎，尚未接進培育流程；接線需等教官卡的靈感事件資料（MENT-01）。

## 驗收
- 公式數值、封頂與 LUK 夾取。
- 閘門理由：區間外、星等不足、血統不符；區間端點含在內。
- 擲骰只對合格事件消耗亂數；已確認不重擲；非法 Base_Rate 拋錯。

# [PROG-2-0287] 傭兵薪水與欠薪凍結（傭兵規格 §3.1、§4）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0287 |
| 負責 Agent | claude-code-haiku-5.5 |

## 完整描述
每日付黃金與美酒；付不起即凍結。凍結不可出戰、不可教官。倒數內補足欠款即恢復；倒數歸零仍未補即離隊。

## 設計選擇（我的判斷）
- 規格的「24 小時」對應 1 個遊戲日（PM 裁定）。
- 凍結後倒數 1 日；每個凍結日欠款加一份日成本，補繳時每欠一日付一份。
- 規格沒寫倒數歸零的結果，我判為離隊（Departed）。
- 薪水金額由呼叫端傳入，規格的「隨武將強度掛鉤」公式未定，不自行發明。
- 離隊後的告別信與 30 天冷卻由 MERC-05（#113）接線，本卡不 import 該分支。
- 純函式，不改輸入、不寫存檔。

- `tests/MercenaryUpkeep.test.ts`：正常扣款、凍結、凍結限制、離隊、離隊後無事件、補繳回 Active、補繳不足、非凍結補繳、輸入不變、非法成本。
- run-cli ALL PASS，無新增失敗。

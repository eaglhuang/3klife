# [PROG-2-0293] run-cli 自動掃描 tests/*.test.ts

## 問題
`tests/run-cli.ts` 以手寫 import 與 register 清單登記每個測試，多條 PR 同時追加同一區塊，導致文字衝突，#126~#131 因此在夜間無法合併。

## 修正
啟動時掃描 `tests/*.test.ts` 與 `tests/ucuf/*.test.ts`，把匯出的 `create*Suite()` 一律註冊。原本就未登記的檔案列入 SKIP，測試數不變（ALL PASS 1052）。之後新增測試檔不必再改 run-cli.ts。

## 驗收
headless 測試數與修改前相同；compute-gate standard 通過。

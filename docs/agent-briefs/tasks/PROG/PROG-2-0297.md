# [PROG-2-0297] GameSession 持有女性武將來源（FEM-01 會話接線）

## 問題
#168 讓存檔快照有 `femaleSources` 欄位，但 `GameSession` 沒有持有也沒傳入快照、讀檔也沒還原，所以經遊戲存檔來源紀錄永遠是空的（與傭兵包在 #148 前的缺口相同）。

## 修正
`GameSession` 新增 `femaleSources` getter（回傳副本）與 `setFemaleSource`（校正後寫入，不合法回傳 false）；快照帶入、讀檔還原、開新局清空。

## 測試
`tests/CrossSystemIntegration.test.ts`：來源登記→存檔→重開讀回一致、不合法被拒、開新局清空；另補傭兵試用走完後結義的整合測試。

# [PROG-2-0298] 傭兵結義：好感為門檻，費用從結義點數餘額扣

## 問題
PM 裁定（2026-10-14）：傭兵好感滿 60 只是結義門檻，費用從 GCH-06 的結義點數餘額扣，好感不扣。但 master 的 `bondMercenaryToRoster` 仍把好感當點數扣，好感上限 60 低於 R 的 100 點，結義永遠不成功。

## 修正
`bondMercenaryToRoster` 新增選填參數 `bondPoints`：有傳入時要求好感滿 60（否則 `affection-not-full`），費用從餘額扣、好感不變，結果帶 `bondPointsLeft`；不傳時沿用舊行為（既有純邏輯測試不變）。`GameSession.bondMercenaryToRoster` 傳入會話的 `bondPoints` 並寫回餘額。

## 測試
`tests/GameSessionMercenary.test.ts` 新增 3 條：滿 60 且點數足夠成功；點數不足被擋且全不變；好感 59 即使點數很多也被擋。

## 設計選擇（我的判斷）
- 能否選擇沿用 runDomesticTask 的規則：同一季只能選一項，已選一項後全部關閉。
- 列文字採「資源名 +產出量」，產出量取自 DOMESTIC_TASK_OUTPUT（暫定值）。
- 任務與資源名稱為暫定繁中字串，字串表定案後改 key。
- 不改 DomesticTasks 的產出表，不改存檔。

## 未做與原因
- **季結產出接線未做**：協調者指示「季結時的內政產出」，但 runDomesticTask 與規格都是「選任務當下入帳」。若改成季結才給，會和既有純函式衝突，所以這裡不擅自改。
- **資源欄位**：會話內目前有 food（經 MilitaryReserve）與 cityTroops，但沒有獨立的 gold、fame。接線前需先決定這兩項放在哪個狀態。

# [PROG-2-0308] 結義轉武將名冊接線（MERC-04 後段）

## 範圍
- 傭兵狀態加入選填欄位 generalId（對應 generals.json 武將）與 affection（好感，0~60）。舊存檔沒有這兩欄時照常讀取。
- 純邏輯 bondMercenaryToRoster：好感即結義點數（PM 暫定），扣點後把武將寫入名冊，傭兵轉 Bonded 並開始 30 天冷卻。
- GameSession.bondMercenaryToRoster 包住上述流程，自動存檔。
- 數值對應（PM 暫定）：str=STR、int=INT、luk=LUK、lea=round((POL+CHR)/2)。

## 暫定決策（待使用者確認，寫入待辦檔）
1. 結義點數 = 該傭兵目前好感值。
2. 傭兵存檔包加選填 generalId；加入名冊時取對應的 GeneralConfig 模板。
3. 數值對應如上。
4. 稀有度由呼叫端傳入（規格未定稀有度來源）。
5. 傭兵目前數值由呼叫端傳入（傭兵尚未儲存數值快照）。

# [PROG-2-0312] 虎符單一來源：收斂到 GameSession (死亡與傳承)

## 開單原因
QA 發現 LegacyService 季結時也會產虎符並存在自己的 store（tiger_tallies），與 GameSession 的虎符結算並存，兩邊的卡與分數不同步。依 PM 指示統一成單一來源，GameSession 為準。

## 完整描述
- LegacyService.settleSeason 不再呼叫 produceDeathTally，不寫 tiger_tallies；移除 tigerTallies 結算欄位、tallyScoreProvider 與 getTigerTallies。
- 英靈卡（spirit_cards）、教官卡（mentor_cards）與歸檔快照維持原樣。
- 虎符只由 GameSession._settleDeaths（TallyDeathSettlement）產生，存在存檔的 tallyCards。
- 測試：LegacyTally 改為「不寫虎符庫」與「GameSession 唯一產卡」的回歸測試；SpiritRelic 系列移除虎符斷言。
- 瀏覽器流程檢查（tools_node/lib/web-three-generation-flow.js）改讀存檔的 tallyCards。

## 如何驗證
1. run-cli ALL PASS（1105）；compute-gate standard。
2. 回歸測試：tests/LegacyTally.test.ts 的「不寫虎符庫」與「GameSession 唯一產卡」。

# [PROG-2-0313] 英靈死亡快照：英勇事蹟、最終屬性與技能（SPI-03）

## 開單原因
WBS SPI-03（英靈世家系統，data，純邏輯）。GeneralArchiver 只存魂卡基本欄位，缺英勇事蹟、最終屬性、技能快照，英靈陳列室與詳情頁無法回看「他當年強在哪裡」。

## 完整描述
- 新增純邏輯模組 SpiritArchiveSnapshot：依死亡時的武將資料建立 Spirit_Archive_Snapshot 欄位（Spirit_ID、Death_Season、Heroic_Deeds_Summary、Final_Stats_Snapshot、Final_Skills_Snapshot、Final_Equipment_Snapshot、Battle_Record_Ref、Legacy_Quote、Display_Weight）。
- GeneralArchiver.archive 把快照掛在 SpiritCard.archiveSnapshot 上（與魂卡同一筆存檔，不新增 store）。
- 暫定預設（規格未定，PM 依可逆原則選定）：
  - Spirit_ID 沿用魂卡 uid（即武將 id），避免另開 id 體系。
  - Battle_Record_Ref 指向 L5 歸檔位置 `generals_archive_l5:<uid>`。
  - Heroic_Deeds_Summary 由戰績（勝負、擊殺、功勳、里程碑）組成文字列。
  - Display_Weight = 最終五圍合計 + 功勳，僅作預設排序權重。
  - Legacy_Quote 取武將 introLine，缺則空字串。
  - Final_Equipment_Snapshot：武將模型目前沒有裝備欄位，缺則空陣列。

## 如何驗證
1. tests/SpiritArchiveSnapshot.test.ts：欄位齊全、缺資料時的預設、權重與排序鍵、戰績摘要。
2. GeneralArchiver 歸檔後魂卡帶快照；既有 SpiritRelic 測試仍通過。
3. run-cli ALL PASS；compute-gate standard。

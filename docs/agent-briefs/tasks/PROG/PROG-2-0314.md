# [PROG-2-0314] 轉生：重複抽到同名武將轉數 +1（GCH-05）

## 開單原因
轉蛋重複抽到同名武將時只提示「已持有」、不加入，等於浪費抽數，也是長期遊玩新人才變少的原因（QA 發現）。規格要求重複抽到會轉生（+1 轉）。

## 完整描述
- Rebirth 純邏輯：1~5 轉的屬性上限與培育機會（轉蛋系統.md §F）；重複抽 +1；滿 5 轉再抽標記溢出。
- GameSession.addGenerals 新增選項 rebirthOnDuplicate：轉蛋啟用，同一批多次抽到同名會逐筆累加。
- 俘虜招募等其他來源不啟用，維持原行為。
- 武將新增 rebirthCount 欄位，缺欄位視為 1 轉。

## 如何驗證
1. tests/Rebirth.test.ts：轉生表、缺欄位預設、1→2 轉、滿轉溢出、GameSession 寫回名冊、同批多次累加、未啟用不改、新武將照常加入。
2. run-cli ALL PASS；compute-gate standard。

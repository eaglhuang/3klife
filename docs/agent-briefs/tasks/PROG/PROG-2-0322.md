# [PROG-2-0322] 雙牆任務板可見性、置頂與重算時機（HALL-03）

## 範圍
- getVisibleHallTasks：官階、沙盤階段、軍事情報度過濾。
- arrangeHallTasks：已接取任務置頂。
- getDayPeriod / shouldRecomputeBoard：早中晚切點與重算時機。

## 暫定決策
1. 難度對照：EASY 0、NORMAL 1、ELITE 2、ADVANCED 3、HELL 4（最低官階）。
2. 早中晚切點：06~11 早、12~17 中、其餘晚。

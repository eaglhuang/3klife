# [PROG-2-0327] 試用券招募接上 GameSession（MERC-02）

## 範圍
- PlayerInventory：新增試用券道具 ITEM_TRIAL_TICKET（暫定，名稱「試用券」）。
- GameSession.hireTrialMercenary(uid, template)：以背包試用券數量呼叫 useTrialTicket，成功時消耗 1 張、加入傭兵包、建立薪水紀錄，並自動存檔。
- 同 uid 已存在則拒絕，失敗時不改任何狀態。

## 暫定決策
1. 試用券道具 ID 為 ITEM_TRIAL_TICKET，初始數量 0（規格未定）。
2. uid 由呼叫端傳入（避免純邏輯內產生亂數）。
3. 數值來源沿用 statsOfTemplate（POL/CHR 暫以 lea 代入）。

## 不在範圍
- 招募的 View 與轉蛋入口。

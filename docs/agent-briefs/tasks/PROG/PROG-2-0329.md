# [PROG-2-0329] 退役流程接上教官分流（FATE-08）

## 範圍
- LegacyService.retireGeneral 退役時呼叫 routeRetirement，把分流結果寫進 MentorCard 的 mentorRoute 欄位（武→戰技教官、文→智識教官、雙職能→全能教官，reason 一併保留）。
- 測試：武職、文職、雙職能、未定職能（UNKNOWN_CLASS）四種情況。

## 暫定決策
1. 分流結果存在教官卡上，不改退役的卡片 uid 與來源標記。
2. 職能只讀 primaryClass / subClass，不從屬性猜；未定職能時 reason 為 UNKNOWN_CLASS，呼叫端需檢查。

## 不在範圍
- 產物（虎符／竹簡）發放：虎符唯一來源是死亡結算，竹簡道具尚未定義，待 PM 裁定。

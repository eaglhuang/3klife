# [PROG-2-0332] 宿命轉蛋：無限重置十連抽與初始名將鎖定（OPEN-05）

## 範圍
- DestinyGacha.ts（純 TS）：十連抽、免費無限重置、選定與確認鎖定一位初始名將。
- 設定沿用 GachaConfig（resetEnabled、firstPickOnly、confirmRequired、pickCount、candidateIds），由 optionsFromGachaConfig 讀取。
- 測試：十連不重複、重置回初始、重置次數不限、選定需先抽、確認鎖定後拒絕再抽與重置、設定停用重置被拒。

## 暫定決策
1. 一次十連內 id 不重複（firstPickOnly 的解讀，暫定）；重置後整池恢復。
2. 只能從未抽狀態開始十連，抽完需重置或確認；確認後鎖定，不可再抽與重置。
3. 隨機源由呼叫端注入，純邏輯不呼叫亂數。

## 不在範圍
- 初始六名將的資料表（OPEN-02）、結果揭示 UI、存檔。

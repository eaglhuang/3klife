# [PROG-2-0336] 貨幣分流與扣款規則（GCH-04）

## 開單原因
WBS v4 6b 節 P1 待接線項。現行錢包只有 gems/gold/tickets，與規格的靈玉／銅錢符／求籤令不對應，也沒有卡池可用性規則。

## 完整描述
- 純邏輯：靈玉（付費）兩池可用；銅錢符（免費）僅常設池可用、限定池不支援；求籤令為定向道具，不作為池幣。
- 單抽 150、十連 1500（規格 §單抗／10 連 UI 流程）。
- 求籤令定向保底：指定一位 SSR，最多 100 抽內必出（計數不足 100 不強制）。
- 餘額不足拒絕扣款。

## 如何驗證
1. tests/GachaCurrency.test.ts 覆蓋池可用性、費用、不足拒絕、定向保底。
2. run-cli ALL PASS；compute-gate standard。

## 預設選擇（PM 暫定，待裁定）
- 「1 抗免費」（10 連）規格文字不清，本卡不實作折扣，十連 = 10 × 150 = 1500。
- 限定池可用靈玉（規格只寫銅錢符不支援限定池，未寫靈玉）。
- 支援卡池視為常設池，可用銅錢符。
- 求籤令定向保底的計數起點：取得（啟用）後的抽數；命中目標即重置。
- 本卡不接線到現行錢包（gems/gold/tickets），接線另開卡。

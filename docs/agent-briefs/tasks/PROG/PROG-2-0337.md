# [PROG-2-0337] 轉蛋保底計數進存檔（GCH-02 後續）

## 開單原因
PM 裁定（2026-10-14）：GCH-02 的保底計數從 localStorage 移進 PlayerSave 選填欄位；舊檔從 0 開始；localStorage 只在讀取時做一次性遷移。

## 完整描述
- PlayerSave 新增選填欄位 gachaPity（poolId → {pullCount}），舊檔讀回為空。
- GameSession 持有保底表，存檔與讀檔一併保存；覆寫保底表不自動存檔。
- LocalGachaService 改由注入的 GachaPityStore 讀寫；沒有注入時只存記憶體（載入畫面預覽）。
- 大廳接線：寫入保底後順手存檔。舊 localStorage 只在存檔沒有保底資料時遷移一次，遷移後清除舊 key。

## 如何驗證
1. tests/GachaPityStorage.test.ts：存讀往返、舊檔缺欄位、壞資料丟棄、遷移判定。
2. run-cli ALL PASS；compute-gate standard。

## 預設選擇
- 舊 localStorage 只在存檔保底為空時遷移；存檔已有資料則忽略舊值。
- 每抽一次寫保底即呼叫存檔，失敗不影響抽卡（沿用 GameSession 既有存檔路徑）。

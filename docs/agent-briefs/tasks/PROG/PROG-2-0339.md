# [PROG-2-0339] 宿命轉蛋接上開場流程（OPEN-05 接 OPEN-01）

## 範圍
- DestinyOpening.ts（純 TS）：destinyLockedEvent(state) 把已鎖定的轉蛋狀態轉成開場事件；destinyOpeningPhase(id, enterType) 產生開場幕，鎖定事件離開本幕。
- 測試：用 OpeningFlowController 跑完整段落（開場幕 → 宿命轉蛋幕 → 鎖定後結束），並確認未鎖定時不離開、重置不產生離開事件。

## 暫定決策
1. 宿命轉蛋幕的進入事件類型由呼叫端指定（正式開場順序尚未定義）。
2. 離開事件固定為 destiny-locked，只在確認鎖定後產生。

## 不在範圍
- 開場的正式幕順序與劇本、UI、存檔。

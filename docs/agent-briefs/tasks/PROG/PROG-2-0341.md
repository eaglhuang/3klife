# [PROG-2-0341] 初始六名將資料表（OPEN-02）

## 範圍
- assets/resources/data/initial-heroes.json：六位初始名將（張飛、魏延、夏侯惇、張郃、孫策、甘寧）的 id、名字、稱號、出生地、核心因子標籤。資料來源為「史實校正與因子標籤清單」。
- InitialHeroTable.ts（純 TS）：validateInitialHeroes(raw, knownIds) 驗證六人齊全、id 存在於 generals.json、稱號與出生地非空、主因子在因子標籤內、id 不重複。
- 測試：正確資料通過、缺人、id 不在名冊、主因子不在標籤、重複 id。

## 暫定決策
1. 稱號取清單第一個（例：張飛「萬人敵」）。
2. 核心因子標籤清單第一個為主因子 coreFactorTag（暫定）。
3. generals.json 目前的稱號（如「【燕人】」）與清單不同，以史實校正清單為準，待 PM 確認。

## 不在範圍
- introLine、portraitKey、battleVoiceKey 與稀有度／屬性：規格未給值，需內容決定，另案。
- 祖先矩陣與 UI。

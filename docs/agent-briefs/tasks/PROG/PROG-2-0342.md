# [PROG-2-0342] 天氣排程純邏輯（APT-06）

## 開單原因
PM 裁定（2026-10-14）：先做 APT-06 天氣排程，再做 APT-12（環境偵察）。目前戰場只有單一天氣值，沒有 Weather_Schedule。

## 完整描述
- WeatherSchedule 純邏輯：排程條目（Turn_Start、Turn_End 含頭尾、天氣）的驗證；依回合查天氣；查未來 N 回合預報；判斷回合切換。
- 排程沒有覆蓋的回合用預設天氣（晴）。
- 天氣型別沿用現有 Weather enum。規格天氣名（SUNNY/RAINY/FOG/WINDY/NIGHT/THUNDER）與程式 enum 不同，對應方式待 PM 裁定，本卡不改 enum。

# [PROG-2-0401] 天氣 enum 改為規格六種（APT-06 前置）

## 開單原因
PM 裁定（2026-10-14，規格優先）：Weather enum 改用規格名稱 SUNNY / RAINY / FOG / WINDY / NIGHT / THUNDER；snow、sandstorm 沒有在關卡資料用，移除；舊字串（clear、fog…）要能讀進來轉換。

## 完整描述
- Weather enum：Clear=SUNNY、Rain=RAINY、Fog=FOG、Windy=WINDY、Night=NIGHT、Thunder=THUNDER；移除 Snow、Sandstorm。
- normalizeWeather：接受規格名與舊字串（clear、rain、fog、night；舊的 snow→RAINY、sandstorm→WINDY 沿用既有暫定對應）；認不得回傳 null。
- 天氣適性查表改用規格名 key；SortiePrediction 與關卡資料（encounters.json）改用新名稱。

## 如何驗證
1. tests/BattleAptitude.test.ts、tests/BattleModifiers.test.ts 依新名稱更新；新增 normalizeWeather 測試。
2. run-cli ALL PASS；compute-gate standard。

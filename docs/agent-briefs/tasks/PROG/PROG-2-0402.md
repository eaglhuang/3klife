# [PROG-2-0402] 戰場環境偵察純邏輯（APT-12）

## 開單原因
WBS v5 APT-12：出戰前顯示地形分佈與天氣預報。規格「戰場適性系統.md」§J 名詞定義：環境偵察 = 出戰前查看戰場地圖地形分佈與天氣預報。PM 裁定順序：0401 之後做 APT-12。

## 完整描述
- 新增純邏輯 `core/systems/BattlefieldRecon.ts`（不依賴 cc）：輸入地形格與天氣排程，輸出出戰前可直接顯示的資料。
- 地形：沒有地形資料時用平原整片（與 BattleState.reset 的預設一致）；輸出每種地形的格數與逐格列表。
- 天氣預報：沿用 WeatherSchedule.weatherForecast，從第 1 回合起取 N 回合；另列出天氣會改變的回合。
- 預報回合數 N 暫定 5（規格未定，PM 可改）。
- 天氣使用規格代碼（SUNNY/RAINY/FOG/WINDY/NIGHT/THUNDER），與 Weather enum 一致。
- UI 接線（LobbyMissionDetailDialogComposite 顯示）本卡不做：需要在對話框內新增節點，需先確認版面位置（見完成紀錄）。

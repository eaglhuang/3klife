# [PROG-2-0408] HUD 戰法按鈕依天氣與資源顯示可用狀態

## 開單原因
PM 裁定（2026-10-14）：戰法按鈕在不能施放時要變灰並說明原因。另開 UI 卡，Presenter 輸出每個戰法的可用狀態與原因，View 只負責綁定。接在 0407 之後做。

## 完整描述
- 新增純邏輯 `ui/core/TacticAvailabilityPresenter.ts`（不依賴 cc）：輸入戰法（id、標籤、tags）與戰場狀態（天氣、計謀點是否可用、武將 SP 是否足夠），輸出 `{id, label, enabled, reason}`。
- 判定順序與 `BattleSkillTargetingFlow.beginPlayerSkillFlow` 一致：計謀點 → SP → 天氣強約束。
- 原因文字：「計謀點不足」「SP 不足」「天氣禁用」。
- View 綁定：`BattleUIBridge.refreshBattleViews` 呼叫 Presenter，把 enabled 與 reason 傳給 `BattleScenePanel.setTacticSummary` → `ActionCommandComposite`。有原因時，原本的計謀點行改顯示原因。
- 不改施放流程本身；點擊後的防呆仍由 BattleSkillTargetingFlow 負責。

## 如何驗證
1. tests/TacticAvailabilityPresenter.test.ts：晴天全部可用；雨天火計禁用且原因為天氣；計謀點不足與 SP 不足的原因與優先順序。
2. run-cli ALL PASS；tsc 觸及檔案無新錯。

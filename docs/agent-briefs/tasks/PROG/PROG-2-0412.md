# [PROG-2-0412] 粉色因子→地形適性接線（APT-09）

## 開單原因
WBS v6 APT-09：`pinkFactorAptitude` 有測試但戰場與結緣流程未呼叫，且規格有兩套對照表。PM 裁決（2026-10-14）選 A，沿用 `pinkFactorAptitude`（★0~3→D/C/B/A、≥5 祖先升一級）。

## 完整描述
- 粉色地形因子（gene_naval→WATER、gene_mountain→MOUNTAIN、gene_forest→FOREST）存在時，該地形的適性由因子等級決定；其他地形保留原值。
- 戰場判定經 `battleAptitudeProfileOf(general)` 取得 profile，`BattleCombatResolver.getUnitAptitude` 是唯一入口，移動與戰鬥都走這裡。
- 因子等級直接當 ★ 使用（暫定，規格未寫 level 與 ★ 的換算）。

## 兩套對照表的差異（PM 裁決 A 後保留紀錄）
- 採用：`pinkFactorAptitude`，★0→D、★1→C、★2→B、★3→A，≥5 祖先再升一級（最高 S）。與規格「粉色因子→適性映射」段落一致。
- 未採用：規格「適性等級表」的需求欄，寫 ★3→S、★2→A、★1→B。兩者差一級，待企劃確認。

## 如何驗證
1. tests/PinkTerrainAptitude.test.ts：覆寫對應地形、非粉色因子忽略、14 人升級與 S 封頂、不改來源、GeneralUnit 經戰場 profile 讀到因子。
2. run-cli ALL PASS；tsc 觸及檔案無新錯。

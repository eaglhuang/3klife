# [PROG-2-0413] 稀有度雙軸重算併入資料管線（GDP-07）

## 開單原因
WBS v6 GDP-07：管線以 maxStat / avg5 重算 rarityTier，與資料一致，legendary 低於 20%。檢查時發現 validate-generals-data.js 的門檻載入有 bug（`const` 重新賦值），門檻從未生效，稀有度也完全沒有被檢查。

## 完整描述
- 修正門檻載入：`const` 改 `let`。
- 新增雙軸重算，規則與 `RarityResolver.resolveRarityTier` 相同（不讀資料上的 rarityTier，category 覆寫優先，maxStat 與 avg5 取較高 tier）。
- 不一致與 legendary 佔比 ≥20% 只發 warning，不改資料。
- 現況：legendary 13/235（5.5%）；重算只有 xiahou-shi 1 筆不一致。

## 如何驗證
1. `node tools_node/validate-generals-data.js`：0 error，1 warning（xiahou-shi）。
2. tests/GeneralRarityPipeline.test.ts：不一致的 id 必須等於已知清單，legendary 佔比 <20%，測試後還原全域門檻。
3. run-cli ALL PASS。

## 交付物

## 完成紀錄

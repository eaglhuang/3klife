# [PROG-2-0416] Lore 生成腳本改為只補缺漏並對齊 runtime 格式（GDP-02）

## 開單原因
WBS v6 GDP-02：`ingest-generals-ai.js` 生成 lore 欄位，單筆失敗只 WARN 不中斷。盤點發現：
- `generals-lore.json` 已有 235 筆真實 lore，欄位完整；`generals-base.json` 無任何故事欄位，導致腳本對全部 235 筆生成模板文字。
- 腳本產生的 `storyStripCells` 用數字 slot 1–6，runtime 的 `GeneralDetailStorySlot` 為 origin/faction/role/awakening/bloodline/future，格式不一致。
- 真正缺 lore 的是 base 中 12 位武將（cao-ang、cao-pi、cao-xiu、lu-kang、lu-yin、cheng-bing、huo-yi、jiang-wan、gou-fu、ma-liang、pan-jun、lv-kai）。

## 完整描述
- 缺漏判斷改以 `generals-lore.json` 的 id 為準；已有 lore 者不生成（`--force` 才重生）。
- 生成內容改為 runtime slot 名稱；每筆生成後驗證欄位與 6 格 slot，失敗只 WARN 並跳過。
- 生成函式抽成純函式，隨機來源可注入，測試可固定結果。
- 不改 merge 規則（既有優先由 GDP-03 保證）。
- 不處理 id 漂移（cao-cao-pi / cao-pi、lu-dai / lu-yin 等），另記待辦。

## 如何驗證
1. `tests/IngestGeneralsAi.test.ts`：已有 lore 者不生成；缺漏者生成 6 格且 slot 為名稱；單筆壞資料 WARN 跳過不中斷；固定隨機來源結果可重現。
2. run-cli ALL PASS；tsc 觸及檔案無新錯；compute-gate standard 通過。

## 未做
- 呼叫真實 AI API（腳本目前無 API 區塊，維持模板）。
- 修正 base / lore 的 id 漂移（另立卡或待辦）。

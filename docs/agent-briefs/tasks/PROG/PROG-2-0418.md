# [PROG-2-0418] 建置保留既有 runtime 欄位

## 開單原因
PROG-2-0417 盤點：`build-generals-runtime.js` 的 `buildRuntimeRecord` 只回傳固定白名單欄位，legacy 中其他欄位（originRegion、element、introLine、portraitKey、battleVoiceKey 等）在重建後全部消失，連 lore 沒有變動的武將也受影響（例如 cao-cao 有 7 個欄位丟失）。

## 完整描述
- 白名單欄位仍以 master 為準。
- 白名單外的 legacy 欄位保留；白名單欄位在 master 為 undefined 時從 legacy 補值。
- `build-generals-runtime.js` 加 `require.main` 守衛並匯出 `buildRuntimeRecord`，供測試直接呼叫。

## 如何驗證
1. `tests/BuildGeneralsRuntime.test.ts`：白名單外欄位保留；白名單以 master 為準；undefined 從 legacy 補；回歸：以提交版 generals.json 為 legacy，重建後無欄位丟失。
2. run-cli ALL PASS（1785 passed）。

## 未做（第二階段）
- 重產 runtime `generals.json` / `generals-index.json`。需等 PR #294（lore 別名解析）合併，否則 lore 別名的武將會遺失 lore。

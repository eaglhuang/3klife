# [PROG-2-0419] ID 命名契約驗證器（TERM-01）

## 開單原因
WBS v6 TERM-01：validate 工具要能對 generals / gene / bloodline 的 ID 格式違規回報錯誤。現有 validate-generals-data 只驗必填與範圍。

## 完整描述
- 新增 `tools_node/validate-id-contract.js`，規則來源為名詞定義文件「命名統一規則」：Template_ID `{Name}_V{n}`、Bloodline_ID `BL_{Name}`、Gene_ID `{COLOR}_{ATTR}_{NN}`。
- 只檢查存在的欄位；預設只報告，`--strict` 才以 exit 1 失敗。
- 不改任何資料。

## 如何驗證
1. `tests/IdContractValidator.test.ts`：三組規則的通過與違規案例，以及 checkIdContract 回報格式。測試不斷言現有資料的違規數。
2. 實跑 `node tools_node/validate-id-contract.js`：235 筆武將，templateId 235 筆違規、genes[].id 20 筆違規、bloodlineId 0 筆違規。

## 未做
- 嚴格模式（需 PM 裁定命名以規格或資料為準）。
- SIGIL_ / SPIRIT_TALLY_ / V_PID_ 的檢查：資料中尚無對應欄位。

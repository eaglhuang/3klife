# [PROG-2-0420] 退役回顧面板掛載（LobbyScene）與戰績戰報句子多語化（REC-08 接線）

## 開單原因
協調者 PM 裁示（2026-10-15 00:19Z）：退役回顧畫面的程式入口照寫（LobbyScene 掛載，退役成功後開啟），戰績與戰報句子一併移進四語系表，另開小 PR。Codex 只做實機與座標微調。

## 完整描述
- 任務卡編號：PROG-2-0400–0449 段無空號，取 PROG-2-0420（該號無既有檔案）。
- `RetireReviewController.ts`：文案查詢改為 `(key, ...args)`；生涯戰績、劇本句、戰損報告、季度戰報句子走 `ui.retire_review.*` 語系 key（含 `{0}` 等占位符）；zh-TW 預設與原 RetireReviewCopy 組句一致。
- 新增 `RETIRE_REVIEW_OPEN_EVENT` 與 payload（退役者快照）。
- `GeneralListComposite.ts`：退役成功（outcome `retired`）時以退役前快照發出開啟事件。
- `LobbyScene.ts`：`_mountRetireReview()` 比照占卜畫面掛載 `retire-review-screen`，綁 `btnCloseRetire`；訂閱開啟事件後套用文案。
- 四語系 `ui.retire_review.*` 新增 career / script / report / quarterly / bond_ok / bond_no，以文字插入方式（不重排檔案）。

## 解讀選擇
- 退役回顧在退役成功後才開，不在名冊頁常駐入口（PM 未另指定入口，取最小接線）。
- 退役者快照取自退役前的名冊物件，因退役後武將會轉為教官卡、名冊中已無此武將。

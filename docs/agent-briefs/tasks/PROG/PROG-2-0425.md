# [PROG-2-0425] 戰場精力軟懲罰純邏輯（LIFE-10）

## 開單原因
WBS v7 P0 最優先：LIFE-10 規定戰場依精力區間限制戰法，普攻與移動不受限。前置 VIT-01 已驗收，可開工。

## 完整描述
- 新增 `assets/scripts/core/systems/VitalityBattleGate.ts`（不依賴 cc）：
  - `vitalityBandOf(current, max)`：>50% 高段、10%~50%（含兩端）中段、<10% 耗盡段；上限無效視為耗盡。
  - `canPerformAction(band, action)`：基本行為永遠允許；高段全允許；中段只禁終極戰法；耗盡段禁所有戰法。
  - `retreatRiskBonus(band)`：只有耗盡段提高。
- 判定依據：武將壽命系統 §戰場中的精力軟懲罰，與精力系統優化建議一致。
- 規格只寫「撤退風險提高」，沒有數字。`EXHAUSTED_RETREAT_RISK_BONUS = 0.1` 為暫定值，待 PM 裁定。

## 解讀選擇（PM 未裁定時採用的預設）
- 中段是否允許非終極的主動戰法：依精力系統優化建議，只禁終極戰法，所以中段允許一般主動戰法。
- 邊界：恰好 50% 屬中段，恰好 10% 屬中段。

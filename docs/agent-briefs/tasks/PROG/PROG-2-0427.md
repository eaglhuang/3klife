# [PROG-2-0427] 出陣精力帶入回歸測試（LIFE-10）

## 開單原因
協調者（2026-10-14 14:46Z）指出：出陣時應把武將實際精力帶進 `GeneralUnit.vitality`，否則閘門永遠是滿值。

## 完整描述
- 先檢查既有路徑：`BattleSceneLoader.createGeneral` 對我軍主將呼叫 `session.getBattleConfig`，再經 `buildBattleConfig`（`...g` 展開）建立 `GeneralUnit`。名冊上的 `vitality` / `maxVitality` 已原樣帶入。
- 因此本卡不改程式，只補回歸測試，鎖住這條路徑。
- 測試 `tests/BattleDeployVitality.test.ts` 覆蓋：精力 30/100 出陣後仍為 30/100；區間判定為中段；缺精力資料時預設滿值。

## 注意
- 戰場目前不扣精力（奧義 vitalityCostPct、戰鬥 -30 尚未接線）。所以名冊精力只有在存檔中已偏低時才會觸發閘門。
- 閘門觸發的真實條件仍依賴精力扣減的接線，那是另一張卡。

## 如何驗證
1. tests/BattleDeployVitality.test.ts 3 條全綠。
2. run-cli ALL PASS。

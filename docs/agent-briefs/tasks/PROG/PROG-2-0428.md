# [PROG-2-0428] 精力閘門對直接派發生效修正（LIFE-10）

## 開單原因
審查 PROG-2-0426 接線時發現：直接派發（`dispatchDirectBattleSkill`，奧義與直接施放的戰法都走這裡）把 `ownerUid` 設為陣營字串（`'player'` / `'enemy'`），不是單位 uid。閘門用 `state.units.get(ownerUid)` 找施放者，找不到就放行，所以實戰中奧義不會被精力閘門擋下。

## 完整描述
- `checkVitalityGate`：陣營解析改為「有施放者單位用單位陣營；否則用 ownerUid 當陣營」。陣營只接受 `Faction.Player` / `Faction.Enemy`。
- 新增測試：`ownerUid = Faction.Player`、戰場上沒有同名單位、精力 5/100 → 奧義被擋下。修正前此測試紅燈（閘門被跳過、執行器崩潰），修正後綠燈。

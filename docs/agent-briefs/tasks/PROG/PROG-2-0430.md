- `assets/resources/i18n/zh-TW.json`：新增 13 個 key，文字照規格 §G、§H 與階段名稱。

  - UI：`life.death_notify` / `life.age_display` / `life.lifespan_bar`

  - 死亡劇本參數為「武將名、享年」，順序與 `{0}`、`{1}` 一致。

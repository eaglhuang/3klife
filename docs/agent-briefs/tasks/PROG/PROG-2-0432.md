# [PROG-2-0432] 演武聖境精華快照與付費復活（LIFE-11）

## 開單原因
WBS v7 LIFE-11（P0，純邏輯）：死亡名將可保留精華並轉為可繼承資源，數值係數釐清後實作。協調者（2026-10-14 19:05Z）指示：依規格上下文自行提一組暫定係數，做成常數表方便調整，記入待辦並標暫定，不必等待。

## 完整描述
- 規格依據：`武將壽命系統.md` §名將保值（演武聖境）「死後精華快照 = TP × 0.5，轉為可繼承資源」；§E 製作功能清單 #5 演武聖境 P2；商業點「名將死後精華保存→付費復活特定數值」。
- 新增 `LegacyArena.ts`（純邏輯）：
  - `LEGACY_ARENA_TUNING` 常數表：精華快照係數 0.5（規格值）、快照上限 300（暫定）、付費復活回復係數 0.3（暫定）。
  - `legacySnapshotOf(totalPower)`：floor(TP × 係數)，有上限，無效輸入回 0。
  - `legacyReviveRestoreOf(snapshot)`：付費復活回復的精華量，floor(快照 × 回復係數)，無效輸入回 0。
- TP 的定義規格未明寫，由呼叫端傳入「總戰力數值」；本卡不決定 TP 的算法。

## 解讀選擇
- 規格只給 TP × 0.5 一個係數，其餘係數（上限、復活回復比例）為暫定，集中在常數表，定案後只改常數。
- 付費復活的價格與商店掛接不在本卡範圍（屬商業面，待企劃定案）。
- 戰魂寄宿（同名武將，P2）不在本卡範圍。

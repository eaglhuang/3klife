# [PROG-2-0433] 退役戰績評分邊界值補測（REC-07 驗收）

## 開單原因
協調者（2026-10-14 19:14Z）指示：不等 CI，直接開 REC-07。檢查後發現 REC-07 的實作與接線已在 master（PROG-2-0411，`retireScore` / `retireTallyGrade` 與 `LegacyService.retireGeneral` 寫入 retireGrade）。WBS 驗收條件寫「邊界值測試通過」，但現有測試只鎖住剛好等於門檻的值，沒有鎖住「剛好低於門檻」的值。本卡只補這組測試。

## 完整描述
- 在 `tests/BattleRecordStats.test.ts` 新增一條測試，覆蓋三個門檻的下界：
  - 分數 999.999 → N（低於 1000 門檻）
  - 分數 4999.999 → R（低於 5000 門檻）
  - 分數 9999.999 → SR（低於 10000 門檻）
- 不改實作，不改規格。

## 解讀選擇
- 規格門檻寫法為 `>=`，剛好等於門檻屬上一級，既有測試已鎖；本卡補的是剛好低於門檻的一側。
- 虎符是否依退役品質發放仍是 PM 待確認項（PROG-2-0411 notes），本卡不處理。

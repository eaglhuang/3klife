# [PROG-2-0434] 退役戰績回顧與季度戰損報告文字（REC-08）

## 開單原因
協調者（2026-10-14 19:16Z）指示：REC-07 之後直接做 REC-08。同時記錄一條 PM 暫定（退役發同品質虎符）。

## 完整描述
- 規格依據：`武將戰績系統.md` §G 劇本（退役戰績回顧、戰損報告）、§H UI_RETIRE_REVIEW、UI_BATTLE_REPORT。
- 新增 `RetireReviewCopy.ts`（純邏輯）：
  - `retireReviewCareerLine`：退役面板的生涯戰績行（沿用 `buildBattleRecordPanel`）。
  - `retireReviewScriptLine`：退役劇本句「回首征途：勝 X 場，斬敵 Y 人，承傷 Z——英雄無悔。」
  - `vitalityPercentOf`：精力百分比，無條件捨去，夾在 0~100，上限無效回 0。
  - `quarterlyBattleReport`：戰損報告「精力 X%」與劇本句，附結緣建議。

## 解讀選擇
- 結緣建議門檻：規格只寫「不建議進行結緣」，沒有寫數值。暫定沿用精力高區門檻（>50%），精力不在高區才顯示「不建議」。PM 待定案。
- 虎符衝突：PM 暫定「退役時依退役品質發同品質虎符入背包」。規格《兵種（虎符）系統》第 38 行、《武將壽命系統》正式共識都寫「生前退役不直接生成虎符卡，虎符只在死亡結算產出」。依 PM 指示「規格有更明確的寫法就以規格為準」，本卡不實作，記入待辦檔待 PM 確認。

# [PROG-2-0435] 精力狀態對撤退風險的影響（LIFE-10 撤退段）

## 開單原因
協調者（2026-10-14 19:18Z）指示：REC-08 之後做撤退機制。LIFE-10 的規格要求「精力耗盡段提高撤退風險」。

## 完整描述
- 規格依據：`武將壽命系統.md` §精力區間：「<10%：仍可移動與普攻，但不得再發動任何主動戰法，且撤退風險提高」。
- 新增 `RetreatRisk.ts`：`retreatRiskOf(baseRisk, band)` = 基礎風險 + 精力段加成（`retreatRiskBonus`，耗盡段 0.1，PM 暫定），結果夾在 0~1。

## 解讀選擇
- 「撤退風險」解讀為撤退時遭遇不利結果的機率。規格沒說明是「撤退失敗」還是「撤退時被俘」，本卡不區分，只給機率數字。
- 基礎風險由呼叫端給；規格沒有數值。

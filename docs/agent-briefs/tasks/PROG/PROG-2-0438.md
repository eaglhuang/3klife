# [PROG-2-0438] 里程碑獎勵表與達成後的獎勵組合（REC-05）；REC-06 阻塞

## 開單原因
協調者（2026-10-14 19:36Z）指示：若撤退已開 PR，接著做 REC-05 與 REC-06。撤退已開 PR #369。

## 完整描述
- 判定條件已存在（`BattleRecordStats.BATTLE_MILESTONES` 與 `newlyReachedMilestones`），與規格的門檻一致，本卡不重做。
- 新增 `MilestoneRewards.ts`（純邏輯）：
  - `MILESTONE_REWARDS`：依規格獎勵表。百人斬戰法筆記 ×1；千人斬戰法筆記 ×3 加稱號；萬人斬虎符品質提升加英靈牆動畫；不敗、鐵壁為白色隱藏因子；殺意為紅色隱藏因子。
  - `rewardsForMilestones`：依里程碑 id 組獎勵清單。
  - `claimMilestoneRewards(record)`：只讀 record，回傳新達成的 id 與獎勵；呼叫端要把 newIds 寫回 record.milestones，避免重複發放。

## REC-06 阻塞原因
- 隱藏因子覺醒要在達成時解鎖白色或紅色因子（不敗、鐵壁、殺意）。
- `gene-dictionary.json` 只有一般因子，沒有這三個隱藏因子；全文搜尋也沒有 ID。
- 因子 ID 不應自行編造，否則之後會與因子字典不一致。因此獎勵表中 factorId 為 null，待因子字典確認後補上。

## 解讀選擇
- 稱號名稱規格未定，titleId 用暫定佔位字串。
- 「虎符品質提升」與「英靈牆特殊動畫」只做為獎勵標記，實際效果待企劃與 cc 層。

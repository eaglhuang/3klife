# [PROG-2-0440] 隱藏因子覺醒：不敗／鐵壁／殺意（REC-06）

## 開單原因
REC-05（PROG-2-0438）時 REC-06 因因子字典沒有「不敗、鐵壁、殺意」而阻塞。協調者轉達 PM 裁定（2026-10-14 23:44Z，暫定可逆）：照規格名稱新增三個隱藏因子 ID，顏色照規格（不敗、鐵壁為白；殺意為紅）；白色若字典尚無對應色，先掛暫定標記並記入待辦檔。

## 完整描述
- `gene-dictionary.json` 新增三筆隱藏因子：`gene_hidden_undefeated`（不敗，白）、`gene_hidden_iron_wall`（鐵壁，白）、`gene_hidden_killing_intent`（殺意，紅）。
  - ID 採用字典現有前綴 `gene_`（PM 範例寫 `hidden_*`，但字典內所有因子皆為 `gene_*`，故以字典為準）。
  - 欄位沿用既有隱藏因子格式（category `hidden`、maxLevel 1、isHidden true）；color 用規格色；加 `provisional: true` 標記白色/紅色尚未與字典色譜正式對齊。
- `MILESTONE_REWARDS` 的隱藏因子獎勵填入 factorId。
- 測試：每個隱藏因子獎勵的 factorId 都存在於字典、isHidden 為 true、顏色與規格一致。

## 解讀選擇
- ID 前綴：採 `gene_`，不採 PM 範例的 `hidden_`（與字典一致）。
- 白色、紅色不在字典既有色譜內（既有隱藏因子為 gold）；改名或改色只需改字典，故以 provisional 標記。

## 未覆蓋
- 覺醒後的實際因子掛載（背包／武將因子寫入）沒有在本卡接，只給獎勵清單的 factorId。
- KIN-05 白因子的正式裁決仍待使用者。

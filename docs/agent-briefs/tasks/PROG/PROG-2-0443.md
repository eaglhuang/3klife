# [PROG-2-0443] 補元散精力回復（VIT-05）

## 開單原因
WBS v7 VIT-05「補元散道具（+50/+100，不超過上限）」為 P0 純邏輯，依賴 VIT-01（已完成）。經濟系統.md 道具表寫明回復量。

## 完整描述
- 新增 `applyVitalityPill(current, max, kind)`：補元散 +50、高級補元散 +100，結果夾在 0 到上限之間。
- 無效輸入保護：精力非有限數視為 0，上限無效視為 0。

## 解讀選擇
- 已滿時仍可使用、回復為 0（暫定，規格未寫禁止）。
- 只算精力，不管售價與扣道具（那在商業與背包層）。

## 未覆蓋
- 道具扣除與存檔寫入。
- 售價（經濟系統寫「補元散 10 寶石」，屬商城層）。

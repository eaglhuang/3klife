# [PROG-2-0444] 補元散存檔寫入與背包使用流程（接 PROG-2-0443）

## 開單原因
PM 指示（2026-10-15 00:00Z）：存檔寫入與 cc 背包按鈕接線照寫（雲端不能建置，程式照寫），另開新分支 PR；實機驗收交 Codex。

## 完整描述
- `GameSession.usePillOnGeneral(generalId, kind)`：用 `useVitalityPill` 檢查並扣道具、回復精力、寫回名冊（vitality / maxVitality）、廣播 InventoryChanged、自動存檔。拒絕時整體不變。
- `VitalityPillController`（純邏輯）：提供持有數，使用鈕 → 提示文字（精力已滿、沒有道具、查無武將）。
- 存檔：背包整包存，道具 key 經 `normalizeInventory` 保留；有測試鎖住。

## 解讀選擇
- 上限沿用名冊上的 maxVitality，缺值用性別基礎值（與 VitalityCap 一致）。
- 分支疊在 #390 上，因為 0443 的道具定義還沒合併進 master。

## 未覆蓋
- cc 背包按鈕的場景節點綁定與 prefab（交 Codex 實機接線）。
- 售價（PM 指示先不做）。

## 實機驗收（交 Codex）
1. 進背包，持有補元散時按使用：精力依武將上限回復 50，道具減 1。
2. 精力已滿時按使用：提示「精力已滿，不需使用補元散」，道具數不變。
3. 高級補元散回復 100，夾在上限內。
4. 離開並重進遊戲：道具數與武將精力保留。

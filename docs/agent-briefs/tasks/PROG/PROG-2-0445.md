# [PROG-2-0445] 戰績里程碑字串進語系表（REC-12）

## 開單原因
PM 指示（2026-10-15 00:25Z）：壽命線剩餘 P1。WBS v8 壽命相關 P1 中，REC-12（戰績劇本與字串：百人斬、千人斬、不敗、守護、退役回顧）未開始、無依賴，且是純字串工作。

## 完整描述
- `BattleRecordStats.ts`：六個里程碑（KILL_100、KILL_1000、KILL_10000、UNDEFEATED_50、GUARDIAN_WALL、ASURA）的 zh-TW 預設名稱保留為 `BATTLE_MILESTONES.displayName`，新增語系 key `record.milestone.<id>` 與 `milestoneTextKey(id)`、帶 fallback 的查詢函式。
- 四語系 `record.milestone.*` 新增六個 key（文字插入，不重排檔案）。
- 退役回顧（`ui.retire_review.*`）已於 PROG-2-0420 進語系表，本卡不重做。
- 測試：每個里程碑都有四語系 key；zh-TW 語系表與 fallback 一致；無語系表時退回 zh-TW 名稱。

## 解讀選擇
- 只做名稱字串。`UI_STAT_*` 面板標籤與「本場戰績」文字仍維持現況（WBS 驗收只要求 Key 進 i18n）。
- 呼叫端（BattleUIBridge 戰鬥飄字、退役面板）暫未改為語系查詢，待 Codex 實機或後續卡接線。

## 未覆蓋
- 戰鬥飄字與戰績分頁改走語系查詢（需 cc 接線）。
- 「不敗」里程碑的文案是否要改用規格中的「不敗」而非「不敗神話」，維持現有名稱（規格未另定）。

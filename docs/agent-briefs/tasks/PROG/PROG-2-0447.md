# [PROG-2-0447] 名士占卜面板的方向提示 cc 接線（接 PROG-2-0446）

## 開單原因
PM 指示（2026-10-15 00:07Z）：占卜面板方向提示的 cc 接線照寫，另開 PR，附 Codex 驗收步驟。

## 完整描述
- `SageOracleController.getView()`：有占卜對象時，列出仍鎖住且等級還看不到的因子色系，文字為「未解鎖方向：戰法、體魄」，節點 `directionHint` 啟用；沒有則為空字串、不啟用。
- `sage-oracle-main.json`：新增 `directionHint` 標籤節點，插在 `costLabel` 後。

## 解讀選擇
- 面板用語沿用既有 COLOR_HINT（屬性、適性、戰法、天命、天賦、體魄），不直接顯示英文色名。
- 節點座標 top 412 是暫定，需實機確認版位。

## 未覆蓋
- 因子名稱與精準結果（規格不給）。
- 實機版位與字級（交 Codex）。

## 實機驗收（交 Codex，PM 轉）
1. 開名士占卜，選一位還有鎖定綠、紅、紫因子且等級未達門檻的武將：占卜對象資訊下方應出現「未解鎖方向：…」。
2. 切換到等級已達門檻的武將（或提高發現等級）：提示消失，版位不留空白。
3. 沒有可占卜的武將：提示不出現，「名冊中沒有尚有鎖定因子的武將」照常顯示。
4. 確認 directionHint 不與「占卜」「預言子嗣」按鈕重疊，若重疊，調整 sage-oracle-main.json 的 widget.top。

# [PROG-2-0448] 退役戰績回顧與季度戰損報告的畫面流程（REC-08）

## 開單原因
PM 依 WBS v8 派工：REC-08 為 P1，文字模組已有（PROG-2-0434），缺畫面流程。

## 完整描述
- 新增 `buildRetireReviewView(general)`：回傳退役回顧的生涯戰績一行與劇本句，以及季度戰損報告的精力行與劇本句（含是否建議結緣）。
- 缺資料時（舊存檔沒有戰績或精力）用空戰績與 0%，不拋錯。

## 解讀選擇
- 文字全部沿用 RetireReviewCopy，不另拼字。
- 結緣門檻沿用精力高區 50%（暫定，待 PM 定案）。

## 未覆蓋
- 退役面板與季度戰報的 layout 節點、i18n 綁定與場景接線（交 Codex 實機）。

## 實機驗收（交 Codex，PM 轉）
1. 進退役流程，選一位 65 歲以上武將：回顧面板顯示生涯戰績與劇本句。
2. 選一位舊存檔武將（沒有戰績）：面板顯示空戰績，不閃退。
3. 季度戰報：精力高於 50% 顯示「可進行結緣」，否則顯示「不建議進行結緣」。

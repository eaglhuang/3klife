# [PROG-2-0450] 趕路倒數 CountdownManager（OPEN-11，純邏輯）

## 範圍
- CountdownManager.ts（純 TS）：createCountdown（targetId、起始時間、時長、可否加速）、countdownStatus（依絕對時間算剩餘與狀態，離線時間自動累積）、rushCountdown（加速完成，回傳需扣的 rushPrice，不扣錢）、shouldShowResidentIcon（趕路中才顯示常駐圖示）。
- 測試：離線後回來仍正確、到點切換為已到達、加速條件、無法加速時拒絕、時長非法時拋錯。

## 暫定決策
1. 時間以呼叫端傳入的毫秒計算，不讀系統時鐘，方便離線與測試。
2. arrivalTime 的單位規格未寫，由呼叫端換算成毫秒（暫定）。
3. rushPrice 只回傳金額，扣款由呼叫端處理。

## 不在範圍
- 倒數 UI、存檔、紅顏資料（OPEN-10）、通知規則。

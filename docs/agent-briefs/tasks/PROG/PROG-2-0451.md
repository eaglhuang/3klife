# [PROG-2-0451] 大廳武將點位接線（HALL-07，純邏輯呼叫端）

## 範圍
- 既有 HallCharacterRoll.ts（PROG-2 前期已合併）只有加權抽樣與刷新判斷，無任何呼叫端。
- 新增 HallCharacterPresenter.ts（純 TS）：
  - refreshHallCharacterSpots(state, nowSec, candidates, count, random)：距上次刷新未滿 60 秒則原樣回傳；到期才重抽並更新 lastRefreshSec。
  - buildHallSpotRows(spots, candidates)：把被抽中的 id 轉成列資料（id、是否收藏、是否已派任務）。
- 點位數與人數沿用 clampSpotCount / clampOccupantCount。

## 暫定決策
1. 時間單位沿用 HallCharacterRoll 的秒。
2. 本卡只提供純邏輯與列資料，不改 LobbyScene（UI 接線另開卡）。

## 不在範圍
- 頭頂姓名、集體反應、點擊對話（UI，GDART/HALL-07 美術部分）。
- 收藏與派任務狀態的來源（由呼叫端注入）。

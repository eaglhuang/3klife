# [PROG-2-0454] 自告奮勇彩蛋判定與成功率加成（HALL-06，純邏輯）

## 範圍
- HallVolunteer.ts（純 TS）：
  - shouldShowVolunteerEvent(task, general)：任務標籤與武將 roleTags 有交集、武將情緒為 EAGER、任務尚未標記 VOLUNTEER_SHOWN。（依大廳系統 F-2）
  - markVolunteerShown(task)：回傳新任務物件，加上 VOLUNTEER_SHOWN 旗標，不改輸入（一次性演出）。
  - sortVolunteersFirst(candidates, task)：自告奮勇者排在下拉清單前面，其餘保持原順序。
  - applyVolunteerBonus(baseRate, volunteered)：自告奮勇成功率 +50%，結果夾在 0~1。
- 測試覆蓋：判定四條件、一次性旗標、排序穩定、加成與夾值。

## 裁定與暫定決策
1. PM 裁定採「大廳補遺版（成功率 +50%）」，理由：補遺較新、數字較具體。名詞定義的「不綁固定成功率」說法記入待辦檔，等企劃統一用詞。
2. 「+50%」暫定解讀為加 0.5 個百分點（50 percentage points）而非乘 1.5 倍，理由：補遺寫「+50%」且 UI 顯示為加成標示。若企劃要乘法，只改 applyVolunteerBonus 一處。上限 100%。
3. roleTags、mood 欄位目前武將資料沒有，由呼叫端注入；本卡不新增武將欄位。

## 不在範圍
- 大廳下拉與一次性小演出的畫面（UI 卡）。
- 武將人物頁的推薦標籤（UI 卡）。

# [PROG-2-0458] 轉職令購買入口（FATE-07 轉職令 UI 接線）

- ItemShopPricing（core/systems，純資料與判斷）：JOB_CHANGE_ORDER_OFFER（精元 50）、canAffordOffer。
- JobChangeController（ui/core，純邏輯）：canBuyOrder、buyOrder（精元不足不扣款）、flow view 的 btnBuyOrder 與按鈕文字。
- job-change-main.json：新增 btnBuyOrder 節點（skinSlot job.button.bg）。
- LobbyScene：_mountJobChange 注入 gems（LocalGachaService 精元）與 buyOrder（spendCurrency + addItem），綁定 btnBuyOrder。

# [PROG-2-0459] 天下沙盤入口（Q16 方案 B）

## 範圍
- HallMissionBoard / LobbyHubSchema：HallBoardKey 與選填 Mission_Boards.Expedition，缺省不報錯。
- HallMissionBoardPresenter：任務牆不存在時列表為空。
- HallBoardPanelController：Expedition 牆標題「天下沙盤・遠征」，接取沿用同一條 assign 路徑。
- lobby-hub.json：範例遠征牆（E-EASY-01 需階段 1；E-NORMAL-01 需階段 2）。
- hall-board-main.json 新增分頁鈕；lobby-season-hud-main.json 新增「天下沙盤」入口。
- LobbyScene：btnOpenSandtable 開啟任務牆並切到遠征牆；分頁鈕切換。
- 測試 4 條：遠征牆過濾與標題、共用接取入口、無遠征資料不拋錯、分頁鈕與 layout 對應。

## 暫定決策
1. 依 整併疑問書 Q16 的 B（採推薦）：遠征與雙牆共用一條入口，大廳只是呈現面。
2. 沙盤入口先做成任務牆的一個分頁，不做地圖本體；之後地圖熱點可直接呼叫同一個 _openHallBoard('Expedition')。
3. 遠征任務範例資料沿用 HALL_DEFAULT_PLAYER（沙盤階段 1）。

## 不在範圍
- 沙盤地圖、熱點與放大動畫。
- 實機驗收（交 Codex 0110 重驗）。

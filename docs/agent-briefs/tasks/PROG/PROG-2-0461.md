# [PROG-2-0461] NPC Persona Card 資料結構（NPC-01）

## 範圍
- NpcPersonaCard（core/systems，純邏輯）：型別、NPC_LINE_MAX_CHARS（60，暫定）、validateNpcPersonaCards。
- assets/resources/data/npc-persona-cards.json：佔位資料，只有張飛一張。
- 測試 4 條：佔位檔通過、必填欄位與 key 一致、字數與錨點、空表與不改輸入。

## 暫定決策
1. 欄位名稱沿用規格 I-1 的 Snake_Case，不另改名。
2. 佔位內容直接用規格範例的張飛卡，標記 Content_Status = PLACEHOLDER，正式內容待企劃。
3. 字數上限 60 採規格 F-3 的 maxLineChars 概念，數值暫定。

## 不在範圍
- 離線模板引擎（NPC-03，另卡）。
- RAG 改寫與中台介接。

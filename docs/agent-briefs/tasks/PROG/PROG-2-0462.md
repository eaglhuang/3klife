# [PROG-2-0462] 離線模板台詞引擎（NPC-03）

## 範圍
- OfflineTemplateEngine（core/systems，純邏輯）：fillTemplate、isAcceptableOfflineLine、renderOfflineLine。
- 測試 5 條：槽位、字數區間、模板輪替、回退安全句、不改輸入。

## 暫定決策
1. 字數區間採規格 G 的 20~60 字，以 Unicode 字元計。
2. 找不到情境、缺槽位、字數不合都回退安全句（FALLBACK_LINE），不丟錯。
3. 安全句不套字數下限，因為規格把它定義為固定句。

## 不在範圍
- 正式模板文案（待企劃）。
- 武將頭像點擊的 cc 接線。
- RAG_REWRITE 與中台介接。

# [PROG-2-0475] 趕路觸發與存檔（回合制）

- GameSession：startTravel、travel、每季遞減（advanceSeason）、歸零清除、TravelChanged 事件、存檔快照與讀檔。
- PlayerSaveService：選填欄位 travelCountdown，讀回經 normalizeTravelCountdown。
- LobbyScene：接取天下沙盤遠征成功後呼叫 startTravel。
- 新局與讀檔清除舊的時間戳記倒數（_countdown）。
- 測試：startTravel、季推進到達、存檔帶上趕路、新局清除、讀回驗證。

3. 趕路目標為接取任務的出戰主將。

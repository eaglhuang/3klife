# [PROG-2-0476] 傭兵名牌入口（MERC-07）

## 範圍
- MercenaryPanelController.selectUid(uid)：依 uid 選取，不在名單內回傳 false。
- MercenaryNameplateRows（ui/core，純資料）：名牌列的武將名與狀態文字，上限與面板列數一致。
- LobbyScene.openMercenaryPanelFromNameplate(uid)：先選取再開面板。
- 測試：選取、名牌文字、名牌上限。

## 暫定決策
1. 入口是名牌點擊，不在 HUD 加按鈕（PM 既定，記在團隊記憶）。
2. 名牌狀態文字：試用中顯示剩餘日數、已結義、其他視為已離隊。

## 不在範圍
- 大廳名牌的實際位置與排版（大廳目前沒有名牌節點，待 PM 定版後由 cc 端接線）。
- 實機排版交 Codex 驗收。

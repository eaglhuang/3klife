# [PROG-2-0479] 大廳任務委任與回看紀錄（HALL-05）

## 範圍
- HallAutoAssign（純邏輯）：autoAssignHallTask（僅 AI_Assign_Enabled 為真時委任）、pickAutoAssignGeneral（戰力最高優先）、appendAssignRecord（不可變追加）、listAssignRecords（依任務篩選，新到舊）。
- 既有 F-5 四函式（HallTaskIntel）不改動。
- 測試：委任開關、選將與同分、無候選與非有限戰力、情報度不被委任改動、紀錄不可變與回看。

## 暫定決策
1. 選將規則：戰力最高者優先，同分取 generalId 字典序較小者。規格未寫選將權重，待企劃定版。
2. 紀錄只記「誰、何時、接哪個任務」，結算結果（成敗、獎勵）由後續系統寫入，本卡不做。

## 不在範圍
- 結算流程與獎勵（後續卡）。
- 大廳委任按鈕的畫面接線（交 Codex 實機驗收）。

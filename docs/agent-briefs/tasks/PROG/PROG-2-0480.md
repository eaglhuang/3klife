# [PROG-2-0480] 大廳委任結算紀錄（HALL-05 缺口）

## 範圍
- HallAutoAssign：紀錄新增 outcome、settledAt（缺省為未結算）。
- settleLatestAssign：結算同一任務最新一筆未結算紀錄；已結算或無紀錄時拒絕；回傳新陣列。
- 測試：套用範圍、拒絕情況、回看含結算資訊。

## 暫定決策
1. 結算結果只有 success / failure。實際戰鬥結果的對應規格未寫，由呼叫端決定。
2. 只結算最新一筆未結算紀錄，避免同一任務的舊紀錄被重複結算。

## 不在範圍
- 戰鬥結果如何換算成 success / failure（後續系統）。
- 大廳委任與結算畫面接線（交 Codex 實機驗收）。

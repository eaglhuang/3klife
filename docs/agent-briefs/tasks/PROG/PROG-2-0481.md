# [PROG-2-0481] 數值常數集中化 NumericalConfig JSON + FormulaRegistry（NUM-04）

## 開單原因
WBS v8 NUM-04（M0，P1，data）：剋制、適性、年齡、轉生、奧義、虎符等數值常數目前零散在 `Constants.ts` 與各系統內。本卡先建立單一 JSON 來源與純 TS 讀取驗證器，為 NUM-05/06/07/08/11 等後續卡提供共同前置。

## 完整描述
- 新增 `assets/resources/data/numerical-config.json`（+ .meta）：內容依 `數值系統.md` §I，包含 `NumericalConfig` 與 `FormulaRegistry` 兩個頂層鍵。
- 新增 `assets/scripts/core/config/NumericalConfig.ts`（+ .meta）：純 TS，無 cc 依賴。提供型別 `NumericalConfig`、`parseNumericalConfig(raw: unknown)`（回傳 `{ ok, config } | { ok, errors }`），驗證各區段存在且數值欄位為有限數字。
- 新增 `tests/NumericalConfig.test.ts`：讀取真實 JSON 解析成功；抽樣比對規格值；與 `Constants.ts` 的 `COUNTER_MULTIPLIER`（1.3）、`SP_PER_KILL`（20）交叉比對；缺欄位、非數字時回報錯誤。
- 本卡不改寫既有消費端（`Constants.ts` 與各系統仍保留原常數），消費端改線留給後續卡，避免一次動太多檔。

## 如何驗證
1. `tests/NumericalConfig.test.ts` 全綠。
2. run-cli ALL PASS。
3. `tsc --noEmit -p tsconfig.test.json` 觸及檔案無新錯。
4. compute-gate standard 通過。

## 相關聯任務卡
- NUM-04（WBS v8，M0）；後續 NUM-05/06/07/08/11 依賴本卡。

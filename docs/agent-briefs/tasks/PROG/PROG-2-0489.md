# [PROG-2-0489] ResultPopup 測試改寫為 run-cli suite，並排除 tsc 範圍外檔案

## 開單原因
PM 裁定：ResultPopup.test.ts 目前是 jest 寫法，專案沒有 jest，且匯入路徑不存在，所以從未真正執行。改寫成 run-cli 的 `createResultPopupSuite()` 寫法，讓它實際跑起來。另依 PM 裁定，將 `assets/scripts/ui/core/_pending-delete/` 與 ATM 同步檔 `tests/atm-lang-csharp.test.ts` 從 tsc 專案排除（不刪檔、不改 ATM 同步檔內容），使非 battle 的 tsc 錯誤可清到 0。

## 範圍
1. `tests/ResultPopup.test.ts`：移除 jest.mock，改用手寫 binder 與 no-op 動畫，覆蓋三種結果的標題、按鈕事件、resetState。
2. `tsconfig.test.json`：exclude 加入 `assets/scripts/ui/core/_pending-delete/**` 與 `tests/atm-lang-csharp.test.ts`。

## 不在範圍
- 不刪除任何檔案（`_pending-delete/` 的刪除另議）。
- 不改 `tests/atm-lang-csharp.test.ts` 內容。
- 不動 battle/** 的 tsc 錯誤。

## 如何驗證
1. `npx ts-node --transpile-only -r ./tests/register-cc-test-stub.js -r ./tests/register-tsconfig-test-paths.js --project tsconfig.test.json tests/run-cli.ts` 能跑到 ResultPopup suite 並通過。
2. `npx tsc --noEmit -p tsconfig.test.json` 中 ResultPopup、_pending-delete、atm-lang-csharp 的錯誤消失。
3. 閘門 `node tools_node/compute-gate.js --profile standard --agent-feedback`。

## 實測結果
- ResultPopup suite：9 項全部通過（run-cli 總數 2377 → 2386）。原因：run-cli.ts 的 SKIP 名單含 ResultPopup，故先前從未被註冊；本卡同時將其移出 SKIP（tests/run-cli.ts 納入鎖定範圍）。
- tsconfig exclude 生效：tests/atm-lang-csharp.test.ts 的 13 筆錯誤已消失。
- 阻塞：`assets/scripts/ui/core/_pending-delete/UIPreviewShadowManager.ts` 的 5 筆錯誤來自 tsconfig exclude 無法擋住的傳遞 import。UIPreviewBuilder.ts:23 仍 import 該檔，且 :51 執行期會 new 它；該檔內的相對路徑（./UISkinResolver、./UIPreviewStyleBuilder、./UIPreviewLayoutBuilder、./UISpecTypes）在 _pending-delete/ 內已不存在。修正方式需另行裁定（改 import 路徑、或 @ts-nocheck、或正式遷移），本卡不擅自改。

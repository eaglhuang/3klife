run-cli 啟用後 38 項失敗，分兩類：
1. 測試範圍錯誤：`ui-spec/layouts/` 內混有 `.bake-manifest.json`、`.optimizer-scan.json`、`.compare.*.json`、`.pixel-diff.json` 等報表檔，它們沒有 root。

第 2 類是資料問題，需 UI 資料擁有者裁定修正方式，本卡不弱化驗證。啟用前須先決定第 1 類的過濾規則並修第 2 類。

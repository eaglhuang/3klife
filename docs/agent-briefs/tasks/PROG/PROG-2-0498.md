## 完整描述
DS-04 驗收條件：Root Data 預設值含全部掛載路徑，缺漏欄位由 Migration 補齊。
本卡交付：規格 §二.2 的 25 個頂層掛載點清單與形狀、新存檔的預設骨架、只補缺漏的補齊函式，以及可接入 runSemverMigrations 的遷移步驟。

## 設計選擇（我的判斷）
- 補齊只補 `undefined`，null、空陣列、有資料的值一律保留，避免覆寫玩家存檔。
- 遷移步驟作用於 `Data` 區塊，其他欄位（Player_ID、Last_Sync_Hash、Action_Records）原樣保留。
- 形狀只在規格有 `[*]` 或 JSON 範例時定為確定，其餘標為「暫定」並寫在 basis 欄位，方便 PM 逐項確認。
- 不改 SAVE_VERSION_LATEST，避免影響現有存檔與既有測試。

## 需 PM 裁定
1. 遷移步驟是否接入正式版本鏈並把 SAVE_VERSION_LATEST 升到 1.0.1（規格要求 Data 增刪即升版）。
2. 暫定形狀的 11 條路徑（Inventory_Service、Talisman_Inventory、Spirit_Archive_Snapshot、Spirit_Family_State、Oracle_History、Family_Relations、NPC_Memory、Rival_Nations、Officer_System 等）是否依規格另行標註。

- `tests/DataMounts.test.ts`：25 個掛載點、關鍵子系統存在、骨架形狀正確、補齊不覆寫、冪等、遷移經 runSemverMigrations 跑通。
- run-cli 全數通過；tsc 無新增錯誤；compute gate standard 通過。

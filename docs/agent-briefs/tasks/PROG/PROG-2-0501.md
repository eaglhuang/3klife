## 設計選擇（我的判斷）
- 純函式 `parseSupportCard(raw)`：錯誤全部收集後一起回傳，成功時回傳新物件，不改輸入。
- Friendship_Bonus / Training_Effect 暫定依星等 ★0~★5 索引；靈感引擎的友情小數 = 倍率 − 1（`friendshipBonusFor`）。這同時定案了 PROG-2-0280 之後靈感引擎的換算問題。
- Role_Boundary 固定 `TeachingOnly`。
- Stat_Bonus 鍵名照 JSON 原樣保留，不做白名單（規格例子 STR/AGI 與遊戲培育五格不一致，待策劃定案）。

# [PROG-2-0508] 發現等級門檻鍵名對齊（FUL-01 DiscoveryThresholds）

## 來源
- PM 裁定（2026-10-14）：FACTOR_DISCOVERY_LEVEL 採程式常數；config 鍵名對齊常數，並加讀取相容測試。
- 規格 因子解鎖系統.md 示例 `DiscoveryThresholds: { Phase1: 20, Phase2: 45 }` 與階段表不一致：階段表為 Phase1 = 藍粉（Lv1）、Phase2 = 綠白（Lv20）、Phase3 = 紫紅（Lv45）。

## 範圍
- 新增純邏輯 `DiscoveryThresholds.ts`：解析 `{ Phase2, Phase3 }`，拒絕舊鍵 `Phase1`，驗證為正整數。
- 提供與 FACTOR_DISCOVERY_LEVEL 的一致性檢查。
- Headless 測試覆蓋：對齊鍵名與常數一致、舊鍵被拒、缺鍵與非整數被拒。

## 不做
- 不新增 config/gameplay.json（倉庫內目前沒有該檔）；由設定接線時再讀取此解析器。
- 不改 FACTOR_DISCOVERY_LEVEL 常數。

## 暫定
- Phase1 不設鍵，固定為 Lv1（藍粉），與階段表一致。

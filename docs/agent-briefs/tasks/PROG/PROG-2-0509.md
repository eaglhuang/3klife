# [PROG-2-0509] LUK 覺醒速度修正（LUK-05 局部）

## 來源
- 規格 運氣系統.md §LUK 對覺醒速度：`Awakening_Speed_Modifier = 1 + (LUK / 300)`（LUK=90 → ×1.3）。
- WBS v5 LUK-05：三個修正（事件率、覺醒速度、繼承率）需接到培育／覺醒／繼承處。

## 範圍
- 事件率修正 `Base × (1 + LUK/200)`：已由 MentorInspiration.inspireChance 接上，本卡不重做。
- 覺醒速度：培育回合的覺醒機率乘上 `1 + LUK/300`（封頂 1）。接入 NurtureService 覺醒呼叫。
- 測試：覺醒速度純函式、培育覺醒機率隨子嗣 LUK 變化、LUK 缺省時行為與舊版相同。

## 不做（待 PM 裁決）
- 繼承率修正：規格寫 `Base_Rate + ParentAvgLUK × 0.01`，但 Base_Rate 為 0~1 機率時加上 0.6 會超過上限，且註解又寫「相對基礎」。文字有衝突，本卡不實作。

## 暫定
- 「覺醒速度」解讀為乘在培育覺醒機率上；規格未明寫是乘在機率或是縮短時間。

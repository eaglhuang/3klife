# [PROG-2-0510] LUK 繼承率修正（LUK-05 收尾）

## 來源
- 規格 運氣系統.md §繼承成功率修正：父母平均 LUK 影響子嗣繼承優質因子的成功率。
- PM 裁定（暫定）：採乘法 `Base × (1 + ParentAvgLUK / 100)`，上限 1，與註解「相對基礎」一致；寫進待辦檔後實作。

## 範圍
- `FactorInheritance.ts`：新增 `inheritanceLukRate(base, parentAvgLuk)`；`inheritFactors` 可選 `parentAvgLuk`，因子池機率套用修正。
- `BreedingSystem.ts`：配種時以父母平均 LUK 傳入。
- 測試：純函式（乘法、封頂 1、負值與非法值視為 0）、`inheritFactors` 缺省 LUK 時與舊版相同、有 LUK 時高於基礎率。

## 暫定
- 因子池機率基礎為 FACTOR_POOL_RATE（一代 1、二代 0.5、三代 0.25）。
- 公式為 `Base × (1 + avg/100)`；avg=60 時 ×1.6。

# [PROG-2-0511] 天命波動接入 EP（LUK-02）

## 來源
- 規格 運氣系統.md §F：`天命波動 = LUK × Random(-0.5, +1.5)`，`EP = 50 + [共鳴] + [異脈] + [契合] + [天命波動]`。
- WBS v5/v6 LUK-02：EP 加入 LUK×Random(-0.5,1.5)，並可注入隨機源測試。
- 既有 EP_MVP 註解寫「天命波動延後到 P1」。

## 範圍
- `BreedingSystem.ts`：`rollFateWave(parentAvgLuk, random)`、`applyFateWave(ep, wave)`；`EpBreakdown` 新增 `fate`；配種在生成子嗣前擲一次並修正 EP（`childBaseStat` 讀 EP，子嗣能力也會受影響）。
- 預覽 EP（`previewBreedingEp`）不擲骰，`fate = 0`。
- 測試：範圍、LUK 0 為 0、注入隨機源可重現、套用後評級重算、配種結果 fate 與 LUK 相關。

## 暫定（規格沒寫的部分）
- 「LUK」取父母平均 LUK（與繼承率同口徑）。
- 波動值四捨五入為整數 EP。
- 預覽 EP 不含天命波動，UI 需標示（待 PM 確認）。
- 天命重置卷（LUK-07）、天命傳承（LUK-06）不在本卡。

# [PROG-2-0512] 命紋靈獸原型表對齊規格（BLT-12 純邏輯部分）

## 開單原因
養成線的 P0 已全數接線。WBS 中 BLT-12 的靈獸原型對照表是純邏輯可做的部分，PM 指派自選下一張時取它。規格（血統理論系統.md §M）優先於現有暫定清單。

## 做法
1. `core/systems/BloodlineBeast.ts`：六種原型的人格標籤、覺醒傾向說明、奧義偏向改為規格表原文。`BloodlineBeastDefinition` 新增 `awakeningHint`、`ultimateBias`，驗證時缺一即擋。
2. `formatBeastSummary`：摘要改顯示覺醒傾向說明與奧義偏向，不再顯示事蹟類型 id。
3. `tests/BloodlineBeast.test.ts`：新增兩條，一條鎖住清單與規格表一致，一條鎖住新欄位的驗證；摘要測試改為新文案。

## 如何驗證
1. headless 全綠（ALL PASS 2882，略過 3）。
2. `tsc -p tsconfig.test.json --noEmit` 與 master 基線比對，無新增錯誤。
3. 計算型閘門 standard。

## 缺口
- 覺醒傾向的事蹟類型 id 仍暫定，規格只給文字，待事蹟系統定案。
- 靈獸與武將的綁定規則（目前是雜湊取餘）仍暫定，規格未定。
- 摘要多了兩行，LobbyScene 的標籤版面待 Codex 實機確認。
- 祖紋命篆與靈獸美術不在本卡範圍。

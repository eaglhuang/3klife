- 事件文案：「{Name} 今日及笄，主公請為她選擇前路。」
- WBS FEM-06：14 歲觸發選擇並更新職能。

## 範圍
- 純邏輯 `DaughterComingOfAge.ts`：
  - `isComingOfAge(general, previousAge, nextAge)`：女性、年齡跨過 14 時回報一次，已選過路線不再回報。
  - `chooseDaughterRoute(general, route)`：驗證路線與條件，回傳新物件（不改輸入），寫入 `daughterRoute`。
- 測試：跨齡觸發、非女性不觸發、已選不重觸發、非法路線與未滿 14 歲被拒、不改輸入。

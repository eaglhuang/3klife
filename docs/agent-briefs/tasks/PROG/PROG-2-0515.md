# [PROG-2-0515] 家族關係：關係 Schema 與相性標籤引擎（KIN-01 / KIN-03）

## 來源
- 規格 家族關係（史實相性）系統.md §F「標籤共鳴加成表」、§I Data Schema。
- WBS v6 KIN-01（關係類型與 Schema）、KIN-03（相性標籤引擎，依賴 KIN-01）。

## 範圍
- `core/systems/KinRelation.ts`：史實關係 5 種、動態關係 4 種的型別；`parseHistoricalRelation` / `parseDynamicRelation` 驗證 raw JSON；`analyzeTagResonance(ancestors)` 算共鳴與家風。
- 共鳴門檻沿用 `EP_RESONANCE_MIN_COUNT`（3），與 `computeEpMvp` 同一來源。
- 測試：`tests/KinRelation.test.ts`。

## 不在本卡
- 史實相性資料表（KIN-02，需企劃名單）、爆發力接線（KIN-04）、純血 +30（需同族欄位，待定）。
- 本卡不改 `computeEpMvp`，不改變現有 EP 數值。

## 暫定（規格沒寫清楚的部分）
- 「countSharedTags ≥ 3」解讀為「同一標籤出現在 ≥3 位祖先身上」，與現行 `computeEpMvp` 一致。規格表格的「共享標籤數 5+」同樣以單一標籤出現在 ≥5 位祖先計。
- 家風傳承以「同一標籤 ≥5 位祖先」判定，只回傳布林，不發 Buff（Buff 內容待 KIN-11）。

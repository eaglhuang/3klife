# [PROG-2-0517] 天命波動改為小區間（LUK-02 修正）

## 來源
- PM 裁定（2026-10-14，QA 複查 PROG-2-0511 發現）：現行 `LUK × Random(-0.5, +1.5)` 在高 LUK 下會讓 EP 爆量，接近雙親 2 倍。改照《運氣屬性加入爆發力公式》（討論來源/運氣屬性加入爆發力公式.md）的小區間規則。
- 規格：運氣平均值 > 80 → 爆發力隨機 +5～+15；< 40 → -5～-10；其餘 0。

## 範圍
- `BreedingSystem.ts`：`rollFateWave(parentAvgLuk, random)` 改為區間規則；常數改為區間上下限。`applyFateWave` 與配種流程不變（仍四捨五入、仍在生成子嗣前擲一次）。
- 測試 `tests/FateWave.test.ts` 依新區間更新。

## 暫定（規格沒寫清楚的部分）
- 邊界：恰好 80 與恰好 40 都視為「其餘」，得 0。
- 區間內以均勻分布擲骰。
- LUK ≤ 0 或非有限值維持原行為，視為無資料，波動 0 且不擲骰（避免無 LUK 資料的武將全部被扣 EP）。PM 若要 LUK=0 也套用 < 40 區間，需另裁。
- 波動只在 rollFateWave 擲一次；預覽仍不含波動。

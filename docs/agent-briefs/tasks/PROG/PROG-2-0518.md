# [PROG-2-0518] 動態關係建立與存檔快照（KIN-06）

## 來源
- 規格 家族關係（史實相性）系統.md §5：戰場共鬥→戰友、結義傭兵→義兄弟、結緣→夫妻。
- WBS v6 KIN-06：對應事件發生時建立 DynamicRelation 並寫入存檔；WBS 另列「親子」。

## 範圍
- `core/systems/KinDynamicRelations.ts`：
  - `dynamicRelationForEvent(kind, uidA, uidB, season)`：事件 → 關係型別對照，經 `parseDynamicRelation` 驗證。
  - `DynamicRelationBook`：`record` 依「雙方＋型別」去重（順序無關）；`listFor(uid)`；`snapshot()` / `restore()` 給存檔用，無效項目略過並回報數量。
- 測試：`tests/KinDynamicRelations.test.ts`。

## 不在本卡
- 戰場/結義/結緣事件的實際呼叫端接線（各線 owner 接，本卡只提供入口）。
- 親密度增減（KIN-10 衰退與互動）、關係圖鑑 UI（KIN-07）。
- 存檔欄位正式寫入 GameSession（本卡只提供 snapshot/restore 純函式）。

## 暫定
- 新建關係的起始親密度 `DYNAMIC_RELATION_INITIAL_INTIMACY = 30`（規格未寫）。
- 親子事件列入（WBS 有、規格 §5 沒列）。
- 同一對武將可同時擁有不同型別的關係（如戰友與夫妻），同型別只保留一筆。

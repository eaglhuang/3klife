# [PROG-2-0519] 運氣特殊門檻判定（LUK-06）

## 來源
- 規格 運氣系統.md「LUK 特殊門檻效果」：≥80 戰法強制複製（父親最強戰法 100% 繼承）；≥95 血統變異（隨機一個因子突破 ★，上限 ★4）；=100 天命傳承（額外繼承一個曾祖代因子）。
- WBS v6 LUK-06：各門檻只在達標時觸發且可測。

## 範圍
- `core/systems/LuckThresholds.ts`：`luckThresholdEffects(luk)` 回傳三個旗標；`LUK_MAX = 100`。
- 測試 `tests/LuckThresholds.test.ts`。

## 不在本卡
- 戰法複製、因子突破、曾祖因子繼承的實際套用（需配種流程與因子資料，另卡接線）。
- LUK 上限依紫因子計算（LUK-03，待 PM 裁定）。

## 暫定
- 門檻以父母平均 LUK 判定，與繼承率同口徑。
- `=100` 以 `>= LUK_MAX` 判定（LUK 不會超過上限）。
- LUK 缺省、負數、非有限值視為 0，三個旗標皆 false。
- ≥95 血統變異的 ★ 突破幅度（+1）與上限（★4）採規格字面，細節待企劃確認。

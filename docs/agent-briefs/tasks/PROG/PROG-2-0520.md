# [PROG-2-0520] 史實相性配對表與爆發力／受孕率接線（KIN-02 / KIN-04）

## 來源
- 規格 家族關係（史實相性）系統.md §F（名將契合 +25、宿敵受孕率 ×0.7）、§F 史實關係類型定義、§I Schema。
- WBS v6 KIN-02（史實相性資料表）、KIN-04（爆發力關係加成接線）。
- PM 裁定（2026-10-14）：先用從現有 generals 資料挑的暫定名單做邏輯與結構，名單記入待辦檔，等企劃替換。

## 範圍
- `assets/resources/data/historical-relations.json`：暫定名單 6 筆（夫妻 2、義兄弟 3、宿敵 1），欄位依 HistoricalRelation Schema。
- `core/systems/HistoricalPairs.ts`：`HistoricalPairTable`（載入時逐筆驗證，回報略過數量）、`relationBetween`（順序無關）、`affinityResolverOf(table)`（非宿敵的史實配對 → 契合 +25）、`conceptionModBetween`（宿敵 0.7、夫妻 1.2，取自資料）。
- `BreedingSystem.ts`：`BreedingRequest` 新增 `historicalConceptionMod`，與 `motherConceptionMod` 相乘後套用受孕率（仍封頂 0.95）。
- `BreedingService.ts`：新增 `historicalPairs` 選項；未指定 `isHistoricalPair` 時改用表；配種與 EP 預覽都走表。
- 測試：`tests/HistoricalPairs.test.ts`。

## 暫定（規格未定或與規格內部不一致）
- 名單為暫定，ID 取自現有 generals.json；企劃給正式名單後替換 JSON 即可。
- EP 契合固定 +25（沿用 EP_AFFINITY_BONUS，§F「名將契合 +25」）。表內 epBonus 欄位（SWORN 15 等）目前不採用，待 PM 確認。
- 宿敵：§F 寫「不直接給 EP」，表格列 -10；本卡依 §F，宿敵不影響 EP，只影響受孕率。
- 宿敵後代的「狼性」白因子不在本卡（KIN-05）。

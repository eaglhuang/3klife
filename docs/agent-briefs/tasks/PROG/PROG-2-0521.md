# [PROG-2-0521] 動態關係親密度衰退與互動回補（KIN-10）

## 來源
- 規格 家族關係（史實相性）系統.md §I：DynamicRelation.Decay_Rate「每季衰減值」；Server 表有 last_interact。
- WBS v6 KIN-10：每季依 Decay_Rate 減親密度，互動可回補。
- 注意：規格功能表把 9 號「關係衰退與維護」標為 P2，WBS v6 標為 P1。本卡依 WBS（PM 指示）。

## 範圍
- `core/systems/KinDynamicRelations.ts`：
  - `DynamicRelationBook.decaySeason()`：每筆依 decayRate 減親密度，下限 0；回傳受影響筆數。
  - `DynamicRelationBook.interact(uidA, uidB, type?, gain?)`：回補親密度，上限 100；找不到回傳 null。
  - `DYNAMIC_RELATION_DECAY_RATE = 2`（暫定）：事件建立時寫入 decayRate，之前固定為 0 等於不衰退。
  - `DYNAMIC_RELATION_INTERACT_GAIN = 10`（暫定）。
- 測試 `tests/KinDynamicRelations.test.ts` 補充。

## 暫定
- 每季衰減值 2、互動回補 10，規格沒寫數值。
- 衰退與回補只改親密度，不刪除關係。親密度歸 0 時關係保留（是否失效待 PM 裁定）。
- 不記錄 last_interact 季度（Server 表欄位，本卡不做存檔格式）。

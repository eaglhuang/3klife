# [PROG-2-0524] 動態關係存讀檔與互動觸發（KIN-06 存檔 / KIN-10 interact）

## 來源
- WBS KIN-06「寫入存檔」；Server 表欄位 last_interact 只記錄季度，本卡不做。
- 協調者指示（2026-10-14）：先接存讀檔，再接 interact 觸發。

## 範圍
- `core/systems/KinDynamicRelations.ts`：`normalizeDynamicRelations(raw)`，逐筆驗證、去重，無效略過。
- `core/services/PlayerSaveService.ts`：選填欄位 `dynamicRelations`；建立快照時寫入，讀檔時正規化；舊檔沒有此欄位時為空。
- `core/managers/GameSession.ts`：快照寫入與讀檔還原；新遊戲重置為空；新增 `interactDynamicRelation(uidA, uidB)`，有變動時自動存檔（沿用 spendSiegeLifespan 的寫法）。
- 測試 `tests/KinSeasonWiring.test.ts`：存讀往返保留親密度與關係；舊檔無欄位讀回空；互動後自動存檔。

## 不在本卡
- interact 的 UI 按鈕（需要場景，本卡只提供 session 入口）。
- 事件呼叫端（戰場、結義、結緣）建立關係。

## 暫定
- 存檔欄位名稱 `dynamicRelations`，陣列格式與 DynamicRelation 相同（camelCase）。

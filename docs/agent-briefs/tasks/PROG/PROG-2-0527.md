# [PROG-2-0527] 結緣與開獎提示改用規格措辭（§H 字串）

## 來源
- 結緣系統（配種）§H：UI_CHILD_BORN、UI_PREG_STATUS、UI_UNVEIL_5、UI_DAQI。
- PM 裁定（2026-10-14）：待產／誕下／開獎／大器晚成提示以規格措辭為準，規格優先。

## 範圍
- `ui/core/BondingSetupController.ts`：誕下與待產提示改用 `ui.breed.child_born`、`ui.breed.preg_status`（取代寫死的「神祕期至 5 歲開獎」句）。
- `ui/core/NurtureFlowController.ts`：開獎標題（fateName）改用 `ui.breed.unveil_5`；逆天觸發大器晚成時的提示改用 `ui.breed.daqi`。
- `ui/core/BreedingTexts.ts`：新增 `withBreedFallback`，語系表未載入時退回預設文案（BondingSetup 與 NurtureFlow 共用）。
- `ui/scenes/LobbyScene.ts`：兩個控制器共用注入。
- 測試：`tests/BreedingStrings.test.ts`、`tests/NurtureFlow.test.ts`（fateName 期望改為開獎標題）。

## 暫定
- 「喜獲 {2}」的 {2} 沿用 千金／麟兒（規格的 {Gender} 未列值）。
- UI_DAQI（§H「潛龍在淵」）與 §G 劇本（「此子雖木訥，然其志在遠」）措辭不同：本卡用 §H 作為 UI 文字，§G 劇本句留待演出設計。
- 開獎標題放在 fate 面板既有的 fateName 節點，不新增版面節點。

# [PROG-2-0528] 世代成就判定（RET-07）

## 來源
- WBS RET-07「世代成就（跨三代因子傳承偵測與獎勵）」。
- 規格：留存系統.md §世代成就：後代擁有祖先的因子，且世代差 ≥ 3 時，觸發成就並給予獎勵（高級貨幣 ×100）。
- PM 指示：不涉白因子，可直接開工。

## 範圍
- `core/systems/LegacyAchievement.ts`（新，純邏輯）：`legacyAchievementsOf(graph, uid, genesOf)`，回傳每個觸發的 (祖先, 因子) 組合與獎勵描述。
- `tests/LegacyAchievement.test.ts`（新）：世代差 3 觸發、差 2 不觸發、後代沒有該因子不觸發、同一因子多位祖先只計一次、無祖譜回傳空陣列。

## 暫定
- 「同一因子」以因子 id 去重：同一個後代對同一因子只給一次成就（規格偽代碼未寫去重）。
- 獎勵只回傳描述 `{ currency: 'premium', amount: 100 }`；專案目前沒有高級貨幣入帳 API，發放與 Legacy_Count 累加另卡。

## 不在本卡
- 高級貨幣入帳與 Legacy_Count 存檔。
- 成就 UI 與播報。

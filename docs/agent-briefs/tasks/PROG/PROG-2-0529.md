# [PROG-2-0529] 世代成就獎勵入帳與 Legacy_Count 存檔（RET-07 續）

## 來源
- 協調者指示（2026-10-14）：先確認是否已有元寶／精元錢包可共用，別重複造。
- 結論：已有轉蛋錢包（GachaWalletSave），`gems` 即靈玉（付費），規格「高級貨幣」對應此欄位。沿用，不另開錢包。

## 範圍
- `core/services/GachaWalletRules.ts`：新增 `STARTER_GACHA_WALLET`（純資料，原為 LocalGachaService 私有常數，數值不變）。
- `core/services/LocalGachaService.ts`：DEFAULT_WALLET 改為引用 `STARTER_GACHA_WALLET`。
- `core/systems/LegacyAchievement.ts`：`grantLegacyRewards(wallet, achievements)` 純函式，把成就獎勵加到 `gems`；`normalizeLegacyCount`。
- `core/services/PlayerSaveService.ts`：選填欄位 `legacyCount`（非負整數，舊檔為 0），建立快照寫入、讀檔正規化。
- `core/managers/GameSession.ts`：`legacyCount` 狀態；`applyLegacyAchievements(achievements)` 入帳、累加次數、自動存檔；快照／還原／新遊戲重置。
- 測試：`tests/LegacyAchievement.test.ts` 加入獎勵入帳案例；`tests/LegacyRewardWiring.test.ts`（新）：session 入帳與存讀往返。

## 暫定
- 錢包為 null（尚未寫入存檔）時，以 STARTER_GACHA_WALLET 為基底入帳，避免只剩靈玉、其餘歸零。
- Legacy_Count 為玩家層級次數（規格 留存系統 §存檔欄位，未註明層級，暫定玩家層）。

## 不在本卡
- 成就 UI 與播報。
- 把 RET-07 接到實際的結緣／子嗣事件（事件呼叫端另卡）。

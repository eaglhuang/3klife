# [PROG-2-0532] 戰法槽位依智力計算（NUR-10 部分）

## 來源
- WBS v7 NUR-10「戰法學習 TP 門檻與戰法槽位（INT/30）」。
- 規格：培育系統.md §F-7 戰法槽位。

## 範圍
- `core/systems/TacticLoadout.ts`（新，純邏輯）：`tacticLoadoutCapacity(int)`、`TACTIC_LOADOUT_MAX = 4`。
- `tests/TacticLoadout.test.ts`（新）：各智力區間的槽位數、上限、非法輸入。

## 規格衝突與暫定
- §F-7 的公式寫 `max(1, floor(INT / 30))`，但表格與註解寫「智力 30~59 為 2 槽、90~99 為 4 槽」，兩者不一致（公式在 30~59 給 1 槽）。
- 本卡採表格與註解：`1 + floor(INT / 30)`，上限 4。待 PM 確認。

## 不在本卡
- 戰法學習的 TP 門檻：規格只給戰法的 TP 消耗（例如空城計 55 TP），沒有「學習門檻」的定義，待 PM 裁定。
- 戰法槽位接到培育 UI 與存檔。

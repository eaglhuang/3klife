# [PROG-2-0543] 自動培育（NUR-14）

## 來源
- WBS v7 NUR-14「自動培育（解鎖條件、0.7 懲罰、評級上限 A、無事件）」。
- 規格：培育系統 shard-a「自動培育限制條件」、shard-b F-5（AUTO_PENALTY 0.7、AUTO_TP_PENALTY 0.5）。
- PM 暫定（2026-10-14，記入待辦）：
  - 解鎖：主線第一次通過培育季後解鎖。
  - 消耗：每次自動培育消耗 1 張自動培育券，執行一整季。
  - 排程：沿用玩家上一次的手動排程；沒有排程時平均分配到最低屬性。

## 範圍
- `core/systems/NurtureSystem.ts`：`executeRound` 加 `options.auto`（不擲事件骰、獲取量 ×0.7、教官 TP 加成 ×0.5）；`computeTpGain` 加 scale。
- `core/systems/AutoNurture.ts`（新，純邏輯）：解鎖判定、券扣除、評級上限 A、排程解析、整季執行。
- `tests/AutoNurture.test.ts`（新）。

## 暫定
- 「平均分配到最低屬性」解讀：取實力最低的屬性（同值全部納入），依序輪流分配回合。
- 手動排程需為 36 回合完整陣列才採用，否則視為沒有排程。

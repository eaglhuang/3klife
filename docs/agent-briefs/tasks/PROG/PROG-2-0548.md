# [PROG-2-0548] 自動培育接線到 GameSession（NUR-14 接線）

## 來源
- NUR-14 純邏輯（PROG-2-0543）與存檔欄位（PROG-2-0544）已完成，但遊戲端仍無法啟動自動培育。
- PM 指示（2026-10-15）：已完成純邏輯但缺 cc 接線的功能，寫好接線並列 Codex 驗收步驟。

## 範圍
- `core/managers/GameSession.ts`：`runAutoNurture(childId, manualSchedule?, random?)`。流程：解鎖 → 券 → 找會話（須進行中）→ 解析排程（沿用手動排程，否則平均分配到最低屬性）→ 扣券 → 跑完整季 → 寫回培育狀態並自動存檔。
- `tests/AutoNurture.test.ts`：接線測試（未解鎖、無券、成功扣券跑滿 36 回合、找不到會話）。

## 暫定
- 手動排程由呼叫端傳入（上一次手動排程的保存位置由 UI 決定，尚未實作）。
- 亂數預設 Math.random，正式版待 Q25 亂數存檔規則接上。

## Codex 驗收步驟（cc 畫面線，待實機）
1. 進入培育畫面，手動培育一季（36 回合）後到達「主線通過培育季」的條件（或用測試存檔把 mainlineNurtureClearedOnce 設為 true）。
2. 在存檔中給自動培育券 ×1（grantAutoNurtureTickets）。
3. 在培育畫面啟用「自動培育」按鈕，應呼叫 runAutoNurture；成功後培育狀態變為完成，券數減 1。
4. 無券或未解鎖時，按鈕應顯示對應原因（LOCKED / NO_TICKET），不扣券。
5. 完成後進入畢業，評級不得為 S（上限 A）。

## 不在本卡
- 培育畫面的自動培育按鈕與文案（cc 畫面線，由 Codex 接）。

# [PROG-2-0549] 培育畫面自動培育按鈕（NUR-14 cc 接線）

- PM 指示（2026-10-15）：培育畫面的「自動培育」按鈕 cc 接線照寫，雲端不能建置，Codex 只做實機驗收。
- 依賴 PROG-2-0548（GameSession.runAutoNurture）。

## 範圍
- `ui/core/NurtureFlowController.ts`：新增可選依賴 `autoNurture`、方法 `autoNurture()`；訓練期 `btnAutoNurture` 可按；被擋下時提示對應文案（LOCKED / NO_TICKET / NOT_NURTURING / SESSION_ENDED）。
- `ui/scenes/LobbyScene.ts`：綁 `btnAutoNurture`，依賴接 `services().session.runAutoNurture`。
- `assets/resources/ui-spec/layouts/nurture-flow-main.json`：trainBlock 內新增 `btnAutoNurture`（位於休息按鈕下方）與 `autoNurtureLabel`。
- `tests/NurtureFlow.test.ts`：兩案（預設不可按；NO_TICKET 提示文案）。

## 暫定
- 自動培育沿用 GameSession 的排程解析（沒有手動排程時平均分配到最低屬性）；手動排程的保存位置尚未實作。
- 按鈕版面沿用 `nurture.button.rest.bg` 皮膚，位置為暫定，實機可調整。

## Codex 驗收步驟（實機）
1. 進入培育畫面，該子嗣在培育中時，「自動培育整季」可按；未培育時不可按。
2. 未通過主線培育季時按下，提示「尚未解鎖自動培育」，券數不變。
3. 已解鎖但券為 0 時按下，提示「沒有自動培育券」，券數不變。
4. 已解鎖且有券時按下：券減 1，培育進入可畢業狀態，提示「自動培育完成（36 回合）」。
5. 畢業後評級不得為 S。
6. 按鈕位置與文字在實機版面是否擠到「放棄培育」，若擠到請回報，由 cc 端調整。

# [PROG-2-0550] 遺傳因子槽 GeneObject（GEN-02）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0550 |
| 負責 Agent | claude-code-haiku-5.5 |
| 關聯 | WBS v5 GEN-02（P0，僅資料）、FBR-02 歸養成線 |

## 完整描述
武將系統規格要求每位武將有 3~5 個 GeneObject（Type/ID/Level/Is_Locked/Discovery_Level）。資料現況：235 位武將中只有 5 位有 genes，其餘 230 位沒有；有的 genes 欄位名稱與規格不同（displayName、isLocked 與 discoveryLevel 只有部分有）。

## 設計選擇（我的判斷）
- Type 對應 gene-dictionary 的 color（六色），不採 genes 裡的中文分類（謀略、統率…），那是分類不是顏色。
- ID 必須存在於 gene-dictionary；Level 必須在 1..maxLevel 之間。
- 缺的 isLocked 預設 false，缺的 discoveryLevel 預設 1（與存檔的 optional 欄位規則一致）。
- 數量規則只對「有 genes 的武將」檢查 3~5 個。沒有 genes 的 230 位不算失敗，列為待補，不捏造內容。
- 序列化：正規化後轉 JSON，再讀回應相等。

## 驗收
- 5 位有 genes 的武將通過數量與字典檢查。
- 錯誤路徑：數量不在 3~5、ID 不在字典、等級超過上限、同一武將重複因子。
- 序列化往返一致。

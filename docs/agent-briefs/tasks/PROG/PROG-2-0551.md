# [PROG-2-0551] 稱號系統（GEN-10）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0551 |
| 負責 Agent | claude-code-haiku-5.5 |
| 關聯 | WBS v5 GEN-10（P0，僅資料）、MVP-01（PR #218） |

## 完整描述
規格：Template_ID 加 Title 辨識同名不同版本的武將。WBS 驗收：所有武將有 title，UI 顯示「名稱・稱號」。資料現況：235 位都有 title，沒有同名武將，Template_ID 也都唯一。本卡做純邏輯部分：顯示格式、同名辨識與資料檢查。UI 的 View 接線不在本卡範圍。

## 設計選擇（我的判斷）
- 顯示格式：有稱號時「名稱・稱號」，沒有時只顯示名稱。稱號保留資料原文（例如【魏武】），不另行去括號。
- 同名武將：若有兩位以上同名，顯示時要帶稱號辨識；本卡只檢查「同名的稱號不可相同」與「Template_ID 不可重複」。
- 資料缺稱號只回報，不會阻止其他檢查。

## 驗收
- 235 筆武將都有 title；Template_ID 不重複。
- 同名武將的稱號相同會回報；空稱號會回報。
- 有稱號與無稱號的顯示格式正確。

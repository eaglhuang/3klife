## 完整描述
規格：Role 只有 Combat（戰鬥武將）與 Mentor（專業教官），加入時決定、不可更改。資料現況：role 欄位有 8 種值（Combat 107、Support 94、Commander 17、Hybrid 9、Warrior 3、Advisor 2、Noble 2、Planner 1），沒有統一。

## 設計選擇（我的判斷）
- Support → Mentor：規格名詞表寫「教官 = Mentor / Support」。
- Combat、Commander、Warrior、Hybrid → Combat：都是上戰場的武將。這是我的判斷，待企劃確認。
- Advisor、Noble、Planner：規格沒有定義，不猜。回報為「待裁決」，不算錯誤也不歸類。
- 不可變更：角色一旦定下就保留原值（對應「加入時決定不可更改」），不因為之後的資料值而改掉。

## 驗收
- 已知值正確歸類，未知值回報而不歸類。
- 已定下的角色不會被新值覆蓋。
- 235 筆資料的歸類結果可統計。

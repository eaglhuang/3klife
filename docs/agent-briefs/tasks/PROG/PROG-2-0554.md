# [PROG-2-0554] 六色屬性年齡修正接上戰力與武將詳情（GEN-11 接線）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0554 |
| 負責 Agent | claude-code-haiku-5.5 |
| 關聯 | PROG-2-0553（GEN-11 純邏輯，#227）、GEN-10 稱號格式（#222，已合併） |

## 完整描述
PM 指示（04:43Z）：GEN-11 成長曲線要接到戰力計算與武將詳情。
現況：`calculateBattlePowerRating` 已用 `AGE_MODIFIER[general.agePhase]`，但唯一的呼叫端 `SortiePrediction` 把 agePhase 寫死為 `'Prime'`，武將年齡完全沒進戰力。武將詳情的年齡欄只顯示壽命文字，沒有階段。

## 設計選擇（我的判斷）
- 戰力：`SortiePrediction` 用 `agePhaseOf(g.age)` 取階段；`age` 不是數字時退回 `'Prime'`（舊行為）。不在戰力函式內重複乘係數，避免雙重計算。
- 詳情：`GeneralGrowth` 新增 `agePhaseLabel(age)`，武將詳情年齡欄追加階段名稱（純文字，不改數值）。
- 本卡不改 `applyAgeToStats` 的顯示數值，六色面板的修正數值另案決定。
- GEN-11 純邏輯檔以 #227 同內容帶入本分支，不堆疊 #227 分支。

## 驗收
- 老年武將的粗估戰力低於壯年同屬性武將；未填年齡維持舊值。
- 階段標籤與 agePhaseOf 一致。
- run-cli 全部通過；compute gate standard 通過。

## 完整描述
規格（戰法系統.md G-3）：趙家槍法對前方直線連續三格，對路徑上所有敵軍依序進行三次獨立攻擊結算，係數 1.0 / 1.2 / 1.4 遞增。
現況：profile 為直線 4 格、只結算一次。三段遞增沒有實作。血統限制已在 BloodlineTacticAdapter 完成，本卡不動。

## 設計選擇（我的判斷）
- 新增 profile 欄位 `hitStageMultipliers`；只有趙家槍法設定，其他技能不變。
- 直線長度改為 3 格（規格原文「連續三格」）。
- 多段結算不使用 linear-step 衰減（falloffRule 改 none），避免與規格的 1.0/1.2/1.4 疊加。
- 段間死亡的目標跳過，與既有行為一致。
- 係數 0.8 維持原值，規格只定義段間遞增，未改基礎係數。

## 驗收
- 直線 3 格、三段係數 1.0/1.2/1.4。
- 單一目標三段依序結算，第二段 = floor(第一段 ×1.2)，第三段 = floor(第一段 ×1.4)。
- run-cli 全部通過；compute gate standard 通過。

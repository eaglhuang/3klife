## 完整描述
規格：放入男女雙方即時預覽 EP 與祖譜。
現況：`BreedingService.previewEp` 已能算出 EP 拆解（共鳴、異脈、契合、天命、最多共鳴標籤、評級），但沒有給畫面用的文字，畫面端無從顯示。

## 設計選擇（我的判斷）
- 新增純邏輯 Presenter `BreedingPreviewPresenter`，只把 `EpBreakdown` 轉成文字行，不碰節點，沿用 EnvScoutPresenter 的寫法。
- 天命 fate 為 0（預覽不擲骰）時不顯示天命行，避免誤導玩家以為已有波動。
- 沒有共鳴標籤時顯示「無共鳴標籤」。
- 雙方 14 人樹的縮圖屬於版面節點工作，本卡不做。

## 驗收
- EP 行、三項拆解行、標籤行格式正確。
- fate 為 0 時不出現天命行；fate ≠ 0 時出現。
- 沒有共鳴標籤時顯示「無共鳴標籤」。
- run-cli 全部通過；compute gate standard 通過。

## 完整描述
規格（兵種（虎符）系統.md、虎符星級養成系統）：
- 虎符初始 1★，上場戰鬥累積虎符經驗，達門檻自動升星：2★ 需 100 經驗、3★ 需 350 經驗。
- 每場經驗：勝利 +15、敗北 +8、平手 +10。
- 品質封頂：R 最高 3★、SR 最高 4★、SSR 最高 5★、UR 最高 5★。戰鬥經驗只負責 1~3★，4★ 以上需突破（另案）。
- 星級倍率：攻防 = 1 + 星 × 0.08（1★=1.08 … 5★=1.40）。

## 設計選擇（我的判斷）
- 純邏輯模組，沿用既有 TigerTally 的寫法；不改存檔欄位，只提供計算函式。
- 戰鬥經驗經 `Math.round`，敗北 15×0.53=7.95 → 8、平手 15×0.67=10.05 → 10，與規格文字一致。
- 戰鬥經驗升星上限取 min(3, 品質封頂)，R 虎符最多 3★，SR 以上最多 3★（4★ 以上不由戰鬥經驗升）。
- 經驗一次可跨越多個門檻，循環升到能到達的最高星。

## 驗收
- 星級倍率 1★~5★ 為 1.08~1.40。
- 勝/敗/平經驗為 +15 / +8 / +10；100 經驗升 2★，350 經驗升 3★。
- R 虎符不超過 3★；SR 以上戰鬥經驗最多到 3★。
- 單次經驗跨過多個門檻時正確升到最高星。
- run-cli 全部通過；compute gate standard 通過。

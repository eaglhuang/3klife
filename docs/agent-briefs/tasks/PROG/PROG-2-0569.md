# [PROG-2-0569] 戰法條件觸發 TCOND 評估器（TAC-07）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0569 |
| 負責 Agent | claude-code-haiku-5.5 |
| 關聯 | WBS v6 TAC-07（M7，P1，純邏輯）；TAC-01 統一戰法請求（已接線）；戰法系統.md §G-6-1 `TCOND` |

## 完整描述
規格：`TCOND` 為條件觸發，包含鄰格條件、天氣條件、兵種條件。WBS 驗收：騎兵戰法帶步兵不可發動的兵種限制有測試。
現況：`TCOND` 沒有實作，戰法無法依鄰格、天氣、兵種判斷能否發動。

## 設計選擇（我的判斷）
- 新增純邏輯模組 `TacticCondition`，提供 `evaluateTacticConditions(conditions, context)`：所有條件都要成立才可發動（AND），沒有條件時視為可發動。
- 三種條件：
  - 兵種：施放者兵種必須在允許清單內（例：騎兵戰法限制騎兵）。
  - 天氣：當前天氣必須在允許清單內。
  - 鄰格：周圍格子中，我方（或敵方）單位數至少達到門檻。
- 隱身忽略索敵沿用既有 `stealthOpenTurns`，本卡不另改。
- 單一條件失敗時回傳失敗原因，供 UI 提示。

## 驗收
- 騎兵戰法帶步兵（不在允許清單）時不可發動，騎兵可發動。
- 天氣不符時不可發動。
- 鄰格敵方數量不足門檻時不可發動，達到門檻可發動。
- 沒有任何條件時可發動。
- run-cli 全部通過；compute gate standard 通過。

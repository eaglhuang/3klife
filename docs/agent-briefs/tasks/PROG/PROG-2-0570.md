# [PROG-2-0570] 虎符陣容 Set 羈絆判定與攻防加成（TRP-14）

## 完整描述
規格：同一場戰中，相同 Set 的虎符部隊在場達到門檻即觸發攻防加成。跨主將、副將、好友武將都計入；出征前的參謀與補給副將不算。同一 Set 只加一次，不疊加。

| Set | 成員數 | 需在場 | 攻 | 防 |
|---|---|---|---|---|
| 五虎將 | 5 | 3 | +10% | +10% |
| 江東十二虎臣 | 4 | 3 | +10% | +5% |
| 曹魏五謀 | 5 | 3 | +8% | +8% |

## 設計選擇（我的判斷）
- 純邏輯模組，輸入為在場虎符部隊 ID 清單，不依賴戰場單位，因此不需要等 TRP-04 的正式 ID 資料。
- 同一 Set 只算一次；達到門檻才列為成立。
- 多個不同 Set 同時成立時採加法疊加（PM 裁定，不相乘）：每個 Set 貢獻 (加成 − 1)，合計後加回 1。
- 攻防加成只回傳倍率，不直接改單位數值，由戰場端套用。

## 驗收
- 五虎將 3 個成員在場觸發，2 個不觸發。
- 江東十二虎臣與曹魏五謀的門檻與加成正確。
- 同一 Set 的重複成員不重複計算。
- 兩個不同 Set 同時成立時，攻防加成加法疊加（PM 裁定）。
- run-cli 全部通過；compute gate standard 通過。

## 完整描述
PM 裁定：虎符星級存在玩家卡組的每張卡實例上（`stars` + `battleExp`），隨卡組存檔，缺欄位預設 1★ / 0 經驗。
本卡做的是資料面：卡片欄位、讀取預設、存檔正規化，以及寫回經驗的純函式。戰場結算與攻防套用留待下一步。

## 設計選擇（我的判斷）
- `TigerTallyCard` 新增可選的 `stars`、`battleExp`，舊卡不改寫。
- 讀取時 `readCardStarState` 處理缺欄位與超界值：星級夾到 1~5，經驗負值或非有限值回 0。
- `normalizeTallyCardsMap` 在存檔讀回時補上預設值，讓之後的讀取不用再猜。
- `applyBattleExpToCard` 回傳要寫回的兩個欄位，由呼叫端決定何時寫入。

## 驗收
- 缺欄位讀回 1★ / 0 經驗。
- 超界星級與異常經驗會被修正。
- 勝利經驗寫回卡片，累積到門檻升星；R 虎符不超過 3★。
- 存檔正規化補上星級欄位。
- run-cli 全部通過；compute gate standard 通過。

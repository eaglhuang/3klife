# [PROG-2-0573] 虎符戰後經驗與戰法發動條件接線（TRP-10 / TAC-07 接線第二步）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0573 |
| 負責 Agent | claude-code-haiku-5.5 |
| 關聯 | TRP-10（PROG-2-0568 / PROG-2-0571）、TAC-07（PROG-2-0569 / PROG-2-0572） |

## 完整描述
1. 戰後：出陣過的虎符依戰場結果累積戰鬥經驗，達門檻自動升星，寫回卡片實例並存檔。
2. 星級攻防：出陣的虎符單位，攻擊與防禦乘上 `1 + 星 × 0.08`。
3. 戰法發動：戰法的 `tcond` 在發動前檢查，不成立時不扣資源、不進入執行器。
4. QA 複查：`readCardStarState` 依品質封頂夾限（R 最高 3★）。

## 設計選擇（我的判斷）
- 結算只看 `player-win` / `enemy-win` / `draw`（`ongoing` 不結算），對應 win / lose / draw。
- 戰場只帶虎符 id；星級由場景從玩家卡組讀取後注入控制器，查不到卡時 1★。
- 武將施放的戰法沒有兵種，兵種條件略過，天氣與鄰格條件照常檢查。

## 驗收
- 勝利經驗寫回出陣卡片、升星；未出陣卡片不受影響；ongoing 不結算。
- R 虎符讀回時最高 3★。
- 戰法條件不成立時，攻擊路徑回傳 `condition-restricted`。
- run-cli 全部通過；compute gate standard 通過。

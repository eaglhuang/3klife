# [PROG-2-0577] 位移格受阻扣血接進戰場（GRD-03 接線）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0577 |
| 負責 Agent | claude-code-haiku-5.5 |
| 關聯 | PROG-2-0576（位移判定純邏輯與受阻傷害比例）；BattleAutoMovePhase.forceMoveUnit |

## 完整描述
PROG-2-0576 的純邏輯合併後，接進 `forceMoveUnit`：推移格數由 `resolveForcedMove` 決定，受阻時依剩餘步數扣最大 HP 的 5%（上限 20%）。

## 設計選擇（我的判斷）
- 扣血走 `applyForcedMoveDamage` 注入，phase 不直接碰戰鬥結算；沒注入時受阻只停下，與舊行為一致。
- `damageSource: 'forced-move'`，沒有攻擊方，不觸發傷害連結。
- 位移事件（UnitMoved）與原本相同，只是格數改由純函式決定。

## 驗收
- 無受阻的推移行為與原本相同。
- 受阻時扣血 = 最大 HP × min(0.2, 剩餘步數 × 0.05)。
- run-cli 全部通過；compute gate standard 通過。

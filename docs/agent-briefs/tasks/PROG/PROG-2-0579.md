# [PROG-2-0579] 出陣虎符帶持有卡實例 uid（QA 最高優先修正）

## 基本資訊
| 欄位 | 值 |

## 問題
出陣時 DeployPanel／DeployComposite 只帶目錄 `tacticId`，但 `tallyInfoOf`（星級、templateId）與 `_settleTallyBattleExp`（戰後經驗）都用 `session.tallyCards` 的實例 uid 查，兩邊對不上，星級恆 1★、經驗不累積、Set 拿不到 templateId。

## 做法
- `TallyCardData` 新增 `instanceUid`。
- `bindHeldTallyInstances(cards, held)`：手牌依 `unitType` 取第一張尚未綁定的持有實例（uid 字典序，結果穩定），每張實例只綁一次；綁不到就不設 `instanceUid`。
- `tallyDeployRefOf(card)`：`cardUid = instanceUid ?? tacticId`，`templateId = tacticId`。
- 面板改存 `TallyDeployRef`；`BattleController.bindTallyAffinity` 用 `cardUid` 查星級與經驗、用 `templateId` 查目錄適性。
- BattleScene 建手牌時套用 `bindHeldTallyInstances`。

## 驗收
- 同兵種手牌綁到持有實例 uid；多出的手牌與兵種不符的持有卡不綁。
- 回歸：手牌選到的 id 一定是 `session.tallyCards` 的鍵，出陣戰勝後 SSR 90 經驗 → 2★、105 經驗（`tests/TallyInstanceDeploy.test.ts`）。
- run-cli 全部通過；compute gate standard 通過。

# [PROG-2-0582] 虎符卡兵種補齊

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0582 |
| 負責 Agent | claude-code-haiku-5.5 |
| 關聯 | PROG-2-0579（實例綁定只能綁同兵種的持有卡） |

## 問題
死亡產出的虎符卡 troopType 是選填，沒有兵種的持有卡永遠綁不上手牌。

## 做法
- 死亡結算前，武將的 troopType 缺值時由 troopAptitude 推出主兵種（`mainTroopTypeOf`）。
- 讀檔後，缺 troopType 的虎符卡依來源武將（名冊中 uid 或 id 相符）回填（`backfillTallyTroopTypes`）。

## 驗收
- 主兵種規則與同等級排序有測試。
- 死亡產卡帶 troopType。
- 讀檔回填不改動已有兵種的卡、不改動傳入物件。
- 回填後的舊卡能綁上同兵種手牌。

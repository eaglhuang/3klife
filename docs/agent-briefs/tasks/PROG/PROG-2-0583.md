# [PROG-2-0583] 修 master 上 BattleController 的匯入錯誤

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0583 |
| 負責 Agent | claude-code-haiku-5.5 |

## 問題
- `BattleController` 從 `BattleState` 匯入 `TerrainGrid`，但 `BattleState` 沒有 re-export。
- `BattleController` 使用 `BattleResult` 卻沒有匯入，該型別定義在 `battle/BattleTypes`。

## 做法
- `BattleState.ts` 加 `export type { TerrainGrid }`。
- `BattleController.ts` 從 `../BattleTypes` 匯入 `BattleResult`。

## 驗收
- 兩類錯誤從 typecheck 消失。
- run-cli 全部通過。

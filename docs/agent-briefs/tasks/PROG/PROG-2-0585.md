# [PROG-2-0585] 戰法傷害投射模組代號對應（TAC-0001 第一片）

## 開單原因
協調者 PM 裁定：P0 優先。SYS-SKILL-TAC-0001（傷害投射包）的 TDIR／TLINE／TFAN 代號在程式裡沒有對應，卡上的覆蓋清單也沒有反映已落地的戰法。本卡是拆出的第一片。

## 規格依據
- 戰法系統規格 G-6-1：`TDIR` 單體直接傷害、`TLINE` 直線多段、`TFAN` 扇形／範圍 AOE。

## 做法
1. 新增 `assets/scripts/battle/skills/BattleSkillModuleTags.ts`：`damageModuleTagOf(profile)`，把 `targetMode` 對到 TDIR／TLINE／TFAN，其餘形狀回 null。
2. 只做代號對應，不改施放、選區與傷害結算；既有 target selector 與傷害 resolver 不動。
3. `tests/BattleSkillModuleTags.test.ts`：三種形狀對應、非傷害形狀不帶代號、已落地戰法（無視防禦、百步穿楊、趙家槍法、無雙亂舞）對到正確代號。

## 如何驗證
1. `tests/BattleSkillModuleTags.test.ts` 通過。
2. run-cli 全綠；compute-gate standard。

# [PROG-2-0586] 增益治療減益模組代號對應（TAC-0002 第一片）

## 開單原因
PM 裁定 TAC-0001 第一片（PROG-2-0585，#564 已合併）之後接 TAC-0002（增益、治療、減益）。TAC-0002 卡上多項標為「未開始」或「進行中」，但程式中已有對應 profile，需先把代號對應寫進程式並釘住。

## 規格依據
- 戰法系統規格 G-6-1：`THEAL` 治療、`TBUFF` 增益、`TDEBUFF` 減益。

## 做法
1. `assets/scripts/battle/skills/BattleSkillModuleTags.ts` 新增 `statusModuleTagOf(profile)`：`heal` → THEAL、`morale` → TBUFF、`slow`／`dot` → TDEBUFF，其餘回 null。
2. `tests/BattleSkillStatusModuleTags.test.ts`：效果種類對應、非狀態形狀不帶代號、已落地戰法（鼓舞、緩速、毒箭）對到正確代號。
3. 只做代號對應，不改 buff／heal／debuff 的結算。

## 如何驗證
1. `tests/BattleSkillStatusModuleTags.test.ts` 通過。
2. run-cli 全綠；compute-gate standard。

## 缺口（不在本卡）
- 醫療（教官，SingleAlly，THEAL）：戰法 profile 表沒有項目，需另卡補上。
- 單騎破陣（教官，Self，TBUFF+TCOND）：只有攻擊倍率公式（`SkillEffectFormulas.ts` 單騎破陣 ×1.3），沒有 profile，需另卡接線。
- 仁德號召（`liu-bei-rally`）為 heal 類，規格表上沒有對應名稱，待核對。
- 八陣圖的 TBUFF 段與 TTILE 段，TTILE 歸 TAC-0003。

## 交付物
- `assets/scripts/battle/skills/BattleSkillModuleTags.ts`、`tests/BattleSkillStatusModuleTags.test.ts`、本卡。

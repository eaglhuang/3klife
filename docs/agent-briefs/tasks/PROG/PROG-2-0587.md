# [PROG-2-0587] 戰法代號接上施放流程，並校正卡上狀態

## 開單原因
QA 指出 PROG-2-0585（#564）與 PROG-2-0586（#570）的代號對照沒有呼叫端，WBS 不會算已接線。PM 要求 TAC-0003 前先接上，並更正卡上與程式不符的狀態。

## 做法
1. `BattleSkillExecutor.execute` 依請求的 profile 填入 `moduleTags`（選填欄位，定義在 `shared/SkillRuntimeContract.ts`）。目前含傷害投射代號（TDIR／TLINE／TFAN）。
2. `moduleTagsOfSkill(profile)`：由 PROG-2-0585 的 `damageModuleTagOf` 組出清單。
3. 測試用固定的 stub resolver 驗證：無視防禦回報 TDIR，增益戰法回報空清單。
4. 更正測試名稱：lu-bu-rampage 的遊戲內名稱是「天下無雙」，不是「無雙亂舞」。
5. 更正卡上狀態：SYS-SKILL-TAC-0001 的威震華夏改為已落地，精銳突擊改為進行中（形狀與規格不符）；SYS-SKILL-TAC-0002 的毒箭 DOT、幼麒天算 Weak 改為已落地。

## 如何驗證
1. BattleSkillModuleTags 測試通過（含施放執行器回報代號）。
2. run-cli 全綠；compute-gate standard。

## 缺口（不在本卡）
- 狀態代號（`statusModuleTagOf`，PROG-2-0586，#570）尚未合併，接上施放流程待其合併後補上。
- 精銳突擊的形狀改為直線，另開卡處理。

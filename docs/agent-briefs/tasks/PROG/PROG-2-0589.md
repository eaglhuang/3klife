# [PROG-2-0589] 地格分類器接上移動與回合結束（TAC-0003 第一片）

## 開單原因
TAC-0003 卡上寫的 HAZARD_FIRE、RIVER_CURRENT、HAZARD_ROCK 骨架實際已在程式，名稱為 hazard-fire、river-current、hazard-rock。但 `TileStateRules.ts` 的分類器只有測試在呼叫，src 沒有呼叫端。PM 裁定：兩處都接，不改戰鬥結果；水流時機維持回合結束。

## 規格依據
- 戰場格子規格：落石阻擋（岩石）、水淹七軍的水流推移（敵軍，回合結束）、火場扣血（回合結束）。
- 分類器原本把水流歸為 force-move（進格推移），與實際回合結束推移不符，本卡校正。

## 做法
1. `TileStateRules.ts`：分類改為六類（normal、hazard、river-current、force-move、stealth、blocked）。規則欄位改為 blocksOnEnter、damagesOnTurnEnd、pushesOnTurnEnd、pushesOnEnter、hidesOnEnter。blocksMovement 優先歸 blocked。
2. 移動阻擋：BattleCombatResolver.isCellMovementBlocked 與 BattleSkillDispatcher 的 isCellFreeForPush 改讀 blocksOnEnter。
3. 回合結束扣血：BattleTileEffectPhase 只對 damagesOnTurnEnd 的格子扣 damagePerTurn。
4. 水流推移：BattleTacticBehavior.advanceFloodAttackTurn 改讀 pushesOnTurnEnd（原本比對 state === 'river-current'）。
5. 測試：TileStateRules 測試更新為新分類與時機；既有火燒、水淹七軍、落石的戰鬥測試維持通過，鎖住結果不變。

## 如何驗證
1. TileStateRules 測試通過。
2. run-cli 全綠（既有戰鬥測試鎖住結果不變）；compute-gate standard。

## 缺口
- 無。

# [PROG-2-0591] 夜襲營帳佔領＝勝利

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0591 |
| 關聯 | 戰法場景規格書 §夜襲作戰（特殊規則：營帳為可攻擊目標物，佔領=勝利條件）；PROG-2-0614（SCN-06）；PM 指示「營帳佔領勝利可以另開一張卡」 |

## 現況
- 程式中還沒有營帳實體；`BattleController.checkVictory` 只判斷主將與兵力。
- 夜襲目前只有命中 -25、暴擊 +20 與敵方遠程視野縮短（PROG-2-0614）。

## 待 PM 裁定（實作前必須確定）
1. 佔領的判定：己方單位站上營帳格即佔領，還是營帳血量歸零才算？
2. 營帳的位置與數量：固定在敵方後排一格，還是每場隨機？
3. 營帳是否可被攻擊（規格寫「可攻擊目標物」）？若可攻擊，血量多少、被打後是否也算佔領？
4. 佔領後是立即勝利，還是要站住一回合？

## 暫定做法（PM 未回覆前不實作）
- 營帳以 tile 上的 object 表示，不新增單位類型，避免影響部署與存活判定。
- 勝利條件在 `checkVictory` 加一條：夜襲旗標開啟且己方單位佔據營帳格，回傳勝利。

## 驗收（待裁定後補）
- 佔領條件成立時回傳勝利；未成立時維持原有勝負判定。
- 夜襲以外的戰場行為不變。

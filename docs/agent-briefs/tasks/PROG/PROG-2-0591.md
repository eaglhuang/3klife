# [PROG-2-0591] 夜襲營帳佔領＝勝利

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0591 |
| 關聯 | 戰法場景規格書 §夜襲作戰（營帳為可攻擊目標物，佔領=勝利條件）；PROG-2-0614（SCN-06）；PM 暫定營帳規則（協調者 2026-10-14 19:43Z 轉達）|

## 做法（PM 暫定）
- 營帳是一個不能被攻擊的地形格（tile effect `scene-camp`，不擋移動），固定在敵方後排中央（lane 3、depth 7），每場 1 個。只用於夜襲與埋伏場景。
- 場景資料可用 `BattleController.configureSceneCamp(position)` 覆寫座標（需在 `initBattle` 前呼叫）。
- 我方任一存活單位在回合結束時站在營帳格上，立即勝利，不需要站住一回合。判定在 `resolveCampCapture`，於 `BattleController.resolvePlayerTurn` 結束時檢查。
- 同一 PR 修正落石施放者：`BattleState.sceneCaster`（預設敵方）取代寫死的玩家主將。天命取施放陣營主將基因；沒有主將或沒有天命時為 0。

## 驗收
- 夜襲與埋伏有營帳，一般戰場沒有；營帳不擋移動、每場 1 個。
- 覆寫座標後營帳在指定格。
- 我方單位站在營帳格上回傳勝利；敵軍站上不算。
- 落石施放者為施放陣營（預設敵方），不再寫死玩家主將。

## 缺口
- 營帳 cc 接線已寫（BoardRenderer 的 scene-camp 底色）；實機驗收交 Codex（見下）。

## Codex 驗收需求
- 夜襲與埋伏開場，敵方後排中央（第 4 欄、第 8 排附近）出現營帳底色格。
- 一般戰場不出現營帳格。
- 我方單位走上營帳格並於回合結束時，戰鬥立即以勝利結束。
- 敵軍站上營帳格不觸發勝利。
- 夜襲的其他格子裝飾若與營帳同格，會被營帳覆寫（營帳最後套用）。

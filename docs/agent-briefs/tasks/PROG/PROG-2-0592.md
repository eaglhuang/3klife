# [PROG-2-0592] 格子狀態機底層（GRD-01）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0592 |
| 負責 Agent | claude-code-haiku-5.5 |
| 關聯 | WBS v7 GRD-01；GRD-02（Hazard）、GRD-03（Force-Move）、GRD-04（Stealth）的前置 |

## 做法
- 新增 `battle/shared/TileStateRules.ts`：四類 `TileStateKind`（normal / hazard / force-move / stealth）與每類的進格規則（`damagesOnEnter`、`pushesOnEnter`、`hidesOnEnter`）。
- `tileStateKindOf(effect)` 由既有 `TileEffect` 欄位推導：`damagePerTurn > 0` 為 hazard；有 `forcedMoveDirection` 為 force-move；`ambush-field` 為 stealth；其餘（含 `night-raid`、`scene-camp`）為 normal。
- 本卡不改 runtime 執行路徑，只提供純資料與純函式；GRD-02 之後再接線。

## 驗收
- 四類各有測試案例，覆蓋 fire、rock、river-current、ambush-field、night-raid、scene-camp 的分類。
- 規則表是資料，不寫死在執行路徑。

# [PROG-2-0593] 掩體格隱蔽接進目標選取（GRD-04）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0593 |
| 關聯 | WBS v7 GRD-04；PROG-2-0578（純邏輯 StealthTile.ts 已存在但未接線） |

## 做法
- `BattleCombatResolver` 新增 `isHiddenFromAttacker(attacker, target)`：先沿用既有陣營隱蔽，再看目標所在格是否為 `ambush-field`，並以 `canTargetUnderStealth` 判定（遠程不能鎖定，近戰不受影響）。
- `findCombatTarget` 與 `findAdjacentEnemy` 的隱蔽判定改用攻擊者感知版本。

## 驗收
- 遠程攻擊者不能鎖定站在掩體格的敵軍；近戰仍可攻擊。
- 目標離開掩體格後立即可被鎖定。

## 缺口
- `canAttackGeneral`（武將直接攻擊判定）仍只看陣營隱蔽，尚未套用掩體格。

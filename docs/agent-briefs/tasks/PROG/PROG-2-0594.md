# [PROG-2-0594] 修正 BattleAptitude 測試的重複 import

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0594 |
| 關聯 | Codex 回報（PROG-2-0655 驗收被擋）；PM 指示優先處理 |

## 現況
- `tests/BattleAptitude.test.ts` 同時從 `CommonEnums` 與 `Constants` 匯入 `TerrainType`、`TroopType`，tsc 報 TS2300 重複宣告。
- 執行期（transpile-only）不報錯，所以 run-cli 之前沒擋住。

## 做法
- 移除 `Constants` 那一行多出的 `TerrainType`、`TroopType`，保留 `CommonEnums` 的匯入。

## 另見（未在本卡處理）
- `BattleControllerSkillTargeting` 的「FloodAttack：敵軍會先完成攻擊，再被水流往左推」斷言 striker.depth = 5，但同一地形的「先前進一格再往左推」測試斷言 depth = 4。兩者互相矛盾，且結果會隨 RNG 改變（固定亂數為 0 時失敗；隨機 seed 時偶發）。需 PM／QA 裁定正確行為後再改測試。

## 驗收
- `tsc -p tsconfig.test.json` 不再報 BattleAptitude.test.ts 的重複宣告。
- run-cli 全數通過。

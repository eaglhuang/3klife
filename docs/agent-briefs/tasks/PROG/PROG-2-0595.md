# [PROG-2-0595] 武將直接攻擊判定套用掩體格（GRD-04 缺口）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0595 |
| 關聯 | PROG-2-0593（目標選取的掩體格接線）；PM 指示另開小 PR |

## 做法
- `BattleCombatResolver.canAttackGeneral`：若敵方武將所在格為 `ambush-field`，遠程攻擊者回傳不可攻擊；近戰不受影響。
- 判定沿用 `StealthTile.ts` 的 `isHiddenOnTile` 與 `canTargetUnderStealth`。

## 驗收
- 遠程攻擊者不能直接攻擊站在掩體格的敵方武將；近戰仍可。
- 武將離開掩體格後恢復可攻擊。

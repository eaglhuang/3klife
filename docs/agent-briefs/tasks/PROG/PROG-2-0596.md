# [PROG-2-0596] 場景戰法發動判定（SCN-03）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0596 |
| 關聯 | WBS v7 SCN-03（戰法場景規格書）；SCN-01 場景表尚未落地，本卡只做純函式 |

## 做法
- 新增 `assets/scripts/battle/shared/SceneGambitTrigger.ts`，純函式，不讀場景 JSON。
- `sceneGambitSuccessRate(intelligence, intThreshold)`：`min(0.95, 0.5 + (INT - 門檻) × 0.02)`。
- INT 未達門檻時不可發動（回傳 0），這是本卡的解讀，規格只寫公式；若 PM 另有規定再改。
- `canTriggerSceneGambit(...)`：INT 與情報都達到各自門檻才可發動，回傳成功率；否則 0。
- 情報門檻的數值來源屬 SCN-01，本卡以參數傳入。

## 驗收
- 門檻邊界：INT 等於門檻為 50%；每高 1 點 +2%。
- 上限 95%，不會超過。
- INT 或情報未達門檻，成功率為 0。
- 有單元測試覆蓋上述情況。

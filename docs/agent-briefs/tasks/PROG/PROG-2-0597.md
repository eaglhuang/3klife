# [PROG-2-0597] 天氣禁用戰法：變灰但可點擊，點擊彈 Toast（APT-07）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0597 |
| 關聯 | WBS v7 APT-07；戰場適性系統規格「UI 強約束格式」；PROG-2-0406（天氣強約束）；PROG-2-0408（按鈕可用狀態與原因） |

## 現況
- 純邏輯已完成：`checkTacticWeather`、`buildTacticAvailability`（原因「天氣禁用」）。
- 天氣禁用時 `ActionCommandComposite.setTacticSummary` 把按鈕設為不可互動，`_onTacticsClick` 直接返回，點擊不會進入選戰法流程，所以 Toast 永遠不會出現。
- 規格要求：按鈕變灰（Gray-out）且點擊彈 Toast「當前天氣不符合施放限制」。

## 做法
- 天氣禁用時按鈕保持可點、字色變灰；其他原因（計謀點不足、SP 不足）維持不可點，行為不變。
- 點擊後照常發出 `tactics` 事件，由既有的 `BattleSkillTargetingFlow` 天氣檢查彈出 Toast，不進入選目標。
- 不改 Toast 文字與原因文字（原因仍為「天氣禁用」，依 PROG-2-0408）。

## 驗收（Codex 實機）
1. 雨、霧或雷暴天氣，且我方武將的計謀是火計：計謀按鈕字色變灰，但按鈕可點。
2. 點擊該按鈕：畫面出現 Toast「當前天氣不符合施放限制」，不進入選目標，不扣計點與 SP。
3. 晴天：同一按鈕正常亮色，可照常施放。
4. 計謀點不足或 SP 不足：按鈕仍不可點，原因文字照舊顯示。

## 缺口
- 實機驗收由 Codex 執行（cc 畫面無法在雲端容器跑）。
- 手動點擊路徑（`tactics` 事件後的選戰法流程）只有讀程式碼確認，未在編輯器實測。

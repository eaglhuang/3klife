# [PROG-2-0598] 推薦戰法三態檢核（LVL-04）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0598 |
| 關聯 | WBS v7 LVL-04；關卡設計系統 D-2（必備／高建議戰法）、D-3（三態、不得二元鎖定） |

## 做法
- 新增 `assets/scripts/core/systems/LoadoutCheck.ts`，純函式，不依賴 cc。
- 每關有「必備」與「高建議」兩組需求；當前出征 loadout 以字串 key 表示。
- 三態判定（規格只說三態，以下為本卡解讀）：
  - 已具備：必備與高建議都已涵蓋。
  - 缺少：缺高建議項，但必備都已涵蓋。
  - 高風險：缺任一必備項。
- 不論哪一態都 `canChallenge: true`，不鎖死進場（規格 D-2 第 4 點）。

## 驗收
- 全部涵蓋 → 已具備。
- 只缺高建議 → 缺少，列出缺口 key。
- 缺任一必備 → 高風險，列出缺口 key，仍可挑戰。
- 空的需求清單 → 已具備。
- 結果不含最佳答案腳本（只列缺口名稱）。
- 單元測試覆蓋上述情況。

## 缺口
- 戰前面板 UI（LVL-03）未做，這裡只給資料。
- 「必備」「高建議」的實際戰法 key 來自關卡資料，尚未有資料表；本卡以參數傳入。

# [PROG-2-0599] Boss 親衛隊召喚觸發判定（LVL-11）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0599 |
| 關聯 | WBS v7 LVL-11；關卡設計系統「親衛隊召喚」（呂布、曹操為敵方主將時，血量降至 50% 以下自動召喚親衛隊，阻擋直接斬首） |

## 做法
- 新增 `assets/scripts/core/systems/BossGuardSummon.ts`，純函式。
- `isBossGuardSummonDue(hp, maxHp, isBoss, alreadySummoned)`：
  - 非 Boss、已召喚過、或 maxHp 不合理 → false。
  - `hp <= maxHp × 50%` → true（規格寫「降至 50% 以下」，取含等號）。
- 親衛隊的兵種與站位不在本卡，由呼叫端決定。

## 驗收
- 血量剛好 50% 觸發；高於 50% 不觸發。
- 同一場只觸發一次（alreadySummoned 為 true 後不再觸發）。
- 非 Boss 不觸發。
- 單元測試覆蓋上述情況。

## 缺口
- WBS 原文寫「<50%」，規格寫「50% 以下」，本卡取 ≤ 50%，請 PM 確認。
- 親衛隊單位資料與站位未定，未接 EnemyAI。

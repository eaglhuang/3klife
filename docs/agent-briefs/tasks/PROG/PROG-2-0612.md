# [PROG-2-0612] 戰場端 Mentor 戰法來源轉換（MENT-16）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0612 |
| 負責 Agent | claude-code-haiku-5.5 |
| 關聯 | WBS v7 MENT-16；教官系統（支援卡） |

## 做法
- 盤點：`MentorTacticAdapter` 已存在，但 `SeedTacticAdapter` 未指定戰法時永遠取第一個槽。
- 修正：未指定戰法時，先取第一個 `source: awakened` 槽的 tacticId。
- 測試：awakened 在第二格仍可建出 `SkillSourceType.Mentor`；普通種子戰法與沒有 awakened 槽時回 null。

## 驗收
- awakened 不在第一格時，Mentor 請求仍可建立。
- 指定普通戰法不轉 Mentor；沒有 awakened 槽回 null。

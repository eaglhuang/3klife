# [PROG-2-0613] 紫色因子戰場效果「天命加護」（FBR-10）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0613 |
| 負責 Agent | claude-code-haiku-5.5 |
| 關聯 | 因子爆發系統.md §MCQ Q39（選項 A）；運氣系統.md；WBS v7 FBR-10 |

## 做法
- 純規則模組 `core/systems/FateBlessing.ts`：天命基因 id（`gene_destiny`、`gene_luck`，測試對照字典 purple）、天命等級（持有且未鎖定的最高等級）、加成公式、事件成功判定。
- 火計（fire 標籤戰法）傷害乘上天命加成。
- 落石開場設置前做一次成功判定。

## 數值（PM 暫定，待確認）
- 每級天命加成 5%：成功率 `min(1, base + level × 0.05)`，傷害倍率 `1 + level × 0.05`。
- 落石基礎成功率 85%（PM 裁定 2026-10-14，暫定，天命加成另計）。
- 落石天命吃施放者基因（場景戰法暫定施放者為玩家主將），亂數走戰場種子亂數源，不用 Math.random。
- 火計目前沒有失敗機制，只加傷害。

## 驗收
- 天命等級只看紫色基因，未解鎖或等級 0 不算。
- 火計傷害隨天命等級增加；非火計戰法不變。
- 落石成功率 = 基礎 + 天命加成，上限 100%。

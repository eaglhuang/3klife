# [PROG-2-0614] 暴擊系統與夜襲改寫（SCN-06）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0614 |
| 負責 Agent | claude-code-haiku-5.5 |
| 關聯 | 戰法場景規格書.md §夜襲作戰；WBS v7 SCN-06；PM 裁定 (a) |

## 做法
- 新增純函式模組 `core/systems/CombatCrit.ts`：基礎暴擊率 5%、暴擊傷害 ×1.5，擲骰比照命中（0 與 100% 不耗亂數）。
- 戰法行為新增可選掛點 `getAccuracyDelta`、`getCritBonus`。夜襲實作：命中 -25、暴擊 +20（個百分點，暫定）。
- 夜襲旗標改為整場生效；兩回合窗口只保留敵方遠程視野縮短。移除先制增傷。
- `BattleCombatResolver`：命中加上場景命中加成；傷害結算前做暴擊判定；`hitRandom` 預設改為戰場種子亂數源。

## 驗收
- 基礎暴擊率 5%，夜襲整場 25%，暴擊傷害 ×1.5。
- 夜襲不再有先制增傷；兩回合後仍有命中與暴擊加成。
- 命中與暴擊的擲骰不再使用 Math.random。

## 缺口
- 營帳佔領＝勝利另開卡。
- 暴擊目前沒有事件給 UI 顯示。
- `BattleControllerSkillTargeting` 未在 run-cli 註冊，只能單獨跑；其中 `tryDeployTroop` 騎兵移動距離在 master 就已失敗，與本卡無關。

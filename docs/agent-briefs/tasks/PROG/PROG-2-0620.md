# [PROG-2-0620] 因子媒介注入型別對齊與存讀檔測試

BLT-10 的 `injectCatalystFactor` / `markCatalystUsed` 型別要求 `genes[].id` 必填，而 `GeneralConfig.genes[].id` 是選填，且 `GeneralConfig` 沒有 `catalystUsed` 欄位（弱型別檢查 TS2559），實際接線時要呼叫端強轉。修正：`CatalystInjectable.genes[].id` 改選填（沒有 id 的因子不參與注入）；`GeneralConfig` 新增選填 `catalystUsed`（缺欄位視為未用，舊檔相容）。補測試：注入 → 標記 → 存檔 → 讀檔後標記還在，再注入回 ALREADY_USED 且不擲骰；沒命中也算消耗；機率邊界 0.75。

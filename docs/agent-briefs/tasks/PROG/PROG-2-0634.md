# [PROG-2-0634] 七進七出穿透傷害致死走陣亡流程＋真實戰場回合 E2E

用 BattleController 跑真實玩家回合時發現：七進七出穿透傷害把敵軍打到 0 血後，敵軍仍留在 state.units 與格子上，沒有 UnitDied 事件，若是主將也不會判陣亡。
技能傷害（BattleSkillDispatcher）致死時會呼叫 onGeneralUnitKilled／onUnitKilled，穿透傷害缺這段。修正：BattleController 新增 applyGhostPassDamage，兩個 auto-move 階段共用。

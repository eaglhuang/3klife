# [PROG-2-0640] 修戰場測試偶發失敗

偶發紅的測試靠隨機才過：敵軍隨機部署會佔位／擋路、地塊增益隨機落點、攻擊目標被暴擊打死時敵軍會繼續前進。
測試改成固定亂數源（存檔亂數源 0）並讓敵方糧草歸零；FloodAttack 目標血量加厚到暴擊打不死。
BattleController.randomInt（地塊增益用）從 Math.random 改走 services().session.randomSource（Q25）。

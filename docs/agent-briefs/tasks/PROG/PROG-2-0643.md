# [PROG-2-0643] MVP 迴圈端到端測試與主將指派斷點

端到端：開場流程 → 宿命轉蛋鎖定 → startNewGameWithStarters → 過一季 → 首戰（真的跑 BattleController）→ 戰後結算 → 壽命到退役年齡 → 退役 → 存讀往返。
找到兩個斷點：
1. 修：主將退役或壽終後 leadGeneralId 仍指向教官卡／已故武將，大廳、出征、榜單與同袍關係會用到它。新增 `_clearLeadIfGone`，退役、換季、戰後結算後清掉。
2. 修：宿命鎖定後開新局，核心原本限定 legendary/mythic，六人只有張飛能過，鎖到其他五位會報錯。規格（新手開場 §6）宿命池就是六位初始名將，玩家選誰誰當核心，所以放寬成六位都能當核心；六位以外仍拒絕。
   - 設定現況：gacha-config 的 hero-pool 是 20 位一般名將池（只含 3 位初始名將），十連不重複需 ≥10 人，不能直接當宿命池；接線時另設六人池並把抽數封頂在池子大小。

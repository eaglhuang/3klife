# [PROG-2-0644] 宿命轉蛋六人池接線

規格（新手開場 §6）：宿命池是六位初始名將，玩家選誰誰當核心。
- `DESTINY_POOL_IDS`：六位初始名將。
- `destinyOptionsFromConfig`：沿用 gacha-config 規則，十連抽數封頂在池子大小（否則 pool-too-small）。
- `rollDestinyPool`：對宿命池抽一輪。
- `startNewGameFromDestiny`：鎖定後開新局，鎖誰誰是核心主將；未鎖定或池外拒絕。
不改 hero-pool 設定（它是一般名將池）。UI 開場宿命幕的畫面接線另排。

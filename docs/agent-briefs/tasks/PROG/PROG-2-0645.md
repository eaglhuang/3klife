# [PROG-2-0645] 宿命開場畫面接線

## 範圍
- `DestinyOpeningController`：roll / reset / select / confirm，鎖定後呼叫 `startNewGameFromDestiny`，開局失敗退回已抽未鎖。
- `destiny-opening-main` layout、`destiny-opening-screen`、skin（以紅顏展示為範本）。
- `LobbyScene._mountDestinyOpening`：隱藏掛載，新玩家（`session.load()` 回傳 false）自動開啟；`openDestinyOpening()` 供之後入口使用。

## 暫定決策
1. 真實設定 `confirmRequired=false`：點候選列即鎖定並開局，確認鈕在該設定下不會啟用（設定改 true 才會用到）。
2. 沒有存檔即視為新玩家；之後若要做「重新開始」入口，呼叫 `openDestinyOpening()`。
3. 劇本幕（OpeningFlowController）尚未串入，這張只接畫面與開新局。

## Codex 驗收步驟（Web 版，無存檔）
1. 清除瀏覽器 localStorage / IndexedDB 後進大廳：應自動出現「宿命轉蛋」面板，只有「轉蛋」鈕可按。
2. 按「轉蛋」：出現六列（張飛、魏延、夏侯惇、張郃、孫策、甘寧，順序隨機），「轉蛋」變灰、「重置」可按。
3. 按「重置」：回到未抽，右下「重置 1 次」；再按「轉蛋」可重抽。重複數次應無上限。
4. 點任一列的「選擇」：面板關閉，大廳季度 HUD 正常；進武將列表應為六位初始名將，主將（出戰核心）是剛才點的那位。
5. 重新整理頁面：不再出現宿命轉蛋（已存檔），主將仍是所選。
6. 版面：六列、三顆按鈕、訊息文字不重疊；phone-16-9 / 19.5-9 / tablet-4-3 三種比例都在畫面內。
7. 若有異常請回報截圖與節點座標；只需微調 `destiny-opening-main.json` 的座標，不要改邏輯。

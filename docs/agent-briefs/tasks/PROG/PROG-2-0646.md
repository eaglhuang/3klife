# [PROG-2-0646] 開場劇本幕串進宿命開場

## 範圍
- `createNewPlayerOpeningFlow()`：intro（intro-done 離開）→ destiny（destiny-locked 離開），用既有 OpeningFlowController。
- 第一幕四頁（古文 → 信件「開始宿命轉蛋」→ 像素回憶 → 漩渦），`OpeningIntroController` 逐頁翻。
- LobbyScene：無存檔新玩家先開 intro，翻完開宿命轉蛋，鎖定後幕序結束。

## 暫定決策
1. 第三幕首戰教學由戰場內提示與大廳 3 段式引導負責，不在大廳內推進幕序。
2. 第四幕紅顏需要『首戰已通過』存檔旗標（目前無欄位），這張不自動觸發；紅顏入口仍在轉蛋 Support 分頁。
3. 第一幕台詞為暫定文字，規格 §5.1 只有主軸。

## Codex 驗收步驟（Web，無存檔）
1. 清 localStorage / IndexedDB 進大廳：先出現第一幕「1 / 4」黑底古文，按鈕「繼續」。
2. 依序翻 2 / 4（信件，按鈕「開始宿命轉蛋」）、3 / 4、4 / 4（按鈕「進入宿命」）。
3. 第 4 頁按下後 intro 面板消失、出現宿命轉蛋面板（PROG-2-0645 驗收項接續）。
4. 點選武將後進入大廳，3 段式引導接著出現；重新整理不再出現 intro 與宿命。
5. 版面：文字不溢出卡片、按鈕在卡片內；三種比例皆可。只微調 opening-intro-main.json 座標。

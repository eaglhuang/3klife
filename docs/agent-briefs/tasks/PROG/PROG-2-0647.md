# [PROG-2-0647] 首戰已通過旗標與第四幕紅顏自動觸發

## 範圍
- `resources.firstBattleCleared`：第一次打贏戰鬥（不限關卡）設為 true，只發一次 `FirstBattleCleared` 事件；新局重置。
- `resources.openingRedFaceShown`：紅顏已自動展示過；`shouldShowOpeningRedFace` = 首戰通過且未展示。
- 舊檔（欄位缺席）：有通關紀錄 → 首戰通過＝true、紅顏已展示＝true（老玩家不補彈）；沒有紀錄 → 都 false。
- PlayerSaveService：這兩個欄位缺席時保持缺席，才能區分舊檔。
- LobbyScene：掛載紅顏展示後，若該彈就開啟並標記已展示。

## Codex 驗收步驟（Web）
1. 新存檔打贏第一場戰鬥回大廳：自動出現「紅顏池・展示」面板，可按「關閉」。
2. 關閉後重新整理或再進大廳：不再自動彈出（紅顏入口仍可手動開）。
3. 打輸首戰回大廳：不彈。
4. 用已有通關紀錄的舊存檔進大廳：不彈。

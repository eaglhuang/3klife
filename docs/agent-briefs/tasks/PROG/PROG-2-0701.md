# [PROG-2-0701] 教官卡詳情三頁籤（MENT-13）

## 來源
- WBS v8 MENT-13（M10 P0，ui，工時 3.0，依賴 MENT-06）。
- 規格：教官系統（支援卡）§F-1 頁籤結構、§F-4 星等表與鎖頭、UI 字串表 UI_CARD_TAB_* / UI_STAR_LOCKED。

## 範圍
- `core/systems/MentorCardTabs.ts`（新，純邏輯）：`buildMentorCardTabView` 回傳頁籤、目前列與各列鎖頭；`eventGroupRequiredStar`、`clampMentorStar`。
- `tests/MentorCardTabs.test.ts`（新）：7 案。

## 暫定
- 事件組 n 需 ★(n-1)，依規格 §F-4 表格推算（★0 組 1，★4 組 1–5，★5 全部）。
- 小插曲不套星等鎖頭（規格只寫支援效果與培育事件）。

## Codex 驗收步驟（cc 畫面線，待實機）
1. 開啟任一教官卡詳情，三個頁籤依序為「支援效果」「培育事件」「小插曲」。
2. ★0 的卡，培育事件頁只有第 1 組可看；其餘列顯示鎖頭與「需達 ★N 才可發動」。
3. 突破到 ★5 後，培育事件頁全部解鎖。
4. 切換頁籤時列內容對應切換，不殘留前一頁資料。

## 不在本卡
- 教官卡詳情頁面的 cc 版型與節點綁定（Codex 實機接）。

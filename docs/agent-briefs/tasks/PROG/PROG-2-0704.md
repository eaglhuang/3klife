# [PROG-2-0704] 教官詳情入口（MENT-13 入口）

## 來源
- PROG-2-0703 已掛載詳情畫面，但沒有任何入口。
- PM 指示：入口方案為培育畫面教官槽可點開詳情；本卡先做最小入口，見「暫定」。

## 範圍
- `core/systems/MentorCardTabs.ts`：`mentorToCardData`，培育教官 → 詳情資料（星等、支援效果一列）。
- `ui/core/NurtureFlowController.ts`：`mentorDetail()` 回傳第一位教官的標題與詳情資料；view 新增 `btnMentorDetail`（有教官時可按）與 `mentorDetailLabel`。
- `layouts/nurture-flow-main.json`：新增 `btnMentorDetail` 按鈕（trainBlock 內，AutoNurture 按鈕右側）。
- `ui/scenes/LobbyScene.ts`：綁 `btnMentorDetail`，呼叫 openMentorCardDetail。
- `tests/MentorCardTabs.test.ts`：新增 mentorToCardData 案。

## 暫定
- 入口先開目前子嗣的第一位教官，不是逐槽點擊：槽位節點目前是純文字 label，要逐槽點擊需改版面，留到後續卡。
- 事件與小插曲資料尚未進培育 session，詳情頁目前只顯示支援效果一列。

## Codex 驗收步驟（實機）
1. 有子嗣在培育中且已有教官時，「教官詳情」可按；沒有教官時變暗。
2. 按下後開啟詳情，標題為該教官名字，支援效果頁顯示「專長　TP 加成 +N%」。
3. 關閉後回到培育畫面，不影響培育狀態。
4. 按鈕位置是否與「自動培育整季」擠在一起，若擠到請回報，由 cc 端調整。

## 不在本卡
- 逐槽點擊的教官槽入口、事件與小插曲資料接入。

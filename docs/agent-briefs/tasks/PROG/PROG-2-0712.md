# [PROG-2-0712] 武將血脈頁顯示覺醒隱藏因子

## 來源
- REC-06 覺醒（PR #633）寫入的隱藏因子 gene，需要在武將詳情的血脈頁看得到。
- 規格：武將戰績系統.md §里程碑（不敗神話、守護之壁、修羅 → 隱藏白／紅因子）。

## 範圍
- `ui/core/HiddenFactorText.ts`（新，純邏輯）：`hiddenFactorLine(genes, lookup)`，列出已覺醒名稱、同名去重，沒有時顯示「尚未覺醒」；語系表查不到時退回 zh-TW。
- `ui/components/general-detail/GeneralDetailBloodlineChild.ts`：掛上 `HiddenFactorCard/HiddenFactorValue`，在 `onDataUpdate` 寫入一行。
- `assets/resources/ui-spec/fragments/layouts/gd-tab-bloodline.json`：在 AwakeningCard 下方加 HiddenFactorCard。
- `assets/resources/i18n/{zh-TW,zh-CN,en,ja}.json`：`ui.general.bloodline.hidden_factor*` 五個 key。
- `tests/HiddenFactorText.test.ts`（新）：7 案，含 zh-TW 語系檔與 fallback 同步。

## 暫定
- 非 zh-TW 語系的文案以 `[ZH-CN]` `[EN]` `[JA]` 前綴標示為暫定。
- 隱藏因子顏色與 level 1 沿用 MilestoneRewards 的暫定值，待 KIN-05 白因子裁決。

## 不在本卡
- 版面高度 40 的實機確認（Codex 驗收）。
- 武將詳情其他 Tab 的隱藏因子顯示。

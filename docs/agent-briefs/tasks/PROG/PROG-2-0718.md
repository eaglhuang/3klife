# [PROG-2-0718] 五階血脈傳承奧義接線到名冊（GDUI-07 續）

## 來源
- GDUI-07（PROG-2-0714）只有純邏輯 `BloodlineTransmissionUltimate`，WBS v12 標為「純邏輯，無 src 呼叫端」。
- 規格口訣：升星開上限，名聲與事蹟點亮內容（武將人物介面規格書.md §6.6、§6.7）。

## 範圍
- `core/systems/BloodlineUltimateRoster.ts`（新，純函式）：`raiseBloodlineUltimateCap`、`awakenBloodlineUltimate`，回傳武將副本，不改輸入。
- `core/managers/GameSession.ts`：`raiseBloodlineUltimateCap(generalId, stars)`、`awakenBloodlineUltimate(generalId)`，比照 `awakenFactor` 的寫法，成功才改名冊並存檔。
- `tests/BloodlineUltimateRoster.test.ts`（新）：8 案，涵蓋升星不降、缺欄位、覺醒成功與三種擋下原因、ALREADY_MAX、不改輸入。

## 暫定
- 名聲與事蹟由呼叫端以 `UltimateProgress` 的欄位傳入（fame、incidents、epicIncidents），沒有在這裡累計。
- 找不到武將時覺醒回傳 `GENERAL_NOT_FOUND`，這是接線用的額外原因，不在規格列舉內。

## 不在本卡
- 升星來源：規格沒說哪種星數驅動 Stage_Cap，目前只有方法參數，沒有任何戰後或 UI 呼叫端。
- 名聲與事蹟的計數來源（目前 fame、incidents 欄位是否由戰績寫入未確認）。
- 覺醒按鈕的 UI 入口與版面（layout / i18n）。
- GameSession 兩個方法的單獨測試（沿用 awakenFactor 的 session 測試模式，後續卡補）。

# [PROG-2-0722] 血統色譜 Tag Pool 呼叫端核對（BLT-13）

## 來源
- WBS v13 BLT-13 標為「Tag Pool 呼叫端未核對」，純邏輯。PM 裁定：呼叫端放在因子揭露／血統生成的因子路徑。

## 核對結果
- 字典注入：`ServiceLoader` 載入 gene-dictionary 後，供 BreedingService（`getDictionary`）與 GameSession（`setFactorDictionary`）使用。
- 血統生成：`BreedingService` 對沒有父母的初代名將呼叫 `generateVirtualAncestry`，並傳入字典。
- 字典行引用：祖先的因子 id 都查得到字典行，色系為六色之一。
- 其他已在用的 defaultTags：戰鬥覺醒（GameSession）、混種戰法（HybridSkill）、結緣（NurtureService）。

## 範圍
- `tests/TagPoolAncestorLookup.test.ts`（新）：3 案，鎖住字典六色齊備、每位名將的祖先因子都引用字典、沒有字典時不回退到已廢止的金色。
- 未改 src：呼叫端已存在，沒有需要補的接線。

## 不在本卡
- 「100 武將 = 100 行」的 Tag Pool 行數與資料格式，未另外核對。

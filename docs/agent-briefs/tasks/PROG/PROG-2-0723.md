# [PROG-2-0723] 好友借用教官 MVP（MENT-14）

## 來源
- WBS v13 MENT-14：FriendBorrow 純邏輯已在，沒有呼叫端；好友系統不存在。
- PM 裁定：先做 MVP「好友」，從資料表讀一組 NPC 好友教官清單，接上借用流程；標暫定。

## 範圍
- `assets/resources/data/npc-friend-mentors.json`（新）：2 位暫定 NPC 好友（一位 SSR、一位 SR）。
- `core/systems/NpcFriendMentor.ts`（新，純邏輯）：`parseNpcFriendMentors`（丟掉壞列、同 id 去重）與 `borrowCandidateOf`。
- `core/managers/GameSession.ts`：`setNpcFriendMentors`、`npcFriendMentors`、`borrowFriendMentor(request)`，借用紀錄存在 `_borrowLedger`。
- `core/managers/ServiceLoader.ts`：`loadNpcFriendMentors()`，在 `prepareBreeding()` 中呼叫。
- `tests/NpcFriendMentor.test.ts`（新）：4 案，涵蓋解析、候選、未知好友、非 SSR、每日上限、卡鎖定。

## 暫定
- 好友名稱與候選卡都是暫定資料，不代表真實玩家。
- 原主結義點數 1 只由 `borrowFriendMentor` 回傳，沒有入帳。

## 缺口（不阻擋結案）
- 借用紀錄未寫入存檔，重開後會清空。
- 結義點數沒有入帳對象；NPC 好友沒有結義點數帳戶。
- day 由呼叫端傳入（YYYY-MM-DD）；遊戲時鐘目前只有季，沒有日。
- 沒有借用 UI 入口，也沒有好友清單 UI。
- 真正的好友系統（好友清單、展示教官槽）屬 server 後續。

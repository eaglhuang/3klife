# [PROG-2-0728] 精力劇本字串進語系表（VIT-09）

## 開單原因
WBS v11 VIT-09（資源循環系統，P0，content）：精力劇本字串與提示未進 i18n，畫面無法顯示。

## 做法
1. 依 `docs/遊戲規格文件/系統規格書/資源循環系統.md` 第 G 節（劇本相關），新增四個 key 到 zh-TW、zh-CN、en、ja：
   - `ui.vit.script.exhausted`：精疲力竭
   - `ui.vit.script.pill_used`：服下補元散
   - `ui.vit.script.pregnancy_lock`：待產凍結
   - `ui.vit.script.hint_late_bloomer`：大器晚成線索
2. `{Name}` 佔位沿用語系表既有的位置參數寫法 `{0}`。
3. zh-TW 文案與規格逐字一致；zh-CN、en、ja 為暫定譯文，待校對。
4. 以文字方式附加到各語系檔尾，原有格式與順序不動。

## 如何驗證
1. `tests/VitalityStrings.test.ts`：四個語系都有四個 key 且非空；zh-TW 文案與規格一致。
2. headless 全綠；計算型閘門 standard。

## 缺口
- UI_VIT_BAR、UI_VIT_COST 等畫面字串（規格 H 節）不在本卡範圍。
- 畫面實際顯示尚未接線。

# [PROG-2-0731] 借將選擇畫面 cc 接線（養成教官欄位入口）

## 來源
- PROG-2-0746 的借將列表視圖模型（mentorBorrowRows）與 MENT-14 的 borrowFriendMentor 已在 master。
- PM 裁定（2026-10-21）：借將畫面從養成流程進入，入口採 A；規格未指定入口時放在養成中武將的教官欄位旁。

## 範圍
- `core/managers/GameSession.ts`：新增 `borrowBlockFor(friend, sessionId)`，與 borrowFriendMentor 同一組 canBorrow 規則，只回傳原因，不改紀錄。
- `ui/core/NurtureFlowController.ts`：新增 `mentorBorrowSessionId()`；教官區 `btnMentorBorrow` 在培育中才可按。
- `assets/resources/ui-spec/layouts/nurture-flow-main.json`：`BtnMentorBorrow`（`btnMentorBorrow`、`mentorBorrowLabel`），位於 TrainBlock 內 `btnLegendaryMentor` 之後。
- `assets/resources/ui-spec/layouts/mentor-borrow-main.json`、`skins/mentor-borrow-default.json`、`screens/mentor-borrow-screen.json`（新）：卡片、標題、5 列（`borrowRow{i}` 與 `btnBorrowRow{i}`）、分頁列、關閉鈕。
- `ui/scenes/LobbyScene.ts`：掛載借將畫面（預設關閉）；`_openMentorBorrow(sessionId)`、`_refreshMentorBorrow`、`_borrowRow(i)`；借用成功或擋下都用 SHOW_TOAST 提示。

## 不做
- 不改借用規則與帳本結構。
- 不做列表的捲動版本（固定 5 列加分頁，PM 已同意）。

## 驗證缺口
- 畫面與按鈕位置未實機確認（Codex）。
- borrowBlockFor 與畫面接線沒有 headless 測試，只靠型別檢查與既有測試。

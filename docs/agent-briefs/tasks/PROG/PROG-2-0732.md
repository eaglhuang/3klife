# [PROG-2-0732] 精力劇本接到培育與結緣的提示點

## 開單原因
PM 裁定（暫定）：(a) 不擋行動，精力歸 0 時只顯示提示 toast；(b) 補元散按鈕放培育畫面，按下顯示劇本 toast；(c) 待產提示放結緣畫面，選中待產的女性武將時顯示；(d) 保留既有 LateBloomClue 規格文字，劇本句先不接。

## 做法
1. 培育 `NurtureFlowController`：新增可選 `showToast`；`train()` 後精力為 0 時發 `ui.vit.script.exhausted`。LobbyScene 接 `SHOW_TOAST`。
2. 補元散 `VitalityPillController.use()` 成功時改回 `ui.vit.script.pill_used`，多收一個武將名參數；失敗的拒絕原因不變。
3. 結緣 `BondingSetupController.pregnantMotherHint()`：母方待產時回傳 `ui.vit.script.pregnancy_lock`。LobbyScene 的母方切換鈕會發 toast。
4. 測試：補元散測試改新文字；`tests/VitalityScriptHooks.test.ts` 鎖住結緣待產提示的有與無。

## 缺口
- 補元散按鈕未建：cc 培育畫面沒有這個節點，要在 nurture-flow-screen 內用程式建立，且要 Codex 實機確認位置。本卡只接到文案與控制器。
- 大器線索保留 LateBloomClue 既有文字（PM 裁定 d）。
- cc 檔 NurtureFlowController、BondingSetupController、LobbyScene、VitalityPillController 只能靠讀程式確認，headless 測不到，型別檢查也沒跑。

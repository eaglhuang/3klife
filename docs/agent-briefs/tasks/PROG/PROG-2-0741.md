# [PROG-2-0741] 五階奧義名聲與事蹟接戰績來源（PROG-2-0718 續）

## 來源
- PROG-2-0718 的缺口：名聲與事蹟計數來源未接，覺醒只讀武將上的 fame、incidents 欄位，戰後沒有寫入者。
- PM 裁定（2026-10-20，暫定）：名聲與事蹟暫用名冊既有的戰績紀錄推算，新卡新分支。

## 範圍
- `core/systems/UltimateProgress.ts`：新增 `ultimateProgressFromBattleRecord(record)`。
  - 名聲 ＝ 勝場 `wins`。
  - 事蹟 ＝ 已達成的里程碑數（`milestones.length`）。
  - 史詩事蹟 ＝ 已達成的 萬人斬（KILL_10000）、修羅（ASURA）、守護之壁（GUARDIAN_WALL）。
- `core/systems/BloodlineUltimateRoster.ts`：`awakenBloodlineUltimate` 可選第二參數 `progress`，沒給時沿用武將自身欄位（既有測試不變）。
- `core/managers/GameSession.ts`：`awakenBloodlineUltimate` 改傳戰績推算的進度。
- `tests/UltimateProgressBattleRecord.test.ts`（新）。

## 暫定
- 名聲 ＝ 勝場、事蹟 ＝ 里程碑數、史詩 ＝ 三個指定里程碑，都是本卡自選的對應，正式公式待 PM 或使用者定案。
- 只改讀取來源，不改 100/300/700/1500 門檻與階段表。

## 不在本卡
- 升星來源（哪種星數驅動 Stage_Cap）：待使用者裁決。
- 覺醒 UI 入口：#647 已在審查中。

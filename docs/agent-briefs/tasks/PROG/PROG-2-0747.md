# [PROG-2-0747] 升星素材路由（GDUI-08，純邏輯）

## 來源
- GDUI-08（WBS v13，M8，未開始）：史實名將吃同模板卡，子孫吃 Lineage_Seal，無規則者不顯示升星。
- 規格：武將人物介面規格書.md §4 UI 規則 2、§6.7 第 5、6 點。

## 範圍
- `core/systems/StarUpMaterial.ts`（新）：`starUpMaterialOf` 回傳 `TEMPLATE_CARD`、`LINEAGE_SEAL` 或 `null`。
- `tests/StarUpMaterial.test.ts`（新）。

## 暫定
- 史實名將以 `isHistorical` 判定，優先於子孫判斷。
- 子孫判定由呼叫端傳入 `isDescendant`，武將模型目前沒有此欄位。
- `lineageSealRule` 由呼叫端傳入，規格只說「有 Lineage_Seal 規則」，沒有給資料來源。

## 不在本卡
- 譜牒印記的取得來源（同家族 duplicate 或家族傳承路徑）。
- 升星按鈕的 UI 接線。

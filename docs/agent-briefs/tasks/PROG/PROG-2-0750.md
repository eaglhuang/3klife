# [PROG-2-0750] 軍師智謀能量累積（SCN-10 純邏輯）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0750 |
| 關聯 | WBS v7 SCN-10（軍師智謀能量 HUD）；WBS 公式「每回合 INT×0.5、滿 100 觸發全局增幅」 |

## 做法
- 新增 `assets/scripts/battle/shared/WisdomMeter.ts`，純函式。
- `advanceWisdomMeter(meter, intelligence)`：
  - `meter + intelligence × 0.5`，上限 100 的前一步不截斷。
  - 達到 100 時回傳 `triggered: true`，能量歸零（本卡解讀，WBS 未寫溢出規則）。
- HUD 與「全局增幅」效果不在本卡。

## 驗收
- 每回合累積 INT×0.5。
- 未滿 100 不觸發；達到 100 觸發一次並歸零。
- INT 為 0 時能量不增加。
- 單元測試覆蓋上述情況。

## 缺口
- 滿能量後的全局增幅效果未定義，未接戰鬥。
- 溢出是否保留未定，本卡採歸零，請 PM 確認。
- HUD（垂直能量條、金色粒子）屬 UI，交 Codex／後續卡。

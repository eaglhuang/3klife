# [PROG-2-0750] 精銳突擊改直線形狀（TAC-0001 規格不符項）

## 開單原因
PM 指示從 TAC-0001 挑規格不符項。精銳突擊（tally-charge）卡上是 TLINE 段，規格是 Self -> LineEnemy，程式卻是單體（EnemySingle）。戰場號段 0550–0599 已滿，依規則改取 0750–0799。

## 規格依據
- 戰法系統規格 G-1：精銳突擊 `Self -> LineEnemy`，模組 `TMOVE`、`TLINE`、`TCOND`。

## 做法
1. `BattleSkillProfiles.ts` 的 tally-charge：targetMode 改為 Line，autoAimMode 改為 densest-line，加上 lineLength 3、maxTargets 3、falloffRule none。chargeMultiplier 2.0 不變。
2. `tests/TigerTallyProfiles.test.ts`：精銳突擊的案例加上形狀為 Line、lineLength 為 3 的斷言。

## 如何驗證
1. TigerTallyProfiles 測試通過。
2. run-cli 全綠；compute-gate standard。

## 缺口
- 衝鋒位移（TMOVE）未做，施放者不會移動到直線起點。
- lineLength 3 與 maxTargets 3 為暫定：規格沒有數字，對齊趙家槍法的直線設定，待企劃確認。

## 交付物
- `assets/scripts/battle/skills/BattleSkillProfiles.ts`、`tests/TigerTallyProfiles.test.ts`、本卡。

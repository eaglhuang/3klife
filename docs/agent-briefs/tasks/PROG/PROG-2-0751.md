# [PROG-2-0751] 戰法效果 kind 擴充（第一片：schema 與純公式）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0751 |
| 關聯 | WBS v8 TAC-10（虎符 G-1）、TAC-11（教官 G-2）；PM 2026-10-15 批准「效果 kind 擴充」分片計畫 |

## 做法（本 PR）
- `BattleSkillEffectKind` 新增 `push` `root` `slow` `dot` `morale` `tile-buff` `extra-attack`。既有 resolver 只接自己的 kind，新增 kind 不影響既有行為。
- `BattleSkillProfile` 新增可選欄位：`chargeMultiplier`、`dotMaxHpRatio`、`slowAmount`、`moraleBonus`、`extraHits`、`pushSteps`、`rootTurns`。全部可選，既有 profile 不必改。
- 新增 `SkillEffectFormulas.ts` 純公式（不依賴 cc）：
  - 精銳突擊：`chargeDamage(base) = base × 2.0`
  - 毒箭：`dotDamagePerTurn(maxHp) = maxHp × 10%`
  - 緩速：`slowedMoveRange(move, amount) = max(0, move − amount)`
  - 鼓舞：`applyMorale(morale, bonus) = morale + bonus`
  - 結姻連射：`totalHitCount(baseHits, extra) = baseHits + extra`
  - 單騎破陣：`soloAttackMultiplier(hasAdjacentAlly) = hasAdjacentAlly ? 1 : 1.3`

## 驗收
- 既有 BattleSkill 相關測試全綠。
- 各純公式的數字與規格一致，單元測試覆蓋。
- 新 kind 未接 resolver 前，既有 resolver 不會誤接（以 effectKind 比對為準）。

## 缺口（留待後續 PR）
- 位移（push／charge／ghost）、狀態（root／slow／dot／morale）、格子（tile-buff）、額外攻擊（extra-attack）的實際結算接線。
- TAC-10、TAC-11 的 profile 與測試，等接線完成後再做。

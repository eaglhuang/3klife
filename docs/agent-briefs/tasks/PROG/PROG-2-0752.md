# [PROG-2-0752] 修 battle/** tsc 錯誤

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0752 |
| 關聯 | PM 優先指示（Codex headless 在 master 失敗，首個 TS2345 在 BattleSkillSourceTranslator.ts:66）；PROG-2-0595（canAttackGeneral 掩體） |

## 錯誤與修法
1. `BattleCombatResolver.ts` `canAttackGeneral`：敵方武將是 `GeneralUnit`，沒有 `lane`／`depth`，掩體判定讀到 undefined，等於從未生效。改為用武將的戰場單位（`state.units` 以武將 unitId 取得）取座標。這修正了 PROG-2-0595 的實際行為缺口。
2. `BattleRuntimeContract.ts`：`BattleResult` 只有 re-export，沒有本地匯入。補 `import type`。
3. `BattleTacticBehavior.ts` `advanceFloodAttackTurn`：`context` 為可選參數，改為 `context?.turnManager`。無 context 時略過標記，行為不再崩潰。
4. `SceneGambitAdapter.ts`：`ownerUid` 預設值原為 `SkillSourceType.SceneGambit`，型別卻被當成 owner 字串。改為 `ownerUid: string` 並保留同一預設值，執行結果不變。

## 驗收
- `npx tsc --noEmit -p tsconfig.test.json` 對上述四個檔案不再報錯。
- headless 全綠。
- 其餘 cc 相關的 tsc 噪音（GradientBackground、ResultPopup 等 cc 型別）不在本卡範圍，為 headless 測試用 cc stub 造成。

## 缺口
- `BattleSceneLoader.ts` 的 AudioClip.name 屬 cc 型別噪音，未改。

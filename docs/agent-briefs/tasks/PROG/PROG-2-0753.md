# [PROG-2-0753] 戰法狀態回合遞減純函式（root／slow／dot）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0753 |
| 關聯 | PROG-2-0751（效果 kind 擴充第一片）；WBS v8 TAC-10／TAC-11 前置 |

## 做法
- 新增 `assets/scripts/battle/skills/SkillStatusTicks.ts`，純函式，不依賴 cc。
- `tickStatusTurns(remaining)`：回合減 1，不低於 0；回傳 `{ remaining, expired }`，`expired` 表示本回合結束後到期。
- `rootedBlocksMove(remaining)`：定身中（remaining > 0）不可移動。
- `slowedStatusMoveRange(move, remainingSlowTurns, amount)`：緩速仍有效時套用 `slowedMoveRange`，否則維持原移動力。
- `dotTickDamage(maxHp, remainingDotTurns, ratio)`：毒傷仍有效時回傳最大 HP 的比例傷害，否則 0。

## 驗收
- 回合遞減到 0 時 `expired: true`，不會變成負數。
- 定身回合 > 0 時不可移動。
- 緩速到期後移動力還原。
- 毒傷到期後不再造成傷害。
- 單元測試覆蓋上述情況。

## 缺口
- 實際套用到戰鬥單位、每回合結算的接線留待後續 PR。

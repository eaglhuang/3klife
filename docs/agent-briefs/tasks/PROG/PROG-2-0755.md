# [PROG-2-0755] 掩體對武將直接攻擊的行為測試

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0755 |
| 關聯 | PROG-2-0595（canAttackGeneral 掩體）；PROG-2-0752（武將座標來源修正）；PM 指示補行為測試 |

## 做法
- 新增 `tests/GeneralStealthBehavior.test.ts`，用最小戰場狀態實際呼叫 `canAttackGeneral`。
- 原本的 `GeneralStealthAttack.test.ts` 只是原始碼守護，無法證明行為；這份測試補上行為證據。

## 驗收
- 敵方武將站在掩體格：射程 2 的遠程不可直接攻擊。
- 同一情境：射程 1 的近戰可以直接攻擊。
- 敵方武將不在掩體格：遠程可以直接攻擊。
- PROG-2-0752 修正前，第一個案例會失敗（武將座標讀到 undefined，掩體從未生效）。

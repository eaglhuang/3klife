# [PROG-2-0756] 衝鋒結算接線（精銳突擊）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0756 |
| 關聯 | PROG-2-0751（chargeMultiplier 欄位）、PROG-2-0754（isStraightLine） |

## 做法
- `BattleSkillExecutionContext` 新增可選 `getCasterCell(faction)`，舊 context 不提供時視為無衝鋒。
- `BattleSkillDispatcher` 由施放者的戰場單位取得格子座標（武將資料沒有座標）。
- `BattleSkillDamageResolver.resolveDamage`：有 `chargeMultiplier`、且施放者與目標在同一直線上時，基礎傷害 ×倍率，最低 1。

## 驗收
- 同一直線：傷害 = floor(未衝鋒傷害 × 倍率)。
- 斜線：傷害與未衝鋒相同。
- 無 chargeMultiplier 的技能：不受影響。
- context 無施放者位置：視為無衝鋒。

## 缺口
- 規格的「衝鋒」是否還需「本回合移動進入直線」，待確認；目前只判定直線。
- 尚無任何 profile 設定 chargeMultiplier，實際戰法接線留待 TAC-10/11。

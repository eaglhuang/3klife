# [PROG-2-0757] 火計連環火場結算

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0757 |
| 關聯 | PROG-2-0754（crossCells）；WBS v8 TAC-10（火計連環） |

## 做法
- `crossCellsForAll`（SkillGridGeometry）：多個中心各自的十字範圍，純函式。
- `BattleSkillProfile.hazardCross`：開啟後，`ProjectedDamageSkillResolver` 在結算後對每個目標的十字格呼叫 `context.setTileHazard`。
- `BattleSkillExecutionContext.setTileHazard` 為可選；dispatcher 以既有 `TileEffect`（`hazard-fire`，`damagePerTurn`）寫入狀態。
- `FIRE_HAZARD_DAMAGE_PER_TURN = 15`，與 BattleTacticBehavior 的火場傷害同值。

## 驗收
- 單一目標十字含自身 5 格，角落裁切為 3 格。
- 多目標各自展開，重疊格不去重。
- 未開啟 hazardCross 的一般傷害技能：仍結算傷害，不產生火場。

## 缺口
- 沒有 profile 實際開啟 hazardCross；火計連環的正式 profile 留待 TAC-10。
- 測試無法注入 profile（`execute` 直接查全域 profile），所以開關的整合路徑靠 tsc 與程式審閱，未有端到端測試。
- 寫入火場會覆蓋該格原有的 TileEffect（例如掩體、落石）。規格未說明，待確認。

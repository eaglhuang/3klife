# [PROG-2-0758] 火場不覆蓋固定地形格

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0758 |
| 關聯 | PROG-2-0757（火計連環）；PM 暫定裁決 2026-10-15 |

## 做法
- `isFixedTileState`（TileStateRules）：`ambush-field`、`scene-camp` 為固定格。
- dispatcher `setTileHazard`：目標格若是固定格則跳過，其餘格直接覆蓋。

## 驗收
- 掩體、營帳為固定格；落石、火場、河流為暫時性格子。
- 單元測試覆蓋上述分類。

## 缺口
- 八陣圖防禦公式另見 PROG-2-0759（獨立分支）。

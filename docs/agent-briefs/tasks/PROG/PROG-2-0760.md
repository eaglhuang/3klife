# [PROG-2-0760] 持續防禦區效果

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0760 |
| 關聯 | PROG-2-0759（八陣圖公式）；WBS v8 TAC-11（八陣圖） |

## 做法
- `TileEffectState` 新增 `formation-zone`；`TileEffect` 新增 `defenseMultiplier`、`zoneFaction`。
- `zoneDefenseMultiplier(effect, unitFaction)`（TileStateRules）：只對 zoneFaction 陣營生效，其餘為 1。
- `BattleCombatResolver.getUnitTerrainDefenseMultiplier` 乘上區域倍率，普通攻擊的防禦結算即生效。

## 驗收
- 所屬陣營站在防禦區：×倍率。
- 敵方站在防禦區：不受加成。
- 無防禦區或其他格子狀態：1。

## 缺口
- 技能傷害（BattleSkillDamageResolver）未接區域倍率，只有普通攻擊生效。
- 八陣圖施放時尚未把 3x3 掛成防禦區，也沒有持續時間與移除規則（規格未寫）。
- `formation-zone` 目前未列入固定格，火場會覆蓋它。是否固定待 PM 裁決。

# [PROG-2-0763] 虎符戰法 G-1 第一批 profile

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0763 |
| 關聯 | WBS v8 TAC-10；規格 戰法系統.md G-1 |

## 做法
- `tally-charge`（精銳突擊）：`chargeMultiplier: 2.0`。
- `tally-fire-chain`（火計連環）：`hazardCross: true`、火系標籤。
- `tally-counter-weak`（幼麒天算）：`counterRatio: 2`、虛弱 1 回合、僅近戰。
- `tally-link`（連環計）：`linkShareRatio: 0.5`、連結 1 格。
- `BattleSkillProfile` 補 `hazardCross` 欄位宣告（PROG-2-0757 已在 master 使用此欄位）。

## 暫定數字（待辦檔）
- 精銳突擊、火計連環的基礎傷害係數取 1.0（規格未寫）。
- 幼麒天算的虛弱持續 1 回合（規格「下回合攻擊降低」推得）。

## 驗收
- 四條 profile 可由 `resolveBattleSkillProfile` 取得，數字與規格一致。

## 缺口（需新效果種類，逐 kind 開卡）
- 毒箭（dot）、長坂雄咆（push + root）、火神狩獵（push）、無雙亂舞（push）、空城計（push）、緩速（slow）、鼓舞（morale）、七進七出（ghost move）、結姻連射（adjacency + extra hit）、威震華夏（首擊條件 + 擊殺重置）、騎射合一（移動後攻擊規則）。

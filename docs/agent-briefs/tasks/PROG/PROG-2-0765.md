# [PROG-2-0765] 效果種類 slow（緩速）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0765 |
| 關聯 | PROG-2-0764（root）；WBS v8 TAC-11（緩速）；規格 戰法系統.md G-2「緩速」 |

## 做法
- `SlowSkillResolver`（effectKind `slow`）：目標為單體敵軍（既有自動瞄準），`applyBuff(Slow, statusTurns)`。
- `mentor-slow` profile：`slowAmount: 1`、`statusTurns: 1`。
- 移動階段既有的 `Slow` 判定（BattleAutoMovePhase）固定扣 1 格，與規格「Move - 1」相同。

## 暫定數字 / 簡化（待辦檔）
- 持續 1 回合（規格「下一回合」）。
- 目標取自動瞄準（最前排敵軍），規格寫「選定格子上的單體敵軍」，手動選格待 TP 與操作接線後補。
- `slowAmount` 目前只作為資料記錄，移動階段仍固定扣 1；若日後要不同數值，需改移動階段讀取 `slowAmount`。

## 驗收
- 單體敵軍施加 Slow 1 回合。
- 沒有可選目標：不施放。

## 缺口
- 計略 TP 消耗、手動選格、教官靈感的觸發條件未接。

# [PROG-2-0766] 效果種類 dot（毒箭）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0766 |
| 關聯 | PROG-2-0763；WBS v8 TAC-10（毒箭）；規格 戰法系統.md G-1「毒箭」 |

## 做法
- `UnitDot`（shared）：中毒記錄、每回合傷害 `floor(maxHp × ratio)` 至少 1、推進一回合。
- `BattleState.unitDots`：以 unitId 為鍵，戰鬥初始化清空。
- `BattleTileEffectPhase`：所屬陣營的中毒單位在其戰術階段扣血，之後推進回合；陣亡者依既有流程處理死亡。
- `DotSkillResolver`（effectKind `dot`）：目標為單體敵軍，`addUnitDot`（dispatcher 實作）。
- `tally-poison-arrow` profile：`dotMaxHpRatio: 0.1`、`statusTurns: 2`。

## 暫定 / 簡化（待辦檔）
- 中毒傷害歸類為 `poison`，不算攻擊者擊殺，也不觸發連結傷害。
- 施放當下不直接造成傷害，只在之後每回合結算（規格「目標中毒 2 回合，每回合 10% MaxHP」）。

## 驗收
- 單體敵軍中毒，比例 0.1、2 回合；沒有目標不施放。
- 每回合傷害與回合推進邏輯由純函式測試（`UnitDot.test.ts`）。

## 缺口
- 戰術階段扣血的接線（BattleTileEffectPhase 的 dot 迴圈）只有 tsc 與審閱驗證，沒有端到端測試。

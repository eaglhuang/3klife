# [PROG-2-0767] 效果種類 push（位移）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0767 |
| 關聯 | PROG-2-0764（root）；WBS v8 TAC-10（長坂雄咆、火神狩獵、無雙亂舞）、TAC-11（空城計）；規格 戰法系統.md G-1「長坂雄咆」 |

## 做法
- `pushAway`（shared/PushMove）：純函式。方向為遠離施放者，前後距離不同沿 depth 軸、同一 depth 沿 lane 軸；每步檢查下一格可站立，遇障礙停在最後一格。
- `PushSkillResolver`（effectKind `push`）：目標為施放者 3x3 內敵軍，逐一推開並 `pushUnitTo`。
- dispatcher 實作 `isCellFreeForPush`（界內、無人、非阻擋格）與 `pushUnitTo`（更新佔用與移動事件）。
- `tally-changban-push` profile：`pushSteps: 1`。

## 暫定 / 簡化（待辦檔）
- 受阻不扣血（規格未寫受阻傷害，依 PROG-2-0764 的 root 同樣不扣血）。
- 方向在斜線時沿 depth 軸（規格「後退」以深度為主）。
- 只實作 3x3 版（長坂雄咆）。火神狩獵的單體擊退、無雙亂舞的 8 格擊退需要單體目標模式，另開卡。

## 驗收
- 純函式：沿深度／沿 lane 遠離、受阻停止。
- resolver：3x3 內敵軍被推開 1 格，3x3 外不動；無施放者位置不施放。

## 缺口
- 長坂雄咆的定身（tally-changban-root）與後退（tally-changban-push）是兩個 profile，組成一個戰法的合併機制待後續。
- 位移事件的 `forcedMoveReason` 為 `skill:push`，UI 未接。

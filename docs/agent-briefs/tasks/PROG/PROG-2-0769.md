# [PROG-2-0769] 效果種類 morale（鼓舞）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0769 |
| 關聯 | WBS v8 TAC-11（鼓舞）；規格 戰法系統.md G-2「鼓舞」（Morale +20） |

## 做法
- `TroopUnit.morale`（預設 0）；`getEffectiveAttack` 乘上 `1 + morale / 100`。
- `MoraleSkillResolver`（effectKind `morale`）：全隊存活友軍 `morale = applyMorale(morale, +20)`。
- `mentor-morale` profile：`moraleBonus: 20`，目標為全體友軍。

## 暫定數字（待辦檔）
- 士氣每點 +1% 攻擊（規格只寫「+20」，未說明換算）。
- 士氣沒有上限與衰減；規格未寫，目前不設。

## 驗收
- 全隊存活友軍士氣 +20，敵軍不變。
- 士氣 20 時攻擊值 ×1.2；預設 0 時既有數值不變。

## 缺口
- 規格寫「加成全局命中與傷害」。目前戰鬥沒有命中系統，只接傷害（經攻擊值），命中待命中機制建立後補。
- 士氣的持續時間（整場或數回合）規格未寫，目前為永久，待 PM 裁決。

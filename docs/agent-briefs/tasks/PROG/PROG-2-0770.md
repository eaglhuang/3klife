# [PROG-2-0770] 鼓舞士氣持續 3 回合（不疊加、可刷新）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0770 |
| 關聯 | PROG-2-0769（morale 效果種類）；PM 裁決 2026-10-15 05:11 |

## 做法
- `shared/Morale.ts`（新）：
  - `MORALE_DURATION_TURNS = 3`（暫定）。
  - `castMorale(unit, bonus)`：未生效時 `morale = bonus` 並設 `moraleTurns = 3`；生效中只把 `moraleTurns` 刷新為 3，士氣不再加。
  - `advanceMorale(unit)`：回合頭 `moraleTurns -= 1`，歸零時 `morale = 0`。
  - `advanceMoraleOf(units, faction)`：只遞減行動陣營的單位（與防禦區同時機）。
- `TroopUnit.moraleTurns`（預設 0）。
- `MoraleSkillResolver` 改呼叫 `castMorale`，不再直接累加。
- `BattleTileEffectPhase`：在行動陣營回合頭呼叫 `advanceMoraleOf`，早於傷害與死亡清理。

## 暫定數字（待辦檔）
- 持續 3 回合，以施放者所屬陣營回合計；施放當回合算第 1 回合，之後的回合頭遞減兩次，第三回合結束前有效。
- 再施放只刷新回合數，不疊加士氣值，也不取較大值。

## 驗收
- 施放後士氣 +20，計時 3。
- 回合頭遞減，三次後歸零、士氣清為 0。
- 持續期間再施放：士氣仍為 20（不疊加），計時回到 3。
- 過期後再施放重新生效。
- `advanceMoraleOf` 只遞減行動陣營，敵方計時不變。
- 既有 `MoraleSkillResolver` 測試（士氣 +20、攻擊 ×1.2）仍通過。

## 缺口
- 「第幾回合開始算、是否含施放當回合」屬於暫定，待 PM 確認；目前以施放者陣營回合計。
- 戰鬥結束或單位離場時是否清士氣，目前未處理（士氣掛在單位上，單位退場即失效）。
- 命中加成仍未接（戰鬥無命中系統）。

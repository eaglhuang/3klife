# [PROG-2-0771] 火神狩獵（單體擊退 + 原格火場）與鼓舞退場清除

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0771 |
| 關聯 | 規格 戰法系統.md 火神狩獵（`Push(1)` + `Tile.State = HAZARD_FIRE`）；PROG-2-0767/0768 位移；PROG-2-0757 火場格；PM 裁決 2026-10-15 05:16（鼓舞退場清零） |

## 做法
- `BattleSkillProfiles.ts`：effectKind 新增 `push-fire`；profile `tally-fire-god-hunt`（單體敵軍、最前排、`pushSteps: 1`）。
- `resolvers/FireGodHuntSkillResolver.ts`（新）：
  - 目標以 `BattleSkillTargetSelector` 選（與緩速同一套）。
  - 先記下目標原格，再 `pushAway` 遠離施放者並 `pushUnitTo`。
  - 受阻傷害沿用 PushSkillResolver：每步 5%、上限 20%（PM 暫定）。
  - 無論是否移動，原格都呼叫 `context.setTileHazard(原格, FIRE_HAZARD_DAMAGE_PER_TURN)`。
- `BattleSkillResolverFactory.ts`：註冊 `FireGodHuntSkillResolver`。
- `shared/Morale.ts`：新增 `clearMorale(unit)`，士氣與計時歸零。
- `runtime/BattleCombatResolver.ts`：`onUnitKilled` 移出戰場時呼叫 `clearMorale`。

## 暫定數字（待辦檔）
- 火神狩獵擊退 1 格；受阻傷害沿用位移的 5%/步、上限 20%。
- 火場傷害沿用 `FIRE_HAZARD_DAMAGE_PER_TURN = 15`。

## 驗收
- 目標被擊退 1 格，原格設為火場，火場數值為 `FIRE_HAZARD_DAMAGE_PER_TURN`。
- 擊退受阻：目標留在原格，原格仍點火，並依未走完步數扣 5%。
- 沒有施放者位置：不施放、不點火。
- `clearMorale` 清掉士氣與計時，之後 `advanceMorale` 回傳 false。

## 缺口
- 戰鬥結束時是否清士氣：目前士氣掛在單位上，戰鬥結束後的單位不會再參與計時，未另外處理。
- 單體目標的命中判定：戰鬥無命中系統，未接。

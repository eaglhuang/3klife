# [PROG-2-0772] 代號只在套用成功時回報

## 開單原因
QA 指出 PROG-2-0588（#576）的 `BattleSkillExecutor` 不論施放是否成功都回報 `moduleTags`。被阻擋或未套用的施放不應帶出規格代號，否則後續消費端會把沒有發生的效果當成發生過。

## 做法
1. `BattleSkillExecutor.execute`：只有 `result.applied` 為 true 時才呼叫 `moduleTagsOfSkill`，否則回空清單。
2. `damageModuleTagOf` 需要 coefficient > 0：修掉緩速被誤標 TDIR 的問題（施工中測試揭露）。
3. `tests/BattleSkillModuleTags.test.ts`：補上執行器測試（#576 聲稱有，但沒有進 master），同一個 stub 先 applied true 驗證代號，再 false 驗證回空清單。

## 如何驗證
1. BattleSkillModuleTags 測試通過。
2. run-cli 全綠；compute-gate standard。

- 無。

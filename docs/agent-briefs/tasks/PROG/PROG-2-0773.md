# [PROG-2-0773] 威震華夏（首回合加倍 + 擊殺再行動）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-0773 |
| 關聯 | 規格 戰法系統.md 威震華夏（`if (Turn == 1) Damage × 2`；致命一擊後 `Target.isDead` 則重置自身 ActionPoint）；TAC-10 虎符戰法 |

## 做法
- `BattleSkillResolver.ts`：`BattleSkillExecutionContext` 新增可選 hook `getTurnNumber?()`（舊測試 context 可不提供）。
- `BattleSkillProfiles.ts`：profile 欄位 `firstTurnDamageMultiplier`、`resetSelfOnKill`；profile `tally-wei-zhen-hua-xia`（單體敵軍、最前排、`coefficient 1.0`、`scalingStat str`）。
- `BattleSkillDamageResolver.ts`：`applyFirstTurn`，回合數為 1 時基礎傷害 ×2（在衝鋒之後、天氣之前結算）。
- `ProjectedDamageSkillResolver.ts`：擊殺目標後，若 `resetSelfOnKill`，對施放者的戰場單位呼叫 `registerActionReset(caster, id, 1, 1)`，再行動 1 次（首擊倍率維持 1）。
- `BattleSkillDispatcher.ts`：`getTurnNumber: () => services().battle.getSnapshot().turn`。

## 暫定數字（待辦檔）
- 首回合倍率 2.0（規格明寫）。
- 重置後的再行動次數 1、首擊倍率 1（規格只寫「重置自身 ActionPoint」，數值待 PM 確認）。
- 基礎係數 `coefficient 1.0`、`scalingStat str`（規格未寫，沿用一般單體物理傷害的暫定值）。

## 驗收
- 第 1 回合傷害為第 2 回合的 2 倍。
- 擊殺目標後，施放者行動重置一次。
- 未擊殺目標，不重置施放者。

## 缺口
- 「首回合」以戰鬥 `turn === 1` 計，與規格 `Turn == 1` 一致；若 PM 定義為施放者自己的第一次行動，需改。
- 行動重置的實際效果依既有 ActionReset 語意（`firstHitPending` 與 `remainingExtraActions`），再行動的時機由戰鬥流程接線，本卡只負責登記。

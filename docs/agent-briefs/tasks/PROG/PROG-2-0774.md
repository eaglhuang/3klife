# [PROG-2-0774] 騎射合一：白馬虎符被動（TAC-10/11 kind 1）

## 開單原因
PM 裁示（2026-10-20）：TAC-10/11 剩下的虎符戰法 kind 每張一卡。本卡做「騎射合一」（白馬）。

## 完整描述
- 規格來源：`兵種（虎符）系統.md` 死亡傳承虎符表，白馬：騎兵、白馬義從、公孫瓚死亡結算、SSR，特殊戰法「騎射合一：騎兵移動 + 弓兵射程」。
- 目錄新增 `tiger-tally-bai-ma`（白馬義從）卡面。規格沒寫的欄位（稀有度數字、星級、特性文字、lore、來源提示）填暫定值。
- 通用被動掛點 `TallyPassive.ts`：`TALLY_PASSIVE_BY_TEMPLATE` 以模板 id 查表，後續的梟姬、龍膽被動加一條表項即可共用。
- 白馬被動：攻擊射程下限提高為弓兵射程 2；騎兵移動力不變。
- `TroopUnit.attackRange` 由 readonly 改為可變，讓被動能改射程。

## 做法與暫定數字
- 套用時機：出陣綁定（`bindTallyAffinity`）。PM 裁示是「戰鬥開始時」，但部署在 `startBattle` 之後才有單位，戰鬥開始那一刻沒有單位可套用。
- 射程下限只升不降，已有更高射程的部隊不會被壓低。
- 卡面 SSR，星級 ★★★、稀有度 `epic`：暫定，規格只寫品質。

## 如何驗證
1. `tests/TallyPassive.test.ts`：白馬射程提高、移動力不變；只升不降；其他模板與 null 不改動；白馬目錄卡的兵種、稀有度、觸發時機。
2. run-cli ALL PASS（2539 passed, 3 skipped）。
3. compute-gate standard 9/9 通過。

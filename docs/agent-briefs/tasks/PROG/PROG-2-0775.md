# [PROG-2-0775] 結姻連射：梟姬虎符被動（TAC-10/11 kind 2）

## 開單原因
PM 裁示（2026-10-20）：TAC-10/11 剩下的虎符戰法 kind 每張一卡。本卡做「結姻連射」（梟姬）。協調者裁示：不等 #514 合併，依賴寫在卡上。

## 完整描述
- 規格來源：`兵種（虎符）系統.md` 名將專屬虎符表，梟姬符：弓兵、巾幗軍、孫尚香死亡結算、SR，特殊戰法「結姻連射：與男性相鄰時攻擊次數 +1」。
- 目錄新增 `tiger-tally-jiao-ji`（巾幗軍）卡面，弓兵、SR；卡面文字與星級為暫定值。
- 通用被動掛點（PROG-2-0774 的 `TallyPassive.ts`）新增梟姬表項 `extraHitWhenAdjacentMale: 1`，`extraAttackHitsOf` 回傳額外次數。
- `BattleCombatResolver.resolveCombat` 改為迴圈：攻擊次數 = 1 + 額外次數，每一下都走原本的命中、傷害、反擊解算；目標或攻擊者死亡即停。

## 做法與暫定數字
- 「相鄰」：武將不在格子上，沒有 lane。判定為：攻擊方所屬陣營主將是男性（gender `男`），且攻擊方站在主將所在排的前一排（玩家側 depth = GRID_DEPTH−1；敵方側 depth = 0）。所有 lane 都算。
- 「攻擊次數 +1」解讀為同一次攻擊完整解算兩下，每下各自擲命中與暴擊、各自觸發反擊。
- 卡面 timing 為 `on-attack`（每次攻擊判定），不是出陣時套用。

## 如何驗證
1. `tests/TallyPassive.test.ts`：梟姬相鄰 +1、不相鄰 0；沒有此被動的部隊不多打；相鄰判定（男性主將前一排才算，女性主將不算）；梟姬目錄卡。

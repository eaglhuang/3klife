# [PROG-2-0777] 空城計：教官戰法位移（TAC-10/11 kind 3）

## 開單原因
PM 裁示（2026-10-20）：TAC-10/11 剩下的 kind 每張一卡。本卡做「空城計」（教官）。協調者裁示：從 master 開分支，與虎符被動無關，可獨立合併。

## 完整描述
- 規格來源：`戰法系統.md` 空城計：`if (Self.INT > Target.INT)` 觸發，半徑 2 內敵方單位沿反向直線位移 `Push_Backward(2)`。
- 實作：沿用既有位移解析器（PushSkillResolver），profile 新增 `pushRadius`（範圍）與 `pushRequiresIntAdvantage`（智力門檻）。
- 智力比較：施放者所屬陣營主將的智力，與每個敵軍所屬陣營主將的智力比較（同陣營敵軍共用同一位主將，結果等同逐單位判定）。

## 做法與暫定數字
- 範圍：半徑 2（方形，沿用 `squareCells`）。
- 後退：2 格；受阻時沿用既有的受阻傷害（每步 5%，上限 20%，PM 暫定）。
- 智力不高於敵方主將時，該單位不位移（不算受阻，不扣血）。

## 如何驗證
1. `tests/PushSkillResolver.test.ts`：半徑 2 內後退 2 格、半徑外不動；施放者智力不高於敵方時不位移。
2. run-cli ALL PASS（2597 passed, 3 skipped）。

# [PROG-2-0778] 空城計教官事件接線（TAC-11 續）

## 完整描述
- 規格來源：`戰法系統.md` 空城計列「智力判定，55 TP」；`教官系統（支援卡）.md` §F-6 諸葛亮 SR 靈感事件：事件組 2，回合 5~18，基礎率 25%，最低 ★1。

## 做法與暫定數字
- 協調者原先給的暫定是「消耗 3 TP」，與規格的 55 TP 衝突。本卡採規格 55 TP，並在待辦檔標註。
- 「教官在場時每場觸發一次」：既有引擎的規則是每個事件每場最多確認一次，本卡沿用，不另加規則。

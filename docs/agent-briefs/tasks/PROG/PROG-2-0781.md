# [PROG-2-0781] 百步穿楊：射程 +2 與爆擊率 +50%（G-1 偏差修正）

## 開單原因
PROG-2-0780 核對 G-1 時發現兩處偏差。協調者裁示：照規格修正，另開一張卡。

## 完整描述
- 規格（戰法系統 G-1 百步穿楊）：`Range + 2`，`Crit + 50%`，裝備[烈弓]符。實作功能欄位寫「傷害結算時爆擊率基數直接 + 50%」。
- 修正前：`critBonus: 0.5` 讓每次命中傷害 ×1.5（必爆），射程沒有接上。
- 修正後：
  - 射程：`rangeBonus: 2`，目標需在施放者攻擊射程 ＋ 2 之內（格距＝同排 lane 差 + depth 差）。範圍外的敵軍不被選為目標。
  - 爆擊：`critRateBonus: 0.5`，以基礎爆擊率 5% ＋ 50% 擲骰，擲中傷害 ×1.5（沿用 CombatCrit 的 `critRateOf` / `rollCrit` / `critDamageOf`）。
  - 亂數：新增 `randomSource`（BattleSkillExecutionContext），由 BattleSkillDispatcher 接到戰場種子亂數源（`services().session.randomSource()`，Q25）。沒有亂數源的 context 不爆擊。

## 做法與暫定數字
- 基礎爆擊率 5% 來自 CombatCrit（既有數字），本卡沒有改它。
- 射程基準：目前取施放者主將所在的戰場單位攻擊射程（`getCasterUnitId` → `getUnit`）。因為戰法由主將施放，這個值是主將單位的射程，不是烈弓符弓兵部隊的射程。若要改成弓兵部隊，需要戰法施放時帶入來源部隊。

## 如何驗證
1. `tests/HundredStepsRangeCrit.test.ts`：射程內（格距 3）可選、射程外（格距 5）不選；爆擊 0.54 擲中 ×1.5 得 138，0.56 未中得 92。
2. `tests/BattleSkillDamageResolver.test.ts`：舊的 critBonus 測試改為爆擊率語意（擲中 138、未中 92、無亂數源 92）。
3. run-cli ALL PASS（2614 passed, 3 skipped）；tsc 無 touched 檔案錯誤；compute-gate standard。

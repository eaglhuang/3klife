# [PROG-2-0782] 編制預設與推薦（DEP-14）

## 開單原因
v10 WBS 的 DEP-14（P2，M8）：儲存 sortie loadout 與戰前推薦。協調者指定由本線接 cc 端。

## 完整描述
- 規格（戰場部署系統 §E 第 9 項）：編制預設 / 推薦，儲存出征編制並於戰前推薦。
- 純邏輯 `core/systems/SortieLoadoutPreset.ts`：
  - `savePresetFor`：每位主將存一組（參謀官 / 後勤官），覆寫舊的，不改原資料。
  - `resolvePreset`：依目前可出戰名單解析，失效的人選改為不派，不替換成別人；主將本人與重複人選不保留。
  - `hasUsablePreset`：預設是否還有任何有效人選。
- `SortieSetupController`：新增 `savePreset()` 與 `applyPreset()`。預設全部失效時不改動編制，並給出提示。

## 做法與暫定數字
- 推薦 = 套用預設的結果，不另挑人，符合規格「推薦需玩家確認」。
- 一位主將只存一組預設（暫定）。

## 如何驗證
1. `tests/SortieLoadoutPreset.test.ts`：解析失效與重複、儲存覆寫、控制器儲存後套用還原、無預設或全失效時回傳 false 不改編制。
2. run-cli ALL PASS（2648 passed, 3 skipped）；compute-gate standard。

## 缺口

# [PROG-2-0783] 地形 S/D 效果：沙漠每回合精力消耗（APT-05 部分）

## 開單原因
WBS v10 APT-05：五大地形格與 S/D 級特殊效果（水域合攻、沙漠耗精力、林地隱身）。協調者裁示：沙漠判斷順序為「先扣每回合精力，再減半」，即沙漠地形每回合扣精力 × 0.5。

## 完整描述
- 規格（戰場適性系統 地形適性效果）：沙漠 S 級「精力消耗減半」，D 級「每回合扣精力、移動減速」。
- 純邏輯 `core/systems/DesertVitality.ts`：`desertVitalityDrain(terrain, grade)`。非沙漠為 0；沙漠 S 級為基礎 × 0.5；其他等級為基礎值。

## 做法與暫定數字
- 基礎每回合消耗 4（暫定，規格沒有數字）。
- 判斷順序照協調者暫定：先扣基礎，再依 S 級減半。
- 注意：協調者原文是「沙漠地形每回合扣精力 × 0.5」，我把它解讀為 S 級減半；D 級扣完整基礎值。若要所有沙漠一律減半，改一行即可。

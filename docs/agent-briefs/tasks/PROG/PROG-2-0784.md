# [PROG-2-0784] 編制預設存檔與畫面按鈕（DEP-14 續）

## 開單原因
協調者裁示（2026-10-20）：預設要進存檔（舊存檔缺欄位視為空），畫面按鈕與 layout 節點由本線接。

## 完整描述
- 存檔：`PlayerSaveSnapshot.sortiePresets`（選填）。`normalizeSortiePresets` 讀回時只留格式正確的條目。`GameSession.createSnapshot` 寫出，新遊戲與讀檔時重設。
- 畫面：`sortie-setup-main.json` 新增 `btnSavePreset`、`btnApplyPreset` 及兩個標籤節點（`savePresetLabel`、`applyPresetLabel`），位於摘要與通知列下方。
- 控制器：`getView` 提供兩個按鈕的文字與啟用狀態；儲存需要預設儲存可用，套用需要該主將已有預設。
- LobbyScene：綁定兩個按鈕到 `savePreset` / `applyPreset`，並把 `presets` 依賴接到 GameSession。

## 做法與暫定數字
- 預設以主將 id 為鍵；主將換人後舊預設保留，但不會自動套用。
- 套用時仍只保留可出戰的人選（沿用 PROG-2-0782 的解析）。

# [PROG-2-0786] 水域 D：移動力歸 1、攻擊減半（APT-05 地形專屬規則）

## 開單原因
協調者裁示（2026-10-20）：地形 S/D 以規格為準，地形專屬規則優先於通用表。水域 D 照規格取代通用 D 表，不疊加。

## 完整描述
- 規格（戰場適性系統 地形適性效果）：水域 D「移動力歸 1、攻擊減半」。
- 修改前：水域 D 套用通用 D 表（攻防 −25%、移動 −2、命中 −15%）。

## 做法
1. `BattleAptitude.resolveAptitude`：地形為水域（river）且地形等級 D 時：
   - 攻擊地形項改為 ×0.5（取代 −25%）；
   - 防禦地形項為 1（不扣）；
   - 命中地形項為 0（不扣）；
   - `moveSetTo = 1`（移動力歸 1）。
2. `applyAptitudeMove(baseMove, moveDelta, moveSetTo)`：有設值時直接設為設值（下限 1），原本為 0 格的維持 0。
3. 接線：`BattleCombatResolver.getUnitMoveSetTo` → `BattleAutoMovePhase.getAptitudeMoveSetTo` → `BattleController` 兩個 auto-move 階段。
4. 兵種與天氣的適性照常計算（騎兵 D 在水域仍扣攻防與移動）。

## 暫定
- 「攻擊減半」只作用在地形項上，兵種 D 仍會再扣 −25%；以協調者「取代通用 D 表」的裁示為準。
- 移動歸 1 是「設為 1」，不是「上限 1」。

## 如何驗證
1. `tests/WaterDAptitude.test.ts`：水域 D 攻擊 0.5、防禦 1、命中 0、移動設值 1；騎兵 D 疊加兵種項；平原 D 不變；水域 B 不變；`applyAptitudeMove` 設值與既有規則。
2. run-cli 全綠；compute-gate standard。

# [PROG-2-0791] 編制預設按下「儲存預設」即存檔

## 開單原因
協調者 QA 提醒：「儲存預設」只改記憶體，要等下一次存檔才寫入。改為按下即存檔。

## 做法
1. `GameSession.setSortiePresets`：寫入後，若有存檔服務就 `await this.save()`（同其他變更的 `_autoSave` 模式）。
2. `LobbyScene`：預設的 `set` 改為 `void` 呼叫，不阻塞按鈕。

## 如何驗證
1. `tests/SortiePresetAutoSave.test.ts`：有存檔服務時不呼叫 save() 也能讀回預設；沒有存檔服務時只改記憶體、不丟錯。
2. run-cli 全綠；compute-gate standard。

## 缺口
- 無。讀檔路徑的測試在 PROG-2-0792。

# [PROG-2-0793] 醫療（已損 HP 比例治療）profile 與結算

## 開單原因
SYS-SKILL-TAC-0002 的「醫療」（教官 G-2，THEAL，P0）尚無 profile。規格 `戰法系統-shards/g.md` 寫明：`Target.HP = min(Target.MaxHP, Target.HP + (Target.MaxHP - Target.HP) * 0.25)`，即依目標已損 HP 的 25% 治療，與仁德號召「依施放者最大 HP」的固定量不同。

## 做法
1. `BattleSkillProfile` 新增 `healMissingRatio?: number`（依目標已損 HP 的比例）。
2. `BattleSkillProfiles.ts` 新增 `medical-aid`：`AllySingle`、`effectKind: 'heal'`、`healMissingRatio: 0.25`、`coefficient: 0`。
3. `HealSkillResolver.execute`：若 profile 有 `healMissingRatio`，每個目標分別計算 `floor((MaxHP − HP) × ratio)`，不再用施放者 maxHp；已滿血的目標不加量。既有 `healRatio` 路徑不變。
4. 不改 `TroopUnit.heal` 的上限夾制（已 `min(MaxHP, …)`）。

## 如何驗證
1. 新增 `tests/MedicalAidHeal.test.ts`：profile 形狀、已損 HP 計算、滿血目標不加量、溢補不超過上限、既有仁德號召路徑不變。
2. run-cli 全綠；compute-gate standard；`tsc -p tsconfig.test.json` 無本卡新增錯誤。

## 缺口
- 醫療尚未進入戰法資料表（tactic-library / generals 配置），本卡只補 profile 與結算；資料接線另開卡。
- 戰報文字 key 本卡沿用 battleSkillId，i18n 另補。

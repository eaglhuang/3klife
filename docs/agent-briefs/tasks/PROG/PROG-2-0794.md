# [PROG-2-0794] 單騎破陣接線（回合開始判斷、ATK +30%）

## 開單原因
SYS-SKILL-TAC-0002 的「單騎破陣」（趙雲教官靈感，TBUFF+TCOND）只有純公式 `soloAttackMultiplier`（PROG-2-0751），沒有呼叫端。規格：回合開始時判斷相鄰 1 格無友軍，則 ATK +30%，持續到施放者下一回合開始。

PM 裁定（暫定）：由規格表列的武將帶，沒列就給趙雲；效果持續到施放者下一回合開始時結束。

## 做法
1. `TroopUnit` 新增 `soloBreachMultiplier`（預設 1），`getEffectiveAttack` 乘上它；預設下數值不變。
2. 新增 `battle/runtime/BattleSoloBreach.ts`：`applySoloBreachAtTurnStart`。只對帶戰法的單位（玩家武將化身、武將為趙雲時）重算：相鄰（正交 1 格）無存活友軍則 `soloAttackMultiplier(false)`，否則 1。
3. `BattleController.finalizeRuntimeTurnCycle` 在 `refreshForNextTurn` 之後呼叫，等於每回合開始重算，舊效果於下一回合開始時結束。

## 如何驗證
1. 新增 `tests/SoloBreachAttack.test.ts`：無相鄰友軍 ×1.3、有相鄰友軍 ×1、非趙雲不套用、下一回合重算後恢復、預設 ATK 不變。
2. run-cli 全綠；compute-gate standard；`tsc -p tsconfig.test.json` 無本卡新增錯誤。

## 缺口
- 戰場開場第 1 回合前尚未重算，第 1 回合依預設 ×1（暫定，待 PM 確認是否要在開場也判斷）。
- 只做 ATK 乘區，不含戰報文字與 UI 圖示。

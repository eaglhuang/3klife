# [PROG-2-0795] TAC-0003 卡面同步與長坂雄咆驗證

## 開單原因
TAC-0003 卡面的 `長坂雄咆`、`火神狩獵` 仍是未勾，程式已落地。PM 要求先同步卡面並逐條驗證 `長坂雄咆`、`無雙亂舞`。

## 做法
1. 逐條對照程式與既有測試：
   - 長坂雄咆：`tally-changban-push`（3x3 內敵軍後退 1 格，`PushSkillResolver.test.ts` 3x3 內外案例、`PushE2E.test.ts`）與 `tally-changban-root`（定身 1 回合，`RootSkillResolver.test.ts`、`StatusKindsE2E.test.ts`）。兩段都有測試，改 [x]。
   - 火神狩獵：`tally-fire-god-hunt`（push-fire，`FireGodHuntSkillResolver.test.ts`，PROG-2-0771），改 [x]。
   - 無雙亂舞：程式沒有對應 profile。規格是周身 8 格 AOE 傷害加擊退 1 格，目前沒有「區域傷害＋擊退」的組合效果種類，不能只靠既有 profile 驗證。保留 [ ]，另開卡設計。
2. 只改 TAC-0003 卡面，不改程式。

## 如何驗證
- 上述測試在 master 已存在（本卡不新增測試，也不改行為）。
- compute-gate standard。

## 缺口

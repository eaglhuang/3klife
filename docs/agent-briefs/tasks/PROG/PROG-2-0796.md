# [PROG-2-0796] 騎射合一：移動 +1 與移動後攻擊確認

## 開單原因
TAC-0003 的 `騎射合一`（虎符 G-1）規格：`Range = 2`、`Move + 1`，可同回合先移動再遠程攻擊。PM 裁定攻擊用移動後位置計算射程。

目前程式：
- 射程：白馬 `attackRangeFloor = 2` 已落地（PROG-2-0774）。
- 移動：白馬只有射程，沒有 `Move + 1`；既有測試 `騎射合一：…移動力不變` 與規格不符。
- 移動後攻擊：戰鬥階段在移動階段之後結算，攻擊目標用當下格位計算，沒有「移動者不能攻擊」的判定（`hasUnitMovedThisTurn` 只用在擊殺後前進，`BattleCombatResolver.advanceAfterKill`）。

## 做法
1. `TallyPassiveSpec` 新增 `moveRangeBonus`；白馬表項加 `moveRangeBonus: 1`，`applyTallyPassive` 套到 `moveRangeBonus`（綁定時套一次）。
2. 更新 `tests/TallyPassive.test.ts`：白馬移動力 +1，射程仍為 2。
3. 移動後攻擊：本卡只確認現況（上列程式依據），不改戰鬥流程。

## 如何驗證
1. `tests/TallyPassive.test.ts` 通過（白馬移動 +1、射程 2、其他模板不變）。
2. run-cli 全綠；compute-gate standard；`tsc -p tsconfig.test.json` 無本卡新增錯誤。

## 缺口
- 移動後攻擊沒有整合測試（需完整戰鬥迴圈 harness）；本卡以程式確認，不另寫整合測試。
- 規格衝突：`兵種（虎符）系統.md` 寫「騎兵移動 + 弓兵射程」，`戰法系統` g.md 寫 `Move + 1`，本卡以 g.md 為準（暫定）。

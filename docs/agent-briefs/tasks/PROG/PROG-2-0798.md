# [PROG-2-0798] 七進七出：穿透路徑規則（純規則層）

## 開單原因
TAC-0003 的 `七進七出`（虎符 G-1，TMOVE+TSTEALTH）規格：`Ghost_Move = True`，移動穿透敵格。PM 裁定：路徑上每個敵軍各受一次傷害；不可穿越岩石與友軍；終點必須空。

## 做法
1. 新增 `battle/shared/GhostMovePath.ts`：`resolveGhostPath(cells, casterFaction)` 純規則。依序走過路徑格（不含起點）：
   - 岩石（blocksMovement）或友軍佔用 → 整段無效（blocked）。
   - 敵軍佔用 → 記為一次穿透傷害（同一格不重複）。
   - 終點有任何佔用 → blocked。
2. 只做規則層，不接移動流程。
3. 新增 `tests/GhostMovePath.test.ts`：空路徑通過、穿越兩敵各記一次、穿越岩石 blocked、穿越友軍 blocked、終點有敵 blocked。

## 如何驗證
1. `tests/GhostMovePath.test.ts` 通過。
2. run-cli 全綠；compute-gate standard；tsc 無本卡新增錯誤。

## 缺口
- 規則層尚未接到實際移動流程（BattleController / 移動階段），沒有呼叫端，WBS 上不算已接線；接線另開卡。
- 閃避反擊（Counter_Attack_Rate 0）未做。

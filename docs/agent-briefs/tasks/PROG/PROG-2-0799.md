# [PROG-2-0799] 無雙亂舞：周身區域傷害加擊退

## 開單原因
TAC-0003 的 `無雙亂舞`（虎符 G-1，TFAN+TPUSH）規格：選定自身周圍 8 格為攻擊範圍，對區域內所有敵方執行同一套傷害結算，並強制擊退 1 格。目前沒有對應 profile，PM 裁定沿用 `PushSkillResolver` 的 `pushRadius` 加上傷害。

## 做法
1. `BattleSkillProfiles.ts` 新增 `tally-wushuang`：`AroundSelf`、`effectKind: 'push'`、`pushRadius: 1`、`pushSteps: 1`、`coefficient: 1.0`、`scalingStat: 'str'`。
2. `PushSkillResolver`：`coefficient > 0` 時先用 `BattleSkillDamageResolver` 結算傷害（同一套公式）；單位因此陣亡則不擊退。`coefficient` 為 0（長坂雄咆）維持原行為。
3. 新增 `tests/WushuangLuanwu.test.ts`：周身 3x3 內敵軍受傷並擊退、3x3 外不動、傷害致死不擊退、長坂雄咆（coefficient 0）不受影響。

## 如何驗證
1. `tests/WushuangLuanwu.test.ts` 與既有 `PushSkillResolver.test.ts` 通過。
2. run-cli 全綠；compute-gate standard；tsc 無本卡新增錯誤。

## 缺口
- 傷害係數 1.0 與 scalingStat 為暫定，規格未寫數字；待企劃確認。
- 擊退是否以傷害前或後的站位判定，本卡採傷害後仍存活才擊退。
- 戰報文字 key 沿用既有 push 格式，i18n 另補。

## 交付物
- `assets/scripts/battle/skills/BattleSkillProfiles.ts`、`assets/scripts/battle/skills/resolvers/PushSkillResolver.ts`、`tests/WushuangLuanwu.test.ts`、本卡。

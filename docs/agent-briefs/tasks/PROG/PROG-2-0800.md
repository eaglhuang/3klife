# [PROG-2-0800] 壽命劇本句接上 cc 呼叫端（LIFE-13）與成長階段事件

## 開單原因
WBS v8 LIFE-13（P0）：壽命與階段劇本字串已有 Key（LifeScriptCopy），但 src 沒有任何呼叫端，字串未接 t()。協調者 PM 裁示（2026-10-15 00:29Z）：壽命線溢出段 0800–0849，LIFE-13 用 0800；grow-up / prime / elder 在 GeneralAging 每季推進、年齡跨入新成長階段時發出階段轉換事件並接劇本句（暫定）。

## 完整描述
- `GeneralAging.ts`：新增成長階段起點 `LIFE_GROWTH_STAGE_STARTS`（grow-up=5 少年、prime=40 壯年巔峰、elder=55 老年，暫定），每季增齡時對跨過的起點發出 `entered-growth-stage` 事件（帶 `stage`）。純函式 `growthStagesCrossed(prev, next)`。
- `GameSession.ts`：新增 `GeneralGrowthStage` 事件，推進季時廣播階段事件。
- `LobbyScene.ts`：
  - 階段事件 → `lifeScriptCopy(stage, name)` 經 i18n 顯示 toast。
  - 退役（`GeneralRetired`）→ `lifeScriptCopy('retire', name)` 顯示 toast。
  - 死亡（`GeneralDied`）保留既有 UI_DEATH_NOTIFY（既有測試鎖定該字串），另外顯示 `lifeScriptCopy('death', name, age)` 劇本句。
- 測試：跨界判定（含跨多個階段、不跨界、已跨過不重複）；事件只在 alive 武將上發出；LobbyScene 接線字串鎖定。

## 解讀選擇
- 成長階段對應：grow-up ↔ 少年起點 5（漸漸長大），prime ↔ 壯年巔峰 40（正值壯年），elder ↔ 55（年邁力衰）。青年 15 沒有對應劇本句，不發事件。
- afterlife 劇本句（英靈卡與虎符卡歸檔）未接：LIFE-13 的身後結算由 Legacy 流程產生，本卡不改 Legacy。
- 死亡通知與劇本句合併成一則 toast（UI_DEATH_NOTIFY 換行接劇本句），避免兩則重疊（PM 裁示 2026-10-15 00:32Z）。

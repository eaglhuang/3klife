# [PROG-2-0802] 演武聖境精華快照接上死亡結算與英靈卡（LIFE-11）

## 開單原因
PM 裁示（2026-10-15 00:33Z）：Total_TP 採「武將培育期間累積 TP 總和」（培育加 tp 時同步累加到武將、存檔）。付費復活價格與商店掛接先不做（商業數字待使用者）。LIFE-11 的精華快照（TP × 0.5，上限暫定）要在死亡結算時寫進英靈卡。

## 完整描述
- `NurtureSystem.ts`：培育 session 新增 `totalTp`（只增不減；受傷撤回時同步扣回；戰法學習消耗不扣）。畢業時寫入武將 `totalTp`。
- `LegacyService.ts`：死亡結算時以 `legacySnapshotOf(武將 totalTp)` 算精華快照，經 `GeneralArchiver.markLegacyEssence` 寫入英靈卡 `legacyEssence`；同 uid 重跑時保留既有值。
- `SpiritCard.ts`：新增可選欄位 `legacyEssence`（舊資料缺欄位視為未定，不遷移）。
- `LegacyArena.ts`：新增純函式 `legacyEssenceLine`（「精華快照：N」）。
- 測試：累積 TP 只增不減的規則（受傷回扣）；精華快照寫入與保留；舊卡缺欄位不報錯。

## 解讀選擇
- 只累積「培育獲得」的 TP，不含戰法學習消耗（消耗不代表武將總量減少）。
- 受傷撤回的 TP 同步扣回，因為本回合 TP 已被撤回不算獲得。
- 英靈卡的 UI 顯示：目前沒有 cc 元件讀取英靈卡摘要，本卡只提供純函式行，cc 接線待英靈圖鑑畫面卡。

## 未覆蓋
- 付費復活價格與商店掛接（PM：商業數字待使用者）。
- 英靈圖鑑 cc 畫面（現況沒有讀英靈卡的元件）。
- 戰魂寄宿（SAME-08）用同一快照，不在本卡。

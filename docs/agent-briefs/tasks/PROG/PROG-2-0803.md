# [PROG-2-0803] 英靈圖鑑畫面（季度 HUD 入口）與死亡路徑測試

## 開單原因
PM 裁示（2026-10-15 00:36Z）：英靈圖鑑畫面（layout JSON、screen 註冊、大廳入口），讓 legacyEssenceLine 有呼叫端；另補 LegacyService 死亡路徑測試。

## 完整描述
- `SpiritCodexController.ts`（純邏輯）：只列 isSpiritRelic 為 true 的英靈卡，依歸檔時間新到舊，最多 6 列，其餘「另有 N 位」；空清單顯示空狀態。列文字「名｜死亡年｜精華快照：N」。
- 版面：`spirit-codex-main.json`（卡片、標題、數量、列表、更多、關閉鈕）、`spirit-codex-screen.json`（uiId SpiritCodex，Popup）、`spirit-codex-screen.skin.json`（由退役回顧 skin 複製，slot 改 codex.*），各含 .meta。
- 入口：`lobby-season-hud-main.json` 新增 `btnOpenSpiritCodex`（接在沙盤下方，bottom 344）；LobbyScene 掛載 `SpiritCodexHost`，點擊時從 `services().legacy.getArchiver().getAllSpiritCards()` 讀取並套 view。
- 四語系新增 `ui.spirit_codex.title / close / count / empty / more`（文字插入）。
- 測試：`LegacyEssenceSettlement.test.ts` 走真正的死亡推進流程，確認英靈卡 legacyEssence = floor(totalTp×0.5)、封頂、零 TP。

## 解讀選擇
- 入口放在季度 HUD（已有一排功能鈕），不另外新增大廳主畫面的按鈕。
- 只列正式英靈卡（isSpiritRelic），一般死亡快照不列入圖鑑。
- 精華快照行暫用既有中文 `legacyEssenceLine`，未進語系表（與 0802 一致，待英靈圖鑑定稿後四語化）。

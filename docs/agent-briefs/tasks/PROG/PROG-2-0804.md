# [PROG-2-0804] 精華快照行進語系表

## 開單原因
PM 裁示（2026-10-15 00:40Z）：精華快照行（「精華快照：N」）也請移進語系表。0802 與 0803 暫用中文，這張卡把它改為 i18n key。

## 完整描述
- `LegacyArena.ts`：新增 `LEGACY_ESSENCE_LINE_KEY = 'legacy.essence_line'`、zh-TW 預設 `LEGACY_ESSENCE_LINE_FALLBACK_ZH_TW`、`legacyEssenceValue`（取整、不為負）；`legacyEssenceLine(essence, lookup?)` 有 lookup 時走語系，未命中退回 zh-TW。
- `SpiritCodexController.ts`：列文字把 lookup 傳給精華快照行。
- 四語系新增 `legacy.essence_line`：zh-TW「精華快照：{0}」、zh-CN「精华快照：{0}」、en「Essence snapshot: {0}」、ja「精華スナップショット：{0}」。

## 解讀選擇
- 精華快照行是英靈圖鑑的單行文字，key 用 `legacy.` 前綴，不放 `ui.`，因為它不是版面節點文字。

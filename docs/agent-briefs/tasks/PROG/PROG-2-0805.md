# [PROG-2-0805] 人工審核清單自動化（GDP-08）

## 開單原因
WBS v8 GDP-08：人工審核清單自動化（極值武將、tier 分布、亂碼截斷、重複 id、關鍵 25 位 lore）。驗收為「輸出審核報告列出 Top 屬性、分布與疑似亂碼」。目前無此工具，審核只能靠人眼逐筆看。

## 完整描述
- 新增 `tools_node/audit-generals-report.js`：純函式 `buildAuditReport` 與 `formatAuditMarkdown`，另有 CLI 印出 Markdown 報告（預設讀 `assets/resources/data/master/`，唯讀，不寫檔）。
- 報告內容：
  - Top 10 武將（依 ep 排序）與各屬性最大值（Top 屬性）。
  - rarityTier 與 characterCategory 分布。
  - 重複 id（跨 generals-base / generals-lore / generals-stories）。
  - 疑似亂碼：U+FFFD、控制字元、連續 3 個以上問號。
  - 疑似截斷：lore 文字未以句末標點結尾。
  - 關鍵 25 位缺 lore 或 storyStripCells。
- 暫定（可逆）：「關鍵 25 位」定義為 ep 最高的 25 位。PM 若另有定義，只改一行。
- 報告為唯讀工具，有發現只列出，不改資料；exit code 維持 0，除非給 `--strict`。

## 如何驗證
1. `node tools_node/audit-generals-report.js`：印出 Top 10、分布、亂碼與截斷清單，不寫檔。
2. tests/GeneralAuditReport.test.ts：以 inline fixture 測各檢查項；另以實際 master 資料做煙霧測試（報告含 10 位 Top 武將、重複 id 為 0）。
3. run-cli ALL PASS；tsc 通過；compute gate standard。

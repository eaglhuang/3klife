# [PROG-2-0807] Wiki 摘要句末截斷與消歧義過濾（GDP-01 修補）

## 開單原因

## 完整描述
- `cutAtSentenceEnd`：摘要超過 200 字時只在句末（。！？）截斷；上限內找不到句末則回傳 null，改用佔位文字。
- `isDisambiguationText`：「可以指：」開頭的摘要視為消歧義，不採用；fetchWikiSummary 遇 `type: disambiguation` 也回 null。
- 既有 generals-lore.json 的 24 筆不改動：wiki 無法連線（代理 403），原文也不在 repo，無法還原。清單記在待辦檔「武將 lore 截斷與消歧義」。

# [PROG-2-0811] GameSession 年度推進與年末事件（TIME-07 接線）

## 開單原因
TIME-07 第一段（PROG-2-0810）只有年報的資料與文字，沒有接上 GameSession。協調者要求：提供年度推進指令 advanceYear，並開放年度事件掛點，養成線的 FEM-06 女兒成年後會接上這個掛點。

## 完整描述
- `GameSession.advanceSeason`：累積本年老化事件；第 4 季結束（`advance.yearEnded`）時產生 `YearReport`，放進 payload 的 `yearReport`，並發出 `GAME_SESSION_EVENTS.YearEnded`。
- `GameSession.advanceYear()`：最多推進 4 季，遇到年末就回傳年報；季數對不上時拋錯，不回傳假資料。
- 年末事件 `YearEnded` 是年度掛點，payload 為 `YearReport`。
- 暫定（可逆）：年度累積的老化事件只放記憶體，不存檔；年中讀檔時從 0 起算。

## 依賴與注意
- 依賴 PROG-2-0810 的 `YearReport.ts`。該卡還在 PR #474（未合併）。本分支只放與 #474 完全相同的 `YearReport.ts` 與 `.meta`（同內容，合併時不衝突），不疊在 #474 分支上。

## 如何驗證
1. tests/YearEndSession.test.ts：advanceYear 跑滿一年並計入死亡、年末事件只發一次、年報只統計該年事件。
2. run-cli ALL PASS（既有換季廣播測試不變）；compute-gate standard。

# [PROG-2-0813] 時代更迭 Era_Reset 觸發（TIME-10）

## 開單原因
遊戲時間系統規格 TIME-10：每 60 個遊戲月（5 年）觸發一次地圖大重組，保留養成資產，重置領土、外交與 AI 勢力。

## 完整描述
- `assets/scripts/core/systems/EraReset.ts`（純邏輯）：
  - 1 季 = 3 個遊戲月，`Total_Game_Months % 60 == 0` 且大於 0 才觸發（第 0 月是開局，不算）。
  - 保留清單：子嗣數值、血統因子、虎符與英靈卡、解鎖科技、玩家成就。
  - 重置清單：領土分配與城池歸屬、外交關係、AI 勢力規模。
- `GameSession.advanceSeason`：季結後若為時代更迭季，發出 `GAME_SESSION_EVENTS.EraReset`（payload: `EraResetEvent`）。
- 目前 session 沒有領土、外交、AI 狀態，本卡只發出訊號與清單；實際重置等世界沙盤系統存在後接入。

2. compute-gate standard。

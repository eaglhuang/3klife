# [PROG-2-0825] 官職階位、經驗與晉升（OFC-01～03、OFC-09 純邏輯段）

## 開單原因
PM 指示：官職系統 OFC-01～03 中規格清楚的部分（階位資料與晉升判定），接上 HALL-11 快照，從 master 開分支。

## 完整描述
- 經驗公式（官職系統 F-1）：難度底數 EASY 10 / NORMAL 18 / ELITE 30 / HIGH 48 / HELL 72，軍事領域 ×1.1，失敗 ×0.4，取 floor。
- 階位門檻（F-2）：階位 2/3/4/5 需要累積經驗 100/260/520/920。
- 晉升：經驗跨門檻即升，連升多階時依序回傳新解鎖的階位；解鎖歷史每階只寫一次。
- 天下大亂保留（F-3）：階位、經驗、解鎖歷史全部保留。
- 讀檔：缺欄位或壞值退回階位 1；階位與經驗互相對齊。
- 快照：`toOfficerSnapshot` 產出 HALL-11 讀的 `{ tier, code: OFFICER_TIER_n }`。

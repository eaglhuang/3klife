# [PROG-2-0826] 官職狀態存檔與 GameSession 接線（OFC-03）

## 開單原因
PM 指示（2026-10-20）：OFC-03 存檔與 GameSession 接線，從 master 新分支，存檔用扁平快照、版號不升。

## 完整描述
- `PlayerSaveSnapshot.officerState?: OfficerState`：扁平欄位；只有階位 > 1 或經驗 > 0 才寫入；讀檔經 `normalizeOfficerState`，舊檔缺欄位即為階位 1。
- `GameSession`：`_officerState` 取代 HALL-11 的暫存快照；`createSnapshot` / `load` 讀寫；新遊戲重置為初始狀態。
- `GameSession.gainOfficerExp(task)`：依 F-1 算經驗、只升不降、回傳這次新解鎖的階位（由低到高）。
- `GameSession.officerUnlocks` 改由官職階位推得（`toOfficerSnapshot` → `officerUnlocksOf`），大廳任務牆與沙盤入口自動跟著官職走。
- `setOfficerSnapshot` 移除（只有 HALL-11 測試用，已改寫）。

## 暫定（可逆）

# [PROG-2-0827] 官職階位資料檔（OFC-01）

## 開單原因
PM 指示（2026-10-20）：OFC-03 之後接 OFC-01 資料檔。官職階位目前只有程式常數，規格 F-2 的階位表要落成資料檔，方便企劃調整。

## 完整描述
- 新增 `assets/resources/data/officer-tiers.json`：5 階，每階含 `tier`（1~5）、`code`（OFFICER_TIER_n）、`title`（鄉里義士 / 縣府佐官 / 郡守 / 州牧 / 霸府重臣）、`expToReach`（初始 0；100 / 260 / 520 / 920）、`unlockedFeatures`（代碼清單）。
- 門檻對上規格 F-2；與 `OFFICER_TIER_EXP_THRESHOLDS`（OfficerState.ts）的一致性測試待 #594 / #601 合併後補上（本分支不依賴該檔）。

## 暫定（可逆，待企劃確認）
- `unlockedFeatures` 代碼依 F-2「主要解鎖」欄自擬（例如 QUEST_ELITE、WORLD_SANDTABLE_S1），規格沒有定義正式代碼。
- 任務難度對應 basic / normal / elite / advanced / hell，與 OfficerSnapshot 的 QuestDifficultyCap 一致。

## 如何驗證
1. tests/OfficerTiersData.test.ts：5 階齊全、代碼連續、門檻對上 F-2、解鎖代碼非空、任務上限排序。
2. run-cli ALL PASS；compute-gate standard。

# [PROG-2-0832] 大廳任務結算與官職晉升提示（OFC-03 / OFC-08 最小可行）

## 開單原因
PM 指示（2026-10-20）：大廳任務結算由 Claude 開卡做。最小可行：結算時呼叫 gainOfficerExp，並觸發 OFC-08 晉升提示。

## 完整描述
- `hallMissionToOfficerTask({difficulty, board, success})`：轉成 F-1 的 OfficerTaskResult，無法對應回傳 null。
- `GameSession.settleHallMission(outcome)`：完成或失敗都入帳官職經驗；晉升時發出 `GAME_SESSION_EVENTS.OfficerPromoted`，payload `{ tiers }`。
- `officerPromotionNoticeOf(tiers, rows?)`：UI_OFFICER_PROMOTE「晉升 {RankName}」，逐階一行。
- LobbyScene 監聽 OfficerPromoted：刷新官職區塊並以 SHOW_TOAST 顯示提示。

## 暫定（可逆，規格缺）
- 難度對應：basic→EASY、normal→NORMAL、elite→ELITE、advanced→HIGH、hell→HELL。
- 牆對應：Military→MILITARY、Domestic→DOMESTIC；Expedition 不入帳。
- 晉升一次性獎勵：規格沒寫內容，本次不發獎。

## 如何驗證
1. tests/HallMissionSettlement.test.ts：難度與牆對應、無對應不入帳、完成與失敗入帳經驗、晉升發事件、無晉升不發事件、文案逐階一行。
2. run-cli ALL PASS；tsc 無新增錯誤；validate-ui-specs；compute-gate standard。

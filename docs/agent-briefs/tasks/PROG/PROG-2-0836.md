# [PROG-2-0836] 大廳任務派遣流程（任務牆 → 派遣 → 結算）

## 開單原因
PM 2026-10-20：#617 結算 API 與 #619 派遣條件已合併，接上任務牆點擊，讓玩家能完成一輪派遣與結算。

## 完整描述
- 任務牆點「接取」改為派遣：`GameSession.dispatchHallTask` 先過 `canDispatchHallTask`（可見、未接取、有武將），再指派武將，最後 `settleHallMission` 結算官職經驗。
- 成敗：`judgeHallMissionSuccess(難度, 武將戰力)`，武將戰力暫用 `estimateSortiePower`（粗估）。
- 結算後任務仍留在指派表（已接取），一次派遣只結算一次。
- 結果以 toast 顯示「任務成功 / 任務失敗」；晉升沿用既有 OfficerPromoted 提示。

## 暫定（可逆）
- 派遣即結算，不做時間進行中。
- 武將戰力用 `estimateSortiePower`，門檻數值沿用 #619 的暫定表。
- 沙盤 Expedition 牆沿用既有遠征出發流程，不給官職經驗（無領域對應）。
- 失敗仍消耗任務（已接取），不退回。

# [PROG-2-0844] 戰場狀態、單挑與奧義文案（en / ja，第一批）

## 開單原因
PM 2026-10-20 指示：全檔約 190 個佔位語系 key，戰場相關由本線補 en / ja，每批約 40 個一張卡。本卡為第一批：狀態、戰場、單挑、奧義。

## 範圍切分（與底座、養成線以 key 前綴分開）
- 本卡：`status.*`、`battle.*`、`duel.*`、`UI_DUEL_*`、`UI_ULTIMATE_*`（36 key）。
- 下一張 PROG-2-0845：`ui.result.*`（10）、`toast.deploy_*`、`toast.no_grain`、`toast.cooldown`（4）。
- 不碰：`ui.general.*`、`ui.lobby`、`ui.start_battle`、`network.*`、`toast.sync_*` 等（底座／養成線）。

## 譯文
- en：Poisoned、Stunned、Shield、ATK Up、HP Up、Cursed；Round、Deploy、End Turn、Duel、Tactic、Supplies 等。
- ja：毒、スタン、シールド、攻撃強化、HP強化、呪い；ターン、配置、一騎打ち、計略、兵糧 等。
- 佔位字串 `{0}`、`{1}` 保留不動。

## 寬度風險摘要（字元數估算，相對 zh-TW）
- 高（英文膨脹 ≥ 4 倍）：`battle.deploy_failed`（4 → 21，5.3 倍）、`status.poison`、`battle.grain`、`duel.reject_penalty`（4.0 倍，長句）。建議：狀態 pill 與資源列寬度要容納 8 字元以上；`battle.deploy_failed` 若放在窄 toast 需換行或縮句。
- 中（3–4 倍）：`UI_ULTIMATE_TITLE`、`status.stun`、`UI_DUEL_REJECT`（按鈕）、`battle.dp`、`status.shield`、`status.curse`、`battle.deploy`、`battle.strategy`、`duel.*` 的標題與按鈕。建議：按鈕與標題改為可換行或自動縮字。
- 低：`duel.challenge_desc`、`battle.damage.receive`、`battle.heal.receive`、`status.buff_*`（≤ 1.8 倍）。
- ja 整體膨脹低於 2.5 倍，最高為 `UI_ULTIMATE_CANCEL`（2.5 倍，按鈕）。
- 實機排版未驗證，待 Codex 在 Web 建置中抽查高風險項。

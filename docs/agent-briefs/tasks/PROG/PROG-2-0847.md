# [PROG-2-0847] i18n 溢出檢查工具支援扁平語系檔

## 開單原因
PM 2026-10-20 指示：`tools_node/i18n-overflow-check.js` 假設每個語系是一個目錄，本專案的語系是扁平檔 `assets/resources/i18n/{locale}.json`，所以工具一跑就報「找不到 zh-TW」，無法產出寬度風險摘要。

## 完整描述
- `loadLocale` 先找目錄；找不到目錄時改讀 `{locale}.json` 扁平檔。
- 扁平檔的 `_comment*` 註解鍵不計入檢查。
- 其餘演算法（字元寬度估算、閾值 1.3）不動。

## 暫定（可逆）
- 扁平檔的 key 本身就含點號（如 `ui.result.title`），直接當作完整 key 使用，不再攤平。

## 如何驗證
1. `node tools_node/i18n-overflow-check.js --locale en`：可輸出風險表，缺譯清單正確列出尚未合併的 key。
2. `node tools_node/i18n-overflow-check.js --locale ja`：同上。
3. compute-gate standard 通過。

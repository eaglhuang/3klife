# [PROG-2-0852] 存檔改為規格 Root Save（含 Data 區塊）— MVP 後

## 基本資訊
| 欄位 | 值 |

## 完整描述
PM 裁定（2026-10-20）：MVP 期間存檔維持扁平 PlayerSaveSnapshot，SAVE_VERSION_LATEST 維持 1.0.0；規格 Root Save（`{Player_ID, Save_Version, Last_Sync_Hash, Data:{…}, Action_Records}`）排到 MVP 之後再做。本卡只登錄，不實作。

## 查證結果（實作前必讀）
1. 正式存檔是扁平 PlayerSaveSnapshot，沒有 `Data` 區塊。`DataMounts.ts` 的遷移步驟作用於 `Data`，直接接到現在的讀取路徑會把不存在的 `Data` 寫進每份存檔。
2. `runSemverMigrations`、`toSaveEnvelope`、`fromSaveEnvelope` 目前沒有正式呼叫端，只有測試在用。
3. `SAVE_VERSION_LATEST` 只影響寫入時的版號戳記。升到 1.0.1 不會讓任何遷移生效。

## 驗收（MVP 後定）
- 存檔寫入為 Root Save 形狀，且可讀回扁平舊檔（經遷移）。
- 舊扁平存檔載入不遺失資料；遷移鏈經 `runSemverMigrations` 串接並有測試。
- run-cli 全數通過；compute gate standard 通過。

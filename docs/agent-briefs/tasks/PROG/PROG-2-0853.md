## 完整描述
BRD-12 驗收條件：子嗣與結緣紀錄可序列化存取；Server 表 Child_UID／Breeding_Mode／EP_Actual／Birth_Season／Unveil_Season 等欄位齊備。
本卡交付純邏輯部分：本機端與 Server 端紀錄型別、欄位驗證、子嗣轉表列，以及 JSON 序列化與讀回驗證。

## 設計選擇（我的判斷）
- 規格兩端欄位名不同（本機 Father_ID/UID，Server Father_UID/Child_UID），轉換集中在 `toServerChildRow`。
- Unveil_Season 依規格固定為 Birth + 20，表列驗證會擋偏離值。
- 讀回與寫入都驗證，壞資料丟錯，不產生半套資料。
- Child.Status 規格只舉 Mystery，未列完整列舉，目前只驗非空字串，不擅自列舉。

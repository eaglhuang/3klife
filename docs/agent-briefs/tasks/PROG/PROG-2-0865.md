## 現有行為（已查，不改）
`LegacyService.retireGeneral` 把武將標成 `isMentorCard: true` 並留在名冊內（`roster.map` 替換，沒有移除）。
所以退役武將仍在名冊裡，可以直接在它身上記 `catalystUsed`。

## 設計
- `GameSession.retireGeneral(generalId, options?: { catalystChildId?: string })`：
  - 不帶 `catalystChildId`：行為完全不變。
  - 帶了：先驗證子嗣（存在、年齡 0~`UNVEILING_AGE`、尚未開獎），驗證失敗拋錯，且不改任何狀態。
  - 退役武將已用過媒介（`catalystUsed`）時，不注入，不消耗，退役照常完成。
  - 通過後以 `injectCatalystFactor` 注入，亂數用 `this._random`（存檔亂數，Q25）。
  - 擲過骰（`consumed`）才把退役武將標成 `catalystUsed`。
  - 子嗣與退役武將的更新和退役一起 `replaceAll`，只存一次檔。
  - 發出 `GeneCatalystInjected` 事件，payload 為 `{ childId, injectedFactorId, consumed }`。
- 子嗣年齡上限用 `UNVEILING_AGE`（5）：規格寫 0~5 歲，年滿 5 歲時才開獎，所以 5 歲仍屬於 0~5 歲。

## 範圍
- `assets/scripts/core/managers/GameSession.ts`：`retireGeneral` 加選用參數、事件常數 `GeneCatalystInjected`。
- `tests/GameSessionCatalyst.test.ts`（新增）：無媒介時行為不變、注入後子嗣與退役武將狀態、子嗣年齡不合法時拋錯且不改名冊、已用過時不注入。

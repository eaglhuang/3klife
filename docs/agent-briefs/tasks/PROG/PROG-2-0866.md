## 現況
- `ui/core/RetirementFlowController.ts`：純 TS 控制器，管理退役候選、選擇、二次確認，依賴注入 `retireGeneral`。
- `ui/components/GeneralListComposite.ts`：退役工具列（下一位／退役轉教官／取消），由控制器驅動。

## 設計
- **媒介是武將的一次性旗標，不是道具**：退役時選一位 0~5 歲、未開獎的子嗣即可，不需要庫存。所以取得來源與 UI 無關，仍記待使用者裁決。
- 控制器新增：
  - `catalystChildren()`：候選子嗣（0~`UNVEILING_AGE` 歲、未開獎、未死亡、不是目前退役武將）。
  - `selectNextCatalystChild()`：循環 無 → 子嗣1 → … → 無。
  - `catalystChild`：目前選中的子嗣（退役目標改變時自動清空）。
  - `retire()`：有選子嗣時，把 `{ catalystChildId }` 傳給 `deps.retireGeneral`。
- 視圖：工具列新增「媒介：無／子嗣名」按鈕，按下循環選擇；退役目標的文字顯示目前媒介。
- 驗證失敗（子嗣不合法）由 GameSession 拋錯，控制器既有的 `failed` 分支會把訊息顯示在 notice。

## 範圍
- `assets/scripts/ui/core/RetirementFlowController.ts`：新增媒介選擇與傳遞。
- `assets/scripts/ui/components/GeneralListComposite.ts`：新增一顆按鈕與刷新邏輯。
- `tests/RetirementFlowCatalyst.test.ts`（新增）：候選範圍、循環選擇、退役時傳入參數、目標改變時清空、不選時不傳參數。

## 設計
- `core/systems/BreedingBirthRecord.ts`：`buildBreedingBirthRecord(result, omen)`。只有 `conceived` 且有子嗣才產生；組出會話與子嗣紀錄後用 schema 驗證，失敗回報 errors 且 record 為 null。純函式。
- `core/managers/GameSession.ts`：`recordBreedingBirth(record)` 寫入記憶體；`breedingBirthRecords()` 回傳複本。本局內有效，未進存檔（暫定）。
- `ui/core/BondingSetupController.ts`：可選依賴 `recordBreeding`。結緣成功時先算一次天象（`omen`），通知文字與紀錄共用同一個值；驗證通過才呼叫 `recordBreeding`。驗證失敗不影響結緣結果。
- `ui/scenes/LobbyScene.ts`：接 `recordBreeding: (r) => services().session.recordBreedingBirth(r)`。

## 暫定
- `Oracle_Hints` 先給空陣列（名士批語的記錄格式待定）。
- 子嗣 `Status` 沒有時寫 `'Unknown'`；`Is_Daqi` 取 `fate.lateBloomer`，沒有則 `false`。
- 紀錄只存記憶體，不進存檔、不送 server（WBS 規定 Server 端不連外部服務）。

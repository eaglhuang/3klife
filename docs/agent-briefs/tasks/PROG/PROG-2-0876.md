## 問題
`tsconfig.cc-check.json` 是 `strict: false`。在這個設定下，`if (!x.ok)` 或 `x.ok ? a : b` 不會把 `{ ok: true } | { ok: false; reason }` 收窄，於是讀 `reason`、`stage`、`errors`、`blocked` 等欄位時報 TS2339 / TS2322。

## 做法
把判斷改成 `=== true` / `=== false`。布林值的語意不變，只是讓型別檢查器能收窄。

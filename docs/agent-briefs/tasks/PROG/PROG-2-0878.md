## 規格
運氣系統.md「LUK 特殊門檻效果」：LUK = MAX(100) 時可解鎖「天命傳承」，額外繼承一個曾祖代因子。

## 暫定
- 曾祖代 = 第 3 世代祖先來源，與 `inheritFactors` 的 generation 定義一致。
- 候選：曾祖代身上、色系已啟用、子嗣尚未擁有的因子；隨機挑一個。
- 星級沿用第 3 世代的星級分布，並以因子 maxLevel 封頂。
- 「額外」：不計入 maxFactors 名額，可以超過上限。
- 沒有候選時不消耗亂數；有候選時消耗兩次（挑選一次、星級一次）。
- 套用位置在子嗣生成前（與血統變異同一段），門檻未達時完全不變。

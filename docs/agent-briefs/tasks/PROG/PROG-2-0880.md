## 設計
- `core/services/PlayerSaveTableRows.ts`：`mapSnapshotToSixTables(snapshot)` 把快照映射成 generals／mercenaries／player_resources 列，並以鏡像的 CHECK 規則驗證。純函式。
- `core/services/PlayerSaveService.ts`：`save()` 在寫入前呼叫映射與驗證，錯誤存在 `lastSixTableErrors()`；只回報，不阻擋存檔。
- core 不可引用 server（模組邊界），所以規則在 core 內鏡像；測試端用 server 的驗證器交叉檢查口徑一致。

## 暫定
- 存檔沒有玩家 id，先用 `local-player`。
- 傭兵沒有對應 upkeep 紀錄時視為 Active。
- essence 存檔沒有來源，暫定 0。
- 缺欄位保留空值由規則回報，不補預設（武將的模板與血脈欄位）。

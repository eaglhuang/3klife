## 設計
- `cc/env` 是 Cocos 編譯期的環境常數（DEV、EDITOR 等）。雲端 cc-check 沒有編輯器產生的型別來源，所以找不到。
- 新增 `types/cc-env.d.ts`，只宣告 DEV、EDITOR、PREVIEW、BUILD、TEST 五個 boolean。
- 只在 `tsconfig.cc-check.json` 的 include 納入，不影響 Cocos 編譯或主 tsconfig。

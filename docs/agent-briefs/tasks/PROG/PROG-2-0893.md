# [PROG-2-0893] LobbyScene 武將列表 options 型別補 npcDialogueSaveId

## 開單原因
`tsc -p tsconfig.cc-check.json` 在 `ui/scenes/LobbyScene.ts` 報 2 個 TS2353（2918、2926 行）：`_showGeneralListWithHandler` 的 `options` 參數型別沒有 `npcDialogueSaveId`，但呼叫端有傳，而 `GeneralListOpenPayload` 已定義此欄位。

## 完整描述
`_showGeneralListWithHandler` 的參數型別改為沿用 `GeneralListOpenPayload['options']`，與開啟武將列表的 payload 型別同源，不另寫一份。執行期行為不變。

## 做法
1. `assets/scripts/ui/scenes/LobbyScene.ts`：把 `_showGeneralListWithHandler` 的 `options` 型別換成 `NonNullable<GeneralListOpenPayload['options']>`。預設值保留 `{ factionFilter: 'all' }`。

## 如何驗證
1. `npx tsc -p tsconfig.cc-check.json --noEmit` 中 LobbyScene 的 TS2353 消失。
2. run-cli 全綠；compute-gate standard 9/9。

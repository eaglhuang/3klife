# [PROG-2-0894] LobbyScene 缺匯出修正（UIManagedController／remarkRandomOf）

## 開單原因
`tsc -p tsconfig.cc-check.json --noEmit` 在 `ui/scenes/LobbyScene.ts` 報兩類缺匯出：
- `UIManagedController` 不存在於 `core/managers/UIManager.ts`。UIManager 本身一律用 `shared/interfaces/IUIInterfaces` 的 `IUIManagedController`。
- `remarkRandomOf` 不存在於 `core/systems/SageRemarks.ts`。呼叫端要的是「依武將配對字串確定性產生 `() => number`」，供 `buildSageRemarks` 使用。

## 完整描述
1. LobbyScene 的 `UIManagedController` 改為 `IUIManagedController`（沿用 shared 介面，不另造型別別名）。
2. `SageRemarks.ts` 新增 `remarkRandomOf(seedKey: string): () => number`：以 FNV-1a 把字串雜湊成 32 位種子，再交給既有 `SeededRandom`（mulberry32-v1）。同一對父母永遠得到同一串亂數，與 `hashId` 的做法一致。
3. `tests/SageRemarks.test.ts` 補一個案例：同 key 結果可重現，不同 key 結果不同。

## 做法
見上方 1–3。執行期行為只新增 `remarkRandomOf`，既有 `buildSageRemarks` 不變。

## 如何驗證
1. `tsc -p tsconfig.cc-check.json --noEmit` 中 LobbyScene 的 TS2305 兩筆消失。
2. run-cli 全綠；compute-gate standard 9/9。

# [PROG-2-0895] DeployPanel 吐司型別轉換（Component→ToastMessageLike）

## 開單原因
`tsc -p tsconfig.cc-check.json --noEmit` 在 `ui/components/DeployPanel.ts` 報 TS2352：`toastNode.getComponent(...)` 的鏈式結果是 `Component`，直接 `as ToastMessageLike` 被判定為無重疊。

## 完整描述
同檔案第 1040 行已用 `as unknown as ToastMessageLike` 處理同樣的轉換。第 1031 行改用同一寫法，與既有風格一致，執行期行為不變。

## 做法
1. `assets/scripts/ui/components/DeployPanel.ts` 第 1031–1035 行：`as ToastMessageLike | null` 改為 `as unknown as ToastMessageLike | null`。

## 如何驗證

# [PROG-2-0898] GameSession 借用檢查收窄（BorrowCheck.blocked）

## 開單原因
`tsc -p tsconfig.cc-check.json --noEmit` 在 `core/managers/GameSession.ts` 報 TS2339：`if (!check.ok) return { ok: false, blocked: check.blocked }` 中，`check` 在 `!check.ok` 分支沒有被收窄成 `{ ok: false; blocked }`，所以 `blocked` 不存在於 `BorrowCheck` 聯集。

## 完整描述
規格查核：`canBorrow` 的回傳型別（`FriendBorrow.ts`）已定義 `BorrowCheck = { ok: true } | { ok: false; blocked: BorrowBlockReason }`，本卡沒有改變借用規則或檢查順序，屬型別收窄問題，規格無需變更。

修法：把判斷改成明確比對 `check.ok === false`，讓 TypeScript 收窄到 `blocked` 分支。執行期行為不變（兩者對 `ok` 的布林值判斷一致）。

## 做法
1. `assets/scripts/core/managers/GameSession.ts`：`if (!check.ok) return ...` 改為 `if (check.ok === false) return ...`。

## 如何驗證
1. `tsc -p tsconfig.cc-check.json --noEmit` 中 GameSession 的 TS2339 消失。
2. run-cli 全綠（含借用相關測試）；compute-gate standard 9/9。

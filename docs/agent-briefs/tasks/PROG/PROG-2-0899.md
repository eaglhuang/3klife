# [PROG-2-0899] UIScreenRuntimeStateRegistry 版本核對參數型別（content）

## 開單原因
`tsc -p tsconfig.cc-check.json --noEmit` 在 `ui/core/UIScreenRuntimeStateRegistry.ts` 第 187、190 行報 TS2339：`assertRouteMatchesScreen` 的 `screen` 參數型別是 `UIScreenSpec`，該型別沒有 `content`，但函式內要讀 `screen.content?.source`。

## 完整描述
同一檔案已定義 `UIScreenSpecWithContent`（`UIScreenSpec & { content?: {...} }`），`loadScreen` 的呼叫端與第 128 行的函式都用這個型別。本卡只把 `assertRouteMatchesScreen` 的參數改成同一型別，不改檢查邏輯。

## 做法
1. `assets/scripts/ui/core/UIScreenRuntimeStateRegistry.ts`：`assertRouteMatchesScreen(screen: UIScreenSpec, ...)` 改為 `screen: UIScreenSpecWithContent`。

## 如何驗證
1. `tsc -p tsconfig.cc-check.json --noEmit` 中 UIScreenRuntimeStateRegistry 的 TS2339 兩筆消失。
2. run-cli 全綠；compute-gate standard 9/9。

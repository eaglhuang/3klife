# [PROG-2-0901] 改派建議 Deploy_Suggestion（DEP-10）

## 開單原因
WBS v13 DEP-10（P1，未開始）：戰場部署系統 §部署失敗與改派建議。規格：原目標不可部署時，UI 推薦玩家可主動改派的低耗部隊；玩家必須再次確認，不自動改派。DEP-03 的三種不可部署原因已接線，建議部分尚無。

## 完整描述
規格 `戰場部署系統.md` 的 `Deploy_Suggestion`：不可部署時給出一個可派出的低耗部隊，文案「可改派低耗部隊：{TroopName}。」。

## 做法
1. `core/systems/SortieDeploy.ts` 新增純函式 `suggestLowCostDeploy(state, deniedType, candidateTypes)`：排除被擋的兵種，依 `checkDeploy` 通過者取糧耗最低、其次兵力耗最低；同分取候選順序較前者；沒有則回 `null`。
2. `battle/controllers/BattleController.ts` 的部署失敗回傳 `DeployOutcome` 加上 `suggestion`（候選為 `UNIT_TROOP_COST` 的兵種）。只回傳建議，不改部署結果（不自動改派）。
3. 新增 `tests/SortieDeploySuggestion.test.ts`。

## 如何驗證
1. run-cli 全綠；compute-gate standard；`tsc -p tsconfig.test.json` 無本卡新增錯誤。

## 缺口
- 「可改派」的 UI 文案與二次確認視窗未做（cc 畫面接線另開）。
- 「低耗」以糧耗、再以兵力耗排序，是暫定；規格未寫排序規則。

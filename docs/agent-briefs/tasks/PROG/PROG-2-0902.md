# [PROG-2-0902] 改派建議文案接上部署畫面（DEP-10 cc 接線）

## 開單原因
PROG-2-0901 已由 `BattleController` 回傳 `suggestion`，但兩個部署面板（`DeployPanel`、`DeployComposite`）的失敗提示還沒顯示。規格 `戰場部署系統.md` §G 與 §H：改派建議文案「可改派低耗部隊：{TroopName}。」，UI 只推薦、不自動改派。協調者 PM 指示：文案與二次確認由本線接著做。

## 完整描述
1. `SortieDeploy.ts` 新增純函式 `deploySuggestionCopy(troopName)`，回傳規格文案。
2. 兩個部署面板的部署失敗提示，若回傳帶 `suggestion`，在原提示後附上改派文案（兵種顯示名沿用各面板既有的名稱對照）。
3. 不改部署結果，不自動改派。

## 如何驗證
1. `tests/SortieDeploySuggestion.test.ts` 新增文案案例。
2. run-cli 全綠；compute-gate standard；`tsc -p tsconfig.test.json` 無本卡新增錯誤。

# [PROG-2-0903] 改派二次確認（點兩次，A 案）

## 開單原因
規格 `戰場部署系統.md` §部署失敗與改派建議：UI 可推薦低耗部隊，但玩家必須再次確認，不自動改派。PROG-2-0902 只把建議寫進失敗提示。PM 裁定採 A 案：沿用既有部署面板，不做新視窗。

## 完整描述
1. `SortieDeploy.ts` 新增純函式 `nextRedirectStep`：第一次點不可部署的目標 → 記下建議（arm）；同一目標、同一格、同一建議的第二次點 → 確認改派（confirm）；沒有建議 → 清空（none）。
2. `DeployPanel.ts`、`DeployComposite.ts`：依 step 處理。arm 只顯示「再點一次確認改派」，confirm 才以建議兵種重新部署；成功後清空確認狀態。
3. 不做自動改派；確認狀態只存在面板記憶體中。

## 如何驗證
1. `tests/SortieDeploySuggestion.test.ts` 新增 `nextRedirectStep` 案例。
2. run-cli 全綠；compute-gate standard。

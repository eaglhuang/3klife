# [PROG-2-0904] 委任 AI 四級部署策略（DEP-11 純邏輯）

## 開單原因
WBS v13 DEP-11（P1，未開始，5.0）：委任 AI Auto-Battle 依武將智力分四級，保留糧草比例、保留特殊兵與器械槽有行為差異並有測試。規格 `戰場部署系統.md` §委任 AI：`getAIDeployQuality` 門檻 90 / 70 / 50，`AI_RESERVE_POLICY` 表。本線先做純決策，不接戰鬥流程。

## 完整描述
1. 新增 `core/systems/DelegateAi.ts`：
   - `delegateQualityOf(int)`：≥90 EXPERT、≥70 HIGH、≥50 MEDIUM、其餘 LOW。
   - `DELEGATE_RESERVE_POLICY`：照規格表（LOW 0 / MEDIUM 10% / HIGH 18% 且保留 1 槽 / EXPERT 25% 且保留 1 槽）。
   - `delegateDecideDeploy(state, request, quality, { bossTargetVisible })`：依序判斷部署合法性（checkDeploy）、糧草保留線（`maxFood × 比例`）、精銳保留槽（非主將目標時不得佔用保留的精銳名額）、特殊兵只留給主將戰（`bossTargetVisible`）。回傳 deploy 與原因。
2. 純決策，不改 `SortieState`，不接 BattleController 自動流程（目前沒有自動戰鬥入口）。
3. 新增 `tests/DelegateAi.test.ts`。

## 如何驗證
1. 四級門檻邊界、LOW 不保留、MEDIUM 糧草線、HIGH 特殊兵等主將戰、精銳保留槽等案例。
2. run-cli 全綠；compute-gate standard。

## 缺口
- 「依 scenePresetId 與敵方陣容選高 TigerTallyScore 單位」（EXPERT）與「剋制部署」未做，需要敵方陣容資料與虎符分數，另開卡。

- 委任 AI 尚無自動戰鬥入口，本卡沒有呼叫端。

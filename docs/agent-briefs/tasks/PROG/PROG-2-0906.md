# [PROG-2-0906] 修 DeployPanel 改派建議的 TS 錯誤

## 開單原因
PM 指示（2026-10-21 02:27Z）：底座線回報 DeployPanel 有 TS 錯誤。#707（PROG-2-0903 改派點兩次確認）已於 02:31Z 合併，依 PM 指示從 master 開卡修正。

## 錯誤位置（master c86c0dc6 實測）
1. `DeployPanel.ts` `onDeployClick` 讀 `outcome.suggestion`，但 `IDeployController.tryDeployTroop` 回傳型別只有 `{ ok, reason? }`（TS2339）。
2. `DeployPanel.ts` 有兩個 `toTroopDisplayName`（TS2393）。第一個是 #696 (PROG-2-0902) 新增、與原有的同名方法重複，刪除新增的那個。

## 完整描述
1. `assets/scripts/shared/interfaces/IBattleUIComponents.ts`：`IDeployController.tryDeployTroop` 回傳型別補 `suggestion?: string | null`，與 BattleController 的 `DeployOutcome` 對齊。
2. `assets/scripts/ui/components/DeployPanel.ts`：刪除 #696 新增的重複 `toTroopDisplayName`（保留原有那個，映射相同）。
3. 不動底座的其他檔案。

## 如何驗證
1. 用獨立 tsconfig 對 DeployPanel.ts 做型別檢查：TS2339 `suggestion` 與 TS2393 消失（cc 型別缺失的雜訊不算）。
2. `npm test` 全綠；`tsc -p tsconfig.test.json` 無新增錯誤。
3. compute-gate standard。

# [PROG-2-0907] 戰法 AI 選技規則（TAC-15 純規則層）

## 開單原因
PM/協調線指示（2026-10-21 02:35Z）：#719 合併前從 WBS v14 戰場段自選不相依的卡。TAC-15 依賴 TAC-09（已接線），WBS 狀態未開始。

## 規格來源
- `戰法系統-shards/g5.md` Step 6 AI 規則層：單體傷害優先看斬殺線；Buff / Heal 優先看我方危險值；Tile / Scene 類優先看 choke point、密集區、天氣相容。
- `AI武將強度系統.md` `AI_UseTactic`：高 IQ 依場上情況選最優戰法。

## 完整描述
1. 新增 `battle/shared/TacticAiRules.ts`（純邏輯，不依賴 cc）：
   - `scoreTacticCandidate(candidate, situation)`：依類別算分。
     - `single-damage`：傷害為基礎分；若有敵方 HP ≤ 預估傷害（斬殺線）加斬殺加分。
     - `buff-heal`：我方最低 HP 比例 ≤ 危險線時，效果值加高分；否則降權。
     - `tile-scene`：choke point、密集區、天氣相容各加分；天氣不相容直接不選。
   - `pickTacticByAiRule(candidates, situation)`：回傳最高分的戰法 id；全部 0 分或沒有候選時回 null。
2. 門檻為暫定：斬殺加分、危險線 35%、降權比例。規格未寫數字，之後由待使用者裁決或數值平衡調整。
3. 不接戰鬥流程（EnemyAI / BattleController 呼叫端另開卡）。

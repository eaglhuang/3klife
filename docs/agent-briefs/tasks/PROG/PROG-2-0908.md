# [PROG-2-0908] 委任 AI 接上 BattleController（DEP-11 呼叫端）

## 開單原因
#719（PROG-2-0905 `delegatePickDeploy`）已合併。協調線設計（2026-10-21）：委任開啟後，BattleController 在玩家部署時呼叫委任挑選；候選依 DEP-11 保留策略過濾，並依糧耗低→兵力耗低排序（與 DEP-10 同規則）。

## 完整描述
1. `core/systems/DelegateAi.ts`：新增 `sortDelegateCandidates(state, candidates)`，依糧耗、兵力耗由低到高排序（不合法的排後面，同值保留原順序）。
2. `battle/controllers/BattleController.ts`：
   - `enableDelegateFromGeneral()`：依我方主將智力 `delegateQualityOf(int)` 開啟委任；無主將則關閉。
   - `disableDelegate()`：關閉。
   - `tryDelegateDeploy(lane, situation?)`：委任未開或無出征帳本時回 null；否則同步帳本、排序候選、`delegatePickDeploy` 挑兵種，再走既有 `tryDeployTroop`。
3. 路（lane）由呼叫端決定，不在控制器內擅自挑。
4. 不做委任開關 cc UI（另開卡）；每回合自動呼叫的時機也由呼叫端決定（另開卡）。

## 如何驗證
1. `sortDelegateCandidates`：糧耗排序、同糧耗依兵力、不合法排後。
2. BattleController：委任開啟後 tryDelegateDeploy 會部署一隊並扣糧；未開啟回 null。
3. run-cli 全綠；compute-gate standard。

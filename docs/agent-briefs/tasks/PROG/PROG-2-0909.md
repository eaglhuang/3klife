# [PROG-2-0909] CharacterDs3StatsChild 生命條綁定型別（_bindVital）

## 開單原因
`tsc -p tsconfig.cc-check.json --noEmit` 在 `ui/components/character-ds3/CharacterDs3StatsChild.ts` 第 152、153 行報 TS2345：`_bindVital` 的參數型別是 `typeof VITAL_BINDINGS.hp`，而 `VITAL_BINDINGS` 用 `as const`，`hp` 的節點名是字面型別，`sp`、`vitality` 的字面型別不同，無法傳入。

## 完整描述
新增 `VitalBindingDefinition` 介面（四個欄位都是 `string`），與同檔既有的 `StatRowDefinition` 寫法一致。`_bindVital` 參數改用此介面。`VITAL_BINDINGS` 保留 `as const`，執行期行為不變。

## 做法
1. `assets/scripts/ui/components/character-ds3/CharacterDs3StatsChild.ts`：在 `VITAL_BINDINGS` 前新增 `VitalBindingDefinition` 介面；`_bindVital(binding: typeof VITAL_BINDINGS.hp)` 改為 `_bindVital(binding: VitalBindingDefinition)`。

## 如何驗證
1. `tsc -p tsconfig.cc-check.json --noEmit` 中 CharacterDs3StatsChild 的 TS2345 兩筆消失。
2. run-cli 全綠；compute-gate standard 9/9。

# [PROG-2-0912] 敵方戰法候選來源（EnemyAI 接線第 1 段）

## 開單原因
PROG-2-0907 的 `pickTacticByAiRule` 已合併，但 EnemyAI 目前沒有戰法選技路徑，也沒有敵方候選來源。協調線同意拆成兩段：第 1 段先從敵方武將的戰法槽產生候選清單，第 2 段再接到敵方回合。

## 完整描述
1. 新增 `battle/shared/EnemyTacticCandidates.ts`（純邏輯）：
   - `tacticAiCategoryOf(libraryCategory)`：把戰法庫分類對到 `TacticAiCategory`。暫定對照：`support`→buff-heal；`formation`、`ambush`→tile-scene；`charge`、`ranged`、`scheme`、`control`、`duel`→single-damage。未知分類回 null，不選。
   - `buildEnemyTacticCandidates(slots, library)`：逐一讀武將戰法槽，跳過 `source === 'locked'` 的槽，跳過戰法庫查不到或分類未知的戰法，同一戰法 id 只留一次。產生的候選只帶 `tacticId` 與 `category`，數值欄位留空，由第 2 段依戰況填入。
2. 不改 EnemyAI、BattleController 的流程。

## 如何驗證
1. `tests/EnemyTacticCandidates.test.ts`：分類對照、鎖定槽跳過、未知戰法跳過、去重、空槽回空陣列。
2. run-cli 全綠；compute-gate standard。

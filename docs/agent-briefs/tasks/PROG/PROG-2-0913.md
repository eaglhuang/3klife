# [PROG-2-0913] 委任開關接上玩家部署階段（DEP-11 cc 接線）

## 開單原因
#731（PROG-2-0908）已合併。PM 決定（2026-10-21 07:04Z）：玩家部署階段開始時（敵方部署之前）呼叫一次 `tryDelegateDeploy`，開關開啟才觸發；路由取我方部隊最少、同數取小路號；cc 版面接線由本線自行完成，卡標 in-review，座標微調交 Codex 驗收。

## 完整描述
1. `BattleController`：
   - `runPlayerDelegateDeployPhase()`：委任關閉時不做事；開啟時呼叫 `tryDelegateDeploy(pickDelegateLane())`。在 `enemy-deploy` 階段的 case 內、敵方部署之前呼叫。
   - `pickDelegateLane()`：我方存活部隊最少的路，同數取較小路號（暫定）。
   - `setDelegateEnabled(on)`、`isDelegateEnabled()`。
2. `IDeployController`：增加 `setDelegateEnabled`、`isDelegateEnabled`。
3. `DeployPanel`：`btnDelegate`（`@property(Button)`，由 cc 場景綁定），點擊時反向切換開關並以吐司回報。
4. 版面說明：DeployPanel 的功能按鈕是場景節點（綁定在 .scene，程式只設定位置），`deploy-panel-main.json` 只描述資訊列，沒有按鈕節點。因此開關按鈕不寫進 layout JSON；版面與按鈕座標交 Codex 驗收。吐司文案暫為內嵌字串，與同檔其他吐司一致。

## 如何驗證
1. `tests/DelegateWiring.test.ts`：路由（最少、同數取小路號）、委任關閉不部署、開啟後部署一隊、開關切換。
2. run-cli 全綠；`tsc -p tsconfig.test.json` 無新增錯誤；compute-gate standard。
3. cc 畫面未在雲端驗證（無法建置），交 Codex 實機確認。

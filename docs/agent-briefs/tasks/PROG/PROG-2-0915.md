# [PROG-2-0915] 戰法預估傷害（敵方選技的數值來源）

## 開單原因
PROG-2-0914 的 `pickEnemyTactic` 需要「單體傷害預估」才能做斬殺判斷，但 `ProjectedDamageSkillResolver` 是實際執行傷害的 resolver，沒有回傳預估值。PM 指示（2026-10-21 07:13Z）：開純函式卡，沿用 `FormulaSystem.calculateDamage` 這套公式，不另編。

## 完整描述
1. 新增 `battle/shared/TacticDamageEstimate.ts`（純邏輯）：
   - `estimateTacticDamage(context, multiplier = 1, formula = new FormulaSystem())`：以同一個 `FormulaSystem.calculateDamage` 算出基礎傷害，再乘以戰法倍率、向下取整，最低 1。
2. 不改 `BattleSkillDamageResolver` 與 `ProjectedDamageSkillResolver`（避免動到實際戰鬥流程）。
3. 規格已知的戰法加成（蓄力、首回合、天氣、階段倍率）不在估算內，估算只看單次命中的基礎傷害，之後由呼叫端決定是否加倍率；此限制記入待辦檔。

## 如何驗證
1. `tests/TacticDamageEstimate.test.ts`：倍率 1 等於 `FormulaSystem.calculateDamage`；倍率 0.5 約減半；結果不低於 1；預設公式實例與傳入實例結果一致。
2. run-cli 全綠；compute-gate standard。

# [PROG-2-0917] 虎符裁決欄位約束（TERM-07）

## 開單原因
PM 巡檢要求挑一張 P1 純邏輯、不碰 BattleController 回合流程的卡。WBS v15 的 TERM-07 是 P1、類型 logic，驗收條件為：糧耗與 Set 羈絆各自只有一個常數來源，schema 不含 `Cooldown_Turns`、`TallyCategory`。

## 現況（開卡時核對）
- 糧耗：`TALLY_GRAIN_COST` 在 `core/systems/SortieDeploy.ts`，`getTallyGrainCost` 為唯一查表入口，fallback 20。
- Set 羈絆：WBS 寫的 `SET_BONUS_DEFS` 實際名稱為 `TIGER_TALLY_SET_DEFS`，在 `core/systems/TigerTallySetBonus.ts`，`fieldTallySetMods` 為唯一套用入口。
- `Cooldown_Turns`、`TallyCategory` 只出現在規格文件，程式與 `assets/resources/data` 內沒有。

## 完整描述
1. 新增 `tests/TigerTallyRuleConstraints.test.ts`（純測試，不改產品程式）：
   - 糧耗表四個品質都有星級 1 起的查表值，`getTallyGrainCost` 對未知品質回 fallback。
   - `TIGER_TALLY_SET_DEFS` 每筆 def 只含 `setId / name / memberTroopIds / requiredCount / bonus`，不含冷卻或分類欄位。
   - 掃描 `assets/scripts` 與 `assets/resources/data`，不得出現 `Cooldown_Turns`、`TallyCategory`、`tallyCategory`、`cooldownTurns`。
2. 名稱差異（SET_BONUS_DEFS → TIGER_TALLY_SET_DEFS）以程式實名為準，記在待辦檔。

## 如何驗證
1. 新測試全綠；run-cli 全綠。
2. `npx tsc -p tsconfig.test.json --noEmit` 只剩 master 既有 4 個錯誤。

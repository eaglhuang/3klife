# [PROG-2-0918] 敵方選技接進敵方回合（EnemyAI 接線）

## 開單原因
PROG-2-0912、0914、0915 的純邏輯（戰法候選、數值填入與選技、預估傷害）已合併，但敵方回合仍只施放武將主技能。PM 同意接線。

## 完整描述
1. `BattleController.chooseEnemyTactic()`：敵將戰法槽 → `buildEnemyTacticCandidates` → 填入數值 → `pickEnemyTactic`，回傳 `{ tacticId, battleSkillId }`；沒有可選時回 null。
2. 數值（暫定）：單體傷害以我方血量最低的單位估算（`estimateTacticDamage`，倍率 1、地形平原）；效果值與地形不填。
3. `BattleSpecialResolvePhase`：敵方施放時先問 `chooseEnemyTactic`，有結果就用它的 battleSkillId 與 tacticId，沒有則退回武將主技能。
4. `castEnemySeedTactic` 多帶 tacticId，交給 `castBattleSkill`（PROG-2-0916）。

## 如何驗證
1. `tests/EnemyTacticTurnE2E.test.ts`：無戰法槽回 null；有戰法槽挑出戰法；6 回合真實流程內敵方以該戰法施放；玩家施放路徑不受影響。
2. run-cli 全綠；tsc 只剩 master 既有 4 個。

## 已知限制
- 敵將 SP 目前由 `initBattle` 歸零後只靠既有機制回復；本卡沒有改 SP 規則。
- 效果值與地形未填，buff-heal 與 tile-scene 類戰法在本卡內分數為 0，只在單體傷害類戰法有機會被選中。

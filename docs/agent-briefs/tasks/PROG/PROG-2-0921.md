# [PROG-2-0921] 戰鬥入口寫入 AI 難度

## 開單原因
PROG-2-0920 的 `BattleState.aiDifficulty` 只有預設值，沒有來源。PM 裁定：難度由戰鬥入口參數寫入；遭遇資料有 `difficulty` 欄位就讀，沒有則 NORMAL。玩家設定選單之後再說。

## 完整描述
1. `resolveAiDifficulty(...sources)`：依序取第一個合法難度，不合法或沒有則 NORMAL。
2. `EncounterConfig.difficulty?`（可選）與 `IBattleEntryParams.aiDifficulty?`（可選）。
3. `BattleController.initBattle` 新增最後一個可選參數 `aiDifficulty`（預設 `'normal'`），寫入 `state.aiDifficulty`。
4. `BattleScene` 與 `BattleSceneFlow` 兩個戰鬥入口，以 `resolveAiDifficulty(入口參數, encounter.difficulty)` 傳入。
5. `encounters.json` 目前沒有 difficulty 欄位，本卡不改資料，全部關卡仍是 NORMAL。

## 如何驗證
1. `tests/AiSpCharge.test.ts`：入口參數優先、遭遇資料次之、拼錯與缺省回 NORMAL；`initBattle` 傳入 hell 寫進 state，未傳則 normal。
2. run-cli 全綠；tsc 只剩 master 既有 4 個。

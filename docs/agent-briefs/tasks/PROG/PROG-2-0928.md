# [PROG-2-0928] 虎符特殊戰法管線（34 條接 BattleSkill）

## 開單原因
WBS v16.2 TRP-15：規格 34 條兵種專屬戰法（死亡傳承通用 17 + 名將專屬 17）要各自對應 battleSkillId，並有 smoke 測試。驗收條件：每條虎符戰法對應 battleSkillId 並有 smoke 測試。

## 現況（開卡時核對）
- `TigerTallyTacticAdapter.buildRequest` 已能組 TigerTally 來源的請求（TRP-04）。
- `BattleSkillProfiles` 原本只有 11 條虎符相關 profile（G-1／G-2 已落地的效果），其餘 23 條規格戰法沒有 battleSkillId。
- 規格表只給效果文字，沒有 coefficient 與目標形狀的數值。

## 完整描述
1. `assets/scripts/core/config/TigerTallySpecTactics.ts`：34 條對照表，欄位含 tacticId、battleSkillId、group、虎符名稱、兵種名稱、來源、品質、效果摘要、reusesProfile。
2. 11 條沿用既有 profile（陷陣→tally-defense-pierce、虎豹→tally-charge、無當→tally-poison-arrow、都督→tally-fire-chain、忠義符→tally-wei-zhen-hua-xia、當陽符→tally-changban-root、烈弓符→tally-hundred-steps、麒麟符→tally-counter-weak、無雙符→tally-wushuang、連環符→tally-link、火神符→tally-fire-god-hunt）。
3. 23 條建立殼 profile（`BattleSkillProfiles` 尾端迴圈）：targetMode EnemySingle、coefficient 0、無效果欄位。殼不造成傷害，避免在效果未實作前產生未定義的數值。
4. 測試 `tests/TigerTallySpecTactics.test.ts` 6 案例：數量與唯一性、每條都解析得到 profile、沿用 11／殼 23、殼 coefficient 0、陷陣防禦穿透 0.5、適配器對 34 條都能組出 TigerTally 請求。

## 裁決（暫定）
- 沿用既有 profile 時只採已落地的效果，不為了對齊規格文字去改舊 profile。
- 殼的 targetMode 一律 EnemySingle：規格形狀（周圍、範圍、全隊、自身）還未逐條確認，等效果卡再定。
- 都督（一般）沿用 tally-fire-chain：規格寫「弩箭標記後引燃草叢」，既有 profile 是十字火場，形狀近似但不完全相同，記入待辦。

## 殘留（不在本卡）
- 23 條殼的效果：移動、士氣、治療、叛變、陣亡連鎖、攻擊次數依男性相鄰等，需逐條另卡。
- 白馬義從的 battleSkillId 改用 `tally-bai-ma-yi-cong`，避免與 catalog 既有 `tiger-tally-bai-ma` 衝突，兩者尚未合併。

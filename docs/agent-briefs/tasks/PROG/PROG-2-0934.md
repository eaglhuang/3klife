# [PROG-2-0934] 數值系統 UI 字串進 i18n 並在戰場顯示（NUM-16）

## 來源
- WBS v16.2 NUM-16（戰場 P1，未開始，1.0）：`STAT_*`／`VAL_*`／`LABEL_*`／`POPUP_*` 與 G-1 文案進 i18n 並在戰場顯示。
- 規格：`數值系統.md` §H-1、§H-2。

## 範圍
- 四個語系（zh-TW、zh-CN、en、ja）新增 24 個 key：STAT 6 + 2 層、VAL 3、LABEL 7、POPUP 6。
- `VfxEffectConfig.ts`：暴擊飄字 `POPUP_CRIT`、未命中飄字 `POPUP_MISS`（原為硬字串）。
- `EffectSystem.ts`：飄字送出前經 `services().i18n.t` 翻譯；key 不存在時 `t` 會回傳原字串，既有飄字不受影響。
- `tests/BattleNumericStrings.test.ts`：5 案（完整性、繁中與英文對規格、飄字 key、既有 key 不被覆寫）。

## 不做
- G-1 劇本文案（含參數插值）不在本卡，屬另外的劇本 key 落地。
- 其餘飄字（攻擊力提升、戰敗等）保留硬字串，待各自的 i18n 卡處理。

## 暫定
- zh-CN、ja 全部翻譯，以及 en／zh-TW 中 H-2 之外的 POPUP 英文，為本卡自行決定。

# [PROG-2-0935] 數值配置 Server 表與熱更新比對（NUM-17）

## 來源
- WBS v16.2 NUM-17（戰場 P1，未開始，2.0）：Server 端 `numerical_config` 資料表與熱更新，config_key／value／version 可由 sync API 下發並讓客戶端比對版本。
- 規格：`數值系統.md` §I「Server 端」。
- 協調者 2026-10-27 指示：白因子等待裁決的卡先跳過，選不受阻的 MVP 卡。

- `server/schema/008_numerical_config.sql`：`numerical_config` 表，欄位與規格 §I 一致（DECIMAL(10,4)）。僅定義，不部署。
- `server/schema/num17-config-row.ts`：`validateNumericalConfigRow` 列驗證；`planNumericalConfigSync` 熱更新比對（新鍵與較新版本套用、較舊略過、同版同值略過、同版異值衝突）。

- 不做 sync API 本身（規格與 repo 限制：Server 只寫 schema 與驗證，不連外部服務）。
- 不接客戶端的配置載入流程。

## 暫定
- 同版本號但數值不同視為衝突，不套用，交呼叫端處理。

# [PROG-2-0940] 兵種／虎符 UI 字串進 i18n（TRP-19）

## 來源
- WBS v16.2 TRP-19（戰場 P1，未開始，1.0）：`UI_TALLY_*`、`UI_TROOP_*` 等 key 進入 i18n 且畫面引用。
- 規格：`兵種（虎符）系統.md` 的 UI 字串表（21 列）。

## 範圍
- 四個語系新增 21 個 key：`UI_TROOP_*` 7 個、`UI_TALLY_*` 14 個。
- 佔位符把規格的 `{TallyName}`、`{GeneralName}`、`{TroopName}`、`{Quality}`、`{Star}`、`{Gold}`、`{Essence}`、`{TerrainName}`、`{Grade}`、`{ClanName}`、`{Gender}` 依出現順序換成 `{0}`、`{1}`…（與既有 i18n 寫法一致）。
- `tests/BattleTallyStrings.test.ts`：3 案（存在且非空、四語系佔位符一致、繁中對規格）。

## 不做
- 畫面引用（把虎符彈窗、戰報改呼叫這些 key）另卡處理，本卡只落地字串。
- 劇本與圖鑑的其他文案不在本卡。

## 暫定
- 簡中、日文與英文翻譯由本卡自行決定。

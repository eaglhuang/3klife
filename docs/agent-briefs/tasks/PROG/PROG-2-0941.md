# [PROG-2-0941] 放走俘虜的未來來投（POW-07）

## 為什麼做
俘虜處理系統 §F：放走俘虜會獲得名聲，且「未來某季該武將主動來投」的機率為 5%。
`FUTURE_RETURN_CHANCE` 早已定義但沒有呼叫端，放走後俘虜就直接消失。

## 做什麼
- PrisonState 增加 `released` 名單，記錄被放走的武將與放走季。
- `addReleasedPrisoner`：放走時加入名單（回傳新狀態）。
- `rollFutureReturns(state, season, random)`：每季對「放走於更早季」的俘虜擲骰，中了就移出名單並回傳。

## 驗收
- 單元測試：放走進名單且不改原物件；當季放走不會當季來投；擲中與未中的分支；不合格者不消耗亂數；舊存檔正規化與壞項目略過。
- 純邏輯，未接 GameSession 與畫面。

## 暫定
- 每季各擲一次（規格只寫「未來某季」與 5%）。
- 來投者加回名冊的方式由呼叫端決定。

# [PROG-2-0942] 監獄格數與擴容（POW-06）

## 為什麼做
俘虜處理系統 §F：監獄初始 3 格、付費可擴到 10 格。關押、每季產出、滿格拒收已經接線；缺的是擴容本身。

## 做什麼
- `expandPrisonSlots(state)`：一次 +1 格，回傳新狀態（不改輸入）；達上限回傳 ok=false。
- 費用與扣款不在本卡，由呼叫端決定。

## 驗收
- 滿格關押被拒（PRISON_FULL）、不扣資源。
- 擴容後同一關押成功。
- 擴容到 PRISON_SLOTS_MAX 為止，之後被拒且狀態不變。
- 每季產出依關押者加總。

## 暫定
- 擴容一次 +1 格。規格檔不在本容器，步數與費用待 PM 核對。

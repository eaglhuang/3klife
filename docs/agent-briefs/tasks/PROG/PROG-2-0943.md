# [PROG-2-0943] 放走俘虜來投接線（POW-07 接線）

## 為什麼做
PROG-2-0941 已有 rollFutureReturns 純函式，但 GameSession 還沒呼叫，放走後的 5% 來投不會發生。

## 做什麼
- 放走時寫入 released 名單（targetUid、targetName、放走季）。
- 季結算時對名單擲 5%，中了的依 uid 從武將配置入冊；查不到配置則略過並警告，仍從名單移除。
- LobbyScene 載入 generals 後呼叫 setGeneralTemplates 注入配置。

## 驗收
- 放走進名單；同季結算不來投。
- 擲中入冊並從名單移除；未中留在名單；查無配置略過。

## 暫定
- 不快照武將，依 generals 配置以初始狀態重建（PM 2026-10-27 裁定）。
- 只有大廳載入過的容器會有配置。其他場景觸發季結算時查無配置會略過。
- 待辦檔（/mnt/project-files/reports）在本容器讀不到，此項記在本卡，待 PM 同步。

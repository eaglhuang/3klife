# [PROG-2-0944] 開場信件與教學引導文案入 i18n（COPY-02）

## 為什麼做
正式版劇本文案 §2.1（開場信件推薦版）與 §4（教學引導）目前只存在於規格檔，程式裡沒有 Key，無法依語系載入。

## 做什麼
- 兩個 Key 進四個語系：`copy.letter.opening.body`、`copy.tutorial.guide.body`，段落以 `\n\n` 分隔。
- 繁中原文照規格逐字抄，不改寫。

## 驗收
- 四語系都有兩個非空 Key（單元測試）。
- 繁中段數與開頭文字與規格一致（單元測試）。
- 未完成：Key 在 Win95 信件畫面顯示。repo 沒有該畫面，需先指定畫面規格。

## 暫定
- 其他三語系暫放繁中原文，待企劃翻譯。
- 採用 §2.1 推薦版（規格寫「適合直接作為正式開場主文」），未採用 §2 原版。

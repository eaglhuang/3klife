# [PROG-2-0945] 趣味台詞彩蛋庫與使用規則（COPY-05）

## 為什麼做
正式版劇本文案 §7 的趣味台詞只是備選，規格 §7.4 限定只能在開場信與角色初登場使用。目前沒有機制防止它們被用在別處。

## 做什麼
- 新增 FunLineLibrary：14 條台詞，每條標註允許的場景。
- `funLinesFor(scene, speakerId?)` 只回傳允許場景內的台詞。
- §7.3 紅顏台詞因為屬於紅顏趕路情境，保留為 reserved，不會被任何場景查出。

## 驗收
- 六位名將各一條初登場台詞，且不進開場信（單元測試）。
- 開場信五條，只在開場信出現（單元測試）。
- 紅顏三條保留，任何場景都查不到（單元測試）。

## 暫定
- 觸發條件以場景代表；規格沒寫更細的觸發條件。
- 初登場的呼叫端（名將登場畫面）尚未接線，本卡只提供查詢。

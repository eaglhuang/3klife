# [PROG-2-0946] 大廳字串與劇本文案入 i18n（HALL-13）

## 為什麼做
大廳系統.md §H 的字串與 §G 的劇本句還沒有 Key，大廳畫面無法依語系載入，城市兵源成本也沒有統一文字。

## 做什麼
- §H 的 21 個 UI_HALL_* Key 進四語系。
- §G 的 9 句劇本進 UI_HALL_SCRIPT_*。
- 軍事成本「消耗城市兵源 {0}」進 UI_HALL_COST_TROOPS。

## 驗收
- 四語系都有上述 31 個非空 Key（單元測試）。
- 繁中文字與規格逐字一致（抽樣，單元測試）。
- 佔位符數量與繁中一致（單元測試）。
- 未完成：大廳畫面引用這些 Key。大廳的 cc 接線不在本卡範圍，留給後續卡。

## 暫定
- 其他三語系暫放繁中原文，待企劃翻譯。
- 佔位符統一為 {0}；規格寫的 {Percent}、{Name}、{Stage}、{ThemeName}、{GeneralName}、{TaskTitle} 依 repo 慣例轉為位置參數。
- WBS 寫 20 個 UI_HALL_* Key，規格 §H 實際 21 列，以規格為準。

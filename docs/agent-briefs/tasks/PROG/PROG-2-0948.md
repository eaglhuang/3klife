# [PROG-2-0948] 核心武將錨點台詞不可覆蓋（NPC-07）

## 為什麼做
NPC 人性化規格 §E #8：核心武將保留不可覆蓋的錨點台詞。§F-3 第 2 條要求錨點不被中台覆蓋。人格卡資料與結構驗證已在 master，缺的是覆蓋時的守門。

## 做什麼
- `protectGoldenLine(goldenLines, currentLine, replacement)`：目前台詞是錨點就保留原台詞，否則採用替換內容。
- `anchorShareOk(goldenCount, totalCount)`：錨點佔比不得超過 20%。

## 驗收
- 張飛的錨點台詞「燕人張翼德在此！」不被取代（以真實資料檔為樣本）。
- 非錨點台詞可以被取代。
- 資料檔仍通過 validateNpcPersonaCards。
- 佔比 20% 以內通過，超過、總數 0、數值不合理都不通過。

## 暫定
- 中台結果一律不取代錨點，只作 style 參考（PM 裁定）。
- 「20%」以佔比上限解讀（PM 裁定）。
- 呼叫端（台詞生成流程）尚未接線，本卡只提供守門函式。

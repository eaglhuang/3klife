# [PROG-2-0949] 血統樹主角區資料整理（BUI-05）

## 為什麼做
血統樹 14 人 UI 規格 §2.3 底部主角區要顯示子代立繪、稀有度，以及覺醒／未解鎖的因子詞條。因子遮罩與動畫建議已在 FactorMaskState，缺的是把它們整理成面板欄位的 Presenter。

## 做什麼
- `buildMainTargetPanelView(child, genes, playerDiscoveryLevel, previous?)`：回傳 `portraitPath`、`rarityTier`、`awakenTraits`、`lockedTraits`、`factorViews`。
- 已可見的因子標籤進 `awakenTraits`，未可見者進 `lockedTraits`（標籤由遮罩處理）。
- 不修改輸入。

## 驗收
- 立繪與稀有度原樣帶出；缺立繪時為 null。
- 玩家等級 9 時，綠色（需 Lv8）覺醒、紫色（需 Lv45）鎖住。
- 前一次鎖住、這次看見的槽位 playAnimation 為真；首次載入不亮。
- 輸入的因子與子代資料不被修改。

## 暫定
- 因子狀態沿用 FactorMaskState（PM 裁定）。
- 節點的 cc 綁定（Prefab、Label、Sprite）不在本卡範圍，本卡只提供純資料整理。

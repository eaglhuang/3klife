# [PROG-2-0950] 賽季戰績接上戰後結算（REC-10 接線）

## 開單原因
PM 2026-10-21 指示：PROG-2-0848 的賽季純邏輯要有 src 呼叫端。本卡把賽季戰績接進 BattleRoster 戰後結算與 GameSession。

## 範圍
- `BattleRecord` 新增 `season?: SeasonStats`（舊存檔沒有，讀到時視為無）。
- `settleBattle` 接受 `seasonId`，出戰武將的賽季戰績依賽季分段累加。
- `GameSession` 戰後結算傳入 `pvpSeasonIdOf(totalSeasonsElapsed)`。
- 存檔沿用名冊整包寫入，不改存檔版號。

## 暫定
- 每 4 個遊戲季為一個 PvP 賽季，規格未定，待 PM 裁定。

## 不在範圍
- 賽季獎勵結算、Server 表、排行榜。

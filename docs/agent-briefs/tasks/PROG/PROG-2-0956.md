# [PROG-2-0956] 戰績分頁顯示本賽季戰績

## 開單原因
PM 2026-10-21 指示：PROG-2-0950 已把賽季戰績接上戰後結算，本卡讓玩家在武將詳情「戰績」分頁看見本賽季的勝敗與擊殺。

## 範圍
- 純邏輯：`buildSeasonRecordLine`（本賽季一行的文字規則）；`buildBattleRecordTabText` 多收一個目前賽季 ID，回傳 `season` 欄位。
- 畫面：`GeneralDetailRecordChild` 把本賽季一行接在生涯戰績下方（同一個 Label 第二行）。
- 測試：`tests/BattleRecordSeasonLine.test.ts`。

## 規則
- 目前賽季 ID 未知 → 「本賽季：—」。
- 沒有賽季紀錄、賽季 ID 過期（上一季殘留）、或本季沒有勝負 → 「本賽季：尚未出征」。
- 其他 → 「本賽季：N勝 N敗 斬N人」。

## 暫定
- 本賽季行併入生涯戰績那格的第二行，不新增版面節點。
- 賽季 ID 由 `pvpSeasonIdOf`（每 4 個遊戲季一賽季）換算，規格未定，待 PM 裁定。

## 不在範圍
- 版面獨立欄位、賽季獎勵、實機排版（待 Codex 驗收）。

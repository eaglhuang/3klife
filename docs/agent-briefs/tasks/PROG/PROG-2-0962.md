# [PROG-2-0962] 季報戰損報告接上季結流程（OFC／REC 季報）

## 開單原因
WBS v15 列為「src 無呼叫端」。純邏輯 `quarterlyBattleReport(name, pct)` 已存在，但唯一呼叫端是 `RetireReviewController`，季結流程沒有產出每位武將的戰損報告。

## 範圍
- `RetireReviewCopy.ts`：新增 `QuarterlyBattleReportRow`（帶 `generalId`）與 `buildQuarterlyBattleReportRows(roster)`。精力缺值的武將略過；`maxVitality` 缺值時以 `vitality` 當上限（顯示 100%）。
- `GameSession.advanceSeason()`：用名冊產出 `quarterlyReports`，放進 `SeasonAdvanced` 事件 payload。
- 測試：每位有精力的武將一列、缺值略過與 100% 回退、GameSession 季結 payload 帶出報告。

## 不在範圍
- 季結彈窗的 cc 畫面與版面（layout／skin／綁定），需另開卡由 Claude 照寫，Codex 負責實機驗收。
- 「建議羈絆」的門檻數字，仍待 PM 裁決。

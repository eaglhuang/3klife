# [PROG-2-0963] 季結戰報彈窗接上大廳推進季度

## 開單原因
PROG-2-0962 已讓季結 payload 帶出 `quarterlyReports`，但大廳推進季度後沒有任何畫面顯示這些戰報。PM 裁定：直接開彈窗卡接線，不等 #759 合併。

## 範圍
- 純邏輯 `SeasonReportPanel`：最多 6 列（名冊順序），空名冊提示，超過列數的人數提示，文字 key 對應彈窗路徑。
- UCUF 規格：`season-report-screen`（Popup 層，uiId `SeasonReport`）、`season-report-main` 版面、`season-report-default` 皮膚、內容契約與 smoke 狀態。
- `SeasonReportComposite`：mount、套文字、關閉（遮罩與 X 按鈕）。
- `LobbyScene`：`_onClickAdvanceSeason` 推進後若有戰報，開啟彈窗；控制器註冊到 UIManager。
- 測試：列上限與順序、人數提示、空名冊、標題列季節字串、文字路徑都存在於版面 JSON。

## 不在範圍
- 結緣或羈絆入口（戰報只顯示建議，不接結緣流程）。
- 精力排序、結緣門檻數字（待 PM 裁決）。
- 實機版面驗收（Codex 負責）。

## 依賴
- 依賴 PROG-2-0962（`quarterlyReports` 欄位）。該 PR（#759）未合併前，本分支是它的堆疊分支，合併後需 rebase 到 master。

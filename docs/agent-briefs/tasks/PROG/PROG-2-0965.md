# [PROG-2-0965] 沙盤標記放置接線（領地）

## 開單原因
PM 裁定（2026-10-21 暫定）：沙盤標記放在領地（州節點），每領地最多一個。0964 已顯示數量，本卡接上放置邏輯與存檔。

## 範圍
- 領地清單 `SandtableTerritories`：內建十三州，`data/sandtable-territories.json` 驗證通過才覆寫；id 為拼音小寫、不可重複。
- `GameSession.placeSandtableMarker(territoryId)`：檢查階段上限、領地存在、該領地尚無標記；通過才記錄。
- 存檔：新增選填欄位 `sandtableMarkerTerritories`（只留清單內 id、去重）；`sandtableMarkersPlaced` 仍寫入數量。
- 大廳載入領地資料檔（與官職階位表同一載入時機）。
- 四語系補 `territory.<id>.name`。

## 不在範圍
- 放置用的領地選擇畫面（按鈕或清單 UI）：另開卡。
- 領地來源替換為世界沙盤資料（TIME-10 接入後）。

## 暫定
- 舊存檔只有數量、沒有領地 id 時，讀回的標記數為 0（0958 的存檔欄位尚未有玩家使用，PM 可指示是否需要相容）。

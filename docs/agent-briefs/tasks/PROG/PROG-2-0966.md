# [PROG-2-0966] 季度戰報排除退休與未成年武將

## 開單原因
QA 回報：季度戰報列出已退休教官與年幼子嗣，還給出「可結緣」建議。PM 裁定：戰報只列現役可出戰武將，退休與未成年一律排除。

## 範圍
- `isQuarterlyReportEligible`：教官卡（`isMentorCard`）一律排除；年齡在 adult 起到 retired 前才算現役；年齡未知不排除（暫定）。
- `buildQuarterlyBattleReportRows` 排除不符合資格的武將。
- 測試：退休教官、退休年齡、未成年、年齡未知四種情況。

## 不在範圍
- 季結彈窗（0963）的列資料已沿用這份 rows，不需另改。

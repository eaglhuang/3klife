# [PROG-2-0970] 內政武將指派服務（GOV-04）

## 開單原因
WBS v16.2 壽命線 MVP 第一項（P0）：領地治理系統 §武將指派，規格功能 2「將武將拖放到內政任務格」。

## 範圍
- `assignGovernanceGeneral(current, task, generalUid, maxSlots)`：指派武將到內政任務格，回傳新清單，不改輸入。
- `removeGovernanceAssignment(current, task)`：卸下任務格的武將。
- 驗證：任務 ID 必須是五大內政之一；任務格已有人時拒絕；同一武將不可重複指派；已用格數達上限時拒絕。
- 測試：成功指派、各種拒絕理由、卸下、不改輸入。

## 不在範圍
- 拖放 UI、太守府畫面（GOV-07）。
- 存檔欄位、季結算接線。

## 暫定
- 每個內政任務最多一位武將，「格」即任務格。
- 同一武將不可重複指派，不做「搬移」（CSV 驗收句：同一武將不可重複指派，超過格數被拒）。
- 格數上限由呼叫端傳入（規格範例 Max_Task_Slots = 5）。

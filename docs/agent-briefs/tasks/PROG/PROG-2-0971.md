# [PROG-2-0971] 世襲主城保護與背水一戰（GOV-09）

## 開單原因
WBS v16.2 壽命線 MVP（P0）：領地治理系統 §世襲主城保護。規格要求玩家主城不可攻陷，外圍城池全失時觸發「背水一戰」加成。

## 範圍
- `canCaptureTerritory(territory)`：主城回傳 false。
- `attemptTerritoryLoss(territories, territoryId)`：主城不被移除，其他領地可移除；回傳新清單。
- `lastStandModifiers(territories)`：領地只剩主城時，回傳防禦 ×2、兵力生產 +50%；否則為 ×1、+0%。
- 測試：主城不可攻陷、外圍可失守、背水一戰觸發條件與加成、不改輸入。

## 不在範圍
- 戰場與領地攻陷的接線（目前沒有呼叫端）。
- 主城標記的存檔來源。

## 暫定
- 「外圍全失」定義為領地清單只剩主城一個。
- 數值沿用規格：防禦 ×2、兵力生產 +50%。

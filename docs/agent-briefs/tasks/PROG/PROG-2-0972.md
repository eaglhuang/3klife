# [PROG-2-0972] 武將日誌主檔與寫入 API（JRN-01）

## 開單原因
WBS v16.2 壽命線 MVP（P0）：武將日誌與離線互動系統 §E 功能 1「武將日誌主檔」。規格要求重大戰果、派遣、互動事件可寫入時間軸，並依武將與類別查詢，且可回扣 Action_Records 序號。

## 範圍
- `appendJournalEntry(state, entry)`：寫入條目，檢查類別、優先度、摘要、Action 序號範圍與 ID 重複；回傳新狀態。
- `queryJournal(state, { generalUid?, category? })`：依武將與類別篩選，依時間新到舊排序。
- `findJournalEntriesByActionSeq(state, seq)`：找出 Action 序號範圍涵蓋該序號的條目。
- 測試：寫入與拒絕、依武將與類別查詢、排序、Action 序號回扣、不改輸入。

## 不在範圍
- 存檔欄位（`General_Journal` 持久化）與 Server 欄位。
- 晨報摘要（JRN-02）、大廳與人物頁的讀取接線。

## 暫定
- 類別列表 BATTLE / DISPATCH / INTERACTION / GROWTH / SYSTEM：規格只在範例出現 `DISPATCH`，未列舉全部類別。
- Priority 範圍 0~100（規格範例 80）。
- 可見性 VISIBLE / HIDDEN（規格 F-1 公式中出現 HIDDEN）。

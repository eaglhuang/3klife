# [PROG-2-0973] 太守府治理頁文字與數值（GOV-07）

## 開單原因
WBS v16.2 壽命線 MVP（P0）：領地治理系統 UI（GOV-07），依 2026-04-26 覆寫裁定 §3~4：人口核心儀表盤、產出卡拆分、城市兵源卡。

## 範圍
- `buildGovernorHallView(snapshot)`：人口與民心、四條流向（金錢／糧草／城市兵源上限／補兵速度）、金錢與糧草產出卡（基礎值／人口紅利／政策修正／總計）、城市兵源卡（目前/上限、每回合補兵、距離回滿）。
- `turnsToFullTroops(current, cap, recruitPerTurn)`：距離回滿的回合數。
- 測試：儀表盤、流向、產出卡正負號、兵源卡各狀態、回合數進位、不改輸入。

## 不在範圍
- 太守府 cc 畫面、layout JSON 與按鈕綁定。
- 治理結算的產出公式（本模組只接受呼叫端傳入的數值）。
- 初期 8000 左右出征軍勢保底（規格 §6，屬平衡與結算）。

## 暫定
- 距離回滿以無條件進位計算；補兵為 0 時顯示無法回滿。

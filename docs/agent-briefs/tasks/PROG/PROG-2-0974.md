# [PROG-2-0974] 領地治理純邏輯接到會話（GOV-04 / GOV-09 / JRN-01 接線）

## 開單原因
WBS 規定 src 要有呼叫端才算已接線。GOV-04（指派）、GOV-09（主城保護）、JRN-01（日誌）已合併為純邏輯，但目前沒有任何呼叫端。PM 指示：做完純邏輯後開接線卡，並補多回合的真實流程測試。

## 範圍
- `GameSession`：新增指派、卸下、領地、失守、背水一戰加成、日誌寫入與查詢；狀態只在操作成功時改變。
- 測試：三支跨 `advanceSeason()` 的多回合流程測試，以及被拒絕操作不改變狀態。

## 不在範圍
- 存檔欄位與 normalize（指派、領地、日誌需要進 save snapshot，另卡處理）。
- 季結時自動寫入日誌。
- 太守府 cc 畫面（GOV-07 只有 presenter）。
- 領地資料來源（目前由 setTerritories 注入）。

## 暫定
- 主城領地 id 為 `home-city`，規格未給固定 id。

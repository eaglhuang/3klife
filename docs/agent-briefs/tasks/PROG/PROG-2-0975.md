# [PROG-2-0975] 領地治理存讀檔接線（指派、主城、日誌）

## 開單原因
PM 指示：指派、主城狀態、日誌要能跨存讀檔保留，才算真正接到遊戲流程。PROG-2-0974 目前只是記憶體狀態。

## 範圍
- `LifespanSave.ts`：三組讀檔校正，不合法條目丟棄，日誌逐筆套用寫入驗證。
- `PlayerSaveService.ts`：`governanceAssignments`、`territories`、`journalEntries` 三個選填欄位。
- `GameSession.ts`：快照只寫非預設值（舊檔格式與預設狀態不變）、`restoreLifespanState` 由 `load()` 呼叫、新遊戲時重置。
- 測試：讀檔校正的各種壞資料；跨 `advanceSeason` 與 JSON 往返的多回合存讀檔。

## 不在範圍
- 季結自動寫入日誌（另卡）。
- 太守府 cc 畫面、領地資料來源。

## 堆疊
- 本卡基於 PROG-2-0974（PR #802，尚未合併）。#802 合併後需 rebase 到 master。

## 暫定
- 主城領地 id 為 `home-city`。
- 版號不升（扁平選填欄位，與 sandtable 欄位一致）。

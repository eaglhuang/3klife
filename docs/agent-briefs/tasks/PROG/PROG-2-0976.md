# [PROG-2-0976] 季結自動寫入日誌

## 開單原因
PM 指示：PROG-2-0974 / 0975 已能指派、存讀檔、寫日誌，但季結不會留下任何紀錄。
每結束一個季，應在日誌留下一筆 SYSTEM 條目，列出該季有戰損報告的武將，讓玩家能回看。

## 範圍
- `GameSession.ts`：`advanceSeason` 在季結算的報告產生後呼叫 `recordSeasonJournal`，寫入一筆 SYSTEM 條目。
- 條目 ID 為 `SEASON-<結束的季序號>`；同一季重複結算時 ID 重複，寫入會被拒絕，不會寫兩筆。
- 測試：兩次季結的順序與分類、重複 ID 被拒、跨存讀檔保留。
- 既有多回合日誌測試（`GameSessionLifespanWiring`）改為計入自動寫入的季結條目。

## 不在範圍
- 季結摘要的戰損細節文字（只列季名）。
- 太守府 cc 畫面。

## 暫定
- 時間戳 `年-季序號-01T00:00:00` 只作排序鍵，尚未對應遊戲內實際日期。
- 優先級 50，低於派駐與戰鬥條目。

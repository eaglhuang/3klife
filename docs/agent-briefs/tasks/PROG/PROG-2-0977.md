# [PROG-2-0977] 戰場部署紀錄 Server 列與驗證（DEP-13）

## 來源
- WBS v16.2 DEP-13（戰場 P1，未開始，2.0）：Server/Client 部署紀錄 schema（Sortie_Loadout／Battle_Deploy_State／battle 表），戰鬥結算寫入 battle 記錄含 food_spent／troops_lost 等欄位。

- `server/schema/007_battle_deploy_records.sql`：`battle_deploy_record` 表，欄位與規格 §I 表一致。僅定義，不部署。
- `server/schema/dep13-row-validators.ts`：`validateBattleDeployRecordRow`，檢查 ID 長度、三角色不重覆、無參謀官／後勤官時加成為 0、戰損＋返還 ≤ 出征軍勢上限、精銳次數 ≤ 精銳上限、非負整數與 TINYINT 上限。
- `tests/ServerSchemaDep13.test.ts`：6 案。

- 不建立玩家主表與外鍵。
- 不改客戶端 `SortieDeploy.ts`。

## 暫定
- 軍勢守恆（戰損＋返還 ≤ 上限）與精銳次數 ≤ 精銳上限，規格未明寫，先以常識邊界實作。

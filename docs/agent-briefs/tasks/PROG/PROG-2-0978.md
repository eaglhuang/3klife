# [PROG-2-0978] 史實合攻戰場演出（KIN-09 演出）

## 來源
- 協調者 2026-10-21 指派：KIN-09 合攻聯動的戰場演出；邏輯已在 PROG-2-1063／1065（`ComboAttackKin`、`resolveKinComboFollowUp`）。
- WBS KIN-09 驗收含「並有戰場演出」。

## 範圍
- `Constants.ts`：新增 `EVENT_NAMES.KinComboAttack`（payload `{ attackerId, helperId, targetId }`）。
- `BattleCombatResolver.resolveKinComboFollowUp`：擲中觸發率後、追加傷害前發出事件。
- `BattleUIBridge`：接聽事件，記一行戰報，並以 `playAttackAnimationAsync` 播助攻方撲向目標的動畫（排入既有戰鬥視覺佇列）。
- `tests/KinComboPresentation.test.ts`：2 案（有義兄弟且觸發發一次事件；無史實關係不發）。

## 不做
- 不改觸發率與傷害數值。
- 不新增版面、皮膚或語系 key（戰報文字先用中文硬字串，同 `naval` 合攻的既有做法）。
- cc 端實機演出待 Codex 驗收。

## 暫定
- 戰報文字「與X史實合攻，追擊Y」與助攻方撲擊動畫為本卡自行決定，待演出驗收微調。

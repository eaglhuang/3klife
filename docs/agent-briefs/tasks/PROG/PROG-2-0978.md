# [PROG-2-0978] 自動治理 AI 與手動/自動切換（GOV-06）

## 開單原因
領地治理規格「自動治理分配」：閒置武將依任務親和度 argmax 分到內政任務格，並可在手動與自動間切換、切換狀態需保存。

## 範圍
- `GovernanceAutoAssign.ts`：`taskAffinity` 與 `autoAssignIdle`，依規格式 `Task_Affinity = General[Primary_Stat] × Weight`，每位閒置武將挑未佔用任務中親和度最高者，平手取任務表順序較前者。
- `GameSession`：`autoGovernance` 開關與 `setAutoGovernance()`；開啟時季結前自動分配閒置武將。
- 存讀檔：`governanceAutoMode` 選填欄位，只在開啟時寫入，舊檔讀回關閉。

## 不在範圍
- 太守府畫面的切換按鈕（畫面另卡）。
- 領地升級 GOV-08（數值表與費用規格未定，待使用者裁決）。

## 暫定
- 任務權重 Weight 全部為 1，規格未給定數值。
- 外交主屬性為 INT+CHR；規格表寫 CHR，武將欄位為 cha。

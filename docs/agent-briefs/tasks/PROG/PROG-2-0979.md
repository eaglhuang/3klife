- `tests/BattleHudScreenAnchors.test.ts`：找 UITransform 處加非空斷言。

- 抽獎錢包型別、傳承、修練、UIPreviewStyleBuilder 等其他線的錯誤不在本卡範圍，留給各線。

## 暫定
- `EventHandler` 改必填是型別層調整，執行時不變。

# [PROG-2-0982] 傭兵告別信進收件匣（RET-03）

## 開單原因
留存系統 RET-03：傭兵到期（Expired）且好感 ≥20 時，依好感生成告別信，進收件匣並有未讀標記。

## 範圍（本卡）
- `FarewellLetterInbox.ts`：好感分級、告別信生成、加入收件匣（同 ID 不重複）、標記已讀、未讀數。純邏輯，不改輸入。
## 接線（另卡，等 #954 合併後）
- `GameSession`：傭兵日推進離隊時，好感 ≥20 才寫信；提供收件匣讀取與標記已讀。
- 存讀檔：`farewellLetters` 選填欄位，空時不寫入，舊檔沒有時為空收件匣。

## 不在範圍
- 收件匣 cc 畫面與入口（另卡）。
- 告別信的感人版內文（企劃台詞待裁決）。
- RET-02 名牌原主名字：原主名字來源規格未定，阻擋。

## 暫定
- 好感分級邊界：<20 不寫、20–39 普通、≥40 感人。
- 好感來源採 `affection`（結義點數即好感，PM 暫定），不用結義進度天數 `bond`。

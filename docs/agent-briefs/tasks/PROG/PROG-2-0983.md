# [PROG-2-0983] 領地升級與內政任務格數（GOV-08）

## 開單原因
領地治理規格「領地升級：升級太守府→解鎖更多任務格」。PM 已暫定數值（見待辦檔），本卡以資料表驅動，之後改表即可。

## 範圍
- `TerritoryUpgrade.ts`：等級上限 5；各等級格數表；升級費用公式；純函式規劃結果（不改輸入）。
- `GameSession`：`territoryLevel`、`pendingTerritoryLevel`；`orderTerritoryUpgrade(spendGold)` 下單即扣糧草與金錢；季結時生效；`maxTaskSlots` 依等級計算，`assignGovernor` 與自動治理的上限都接上 `maxTaskSlots`。
- 存讀檔：`territoryLevel`、`territoryUpgradePending` 選填欄位，預設值時不寫入，舊檔讀回 Lv1、無待生效升級。

## 不在範圍
- 太守府升級按鈕與畫面、大廳入口（另卡）。

## 暫定
- 格數 Lv1–5 為 2/3/4/5/6；費用依 PM 2026-10-21 指示。Lv1=2 格依 PM 2026-10-27 裁定，已由 #959 合入 master。
- 金錢不在 GameSession 內，由呼叫端錢包扣款；扣款失敗時整筆不成立。

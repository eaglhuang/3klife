# [PROG-2-0984] 離線互動事件觸發（JRN-04，F-3 純邏輯）

## 開單原因
WBS v16.2 JRN-04：離線 >=4h 且有衝突標籤時觸發離線互動事件，同一對角色同一登入窗僅 1 則。
規格：`武將日誌與離線互動系統.md` §F-3（`shouldTriggerOfflineInteraction`）。

## 範圍
- `OfflineInteractionTrigger.ts`：觸發條件（離線 >=4 小時、未讀晨報 <3、有衝突標籤、未被離線互動鎖定）；同一登入窗同一對角色的紀錄與查詢。純函式，不改輸入。
- 測試覆蓋各條件邊界與同窗去重。

## 不在範圍
- 離線時長、衝突標籤、未讀晨報數的來源（接線另卡）。
- 寫入日誌、正式任務結算、cc 畫面。

## 暫定
- 對角色配對 key 以較小 uid 在前排序，與順序無關。

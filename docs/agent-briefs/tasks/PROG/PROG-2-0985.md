# [PROG-2-0985] 傭兵告別信接線（RET-03 接線）

## 開單原因
PROG-2-0982（#966）已有告別信純邏輯。本卡把它接到傭兵離隊流程與存讀檔，讓玩家真的收到信。

## 範圍
- `GameSession`：傭兵日推進離隊時，好感 >=20 才寫入收件匣；提供收件匣唯讀副本與已讀標記；存讀檔與重置。
- `LifespanSave`／`PlayerSaveService`：`farewellLetters` 選填欄位，空時不寫入，舊檔為空收件匣。
- 測試：離隊寫信分級、好感不足不寫、同日不重複、已讀、存讀檔往返、舊檔缺欄位。

## 不在範圍
- 收件匣 cc 畫面與入口（另卡）。
- 太守府大廳入口與升級按鈕（PM 另開卡）。

## 暫定
- 好感取 `affection`，缺值視為 0。
- 武將名由名冊查，查不到時用 uid。

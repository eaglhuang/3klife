# [PROG-2-0986] 太守府大廳入口與升級按鈕（GOV-07／GOV-08 接線）

## 開單原因
PM 指示：太守府入口放大廳內政分類；畫面顯示等級與任務格數；升級按鈕呼叫 `orderTerritoryUpgrade`。

## 範圍
- 大廳內政分類新增「太守府」，開啟既有太守府畫面。
- 太守府畫面新增等級、任務格數、待生效升級文字，與升級按鈕。
- 升級按鈕：金錢走錢包 `spendCurrency`，糧草在 GameSession 內扣；成功後存檔並刷新。

## 不在範圍
- 人口與民心真實值：規格只有推導說明、沒有數值來源，維持零值占位，列入待辦檔「待使用者裁決」。
- 產出卡的真實數值來源。

## 暫定
- 按鈕可否以糧草與待生效狀態判斷；金錢不足時由 GameSession 回傳失敗，畫面只刷新、不另外提示。

## 開單原因

## 範圍
- `LoginStreak.ts`：依真實日曆日（UTC+8 00:00 切日）計算連續登入天數；同一天重複登入不增加；隔一天 +1；漏一天歸 1。純函式，不改輸入。
- `GameSession`：登入時記錄一次；讀取連續天數；存讀檔欄位 `loginStreak`（預設值不寫入）。

## 暫定（PM 2026-10-27）

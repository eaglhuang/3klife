# [PROG-2-0988] 非培育子嗣內政職位：屯田官、說客（GOV-10）

## 開單原因
WBS v16.3 GOV-10：非培育子嗣可擔任地方官職，每季提供加成。縣令已完成（PROG-2-1162）；本卡補屯田官與說客的產出公式。

## 範圍
- `ChildOfficialPosts.ts`：Official_Output = Base_Output × (1 + Child_RelevantStat / 100)；屯田官（POL）基礎 -20% 培育糧草消耗，說客（CHR）基礎 +15% 傭兵結義成功率；未成年（出生、開獎階段）效率 ×0.5，常數集中在一處。
- 測試覆蓋公式、未成年係數與負數屬性。

## 不在範圍
- 屯田官與說客的效果接線：現有程式沒有培育糧草消耗，結義也沒有成功率判定，等有對應系統再接。
- 工匠：程式沒有建築系統，PM 裁定略過。

## 暫定（PM 2026-10-27）
- 兒童低效＝未成年效率 ×0.5。

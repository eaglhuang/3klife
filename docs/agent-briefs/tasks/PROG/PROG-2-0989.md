# [PROG-2-0989] 名將挑戰賽賽季週期、段位與軟重置（TRN-01 純邏輯）

## 開單原因
WBS v16.3 TRN-01：14 天一季，培育期 7 天與競賽期 7 天自動輪轉；段位門檻與賽季結束的軟重置規則已在規格中。

## 範圍
- `TournamentSeason.ts`：賽季相位（PREPARATION／COMPETITION／ENDED，依賽季第幾日判定）；段位（銅到傳說）門檻；賽季結束的軟重置（傳說 -250、鑽石 -200、白金 -150，下限 0）。純函式，不改輸入。
- 測試覆蓋相位邊界、段位邊界與軟重置。

## 不在範圍
- 獎勵發放（TRN-10，獎勵表屬商業內容，待使用者裁決）。
- ELO 配對積分：規格的勝負積分區間與公式數值前後不一致，另案裁定。
- 伺服器排程與 UI（TRN-11）。

## 暫定
- 相位以賽季第幾日判定；賽季開始前視為培育期。
- 銅、銀、金段位的軟重置規格沒有列，維持不變。

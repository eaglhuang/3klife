# [PROG-2-0991] JRN-04 觸發接到大廳載入；太守府金錢不足提示（QA 補充）

## 開單原因
QA 複查：JRN-04 尚無呼叫端，請接到大廳載入；太守府金錢不足時升級按鈕要有提示或停用。

## 範圍
- `GameSession`：讀檔時記下存檔時間 savedAt；`offlineInteractionDue(nowMs, context)` 以「現在減存檔時間」換算離線時長，交給 `shouldTriggerOfflineInteraction`。
- `LobbyScene`：載入存檔後檢查一次，若觸發則寫日誌（目前沒有消費端）；升級被錢包拒絕時記下金錢不足，按鈕改顯示提示並停用，重新開啟太守府時清除。
- `GovernorHallController`：接受金錢不足旗標，按鈕顯示「金錢不足，無法升級」。

## 暫定（PM 2026-10-27）
- 離線時長＝現在減上次存檔時間。
- 未讀晨報數 0、衝突標籤空：所以目前觸發結果恆為否。

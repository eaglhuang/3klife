# [PROG-2-1000] 存檔從備份還原時大廳提示

## 開單原因
QA 的 #728 讓 `GameSession.load()` 在主存檔損毀、改從上一份備份還原時發出 `LoadRecoveredFromBackup` 事件（`core/managers/GameSession.ts`）。目前大廳沒有監聽，玩家不會知道讀到的是舊進度。

## 完整描述
大廳監聽 `LoadRecoveredFromBackup`，以 toast 告知玩家「存檔損毀，已從上一份備份還原」。文案走 i18n，四語系（zh-TW、zh-CN、en、ja）各補一鍵 `toast.save_recovered_from_backup`。事件 payload 不使用。

文案為 PM 暫定，待 PM 統一記入待辦檔 `/mnt/project-files/reports/3KLife-待辦與暫定設計-2026-10-11.md`。

## 做法
1. `assets/resources/i18n/{zh-TW,zh-CN,en,ja}.json`：在 `toast.offline_reminder` 後新增 `toast.save_recovered_from_backup`。
2. `assets/scripts/ui/scenes/LobbyScene.ts`：新增私有方法 `_bindSaveRecoveryToast()`，訂閱事件並 push 進 `_sessionEventUnsubscribers`（onDestroy 會統一退訂）；`onLoad` 流程於 `_openPrisonerPopupIfPending()` 後呼叫。

## 如何驗證
1. `tsc -p tsconfig.cc-check.json --noEmit` 不新增錯誤。
2. run-cli 全綠（含 i18n 鍵值檢查）。
3. compute-gate standard 9/9。
4. 實機（Codex 端）：讀到備份還原時大廳出現 toast。

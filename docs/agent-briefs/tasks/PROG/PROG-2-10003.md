## 開單原因
`playtest-online.js --year` 每季回報「戰鬥 失敗；錯誤 1」。實機重現後確認：
- 「戰鬥 失敗」是遊戲結算畫面的真實敗北（螢幕截圖與 reviewTexts 一致，無 console error／pageerror），欄位沒讀錯，battle 步驟本身 PASS。
- 「錯誤 1」是該季子步驟失敗筆數（當時是 nurture 學府步驟，已由 PROG-2-9999 對齊），與戰鬥輸贏無關。
- 敗北根因：首戰編成把出戰主將設為空，之後戰場退回關卡指定的名冊外主將（張飛），沒有出征帳本，自動代打（委任）無法出兵，只會結束回合。

## 完整描述
- 摘要行改成「戰鬥 敗北/勝利；步驟失敗 N（戰鬥輸贏不算在內）」。
- 年循環每場戰鬥前先指定一位可出戰武將當主將（`--no-set-lead` 可重現原狀）。
- 產品面待 PM 裁決：首戰後主將維持「未定」時，自動代打要不要補出征帳本或還原主將。

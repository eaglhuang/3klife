# [PROG-2-10008] 首戰主將不在名冊時還原起始主將，不再設為空（總PM 裁決方案①）

## 開單原因
首戰編成視窗在關卡指定主將（例：長坂坡張飛）不在名冊時，會把出戰主將設為空，首戰後大廳一直「主將 未定」；
之後戰場退回名冊外的關卡指定主將，沒有出征帳本（sortie:null、canDelegate:false），按「自動」只結束回合、不部署，玩家大概率敗北（PROG-2-10003 查出）。

## 完整描述
- 名冊外主將時，出戰主將還原為起始主將（目前仍可出戰的主將；沒有時退回張飛／最高統率的可出戰武將），不再設為空。
- 參謀官／後勤官與出征帳本都以還原後的主將為準。
- 不改戰場核心規則。

## 如何驗證
1. tests/SortieLoadoutWindow.test.ts：名冊外主將時主將不為空、出征帳本不為 null、可委任
1. tsc 測試設定 0 錯、run-cli 全過、compute-gate quick
1. 實機 `playtest-online.js --year --no-set-lead`：大廳主將不是「未定」，按「自動」有部署出征軍勢

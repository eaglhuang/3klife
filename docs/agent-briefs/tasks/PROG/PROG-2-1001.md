# [PROG-2-1001] GeneralDetailOverviewChild 型別錯誤（TS2352／TS2345）

## 開單原因
`tsc -p tsconfig.cc-check.json --noEmit` 在 `ui/components/general-detail/GeneralDetailOverviewChild.ts` 報兩筆：第 143 行 `s as Record<string, unknown>` 被判定無重疊（TS2352）；第 182 行 `_applyBulletList` 參數型別取自 `typeof ROLE_LINE_PATHS`，傳入 `TRAIT_LINE_PATHS` 時字面型別不同（TS2345）。

## 完整描述
1. 第 143 行改 `s as unknown as Record<string, unknown>`，與同專案其他 cc 型別轉換寫法一致。
2. 新增 `BulletLinePathDefinition`（rowPath／bulletPath／textPath 三個 string 欄位），`_applyBulletList` 參數改為 `readonly BulletLinePathDefinition[]`，ROLE 與 TRAIT 兩組共用。`ROLE_LINE_PATHS`／`TRAIT_LINE_PATHS` 保留 `as const`，執行期行為不變。

## 做法
1. `assets/scripts/ui/components/general-detail/GeneralDetailOverviewChild.ts`：兩處修改如上。

## 如何驗證
1. `tsc -p tsconfig.cc-check.json --noEmit` 中 GeneralDetailOverviewChild 的兩筆錯誤消失。
2. run-cli 全綠；compute-gate standard 9/9。

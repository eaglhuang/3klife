# [PROG-2-1002] BattleUIBridge 治療／移動事件誤傳傷害觀測（UnitDamagedPayload）

## 開單原因
`tsc -p tsconfig.cc-check.json --noEmit` 在 `battle/views/BattleUIBridge.ts` 第 396、414 行報 TS2345：`_onUnitHealed`（治療）與 `_onUnitMoved`（移動）把自己的 payload 傳給 `_observeSpecialActionHit(data: UnitDamagedPayload)`，兩者形狀不符。

## 完整描述
`_observeSpecialActionHit` 只為傷害事件設計，治療與移動的 payload 沒有 `damage`、`attackerFaction`，會被 `SpecialActions.observeUnitHit` 在第一個判斷直接 return（`attackerFaction !== Player` 或 `!(damage > 0)`）。因此這兩個呼叫在執行期沒有任何效果，移除它們不改變行為，也不必用強轉騙過型別。

## 做法
1. `assets/scripts/battle/views/BattleUIBridge.ts`：`_onUnitHealed`、`_onUnitMoved` 各刪除一行 `this._observeSpecialActionHit(data);`。

## 如何驗證
1. `tsc -p tsconfig.cc-check.json --noEmit` 中 BattleUIBridge 396、414 兩筆消失。
2. run-cli 全綠（含戰場特殊行動相關測試）；compute-gate standard 9/9。

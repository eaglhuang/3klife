# [PROG-2-10043] 結緣提親機率面板與吃醋彈窗掛進遊戲

## 開單原因
Antigravity 提交的 BondingAndEpithetPanel（#2650，PROG-2-10037）與 JealousyPopupPanel（#2651，PROG-2-10038）只有元件與純邏輯，沒有畫面節點，也沒有任何玩家操作會把它們叫出來。本卡把兩個面板掛進遊戲。

## 完整描述
1. 結緣畫面（bonding-setup-screen）新增「提親機率」按鈕，開 bonding-proposal-screen：顯示真實好感 F（GameSession.bondAffinityOf）、世交相性 K（FamilySynergy 帳本）、被拒次數帶來的誠意，成功率分項與小名 8／12／15 歲三段揭曉；按「提親」擲骰，被拒真的扣好感 -12，成功且符合納配偶條件才入家族。
2. 吃醋彈窗（jealousy-popup-screen）：換季事件在配偶 ≥ 2 位且有人本年未哄過時開啟，三選項結算寫回真實好感與銀兩。
3. 兩個畫面皆為 UCUF 規格（layout／skin／screen），皮膚登記進 settle 家族，顏色走 settle.* token；文字走 i18n 四語系。
4. 修正 Antigravity 面板兩處無法編譯／執行的 API 假設（ThemeService.instance、I18nSystem.instance 都不存在），改為注入。

## 驗證方式
tests/BondingJealousyMount.test.ts、run-cli.ts 註冊三組面板測試、網頁版建置實跑截圖。

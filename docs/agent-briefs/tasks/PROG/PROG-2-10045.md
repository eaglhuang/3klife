## 目標
實跑戰場（?qaBattle=1&qaSlow）找手感打磨點，一批小修。只動表現層，不改五路對撞與結算。

## 發現與做法
1. 地形／buff 吃到／毒／狀態飄字沒帶錨點，同單位同時跳兩句會疊成「水域攻擊桎28」。`UnitRenderer.playBuffConsumeValue`／`playPoisonFloat` 改帶格子錨點（`cellFloatAnchor`），沿用 FloatStaggerTracker 錯開。
2. 自動代打每次部署都跳 800×112 的「我方已部署…」橫幅蓋住戰場中央（一回合 3～5 次）。自動代打時不跳（戰報已有紀錄）；手動部署停留縮為 0.8 秒。
3. 長飄字（「攻擊 +40 生命 -96」）以 42 字級寬度逾 500px 蓋住名牌。`floatFitFontSize` 縮到寬度上限 340px、下限字級 28；短字不變。

## 驗收
- tsc -p tsconfig.test.json 0 錯；tests/run-cli.ts ALL PASS；tests/FloatFit.test.ts。
- 前後對照截圖：筆記夾 vfx-hud-1126（before-sheet／after-sheet）。改前 12 格抽樣有 6 格出現部署橫幅，改後 0 格。
- 未實跑驗證：長字縮放（無長句飄字樣本）、手動部署 0.8 秒停留。

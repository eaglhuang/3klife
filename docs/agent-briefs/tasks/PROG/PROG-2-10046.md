# [PROG-2-10046] 年終頒獎典禮三幕式面板掛進遊戲

## 開單原因
Antigravity 提交的 YearEndCeremonyPanel（PROG-2-10044）只有元件，且引用不存在的 `ThemeService.instance`、`I18nSystem.instance`，沒有畫面節點，遊戲內也沒有任何流程叫出它；YearEndRankingService（PROG-2-10027）同樣沒有呼叫端。本卡把兩者掛進歲末結算。

## 完整描述
1. 年末 YearEnded 觸發後，年報與季報照舊；季報關閉後以 YearEndRankingService 結算本年榜單（玩家分數暫取家族聲望 clanPrestige），開 year-end-ceremony-screen。
2. 三幕自動換幕（7／8／8 秒，合計 ≤ 30 秒）；首次必看完整播放、不顯示跳過；播完（或跳過）才寫 resources.yearEndCeremonySeen 並存檔，第 2 次起顯示跳過鈕。
3. 畫面為 UCUF 規格（layout／skin／screen），皮膚登記進 settle 家族，顏色走 settle.text.title／value／accent；文字全走 i18n 四語系。
4. 重寫元件注入式 API（setServices），修正兩個不存在的單例假設。

## 驗證方式
tests/YearEndCeremonyMount.test.ts、tests/YearEndCeremonyPanel.test.ts 註冊進 run-cli.ts；網頁版建置實跑截圖 artifacts/ui-review/ceremony-1126。

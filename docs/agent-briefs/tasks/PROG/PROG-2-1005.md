# [PROG-2-1005] 大廳任務情報完整判斷改走 HallTaskIntel（HALL-05 接線第一段）

## 開單原因
WBS HALL-05 標示「純邏輯、無 src 呼叫端，HallTaskIntel 亦未接線」。大廳任務彈窗的情報完整判斷（`isFullIntel`）自成一套，與 F-5 的 `HallTaskIntel` 各算各的。

## 完整描述
`isFullIntel` 改為呼叫 `canRevealFullHallTask`，讓 F-5 的判斷只有一處來源。行為逐項等價：

- 100 → 完整（與舊版相同）。
- 超過 100 → 完整（`HallTaskIntel` 夾回 100，舊版也是完整）。
- 99.5、0 → 未完整。
- NaN、Infinity → 未完整（`HallTaskIntel` 把非有限數視為預設 50，未滿 100）。

委任與回看紀錄不在本卡範圍，列為 PROG-2-1006（需要存檔欄位）。

## 做法
1. `assets/scripts/ui/core/HallDetailActionStates.ts`：`FULL_INTEL_PERCENT` 引用 `HALL_INTEL_FULL_PERCENT`；`isFullIntel` 改呼叫 `canRevealFullHallTask`。
2. `tests/HallExecuteConfirm.test.ts`：新增等價案例（100、101、99.5、NaN、Infinity）。

## 如何驗證
1. run-cli 全綠（含新案例）。
2. tsc cc-check 無新增錯誤。
3. compute-gate standard 9/9。

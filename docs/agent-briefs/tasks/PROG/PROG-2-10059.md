## 開單原因
年底結算呼叫 dueBloodlineEvent 產生待處理事件佇列並存檔（本卡不做彈窗）；提供 resolveBloodlineEvent(childId,eventId,choice) 發放獎勵，每名孩子每年最多一件，承 PROG-2-10057、PROG-2-10058。

## 完整描述
- assets/scripts/core/systems/BloodlineGrowthSettlement.ts：歲末排程 queueBloodlineGrowthEvents、待決佇列 normalize、resolvePendingBloodlineEvent、效果落地（帳本、五維）、存檔欄位 normalize。
- GameSession：換年時（advance.yearEnded）為家族裡每位孩子呼叫 dueBloodlineEvent 排佇列；resolveBloodlineEvent 入帳；SeasonAdvancedPayload.growthEventsQueued。
- 存檔：PlayerSaveSnapshot.bloodlineGrowthEvents = { records, pending }，兩者皆空不寫；舊存檔缺欄位視為空；已加進 sync06 白名單。
- 命令：family.growthEvents（查詢待決）、family.resolveGrowthEvent（只送 childId／eventId／optionId，不得帶數值；E370 不在待決、E371 無此選項、銀兩不足回 INSUFFICIENT_BALANCE）。

## 設計
- 孩子名單：家族登記的非配偶成員＋名冊上有父或母的武將，已過世者略過；年齡取整歲（一季 +0.25，一年 +1），9～11 歲對應第 3～5 年事件。
- 一件事件選過就不再排；沒選的事件留在待決佇列（不補發也不丟）。同一次歲末每名孩子最多新增一件。
- 銀兩不足時整件不生效、待決保留；銀兩扣款走 silverLedger.spendSilver（家族銀兩，不是國家金）。
- 五維加減夾在 0～100，同時寫回名冊的頂層欄位與 stats；聲望變動發 ClanPrestigeChanged。

1. 資料：assets/resources/data/master/year1-goals.json（6 目標、總獎 650 銀兩、稱號、安慰獎 20）＋載入器與 schema 驗證 Year1Goals.ts（總額必須等於各項加總、不得用金、稱號與套件不重複）。
2. 追蹤：掛在既有路徑，不另造事件。recordBattle 勝利、enrollGenerals（排除配偶入門）、chooseDomesticTask、giftFemale、spendLifespan(nurture)、enrollSpouse 對帳配偶數、年末典禮名次；新事件 Year1GoalsChanged。
3. 存檔：PlayerSaveSnapshot.year1Goals（選填，舊存檔 ?? 預設全空），同步加進 server sync06 白名單。
4. 領獎：reward.claim（套件 BUNDLE_Y1_GOAL_*、grantKey、來源 year1Goal）走 SilverRoutedWallet 入家族銀兩；兩層防重（存檔 claimed＋grantKey）；領獎不算本年入帳（不墊高榜單分數）。
5. 親子談話替代判定：談話按鈕尚未存在，以「府內送禮或培育互動」頂替（資料 fallback.enabled 可關）；親子好感 +3 與稱號先記在存檔，等系統上線再結算。
6. UI：大廳上方中央「首年目標 X/6」進度條＋「下一步：…」提示＋前往按鈕（UCUF 三層＋Year1GoalsPanel＋Year1GoalsController），完成時詼諧 Toast（排隊逐則播）；年末典禮第 3 幕新手滿貫（>=5/6）加一行賀詞。
7. 四語系 i18n；皮膚登記進 settle 家族。
8. 收入對帳：repo 內查無「首年事件收入 1,600」這筆資料也沒有重複發放的來源，故未調整既有收入；請 PM 確認 1,600 的出處。

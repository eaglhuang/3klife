## 開單原因
換年待決的血統成長事件彈窗（A／B 選項呼叫 family.resolveGrowthEvent，Toast 回報）；家族孩子面板加親子談話按鈕，每年一次好感增量放 JSON，3 句搞笑話題輪替，累計 childInteractionCountThisYear；承 PROG-2-10057／10058／10059。

## 完整描述
- 成長事件彈窗：換年排出待決事件後，大廳依序（季報、典禮、吃醋之後）彈出；顯示孩子名／歲數、事件標題與描述、A／B 選項含效果摘要；選項走 family.resolveGrowthEvent，Toast 顯示結果；「稍後再說」只收起、事件仍待決，下次進大廳再問。銀兩不足只提示、不消耗事件。
- 親子談話：入口放在祠堂面板（孩子清單在這裡看得到），按鈕文字用 ui.child.talk_btn；每個孩子每年一次，好感增量與 3 句搞笑話題放 assets/resources/data/master/child-talk-config.json；命令 family.talkToChild（E372 未知孩子、E373 今年談過），權威端在 GameSession。
- childInteractionCountThisYear：存在 bloodlineChildLedger.interaction，跨年自動歸零；親子談話與成長事件選擇都累計；GameSession.childInteractionCountThisYear 與 family.childLedger 的 interactionCountThisYear 可讀（首年目標清單 y1_first_talk 直接讀它，origin/master 上原本沒有同名欄位）。
- 存檔相容：舊存檔缺談話欄位視為從沒談過。
- 副作用：祠堂開放階位由 2 降為 1（官職階位 1 即可進祠堂），OfficerFeatureUnlocks 測試同步更新。

## 如何驗證
1. tests/ChildGrowthPopup.test.ts：話題表、帳本相容、一年一次、命令錯誤碼、存檔讀回與舊存檔、彈窗觸發／守衛／選項入帳／銀兩不足／稍後再說、祠堂親子談話、畫面規格與四語系。
2. npx ts-node …tests/run-cli.ts 全過；npx tsc -p tsconfig.test.json --noEmit 0 錯；compute-gate standard 通過。
3. 網頁版（web-desktop 建置＋無頭 Chrome 1920 寬）截圖：artifacts/ui-review/child-growth-popup-open.png、child-growth-popup-toast.png、clan-shrine-child-talk-*.png（不提交）。

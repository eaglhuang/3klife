# [PROG-2-10078] 戰場小兵 Spine 骨架預載與節點池預熱（騎兵出現延遲）

## 開單原因
實玩：首次載入小兵很慢，騎兵出現時已跑出好幾格。量測：進戰場後騎兵 Spine 顯示延遲約 2.3 秒（步兵／盾兵約 0.5 秒）。

## 交付物
- SpineUnitOverlay.preload：戰前載好兵種骨架資料並持有引用、預熱節點池、預熱受擊閃白材質
- BattleScene 載入流程依雙方可用兵種預載（敵方 AI 兵種池＋我方手牌）
- tests/SpineUnitPool.test.ts 補預載測試

## 如何驗證
tsc -p tsconfig.test.json 0 錯、tests/run-cli.ts、compute-gate quick；實跑量測骨架顯示延遲前後對照。

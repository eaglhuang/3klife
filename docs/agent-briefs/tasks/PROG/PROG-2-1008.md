# [PROG-2-1008] 委任任務戰後結算呼叫點（HALL-05 缺口二）

## 開單原因
PROG-2-1006 的 `settleHallAssign(taskId, outcome, settledAt)` 目前沒有任何呼叫點，委任紀錄會一直停在未結算狀態。

## 完整描述
1. 戰役或任務結束時，若該任務有未結算的委任紀錄，呼叫 `settleHallAssign` 寫入結果並存檔。
2. 結果的來源沿用既有的 `HallMissionSettlement`（`hallMissionToOfficerTask`），避免另算一套結果。
3. 同一任務重複結算不會重複寫入（既有測試已涵蓋 double-settle 拒絕）。

## 做法（待 #767 合併後執行）
1. 從新的 master 開分支，`task-lock.js lock PROG-2-1008` 後再動手。
2. 找出既有的任務結束回呼（與 `GameSession.settleHallMission` 同一路徑），在其中補 `settleHallAssign`。
3. 補多回合真實流程測試，不只測單元（參考 #750 教訓）。

## 如何驗證
1. run-cli 全綠（含新流程測試）；tsc cc-check 無新增錯誤；compute-gate standard 9/9。

## 未定事項（暫定）
- 結算時機沿用任務結束的回呼；若找不到單一回呼點，改在 `settleHallMission` 內一併結算（暫定）。

# [PROG-2-1009] 統一物件庫推導虎符與英靈卡視圖（DS-08）

## 開單原因
WBS DS-08 要求統一物件庫為 canonical，虎符清單與英靈卡集合由它推導，不另存真相。Data Schema §2-1a 與 §2-2 #11 互相矛盾，PM 裁定以 §2-2 #11 為準：統一物件庫為 canonical，`Talisman_Inventory` 改為推導視圖。

## 完整描述
1. `core/systems/InventoryProjection.ts`（純函式，不依賴 cc）：
   - `deriveInventoryViews(records)` 讀統一物件庫的列，回傳 `talismans`、`spiritCards`、`skipped`。
   - TALLY 列轉成 `TalismanInventoryEntry`，SPIRIT_CARD 列轉成 `SpiritCardEntry`，OTHER 列忽略。
2. 不合法的列（數量不為 1、品質或來源不合法、缺數值或來源欄位、英靈卡的 Slot 或布林欄位錯）跳過並記錄原因，不補預設值。
3. 重複的 `Inventory_ID` 只取第一筆，其餘記為跳過。

## 如何驗證
1. `tests/InventoryProjection.test.ts` 5 案：兩類視圖都由總表推導、副本語意、跳過與原因、重複 ID、未綁定虎符為 null。
2. run-cli 全綠；tsc cc-check 無錯誤。

## 未做（留待後續卡）
- 執行期的物件庫存取與 `GameSession` 接線：目前沒有虎符與英靈卡的執行期資料來源，無 src 呼叫端。
- 存檔版號不升（MVP 期間維持扁平快照，依 PM 裁定）。

## 暫定
- 虎符以外的 `Attributes` 欄位名沿用 Data Schema §2-1a 的欄位名（暫定）。

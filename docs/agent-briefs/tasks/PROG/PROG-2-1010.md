# [PROG-2-1010] 基礎資源上限夾制與不足提示（ECO-11）

## 開單原因
WBS ECO-11（P0，底座 MVP）：資源超出上限要夾制，不足時顯示警示。目前沒有任何夾制或提示的純邏輯。

## 完整描述
1. `core/systems/ResourceCap.ts`（純函式，不依賴 cc）：
   - `clampResource(key, amount)`：夾到 [0, 上限]，負數與非有限數回 0。
   - `resourceShortageWarning(key, have, need)`：存量低於需求回傳 `UI_RES_LOW` 字串，否則 null。
2. 上限取經濟系統基礎資源表的初始值（糧草 10000、黃金 5000、城市兵源 3000、名聲 2000）。

## 如何驗證
1. `tests/ResourceCap.test.ts` 3 案：上限與規格一致、夾制、不足提示與相等不提示。
2. run-cli 全綠；tsc cc-check 無錯誤。

## 未做（留待後續卡）
- 經濟流程與 UI 呼叫端：目前無 src 呼叫端，提示文案也尚未走 i18n key。

## 暫定
- 上限數值與提示文案沿用規格表的初始值，之後由設定表覆寫（暫定）。

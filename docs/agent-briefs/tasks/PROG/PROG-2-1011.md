# [PROG-2-1011] 裝備品質加成與合入面板數值（BAG-04）

## 開單原因
WBS BAG-04（P0，底座 MVP）：裝備效果要合入戰場數值，品質決定加成範圍。目前沒有任何加成與品質的純邏輯。

## 完整描述
1. `core/systems/EquipmentBonus.ts`（純函式，不依賴 cc）：
   - `EQUIP_BONUS_RANGE`：依武將背包規格表的品質範圍。
   - `clampEquipBonus`：加成夾進品質範圍。
   - `equipStatBonuses`：武器 → 武力、智力；防具 → 統帥、生命；飾品 → 政治、魅力。
   - `applyEquipBonuses`：合入面板，`final = base + Σ 加成`。
2. 進階欄（坐騎、典籍、傳家寶物）規格表沒有對應屬性，這版不加成。

## 如何驗證
1. `tests/EquipmentBonus.test.ts` 4 案：品質範圍、夾範圍、欄位對應、合入面板且不改輸入。
2. run-cli 全綠；tsc cc-check 無錯誤。

## 未做（留待後續卡）
- `EquipItem` 目前只有 uid 與欄位類型，沒有品質與加成欄位；執行期也沒有裝備物件來源。因此無 src 呼叫端，尚未接戰場數值與面板。
- 接線前需要先定義裝備物件的存檔欄位（品質、加成值）。

## 暫定
- 武器的加成同時加到武力與智力，防具同時加到統帥與生命，飾品同時加到政治與魅力（規格寫「A/B 加成」，暫定整額加兩項）。
- 進階欄不加成（暫定）。

# [PROG-2-10111] playtest character-intro-tabs 點名冊第一列沒開出人物介紹

## 根因
名冊列表是回收列池（約 13 列）。playtest 的 locate 預設由前序最後一列往下挑，挑到列表遮罩下緣外（中心 y≈1068）的那一列，玩家看不到也點不到，點了沒反應。11/25 名冊列少，最後一列仍在可視範圍，所以當時 32/32。遊戲本身正常：真滑鼠點畫面最上方那列可開出人物介紹。

## 變更
- tools_node/playtest-online.js：名冊第一列改明確取前序第一個 Row（畫面最上方、玩家看得到），記錄 rowCount。

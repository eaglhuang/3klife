# [PROG-2-10115] 名冊出現「敵軍」陣營武將

## 根因
名冊來源是 session.roster（OwnedRosterSource），沒有混入敵將。generals.json 有 41 位模板 `faction: 'enemy'`（公孫瓚、呂布、貂蟬等），僅是「模板預設站敵方」的戰場標記（奧義系統規格書註明呂布為此），可由轉蛋等入名冊；名冊列表陣營欄照原樣顯示「敵軍」，造成誤會。規格允許，非資料 bug。

## 變更
- FactionDisplay.ts 新增 rosterFactionDisplayName：enemy 標「在野」；名冊列表陣營欄改用。
- tests/FactionDisplay.test.ts 補測試。

## 待裁決
詳情頁表頭仍顯示「敵軍」（GeneralDetailOverviewMapper，有測試鎖定）；是否一併改在野，見回報選擇題。

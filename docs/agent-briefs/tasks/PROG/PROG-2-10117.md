## 開單原因
core.hooksPath 指向主樹 .githooks，mailbox 分支的 detached worktree 也會跑 master 的 pre-commit；但 hook 以相對路徑呼叫 tools_node/check-encoding-integrity.js，mailbox 分支沒有 tools_node，每封信 commit 都失敗，各 AI 只能先用 git archive 解出 tools_node 才能過。改為：工具存在時照舊執行；不存在時改跑內建零依賴檢查（對 staged 文字檔從 index 讀內容，擋 UTF-8 BOM 與 U+FFFD），不再整個失敗。

## 完整描述

- tools_node/adapters/atm-3klife/governance-profile.json
- tools_node/atomic-framework/governance/renderers.js
- tools_node/atomic-framework/governance/profile.js
- tools_node/test/precommit-encoding-fallback.test.js

## 如何驗證
1. 在有 tools_node 的 worktree 行為不變，仍執行 check-encoding-integrity.js --staged
1. 在無 tools_node 的 worktree，staged 文字檔含 BOM 或 U+FFFD 時 commit 被擋並列出檔名
1. 在無 tools_node 的 worktree，乾淨的 .md commit 可直接成功，不需 git archive
1. 回歸測試覆蓋上述三種情境

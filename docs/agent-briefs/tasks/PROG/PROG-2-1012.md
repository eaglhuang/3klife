# [PROG-2-1012] 道具效果派發器（ITM-04a）

## 開單原因
道具系統規格要求每種 Effect_Type 都要有統一的效果引擎，但目前各道具效果散在各子系統，沒有統一入口。PM 裁定把 ITM-04 拆成兩張：04a 先做純派發器，04b 再接真實呼叫端。

## 完整描述
1. `createItemEffectDispatcher` 以註冊制派發六種 Effect_Type（RESTORE_VITALITY、BOOST_CONCEPTION、UNLOCK_TRAINING、REFRESH、ORACLE、EQUIP）。
2. 未註冊的效果回傳 `UNREGISTERED_EFFECT`，處理函式不被呼叫，不丟例外。
3. Effect_Value 非有限數或 ≤ 0 時回傳 `INVALID_VALUE`，處理函式不被呼叫。
4. `vitalityRestoreAmount(maxVitality)` 依規格「回精力 50%」計算整數回復量，上限非正或 NaN 時為 0。

## 如何驗證
1. run-cli 全綠（含 `tests/ItemEffectDispatcher.test.ts`）。
2. tsc cc-check 無新增錯誤。
3. compute-gate standard 9/9。

## 未做（ITM-04b）
- 至少接通一個已有呼叫點的效果（PM 指定回精力或求籤），讓 src 有真實呼叫端。
- 其餘效果的子系統接線，等 04b 逐項確認呼叫點後再做。

## 未定事項（暫定）
- 回精力比例採規格 50%，取整數向下（暫定，規格未寫取整方式）。

# [PROG-2-1013] 日誌與派遣的一句武將反應（NPC-04）

## 開單原因
NPC人性化規格書 §F-2 要求晨報與人物日誌能產生一句個性化反應（JOURNAL_REACTION 模式），失敗時回退固定句。WBS 把 NPC-04 排在 NPC-03 之後；NPC-03 與 persona card 目前都還沒有實作，本卡先做可獨立測試的純邏輯。

## 完整描述
1. `journalReactionLine(entry, generalName, pick)` 依日誌類別（BATTLE / DISPATCH / INTERACTION / GROWTH / SYSTEM）挑一句模板，填入武將名。
2. 挑選索引由呼叫端傳入 `pick`，不用亂數；非有限數視為 0，超出範圍取模。
3. 台詞需為 20~60 字且無未填的 `{}` 佔位；不合格或武將名為空時回傳 `JOURNAL_REACTION_FALLBACK`（「此事容我再想想。」）。
4. 結果標示來源 `TEMPLATE` 或 `FALLBACK`，方便之後接 UI 與除錯。

## 如何驗證
1. run-cli 全綠（含 `tests/JournalReaction.test.ts` 5 案，涵蓋所有模板的字數檢查）。
2. tsc cc-check 無新增錯誤。
3. compute-gate standard 9/9。

## 未做
- NPC-03 STATIC_TEMPLATE 引擎與 persona card（NPC-01）：未存在，之後接上時模板應改由資料檔提供。
- 晨報與派遣結果 UI 的呼叫端：待 JRN-02 晨報摘要接線時再接。
- 正式台詞文案：目前為工程暫定，待企劃定稿。

## 未定事項（暫定）
- 模板數量與文案由工程先寫（暫定，規格未給句庫）。
- 同一登入窗只允許一則主動互動的限制（規格 F-1 規則 3）不在本卡，屬晨報排程範圍。

# [PROG-2-1014] 核心武將 Persona Card 暫定資料（NPC-01 補完）

## 開單原因
NPC-01 的 schema 與驗證已由 PROG-2-0461／0462 完成，但資料檔只有張飛一張卡。NPC-02（情境鍵清單）需要核心武將的 persona card 才能往下做，PM 指示先補上暫定資料。

## 完整描述
1. 依 NPC人性化規格書 §I-1 的欄位，為劉備、關羽、諸葛亮、趙雲、曹操新增 persona card，內容依武將史實性格草擬。
2. 關係錨點沿用 historical-relations.json 的結義、君臣、宿敵關係，目標武將都必須存在於同一張表。
3. 所有卡標為 `Content_Status: PROVISIONAL`，表示內容待企劃定稿。
4. 測試確認核心六卡齊全、錨點指向存在的武將、金句不超過 `NPC_LINE_MAX_CHARS`。

## 如何驗證
1. run-cli 全綠（含 `tests/NpcPersonaCard.test.ts` 新增的核心卡案例）。
2. tsc cc-check 無新增錯誤。
3. compute-gate standard 9/9。

## 未做
- 正式性格、台詞與禁忌：待企劃定稿後替換，結構不變。
- 其餘武將的 persona card：本卡只做 PM 指定的核心六位。

## 未定事項（暫定）
- 核心名單沿用 historical-relations.json 的暫定名單（PROG-2-0520），待企劃給正式名單。
- 金句與安全回退句為工程草擬，不代表正式文案。

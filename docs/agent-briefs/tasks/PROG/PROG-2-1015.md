# [PROG-2-1015] 季結自動結算大廳委任（QA 缺口）

## 開單原因
QA 發現大廳委任只有寫入紀錄、沒有結算入口（派遣即結算只覆蓋手動派遣），委任幾次後武將都會因未結算紀錄被判為忙碌，無法再委任。PM 裁定優先處理。

## 完整描述
1. 季結時，所有未結算的委任依武將戰力（`estimateSortiePower`）判定成敗，門檻沿用派遣即結算的 `judgeHallMissionSuccess`。
2. 結算後紀錄寫入成敗與結算時間，武將釋放，可再次委任。
3. 武將已不在名冊（陣亡或離開）時戰力為 0，判為失敗。
4. 紀錄帶有難度與任務牆時，同時入帳官職經驗（比照派遣即結算）。
5. 委任時一併記下難度與任務牆；舊存檔的紀錄缺省，依未知難度判為失敗。
6. 大廳 UI 委任時傳入難度與任務牆。

## 如何驗證
1. 純邏輯：`settleOpenAssignsForSeason` 判定成敗、保留已結算紀錄、不改輸入（tests/HallAutoAssign.test.ts 2 案）。
2. 跨季流程：委任後 `advanceSeason`，紀錄結算、武將可再委任，存檔讀回一致（tests/HallAssignLog.test.ts 1 案）。
3. run-cli 全綠、tsc cc-check 無錯誤、compute-gate standard 9/9。

## 未做 / 暫定
- 季結判定與派遣同門檻，待企劃確認（暫定）。
- 武將陣亡於季結時判為失敗（暫定）。
- 官職經驗只在紀錄有難度與任務牆時入帳，舊紀錄不補。

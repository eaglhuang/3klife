# [PROG-2-1016] 核心武將情境鍵清單（NPC-02）

## 開單原因
NPC-02 要求每位核心武將至少有 3 個可由本地資料取得的情境鍵，供玩家點頭像時選擇（規格 G：點武將頭像、說一句 20~60 字短句）。NPC-01 補完後，PM 指示接續做 NPC-02。

## 完整描述
1. 新增 `assets/resources/data/npc-context-keys.json`，六位核心武將各列出情境鍵，欄位含鍵名、類別、顯示文字、欄寬上限與來源。
2. 張飛的 4 個鍵（長坂橋斷後、劉備、關羽、曹操）取自 `scratch/keyword-options-check/zhang-fei.keywords.json`，來源標為 `LOCAL_KEYWORD_OPTIONS`。
3. 其餘五位的鍵標為 `PROVISIONAL_DRAFT`，依演義事件草擬。
4. 測試確認每位核心武將至少 3 個鍵、同武將內鍵不重複、類別合法、顯示文字不超過欄寬，並確認張飛來源為本地資料。

## 如何驗證
1. run-cli 全綠（含 `tests/NpcContextKeys.test.ts` 3 案）。
2. tsc cc-check 無新增錯誤。
3. compute-gate standard 9/9。

## 未做 / 暫定
- 其餘五位武將的情境鍵未經本地關鍵字抽取：repo 內沒有 `artifacts/data-pipeline` 的抽取結果，只能草擬，之後由資料管線產出後替換。
- 情境鍵正式清單待企劃定稿。
- 張飛的鍵來自 scratch 目錄的檔案；正式使用前應搬到 data 管線的正式產出位置。

# [PROG-2-1017] 道具效果派發接上補元散（ITM-04b）

## 開單原因
PROG-2-1012 只建了派發器，src 沒有呼叫端。PM 指示 04b 至少要接通一個已有呼叫點的效果，讓派發器進入真實流程。補元散的回精力已有呼叫點（GameSession.usePillOnGeneral → VitalityPill），是最小的接線點。

## 完整描述
1. `VitalityPill.applyVitalityPill` 的回復計算改由 `ItemEffectDispatcher` 派發 `RESTORE_VITALITY`，結果仍夾在精力上限內。
2. 數值與既有行為完全相同：補元散 +50、高級補元散 +100，不超過上限。
3. 派發失敗時精力不變，不拋例外（實際上回復量來自內建表，不會失敗）。

## 如何驗證
1. run-cli 全綠（含 `tests/VitalityPill.test.ts` 新增的派發回復案例，既有案例不變）。
2. tsc cc-check 無新增錯誤。
3. compute-gate standard 9/9。

## 未做
- BOOST_CONCEPTION、UNLOCK_TRAINING、REFRESH、ORACLE、EQUIP 尚未接到子系統，待確認各自呼叫點後逐項處理。

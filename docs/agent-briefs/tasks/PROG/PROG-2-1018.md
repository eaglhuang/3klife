# [PROG-2-1018] 生成台詞性格漂移防護（NPC-06）

## 開單原因
NPC人性化規格書 F-3 要求連網生成的台詞（RAG 改寫）不得偏離武將性格：字數超標、含現代用語、主張未支持的史實、缺少語氣標籤，都必須回退到安全句。NPC-06 可以獨立完成，PM 指示先做。

## 完整描述
1. `canAcceptGeneratedLine` 檢查台詞字數（不超過上限）、旗標（MODERN_SLANG、UNSUPPORTED_HISTORY_CLAIM 不允許）、語氣標籤（武將要求的全部具備）。
2. `guardGeneratedLine` 過檢則採用生成台詞，不過則回退武將的 Safe_Fallback_Line。
3. 字數上限預設 `NPC_LINE_MAX_CHARS`（60，暫定）。

## 如何驗證
1. run-cli 全綠（含 `tests/PersonalityDriftGuard.test.ts` 5 案）。
2. tsc cc-check 無新增錯誤。
3. compute-gate standard 9/9。

## 未做
- 生成端（RAG_REWRITE）尚未存在，本卡沒有呼叫端；接上生成端時再由其傳入旗標。
- 20% 核心金句不被中台覆蓋的規則不在本卡。

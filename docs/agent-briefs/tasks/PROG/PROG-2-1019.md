# [PROG-2-1019] 加速卡縮短剩餘時間（ECO-08）

## 開單原因
WBS ECO-08 要求加速卡每張縮短 2 小時、剩餘時間不低於 0。PM 指示 ECO-08 排在 DS-08 存檔卡之前做。

## 完整描述
1. `accelerateRemaining(remainingMs, cards)`：每張縮短 2 小時；剩餘時間不低於 0；只回報實際消耗的張數。
2. 非有限數或負數視為 0；卡數取整數向下；剩餘為 0 時不消耗卡。

## 如何驗證
1. run-cli 全綠（含 `tests/AccelerateCard.test.ts` 4 案）。
2. tsc cc-check 無新增錯誤。
3. compute-gate standard 9/9。

## 未做 / 暫定
- 5 精元的售價未扣款：精元與靈玉是否同一貨幣尚待使用者裁定。
- 月卡每日贈送 1 張屬 ECO-09。
- End_Time 的時間基準以毫秒剩餘量暫定。
- 尚無呼叫端，接入加速流程時再由呼叫端扣道具。

# [PROG-2-1020] 移除退役產生虎符的來源

## 開單原因
PM 裁定 DS-08 存檔前先處理：兵種（虎符）系統 Q61=C 明文禁止退役產生虎符，規格優先，因此拿掉 PROG-2-0739 加入的退役發卡。

## 完整描述
1. 武職退役時不再產生虎符，移除 `produceRetireTally` 與 GameSession 的退役發卡。
2. 虎符只在陣亡結算產生（`produceDeathTally`）。
3. 舊存檔裡的 retire 卡保留在過渡欄位，不遷移、不刪除。
4. 既有的退役測試改為斷言不產卡，並保留「退役者死亡不再產卡」的檢查。

## 如何驗證
1. run-cli 全綠（`tests/RetireDeathTallyChain.test.ts` 3 案已更新）。
2. tsc cc-check 無錯誤。
3. compute-gate standard 9/9。

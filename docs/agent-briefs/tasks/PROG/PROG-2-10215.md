## 開單原因
使用者試聽 PROG-2-10190 後回饋：回復音效不明顯、太少；水淹少了「嘩啦嘩啦」的連續水聲。

## 完整描述
- 回復：主音改為變調琶音＋氣流＋光暈尾音（約 1.7 秒、響度約為舊版 1.7 倍），另疊 2～3 聲閃光風鈴。
- 水淹：主音改為水湧 whoosh＋兩層急流＋尾巴（2.4 秒），另疊 3～5 聲水花（隨機偏移）。
- `battle-audio-layers.json` 的 `tactic.layers`：每組可設額外疊層（clips／volume／delayMs／count）；疊層算同一施放群組，主音通過發聲池才疊、不另占名額，不改 SfxVoicePool 全域上限（tactic 每秒 3 聲不變）。
- 素材：BigSoundBank 擋腳本下載（403），改用既有 CC0 素材＋程式合成混音，如實記入 LICENSES-cc0.md、_MANIFEST.md；新增檔共 <1MB。
- 涉及：BattleAudio.ts、BattleAudioLayers.ts、battle-audio-layers.json、assets/bundles/audio/clips/tactic_*、tools/gen-tactic-heal-flood-sfx.py、tests/TacticSfx.test.ts。

## 如何驗證
單測（疊層解析、多層排程、素材與授權）、tsc 0 錯、run-cli 全過、compute-gate quick；試聽頁讓使用者比對新舊。

# [PROG-2-10246] 武將天生戰法／奧義模板＋覆寫資料落地

## 開單原因
235 位武將中 218 位只有 1 個天生戰法，且 135 位火計、101 位鼓舞，戰場上多數武將只放那兩招；217 位沒有奧義。特效與音效已由 battleSkillId 自動對應，缺的是「武將 → 招式」的指派資料。

## 完整描述
1. 新增 `data/master/general-skill-templates.json`（13 個模板，含兜底）與 `general-skill-overrides.json`（前 30 位專屬覆寫）。
2. 新增純函式解析器 `core/systems/GeneralSkillTemplates.ts`：模板匹配、輪轉選招、每種戰法／奧義持有人數上限（武將總數 15%）。
3. 新增 `tools_node/apply-general-skill-templates.js`（可重跑、`--dry-run`、`--report`）：把解析結果同步寫進 master `generals-base.json` 與 runtime `generals.json`，並補齊戰法庫 `tactic-tpl-*`、共用奧義定義 `ult-tpl-*`（只引用既有招式 profile，不新造係數與冷卻）。
4. 每位武將至少 2 個不同天生戰法；奧義給 SR（epic）以上武將，其餘維持無。
5. 補 10 個原本沒有招式名的招式 i18n（四語系）與 `BattleSkillPresentation` 招式表；新戰法庫 id 對到規格 TP 表既有招式（沿用既有 TP 數值）。

## 如何驗證
- `tests/GeneralSkillTemplates.test.ts`：匹配規則、15% 上限、至少 2 戰法、奧義範圍、覆寫生效、master／runtime／解析器三方一致。
- tsc 0 錯、run-cli 全過、compute-gate quick。
- web-desktop 實跑標準戰，確認不同武將施放不同招式。

## 未做
- 建議表標「新」的 3 招（遺計、國色、穩固）由企劃另開 profile；本卡改用同特效群組的既有招式。
- 新戰法庫條目未寫 descKey（戰法說明文案），待企劃補。

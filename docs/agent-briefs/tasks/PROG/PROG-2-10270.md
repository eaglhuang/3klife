# [PROG-2-10270] 戰場 Spine 多頁圖集執行期合併

## 開單原因
戰場 draw call 目標 <60；101 具 Spine 時總 797，Spine 約 511。逐 draw 拆解發現騎兵（含呂布）骨架 15～16 張圖集頁且繪製順序交錯，每具 17～26 次 draw，其餘兵種單頁各 1 次。

## 完整描述
載入多頁骨架時，把各頁貼圖以 GPU 拷貝併成單頁，改寫 atlas 文字（bounds 平移），產生合併版 SkeletonData 供節點使用；可由旗標關閉、頁數門檻可調；戰場結束釋放合併貼圖。不動美術資產與骨骼資料。

## 如何驗證
單測（atlas 改寫純函式）、tsc 0 錯、tests/run-cli.ts 全過、compute-gate quick、web-desktop 實跑前後 draw call 與截圖比對。

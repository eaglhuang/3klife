# [PROG-2-1028] 血統樹節點卡資料映射（BUI-02）

## 開單原因
WBS BUI-02：依「血統樹14人UI規格書」§2.2 與 §3.3，14 位先祖卡需由遞迴資料實體化後再賦值。
本卡先做純邏輯映射層，cc 的 NodeCard prefab 與 Layout 綁定屬 UI 線。

## 完整描述
1. 新增 `assets/scripts/core/systems/BloodlineNodeCards.ts`（純 TypeScript，不依賴 cc）：
   - `buildNodeCards(sources)`：依 `PEDIGREE_SLOTS` 固定順序產出 14 張卡。
   - 排數：上排 8 人、中排 4 人、下排 2 人（父母），對應規格 Gen1/Gen2/Gen3Container。
   - 欄位：name、location、factorStars、portrait、stats（武力/統率）、genes、tags。
   - 來源缺資料或名稱為空：輸出 `empty: true` 的卡。
   - 因子星數：負數與 NaN 為 0，小數無條件捨去。
   - 立繪：只有父母掛真立繪（SPRITE），其餘用共用 icon（§3.4）。
2. 輸出複製來源資料，改動輸出不影響來源。
3. 不改 layout JSON、不改 UIPreviewBuilder。

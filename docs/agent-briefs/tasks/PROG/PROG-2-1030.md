# [PROG-2-1030] users／save_snapshots 表定義與列驗證（DS-13 部分）

## 開單原因
WBS DS-13：建立 Server 資料表 users、save_snapshots，並讓靜態 Config 上 CDN。
本卡只做 repo 內可驗證的部分：DDL 與列驗證。依 CLAUDE 與專案規則，Server 端只寫 schema 定義與驗證，不部署、不連外部服務。

## 完整描述
1. 新增 `server/schema/008_users_save_snapshots.sql`：`users`、`save_snapshots` 兩張表，欄位與 Data Schema §一一致。
2. 新增 `server/schema/save-snapshot-row-validators.ts`：
   - `validateUserRow`：Player_ID、Account 非空與長度上限；Created_At 可解析。
   - `validateSaveSnapshotRow`：Player_ID 非空；Save_Version 為 x.y.z；Last_Sync_Hash 為 64 位十六進位；Session_Secret 非空；Updated_At 可解析；Save_Data_JSON 為合法 JSON 且根節點含 Data 物件。
3. 新增 `tests/ServerSchemaSaveSnapshot.test.ts`。

## 如何驗證
1. run-cli 全綠（新增 7 案）；`npx tsc -p tsconfig.cc-check.json --noEmit` 無錯誤；compute-gate standard 9/9。

## 未做

- 靜態 Config 上 CDN 與 Client 版號／MD5 核對：屬發布流程，不在本卡。

# [PROG-2-1031] 虎符／英靈卡不入一般格的分域（BAG-10）

## 開單原因
WBS BAG-10：虎符與英靈卡不應占用普通背包格（Display_Bucket 分域）。武將裝備道具系統 §5 已定義此規則。

## 完整描述
1. 新增 `assets/scripts/core/systems/BagDomain.ts`（純 TypeScript）：
   - `bagDomainOf(record)`：TALLY → TALLY_SLOT、SPIRIT_CARD → SPIRIT_SLOT、OTHER → GENERAL_BAG。
   - `countGeneralBagSlots(records)`：只計 GENERAL_BAG 的列，格數以列計算，數量堆疊不增加格數。
2. 不改 InventoryProjection、不改 UI。

## 如何驗證
1. `tests/BagDomain.test.ts`：三種分域、一般格計數、數量堆疊、空清單。
2. run-cli 全綠；`npx tsc -p tsconfig.cc-check.json --noEmit` 無錯誤；compute-gate standard 9/9。

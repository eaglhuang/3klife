# [PROG-2-1032] 安胎藥接結緣受孕率（ITM-04b，BOOST_CONCEPTION）

## 開單原因
ITM-04b 的五類效果尚未接到子系統。安胎藥（ITEM_FERTILITY，受孕率 ×1.5）的呼叫點已明確：結緣受孕判定 `BreedingSystem.runBreeding` 的受孕率倍率。PM 指示照推薦直接接。

## 完整描述
1. 新增 `FertilityBoost.ts`：`fertilityConceptionMod(active)`，啟用時經 ItemEffectDispatcher（BOOST_CONCEPTION）回傳 1.5，否則 1。
2. `BreedingSystem.BreedingRequest` 新增選填 `itemConceptionMod`，與母體、史實、季節倍率相乘；不傳視為 1。
3. `BreedingService` 新增選填選項 `itemConceptionMod: () => number`，寫入每次配種的 request。

## 如何驗證
1. `tests/FertilityBoost.test.ts`：未啟用為 1、啟用為 1.5；不傳時受孕率不變；倍率乘進受孕率並受上限 0.95 約束。
2. run-cli 全綠；`npx tsc -p tsconfig.cc-check.json --noEmit` 無錯誤；compute-gate standard 9/9。

## 未做（另卡）
- 道具使用流程：扣 ITEM_FERTILITY、記錄「下一次結緣」的一次性倍率、結緣後清除。ServiceLoader 目前不傳 `itemConceptionMod`，所以遊戲內尚無實際加成，直到使用流程卡完成。
- 安胎藥的物品定義與取得來源：規格寫「商城」，屬商業設計，等 ECO 線裁決後再做。
- 其餘四類效果（UNLOCK_TRAINING、REFRESH、ORACLE、EQUIP）與保證受孕（ITEM_CHARM）：各自另卡。

## 自行決定的選擇（PM 可改，皆可逆）
- 倍率只影響受孕率判定，不影響其他結緣數值。
- 倍率放在 request 的獨立欄位，與既有的母體、史實、季節倍率相乘，沿用同一上限。

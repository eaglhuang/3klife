# [PROG-2-1035] 道具背包檢視模型與不足提示（ITM-10）

## 開單原因
ITM-10 要求道具背包 UI，顯示持有清單、篩選，數量不足時導向商城。規格的篩選分類沒有列出分類表，這一片先做可以確定的部分。

## 完整描述
1. 新增 `ItemBagView.ts`：`buildItemBagRows` 依 ID 排序列出道具與數量，支援只看持有；`itemLackPrompt` 數量不足時回傳含商城導向的提示。
2. 純函式，不改背包資料。

## 如何驗證
1. `tests/ItemBagView.test.ts`：排序與數量、持有篩選、不足提示與相等不提示。
2. run-cli 全綠；`npx tsc -p tsconfig.cc-check.json --noEmit` 無錯誤；compute-gate standard 9/9。

## 未做（另卡）
- 篩選分類：規格未列分類表，待補。
- 背包畫面接線（cc）。

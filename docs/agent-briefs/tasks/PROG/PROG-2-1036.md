# [PROG-2-1036] 統一物件庫推導武將一般裝備背包

## 開單原因
寶頁要顯示每位武將的一般裝備，但先前沒有存放位置。PM 裁定裝備存在統一物件庫，每件加選填 `equippedBy`（武將 uid）與 `slotId`，武將背包由 uid 篩出。

## 完整描述
1. `InventoryRecord` 新增選填 `equippedBy`、`slotId`；缺欄位即未裝備。
2. 新增 `GeneralBackpackView.ts`：`deriveGeneralBackpack(records, uid)` 只讀篩出該武將的一般裝備，不改輸入。

## 如何驗證
1. `tests/GeneralBackpackView.test.ts`：舊檔缺欄位、只篩指定武將、非 OTHER 列不算、同格重複保留先出現者、進階欄解鎖、不改輸入。
2. run-cli 全綠；`npx tsc -p tsconfig.cc-check.json --noEmit` 無錯誤；compute-gate standard 9/9。

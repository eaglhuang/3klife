# [PROG-2-1037] 寶頁六格裝備接線（cc 畫面）

## 開單原因
PROG-2-1034（2x3 格位模型）與 PROG-2-1036（統一物件庫推導背包）完成後，寶頁還沒有把六格顯示出來。layout 原有節點名都是 generic 的 div／span，無法辨認哪一格，coordinator 批准新增具名格位節點。

## 完整描述
1. layout：`CharacterDs3TabEquip_div_1` 底部新增 `EquipGearGrid`（兩列三欄），六個 label 節點名為 `EquipSlot_<WEAPON|ARMOR|ACCESSORY|MOUNT|TOME|TREASURE>`，styleSlot 指向 `auto.character-ds3-tab-equip.equipslot_<槽>`。
2. skin：新增六個 label-style 條目，樣式沿用 span_2，字級 14。
3. GameSession 新增唯讀 `inventoryRecords`；存檔讀回的展開運算保留 equippedBy／slotId。
4. Overview 狀態新增 `gearSlots`，由統一物件庫列經 `deriveGeneralBackpack` 與 `buildGearPageSlots` 推導。
5. `CharacterDs3EquipChild.onDataUpdate` 寫入六格文字（`gearSlotText`：槽名加未解鎖／空／已裝備）。

## 如何驗證
1. `tests/GearPageSlots.test.ts`：格位文字依狀態輸出。
2. run-cli 全綠；`npx tsc -p tsconfig.cc-check.json --noEmit` 無錯誤；compute-gate standard 9/9。
3. 座標與節點位置交 Codex 實機核對（cc 引擎內無法在容器驗證）。

# [PROG-2-1038] 道具使用流程：刷新券與安胎藥

## 開單原因
刷新券（#971）與安胎藥（#964）的效果都已寫好，但沒有任何使用入口。QA 複查指出兩者都沒有呼叫端。PM 裁定安胎藥以 `ITEM_FERTILITY_ARMED` 標記實作。

## 完整描述
1. `PlayerInventory`：新增 ITEM_REFRESH、ITEM_FERTILITY、ITEM_FERTILITY_ARMED 常數，前兩者有顯示名稱，ARMED 不顯示於背包。
2. `ItemUseFlow.useItem`：只接兩種道具，數量不足回傳商城導向提示；刷新券先派發效果、成功才扣；安胎藥扣一張並寫入 ARMED，已 armed 時回傳 ALREADY_ARMED。
3. `GameSession.useItem` 寫回背包與傭兵池、救美冷卻時間戳；`clearFertilityArm` 清除標記。
4. `BreedingService` 新增 `onBreedPerformed`，在結緣實際執行（非 blocked）後呼叫；`ServiceLoader` 以 ARMED 標記提供 `itemConceptionMod`，並在結緣後清除。

## 如何驗證
1. `tests/ItemUseFlow.test.ts`：刷新券扣一張並到期、不足提示、安胎藥扣一張並 armed、已 armed 不重複、不支援與原型屬性名稱被拒、冷卻一小時後仍到期。
2. run-cli 全綠；`npx tsc -p tsconfig.cc-check.json --noEmit` 無錯誤；compute-gate standard 9/9。
3. 注意：GameSession 與 ServiceLoader 依賴 cc，無法在容器內整合測試；由 Codex 實機確認結緣後加成與清除。

- 裝備名稱顯示（待 provisional 裝備定義表）。

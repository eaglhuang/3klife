# [PROG-2-1039] 一般裝備定義表與寶頁顯示裝備名

## 開單原因
PROG-2-1037 之後，寶頁六格只會顯示「已裝備」，玩家看不到是哪一件。統一物件庫的列只存 Inventory_ID 與數量等欄位，名稱不該寫進列裡（PM 裁定：物件列只存定義 id，名稱由獨立定義表提供）。

## 完整描述
1. 新增 `assets/scripts/core/systems/GearDefinitions.ts`：一般裝備定義表，六個槽各一筆占位定義（`GEAR_<槽>_PLACEHOLDER`），標記 `provisional: true`，稀有度 `UNSET`，名稱為占位字串（如「武器（占位）」）。
2. 提供 `gearDefinitionOf(id)`：查無 id、空值與原型屬性名稱（如 `toString`）一律回傳 `undefined`。
3. `InventoryRecord` 新增選填 `Gear_ID`；缺欄位即無定義，不以預設值補。
4. `gearNameOfUid(records, uid)`：依武將背包的 uid（即 Inventory_ID）查出裝備名稱。
5. `GearSlotView` 新增 `equippedName`；`buildGearPageSlots` 接受可選的 `nameOfUid`，已裝備且查得名稱時寫入；`gearSlotText` 顯示「槽名：裝備名」，查不到時仍顯示「已裝備」。
6. `GeneralDetailOverviewMapper` 把 `gearNameOfUid` 傳入格位推導。

## 如何驗證
1. `tests/GearDefinitions.test.ts`：六槽占位定義完整、查無 id 與原型名稱回傳 undefined、Gear_ID 查名稱、格位文字含裝備名與退回「已裝備」。
2. run-cli 全綠；`npx tsc -p tsconfig.cc-check.json --noEmit` 無錯誤；compute-gate standard 9/9。

## 未做（另卡）
- 穿戴／卸下寫入路徑（GameSession 寫 equippedBy／slotId，寶頁格點擊選可裝備道具）。
- 背包使用按鈕 cc 接線（等 #1020 合併後接 `useItem`）。
- 正式裝備名稱、稀有度與數值（待企劃；現為 provisional 占位）。

# [PROG-2-1041] 道具背包畫面（ITM-10）

## 開單原因
道具系統規格列出「道具背包 UI（P1）」，持有列表、數量、篩選。PROG-2-1035 只做了模型，PROG-2-1038 做了使用流程。現在要有畫面，玩家才能實際使用刷新券與安胎藥。

## 完整描述
1. `ItemBagController`（純 Presenter，`assets/scripts/ui/core/`）：列出持有道具（最多 BAG_ROW_SLOTS 列）、選取、使用需兩步確認（使用 → 確定）、使用結果轉提示文字；確定後才呼叫 `useItem`。
2. 版位：規格未寫，採清單加右側詳情加「使用／確定／取消」按鈕，layout 為 `item-bag-main.json`，screen `item-bag-screen`，skin `item-bag-screen.skin`。
3. `LobbyScene`：隱藏掛載，`openItemBag()`；確定使用成功才 `session.save()`。
4. 大廳入口：商城分類第四項「背包」（與倉庫並列）。

## 偏離規格或指示之處
- coordinator 指示入口放大廳「與太守府同區」（內政）。但內政分類已有 5 項，正好是 `LOBBY_SUB_SLOTS` 上限，加第 6 項版型放不下。因此改放商城分類。若 PM 要放內政，需先把子選單上限增為 6，屬另一張 layout 卡。

## 如何驗證
1. `tests/ItemBagController.test.ts`：持有列表與截斷上限、未選取提示、確認流程、取消、結果提示（商城導向、已生效）、用完取消選取。
2. `tests/LobbyCityHubController.test.ts`：入口總數改為 19，商城第四項為背包。
3. run-cli 全綠；`npx tsc -p tsconfig.cc-check.json --noEmit` 無錯誤；compute-gate standard 9/9。
4. 座標與版位交 Codex 實機驗收。

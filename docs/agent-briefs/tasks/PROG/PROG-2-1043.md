# [PROG-2-1043] GameSession 穿戴與卸下一般裝備

## 開單原因
PROG-2-1040 只有穿戴與卸下的純邏輯，還沒有接到 GameSession，所以寶頁六格仍然沒有寫入路徑。本卡接上 GameSession，並以一般裝備定義表判斷能否放入格位。

## 完整描述
1. `GameSession.equipGear(gearUid, generalUid, slotId)`：呼叫 `equipGear` 純邏輯，可否放入由 `gearDefinitionOf(record.Gear_ID)?.slot === slot` 判斷；成功才寫回物件庫列。
2. `GameSession.unequipGear(generalUid, slotId)`：呼叫 `unequipGear`，成功才寫回。
3. 失敗時物件庫完全不變；回傳的 `GearEquipResult` 原因交由 UI 顯示。

## 如何驗證
1. `tests/GameSessionGearEquip.test.ts`：符合槽位可穿戴並反映到寶頁背包；槽位不符拒絕且物件庫不變；未知 Gear_ID 拒絕；卸下後格位回到空。
2. run-cli 全綠；`npx tsc -p tsconfig.cc-check.json --noEmit` 無錯誤；compute-gate standard 9/9。

## 未做（另卡）
- 寶頁格點擊與從背包選可裝備道具的 cc 畫面接線：格位目前是 label，需改成可點按鈕並加選取清單。
- 存檔由呼叫端負責，與道具使用一致。

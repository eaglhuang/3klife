# [PROG-2-1044] 寶頁格位選取清單與面板流程（純邏輯）

## 開單原因
寶頁六格（PROG-2-1037）與穿戴寫入（PROG-2-1043）都已完成，但玩家還不能點格子選裝備。cc 接線需要先有可測試的清單與流程，因此本卡先做純邏輯。

## 完整描述
1. `GearPickerView.ts`：`buildGearPickerRows` 列出可放入該格的一般裝備（排除他人已裝、非裝備、查無定義）；`hasEquippedInSlot` 判斷該格是否有這位武將的裝備。
2. `GearSlotPickController.ts`：開格、選一件穿上（成功關閉、失敗留在面板顯示原因）、卸下（該格有裝備才可用）、扁平 FlowView（key 預留給選取面板 layout）。
3. 寫入經注入的 `equip`／`unequip`，即 GameSession.equipGear／unequipGear；本檔不改物件庫。

## 如何驗證
1. `tests/GearSlotPickController.test.ts`：清單篩選、重新穿戴、已裝判斷、開格與 FlowView、穿上成功與失敗、卸下、面板關閉狀態。
2. run-cli 全綠；`npx tsc -p tsconfig.cc-check.json --noEmit` 無錯誤。

## 未做（另卡 PROG-2-1045）
- 寶頁格位點擊（EquipSlot 標籤改為可點，或覆蓋透明按鈕）。
- 選取面板的 layout、skin 與節點 id（對應本檔 FlowView 的 key）。
- GeneralDetailComposite 接線：把 GameSession 的 equipGear／unequipGear 與面板綁在一起，並存檔。

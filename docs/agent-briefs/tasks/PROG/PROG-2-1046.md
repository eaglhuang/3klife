# [PROG-2-1046] StoryDock 三態與 reflow 切分（GDUI-06 純邏輯）

## 開單原因
武將人物介面規格書 §6.4 要求命頁底部 StoryDock 支援 COLLAPSED、HALF、EXPANDED 三態，展開時主血統區要縮放，不可 overlay 蓋住 14 人血統圖。本卡先把三態規則做成可測試的純邏輯。

## 完整描述
1. 三態格數：COLLAPSED 1 格、HALF 3 格、EXPANDED 5 格（與故事條五段節奏一致）。
2. 故事條依固定節奏取格，文字不足補空字串，不補假故事。
3. `storyDockLayout` 把總高度切成血統區與故事條，兩者相加等於總高度（不 overlay）。
4. `nextStoryDockState` 把手向上拖展開一階、向下拖收合一階，到頂或到底停住。

## 如何驗證
1. `tests/StoryDockView.test.ts`：格數、節奏、取格與補空、高度守恆、總高度不足、把手拖拉。
2. run-cli 全綠；`npx tsc -p tsconfig.cc-check.json --noEmit` 無錯誤；compute-gate standard 9/9。

## 未做（另卡）
- cc layout reflow 接線與把手拖拉事件。
- 三態高度數值為暫定，待 Codex 實機微調。

# [PROG-2-1047] 技頁已習得列接上三態檢視模型（GDUI-10 cc 接線）

## 完整描述
1. `GeneralDetailSkillsChild` 在沒有 `tacticSlots` 時，改用 `buildTacticsTabView` 組已習得列。
2. 每列顯示「名稱［等級 · TP · 類型］」；戰法庫查無定義時顯示 id，不補假資料。
3. TP 消耗沿用 `SortieDeploy.getTacticTpCost`，與戰場消耗同一張表。
4. 可習得、未解鎖、主戰法目前傳入空值，因為規格尚未定義資料來源（見 PROG-2-1042 的未做事項）。

2. compute-gate standard 9/9。
3. 實機：Codex 開技頁確認列文字與換行（cc 端無法在容器內建置）。

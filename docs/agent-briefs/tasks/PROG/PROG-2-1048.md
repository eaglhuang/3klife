# [PROG-2-1048] 血統樹 14 人版型節點結構（BUI-01）

## 開單原因
WBS BUI-01 要求血統樹的節點結構與 Layout JSON 先定下來，之後的綁定與連線繪製才有依據。目前 `assets/resources/ui-spec/layouts/` 沒有 `bloodline-tree-main.json`。

## 完整描述
1. 新增 `bloodline-tree-main.json`：根節點 `BloodlineTreeRoot`，下分 `HeaderTitle`、`TreeArea`、`BottomInfoArea`。
2. `TreeArea` 內含 `Gen1Container`（8 張）、`Gen2Container`（4 張）、`Gen3Container`（2 張），以及 `LineGraphics`。
3. `BottomInfoArea` 內含 `LegendPanel`、`MainTargetPanel`（`TargetPortrait`、`TargetRarity`）與 `SkillDetails`。
4. 卡片名稱為 `NodeCard_G{世代}_{序號}`，14 位先祖加 1 位子代，共 15 個槽位。
5. 新增 `.meta`，uuid 為新產生值。

## 如何驗證
1. `tests/BloodlineTreeLayout.test.ts` 4 案：根節點與必備節點、14＋1 槽位數量、容器內卡片數、名稱不重複。
2. run-cli 全綠；`npx tsc -p tsconfig.cc-check.json --noEmit` 無錯誤。
3. compute-gate standard 9/9。

## 未做（另卡）
- `UIBloodlineConnections`（依卡片位置畫連線）。
- 卡片內容綁定、Prefab 化與 skin。
- `LineGraphics` 目前以 `_contract` 標記，未實作 Graphics 節點類型。

# [PROG-2-1054] 子嗣奧義覺醒接線（ULT-15 接線）

## 來源
- PROG-2-1053 已完成純邏輯。本卡把它接到培育訓練回合，並以真實流程測試驗證。
- 1055（寫入父母 id）無需開卡：createChild 已寫入 fatherId／motherId，名冊保留這兩欄。

## 範圍
- `core/systems/ChildUltimateAwaken.ts`：`childUltimateCandidates`（奧義 inheritanceGeneId 必須是子嗣的綠色因子）。
- `core/services/NurtureService.ts`：`childUltimate` 選項與 `_rollChildUltimate`，只在訓練回合擲。
- `core/managers/ServiceLoader.ts`：`loadUltimateDefinitions`，於 prepareBreeding 載入奧義母表。
- `tests/ChildUltimateWiring.test.ts`：4 案真實流程測試（覺醒寫入、無綠色因子、只休息、未提供選項）。

## 暫定
- 「對應綠色因子」以奧義的 inheritanceGeneId 等於子嗣的綠色基因 id 判定（基因 type 即顏色）。
- 每個訓練回合各擲一次，同一奧義只記一次。

## 缺口
- 父方不在名冊內時沒有候選。
- 子嗣奧義的存檔只隨名冊 JSON，未單獨做存檔往返測試。

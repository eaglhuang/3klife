# [PROG-2-1065] 史實合攻接進戰場判定（KIN-09 接線）

- PM 裁定（暫定）：20% 只套在有史實關係的相鄰組合；追加傷害沿用 50%，不觸發反擊、不擲命中；一般友軍不觸發。
- 前置：PROG-2-1063（ComboAttackKin 純邏輯）。

- `battle/runtime/BattleCombatResolver.ts`：`resolveKinComboFollowUp`；共用 `applyCombinedFollowUpDamage`、`findCombinedHelper`；context 的 `relationsBetween`。
- `core/systems/ComboAttackKin.ts`：`comboChanceOfPair`。

- `battle/controllers/BattleController.ts`：`historicalPairs`、`relationsBetweenUnits`、`sourceTemplateOfUnit`；`tallyInfoOf` 增 `sourceTemplateId`。
- `battle/views/BattleScene.ts`：載入史實配對表；虎符來源武將 uid → 模板 id。
- `core/managers/ServiceLoader.ts`：`historicalPairTable()` 存取器。
- 測試：`tests/KinComboBattle.test.ts`（多回合，3 案）、`tests/KinComboRelations.test.ts`（真實資料，3 案）、`tests/ComboAttackKin.test.ts`（+1）、`tests/FactorTacticLinkage.test.ts`（來源字串測試的切片邊界）。

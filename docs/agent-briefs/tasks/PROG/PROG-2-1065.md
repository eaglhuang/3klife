# [PROG-2-1065] 史實合攻接進戰場判定（KIN-09 接線）

## 來源
- PM 裁定（暫定）：20% 只套在有史實關係的相鄰組合；追加傷害沿用 50%，不觸發反擊、不擲命中。
- 前置：PROG-2-1063（ComboAttackKin 純邏輯）。

## 範圍
- `battle/runtime/BattleCombatResolver.ts`：新增 `resolveKinComboFollowUp`；共用 `applyCombinedFollowUpDamage` 與 `findCombinedHelper`；context 可選 `relationsBetween`。
- `core/systems/ComboAttackKin.ts`：`comboChanceOfPair`（沒有關係為 0）。
- `tests/KinComboBattle.test.ts`（新，3 案，多回合）。
- `tests/ComboAttackKin.test.ts`：+1 案。
- `tests/FactorTacticLinkage.test.ts`：來源字串測試的切片邊界改為新方法名。

## 缺口
- BattleController 尚未提供 `relationsBetween`：部隊的 commanderUid 只指向玩家主將，沒有部隊對應到史實關係武將的來源，因此遊戲中目前不會觸發。需另卡補對應（例如以虎符的來源武將 `sourceGeneralUid` 查 historical-relations.json）。
- 戰場演出未做。

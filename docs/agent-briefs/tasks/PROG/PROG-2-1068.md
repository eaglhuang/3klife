# [PROG-2-1068] 關係組合場景事件（KIN-08）

## 來源
- 規格 家族關係（史實相性）系統.md §A #7「關係事件觸發」（P1）：特定關係組合在戰場／治理中觸發專屬事件。
- §G 劇本相關：名將契合、義兄弟合攻、宿敵配種等劇本句。
- WBS v16 KIN-08：指定關係組合在對應場景觸發一次事件並顯示劇本。

## 範圍
- `core/systems/RelationEvents.ts`：
  - `RELATION_EVENT_DEFS`：戰場 COUPLE → famous-match、SWORN → sworn-combo；治理 RIVAL → rival-breed。
  - `detectRelationEvents(table, {scene, templateIds})`：場景在場武將兩兩比對 HistoricalPairTable，回傳命中事件（只給 loreKey）。
  - `RelationEventLedger`：`tryFire` / `takeNew` 保證同場景實例、同對、同事件只觸發一次；`snapshot` / `restore` 給存檔用。
- 測試：`tests/RelationEvents.test.ts`（8 案，涵蓋場景過濾、順序無關、去重、存檔還原）。

## 暫定（待辦檔記錄）
- 場景對應：名將契合、義兄弟合攻歸戰場；宿敵配種歸治理（配種）。規格 §G 未標明場景。
- 劇本字串以 loreKey 輸出，文字由 UI 字串表解析；本卡不新增字串。

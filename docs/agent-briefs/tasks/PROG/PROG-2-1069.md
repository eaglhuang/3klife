# [PROG-2-1069] 父母因子→子嗣預期因子分布（ORAC-03）

## 來源
- WBS v16 ORAC-03：預言輸入，父母因子→子嗣預期因子分布（與結緣預覽共用），純邏輯，係數 0.4。
- 名士預言系統.md §F：WeightedSample 需要子嗣實際因子分布。

## 範圍
- `core/systems/ChildFactorExpectation.ts`：
  - `expectedChildFactorPool(sources, options)`：與 `inheritFactors` 同一套進池規則，算出每個因子的進池機率（多祖先取 1 - Π(1 - p)）與六色預期權重（正規化總和 1）。
  - 輸入沿用 `AncestorFactorSource[]`，可直接接 `BreedingSystem.buildFactorSources(pedigree, profiles)` 的結果。
- 測試：`tests/ChildFactorExpectation.test.ts`，含固定種子 20000 次抽樣與 `inheritFactors` 比對（誤差 < 0.02）。

## 不做
- 屬性（武力／智力）分布：字典與祖譜目前只有色系資料。
- 星等、maxFactors 截斷：不影響進池機率的部分不計入。
- 名士占卜與結緣預覽的 UI 接線。

# [PROG-2-1076] 戰場 HUD 主將名與回合數接上執行期資料

## 來源
- MVP 循環實機測試：不論玩家選誰出戰，戰場 HUD 都顯示「關羽」、回合永遠是「第 7 回合」。
- 原因：`battle-hud-screen` 版面由 HTML 示意稿轉成，節點名是 `div_N` 且沒有 `id`；`BattleHUDComposite` 用 `binder.getLabel('PlayerNameLabel')` 等 id 取不到 Label，畫面停在示意稿假字。

## 範圍
- `layouts/battle-hud-screen.json`：div_4 → `TurnLabel`、div_58 → `PlayerNameLabel`、div_124 → `PlayerCommandNameLabel`、div_78 → `EnemyNameLabel`（只加 id，不改節點名）。
- `BattleHUDComposite.ts`：底部指令列主將名與頂部同步。
- `tests/BattleHudBindingIds.test.ts`（新）。

## 缺口（另開卡）
- HUD 其餘欄位（八格陣列其他武將、LV、戰報、右側數值卡、關卡名）仍是示意稿假資料。

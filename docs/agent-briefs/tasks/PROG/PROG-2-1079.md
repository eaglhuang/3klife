# [PROG-2-1079] 缺翻譯時 label 退回原文，不露出 auto.* 鍵名

## 來源
- MVP 實機測試：大廳與戰場畫面直接顯示 `auto.lobby-main-screen...`、`auto.battle-hud-screen...` 鍵名。
- 原因：HTML 稿轉成的 8 個 layout 共約 1,100 個 `auto.*` textKey，zh-TW 字典一個都沒收錄；`UIPreviewNodeFactory` / `UIPreviewBuilder` 查不到翻譯時直接回傳鍵名，忽略同節點上的原文 `text`。

## 範圍
- `ui/core/UILabelText.ts`（新，純邏輯）：翻譯 > 原文 > 鍵名 > bind 佔位 > 空字串。
- `UIPreviewNodeFactory.ts`、`UIPreviewBuilder.ts` 改用它。
- `tests/UILabelText.test.ts`（新）。

## 缺口
- `auto.*` 鍵正式收進 zh-TW / 其他語系字典，另案處理（ui-i18n-localize）。

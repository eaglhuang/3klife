# [PROG-2-1081] 大廳讀存檔前未初始化服務，重開遊戲被當新玩家

## 來源
- MVP 無頭實機測試：完成宿命轉蛋後重開遊戲，大廳仍判定新玩家，開場介紹重跑、主將為空。
- 原因：`ServiceLoader.initialize()` 才會 `session.setSaveService(...)`；`LobbyScene.start` 沒呼叫，`_loadPlayerSave` 時拋「尚未設定存檔服務」被吞成新局。之後其他元件順手初始化，存檔寫得進、讀不回。

## 範圍
- `LobbyScene.start` 開頭呼叫 `services().initialize(this.node)`（initialize 冪等）。
- `tests/LobbySaveLoadOrder.test.ts`（新）：initialize 必須在讀檔之前。

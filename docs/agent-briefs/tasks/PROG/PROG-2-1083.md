# [PROG-2-1083] 戰鬥 HUD 從 HTML 轉來的面板蓋住戰場

## 來源
- MVP 無頭實機截圖：進戰場後上方一條粉紅色帶橫跨畫面、右側一塊整條黑色面板、左上一塊棕色空框，指令列跑到畫面上半部。
- 原因：`battle-hud-screen.json` 由 HTML 轉換而來，
  - `div_13` 是 HTML 原型畫的 5x8 棋盤格與單位卡，和遊戲本身的 3D 棋盤重複，執行期被拉成整條色帶。
  - `aside_1`、`aside_2`、`button_1`、`div_122` 的 widget 上下左右四邊全設（含負值），執行期尺寸被撐開、位置跑掉。

## 範圍（只求清楚可操作，美感之後再調）
- `div_13` 設 `active: false`（模擬棋盤不顯示）。
- `aside_1`、`aside_2`、`button_1`、`div_122` 改成只錨定兩邊，保留原本寬高。
- `tests/BattleHudScreenAnchors.test.ts`（新）：上述節點不得四邊全錨、不得負值錨點；`div_13` 不顯示。

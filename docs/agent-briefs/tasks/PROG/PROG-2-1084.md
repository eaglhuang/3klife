# [PROG-2-1084] 開局送一位紅顏，讓第一次結緣有對象

## 來源
- 新手開場規格書（doc_spec_0031）第四幕「紅顏登場」與 §8：紅顏池與名將池分開，是血統與後代的定錨。
- `gacha-config.json` 已有 `support-pool`（紅顏池：大喬、小喬、甄宓、黃月英、蔡文姬），但遊戲程式沒接，只有驗證器讀它。
- MVP 實機：六位初始名將全是男性，開局結緣面板「母方：無人可選」，新玩家卡住。

## 範圍（MVP 最小接法）
- 新增 `core/systems/OpeningBeauty.ts`：從紅顏池抽 1 位，支援卡 id 轉武將 id（甄宓→zhen-ji、黃月英→huang-yue-ying、蔡文姬→cai-yan），只收資料表裡存在的女性武將。
- `StarterRosterOptions.beautyGeneralId`：起始名冊在六位名將之後加入這位紅顏（深複製、驗證資料完整）。
- `startNewGameFromDestiny`、`DestinyOpeningController`、`LobbyScene`：宿命鎖定開新局時一併帶入，開局訊息顯示紅顏名字。
- 測試：`tests/OpeningBeauty.test.ts`（新）。

## 不在本卡
- 紅顏「趕路倒數」、加價購、首戰後才登場的演出順序與付費入口（之後另卡）。

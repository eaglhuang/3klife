# [PROG-2-1087] 他國 AI 勢力核心：邦交、季度行動、外交指令、自動模擬戰鬥結算

## 來源
- 治理模式他國 AI 系統（doc_spec_0020）：E-1 AI 國家定義、E-2 勢力性格、E-5 外交（邦交值 -100~+100、變動表、季度回歸）、E-12 玩家互動（送禮／結盟／宣戰）。
- 使用者裁定 2026-10-25：MVP 要有 AI 對手可外交或戰鬥；戰鬥先用自動模擬數值直接跳結算。
- 目前程式只有十三州名稱清單，沒有任何 AI 勢力。

## 範圍（這張只做純邏輯，畫面與存檔串接另開卡）
- `assets/scripts/core/systems/RivalNations.ts`（新）：
  - 8 個 AI 勢力（魏、蜀、吳、呂布、袁紹、劉璋、馬騰、南蠻），君主對到 generals.json，性格、兵力、領地數、與玩家的初始邦交。
  - 邦交等級（同盟／友好／中立／冷淡／敵對／宿敵）。
  - 玩家指令：送禮（扣金、加邦交）、結盟（邦交 ≥40）、宣戰（邦交歸 -100）。
  - 季度推進：邦交向 0 回歸 2；好戰勢力對敵對玩家發動進攻；兵力隨性格成長。
  - 自動模擬戰鬥：玩家出戰武將五維 vs 勢力兵力，給定亂數直接算勝負、雙方損失與戰利品。
- `tests/RivalNations.test.ts`（新）。

# [PROG-2-1089] 招賢館：20 位名將可直接挑選、用金幣招募入名冊

## 來源
- 使用者裁定 2026-10-25：MVP 武將至少要有 20 人可以選。
- 新手開場規格書 §6：宿命池固定六位初始名將（不動）；gacha-config.json 的 hero-pool 已定義 20 位一般名將。
- 目前名將池只能隨機抽，玩家無法自己挑。

## 範圍
- RecruitHallController（新，純邏輯）：列出 hero-pool 20 位（名字、五維、費用、是否已在名冊），分頁 10 位，點選扣金幣入冊。
- recruit-hall screen / layout / skin（新）；LobbyScene 掛載；內政畫面加「招賢館」入口。
- 測試：tests/RecruitHall.test.ts（新）。

## 驗收
- 招賢館列出 20 位名將，可翻頁；金幣足夠時點選即入名冊、扣金幣；已在名冊或金幣不足時按鈕停用並顯示原因。
- run-cli 全綠；tsc cc-check 無錯；compute-gate standard 通過；web build 實機點擊通過。

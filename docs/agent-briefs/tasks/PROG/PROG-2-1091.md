# [PROG-2-1091] 戰鬥自動鈕：依數值模擬直接跳結算

## 來源
- 使用者裁定 2026-10-25：戰鬥先用自動模擬數值結果直接跳結算。
- 實機 2026-10-25：戰鬥 HUD 的 BtnAuto 只發 AutoBattleToggled，沒有任何接收端；首戰開自動等 5 分鐘仍停在第 1 回合。

## 範圍
- BattleAutoResolve.ts（新，純邏輯）：雙方主將與存活部隊的數值折算戰力，加亂數浮動判勝負。
- 戰鬥場景接 AutoBattleToggled：開啟時立即算出勝負，走既有 BattleEnded → 結算彈窗 → 返回大廳流程。
- 測試：tests/BattleAutoResolve.test.ts（新）。

## 驗收
- 首戰按自動即跳結算彈窗，返回大廳後通關紀錄與既有結算一致。
- run-cli 全綠；tsc cc-check 無錯；compute-gate standard 通過；web build 實機通過。

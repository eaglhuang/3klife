# [PROG-2-1092] CompositePanel 掛載時帶入翻譯字典，結算按鈕不再露出鍵名

## 來源
- 實機 2026-10-25：戰鬥結算彈窗按鈕顯示 ui.result.back_to_lobby / ui.result.retry 原始鍵，但 zh-TW.json 已有翻譯。
- 成因：CompositePanel.mount 呼叫 buildScreen(layout, skin, undefined, tokens)，翻譯字典永遠是空的。

## 範圍
- CompositePanel.mount 與 layout 一起載入目前語系字典並傳給 buildScreen。
- 測試：tests/CompositePanelI18n.test.ts（新）。

## 驗收
- 結算彈窗按鈕顯示「返回大廳」「重新挑戰」等中文。
- run-cli 全綠；tsc cc-check 無錯；compute-gate standard 通過；web build 實機通過。

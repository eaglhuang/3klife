# [PROG-2-1107] 武將小人頭：可迭代的美術路徑規則＋自動裁切頭像，先接招賢館

## 來源
- 使用者 2026-10-25：武將姓名旁要有小人頭；立繪還沒畫完，結構要能迭代、不寫死；立繪要從標準路徑取；做法要和美術總監統一。
- 美術總監（100武將2D角色動畫管線評估 session）2026-10-25 對齊結論：正式頭像 sprites/generals/avatars/{file}_avatar.png 256×256 由其管理（只讀）；裁切座標集中在 general-avatar-crops.json，source 分 auto／reviewed；頭頂留 8%、臉在中線上方約 45%；512 母圖留 artifacts；呂布暫代。

## 範圍
- assets/resources/data/general-art-paths.json：立繪／頭像路徑樣板唯一來源（正式頭像 → 自動裁切 → 剪影）。
- assets/scripts/core/systems/GeneralArtPaths.ts、assets/scripts/ui/core/GeneralAvatarLoader.ts：路徑規則與載入。
- tools_node/generate-general-avatars.js：讀標準立繪路徑、無座標自動估算（source:auto）、輸出 sprites/ui_avatars/cropped 與 artifacts 母圖／總覽；不寫 sprites/generals。
- assets/resources/data/general-avatar-crops.json：26 位座標與審核狀態。
- assets/resources/sprites/ui_avatars/cropped/*：自動裁切頭像。
- 招賢館每列加圓形小人頭（recruit-hall-main.json、recruit-hall-screen.skin.json、LobbyScene.ts、RecruitHallController.ts）。
- BattleHUD.ts、BattleHUDComposite.ts、GeneralDetailOverviewMapper.ts 改用 GeneralArtPaths，不再各自寫死路徑。
- tests/GeneralArtPaths.test.ts。

## 驗收
- 招賢館每列顯示圓形小人頭；正式頭像存在時優先使用；放新檔不必改程式。
- compute-gate standard 通過、測試通過。

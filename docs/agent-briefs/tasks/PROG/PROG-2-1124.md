# [PROG-2-1124] 內政導覽列加「紅顏」入口

## 為什麼做
紅顏展示（OPEN-10）已掛載但大廳沒有手動入口（PROG-2-0133 驗收發現），PROG-2-0120 驗收卡因此卡在「找到入口」。

## 做法
- domestic-main.json 的 DomesticNavGroup 加 BtnOpenRedFace，五顆按鈕改為寬 188、間距 21（總寬仍 1024）。
- LobbyScene 綁定 btnOpenRedFace：關閉內政 → openRedFaceShowcase()。

## 驗收
- tsc、單元測試、gate 9/9 通過；Web 版點擊內政 → 紅顏 能開啟展示並可關閉。

# [PROG-2-1126] 紅顏展示與招賢館：一頁六框全身立繪

## 為什麼做
使用者裁定：紅顏圖、名將池都要顯示全身立繪，一頁由左到右六個瘦長框，超過六位翻頁；每張立繪比例相同、頭高一致，左右與下身可被框切掉。

## 做法
- PortraitGallery（純邏輯）：六框分頁、選取、核心徽章、選中金框；兩畫面共用同一套節點 id。
- PortraitFrameFit（純數學）：依 general-avatar-crops.json 的臉部標記，臉高統一、眼睛同高、臉置中；無標記退回估算，無立繪放剪影頭像。
- 紅顏展示改 RedFaceGalleryController（轉蛋分頁的五列版不動）；招賢館改點框選人、按「招募」。

## 驗收
- 單元測試、gate 9/9；Web 實跑兩畫面立繪頭高一致、翻頁與招募正常。

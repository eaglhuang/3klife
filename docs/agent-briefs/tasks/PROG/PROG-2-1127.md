# [PROG-2-1127] 新手首戰自動模擬保證勝利

## 背景
使用者裁定 2026-10-26：首戰保證勝。實測新玩家首戰自動模擬 4 場 1 勝 1 敗 2 和，開場第四幕（首勝回大廳自動展示紅顏）常不觸發。

## 規則
- 尚未首勝（session.firstBattleCleared 為 false）時，自動模擬結果固定為 player-win；首勝後照常依戰力隨機。

## 驗收
- 單元測試：未首勝時敗／和改為勝；已首勝不改。
- Web 實機：新玩家首戰按自動 → 勝利 → 回大廳自動展示紅顏。

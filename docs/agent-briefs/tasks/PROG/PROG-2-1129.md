# [PROG-2-1129] 首勝回大廳：紅顏展示關閉後才彈俘虜處置

## 問題
首戰勝利回大廳時，開場第四幕紅顏展示與俘虜處置窗同時自動開啟，俘虜窗疊在紅顏之上，紅顏被擋住。

## 修正
- 紅顏展示開著時，大廳載入不先彈俘虜窗；紅顏關閉時才檢查待處置俘虜並彈出。

## 驗收
- Web 實機：首戰勝回大廳先見紅顏，按關閉後出現呂布俘虜處置窗。

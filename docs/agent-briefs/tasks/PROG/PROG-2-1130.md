# [PROG-2-1130] 結緣配置面板下半部疊字重排

## 為什麼做
MVP 循環實機走查：結緣配置面板下半部，可否結緣、消耗、確認鈕、名士批語、結緣結果與父母兩側家族樹全疊在一起，家族樹還超出卡片下緣。

## 做法
- 卡片加高，下半部改三欄：左父系家族樹、中欄（可否結緣／消耗／確認鈕／名士批語）、右母系家族樹。
- 結緣結果通知放卡片最底一列，因子階段移到模式列右側。
- 只改 layout JSON，不動結緣規則與程式。

## 驗收
- Web 實機結緣前後截圖，文字不重疊、家族樹不出卡片。
- 單元測試、gate standard 全過。

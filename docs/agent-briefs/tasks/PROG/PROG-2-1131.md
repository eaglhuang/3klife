# [PROG-2-1131] 結緣面板：父母大頭照、名士批語小頭像

## 為什麼做
使用者要求：結緣畫面父方、母方都放大頭照；名士占卜批語旁放名士小頭像，比較有遊戲感。

## 做法
- 父／母欄左側加圓形頭像框（沿用 loadGeneralAvatar，沒頭像退剪影）。
- 名士批語拆成三列，每列左側一個名士小頭像；BondingView 多帶 sageIds。
- 不改結緣規則。

## 驗收
- Web 實機截圖：父母頭像、名士小頭像顯示，換父母時頭像跟著換。
- 單元測試、gate standard 全過。

# [PROG-2-1132] 培育畫面：用 TP 學戰法（MVP 結訓點選）＋訓練區重排

## 為什麼做
MVP 遊戲驗證規格書（doc_spec_0158）§培育模式「結訓點選：用 TP 點數購買戰法（因子折扣邏輯）」；培育系統 shard-a #7「戰法學習 P1」。實機走完 36 回合，TP 累積到 240 卻無處可花：後端 GameSession.learnTactic 已存在（綠因子半價、門檻＝成本×2、智力決定槽位），但畫面沒有入口。
同時發現訓練區 NurtureLog 整列寬，與「自動培育」「教官詳情」按鈕疊字，借將按鈕超出區塊下緣。

## 做法
- NurtureFlowController：培育中與 36 回合完成（畢業前）顯示戰法列，可左右切換戰法庫 8 招，顯示成本（含綠因子折扣）、門檻、已學槽位；「學習戰法」呼叫 deps.learnTactic。
- LobbyScene：learnTactic 接 GameSession.learnTactic，戰法名接 tactic-library。
- 版面：訓練區改左（休息／自動／補元散／戰法）中（培育紀錄）右（中止／教官／英靈／傳道／借將）三欄；畢業區按鈕右移避開戰法列。

## 驗收
- Web 實機：培育中切換戰法、TP 足夠時可學、TP 扣除；畢業前仍可學。
- 單元測試、gate standard 全過。

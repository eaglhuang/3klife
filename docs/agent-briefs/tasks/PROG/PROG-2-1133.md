# [PROG-2-1133] 戰後覺醒在結算窗揭示（鎖頭碎裂）

## 為什麼做
GameSession.recordBattle 會擲戰場覺醒並發 FactorAwakened，但畫面只寫進戰鬥紀錄，玩家在結算窗看不到。MVP 循環「戰鬥→覺醒」需要可見回饋。

## 做什麼
- 結算寫回完成後，若 settlement.awakenings 非空，在結算窗描述下方追加「🔓 鎖頭碎裂！【覺醒】{名稱}」行。
- 純函式格式化，單元測試覆蓋。

## 驗收
- 單元測試、tsc、gate standard 通過。

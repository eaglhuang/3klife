# [PROG-2-1135] 靈感戰法對應到現有戰法庫（中文名＋戰場效果）

## 為什麼做
支援卡 17 個靈感戰法（TAC_*）不在 tactic-library（僅 8 招），結業兌換後顯示 id、上戰場也找不到技能。
使用者裁定（2026-10-26）：MVP 先對應到現有 8 招，之後再逐招補獨立效果。

## 做什麼
- 新增 InspiredTacticMap：TAC_* → 中文名＋戰法庫 id。
- 戰場組槽（BattleRoster.buildTacticSlots）把 TAC_* 轉成戰法庫 id。
- 培育畫面戰法名稱查不到戰法庫時改用對照表中文名。
- 測試：支援卡資料裡每個靈感戰法都有對照，且對到存在的戰法庫 id。

## 驗收
- 單元測試、tsc、gate standard 通過；Web 實機結業兌換顯示中文名。

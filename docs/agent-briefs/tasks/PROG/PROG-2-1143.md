## 完整描述
PM 指示：底座批次先做 HALL-09。驗收句為「切換 Theme_ID 即可更換日夜光色與節慶三層，不含節慶硬寫分支」。
規格 §E-6：日夜至少兩套基礎光色；節慶分背景、裝飾、前景粒子三層；節慶插槽平時隱藏；主程式不得為節慶寫分支。

本卡交付純邏輯 `resolveHallTheme(theme, catalog)`：
- 輸入 `Lobby_Hub.Current_Theme` 與節慶層配置表 `HallThemeCatalog`，輸出 `HallThemeFrame`（日夜、色調、基礎背景、節慶是否啟用、三層圖層）。
- 節慶 ID 為 `NONE` 或不在配置表內，節慶插槽隱藏，圖層為空。
- 節慶有背景層時覆蓋基礎背景，沒有則退回基礎背景。
- 回傳的裝飾陣列為複本。

## 不在範圍
- 日夜兩套基礎光色的色值：規格只寫「至少兩套」，沒有數字。Current_Theme 目前只有單一組 Background_ID 與 Overlay_Tint，暫不新增。
- cc 畫面掛載：背景、裝飾、粒子節點與 layout 接線，待大廳畫面線處理。
- `lobby-hub.json` 與節慶配置資料：本卡不新增節慶內容。

## 暫定
- `HALL_EMPTY_THEME_CATALOG` 為空配置，所以目前任何 Festival_Theme_ID 都視為未啟用。
- 未知節慶 ID 不丟錯，直接隱藏，不沿用其他節慶的圖層。

# [PROG-2-1145] 17 個靈感戰法各自接上戰場效果

## 為什麼做
PROG-2-1135 先把 17 個靈感戰法（教官系統 §F-5／§F-6）暫對到戰法庫 8 招，造成「學到緩速卻放出戰吼」等落差。
使用者 2026-10-26 核可「依招名擬效果表」並「照表實作」。

## 做什麼
- 戰法庫新增 17 筆 `tactic-insp-*`，各自指向最貼近招名的既有戰場技能（battleSkillId），rarityAccess 留空，不進武將自動配招。
- 新增 2 個技能設定：連擊（單體兩段 0.6）、挑釁（單體暈眩 1 回合）。
- InspiredTacticMap 改指向新條目；SortieDeploy 戰法庫 → 規格 id 對照補 17 筆，TP 成本沿用數值表（趙家槍法暫定 40）。

## 效果表（數值暫定）
長槍突刺→guan-yu-slash；騎兵衝鋒→tally-charge；龍膽→tally-defense-pierce；趙家槍法→zhao-yun-pierce；單騎破陣→tally-wushuang；
連擊→insp-combo-attack（新）；疾行→wei-zhen-reset；堅盾→tally-counter-weak；緩速→mentor-slow；挑釁→insp-taunt（新）；
結義之怒→lu-bu-rampage；威震華夏→tally-wei-zhen-hua-xia；空城計→empty-fort；火攻→zhou-yu-inferno；赤壁烈焰→tally-fire-chain；
連環計→lian-huan-chain；夜襲→sima-yi-shadow。

## 驗收
- 單元測試、tsc、gate standard 通過。
- Web 實機：學到靈感戰法的武將出戰，施放結果與招名一致（例：緩速對敵移動 −1，不再是戰吼）。

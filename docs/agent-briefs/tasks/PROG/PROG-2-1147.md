# [PROG-2-1147] 宿命轉蛋改六框立繪，每位名將附登場台詞

## 為什麼做
使用者 2026-10-26：初始名將應該跟招賢館一樣列出所有可選人物立繪，每人有簡單台詞。
新手開場規格書（doc_spec_0031）§4 分鏡 6：六位初始名將的高辨識立繪，每位都要有一句台詞；§5.2 已寫好六句登場台詞，§6 有建議稱號。
現況宿命轉蛋只有六列純文字名字＋「選擇」。

## 做什麼
- 宿命轉蛋面板改用招賢館同款六框全身立繪（PortraitGallery 節點 id、PortraitFrameFit 擺位），框內名字＋稱號，框下顯示 §5.2 台詞。
- 未轉蛋時就列出六位（不可點）；轉蛋後順序打亂、可點選，點選只選中（金框），按「確認」才鎖定開局。
- 沒有立繪的武將暫用剪影頭像（甘寧、孫策、魏延、夏侯惇立繪由 UI-2-0115 補上後自動顯示）。

## 驗收
- 單元測試、tsc、gate standard 通過。
- Web 實機截圖：未轉蛋六框、轉蛋後選中金框、確認後進教學。

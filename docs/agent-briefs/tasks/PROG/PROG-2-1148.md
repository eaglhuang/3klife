# [PROG-2-1148] 主大廳改城池主視覺：君主頂列、都市卡、功能分類收納

## 為什麼做
使用者 2026-10-26：主 UI 不要把按鈕通通列出來，要有功能性的收納，並且要有目前勢力君主的頭像與資源、所在都市、人口與都市陣營概念。
使用者 2026-10-27 選定版型「城池主視覺」。
大廳系統規格（doc_spec_0002）E-1：頂部狀態列常駐顯示玩家資源、官職、時段。

## 做什麼
- 新增 lobby-city-hub 畫面：
  - 頂列：勢力主將頭像、勢力名、官職，以及金、紅玉、糧、兵四項資源。
  - 都市卡：城名、州、人口、民心、守軍、陣營，以及天下勢力的邦交摘要。
  - 底部五類收納列：出征、武將、內政、培育、商城。點類別才展開子功能，再點一次收起。
- 季度卡只留季節資訊與「推進一季」，其他七個入口改收進分類列。
- 舊的底部導覽列、假頂列（劉玄德／寫死資源）與舊 dock 在執行期隱藏。
- 人口、民心目前沒有存檔狀態，先用暫定推算：
  - 人口：主城基數＋每季成長。
  - 民心：基礎值＋名聲加成。
  - 治理系統接上後再換成真值。

## 驗收
- 單元測試（分類切換、檢視文字）、tsc、gate standard 通過。
- 實機截圖：頂列、都市卡、分類展開與子功能可進入。

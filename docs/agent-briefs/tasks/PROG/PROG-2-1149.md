# [PROG-2-1149] 選主將標題：主將不在目前頁時誤顯示「不可出戰」

## 為什麼做
PROG-2-1148 實機驗收時發現：大廳選主將清單換頁後，若主將在別頁，標題顯示「出戰主將：（不可出戰）」。
原因是標題只在目前頁的列裡找主將名。MVP 遊戲驗證規格書（doc_spec_0045）§E 出戰前選主將。

## 做什麼
- `buildLeadSelectView` 多回傳 `leadLabel`：在全部可出戰武將中查主將顯示名；未指定為 null，已指定但不可出戰為 undefined。
- 大廳標題改用 `leadLabel`。

## 驗收
- 單元測試涵蓋跨頁主將名、未指定、不可出戰三種情況。
- compute-gate standard 全過。

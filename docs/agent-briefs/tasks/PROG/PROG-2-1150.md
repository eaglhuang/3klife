# [PROG-2-1150] 城池主選單「出征」分類直達外交・征伐

## 為什麼做
MVP 目標要求玩家能與 AI 對手互動（外交或戰鬥，戰鬥自動模擬直接結算）。
外交・出征畫面（PROG-2-1088）已存在，但 PROG-2-1148 新主選單後只能從內政面板深處進入。

## 做什麼
- 出征分類子功能改為：戰場、外交・征伐、洪戰。
- 外交・征伐開啟既有 rival-diplomacy 畫面。

## 驗收
- 單元測試：出征第 2 格為 rival，動作總數 14 且不重複。
- 實機：出征 → 外交・征伐 開出外交畫面。
- compute-gate standard 全過。

# [PROG-2-1153] 傭兵面板稀有度寫死 R：結義按鈕點數與實際扣點不一致

## 為什麼做
傭兵系統（試用）規格書 §F：結義點數 R100／SR300／SSR600／UR1200。
實際結義（bondMercenaryToRoster）依模板 rarityOfTemplate 扣點，但大廳傳給傭兵面板的稀有度寫死 'R'，面板顯示「結義（100 點）」並以 100 判斷點數是否足夠；名將池 20 位皆為 epic／legendary（SSR／UR），玩家 100 點時按鈕可按但結義失敗。

## 做什麼
- 面板稀有度改用 rarityOfTemplate(模板)，與實際扣點同源；查不到時維持 R。

## 驗收
- 單元測試：SSR 顯示 600 點、UR 顯示 1200 點。
- compute-gate standard 全過。

# [PROG-2-1154] 傭兵 6 日倒數接上時間軸（MVP 定案一季＝一日）

## 為什麼做
MVP 遊戲驗證規格書（doc_spec_0045）§E #11 傭兵 6 日結義；傭兵系統（試用）規格書 §E #2「6 日結義倒數」、#5「6 日到期未結義→離隊+告別」。
advanceMercenaryDay 已實作但無呼叫端，倒數永遠不動，傭兵無法期滿結義也不會離隊。

## 做什麼
- MVP 定案（2026-10-27 使用者裁定）：每推進一季，傭兵過一日（規格原為真實每日登入；日後改版只需換觸發點）。
- 季度結果 SeasonAdvancedPayload 多帶 mercenaryDepartures（離隊 uid）；大廳顯示「{Name} 已離隊。六日情緣，且作追憶。」（UI_MERC_FAREWELL）並刷新傭兵面板。
- advanceMercenaryDay 拆出不存檔的 _tickMercenaryDay，季度推進共用，避免重複存檔。

## 驗收
- 單元測試：推進一季傭兵日 +1；期滿未結義者出現在 mercenaryDepartures。
- 實機：試用招募後推進季度，倒數遞減。
- compute-gate standard 全過。

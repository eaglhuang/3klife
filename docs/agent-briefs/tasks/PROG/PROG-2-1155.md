# [PROG-2-1155] 修 LobbyScene 傭兵稀有度型別錯誤

## 為什麼做
PROG-2-1153 的 `(general && rarityOfTemplate(general)) ?? 'R'` 讓 general 的假值型別滲入，tsc 報 TS2322（MercenaryDisplayInfo.rarity 不接受 ""）。
平時 tsconfig 的 ignoreDeprecations "6.0" 讓本機 tsc 5.9.3 在設定階段就停（TS5103），所以沒被發現；加 `--ignoreDeprecations 5.0` 才看得到。

## 做什麼
- 改為 `(general ? rarityOfTemplate(general) : undefined) ?? 'R'`，行為不變。

## 驗收
- `npx tsc --noEmit -p tsconfig.json --ignoreDeprecations 5.0` 在 assets/ 與 tests/ 無錯誤（排除 TS1323）。
- 單元測試全過；compute-gate standard 9/9。

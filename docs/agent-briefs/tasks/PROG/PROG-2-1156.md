# [PROG-2-1156] 教官爆發補靈感率加成，支援卡帶入擅長格與爆發率

## 為什麼做
逐條比對教官系統（支援卡）規格書（doc_spec_0027）§E #12 與 §F-8 時發現兩個缺口：
1. 爆發（教官站在擅長格）時，靈感觸發率應「基礎 +5%」，程式沒有套用。
2. 支援卡教官進培育時，忽略卡上的 Slot_Burst_Rate 與 Training_Slot_Affinity，一律用推算擅長科目與預設 0.5 爆發率，§F-8 各稀有度的爆發率區間形同無效。

## 做什麼
- MentorInspiration：InspireContext 加 burstRateBonus；P(靈感) = Base_Rate × (1 + 爆發加成) × (1 + 友情) × (1 + LUK/200)。
  暫定：「基礎 +5%」解讀為相對 +5%（×1.05），與友情加成同為乘算，基礎率 0 的事件仍不觸發。
- NurtureService：以剛訓練那一回合的站格判定爆發（executeRound 已替下一回合重骰，不能用新站格）。
- mentorFromCard：有支援卡時擅長科目取 Training_Slot_Affinity 第一格、爆發率取 Slot_Burst_Rate；呼叫端覆寫仍優先。

## 不在本卡
- §F-8「友情訓練觸發率 +10%」：目前沒有友情訓練觸發機制，需另案。
- 爆發率隨星等成長（SSR ★0 40–65% → ★5 55–80%）：Schema 只有單一 Slot_Burst_Rate，需另案。

## 驗收
- 單元測試：爆發機率公式、基礎率 0 不變、接線測試同一擲骰值只有爆發時觸發、支援卡帶入擅長格與爆發率。
- 全部測試通過、tsc 乾淨、compute-gate standard 9/9。

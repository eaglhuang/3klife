# [PROG-2-1157] 天命商店：大保底 200 抽兌換 SSR（邏輯與服務層）

## 為什麼做
逐條比對轉蛋系統規格書（doc_spec_0042）§E 時，#7「天命商店：200 抽保底兌換介面」未實作。
PROG-2-0335 只記累計抽數，註明「大保底只記計數，不發天命商店」。

## 做什麼
- DestinyShop.ts（純邏輯）：每池每滿 200 抽 1 次資格＝floor(累計 / 200) − 已兌換次數；兌換只能選本池 SSR，成功後已兌換 +1，累計抽數不變（小保底週期不受影響）。
- GachaPityState 加 destinyExchanges（0 時不寫出，舊存檔相容）；抽卡時保留此欄位。
- LocalGachaService：getDestinyShopCredits／getPullsToNextDestinyCredit／exchangeDestinyShop；兌換結果入冊與保底寫回同一批存檔，並寫入抽卡紀錄（LOCAL_DESTINY_SHOP_EXCHANGE）。

## 暫定
- 兌換不計入抽數；資格可累積、不過期。

## 不在本卡
- 天命商店畫面與轉蛋頁入口（下一張卡接 UI）。

## 驗收
- tests/DestinyShop.test.ts：資格計算、兌換閘門、保底欄位相容、服務層兌換入冊與寫回。
- 全部測試通過、tsc 乾淨、compute-gate standard 9/9。

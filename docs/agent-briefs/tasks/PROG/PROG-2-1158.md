# [PROG-2-1158] 天命商店：兌換畫面與轉蛋頁入口

## 為什麼做
PROG-2-1157 已完成天命商店的資格計算與兌換（服務層），但玩家沒有入口可用。
轉蛋系統規格書（doc_spec_0042）§E #7「200 抽保底兌換介面」、UI_PITY_BIG「天命值：{N}/200」。

## 做什麼
- 轉蛋頁（gacha-ds3）左上角原「名將池說明」框（GachaDs3_div_35，內容是佔位字 Bloodline_Seed）改當入口：顯示目前輪播池的天命值與可兌換次數，點擊開天命商店。
  - 該框被宿主後加的「‹ 返回大廳」鈕蓋住，執行期往下移一列並放大字（原稿字高 12px 看不清）；不改 gacha-ds3 版面與 bake 檔。
- 新增 destiny-shop-screen（layout／skin／screen）＋ DestinyShopController（純邏輯 Presenter）：本池 SSR 上一位／下一位、兌換按兩次才生效（第一次顯示「命運之輪已轉至盡頭」確認）、沒資格時兌換鈕不能按。
- 名將池（GENERAL_STANDARD_01）兌換武將；教官池（mentor-pool）兌換教官卡（走既有入冊回呼）；紅顏池不累計天命值，點入口跳提示。
- LocalGachaService.getDestinyShopCandidates：畫面列表與兌換用同一條 SSR 篩選規則。

## 驗收
- tests/DestinyShopController.test.ts：view key 對得到 layout 節點 id、兩段確認、換人取消待確認、空狀態、入口文字、接線。
- 全部測試通過、tsc 乾淨、compute-gate standard 9/9。
- 網頁版實機：入口顯示「天命值：10/200 · 可換 1 次」，開店、兌換兩次後資格歸 0、兌換鈕反灰、入口同步更新。

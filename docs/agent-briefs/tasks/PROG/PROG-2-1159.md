# [PROG-2-1159] 內政任務格指派武將，產出依武將屬性計算

## 為什麼做
領地治理系統（doc_spec 領地治理系統.md）§F：五大內政任務產出依指派武將屬性計算（農耕 100+POL×2、商業 50+CHR×3、外交 20+(INT+CHR)、軍備 80+STR×2、偵查 30+INT×2）。
目前 GameSession 已有 assignGovernor／unassignGovernor 與存檔欄位，但大廳內政畫面沒有指派入口，產出也是固定值。

## 做什麼
- DomesticTasks：新增 §F 屬性公式；有指派武將時用公式，未指派沿用原固定值（暫定）。偵查暫產黃金（尚無「情報」資源，暫定）。
- GameSession.chooseDomesticTask 帶入該任務格指派武將的屬性。
- 內政畫面每格加「換將」鈕與目前武將名稱；輪流切換可用武將（已在他格的跳過）與「未指派」。
- 修正 GameSession 註解：治理指派已隨 lifespanSaveFields 寫入存檔。

## 驗收
- 單元測試：公式、指派後產出、換將輪替、版面節點 id 對得上。
- 網頁版實機：指派武將後產出數字變動，選任務入帳正確。

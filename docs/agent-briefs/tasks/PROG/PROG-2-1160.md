# [PROG-2-1160] 內政一鍵自動指派（自動治理）

## 為什麼做
領地治理系統 §E #4 自動治理（P1）、§F 自動治理分配：閒置武將依 Task_Affinity = 主屬性 × 權重，分配到最優的空內政格。
PROG-2-1159 已有手動換將，但沒有自動分配。

## 做什麼
- 新增 DomesticAutoGovernance：只補空的任務格、只用未指派的武將；每次取全體（武將, 任務）中親和度最高的一組，直到格子或武將用完。親和度沿用 §F 公式的屬性部分（暫定：規格逐將 argmax 未定順序，改全域貪婪避免先後順序影響結果）。
- 內政畫面加「自動指派」鈕，完成後顯示「太守府已自動安排武將執行內政。」。

## 驗收
- 單元測試：只補空格、不動手動指派、親和度最高者優先、武將不足時部分補滿。
- 網頁版實機：按自動指派後五格都有主事且產出依屬性變動。

# [PROG-2-1161] 內政手動／自動治理切換

## 為什麼做
領地治理系統 §E #7 手動/自動切換（P1）、資料欄位 Auto_Mode、UI_GOV_AUTO「自動治理已啟用」。
PROG-2-1160 已有一鍵自動指派，但沒有持續的自動模式。

## 做什麼
- GameSession 新增自動治理開關（寫入存檔，舊檔讀回關閉；開新局重置為關閉）。
- 開啟時立即補空格；之後每季結算（武將陣亡騰出格子後）自動再補。已有主事的格子不動，玩家仍可手動換將。
- 內政畫面加「自動治理：開／關」切換鈕，開啟時提示「自動治理已啟用」。

## 驗收
- 單元測試：開啟即補格、季結算後補上陣亡空出的格子、關閉時不補、存讀檔保留開關。
- 網頁版實機：切換鈕文字與提示正確，開啟後五格補滿。

# [PROG-2-1162] 子嗣擔任郡城縣令：內政黃金產出加成

## 為什麼做
領地治理系統 §E #9 非培育子嗣內政（P1）、§F 非培育子嗣內政職位：郡城縣令「黃金產出 +20%」，Official_Output = Base_Output × (1 + Child_RelevantStat / 100)。
四個職位中只有縣令能直接作用在現有系統（內政黃金）；屯田官（培育糧草消耗）、工匠（建築時間）、說客（傭兵結義成功率）目前沒有對應數值可接，另卡處理。

## 做什麼
- ChildMagistrate：子嗣判定（有父或母，與 LegacyService 相同）、縣令加成 = 20% × (1 + POL / 100)（暫定：縣令規格寫「任何子嗣」未指定屬性，暫用政治）。
- GameSession：縣令指派（存檔 magistrateUid，舊檔讀回空；開新局清空；陣亡時卸任）；內政黃金產出（商業、偵查）套用加成。
- 內政畫面空白格加「郡城縣令」欄與「換人」鈕，依加成由高到低輪替子嗣，已任內政主事者跳過。

## 驗收
- 單元測試：加成公式、只有子嗣可任、黃金任務套用加成、非黃金任務不受影響、存讀檔保留、陣亡卸任。
- 網頁版實機：指派縣令後商業產出顯示提高。

# [PROG-2-1163] 教官爆發率隨突破星等成長

## 為什麼做
教官系統（支援卡）§F 爆發機率範圍：SSR ★0 為 40%~65%、滿突破 ★5 為 55%~80%（「滿突破核心回報之一」）。
目前 mentorFromCard 直接用支援卡的 Slot_Burst_Rate，星等不影響站擅長格的機率。

## 做什麼
- MentorBreakthrough：每升 1 星爆發率 +3 個百分點（★0→★5 共 +15，對齊 SSR 兩端範圍差；暫定 R／SR 同樣套用），上限 80%（規格最高值）。
- mentorFromCard：支援卡或預設爆發率依卡片星等加成；呼叫端明確覆寫 burstRate 時不加成。

## 驗收
- 單元測試：★0 不變、★5 +15%、上限 80%、覆寫值不加成、預設 0.5 也隨星等成長。

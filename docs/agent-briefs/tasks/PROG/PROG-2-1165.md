# [PROG-2-1165] 進度矩陣補登已實作系統（依 @spec-source 重算「尚無實作」列）

## 為什麼做
cross-ref-進度.md D-1 表有 20 多列寫「尚無實作」，但程式檔頭的 `@spec-source` 早已指向這些規格（例如同名武將、轉蛋、傭兵、留存）。
build-progress-matrix.js 只吃舊四欄表，遇到五欄表直接結束，所以表格一直沒有重算，Agent 依索引找下一項時會被誤導。

## 做什麼
- build-progress-matrix.js 支援五欄表：只重算「對應代碼檔」為「尚無實作」的列，代碼檔從 `@spec-source` 標註掃出；其他列原樣保留。
- 有找到代碼檔的列：邏輯標 🟡（只證明有程式，不代表規格全數落地），接線與測試照既有規則自動判定，runtime 驗收維持 ⬜。
- 名詞定義文件（doc_spec_0008）是名詞表不是系統，不補登。
- `--check` 在五欄模式下有待更新的列時回傳 1。

## 驗收
- `node tools_node/build-progress-matrix.js --check` 先回報落差，寫檔後再跑回傳 0。
- 只有原本「尚無實作」的列被改動（git diff 確認）。

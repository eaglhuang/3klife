# [PROG-2-1166] LUK 上限依紫因子計算（LUK-03）

## 為什麼做
運氣系統 §F「紫色因子對 LUK」：LUK_Max = 50 + Purple_Gene_Level × 10（★5 紫因子 → 上限 100）。
目前上限固定 100（LuckThresholds.LUK_MAX，註明待 LUK-03）。使用者 2026-10-27 裁定：照規格公式做。

## 做什麼
- LuckThresholds：新增 lukMaxForGenes(genes)，紫因子等級取持有紫色基因的最高等級，結果不超過 100。
- BreedingSystem.createChild：子嗣 LUK 依自身基因算出的上限封頂。
- 門檻效果（≥80／≥95／=100）不變，仍以絕對值 100 判定天命傳承。

## 驗收
- 單元測試：無紫因子上限 50、★3 → 80、★5 → 100、超過 ★5 仍 100、子嗣 LUK 被封頂。

# [PROG-2-1168] 轉蛋戰法隨機化（第 2、第 3 戰法隨機，重複轉戰法經驗值）

## 為什麼做
轉蛋系統 §E #6（P1）「同名武將第 2、第 3 戰法隨機，重複轉經驗值」；討論來源「轉蛋與戰場武將處置系統」§2.1：每次抽到同名武將，第二、第三戰法隨機生成，重複戰法自動轉為「戰法經驗值」提升等級。
使用者 2026-10-27 裁定：先用暫定數值做。

## 做什麼（數值皆暫定）
- 新增 core/systems/TacticRandomization.ts（純邏輯）：
  - 候選池：戰場戰法庫 8 招基本戰法（不含靈感戰法），排除第 1 戰法，每次抽 2 招不重複。
  - 已持有的戰法：+100 戰法經驗；每 100 經驗 1 級，最高 5 級。
  - 未持有：補到空的 slot-2／slot-3；兩格都滿則捨棄。
- GeneralUnit：戰法槽來源新增 'gacha'；GeneralConfig 新增 tacticExp（戰法 id → 經驗）。
- GameSession.enrollGenerals：轉蛋入冊（rebirthOnDuplicate）時，新抽到與重複抽到都擲一次。

## 不做
- 戰法等級對戰場效果的加成（規格未定義）。
- UI 顯示戰法等級。

## 驗收
- 單元測試：抽 2 招不重複且不含第 1 戰法、空槽補位、重複轉經驗、經驗封頂、入冊接線。

# [PROG-2-1169] 三國日報事件引擎（插槽式敘事，純邏輯）

## 為什麼做
留存系統.md (doc_spec_0025) §E #8「三國日報（動態敘事）」與 #9「插槽式敘事引擎」皆 P1、尚無實作。

## 做什麼
- 新增 core/systems/DailyNewsEngine.ts（純邏輯，不依賴 cc）：
  - 規格 §F 的 PlayerLogType、DailyNewsType、NarrativeSlot、NEWS_TRIGGER_TABLE、DAILY_NEWS_COUNT（1~3）。
  - generateDailyNews(logs, generals, now, random)：取前 24h Log，依觸發表選事件類型，套 [角色]+[情緒]+[行為]+[結果] 模板。
  - 復仇取回 5%~20%、代勞情緒「得意」、復仇情緒「憤怒」照規格；24h 內沒有 Log 視為 IDLE_LONG。
  - dailyNewsTitle(date)：「三國日報 —— {Date}」。

## 暫定
- 其他情緒對應、代勞任務名、團購物品、特訓屬性與數值（+1~3）、離線社交的「其他主公」都先用暫定字串。
- 同一次登入不重複出同類事件。

## 不做
- 不發獎勵（只產生文字）；不接 UI、存檔 Daily_News、Log 採集點。

## 驗收
- 單元測試覆蓋觸發表、數量上下限、24h 篩選、復仇比例範圍、空名冊。
- compute-gate standard 9/9。

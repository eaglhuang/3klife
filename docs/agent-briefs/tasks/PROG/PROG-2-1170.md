# [PROG-2-1170] 三國日報接線：行為紀錄採集、登入生成、存檔

## 為什麼做
PROG-2-1169 只做了日報生成引擎，遊戲裡沒有行為紀錄可讀，日報不會出現。留存系統.md (doc_spec_0025) §I 本機存檔有 Daily_News。

## 做什麼
- DailyNewsEngine：appendPlayerLog（只留 24h 內、最多 50 筆）、DailyNewsState、refreshDailyNews（UTC+8 每日第一次登入才生成）、markDailyNewsRead、存檔正規化。
- GameSession：
  - recordPlayerLog(type, resource?, atMs?) 公開給其他系統用。
  - recordBattle：勝 → BATTLE_WIN、敗 → BATTLE_LOSE。
  - recordBreedingBirth → GENERAL_BORN。
  - enrollGenerals（轉蛋入冊）：有新武將 → GACHA_SUCCESS，全是重複 → GACHA_FAIL（暫定判定）。
  - recordLoginAt：登入後生成當日日報；dailyNews getter、markDailyNewsRead。
  - 存讀檔保存 playerLogs 與 dailyNews；新局清空。
- PlayerSaveService：新增選填欄位 playerLogs、dailyNews，版號不升。

## 不做
- UI；獎勵入帳；其餘 Log 類型（RESOURCE_LOW、退役、虎符升級、單挑、忠誠下降）的採集點留給 recordPlayerLog 呼叫。

## 驗收
- 單元測試：戰鬥／轉蛋／出生寫入紀錄、每日只生成一次、跨存讀檔保留、新局清空。
- compute-gate standard 9/9。

# [PROG-2-1172] 三國日報採集點：單挑勝負

## 為什麼做
留存系統.md (doc_spec_0025) §F PlayerLogType 的 DUEL_WIN／DUEL_LOSE 是最後兩種沒有採集點的紀錄；單挑在戰場 TurnFlowManager 結算，GameSession 不經手（PROG-2-1171 未做）。

## 做什麼
- DailyNewsEngine：duelLogType(result, accepted)：單挑成立且我方勝 → DUEL_WIN、敵方勝 → DUEL_LOSE；拒絕或平手 → null。
- TurnFlowManager：兩處單挑結算後呼叫 services().session.recordPlayerLog。

## 不做
- 拒絕單挑的懲罰不算單挑勝負，不記。UI。

## 驗收
- 單元測試覆蓋 duelLogType。
- compute-gate standard 9/9。

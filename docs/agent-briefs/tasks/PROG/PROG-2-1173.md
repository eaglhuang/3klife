# [PROG-2-1173] 大廳登入接線：記錄登入並以 toast 顯示三國日報

## 為什麼做
GameSession.recordLoginAt 在遊戲中沒有任何呼叫點：連續登入（PROG-2-0987）與三國日報（PROG-2-1170）實際上都不會觸發。留存系統.md (doc_spec_0025) §G／§H 有日報頭條字串。

## 做什麼
- DailyNewsEngine：dailyNewsToastLines(state, date)：有未讀日報時回傳 [頭條, 每條「{角色}（{情緒}）：{行為}，{結果}」]，否則空陣列。
- LobbyScene._loadPlayerSave：讀檔後呼叫 recordLoginAt(Date.now())；有未讀日報就以 SHOW_TOAST 每隔數秒依序顯示，標記已讀並存檔。

## 不做
- 報紙式日報面板（需走 UCUF 畫面流程），先用 toast。

## 驗收
- 單元測試覆蓋 dailyNewsToastLines。
- compute-gate standard 9/9；實機待驗收。

# [PROG-2-1175] 武將日誌寫入點：戰鬥、派遣、出生、退役

## 為什麼做
武將日誌與離線互動系統.md (doc_spec_0015) §E-1 要求把重大戰果、派遣、互動與成長事件寫入日誌時間軸。目前唯一寫入點是季度結算，晨報（PROG-2-1174）內容因此只有「某季結算」。

## 做什麼
- 新增 JournalEvents.ts：JOURNAL_EVENT_RULES 表（事件 → 類別、重要度、摘要模板，皆暫定）與 buildJournalEvent。
- GameSession 寫入點：
  - recordBattle 勝／敗 → BATTLE，相關武將為出戰武將。
  - dispatchHallTask 結算 → DISPATCH，相關武將為派遣武將。
  - recordBreedingBirth → GROWTH，相關武將為父母。
  - retireGeneral → GROWTH，相關武將為退役武將。
- 時間戳沿用季度日誌的遊戲時間格式；條目 ID 用目前條目數 +1。

## 不做
- 互動（INTERACTION）事件：離線互動事件尚未產生資料。
- 正式文案與重要度：待企劃定稿。

## 驗收
- 單元測試覆蓋模板、空名、四個寫入點。
- compute-gate standard 9/9。

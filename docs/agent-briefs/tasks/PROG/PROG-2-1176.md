# [PROG-2-1176] 季結自動結算的大廳委任寫入派遣日誌

## 為什麼做
PROG-2-1175 只在「派遣即結算」寫派遣日誌；AI 委任在季結時由 settleOpenAssignsForSeason 自動結清，這條路徑沒有寫日誌，且結算結果沒帶武將 ID。武將日誌與離線互動系統.md (doc_spec_0015) §E-1 要求派遣事件寫入時間軸。

## 做什麼
- HallAutoAssign.settleOpenAssignsForSeason 的 settled 每筆加 generalId。
- GameSession._settleOpenHallAssigns 每筆結算寫 DISPATCH_SUCCESS／DISPATCH_FAIL 日誌（沿用 JournalEvents 規則）；武將已不在名冊時略過。

## 驗收
- 單元測試：委任後跨季，派遣日誌出現該武將。
- compute-gate standard 9/9。

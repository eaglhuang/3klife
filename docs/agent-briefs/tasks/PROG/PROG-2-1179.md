# [PROG-2-1179] 暫定派遣任務清單與派遣板列（JRN-03 第三段）

## 為什麼做
PROG-2-1178 有了派遣狀態與登入結算，但規格（武將日誌與離線互動系統.md (doc_spec_0015) §E-3）沒給任務清單，沒有任務可派；大廳派遣板（JournalHubController.dispatchRows）也沒有資料來源。

## 做什麼
- DispatchCatalog.ts：
  - DISPATCH_JOB_CATALOG：5 個暫定任務（名稱、時長、需求標籤、需求能力、故事標籤、顯示用回報），其中 1 個高風險。標籤對齊現有 careerClass／role 值，故事標籤用日誌類別。
  - findDispatchJob：依 id 取任務。
  - dispatchBoardRows：派遣板列；進行中的排前面顯示「武將・剩 N 時」，高風險顯示「需親自決策」，其餘「可派遣」。
- GameSession：dispatchBoardRows(nowMs) 供大廳派遣板使用。

## 不做
- 大廳派遣板的 UCUF 掛載與點擊派遣流程。
- 獎勵發放。

## 驗收
- 單元測試覆蓋清單合法性、板列狀態與排序、GameSession 板列。
- compute-gate standard 9/9。

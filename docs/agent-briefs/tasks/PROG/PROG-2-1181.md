# [PROG-2-1181] 派遣板點列派遣（JRN-03 第四段）

## 為什麼做
PROG-2-1180 把派遣板接進大廳，但只能看不能派；玩家無法實際派出武將，派遣循環沒有入口。

## 做什麼
- GameSession.dispatchJobById(jobId, nowMs)：從暫定清單找任務，自動挑名冊中最適合（§F-2 分數最高）且不忙碌、不在冷卻的武將派出；玩家親自點選視同親自決策，高風險任務可派。回傳結果與武將名，並存檔。
- 派遣板 4 列改為按鈕；LobbyScene 點列即派遣，以提示訊息回報結果並刷新面板。

## 暫定
- 不開選將清單，直接挑分數最高者（同分取名冊順序）；選將介面待企劃定版。

## 不做
- 獎勵實際發放（回報仍為顯示文字，結構化獎勵待企劃定義）。
- 人物頁日誌回看。

## 驗收
- 單元測試：挑最高分、略過忙碌與冷卻、無人可派、未知任務、進行中任務回報。
- compute-gate standard 9/9；實機待 Codex 驗收。

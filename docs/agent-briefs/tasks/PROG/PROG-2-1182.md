# [PROG-2-1182] 派遣完成發放獎勵（JRN-03 第五段）

## 為什麼做
派遣已可點列派出（PROG-2-1181），但完成時只寫日誌，回報「糧草 50」等只是顯示文字，玩家拿不到任何東西；派遣循環沒有收益。

## 做什麼
- DispatchJobDef 加選填結構化獎勵（資源：糧草／金幣／名聲，數量）；暫定清單填入。
- 品質倍率（暫定）：差 0.5、普通 1、良 1.2、優 1.5，向下取整。
- GameSession.settleDispatchJobs：依完成品質發獎；糧草與名聲直接入帳（有上限），金幣交呼叫端錢包（沿用內政任務 grantGold 作法）。recordLoginAt 一併傳入。
- LobbyScene：登入結算與打開晨報派遣板時都結算，金幣交 LocalGachaService；開板時提示本次完成的任務。

## 暫定
- 獎勵數值與品質倍率皆暫定，規格（doc_spec_0015 §E-3）未定義。

## 不做
- 選將清單、人物頁日誌回看。

## 驗收
- 單元測試：各資源入帳、品質倍率、上限、未定義獎勵不發、金幣交呼叫端。
- compute-gate standard 9/9；實機待 Codex 驗收。

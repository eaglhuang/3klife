# [PROG-2-1183] 武將日誌回看抽屜（JRN 人物頁故事回看掛點）

## 為什麼做
武將日誌與離線互動系統.md (doc_spec_0015) 範圍第 6 項「人物頁故事回看掛點」：讓人物頁或抽屜可讀取武將日誌摘要。日誌已在寫（戰鬥、派遣、子嗣、退役），玩家卻看不到任何一位武將的日誌。

## 做什麼
- GeneralJournalController（ui/core，純邏輯）：依名冊切換武將（上一位／下一位、指定武將），列出該武將日誌最新 6 則（隱藏條目不列），時間顯示為「N年春」，空狀態、頁碼。
- 新畫面 general-journal-screen（抽屜式彈窗）。
- 晨報派遣板加「武將日誌」入口；LobbyScene 掛載並提供 openGeneralJournal(generalId) 給日後人物頁接入。

## 暫定
- 入口先放在晨報派遣板：人物頁（character-ds3）版面屬 UI 美術權威流程，入口鈕待 UI 管線加入後呼叫 openGeneralJournal。
- 每頁 6 則、空狀態字串暫定。

## 不做
- 修改 character-ds3 人物頁版面、日誌分頁捲動、依類別篩選。

## 驗收
- 單元測試：最新在前、隱藏不列、上限 6、切換武將循環、空名冊、時間格式。
- 版面與皮膚驗證無 error；compute-gate standard 9/9；實機待 Codex 驗收。

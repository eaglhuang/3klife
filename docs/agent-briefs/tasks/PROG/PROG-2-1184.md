# [PROG-2-1184] 離線戰鬥快照（JRN-05）

## 為什麼做
武將日誌與離線互動系統.md (doc_spec_0015) §E-5、§F-4：自動解決／代勞的戰果要保留可驗證的摘要快照，不能只回傳裸數字。目前敵國來犯時的季度自動迎戰（GameSession._tickRivals）只回傳兵力數字，沒有快照、也沒寫日誌。

## 做什麼
- OfflineBattleSnapshot.ts：§F-4 介面；lineup／tileState／tactic／result 摘要以確定性雜湊產生；resultDigest 為 WIN/LOSE × MAJOR/MINOR；syncHashLink 串前一筆快照的 link（首筆接 EMPTY_SYNC_HASH），形成可回扣的鏈；鏈驗證函式；只留最近 20 筆；存檔正規化。
- GameSession：季度敵國自動迎戰每場產生 AUTO_RESOLVE 快照，寫一筆 BATTLE 日誌（snapshotRef 指向快照）；存檔欄位 offlineBattleSnapshots。

## 暫定
- 雜湊用 FNV-1a 32 位元（伺服端可換 sha256）；MAJOR／MINOR 門檻兵力比 1.5；保留筆數 20；seed 以「年-季-序」字串表示（亂數器目前無字串種子）。
- 目前 session 尚無 Action_Records 鏈，syncHashLink 先串快照自身鏈，起點與存檔 Last_Sync_Hash 空值一致。

## 不做
- 戰場內「自動」鈕的快照（戰場流程在 battle 層，另卡）、快照回看 UI、伺服端驗證。

## 驗收
- 單元測試：確定性、摘要分級、鏈接續與竄改偵測、上限、正規化、GameSession 季度敵襲寫快照與日誌、存讀檔。
- compute-gate standard 9/9。

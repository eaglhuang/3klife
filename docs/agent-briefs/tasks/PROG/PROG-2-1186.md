# [PROG-2-1186] 派遣板選將

## 為什麼做
PROG-2-1181 點派遣列一律自動挑分數最高的武將，玩家無法指定人選（卡上「未做：選將清單」）。武將日誌與離線互動系統.md (doc_spec_0015) §G 派遣由玩家決策，需要能指定武將。

## 做什麼
- 派遣板標題下加一列選將：◀ 派遣武將：自動挑選／某武將 ▶，在「自動挑選」與目前可派（不忙碌、不在冷卻）的武將間循環。
- GameSession.dispatchJobById 可帶指定武將 id；指定武將忙碌或冷卻時回報原因與姓名。新增 dispatchIdleGenerals(nowMs)。
- 提示字串：指定武將忙碌／休整中時點名說明。

## 暫定
- 選將列預設「自動挑選」，沿用 1181 的最高分規則；清單順序沿用名冊順序。
- 選將列只用文字循環切換，不做頭像清單（待美術定版）。

## 不做
- 顯示每位武將對各任務的分數預覽、頭像清單。

## 驗收
- 單元測試：指定武將派出、指定武將忙碌／冷卻的回報、控制器循環與失效人選回到自動、畫面規格含新節點。
- compute-gate standard 9/9。

# [PROG-2-1188] 派遣板分數預覽

## 為什麼做
PROG-2-1186 加了選將列，但玩家看不到人選對各任務的適性，選將只能盲猜。武將日誌與離線互動系統.md (doc_spec_0015) §F-2 的派遣評分與品質分級已實作，可直接預覽。

## 做什麼
- 派遣板未進行的任務列顯示預覽：「武將名 分數 分・品質」；選將列為自動挑選時預覽最高分的可派武將，指定武將時預覽該武將；高風險任務尾綴「・需親自決策」。
- 沒有可派武將時維持原字串（可派遣／需親自決策）。
- GameSession.dispatchBoardRows 加預覽選項（預設不預覽，既有呼叫不變）；自動挑將抽成共用函式，與點列派遣同一規則。

## 暫定
- 品質中文名：欠佳／普通／良好／極佳。

## 不做
- 預覽獎勵加乘後數量、頭像清單。

## 驗收
- 單元測試：自動預覽最高分武將、指定武將預覽、高風險尾綴、無可派武將維持原字串、預設不預覽。
- compute-gate standard 9/9。

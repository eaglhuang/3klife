# [PROG-2-1189] 外交「出征」留離線戰鬥快照

## 為什麼做
武將日誌與離線互動系統.md (doc_spec_0015) §F-4：自動解決的戰果要留可驗證快照。季度敵襲（PROG-2-1184）與戰場自動鈕（PROG-2-1185）已接；外交面板的「出征」（治理模式他國AI系統 doc_spec_0020 E-12，PROG-2-1088）也是數值自動結算，仍只顯示結算文字。

## 做什麼
- GameSession 加公開 recordRivalCampaign(squad, nationId, battle)：留 AUTO_RESOLVE 快照，寫 BATTLE 日誌「我軍出征某勢力告捷／失利」。
- RivalDiplomacyController 加選用依賴 recordBattle，出征結算時在 setWorld（會存檔）前呼叫；LobbyScene 接到 GameSession。

## 暫定
- 日誌重要度沿用敵襲（勝 70／敗 65）；seed 為「年-季-C勢力 id」。

## 不做
- 出征陣容選擇、伺服端驗證。

## 驗收
- 單元測試：出征後快照與日誌（含勢力名）、與既有快照同鏈；未提供 recordBattle 時照舊。
- compute-gate standard 9/9。

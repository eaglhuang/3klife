# [PROG-2-1191] 名將挑戰賽彈窗（賽季卡、報名、參戰）

## 為什麼做
PROG-2-1190 已把挑戰賽本機賽季接進 GameSession，但玩家沒有入口。

## 做什麼
- TournamentPanelController（純邏輯）：賽季／相位／剩餘日、積分與段位、今日剩餘次數（免費／付費）、出戰陣容、上一場結果或拒絕原因；報名與參戰按鈕可用狀態。
- tournament-screen（popup）：版面與 skin。
- LobbyScene：掛載彈窗；晨報派遣板入口列加「挑戰賽 ▶」；額外參戰扣金錢；報名、參戰後存檔。

## 暫定
- 入口暫放晨報派遣板入口列（與武將日誌、戰報同列）；額外參戰以金錢支付；文案待企劃定版。

## 不做
- 獎勵（TRN-10）、排行榜、對手陣容展示、伺服端。

## 驗收
- 控制器單元測試；validate-ui-specs；compute-gate standard 9/9。

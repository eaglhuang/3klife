# [PROG-2-1192] 三國日報／晨報登入面板改走 UCUF 畫面

## 為什麼做
使用者裁示：日報／晨報要走 UCUF 畫面流程，取代現在的 toast 提示。目前登入後以 SHOW_TOAST 逐行輪播（每則 3 秒），訊息會互相覆蓋、無法回看全部內容。

## 做什麼
- DailyReportController（純邏輯）：登入時擷取未讀日報（標題＋最多 3 則）與未讀晨報（開場＋最多 3 則），輸出 FlowView；兩者都沒有時不開面板。
- daily-report-screen（popup）：layout／skin／meta。
- LobbyScene：讀檔後改開面板，不再發 toast；顯示即標記已讀並存檔（與原行為相同）；「晨報派遣板 ▶」直接開派遣板。

## 暫定
- 版面、按鈕文案；日報與晨報同一張面板上下分區。

## 不做
- 日報歷史回看、分頁、角色立繪。

## 驗收
- 控制器單元測試；validate-ui-specs；compute-gate standard 9/9。

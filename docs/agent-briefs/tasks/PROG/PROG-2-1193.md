# [PROG-2-1193] 離線互動事件內容（JRN-04，doc_spec_0015 §E-4、§F-3）

## 為什麼做
武將日誌規格功能 #4「離線互動事件」只有觸發判定（OfflineInteractionTrigger），衝突標籤沒有來源、也沒有任何互動內容；大廳只記一行 log。

## 做什麼
- OfflineInteractionEvents.ts（純邏輯）：
  - 候選＝名冊在世武將之間的動態關係（同袍／結義／夫妻／親子），關係類型即 activeConflictTags。
  - 同一登入窗同一對角色只排 1 則（沿用 offlineInteractionKey）；隨機挑一組。
  - 摘要用規格 §G 句「{GeneralA} 與 {GeneralB} 在你離席時發生了一段插曲。」加關係類型的細節句；寫成 INTERACTION 日誌。
- GameSession：登入時（晨報產生前）若觸發成立就寫一則互動日誌，讓晨報可挑到；互動紀錄存檔（最多保留 20 筆）；offlineInteractionDue 改用關係標籤。
- LobbyScene：移除「待觸發」暫時 log。

## 暫定
- 細節句庫、重要度 50、登入窗以讀檔時的存檔時間為識別、紀錄上限 20。

## 不做
- 互動影響親密度或數值、互動選項、LLM 生成（§K 第二階段）、獨立互動面板。

## 驗收
- 單元測試：候選過濾、去重、摘要、GameSession 登入觸發與存讀檔；compute-gate standard 9/9。

# [PROG-2-1194] 名將挑戰賽賽季獎勵發放（doc_spec_0007 §E-9）

## 為什麼做
挑戰賽規格功能 #9「賽季獎勵發放」(P1)：本機賽季已能輪轉並留歷史（PROG-2-1190），但賽季結束後沒有任何獎勵，TournamentLocal 註明「獎勵發放未做」。

## 做什麼
- TournamentLocal：段位獎勵表（資料常數，暫定金錢）；歷史加 rewardClaimed；有參賽（有鏡像快照）的已結束賽季列為待領；領取函式回傳獎勵並標記已領。
- GameSession：pendingTournamentRewards／claimTournamentRewards(nowMs, grant)。
- 挑戰賽彈窗：新增「賽季獎勵：{Rewards}」行（規格 §H UI_TOURNAMENT_REWARD）與「領獎」按鈕；領取後存檔。
- LobbyScene：領獎經錢包 grantCurrency('gold')。

## 暫定
- 獎勵內容先只發金錢；稀有虎符／限定外觀等待企劃定版。
- 數額：青銅 100／白銀 200／黃金 400／白金 700／鑽石 1000／傳說 1500。
- 未參賽（本季沒有鏡像快照）不發。

## 驗收
- 單元測試：待領清單、領取後清空、未參賽不發、舊存檔正規化、面板文案與按鈕狀態。
- 全套測試、tsc、validate-ui-specs、compute-gate standard。

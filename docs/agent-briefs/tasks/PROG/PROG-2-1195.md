# [PROG-2-1195] 名將挑戰賽場地屬性公告（doc_spec_0007 §E-2、§A 杯賽命名）

## 為什麼做
挑戰賽規格功能 #2「場地屬性公告」(P1)：賽季開始要公告本季地形／天氣，讓玩家在培育期針對性培育。目前彈窗只顯示「第 N 季」，沒有杯名與場地。

## 做什麼
- TournamentLocal：杯賽表（資料常數：杯名、地形、天氣），依賽季序號輪替；tournamentVenueOf(seasonIndex)；狀態回傳 venue。
- 挑戰賽彈窗：賽季行改「第 N 屆【杯名】｜相位｜剩 X 日」（§H UI_TOURNAMENT_SEASON）；新增場地行「地形：{Terrain}、天氣：{Weather}」（§G 開幕句）。

## 暫定
- 杯賽輪替順序與武將盃／長坂盃的地形天氣；赤壁／官渡／虎牢／夷陵沿用規格 §K 表。
- 場地暫不影響本機對戰結果（對戰仍只看戰力）。

## 驗收
- 單元測試：輪替、狀態帶場地、面板文案。
- 全套測試、tsc、validate-ui-specs、compute-gate standard。

# [PROG-2-1196] 名將挑戰賽季節 BOSS 公告與弱點加成（doc_spec_0007 §E-8、§F 季節 BOSS）

## 為什麼做
挑戰賽規格功能 #8「季節 BOSS 戰」與 #10「賽季虎符連動」都以每季 BOSS 的弱點標籤為核心；目前沒有 BOSS 資料，彈窗也沒有 §H UI_TOURNAMENT_BOSS 公告。

## 做什麼
- TournamentLocal：每個杯賽帶一個季節 BOSS（資料常數：名稱、弱點標籤、基礎戰力）；弱點標籤中文表；bossWeaknessMultiplier(attackTags, boss) 命中任一弱點 ×1.5（規格 BOSS_WEAKNESS_BONUS），否則 ×1。
- 挑戰賽彈窗：新增「賽季 BOSS：{BossName}（弱點：{Tags}）」行。

## 暫定
- BOSS 名稱、弱點標籤組合、基礎戰力 10000、標籤中文名。

## 未做
- BOSS 挑戰戰鬥（規格為全服合力，需伺服器）；虎符帶標籤（#10，待虎符發行資料）。

## 驗收
- 單元測試：每杯都有 BOSS、弱點倍率、面板文案。
- 全套測試、tsc、validate-ui-specs、compute-gate standard。

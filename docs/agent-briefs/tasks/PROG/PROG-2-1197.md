# [PROG-2-1197] 官職晉升一次性獎勵與晉升提示階位名（doc_spec_0014 §E-6）

## 為什麼做
官職規格功能 #6「晉升提示與獎勵」(P1)：晉升時已有 toast，但沒有一次性獎勵；且大廳呼叫 officerPromotionNoticeOf 沒帶階位表，toast 只顯示「晉升 」沒有官名。

## 做什麼
- officer-tiers.json 每階加 promotionRewardGold（資料驅動）；OfficerTierTable 驗證並安裝；OfficerState 內建備援表。
- 晉升提示沒帶階位表時退回內建官名；有獎勵時附「（金錢 +N）」。
- LobbyScene 晉升事件時把該次晉升各階獎勵入錢包金錢（晉升只會發一次事件，已解鎖階位不重發）。

## 暫定
- 獎勵只發金錢：縣府佐官 200／郡守 400／州牧 800／霸府重臣 1500；官印外觀、升官動畫待企劃與美術。

## 驗收
- 單元測試：資料驗證含獎勵欄位、晉升文案帶官名與獎勵、獎勵加總。
- 全套測試、tsc、compute-gate standard。

# [PROG-2-1198] 許願池本機邏輯與存檔（doc_spec_0032 §E-6 免費許願軌）

## 為什麼做
經濟系統功能 #6「許願池商城」(P1)：免費玩家用時間換商品。目前沒有任何許願池邏輯，大廳許願祭壇（doc_spec_0002 §E-7）也無資料可接。

## 做什麼
- 新增 WishPool.ts（純邏輯）：每日早／中／晚 3 巡（UTC+8 06:00／12:00／18:00，00:00–06:00 算前一日晚巡）、每巡 3 項、同時最多 5 個進行中；商品表依 WISH_YIELD_TABLE 的產量比率與償還時數；加速卡每張 -2h、不低於 0；到期可領；正規化。
- GameSession：存檔欄位 wishPool、許願／加速（扣加速卡道具）／領取（入背包）。
- PlayerInventory：補入學令、虎符精華、延壽丹、加速卡的道具 id 與顯示名（PM 暫定 id）。

## 暫定
- 許願數量 = max(1, floor(課金即買數量 × 產量比率))；課金即買數量暫定讓每件許願得 1 個。
- 課金即買軌（精元直購）、加速卡購買與月卡贈送不在本卡。

## 驗收
- 單元測試：巡次判定、每巡／同時上限、到期、加速卡、領取入背包、存讀檔。
- 全套測試、tsc、compute-gate standard。

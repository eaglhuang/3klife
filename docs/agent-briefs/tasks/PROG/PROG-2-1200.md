# [PROG-2-1200] 道具背包分頁，許願池新道具進背包顯示（ITM-10 延伸）

## 為什麼做
背包面板只有 13 列（BAG_ROW_SLOTS），程式註明「超過的持有道具暫不顯示（分頁另卡）」。PROG-2-1198 新增入學令、虎符精華、延壽丹、加速卡後，因列數不足把顯示名暫放在 WishPool，玩家許願得到這些道具在背包看不到。

## 做什麼
- ItemBagController 加分頁：每頁 13 列，上一頁／下一頁，頁碼「第 p/n 頁」；只有一頁時隱藏分頁按鈕。
- 四種新道具顯示名併回 ITEM_DISPLAY_NAMES，WishPool 改用背包名稱表。
- item-bag-main 版面在清單下方加分頁列；LobbyScene 綁定分頁按鈕。

## 驗收
- 單元測試：持有全部道具時跨頁可看到每一種、翻頁邊界、選取依頁碼對應、使用後頁碼夾回。
- 全套測試、tsc、validate-ui-specs、compute-gate standard。

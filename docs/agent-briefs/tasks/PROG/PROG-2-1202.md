# [PROG-2-1202] 世家總覽熱點顯示規則與家族分組（HALL-12）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-1202 |
| 負責 Agent | claude-code-haiku-5-5 |
| 關聯 WBS | HALL-12（P1，大廳系統，3.0h） |
| 規格 | 大廳系統 §E-10；Data Schema `Data.Spirit_Family_State` |

## 完整描述
驗收：已解鎖世家系統時顯示世家總覽熱點，依家族分組顯示家族名、主卡、深度、名聲；未解鎖則隱藏。
本卡交付純邏輯：熱點可見性、武將世家入口的可見性、家族分組與排序（深度高到低、名聲高到低、同分依 key）。

## 不在範圍
- 大廳與命頁的 cc 節點接線：代碼中沒有世家系統的解鎖旗標，也沒有「分支已形成」的判定來源，無法接線。
- 家族名稱來源：read model 只存 key，名稱由呼叫端注入。

## 暫定
- `familySystemUnlocked` 由呼叫端傳入，待解鎖來源定案。

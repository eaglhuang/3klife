# [PROG-2-1205] 初始虎符寫入會話與存檔（OPEN-13）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-1205 |

## 完整描述
教學戰完成後產出的初始虎符要留在會話裡、跟著存檔走，不能每次讀檔都消失。
1. `GameSession.completeTeachingBattle` 第一次完成時產出虎符；之後再完成不覆蓋既有虎符。
2. 存檔只在有虎符時寫入 `startingTalisman`；舊檔沒有此欄位時讀回 null，版號不升。
3. 讀檔經 `normalizeStartingTalisman` 驗證，結構不合的資料直接丟棄。

## 不在範圍
- 教學戰本身的 cc 場景與戰鬥入口。
- 虎符在第一代子嗣繼承時的套用。
- 英靈記憶路徑（規格寫「虎符／記憶」二擇，本卡只做虎符）。

## 暫定
- 基因上限沿用 PROG-2-1203 的 `TEACHING_STARTING_GENE_LIMIT = 2`。

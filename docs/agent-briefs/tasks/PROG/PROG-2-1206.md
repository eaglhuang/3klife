# [PROG-2-1206] 武將命頁世家捷徑改走分支判定（HALL-12 接線）

| 欄位 | 值 |

## 完整描述
命頁的世家捷徑原本自己判斷 `hasFamilyBranch`；本卡讓顯示與點擊都改用 `branchShortcutVisible`，規則只在一處。分支已形成的來源是 `GeneralUnit.spiritFamilyState`，沿用既有欄位。

## 阻塞（待使用者裁決）
- 大廳世家熱點的解鎖來源：規格 §E-10 第 5 點寫「未解鎖世家系統時入口可隱藏」，但代碼中沒有世家系統的解鎖旗標（`OfficerUnlocks` 沒有對應欄位）。
- 在裁決前，大廳熱點維持無條件顯示，行為與改動前相同。

## 不在範圍

- 家族名稱來源（read model 只存 key）。

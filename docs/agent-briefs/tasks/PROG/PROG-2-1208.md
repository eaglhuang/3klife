# [PROG-2-1208] 教學戰傳說英靈入口（OPEN-13，PM 暫定）

## 基本資訊
| 欄位 | 值 |

## 完整描述
1. 暫定英靈：generals.json 中稀有度最高的武將，同級依 id 排序取第一位，即曹操（`cao-cao`），基因取其未鎖定因子。資料在 `assets/resources/data/teaching-spirit.provisional.json`，程式常數在 `TeachingSpiritProvisional.ts`，測試比對兩者一致。
2. 入口：首戰教學戰（`isTutorialBattle`）開戰時，`IBattleEntryParams.teachingSpirit` 帶入暫定英靈。
3. 戰場：`BattleScene` 把 `teachingSpirit` 放進場景 context，`BattleUIBridge` 戰後傳給 `recordBattle`，勝利時產出初始虎符。

## 暫定
- 英靈身分與基因：PM 暫定，企劃定案後換檔。
- 以首戰教學戰代替「英靈夢回開場戰」，兩者在代碼中都是「第一場、尚未通關」的戰鬥。
- 基因採未鎖定因子，隱藏因子不帶入。

## 未做
- 英靈夢回開場獨立劇情入口。
- 企劃定案後的資料替換。

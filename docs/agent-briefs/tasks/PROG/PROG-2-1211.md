# [PROG-2-1211] 祖紋命篆視覺樣式解析（BUI-08）

## 開單原因
血統樹 §4.2 規定祖先連線要用祖紋命篆，色彩要與六色因子一致；§4.3 限定只能改色調、徽記、紋樣，不推翻版型。現在沒有一個地方決定「某因子色的連線該用什麼色、什麼徽記、什麼紋樣」，畫連線的程式只能各自硬寫。

## 完整描述
1. 新增 `assets/scripts/core/systems/CrestStyle.ts`：
   - `resolveCrestStyle(color, colors?)` 回傳 `{ neutral, tint, badgeKey, glyphId }`。
   - 六色的色調取自 `FACTOR_TAG_COLORS`，徽記 key 取自 `FACTOR_TAG_I18N_KEYS`，紋樣 id 為 `crest_{色}`，與標籤色保持一致。
   - `null`、`undefined`、未知字串都退回中性樣式（`neutral: true`，`badgeKey: null`），不顯示徽記字。
2. 新增 `tests/CrestStyle.test.ts`（4 案）：六色對應、六色互異、中性退回、自訂色碼表優先。

## 暫定決策
1. 中性色 `#9A9A9A` 與紋樣 id `crest_neutral` 為暫定，等美術定稿再換。
2. 樣式只看單一因子色，不處理兩端顏色不同的連線混色；混色規則等連線繪製卡一併決定。

## 不在範圍
- 連線與節點的實際繪製（BUI-04 UIBloodlineConnections）。
- 紋樣圖集、命紋靈獸小圖騰。

# [PROG-2-1212] 血統樹父子連線依因子色上色（BUI-04 連線套樣式）

## 開單原因
PROG-2-1300 已合併連線繪製元件 `UIBloodlineConnections`，但連線顏色還是呼叫端傳入的固定色，沒有依子代因子色上色。規格 §4.2 要求連線色與六色因子一致。

## 完整描述
1. `FactorTagTokens.ts` 新增 `parseHexRgb`（#RRGGBB → RGB，格式不合回 null）與 `factorEdgeRgb`（六色依 `factorTagColorOf` 上色；null、未知色、色碼壞掉都退回 `FACTOR_EDGE_NEUTRAL_RGB`）。
2. `UIBloodlineConnections.ts` 新增 `FactorBloodlineEdge` 型別與 `drawFactorConnections`，內部轉成 cc `Color` 後沿用既有的 `drawConnections`。
3. `tests/FactorTagTokens.test.ts` 新增 2 案：RGB 解析與格式拒收；六色上色與中性退回。

## 暫定決策
1. 中性灰 `#9A9A9A`（RGB 154）暫定，與 CrestStyle 的 `CREST_NEUTRAL_TINT` 同值；兩處合一由 PROG-2-1211 合併後處理。
2. 本卡不依賴 `CrestStyle.ts`（僅在 PR #1103，未合併），避免疊卡。

## 不在範圍
- 佈局層傳入子代因子色的呼叫端。
- 祖紋紋樣與徽記的實際繪製。

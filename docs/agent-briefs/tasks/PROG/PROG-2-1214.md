# [PROG-2-1214] 中性色收斂成單一來源

## 開單原因
祖紋命篆（PROG-2-1211）與連線上色（PROG-2-1212）各自定義了中性灰 `#9A9A9A`，兩處只靠註解說同值，之後改色容易漏改。

## 完整描述
1. `FactorTagTokens.ts` 新增 `FACTOR_NEUTRAL_TINT`，作為中性色唯一來源；`FACTOR_EDGE_NEUTRAL_RGB` 與它同值。
2. `CrestStyle.ts` 的 `CREST_NEUTRAL_TINT` 改為引用 `FACTOR_NEUTRAL_TINT`。
3. `tests/FactorTagTokens.test.ts` 新增一案，比對 `FACTOR_NEUTRAL_TINT` 解析出的 RGB 與 `FACTOR_EDGE_NEUTRAL_RGB`。

## 暫定決策
1. 不讓 `FactorTagTokens` 反向 import `CrestStyle`，避免循環依賴；來源放在較底層的 `FactorTagTokens`。

## 不在範圍
- 中性色的美術定稿（仍為暫定）。

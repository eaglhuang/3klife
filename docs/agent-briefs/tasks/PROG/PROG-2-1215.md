# [PROG-2-1215] 14 人版血統樹畫面宿主（BUI-01 接線，PM 裁定 A）

## 開單原因
`bloodline-tree-main.json`（14 人版）與 `BloodlineTreeBinding` 都已在 master，但沒有任何畫面元件載入它們，binding 沒有呼叫端。PM 裁定 A：新建獨立元件，不改寫現有 BloodlineTreePanel。

## 完整描述
1. 新增 `BloodlineTreeScreen.ts`：繼承 `UIPreviewBuilder`，`build()` 載入版型、語系與 token 並建出節點樹；`renderCards(cards)` 依 `bindTreeCards` 找到 `NodeCard_G{世代}_{序號}`，設定卡片文字。
2. 新增 `tests/BloodlineTreeScreenLayout.test.ts` 3 案：每排卡數 8／4／2、綁定名稱都存在於版型容器、序號從 0 開始。

## 暫定決策
1. 版型讀取失敗或節點找不到時靜默略過，不拋例外。
2. 血統樹專用 skin 尚未建立，暫以 `null` skin 建構。

## 不在範圍
- LobbyScene 掛載入口（需要宿主節點，另卡）。
- 連線上色接線（等 PR #1112 合併）。

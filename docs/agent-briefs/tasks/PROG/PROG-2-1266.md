# [PROG-2-1266] 命頁右半六塊順序與英靈卡操作（GDUI-05）

## 來源
- WBS v16.3 GDUI-05：命頁右半六塊資訊欄（血脈摘要 / 靈獸 / 奧義軌 / 特殊因子 / EP 與覺醒進度 / 英靈卡操作）。P1，底座，5.0h。
- 規格：武將人物介面規格書 §6.3（六塊固定順序）、英靈世家系統 E-4（命槽單插槽、替換需提示被動解除）、§12（BATTLE_LOCKED）。

## 範圍
- `core/systems/BloodlineRightPanelLayout.ts`（新，純邏輯）：`BLOODLINE_RIGHT_PANEL_BLOCKS` 固定六塊順序、`spiritSlotActions(state)` 依命槽狀態與戰鬥鎖定回傳可用操作。
- `tests/BloodlineRightPanelLayout.test.ts`（新，headless）。

## 暫定
- 命槽為單插槽（E-4 第 3 條）；「設為主卡」只在已裝配且非主卡時可用。
- 戰鬥中（BATTLE_LOCKED）插入、替換、卸下、設為主卡全部停用，查看詳情仍可用。
- 替換時回傳 `warnPassiveLoss: true`，cc 端需提示原卡被動解除。

## 缺口
- 六塊的 cc 掛載與文字 i18n 待 View 卡；目前只有順序與操作可用性。

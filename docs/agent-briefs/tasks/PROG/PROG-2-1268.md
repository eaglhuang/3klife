# [PROG-2-1268] 疲勞度與失敗率曲線（FORM-02）

## 來源
- WBS v16.4 FORM-02：疲勞度與失敗率曲線（2.2）。P2，養成，1.0h，純邏輯。
- 規格：育成與戰鬥公式基準手冊 §2.2。
  - 體力 ≥ 70%：失敗率 0%。
  - 體力 30%～70%：失敗率由 5% 爬升至 35%。
  - 體力 < 30%：失敗率 40%～99%。

## 範圍
- `core/systems/FatigueFailureRate.ts`（新，純邏輯）：`fatigueFailureRate(staminaRatio)` 回傳 0..1。
- `tests/FatigueFailureRate.test.ts`（新，headless）。

## 暫定
- 規格寫「指數型」但只給端點範圍。風險區用 5% + 30% × t²，危險區用 40% + 59% × t，t 為該區間內的進度（0..1）。端點與規格一致，中段形狀待企劃確認。
- 體力比例輸入會夾在 0..1；非有限值視為 0。

## 缺口
- 中段曲線形狀待企劃確認。

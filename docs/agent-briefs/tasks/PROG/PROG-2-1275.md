# [PROG-2-1275] 藍色 3 星因子繼承機率（FORM-08）

## 來源
- WBS v16.4 FORM-08：因子繼承機率（藍色 3 星機率與世代相性，第 5 章）。P2，養成，2.0h，純邏輯。
- 規格：育成與戰鬥公式基準手冊 §5.1、§5.2。
  - 數值 < 600：獲得 3 星藍色因子 0%。
  - 600 ≤ 數值 < 1100：6%。
  - 數值 ≥ 1100：10%。
  - 相性影響白色戰法因子與紅色適性因子的機率（§5.2），規格沒有給數字。

## 範圍
- `core/systems/BlueFactorInheritance.ts`（新，純邏輯）：`blueFactorInheritChance(value)`。
- `tests/BlueFactorInheritance.test.ts`（新，headless）：三段邊界（599／600／1099／1100）與非有限值。

## 暫定 / 缺口
- §5.1 寫「數值」但沒有指明是哪一項屬性，本卡只接受傳入的數值，由呼叫端決定；待企劃確認。
- §5.2 相性對白、紅因子的影響只有定性描述，沒有數字，本卡不實作，待企劃給出數值表。

# [PROG-2-1285] 命槽插入與替換純邏輯（GDUI-05）

## 來源
- PM 裁定（2026-10-27）：插入與替換用簡易選卡面板（列表＋確認），暫定，記入待辦檔。
- 承接 PROG-2-1280（卸下與設主卡已合併於 #1166）。

## 範圍
- `core/systems/SpiritSlotFlow.ts`：
  - `unequippedSpiritCards(records)`：倉庫裡未裝在任何武將身上的英靈卡（選卡清單用）。
  - `insertSpiritCard(records, generalUid, spiritId, battleLocked)`：空命槽放入卡；新卡 isPrimary 為 null（主卡另外設定）。
  - `replaceSpiritCard(records, generalUid, spiritId, battleLocked)`：舊卡卸回倉庫、新卡裝入，同一筆結果寫回。
- `core/managers/GameSession.ts`：`insertSpiritCard`、`replaceSpiritCard` 包裝方法（成功才寫回）。
- `tests/SpiritSlotFlow.test.ts`：插入、替換、選卡清單共 11 個案例。

## 暫定
- 戰鬥鎖定一律拒絕（E-4），由呼叫端傳入 `battleLocked`，本次接 `false`。
- 插入時 isPrimary 設 null，不自動成為主卡（主卡由「設為主卡」按鈕決定）。

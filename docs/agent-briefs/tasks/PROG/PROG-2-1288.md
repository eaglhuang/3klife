# [PROG-2-1288] 因子池預覽改接 ChildFactorExpectation（ORAC-03）

## 來源
- PM 裁定（2026-10-27）：保留與實際繼承一致的算法，刪除另一份；§F 準確率與扭曲記入待辦檔。
- 比對結果：`previewFactorPool` 沒有套父母 LUK，`ChildFactorExpectation` 有，實際繼承（`FactorInheritance.inheritFactors`）有套 LUK。

## 範圍
- `core/systems/BreedingSystem.ts`：刪除 `previewFactorPool` 的重複進池迴圈，改為 `expectedFactorPool`，內部呼叫 `expectedChildFactorPool`，父母平均 LUK 與實際繼承相同。
- `core/services/BreedingService.ts`：`previewFactorPool(fatherId, motherId)` 方法名不變，改呼叫 `expectedFactorPool`。UI（大廳預言、SageOracleController）不動。
- `tests/SageProphecy.test.ts`：因子池預覽案例的期望值由 75% 改為 91%（父母 LUK 40，祖父母進池率 50%×1.4 = 70%，1 − 0.3² = 91%）。

## 暫定
- 父母 LUK 非 0 時預覽數字會變高，這是與實際繼承一致的結果，不是回歸。

## 不含
- §F 名士準確率與扭曲（Distort）邏輯：程式裡沒有，記入待辦檔。

# [PROG-2-1290] 培育屬性增長總公式與乘區（FORM-01）

## 來源
- WBS FORM-01（養成段 v16.4，P2 純邏輯）；規格：育成與戰鬥公式基準手冊 §2.1。
- 驗收：加法區、資質、運勢、陪伴、傾囊相授（連乘）、人數補正各有單測；傾囊為唯一連乘。

## 範圍
- `core/systems/TrainingGainFormula.ts`：`trainingGainBreakdown`，回傳各乘區與最終值。
- `tests/TrainingGainFormula.test.ts`：9 個案例，含整條公式（(10+5)×1.2×1.2×1.25×1.1 = 29.7）。

## 暫定
- 人數補正「額外 +5%」每位閒雜角色加法計（1 + 0.05n），不是逐人連乘。
- 基礎運勢係數缺省 0.2。

## 接線
- `NurtureSystem.computeStatGain` 改走本公式：教官加值進加法區、資質走 growthModifier、同格協力走陪伴乘區、傾囊相授走傾囊乘區；運勢與人數補正以中性值帶入。
- 數值與舊公式逐項一致，無平衡變動。

## 不含（待裁決）
- FORM-02 其餘部分（疲勞 §2.2 與培育 §F-2 失敗率曲線）仍 held，等使用者裁決。

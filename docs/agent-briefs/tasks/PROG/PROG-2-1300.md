# [PROG-2-1300] 血統樹父子貝茲連線（BUI-04）

## 為什麼做
血統樹 14 人 UI 規格 §2.3 的連線不能用長條 Image 湊合，要在排版後用 Graphics 動態畫貝茲曲線，才能容忍不同螢幕比例。

## 做什麼
- `bloodlineCurveBetween(from, to, bendRatio)`：父到子的三次貝茲控制點。
- `sampleCubicBezier(curve, segments)`：取樣成折線點。
- `UIBloodlineConnections`（掛 Graphics）：`drawConnections(edges)` 逐條畫線。

## 驗收
- 端點與控制點正確，取樣首尾等於端點。
- 段數小於 1 時仍至少兩點。
- 含 NaN／Infinity 的座標不產生線（不破圖）。
- 實機：Codex 於不同比例檢查連線與卡片對齊。

## 暫定
- 控制點推出量 0.5（PM 裁定）。
- 連線顏色由呼叫端傳入，色碼對應 uid-design-tokens.json 另卡接。

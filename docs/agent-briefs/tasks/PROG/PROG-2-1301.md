# [PROG-2-1301] 血統樹主角區 cc 綁定（BUI-05 接線）

## 為什麼做
PROG-2-0949 已把主角區資料整理成純邏輯，但畫面上還沒有 Label 接收這些文字。

## 做什麼
- `formatTraitList(traits, separator, emptyText)`：詞條列合成一行，空資料用佔位字。
- `UIMainTargetPanel.applyView(view)`：寫入稀有度與兩組詞條 Label。

## 驗收
- 多個詞條以頓號合併；空陣列與全空白項目回傳佔位字。
- 元件在 Label 未綁定時不拋例外（headless 不測元件，tsc 檢查型別）。
- 實機：Codex 驗收排版與字數不溢出。

## 暫定
- 立繪不在本卡載入（PM 裁定：資源載入另卡）。

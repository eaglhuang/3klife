# [PROG-2-1303] 戰法特效與掠奪飄字掛點（TAC-16）

## 為什麼做
戰法系統 §H 要求 SSR/UR 閃現、火計與水計的格子特效、資源目錄與掠奪飄字。這些是畫面層播放的前置判斷，程式端先提供掛點。

## 做什麼
- `tacticVfxHooks(input)`：依品質與元素回傳要播的 hook。
- `tacticFxPath(id)`：組出 `assets/fx/tactics/<id>.prefab`，不合規 ID 回傳 null。
- `lootFloatingTexts(events)`：掠奪型戰法在擊破或佔領時，每項資源產生一行金色飄字。

## 驗收
- SSR、UR 閃現；其他品質不閃現。
- 火計掛火焰，水計掛流動波紋並標示向右。
- 特效路徑只接受小寫英數與連字號。
- 飄字只在掠奪型且擊破或佔領時產生，數量 0 略過。

## 暫定
- 戰法資料尚無 element、lootTrigger 欄位，由呼叫端傳入（待資料定案）。
- 火計、水計、峽谷落石、火燒敵營的條目與 ID 命名待企劃定案。
- Prefab 實際播放與實機特效由畫面層與 Codex 驗收。

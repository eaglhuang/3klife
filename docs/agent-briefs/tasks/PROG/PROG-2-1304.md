# [PROG-2-1304] 開場信件已讀旗標隨存檔（COPY-02 接線前置）

## 為什麼做
開場信件面板（PROG-2-1302）需要一個存檔旗標，才能做到「只在新局首次進大廳開一次」。這張卡只做狀態與存檔，不含畫面掛載。

## 做什麼
- `GameSession.openingLetter`：唯讀副本。
- `GameSession.markOpeningLetterSeen()`：記為已讀並自動存檔；已讀時不重複存。
- 新局重置、存檔快照、讀檔還原都包含此欄位。
- `PlayerSaveService`：選填欄位，壞值正規化為未讀。

## 驗收
- 關閉信件後已讀寫進存檔，重開不再自動開。
- 未關閉時讀回仍是未讀。
- 重複標記不出錯。

## 未接線（後續卡）
- 大廳首次進入開啟信件面板，需要 opening-letter 畫面節點與 UI 佈局。
- 目前沒有 `opening-letter-screen` 佈局，不能在這張卡掛載。

## 暫定
- 舊存檔沒有此欄位，讀回視為未讀（PM 裁定：只在新局首次進大廳開啟，舊檔行為待定）。

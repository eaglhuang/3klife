# [PROG-2-1305] 開場信件大廳接線與畫面佈局

## 為什麼做
PROG-2-1302 做了面板元件、PROG-2-1304 做了存檔旗標，但大廳還沒有畫面可掛，也沒有首次進入時的呼叫端。

## 做什麼
- `screens/opening-letter-screen.json`、`skins/opening-letter-screen.skin.json`、`layouts/opening-letter-main.json`：標題、本文、關閉鈕。
- `LobbyOpeningPanels`：掛載、刷新、關閉並記為已讀。
- `LobbyScene`：在新手引導之後掛載。
- 語系：新增 `copy.letter.opening.title`。

## 驗收
- 未讀且就緒時開啟，帶入標題與本文。
- 新局等宿命開局開始後才開。
- 關閉後隱藏、記為已讀並存檔，讀回後不再自動開。

## 未完成
- 座標與實機排版交 Codex 驗收。

## 暫定
- 標題文字暫定，待企劃定稿。
- 信件與新手引導同時可見時，信件在上層。

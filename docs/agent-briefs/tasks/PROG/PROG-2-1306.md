# [PROG-2-1306] 英靈插卡四段演出時間軸（TRP-18）

## 為什麼做
兵種系統 §血脈卡與英靈插卡演出規定了四段順序，§特種軍隊血脈紋樣原則要求四處共用同一個 Sigil_Pattern_ID。畫面層需要時間軸與段落判斷，動畫本身另外做。

## 做什麼
- `buildSpiritInsertPlan(sigilPatternId)`：組出四段時間軸，ID 不合規回傳 null。
- `spiritInsertStageAt(plan, elapsedMs)`：依播放時間回傳目前段落；邊界屬於下一段。
- `sameSigilFamily(ids)`：檢查卡面、旗紋、英靈面、特種軍隊是否為同一家徽。

## 驗收
- 四段順序正確，首尾相接，總長為各段加總。
- 段落邊界切換正確，尚未開始為 null，播完為 done。
- ID 不合規不組軸；同一家徽通過，混用或空值不通過。

## 暫定
- 各段時長為暫定值（PM 裁定，待美術定稿）。
- 插卡動畫、特效與實機節奏交畫面層與 Codex 驗收。

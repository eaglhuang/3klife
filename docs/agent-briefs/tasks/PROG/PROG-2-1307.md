# [PROG-2-1307] Hazard 格換皮（GRD-05）

## 為什麼做
戰場格子系統 §C 要求同一套 Hazard 傷害邏輯可以表現為毒沼或火海，目前沒有換皮掛點。

## 做什麼
- `HazardVisualSkin.ts`：依換皮 ID 組出 Decal 與 VFX 路徑，只對 hazard 格回傳。
- 單元測試：兩種皮路徑不同、傷害規則不變、非 hazard 格不掛。

## 不做什麼
- 不產出美術 Prefab，不改傷害邏輯。

## 暫定
- 資源路徑沿用 `assets/fx/hazard/` 命名，待美術定稿。

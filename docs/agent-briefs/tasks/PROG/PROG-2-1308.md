# [PROG-2-1308] 戰場適性台詞（APT-14 台詞部分）

## 為什麼做
戰場適性系統 §G 規定水戰 S、山地 S、大霧、夜戰、適性不足與天氣變化各有一句劇本台詞，程式端還沒有選台詞的規則。

## 做什麼
- `AptitudeDialogue.ts`：依優先序回傳台詞種類，組出本地化 key，替換 `{Name}`。
- 四語系新增六句台詞 key。

## 不做什麼
- 地形格視覺差異與 UI_APT_* 等級文字拆為 P2 另卡。
- 戰鬥流程的呼叫端留待後續接線。

## 驗收
- 單元測試：水戰／山地 S 命中、大霧／夜戰需 S、風向優先、D 級不適、`{Name}` 替換。

# [PROG-2-1309] 每日補貼（ECO-06）

## 為什麼做
經濟系統規定低資源玩家每日登入可得基礎救濟，程式端還沒有判定與入帳。

## 做什麼
- `DailySubsidy.ts`：依上次領取日與今日判定，計算各資源補量並夾制。
- 單元測試：只補低於門檻者、同日不重領、無需補時不記領取、隔日可再領。

## 不做什麼
- 不接登入流程與存檔欄位，留待後續接線。

## 暫定
- 沒有資源低於門檻時不寫入領取日（以「真的領到才記」解讀「同日只領一次」）。

# [PROG-2-1312] 關卡推薦槽數與槽位缺口（LVL-05）

## 為什麼做
關卡設計系統 §E 要求關卡寫明推薦對策槽數，並與武將可裝備槽位比對。

## 做什麼
- 推薦槽數：明寫優先，沒寫以強制攜帶戰法數為準，限制在 1~4。
- 槽位缺口：推薦槽數減去武將槽位，最少為 0。

## 暫定
- 培育與關卡等級對槽位的加成未定義，本卡只計智力。

# [PROG-2-1313] 軍師 HUD 四摘要欄（LVL-06）

## 為什麼做
關卡設計系統 §D-4 要求主戰場 HUD 提供軍師可讀的四個摘要欄，目前沒有文字組成的規則。

## 做什麼
- 四欄文字組成：危害、互動物件狀態、戰後收益摘要、對策缺口。
- 不接收埋伏點、AI 路徑或站位，從輸入結構上避免洩漏答案。

## 暫定
- 格式與預設句（如「本回合無主題危害」）為暫定文案。

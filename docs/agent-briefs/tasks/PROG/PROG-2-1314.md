# [PROG-2-1314] AI 難度表（AIS-01）

## 為什麼做
AI 武將強度系統 E-1 定義五個難度，但程式端沒有統一的難度資料，數值散在各處。

## 做什麼
- `ai-difficulty.json`：五列資料。
- `AiDifficultyTable.ts`：解析與驗證，缺列或超界即回報錯誤。
- 測試 3 案，含實際資料檔。

## 不做什麼
- 不改戰鬥入口；AiSpCharge 仍以內嵌倍率運作，接線留待後續。

## 暫定
- 單挑閾值 NORMAL 以上一律 0.58，只有 EASY 降為 0.45。
- 奧義 EASY 關閉，其餘開啟。
- 難度加成同時用於部署與轉生，依規格兩處相同的表。

# [PROG-2-1315] 每日補貼接上登入與大廳提示（ECO-06 接線，doc_spec_0032）

## 為什麼做
PROG-2-1309 已有 DailySubsidy 純邏輯，但沒有呼叫端：玩家資源再低也領不到補貼，存檔也沒有上次領取日。交叉索引 Sec D 的「經濟補貼提示」掛點（LobbyMain 資源列）仍是 pending。

## 做什麼
- GameSession：claimDailySubsidy(epochMs, goldBalance, grantGold)——日序號用 UTC+8 切日（與連續登入同一切日）；糧草、城市兵源寫進軍備（依軍備上限夾制），黃金交給 grantGold（錢包）；存檔欄位 Daily_Subsidy（上次領取日與本日各項補量），版號不升。
- LobbyScene：讀檔登入後領取，有補時 toast 提示「每日補貼：糧草 +400、黃金 +150」並存檔。

## 暫定
- 提示文案（規格未定字串 key）暫用「每日補貼：X +N」。
- 地窖保護（戰敗保底）不在本卡。

## 驗收
- 單元測試：低於門檻才補、同日只領一次、隔日可再領、黃金交給錢包、軍備上限夾制、存讀檔保留。
- 全套測試、tsc、compute-gate standard。

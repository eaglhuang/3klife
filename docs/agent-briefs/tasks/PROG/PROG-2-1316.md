# [PROG-2-1316] AI Profile 模板與路線策略（AIS-03）

## 為什麼做
AI 武將強度系統 E-3 定義八種 AI Profile（軍事壓制、防守反擊……），E-4 另定路線選擇。程式端還沒有這份行為模板資料。

## 做什麼
- `ai-profiles.json`：八列資料，每列含部署傾向（偏好兵種、是否偏好剋制、低品質、特殊兵種）、戰法傾向標籤、路線策略、史實典型武將。
- `AiProfiles.ts`：純邏輯解析與驗證，缺列、重複、未知兵種或未知路線策略都回報錯誤。
- 測試：實際資料檔的八列與規格表一致；錯誤輸入會被擋下。

## 不做什麼
- 不改戰鬥部署流程，尚未接到 AI_Deploy。
- 戰法標籤只記傾向，不對應實際戰法 ID。

## 暫定
- 規格路線表只有六列，BALANCED 與 ARCHER_FOCUS 的路線策略留空（null），待規格補。
- 戰法傾向標籤由規格文字轉寫（衝鋒、反擊、計策等），正式對應待戰法系統定案。
- 史實典型武將只作參考資料，不影響數值。

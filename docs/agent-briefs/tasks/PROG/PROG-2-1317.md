# [PROG-2-1317] 反擊發動率接上戰鬥（FORM-05 接線）

## 為什麼做
FORM-05（PROG-2-1263）的 `tacticTriggerRate` 已有純邏輯，但沒有任何戰鬥流程呼叫它。依協調者裁定，發動率只影響被動／自動觸發，玩家主動施放不擲骰。反擊是目前戰鬥中最明確的自動觸發。

## 做什麼
- 反擊觸發時，依守方武將的智力算發動率 `1 − 90/INT`（裁定 K=90，與規格範例一致），擲亂數，未過則不反擊。
- 未過的擲骰不消耗反擊次數，反擊保持待命，下一次被攻擊仍可再擲。
- 守方沒有武將時不擲骰，維持原行為。
- 測試：真實 BattleController 多回合推進，第 1 回合擲骰失敗不反擊且次數不減，第 2 回合擲骰成功才反擊並消耗次數。

## 不做什麼
- 主動施放的戰法（玩家點選施放）不擲骰。
- 不加入戰法自身的成功加成（successBonus 暫為 0）。

## 暫定
- K=90 依協調者裁定（規格 §4.1 寫作 9000/INT %，即 90/INT，與範例一致）。
- 擲骰失敗不消耗觸發次數（暫定：未發動即視為未觸發）。

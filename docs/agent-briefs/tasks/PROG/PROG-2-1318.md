# [PROG-2-1318] 虎符精華突破接上 GameSession（TRP-11 接線）

## 為什麼做
TRP-11（PROG-2-0839）的 `resolveTallyBreakthrough` 已有純邏輯，但沒有任何存檔流程呼叫它，虎符卡無法從 3★ 突破到 4★／5★。

## 做什麼
- `GameSession.breakthroughTally(cardUid, roll, wallet)`：依卡的品質與目前星級呼叫突破邏輯；成功時把新星級寫回虎符卡並存檔。
- 金幣與精華由呼叫端依回傳的 `goldSpent`、`essenceSpent` 扣款，失敗時扣一半材料、星級不變。
- 測試：成功升星、失敗扣半材料且星級不變、材料不足不扣不升、星級超過品質封頂被擋。

## 不做什麼
- 不做突破 UI（cc 按鈕與畫面）。
- 保底符沒有道具模型，呼叫端暫傳 0。

## 暫定
- 保底符數量暫由呼叫端傳入，待道具模型定案後接上。
- 失敗時材料扣除由呼叫端執行，GameSession 不直接扣錢包與道具。

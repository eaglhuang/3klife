# [PROG-2-1319] 敵將屬性縮放接上開戰流程（AIS-02 接線）

## 為什麼做
PROG-2-1315 的 AiStatScaling 只有純公式，敵方武將建立時沒有套用，難度與章節對敵將屬性沒有作用。

## 做什麼
- `AiStatScaling.ts`：年齡轉階段（`aiAgeStageOf`）與敵將 config 縮放（`scaleAiEnemyConfig`），只縮放 str、int、lea、luk；hp 與精力不在規格範圍內，不縮放。
- `StageChainNodes.ts`：`stageChapterOf`，章節 = 關卡所屬 chainId 在關卡資料中的序位（從 1 起），依裁定採用。
- `BattleSceneLoader.ts`：`createGeneral` 對敵方武將套用縮放後再建立 GeneralUnit，不改 readonly 欄位。
- `BattleSceneFlow.ts`：開戰時讀取 ai-difficulty.json 與關卡章節，傳給敵將建立。
- 測試：年齡階段邊界、縮放只作用於四項數值、章節序位、結果與 GeneralUnit 建立一致。

## 不做什麼
- hp 與精力不縮放。
- cc 呼叫端的實機驗收交 Codex。

## 暫定
- 章節 = 關卡鏈在關卡資料中的序位（協調者裁定，待企劃確認）。
- 武將缺 age 時視為青年（修正 1.0）。
- 幼兒年齡（<5）暫以少年計。

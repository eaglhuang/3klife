# [PROG-2-1325] 單挑 AI 接受閾值改讀難度表

## 為什麼做
PROG-2-1322 寫死了閾值（EASY 0.45、其他 0.58），表格裡的 duelAcceptThreshold 沒人讀，改表無效。#1197 已合併，可以接上。

## 做什麼
- `decideDuelAccept` 改收閾值數字，不再查難度；寫死的閾值表移除，保留 0.58 作為未設定表格時的備援與玩家防守閾值。
- BattleState 記閾值；BattleController 新增 `configureAiDifficulty(entry)`（initBattle 之後呼叫，同 configureSortie 模式），場景入口傳入 enemyScale.difficulty。
- 單挑流程敵方防守時讀該閾值。

## 不做什麼
- 玩家防守閾值不動（規格 0.58）。
- 「有利時主動發起」屬發起判定，另開卡。

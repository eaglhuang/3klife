# [PROG-2-1326] AI 難度自適應（AIS-11）

## 為什麼做
規格 E-8：玩家連續 3 場勝利，敵方 statScale 上調 0.1；連續 3 場失敗，下調 0.1；夾在 0.7~2.5。WBS AIS-11。

## 做什麼
- 純邏輯 `AiAdaptiveDifficulty.ts`：連勝連敗計數、自適應倍率、提示文案。
- 計數存在扁平存檔快照的選填欄位 `aiAdaptiveStreak`，缺值視為 0，版號不升。
- 每場正式戰鬥結算時更新計數（GameSession.recordBattle）。
- 開戰 `loadEnemyScale` 套用自適應倍率；上調或下調時把提示寫進戰鬥記錄。

## 不做什麼
- 存讀檔流程測試（連勝計數跨存檔）：記入待辦檔，另補。
- 平手的處理（暫定視為打斷）與 E-8 字面公式正負（依註解實作）：待企劃確認。

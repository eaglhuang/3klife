# [PROG-2-1328] AI 擊殺能量倍率改讀難度表

## 為什麼做
AI 擊殺得到的能量倍率原本寫死在 AiSpCharge.ts（AI_DIFFICULTY_SP_MOD）。ai-difficulty.json 已有 spGainModifier 欄位，改成讀表，調數值只改表。

## 做什麼
- `aiSpGainPerKill(spGainModifier)` 收倍率數字，`floor(SP_PER_KILL × 倍率)`。
- BattleState 記 `aiSpGainModifier`（預設 1），BattleController.configureAiDifficulty 寫入，initBattle 時重設為 1。
- BattleCombatResolver 敵方擊殺改用 state 上的倍率；玩家擊殺不變。

## 不做什麼
- 不改玩家擊殺能量。
- 不改難度表數值。

## 驗證
- `npx tsc -p tsconfig.test.json --noEmit` 錯誤數 0。
- 測試以真實 ai-difficulty.json 驗證各難度擊殺能量，並覆蓋 initBattle 重設為 1。

# [PROG-2-1329] 敵方奧義施放決策（AIS-07）

## 為什麼做
AI 武將強度系統的 AI_UseUltimate 規則尚未接進戰場，敵方精力滿只會觸發戰法，不會施放奧義。難度表的 aiIq 與 canUseUltimate 也沒人讀。

## 做什麼
- `aiShouldUseUltimate`（純邏輯，不依賴 cc）依 IQ 判定：LOW 不放；MEDIUM 精力 > 50 且玩家存活 > 3；HIGH 以上擊殺 ≥ 2 或落後且精力 > 30（EXTREME、PERFECT 暫同 HIGH）。
- `BattleController.chooseEnemyUltimate`：難度表允許、精力滿、有解鎖奧義槽、判定成立，才回傳奧義組合。
- 敵方 special-resolve 階段先嘗試奧義，生效後才清精力並發事件。

## 不做什麼
- 不改玩家奧義規則。
- 不改難度表數值。

## 待 PM 確認（暫定，可逆）
- estimatedKills 規格未定義 estimateUltKills，暫以 0 傳入；高 IQ 目前只在落後時會放。
- vitality 以武將精力 general.vitality 計算（奧義實際扣的是精力）。
- isLosing＝敵方存活單位少於玩家。

## 驗證
- `npx tsc -p tsconfig.test.json --noEmit` 錯誤數 0。
- AiUltimateDecision 單元 5 案；AiEnemyUltimateFlow 4 案（真實回合流程，監聽奧義施放次數）。

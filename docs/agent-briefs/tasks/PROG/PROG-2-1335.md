# [PROG-2-1335] 挾天子令控制敵兵 2 回合（ult-cao-cao-3）

## 為什麼做
奧義 ult-cao-cao-3 的 battleSkillId 為 null，玩家施放沒有對應戰法路徑。規格：控制一名敵將為我方行動 2 回合。

## 做什麼
- BattleState：controlUnit（記原陣營與 2 回合）、tickControlledUnits（回合結束遞減，歸零換回）、陣亡清紀錄。
- ControlOverrideSkillResolver（effectKind control-override）＋ profile cao-cao-ult-control，沿用自動瞄準選目標。
- BattleController.finalizeRuntimeTurnCycle 於 nextTurn 後呼叫 tickControlledUnits。
- TroopUnit.faction 改為可變。

## 不做什麼
- 敵方曹操不施放挾天子令（AI 只用武將主技能路徑）。

## 驗證
- tsc test／cc-check 錯誤數 0；全套件 5101 通過；UltCaoCao3ControlFlow 4 案。

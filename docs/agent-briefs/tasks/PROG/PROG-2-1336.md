# [PROG-2-1336] 勸降成功時保護我方武將持有的虎符（POW-08 修正）

## 為什麼做
QA 線發現：勸降成功時，若該虎符現在被我方武將持有，會被轉走給俘虜。放走時已有保護，勸降沒有。

## 做什麼
- `GameSession.resolvePrisoner`：轉移前若虎符已被武將持有，跳過轉移。
- 測試：勸降成功但虎符由 lead 持有，結束後仍為 lead。

## 暫定（可逆）
- 已被我方武將持有的虎符兩種結局（勸降、放走）都不動。

# [PROG-2-1338] 俘虜身上虎符的轉移（POW-08，暫定）

## 為什麼做
俘虜規格：勸降或招募成功才轉移虎符，放走時虎符跟著他走。原本 transferTally 沒有呼叫端，放走也沒有處理虎符。

## 做什麼
- PendingPrisoner 加選填 tallyId，capturePrisoner 可帶入，存讀檔保留。
- 勸降或招募成功：transferTally 給俘虜。放走：takeTallyAway 帶走君主持有的卡（已被武將持有則不動）。
- 沒有 tallyId 不轉移。

## 不做什麼
- 戰場端還沒有敵將虎符資料，BattleUIBridge 未傳 tallyId，實際遊戲暫不轉移（待企劃）。
- 監禁（無期徒刑）不轉移虎符（規格未寫）。

## 驗證
- tsc test／cc-check 錯誤數 0；全套件 5145 通過；PrisonerTallyFlow 5 案（含跨季、存讀檔）。

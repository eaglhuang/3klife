# [PROG-2-1339] 敵方 AI 施放綁定戰法的奧義

## 為什麼做
奧義定義有綁定 battleSkillId 的戰法（例如唯才是舉、挾天子令），玩家施放時會走戰法路徑；敵方 AI 之前一律用武將主技能，綁定的戰法效果敵方永遠用不到。

## 做什麼
- `BattleSceneLoader.findUltimateBattleSkillId(ultimateId)`：查奧義定義的 battleSkillId。
- `BattleController.chooseEnemyUltimate`：奧義綁定的戰法可解析且已實作時，回傳該戰法 id；否則沿用 `general.skillId`。施放仍走既有 `tryEnemyUltimate → castBattleSkill(Faction.Enemy, …)`。

## 不做什麼
- 不改 AI 的施放條件（aiCanUseUltimate、精力、shouldUse 判斷維持原樣）。
- 不新增戰法本身的效果。

## 暫定（可逆）
- 綁定戰法未實作或未綁定：沿用武將主技能。
- `isBattleSkillImplemented` 對未知 id 會回 true，所以先確認 `resolveBattleSkillProfile` 有 profile 再看實作狀態。

## 驗證
- `npx tsc -p tsconfig.test.json --noEmit` 錯誤數 0；`npx tsc -p tsconfig.cc-check.json --noEmit` 錯誤數 0。
- 全套件 AiEnemyLinkedUltimateFlow 3 案：綁定已實作戰法施放該戰法；綁定未實作沿用主技能；多回合精力清空後不重放。

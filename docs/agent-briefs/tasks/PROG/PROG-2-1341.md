# [PROG-2-1341] 地窖保護：戰敗後糧草保底（ECO-06，doc_spec_0032）

## 為什麼做
經濟系統「地窖保護與每日補貼」規定 CELLAR_PROTECTION（糧草 1500、黃金 600，戰敗後觸發），防止連續戰敗把玩家打到零資源。每日補貼已接線（PROG-2-1340），地窖保護仍沒有程式。

## 做什麼
- `CellarProtection.ts`：純邏輯。保底值常數；`protectedAfterLoss(before, after, floor)`——戰敗扣減後不低於 min(戰前, 保底)；戰前已低於保底則不再扣。
- GameSession：戰敗（enemy-win）且有出征結算時，糧草扣減套用地窖保護；記下本場保住的糧草量供呼叫端提示。

## 不做什麼
- 黃金目前沒有戰敗扣減路徑，只提供保底值與函式，不接線。
- 掠奪系統尚未實作；保底層「不可被掠奪」待掠奪系統接上。
- 存檔欄位 Resource_Protection（最近觸發時間）暫不寫入。

## 驗收
- 單元測試：戰敗扣到保底以下被夾回、戰前已低於保底不再扣、勝利照常扣、保底不超過戰前。
- 全套測試、tsc、compute-gate standard。

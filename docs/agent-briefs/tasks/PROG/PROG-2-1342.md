# [PROG-2-1342] 戰敗結算顯示地窖保護提示（ECO-06，doc_spec_0032、doc_ui_0030）

- BattleUIBridge：戰後結算完成後，若 `lastCellarProtectedFood > 0`，寫戰鬥日誌並加入結算彈窗細項。

# [PROG-2-1344] 虎符戰記摘要（general-tally-summary，doc_spec_0012、doc_ui_0012、doc_ui_0030）

## 為什麼做
UI 補遺 general-tally-summary 要求人物頁 overview 次卡顯示「當前裝備虎符、TigerTallyScore band、兵種傾向、近期戰場表現摘要」。交叉索引 Sec D 仍為 pending；虎符槽讀取（PROG-2-1026）已有，但沒有摘要文字。

## 做什麼
- `GeneralTallySummary.ts`（純邏輯）：輸入虎符槽與戰績，輸出三行——虎符（品質、星級、分數與 band）、兵種傾向（綁定兵種中文名）、近期戰績（勝敗與勝率）。沒裝備虎符與沒有戰績各有空狀態文字。
- GeneralDetailOverviewMapper：content state 新增 `tallySummary`（戰績由呼叫端選填）。

## 不做什麼
- 不加版面節點（人物頁為 UCUF 對照版面，畫面渲染另卡）。
- 不展開完整虎符圖鑑或養成頁。

## 暫定
- band 沿用品質門檻（UR 85+、SSR 65-84、SR 40-64、R 0-39）。
- 文案（規格無字串 key）。

## 驗收
- 單元測試：裝備／未裝備、band 邊界、兵種名稱與未綁定、戰績與無戰績、mapper 帶出摘要。
- 全套測試、tsc、compute-gate standard。

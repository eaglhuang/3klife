# [PROG-2-1345] 虎符戰記摘要讀取武將戰績（general-tally-summary 後續）

## 為什麼做
PROG-2-1344 的 tallySummary 戰績由呼叫端選填，但人物頁所有呼叫端都沒傳，近期戰績永遠是「尚無戰績」。名冊武將身上已有 battleRecord（UltimateProgress 也從這裡讀）。

## 做什麼
- GeneralDetailOverviewMapper：沒有傳入 battleRecord 時，改讀武將設定上的 battleRecord（新增 `battleRecordOf`）；明確傳入時仍以傳入值為準。

## 不做什麼
- 不加版面節點；摘要的畫面位置待決定（overview 統領軍勢面板已滿、兵分頁尚無虎符槽版面）。

## 驗收
- 單元測試：武將有 battleRecord 時自動帶入、傳入值優先、格式不對時視為無戰績。
- 全套測試、tsc、compute-gate standard。

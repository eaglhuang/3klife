# [PROG-2-1347] 延壽丹效果：對武將使用延長壽命上限（武將壽命系統 E-6）

## 為什麼做
背包已有延壽丹（ITEM_LONGEVITY_PILL），但註解寫「用途待接線」，用了沒有效果。武將壽命系統功能清單 E-6「延壽丹效果與限制」為 P1。

## 做什麼
- `LongevityPill.ts`（純邏輯）：useLongevityPill(inventory, general) 檢查道具與武將狀態，成功時扣 1 顆、壽命上限 = resolveMaxLifespan + 3。
- GameSession.useLongevityPillOnGeneral(generalId)：仿補元散寫回名冊（maxLifespan）並自動存檔。

## 不做什麼
- 使用介面（選武將面板）另卡。

## 暫定
- 延長量採經濟系統道具表「壽命 +3 歲」；壽命規格寫「1~5 歲」，兩者不一致，先取固定 +3。
- 規格未寫使用次數上限，先不限。已陣亡武將不可使用。

## 驗收
- 單元測試：沒道具拒絕不扣、陣亡拒絕不扣、成功扣 1 顆並 +3、已有 maxLifespan 時疊加、GameSession 寫回名冊。
- 全套測試、tsc、compute-gate standard。

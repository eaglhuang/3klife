# [PROG-2-1349] 運氣影響事件觸發率（運氣系統 E-5，doc_spec_0035）

## 為什麼做
運氣系統功能清單 #5「事件觸發率」（P1）規定 `Event_Rate = Base_Rate × (1 + LUK / 200)`，程式端沒有任何地方實作；其他五項（LUK 屬性、天命波動、紫因子上限、Lv46 解鎖、覺醒速度）已有。

## 做什麼
- `LuckEventRate.ts`：luckEventRate(baseRate, luk)，結果夾在 0~1；LUK 非有限數或負數視為 0。
- 培育好感事件（NurtureEvents）改用此公式：rollNurtureRoundEvents 加選填 luk 參數。
- NurtureSession 開場快照子嗣 LUK（luk 欄位；舊存檔沒有視為 0，機率不變）。

## 暫定
- LUK 只提高有利事件（好感），不提高受傷等不利事件；規格只寫「隨機事件觸發機率」未分好壞。
- 先接培育好感事件；其他隨機事件之後再逐一接。

## 驗收
- 單元測試：公式（LUK 0／100／負值）、上限 1、培育好感依 LUK 觸發、受傷不受影響、舊會話無 luk 不變。
- 全套測試、tsc、compute-gate standard。

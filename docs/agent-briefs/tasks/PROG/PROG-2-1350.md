# [PROG-2-1350] 血統樹連線資料組裝（BUI-04 呼叫端的純資料部分）

## 開單原因
`UIBloodlineConnections` 已有繪製入口（PROG-2-1300），但沒有任何地方把「節點座標＋子代因子色」組成連線資料。佈局層要接上繪製，需要先有一個純函式負責組裝。

## 完整描述
1. `BloodlineConnections.ts` 新增 `FactorConnectionEdge`（from、to、childColor）與 `factorConnectionEdges(positions, childColorOf)`。
2. 連線清單依 `bloodlineEdges()` 的 14 條產生；缺任一端座標的連線略過，且不呼叫 `childColorOf`。
3. 測試 2 案：完整位置產生 14 條並依子代決定顏色；缺位置略過且不多呼叫。

## 暫定決策
1. 連線顏色取 `edge.child` 的因子色（該節點指向父母的那條線），與 `bloodlineEdges` 的語意一致。
2. 不引入 cc，型別只用 core 內的 `FactorColor`。

## 不在範圍
- 佈局腳本接線與實際畫面驗收（cc 端，另卡）。

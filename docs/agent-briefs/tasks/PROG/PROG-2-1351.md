# [PROG-2-1351] 限時道具到期判定與回收（ITM-08）

## 開單原因
道具系統規格把「限時道具到期自動回收」列為 P2，但目前 src 沒有任何到期判定。道具有 Expire_At 欄位，到期後要移出背包並通知玩家。

## 完整描述
1. 新增 `ItemExpiry.ts`：`sweepExpiredItems(items, nowMs)` 回傳 `{ kept, expired }`。
   - `expireAt` 為 null 的道具永久保留。
   - 到期判定為 `nowMs >= expireAt`。
   - `expireAt` 不是有限數字時保留該道具，不刪除資料。
   - 兩組都保留原本順序，不改動傳入的陣列。
2. 新增 `ItemExpiry.test.ts` 5 案，涵蓋永久、到期當下、未到期與已到期混合、無法解析的時間戳、順序與不改動輸入。

## 暫定決策
1. 到期邊界採「到期時刻當下即過期」。規格沒寫邊界，待定案後再調整。
2. 無法解析的時間戳保留而不回收，避免資料錯誤時把道具刪掉。

## 不在範圍
- UI_ITEM_EXPIRE 通知文字與背包接線。
- 定時掃描的呼叫點。

# [PROG-2-1352] 限時道具過期通知文字（ITM-08 文案）

## 開單原因
道具系統規格的 UI_ITEM_EXPIRE 通知（「{ItemName} 已過期並回收」）還沒有任何語系字串。ITM-08 的呼叫點要顯示它，所以先把文字落地。

## 完整描述
1. 四個語系新增 `ui.item.expire`，佔位符寫成 `{0}`，與既有字串一致：
   - zh-TW：`{0} 已過期並回收`
   - zh-CN：`{0} 已过期并回收`
   - en：`{0} has expired and was reclaimed`
   - ja：`{0} は期限切れのため回収されました`
2. 新增 `tests/ItemExpireText.test.ts` 3 案：key 存在、佔位符唯一、zh-TW 與規格一致。

## 暫定決策
1. 規格的 `{ItemName}` 對應到程式的 `{0}`，沿用既有佔位符寫法。
2. zh-CN、en、ja 譯文為暫定，待語系統一時再校對。

## 不在範圍
- 呼叫點與背包接線（等 PR #1123 合併後另卡）。

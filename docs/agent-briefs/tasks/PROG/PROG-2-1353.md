# [PROG-2-1353] 血統樹畫面接上樣式、連線與綁定（BUI-04 cc 接線）

## 開單原因
PROG-2-1215 的 `BloodlineTreeScreen` 仍以 null skin 建構，沒有畫連線；`BloodlineTreeBinding` 目前只有測試、沒有畫面呼叫端。PROG-2-1350 已備妥連線資料，這張卡把它們接進畫面。

## 完整描述
1. 新增共用模組 `ui/components/BloodlineTreeLines.ts`：`loadBloodlineTreeSkin()` 與 `redrawBloodlineTreeConnections(root, cards, childColorOf)`。後者依卡片節點位置（經 `UITransform.convertToNodeSpaceAR` 換到 LineGraphics 本地座標）組出 `factorConnectionEdges`，交給 `UIBloodlineConnections.drawFactorConnections` 上色重畫。子代位置取 `TargetPortrait`。不綁定特定畫面，命頁可直接呼叫。
2. `BloodlineTreeBinding` 測試新增一案：每張卡的 slot 位數等於 4 − 排數，鎖住排數與血統位置一致。

## 暫定決策
1. `BloodlineTreeScreen.ts` 不改動（與 #1128 刪檔衝突，PM 裁定命頁重複）。不新增 `treeSlotFor`：`bindTreeCards` 已帶出 `card.slot`，再包一層是重複邏輯。
2. `UIBloodlineConnections.ts` 不改，只使用既有 API。
3. LineGraphics 節點缺少 Graphics 或元件時自動補上，缺節點則靜默略過，與既有元件的容錯方式一致。

## 不在範圍
- 命頁左欄的 14 人整合與 LobbyScene 掛載（養成線負責，PROG-2-1098 欄位）。
- 實機畫面與座標微調（Codex 驗收）。

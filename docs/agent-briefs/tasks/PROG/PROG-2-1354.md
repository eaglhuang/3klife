# [PROG-2-1354] 加速卡規則改由 AccelerateCard 統一計算（ECO-08 呼叫端）

## 開單原因
`AccelerateCard.ts`（ECO-08，PROG-2-1019）已有測試，但沒有任何 src 呼叫端。許願池 `WishPool.speedCardsNeeded` 另寫了同一條規則（每張 2 小時、不超過剩餘時間所需張數），兩份規則容易日後漂移。

## 完整描述
1. `speedCardsNeeded` 改為委派 `accelerateRemaining(remaining, cards).cardsUsed`。
2. `SPEED_CARD_HOURS` 改為引用 `ACCELERATE_CARD_HOURS`，單一來源。
3. 測試：既有 WishPool 測試（speedCardsNeeded 的 2／4／0 三個數值）不改、必須全綠，即為兩者一致的證據；不另加 parity 測試。

## 暫定決策
1. 委派只改計算來源，不改 `applySpeedCards` 的結束時間下限行為。
2. 不改 UI 與存檔格式。

## 不在範圍
- ITM-08 過期回收呼叫點：背包目前是扁平數量表，沒有每件道具的到期時間，需先裁決資料模型。
- 大廳／開場與背包其餘模組（BagDomain、EquipmentBonus、GeneralEquipTransfer、各模組的存讀檔流程測試）另卡。

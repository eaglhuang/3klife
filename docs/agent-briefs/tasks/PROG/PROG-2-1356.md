# [PROG-2-1356] 賽季虎符連動：虎符克制標籤與 BOSS 弱點命中（名將挑戰賽 E-10，doc_spec_0007）

## 為什麼做
名將挑戰賽功能清單 #10「賽季虎符連動」（P1）：新虎符具備對 BOSS 的克制標籤。季節 BOSS 與弱點、命中 ×1.5 已有（PROG-2-1196），但虎符本身沒有任何標籤，玩家無從「配置克制陣容」。

## 做什麼
- TigerTallyCard 加選填 `bossTags`（新發行虎符可直接帶標籤）。
- `TallyBossTags.ts`：tallyBossTags(card) 有明確標籤用明確標籤，否則依兵種對照表推得；tallyBossMatch(cards, boss) 回傳命中弱點的虎符數與命中的標籤。
- 挑戰賽彈窗 BOSS 列附「虎符命中 N 張（標籤）」。

## 暫定
- 兵種→標籤對照（規格未寫）：弓兵→遠程、槍兵→反騎兵、器械／水軍→火攻、盾兵／醫療→反控制；騎兵、步兵不帶標籤。緩速（SLOW）只靠明確標籤。
- 命中算全部持有的虎符（尚無挑戰賽專用虎符出陣欄）。
- BOSS 戰需伺服器，傷害 ×1.5 的實戰套用不在本卡。

## 驗收
- 單元測試：明確標籤優先、兵種推得、無效標籤濾除、命中統計、彈窗文字。全套測試、tsc、compute-gate standard。

# [PROG-2-1357] 選裝備清單依品質排序並標示品質（武將背包系統 E-6，doc_spec_0017）

## 為什麼做
武將背包（倉庫）系統功能清單 #6「物品篩選排序」（P1）：按品質／類型／取得時間排序。目前寶頁選裝備清單只依裝備 id 排序，也看不到品質。

## 做什麼
- GearPickerView：列加 quality；排序改為品質由高到低（SSR→SR→R→N，不認得的排最後），同品質依 id。
- GearSlotPickController：每列顯示「品質｜名稱」。

## 暫定
- 選裝備清單已限定同一槽位（同類型），故不另做類型排序；取得時間資料層尚無 acquired_at 欄位，暫不做。
- 顯示格式「SR｜名稱」。

## 驗收
- 單元測試：品質排序、不認得品質排最後、同品質依 id、標籤文字。全套測試、tsc、compute-gate standard。

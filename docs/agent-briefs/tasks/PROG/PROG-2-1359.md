# [PROG-2-1359] 限時道具回收接上物件庫與登入切日（ITM-08 呼叫點）

## 開單原因
PROG-2-1351 已有 `sweepExpiredItems`，但沒有呼叫端。協調者裁定限時道具以統一物件庫列儲存、加選填 `expiresAt`，回收掃物件庫，掛在登入切日時呼叫，並補存讀檔流程測試。

## 完整描述
1. `InventoryRecord` 加選填 `expiresAt`（毫秒時戳）。
2. `normalizeInventoryRecords` 讀回時只保留有限數字的 `expiresAt`；缺欄位或格式不合即視為永久，列本身不丟棄。
3. `ItemExpiry.ts` 新增 `sweepExpiredRecords`，掃描物件庫列，判定規則與 `sweepExpiredItems` 相同。
4. `GameSession.recordLoginAt` 切日時回收過期列，回收結果存到 `lastExpiredInventory`，供 UI 顯示。
5. 測試：判定規則（ItemExpiry）與存讀檔流程（新增 InventoryExpirySaveFlow 測試）：舊檔列保持永久、限時列跨存讀檔保留、登入後過期列被移除並出現在 lastExpiredInventory、壞格式的 expiresAt 被丟棄。

## 暫定決策
1. 版號不升（協調者裁定）。
2. 登入切日以 `recordLoginAt` 為掛鉤點，與連續登入同一個 UTC+8 切日。

## 不在範圍
- LobbyScene 的 toast 顯示 UI_ITEM_EXPIRE（cc 端另卡）。
- 限時道具的來源（商城／活動）未定。

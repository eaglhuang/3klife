# [PROG-2-1360] 倉庫已用格數改計統一物件庫的一般列（BAG-10 呼叫端）

## 開單原因
`BagDomain.countGeneralBagSlots` 已有測試，但沒有 src 呼叫端。倉庫容量顯示用的 `warehouseUsedSlots` 只數扁平道具表，忽略物件庫中的一般裝備列，與 BAG-10「一般道具占一般倉庫格」不符。

## 完整描述
1. `warehouseUsedSlots` = 扁平道具種類數 + `countGeneralBagSlots(非裝備中的列)`。
2. 已裝在武將身上的列（`equippedBy` 有值）不計入倉庫，因為它們在武將背包。
3. 測試：存讀檔流程，物件庫中的一般裝備列跨存讀檔後仍占格；虎符列與裝備中的列不占格。

## 暫定決策
1. 一般裝備列以 1 列 1 格計（BAG-10 的列計格規則）。
2. 這會改變玩家看到的容量數字，屬於規格修正；若 PM 不同意，可整段還原。

## 不在範圍
- EquipmentBonus 的呼叫端（裝備加成數值來源未定）。
- GeneralEquipTransfer 退役（與 GearEquipFlow 職責重疊，待 PM 裁定）。

# [PROG-2-1367] 版本圖鑑的版本差異面板（SAME-07 畫面接線）

## 為什麼做
SAME-07 的版本差異比對已有純邏輯，但圖鑑畫面沒有顯示。

## 做什麼
- GeneralVersionDiff：比對對象選擇與面板 FlowView 片段。
- GeneralVersionGalleryController：選中血源時帶出差異面板。
- general-version-gallery-main layout：新增 diffPanel 與四個文字節點（不改既有節點）。

## 不做什麼
- 戰法與立繪對比（版本表沒有對應欄位，顯示「—」）。
- 讓玩家自選比對版本（先用最早 vs 最新）。

## 驗收
- 單元測試 7 項；全套、cc-check、測試 tsc、compute-gate standard。
- 面板座標與字級交 Codex 實機驗收。

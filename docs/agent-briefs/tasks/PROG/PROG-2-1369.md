# [PROG-2-1369] 初始六名將資料檢查接上名將登場幕（OPEN-02 無呼叫端模組接線）

## 為什麼做
InitialHeroTable（PROG-2-0342）只有測試呼叫。名將登場幕（PROG-2-1365）讀的是 InitialGeneralShowcase 的硬寫清單，initial-heroes.json 的史實欄位（出生地、核心因子標籤）沒有任何執行路徑檢查，資料壞掉無從察覺。

## 做什麼
- LobbyScene 名將登場幕首次掛載時，讀 data/initial-heroes，用已載入的武將資料核對 generalId，問題逐條 UCUFLogger.warn。

## 不做什麼
- 不改登場畫面顯示的資料來源，不刪 InitialGeneralShowcase 或 initial-heroes.json。
- 不補 introLine 台詞（待企劃）。

## 暫定
- 只警告不阻擋，與 PROG-2-1368 的做法一致。
- InitialGeneralShowcase 與 InitialHeroTable 內容重疊，哪一個保留待裁決，本卡不決定。

# [PROG-2-1371] 開場進度存檔與接續（QA：名將登場途中關遊戲會跳過登場）

## 為什麼做
QA 回報：名將登場途中關遊戲，下次開啟會跳過登場。原因是新玩家開場只靠記憶體中的流程，存檔後讀回就被當作一般玩家。

## 做什麼
- 存檔新增選填扁平欄位 openingPhase（版號不升，舊檔沒有即沒有進行中的開場）。
- 每次開場推進幕都寫入目前幕；開場結束寫入空值。
- 讀檔後若不是新玩家且有進行中的幕，接回該幕（intro／destiny／showcase）。
- 幕 id 認不得時視為開場已結束。

## 不做什麼
- 不記幕內進度（第一幕第幾頁、名將第幾位）：接續時從該幕開頭重來。
- 不改存檔版號與遷移鏈。

## 暫定
- 幕內進度不存，理由：幕內內容很短，重播成本低；若 QA 要求精確續播再另開卡。

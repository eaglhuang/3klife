# [PROG-2-1372] 武將 25 核心欄位覆蓋率摘要接上大廳載入（GDP-05 無呼叫端模組接線）

## 為什麼做
GeneralCoreFields（PROG-2-1271）只有測試呼叫。武將資料還缺 genes、skillId 等欄位（待企劃補值），目前沒有任何執行路徑能看到缺口有多大。

## 做什麼
- 新增 formatCoreFieldCoverage：一行摘要，列出完整數與缺值最多的三欄。
- LobbyScene 載入武將資料後記一行 info。

## 不做什麼
- 不擋載入、不補值、不改武將資料。

## 暫定
- 只記 info，不用 warn：缺值是已知的待補資料，每次開啟大廳都警告會淹沒真正的錯誤。

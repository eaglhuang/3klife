# [PROG-2-1374] 掛機每日免費入學令（ITM-06）

## 為什麼做
道具規格的掛機產出公式 daily_free_enroll = floor(facility_level/5)+1，保障無課玩家每天有 1–2 張入學令。目前沒有實際發放路徑。

## 做什麼
- dailyFreeEnrollCount：公式與非法等級回退。
- GameSession.recordLoginAt：登入切日才發一次，張數依太守府等級。

## 不做什麼
- 不做無課玩家的任務掉落與推薦獎勵（另有卡）。
- 不新增獨立的「免費入學令」道具 ID（沿用 ITEM_ADMISSION_TOKEN）。

## 暫定（PM 裁定）
- facility_level＝太守府等級。
- 登入切日發放，與限時道具回收同一時點。
- 同日重登不重發：以 lastLoginDay 是否改變判斷；登入狀態未存檔時下次登入會再判斷一次，不會重複發放。

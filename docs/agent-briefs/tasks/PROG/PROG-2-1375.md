# [PROG-2-1375] ITM-01 道具資料表（ItemDef：分類＋稀有度）

## 為什麼做
道具系統規格 P0「道具資料表定義」要求每個道具有 ID、名稱、分類、稀有度。目前道具只有 PlayerInventory 裡的常數與顯示名稱表，沒有分類也沒有稀有度，ITM-02（分類篩選）與 BAG-05（排序）都讀不到欄位。

## 做什麼
- 新增 ItemDef.ts：五大分類（消耗品／材料／特殊道具／貨幣／寶物）、ItemDef 表（id、名稱、分類、稀有度）、itemDefOf 查詢。
- 道具 ID 常數搬到 ItemDef.ts 當單一來源；PlayerInventory re-export，既有 import 不用改。
- PlayerInventory 的 ITEM_DISPLAY_NAMES 改由資料表推導（有呼叫端：ItemBagView、ItemBagController、SageOracleController、WishPool）。名稱與顯示順序不變。
- 測試：每個背包道具常數都有定義、ID 不重複、分類合法、顯示名稱與順序不變。

## 不做什麼
- 不做分類篩選與排序 UI（ITM-02／BAG-05 下一張卡）。
- 不改存檔格式、不改道具數量邏輯。
- ITEM_FERTILITY_ARMED 是內部標記、不進背包，不建定義。

## 暫定（PM 2026-10-28 裁定，可逆）
- 分類：規格有明寫的照寫（戰法筆記＝材料、補元散＝消耗品）；其餘依用途判斷，用完即減少歸消耗品，靠它觸發功能歸特殊道具。
- 稀有度：規格沒寫，全部填最低階 1。
- 規格的道具 ID（ITEM_WINE、ITEM_ELIXIR…）與程式現行 ID 不同，沿用程式現行 ID。

# [PROG-2-1376] STORY-05 角色雙故事層檢核（閘門先設警告）

## 為什麼做
角色雙故事層規格（doc_spec_0013）要求每位武將有六格故事帶、歷史趣聞與血脈傳聞，且不得留 `???` 佔位字。目前只靠人工看，沒有自動檢查，缺漏會悄悄進到正式資料。

## 做什麼
- 新增 `tools_node/validate-story-layers.js`：檢查六格順序（origin／faction／role／awakening／bloodline／future）、各格文字非空、無 `???`；歷史趣聞與血脈傳聞非空、無 `???`。
- 接入 `compute-gate`：新 gate `story-layers`，`failAction: warn`，加入 standard 與 full profile。
- 測試 `tests/StoryLayerCheck.test.ts`：正式資料通過，並覆蓋順序錯、空文字、佔位字、缺欄位。

## 不做什麼
- 不補文案、不改 generals.json（現況 235 位全部通過）。
- 不檢查「歷史趣聞偏前段、血脈傳聞偏後段、中段有命運介入」，這需要人工判斷。
- 不擋閘門：先以警告接入，之後由 PM 決定是否升為阻擋。

## 暫定
- 閘門先設 warn，避免既有資料或之後的新增稿件被單一欄位卡住。

# [PROG-2-1377] ITM-02 道具分類篩選

## 為什麼做
道具系統規格 P0 要求背包依五大分類（消耗品／材料／特殊道具／貨幣／寶物）篩選。ITM-01 已經有分類資料，這張把分類接進背包列與畫面流程。

## 做什麼
- 背包列帶上分類，`buildItemBagRows` 可依分類篩選（null 為全部）。
- 列的來源改為道具資料表（ITEM_DEFS），不再從顯示名稱表反推。
- `ItemBagController` 新增 `category`、`setCategory`；切換分類回到第一頁並取消選取。

## 不做什麼
- 分類頁籤按鈕的 layout 節點與 LobbyScene 綁定：屬於 cc 掛載，放到實機驗收一併處理。
- 不改道具數量與使用流程。

## 暫定
- 分類篩選與持有條件可並用；預設（null）列出全部分類。

# [PROG-2-1382] Loading Tips 內容 schema 驗證（LT-05）

## 為什麼做
LT-02 的選取器依賴四池與持有／未持有兩組權重。內容若漏池或權重鍵不一致，執行期只會靜默少抽，需要在驗證階段擋下。

## 做什麼
- validate-loading-tips.js：純函式 checkLoadingTips，回傳問題清單。
- validate-ui-specs.js：讀取 content/bloodline-mirror-loading-tips-v1.json 並呼叫檢核，問題列為失敗。

## 不做什麼
- 不改 LoadingTips.ts 的選取邏輯與權重數值。
- 不新增獨立閘門（沿用 validate-ui-specs 既有閘門）。

## 驗收
- tests/LoadingTipsSchema.test.ts 6 項（含真實內容檔通過）。
- validate-ui-specs 對真實資料通過。
- run-cli ALL PASS，測試 tsc 0 錯，compute-gate standard 通過。

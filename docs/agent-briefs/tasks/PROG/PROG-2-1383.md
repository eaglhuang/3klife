# [PROG-2-1383] 道具取得來源追蹤（ITM-05）

## 為什麼做
道具規格要求每次入庫記錄來源，以便之後查詢。目前入庫點沒有來源，無法區分商城、任務、掉落與活動。

## 做什麼
- ItemAcquisitionLog：增量比對入庫前後數量、保留最後 200 筆、依道具與來源查詢、存檔正規化。
- GameSession：所有入庫點記錄來源；addItem 加選填 source；查詢介面 queryItemAcquisitions。
- 存檔：itemAcquisitionLog 選填欄位，有紀錄才寫，版號不升。

## 不做什麼
- 不改純函式 addItem 與 PlayerInventory 的數量結構。
- 不做扣除紀錄、不做 UI 顯示（道具背包的來源篩選另案）。

## 暫定（PM 裁定）
- 來源判斷依各入庫點所在系統，判斷不了者留 UNKNOWN。
- 上限 200 筆；舊檔沒有欄位為空，來源缺值為 UNKNOWN。

## 驗收
- tests/ItemAcquisitionLog.test.ts 7 項（含存讀檔與舊檔相容）。
- run-cli ALL PASS，測試 tsc 0 錯，cc-check 無錯，compute-gate standard 通過。

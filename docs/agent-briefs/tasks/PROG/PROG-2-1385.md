# [PROG-2-1385] 無期徒刑傳家寶物掉落（EQP-09 來源）

## 為什麼做
俘虜處理 K 節與道具系統都寫明：無期徒刑囚犯會交出傳家寶物。目前關押只產出情報與糧草，沒有傳家寶來源，寶頁的傳家寶欄因此沒有資料。

## 做什麼
- ITEM_TREASURE（傳家寶物，寶物分類）加入道具定義。
- rollPrisonTreasures：每位關押俘虜每季擲一次，骰值低於機率就掉一件。
- 季結時在監獄產出之後入庫。

## 不做什麼
- 裝備與販賣流程（EQP-03 / EQP-06 與經濟線）。
- 掉落的來源紀錄（ITM-05 在 #1282，合併後補一行 DROP 記錄）。
- HeirloomCard 卡片欄位（規格未定，TSK-04 仍 blocked）。

## 暫定（PM 待裁）
- 掉落機率 0.05；規格只寫「有掉落池」，沒有數字。

## 驗收
- tests/PrisonTreasureDrop.test.ts 3 項；tests/ItemDef.test.ts 顯示順序更新為含傳家寶物。
- run-cli ALL PASS，測試 tsc 0 錯，cc-check 無錯，compute-gate standard 通過。

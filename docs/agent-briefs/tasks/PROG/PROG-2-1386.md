# [PROG-2-1386] 美術接線 icon 槽位檢核（GDART-10 自動化部分）

## 為什麼做
武將人物介面美術接線清單列了約 47 個 icon 槽位，目前沒有任何機器檢查：路徑寫錯會默默落空，哪些圖還沒匯入也沒人看得到。

## 做什麼
- validate-art-wiring.js：解析規格的 icon 路徑、判斷格式、檢查圖檔是否存在。
- validate-ui-specs.js 呼叫它：格式錯誤判失敗，未落地的圖列 warning。

## 不做什麼
- 節點名與 layout 對照（layout 仍是草稿，規格明載節點名為未來命名）。
- 兩態、鎖定樣式、觸控區的實機審查（屬美術與 Codex 驗收）。

## 暫定
- 圖檔副檔名接受 png/jpg/webp。

## 驗收
- tests/ArtWiringIcons.test.ts 5 項；run-cli 全綠；測試 tsc 0 錯；cc-check 無錯；validate-ui-specs 通過。

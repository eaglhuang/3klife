# [PROG-2-1387] 退役裝備傳給子嗣（EQP-07 傳承）

## 為什麼做
PM 裁定（2026-10-28）：武將退役後，裝備可以直接轉給指定子嗣，不必先回倉庫再手動穿。規格寫「退役後可傳承的裝備，允許轉移到後代」。

## 做什麼
- transferGearToHeir：子嗣格位已解鎖且為空，就保留原格；否則裝備回倉庫。
- retireGeneral 新增選填 heirChildId，轉移要早於退役的清裝備流程。

## 不做什麼
- 父子血緣驗證（模型尚無父母欄位）。
- 英靈卡與虎符轉移。
- 子嗣選擇的 UI。

## 暫定（PM 可逆裁定）
- 預設仍回倉庫；接收者只驗存活、非本人、非導師卡。

## 驗收
- tests/GearHeirTransfer.test.ts 7 項，含存讀檔；run-cli 全綠；測試 tsc 0 錯；cc-check 無錯。

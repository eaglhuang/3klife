# [PROG-2-1388] 退役裝備接收子嗣：選擇 UI 與血緣驗證

## 為什麼做
PROG-2-1387 只有後端參數，退役畫面沒有入口。這張補上選擇按鈕，並把驗證改成真正的父母關係，不再只看存活。

## 做什麼
- 退役工具列新增「接收」按鈕，循環選擇父母指向退役者的存活子嗣。
- 退役時把選到的接收者傳給 retireGeneral。
- GameSession 以 fatherId／motherId 驗證血緣。

## 不做什麼
- 血統圖查詢（roster 欄位與血統圖同源，目前不另外查）。
- 英靈卡與虎符轉移。

## 驗收
- tests/RetirementFlowHeir.test.ts 5 項；tests/GearHeirTransfer.test.ts 更新；run-cli 全綠；測試 tsc 0 錯；cc-check 無錯。

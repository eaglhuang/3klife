# [PROG-2-1390] 物品鎖定與一般裝備分解回收（BAG-07）

## 為什麼做
規格（武將背包（倉庫）系統 §整併 第 9 項）要求物品可鎖定以防誤分解，並可分解一般裝備回收材料。

## 做什麼
- InventoryRecord 新增選填 isLocked；舊檔不補值。
- setRecordLocked：只改旗標，不影響穿戴。
- decomposeGearRecord：只收一般裝備、未鎖定、未裝備；成功移除列並給 1 件竹簡。
- GameSession 包成 setInventoryLocked／decomposeGear，並發出庫存變更事件。

## 驗證
- tests/GearLockDecompose.test.ts 6 項（純函式與 GameSession 流程，含存讀檔）。
- run-cli ALL PASS；tsc 測試 0 錯；cc-check 無錯。

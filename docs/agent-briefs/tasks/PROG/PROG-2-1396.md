# [PROG-2-1396] /sync/delta 路徑白名單（SYNC-06）

## 為什麼做
同步 API 規格 §7 要求伺服器驗證 patches 的 JSON Pointer 路徑白名單，防止注入。整合樹的 applyJsonPatches 之前沒有白名單。

## 做什麼
- 白名單取自客戶端存檔快照的頂層欄位（PlayerSaveSnapshot）。
- /sync/delta 套用前驗證，不合規回 400（E002）。
- 契約測試確保白名單與客戶端存檔定義同步。

## 不做
- 不做 /sync/full（全量覆蓋不經 patch，規格未要求白名單）。
- 不改客戶端 DeltaPatchBuilder。

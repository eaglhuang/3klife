# [PROG-2-1399] 限定池排程接上轉蛋（GCH-12）

## 為什麼做
LimitedPoolSchedule 只有純邏輯，沒有呼叫端。轉蛋規格要求限定池依排程上下架，且銅錢符不可用於限定池。

## 做什麼
- 讀取排程設定 JSON（預設空陣列，沒有限定池開放）。
- 轉蛋結算路徑檢查限定池時間窗與貨幣規則，限定角色接上 Up 名單。
- 流程測試：窗前、窗內、窗後、銅錢符、靈玉、無設定時既有池子不變。

## 不做
- 不填真實時間窗（待使用者裁決）。
- 池列表 UI 不顯示限定池（只接抽卡結算路徑）。

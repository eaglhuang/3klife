# [PROG-2-1401] 試用傭兵出戰計數（RET-01 後續）

## 基本資訊
| 欄位 | 值 |
|---|---|
| 卡號 | PROG-2-1401 |
| 負責 Agent | ClaudeCode_claude-haiku-5-5 |
| 關聯 WBS | RET-01（後續：戰鬥結算寫入 battles、wins） |
| 規格 | 留存系統 §F 插畫解鎖條件；協調者裁決 A：試用傭兵以存檔 id 進出戰清單，出戰不計精力與戰績，戰後更新傭兵 battles、wins |

## 完整描述
1. `recordTrialBattle`：試用中的傭兵出戰後場數 +1，戰勝才勝場 +1，插畫階段依 RET-01 規則推進（只進不退）。結義與到期的傭兵不動。
2. `GameSession.recordBattle`：deployedIds 內的試用傭兵 id 寫入計數；ongoing 不計；名冊武將不受影響。
3. 存檔：battles、wins 為選填欄位，非法值只丟該欄。

## 不在範圍
- 出戰清單接線：目前 UI 沒有列出試用傭兵，所以實際遊戲中 deployedIds 不會包含傭兵 id，階段 2、3 仍不會在遊戲中達成。需另卡處理。
- 精力與戰績的排除：沿用 BattleRoster 既有規則（試用傭兵不在名冊，settleBattle 會略過）。

## 暫定
- 平手只計場數，不計勝場。

# [PROG-2-1405] 結緣時宿敵配種關係事件（KIN-08 治理呼叫端）

## 開單原因
家族關係（史實相性）系統 §G 規定宿敵配種要有劇本事件。KIN-08 已在 master 定義關係事件規則，但結緣流程還沒有呼叫端，事件無法被觸發。

## 完整描述
1. `RelationEvents.ts`：新增 `relationEventsForBreeding(table, ledger, scopeKey, fatherId, motherId)`，以季度為 scope，同季同一對只觸發一次。
2. `BreedingService.breed`：結緣非 blocked 時呼叫，結果寫入 `BreedingResult.relationEvents`。
3. `BreedingSystem.ts`：`BreedingResult` 增加選填 `relationEvents`。
4. 測試 `tests/RelationEventsBreeding.test.ts` 3 案。

## 不在範圍
- 一次性紀錄存檔（ledger snapshot 接 GameSession），另卡。
- 戰場呼叫端與劇本事件顯示，另卡。

## 暫定決策
1. 場景對應：治理（結緣）→ 宿敵配種（RIVAL）；沿用 RelationEvents.ts 既有暫定。
2. 季度 scope 以 `season-{currentSeason}` 組成。

# [PROG-2-1406] 結緣時宿敵關係事件台詞顯示（KIN-08 劇本 UI）

## 開單原因
PROG-2-1405 讓結緣會產生 `relationEvents`，但結緣畫面沒有讀取它，玩家看不到宿敵配種的劇本台詞。

## 完整描述
1. `BondingSetupController.confirm`：結緣未被阻擋時，把每筆事件的 `loreKey` 用 `relationLoreText` 轉成台詞，接在通知列後面。
2. 文字查找先用注入的 `text`，缺 key 時退回 zh-TW 預設（`withRelationFallback`）。
3. 測試 `tests/BondingRelationLore.test.ts` 2 案：宿敵配對出現台詞、非宿敵配對不出現。

## 不在範圍
- 戰場呼叫端（`detectRelationEvents` 的 battle 場景目前沒有呼叫端），另卡。

## 暫定決策
1. 台詞接在既有通知列後面，不另開視窗；沿用結緣畫面的通知格式。
2. 同季同對只在第一次結緣時出現，由 BreedingService 帳本決定，UI 不另判斷。

# [PROG-2-1407] 復仇取回：缺糧紀錄帶缺口數量（RET-05）

## 開單原因
留存系統 §F 規定日報的「復仇」要取回損失資源的 5%~20%。但玩家日誌的缺糧紀錄只有資源名稱，沒有數量，取回的基數不存在。

## 完整描述
1. `PlayerLogEntry` 新增選填 `amount`。讀檔時只保留合法正整數，其餘丟掉、紀錄本身保留。扁平存檔、版號不升。
2. 季結判定缺糧（糧草低於門檻）時，RESOURCE_LOW 紀錄帶上缺口 = 門檻 − 目前糧草。
3. `GameSession.claimRevengeRecovery(pct)`：取最近一筆帶數量的缺糧紀錄，依 pct 換算取回糧草（不超過糧草上限），並消耗該筆紀錄，不可重領。

## 不在範圍
- 復仇日報的按鈕與 UI 呼叫端（另卡）。
- 百分比擲骰：由呼叫端傳入。

## 暫定決策
1. 缺口定義為門檻減目前糧草（沿用 TALLY_SHORTAGE_FOOD_THRESHOLD）。規格沒有寫「損失」的確切數量，這是暫定基數。
2. 取回的是糧草，不是其他資源。
3. 只取最近一筆，每筆只能取一次。

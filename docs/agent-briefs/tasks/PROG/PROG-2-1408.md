# [PROG-2-1408] 復仇取回按鈕（RET-05 UI 接線）

## 開單原因
PROG-2-1407 只有 GameSession 入口，玩家看不到復仇取回。登入面板的日報有復仇項目時，應該能按下取回糧草。

## 完整描述
1. 登入面板的按鈕列新增 `btnRevenge`（復仇取回 ▶），只在日報含復仇項目且有可取回的缺糧時顯示。
2. 點擊後呼叫 `claimRevengeRecovery`，百分比用遊戲亂數源擲出，存檔後按鈕隱藏，並以提示顯示取回數量。

## 不在範圍
- 日報文字的百分比與實際取回一致（需要把擲出的百分比存進日報條目，會改日報存檔，另卡）。
- 實機座標微調（交 Codex）。

## 暫定決策
1. 按鈕文案「復仇取回 ▶」為暫定。
2. 取回百分比取點擊時的亂數，不取日報文字裡的百分比。

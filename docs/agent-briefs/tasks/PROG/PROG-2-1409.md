# [PROG-2-1409] 復仇日報百分比與取回一致

## 開單原因
日報文字在登入時擲出 5~20%，取回時又重新擲，玩家看到的「取回了 X%」和實際數字可能不同。

## 完整描述
1. 日報的復仇條目在生成時擲一次百分比，寫進條目的選填欄位 `pct`，文字用同一個值。
2. 讀檔時只保留 5~20 的整數，其餘丟掉。
3. 登入面板的取回按鈕只在有 `pct` 的復仇條目時出現，取回用條目的 `pct`。

## 不在範圍
- 補擲舊存檔的復仇條目（舊條目沒有 pct，該日不顯示按鈕）。

## 暫定決策
1. 只有復仇條目多消耗一次亂數，其他條目的亂數順序不變，既有測試結果不動。

# [PROG-2-1411] 英文壽命劇本與戰報鍵縮短（i18n 寬度，第二批）

## 開單原因
寬度報告 #694 指出英文譯文超出 zh-TW 欄寬的鍵。PROG-2-1410 處理了退役審查、季節、官職與導覽，這張接著處理壽命劇本（life.script.*）與戰報里程碑（record.milestone.*）中超過 2.0 倍的鍵。

## 完整描述
1. 只改 `en.json`，十個超過 2.0 倍的鍵縮短，語意保留，`{0}`、`{1}` 占位符不動。
2. zh-TW 原文與 ja 不動。

## 不在範圍
- 1.5~2.0 倍的鍵。
- LORE_REL_*、UI_REL_*：屬於關係系統，不屬壽命組。
- 實機排版（交 Codex 驗收）。

## 暫定決策
1. 英文縮短為實作層的可逆選擇，依 #694「各組自行縮短」。
2. 里程碑鍵改用數字形式（例如 "100 Kills"），取其寬度短且語意清楚。

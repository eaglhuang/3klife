# [PROG-2-1412] 關係事件帳本存檔（KIN-08 同季只播一次跨重開）

## 開單原因
QA 指出 PROG-2-1405 的 `RelationEventLedger` 只在記憶體，玩家同季結緣後重開遊戲，宿敵事件會再播一次。

## 完整描述
1. `GameSession` 持有 `relationEvents` 帳本，新局與讀檔時清空／還原。
2. 存檔寫入 `relationEventKeys`（鍵為 `scope#eventId#pairKey`），只在有資料時寫入；舊檔缺欄位讀回為空。
3. `BreedingService` 接受選填 `relationLedger`，`ServiceLoader` 注入 session 帳本，讓結緣與存檔共用同一份紀錄。
4. 存讀檔流程測試：同季不重播、換季照播、舊檔相容、壞資料過濾與去重、版號不變。

## 不在範圍
- 戰場呼叫端與劇本事件顯示，另卡。

## 暫定決策
1. 存檔版號不升（PLAYER_SAVE_SCHEMA_VERSION 維持 1），沿用 dynamicRelations 的後加選填欄位做法。
2. 帳本只存已播鍵，不存時間；換季的 scope 不同自然不衝突，不需清理。

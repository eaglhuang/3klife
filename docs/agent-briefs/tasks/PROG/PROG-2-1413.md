# [PROG-2-1413] 戰場開場關係事件呼叫端（KIN-08 戰場場景）

## 開單原因
PROG-2-1405 只接了結緣（治理）場景，`detectRelationEvents` 的戰場場景（名將契合、義兄弟合攻）沒有任何呼叫端，戰場不會觸發史實配對的劇本事件。

## 完整描述
1. `relationEventsForBattle`：出陣雙方（玩家與敵方武將）判定事件，經 session 帳本過濾，同一戰役只回傳新事件。
2. `BattleController.bindRelationEvents(scopeKey, ledger)`：場景在 `initBattle` 前綁定帳本與戰役實例 key。
3. `initBattle`：綁定後判定開場事件，寫入 `relationEventHits`。
4. `BattleScene` 綁定 `battle:<encounterId>` 與 `services().session.relationEvents`。
5. 測試 `tests/BattleRelationEvents.test.ts`：真實 `BattleController` 跑多個完整回合，驗證開場事件只觸發一次、同戰役再開不重播、換戰役照播。

## 不在範圍
- 戰場關係事件的顯示（Toast 或結算列）；`relationEventHits` 目前無呼叫端讀取，另卡。
- `BattleSceneFlow` 沒有設定 `historicalPairs`，也未綁定帳本，該路徑暫不觸發，另卡。

## 暫定決策
1. 判定範圍只看出陣的玩家與敵方主將，不含參謀、副將與虎符部隊。
2. 戰役實例 key 用 encounter id，同一關卡只觸發一次；存檔與帳本共用。

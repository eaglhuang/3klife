# [PROG-2-1414] 趕路倒數來源：首次展示紅顏時開始（OPEN-11）

## 開單原因
CountdownManager 與主畫面常駐圖示都已存在，但沒有任何呼叫端會開始倒數（`startCountdown` 無呼叫端），倒數圖示在遊戲裡永遠不出現。倒數也沒有存檔，離線時間無法累積。

## 完整描述
1. 首次展示紅顏（新手開場第四幕）時，若沒有進行中的倒數，開始一筆倒數：甄姬、3 小時、可加速。
2. 倒數寫入存檔欄位 `countdown`，讀檔還原；欄位不合法或缺欄時為 null，不猜測補值。
3. 測試：首次開始且不重置、JSON 存讀後離線仍依絕對時間計算、無趕路的存檔不寫欄位、欄位驗證拒收。

## 不在範圍
- 諸葛亮未買時的 7 天倒數：依付費流程，另卡。
- RedFaceCopy 的 travel／countdown 文案接線：另卡。
- 0.99 立即抵達的扣款：OPEN-12。

## 暫定決策
1. 開始時機沿用紅顏展示的時點（首戰後第一次回大廳），規格寫「教學結束」，兩者在目前流程是同一刻。
2. 目標甄姬、時長 03:00:00、可加速，依新手引導規格 4.3 暫定。
3. 倒數以 Date.now 傳入的絕對時間戳記錄，不靠每秒累加。

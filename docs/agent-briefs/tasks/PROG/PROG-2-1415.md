# [PROG-2-1415] 戰場關係事件帳本接 session 存檔（KIN-08 戰場端）

## 開單原因
#1202（PROG-2-1420）的戰場帳本是控制器自己的記憶體物件，每場戰役新建一份，讀檔重進同一關會再播一次事件。結緣端在 PROG-2-1412 已改成 session 帳本，戰場端也要對齊。

## 完整描述
1. `BattleController.bindRelationEvents(scopeKey, ledger)`：場景綁定 session 的 `relationEvents` 與 `battle:<encounterId>`。
2. 未綁定時維持原行為（一場一份、scope 為 `battle`）。
3. `BattleScene` 在部署前綁定。
4. 測試：同一關重進不重播、換關照播；JSON 存讀後同一關不再觸發；未綁定行為不變。

## 不在範圍
- 事件顯示 UI（`RelationEventTriggered` 目前沒有 toast 接線）。

## 暫定決策
1. 戰役實例 key 用 encounter id，與 PROG-2-1412 結緣端的做法一致。
2. 存檔版號不升，沿用 `relationEventKeys` 欄位。

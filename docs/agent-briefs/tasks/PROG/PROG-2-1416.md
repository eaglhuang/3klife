# [PROG-2-1416] 監獄容量依主城等級（ECO-14，經濟系統 Q49 選項 B）

## 開單原因
經濟系統 Q49 裁決：監獄依主城等級有固定關押上限，避免玩家無限卡押俘虜。原本的上限只看監獄格數（初始 3、可擴到 10），沒有連到主城等級。

## 完整描述
1. `PRISON_CAPACITY_BY_LEVEL` 資料表與 `prisonCapacityOf(level)`：Lv1–2 為 3、每兩級 +1、Lv15 起封頂 10。
2. `GameSession.resolvePrisoner` 的關押檢查改用主城等級容量。
3. 俘虜處置面板的容量顯示改用同一來源，與實際擋下的上限一致。
4. 測試：全部等級符合公式、低於第一列取第一列、達到容量回報 PRISON_FULL、未達可關押。

## 不在範圍
- `PrisonState.slots` 欄位是否移除（存檔相容）：現在不影響容量，待 PM 決定。

## 暫定決策
1. 容量公式與表依 PM 暫定（min(10, 3 + floor((Lv − 1) / 2))），規格只裁了「依主城等級」，未給數字。

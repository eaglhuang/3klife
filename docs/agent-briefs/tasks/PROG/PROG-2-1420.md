# [PROG-2-1420] 戰場關係事件：部署時偵測名將契合、義兄弟合攻（KIN-08 戰場端）

## 為什麼做
RelationEvents（PROG-2-1068）已有戰場事件定義，治理端已由 PROG-2-1405 接上，但戰場沒有呼叫端：出陣武將命中夫妻、結義關係時不會觸發任何事件。

## 做什麼
- BattleController：玩家每次部署成功後，以我方主將模板加上在場我方部隊的虎符來源武將模板，用 `detectRelationEvents`（scene: battle）比對史實配對表。
- 同一場戰役同一事件同一對只觸發一次（每場一份記憶體帳本，戰役結束即丟）。
- 新命中時送出 `EVENT_NAMES.RelationEventTriggered`（payload：turn、hit），並保留在 `relationEventHits` 供戰後讀取。

## 不做什麼
- 戰報或 toast 顯示：i18n 的 LORE_REL_EVENT_FAMOUS_MATCH 字串寫死「周瑜與小喬」，套到其他配對會錯，需另定文案。
- 不改 RelationEvents.ts（PR #1194 正在改帳本存檔）。
- 事件的數值效果（爆發力提升）規格沒給數字。

## 驗收
- 單元測試：主將與虎符來源命中結義觸發一次、重複部署不重播、無配對表或無關係不觸發、敵方部隊不計入。
- 全套測試、tsc、compute-gate standard。

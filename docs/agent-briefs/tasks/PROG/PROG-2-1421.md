# [PROG-2-1421] 戰場關係事件寫進戰報，名將契合改通用文案

## 為什麼做
PROG-2-1420 已在部署時送出 RelationEventTriggered，但戰報沒有顯示；LORE_REL_EVENT_FAMOUS_MATCH 寫死「周瑜與小喬」，套到其他夫妻會錯。使用者 2026-10-28 裁定改為通用文案「{0}與{1}，天作之合！」。

## 做什麼
- 四語系 LORE_REL_EVENT_FAMOUS_MATCH 改為帶兩個名字佔位的通用文案。
- 名字解析放在 RelationEventLogText：我方主將用戰場上的名字，其餘查 generals-index（uid → name），查不到退回 id。
- 不改 BattleScene（BAT-1-0001 鎖住）與 BattleController。
- BattleUIBridge 收到事件時以 i18n 組字寫一行戰報。

## 驗收
- 單元測試：名字帶入 payload、文案組字（名將契合帶名字、義兄弟合攻不帶）、查不到名字退回 id。
- 全套測試、tsc、compute-gate standard。

# [PROG-2-1430] D-4 加權總表改由工具重算

## 為什麼做
cross-ref-進度 D-4 加權總表（38%）停在 2026-04-12，每份規格書的狀態（🟢／🟡／🔴）是人工判定，工具不會重算；D-1 五欄表除「尚無實作」列外，接線與測試欄也不會隨程式更新。

## 做什麼
- `build-progress-matrix.js` 五欄模式：每列依「對應代碼檔」重算接線、測試欄（代碼檔不存在時邏輯欄降級）；保留代碼欄的註記文字。
- 新增 D-4 重算：依 D-1 五欄推出每份規格書狀態（邏輯／接線／測試全 ✅ = 🟢；有代碼 = 🟡；無代碼 = 🔴；名詞表類 = 🔷），套原加權公式（核心 ×3／UI ×2／其他 ×1）重寫加權總表、狀態分布表、計算日期與 D-5 當日一列。
- 分類（核心／UI）寫成腳本頂端的資料表，不寫死在流程裡。
- `--check` 時加權數字有落差也回傳 1。

## 不做什麼
- 不判定「邏輯」欄是否全部落地（規格條目逐條比對無法自動化，維持既有標記）。
- runtime 驗收欄仍需登記 headless／Playwright 證據才標 ✅。

## 驗收
- 重跑工具兩次結果相同（可重複執行）；`--check` 回傳 0。
- compute-gate standard 通過。

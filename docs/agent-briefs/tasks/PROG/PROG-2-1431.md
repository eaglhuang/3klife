# [PROG-2-1431] 天下沙盤側邊挑戰賽賽季卡（tournament-season-card）

## 為什麼做
UI 規格補遺 (doc_ui_0030) `tournament-season-card` 定位為「世界沙盤側邊次卡」，內容：本季盃賽名稱、主地形、主天氣、剩餘天數、已登錄快照狀態。cross-ref-進度 D-3 記為「世界沙盤側卡未另做」。

## 做什麼
- TournamentPanelController 抽出 `tournamentSeasonCardLines`（屆次／盃名／階段／剩餘天數、地形天氣、報名快照），挑戰賽彈窗與沙盤側卡共用同一套文字。
- 天下沙盤彈窗右側加一張 360 寬的次卡，沿用沙盤彈窗 skin slot，不新增美術。
- LobbyScene 開沙盤時帶入本季狀態。
- D-3 更新：賽季卡改 ✅；經濟補貼提示的規格定位是「資源列或許願祭壇附近」，許願祭壇已做，註記為已滿足。

## 不做什麼
- 不在側卡展開完整賽制、報名或參戰（規格限制：只做導覽）。

## 驗收
- 單元測試：文字與路徑；全套測試、tsc、validate-ui-specs、compute-gate standard。
- 未做 runtime 截圖驗收。

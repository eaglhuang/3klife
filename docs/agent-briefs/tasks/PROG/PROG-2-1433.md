# [PROG-2-1433] 虎符數值型被動：解煩、丹陽、吳國

## 為什麼做
PROG-2-1432 重判兵種（虎符）系統 (doc_spec_0012)：「特殊兵種列表」34 條特殊戰法中 20 條仍是 `pendingEffect` 殼。其中解煩、丹陽、吳國三條是單純數值加成，可用既有 TallyPassive 掛點落地。

## 做什麼
- TallyPassiveSpec 加 `attackMultiplier`、`attackTerrains`、`terrainMoveBonus`（地形條件可選，資料寫在表裡，不寫死在流程）。
- 解煩（突擊步兵）：移動 +2、攻擊 +20%，不限地形。
- 丹陽（山地特化）：站在山地時移動 +2、攻擊 +20%。
- 吳國（水域特化）：站在河道時移動 +2、攻擊 +20%。
- 攻擊加成接 `BattleCombatResolver.getTallyAttackMod`（普攻、援護、反擊共用）；地形移動加成接 `BattleAutoMovePhase`（與林地加成同處）。
- 模板 id 沿用規格表 tacticId（同龍膽符做法）；三種虎符尚無卡片模板，玩家目前拿不到，屬已知缺口。
- D-1a 缺口清單同步。

## 不做什麼
- 不新增虎符卡片模板與產出（另卡）。
- 不移除對應的 `pendingEffect` 技能殼（效果以被動實作，與白馬相同）。

## 驗收
- 單元測試：三種被動的移動與攻擊乘數、地形條件；全套測試、tsc、compute-gate standard。

# [PROG-2-1434] 紅顏趕路文案接線（COPY-04，travel／countdown）

## 範圍
- RedFaceCopy.ts：redFaceTravelCopy（純邏輯）。開場趕路倒數（OPEN-11，目標 zhen-ji）進行中才回傳 travel 段落（段落間空一行）與 countdown 段落；到點、非開場倒數、沒有倒數都回傳 null。
- RedFaceShowcaseController.ts：可選依賴 travelCopy；選中的紅顏是趕路目標（甄姬／甄宓別名）時，詳情區改顯示趕路文案。未提供依賴時行為與舊版相同。
- LobbyScene.ts：讀取 data/copy/red-face-copy 並解析；解析失敗只列警告，不擋畫面。
- 測試：tests/RedFaceCopy.test.ts 新增趕路狀態四條分支。

## 暫定決策
1. 趕路文案顯示在紅顏展示的詳情區（detailLine＝趕路段落，detailMeta＝倒數提示），不新增 layout 節點。
2. 趕路段落三段以空行串成一段文字；長度風險交給版位檢查。
3. 常駐倒數圖示與剩餘時間格式化不在本卡範圍（規格 4.3 留存設計，另卡處理）。

## 不在範圍
- 價格段落（price099、price2999）：等商店付費 UI。
- 諸葛亮七天倒數：需要購買狀態。
- 戰場關係事件顯示 UI（另一張卡）。

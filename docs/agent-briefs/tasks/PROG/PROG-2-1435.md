# [PROG-2-1435] 戰場關係事件 Toast 顯示

## 為什麼做
PROG-2-1421 已把戰場關係事件寫進戰報，但戰報在紀錄列裡，玩家在部署時不一定看得到。觸發當下需要一條即時提示。

## 做什麼
- BattleUIBridge `_onRelationEventTriggered`：組好的戰報文字同時送 `deployRuntime.showToast`，顯示 2.5 秒。
- 戰報與 Toast 用同一句文字，不另外寫字串。

## 暫定決策
1. Toast 沿用既有 deployRuntime 通道，不新增 layout 節點。
2. 顯示時間 2.5 秒，比照戰場其他短提示的寫法（1.2–1.5 秒偏短，長句需要更久）。
3. 規格未定 Toast 樣式，採預設色。

## 不在範圍
- 關係事件的數值效果（規格沒給數字）。
- 戰後結算畫面的關係事件列表。

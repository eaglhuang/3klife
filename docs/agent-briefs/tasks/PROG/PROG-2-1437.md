# [PROG-2-1437] 虎符被動：止啼符、藤甲

## 為什麼做
PROG-2-1432 重判兵種（虎符）系統 (doc_spec_0012)，PROG-2-1433 後仍有 17 條特殊戰法是 `pendingEffect` 殼。止啼符（後排 +50%）與藤甲（物理減傷 50%、火攻 ×3）是傷害乘數，可用既有掛點落地。

## 做什麼
- TallyPassiveSpec 加 `backRowDamage`、`physicalDamageTaken`、`fireDamageTaken`（數字寫在資料表）。
- 止啼符：目標站在其陣營後排兩列（我方 depth 0–1、敵方最後兩列）時，部隊攻擊傷害 ×1.5。
- 藤甲：承受部隊攻擊（普攻、合攻、反擊）傷害 ×0.5；承受帶 `fire` 標籤的戰法傷害 ×3。
- D-1a 缺口清單同步。

## 不做什麼
- 不新增虎符卡片模板（另卡）；不移除 `pendingEffect` 技能殼。

## 驗收
- 單元測試：後排判定兩陣營、藤甲物理與火計乘數；全套測試、tsc、compute-gate standard。

# [PROG-2-1439] Utility AI 行為選擇與登入窗限流（NPC-05）

## 範圍
- NpcUtilityAi.ts（純 TS）：
  - scoreNpcAction：eventWeight × personalityWeights[actionType] × relationshipModifier × moodModifier × cooldownModifier，權重缺項回傳 0。
  - selectNpcAction：候選中取分數最高且大於 0 的一項，全部為 0 回傳 null。
  - NpcInteractionLimiter：同一武將同一登入窗只允許 1 則高權重互動（規格 F-1 第 3 點），低權重不受限，換登入窗重算。
- 測試：tests/NpcUtilityAi.test.ts，5 條。

## 暫定決策
1. 個性權重表由呼叫端傳入，不寫進 NpcPersonaCard（規格沒有定義權重欄位，也沒有數字）。
2. 高權重門檻暫定 0.5（NPC_HIGH_WEIGHT_THRESHOLD），規格未給數字。
3. 行為名稱採泛型，不先鎖定列舉，等 F-1 的行為清單定案再收斂。

## 不在範圍
- 把 selectNpcAction 接到大廳或事件的呼叫端（待 NPC 對話面板與事件來源）。
- 主動互動的 UI 顯示與台詞（NPC-07/08）。

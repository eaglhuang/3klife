# [PROG-2-1441] 移除 SMART 兵種入口，統一參謀官／後勤官稱謂（TSK-01）

## 為什麼做
武將裝備道具系統實作任務清單 §0 前置共識：移除 `SMART` 兵種在正式出征與 UI 顯示中的所有入口，並統一支援職稱為 `參謀官`／`後勤官`。

## 做什麼
- `AiProfiles.ts`：`AI_TROOP_CODES` 移除 `SMART`；AI 部署兵種偏好資料再填 `SMART` 會被解析器擋下。
- `AiDeployTroopPick.ts`：註解同步（SIEGE、NAVY 不在 AI 可部署範圍）。
- 職稱：盤點後 UI 字串（`SortieSetupController`、`SortieDeploy` 相關畫面文字）已是 `參謀官`／`後勤官`，沒有 `副將` 或 `參謀` 單獨作為正式用語，本卡不改動。

## 不做什麼
- 不改 `SIEGE`、`NAVY` 的代碼與規格，它們仍不在 AI 可部署範圍。
- 不改程式註解內的「參謀」簡稱（非 UI 字串）。
- 不動英靈卡光效與家族共鳴等其他 §0 條目，那些另有任務。

## 驗收
- `AiProfiles.test.ts` 新增 SMART 被擋案例，全測試 ALL PASS。
- `tsc -p tsconfig.test.json --noEmit` 錯誤數 0。
- `compute-gate.js --profile standard --agent-feedback` 全綠。

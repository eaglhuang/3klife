# [PROG-2-1442] 武將日誌／晨報字串與劇本文案落地（JRN-07）

## 為什麼做
武將日誌與離線互動系統規格 §H 列出 9 個 UI key，§G 列出 5 句劇本文案。現行這些字串只以常數寫死在核心模組（`MorningReport.ts`、`DispatchQuality.ts`、`OfflineInteractionEvents.ts`），i18n 沒有對應 key，切語系時無法替換。

## 做什麼
- `zh-TW.json`、`en.json`、`ja.json` 各加 14 個 key：
  - §H 的 9 個：`UI_JOURNAL_TITLE`、`UI_MORNING_REPORT_TITLE`、`UI_DISPATCH_BOARD_TITLE`、`UI_OFFLINE_INTERACTION_TITLE`、`UI_OFFLINE_BATTLE_SNAPSHOT`、`UI_JOURNAL_EMPTY`、`UI_MORNING_REPORT_EMPTY`、`UI_DISPATCH_COMPLETE`、`UI_DISPATCH_QUALITY`。
  - §G 的 5 句：`UI_JOURNAL_STORY_MORNING_OPENING`、`UI_JOURNAL_STORY_DISPATCH_DONE`、`UI_JOURNAL_STORY_OFFLINE_INTERACTION`、`UI_JOURNAL_STORY_OFFLINE_SUPPORT`、`UI_JOURNAL_STORY_LOG_REVIEW`。
- 佔位符改用 i18n 的編號格式：`{GeneralName}`→`{0}`、`{JobName}`→`{1}`、`{RewardText}`→`{2}`、`{GeneralA}`→`{0}`、`{GeneralB}`→`{1}`。
- `tests/JournalStringsI18n.test.ts`：三語非空、佔位符編號與 zh-TW 相同、zh-TW 的 G 章文案與核心常數逐字相同。

## 不做什麼
- 不改核心模組的常數，也不把 UI 接到 i18n；接線另案（核心是純 TS，不依賴 cc）。
- 不補 zh-CN：與 NPC-09 相同做法，待語系審閱時一併補。
- 英文與日文譯文是草稿，待語系審閱。

## 驗收
- 新測試通過；全套 ALL PASS。
- `tsc -p tsconfig.test.json --noEmit` 錯誤數 0。
- `compute-gate.js --profile standard --agent-feedback` 全綠。

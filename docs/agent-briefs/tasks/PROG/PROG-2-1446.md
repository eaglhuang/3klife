# [PROG-2-1446] 三國日報登入面板：文字接 i18n 與完整接線（RET-06）

## 為什麼做
RET-06 要求登入後彈出日報，顯示標題與日期、各事件字串，並標記已讀。擷取、彈窗掛載、已讀標記、復仇按鈕已經在前幾張接好，但面板上的標題、分區標題與按鈕仍是寫死的中文，切語系不會變。

## 做什麼
- 新增 `ui/core/DailyReportTexts.ts`：面板文字查表，支援 `{0}` 參數；缺譯文退回 zh-TW 預設。
- `DailyReportController.capture` 接受可選的查表參數；標題改由查表組出（日期帶入 `YYYY-MM-DD`，與核心標題格式一致）；面板 chrome 文字走查表。
- `LobbyScene._showDailyNews` 傳入 `services().i18n.t`。
- 三語 JSON 新增 6 個 key：`UI_DAILY_NEWS_TITLE`（規格 §H）、`UI_DAILY_REPORT_NEWS_HEADER`、`UI_DAILY_REPORT_MORNING_TITLE`、`UI_DAILY_REPORT_OPEN_HUB`、`UI_DAILY_REPORT_REVENGE`、`UI_DAILY_REPORT_CLOSE`（後五個為暫定）。

## 不做什麼
- 事件內文（復仇、代勞、切磋、特訓、八卦）仍由核心 `DailyNewsEngine` 用 zh-TW 插槽模板組成。要做成多語，需要先讓插槽引擎回傳 key 加參數，另卡處理。
- 規格 §G「三國日報頭條」的括號記號不入譯文（與 PROG-2-1442 的修正一致）。
- zh-CN 不補（與前卡相同）。

## 驗收
- 新測試：查表有譯文用譯文、缺 key 退回預設、日期參數正確、zh-TW.json 與預設一致、控制器走查表、不傳查表時與原本相同。
- 全套 ALL PASS；`tsc -p tsconfig.test.json --noEmit` 與 `tsc -p tsconfig.cc-check.json --noEmit` 錯誤數 0；`compute-gate.js --profile standard --agent-feedback` 全綠。
- cc 實機驗收（登入面板畫面與文字寬度）待 Codex，標 in-review。

# [PROG-2-1449] 兵頁適性列與子面板呼叫端（TSK-05 第一段）

## 為什麼做
人物頁「兵」頁的 `CharacterDs3AptitudeChild` 還是空殼，onDataUpdate 沒有任何實作。PM 指示：純邏輯與子面板接線放同一張 PR，讓空殼子面板成為呼叫端。

## 做什麼
- `core/systems/AptitudeView.ts`：`buildAptitudeView(troopAptitude, tallyLine)`，兵種列只取武將有的兵種，順序沿用 `AI_TROOP_CODES`；等級 S～D 的效率文字沿用 `BATTLE_POWER_CONSTANTS.APTITUDE_EFFICIENCY`；非法等級顯示「—」。
- 地形（6 列）與天氣（6 列）目前沒有資料欄位，全部「—」。
- `CharacterDs3AptitudeChild.onDataUpdate` 收到武將資料後呼叫 `buildAptitudeView`，結果由 `view` getter 讀取。

## 不做什麼
- 地形與天氣的資料來源、虎符槽的裝備操作與虎符摘要、五段 layout 與 cc 畫面綁定、戰鬥定位：依 PM 指示分段另卡。
- 中文名（騎兵、機械、水軍等）為暫定，規格未定字串 key。

## 驗收
- `tests/AptitudeView.test.ts`：兵種列篩選與順序、倍率對應、非法等級、地形與天氣占位、虎符槽預設、子面板收到資料後更新 view、非物件資料不拋錯。
- 全套 ALL PASS；兩個 tsc 錯誤數 0；compute-gate standard 通過。
- cc 實機驗收待 Codex，標 in-review。

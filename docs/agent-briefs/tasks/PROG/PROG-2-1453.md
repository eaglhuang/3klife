# [PROG-2-1453] 奧義升級等級不設上限

## 為什麼做
PROG-2-1451 讓奧義升級等級進戰鬥傷害，但規格未寫上限，暫以 5 計。使用者裁定（2026-10-28）：不設上限，傷害公式跟著放寬。

## 做什麼
- `ultDamage` 的 ult_level 只要求整數 ≥ 1，不再限制 ≤ 5；槽位（base_power 查表）仍限 1~5。
- `battleUltLevelOf` 不再截到 5。

## 驗收
- 單元測試；全套測試、tsc、compute-gate standard。

# [PROG-2-1459] 火燒偷襲戰：我方火抗 +50%

## 為什麼做
戰法場景規格書 (doc_spec_0039) B-3 火燒偷襲戰特殊規則「我方火抗 +50%」沒有代碼（PROG-2-1458 重判缺口 3）。

## 做什麼
- 火攻場景（BattleTactic.FireAttack）中，我方（發動場景戰法的玩家陣營）承受火焰傷害 ×0.5：火焰格每回合傷害、火系戰法傷害。
- 行為表新增可選掛鉤 `getFireDamageTakenMultiplier`，其他場景回 1。

## 不做什麼
- 擊破落石／掠奪敵營掉落（另開卡）。

## 驗收
- 新測試覆蓋火格傷害與火系戰法傷害；全測試 ALL PASS；tsc 0；compute-gate standard。

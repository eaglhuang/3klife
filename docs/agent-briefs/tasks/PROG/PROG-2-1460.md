# [PROG-2-1460] 天氣強約束：遠程命中與遠程射程

## 為什麼做
戰場適性系統 (doc_spec_0041) §天氣對戰法與機制的強約束是天氣影響的唯一真相來源，其中「遠程攻擊命中」（雨 -20%、霧 -30%、夜 -25%）與「遠程射程」（大風 -2）兩列沒有代碼；目前只有適性等級的命中修正。

## 做什麼
- WeatherTacticRestriction 新增 `weatherRangedHitDelta`、`weatherRangedRangeDelta`。
- BattleCombatResolver：遠程（基礎射程 > 1）攻擊的命中加上天氣修正；有效射程加上大風修正（最少 1 格）。
- 暫定（可逆）：夜襲場景已有全局命中 -25%，夜戰天氣的遠程命中修正不再疊加。

## 不做什麼
- 天氣適性表的士氣、機械故障／損毀、視野 -3 格（另案）。
- 技能施放射程（dispatcher 的 casterRangeCap）。

## 驗收
- 新測試覆蓋四種天氣命中、近戰不受影響、大霧免疫仍必中、大風射程；全測試 ALL PASS；tsc 0；compute-gate standard。

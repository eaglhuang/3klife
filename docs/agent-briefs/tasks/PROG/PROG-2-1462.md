# [PROG-2-1462] 火燒偷襲戰掠奪寫入 Stage_Salvage

## 為什麼做
戰法場景規格書 (doc_spec_0039) B-3 火燒偷襲戰「我軍佔領火焰格 = 掠奪成功，糧草 +200~500」沒有代碼（PROG-2-1458 重判缺口 3）。關卡設計系統 (doc_spec_0049) §I 規定互動物件收益先寫入關卡級 `Stage_Salvage`（石材／木材／補給／情報），戰鬥結束一次結算，戰中不改帳號經濟。

## 做什麼
- 新增 StageSalvage.ts：空累計、加總、火攻掠奪補給擲骰（200~500）。
- BattleState 新增 `stageSalvage` 與已掠奪格集合，開局重置。
- BattleTileEffectPhase：火攻場景我方回合結束時站在火攻格（scene-gambit:fire-attack）視為佔領，每格掠奪一次，補給累加。
- BattleEnded 事件帶出 `salvage` 快照，供戰後摘要使用。

## 不做什麼
- 武器材料 +10、教官經驗 +20（Stage_Salvage 沒有這兩類，待裁定）；擊破落石（機制未定義）。
- 戰後彈窗顯示與帳號經濟入帳；金色浮動文字。

## 驗收
- 新測試覆蓋佔領掠奪、每格一次、敵方不掠奪、非火攻場景不掠奪、BattleEnded 帶出；全測試 ALL PASS；tsc 0；compute-gate standard。

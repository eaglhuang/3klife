# [PROG-2-1463] AI 部署依 Profile 路線策略選路

## 為什麼做
AI武將強度系統 (doc_data_0002) E-4「路線選擇」表已轉成 ai-profiles.json 的 laneStrategy（PROG-2-1316），但戰鬥沒有載入，EnemyAI 部署仍隨機選路；E-6 武將模板對應的 Profile 也沒有資料。

## 做什麼
- 新增 AiLaneStrategy.ts：依策略從空的部署線挑一條（純邏輯）。
- ai-profiles.json 新增 generalProfiles（E-6 九位武將 → Profile），AiProfiles 解析與查詢。
- 建立敵將時（BattleSceneLoader.createGeneral）掛上路線策略；BattleController.initBattle 交給 EnemyAI；沒有策略時維持隨機。

## 挑線細則（使用者確認 2026-10-28，記錄於 PROG-2-1464）
- FOCUS_2_3：集中中央 3 路（1~3），路內挑己方最少的線。
- SPREAD_5／ALL_5：挑己方部隊最少的線。
- SCOUT_WEAK：挑玩家部隊最少的線。
- CAVALRY_CHARGE_1：挑己方部隊最多的線（開局中央），不空就挑最近的空線。
- EMPTIEST_1_2：挑雙方部隊總數最少的線。
- 同分隨機。

## 不做什麼
- 戰法使用決策、AI 虎符選擇（E-6b）、出場台詞。

## 驗收
- 新測試覆蓋六種策略與 EnemyAI 接線；全測試 ALL PASS；tsc 0；compute-gate standard。

## 挑線細則（使用者確認 2026-10-28）
每次部署只從空的部署線挑一條，同分隨機。
- AGGRESSIVE（FOCUS_2_3）：只在中央 3 路（1~3）挑己方部隊最少的線；中央沒空線才挑其他空線。
- DEFENSIVE（SPREAD_5）、SWARM（ALL_5）：挑己方部隊最少的線。
- STRATEGIC（SCOUT_WEAK）：挑玩家部隊最少的線。
- CAVALRY_RUSH（CAVALRY_CHARGE_1）：挑己方部隊最多的線（開局中央），不空就挑最近的空線。
- ELITE_FEW（EMPTIEST_1_2）：挑雙方部隊總數最少的線。
- 未列出的 Profile：隨機。

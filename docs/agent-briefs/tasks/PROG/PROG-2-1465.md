# [PROG-2-1465] 因子揭露順序改照因子爆發系統 §K

## 為什麼做
兩份規格衝突：因子解鎖系統 (doc_spec_0009) §F 為「藍粉 → +綠白 → +紫紅」，因子爆發系統 (doc_spec_0010) §K 為「藍粉綠 → +白紅 → +紫」。程式照 §F。使用者 2026-10-28 裁定以 §K 為準。

## 做什麼
- FACTOR_DISCOVERY_LEVEL：綠 20→1、紅 45→20（Lv 門檻 20/45 不變）。
- UnlockPhase.phaseFactorColors 改由 FACTOR_DISCOVERY_LEVEL 推導，不再另寫一份顏色表。
- DiscoveryThresholds、FactorAwakening 的「第二階段代表色」由綠改白。
- 因子解鎖系統 (doc_spec_0009) §A §B §F §H §I 同步改成 §K 順序。
- 測試跟著改。

## 不做什麼
- 不改 Lv 門檻、不改覺醒途徑表、不改 generals.json 個別因子自帶的 discoveryLevel。

## 驗收
- 全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

# [PROG-2-1466] 敵方戰法依 AI 智力分級（AI_UseTactic）

## 為什麼做
AI武將強度系統 (doc_data_0002) E-4「戰法使用決策」分低／中／高 IQ 三種行為，現行敵方選技（PROG-2-0918）不分 IQ，一律用情境打分；難度表 canUseTactics 也沒有讀。

## 做什麼
- 新增 AiTacticDecision.ts：低 IQ 30% 才出手且隨機挑戰法；中 IQ 挑預估傷害最高的戰法；高 IQ 以上沿用 TacticAiRules 打分。
- BattleState 加 aiTacticIq（未套難度表為 null，沿用既有打分）與 aiCanUseTactics；configureAiDifficulty 寫入。
- BattleController.chooseEnemyTactic 依 IQ 選技；新增 shouldEnemyHoldTactic；敵方特殊階段先問要不要出手。

## 暫定（可逆）
- EXTREME、PERFECT 與 HIGH 同規則（同 AiUltimateDecision）。
- 「TP 夠」沿用既有門檻（敵將 SP 滿才選技）。
- 中 IQ 沒有可估傷害的戰法、或低 IQ 抽中但沒有戰法槽時，退回武將主技能。
- 低 IQ 本回合不出手時 SP 保留，下回合再抽。

## 不做什麼
- 不改 TacticAiRules 打分數字；不做高 IQ 的 AOE／控制技細分（現行候選只有單體傷害、增益治療、地形場景三類）。

## 驗收
- 新測試覆蓋三種 IQ、canUseTactics 與回合接線；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

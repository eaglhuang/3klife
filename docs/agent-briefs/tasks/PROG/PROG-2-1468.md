# [PROG-2-1468] AI 部署兵種依智力與 Profile 偏好（AI_Deploy）

## 為什麼做
AI武將強度系統 (doc_data_0002) E-4「部署決策」：IQ ≥ NORMAL 才分析玩家兵種選剋制，否則依 Profile 偏好兵種隨機選。現行 EnemyAI 不分 IQ，一律 35% 機率剋制、否則全兵種隨機；ai-profiles.json 的 preferredTroops／preferCounter 沒有使用。

## 做什麼
- 新增 AiDeployTroopPick.ts：低 IQ 不剋制；其他 IQ 有剋制兵種時，preferCounter 的 Profile 必定剋制、其餘沿用 35% 機率；否則從 Profile 偏好兵種隨機挑，沒有偏好或都買不起時全兵種隨機。
- AiProfiles 加 deployPreferenceOfGeneral；GeneralUnit 加 aiDeployPreference；BattleSceneLoader 建敵將時填入。
- EnemyAI 加 iq／deployPreference；BattleController.initBattle 交付偏好、configureAiDifficulty 交付 IQ。

## 暫定（可逆）
- 「IQ ≥ NORMAL 剋制」沿用既有 35% 機率（AI_COUNTER_STRATEGY_CHANCE），只有 preferCounter（STRATEGIC）必定剋制。
- 未套難度表（IQ null）沿用既有行為。
- 兵種代碼對照：CAVALRY→騎、INFANTRY→步、SHIELD→盾、PIKE→槍、ARCHER→弓；SIEGE、SMART、NAVY 不在 AI 可部署兵種內。

## 不做什麼
- 虎符特殊兵種（AI 虎符池未定）、preferLowQuality／preferSpecialTroops（目前無品質分級可選）。

## 驗收
- 新測試；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

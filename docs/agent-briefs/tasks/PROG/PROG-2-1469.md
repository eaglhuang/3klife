# [PROG-2-1469] 敵將發動戰法／奧義的戰報文案（G-2）

## 為什麼做
AI武將強度系統 (doc_data_0002) G-2 難度提示文案規定：
- AI 使用戰法：「敵將 {名} 發動戰法——{戰法名}！」
- AI 使用奧義：「危急！敵將 {名} 發動奧義——{奧義名}！全軍戒備！」

現行戰報對敵方一律顯示「敵方戰法【分類】：名稱」，沒有敵將名字，也沒有奧義警示。

## 做什麼
- BattleSkillPresentation.buildBattleSkillUsedMessage 加選用參數 generalName；敵方且有名字時改用 G-2 文案。
- 敵方自動戰法（BattleSpecialResolvePhase）與敵方奧義（BattleController）的 GeneralSkillUsed 事件帶上敵將名字。
- BattleUIBridge 把名字交給文案函式。

## 不做什麼
- G-1 出場台詞與「進入困難關卡」提示：顯示點在 BattleScene，目前被 BAT-1-0001 鎖住，另開卡。
- 我方戰報文案不變；事件沒帶名字時沿用舊格式。

## 驗收
- 新測試；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

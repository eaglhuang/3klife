# [PROG-2-1470] AI 出場台詞、困難提示與戰鬥記錄 Schema（AIS-14）

## 為什麼做
AIS-14 的敵將發動戰法與奧義戰報已由 #1280（PROG-2-1469）完成。剩下的是 G-1 出場台詞、G-2 困難關卡提示，以及 battle_ai_log 的 Server 定義。

## 做什麼
- `AiEntranceLines.ts`（純邏輯）：八個 AI 模板台詞依敵將 id 查表；`hardEncounterHintOf` 判斷困難提示；`openingAiLogLinesOf` 組出開戰文案。
- `BattleScene.ts`、`BattleSceneFlow.ts`：開戰與重開時把開戰文案寫進戰報，與既有的自適應提示同一位置。
- `server/schema/009_battle_ai_log.sql`：battle_ai_log 表定義，只定義、不部署、不執行。
- `server/schema/ai14-row-validators.ts`：難度與結果列舉、自適應倍率 0.7~2.5、非負整數欄位檢查。

## 暫定（可逆）
- 困難關卡提示以 HARD 以上（困難、噩夢、地獄）顯示；規格只寫「困難關卡」，沒寫門檻。
- 出場台詞在戰報中以「敵將名：台詞」呈現。

## 不做什麼
- 不改戰法與奧義戰報（#1280 已做）。
- 不寫入實際資料庫，不接 Server。
- 戰報與台詞的實機顯示未驗證，需 Codex 驗收。

## 驗證
- `npx tsc -p tsconfig.test.json --noEmit` 錯誤數 0。
- 全套件 4906 通過、3 skipped。

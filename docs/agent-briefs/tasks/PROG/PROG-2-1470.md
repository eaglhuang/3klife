# [PROG-2-1470] HARD 以上敵將只在有利時發起單挑（E-7）

## 為什麼做
AI武將強度系統 (doc_data_0002) E-7：「HARD+：真實評估，且會在有利時主動發起」。現行敵將只要推進到我將面前就一定發起單挑，不分難度、不看局勢。PROG-2-1322 把這項留作另開卡。

## 做什麼
- AiDuelDecision 新增 aiShouldInitiateDuel(iq, defenderScore)：LOW／MEDIUM／未套難度表一律發起（維持現行）；HIGH 以上只在我方（防守方）單挑分數 ≤ 0.5（敵方佔優）時發起。
- BattleController 加 shouldEnemyInitiateDuel()，以 duelFlow.evaluateDuelAcceptance(Enemy).score 判斷（玩家防守的評估不吃亂數）。
- TurnFlowManager.checkDuelChallenge：敵將面前判定同時要求 shouldEnemyInitiateDuel；不發起時單挑未結算，之後回合局勢轉為有利仍可發起。

## 暫定（可逆）
- 「有利」= 我方防守分數 ≤ 0.5（AI_DUEL_INITIATE_MAX_DEFENDER_SCORE），即敵方在 HP、兵力、戰力加權上不輸。
- 「主動發起」仍以推進到我將面前為前提，不另做遠距發起。

## 不做什麼
- 我方發起與敵方接受判定不變。

## 驗收
- 新測試；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

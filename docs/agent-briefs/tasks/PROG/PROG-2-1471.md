# [PROG-2-1471] AI 特殊兵種戰力與 AI 戰力評估公式（E-2b、F-1）

## 為什麼做
AI武將強度系統 (doc_data_0002) E-2b「AI_SpecialTroopPower」與 F-1「evaluateAIPower」及難度匹配（±20%）在程式中沒有對應實作，E-9 回合結束重算與 AI 匹配都依賴它們。

## 做什麼
- 新增純邏輯 AiPowerEvaluation.ts：
  - aiGeneralStatBonus：依兵種取主／副屬性（STAT_MAPPING），(主×0.7＋副×0.3)/1000。
  - aiSpecialTroopPower：兵種基礎攻防 × 品質 × (1＋星×0.08) × 屬性修正（防禦取一半）× 適性 × 共鳴 1.1，floor。
  - evaluateAiPower：六圍總和＋(特殊兵種攻＋防)×2＋戰法 TP×10＋轉生×2000＋年齡修正×1000。
  - aiPowerMatchDiff／isAiPowerMatched：|AI−玩家|/玩家，NORMAL 容許 0.2。
- 品質、星級、適性、共鳴、年齡常數一律讀 BattlePowerRating.BATTLE_POWER_CONSTANTS，不另寫數字。

## 暫定（可逆）
- 適性缺值視為 B（與 AiTallySelection 一致）。
- 玩家戰力 ≤ 0 時差距視為 Infinity（不匹配）。

## 不做什麼
- 不接戰場或 E-9 回合重算（AI 國家／武將池模型尚未建立）；不調整縮放倍率。

## 驗收
- 新測試；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

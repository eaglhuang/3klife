# [PROG-2-1472] 霸權判定與反霸權同盟（他國 AI E-8、F-4、F-5）

## 為什麼做
治理模式他國AI系統 (doc_spec_0020) E-8「霸權反制與橡皮筋同盟」與 F-5「反霸權同盟觸發」沒有實作；F-4 的衰減速率目前固定 2（RivalNations.RELATION_DRIFT），沒有霸權壓力下加速的分支。

## 做什麼
- 新增純邏輯 RivalHegemony.ts：
  - domainRatioOf：勢力領土 ÷ 全部領土。
  - findHegemon：佔比 ≥ 30% 的勢力（多個時取佔比最高、同分取先出現者），沒有回 null。
  - shouldStartCoalition（≥ 0.30）、shouldApplyRebellionPressure（≥ 0.40）。
  - coalitionStateOf：有霸主且自己不是霸主 → FORCED_MEMBER、衰減速率 4；否則不在聯盟、速率 2。
  - decayRelation(value, rate)：向 0 回歸、不越過 0。

## 暫定（可逆）
- 多個勢力同時過 30% 時只取佔比最高者為霸主。
- 全部領土為 0 時佔比為 0。

## 不做什麼
- 不改 RivalNations.advanceRivalSeason：MVP 只記「勢力 ↔ 玩家」邦交，聯盟成員間的邦交與玩家領土計入方式需使用者決定，另開卡接線。

## 驗收
- 新測試；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

# [PROG-2-1473] 他國 AI 擴張決策與軍事任務品質（E-4、F-2、E-11、F-6）

## 為什麼做
治理模式他國AI系統 (doc_spec_0020) E-4「AI 擴張決策」、F-2「擴張效用函數」、E-11／F-6「軍師智力與軍事任務品質」在程式中沒有實作。現行 RivalNations.advanceRivalSeason 只依性格擲骰進攻玩家，不看兵力、糧草、目標效用。

## 做什麼
- 新增純邏輯 RivalExpansion.ts：
  - evaluateExpansionTarget（F-2）：0.30×min(2, 兵力比)＋0.20×min(1, 資源價值)＋0.20×min(1, 仇恨)＋0.15×邦交落差＋0.15×min(1, 情報)。
  - EXPANSION_WILLINGNESS、MIN_TROOPS_FOR_ATTACK 1500、FOOD_FOR_CAMPAIGN 3000、EXPANSION_ATTACK_SCORE 0.6。
  - evaluateExpansion（E-4）：兵力或糧草不足 → HOLD；擲骰超過意願 → HOLD；目標最高分 ≥ 0.6 → ATTACK，否則 HOLD。
  - militaryMissionTierOf（E-11：≥90 MASTER、≥70 ADVANCED）、missionIntelBandOf（F-6：≥90→3、≥70→2、≥50→1）。

## 暫定（可逆）
- 邦交落差採 F-2 公式 (100 − 邦交)/200；E-4 註解寫 (1 − 邦交/100)，兩者不一致，以公式節為準。
- RAIDER 規格寫 special，暫定意願 0.5。
- 同分目標取先出現者；沒有目標回 HOLD。

## 不做什麼
- 不改 advanceRivalSeason（勢力彼此交戰、領地相鄰關係尚未建模）。

## 驗收
- 新測試；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

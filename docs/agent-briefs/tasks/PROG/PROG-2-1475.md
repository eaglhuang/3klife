# [PROG-2-1475] 他國 AI 勢力興衰與時代更迭觸發（E-9、E-10）

## 為什麼做
治理模式他國AI系統 (doc_spec_0020) E-9「AI 勢力興衰」與 E-10「時代更迭」的判定在程式中沒有實作。

## 做什麼
- 新增純邏輯 RivalRiseFall.ts：
  - nationPowerScore：兵力＋武將數×200＋領地×500＋名聲。
  - nationStandingOf：>10000 HEGEMONY、>6000 STRONG、>3000 STABLE、>1000 DECLINING、其餘 COLLAPSING。
  - shouldEvaluateStanding：每 4 季評估一次。
  - NATION_STANDING_EFFECTS：HEGEMONY 他國敵對 +10／季；COLLAPSING 叛逃率 +20%、鄰國入侵機率 +50%。
  - shouldTriggerEraShift（E-10）：最強勢力佔比 ≥ 0.9，或玩家領地 ≤ 2 且連續崩潰 ≥ 3 季。

## 暫定（可逆）
- 「每年評估」以季數 % 4 === 0 判定（第 0 季也評估）。
- 叛逃率與入侵機率為加算值，基礎值由呼叫端決定。

## 不做什麼
- 不改 advanceRivalSeason、不實作包圍網事件與地圖重組。

## 驗收
- 新測試；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

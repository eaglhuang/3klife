# [PROG-2-1476] 他國 AI 外交決策與邦交事件變動（E-5）

## 為什麼做
治理模式他國AI系統 (doc_spec_0020) E-5 的邦交事件變動表與「AI 外交決策」（主動結盟、主動貿易、背叛、合縱連橫）在程式中沒有對應實作；RivalNations 只有玩家送禮／結盟／宣戰。

## 做什麼
- 新增純邏輯 RivalAiDiplomacy.ts：
  - RELATION_EVENT_DELTA：結盟 +30、貿易完成 +5、共同擊敗宿敵 +20、攻擊 -50、背叛結盟 -80、拒絕貿易 -5、入侵領地 -30；送禮 +10~+30（依禮物價值內插）。
  - HISTORICAL_RIVAL_INITIAL -30、HISTORICAL_ALLY_INITIAL +20。
  - applyRelationEvent：加總後夾在 -100~100。
  - aiDiplomacyIntents：
    - DIPLOMAT 且邦交 > 30、未結盟，擲骰 < 0.3 → 提議結盟。
    - 邦交 > 0、自身金 > 3000、對方糧 < 3000 → 提議以金換糧。
    - WARLORD 已結盟，對方兵 < 自身兵×0.5 且擲骰 < 0.4 → 背叛。
    - 最強國不是自己且兵力 > 自身×2，邦交 > -20 且未結盟 → 提議反霸權同盟。

## 暫定（可逆）
- 送禮變動以禮物價值 1000 黃金對應 +10、3000 以上 +30 線性內插。
- 擲骰只在條件成立時才消耗，與規格虛擬碼順序一致。

## 不做什麼
- 不改 advanceRivalSeason 與既有玩家外交 UI 的數值（RivalNations 送禮 +15 為玩家側既有規則）。

## 驗收
- 新測試；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

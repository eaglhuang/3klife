# [PROG-2-1477] 他國 AI 武將經營：結緣、退役、死亡、俘虜（E-7 其餘）

## 為什麼做
治理模式他國AI系統 (doc_spec_0020) E-7「AI 武將經營」中招募已由 PROG-2-1474 完成；結緣條件、退役、死亡結算（30% 流入傭兵市場）、俘虜招降／釋放規則仍未實作。

## 做什麼
- 新增純邏輯 RivalGeneralUpkeep.ts：
  - canAiStartBonding：有可配對組合且糧草 > 2000。
  - isRetirementCandidate：年齡 ≥ 65 且狀態 ACTIVE（是否真的退役由 shouldRetire 呼叫端決定）。
  - isGeneralDead：年齡 > 壽命上限或體力 ≤ 0。
  - shouldReleaseToMercenaryMarket：死亡結算時擲骰 < 0.3。
  - prisonerDecision：忠誠 < 30 且擲骰 < 0.5 → RECRUIT；否則俘虜超過 4 季 → RELEASE；其餘 HOLD。

## 暫定（可逆）
- 「死亡流入傭兵市場」依規格虛擬碼字面處理（實際上流入的是傳承資料，由接線端決定內容）。
- 擲骰只在條件成立時消耗。

## 不做什麼
- 不建 AI 武將池、不實作 selectBestPair 因子互補與英靈卡／虎符卡產出（另有正式死亡結算規則）。

## 驗收
- 新測試；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

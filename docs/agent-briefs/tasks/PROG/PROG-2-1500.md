# [PROG-2-1500] 登入面板晨報開場與條目接查表（RET-06 後續）

## 為什麼做
#1300 讓登入面板的標題與按鈕走查表，但晨報開場與條目仍是 zh-TW 字串。#1308 讓晨報條目帶上 key 與參數，現在可以接到面板。

## 做什麼
- `MorningReport.ts` 新增 `MORNING_REPORT_OPENING_KEY`。
- `DailyReportController.capture` 改由 `morningPanelLines` 組出晨報開場與條目：開場以 `journalSummaryText` 查 `UI_JOURNAL_STORY_MORNING_OPENING`，條目依 summaryKey／summaryArgs 取譯文；缺譯文退回 zh-TW。

## 不做什麼
- 日報條目（復仇、代勞、切磋、特訓、八卦）仍用核心 zh-TW 模板，需先 key 化插槽引擎，另卡。
- 離線互動開場（detail 仍是 zh-TW）另卡。

## 驗收
- `tests/DailyReportMorningKeys.test.ts`：有 key 走查表、參數照傳；無查表或舊條目退回 zh-TW；缺譯文退回；已讀與無條目不開面板；真實 GameSession 寫入、登入、存讀檔後面板取到譯文。
- 全套 ALL PASS；`tsc -p tsconfig.test.json --noEmit` 與 `tsc -p tsconfig.cc-check.json --noEmit` 錯誤數 0。
- cc 實機驗收（登入面板文字）待 Codex，標 in-review。

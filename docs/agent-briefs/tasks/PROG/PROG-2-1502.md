# [PROG-2-1502] 他國 AI 國家資源與季度內政結算接線（RAI-01、RAI-02、RAI-03 最小接線）

## 為什麼做
PM 裁定 (a)：先補 AI 國家的資料，讓季度內政結算有真實呼叫端。RivalGovernance.aiGovernanceTick 已存在但沒有呼叫端（資源欄位不在 NationState 內）。

## 做什麼
- NationState 新增選填 `resources`（糧、金、名聲、情報）；新局與讀檔缺漏時補 AI_STARTING_RESOURCES。
- RivalGovernance 新增 NATION_PRIMARY_TASK：每個性格取 E-2 內政偏好最高的一項（每季一名武將代表國家執行）。
- advanceRivalSeason 每季呼叫 aiGovernanceTick，糧／金／名聲／情報寫回 NationState。
- normalizeRivalWorld 讀檔補預設、夾在資源上限內。

## 暫定（可逆）
- 初始糧 300（同玩家新局 DEFAULT_SORTIE_FOOD）；金 5000（玩家錢包是 128450，但 AI 金幣上限 5000，取上限）；名聲、情報從 0 開始。
- 君主武將屬性尚無資料來源（RAI-08 之前），四項一律 60。
- 兵力：既有 PROFILE_TUNING 成長與 MILITARY 任務產出並存，待 PM 裁定是否合併。

## 不做什麼
- 不做武將招募、結緣、退役（RAI-08）。
- 不做 Server 持久化（RAI-14）。

## 驗收
- tests/RivalNationResources.test.ts：初始資源、主要任務對照、季推進產出與封頂、舊檔補值、超上限夾值、JSON 存讀往返。
- 全套 ALL PASS；tsc 兩組皆 0；compute-gate standard 11/11。

# [PROG-2-1503] 他國每 2 季招募（RAI-03 招募段，E-7、F-3）

## 為什麼做
PM 裁定：RAI-03 剩下的招募與分配。內政主要任務分配已在 PROG-2-1502 接線，本卡補招募。

## 做什麼
- `NationState.governedSeasons`：每季 +1。
- `NationState.recruits`：S／A／B／C 累計數量。
- 季數為偶數時，依季內政後的名聲擲一次品質（E-7 三段、F-3 機率）。

## 暫定（可逆）
- 招募不扣糧金（規格未給消耗數值）。
- 只記數量，不產生武將；武將產出與結緣留給 RAI-08。

## 不做什麼
- 不做武將生成、結緣、退役、死亡（RAI-08）。

## 驗收
- tests/RivalRecruitment.test.ts：每 2 季、品質分段、四季兩名、讀檔補零與夾值、JSON 存讀往返。
- 全套 ALL PASS；tsc 測試與 cc-check 皆 0；compute-gate standard。

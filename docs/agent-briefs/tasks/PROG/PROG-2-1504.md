# [PROG-2-1504] 英靈卡與虎符詳情共用入口（TSK-12）

## 為什麼做
WBS TSK-12：英靈卡與虎符詳情要共用同一個詳情 screen，原本各掛一套版面。spirit-tally-detail-main.json 版面已存在但沒有接線，只有預覽路徑在用。PM 裁定直接切換，綁定一併補齊。

## 做什麼
- spirit-tally-detail-main.json：補上英靈卡欄位（血脈等級、靈力、連結虎符、灌注鈕、關閉鈕）與虎符欄位（卡面名稱、稀有度、來源、典故、攻防血速耗、摘要、特性與奧義容器）。
- SpiritTallyDetailView（純邏輯）：英靈卡與虎符各一個文字組裝函式，key 對應版面節點名稱或 id。
- LobbyScene：英靈卡詳情改掛共用 screen。
- TigerTallyDetailComposite：改掛共用 screen，文字改由 binder.setTexts 批次寫入。

## 暫定（可逆）
- 節點位置與尺寸先依版面區塊放置，待 Codex 實機調整。
- 虎符的特性、奧義卡片仍由程式動態生成到容器中。
- 英靈卡的稀有度標籤（SpiritRank）暫不填。

## 不做什麼
- 不刪舊版 spirit-card-detail-main.json、tiger-tally-detail-panel-main.json（預覽與既有測試仍引用）。
- 不改灌注流程本身（按鈕仍只有外觀與可用狀態）。

## 驗收
- tests/SpiritTallyDetailScreen.test.ts：文字 key 與版面節點對應、灌注權限、虎符預設句與組裝、版面 id 不重複、screen 指向。
- 全套 ALL PASS；tsc 測試與 cc-check 皆 0；validate-ui-specs 通過。
- 實機（cc 畫面）待 Codex 驗收。

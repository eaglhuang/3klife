# [PROG-2-1505] 他國出征判定接線（RAI-05 方案 b）

## 為什麼做
RivalExpansion.evaluateExpansion（E-4 門檻與 F-2 效用）已寫好但沒有呼叫端。PM 裁定 (b)：保留既有固定機率，判定 ATTACK 時多一道關卡。

## 做什麼
- advanceRivalSeason：固定機率通過後，呼叫 evaluateExpansion，目標為玩家，回 ATTACK 才發出進攻事件。
- 玩家數值由 GameSession 傳入（城防兵、糧草；金幣 0）。

## 次要任務（PROG-2-1505 補）
- 原本只有主要任務（軍備型）時，非軍備型勢力糧草不成長，出征門檻永遠過不了。
- 新增 NATION_SECONDARY_TASK（E-2 內政偏好第二順位），每季兩項任務都結算。
- 例：呂布（WARLORD）主要軍備、次要農耕。

## 暫定（可逆）
- 出征分數門檻 0.6 → 0.75（PM 12:43 裁定 (c)，照建議值）。
- 玩家金幣傳 0。
- 敵對度取 max(0, -邦交)。
- 目標只有玩家（規格的鄰國互攻延後）。

## 模擬數字（20 seed × 60 季、全國交戰、初始糧 300）

- 糧 3000、分數 0.7：31.9 / 37.2
- 糧 3000、分數 0.72：28.6 / 32.6

- 糧 3000、分數 0.76：28.0 / 32.6
- 糧 3000、分數 0.77 以上：0 / 0
- 糧 5000、分數 0.6：39.6 / 40.8

- 只降 WARLORD 意願無法到目標：魏（MILITARIST）每 20 組約 211 次，與呂布無關。

  - WARLORD 0.1、MILITARIST 0.1：3.4 / 3.9

## 影響（請 PM 注意）
- 採用值約 5–6 次／60 季，落在 PM 目標（5–7 次）。
- 出征意願是暫定數字，且 WARLORD、MILITARIST 同時被壓低，等同削弱這兩國的擴張；企劃若要保留原規格意願，需另找調整手段。
- 原本只有固定機率時每季每國都可能進攻。

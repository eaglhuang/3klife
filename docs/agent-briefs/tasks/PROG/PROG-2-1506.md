# [PROG-2-1506] 天下大亂時代更迭（RAI-12 最小版）

## 為什麼做
RivalRiseFall.shouldTriggerEraShift 已寫好但沒有呼叫端。PM 裁定：先做佔比分支，玩家崩潰分支延後。

## 做什麼
- 每年評估一次：最強勢力（含玩家）領土佔比 ≥ 0.9 即觸發。
- 觸發時 AI 國家回到新局初始值（兵力、領土、邦交、資源、招募紀錄）。
- 玩家資產不動。

## 暫定（可逆）
- 只做佔比分支；玩家崩潰分支延後（傳 playerCollapseSeasons 0）。
- 佔比計算納入玩家領土。
- 每年評估沿用 E-9 節奏（season % 4）。

## 驗收
- tests/RivalRiseFall.test.ts：佔比計算（含空與零）。
- tests/RivalEraShift.test.ts：未達門檻不動、非年度季不動、觸發後 AI 回初始值、多季推進流程。
- 全套 ALL PASS；tsc 測試與 cc-check 皆 0；compute-gate standard。

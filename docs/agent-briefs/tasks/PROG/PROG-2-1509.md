# [PROG-2-1509] 火燒偷襲戰掠奪：Stage_Salvage 新增武器材料與教官經驗

## 為什麼做
戰法場景規格書 (doc_spec_0039) B-3 火燒偷襲戰掠奪列有「武器材料 +10、教官經驗 +20」，PROG-2-1462 因 Stage_Salvage 只有四類而暫不記。使用者 2026-10-29 裁定「加成新類別」。

## 做什麼
- SalvageTotals 新增 weaponMaterial（武器材料）、instructorExp（教官經驗）；戰後摘要標籤同步。
- 每掠奪一格火攻格：補給 200~500＋武器材料 10＋教官經驗 20。
- BattleState 初值與重置、emptyStageSalvage、addStageSalvage 同步新欄位。

## 不做什麼
- 不做戰後把武器材料／教官經驗寫入帳號經濟（目前 Stage_Salvage 四類也尚未結算入帳）。

## 驗收
- 測試更新；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

# [PROG-2-1511] 爆發力「精力滿載 +10」加成（因子爆發系統 爆發力加分因子）

## 為什麼做
因子爆發系統 (doc_spec_0010)「爆發力加分因子標準化補充」列「精力滿載：父母於結緣時精力均達高檔 +10」，cross-ref 進度 D-1a 記為缺口 3（未進 computeEpMvp）。

## 做什麼
- BreedingSystem：EP_VITALITY_FULL_BONUS = 10；EpBreakdown 新增 vitalityFull；computeEpMvp 新增選填參數；previewBreedingEp 以父母結緣前精力判定（兩人都 > 50% 上限，沿用 VitalityBattleGate.VITALITY_HIGH_THRESHOLD_PCT）。
- 結緣預覽拆解行：精力加成不為 0 時附加「精力 +10」。

## 暫定（可逆）
- 「高檔」採 VitalityBattleGate 的高段門檻（> 50%），與退役評語「建議結緣」同一條線。

## 驗收
- 新測試；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

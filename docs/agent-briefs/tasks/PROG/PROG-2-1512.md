# [PROG-2-1512] 奧義選單灰化本場已用奧義

## 為什麼做
奧義系統 E-9「每場每個奧義限用 1 次」已在 BattleSkillDispatcher 擋下（PROG-2-1451），但 cross-ref 進度 D-1a 記缺口「奧義選單尚未灰化已用奧義」，玩家點了才知道不能用。

## 做什麼
- UltimateSkillItem 新增選填 used；新增純函式 markUsedUltimates(skills, usedIds)（ui/core/UltimateUsage.ts，不依賴 cc）。
- 選單列 used 時變灰、按鈕不可點。
- ActionCommandComposite 監聽玩家 GeneralSkillUsed（sourceType Ultimate）記下 skillId；setUltimateSkills（新戰鬥）時清空。

## 暫定（可逆）
- 以 skillId 判定已用（事件只帶 skillId），與 dispatcher 以 ultimateId 為鍵的結果一對一。

## 驗收
- 新測試；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

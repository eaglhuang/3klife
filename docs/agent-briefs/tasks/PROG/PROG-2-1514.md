# [PROG-2-1514] 虎符「鐵騎」恐懼衝鋒

## 為什麼做
兵種（虎符）系統 (doc_spec_0012) 西涼鐵騎：「恐懼衝鋒：衝鋒時周圍敵軍士氣 -20」；cross-ref 進度 D-1a 列為未實作。

## 做什麼
- TallyPassiveSpec 新增 fearCharge；`tiger-tally-tie-qi` 帶 { radius 1, moralePenalty 20 }。
- 純函式 applyFearCharge(attacker, units)：攻擊者周圍敵軍士氣 -20；免疫恐懼（先登）不受影響。
- BattleCombatResolver.resolveCombat 每次攻擊開始時呼叫一次。

## 暫定（可逆）
- 「衝鋒時」以鐵騎發動部隊攻擊判定；「周圍」取 1 格（含斜角，與錦帆光環同）。
- 降士氣若本來沒在計時，開始計 3 回合（MORALE_DURATION_TURNS），到期歸零，避免永久負士氣。
- 鐵騎模板尚未進 TallyCardCatalog，玩家暫時拿不到。

## 驗收
- 新測試；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

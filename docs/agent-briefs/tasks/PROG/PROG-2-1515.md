# [PROG-2-1515] 虎符「大喬」士氣不降

## 為什麼做
兵種（虎符）系統 (doc_spec_0012) 大喬親衛：「全隊魅力 +20、士氣不降」；cross-ref 進度 D-1a 列為未實作。

## 做什麼
- TallyPassiveSpec 新增 moraleNoDecrease；`tiger-tally-da-qiao` 帶此被動。
- 恐懼衝鋒（鐵騎）的扣士氣對大喬親衛不生效。

- 「士氣不降」只擋敵方扣士氣效果；自己鼓舞到期歸零仍照常。
- 「全隊魅力 +20」：戰場部隊沒有魅力屬性，本卡不做，留在 cross-ref 缺口。

## 驗收
- 新測試；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

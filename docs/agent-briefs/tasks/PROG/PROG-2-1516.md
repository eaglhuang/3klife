# [PROG-2-1516] 戰鬥 bind 路徑契約對齊（無呼叫端模組盤點）

## 為什麼做
無呼叫端模組盤點列出 BattleBindData.ts（DATA-1-0001）沒有 TS import。但 `docs/keep-shards/keep-ui-arch.md` 規定新的動態 label 必須使用此契約的 path，所以保留。檢查 layout JSON 後發現 `tally[n].unitSub`、`tally[n].rarity`、`tally[n].stars` 三個路徑在 layout 使用、契約卻沒登錄。

## 做什麼
- TallyUnitData 補 unitSub／rarity／stars 三欄位（bind 註解）。
- 新增 `BATTLE_BIND_PATHS` 執行期清單。
- tests/BattleBindData.test.ts：battle 系列 layout 的 bind 路徑必須都在清單內；清單無重複。

## 暫定（可逆）
- 清單以 `tally[n]` 表示 0~3 任一索引。

## 驗收
- 全套測試 ALL PASS；tsc 測試型別與 cc-check 皆 0；compute-gate standard。

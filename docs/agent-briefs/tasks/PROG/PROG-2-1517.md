# [PROG-2-1517] 霸權判定接進季推進的邦交衰減（E-8、F-4）

## 為什麼做
#1302（PROG-2-1472）合併時只有純邏輯，`advanceRivalSeason` 沒有呼叫霸權判定，聯盟成員的邦交衰減仍是 2。

## 做什麼
- `RivalPlayerStats` 新增選填 `territories`；`GameSession._tickRivals` 傳入守城領地數。
- `advanceRivalSeason`：依季開始時的領土算霸主（`findHegemon`），每個勢力用 `coalitionStatusOf` 取衰減速率，以 `decayRelation` 回歸 0。

## 不做什麼
- 反霸權叛亂壓力（佔比 ≥ 40%）的效果規格未定，本卡只保留判定函式。

## 暫定（可逆，已寫入待辦檔）
- 玩家領土與他國領土同一把尺計入佔比。
- 霸權判定用季開始時的領土。
- 聯盟成員之間的邦交不另計。

## 驗證
- `npx tsc -p tsconfig.test.json --noEmit` 錯誤數 0；`npx tsc -p tsconfig.cc-check.json --noEmit` 錯誤數 0。
- 全套件 5256 通過、3 skipped。
- RivalHegemonyWiring 5 案：沒有霸主、他國霸主、玩家霸主、3 季流程不越過 0、存讀檔後不變。

# [PROG-2-1527] 虎符「南蠻」巨型踐踏濺射

## 為什麼做
兵種（虎符）系統 (doc_spec_0012) 南蠻象兵：「巨型踐踏：無視輕型步兵阻擋，攻擊附帶濺射傷害」；cross-ref 進度 D-1a 列為未實作。

## 做什麼
- TallyPassiveSpec 新增 splash；`tiger-tally-nan-man` 帶 { radius 1, ratio 0.5 }；純函式 tallySplashTargetsOf。
- BattleCombatResolver.resolveHit：主傷害後，目標周圍 1 格（含斜角）的其他敵軍受主傷害 × 0.5（至少 1），不觸發反擊與傷害連結；打死照常結算。

## 暫定（可逆）
- 規格未寫濺射數字：範圍 1 格、50%（比照 PROG-2-1457 使用者裁定先用暫定數字）。
- 「無視輕型步兵阻擋」需定義輕型步兵與阻擋規則，本卡不做。

## 驗收
- 新測試；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

# [PROG-2-1529] 虎符「白耳」替主將承傷

## 為什麼做
兵種（虎符）系統 (doc_spec_0012) 白耳兵：「精銳護衛：剋制弓兵，替主將承傷，斷後時防禦 ×2」；剋制弓兵已由 PROG-2-1457 補上，替主將承傷列在 cross-ref 進度 D-1a 缺口。

## 做什麼
- TallyPassiveSpec 新增 guardsGeneral；`tiger-tally-bai-er` 帶 { radius 1 }；純函式 tallyGeneralGuardOf(general, units)。
- BattleCombatResolver.applyUnitDamage：主將部隊受傷時，若周圍 1 格內有存活的同陣營白耳兵，傷害改由白耳兵承受；白耳兵被打死照常結算。

## 暫定（可逆）
- 範圍 1 格（含斜角），全額轉移；多個白耳取第一個找到的。
- 「斷後時防禦 ×2」需先定義斷後，本卡不做。

## 驗收
- 新測試；全測試 ALL PASS；tsc 0；測試型別 0；compute-gate standard。

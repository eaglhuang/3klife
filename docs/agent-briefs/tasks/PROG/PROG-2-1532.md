# [PROG-2-1532] 重判武將壽命系統，缺口補進 D-1a

## 為什麼做
cross-ref 進度表把武將壽命系統 (doc_spec_0018) 標🟡，但 D-1a 沒有列缺口，後續無法開卡。

## 重判結果
E 製作功能清單 8 項：壽命上限（基礎 65 + 紅因子 ×3 + 變異 -5~+10，GeneralAging.resolveMaxLifespan）、年齡階段、退役判定、死亡判定、演武聖境（SpiritCard／LegacyService）、延壽丹（LongevityPill）、身後傳承已落地。
缺口：E-1「戰傷減損」與名詞「戰傷 War_Injury：戰場受重傷降低壽命」沒有程式；規格未定義「重傷」條件與減損年數，需人工裁定後再開實作卡。

## 做什麼
- cross-ref 進度 D-1a 新增武將壽命系統一列。

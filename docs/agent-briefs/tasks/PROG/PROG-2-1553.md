# [PROG-2-1553] 軍師智謀能量接進回合推進（SCN-10）

## 為什麼做
WisdomMeter 有純邏輯（每回合 INT×0.5、滿 100 觸發），但戰場沒有每回合累積，無呼叫端。

## 做什麼
- BattleState：`wisdomMeter`、`wisdomTriggerCount`，reset 時歸零。
- BattleController：回合收尾呼叫 `updateWisdomMeter`，用我方主將智力累積。

## 不做什麼
- 全局增幅效果與 HUD。

## 暫定（可逆）
- 以我方主將智力計算；觸發只記次數，不發事件。

## 驗證
- `npx tsc -p tsconfig.test.json --noEmit` 錯誤數 0。
- WisdomMeterFlow 2 案（多回合真實流程）。

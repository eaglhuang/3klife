# [PROG-2-1554] 單挑攻擊力走注入的 svc.formula

## 為什麼做
`BattleGeneralDuelFlow.resolveAcceptedGeneralDuel` 收到 `svc` 參數，骰子（閃躲、暴擊）都走 `svc.formula`，但武將沒有化身單位時的攻擊力 `getAttack` 卻直接用 `services().formula`，忽略了注入的 `svc`。

## 做什麼
- `getAttack` 改用注入的 `svc.formula.calculateGeneralAttack`。
- 新增測試：以假的 `svc`（formula 為替身）呼叫單挑結算，驗證攻擊力來自注入的 formula，而非全域 `services().formula`。

## 不做什麼
- 不改 `placeGeneralOnBoard`（`services().formula`）：那是部署武將時算化身屬性，不在單挑結算的注入路徑上。
- 不改單挑的骰子、回合上限或懲罰規則。

## 暫定（可逆）
- 生產路徑 `resolveDuelChallenge` 傳入的 `svc` 即 `services()`，所以遊戲行為不變；這張卡修的是參數被忽略的問題，屬於可測性與一致性修正。

## 驗證
- `npx tsc -p tsconfig.test.json --noEmit` 錯誤數 0。
- `npx tsc -p tsconfig.cc-check.json --noEmit` 錯誤數 0。
- 新測試在修正前失敗、修正後通過。

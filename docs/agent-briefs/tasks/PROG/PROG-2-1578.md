# PROG-2-1578 南蠻無視輕型步兵阻擋

兵種（虎符）系統：南蠻象兵「巨型踐踏：無視輕型步兵阻擋」。輕型步兵以 TroopType.Infantry 認定（暫定）。
自動前進時前方是敵方步兵、後一格空著且可通行，就直接越過，花 1 點移動力；被越過的步兵不受傷（濺射另由攻擊觸發）。

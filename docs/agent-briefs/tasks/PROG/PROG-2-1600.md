# [PROG-2-1600] 傭兵名牌列接上面板（MERC-07 接線）

MercenaryPanelController 已掛在大廳，但沒有呼叫 MercenaryNameplateRows，原主與稀有度文字不會顯示。

## 完整描述
1. MercenaryPanelController.getFlowView 改用 buildMercenaryNameplateRows 產生每列資料，輸出 `mercRow{i}Name` 與新增的 `mercRow{i}Meta`（原主・稀有度）。

# PROG-2-1617 南蠻勇士／南蠻豹騎裁定追加虎符

依使用者裁定 Q3（參照既有兵種推算）與 MCQ Q56 選項 A：孟獲產南蠻勇士、祝融夫人產南蠻豹騎；卡面為步兵／騎兵基礎值 ×1.1。

### 特殊戰法正式規格定案（2026-11-06）

1. **南蠻勇士（孟獲虎符）**：
   - 戰法名稱：**【蠻王狂嘯（Wild Roar）】**（主動，冷卻 4 回合）
   - 效果：自身周圍 1 格範圍內全體敵軍陷入「威嚇」狀態，攻擊力降低 $20\%$（持續 2 回合）；施放該回合自身獲得 $15\%$ 傷害吸血轉化為當前兵力。
2. **南蠻豹騎（祝融夫人虎符）**：
   - 戰法名稱：**【林地疾襲（Jungle Pounce）】**（被動 ＋ 衝鋒觸發）
   - 效果：於山林與草叢地形無視移動減速；發動衝鋒攻擊時有 $30\%$ 機率觸發【撕裂】，造成 $1.4$ 倍暴擊傷害，並附加流血 Debuff（每回合損失目標當前兵力之 $5\%$，持續 2 回合）。

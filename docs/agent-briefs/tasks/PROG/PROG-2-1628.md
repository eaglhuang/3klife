# PROG-2-1628 UCUF 尺寸單一來源：建畫面不再自算對齊

問題：_buildNode 以設計解析度 1920×1080 自算 Widget 結果，百分比在建置時換成固定像素，實際畫面不是 1920×1080 時與 Cocos Widget 結果不一致。

做法：
- buildScreen 以掛載節點實際尺寸建置，無尺寸才退回設計解析度。
- applyWidget 百分比改以比例保存（isAbsolute* = false），畫面改尺寸時由引擎重算。
- 建樹兩處重複的拉伸尺寸計算抽成 UISpecTypes.widgetStretchSize，單一算法。

後續：多輪重算與畫面補丁由 PROG-2-1629 移除。

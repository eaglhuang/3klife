# PROG-2-1628 UCUF 尺寸單一來源：建畫面不再自算對齊

問題：_buildNode 以設計解析度 1920×1080 自算 Widget 結果（effectiveW 只看 left/right、忽略 hCenter），百分比在建置時就換成固定像素；實際畫面不是 1920×1080 時與 Cocos Widget 結果不一致，造成列表撐寬、文字拉成一行等錯亂。

做法：百分比保留為 Widget 的 isAbsolute* = false；_buildNode 只寫 Widget 參數，不再預算寬高；以實際畫布尺寸建置，最後由引擎做一次確定性排版。

驗收：武將列表、武將詳情、大廳在 1280×720、1920×1080、窄螢幕三種尺寸截圖對齊；全套測試與 tsc 0。

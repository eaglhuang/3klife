# PROG-2-1629 UCUF 單次排版、取消每幀對齊（拆補丁第一步）

問題：_postBuildPass 跑 3 次對齊、2 次排版，且把每個 Widget 強制成 ALWAYS（每幀重算，主專案大廳實測 1519 個）。

做法：
- _postBuildPass 改為一輪：對齊 → 排版 → 容器邊界 → 排版後對齊 → 對齊。
- _realignAllWidgets 不再強制 ALWAYS；applyWidget 明確設 ON_WINDOW_RESIZE，只在視窗尺寸改變時重算。
- 測試 stub 補 Widget.AlignMode。

驗證：工作樹另開 Cocos 預覽，無頭瀏覽器自動走完開場（開場→來信→宿命轉蛋→名將登場→大廳），1280×720 與 960×720 拆前拆後截圖一致；大廳 Widget 全數改為 ON_WINDOW_RESIZE。

剩餘：__safeArea、_realignAncestors、GeneralListComposite 寫死 bottom 等畫面補丁另行移除。

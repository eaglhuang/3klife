# PROG-2-1634 UCUF 按鈕文字未指定對齊時預設置中

問題：開場「繼續」、來信「關閉」等按鈕文字卡在按鈕左上角。skin 的 label-style 沒寫對齊時，UISkinResolver 一律回 LEFT/TOP。

做法（底層通則，非單畫面補丁）：
- UISkinResolver 記錄 skin 是否明寫水平/垂直對齊（alignExplicit）。
- UIPreviewNodeFactory.buildLabel：父節點是 Button 且未明寫對齊時，改水平、垂直置中；有明寫的照 skin。

驗證：工作樹另開 Cocos 預覽，以無頭瀏覽器 1280×720、960×720 截圖，開場「繼續」與來信「關閉」皆置中。

# PROG-2-1635 讀檔接回開場時，信件不再疊在開場畫面上

問題：讀檔接回未播完的開場（openingPhase=intro）時，_isNewPlayer 為 false，開場信件只看「未讀」就立刻顯示，疊在開場故事面板上（960×720 無頭截圖重現）。新手教學的 ready 判定也有同樣問題。

做法：LobbyScene 傳給 LobbyOpeningPanels 的 isNewPlayer 改為「新局，或開場尚未播完」。開場未完時，信件要等 openDestiny（第一幕結束）才出現；教學等宿命轉蛋開始後才出現。

# PROG-2-1638 UCUF 轉換副產品移出遊戲資源目錄

converter 在 assets/resources/ui-spec 寫入的轉換證據（.r-guard／.visual-review／.readiness／.bake-manifest／.css-coverage 等）會整包打進遊戲。

## 做法
- tools_node/lib/ui-spec-sidecars.json 定義執行期副檔（local-tokens、interaction、tab-routing、runtime-version）與證據副檔清單；ui-spec-sidecars.js 提供 evidenceSuffixOf／toEvidencePath／destinationFor／resolveExisting
- runtime-sync 寫入、readiness-gate／compare-html／cli-shell-context 讀取改走 helper（讀取先找新位置再退舊位置）
- 164 個證據檔 git mv 到 ui-spec-evidence/（同子路徑），刪除對應 .meta
- validate-ui-specs 新增 runtime-spec-only 規則，證據檔再出現在 resources 即失敗

## 驗收
- resources/ui-spec 無證據檔；check:ui-spec strict 通過；html-to-ucuf 契約 self-test 通過

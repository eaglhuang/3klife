# PROG-2-1638 UCUF 轉換副產品移出遊戲資源目錄

converter 在 `assets/resources/ui-spec` 寫入 127 個副產品 JSON（.r-guard / .visual-review / .logic-inventory / .bundle-suggestion / .css-coverage / .optimizer-scan 等，約 524KB），resources 目錄會整包打進遊戲。

## 範圍
- 副產品改寫到 `artifacts/ui-spec-sidecars/`（或 docs 下證據區），所有讀寫工具改路徑
- 遊戲執行期確實讀取的才留在 resources：先核實 `.interaction`、`.local-tokens`、`.runtime-version`（assets/scripts 有引用）
- 加 validate-ui-specs 規則：resources/ui-spec 出現非執行期副檔名即失敗

## 驗收
- resources/ui-spec 只剩執行期檔案；html-to-ucuf 工作流與 self-test 通過；遊戲畫面不變

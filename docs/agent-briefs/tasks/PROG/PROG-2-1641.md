# PROG-2-1641 HTML 轉 UCUF 定位四邊不再被瀏覽器補算值釘死

屬 HTML-to-UCUF roadmap（doc_other_0131）NextFix 小卡。

## 問題

1. `mergeComputedStyle` 把 getComputedStyle 的 top/right/bottom/left 全部抄入；瀏覽器對絕對定位元素會把四邊都算成 px，導致 widget 同時釘左右/上下。畫布寬度偏離 1920 時元件被拉長（武將詳情翻頁鍵 96px → 約 1009px 的金色長條、「傳」分頁與返回鍵超寬）。
2. `performance.js` 在 ESLint 清理時把 `totalNodeCount` 改名為 `_totalNodeCount` 但遞增處未改，轉換器在 master 上直接 ReferenceError，整條 dom-to-ui 管線無法執行。

## 修正

1. 定位四邊只在作者原本有寫（非 auto）時才以 computed 值換算。
2. 移除未使用的計數變數。

## 驗證

- `node tools_node/test/dom-to-ui-self-test.js`：50 項通過；`html-cocos compare pass` 一項因本機 puppeteer 無法啟動瀏覽器失敗（環境問題，修正前同樣無法執行）。

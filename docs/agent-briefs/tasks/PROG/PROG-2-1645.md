屬 HTML-to-UCUF roadmap（doc_other_0131）NextFix 小卡，接續 PROG-2-1641／1644。

## 問題
原稿未標 `data-ucuf-tab-content`／`role=tabpanel`／`aria-controls` 時，分頁重播一律失敗（character_v3 為 0/5），Cocos 實跑時右側整欄資訊缺失；且分頁鍵以順序對應，第一個分頁會點到左翻頁鍵。

## 修正（引擎中立，僅動 HTML 解析層）
- 分頁鍵文字對照抽成共用 `TAB_TEXT_HINTS`（draft-builder-core 與分頁重播共用），先以文字辨認分頁鍵。
- 無明確標記時，切到另一分頁比對文字變動的葉節點，取共同祖先鏈；切回後取第一個仍存在的容器作為內容區（相容 React 整批換節點）。來源標 `inferred-tab-diff`。
- 原稿有明確標記時行為不變。

## 驗證
- character_v3 分頁重播 5/5（各分頁文字量不同），完整工作流產出 5 個分頁 fragment。
- Cocos 預覽實跑：右側資訊欄出現（前一輪完全缺失）。
- dom-to-ui 自測僅 html-cocos compare 一項失敗（本機 puppeteer 環境問題，與本修正無關）。

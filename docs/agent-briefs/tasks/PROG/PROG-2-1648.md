## 問題
character_v3 名將數字「2,840」在 Cocos 被切掉上半與左側。原稿 text-shadow 為 0 0 20px 光暈；Cocos Label 字貼圖不替模糊留邊距，模糊值大時把字本身切掉。

## 修正
轉換器保持中立（照實輸出 CSS 模糊值）；Cocos 接口 UIPreviewStyleBuilder 套用陰影時，模糊上限＝字級 × 1/6（常數 LABEL_SHADOW_BLUR_MAX_RATIO）。通用於所有文字陰影。

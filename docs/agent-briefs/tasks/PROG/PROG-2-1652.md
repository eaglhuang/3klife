屬 HTML-to-UCUF roadmap（doc_other_0131）。使用者裁定：邊框只保留 HTML 原稿有的效果，舊畫面多餘的框一律去掉，降低複雜度與渲染負擔。

## 問題
分頁切換按鈕沒指定貼圖時，轉換器固定套舊武將詳情的 tab_active_button／detail_tab_active_frame 華麗貼圖，與原稿素面金框圓鈕不符。

## 修正
沒指定 data-tab-normal／data-tab-selected／data-sprite 時，改照 CSS 的底色、圓角、邊框產生（與一般按鈕同一規則）；刪除寫死的舊貼圖常數。原稿明確指定貼圖時照用。

## 驗證
- Cocos 實跑（無頭 Chrome 截 canvas）：右側分頁鈕為素面圓鈕、作用中金框，與 HTML 一致。
- dom-to-ui-self-test 僅既有環境性 html-cocos compare 一項失敗。

## notes
- 轉換後立繪區只有立繪背景／立繪圖／左右翻頁鍵三層，無多餘外框；遊戲現行 character-ds3 的多層外框會在正式換成 character_v3 轉換稿時一併移除。
- 重構第 2 步（引擎接口）順延下一張卡。

屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1652。

## 問題
character_v3 正式六分頁（doc_ui_0012 §0）最後一頁為「兵／ARMY」，但分頁文字對照只有舊名「適／APT」。「兵」鈕沒被認成分頁切換，去重複機制失效，Cocos 出現兩顆「兵」；兵分頁內容檔也沒產生。

## 修正
分頁文字對照（TAB_TEXT_HINTS，資料表）補「兵」「ARMY」→ aptitude。

## 驗證
- 轉換結果恰好六顆分頁鈕且皆有分頁契約；aptitude 內容檔產生（六頁齊）。
- Cocos 實跑右側六顆分頁鈕，與 HTML 一致。

## notes
- 剩餘差異：右下角米色三角、故事條收合狀態。

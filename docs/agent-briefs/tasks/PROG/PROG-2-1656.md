屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1655。

## 問題
character_v3 底部中央的「▲ 逸 事 ▲」切換鈕在 Cocos 不見。連帶查出四個通則問題：
1. 切換鈕一律被刪，假設故事條收合片段會提供；但只有手寫的 ds3 有該片段，v3 沒有，鈕就消失。
2. 只有文字、但帶底色或邊框的元素被轉成純 label，底框丟失。
3. 背景色對不到色票時整塊變透明（本畫面 23 處）。
4. 後處理「panel 合併成 label」：Cocos 子節點畫在父節點之後，底色會蓋住文字，內距也被刪；這個合併只對帶 skinSlot 的 panel 生效，所以只要底色可見就一定畫錯。

## 修正
- 只有在預設收合片段檔確實存在時才刪切換鈕，否則保留原位。
- 只有文字但帶底色或邊框的元素轉成 panel，文字另包節點；沒有 layout 的框依 CSS 內距定位文字。
- 對不到色票的背景色改用原色碼（保留 unmapped-color-literal 警告，色票缺口可追蹤）。
- 刪除 optimize-ucuf-layout 的 panel 合併成 label 整段。

## 驗證
- Cocos 實跑：切換鈕出現在底部中央，文字位置與 HTML 對齊；其他區塊無退步。
- dom-to-ui 自測只剩既有已知的 html-cocos compare 一項失敗；adjustedCoverage 維持 0.963。

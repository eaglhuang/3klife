屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1656。

## 問題
任何一邊 border-style 為 none 時整圈邊框不畫；border-radius 四角不同時（如 10px 10px 0 0）被當成四角相同。character_v3 的「逸事」切換鈕（上三邊有框、上圓下方）因此少了框、底角變圓。

## 修正
- 轉換器：四邊不同時輸出 borderSides {top,right,bottom,left}；四角不同時輸出 cornerRadii [左上,右上,右下,左下]。均一時沿用原欄位。
- GradientBackground：外框與內框各自依分角半徑算有號距離，內框依各邊寬度內縮，保留反鋸齒。
- UIPreviewStyleBuilder：漸層帶上新欄位；純色框遇分邊／分角改走 GradientBackground 單色填滿（RoundedRectBackground 只能畫均一形狀）。

## 驗證
- Cocos 實跑：切換鈕上方圓角、三邊有框、底邊無框，與 HTML 一致。
- tsc 無錯；dom-to-ui 自測只剩既有已知一項；adjustedCoverage 維持 0.963。

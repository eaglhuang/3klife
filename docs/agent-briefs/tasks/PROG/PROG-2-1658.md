屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1657。

## 問題
character_v3 右欄（分頁內容區）整體比 HTML 低 50px。延後掛載宿主 right-content 自己帶 layout paddingTop 50，掛進來的分頁片段根節點又複製了宿主的排版與內距，內距算了兩次。

## 修正
延後掛載宿主（lazySlot）不再輸出 layout：它沒有自己的子節點，排版與內距由片段根節點負責。

## 驗證
- Cocos 實跑（搭配最新執行期程式）：右欄名字、資訊卡、精力條、名聲區塊的高度與 HTML 對齊。
- 同時確認 2,840 不再被切（PROG-2-1648 生效）。
- dom-to-ui 自測只剩既有已知一項；adjustedCoverage 維持 0.963。

## notes

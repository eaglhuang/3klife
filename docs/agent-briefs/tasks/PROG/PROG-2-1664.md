屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1663。

## 問題
character_v3 點「屬」後右欄已切換，但金框高亮仍停在「將」。HTML 依目前分頁切換按鈕外觀；轉換器只看得到開場狀態（一顆啟用、其餘未啟用）。

## 修正
- UIPreviewBuilder 新增 _restyleFromSpec：不重建節點，把另一份同結構 spec 的外觀套上（按鈕皮膚套不上時與建按鈕同樣退回背景皮膚；子節點以名稱對應）。
- UIScreenPreviewHost：同一插槽的語意分頁鈕成一組，點擊時被點的鈕套開場啟用鈕外觀、其餘套未啟用鈕外觀。

## 驗證
- Cocos 實跑真實點擊「屬」：「屬」變金框高亮、「將」回到未啟用外觀。
- 測試型別檢查 0 錯誤。

屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1664。

## 問題
character_v3 屬性頁的雷達圖只轉出 svgMeta，執行期沒有繪製；轉換器又因 HTML 解析器把 viewBox 轉成小寫 viewbox 而讀不到畫布尺寸。

## 修正
- draft-builder-core：viewBox 同時讀 viewbox。
- 新增引擎中立純函式 RadarSvgConfig.radarConfigFromSourceSvg：由原稿資料多邊形算各軸數值，取原稿顏色／線寬／標籤。
- UIPreviewBuilder：rendererHint 為 svg-radar-chart 時經 ICompositeRenderer.drawRadarChart 繪製；渲染器由子類提供（_getSvgCompositeRenderer）。
- UIScreenPreviewHost：提供 CocosCompositeRenderer。
- CocosCompositeRenderer：原稿線寬依縮放換算且最少 1px（Graphics 不畫次像素線，0.7 格線會消失）。

## 驗證
- Cocos 實跑點「屬」分頁，與 HTML 對照：六軸數值形狀、軸色、頂點色、格線一致。
- 測試型別檢查 0 錯誤；轉換 adjustedCoverage 維持 0.963。

## notes
殘差：外框線略細、整張圖比原稿高約 10px，另案處理。

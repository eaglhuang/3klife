屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1667。

## 問題
1. UIPreviewBuilder 建立的 skinLayer_／composite_ 子節點沒設圖層，落在 DEFAULT，UI 攝影機看不到：舞台底色 #0a0a0a、立繪區漸層等全部沒畫，看到的是主攝影機天空盒（背景偏亮、右下米色三角、整體對比低）。
2. 立繪 img 的 filter: drop-shadow 被換成矩形陰影，修好圖層後露出一個深色方框。

## 修正
1. 兩處子節點 layer 繼承父節點。
2. draft-builder-core：圖片內容（image／composite-image／url 背景）外形由透明度決定，drop-shadow 不轉矩形陰影；box-shadow 照常。

## 驗證
Cocos 實跑屬性頁：右側背景 (24,22,18)→(10,10,10)、右下 (150,137,126)→(10,10,10)，與 HTML 相同；立繪方框消失；文字邊緣銳利度 2917→3136。

屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1668。

## 問題
雷達圖同心格線幾乎看不見，資料外框只剩約 1px（原稿 2px）。Cocos Graphics 線條邊緣抗鋸齒會吃掉約 1px 可見寬度；外框另被寫死 230 透明度。

## 修正
CocosCompositeRenderer 新增 _applySourceStroke（取代 _sourceStrokePx）：線寬依原稿比例換算後加回 1px 抗鋸齒損失；小於 1px 的線維持 1px 可見寬度、透明度依線寬縮放（同瀏覽器覆蓋率）；外框用原稿顏色不另降透明度。格線、軸線、外框共用此規則。

## 驗證
Cocos 實跑屬性頁截圖與 HTML 放大比對：四圈同心格線與六條軸線的粗細、淡度一致，外框 2px 一致。

## notes
殘差：雷達軸標籤字級偏小、位置偏內，另案。

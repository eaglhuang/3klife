屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1669。

## 問題
雷達軸標籤比 HTML 小（14px，原稿 SVG 縮放後 15.3px），且原稿座標已含文字偏移，又被加一次 offsetY。

## 修正
CocosCompositeRenderer：有原稿標籤時字級乘以 viewBox 縮放比（新增 _sourceScale），位置直接用原稿座標；無原稿時維持舊行為。

## 驗證
Cocos 實跑屬性頁：六個標籤字級 15.3、字寬與 HTML 相同（武力 29px），位置差 ≤3px。

## notes
HTML 原稿的「政治」被 SVG 邊界裁掉一半，屬原稿瑕疵；Cocos 保留完整顯示。

屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1670。

## 問題
character_v3 立繪區背景（兩層 radial + 一層 linear，外加 ::after 右側漸暗）在 Cocos 只剩一片平色：
1. parseGradient 把 `ellipse at 30% 40%` 的位置誤當半徑，光暈極小。
2. 父元素有子元素時 ::after 一律跳過（怕疊放錯）。
3. 預覽端只畫 slot.gradient（最底層），backgroundLayers 其餘層沒畫。
4. 往 transparent 漸變時 Cocos 以直接 RGBA 插值，顏色往黑偏（CSS 為預乘插值）。

## 修正
1. snapshot-to-slots：半徑只解析 `at` 之前；無尺寸時依 CSS 關鍵字（預設 farthest-corner）換算橢圓半徑。
2. draft-builder-core：::after 照 CSS 疊放規則插在一般子元素之後、z-index 為正的定位子元素之前。
3. UIPreviewStyleBuilder：最底層畫在節點，其餘漸層層各建鋪滿子節點，第一層在最上。
4. 全透明色標借用相鄰可見色標的 RGB（等同預乘插值）。

## 驗證
Cocos 實跑屬性頁 8 個取樣點與 HTML 相差 ≤3（如 (150,300) H(50,40,26) / C(50,40,27)；右側漸暗 (1150,900) 同為 10）。dom-to-ui self-test 僅既有 html-cocos compare 失敗。

## notes
::before 在有子元素時仍跳過，未見實例，另案。

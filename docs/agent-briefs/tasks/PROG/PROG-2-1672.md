屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1671。

## 問題
專案字型只有一種字重，粗體文字在 HTML 與 Cocos 都是模擬加粗，筆畫與原設計不同。

## 修正
1. 新增 fonts/manrope/font-bold.ttf、fonts/newsreader/font-bold.ttf：取自 Google Fonts 官方可變字型（OFL），以 fontTools 固定 wght=700（Newsreader opsz=16，與原檔相同），再裁成與原檔相同的字元集（36KB／54KB）。
2. ui-design-tokens typography.boldFonts：一般字型 → 粗體字型與其 unicodeRange（資料驅動）。
3. UISkinResolver 解析 boldFontPath／boldFontRanges；UIPreviewBuilder 預載粗體字型；UIPreviewStyleBuilder 在文字全在粗體字型範圍內時改用真粗體並關閉模擬加粗，否則（如中文退回系統字）維持模擬加粗。
4. 設計原稿（Design System_20260513，未入版控）colors_and_type.css 加 font-weight 600–900 的 @font-face，HTML 端同步使用真粗體。

## 驗證
Cocos 實跑屬性頁：23 個文字改用真粗體，數字 98／16,800／120 字形與粗細與 HTML 一致；中文標題維持模擬加粗。

## notes
- 現有 manrope／newsreader font.ttf 實為 ExtraLight（字重 250），是否換成 Regular 待使用者決定。
- NotoSansTC 粗體原檔約 11.4MB，依使用者指示未下載，中文仍為模擬加粗。

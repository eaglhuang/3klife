屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1672。

## 需求
武將（及其他畫面）背後要能放一張全螢幕的三國風背景圖。背景圖由設定表決定、可替換，取代目前的黑色漸層底。

## 現況
UI 沒有可設定的全螢幕背景圖。戰場有 encounters.json backgroundId，DS3 畫面規格只留了 TODO。

## 修正
1. 新增 data/ui-screen-backdrops.json：screens（畫面 id → 背景圖 id）、default、backdrops（sprite、replaceFillCoverRatio）。預設不對應任何畫面，行為不變。
2. 新增 ScreenBackdrop.ts（引擎中立）：resolveScreenBackdrop、coverSize（等比蓋滿）。
3. UIPreviewBuilder.buildScreen 建完後依 layout id 套用：在最底層插入 __screenBackdrop Sprite（cover-fit）。覆蓋畫面達比例的容器，其不透明底色（Solid／Gradient／RoundedRect 與它驅動的 Sprite）關閉；__bgLayer_*、Pseudo 修飾層保留。

## 驗證
暫時把 character-v3-probe 對應到 general_detail_martial，Cocos 實跑：背景圖鋪滿全螢幕，立繪後方換成背景圖，右側面板半透明底仍保留。

## notes
- 目前設定表 screens 為空，正式要哪個畫面用哪張圖、是否改 default，待使用者選圖後填表即可，不需改程式。

屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1671。

## 問題
父元素有子元素時 ::before 整個被略過（例：character_v3 .cell::before 網點紋）；::after 只處理「正 z 子元素」一種情況。

## 修正
1. computed-style-capture 擷取 position，pseudo 也有 position／z-index。
2. draft-builder-core：::before、子元素、::after 一律算 CSS 疊放層（負 z → 一般流 → 定位 auto/0 → 正 z，同層照文件順序）後穩定排序；不再略過有子元素的 pseudo。暫存欄位排序後刪除，不進輸出。
3. dom-to-ui-self-test 新增疊放順序案例。

## 驗證
self-test 新案例通過，其餘結果與修改前相同（唯一失敗為既有的瀏覽器啟動環境問題）；character-v3-probe 重轉輸出正常。

屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1672。使用者裁決：英文字型換一般字重；下載 NotoSansTC 粗體。

## 問題
- manrope／newsreader font.ttf 實為 ExtraLight（字重 250）。
- notosans_tc/font.ttf 是 Thin 拉丁字型，沒有任何中文字，中文全退回系統字，粗體只能模擬。

## 修正
1. manrope、newsreader font.ttf 改由 Google Fonts 官方可變字型（OFL）固定 wght=400 產生，字元集與原檔相同。
2. notosans_tc：以 Google Fonts NotoSansTC[wght]（OFL）產生 font.ttf（400）與 font-bold.ttf（700），字集 = notoserif_tc 字集 ∪ resources JSON 用到的中文字 ∪ ASCII／全形標點，共 3378 字，各約 1.1MB。
3. ui-design-tokens typography.boldFonts 增加 notosans_tc 對應與 unicodeRange（由字型 cmap 產生）。
4. 設計原稿（未入版控）fonts 換成同一批檔案，colors_and_type.css 加 NotoSansTC 600–900 粗體 @font-face。

## 驗證
Cocos 實跑將分頁：名將、數字、內文字重與 HTML 一致，不再是極細體。

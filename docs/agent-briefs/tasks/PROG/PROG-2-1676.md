屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1674。

## 問題
武將介紹各分頁的圓形等級徽章（S／A／B／C／D）用 display:grid; place-items:center 置中字母，轉出的 label 卻是靠左，字母偏左被切。

## 修正
draft-builder-core 新增 looseTextBoxAlign：grid 看 justify-items（place-items），flex 看主軸 justify-content 或縱向 align-items。容器自身就是文字（label）或包匿名文字時，此對齊優先於 text-align（CSS 中文字盒為收縮寬度的 grid／flex 項目，位置由容器決定）。self-test 新增案例。

## 驗證
self-test 52 項通過（唯一失敗為既有瀏覽器啟動環境問題）。Cocos 實跑兵、寶分頁：徽章字母置中，與 HTML 一致。

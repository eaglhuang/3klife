屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1676。武將介紹分頁比對所見。

## 問題
1. 命頁「命紋已顯」是一般區塊裡的行內 span：computed width 為 auto，轉出沒有寬度，被垂直排版撐滿整列。
2. 區塊流轉成的垂直排版在 Cocos 預設把子框置中，CSS 是靠左（依 text-align）。
3. 技頁「LV.7」在 HTML 只有一行，Cocos 字寬稍寬就換行，RESIZE_HEIGHT 又把框長成兩倍高。

## 修正
1. deriveComputedGeometry：display:inline 的元素改用量到的框大小。
2. inferBlockFlowLayout：alignItems 依 text-align（預設 start）。
3. UIPreviewNodeFactory：原稿高度不到 1.5 行的 label 改 SHRINK＋不換行，框高維持原稿。

## 驗證
self-test 52 項通過（唯一失敗為既有瀏覽器啟動環境問題）；Cocos 實跑命、技分頁與 HTML 一致；將／屬／寶／兵分頁無退步。

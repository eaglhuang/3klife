屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1677。武將介紹屬分頁比對所見。

## 問題
1. 屬頁數值條底槽從整列最左邊開始：對齊標籤欄的空盒只靠 min-width 撐開，轉換時被當空容器丟掉。
2. 填色條在底槽裡置中：只有一個子元素的區塊不產生排版，Cocos 預設置中，CSS 是靠左上。

## 修正
1. 空容器若只靠 min-width／min-height 撐開，保留其大小當佔位。
2. inferBlockFlowLayout 不再略過單子元素區塊，一律用垂直排版、依 text-align 對齊。

## 驗證
self-test 52 項通過；閘門 11/11；test tsc 0。Cocos 實跑屬分頁條形圖起點與靠左填色和 HTML 一致；將／命／技／寶／兵無退步。

屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1679。武將介紹立繪左右箭頭比對所見。

## 問題
立繪箭頭在 HTML 是上一位／下一位武將（prevCharacter／nextCharacter），轉換後為 tabSwitch 目標 pool.prev／pool.next。UIScreenPreviewHost 把它模糊比對成分頁路由（左箭頭到兵、右箭頭到將），變成切換分頁。

## 修正
UIScreenPreviewHost：相對循環目標（pool.prev／pool.next／prev／next）不走路由，按下時在宿主節點送出 EVENT_POOL_CYCLE（步數 -1／+1），交給持有資料池的畫面換武將。

## 驗證
閘門 11/11；test tsc 0。Cocos 實跑：互動報告 pass、8 個動作綁定；按左右箭頭分別送出 -1、+1，分頁不再切換。

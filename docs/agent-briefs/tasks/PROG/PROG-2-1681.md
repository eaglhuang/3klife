屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1680。使用者回報武將介紹缺家族血統（14 人三代祖譜）。

## 問題
命分頁在 HTML 會把左側立繪換成全幅家族血統（#bloodline-fullscreen），並隱藏立繪、稱號、等級章。分頁重播只擷取內容區（right-content），這塊被漏掉。

## 修正
1. render-html-tab-fragments：記下預設畫面可見的 id 區塊；每個分頁比對出內容區以外新出現的區塊（擷取成片段 HTML）與被隱藏的區塊。
2. per-tab-replay：區塊轉成片段，寫入分頁路由 regions／hides；區塊掛載點改為延遲插槽，內距移到片段根節點。
3. UIScreenPreviewHost：切分頁時顯示並填入該分頁的區塊、隱藏它蓋掉的區塊，其他分頁的區塊與被隱藏區塊還原。

## 驗證
self-test 52 項通過；閘門 11/11；test tsc 0。Cocos 實跑命分頁左側顯示 14 人家族血統、立繪／稱號／等級章隱藏，切回將分頁還原。未完成：祖譜世代間連接線（SVG）尚未轉出。

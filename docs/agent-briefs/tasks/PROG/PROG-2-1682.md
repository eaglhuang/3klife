屬 HTML-to-UCUF roadmap（doc_other_0131），接續 PROG-2-1681（家族血統區塊已轉出，世代連接線缺）。

## 問題
1. 只有線條的 SVG 沒有渲染器提示，轉出後是空的 composite。
2. 排版容器裡 position:relative 的子項被 CSS 疊放順序排到最後，連接線容器跑到祖譜底部。
3. 直排容器中子項的交叉軸外距（margin-left:82）遺失。
4. 解析後的屬性名是小寫 viewbox，讀不到 viewBox，改用 width="100%" 當寬度。

## 修正
1. draft-builder-core：只含 line 的 SVG 判為 svg-line-art，svgMeta 記 viewBox、preserveAspectRatio、線段。
2. 新增引擎中立 SvgLineArt.ts：依 viewBox／縮放方式把線段換算到節點框；UIPreviewBuilder 以 Graphics 畫出。
3. 排版容器內留在流內的子項維持文件順序，只有脫離流的子項依疊放順序排。
4. flex 子項外距包裝層同時表達交叉軸外距。
5. viewBox 大小寫皆可讀。

## 驗證
SvgLineArt 測試 3 項通過；self-test 52 項通過；test tsc 0。Cocos 實跑命分頁：曾祖→祖父→父母→本代三段連接線位置與顏色對齊 HTML；屬分頁雷達不受影響。

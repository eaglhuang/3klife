使用者指示大廳改用正式武將面板（GeneralDetailComposite）。實測正式面板的子面板依固定節點名填資料，但轉換器自動命名每次重轉都會變，現已對不上；設計稿不進版控，無法在原稿加 data-name。本卡為三步計畫第一步。

## 修正
1. 新增 tools_node/lib/html-to-ucuf/bind-map.js：讀 tools_node/data/ui-bind-maps/<screenId>.json，渲染後依 selector／text／index 寫入 data-name；以 MutationObserver 在框架重畫（切分頁）後重新套名。
2. render-html-snapshot、render-html-tab-fragments 新增 --bind-map；工作流程有該畫面的綁定表時自動帶入。
3. README 說明格式。

## 驗證
html-bind-map 測試通過；以 character_v3 探針綁定表實跑轉換，OverviewName 出現在主畫面快照與將分頁片段（探針表未提交）。

## 後續
第二步：替 character-ds3-main 建綁定表並讓子面板改用固定名稱（先做將分頁）。第三步：大廳改開正式面板並接箭頭。

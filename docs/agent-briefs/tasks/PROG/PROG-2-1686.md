三步計畫第三步。使用者指示大廳改用正式面板（GeneralDetailComposite，ds3 版型）。

## 修正
1. GeneralDetailComposite：ds3 左右箭頭（button_1/2）呼叫 onRequestCycle(-1/+1)；切分頁後呼叫 onDs3TabSwitched；公開 ds3Binder。
2. LobbyScene：選武將改開正式面板；箭頭以 cyclePoolItem 換下一位並重新 show；寄宿戰魂、血統小傳、命紋靈獸、因子六角、版本圖鑑改由 _characterDs3Surface() 取正式面板（未開時退回舊 host）。

## 驗證
Cocos：大廳 _openGeneralDetailDirect(張飛) 開正式面板、舊 host 關閉；點右箭頭後畫面換成趙雲（姓名、六圍、血脈、傳記）。

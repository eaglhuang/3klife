接續 PROG-2-1686。大廳改開正式面板後，左側立繪、立繪下方稱號、姓名旁外號仍固定為張飛。

## 修正
1. 版型節點一次改名：CharacterDs3Main_img_1 → PortraitImage、CharacterDs3Main_div_3 → PortraitFooterTitle（layouts／screens／skins 五檔同步）；將分頁 span_2 → OverviewEpithet。
2. GeneralDetailComposite._requireNode：單一名稱找不到固定路徑時改用綁定器依節點名查找（DS3 版型）。
3. ds3 顯示流程新增 _applyDs3PortraitChrome：載入該武將立繪、關閉版型烘進的示意立繪（PortraitImage_ImageContent）、寫入稱號。
4. 將分頁外號寫入 headerTitle。

## 驗證
Cocos：大廳開張飛→右箭頭換趙雲，立繪、立繪下方稱號、外號皆換成趙雲。

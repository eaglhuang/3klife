教官系統（doc_spec_0027）靈感戰法逐招獨立效果的下一招。夜襲原本借用司馬懿「暗影」（全體敵軍智力傷害），與招名無關。

## 修正
1. 技能設定新增通用欄位 weatherDamageMultiplier（各天氣傷害倍率，未列的天氣 ×1），傷害結算時與火計天氣倍率相乘；匯出 weatherDamageMultiplierOf 供測試。
2. 新增獨立技能 insp-night-raid：前排單體、武力 ×1.0、夜晚傷害 ×1.5（數值暫定）；戰法庫 tactic-insp-night-raid 改指向它。
3. cross-ref 進度表教官系統列補記。

# PROG-2-1717 名將挑戰賽彈窗顯示本月場景賽與規則

名將挑戰賽系統（doc_spec_0007）「月度場景賽」邏輯（MonthlyScenarioCup，PROG-2-1609～1612、1616）已有測試但沒有任何呼叫端（實作進度接線欄 ❌）。
本卡先把本月場景接到玩家看得到的地方：
- TournamentPanelController：新增 trnMonthlyLabel「本月場景賽：{名稱}｜{規則}」，月份取裝置當地月份（暫定，規格「每月一場」未指明時區）。
- monthlyScenarioRuleText：四種規則轉中文（禁用某類戰法、需某兵種適性 A 以上、某屬性戰法威力倍率、某兵種 S 適性地形加成倍率）。
- tournament-main 版面：BOSS 列後加一列 TrnMonthlyLabel（卡片高度足夠，不改其他節點）。

報名畫面、月度戰績存檔不在本卡範圍。

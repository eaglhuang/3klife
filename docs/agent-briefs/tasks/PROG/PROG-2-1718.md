# PROG-2-1718 換季開場提示

遊戲時間系統（doc_spec_0034）§G「季度開始：第 {Year} 年 {Season} 季——{SeasonEvent}」與 §H UI_SEASON_SPRING～WINTER
四句季節主題字串已在 i18n（ui.season.spring／summer／autumn／winter），但沒有程式使用。
- SeasonTexts.seasonThemeText：依季節取 ui.season.{spring|summer|autumn|winter}，語系表查不到時退回 zh-TW 預設（與 §H 一致）。
- SeasonTexts.seasonStartText：「{季度顯示}　{季節主題}」，例「第 3 年 1 季　春——萬物復甦」。
- LobbyScene：換季（SeasonAdvanced）時先跳這句提示，再跳既有的來犯、離隊提示。

§E-5 季度事件（春播／秋收／冬戰）規格只有名稱、沒有效果，不在本卡範圍。

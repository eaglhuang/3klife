# PROG-2-1720 讀檔接上存檔遷移流程（熱更新與版本控制 §二.1）

熱更新與版本控制規格書（doc_tech_0012）§二.1 要求讀檔發現 Save_Version 過舊時，依序往上執行各版 Migration，
完成後把 Save_Version 標成最新。SaveVersion.runSemverMigrations 已有遷移鏈，但 PlayerSaveService 讀檔只讀版號、沒跑遷移。

變更：
- 新增 core/storage/PlayerSaveMigrations.ts：遷移步驟登錄表 PLAYER_SAVE_MIGRATIONS（目前最新 1.0.0，尚無步驟）與 migratePlayerSaveRaw。
- validatePlayerSaveSnapshot 驗證前先跑遷移；缺可接步驟時拋錯，交給既有備份回復流程。
- SaveVersion.test.ts 補 2 個案例：登錄表能接到最新版、舊檔依序升級且新版不降版。

未做：§一 主版號不符強制前往商店更新、§三 熱更新管線（需伺服器版本端點與原生打包，另案）。

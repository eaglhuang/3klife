# PROG-2-1721 主城倉庫物品清單與排序（武將背包系統 §E-6）

武將背包（倉庫）系統（doc_spec_0017）§E-6 要求倉庫物品可按品質／類型／取得時間排序。倉庫面板原本只顯示容量，沒有物品清單。

變更：
- 新增 core/systems/WarehouseSort.ts：三種排序（品質 UR>SSR>SR>R>N、類型 虎符→英靈卡→裝備、取得時間新的在前）、循環切換、清單行文字（裝備用定義名稱，鎖定加註「已鎖定」）。
- WarehousePanelController：新增 storedRecords 依賴、cycleSort()、warehouseList 清單文字（最多 8 件，其餘「…另有 N 件」）與排序按鈕文字。
- warehouse-panel-main.json：新增 BtnWarehouseSort 按鈕與 WarehouseList 文字節點。
- LobbyScene：倉庫傳入統一物件庫中未裝備的列，接上排序按鈕。

暫定：物件列沒有存取得時刻，取得時間以物件庫列順序代表。
未做：§E-9 分解（規格未定義回收哪些材料、多少）；名稱以外的篩選。

# PROG-2-1735 倉庫「取得時間」排序改看虎符取得季

## 交付

- `WarehouseSort.sortWarehouseRecords(..., 'acquired')`：有 `Attributes.Acquired_Season` 的列依取得季由新到舊；同季或沒有取得季時沿用列順序（新的在前）；沒有取得季的列排在後面（暫定）。
- 原因：虎符列每次重建都依 uid 字典序接在物件庫最後，原本「列順序＝取得順序」的假設對虎符不成立。
- `tests/WarehouseSort.test.ts` 新增 1 案。
- d1a-rejudge 背包列更新：鎖定切換已接進裝備挑選，原紀錄過時。

# PROG-2-1754 名將挑戰賽：月度場景賽參戰與歷史留存

依名將挑戰賽系統.md (doc_spec_0007)「月度場景賽（特別賽制）」、§rollover「Monthly_Scenario_History」與 K 段積分公式：月度場景賽原本只有規則、計分函式與公告行，沒有參戰入口，也沒有存歷史。

## 交付

- `MonthlyScenarioCup.ts`：`playMonthlyScenario`（排除不合資格者、單人積分前 3 計隊伍分、同月留最高分）、`monthlyScenarioMemberOf`、`monthKeyOf`、`normalizeMonthlyScenarioHistory`。
- `TournamentLocal.ts`：`TournamentState.monthlyHistory`（選填，存檔正規化），不動主賽積分。
- `GameSession`：`playMonthlyScenario(nowMs)`、`monthlyScenarioHistory`。
- `TournamentPanelController`：`playMonthly()`、「場景賽」鈕、月度列附「本月最佳 N」；LobbyScene 接線。
- `tournament-main.json`：按鈕列改五顆（176 寬），中間加 `btnMonthly`。
- 測試：`tests/MonthlyScenarioPlay.test.ts` 4 案。

## notes

- 暫定：名冊沒有戰法等級，戰法點數記 0；地形倍率取規則指定兵種適性（山地奇兵類）或該將最高適性，無適性視為 B；出戰人數 3。
- 名冊武將沒有戰法標籤，「禁用騎兵戰法」目前只在有帶 tacticTags 時生效。
- 稱號（Title_Granted）與限定獎勵規格未定，未做。
- 未在 Cocos 實機驗證按鈕列排版。

# PROG-2-1758 軍師 HUD 補參謀常駐行「INT N，正在執行：場景戰法」

主戰場UI規格書.md (doc_ui_0001) §6.3 要求棋盤上方常駐「INT 99, 正在執行: 夜襲」，§6.4 `strategist-hud-summary` 也列 `Strategist_Name`。master 上軍師 HUD 只有危害、物件、回收、缺口四欄，戰場內沒有「正在執行」。

## 交付

- `StrategistHud.ts`：輸入新增選填 `executing`（姓名／智力／戰法名），摘要新增 `executingTactic`；戰場日誌句把它排在最前。
- `StrategistHudSource.ts`：場景戰法戰鬥（battleTactic 非 Normal）且有我方主將時帶入；戰場沒有獨立參謀官，以我方主將姓名與智力代表。
- `BattleEntryParams.ts`：匯出 `battleTacticLabel`（沿用既有 TACTIC_LABEL）。
- 測試：StrategistHudLog 3/3、StrategistHudSource 5/5。

# PROG-2-1759 大廳任務牆接上玩家累積情報（Required_Intel 判定）

大廳系統.md 規定 `Required_Intel` 決定軍事任務是否可見；`getVisibleHallTasks` 已實作判定，但 `hallPlayerOf` 把情報度寫死為 0，所以凡是有情報門檻的軍事任務永遠不會出現。另一方面監獄每季產出的情報（`prison.intel`）一直累積，卻沒有任何地方使用。

## 交付

- `OfficerSnapshot.hallPlayerOf(unlocks, intel = 0)`：帶入累積情報，取整並夾在 0~100（HallPlayerState 註明情報度 0~100）。
- `GameSession.intel`：回傳玩家累積情報（目前來源為監獄產出），不用複製整個 prison 狀態。
- `LobbyScene`：任務牆顯示與派遣兩處呼叫改傳 `session.intel`。
- 測試：`tests/HallPlayerIntel.test.ts` 2 案。

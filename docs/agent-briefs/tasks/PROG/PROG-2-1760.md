# PROG-2-1760 軍師 HUD 參謀常駐行附「情報 目前值 / 門檻」

## 交付

- `StrategistHud.ts`：`StrategistExecution` 新增選填 `intel { current, required }`，常駐行附「（情報 32 / 40）」。
- `StrategistHudSource.ts`：`strategistHudInputOf` 新增選填 `playerIntel`；只在戰法設有情報門檻（SCENE_GAMBIT_GATES，目前森林埋伏 45、夜襲 40）時附上。
- `BattleUIBridge.ts`：回合日誌傳入 `services().session.intel`。
- 測試：StrategistHudSource 補斷言（有門檻附情報、無門檻不附）。

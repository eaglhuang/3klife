# PROG-2-1763 關卡推薦戰法暫定值＋戰前三態檢核接線

依關卡設計系統.md (doc_spec_0049) §D-2／D-3／D-4。使用者裁定第 18 題選 (a)：依每關主題先填暫定推薦戰法，再接上戰前三態檢核。

## 交付

- 新增 `assets/resources/data/tactic-counter-tags.json`：規格戰法 TAC_* → 對策標籤（破城、反隱、夜戰、抗混亂…），全部暫定。
- `encounters.json` 暫定值：虎牢關（攻城）必備「破城」、高建議「鼓舞」；長板坡（夜襲）必備「反隱」、高建議「夜戰」。
- `EncounterConfig`／`StageChainNodes` 新增 `highlyRecommendedLoadout`；Preview_Intel 推薦清單 = 必備＋高建議。
- `LoadoutCheck.ts` 新增 `loadoutTagsOf`（戰法庫 id 先轉規格 id）與 `loadoutCheckLogLine`（三態文案，高風險標「仍可挑戰」）。
- `BattleSceneLoader.loadLoadoutCheck` 讀關卡與標籤表；`BattleUIBridge` 每關查一次，寫一行戰場日誌，缺口帶進軍師 HUD「對策缺口」欄。

## notes

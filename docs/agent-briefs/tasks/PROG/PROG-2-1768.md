# PROG-2-1768 虎符產出、升星與傳奇部隊劇本句（兵種（虎符）系統 §G）

名將陣亡產出虎符、虎符戰後升星時玩家完全沒有提示；白馬義從、陷陣營部署也沒有規格句。

## 交付

1. 戰鬥結算產出或升星時，戰鬥日誌與結算細項顯示規格句。
2. 換季時有武將陣亡產出虎符，大廳顯示規格句。
3. 部署白馬義從、陷陣營虎符時，戰鬥日誌顯示規格句。

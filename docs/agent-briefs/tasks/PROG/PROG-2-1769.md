# PROG-2-1769 他國背叛、南蠻掠奪與國家滅亡事件（治理模式他國AI系統 §G）

aiDiplomacyIntents 沒有呼叫端，他國不會背叛玩家；南蠻每 6 季侵襲的規則也沒做；領地歸零的國家照常運作且無人提及。

## 交付

1. 盟友 WARLORD 依 E-5 規則背叛玩家：解除同盟、邦交 -80，大廳顯示規格句。
2. 南蠻每 6 季掠奪玩家糧草與兵力，大廳顯示規格句。
3. 領地歸零的國家標記為滅亡、不再出兵，大廳顯示規格句一次；領地恢復時解除。

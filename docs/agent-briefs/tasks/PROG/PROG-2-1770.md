# PROG-2-1770 他國主動求盟與商隊提議，玩家可接受或拒絕（治理模式他國AI系統 §G）

aiDiplomacyIntents 已能算出 PROPOSE_ALLIANCE 與 PROPOSE_TRADE，但結果沒被使用，玩家從未收到他國提議，§G-1 的兩句文案也沒有出現的地方。

## 交付

1. 每季依 E-5 規則產生他國提議，存進勢力狀態、可存讀檔，到達時大廳提示。
2. 外交畫面顯示待回覆的提議，有接受／同意與拒絕按鈕。
3. 接受求盟即結盟、邦交 +30；同意商隊就交換糧草與黃金、邦交 +5；拒絕商隊邦交 -5。

## notes

狀態: 完成。他國會依 E-5 規則主動求盟或派商隊，大廳提示到達，外交畫面可接受／同意或拒絕。

驗證: 單元測試 5824 通過、3 略過；新增 tests/RivalProposals.test.ts 12 項。Cocos LobbyScene 實跑以真實滑鼠點按鈕：接受蜀求盟後結盟、邦交 50→80；同意吳商隊後糧草 1000→400、邦交 10→15、進入冷卻；換季時大廳出現求盟提示；無頁面錯誤。

變更: 新增 core/systems/RivalProposals.ts；NationState 加 proposal、proposalBlockedUntil 並可存讀檔；resolveRivalPlayerEvents 產生與取消提議；GameSession.respondRivalProposal；RivalDiplomacyController、LobbyScene、rival-diplomacy-main.json 加提議句與兩個按鈕（結果區高度 380→200）。

阻塞: 無。暫定（可逆）：商隊 300 黃金換 600 糧草（比率照 E-6，交易量規格未定）；回覆後同一國 4 季不再提議、一季最多一件新提議（頻率規格未定）；提議等到回覆為止，開戰、滅亡時取消；拒絕求盟邦交不變。未做：PROPOSE_ANTI_HEGEMONY（合縱連橫）沒有玩家介面與文案。

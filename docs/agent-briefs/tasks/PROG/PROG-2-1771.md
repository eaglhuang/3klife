# PROG-2-1771 傭兵第三日、結義與離隊劇本句（傭兵系統 §G）

傭兵系統 §G 的日常互動、結義確認、退場告別三句都沒有出現：試用第三日沒有對話，結義成功沒有提示，離隊提示用的是字串表預設句。

## 交付

1. 試用傭兵走到第 3 日時大廳提示「與主公並肩三日，已知主公非凡人。」
2. 結義成功時提示「{Name} 願誓死追隨主公！桃園之義，永世不渝！」
3. 離隊提示改為「六日之約已盡，{Name} 含淚辭別…」。

# PROG-2-1773 治理事件與季度治理報告（領地治理系統 §G）

領地治理 §G 的「季度治理報告」與「治理事件（蝗災）」都沒有實作：換季時玩家看不到本季治理成果，也不會遇到治理事件。

## 交付

1. 換季時顯示本季治理成果（內政產出加上季結算的糧草與城市兵源）。
2. 換季時有機率發生蝗災：提示玩家，且該季農耕產出 -50%；內政面板看得到事件與減半後的產出。
3. 事件進存檔，舊檔讀回視為沒有事件。

## notes

狀態: 完成。換季顯示本季治理成果；每季 10% 發生蝗災，提示玩家且該季農耕產出 -50%，內政面板顯示事件與減半後的產出；事件進存檔。

驗證: 單元測試 5839 通過、3 略過；新增 tests/GovernanceEvents.test.ts 8 項。Cocos LobbyScene 實跑：換季 toast「本季治理成果：糧草 +150」「郡城 發生蝗災！農耕產出本季 -50%」，內政面板農耕 +60、商業 +100 不變，選農耕實際入帳 60；無頁面錯誤。

變更: 新增 core/systems/GovernanceEvents.ts；DomesticTasks 加倍率與 lastGrant；DomesticPresenter、DomesticPanelController 接倍率與事件句；GameSession 擲骰、報告、存讀檔；PlayerSaveService 與 sync06-patch-whitelist 加 governanceEvent；LobbyScene 換季 toast。

阻塞: 無。暫定（可逆）：規格沒寫機率，暫定每季 10%；只有蝗災一種；領地沒有城名資料，{City} 暫用「郡城」；報告含內政入帳加季結算增加的糧草與城市兵源。事件擲骰用季數與亂數狀態導出的獨立序列，不消耗主亂數。

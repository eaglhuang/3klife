# PROG-2-1774 糧草告急、安胎藥與囚犯傳家寶提示句（經濟系統 §G、道具系統 §G）

季末糧草見底、囚犯交出傳家寶物時玩家都看不到任何提示；安胎藥使用後只顯示通用的「已使用」。

## 交付

1. 季末糧草低於缺糧門檻時，大廳提示「主公，糧草告急！」。
2. 俘虜交出傳家寶物時，大廳提示是哪位囚犯交出的。
3. 道具背包使用安胎藥時顯示規格句；其他道具維持原提示。

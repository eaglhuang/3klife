# PROG-2-1775 結緣出生的血統提示句（血統理論系統 §G、§H）

祖輩因子繼承、EP 共鳴與 Wild Gene 跳星都已生效，但子嗣出生時玩家看不到任何提示。

## 交付

1. 子嗣繼承到祖輩以上的因子時，顯示該祖先的英靈顯現句。
2. EP 共鳴成立時顯示血脈共鳴句。
3. Wild Gene 跳星時顯示基因突變句。

# PROG-2-1781 戰法與奧義的戰鬥訊息進戰報

派發器的 battleLogLines 在派發器之外沒有地方讀取，組合奧義、英靈附體與被擋下的原因，玩家都看不到。

## 交付

1. 組合奧義與英靈附體生效時寫進戰報，雙方都顯示。
2. 玩家的戰法或奧義因條件未達、本場已施放、撤退失敗、精力不足被擋下時，戰報顯示原因；AI 被擋下不顯示。
3. 事件改名為通用的 BattleSkillNotice。

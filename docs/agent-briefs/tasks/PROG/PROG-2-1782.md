# PROG-2-1782 數值表現文案（數值系統 §G-1）

暴擊、SP 蓄滿、轉生突破與 EP 特高都有數值效果，但玩家看不到提示。

## 交付

1. 部隊暴擊時，戰報顯示「天命一擊！{將軍名} 造成 {damage} 點致命傷害！」，傷害是最終結算值。
2. 玩家主將 SP 蓄滿時，戰報顯示「技能能量蓄滿！可發動武將技能！」，只在跨過滿格時說一次。
3. 轉生時顯示「第 {N} 次轉生！屬性上限突破至 {CAP}！」，一批抽卡只說最高的一句。
4. 子嗣 EP 特高時，出生提示加「天賦異稟！爆發力 EP 達到 {EP}！此子前途不可限量。」。

## notes

- 狀態: 完成。暴擊、SP 蓄滿、轉生突破、EP 特高都有提示。
- 驗證: 單元測試 5871 通過、3 略過（tests/run-cli.ts）；tsc 0；Cocos BattleScene 用真實 TroopUnit 與真實結算，戰報面板出現雙方暴擊句（傷害等於實際扣血）；SP 蓄滿只在玩家跨過滿格時出現一次。Cocos LobbyScene 抽卡流程出現轉生突破句，一批兩位只說最高的一句；抽卡結果是 QA 假資料。EP 特高只有單元測試，沒有在畫面上看過。
- 變更: 新增 NumericalScriptLines；BattleCombatResolver 廣播暴擊與 SP 蓄滿；BloodlineBirthLines 加 EP 特高；LobbyScene 接轉生突破。
- 暫定: 部隊暴擊句用同陣營主將名；EP 特高門檻 100；N 是轉數減 1；一批抽卡只說最高的一句。
- 未做: 精力不足句「{將軍名} 體力不支，無法出擊。」。出戰名單本來就只列可出擊的武將，目前沒有觸發點。武將單挑的暴擊也沒有加。

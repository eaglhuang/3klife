# PROG-2-1784 舊資料中文類型的因子顏色納入階段與覺醒規則

generals.json 的 gene.type 是中文分類（戰鬥、戰法、特質…）。normalizeFactorColor 認不得，顏色變成 null，造成：

- 藍、粉因子在一般戰鬥永遠不會覺醒（一般戰鬥只開放藍粉，null 不算）。
- 綠、白、紫、紅因子不受探索等級與觸發方式限制，也一開始就看得到。

## 交付

1. normalizeFactorColor 認得舊資料的中文類型，所有呼叫端一起修正。
2. 單元測試涵蓋覺醒門檻、觸發方式、一般戰鬥覺醒與可見門檻。

## notes

- 狀態: 完成。舊資料的中文類型都會對應到色系，階段與覺醒規則一起生效。
- 驗證: 單元測試 5877 通過、3 略過（tests/run-cli.ts）；tsc 0；Cocos 載入真實 generals.json，在瀏覽器裡直接呼叫 factorMaskView 與 rollBattleAwakening：探索 Lv1 時關羽「義勇」、趙雲「護主」、呂布「狂烈」顯示「??? (Lv21 解鎖)」，Lv99 顯示名字；5 位武將都能在一般戰鬥覺醒（亂數固定）。人物頁畫面沒有打開看。
- 變更: normalizeFactorColor 加上舊資料對應表；resolveFactorColor 改走同一入口。
- 影響: 玩家在探索 Lv21 前看不到人格、特質類因子的名字；戰法類只能由教官、戰場或名士覺醒。
- 阻塞: 無。

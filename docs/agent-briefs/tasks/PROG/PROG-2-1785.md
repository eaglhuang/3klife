# PROG-2-1785 教官窺探句（因子解鎖系統 §G）

規格：窺探是「培育中教官提前暗示鎖住因子的方向」。目前只有名士占卜能預覽方向，培育時教官不會說。

## 交付

1. 訓練回合有教官、這回合沒覺醒、子嗣還有探索等級未到的鎖定因子時，依窺探機率顯示「教官 {Mentor}：此子似乎還藏有{Hint}…」。
2. 只暗示方向，不透露因子名稱，也不改武將資料。

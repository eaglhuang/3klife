# PROG-2-1791 史實名門加成（血統理論系統 §E #7、§G）

規格要袁紹、曹操等有預設家譜的武將初始 EP 更高，並有「四世三公」登場句；程式裡沒有名門的概念。

## 交付

1. 名門表：列出名門武將、EP 加成與登場句。
2. 武將新入名冊時套用 EP 加成，評級跟著更新；重複抽到不重複加。
3. 轉蛋抽到新的名門武將時顯示 §G 句。

## notes

- 狀態: 完成。袁紹、袁術、曹操第一次入名冊時 EP +5，字母評級跟著更新；轉蛋抽到時顯示名門句。
- 驗證: 單元測試 5919 通過、3 略過（tests/run-cli.ts）；tsc 0；Cocos 以真實武將資料入冊並走轉蛋成功流程：袁紹 EP 61→66、B+→A-，模板不變，畫面依序讀到「新增 1 位武將入名冊」「四世三公之後，天生帶有名門因子！」。轉蛋結果是直接餵入的，沒有真的抽中袁紹。
- 變更: 新增 FamousClan；GameSession.enrollGenerals 套加成；LobbyScene 轉蛋成功顯示句子。
- 暫定: 名單（規格只點名袁紹、曹操「等」）；+5；曹操句「譙沛曹氏之後」是自擬的；S 與 S- 的分界 85。
- 未做: 句子說「天生帶有名門因子」，但名門因子沒有定義，目前只有 EP 加成；模板畫面（未入名冊的圖鑑）仍顯示原始 EP；舊存檔已入冊的名門武將不補加；開局名冊不走 enrollGenerals 者不會加。
- 阻塞: 無。

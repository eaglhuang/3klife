# PROG-2-1794 蓋棺論定與生平印記（血統傳承 G2 規格書 §E #7）

規格要武將退位或去世時，依生平戰役與施政成就凝練 1～2 個白因子「生平印記」（如【破虜】【治平】）。程式沒有。

## 交付

1. 純邏輯：印記表與達成條件，寫成白因子，不重複。
2. 退役與去世時套用，發事件。
3. 大廳顯示一句提示。

## notes

- 狀態: 完成。武將退役或死亡時，依生平功業寫入白色印記因子：破虜（殺敵 100 或勝場 10）、治平（政治 80）；有寫入就顯示「蓋棺論定」提示句。
- 驗證: 單元測試 5937 通過、3 略過（tests/run-cli.ts）；tsc 0；Cocos 以趙雲（勝 12、殺 300、政治 74）呼叫 retireGeneral：提示列依序顯示退役句與「蓋棺論定：趙雲 一生功業凝為【破虜】，傳於後世！」，名冊因子多一筆破虜 white Lv1，教官卡 gene_refs 含 imprint_polu。死亡路徑與諸葛亮的治平只有單元測試，沒有實機跑。
- 變更: 新增 LifeImprint；GameSession 加 LifeImprinted 事件，advanceSeason 在季度結算前、retireGeneral 在產生教官卡前寫入；LobbyScene 監聽事件顯示提示句。
- 暫定: 兩個印記的條件與提示句都是自擬；政治用目前能力值判斷，因為沒有逐將施政紀錄；印記是白因子 Lv1，目前沒有實際加成。
- 未做: 印記的數值效果；其他功業類型；死亡者靠歸檔保存印記，沒有另做畫面顯示。
- 阻塞: 無。

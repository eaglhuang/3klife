# PROG-2-1795 門閥四階升格（血統傳承 G4 規格書 §E #1、§F-1）

規格要家族依歷代成材人數、EP 與代表因子，從布衣寒門升到地方豪族、郡望世家、天下高門。程式沒有。

## 交付

1. 純邏輯：從名冊與亡者歸檔算出家族統計與門第階級。
2. 每季檢定，只升不降，寫進存檔，升格時發事件。
3. 大廳顯示升格提示句，血統樹標題顯示目前門第。

# PROG-2-1796 血脈疲勞與外婚復壯（血統傳承 G3 規格書 §E #3、§F-1）

規格要子嗣帶血脈疲勞 h：近婚 +1、外婚 −1；當胎病弱風險外婚 1%，近婚依 h 查表。程式沒有。

## 交付

1. 純邏輯：h 轉移、病弱風險、文案。
2. 結緣時寫入子嗣的 h，擲病弱。
3. 結緣畫面預告，出生時提示。

## notes

- 狀態: 完成。子嗣出生時帶血脈疲勞 h：近婚 max(父,母)+1、完整外婚 max(父,母)-1；當胎病弱風險外婚 1%，近婚依 h 查表 12／20／32／48%。結緣畫面預告，出生時提示。
- 驗證: 單元測試 5955 通過、3 略過（tests/run-cli.ts）；tsc 0；Cocos 結緣畫面按真按鈕：趙雲（h=3）配甄姬顯示「異姓復壯：血脈疲勞 3→2，病弱風險 1%」，張飛（h=1、同血脈）配甄姬顯示「血脈疲勞 1→2，病弱風險 20%」，字沒有超出欄位；按確認結緣後子嗣 h=2，提示列顯示「近親成婚，子嗣血脈疲勞升至 2 階。」。病弱與復壯出生句只有單元測試，實機這次沒擲中病弱。
- 變更: 新增 BloodFatigue；BreedingSystem 加 isInbredPair、資格結果 inbred、子嗣 bloodFatigue、結果 bloodFatigue；BloodlineBirthLines 與 BondingSetupController 顯示；Breeding.test 舊測試亂數由 0 改 0.3，避開新的病弱判定。
- 暫定: 病弱效果規格沒寫，暫定精力上限 ×0.8 並掛 frail-birth 旗標；近婚定義為同血脈或 4 代內有共祖；現有 3 代內共祖仍直接擋結緣，所以實際走得到的近婚只有同血脈與第 4 代共祖；舊武將缺欄位視為 h=0。
- 未做: 外戚 m-only 純化與多樣性 D、規格允許的表親聯姻與同姓不婚判定（要改現有 3 代封鎖規則）；寒門 NPC 水源（沒有 NPC 婚配池，預設就是 0）；h 目前不顯示在人物頁。
- 阻塞: 無。

# PROG-2-1798 退役流程接上榮退太傅文案

血統傳承 G2 規格書 §G「老將榮退太傅」與 §H `UI_G2_RETIRE_TUTOR` 都有文案，退役流程沒有接。

## 交付

1. 第一次按退役時，在職能分流句後顯示轉任宗學太傅的說明，同時保留不能再出戰或結緣的提醒。
2. 高 EP 武將確認退役後顯示老臣句，EP 帶實際數值；其他武將維持原本的退休語錄。
3. 退役回顧會蓋住退役列，語錄也要放進回顧畫面。
4. 回顧畫面拿掉兩句錯誤內容：對已退役武將說「可進行結緣」，以及武職「獲得虎符 ×1」（實際不發，#820 與兵種虎符系統都定為只在死亡結算發）。

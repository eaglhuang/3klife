# PROG-2-1800 郡望家風：族人修業效率 +10%

血統傳承 G4 規格書 §F-1 Tier 2：代表性藍因子列為郡望家風，族人開蒙修業該維度效率 +10%。程式沒有這個效果。

## 交付

1. 升上郡望世家時定下家風：族人持有最多的 3★ 以上藍因子，寫進存檔。
2. 有父母紀錄的子嗣入學後，對應維度的修業收益 +10%。
3. 升格提示、入學提示與血統樹標題顯示家風。

## notes

- 狀態: 完成。升上郡望世家時定下家風（族人持有最多的 3★ 以上藍因子），寫進存檔；有父母紀錄的子嗣入學後，對應維度修業效率 +10%；升格提示、入學提示與血統樹標題都顯示家風。
- 驗證: 單元測試 5972 通過、3 略過（tests/run-cli.ts）；tsc 0；Cocos 用五位三代族人走真的換季：提示列讀到升格句與「郡望家風確立：【軍令】，族人統率修業 +10%！」，存檔快照有 clanTradition；帶一位教官入學，提示與 session 都是統率，computeStatGain 統率 20×1.08×1.1=24、武力 20×1.27=25（無家風加成）；血統樹標題截圖為「門第：郡望世家｜家風：軍令」。
- 變更: 新增 ClanTradition；GameSession 加 clanTradition 與存讀檔；NurtureSystem 在 trainingBoosts 加家風；NurtureService 只對有父母紀錄的子嗣帶入；ServiceLoader 接線；PlayerSaveService 與 sync06 白名單；LobbyScene 提示與血統樹標題；NurtureFlowController 入學提示。

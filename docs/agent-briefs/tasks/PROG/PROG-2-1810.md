# PROG-2-1810 鄉評一鍵篩路線：結緣畫面依公開傾向篩人選

## 交付

1. 結緣畫面加路線鈕，循環切換不限、全才、武骨、才思、統御、治才、風儀。
2. 只用 Layer 1 公開的資訊篩，不洩漏細箱。
3. 可與只看月旦評疊加；某一方篩不到人時保留全部並提示。

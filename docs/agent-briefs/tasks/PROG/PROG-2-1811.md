# PROG-2-1811 天下求親：門閥升到郡望後，名門每年上門提親

血統傳承 G4 §E #4：家族升格為郡望或高門後，天下其他名門每年主動遣媒人攜重禮上門求娶或入贅。

## 交付

1. 年末門第達郡望以上、族中有適齡未婚子弟時，產生一筆提親。
2. 彈窗列出提親家族、對象的鄉評公開資訊、同姓與否、聘禮。
3. 應允：對象進名冊、收聘禮。婉拒：什麼都不發生。稍後：下次進大廳再問。
4. 提親寫進存檔，未回覆的到下一年被新提親取代。

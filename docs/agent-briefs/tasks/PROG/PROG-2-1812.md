# PROG-2-1812 世交相性 K：與聯姻名門的最近 8 名子嗣滑動窗

血統傳承 G3 §E #4、§F-2：按雙家族配對，取最近 8 名滿 18 歲結算子代計算門風契合度 K。G4 §F-1 高門條件的「與 2 個郡望世家滿額相性」也要用到。

## 交付

1. 依規格公式計算 Confidence、P、K，存 Recent_8 位元遮罩、樣本數與歷史累計。
2. 年末把剛滿 18 歲、父母之一來自聯姻名門的子嗣一次性結算，不重複。
3. 結緣畫面顯示 UI_G3_SYNERGY_K_WINDOW。
4. 門第檢定：獨立分支不足 2 條時，可改以 2 家滿額相性達成高門。
5. 嚴禁加回先天能力或傳星機率。

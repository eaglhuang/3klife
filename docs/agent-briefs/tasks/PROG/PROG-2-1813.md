# PROG-2-1813 世交合譜：結緣時鎖定雙親共有因子，K 折抵成本

血統傳承 G3 §E #5、§F-3 途徑②：與聯姻名門結緣時，可鎖定雙親共同持有的 1 項因子必不流失；成本受世交相性 K 折抵，最高 50%（§F-2）。

## 交付

1. 結緣畫面加合譜鈕，循環選擇雙親共有因子；雙親都不是名門或沒有共有因子時不可按。
2. 受孕成功時子嗣必帶所選因子；只有真的保住本會被擠掉的因子才扣成本，受孕失敗不扣。
3. 名門對象進門時帶一項與提親子弟相同的家學因子，否則共有因子永遠不存在。
4. 不改傳星機率，亂數序列不變。

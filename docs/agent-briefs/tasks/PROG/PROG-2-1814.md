# PROG-2-1814 世交太傅伴讀：名門出身的教官依 K 提高修業效率

血統傳承 G3 §F-2 作用面限制：世交相性 K 作用於世交太傅伴讀的修業效率，最高 +15%，不得加回先天能力或傳星機率。

## 交付

1. 教官卡帶出身世家；入學教官含名門出身者時，依該家 K 給全維度修業效率加成，多家取最高。
2. 入學時定值，存進培育會話；之後 K 變動不影響進行中的培育。
3. 入學提示顯示加成；K 為 0 時不顯示。

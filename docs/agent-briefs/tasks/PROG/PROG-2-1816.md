# PROG-2-1816 父系家傳：成婚時免費保住父親 1 項核心因子，與世交合譜共用一槽

血統傳承 G3 §F-3 途徑①：成婚誕生時佔用主門風承襲槽（與世交合譜互斥），不花社交成本，保護父親 1 項核心金／紅／藍因子進入子代。

## 交付

1. 結緣按鈕循環：不用 → 世交合譜各因子 → 父系家傳各因子 → 不用，一次只能選一項。
2. 受孕成功時子嗣必帶所選父親因子，星數照父親；被擠掉才補，不動亂數。
3. 結緣預覽與結果提示顯示家傳內容。

## notes

- 狀態: 完成。結緣時可免費保住父親 1 項核心因子，與世交合譜共用同一顆按鈕，一胎只能選一項。
- 驗證: 單元測試 6088 通過、3 略過（tests/run-cli.ts）；tsc 0；Cocos 開結緣畫面選家傳，看過兩張截圖：按鈕與預覽句正常、受孕後提示「保住了 勇烈」、子嗣帶 5★、黃金未扣、按鈕回到「門風：不用」；另跑一次本就傳下的情況，提示正確。
- 變更: FamilyCompact 加 heritageFactorsOf、applyHeritageLock，抽出共用的 lockFactor；BreedingSystem 與 BreedingService 加 heritageFactorId、heritageRescued；BondingSetupController 改成單一承襲槽；CustomGoldFactor 匯出 id 前綴。按鈕的未選文字由「合譜：不用」改為「門風：不用」，沒有名門對象時也能按。
- 暫定: 核心因子指藍、紅與自創金因子；星數照父親；因子滿額時擠掉排序最後一項；服務層兩者都傳時合譜優先。

# PROG-2-1817 母門擇承：母親或舅氏任主太傅時，開蒙首 3 回合承襲母系因子

血統傳承 G3 §F-3 途徑③：不佔成婚槽，強制綁定母親或外家舅氏擔任主太傅，消耗開蒙首 3 回合課業，從外祖父或母系三代家學中擇 1 項代表性因子寫入子代。

## 交付

1. 出生時記下母系資料：母親與外祖父母的身分、母系三代 3★ 以上因子。
2. 培育第 1 回合、第一位教官是母親或舅氏時，家學研習按鈕可選母門擇承。
3. 走 3 回合，因子以 1★ 寫入，每胎限 1 次，與家學研習名額分開。

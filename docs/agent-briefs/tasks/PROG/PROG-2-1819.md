# PROG-2-1819 外戚血脈純化：命中外戚共祖時，該祖先的藍因子有機會升到 5★

血統傳承 G3 §E #2：28 祖位內有外戚共祖時，該共祖對應的藍因子可推到 5★，代價是近婚的血脈疲勞。

## 交付

1. 祖譜圖能列出兩人的共同祖先。
2. 非同血脈但有共祖的配對，子嗣帶到共祖藍因子時，每胎 1 項有機率 ★+1，最高 5★。
3. 結緣畫面預覽共祖與因子，出生提示顯示 UI_G3_PURIFY_DESC。

## notes

- 狀態: 完成。非同血脈但 28 祖位內有共祖的配對，子嗣帶到共祖的藍因子時，每胎 1 項有 30% 機率 ★+1，最高 5★。
- 驗證: 單元測試 6113 通過、3 略過（tests/run-cli.ts）；tsc 0；Cocos 建四代族譜開結緣畫面看過截圖：預覽列出共祖與因子、血脈疲勞 0→1、出生提示純化句、子嗣該項 3★ 升 4★。
- 變更: 新增 KinPurification.ts；BloodlineGraph 加 commonAncestors；BreedingSystem 在門風連攜之前判純化，中了就不再判連攜；BreedingService 加 kinPurificationTargets；BondingSetupController 加預覽與出生提示。
- 暫定: 規格的 m-only 要有上限 m 才成立，現有星數不受 m 限制，所以做成機率升星，也就違反規格「不改變傳星抽樣機率」的字面；機率 30% 沿用近親純化暫定值；共祖不限星數；因子要真的傳到子嗣才判；提示句把規格的註換成這胎實際星數。
- 未驗證: 提示句補上「此胎得 N★」是看完截圖後才改的，這句只有單元測試；同血脈與外戚共祖重疊的配對 Cocos 沒走過。
- 未做: G3 §G 譜牒官預警劇本句；多樣性 D；同血脈的舊近親純化沒有統一成這套；3 代封鎖還在，實際只有第 4 代共祖能觸發，與規格允許表親衝突。

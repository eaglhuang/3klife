# PROG-2-1821 開蒙禮與加冠禮：培育中兩次先祖遺風覺醒與適性突破

G1 規格 §E #3、#5 與 §F：12 歲開蒙禮與 16 歲加冠禮各做一次獨立形成檢定（q=0.0591），並演出先祖遺風覺醒；加冠禮另做兵種適性突破。

## 交付

- core/systems/EnrollmentRites.ts：祖輩關係、形成檢定、遺風覺醒、適性突破、提示句
- NurtureService：親手培育與太傅代管都會補上到期的儀式，每胎各一次
- 培育畫面：§G 典禮句走 toast，§H 覺醒句接在提示列
- tests/EnrollmentRites.test.ts

## notes

- 狀態: 完成。第 1 回合後辦開蒙禮、第 24 回合後辦加冠禮，親手培育與太傅代管都會辦；各做一次 q=0.0591 形成檢定，沒形成就喚醒星等最高的沉睡因子；加冠禮另把祖輩階級較高的兵種適性升一階。
- 驗證: 單元測試 6127 通過、3 略過（tests/run-cli.ts）；tsc 0；Cocos 實跑：休息一回合後提示「【開蒙覺醒】趙統 展現了來自父親 趙雲 的【神槍】資質！」，代管後提示「【加冠大成】…【騎兵】適性突破至 S 階！」，騎兵 A 變 S，ritesDone 兩項都有；典禮 toast 已浮在培育面板之上（截圖確認）。
- 變更: 新增 EnrollmentRites.ts；NurtureService 加 performDueRites，train 與 GameSession.runAutoNurture 共用；NurtureSession 加 ritesDone；培育提示列與 toast 接句；ToastMessage 顯示時移到最上層，修掉面板內 toast 被遮罩蓋住的既有問題；AptitudeView 匯出 APTITUDE_GRADES。
- 暫定: 開蒙在第 1 回合結束時辦（規格是 12 歲入學時）；形成的因子 1★ 且直接現身，每次最多 1 個；適性突破不擲骰、不要求紅因子，只看祖輩有沒有更高階，每次升一階；子嗣沒有該兵種適性視為 C；已辦記號放培育會話，放棄重修會再辦一次，已得的因子與適性保留。

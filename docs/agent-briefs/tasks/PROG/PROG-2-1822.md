# PROG-2-1822 器局巔峰曲線：早慧、中堅、晚成與文武年齡分流

G2 規格 §E #5、§F：早慧 19–27、中堅 24–35、晚成 29–42；過峰後武力依斜率下滑，智政魅維持 95%～100% 高原。

## 交付

- core/systems/PeakCurve.ts：曲線判定、戰場倍率、提示句
- BattleRoster.battleStat 套用倍率，只影響有實力層的武將
- GeneralAging 發出過峰事件，大廳顯示老而彌堅句
- 武將詳情年齡列顯示曲線
- tests/PeakCurve.test.ts

## notes

- 狀態: 完成。培育武將依早慧 19–27、中堅 24–35、晚成 29–42 算巔峰窗；過峰後戰場武力每年掉 1.5%、最低 60%，智政魅每年掉 0.5%、最低 95%；剛過峰時大廳顯示老而彌堅句；人物頁年齡欄顯示曲線名，年齡取整。
- 驗證: 單元測試 6137 通過、3 略過（tests/run-cli.ts）；tsc 0；Cocos 實跑：推進一季跨過 42 歲時出現老而彌堅 toast；同數值的晚成武將 42 歲與 62 歲比較，武力依斜率下降、智力停在高原、統率不變；人物頁截圖確認年齡欄顯示「42 歲・晚成」且字級正常。
- 變更: 新增 PeakCurve.ts；BattleRoster.battleStat 套倍率；GeneralAging 加 passed-peak 事件；GameSession 加 GeneralPassedPeak 頻道；LobbyScene 接 toast；GeneralDetailOverviewMapper 與 GeneralDetailBasicsChild 顯示曲線。OverviewAge 版面寬度由 53 改 137，原本照「34 歲」定寬，字變長會被縮到看不見。
- 暫定: 斜率與下限都是自擬，規格只說「依衰退斜率」與 95%～100%；曲線依 id 決定，抗命的大器晚成固定晚成，規格沒寫怎麼分配；只套用有實力層的培育武將，卡面成年武將不變，否則現有 233 位 30 多歲武將會整批變弱；巔峰前不打折；統率與運氣規格沒提，不動；戰法槽位仍用未打折的智力，避免變老後已學戰法被擠掉。
- 規格衝突: 既有 LIFE-02 年齡係數把 40～55 歲定為壯年巔峰（×1.1），與 G2 的巔峰窗不同；兩者目前各管各的，LIFE-02 只在戰力評分與 applyAgeToStats 使用。
- 未做: 健康任期 H 與 ΔH_aging 的消耗，所以提示句拿掉「消耗氣血壽元」那段；H 耗盡時的告老還鄉或病篤；出生時依 G3 或因子決定曲線；人物頁只顯示曲線名，沒顯示窗口年齡與目前折扣。
- 阻塞: 無。

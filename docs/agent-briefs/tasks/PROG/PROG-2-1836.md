# PROG-2-1836 血脈清濁燈號，結緣畫面顯示清朗到枯竭與當胎、殘留風險

## 交付

- 結緣畫面估算區新增獨立一行，顯示燈號、當胎病弱風險與子嗣殘留階數。
- 單元測試與 Cocos 實跑截圖。

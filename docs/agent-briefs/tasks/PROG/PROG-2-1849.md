# PROG-2-1849 玩家永久擁有的武將從他國名冊移除

他國名冊只在開局排除玩家已有的武將（RivalOfficers：同一位武將不能同時在玩家與他國陣中）。開局後才招到的武將仍留在他國名冊，繼續計入對方軍力。

## 交付

- 每季推進前，把玩家名冊裡的武將（含已結義傭兵）移出他國名冊，並卸下其虎符。
- 試用中的傭兵不移除，離隊後仍屬原勢力或市場。
- 單元測試與 Cocos 實跑。

# PROG-2-1850 部隊踏上擅長或極差的地形時飄字提示

戰場適性系統 §E-10「適性反饋」：地形格已有底色差異，但武將站上適性高／低的地形沒有提示。

## 交付

- 我方部隊移動到不同地形時，主將該地形適性為 S、A 或 D 就飄字，文字用規格 UI_APT 字串。

- 單元測試與 Cocos 實跑截圖。

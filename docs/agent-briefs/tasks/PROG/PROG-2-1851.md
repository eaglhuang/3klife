# PROG-2-1851 戰場顯示智謀能量條與軍師摘要

## 交付

- 戰場新增垂直智謀條，隨回合由下往上填充，觸發全局增幅時噴發金色粒子。
- 戰場新增軍師摘要條，顯示本回合危害、互動物件、回收累計、推薦戰法缺口，全空時隱藏。
- 不擋戰場點擊；單元測試與 Cocos 實跑截圖。

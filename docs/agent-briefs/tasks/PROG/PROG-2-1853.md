# PROG-2-1853 戰場武將名牌旁加精力能量環

武將壽命系統 §UI 可視化要求：武將頭像旁應有精力狀態的常駐提示（火苗、氣焰或能量環）；精力充足用飽和冷色／紫光，接近枯竭改灰暗或弱火；不取代數值，玩家仍要讀到百分比。目前戰場沒有頭像節點，武將以名牌（GeneralLabel）加 Q 版立繪呈現，名牌旁沒有精力提示。

## 交付

- 純邏輯：精力比例、區段（充足／中段／枯竭）、百分比文字與對應顏色。
- 戰場雙方武將名牌左側加能量環，弧長等於精力比例，環中顯示百分比；隨名牌刷新。
- 單元測試與 Cocos 實跑截圖（充足、中段、枯竭三種）。

## notes

- 狀態: 完成。戰場雙方武將名牌左側新增精力能量環：弧長等於精力比例，環中顯示百分比；精力過半為紫色，10%～50% 為琥珀色，低於 10% 為灰色。名牌刷新時一起更新。
- 驗證: 單元測試 6310 通過、3 略過（tests/run-cli.ts）；tsc 0；Cocos 在 BattleScene 實跑截圖：我方 72% 紫環、敵方 30% 琥珀環；改為我方 5% 灰環、敵方 100% 滿圈紫環，數字都可讀，無錯誤。精力值是測試時直接設定的。
- 變更: VitalityBarView 加 vitalityRingView 與 VITALITY_RING_COLORS（區段沿用 vitalityBandOf）；UnitRenderer 的武將名牌加 VitalityRing 節點（Graphics 底環＋精力弧＋百分比 Label）；新增 tests/VitalityRing.test.ts；更新 spec-audit-lifespan 與 D-1a 缺口紀錄。
- 暫定: 戰場沒有武將頭像節點，改放在名牌左側；半徑 24、線寬 6；顏色紫／琥珀／灰；我方能量環會稍微壓到左側兵種卡邊緣（名牌本身原本就會壓到）。
- 規格衝突: 無。
- 未做: 火苗或氣焰動態效果（只做靜態能量環）；大廳或詳情頁頭像旁的提示。
- 阻塞: 無。

# PROG-2-1854 主城倉庫清單可逐件選取並鎖定或解鎖

武將背包（倉庫）系統 §鎖定保護：重要裝備可鎖定，防止誤賣或誤分解。目前只有武將詳情的裝備挑選可以切換鎖定；主城倉庫清單只顯示「（已鎖定）」，不能逐件選取。

## 交付

- 倉庫面板新增「上一件／下一件」選取與「鎖定／解鎖」按鈕；選取的列加標記，超過一頁時清單跟著翻頁。
- 鎖定切換寫入 GameSession.setInventoryLocked，提示列顯示結果；換排序時保留選取的那一件。
- 單元測試與 Cocos 實跑截圖。

## notes

- 狀態: 完成。主城倉庫面板的排序鈕改成一列四鈕（排序、上一件、下一件、鎖定／解鎖）。選取的列尾加「◀」，選到第二頁以後清單跟著翻頁，前後以「…前有／另有 N 件」帶過。鎖定切換寫入 GameSession.setInventoryLocked，提示列顯示「已鎖定／已解鎖 [品質] 名稱」，按鈕文字跟著改；換排序時仍選同一件。
- 驗證: 單元測試 6315 通過、3 略過（tests/run-cli.ts）；tsc 0；check:ui-spec strict 通過；Cocos 在 LobbyScene 實跑：在倉庫放 11 件測試物品後打開面板，用真的按鈕按兩次下一件、按一次鎖定，選到第三件（UR 英靈卡），存檔列 isLocked 變 true、按鈕改為「解鎖」、清單加註（已鎖定）。再移到第 10 件，清單翻到第二頁。截圖確認一列四鈕不重疊。測試物品是直接塞進 session 的。

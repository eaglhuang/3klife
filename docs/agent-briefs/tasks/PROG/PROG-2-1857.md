# PROG-2-1857 戰後結算視窗加「關卡回收」摘要

關卡設計系統 §I-2/I-3 Stage_Salvage 戰後一次結算。回收物在戰後已入帳（PROG-2-1571），戰中提示條已有（PROG-2-1851/1852），但戰後結算視窗沒有任何回收摘要，玩家看不到這場帶回了什麼。d2-d3-pending-ui「關卡回收摘要」列的戰後摘要卡未接。

## 交付

- StageSalvageSettlement 加 salvageSummaryLines(salvage, won)：勝或平列「關卡回收：…」與補給轉糧草說明；戰敗且有回收時列「戰敗，回收物未能帶回」；沒有回收時不列。
- BattleUIBridge 戰後結算把這些行放進結算視窗明細與戰場日誌。
- 更新 d2-d3-pending-ui 過時的兩列。
- 單元測試與 Cocos 實跑截圖。

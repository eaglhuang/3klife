# PROG-2-1862 Boss 親衛隊召喚接進戰場敵方部署階段

關卡設計系統（doc_spec_0049）Boss AI：「在特定將軍（如呂布、曹操）作為敵方主將時，血量降到 50% 以下自動召喚親衛隊，阻擋玩家直接斬首」。BossGuardSummon（PROG-2-0599）只有觸發判定，沒有任何地方呼叫。

## 交付

- BossGuardSummon 加 Boss 名單、親衛隊編成（盾兵 2 隊，暫定）、站位（後排最靠中間的空路線）與戰報句。
- BattleState 記本場是否已召喚；敵方部署階段先判定並生成親衛隊，再照常部署，不耗敵方糧草。
- 戰報提示「呂布危急，親衛隊現身護主！」。
- 更新 d1a-rejudge；單元測試與 Cocos 實跑。

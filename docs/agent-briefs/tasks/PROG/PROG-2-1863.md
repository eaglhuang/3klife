# PROG-2-1863 水攻場景水門佔領回收

關卡設計系統（doc_spec_0049）G-2 水淹圍堵「水門、堤防與漂流物的控制權可在戰後結算為水路情報與補給回收」，§I 把 Floodgate 列為四種正式互動物件之一。目前水門沒有對應格子效果，軍師 HUD 不會列出（d1a-rejudge 關卡設計系統列）。

## 交付

- 水攻開局在淺灘最上游、最靠中路放一格水門（新格子狀態 scene-floodgate，不影響移動與傷害，棋盤金色標示）。
- 我方回合，我方部隊站上水門即佔領：移除水門，Stage_Salvage 記入情報與補給（暫定 5／150，受運勢加成），飄金色字。
- 軍師 HUD 列水門存活／已回收；水淹範圍重算時不再放。
- 更新 d1a-rejudge；單元測試與 Cocos 實跑。

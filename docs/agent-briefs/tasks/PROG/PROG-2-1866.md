# PROG-2-1866 戰場適性台詞與 Toast 事件接上畫面

掃描 EVENT_NAMES 發現有發送卻沒人接收的事件：
- AptitudeDialogue：BattleController 每回合依地形、天氣選出戰場適性系統（doc_spec_0041）§G 的台詞（含「風向突變」天氣變化台詞），但畫面沒接，玩家看不到。
- ShowToast：ActionCommandComposite 大招 SP 不足時發「奧義蓄力中，SP 不足」，畫面沒接。

## 交付

- BattleUIBridge 訂閱 AptitudeDialogue：寫進戰報並浮 Toast。
- BattleUIBridge 訂閱 ShowToast：交給 deployRuntime 的 Toast 佇列。
- 單元測試與 Cocos 實跑；更新 d1a-rejudge。

## notes

- 狀態: 完成。
- 驗證: Cocos BattleScene 實跑：我方步兵上場、天氣轉大風後觸發適性台詞，畫面中央 Toast 顯示「風向突變——張飛：大風來襲！火攻將更具威力！」並寫進戰報；發 ShowToast 時顯示「奧義蓄力中，SP 不足」；0 錯誤，截圖確認。單元測試 6350 通過；compute-gate 通過。
- 變更: BattleUIBridge 訂閱 AptitudeDialogue（寫戰報＋Toast，停留秒數與 key 用 AptitudeDialogue.aptitudeToastPayload）與 ShowToast（交給 deployRuntime Toast 佇列）；IDeployRuntimeLike.showToast 的 options 加 key；d1a-rejudge 補記。
- 觀察: 語系字串只在 LobbyScene 載入，若直接從登入畫面跳戰場（預覽／QA）台詞會顯示成 i18n 鍵；正常經大廳進戰場不受影響。
- 未接: 同一掃描另有 WeatherChanged（台詞已涵蓋）、FortressDamaged、BuffApplied、單挑三事件、DuelPenaltyApplied、BattleSpeedToggled（加速鈕無效果）、ShowSettingsRequested（戰場設定鈕無反應）、GameModeChanged 只發不收，待後續卡判斷。

# PROG-2-1867 戰場控制列 x2 加速鈕生效

主戰場UI規格補充_v3（doc_ui_0003）v3-2 控制列 Auto／x2／⚙。BattleLogComposite 按 x2 只發 BattleSpeedToggled，沒有任何地方接收，按了沒效果。

## 交付

- BattleTimeScale：把 director.tick 的 dt 乘倍率（Unity Time.timeScale 的對應），切回 1 還原，不疊乘。
- BattleUIBridge 訂閱 BattleSpeedToggled 套用倍率；unsubscribeEvents（離開戰場）還原 1，避免大廳也快轉。
- 單元測試與 Cocos 實跑；更新 cross-ref 進度。

## notes

- 狀態: 完成。
- 驗證: Cocos BattleScene 實跑，量 2 秒 scheduleOnce 的實際耗時：1 倍 2029ms；按控制列 x2 後 1071ms；再按回 1 倍 2059ms；開著 x2 離開戰場回登入畫面後 2033ms（已還原），0 錯誤。單元測試 6353 通過；compute-gate 通過。
- 變更: 新增 BattleTimeScale（包裝 director.tick 乘倍率，切回 1 還原、不疊乘）；BattleUIBridge 訂閱 BattleSpeedToggled，unsubscribeEvents 時還原 1；cross-ref 進度補上。
- 注意: 加速作用在整個引擎畫面（動畫、tween、scheduleOnce、Spine），戰鬥規則不變；瀏覽器 setTimeout 型的延遲不受影響。

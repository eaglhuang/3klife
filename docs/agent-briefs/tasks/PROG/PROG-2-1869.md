# PROG-2-1869 單位中 Buff／Debuff 時頭頂飄狀態名

主戰場UI規格書（doc_ui_0001）§3.2 戰鬥飄字：Buff/Debuff 以文字提示（如「暈眩」）。戰法與反擊施加狀態時會發 BuffApplied，但沒有任何地方接收，玩家看不出哪個單位被暈眩、定身。

## 交付

- battle/shared/StatusEffectLabel：七種狀態的中文名（沿用既有用字）。
- BattleUIBridge 訂閱 BuffApplied，在該單位位置飄狀態名；陣亡、找不到單位或未知狀態不飄。
- 單元測試與 Cocos 實跑；更新 cross-ref 進度。

## notes

- 狀態: 完成。
- 驗證: Cocos BattleScene 實跑，放我方、敵方步兵各一並發 BuffApplied（疾行、暈眩），兩個單位頭頂分別出現「疾行」「暈眩」飄字，0 錯誤。單元測試 6357 通過；compute-gate 通過。
- 變更: 新增 battle/shared/StatusEffectLabel（七種狀態中文名，沿用既有用字）；BattleUIBridge 訂閱 BuffApplied 走既有 status 飄字；陣亡／找不到單位／未知狀態不飄；cross-ref 進度補上。
- 注意: 只在發 BuffApplied 的地方飄（戰法施加狀態、反擊虛弱）；其他直接 applyBuff 不發事件的路徑不在本卡範圍。規格 §3.1「血條上方顯示 Buff 數值變化」另案。

# PROG-2-1870 單位頭頂數值帶出 Buff 增減量

主戰場UI規格書（doc_ui_0001）§3.1：狀態數值要顯示 Buff 帶來的變化，如「35 (+10)」。目前單位上排的攻、命標籤只把數字變綠，不顯示增減量，減益也同樣是綠色。

## 交付

- battle/shared/StatBonusText：數值加增減量字串與顏色分級（增益綠、減益紅、無變化白）。
- UnitRenderer 攻、命標籤套用；字串變長時單行縮字塞進徽章。
- 單元測試與 Cocos 實跑；更新 cross-ref 進度。

## notes

- 狀態: 完成。
- 驗證: Cocos BattleScene 實跑，我方步兵攻 +10、命上限 +20，敵方步兵攻 -5 後重繪：我方顯示「45 (+10)」「120 (+20)」綠色，敵方「30 (-5)」紅色、命「120」白色；截圖確認徽章內單行縮字、未破版；0 錯誤。單元測試 6360 通過；compute-gate 通過。
- 變更: 新增 battle/shared/StatBonusText（字串與顏色分級）；UnitRenderer 攻、命標籤套用並改單行縮字；以前減益也顯示綠色，現改紅色；cross-ref 進度補上。
- 注意: 增減量以「有效值 − 基礎值」計算（含士氣、虎符適性等乘數）；命欄的增減量是生命上限加成。
- 規格衝突: 無。
- 阻塞: 無。

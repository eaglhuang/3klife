# PROG-2-1871 結算面板一律顯示本場擊殺與回合數

主戰場UI規格書（doc_ui_0001）§4.2 結算面板數據：本場擊殺數、回合數。目前本場戰績（斬敵）只在名冊出征的戰鬥才列出，回合數完全沒有；內建戰鬥的結算面板沒有任何數據。

## 交付

- formatPerformance 可附本場回合數。
- 結算摘要不論有無出征資料都列本場戰績（斬敵、傷害、守護、回合）。
- 單元測試與 Cocos 實跑；更新 cross-ref 進度。

## notes

- 狀態: 完成。
- 驗證: Cocos BattleScene（內建戰鬥，無名冊出征）實跑，發 BattleEnded 後結算面板說明欄出現「本場戰績：斬敵 0｜傷害 0｜守護 0｜回合 1」，0 錯誤。單元測試 6360 通過；compute-gate 通過。
- 變更: formatPerformance 加可選回合數（0／負數／NaN 不附）；_settleRosterBattle 不論有無出征資料都列本場戰績；cross-ref 進度補上。
- 注意: 回合數取 services().battle.getSnapshot().turn（戰鬥結束當下的回合）。內建戰鬥現在也會把本場戰績寫進戰報一行。
- 規格衝突: 無。
- 阻塞: 無。

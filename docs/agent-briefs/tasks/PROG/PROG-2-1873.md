# PROG-2-1873 單挑鈕條件不足時灰度加鎖頭

- BattleGeneralDuelFlow／BattleController.generalDuelBlockReason：不改狀態的出陣檢查，原因與 startGeneralDuel 相同（startGeneralDuel 改共用）。

- BattleUIBridge 每次刷新戰場畫面時套用。
- 單元測試與 Cocos 實跑；更新 cross-ref 進度。

# PROG-2-1875 小兵被暴擊時飄字用暴擊樣式

主戰場UI規格書（doc_ui_0001）§3.2：暴擊為橘金粗體放大數字。主將受擊已依 isCrit 切暴擊樣式，但小兵受擊的 UnitDamaged 事件沒帶 isCrit，暴擊時仍是一般紅藍字。

## 交付

- BattleCombatResolver.applyUnitDamage 加 isCrit 選項，UnitDamaged 帶出（連鎖分攤不算暴擊）；普攻結算傳入。
- battle/shared/DamageFloatType.ts：unitValueFloatType 樣式選擇（純邏輯）。
- UnitRenderer.playValueChange 支援 isCrit；BattleUIBridge 轉傳，戰報加《暴擊》。
- 單元測試與 Cocos 實跑；更新 cross-ref 進度。

## notes

- 狀態: 完成。
- 驗證: Cocos BattleScene 實跑：對我方步兵發 isCrit 受傷事件，飄字「-37」為暴擊樣式（字級 60、橘紅 255,60,0）；敵方騎兵一般傷害「-12」維持原樣式（字級 44），截圖確認；0 錯誤。單元測試 6370 通過（新增 UnitCritFloat：樣式選擇、applyUnitDamage 帶出 isCrit）；tsc 0；UI spec strict 與 content-contract、compute-gate 通過。
- 變更: BattleCombatResolver.applyUnitDamage 加 isCrit 選項並帶進 UnitDamaged（普攻結算傳入，連鎖分攤不帶）；新增 battle/shared/DamageFloatType.ts；UnitRenderer.playValueChange(Async) 加 isCrit；BattleUIBridge 轉傳並在戰報加《暴擊》；cross-ref 進度補上。
- 注意: 戰報《暴擊》字樣只做了程式碼檢查，實跑探針沒讀到戰報文字（戰報不是一般 Label）。代為承傷時 isCrit 隨選項轉給護衛。
- 規格衝突: 無。
- 阻塞: 無。

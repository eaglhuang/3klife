# PROG-2-1876 部署列不可部署格覆蓋紅色

主戰場UI規格書（doc_ui_0001）§3.3：不可部署格以紅色網格覆蓋。目前部署列只有空格亮綠，被占或地格擋住的格子沒有任何提示。

## 交付

- battle/shared/DeployCellHint.ts：deployCellHint，與 tryDeployTroop 同一套判斷（被占、blocksOnEnter）。
- BoardRenderer 部署提示：open 用綠材質、blocked 用既有紅材質（enemyDeployHintFillMaterial，原本未使用）。
- 單元測試與 Cocos 實跑；更新 cross-ref 進度。

## notes

- 狀態: 完成。
- 驗證: Cocos BattleScene 實跑：第 0 路部署格放我方步兵、第 3 路設 blocksMovement 地格後開部署提示，覆蓋材質為第 0、3 路紅色，第 1、2、4 路綠色，截圖確認；0 錯誤。單元測試 6372 通過（新增 DeployCellHint，含與 tryDeployTroop occupied 一致）；tsc 0；UI spec strict 與 content-contract、compute-gate 通過。
- 變更: 新增 battle/shared/DeployCellHint.ts（deployCellHint）；BoardRenderer 部署提示 open 綠、blocked 紅（沿用原本未使用的 enemyDeployHintFillMaterial）；cross-ref 進度補上。
- 注意: 紅色材質透明度偏低，畫面上是淡紅；若要更醒目可調該材質顏色，或之後換成紅叉圖示（需美術）。

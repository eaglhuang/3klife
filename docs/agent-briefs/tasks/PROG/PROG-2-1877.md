# PROG-2-1877 結算面板依勝敗切換外觀

主戰場UI規格書（doc_ui_0001）§4.2：勝利時有彩帶／光芒，失敗時色調灰暗。目前結算面板不論勝敗外觀相同。

## 交付

- shared/ResultPopupTone.ts：勝／敗／平的標題色、是否轉灰、是否彈入（純資料）。
- ResultPopupComposite：勝利深朱紅標題彈入；失敗整張卡轉灰、灰色標題；每次顯示都重設。
- 彩帶／光芒粒子需美術素材，不在本卡範圍。
- 單元測試與 Cocos 實跑；更新 cross-ref 進度。

## notes

- 狀態: 完成。
- 驗證: Cocos BattleScene 實跑：showResult('enemy-win') 卡片與頭像轉灰、標題灰色；接著 showResult('player-win') 灰階全部重設、標題深朱紅並彈入，兩張截圖確認；0 錯誤。單元測試 6375 通過（新增 ResultPopupTone）；tsc 0；UI spec strict 與 content-contract、compute-gate 通過。
- 變更: 新增 shared/ResultPopupTone.ts；ResultPopupComposite._applyResultTone（每次顯示重設灰階、標題色、縮放）；cross-ref 進度補上。
- 注意: 原本試用金色標題，壓在金色卡面上看不清，改深朱紅。彩帶／光芒粒子需美術，未做。實跑時發現棋盤地格標籤（如「★ 生命 / 5」）會疊在結算窗之上，屬既有圖層問題，未在本卡處理。
- 規格衝突: 無。
- 阻塞: 無。

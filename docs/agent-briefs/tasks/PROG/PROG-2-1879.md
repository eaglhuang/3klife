# PROG-2-1879 結算窗全螢幕深色遮罩生效

主戰場UI規格書（doc_ui_0001）§4.2：結算面板為「全螢幕深色遮罩 + 中央大型卡片」。實跑發現場景的 Canvas/Popup host 的 Widget 只設置中（alignFlags=18）、尺寸 100×100，底下撐滿父節點的 Overlay 也只有 100×100，被卡片擋住，背景戰場完全沒變暗。

## 交付

- ui/core/WidgetStretch.ts：讓 Widget 四邊貼齊父節點（結構型別，可單元測試）。
- ResultPopupComposite.show()：顯示時把 host 撐滿 Canvas，遮罩因此蓋滿全螢幕。
- 單元測試與 Cocos 實跑；更新 cross-ref 進度。

## notes

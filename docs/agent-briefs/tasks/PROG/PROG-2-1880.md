# PROG-2-1880 拖曳部署時懸停格綠色高亮

主戰場UI規格書（doc_ui_0001）§3.3：「選中：該格子顯示綠色高亮框」、「部署預覽：出現在游標懸停的格子上」。目前拖曳虎符卡部署時，只有影子跟著手指走，棋盤上手指所在的格子沒有任何回饋，要放開才知道會落在哪一路。

## 交付

- battle/shared/DeployCellHint.deployCellStyle：可部署格被懸停時改用選中高亮，不可部署格仍維持紅色（純邏輯）。
- BoardRenderer.setDeployHoverCell：記住懸停格，格子變動時才重繪；新增較亮的選中綠框材質。
- DeployComposite：拖曳中回報手指位置，結束拖曳時清除；IDeployPanelLike 加選用 registerDragHoverCallback。
- BattleScene：懸停位置射線換成格子後交給 BoardRenderer。
- 單元測試與 Cocos 實跑；更新 cross-ref 進度。

## notes

- 狀態: 完成。
- 驗證: Cocos BattleScene 實跑：把第 3 路部署格的螢幕座標餵進 DeployComposite 懸停回呼，經 BattleScene 射線換回同一格（2,0），棋盤該格亮起選中綠框；回報 null 後清除，前後截圖確認；0 錯誤。單元測試 6384 通過（新增 DeployHoverCell）；tsc 0；compute-gate 通過。
- 變更: DeployCellHint.deployCellStyle；BoardRenderer.setDeployHoverCell 與選中綠框材質；DeployComposite.registerDragHoverCallback；IDeployPanelLike 選用方法；BattleScene 接線；cross-ref 進度補上。
- 注意: 規格「部署預覽：半透明單位模型」仍以現有黃色影子標籤代替，未在格子上放半透明單位，留待後續。

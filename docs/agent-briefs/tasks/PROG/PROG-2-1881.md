# PROG-2-1881 網路狀態指示器狀態錯亂修正與測試

UI技術規格書（doc_ui_0049）對應的 NetworkStatusIndicator 在 cross-ref 進度表「測試」欄為 ❌。檢查時另發現兩個錯誤：

1. 恢復連線／同步完成後排定「1 秒後淡出」，但這段時間內若開始同步或再次斷線，計時沒有取消，黃燈或紅燈會被誤藏。
2. 淡入／淡出只在透明度剛好為 0 或 255 時才動作；漸變進行中來的新狀態會被忽略，圖示可能卡在半透明或消失。
3. EventSystem.onBind 沒有以 target 為 this 呼叫 handler；指示器傳入 this.onOnline 等成員方法，一收到事件就拋 TypeError（Cannot read properties of undefined），元件實際上從未正常運作。
4. 類別上分開寫了 `@requireComponent(Sprite)` 與 `@requireComponent(UIOpacity)`，後者被前者覆蓋，UIOpacity 從未自動補上；淡入淡出因 null 檢查直接跳過，圖示不會隱藏。

## 交付

- ui/core/NetworkIndicatorState.ts：事件 → 顏色／顯示／轉圈／自動淡出秒數（純資料）。
- NetworkStatusIndicator：改用狀態對應；任何新事件先取消上一次的自動淡出；淡入淡出先停掉進行中的動畫再走向目標值。
- NetworkStatusIndicator 改為 `@requireComponent([Sprite, UIOpacity])`。
- EventSystem.onBind：以 target 為 this 呼叫 handler，銷毀時解除同一個包裝函式（與說明範例 `onBind(..., this.onUnitDied, this)` 一致）。
- 單元測試（含 onBind）與 Cocos 實跑；更新 cross-ref 進度。

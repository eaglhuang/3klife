# PROG-2-1882 武將列表排序缺值錯亂修正與測試

UI技術規格書（doc_ui_0049）對應的武將列表在 cross-ref 進度表「測試」欄為 🟡。進度表列的 GeneralListPanel 已廢止、無程式引用，實際使用的是 GeneralListComposite。

檢查 GeneralListComposite 的欄位排序時發現：數字欄位（年齡、武力等）遇到缺值時改用字串比較，同一個比較函式對數字用大小、對缺值用字串，結果前後矛盾，排序會錯亂，缺值武將在升冪時還會排到最前面。

## 交付

- ui/core/GeneralListSort.ts：排序純函式，缺值（含無兵種適性）不論升降冪一律排最後；穩定排序。
- GeneralListComposite 改用此函式。
- 單元測試；更新 cross-ref 進度。

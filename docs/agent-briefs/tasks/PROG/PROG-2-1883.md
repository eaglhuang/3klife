# PROG-2-1883 材質系統測試與預設服裝共用陣列修正

keep.md（doc_index_0011）§7 對應的 MaterialUtils／MaterialSystem 在 cross-ref 進度表「測試」欄為 ❌。檢查時發現兩個問題：

1. captureOutfit 在單位未綁定時回傳 { ...DEFAULT_OUTFIT }，只是淺複製；回傳值的顏色陣列與 DEFAULT_OUTFIT 是同一個，呼叫端一改就污染全域預設值。
2. bindUnit 一開始就為單位建立空的實例表；Shader 未載入而回傳 null 時，空表仍留在記憶體中。

## 交付

- captureOutfit 預設值改為深複製；bindUnit 先查不建表。
- 單元測試：setMaterialSafe 兩種路徑、bindUnit 實例與失敗、applyOutfit／captureOutfit 往返、預設值不被污染、受擊邊緣光與溶解夾值、releaseUnit。
- 更新 cross-ref 進度。

# PROG-2-1885 白馬虎符卡面與被動不一致修正、戰法系統 G 節核對

戰法系統（doc_spec_0038）在 cross-ref 進度表只登記 ActionSystem.ts，「邏輯」欄為 🟡。逐項核對 G 節戰法大清單時發現：

- G-1 虎符戰法 25 條「殼」（主動技不可施放）的效果其實已由 TallyPassive 被動實作；只剩南蠻勇士、南蠻豹騎兩條特殊戰法規格未定。
- 白馬虎符卡面寫「騎兵移動不變」，但規格 G-1（Move + 1）與 TallyPassive（moveRangeBonus: 1）都是移動 +1，卡面說明與實際效果不符。

## 交付

- TallyCardCatalog 白馬卡面改為「移動 +1」。
- 測試：卡面說明的移動加成與射程取自被動數值比對。
- 更新 cross-ref 進度。

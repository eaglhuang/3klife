# PROG-2-1889 戰場頂部陣地長條改顯示城寨血量

使用者 2026-11-06 裁決：城寨要顯示血條。規格 doc_ui_0001 §2.1 要求頂部「我軍陣地／敵軍陣地」血量條（我方藍、敵方紅）。現況該長條被主將血量佔用，城寨血量（BattleState.playerFortressHp／enemyFortressHp，開場 500）只寫進戰報，畫面上看不到。

## 交付

- 新增 core/systems/FortressBarView.ts（FORTRESS_MAX_HP 與填充比例純邏輯），BattleState 改用該常數。
- BattleHUDComposite 訂閱 FortressDamaged，頂部長條改顯示城寨比例；頭像旁標籤維持主將血量；我方長條改藍色；開場與重新開始回滿。
- 單元測試 tests/FortressBarView.test.ts。

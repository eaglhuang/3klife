# PROG-2-1891 戰場敵方回合「敵軍行動中…」提示

規格 doc_ui_0001 §4.5：敵方思考中顯示帶狀 Banner「敵軍行動中...」，加掃光或呼吸效果。現況 TurnFlowManager 呼叫 showEnemyThinkingPanel／hideEnemyThinkingPanel，但 UI 端沒有任何實作，敵方回合期間畫面上沒有提示。

## 交付

- 新增 UCUF enemy-thinking-screen（layout／skin／screen）與 EnemyThinkingComposite：HUD 下緣的暗紅細帶，透明度呼吸、句尾點數循環。
- 新增 core/systems/EnemyThinkingView.ts（文字與呼吸參數純邏輯）。
- IDeployRuntimeLike 加可選 setEnemyThinkingVisible，由 DeployComposite 實作（與回合橫幅共用疊加層建立函式）。
- 提示從敵方回合開始顯示到我方回合開始（finalizeAdvance）；戰鬥結束時也收起。
- 單元測試 tests/EnemyThinkingView.test.ts。

# PROG-2-1893 戰場軍師摘要加環境加成百分點

規格 doc_ui_0001 §6.3：地形／天氣／適性／場景增幅應在 HUD 以「百分點摘要」呈現（例：地形 +10%、夜戰 -5%），避免玩家誤以為每項都是獨立乘區。現況戰場 HUD 沒有任何環境加成摘要。

## 交付

- 新增 core/systems/EnvironmentBonus.ts：適性等級換攻擊百分點、組摘要文字（略過 0%、同名只列一次）。
- StrategistHudSource 依我方主將對本場天氣與場上地形的適性組出摘要，接進軍師摘要條與戰場日誌（「環境 雨天 -10%、山地 +20%」）。
- 地形中文名 TERRAIN_LABEL 搬到 shared/BattleEntryParams（battle 層不可 import ui），EnvScoutPresenter 轉出保持既有引用。
- 單元測試 tests/EnvironmentBonus.test.ts。

# PROG-2-1894 Toast 停留 2 秒後上浮消失

規格 doc_ui_0001 §4.1：Toast 出現 2 秒後自動上浮消失。現況未指定時長時只停 1.2 秒，消失時只淡出、不會上浮。

## 交付

- 新增 core/systems/ToastMotion.ts：預設停留 2 秒、最短 0.2 秒、淡出 0.3 秒、上浮 40px。
- ToastMessage 消失時同時淡出並上浮，每次顯示先回原位；收起時停止位移。
- 未指定時長的 Toast（DeployComposite.showToast、SHOW_TOAST 事件）改為停留 2 秒；有指定時長的呼叫照舊。
- 單元測試 tests/ToastMotion.test.ts。

## notes

- 狀態: 完成。
- 驗證: 新增 ToastMotion 3 項測試；單元測試 6431 通過；tsc 0；模組邊界、compute-gate 通過。未在 Cocos 實機截圖（主工作樹編輯器由他人使用）。
- 變更: 新增 ToastMotion.ts；ToastMessage 消失改為淡出＋上浮 40px，顯示前回原位、收起時停止位移；未指定時長預設停留 2 秒（DeployComposite.showToast、SHOW_TOAST）。有指定時長的呼叫照舊。
- 影響: 大廳等其他畫面未指定時長的 Toast 也從 1.2 秒改為 2 秒（共用同一元件）。
- 阻塞: 無。

# PROG-2-1912 退役功業累積祠堂聲望並存檔

MVP 全流程最後一段：退役時把一代功業換成祠堂聲望，累積進 GameSession 並存讀檔（doc_spec_0310 §3）。

## 交付

- GameSession：clanPrestige／clanPrestigeTier；retireGeneral 依將階、戰績 kills、wins 累加聲望並發 ClanPrestigeChanged 事件。
- PlayerSaveService：選填欄位 clanPrestige 與 normalizeClanPrestige，舊檔缺值為 0。
- tests/ClanPrestigeSave.test.ts；server/schema/sync06-patch-whitelist.ts 補欄位。

## 暫定

規格「斬將數」尚無獨立計數，暫用戰績 kills（擊破敵部隊數）。

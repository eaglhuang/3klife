# PROG-2-1971 統一主卡旗標 isPrimary／Family_Primary_Flag

英靈卡的「主卡」目前有兩個欄位，彼此不同步：

- `InventoryRecord.isPrimary`：FamilyContribution、SpiritSlotFlow、SpiritSlotState 讀寫。
- `Attributes.Family_Primary_Flag`：InventoryProjection（Spirit_Card_Collection 投影）與 SpiritFamilyReadModel 讀。

## 待做

接英靈卡存檔時統一成單一真相（建議以 isPrimary 為準，投影時寫出 Family_Primary_Flag），並補一支同步測試。先不要實作，等接存檔時處理。

## 交付

- shared/SkillRuntimeContract.ts：`UltimateSpecialRuleDef`、`CanonicalUltimateDefinition.specialRule`。
- battle/skills/special/SpecialRuleDispatch.ts：kind 路由與預設目標。

- BattleSceneLoader `findUltimateSpecialRule`；BattleController 接上。
- tests/SpecialRuleDispatch.test.ts：五條規則各一項派發整合測試＋白名單外拒絕。

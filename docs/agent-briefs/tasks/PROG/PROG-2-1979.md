# PROG-2-1979 死亡觸發接進陣亡流程

BattleCombatResolver.onUnitKilled 在 UnitDied 之後呼叫 settleDeathTriggers：取出陣亡單位的死亡觸發並結算，取出即清，每個掛勾只觸發一次。

## 交付

- SpecialRuleDispatch.ts：`settleDeathTriggers`（掛勾 id 對應帶 specialRule 的奧義定義，以陣亡者陣營為施放方套用）。
- BattleCombatResolver context `getUltimateSpecialRule`；BattleController 接上。
- tests/SpecialDeathTriggerSettle.test.ts：從 onUnitKilled 一路驗到 BattleState 改變。

# PROG-2-1980 奧義資料 specialRule 盤點

依 ultimate-definitions.json 的 description（奧義規格文字）找出描述涉及「復活／增益轉移／行動條重置／死亡觸發／場勢切換」的奧義，逐一核對能否填 `specialRule`。

## 結論：本卡不填任何 specialRule

能明確對應的兩個奧義，綁定的 battleSkill 已經用既有 resolver 實作了同一效果；再填 specialRule 會讓 PROG-2-1978 的派發層再套用一次，效果加倍。其餘奧義的描述與五條規則的語意不一致，依指示不猜。

## 疑點清單（交使用者裁決）

| 奧義 id | 描述 | 對應 kind | 疑點 |
|---|---|---|---|
| ult-cao-cao-2 唯才是舉 | 復活一名已陣亡友軍，恢復 50% HP | REVIVE（reviveHpRatio 0.5） | battleSkill `cao-cao-ult-revive` 已用 effectKind revive 實作；要改走 specialRule 就得移除舊 resolver 路徑，二擇一 |
| ult-liu-bei-4 漢室餘暉 | 立即重置 1 名友軍行動條 | RESET_ACTION（extraActions 1） | battleSkill `liu-bei-reset` 已用 effectKind reset 實作；同上二擇一 |

## 建議

- 曹操 2、劉備 4：維持既有 resolver，不填 specialRule（推薦）；或改走 specialRule 並移除舊路徑。
- 其餘 6 個：需要規格補定義（或擴充規則）才能填。

# PROG-2-1989 同步安全規範：HTTPS 強制與 PII 過濾（SYNC-09）

依同步API規格書 §7：所有請求強制 HTTPS（dev 環境例外）；Action_Records payload 不得包含 PII。

## 交付

- server/src/sync-security.ts（findPii、findPiiInRecords、requireHttpsMiddleware）
- server/src/sync.ts（/sync、/sync/delta、/sync/actions 回放前檢查 PII，含 PII 回 400；createSyncApp 可選 requireHttps）
- server/src/index.ts（NODE_ENV=production 時 /sync 路由強制 HTTPS）
- tests/SyncSecurity.test.ts

## notes

- 狀態: 完成。
- 驗證: run-cli ALL PASS 6910（含 in-process 端到端）；tsc 0 錯；compute-gate standard 通過。
- 暫定: PII 規格未列舉，暫定欄位名清單（email、phone、realName、address、idNumber、passport、birthday、password、creditCard 等，忽略大小寫與底線）＋字串規則（含 email、整串是 9 碼以上電話號碼）；含 PII 整批拒絕，不做遮蔽。
- 暫定: HTTPS 判定看 req.secure 或 x-forwarded-proto（假設正式環境在反向代理後；直連時該標頭可被偽造）；非 HTTPS 回 403；/healthz 不擋。規格錯誤碼表沒有對應碼，未給 code。
- 阻塞: 無。

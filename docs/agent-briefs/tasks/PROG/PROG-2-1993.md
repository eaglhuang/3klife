# PROG-2-1993 先退役後死亡的英靈卡與虎符補發（SPI-01）

名將身後傳承規格（doc_spec_0570）§2.2、TC-RET-BOUNDARY、TC-LEG-02；使用者裁決 2026-11-08：退役轉教官卡當下不產英靈卡，之後壽終死亡原子補發英靈卡與虎符卡。

## 核對結果

- 英靈卡：SpiritCardDeathSettlement 已經對退役者補發（Has_Retired_Before 標記），一致。
- 虎符：TallyDeathSettlement 原本跳過 isMentorCard，退役者死亡不補發虎符，與裁決不一致，已改。

## 交付

- core/systems/TallyDeathSettlement.ts：不再跳過退役教官卡；重複結算仍由 before 已陣亡與 uid 已存在擋下
- core/managers/GameSession.ts：_settleDeaths 先算完虎符與英靈卡兩條線再一起寫入（原子）
- tests/RetireDeathTallyChain.test.ts：兩個舊測試從「退役者死亡不發虎符」改成「補發一張且不重複」
- tests/RetireSpiritTallyBackfill.test.ts：TC-RET-BOUNDARY、TC-LEG-02、不重複、存檔往返、舊存檔已死者不補發

## notes

- 狀態: 完成。
- 暫定: 不碰退役年齡（11/06 裁決 60 歲可榮譽退役，規格寫 65 歲，等使用者）。
- 暫定: 「原子」指同一次結算兩條線先算完再一起寫入；兩條線仍各自依資格產出（非名將沒有英靈卡但有虎符，沿用 SPI-12 的獨立產出線）。
- 未做: 舊存檔中「已退役並已死亡」的武將不回頭補發（結算只處理存活轉死亡的那一刻）；需要的話要另開補發遷移，請使用者決定。

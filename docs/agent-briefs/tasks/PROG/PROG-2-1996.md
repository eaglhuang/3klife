# PROG-2-1996 釋放敵將頓悟接線（LVL-13）

使用者第二份裁決：「超過 10 人以上」＝ count >= 10（含 10）；頓悟優先習得未學會的教官專屬戰法，全部學會才改既有戰法 Level +1；軍師演武 P2 延後，不開卡。

## 交付

- core/systems/ReleaseEpiphany.ts：pickEpiphanyGain、resolveReleaseEpiphanyWithTactic（沒有戰法收穫＝不觸發、不扣軍資）
- core/managers/GameSession.ts：resolvePrisoner 放走成功後呼叫 _applyReleaseEpiphany；回傳多 epiphany 欄位，花費併入 goldSpent（既有 PrisonerPopupController 會照扣，免改 UI）
- tests/ReleaseEpiphanyWiring.test.ts

## 暫定值（回報）

- 門檻本來就是 >= 10，一致，沒改。
- 「教官專屬戰法」= 名冊中 isMentorCard 武將的 learnedTactics 聯集（沒有另外的專屬戰法資料表）。
- 軍資 = resolvePrisoner 傳入的黃金（PrisonerPopupController 傳的是錢包黃金），消耗 500 暫定值未變。
- Level +1 = tacticExp[戰法庫 id] +100（TacticRandomization 的經驗制，滿級 5 級不再選）。
- 受惠武將只含存活、非教官卡者；沒有通知 UI。

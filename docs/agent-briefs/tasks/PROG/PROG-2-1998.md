# PROG-2-1998 虎符灌注層級攻防加成

使用者第二批裁決：虎符每升 1 階（★1~★5），特種部隊攻防基礎值 +6%。層級資料來自血脈灌注（PROG-2-2081 顯示、PROG-2-2099 同步入口 GameSession.tallyInfusionLevelOf）。

## 交付

- core/systems/TallyInfusionBonus.ts：clampTallyInfusionLevel（0~5）、tallyInfusionStatMultiplier（1 + 0.06 × 層級）。
- core/systems/TigerTallyStar.ts：TallyBattleInfo 加選填 infusionLevel；tallyBattleInfoOf(card, infusionLevel = 0)。
- battle/controllers/BattleController.ts：bindTallyAffinity 的 tallyStarMultiplier = 星級倍率 × 灌注倍率（沒帶層級＝舊行為）。
- tests/TallyInfusionBonus.test.ts

## 未接上（要回報）

- 實際把層級帶進戰場的那一行在 BattleScene.ts:155（BAT-1-0001 鎖定，不可動）：
  `this.ctrl.tallyInfoOf = (tallyId) => { const card = ...tallyCards[tallyId]; return card ? tallyBattleInfoOf(card) : null; }`
  需改成 `tallyBattleInfoOf(card, services().session.tallyInfusionLevelOf(card.templateId))`。在那行改之前，戰場上灌注加成不會生效（等於 0 層）。
- 「專屬兵種戰法發動率 +3%」沒有對應掛點，使用者未裁決，未做。

- 舊檔已灌注過的英靈卡沒有帳本，層級回 0（PROG-2-2099 說明）。

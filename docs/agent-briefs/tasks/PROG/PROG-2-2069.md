# PROG-2-2069 命鏡 Loading 接進場景切換並輪播武將（BML-05）

依 WBS BML-05 驗收：場景切換時顯示命鏡 Loading，可輪播含未持有角色（《血脈命鏡過場載入規格書》§8）。原本命鏡畫面在執行期沒有套用 state 內容。

## 交付

- core/systems/MirrorLoadingRotation.ts：輪播名單（每 3 格一位未持有）。
- ui/core/UIBloodlineMirrorLoading.ts：依契約套 state 內容、標題換武將名、輪播。
- LoadingScene：正式模式在載入背景上蓋命鏡畫面並輪播，失敗保留原背景。
- tests/MirrorLoadingRotation.test.ts。

## 暫定

輪播比例、名單長度、停留秒數為暫定值；武將立繪尚未換圖。

## notes

- 狀態: 完成。
- 驗證: 單元測試 6912 通過；tsc 0；compute-gate 通過。
- 變更: 新增命鏡 Loading 輪播名單（core）與 state 套用／輪播（ui/core），LoadingScene 正式模式掛命鏡畫面並每 2.5 秒換一位，新增 5 項測試。
- 取捨: 輪播比例 1/3、長度 6、2.5 秒為暫定；立繪未換圖；未在 Cocos 實機驗證。
- 阻塞: 無。

# PROG-2-2103 軍事任務接取後下一場戰鬥判定場景戰法（SCN-04）

依《戰法場景規格書》(doc_spec_0039) B-1、B-2：場景戰法唯一來源是軍事任務，接取後下一場戰鬥自動套用，依 INT、情報門檻與成功率判定。

## 交付

- core/systems/HallSceneGambit.ts：任務資料、存檔還原、判定結果。
- core/systems/SceneGambitRules.ts：判定公式自 battle/shared 搬入，原路徑轉出。
- LobbyHubSchema、HallMissionBoard、lobby-hub.json：Scene_Gambit 欄位，夜襲敵營帶夜襲。
- GameSession、PlayerSaveService、sync06 白名單：記錄、判定、存檔。
- LobbyScene、ui/core/HallSceneGambitText.ts：接取與開戰提示、注入 battleTactic。
- tests/HallSceneGambit.test.ts。

## 暫定

發動者用本場主將；未達門檻保留到下一場；任務失敗不記；其餘五種戰法尚無對應任務；提示文案皆暫定。

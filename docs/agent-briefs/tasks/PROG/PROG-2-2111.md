# PROG-2-2111 治理存檔 Server 表（GOV-13）

領地治理系統.md §I「Server 端」列了 player 治理狀態表（Player_ID / Territory_Level / Auto_Mode / Season_Output_JSON）。WBS GOV-13 驗收為「往返一致」。客端本機已有太守府等級與自動治理（GameSession），伺服端沒有表與列驗證。

## 交付

- server/schema/012_governance_state.sql：`player_governance_state` 表（僅定義、未部署）。
- server/schema/gov13-governance-row.ts：`governanceStateToRow`（清理後轉列）、`rowToGovernanceState`（壞列丟錯）、`validateGovernanceStateRow`、`normalizeSeasonOutputs`、`governanceStateValidator`（給記憶體表）。
- tests/ServerSchemaGov13.test.ts：往返、各欄位錯誤、產出紀錄格式與遞增、清理規則、記憶體表、DDL 欄位一致。

## 暫定（規格只寫「每季產出紀錄 TEXT」）

- Season_Output_JSON 存 JSON 陣列，每筆 `{ season, food, gold, fame, troops, intel }`，五項資源對應本機端 Season_Report 的 Food/Gold/Fame/Troops/Intel；season 為累計季數（非負整數），嚴格遞增。
- Territory_Level 1~5（與客端 TERRITORY_MAX_LEVEL 同值；server 不 import 客端碼，數字另寫一份，上限改動時要同步）。
- 字串長度上限 64KB。

## 未做（要回報）

- 沒掛進 HTTP 路由（與 BAG-11、OFC-10、RET-13 同層級）。
- 客端目前沒有存「每季產出紀錄」的欄位（只有當季報告文字），組 `seasonOutputs` 需由呼叫端提供；客端是否要新增歷史欄位屬另案。

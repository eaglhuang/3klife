# PROG-2-2112 任務詳情派遣武將下拉只列可派遣名冊

實跑發現任務詳情的武將下拉列出約 240 位（整本圖鑑 `_generals`），內容高 13488。大廳系統 §E-9「行動人物必須提供下拉選單供玩家指派武將」，指派對象應是玩家名冊。

## 查證

- 來源：`LobbyScene._buildMissionDetailGeneralOptions` 用 `this._generals`（載入的武將資料表全量）。
- 規格 §E-9 只說「提供下拉選單供玩家指派武將」，沒寫可派遣條件；名冊可出戰規則已有 `GameSession.getDeployableGenerals()`（BattleRoster.listDeployable）。

## 交付

- core/systems/MissionGeneralOptions.ts：`buildMissionGeneralOptions`（名稱・稱號、自薦者排前、同 id 去重、無人時空陣列）。
- ui/scenes/LobbyScene.ts：`_buildMissionDetailGeneralOptions` 改用 `session.getDeployableGenerals()`。
- tests/MissionGeneralOptions.test.ts。

## 暫定

- 「可派遣」＝可出戰名單（排除死亡、退役教官、未畢業子嗣、精力不足、培育中）；精力不足者暫不列。
- 沒有可派遣武將時不再回頭列圖鑑；彈窗自帶「未指定武將」占位。

## 未驗證

- 未實機截圖（第二編輯器未在本卡範圍內啟動）；下拉內容高度改善待實跑確認。

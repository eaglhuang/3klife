# PROG-2-2113 文字對比修正

實跑回報三處字色與底色對比不足：虎符圖鑑淡字配淺底、人物頁 UR 標籤深字配紅／綠底、沙盤右側賽季卡淺金字配淺金底（標題幾乎看不清）。

## 查證

- 沙盤賽季卡：`SeasonCard` 用 `popup_card_bg`（金色漸層，取樣平均 #E3BB72），內部四行文字共用深底列表的 `secondaryLight`（#FFE088），對比約 1.1。
- 虎符圖鑑：卡片是薄荷淺底（#BACCB7）卻用白字／金字；詳情面板（#ECE6D7）用白字、金字；頁首標題用深墨字壓在深色匾額（#2A241E）上；頁首狀態徽章是羊皮紙底配白字；側欄的統計摘要是淺底配金字；側欄內文 #6B5E4E 壓在深底上。靜態計算多組低於 3:1。
- 人物頁稀有度標籤：`OverviewRarityTier` 是帶 Sprite 的底板，文字在子節點；`_applyRarityPill` 用 `binder.getLabel` 只找得到底板，字色套不上，維持 skin 的深墨色 `gdv3InkDeep` 壓在紅／綠底。另外綠、藍底原本配白字也只有約 2.8～3.1。

## 交付

- ui-spec/skins/sandtable-territory-default.json、layouts/sandtable-territory-main.json：新增 `onCard` 深墨字樣式，只套在 `SeasonCard` 的四個文字；深底列表維持原淺金字。
- ui-spec/skins/elite-troop-codex-default.json、layouts/elite-troop-codex-main.json：各字色改為對自己的底色達 4.5:1；新增 `etc.label.meta.onLight` 給側欄淺色摘要面板的三行統計。
- ui/core/UIContrast.ts（新）：稀有度標籤配色與 WCAG 對比度函式。綠／藍／紅底壓暗，白字皆 >= 4.5。
- ui/components/character-ds3/CharacterDs3OverviewChild.ts：標籤文字與字色改用 `ds3Label` 往子節點找，確實套上；配色改引用 UIContrast。
- tests/UiTextContrast.test.ts：對比守門（每組字色對底色 >= 4.5、版面指到正確樣式）。

## 暫定

- 底色用貼圖取樣平均色（測試內有註明檔案），漸層貼圖局部較亮／較暗處的實際對比可能略有差異。
- 虎符圖鑑卡片文字一律改深墨色（不再分金／白階層），之後要做階層可在深墨與 `textOnParchmentMuted` 之間調整，但要先換深一點的底。
- 稀有度標籤的底色：綠 #2E7D32、藍 #1565C0、紅 #C62828；金底（傳說）維持深字。

## 未驗證

- 未實機截圖：預覽（7456）載入 LobbyScene 逾時，第二編輯器開在別人的工作樹；以靜態對比計算與測試代替。上線前請在預覽確認三處視覺。
- 人物頁標籤「文字內容」現在會依武將稀有度更新（原本卡在版面預設的 UR）；如有武將資料的 `rarityLabel` 與推算稀有度不一致，標籤文字與底色可能不匹配，另案看資料。

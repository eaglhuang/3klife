# PROG-2-2124 武將列表改用統一 UI（使用者指示）

使用者指示：武將列表原本借人物頁的羊皮紙與薄荷框拼成，文字難讀；複雜的部分砍掉，改成與目前 UI 一致的純色做法。

## 交付

- general-list-main 版面：標題靠左、關閉鈕右上、列加頭像、拿掉性別欄。
- general-list-default 皮膚：只留用到的槽，全部純色。
- GeneralListComposite：頭像依可見範圍載入；對話測試開關只在開發入口顯示；沒人可退役時收起退役列。

## 暫定

排序、選將模式與退役流程都保留；退役列按鈕仍是純文字，沒有底色。

# PROG-2-2129 底色半透明不壓暗子節點

盤點 33 個畫面發現半透明底色把文字與頭像一起壓暗（按鈕字僅剩 26%），來源幾乎都是 SolidBackground。

## 交付

- SolidBackground：透明度烘進共用 alpha 貼圖，sprite.color 恆不透明。
- GradientBackground：tint 透明度乘進像素。
- 直接寫 sprite.color 的呼叫端改走 setSpriteFillColor。
- tests/SolidBackgroundAlpha.test.ts。

## 暫定

美術圖 Sprite 的 slot alpha 與 UIOpacity 維持原行為。

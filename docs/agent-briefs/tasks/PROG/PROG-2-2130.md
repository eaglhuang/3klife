# PROG-2-2130 動態 ZOC 移動阻擋（FORM-09）

依《育成與戰鬥公式基準手冊》§7.1、§7.2：武將以 STR 壓制，在周圍格子產生高移動成本或不可通行區域，INT 可反制。

## 交付

- battle/shared/ZoneOfControl.ts：壓制等級與區域計算。
- BattleAutoMovePhase：一般前進、踐踏落點、換位接上區域。
- tests/ZoneOfControl.test.ts。

## 暫定

門檻與成本規格未定，暫定 1.5 倍高成本、2 倍不可通行、額外 1 點、範圍 1 格；棋盤顯示與聖域另案。

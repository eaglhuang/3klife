# PROG-2-2147 粉色因子血統同因子升階接進子嗣與戰場（APT-09）

pinkFactorAptitude 有「14 人血統中 5 人以上攜帶同因子時升一級」，但 battleAptitudeProfileOf 沒傳祖先數，戰鬥中永遠不會觸發。受孕時統計祖先數存到子嗣，戰場讀取。

範圍外：舊子嗣回補、兵種適性因子（字典目前只有三個地形因子）、畫面顯示升階來源。

## notes

- 狀態: 「14 人血統中 5 人以上攜帶同因子升一級」在戰場生效：受孕時統計並存到子嗣，battleAptitudeProfileOf 讀取。
- 驗證: 單元測試 7305 通過；tsc 0；compute-gate 通過。測試走 breed、名冊正規化、JSON 存讀、GeneralUnit 到戰場適性。沒有實跑編輯器，也沒有打實際戰鬥。
- 變更: BreedingSystem.pinkFactorAncestorCounts 與受孕寫入；GeneralConfig 與 GeneralUnit 的 pinkAncestorCounts；battleAptitudeProfileOf 傳入祖先數；BattleController 與 BattleScene 未動。
- 取捨: 存快照而不是戰場即時查族譜，因為戰場沒有族譜資料且接線檔被鎖。已出生的子嗣沒有這個欄位，不會升階，未做回補。依席位計算，近親時同一祖先佔多席算多次，與 EP 標籤統計一致；規格是否要去重未確認。字典目前只有三個粉色地形因子，兵種適性不在範圍內。
- 阻塞: 無。

# PROG-2-2148 教官卡詳情接上被動效果與培育事件（MENT-13）

詳情頁三頁籤與星等鎖頭已有，但 mentorToCardData 寫死事件與小插曲為空，支援效果只有一列，所以玩家看到的培育事件永遠是空的。支援卡的靈感事件與被動減免已在 mentorFromCard 寫進教官，改為從教官讀取；空頁籤顯示「暫無資料」。

範圍外：小插曲內容（資料表沒有這一欄）、Training_Rate 被動（程式沒有讀取，列出來等於顯示沒生效的加成）。

## notes

- 狀態: 教官卡詳情的培育事件頁有內容了，支援效果多列出生效中的被動減免，專長顯示中文，空頁籤顯示「暫無資料」。小插曲仍無內容。
- 驗證: 單元測試 7309 通過；tsc 0；compute-gate 通過。測試逐張跑過 15 張正式支援卡：事件都有中文名且放得進六列。第二編輯器呼叫 openMentorCardDetail 開三個頁籤，鎖頭與暫無資料正常；傳入的是手寫卡資料，沒有從大廳點進持有卡與培育入口。
- 變更: MentorCardTabs.mentorToCardData 改從教官讀 inspire 與被動減免，新增 specialtyLabel 參數；toMentorCardLayoutState 補空頁籤；MentorHoldingRows 與 NurtureFlowController 傳專長名稱。
- 取捨: 被動只列教官身上已生效的，未解鎖的不顯示鎖頭列；目前資料的被動都是 ★0，所以沒有差異，日後有高星被動要改。Training_Rate 程式沒有讀取，不列出，避免顯示沒生效的加成。家傳戰法只標「（家傳）」，不寫血統條件，血統代碼沒有中文名。鎖頭文字沿用既有「需達 ★n 才可發動」。
- 阻塞: 無。小插曲要等資料表有內容。

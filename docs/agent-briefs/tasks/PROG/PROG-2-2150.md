# PROG-2-2150 出征極速決戰Auto-Resolve與武將個性單挑演算法（LOOP-02）

## 1. 核心目標與問題

目前出征戰鬥必須走完整個五路棋盤戰場，戰鬥時長過長且缺乏快節奏推進機制，導致玩家反覆刷關卡或刷養成資源時極易疲勞。此外，武將在戰鬥中的個性表現（如猛將單挑、謀士奇計）缺乏直觀的反饋，且戰場覺醒（Q52 checkAwakeningQuota）目前未在戰場中接通。
本任務建立「極速決戰（一鍵演武）」機制，讓玩家可在 3 秒內觀看生動動態戰報完成出征，並接通戰場覺醒與戰後結算。

## 2. 核心功能規格

1. **出征雙軌選擇**：
   - 玩家點擊出征陣容確認後，提供「親自指揮（進戰場）」與「極速決戰（一鍵推演）」雙按鈕。
2. **極速決戰推演演算法（3 秒動態文字流）**：
   - 依據雙方出征武將的五維綜合實力、兵種互克（騎剋步、步剋弓、弓剋騎）與地形適性計算基礎勝率。
   - **個性化特寫事件（機率觸發，穿插於戰報）**：
     - **猛將單挑（武力 ≥ 90）**：如關羽、張飛、呂布，40% 機率觸發「【陣前斬將】{猛將}策馬突入敵陣，十合之內斬落敵將馬下！」➔ 敵軍士氣崩潰，勝率直接 +25%。
     - **軍師奇謀（智力 ≥ 90）**：如諸葛亮、周瑜、郭嘉，40% 機率觸發「【奇計伏兵】{軍師}預設火網陷阱，敵軍先鋒中伏大亂！」➔ 我方戰損降低 50%。
     - **仁德呼應（魅力 ≥ 85）**：如劉備，25% 機率觸發「【義軍響應】鄉勇紛紛倒戈來附！」➔ 戰後額外獲得戰俘與民心。
3. **戰場覺醒接通（Q52 落地）**：
   - 戰鬥大捷（Major Victory）且出征武將滿足 EP/血脈潛力門檻時，呼叫 `checkAwakeningQuota`。
   - 每場戰鬥最多覺醒 1 位武將的 1 個因子，彈出「【因子覺醒】{武將}於死鬥中頓悟，解鎖新因子！」特效。
4. **戰後產出流轉**：
   - 獲得武將經驗、銅錢、裝備掉落、虎符經驗，並自動累積戰績（勝/負次數）。

## 3. 驗收條件

- 單元測試：驗證 Auto-Resolve 演算法在極端數值（碾壓、均勢、劣勢）下之勝率符合預期，無死循環。
- 覺醒配額：確認單場戰鬥嚴格遵守「最多覺醒 1 個因子」上限。
- 結算相容：與既有 ResultPopup 和雙卡結算（英靈/虎符）無縫銜接。

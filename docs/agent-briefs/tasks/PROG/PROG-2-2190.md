# PROG-2-2190 人物頁血脈分頁套用因子遮罩、灰鎖與解鎖亮起（FUL-03）

玩家實際看到的 DS3 血脈分頁（CharacterDs3BloodlineChild）沒有套用因子遮罩：等級不足也看得到紫、白等因子的名稱與說明。舊版 GeneralDetailBloodlineChild 有遮罩，但不是正式入口；而且 FactorMaskPresenter 算好的 justRevealed 沒有人讀，亮起動畫從未播放。規格《因子解鎖系統》：灰色鎖頭→彩色亮起的動畫。

範圍外：結緣畫面的因子列、舊版 GeneralDetailBloodlineChild、第一次看到的武將（沒有舊狀態可比）、跨重開遊戲保存舊狀態。

## notes

- 狀態: DS3 血脈分頁套用因子遮罩：未達發現等級名稱顯示 ???、說明欄顯示 Lv N 解鎖，灰字；已看見的用因子色；重開或切回後剛解鎖的因子播放放大再縮回的動畫。
- 驗證: 單元測試 7312 通過；tsc 0；compute-gate 通過。用使用者開好的編輯器（7456）實跑，暫時把兩個原始檔複製到主目錄，跑完已還原：Lv1 藍因子亮、白紫灰字 ???，說明欄 Lv N 解鎖；升到 Lv21 白因子轉亮並放大（量到 1.2 倍），紫仍灰。測試用手寫武將資料直接開面板，並直接改 session 等級，不是實際升級流程。
- 變更: CharacterDs3BloodlineChild 接遮罩、字色與亮起；FactorMaskState 新增 factorLabelTint、Presenter 改依武將分開保存；更新 CharacterDs3BloodlineView 與 WiringBatch0513 測試。
- 取捨: 第一次看到的武將沒有舊狀態可比，不播動畫；舊狀態只存在記憶體，重開遊戲後也不播。色碼用 FACTOR_TAG_COLORS（裁決第 4 題）。舊版 GeneralDetailBloodlineChild 不是正式入口，未動，其 justRevealedSlots 仍無人讀取。戰鬥類舊型別（戰鬥等）經 normalizeFactorColor 對應成因子色。
- 阻塞: 無。
- 編號: 原編號 PROG-2-2149，與主控 Antigravity 同時新開的 MVP 閉環卡撞號，改用此號。提交紀錄仍為舊編號。

# PROG-2-2192 教官卡 Training_Rate 進訓練公式（裁決 17a）

資料有 Training_Rate，規格《教官支援卡四大原型》寫明它干預陪伴乘區 M_Training，但培育公式沒有讀取。裁決 2026-11-09 第 17a 題定為實作生效。站在同一格訓練的教官，其值加進 trainingBoosts；教官卡詳情顯示這項效果。

範圍外：運勢與人數補正乘區、資料數值調整。

- 狀態: Training_Rate 接進訓練公式：教官站在同一格訓練時，其值加進陪伴乘區 M_Training；教官卡詳情列出這項效果（裁決第 17a 題）。
- 驗證: 單元測試 7314 通過；tsc 0；compute-gate 通過。未實跑畫面，教官卡詳情的新效果列未親眼確認。

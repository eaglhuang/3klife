# PROG-2-2193 修幕府大廳版面：任務牆疊字、寬螢幕黑邊

使用者回報幕府大廳完全壞掉。查出兩個原因：任務牆內的牆頭、任務列與列內文字都沒有定位，全部疊在面板中央；底圖固定 1920 寬靠左，比 16:9 寬的視窗右側露黑邊。

範圍外：幕府大廳與主大廳功能重疊的取捨（待使用者裁決）、任務牆資料內容、頂部資源列的實際數值。

## notes

- 狀態: 任務牆的牆頭、任務列與列內文字都有定位，不再疊字；底圖依視窗寬度放大並置中，消除寬螢幕黑邊；人物與對話框改為置中定位；勢力圖回到中央，季節色層跟著地圖；階段標籤照設計稿只在聚焦時顯示；左上主將頭像不再壓到名稱。
- 驗證: 單元測試 7320 通過；tsc 0；compute-gate 通過。用使用者開好的編輯器（7456）實跑 1917×931（可視寬 2335）與 1920×1115 兩種比例，暫時複製改動到主目錄，跑完已還原。任務列用 QA 手動塞四列與置頂標記；存檔實際只有一列。
- 變更: lobby-hall-screen.json、.layout.json 版面；LobbyHallScreenBinder 放大底圖並改用沙盤固定尺寸；HallMapTurnPlayer 新增季節色層與聚焦限定節點；新增 HallBackgroundFit、LobbyHallLayout 測試。
- 取捨: 未驗證聚焦動畫實際播放的畫面。視窗中途改變大小時底圖倍率不會重算，要重開大廳。季節色層是一般半透明，不是設計稿的 soft-light，勢力色會偏淡。超過 262 寬的任務名稱會被縮小或截斷。
- 阻塞: 幕府大廳與主大廳功能重疊的取捨待使用者裁決。右上角開發用「+」（GachaDevOverlayLauncher）在寬螢幕會蓋到返回鈕，不在這張。

# PROG-2-2201 大廳季度推進「下一季」核心發動機與武將個性動態事件（LOOP-01）

## 1. 核心目標與問題

目前遊戲大廳缺乏推動遊戲進程的「時間發動機」，導致武將無法隨時間自然增長年齡（從 36 歲走向 65 歲退役）、子嗣無法長大（0 歲到 5 歲抓周、15 歲入學）、傭兵 6 日試用期無法自然消耗，玩家無法體驗完整的「三國人生歷程」。
本任務在大廳頂部/底部主功能區新增「下一季」按鈕與季度推進控制器（NextQuarterController），讓整個三國養成循環轉動起來。

## 2. 核心功能規格

1. **季度時序推進**：
   - 點擊「下一季」按鈕，季節按「春 ➔ 夏 ➔ 秋 ➔ 冬」輪替，每滿 4 季年號年數 +1。
   - 每次換季，全勢力所有名冊武將年齡增加 `0.25` 歲（4 季滿 1 歲）。
   - 內政產出結算：自動根據當前城池與派遣武將結算糧草、銅錢與木材。
   - 試用傭兵天數更新：當前持有的試用傭兵 `daysLeft - 1`，歸零時觸發「結義轉正 / 告別離隊」通知。
   - 壽命檢核：檢查年滿 60/65 歲之武將，觸發「可榮譽退役轉教官卡」提醒。
2. **武將個性自發動態事件（每季 1~2 起）**：
   - 依名冊中武將的性格標籤與核心屬性，換季時隨機觸發個性化互動浮窗：
     - **豪爽/猛將型（張飛、許褚）**：「主公，近日軍中無事，可否撥下好酒五壇犒賞弟兄？」➔ 消耗 50 銅錢，該武將好感 +15、士氣滿格。
     - **沉穩/軍師型（諸葛亮、荀彧）**：「主公，觀天象夏日多澇，臣已督修堤防。」➔ 領地農業免受天災，農業產出 +10%。
     - **孤傲/戰狂型（呂布、魏延）**：「在下筋骨發癢，自往校場苦練十日！」➔ 武力微幅提升或步騎適性經驗 +20。
3. **UI 表現契約**：
   - 大廳常駐顯示：當前年份與季節徽標（如「建安三年 · 仲夏」）。
   - 「下一季」按鈕點擊後播放輕快四季轉場動效（墨色四季漸變，1.2 秒），彈出季度結算清單與武將事件。

## 3. 驗收條件

- 單元測試：驗證點擊換季後年齡精確累加、領地產出正確增加、傭兵倒數扣減。
- 事件分派：模擬不同性格武將，驗證能依性格抽出對應事件且數值增益正確。
- 體系相容：不破壞既有存檔格式，存檔中正確持久化當前季度與年數。

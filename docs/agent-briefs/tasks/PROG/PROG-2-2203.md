# PROG-2-2203 三國季報晨報重構與市井奇遇隨機互動閉環（LOOP-03）

## 1. 核心目標與問題

目前日報/晨報存在兩個嚴重問題：
1. **彈窗時機混亂**：每次戰鬥後重回大廳都會重複跳出晨報，打斷玩家心流，且到底算每日首次還是每次進大廳跳未正式定案。
2. **內容過於枯燥機械化**：純條列 log 摘要，缺乏「看天下風雲、聽三國八卦」的遊戲樂趣。
本任務定案並重構晨報彈窗時機，並升級為鮮活富趣味性的《三國季報》，加入市井奇遇微抉擇。

## 2. 核心功能規格

1. **彈窗時機定案（解決衝突）**：
   - **戰鬥結束回到大廳：嚴禁彈出晨報**！戰鬥結束只跳戰果結算，回大廳保持乾淨清爽。
   - **觸發時機**：只有在玩家主動點擊「下一季（換季）」時，或換日首次登入大廳時，才觸發《三國季報》浮窗。
2. **季報三大板塊內容結構**：
   - **【天下大勢】（1 條）**：各路諸侯演化動態（如：曹操進駐兗州軍威大振、孫策橫掃江東自稱小霸王）。
   - **【世家風雲】（2 條）**：根據玩家家族與名冊武將生成的生動軼事（例如：張飛與關羽比武擊碎三塊青石、糜夫人開設私塾教化鄉里）。
   - **【市井奇遇】（1 個微抉擇浮窗）**：
     - *案例 A（西域胡商）*：「西域胡商攜汗血寶馬途經，欲換百金。」➔ 選項：【重金購買（消耗 100 銅錢，得良駒道具）】／【婉言謝絕】。
     - *案例 B（落魄隱士）*：「城外茅廬來了一位布衣老者，神情蕭散。」➔ 選項：【備薄酒親訪（消耗 30 糧，得武將統率經驗+10）】／【不作理會】。
3. **資料持久化**：
   - 記錄當季已閱讀標記 `lastSeasonReportViewed`，避免重入場景或重刷大廳時二次觸發。

## 3. 驗收條件

- 單元測試：驗證戰鬥結束回大廳 100% 不跳季報；換季時 100% 準時跳出。
- 奇遇選項：驗證市井奇遇選項能正確扣減資源並發放道具/經驗。
- 文本檢核：確保所有生成的文案符合繁體中文三國風格，無空白或未定字樣。

# PROG-2-2205 出征雙軌選擇：親自指揮／極速決戰不載入棋盤直接結算（LOOP-02 補完）

## 1. 核心目標與問題

PROG-2-2202 已完成極速決戰演算法（兵種互克、主將個性特寫、三幕戰報），但只接在戰場內的「自動」鈕，玩家仍要先載入五路棋盤才能用。doc_spec_1170 §一流程與 §三-1 要求在出征時就能選「極速決戰」，跳過棋盤載入直接結算。使用者 2026-11-10 指示先做這段。

## 2. 核心功能規格

1. **出征雙軌選擇**：大廳按「出戰」後先彈出模式選擇：「親自指揮」照舊進戰場；「極速決戰」不切場景，直接推演；可取消。新手教學戰與沒有關卡資料時照舊直接進戰場。
2. **戰場外推演**：用名冊主將與關卡敵將的五維跑 `quickResolveOutcome`（PROG-2-2202），套新手首戰保證勝。
3. **戰後結算沿用既有流程**：寫 AUTO_RESOLVE 快照與 BATTLE 日誌，呼叫 `recordBattle`（通關、戰績、官職經驗、虎符、覺醒等），攻城戰照舊先扣主將攻城壽命。
4. **戰報彈窗**：顯示勝負、三幕戰報與結算摘要（精力、功勳、覺醒），按「收下戰果」關閉。

## 3. 驗收條件

- 單元測試：TC-AUTOBATTLE-01（關羽出征相當之敵，選極速決戰，戰報有【陣前斬將】且獲勝、關卡記為通關），不切場景；取消不結算；親自指揮呼叫進戰場。
- 戰報彈窗版面節點齊全。
- 兩種 tsc 0、compute-gate standard 通過。

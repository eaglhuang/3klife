# PROG-2-2206 三國季報歷史卷軸與古樸卷軸樣式（LOOP-03 補完）

## 1. 核心目標與問題

PROG-2-2203 完成《三國季報》合成、市井奇遇與彈窗時機，但留下兩項未做：doc_spec_1171 狀態機的「存入存檔與歷史卷軸」（看過去各季季報），以及「古樸木刻三國季報介面」（當時沿用純色彈窗）。使用者 2026-11-10 指示補上。

## 2. 核心功能規格

1. **歷史卷軸存檔**：新一季季報產生時，把上一季季報收進歷史卷軸（新的在前，同季不重複，最多保留 12 季），隨存檔保存，舊檔讀回為空。
2. **翻閱往期**：季報彈窗加「往期」「較新」兩鈕，可在本季與往期之間翻頁；往期只能看，不能再做奇遇抉擇，標題顯示該季年份季節；往期未抉擇的奇遇顯示「未及抉擇，機緣已逝」，不可補選。本季奇遇未抉擇時仍可翻閱往期，但收起季報前必須回到本季完成抉擇；翻頁不扣款、不改奇遇狀態（使用者裁決 B3，2026-11-10）。
3. **古樸卷軸樣式**：季報彈窗改用現有的羊皮紙框與紙質按鈕貼圖（common/parchment、common/paper_utility），文字改深色；不新增生成圖。**暫代美術**：這是重用現有素材的暫代樣式，不代表「古樸木刻」視覺已驗收（使用者裁決 B4）。

## 3. 驗收條件

- 單元測試：換季後上一季進入卷軸、上限 12、同季不重複、存讀檔保留；彈窗翻頁、往期不可抉擇、未抉擇可翻閱但不能收起；版面節點齊全、skin 貼圖路徑都存在。
- 兩種 tsc 0、compute-gate standard 通過。

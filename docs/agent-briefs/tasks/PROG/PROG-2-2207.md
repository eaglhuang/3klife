# PROG-2-2207 修正 master 網頁版建置被 Babel 擋下

## 1. 核心目標與問題

master 用 Cocos Creator 3.8.8 建網頁版（web-desktop）時，內建 Babel 在 `LobbyScene.ts` 女兒及冠事件的 `for (const daughter of (payload as DaughterAwaitingRoute[] | undefined) ?? [])` 崩潰（TS 型別斷言與 `?? []` 合併型別時混入 Flow 型別節點）。tsc 與單元測試抓不到，只有實際建置才會失敗。使用者 2026-11-10 指示另開小卡，讓 master 能直接建出網頁版，不混進 PROG-2-2206。

## 2. 核心功能規格

1. 把該迴圈改成先宣告具名型別變數 `const daughters: DaughterAwaitingRoute[] = ... ?? [];` 再 `for (const daughter of daughters)`，行為不變。
2. 不改其他邏輯。

## 3. 驗收條件

- Cocos Creator 3.8.8 CLI 建置 web-desktop 成功（退出碼 36）。
- 單元測試全過、兩種 tsc 0、compute-gate standard 通過。

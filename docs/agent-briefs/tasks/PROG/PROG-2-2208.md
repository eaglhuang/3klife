## 建議作法
- 所有季報入口共用控制器守衛，掛載途中、開場 FSM 非完成、信件未讀、三段教學未完成時只能排隊。
- 新手規格 §16.5 要求進退場與不遮蔽教學；季報規格 §一僅限定首登／換季，未明訂新手相對順序。本卡採「開場 FSM 完成 + 信件已讀 + 三段教學完成」後釋放一筆待開請求。
- 殘影根因是季報 host 一直 active，而非已證實的 opacity 缺陷。守衛阻擋時停用整個 host，不變更奇遇抉擇或已讀；解除後正常開啟並拉至前景。
- 不修改 PR #2068 的女兒及冠事件迴圈，不改場景／貼圖／版型。

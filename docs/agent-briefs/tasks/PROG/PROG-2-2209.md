## 根因與保留事項
- 大廳 skin 的立繪與文字是關羽範例；原本沒有接主將資料。現在同源繫結，載入失敗不拿其他武將代替，非同步過期結果不套用。
- 宿命確認在角色登場前直接發紅顏 toast；現在保留待顯示通知，重用 #2069 開場守衛，待全部開場 UI 結束才放行一次。
- 命鏡 `loading` 內容的 42% 與「繼續觀測」是靜態示範，不是載入實測數字。真正轉場本來就由 preload 完成自動切換；本輪修正錯誤呈現，未宣稱改善載入耗時。命鏡展示／升星等用途不受影響。
- 宿命台詞原先距末排卡片僅 6px、字級 20；拉開距離並提高至 28。保留原本打字機揭露，不擅自刪除劇情。
- 戰鬥各 UI 可先於背景與控制器完成；Canvas 初始化時先遮蔽但不停生命週期，背景、資料與 HUD 就緒才揭露，失敗顯示錯誤而非範例戰局。
- 標題的舊 Button 在非同步新標題掛載完成前可露出，現在 onLoad 就隱藏；舊開始鈕保留。

#2069 的開場守衛同時涵蓋信件，且用 node.active 隱藏季報，因此 #3 信件背後季報殘影在程式路徑上已被涵蓋，仍待 Windows 實機複驗。

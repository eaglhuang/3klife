# 出征選單與戰場 HUD 分區

文一授權處理 #8/#13。以 #2070 分支為基底，與影片瘦身、操作教學兩張卡互不依賴；待 #2070 先合併。

## 根因與調整
- 大廳分類列與子選單用固定左右內縮，但內部按鈕是固定寬：1280 寬時分類容器只有560、內容卻1200，子選單只有240、內容需880。改為明確置中、容器寬度包住按鈕，並擴大垂直安全距離。原設計1920座標本已有12px間距，沒有實機重現原報告的點擊遮擋，因此不得宣稱已證實所有遮擋根因。
- 戰場左「戰報」與右「關雲長」是 battle-hud-screen 中寫死的 HTML 範例（含固定傷害、關羽技能與屬性），不是正式 BattleLogComposite 或單位快覽。設為初始 active=false，保留真正戰報與按需快覽，避免重複資訊佔住兵種卡與敵方血條。layout 與 layout 鏡像同步，不改 skin 或資料契約。

## 驗證與限制
新增1280/1440/1920寬度幾何檢查、範例側欄與正式戰報接線契約；validate-ui-specs、tsc、standard 閘門與單元測試。
未增加新美術，沒有移除正式戰鬥資訊功能；Windows 建置無痕重玩需確認按鈕點擊、兵種卡與戰報互不遮擋。

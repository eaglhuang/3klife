# 新手資源、戰前偵查與首戰操作第一版

文一授權先照規格製作第一版。已讀新手開場 §第三幕/11/16/18.3、開場順序 FSM §2–3、首戰五路提示規格 §1–4、偵查規格 §1–2。
基於 #2070，與影片瘦身和 HUD 分區兩張卡互不依賴；不改正式文案、戰鬥數值、存檔或獎勵。

## 修正
- 大廳仍保留 §18.3 三段正式文案，新增資源用途、實際出征與武將按鈕說明。框與箭頭依真實 UITransform 邊界定位，不使用寫死螢幕座標。舊版只有三段文字，無操作指引。
- 偵查無資料明確寫「尚未偵查…不代表沒有風險」，缺口提供「武將→主將→技→裝備對策標籤戰法」路徑。不虛構敵陣、不把整個背包當已裝備，也不鎖出征。
- 「斬」原本只是 HTML panel，沒有按鈕事件。改 button 並接既有奧義選擇流程；蓄力不足沿用既有可見提示，滿怒開技能選單與選目標。
- 原首戰提示在 deployRuntime 尚未建立時發出，第一則被吞掉；改在 UI 與事件橋就緒後建立，追加持續可見提示卡與真實目標箭頭。
- 新純邏輯順序：部署→推進交鋒→滿怒奧義→收尾→勝利退場；只接受我方操作事件，重複或不合序事件不亂跳。

# 幕府大廳主政廳化與武將3Q小人站堂隔離修復

針對使用者於 2026-11-10 提出之幕府大廳核心架構與視覺回饋執行整併：

## 核心問題
1. **立繪混雜穿模**：`HallStageCrowd` 在無 Q 版資產時，直接 fallback 讀取大張寫實半身立繪，且以 `SizeMode.RAW` 原圖尺寸載入，造成大喬、孫策等巨大立繪直接疊在木榻上，文字重疊穿模。
2. **雙大廳歷史包袱**：外層 Lobby 與幕府大廳功能重複，底部導航重複，外層大廳品質粗糙。
3. **定位混亂**：幕府大廳應作為玩家的核心主大廳（政廳），統合內政、軍務與日常武將點卯。

## 修正範圍
1. **HallStageCrowd 資產隔離**：
   - 嚴格分離寫實立繪與 3Q 娃娃。禁止大張立繪作為舞台站位精靈。
   - 增加固定尺寸約束或兜底 Q 版小人機制，限制最大寬高（例如寬 140、高 180），避免 RAW 原始解析度破圖。
2. **站位與標籤間距優化**：
   - 重新分配 `HallStagePlanner` 點位間距，避免名牌與武將重疊。
3. **大廳主視覺與入口整併**：
   - 登入進入 `LobbyScene` 後，預設展現幕府大廳，去除外層多餘中轉介面，底部五大選單與幕府政廳無縫連動。

## 驗收標準
- [ ] 幕府大堂無寫實大半身立繪穿模，武將皆為 3Q 小人或統一規格素體。
- [ ] 武將名牌、氣泡不互相疊死。
- [ ] 進入遊戲直接身處具備幕府古風質感的主大廳，功能導航清晰。
- [ ] TypeScript 編譯 0 錯誤、單元測試通過。

# 新手開場順序改為「信 → 六名將登場 → 宿命轉蛋」

使用者試玩後裁決（2026-11-10）：「一封信之後會跟隨六個武將的說話（各有台詞）引導玩家過去轉蛋畫面才對，現在順序錯誤了顛倒」。
舊順序為第一幕 → 致你的一封信 → 宿命轉蛋 → 六名將登場；改為第一幕 → 致你的一封信 → 六名將登場 → 宿命轉蛋，宿命鎖定即開場結束。

## 修正
- `NewPlayerOpening` 幕序改 intro → showcase（intro-done 進）→ destiny（showcase-done 進、destiny-locked 離開＝開場結束）。
- `LobbyOpeningPanels`：原本寫死「關信後進轉蛋」的旗標改為通用 `openLetterThen(next)`，關信後只接續一次；`openDestiny` 直接進轉蛋不再插信。
- `LobbyScene`：幕切換統一走 `_enterOpeningPhase`（名將登場前先開信；名將說完進轉蛋）；讀檔接回幕同一路徑；信件面板改在 intro 之前掛載，讀檔接回名將登場幕時仍會先開未讀的信。
- 名將登場最後一位按鈕由「開始冒險」改「前往宿命轉蛋」。
- PROG-2-2213 起登入後直接開幕府大堂：新玩家開場進行中先不開，開場結束才開，避免蓋住開場。

## 規格待主控更新（本卡不改規格）
- 新手開場規格書 §4：分鏡 5（轉蛋）與分鏡 6（名將登場）順序須依本裁決對調。

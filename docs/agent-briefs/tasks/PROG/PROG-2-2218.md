# 主將化身棋子與首次部署名牌

## 根因與修正
isGeneralAvatarUnit在ensureTroopFormation直接return；同時updateSingleGeneralView遇已出陣化身就移除後排主將model。化身因此永遠只剩小兵cube，不是中路兵種資源缺失。改建立具有底座身體與球形頭的通用戰術棋子，沿用陣營材質，名牌顯示真實姓名＋「主將棋子」。不冒充關羽、不新增角色美術，不宣稱夏侯惇專屬3D模型已存在。
createUnitView原本不設定世界位置，playDeploy要等prefab後才update；首個名牌可先投影世界原點。改建立時立即定位格子。名牌座標改走引擎convertToUINode，避免3D螢幕z交給UI相機screenToWorld造成跨相機深度誤差。

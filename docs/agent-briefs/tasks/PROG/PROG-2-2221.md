# 轉蛋系統介面重構與返回路徑統一（方案 B）

## 背景與問題診斷
1. **轉蛋結果介面破壞**：
   - `gacha-pull-result.json` 佈局檔源自多合一示範視窗（包含獎勵彈窗、確認操作、道具詳情、系統通知、官府告示等）。
   - 真正的卡片抽取結果是 `GachaPullResult_div_341`。目前因示範視窗全數顯示，全部疊在一起導致畫面雜亂崩潰。
2. **轉蛋主畫面展示立繪缺失**：
   - `gacha-ds3` 卡池主畫面中央只有空灰色佔位塊，缺少各卡池對應之宣傳立繪與橫幅。
3. **返回按鈕路由統一**：
   - 轉蛋介面與各子介面的【返回】按鈕需統一路徑至 `returnToLobbyHall()`（幕府政廳），徹底杜絕返回舊大廳之幽靈跳轉。

## 修正範圍
1. **轉蛋結果介面（GachaPullResult）專屬化**：
   - 隱藏或剔除示範用雜項視窗（`div_265`、`div_289`、`div_301`、`div_330`、`div_414`）。
   - 確保抽卡結果彈窗僅聚焦展示：抽得武將矩陣（單抽／十連）、最高稀有度特別展示、消耗資源提示、再抽一次與確定按鈕。
2. **卡池主畫面立繪補齊**：
   - 依照目前卡池（群英會聚、紅顏名將等）綁定對應之武將展示圖或卡池宣傳橫幅。
3. **返回路由統一**：
   - 轉蛋介面關閉與返回按鈕全面連動 `returnToLobbyHall()`。

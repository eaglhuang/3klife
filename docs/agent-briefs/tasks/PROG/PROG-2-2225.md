# 戰鬥HUD靜態尺寸/遮擋審查（#2074）

## 根因
- fitHeight=1080，但卡寬16.2%、戰報11%在窄比例小於內容；頂欄三固定組超出窄畫布。
- HTML樣板底部944寬指令/結束回合與真正ActionCommand重複；SP兩行runtime強制180×18截字。
- 奧義標籤與SP標籤無位置，中心重疊；計謀runtime改12px並SHRINK；戰報32px控制/30px收合，在720p只有約21px；卡片費用小字。

## 方案與假設
- 正式指令統一ActionCommand；隱藏重複樣板/裝飾按鈕（不移除資料/技能），保留同源SP資訊為右側獨立344×100區。
- 卡224寬、戰報344寬；頂部退72；主要動作/戰報觸控至少72設計px，即720p的48 CSS px。
- 計謀簡短功能名+點數/受限，完整技能仍由既有選單提供；不改施放規則。
- 軍師900寬摘要/側邊智謀條也超出直式：摘要改可捲動224×72，智謀改344×48水平條，同一數值/滿格動畫不變。
- 僅戰鬥檔案，無大廳、無場景掛載順序變更。
- 靜態工具依真實fitHeight換算1920×1080、1280×720、1440×900、1024×768、1080×1920。直式僅幾何安全檢查，不宣稱完成整個3D戰場直式UX。

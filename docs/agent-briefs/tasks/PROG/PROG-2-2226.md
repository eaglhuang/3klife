# 新手引導 1/3～3/3 被幕府大堂遮住：改指向大堂上的對應入口

PROG-2-2223 實測發現：轉蛋鎖定後幕府大堂開啟，新手引導卡在最上層，但聚焦框指向的是城市畫面（city hub）的按鈕，不是玩家眼前的大堂入口。實測再查出大堂與城市畫面的上下層也反了（見根因 2）。

## 範圍
- `assets/scripts/ui/scenes/LobbyScene.ts`：引導聚焦（focusTutorial）依目前可見的畫面挑目標。
- `assets/scripts/ui/core/OnboardingTargetResolver.ts`（新）：大堂上的對應目標表與挑選邏輯（純邏輯，不依賴 cc）。
- `assets/scripts/ui/core/OnboardingTargetHighlight.ts`：聚焦框支援多個節點的合併邊界。
- `tests/OnboardingTargetResolver.test.ts`（新）。
- `LobbyScene.ts` 另修開場結束時的開啟順序（見根因 2）。
- 不動：戰鬥 HUD、`LobbyOpeningPanels.ts` 的開場置頂邏輯、PROG-2-2222／2223 的掛載順序。

## 根因
1. 新手引導 2/3、3/3 的目標 `btnCatSortie`、`btnCatGenerals` 已不存在於城市畫面（PROG-2-1148 起底列改由大堂 dock 負責），1/3 的 `ResourceBar` 在城市畫面上，聚焦框指不到大堂上真正的入口。
2. 新玩家開場結束時先開大堂、再 `ui.open(LobbyMain)`；LobbyMain 的 show 會把城市畫面、選卡、選將等拉到最前，大堂反被蓋住（實測 CityHubHost #79 在 LobbyHallHost #75 之上，兩層畫面混在一起）。舊玩家從 start() 進來是先 LobbyMain 後大堂，沒有這問題。

## 修正
- 新增 `OnboardingTargetResolver`：大堂開著時改框大堂上的同功能入口（金玉糧兵＝「返回」同列的兄弟節點、出征＝dock-sortie、武將＝dock-generals），對應表是資料；大堂上找不到就不畫框，不回頭指向被蓋住的城市按鈕。大堂沒開時維持原城市目標。
- `placeTutorialTarget` 支援多個節點，框取合併邊界。
- `_openLobbyHall` 結束後下一幀再定位一次聚焦框（大堂剛啟用那一幀 Widget 尚未對齊）。
- 開場結束分支改為先 LobbyMain、開完再開大堂，與 start() 同順序。
- 未動戰鬥 HUD、`LobbyOpeningPanels.ts` 與 PROG-2-2222／2223 的掛載順序。

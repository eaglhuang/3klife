# 修復 UIPreviewBuilder 元件工廠生命週期延遲初始化防禦（解決 bloodline-mirror-loading 掛載失敗）

## 背景與根因
在 Web-desktop 自動化冒煙測試（`run-web-smoke.js --flow battle-settlement`）中發現：
`[UIScreenPreviewHost] 載入 screen 失敗: bloodline-mirror-loading-screen TypeError: Cannot set properties of null (setting 'i18nStrings')`。

根因分析：
1. `UIScreenPreviewHost` 繼承自 `UIPreviewBuilder`（繼承自 `Component`）。
2. 在 Cocos Creator 3.8.8 執行期或特定時序中（如 `addComponent(UIScreenPreviewHost)` 後立即呼叫 `showScreen`），`UIPreviewBuilder` 的 private 欄位 `nodeFactory`、`styleBuilder`、`layoutBuilder` 可能尚未執行初始化或在反序列化時被重設為 null/undefined。
3. `buildScreen` 執行 `this.nodeFactory.i18nStrings = this.i18nStrings` 時，因 `this.nodeFactory` 為 null 導致致命性 TypeError，進而中斷中繼場景與大廳主流程。

## 解決方案
1. 在 `UIPreviewBuilder.ts` 中將 `nodeFactory`、`styleBuilder`、`layoutBuilder` 實作為具備延遲初始化（Lazy Initializer / Getter）特性的安全防禦結構：
   - 若欄位為 null 或 undefined，存取時即時自動建構合法實例。
2. 同步加強 `this.nodeFactory.i18nStrings = this.i18nStrings` 前的防禦性檢查。
3. 確保 Web 執行期無任何 `i18nStrings` 空指標異常。

無 UI 外觀尺寸變更（純生命週期與空指標防禦修復）。

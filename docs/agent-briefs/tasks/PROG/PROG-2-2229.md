# 標題畫面「開始遊戲」按鈕置中，隱藏「三國志・生存」版名稱文字

使用者 2026-11-11 在試玩版發現「開始遊戲」沒有左右置中。實測（設計解析度 1920 寬）：按鈕寬 440，左邊緣在 x=960，中心落在 x=1180，往右偏 220。另外畫面上多出三段文字：「三國志・生存」、「傳」章旁的「生」、貼左邊的「THREE KINGDOMS · SURVIVAL」。

## 根因
HTML→UCUF 轉換的兩處漏失（設計稿 `Design System/design_handoff/title-screen/index.html`）：
1. `.start { left: 50%; margin-left: -220px }` 只轉出 `left: 960`，`margin-left` 的回移被丟掉。
2. 設計稿用 `body[data-title="legacy"] .t-survival { display: none; }` 在兩種遊戲名稱之間切換，轉換器不處理屬性選擇器，survival 版文字全部顯示出來。

## 修正
- `title-screen.json`／`title-screen.layout.json`（兩檔內容相同，一起改）：
  - `TitleScreen_div_10`（title-screen.start）widget 改成 `top: 742, horizontalCenter: 0`。
  - `TitleScreen_span_2`、`TitleScreen_span_5`、`TitleScreen_span_7` 設 `active: false`。
- 新增 `tests/TitleScreenLayout.test.ts`（7 個）：按鈕置中、不得有窄節點把左邊緣放在畫面正中央、survival 文字隱藏且 legacy 文字保留、兩檔一致。

## 不在範圍
- 轉換器本身（`tools_node/lib/dom-to-ui/`）沒有修。下次從 HTML 重新產生這個畫面時，上面兩個問題會再出現，需要另開卡處理 margin 回移與屬性選擇器的 display:none。

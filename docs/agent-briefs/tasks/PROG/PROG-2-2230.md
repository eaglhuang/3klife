# 載入進度條改成精緻框＋漸層光棒

使用者 2026-11-11 在手機試玩版回報：「正在準備大廳… 已完成 21 個介面」的進度條太大。原本是瀏覽器預設的白底方塊（480 寬、16px 內距、18px 字、24px 高的原生 progress）。要求改用精緻框，裡面跑漸層光棒。

## 範圍
- `assets/scripts/shared/SceneLoadProgress.ts`：只改 DOM 覆蓋層的外觀；`LoadProgressState` 的進度計算與文字不動。
- `tests/SceneLoadProgress.test.ts`：DOM 測試改成驗新結構，另新增一個樣式測試。

## 修正
- 樣式集中在 `SCENE_LOAD_PROGRESS_CSS`，掛在覆蓋層內的 `<style>`，不另外改 `<head>`。
- 外框：寬 min(440px, 86vw)，細金框（1px rgba(212,175,55,.55)），深色半透明漸層底，內外陰影。字 13px，色 #E8D9A8，宋體系，字距 2px。
- 光棒：6px 軌道，填色是金色漸層 #7A5A12 → #D4AF37 → #FFE7A0，外發光。上面有一道白光以 1.6 秒掃過。
- 三種模式用 `data-mode` 切換：
  - `determinate`：寬度等於真實百分比。
  - `indeterminate`：總數未知，32% 寬的光段來回流動，不捏造百分比。
  - `failed`：暗紅色，「重新載入」改成金色小按鈕。
- 拿掉原生 `<progress>` 和系統色 `Canvas`／`CanvasText`。

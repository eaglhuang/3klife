## 根因與驗證
- 教學只避開頂部 Label，忽略 TileBuff_ 與場上單位字樣；展開搜尋起點在敵方上半部。改保護所有畫布內標籤，展開起點放在高度 55% 以後，沒有空位縮成頁籤。
- 卡片實際以 data.cost、data.atk、data.hp 顯示；40/100、35/120 是攻擊／生命，不是蓄力。延伸部署頁，保留五頁流程。
- HUD 建構時硬畫 0/0 且掛載後才訂閱 SP；改建構前訂閱並暫存真實值，上限未到時顯示準備中，不假造 100。

- 31 項 scoped tests、tsc 0 errors；五比例 battle-hud-layout-audit PASS；standard gate 與 encoding 提交前執行。
- Component Sizing Table：UnitName1–4 172×32 → 172×40；其餘 HUD 尺寸不變。
- 需 Windows 重建實機驗證。首個部隊模型與效能另外調查，不在本卡猜測性更動。

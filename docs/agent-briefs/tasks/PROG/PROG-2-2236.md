# 開場十連抽接上滿版結算畫面；六名將立繪換人時不殘留舊圖

新手試玩第三輪（issue #2086）回報：

1. 第 2 項：開場宿命轉蛋十連抽選定按確認後直接進大廳，沒經過 PROG-2-2221 的滿版名將結算畫面（GachaPullResult_hero_showcase）。
2. 第 3 項：六名將登場換下一位時，新立繪載完前畫面殘留上一張或佔位剪影（孫策、甘寧同圖，張飛顯示「?」）。三位正式立繪都存在且不同。

## 範圍
- `assets/scripts/ui/core/LobbyOpeningPanels.ts`：確認開局後先顯示結算畫面，關閉後才推進開場。
- `assets/scripts/ui/core/GachaFlowCoordinator.ts`：結果畫面提供給開場使用的公開入口（指定主角、隱藏再抽）；主角立繪換圖不疊舊圖。
- `assets/scripts/ui/core/DestinyOpeningResult.ts`、`GachaResultRanking.ts`、`PortraitSwapGuard.ts`（新）。
- `assets/scripts/ui/scenes/LobbyScene.ts`：接線；立繪載入前先隱藏舊圖，載完再顯示。
- 測試：`tests/LobbyOpeningPanels.test.ts`、`tests/DestinyOpeningResult.test.ts`、`tests/PortraitSwapGuard.test.ts`。

## 驗收
- 開場確認核心名將後出現滿版結算（大立繪＝選定的名將、名號牌、十張卡列表、關閉鈕），按關閉才往下走。
- 六名將換人時不會出現上一位的立繪或「?」剪影。

# 轉蛋畫面改用原稿固定 id 綁定；紅顏展示改由轉蛋系統程式掛上；採用新轉換產出

使用者 2026-11-11 裁定（接續 PROG-2-2232 阻塞）：綁定改用 HTML 原稿裡固定的 id（例如 pool-brief），紅顏展示改成程式掛上，之後換上新產出，以後重轉不再壞。
紅顏轉蛋、支援卡都是轉蛋畫面中的一池；轉蛋畫面共用，新 UI 集中在轉蛋系統裡支援，不各做一套。

## 範圍
- `tools_node/data/ui-bind-maps/gacha-ds3.json`（新）：原稿元素 → 固定節點名（原稿有 id 用 id 選擇器，其餘限定在所屬區塊）。設計稿資料夾不進版控，名稱寫在綁定表，不改原稿。
- 轉蛋系統共用模組：節點名稱常數、各池文字、輪播切池時一併切右側分頁內容、池附加區塊（紅顏展示）以程式掛載。
- `assets/scripts/ui/scenes/LobbyScene.ts`、`assets/scripts/ui/core/GachaActionBindings.ts`：改用固定名稱。
- 紅顏展示區塊：自轉換產出移出，改為獨立版面由程式掛上。
- gacha-ds3 runtime 檔：以 PROG-2-2232 修好的轉換器重轉並採用。
- 測試：對應單元測試改用固定名稱。

## 驗收
- 產出 JSON 不含任何手接節點；程式不再引用 GachaDs3_div_* 流水號名稱。
- 重轉兩次產出相同、綁定不變。
- 7456 實跑：三池切換時橫幅與右側內容一致，紅顏池顯示紅顏展示，抽卡／歷史／天命入口按鈕可用；與 HTML 原稿左右對比。

# 網頁版啟動先鋪標題底圖，不露出灰底舊標題

使用者 2026-11-12 回報：網頁版一開始出現灰底「三國傳承／GLOBAL EXPEDITION／開始遊戲」，應該一開始就有底圖。
原因：LoginScene 在 title-screen 非同步掛好前，場景內的舊版標題（灰底）先顯示。

## 範圍
- `build-templates/web-desktop/index.ejs`、`style.css`：引擎下載前就鋪標題底圖（`boot-bg.jpg`，與畫布同一 16:9 框）。
- `build-templates/web-desktop/boot-bg.jpg`（新）：標題畫面去掉按鈕與角落 UI 的靜態圖。
- `assets/scripts/ui/scenes/LoginScene.ts`：onLoad 就藏舊標題，載入失敗才拿出備援；標題掛好後淡出底圖。

## 驗收
- 網頁版從開啟到標題出現，全程看不到灰底舊標題。

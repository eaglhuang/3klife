# 宿命轉蛋改為轉蛋系統的宿命池：十連全收、單鍵確定

使用者 2026-11-12 裁定（doc_spec_0471 文首、轉蛋系統.md §L）：宿命轉蛋是轉蛋系統的一池；每輪十連恰含一位六大宿命名將＋9 位一般武將，可無限重轉；按「確定」十位全收，不用點選。

## 範圍
- `assets/resources/data/gacha-config.json`、`assets/scripts/core/models/GachaConfig.ts`：新增 `destiny-pool`（poolType destiny、免費、必出名單與一般武將篩選寫在資料）。
- `assets/scripts/core/systems/DestinyPool.ts`：依池設定抽，每輪恰一位宿命名將。
- `assets/scripts/ui/core/DestinyOpeningController.ts`：去掉點選，確定即開局（核心＝本輪名將）。
- `assets/scripts/ui/core/LobbyOpeningPanels.ts`、`assets/scripts/ui/scenes/LobbyScene.ts`：開場不再用 destiny-opening-screen，改用轉蛋十連結果畫面（重轉／確定）。
- `assets/scripts/ui/core/GachaFlowCoordinator.ts`：`presentDestinyPool` 宿命池結果畫面。
- 對應單元測試。

## 驗收
- 新帳號開場直接看到轉蛋十連結果畫面，恰一位六大名將；重轉免費無限；確定後十位入名冊並進大廳。

# 轉蛋抽到武將時開口講一句台詞（所有池共用）

使用者 2026-11-12 要求：所有轉蛋角色一被抽到就開口講一句符合個性的台詞。

## 範圍
- `assets/resources/data/general-gacha-lines.json`：每位武將一句登場台詞（資料，不寫死在程式）。
- `assets/scripts/ui/core/GachaLines.ts`：讀台詞表、依武將 id 取台詞。
- `assets/scripts/ui/core/GachaFlowCoordinator.ts`：共用結果畫面 hero_desc 顯示本次主角台詞（所有池共用，含宿命池）。
- `tests/GachaLines.test.ts`、`tests/run-cli.ts`。

## 驗收
- 任一池抽完，結果畫面主角下方顯示「台詞」；沒有台詞的武將退回原本描述。

# 奧義漫畫分鏡 cut-in 播放器（Issue #2139）

## 範圍
- 純邏輯時間軸核心 `cutinCore`（取自 spine-trial `ult-cutin-core` 6d2a209）＋ 趙雲範例設定，不寫死格數。
- Cocos 獨立全螢幕疊層 `UltCutinView`：暫停／恢復戰鬥、點擊跳過、第二次施放走縮短重播、缺圖靜默略過、安全區。
- 接在戰場奧義施放點（先播 cut-in，再播既有奧義特效）。
- 14 項自動化測試（N=1,2,3,5、缺圖、跳過、重播）＋ 美術規範文件（交 Codex）。
- 不動大廳與轉蛋流程。

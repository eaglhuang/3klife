# 幕府大廳 Spine 武將隨機走動、發呆、點擊對話（Issue #2135）

## 範圍
- 移植 spine-trial `lobby-wander-gait-v2`（856b82b）`render/lobby_wander/wanderCore.ts`（純 TS，無引擎依賴）到 `assets/scripts/shared/lobby/`。
- 走動範圍、停頓秒數、最小間距、顯示縮放、Spine 對照表寫進 `data/hall-map/hall-wander.json`，不寫死在程式。
- 大廳人群元件：有 Spine 骨架的武將改播 `walk_in_place` / `idle` 並依核心狀態機走動；沒有骨架（私有倉庫美術不進公開倉庫）的維持原本靜態小人。
- 點 idle 中的武將→停住、出現既有對話泡泡約 2 秒、再繼續走；離開大廳（停放）時停止更新。
- 本機 Spine 資料（`.gitignore` 排除，不進 PR）換成新版步態 json，補上關羽、呂布。
- 不動新手開場、教學、十連順序。
- 第三輪（使用者 2026-11-15 裁定）：①砍掉大廳原本固定站位的小人；②只有「有任務可毛遂自薦」的我方武將在場走動，點他彈泡泡（交給你→開任務牆與詳情／再議）；③其餘從我方擁有的武將輪替 2~3 位出來走動（60 秒換一批、進出場走過地板帶外側），點他聊天；台詞（每人至少三句、與友誼有關）內建離線底稿＋本機快取，連線時由伺服器同步（目前只留注入接口）。
- 第四輪（主 AI 轉達使用者 2026-11-15 裁決）：沒有 Spine 骨架的輪替武將先做「通用走動替代」——靜態小人在地板帶平移＋輕微上下晃動＋依方向左右翻面；日後骨架由動作庫／自動轉換管線量產後替換，不手工逐隻補。自薦上限 3、輪替 60 秒、骨架權重 ×4 定案；友誼維持 0；台詞同步接口不接。

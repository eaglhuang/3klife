# 幕府大廳走動小人點擊對話穩定化＋統一台詞接口（LobbyDialogueProvider）

## 範圍
- 點擊對話：所有輪替上場的武將（有無骨架、走路或發呆）點了都停下、面向玩家、頭上彈泡泡；泡泡在最上層、自動收起或再點關閉；連點不疊泡泡；開其他面板時泡泡收起。
- 統一台詞接口 `LobbyDialogueProvider.getLines(generalId, context)`，context 含時段、友誼、事件；本地 JSON 實作＋雲端 server 殼（預設關閉、失敗退回本地、不卡畫面、帶快取）。
- 友誼維持 0，欄位保留由本地資料給預設。
- 單元測試：接口回退、無台詞用通用台詞、連點不疊泡泡（純邏輯模組，不依賴 cc）。

## 開單原因
使用者裁定：武將池、宿命池、紅顏池（support-pool）、支援卡池都必須來自同一個轉蛋系統，先備好架構再接畫面。

## 完整描述
- gacha-config 每個池加 presentation（標題、貨幣、再抽模式、武將展示、入庫目標、文字標籤）
- GachaSystem：依 poolType／poolId 註冊抽卡規則的單一入口；GachaLocalRules 提供武將／紅顏／支援卡規則
- GachaFlowCoordinator 的紅顏、支援卡、武將池抽卡改走 GachaSystem；宿命結果面板文字與展示方式改讀 presentation
- 本階段畫面不變；金幣／招募券舊池與宿命重轉狀態機留待後續卡逐池遷移

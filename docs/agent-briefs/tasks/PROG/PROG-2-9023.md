## 開單原因
試玩版在 iPhone 橫向瀏覽器左右有黑邊，且無法跑滿螢幕。網址列需靠「加入主畫面」隱藏；黑邊來自 web-desktop 範本把畫面鎖在 16:9。寬螢幕應讓背景延伸，介面留在設計安全區（含瀏海）。

## 完整描述
- 試玩版實際走 `build-templates/web-desktop`（專案沒有 web-mobile 範本）。
- 補 Web App meta 與 manifest（fullscreen、landscape、viewport-fit=cover）。
- 取消 CSS／`setFrameSize` 的 16:9 黑邊；引擎既有 AdaptiveResolution（寬螢幕 FIXED_HEIGHT）與多數畫面的 `safeAreaConstrained` 負責介面安全區。
- `LobbyBackdrop` 依可見範圍 cover，不改 LobbyScene。

## 如何驗證
1. `node --test tests/web-shell.test.cjs`
2. LobbyBackdrop 測試：寬於 16:9 時 cover 可見範圍
3. tsc 無新增錯誤
4. Windows 建置部署後，手機從主畫面開啟應為全螢幕；橫向時左右不再是黑邊，介面不進瀏海

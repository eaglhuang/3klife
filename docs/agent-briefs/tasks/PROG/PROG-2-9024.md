## 開單原因
使用者要求：全部池的 UI 與轉蛋功能做到真正可玩、可存檔、可扣錢；限定池每週換一位武將；轉蛋系統要有標準 API，日後可輕易接伺服器。

## 完整描述
- `GachaApi`：listPools／getWallet／pull／getHistory，往來資料皆為可 JSON 序列化的 DTO 與固定錯誤碼；`LocalGachaApi` 以 GachaSystem＋LocalGachaService 實作（錢包、保底、存檔、紀錄沿用）。日後另寫伺服器實作同一介面即可。
- 限定池：`limited-pool-schedule.json` 新增 `rotations`（起算時刻、7 天一期、輪替名單），`LimitedPoolRotation` 展開成時間窗；新增 `limited-pool`（只收靈玉、焦點武將 UP）。
- 主畫面四池：名將 → 限定（期間外略過）→ 紅顏 → 支援卡；價格、該池貨幣餘額、焦點武將、剩餘時間、UP 機率、保底進度改讀 API。
- 限定池暫用名將池版面換字；黑金專屬版面待重轉原稿。

# [PROG-2-9026] 幕府大廳找不到轉蛋入口、武將名牌重疊輪換

## 開單原因
使用者回報試玩站大廳找不到四池轉蛋入口（紅顏因此驗不到），且大廳武將名牌底下名字重疊、一直換。

## 根因
- 幕府大廳（LobbyHallHost）全螢幕蓋在城池（CityHubHost）上；大廳底欄「商城」直接開商店，城池的「商城→轉蛋」子選單被大廳蓋住。
- 大廳設計稿的五個示意名牌（.npc 關羽／劉備／張飛／諸葛亮／黃忠）被轉成固定節點，執行期人群（HallStageCrowd）又在同位置疊自己的名牌，且人群定時換人。

## 完整描述
- 大廳底欄五鈕改走城池同一套分類子選單；大廳開著時子選單搬到大廳最上層，關閉後搬回。
- 設計稿示意名牌加 ucufId，人群啟用時隱藏。

## 如何驗證
compute-gate standard、tsc test 0、單元測試；建置後無頭點大廳「商城→轉蛋」開四池並在紅顏池單抽，名牌不重疊。

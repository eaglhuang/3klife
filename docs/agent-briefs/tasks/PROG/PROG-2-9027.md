# [PROG-2-9027] 四池轉蛋畫面對齊 HTML 原稿並實測功能

## 開單原因
使用者要求四池轉蛋畫面（gacha-ds3）與 Design System 3/ui_kits/gacha/index.html 原稿一致，且功能全部實測。

## 已知差異
- CHAR 快取標籤空白（期間限定、召喚機率、當前卡池）：共用字元圖集塞滿，預算器只預約範本字，未涵蓋執行期換字、換色與跨畫面累積。
- 限定池武將名白字疊在金色漸層底塊上；原稿是文字漸層。
- 「還差 N 抽」被擠成直排；保底條 0 抽看不出；頂端名條與返回鈕重疊。

## 根因與修正
- 字元圖集：預算器只預約套樣式時的範本字；執行期換字／換色／換字級、instantiate 複本都另存字元，且引擎列式擺放的浪費遠大於估算。改在 Label 原型統一攔截（變動與啟用時依實際值預約），大字級（>40px）不走 CHAR，並包住 updateRenderer：畫完四邊形少於字數即判定圖集滿，退回一般模式並停發 CHAR。
- 轉換器：擷取 background-clip:text，漸層字改用漸層中段色當字色、不畫底塊；行內橫排的匿名文字依字級估寬高，避免被擠成直排。

## 如何驗證
compute-gate standard、tsc test 0、單元測試；實建無頭跑四池切換、單抽、十連、餘額、保底、紀錄、重載存檔，並量相似度。

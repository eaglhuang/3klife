# [PROG-2-9029] 立繪換上後隱藏原稿佔位框底色

## 開單原因
轉蛋橫幅立繪後面露出原稿「立繪佔位」的斜紋框：真圖放進佔位格後只藏了佔位字樣，佔位格自身底色仍在。

## 做法
通用規則：佔位格放進真正的美術後，關掉該格自身的底色繪製（漸層、純色、精靈圖）；載入失敗則保留佔位框。

## 驗收
- 四池橫幅立繪後無斜紋框；立繪載入失敗時佔位框仍在。
- 單元測試、test tsc 0、compute-gate standard 通過。

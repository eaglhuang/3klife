# [PROG-2-9030] 大廳子選單展開時不壓住武將名牌

## 開單原因
試玩報告 #2148 第 3 點：大廳底欄子選單展開時擋住中間兩位武將的名字標籤；另回報一次「武將」連點兩下無子選單。

## 做法
子選單搬到大廳上層時暫藏人群名牌，收起或搬回城池時恢復；之後新生成的名牌沿用目前開關。
連點無反應在線上版重現不出（大廳載入完成後第一下展開、第二下收起），推測點擊時大廳仍在整備或新手教學彈窗擋住，不改。

## 驗收
- 子選單展開時名牌隱藏、收起後恢復。
- 單元測試、test tsc 0、compute-gate standard 通過。

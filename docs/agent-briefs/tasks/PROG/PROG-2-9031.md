# [PROG-2-9031] 轉蛋畫面第二批修正：十連卡配色、統計疊字、立繪放大、背景十字線、點擊穿透

## 開單原因（使用者回報）
1. 十連結果卡配色與實際稀有度不符；底部統計字疊在一起。
2. 橫幅主角立繪太小，要盡量滿版且不超出畫面（之後換戰鬥姿態圖）。
3. 背景有黑色十字線。
4. 轉蛋畫面可穿透點到後方大廳按鈕。

## 做法
1. UIScreenPreviewHost.restyleLike：照樣板節點子樹依結構位置換樣式；結果卡依實際稀有度套原稿同稀有度示意卡；統計列清掉疊在字尾的子標籤。
2. 立繪等比放大到畫面頂端（留邊），底邊貼原框底，寬度上限原框 1.8 倍。
3. GradientBackground：全透明色標借最近不透明色標的 RGB，消除未預乘貼圖線性過濾在透明端的暗線。
4. 全螢幕預覽畫面的控制器顯示時加 BlockInputEvents。

## 驗收
- 四池無十字線、立繪放大；十連卡配色與稀有度一致、統計不疊字；轉蛋畫面點不到大廳。
- 單元測試、test tsc 0、compute-gate standard 通過。

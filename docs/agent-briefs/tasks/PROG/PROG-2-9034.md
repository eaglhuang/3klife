# [PROG-2-9034] 修正 Issue #2159 戰鬥 HUD、撤退結算與大廳重疊問題

## 開單原因
網頁試玩 `https://eaglhuang.github.io/3klife-play/`（Issue #2159）發現多項影響遊玩與畫面判讀的問題：
1. `bloodline-mirror-loading-screen` 呼叫 `loadI18n("")` 導致載入 `i18n/` 報錯。
2. 進場首幀左下奧義鈕仍顯示「奧義準備中 / SP 準備中」，大圓未同步初始 SP。
3. 3D 投射層 `UnitOverlayRoot` 排在 2D UI 之後且主將徽章貼齊左右邊緣，造成與左側虎符手牌及右上軍師／戰報鈕重疊。
4. 設定面板確認撤退後 `ResultPopupComposite` 未正確展開顯示。
5. 大廳 `DailyReport` 在 `SceneLoadProgress.complete()` 前就被打開並壓在載入遮罩上方。
6. 大廳中央「天下勢力圖」（`sandbox`）與武將對話泡泡重疊、子選單搬到大廳層後未即時重新對齊 `Widget`，且從子畫面返回大廳時 `CityHubHost` 會蓋過 `_lobbyHallHost` 造成頂列／底列重疊。

## 做法
1. `UISpecLoader.loadI18n` 與 `UIScreenPreviewHost.showScreen` 對空語系正規化並退回 `zh-TW`。
2. `BattleHUDComposite.show()` 與 `ActionCommandComposite.mount()` 先訂閱事件再執行非同步 `mount()`，`_onAfterBuildReady` 立即渲染目前 SP，且 `BattleScene.start()` 於 HUD 就緒後刷新一次視圖。
3. `UnitRenderer.ensureRoots()` 將 `UnitOverlayRoot` 固定置於最底層（`setSiblingIndex(0)`），並夾限主將徽章位置避開左側虎符列與右上軍師／控制鈕區域。
4. `ResultPopupComposite.show()` 先啟用節點、展開尺寸與 `Widget` 對齊並保護重複掛載；`BattleUIBridge._onRetreatRequested()` 補齊結算窗未開時的保底開啟；`BattleHUDComposite._showSettings()` 補全螢幕 `Widget` 與 `ShowSettingsRequested` 事件。
5. `LobbyScene._mountDailyReport()` 掛載期間保持隱藏，改於 `SceneLoadProgress.complete()` 後再視狀態開啟。
6. `LobbyHallScreenBinder._placeBubbleAbove()` 檢查啟用中的 `sandbox` 範圍並將撞到的泡泡下推至勢力圖下緣；`setCrowdTagsVisible(false)` 時同時收起開啟中的泡泡；`LobbyScene._syncCityHubSubMenuLayer()` 於搬移父節點後呼叫 `Widget.updateAlignment()`；`lobbyMainController.show()` 返回大廳時若 `_lobbyHallHost.node.active` 為 `true` 則拉回最上層並同步子選單層級。

## 驗收

- 合併最新 `origin/master` 後重跑所有測試與門禁檢查通過。

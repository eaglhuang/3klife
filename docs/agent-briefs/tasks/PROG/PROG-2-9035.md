# [PROG-2-9035] 大廳面板掛載失敗不可卡死載入遮罩

## 問題
試玩版線上（3f60411c5）使用者有進度的存檔進大廳時停在「幕府大堂整備中，請稍候……」。LobbyScene 依序 await 約 60 個面板掛載，任一個丟例外就中斷整串，遮罩永遠不收。

## 修正
掛載迴圈每一項包 try/catch，失敗以 UCUFLogger.error 記下序號後繼續，保證遮罩收起、大廳可用；壞掉的面板可由日誌定位再個別修。

## 驗收
- tests/LobbyMountGuard.test.ts 通過
- 線上重新部署後，使用者存檔可進大廳

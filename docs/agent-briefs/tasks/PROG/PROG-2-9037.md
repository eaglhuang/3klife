# [PROG-2-9037] 人物介紹命分頁血統樹遮右欄、畫面左右未滿版

## 問題
1. 切到「命」分頁（Bloodline）時，`Ds3BloodlineTree` 的左區寬度以畫面中心為原點固定偏移（-365 ± 595），
   在比 16:9 寬的視窗裡整體右移，覆蓋到右欄（ContentSlot，x 1200 起）的命紋靈獸／覺醒內容。
2. 人物介紹畫面的 `__screenBackdrop`（UIPreviewBuilder._applyScreenBackdrop）只依設計解析度 1920×1080
   做 cover-fit 並置中，不跟著 host 實際寬度走；寬視窗下兩側露出底下的大廳 UI。

## 原因
- 血統樹的 REGION 沒有對齊 `bloodline-fullscreen` 左區（CharacterDs3Main_div_4，62% 寬、左貼齊）。
- 底圖尺寸用設計尺寸而不是 host 實際尺寸，且沒有 Widget 撐滿。

## 修正（通用層）
- `_applyScreenBackdrop`：以 host 實際尺寸與設計尺寸取大者做 cover-fit，並加 Widget 四邊撐滿，任何畫面都不再露出下層。
- `Ds3BloodlineTree`：樹根水平位置改為貼齊 host 左緣（`-hostWidth/2 + 左區寬/2`），寬度固定為左區設計寬，
  不再隨視窗寬度漂移到右欄。

## 驗收
- tests/CharacterDs3BloodlineTreeBounds.test.ts 通過（寬視窗下樹根不超出左區、底圖覆蓋整個 host）
- 7456 預覽（headless）大喬人物介紹切每個分頁截圖，命分頁無遮擋、左右滿版

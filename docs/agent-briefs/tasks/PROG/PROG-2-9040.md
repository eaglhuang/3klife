# [PROG-2-9040] 大廳進場變慢：非必要面板改背景掛載

## 原因
LobbyScene 進場前預先掛載的畫面數量：10/01 6 個 → 10/20 27 → 11/01 45 → 11/08 54 → 11/15 63。每加一個功能就多一個擋在「正在準備大廳」遮罩前的掛載，7456 暖快取實測掛載段約 12 秒，冷啟動更久。

## 修正
控制器註冊、開場、日報、紅顏、出征流程等進場就要用的面板照舊先掛；招賢館、倉庫、許願台、年報、軍師占卜等 35 個點開才用的面板，移到載入遮罩收起後背景逐個掛載。宿主欄位皆為可空型別，尚未掛好時點擊只是無反應，不會出錯。

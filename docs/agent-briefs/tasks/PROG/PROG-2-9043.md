## 開單原因
使用者指示：戰場上的 3D 小兵與武將全部換成 2D Q 版，動作走現有動畫系統。實跑發現遊戲內骨架缺六個共用戰場動作、小兵骨架未匯入，導致全部退回 3D 模型；且敵我小兵同色分不出陣營。

## 完整描述
- 提供可重跑的私有素材匯入工具（併入戰場動作、匯入小兵）與陣營換色工具。
- `soldierSpineConfig` 依陣營選素材：我方藍、敵方紅。
- 小兵素材路徑加入忽略清單，文件補匯入指令。

## 如何驗證
1. 進戰場：雙方武將與小兵皆為 2D Q 版，敵方小兵為紅色、我方為藍色。
2. 部署後結束回合，可見移動、攻擊、受擊動作。
3. `tests/UnitPresentationCore.test.ts` 通過。

## 建議作法
- 依 `docs/battle-chibi-integration.md` 的匯入指令重建素材。

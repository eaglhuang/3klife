## 開單原因
`tools_node/task-lock.js lock --files a,b,c` 會把整串 `a,b,c` 存成單一條目，之後 scope guard 判定檔案未涵蓋而擋下提交，已讓多位代理卡住。ATM 團隊確認此工具屬 3KLife 自身，需在本端修正。

## 完整描述
1. `--files` 同時接受空白分隔與逗號分隔（可混用）。逐一拆開、去除空白、去除空字串與重複，再存成多個條目。
2. 單元測試涵蓋空白、逗號、混用三種寫法。
3. 不碰其他代理的鎖、卡或 PR。

## 如何驗證
1. 新測試通過（空白、逗號、混用三種寫法）。
2. `tools_node/test/task-lock-cross-shard.test.js` 仍通過。
3. `npx tsc -p tsconfig.test.json --noEmit` 錯誤數 0。
4. `npx ts-node --transpile-only --project tsconfig.test.json -r ./tests/register-cc-test-stub.js tests/run-cli.ts` ALL PASS。

## 建議作法

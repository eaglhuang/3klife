# [PROG-2-9047] 無頭線上試玩全流程驗收腳本 playtest-online

## 目標
新增可重複使用的 `tools_node/playtest-online.js`：以 puppeteer-core 加本機 Chrome 無頭，
用全新帳號（`browser.createBrowserContext()`）實玩線上試玩版（預設 https://eaglhuang.github.io/3klife-play/）
或本機建置目錄（`build/web-desktop`），依序驗收並輸出截圖與 JSON 報告。

## 驗收步驟
1. 開機到 LoginScene，點開始遊戲進 LobbyScene，等載入遮罩消失，記錄耗時。
2. 新玩家開場：依序 emit click BtnIntroNext → BtnCloseOpeningLetter → BtnDestinyRoll → BtnDestinyConfirm → BtnFrame0 → BtnShowcaseNext → BtnNextTutorial。
3. 大廳走動小人：送點擊，確認對話泡泡出現。
4. 轉蛋：切換每個池子一次，確認右欄無重複疊加。
5. 人物介紹：開第一位武將，切每個分頁截圖；「命」分頁檢查血統樹範圍 = 主體寬−720 × 主體高。
6. 出征打一場戰鬥到結算，回大廳；卡住超過 120 秒記失敗。

## 參數
`--url`、`--dir`、`--out`、`--viewport`（預設 1920x1080）。

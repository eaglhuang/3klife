# [PROG-2-9102] 開機過快點「開始遊戲」→ TypeError reading 'off'，大廳卡在「啟動遇到問題」

## 現象
進 LoginScene 約 1 秒內點開始遊戲，大廳載入中丟 pageerror，畫面停在「啟動遇到問題，若持續停留請重新整理」，進度「正在準備大廳… 已完成 1 個介面」。

## 堆疊
```
TypeError: Cannot read properties of null (reading 'off')
  at e.off  (cocos-js/_virtual_cc-eccgVFZq.js:1:381561)
  at assets/main/index.js:1991:565
  at assets/main/index.js:1187:1923
  at src/chunks/bundle.js:92
```

## 最小重現
1. `node tools_node/playtest-online.js --login-settle 1000`（全新瀏覽器情境，預設網址 https://eaglhuang.github.io/3klife-play/）。
2. LoginScene 出現後 1 秒就點開始。
3. 看到上述 pageerror；改 `--login-settle 12000`（預設）則 0 錯誤，與 Chrome 旗標無關。
環境：Windows Chrome 無頭，1920x1080，部署版 3480099 之前的線上版（含 3480099 後請再驗）。

## 推測
某個元件在 LoginScene 尚未完成初始化（節點或 target 為 null）時就被轉場銷毀／解除註冊，`off` 對 null 呼叫。應檢查 index.js:1991 附近的 unregister 路徑，加 null 守衛或等初始化完成才開放開始鈕。

## 完成條件
`--login-settle 1000` 實跑 0 pageerror，且大廳正常載入。

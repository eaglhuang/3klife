## 問題
戰場結算按「返回大廳」後，`HallWalkerPlan.ts` 的 `planHallWalkers` 每個 tick 丟 `Cannot read properties of null (reading 'rotatedAtSec')`，預覽出現紅色錯誤層（戰場專家回報，擋住戰場 MVP 回程）。

## 原因
舊 LobbyScene 銷毀時沒有停掉大廳站位輪換計時器；引擎把已銷毀元件的欄位清成 null，計時器仍呼叫 `_buildHallCast` 讀到 null 狀態。

## 修正
- `LobbyScene.onDestroy` 呼叫 `LobbyHallScreenBinder.stopStageTicking()` 只停計時器。
- `_buildHallCast` 在元件已失效時回空名單。
- `planHallWalkers` 狀態為 null 時視同初次排班。

## 驗收
- 單元測試新增 null 狀態案例；compute-gate standard、tsc test 0、run-cli 全過。

# [PROG-2-9106] 轉蛋返回大廳後城池底欄 BtnCat* 消失

## 問題
轉蛋畫面按「返回政廳」後，大廳底欄 `BtnCat*` 節點全部不在（PROG-2-9047 驗收）。

## 目標
重現並找出原因；真 bug 則修，讓返回大廳時 UI 堆疊回到 LobbyMain，城池層恢復。

## 完成條件
- 修好，或寫明「腳本預期錯」並附證據。
- compute-gate standard、`npx tsc -p tsconfig.test.json --noEmit` 0 錯、run-cli 單元測試 ALL PASS。

## 結論
結論: 真 bug，已修

原因: 轉蛋是 UIManager 替換式頁面，打開時收掉 LobbyMain（城池底欄 BtnCat*、季節 HUD）；返回鈕 GachaReturnToLobby 呼叫 returnToLobbyHall 只關宿主、直接開大堂，UIManager 仍停在 GachaMain，LobbyMain 不回來（之後從別頁返回還會把轉蛋翻回來；戰後季報彈窗也被埋在大堂下）

變更: 新增 ui/core/LobbyHallReturn.ts（restoreLobbyMainUi：沿歷史逐頁 close 直到 LobbyMain，沒有就 open）、LobbyScene.returnToLobbyHall 呼叫並防重入、tests/LobbyHallReturn.test.ts 5 案

實跑證據: 同邏輯注入線上版後返回大堂 BtnCatShop 在、getCurrentUI()=LobbyMain、大堂在最上層

驗證: 線上版（https://eaglhuang.github.io/3klife-play/）以修正後腳本實跑 6/7 步通過（唯一失敗為 PROG-2-9106 轉蛋返回）；把 PROG-2-9106 修正邏輯注入線上版後 7/7 通過；compute-gate standard、test tsc 0、run-cli ALL PASS 7737

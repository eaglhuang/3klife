## 問題
線上驗收（來源 d9e999a4c）在大廳直接出征的流程中，console 出現 `[LobbyScene] 背景第 32 個面板掛載失敗 TypeError: Cannot read properties of null (reading 'name')`。

## 原因（推定）
背景面板逐個掛載期間玩家已離開大廳（出征按鈕 67ms 內按下），等待中的面板回來時節點已被引擎銷毀、欄位清成 null。迴圈只在每個面板開始前檢查節點，例外發生在等待途中。

## 修正
`_runDeferredMounts` 捕捉例外時若大廳節點已失效，視為正常中止直接結束，不記錯誤。大廳仍在時的真錯誤照常記錄。

## 驗收
- 線上驗收 console 不再出現此筆；compute-gate standard、tsc 0、run-cli 全過。

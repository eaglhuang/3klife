## 問題
`button-bar` 等 Widget 在 `params` 宣告了預設值（labelCancel、showTertiary…），但 `UITemplateResolver` 展開 compose item 時只合併 Template 參數與 item 參數，沒套 Widget 自身預設。沒傳的參數保持 `${labelCancel}` 原字樣；`active: "${showTertiary}"` 也被當成真值，第三顆按鈕顯示出來。奧義選單原本在元件內手動關掉第三顆按鈕繞過，其他用 button-bar 的範本（dialog-confirm、dialog-select、fullscreen-result）同樣受影響。

## 修正
共用層修：新增純函式 `mergeWidgetParams`，合併順序為 Widget 預設 < Template 參數 < compose item 參數。

## 驗收
- 新增 tests/UITemplateResolverParams.test.ts；compute-gate standard、tsc test 0、run-cli 全過。

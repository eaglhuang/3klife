## 問題（使用者實玩回報）
1. 幕府大廳全螢幕蓋住原本的季節卡，「推進一季」按鈕被壓在軍務牆下面點不到，玩家無法進入下一季。
2. 右上角「返回」只跳一句「主公已在幕府大堂坐鎮」，沒有任何作用。
3. 大廳不會關閉，出征選單裡的「幕府大廳」點了等於沒點。

## 修正
- 右上角按鈕改為「推進一季」，直接走既有的推進季節流程；推進中重複點擊不重入。
- 出征選單拿掉「幕府大廳」。

## 驗證
- 單元測試：選單不再含 lobbyHall；大廳綁定器點右上角會呼叫 onAdvanceSeason。
- 線上實跑：在大廳點右上角，頂列年季文字會變。

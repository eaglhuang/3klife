## 問題
使用者實玩回報：轉蛋系統很多按鈕沒有正確功能，也看不到可消耗道具數量。稽核後找到：
- 「紀錄」鈕在非開發模式整個被擋掉，點了沒反應（結果清單後備視窗同樣被擋）。
- 每個池右側的「詳情 ›」沒有任何人綁事件。
- 池圓點用程式 key 找節點：限定池圓點找不到、紅顏池的點會跳到錯的池。
- 金幣鈕、召喚券鈕在其他池會被改成該池單抽，實際扣的是靈玉或支援券，卻寫著金幣／召喚券。
- 紅顏池畫面寫「召喚券 1／10」，實際規則扣靈玉 160／抽。
- 餘額只顯示池的第一種貨幣，沒有全部資源；結果畫面不顯示剩餘；餘額不足的提示不統一、不帶現有數量。
- 左上說明框其實是天命商店入口，但字樣沒提示。

## 修正
- 紀錄鈕、結果後備清單拿掉 DEV 限制；紀錄動作改顯示中文名稱、空紀錄有提示。
- 「詳情 ›」開池詳情（費用、持有、機率、保底、說明；名將池附死亡傳承提示）。
- 圓點改用原稿池 id（layoutKey）。
- 按鈕統一入口：金幣／召喚券只在名將池可用，其他池明講原因；抽前先查餘額，不足時 toast 寫缺哪種、要多少、現有多少。
- 紅顏池畫面價格同步成實際扣的靈玉（只改顯示，不改規則與數字）。
- 資源列：轉蛋畫面頂部一個 Label 顯示七種資源（靈玉、銅錢符、召喚券、支援券、金幣、積分、求籤令），抽卡、兌換後即時刷新；「我的餘額」顯示下一抽會扣的貨幣；結果畫面標題附剩餘。
- 說明框標題標明「點此開天命商店」（紅顏池除外）。

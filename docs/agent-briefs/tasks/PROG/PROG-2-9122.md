## 問題
- 大廳按「推進一季」後會先後出現事件視窗與季度戰報，關掉戰報後事件視窗被全螢幕遮罩壓住，滑鼠與 ESC 都沒反應，大廳按鈕也全部失效，只能重新整理。

## 根因
- 季度戰報的 X 直接呼叫元件自己的 hide()，沒經過 UIManager.close()，UIManager 仍認為戰報開著，`__ui-backdrop` 沒收掉。
- 遮罩緊貼在「UIManager 登記的最上層彈窗」之下，但事件視窗是 LobbyScene 自己掛的 host，不在 UIManager 內，被夾在遮罩之下。

## 修正
- 層級／遮罩歸屬抽成純函式 assets/scripts/core/managers/UIBackdropLayout.ts。
- UIManager 遮罩歸屬只算「節點真的顯示中」的彈窗；節點被外部關掉時自動重算並收遮罩（通用，不針對單一視窗）。
- 戰報的 X 改走 UIManager.close。

## 驗證
- tests/UIBackdropLayout.test.ts、tests/UIManager.test.ts。
- compute-gate standard、tsc、tests/run-cli.ts。

## notes
- 2026-11-17 完成。根因：戰報 X 直接 hide() 不經 UIManager.close，登記狀態與遮罩殘留；遮罩又只貼在登記的最上層彈窗下，LobbyScene 自己掛的事件視窗被夾在遮罩下。
- 做法：遮罩擁有者改為「登記開啟且節點顯示中」的最上層（純函式 UIBackdropLayout.ts）；UIManager 監看節點 active，被外部關掉時移出堆疊並收遮罩；遮罩緊貼擁有者正下方、不再移動擁有者；戰報 X 改走 close。測試替身補 ACTIVE_IN_HIERARCHY_CHANGED 事件名。

## 問題
- 牆上任務卡顯示設計稿預設文字（夜襲烏巢糧倉等），真正的任務資料晚於牆面刷新才載入，牆面一直沒套上。
- 點牆上任一張卡只會開整面任務牆，不是該任務；「展開軍務牆／內政牆」也只是整面牆的點擊。
- 詳情視窗四鈕只有「委任」有處理；沒有出戰主將時任務牆「接取」鈕是停用的，點了沒有任何提示。

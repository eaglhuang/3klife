- 3：事件結算（性格事件、三國季報奇遇）與內政任務選擇後補刷頂欄。
- 4：頂欄時間與內政面板改用規格 UI_SEASON_DISPLAY「第 N 年 M 季」，頂欄後綴晝夜。
- 2、5：只查原因，見 notes。

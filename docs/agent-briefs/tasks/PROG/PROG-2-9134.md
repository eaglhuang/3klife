## 問題
新玩家開太守府，人口、民心、黃金產出（基礎值／人口紅利／政策修正／總計）都顯示「—」；升級鈕只寫「糧草不足」，看不出差多少。

## 查因（人口、民心屬 a：大廳城市卡已有暫定推算值沒接到太守府；黃金產出屬 c：規格沒給數值或公式）
- 大廳城市卡（LobbyCityHubController 的 cityPopulation、cityMorale，註明暫定）早就顯示人口 8.3 萬、民心 61，太守府的快照卻固定給 null。
- 程式刻意以 null 顯示「—」（GovernorHallView.ts 檔頭與 buildGovernorSnapshot 註解），沒有接線缺漏。
- 規格只說人口、民心影響兵源與產能（領地治理系統.md 頂部 2026-04-26 覆寫裁定；經濟系統.md；戰場部署系統.md §F-0 公式），沒有初始人口、初始民心、Mobilization_Rate、Morale_Mod、Policy_Mod 的數值，也沒有人口紅利與政策修正的公式。
- 黃金：領地治理系統.md §F 只有「商業任務 Base(50)+CHR×3」，屬武將指派任務產出，沒有固定季產出；換季結算目前也不入黃金，規格亦未定義。
- 糧草 150 是 FOOD_PER_SEASON 固定補給，兵源 3000 與補兵 750 來自 MilitaryReserve，這幾項本來就有值。

## 做法（只做不需新數值的部分）
- 升級鈕不足提示加上所需量與現有量：「糧草不足（需 1000，現有 300）」、「黃金不足（需 4000，現有 N）」。
- 太守府人口、民心改用大廳城市卡同一組暫定推算值，兩個畫面數字一致（沒有新增任何數值）。
- 黃金產出（基礎值、人口紅利、政策修正、總計）維持「—」，等使用者裁決。

## 驗證
compute-gate standard、tsc、run-cli、web 建置與 playtest 11/11、真滑鼠截圖。

- 只改 LobbyScene 的掛載／顯示流程，不動戰報面板內部版面。

## 如何驗證
1. 真滑鼠走 大廳 → 內政 → 晨報・派遣板 → 戰報，截圖不再露出底下標題；關閉後回晨報派遣板，大廳其他按鈕可點。

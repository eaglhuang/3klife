## 目標
雲端試玩版（靜態網頁、無後端）玩一整年出現 4 筆 console error（連 localhost:3000/sync 被拒），擋住「全程無錯誤」里程碑。SyncManager 預設改為離線單機：未設定同步伺服器時不發請求、不丟錯、資料留本機佇列；本機開發有後端時可由設定啟用。

## 範圍
assets/scripts/core/systems/SyncManager.ts、tests/SyncManager.test.ts、本卡。

## notes

狀態: 完成。根因是 SyncManager.ts serverUrl 寫死 http://localhost:3000，原防護只擋非 localhost 主機名；QA/本機以 localhost 開試玩版時仍會連線被拒。
變更: serverUrl 預設空字串（離線）；可由全域 SYNC_SERVER_URL、網址參數 ?syncServer= 或 setServerUrl() 啟用；syncNow／syncDelta／syncFull／flushCompressedActions 未設定時靜默返回。移除主機名特例。
驗證: tsc 0 錯誤；run-cli ALL PASS 8108；compute-gate standard 通過（僅既有 import-boundary 警告，與本卡無關）。新增測試：預設離線不呼叫 fetch。

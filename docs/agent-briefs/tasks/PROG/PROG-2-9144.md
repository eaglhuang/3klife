## 目標
依通用任務核心架構設計實作引擎中立（不 import cc）的任務純邏輯：定義型別、情報分層選分支、巢狀結果樹（roll／switch／chance／seq）、seeded 衍生、純函式結算回傳帳本、依情報投影的玩家視圖（含誤導文字）、再探／等待情報計算、IMissionService 介面與 DTO。

# [PROG-2-9150] 武將心智 MIND-2：學習規則＋主動請求＋信箱

## 目標
武將從玩家過去的決定學習（屢敗變謹慎或想雪恥、常搭檔生羈絆、久未派遣抱怨冷落），換季時主動向主公提出請求（求封、請戰、雪恥、請罪、抱怨冷落、進言），請求與台詞都引用實際發生過的事（任務名、對手名、季數）；玩家在信箱答應／拒絕，結果回寫心智事件。

## 使用者裁決
主動請求活躍：全隊每季最多 6 則、同將同類冷卻 1 季；求封／請戰屬重大事件。只勸阻不抗命（成功率小幅下修）；忠誠 <30 且連續受辱才抗命一次並寫信箱。失敗與冷落只影響心情、台詞、意願、請求，不扣忠誠與資源。

## 範圍
core/mind/MindLearning.ts、MindRequests.ts、MindLineTemplates.ts；NpcUtilityAI.ts（五因子接真資料）、JournalReaction.ts（個人化模板）；ui/components/mind/*；SeasonPersonalityEvents.ts（只加與經歷相關權重）；GameSession.ts 只在 mind 既有接線附近加少量呼叫。避開 PROG-2-9148（任務段、PlayerSaveService、ServiceLoader）與 PROG-2-9149（戰後結算、開局段）。

## 不做
queryOpinion 的選將 UI（MIND-3）、npc-brain 接縫（MIND-4）、戰場承接請戰（戰場專家）。

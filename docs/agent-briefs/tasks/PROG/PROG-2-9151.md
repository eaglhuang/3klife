# [PROG-2-9151] 官職晉升解鎖節奏

## 目標
使用者裁決第 70 條：開局只開核心功能；官職晉升跳彈窗列出新解鎖功能；季報預告下一官職會開什麼。讓新玩家玩滿一年不卡關、也不被一次塞滿功能嚇到。

## 範圍
新增 data/officer-feature-unlocks.json、core/systems/OfficerFeatureUnlocks.ts（純邏輯）、tests/OfficerFeatureUnlocks.test.ts、晉升彈窗畫面（ui-spec 三檔）；改 LobbyCityHubController（鎖頭標籤）、LobbyScene（接線）、SeasonReportPanel／SeasonReportComposite（預告一行）。

## 不做
GameSession 任務段／戰後結算段／開局段／mind 接線、PlayerSaveService／ServiceLoader、core/mission/*、core/mind/*、LobbyMissionDetailDialogComposite。

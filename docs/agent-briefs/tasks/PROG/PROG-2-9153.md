## 目標
PROG-2-9404 查出 issue #2319、#2223 的根因：assets 底下約千個 .meta 沒進版控，乾淨工作樹每次建置 uuid 都重新產生；加上 config.json 被快取，玩家瀏覽器拿到舊 config 就去要新建置已不存在的 uuid 而 404。本卡修根因：
1. 補追蹤 .meta（uuid 以主目錄 Cocos 編輯器實際使用者為準，複製不重產；主目錄沒有的新檔才產生新 uuid），加檢查腳本 tools_node/check-untracked-meta.js 並接進 compute-gate。
2. 發版快取：建置後處理腳本 tools_node/stamp-web-build.js，讓新版上線玩家不會拿到舊 config。
3. GachaPoolSwitcher 資源載入失敗或逾時要有後備，附單元測試。

## 範圍
assets/** 底下的 .meta（清單見 PROG-2-9153-meta-list.txt）、tools_node/check-untracked-meta.js、tools_node/stamp-web-build.js、tools_node/compute-gate.js、assets/scripts/ui/core/GachaPoolSwitcher.ts、tests/GachaPoolSwitcher.test.ts。
不動：他人的卡、鎖、PR；主目錄（只讀 .meta）；deploy-batch.sh。

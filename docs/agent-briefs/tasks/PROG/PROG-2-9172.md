# PROG-2-9172：G3 補觸發（家族累積 3 代以上亦升 G3）

## 目標
避免純外婚玩家因未選中三代內共祖表親而跳過 G3 世交合譜與血脈清濁燈號：
- `milestoneStageOfClan` 於家族累積達 3 代（`generations >= g3MinGenerations`）時回傳 `3`。
- 保留「首次在提親介面選中三代內共祖表親」立即觸發 G3 之既有路徑，且階段不倒退。
- 門檻數值外置於 `assets/resources/data/family-milestone-rules.json`。
- 同步更新 `docs/遊戲規格文件/系統規格書/血統與家系漸進揭露里程碑總綱規格書.md`。

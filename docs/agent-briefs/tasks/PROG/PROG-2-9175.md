# [PROG-2-9175] 線上試玩回報：凍結與熱區偏移卡關除錯

## 開單原因
Antigravity 在線上版 295e225d3 實機試玩回報：命鏡升星／世家總覽「繼續」後凍結、借用教官後凍結、招賢館關閉後點紅顏凍結、第 23 年冬季雪花掉幀；多處彈窗熱區比畫面偏上。

## 重現結論（web-desktop 真滑鼠，視窗 1920x1080）
- 命鏡升星結果頁按「繼續」：可重現。宿主節點與 UIManager 彈窗堆疊、擋輸入遮罩都沒關，只被大廳拉到最前面蓋住；之後任何沒 bringToFront 的畫面都會被殘留的全螢幕宿主蓋在下面，看起來像凍結。
- 世家總覽按「返回大廳／繼續觀測」：可重現，同上。
- 培育借用好友教官：無法重現（點「借用」後清單關閉、培育畫面可操作、console 0 錯誤）。
- 招賢館關閉後點紅顏：無法重現（依序操作可正常開關）。
- 第 23 年冬季雪花：卡死無法重現（連推 92 季到第 24 年無例外、無洩漏）；單幀成本約 2ms（桌機），手機會放大，改為降頻＋封頂。
- 熱區偏移：無法重現。DPR 1.25／1.5、視窗 1280x900／1920x700、雙指縮放 1.25／1.5 下真滑鼠都點得到；按鈕框與可見內容中心偏移審計（大廳、任務牆、結緣配置、外交、武將詳情頁籤）0 筆。判斷為 Antigravity 瀏覽器縮放／座標工具差異。

## 根因與修正
- 彈窗殘留：returnToLobbyHall 只關宿主節點與替換式頁面，彈窗層（PopUp：世家總覽、命鏡覺醒／升階）不經 UIManager 關閉。LobbyHallReturn.restoreLobbyMainUi 先逐個關閉彈窗堆疊（有上限、關不掉就停）。
- 雪花：HallSeasonFxLayer 降頻到約 30Hz（累積 dt，速度不變）、手機粒子數封頂 36、春冬小光暈不畫光暈橢圓、重用 Color 不再每顆每幀 new。

# [PROG-2-9176] 線上試玩回報顯示錯誤：舊存檔適性、因子與狀態中文名、結緣文案、召喚券數量、官職提示

## 開單原因
Antigravity 在線上版 295e225d3 實機試玩回報五項問題。

## 規格依據
- 懷孕期：MCQ Q43「受孕後待產 4 回合」只規定母方精力凍結（BRD-02／VIT-03，`pregnancySeasonsLeft`），子嗣當下以 0 歲入冊（既有設計與測試）。改成真正的懷孕中狀態牽動名冊、年齡、開獎、存檔，改動過大，因此改文案。
- 官職門檻：官職系統.md F-2 階位表，數值讀 officer-tiers.json 安裝後的 OFFICER_TIER_EXP_THRESHOLDS。規格沒規定提示位置，沿用點擊鎖定按鈕的 toast。

## 完整描述
1. 舊存檔子嗣兵種適性顯示「—」：讀檔時 `backfillRosterChildAptitudes` 依 `inheritChildAptitudes` 補齊；該規則沒有亂數，同一存檔結果固定（不需要種子）。
2. 占卜露出內部 id、狀態顯示 Mystery／Unveiled：新增 `FactorDisplayName`，GameSession 與 SageOracleController 改用中文名（查不到就不顯示）；兩份 STATUS_DISPLAY 補「待開獎」「已開獎」。
3. 結緣成功文案改為「需調養待產 N 季（期間精力凍結、不能再結緣）；襁褓幼子已入宗族名冊」，四語系同步。
4. 召喚券：底部「持有 N」與「我的餘額」只在切池時刷新，抽完後停在舊值；改為共用 `gachaWalletLabelTexts`，`_refreshWalletPreviewState` 同步刷新。季報奇遇選項旁顯示黃金／糧草／木材持有量。
5. 官職鎖定提示：`lockedActionToast` 補「需要官職經驗 X，目前 Y」。

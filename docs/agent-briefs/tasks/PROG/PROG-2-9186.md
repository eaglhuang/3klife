# PROG-2-9186：任務詳情下拉捲動後擋住關閉鈕

## 目標
1. 捲出捲動區可視範圍的下拉列不可再接收輸入（Mask 只裁畫面不裁輸入）。
2. 點「不可派」的列（出任務中、尚未畢業）時收起下拉、保留原選擇。
3. 下拉開著時關閉鈕可直接關窗。

- `assets/scripts/ui/components/LobbyMissionDetailDialogComposite.ts`

- 變更: 列的 UITransform.hitTest 加上捲動區可視範圍限制；不可派列可點，點了收下拉並保留原選擇。

# [PROG-2-9187] 大廳底欄「培育」開局開放

## 開單原因
使用者 2026-11-20 裁決：大廳底欄「培育」要開局就開放；原本新玩家點開後四個子選單全帶鎖。

## 規格依據
- 官職系統.md F-2 階位表與 PROG-2-9151 解鎖節奏（暫定、可逆）；門檻已在 data/officer-feature-unlocks.json，不寫死在程式。

## 完整描述
1. 開獎・培育改為階位 1（開局開放）。
2. 關係圖鑑改為階位 1：以歷史關係表加手上武將即可顯示恩怨情誼，開局有內容，且與開局已開放的結緣相關。
3. 支援卡、祠堂維持縣府佐官：開局沒有教官卡（只會跳「尚無教官卡」）、聲望 0 無福祉，開了只有空畫面；鎖頭與點擊提示已寫明「縣府佐官」與所需官職經驗。
4. 晉升縣府佐官的教官提醒文案由「培育已開放」改為「培育入學要帶教官，先去教官池抽教官」（文案本無 i18n 鍵，無四語系檔需改）。
5. 測試：新檔階位 1 的開獎・培育與關係圖鑑可用，支援卡、祠堂仍鎖。

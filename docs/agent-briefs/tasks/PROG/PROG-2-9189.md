# PROG-2-9189：學府修業主畫面＋入學（第一版只開潁川）

設計依據：docs/遊戲規格文件/系統規格書/學府修業畫面與接線設計.md (doc_spec_1179)。所有「新增 layout」與「引擎 API」細節以設計文件為準。

## 目標
1. 新增 `AcademyFlowController`（`ui/core`，純邏輯＋依賴注入），管理 `enroll`／`session` 兩個模式與 `idle`／`settling` 狀態。
2. 入學畫面（設計文件 4.1）：選子嗣、學府（潁川可選，其餘四座顯示「即將開放」）、教官（先祖置頂）、控制模式；按「入學」呼叫 `createAcademySnapshot`、`assignYingchuanMentors`、`AcademyAntiSLManager.begin`。
3. 修業主畫面（設計文件 4.2）：TRAIN／REST／GIMMICK_INTERACT 走 `commit`，回合結算後 `acknowledge()`；潁川清談與事件互動（文字列表）；暫離與讀檔 `recover()` 還原。
4. 存檔：新增 `GameAcademySaveStore`（實作 `IAcademySaveStore`，write 失敗必拋）、`GameSession.academyRecord`、`PlayerSaveSnapshot.academy`（缺值相容舊存檔）。
5. 外界凍結：有未結業學府存檔時大廳「下一季」鈕擋下並 toast；`AcademySaveRecord` 另存進入時 `GameTimeState`，`recover()` 以其為準（設計文件第 5 節）。
6. 驗證並記錄以真實時間倒數的項目（任務牆加速卡等）是否在修業期間漏動，寫進 notes，不在本卡處理。

## 範圍（預計改動檔案）
- `assets/scripts/ui/core/AcademyFlowController.ts`（新）、`AcademyFlowView.ts`（新，文字與 enabled 狀態組裝）
- `assets/scripts/core/services/GameAcademySaveStore.ts`（新）
- `assets/scripts/core/managers/GameSession.ts`、`assets/scripts/core/services/PlayerSaveService.ts`
- `assets/scripts/ui/scenes/LobbyScene.ts`（掛載宿主、底欄入口、凍結擋下；子選單門檻由 PROG-2-9187 負責，本卡不改）
- `assets/resources/ui-spec/layouts/academy-enroll-main.json`、`academy-session-main.json` 與對應 `screens/`、`content/`、`skins/` 引用檔（skin 引用 `nurture-flow-default`，不新增圖）
- `assets/resources/i18n/{zh-TW,zh-CN,en,ja}.json`
- `tests/AcademyFlowController.test.ts`、`tests/GameAcademySaveStore.test.ts`

## 手機記憶體
不新增圖集；固定節點、不動態建節點；隱藏用 `active=false`；進出一次節點數回到進入前正負 5%。

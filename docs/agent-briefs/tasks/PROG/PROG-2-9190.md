# PROG-2-9190：學府打斷宿主與四種彈窗

設計依據：docs/遊戲規格文件/系統規格書/學府修業畫面與接線設計.md (doc_spec_1179)。所有「新增 layout」與「引擎 API」細節以設計文件為準。

## 目標
1. 在 `AcademyFlowController` 加 `interrupt` 模式：`pendingInterrupt` 非 null 時疊共用打斷彈窗，玩家作答後 `commit({ actionType: RESOLVE_INTERRUPT, selectedOptionId })`。
2. 四種彈窗共用同一組節點（設計文件 4.3）：`MIDTERM` 期中方針三選一（`STRENGTH`／`BALANCE`／`NOURISH`）、`COMING_OF_AGE` 弱冠戰法三選一（`interruptOptions`，戰法顯示名走 `tactic-library`）、`RESONANCE` 見證（`WITNESS`）、`GRADUATION` 結業確認（`CONFIRM`）。
3. 期中與弱冠結算後取結算前後快照，呼叫 `LobbyScene.showAcademyInheritDraw(before, after, ancestorName)`；`ancestorName` 取先祖教官名。
4. 打斷彈窗不可取消；暫離後重進由 `recover()` 還原並重新彈出；`AUTO` 模式引擎代選，畫面只顯示結果。
5. 方針與戰法文案走 i18n 四語，不外露內部 id。

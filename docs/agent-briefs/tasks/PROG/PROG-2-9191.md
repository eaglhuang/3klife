# PROG-2-9191：學府結業與入口串接、舊培育訓練回合下線

設計依據：docs/遊戲規格文件/系統規格書/學府修業畫面與接線設計.md (doc_spec_1179)。所有「新增 layout」與「引擎 API」細節以設計文件為準。

## 目標
1. 結業串接（設計文件 4.4）：`GRADUATION` 確認後 `showAcademyGraduation` → `graduateFromAcademy` → 關彈窗後清 `academyRecord` → 以 `_advanceSeasonWithSalaries()` 推進外界恰好 1 季 → 回大廳。失敗（回傳 null）時保留存檔、不推季。
2. 入口改接：5 歲開蒙 toast（`GeneralUnveiled`）、lineage 彈窗 `openAcademy`（改 `openAcademyEnroll(childId)`）、15 歲及冠【送入學府】直通、底欄「培育」／「開獎・培育」（有進行中學府時直接回修業主畫面）。
3. 舊 NurtureFlow 縮成「抓周＋入學入口」：隱藏 `trainBlock`／`graduateBlock`／`reportBlock`／`tacticBlock`，`btnStartNurture` 改為「送入學府」；舊訓練回合、結業評級、自動培育訓練的呼叫端下線（純邏輯檔保留供遷移與測試）。
4. 舊存檔遷移（設計文件 1.3，依 Q1 裁決）：讀檔時處理 active 舊會話，退學重來或依進度結業，不推進外界時鐘；舊存檔 fixture 測 round 5、12、36。
5. 時間驗收：覆蓋 doc_spec_0524 的 TC-TIME-13 到 TC-TIME-16。

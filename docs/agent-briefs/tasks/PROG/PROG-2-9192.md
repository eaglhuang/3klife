# PROG-2-9192：academy playtest 步驟與 QA 快進入口

設計依據：docs/遊戲規格文件/系統規格書/學府修業畫面與接線設計.md (doc_spec_1179)。所有「新增 layout」與「引擎 API」細節以設計文件為準。

## 目標
1. `tools_node/playtest-online.js` 新增選用旗標 `--academy`：用新玩家開局送的 4 歲幼苗，走完「下一季 4 次開蒙 → 抓周 → 送入學府 → 入學潁川 → 36 回合 → 結業 → 回大廳」，每個關鍵點截圖（入學、第 1 回合、期中打斷、開獎 toast、弱冠打斷、第 36 回合、結業彈窗、回大廳），輸出 `academy-report.json`（回合數、打斷次數、結業評級、前後季數、`window.__pt` 節點數）。
2. 網址參數 `qaAcademy=<回合>`（沿用 `QaTimeScale` 慣例：無 qa 參數時不介入）：入學後以引擎快進（連續 commit 訓練）到指定回合，供打斷彈窗截圖。不得改動 `QaTimeController`／戰場程式；它只做慢動作，無法推進學府回合。
3. 更新 `--year` 一年循環的「培育」步驟（約 1674 行）改為進入學府入學畫面並截圖，不再點舊訓練鈕。
4. 在 `docs` 的 playtest 說明（檔頭用法註解）補 `--academy`、`qaAcademy` 用法。

## 範圍（預計改動檔案）
- `tools_node/playtest-online.js`
- `assets/scripts/ui/core/AcademyQaFastForward.ts`（新，純邏輯可單元測試）、`assets/scripts/ui/scenes/LobbyScene.ts`（讀網址參數，僅一處掛接）
- `tests/AcademyQaFastForward.test.ts`

## 開單原因
使用者回報：大廳背景預載 44 個介面期間頻繁卡頓，且浮層遮擋右下角信箱。戰場專家回報：背景面板建構中切換場景，buildScreen 讀到 null host 跳錯誤浮層。

## 完整描述
- 背景掛載改由 LobbyMountScheduler 排程：熱門清單優先、閒置才建、每幀預算與玩家操作暫停、換場取消；清單與預算放 JSON。
- 其餘介面按需建構：點擊時立即補建。
- 右下角小進度條改不遮信箱。
- buildScreen 遇 host 已銷毀安靜放棄。

## 如何驗證
1. 單元測試、型別檢查、run-cli 全過；2. 建置實玩 11/11；3. 前後掉幀量測；4. 截圖信箱可點。

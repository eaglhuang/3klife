# PROG-2-9199：家業經營與世家系統規格書

## 目標
1. 產出新規格書 doc_spec_1181：幕府升級後開放「幕府後院」六個家業（家族商店、酒店、歌劇廳、學院、義勇營、貿易商行），給閒置武將、後代與退役老將長期去處。
2. 涵蓋定位與節奏、與既有系統分界、依賴的共用框架（商店、物品庫存、任務、獎勵、技能、劇情六套，只標差異欄位）、幕府等級解鎖、家業通則、六家業逐項、廚房與成長膳產出端（接 PROG-2-9198）、出海貿易、世家包裝與郡望連動、人力取捨與退役、畫面與美術、資料結構、待裁決選擇題、實作卡拆分。
3. 數值、職缺、產出、道具由企劃定案放 JSON；只有大方向列選擇題（Q1~Q6）。

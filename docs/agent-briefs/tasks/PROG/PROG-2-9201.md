## 開單原因

## 完整描述
1. 共通 API 契約（assets/scripts/shared/api/）：封包、版本、reqId、錯誤碼、冪等鍵、IApiClient。
2. 本機伺服器 adapter（assets/scripts/core/api/local/）：命令路由、冪等、saveRev、事件、權威錢包命令。
3. 存檔即 API：save.load／commit／full／rev；GameSession 存讀檔改走 adapter；PlayerSaveSnapshot 增加選填 apiSaveRev，舊檔缺值補 0。
4. 自動檢查：tools_node/check-api-bypass.js＋api-bypass-baseline.json 棘輪，納入 compute-gate。
5. 示範遷移：成人禮轉職令購買（扣靈玉）改走 wallet.spend。其餘遷移列清單。

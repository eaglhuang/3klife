# PROG-2-9210：學府規格追加共用框架依賴章與實作卡拆分建議

## 目標
1. 在 doc_spec_1179 新增第 9 章「依賴的共用框架與共通 API」：學府各功能（修業回合、打斷、結業獎勵與開獎、入學令與道具、戰法與 TP、結業戰法商店、教官）逐項標出底層 base（商店、物品庫存、任務、獎勵、技能、劇情）與只寫的差異欄位；列出重要數值與存檔改走共通 API 的清單與本機／網路 adapter 界線。

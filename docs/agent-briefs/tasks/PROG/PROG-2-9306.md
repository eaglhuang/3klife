## 開單原因
一格只站一個小兵，看不出是部隊。總PM核准 3 人小隊，條件是同兵種共用骨架與圖集、錯開時間差，並量測效能。

## 完整描述
- 隊員與帶頭者共用同一份骨架資料與圖集，只多節點。
- 循環動作錯開起始時間；攻擊、受擊、倒地依序延後。
- 依兵力比例顯示 3／2／1 人。
- 單挑邀請後備彈窗改以類別名稱取得底色元件，移除 battle→ui 的直接引用。
- 新增騎兵／盾兵美術規格文件供 Codex 製作。

## 如何驗證
1. `tests/SpineUnitOverlay.test.js` 小隊案例通過。
2. 實機 4 隊同場 60 fps；敵騎兵受傷後由 3 人變 2 人。
3. 模組邊界守衛 0 違規。

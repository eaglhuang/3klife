## 開單原因
整場自動實跑三場，每場結束都出現一筆未捕捉例外「Cannot read properties of null (reading size)」：戰鬥結束換場景後，等待單位移動完成的迴圈還在跑，但元件已被引擎銷毀、欄位被清成 null。另外大廳多了「選擇戰鬥模式」步驟，進場腳本需要跟上。

## 完整描述
- `UnitRenderer.waitForMovementIdle`／`waitForUnitMovementIdle` 先確認元件仍有效再讀移動中名單，元件銷毀後直接結束等待。
- `tools_node/battle-qa/enter-battle.js` 不再寫死大廳到戰場的按鈕順序，改為每輪看畫面上有「親自指揮／強行出征／戰場／戰前偵查出征」哪個就點哪個；場景尚未載入時不報錯。
- `tests/cc.mock.ts` 補上 `isValid`。
- 結算窗落敗／平手標題改深色，原本淺灰字配淺灰底對比過低。

## 如何驗證
1. 型別檢查 0 錯、單元測試全過、模組邊界檢查通過。
2. 進場流程以同一套邏輯在預覽實跑成功（開始遊戲 → 出征 → 戰場 → 親自指揮 → 進入戰場）。

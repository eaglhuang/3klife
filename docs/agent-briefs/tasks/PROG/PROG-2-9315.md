## 開單原因
實機測試：長坂坡突圍接受敵方單挑後約 3 秒直接出結算、看不到任何交鋒。原因是交鋒動畫需要雙方主將都有 Spine 動畫，任一方沒有就整段略過，所有傷害在同一瞬間提交。

## 完整描述
- `SpineGeneralOverlay.playDuel` 與 `UnitRenderer.playDuelPresentation` 改回傳是否真的播了交鋒動畫。
- `BattleUIBridge.resolveDuelPresentation`：明確得到「沒播」時，逐招提交傷害數字與戰報（招數少每招 0.4 秒，招數多壓縮到總長約 2.4 秒，單招不低於 0.06 秒），最後一招後停 0.5 秒才出結算。
- 有交鋒動畫時行為不變。

## 如何驗證
1. `npx tsc -p tsconfig.test.json --noEmit` 0 錯。
2. 單元測試全過；`tests/DuelPresentationBridge.test.ts` 新增「逐招提交」與「逐招間隔」兩案；`tests/SpineUnitOverlay.test.js` 通過。
3. 未做：新程式尚未在實機預覽驗證。

## 開單原因
使用者 2026-11-16 指示：小兵要有 Q 版動畫與素材，並有兵種設計。原本所有非弓兵的小兵都畫成槍兵，戰場上分不出盾兵、步兵、工兵、醫護、水軍。

## 完整描述
- `troopSpineConfig(兵種, 是否敵方, 虎符卡 id)`：槍兵、弓兵、盾兵、步兵、工兵、醫護、水軍各有素材名；陷陣營、大戟士等虎符套精銳外觀；騎兵等尚無素材的兵種沿用槍兵。
- `troopSpineConfigWithFallback`：素材載不起來時依序退回「精銳 → 兵種 → 槍兵／弓兵」，不讓單位變回方塊。原因：兵種素材是私有美術、不進倉庫。
- `SpineUnitOverlay.hasFailed(path)`：讓呼叫端知道哪份素材已確定載入失敗。
- 文件：`docs/battle-chibi-troop-design.md`（兵種外觀設計）、`docs/battle-chibi-troop-art-commission.md`（給 Codex 的騎兵與連弩手委託，已寄到 mailbox 分支）。
- 工具：`tools_node/battle-chibi/troop_art.py`、`make_troop_variants.py`（由槍兵分件產生各兵種頭飾與武器）、`soldier_rig_attack_class.patch`（待回灌私有倉庫的骨架補丁）。

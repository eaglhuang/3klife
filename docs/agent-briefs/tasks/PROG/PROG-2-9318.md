## 開單原因
總PM 2026-11-16 裁決兩項：部隊打主將保底傷害改 max(1, round(攻擊力×20%))；城市兵源不足時不可讓玩家進戰場一隊都派不出去，要給保底一隊步兵（不扣城市兵源）並在出征畫面提示。

## 完整描述
- `GAME_CONFIG.generalMinDamageRatio = 0.2`；`generalMinDamage(攻擊力)`；傷害管線開啟時，部隊打主將的傷害不低於此值。
- `SORTIE_GUARANTEE_TROOPS = 500`：出征軍勢不足一隊步兵時補到剛好一隊；補上的兵力記在 `guaranteedTroops`，戰後結算戰損先扣這一份，超過的才扣城市兵源。
- 出征畫面摘要：兵源不足時多一行提示（保底一隊步兵、不扣城市兵源、每季自動補兵）。

## 如何驗證
1. `npx tsc -p tsconfig.test.json --noEmit` 0 錯。
2. 單元測試 7716 通過；`tests/SortieDeploy.test.ts` 新增 2 案。
3. `npm run test:battle-skill-smoke`：`tests/BattleCombatRegression.test.ts` 新增 1 案通過；同一支另有 1 案失敗（初始與既有戰技 profile 都應維持自動選目標），與本卡修改的檔案無關，未在乾淨基準上對照。

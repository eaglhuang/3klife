## 開單原因
線上試玩版全新玩家實跑首戰（2026-11-16）：出征軍勢 3000 只夠派 5 隊，第 3 回合起無兵可派；SP 只來自擊殺，我方整場 0 SP，奧義與計謀一次都放不出來；4 隊圍攻敵主將 3 回合只打掉 130 血。總PM 裁決：讓新玩家第一場就能打、能放招、能真的打贏，一般戰鬥平衡盡量不動。

## 完整描述
- `GAME_CONFIG.tutorialStartSpFull`：教學戰開場我方主將 SP 滿。
- `GAME_CONFIG.tutorialEnemyGeneralHpRatio = 0.5`：教學戰敵主將血量上限與現值減半，同一場只套一次。
- `GAME_CONFIG.tutorialSortiePoolMin = 8000`：教學戰出征軍勢不足時補到 8000；補上的算保底兵力，戰損先扣這一份，不扣城市兵源。
- `GAME_CONFIG.spPerDamagingHit = 4`：部隊每次打出傷害（打敵方部隊或主將），所屬主將得 SP；敵方乘難度表倍率。擊殺仍另給 20。

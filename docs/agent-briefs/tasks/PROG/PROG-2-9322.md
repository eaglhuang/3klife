## 開單原因
線上試玩版實跑首戰（2026-11-16）：雙方部隊各走各的路去打主將，整場幾乎不交戰，我方拿不到擊殺 SP。總PM 裁決：路上相鄰或擋路的敵部隊要先交戰。規格（戰場大回合推進狀態機、部署、格子）沒有規定也沒有禁止相鄰交戰。

## 完整描述
- `BattleAutoMovePhase`：一般部隊每走一步前先看斜前方兩格與側面兩格，有看得見的敵部隊就停下。主將化身不算：自己不受限，敵主將化身擋不擋路仍由壓制區（FORM-09）決定。
- `BattleCombatResolver.findCombatTarget`：同路正前方沒有目標時，一般部隊改打相鄰敵部隊（斜前、側面），之後才輪到打主將。
- 開關 `GAME_CONFIG.troopEngageAdjacent`，預設開啟。

## 開單原因
線上實跑發現：主將是張郃或甘寧時奧義選單只顯示「未配置奧義」（235 位武將中 221 位沒有奧義資料，六位初始名將只有張飛有），計謀點開場 12、一招 30，要到第 5 回合才放得出來。新玩家第一場等於沒有招可放。總PM 2026-11-16 裁決：先做通用奧義退路，教學戰計謀點給滿，一般戰鬥不動。

## 完整描述
- `GAME_CONFIG.genericUltimate`：通用奧義的技能 id、名稱「全軍突擊」、傷害係數 0.6（低於專屬全屏奧義常用的 0.72）。
- `buildUltimateSkills`：主將沒有可用奧義槽、也沒有主技能時，回傳通用奧義而不是空清單。有主技能或已解鎖奧義槽的武將不受影響；專屬奧義定案後自然蓋過退路。
- `BattleSkillProfiles`：通用奧義 profile，全屏傷害、力量成長、不附帶狀態。`BattleSkillPresentation` 補演出名稱。
- `GAME_CONFIG.tutorialStartTacticFull`：教學戰 `configureSortie` 在墊高計謀上限後把目前點數補滿；一般戰鬥不動。

## 如何驗證
1. `npx tsc -p tsconfig.test.json --noEmit` 0 錯。
2. 單元測試全過；`tests/GenericUltimate.test.ts` 驗選單退路、有主技能者不受影響、profile 可施放、全體敵軍各受一次傷害、教學戰計謀點給滿而一般戰鬥不變。
3. 未做：尚未線上實跑。發版後用 `tools_node/battle-qa/play-full-battle.js --fresh --ultimate` 驗奧義與計謀實際放出次數。

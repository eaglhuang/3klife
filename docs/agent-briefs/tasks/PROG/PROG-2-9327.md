## 開單原因
六位初始名將只有張飛有奧義，其餘五位只能用通用的全軍突擊。使用者 2026-11-16 核可五位的第一階專屬奧義，總PM 派工：每招沿用現有戰鬥效果，數值先照被沿用那招的原值，實跑後再調。

## 完整描述
- 五個專屬技能 id，profile 直接展開被沿用的那一招（數值相同），戰報與提示顯示各自招名：
  - 魏延「子午奇襲」`wei-yan-ziwu-raid` ← `zhao-yun-pierce`
  - 夏侯惇「拔矢啖睛」`xiahou-dun-eye-devour` ← `liu-bei-rally`
  - 張郃「巧變連營」`zhang-he-adaptive-camp` ← `liu-bei-reset`
  - 孫策「小霸王之威」`sun-ce-conqueror` ← `lu-bu-rampage`
  - 甘寧「百騎劫營」`gan-ning-night-raid` ← `zhang-fei-roar`，加 `enemyRearRowOnly`
- `BattleSkillTargetSelector`：`enemyRearRowOnly` 時敵方全體只取離施放方最遠、且有敵軍的那一排。
- 資料：`master/ultimate-definitions.json` 加五筆第一階定義；`master/generals-base.json` 與 `generals.json` 五位武將各補第 1 格奧義槽。`skillId` 沒有填：填了武將詳情會顯示被沿用那招的舊名稱。
- 沒有跑 `build-generals-runtime`：它會順帶改寫一百多位武將的史傳文字（master 與 runtime 已分岔），與本卡無關。
- 實際效果與派工描述的差異（描述文字已照實際效果寫）：
  - 子午奇襲：直線長度 3、最多 4 個目標、三連刺逐段增傷；不是打穿整路。
  - 拔矢啖睛：全軍回復 18% 兵力；不是只回自己，也沒有下回合攻擊提高。
  - 巧變連營：一隊友軍再行動一次；不是全軍。
  - 小霸王之威：扇形傷害；沒有士氣下降。
  - 百騎劫營：最後排暈眩 1 回合；沒有傷害（張飛那招本來就只有暈眩）。

## 開單原因
線上實跑計謀點給滿卻 8 回合都沒扣。診斷結果是遊戲問題：周瑜、劉備、張郃、夏侯惇第一格戰法是「火攻」，條件是起風天氣，教學戰整場不起風，被 condition-restricted 擋下，畫面上只在戰報寫一句。

## 完整描述
- `GAME_CONFIG.tutorialIgnoreTacticConditions`（預設開）：教學戰不檢查戰法的兵種、天氣、鄰格條件；一般戰鬥照舊。
- `BattleController`：教學戰時 `getTacticConditions` 回空。
- `play-full-battle.js`：計謀步驟讀點數前後、進入瞄準時點目標、第 3 回合起沒放出就直接呼叫結算並印出被擋原因。
- 另一種放不出的情況（不是缺陷）：第一格是「士氣鼓舞」的武將（甘寧、孫策、魏延），我方沒人受傷時無可回復，不扣點。
- 後續建議（未做）：一般戰鬥中條件不成立時，計謀鈕應反灰並寫明條件，而不是按了才在戰報出一句。

## 如何驗證
1. 型別檢查 0 錯、單元測試全過；`tests/TutorialTacticConditions.test.ts` 驗一般戰鬥仍被擋、教學戰不被擋。
2. 未做：新版上線後實跑確認計謀點有扣。

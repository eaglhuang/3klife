## 開單原因
一般戰鬥裡火攻要起風才能放，但計謀鈕照樣亮著，按下去才跳「戰法條件未達成」，玩家不知道差什麼。總PM 2026-11-16 同意開卡：條件不成立時按鈕反灰並寫明條件。實跑另外發現點數不夠時按鈕只寫「受限」，看不到點數累積。

## 完整描述
- `TacticCondition.describeTacticCondition` 把沒達成的條件寫成完整句（需要起風）與兩個字的短原因（待風、缺敵、缺友、兵種）。
- `BattleSkillDispatcher.findUnmetGeneralTacticCondition` 與實際施放共用同一個條件檢查；`BattleController.getPlayerSeedTacticUnmetCondition` 給 HUD 用。教學戰免條件，所以永遠回 null。
- `buildTacticAvailability` 的檢查順序：計謀點 → SP → 天氣 → 戰法條件；條件沒達成時回完整原因與短原因。
- `ActionCommandComposite.setTacticSummary` 多收短原因：有就寫在按鈕第二行；原因是計謀點不足時照樣寫目前點數（灰字）。按下變灰的按鈕會提示「計謀暫不可用：需要起風」。

## 如何驗證
1. 型別檢查 0 錯、單元測試全過；`tests/TacticConditionButton.test.ts` 驗一般戰鬥沒起風查得到條件、起風後沒有、教學戰沒有、原因優先序與短原因文字。
2. 未做：線上目視按鈕文字是否完整不被裁切（按鈕寬度只容得下兩個字，短原因固定兩個字）。

## 開單原因
PROG-2-9322 讓部隊遇到斜前方或側面的敵軍就停下交戰，違反戰場設計。使用者 2026-11-17 親自裁示：旁邊經過的小兵不打是刻意設計，目的是放大兵種互剋與路線卡位；這是五路推進的格子兵種玩法；只有武將棋子經過旁邊才會跟小兵互打。總PM 要求最優先撤回。

## 完整描述
- `GAME_CONFIG.troopEngageAdjacent = false`，註解寫明設計意圖與不可再打開。
- 移動：小兵斜前方、側面有敵軍都照走，只有同一路正面有敵軍才停下（`tests/ZoneOfControl.test.ts`）。
- 攻擊：小兵不打側面與斜前方的敵軍；武將棋子會打側面與斜前方的小兵（`tests/BattleCombatRegression.test.ts`，在戰法冒煙裡跑）。
- 先前在側邊接敵開啟時量到的教學戰數據全部作廢，合併發版後重新量 7 場。
- 今後改動交戰、移動、接敵這類核心規則，先把方案交給總PM 向使用者確認設計意圖。

## 如何驗證
1. 型別檢查 0 錯、單元測試全過；戰法冒煙裡的新測試通過。
2. 未做：線上實跑；教學戰敵軍出兵路線、教學引導、增益格位置的方案尚未實作。

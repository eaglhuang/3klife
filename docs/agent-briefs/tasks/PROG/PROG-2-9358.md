## 開單原因
線上 d7a9992a2 實打，攻擊斬擊一次都沒出現。插偵錯輸出後確認：特效系統有取到池節點、粒子也播了，但節點沒有父節點、不在場景裡，所以畫面上看不到。所有沒指定父節點的方塊特效（含受擊光效、增益地塊光效）都受影響。

## 完整描述
- 特效系統的兩個播放入口改走同一個掛載函式：有指定父節點就用它；沒有、且節點目前沒有父節點時，掛到場景根。
- 已有父節點的節點不搬動。
- 副作用：原本看不到的受擊光效與增益地塊光效現在也會顯示。

## 如何驗證
1. 型別檢查 0 錯；全套單元測試通過（7834 過）。
2. 新增 tests/EffectSystemAttach.test.ts（原始碼守門）。
3. 以攔截方式把線上版主程式換成等效修正後實打：斬擊節點出現 131 次，回合正常、勝利、無新增錯誤。
4. 未做：弓兵飛箭這幾場都沒有弓兵出手，尚未驗到；音效無法由程式試聽。

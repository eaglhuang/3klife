## 開單原因
PROG-2-9358 合併後線上斬擊節點出現 188 次，但畫面上仍看不到。再查出兩個原因：一是特效系統把預設層寫成 1 << 0，引擎實際是 1 << 30，於是把本來正確的 prefab 改到沒有攝影機會畫的層，所有走這條路的特效都看不到；二是原本選的斬擊 prefab 粒子是拉伸模式但長度與速度倍率都是 0，沒有面積。

## 完整描述
- 特效層改用引擎的預設層常數；只有節點在介面層時才記錄修正訊息。
- 攻擊斬擊由 p3d_cfxr_slash_ray 換成 p3d_mep_charge_slash，不動 prefab 資產。
- 新增測試：攻擊類特效對應的 prefab 從登錄表找路徑、直接讀 prefab 檢查，粒子若是拉伸模式，長度倍率與速度倍率不可同時為 0，且要有貼圖。

## 如何驗證
1. 型別檢查 0 錯；全套單元測試通過。
2. 更新 tests/AttackVfxMapping.test.ts、tests/EffectSystemAttach.test.ts。
3. 以攔截方式把線上版主程式換成等效修正後實打：斬擊節點出現、截圖看得到攻擊處光效，回合正常、勝利。
4. 未做：弓兵飛箭在正式線上版尚未驗到；斬擊外觀與亮度未經人眼驗收；音效無法由程式試聽。

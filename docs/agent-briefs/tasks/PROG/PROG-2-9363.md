## 開單原因
特效表有 3 個奧義效果（張飛、關羽、呂布）與 skills.json 的 3 個步驟引用了登錄表裡不存在的特效代號，播放時只記一行警告就略過。查證後確認這些定義戰場目前沒有使用（戰場走 battle_ 開頭那組，全部有 prefab），所以不是線上看得到的缺陷，但資料是錯的，日後接上就會少一層演出。

## 完整描述
- vfx-effects.json：trail_bigsword 改 trail_bigsword1、trail_slash 改 trail_slash_w、energy_blast_ring 改 energy_blast。
- skills.json：3 處 trails（那是分類名不是特效）改 trail_slash_w。
- 新增測試：特效表與技能序列的每個特效代號都要在登錄表裡；戰場流程實際會播的效果只能用有 prefab 的特效。
- 沒有處理：12 個舊效果定義（hit_enemy、skill_ 開頭等）用的是只有貼圖、沒有 prefab 的特效，物件池不會預熱，就算接上也播不出來；這批目前沒有呼叫端，留待決定要補 prefab 還是刪除。

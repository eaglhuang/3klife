## 開單原因
使用者裁決：主將放技能時光效要出現在施放的主將身上，原本打在棋盤中央那版直接換掉、不留開關。

## 完整描述
- UnitRenderer 新增 getGeneralSidelineWorldPosition，回傳該陣營主將站位（中路、己方底線外）的世界座標。
- BattleFlowVfx 新增 playBattleGeneralSkillEffect：有站位就播在主將身上，拿不到站位才退回棋盤中央。
- BattleUIBridge 的主將技能演出改呼叫新函式；勝敗結算的全場光效不動。

## 如何驗證
1. 型別檢查 0 錯；全套單元測試通過；新增 tests/BattleGeneralSkillFxAnchor.test.ts。
2. 線上版注入同一邏輯實打：奧義、戰法各一次，位置皆為我方主將站位，0 報錯，截圖可見。敵方主將放技能這一場沒有發生，未拍到。

## 開單原因
使用者回報戰場上兩位主將都面向錯誤方向。查證：開場朝向正確，第 3 回合單挑結束、主將走回場邊時朝向跟著行進方向翻面，到位後沒有翻回，之後整場都背對戰場。

## 完整描述
- UnitPresentationCore：退場移動開始時記下當時朝向，走到定位後恢復；退場途中仍面向行進方向。
- 一般移動（非退場）到位後維持行進方向，行為不變。
- 補單元測試：我方與敵方退場到位後都要面向戰場；整場單挑演完勝者面向戰場。

## 如何驗證
1. 型別檢查 0 錯；全套單元測試通過。
2. 線上版攔截套用修正後實打：單挑前後各回合截圖，兩位主將都面向戰場；修正前同一時點兩位都背對。

## 開單原因
本機打開奧義選擇彈窗：標題「選擇奧義」是黑字壓在深色底上看不見，技能列畫在標題上方。原因一：建畫面時沒載入色票，金色 token 解析不到退成透明黑。原因二：調整高度時只縮了外框，裡面的捲動區仍是 280 高，內容被推到標題上方。

## 完整描述
- UltimateSelectPopup._build：載入色票並傳給 buildScreen。
- UltimateSelectPopup._resizePopup：捲動區與可視框高度跟著清單高度縮，並重設位置。

## 如何驗證
1. 全套單元測試維持通過；本機預覽量測節點座標與顏色。

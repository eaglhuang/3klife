# [PROG-2-9397] 回合順序改為先部署後行動、部署用完自動結束回合、擊殺不進格、多格移動從原格滑行

## 開單原因
使用者 2026-11-17 定案回合順序「先部署、後行動」、部署到行動力 0 自動結束回合、擊殺後下一次行動才踏格，並回報小兵移動不從原格出發。

## 完整描述
- BattleController／BattleRuntimeContract：敵方先部署再行動。
- BattleAutoMovePhase／BattleCombatPhase：剛部署的部隊當回合行動；擊殺不進格。
- TurnFlowManager／BattlePresentationTiming：部署用完自動結束回合。
- UnitRenderer／BattlePresentationTiming.planMoveSegment：同回合多格移動合併成一段滑行。
- 規格 doc_spec_0376 §2 回合順序段落與階段表。

## 如何驗證
1. 全套單元測試與型別檢查。
2. 本機預覽實點連跑 3 回合以上，取樣節點座標確認移動起點。

## 開單原因
使用者授權：spine-trial main 每有新騎兵動畫就由戰場專家接進遊戲試看效果。spine-trial PR #7（Mount v2）與 #8（騎乘動作 v3）已合併，產出騎手與馬的合成骨架。

## 完整描述
- 騎兵（cavalry）改用 soldier_cavalry_blue__mount_horse_sheet 合成骨架：待機 idle、前進 trot（地速與位移相符，不打滑）、攻擊 thrust、受擊 hit。
- 合成骨架的騎手圖集與馬圖集合成一份多頁圖集，放在私有素材夾 assets/resources/spine/soldiers/（不進公開倉庫）；素材不在時退回槍兵外觀。
- 落腳揚塵與蹄聲依各兵種步態週期同拍。
- 敵方紅色版騎兵尚無素材，暫時沿用紅色槍兵。

## 如何驗證
1. 全套單元測試、冒煙測試與型別檢查。
2. 本機預覽截待機、移動、攻擊畫面，對照步兵比例、蹄聲是否同拍、圖集大小。

## 開單原因
總PM 排定的戰場手感順序：移動 → 部署落地 → 放招 → buff 格統一。現況部署只把 3D 節點從地下 0.45 往上縮放 0.22 秒，Spine 小隊直接從地下冒出、沒有落地感，也沒有塵與聲。

## 完整描述
- 部署時 Spine 小隊從上方落下（重力加速），落地瞬間壓扁再回彈；隊員依序落下（錯開約 0.07 秒），不像整隊同時複製出現。
- 落地時腳下往兩側揚起土黃塵粒（量比走路大，騎兵更多；河流格與水軍不出塵），帶頭者出一聲落地聲（騎兵兩聲）。
- 只改表現，不動部署規則、數值與回合流程；素材未載入完成時延到載入後才開始落地，避免看不到。

## 如何驗證
1. 全套單元測試、冒煙測試與型別檢查。
2. 本機預覽用 qaSlow 定格截部署過程連續幀（下落、落地壓縮、揚塵），步兵與騎兵各一。

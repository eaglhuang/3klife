## 開單原因
總PM 排定的戰場手感順序：移動 → 部署落地 → 放招 → buff 格統一。11/18 使用者裁決：放招蓄力停頓 0.4 秒；招式名改在畫面中央橫幅（不是頭頂小字），約 0.8～1 秒，連續放招排隊或合併，不擋命中特效，避開右側戰報面板。現況出招當下直接播特效，沒有蓄力也沒有中央招式名。

## 完整描述
- 武將出招（戰法、奧義）前先蓄力 0.4 秒：施放方武將有蓄力表現，之後才播招式特效與命中，傷害跳字跟著特效時間走，不提早出現。
- 畫面中央顯示招式名橫幅約 0.8～1 秒；連續放招時排隊或合併，不擋命中特效，避開右側戰報面板。奧義已有漫畫分鏡，橫幅不與分鏡重疊。
- 只改表現，不動技能規則與數值；回合推進會等演出結束，不因延遲卡住流程。

## 如何驗證
1. 全套單元測試、冒煙測試與型別檢查。
2. 本機預覽用 qaSlow 定格截放招過程：蓄力、招式名橫幅、命中與跳字的先後。

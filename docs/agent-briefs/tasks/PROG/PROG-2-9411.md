## 開單原因
總PM 排定的戰場手感順序最後一張：移動 → 部署落地 → 放招 → buff 格統一。使用者 11/17 指示上 buff、戰場上的 buff 格的特效音效要優先補到滿意。現況棋盤 buff 格只有一行浮動文字（綠「攻擊 x 3」、紅「★ 攻擊 / 5」），格子本身沒有標記，與頭頂狀態圖示（PROG-2-9399 圓底＋一字）是兩套視覺語言；吃到減益格時戰報仍寫「吃到增益」、播增益音效。

## 完整描述
- 棋盤 buff 格改用與頭頂狀態圖示同一套圖示：圓底「攻」或「命」，增益金邊、減益紅紫邊，旁邊配「×N」或「÷N」；稀有格加金色外圈。
- 格子地面加淡色光板（增益金、減益紫），一眼看出是哪一格；全部重用節點，不每回合 new。
- 吃到時圖示從格子飛向單位頭頂再由頭頂圖示列彈出；戰報與音效分增益、減益兩種。
- 只改表現，不動 buff 格的生成規則與數值。

## 如何驗證
1. 全套單元測試、冒煙測試與型別檢查。
2. 本機預覽實跑截圖：增益格、減益格、稀有格的外觀，與吃到時的飛入與戰報文字。

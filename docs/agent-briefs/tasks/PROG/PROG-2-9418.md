## 開單原因
基礎戰鬥手感打磨（總PM B(2)）逐格連拍長板坡 3 回合時發現：戰場提示條（800×112 不透明褐底）落在畫面中央偏下（距頂約 625px），交戰期間正好蓋住第 3～5 路的部隊與命中演出。原因是 toast-message-main 的 widget top:120 是以部署面板內 400×60 的小容器計算，不是以整個畫面計算。規格（地形適性飄字反饋與戰況台詞管線規格書 §66）寫的是「畫面中央偏上方浮現透明黑底金邊對話條」。

## 完整描述
- 部署面板的 Toast 容器往上移，使提示條中心落在距頂約 330px（中央偏上），避開中央交戰區與回合橫幅。
- toast.bg 由不透明 #403C30 改為半透明黑底 + 金色細邊 + 小圓角，符合規格。
- 只改 deploy-panel-main 與 toast-message-default 兩個 JSON，不動提示內容、時序、規則與數值。

## 如何驗證
1. 線上版／本機各打 3 回合連拍，修改前後對照：提示條位置與交戰區是否重疊。
2. 手機 720 縮放截圖確認可讀。
3. validate-ui-specs、全套單元測試、型別檢查、compute-gate。

## 開單原因
使用者 11/20 看瓦口隘結算截圖回饋：『這字也太小，也沒有 UI 套用排版設計』。現況結算視窗把勝負說明、時限戰果、兵力、各兵種、戰績、獎勵、戰利品等十多行全塞進同一個 420 高的標籤，靠自動縮字擠進去，字只剩約 12px，也沒有分區。總PM 另要求結算頁『時限到、我方勝』文案補四語系。

## 完整描述
- 卡片加寬為 1120×880；頭像旁放大字標題與勝負說明（32px），不再縮字。
- 明細改成可捲動區：新增純函式 ResultDetailSections 依行首把明細分成戰況、兵力、獎勵、戰後紀事四區；每行依『：』拆成粗體金色欄名＋內容，『｜』改成間隔號，字級 26px、交錯底色。
- appendDetails（覺醒、擒獲等非同步行）照樣追加並重排；掛載失敗的保底結果卡不變。
- 區段標題與時限到勝敗文案補 zh-TW／zh-CN／en／ja 四語系。

## 如何驗證
1. 單元測試：分區規則、欄名拆分、空行略過、多語系鍵四檔齊全。
2. 7456 實機：瓦口隘時限勝利、一般勝利、失敗各截圖，字級可讀、明細多時可捲動；六關回歸。

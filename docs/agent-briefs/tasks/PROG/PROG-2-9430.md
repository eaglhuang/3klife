## 開單原因
PROG-2-9429 實跑發現：新版戰場 HUD（HTML 轉出的 battle-hud-screen）沒有城寨血條節點，守城戰的主要威脅（工兵投石扣城寨）玩家只能從戰報文字看到。使用者 11/06 裁決「城寨要血條」；總PM 11/21 核准 A：守城戰顯示我方城寨血條。
總PM 稽核另指出：年終守城的完整規則只寫在任務卡 9425、9426、9429，沒有正式規格書，要在本卡補上並登錄 doc-id 與索引。

## 完整描述
- 守城戰（玩家是守方）在頂欄正下方置中顯示「我方城寨 N／500」血條；一般關卡不顯示。
- 血條跟著 FortressDamaged 事件更新；掉血時輕震一下；剩三成以下改警示紅。
- 新版 HUD 版面沒有血條節點，執行期建立（不改 HTML 轉出的版面 JSON）。
- 開戰與「再戰一次」兩個入口都依守方開啟。
- 年終守城正式規格書：三檔敵軍、工兵投石、主將駐守、補派、折損扣兵源、失守懲罰、「守城 → 年報 → 換年」順序；標明共用框架（獎懲走獎勵系統、兵源與物品走物品庫存，總綱 doc_spec_1182）。

## 如何驗證
1. 單元測試：血條文字取整與夾限、兩個入口接線。
2. 7456 實機截圖：守城戰開場滿條、被投石後數字減少、低血量警示紅；一般關卡沒有這條。
3. 規格書登錄 doc-id、索引，encoding 檢查通過。

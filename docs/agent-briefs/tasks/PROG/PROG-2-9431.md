## 開單原因
總PM 11/21 審核年終守城戰規格書（doc_spec_1236）§11 待決項，裁決如下：
- (b) 失守民心 −3、大敗人口 −3%、城寨 500：照現值放進 JSON。
- (c) 順序定為「守城 → 年報 → 換年」，年報要反映守城結果。
- (e) 補派工兵上限：戰場專家依模擬自訂，寫進 JSON 與規格。
- (a) 大敗定義、(d) 失守懲罰結構、(f) 平手：屬戰場核心規則，規格先寫建議版並標「待決」，由總PM 轉使用者裁決。

## 完整描述
1. data/defense-battle.json 新增：失守民心變動、大敗人口損失比例、我方城寨上限、補派工兵總量上限。程式改讀這些欄位，壞值退回預設。
2. 守城戰開場依設定的城寨上限設定我方城寨；守城血條用這個上限顯示。
3. 敵方補派工兵：每回合補派之外，再加整場總量上限，達上限後不再補派。
4. 年報新增「守城結果」一行：守住、失守或大敗，以及民心與人口的變動。
5. 規格書更新 §11：已裁決的項目改成定案；(a)(d)(f) 寫建議版並標「待決」。

## 如何驗證
1. 單元測試：設定解析、補派上限、失守懲罰讀設定、年報守城行。
2. 用真實 BattleController 模擬三檔 × 每回合清 0／1／2 隊工兵，選定上限並記錄結果。
3. 7456 實跑守城：城寨上限、補派到上限後停止。

## 開單原因
總PM 11/21 審核：新版 HUD 只有我方 6px 黃色精力條，開場刷新一次，沒有三段色、百分比和敵方條；規格 doc_spec_0397 §3 門檻 60／20% 與武將壽命系統（doc_spec_0018）50／10% 矛盾，裁定採 50／10%。

## 完整描述
1. 精力條約 4px，掛在雙方武將頭上名牌血量列正下方（新版 HUD 頂欄沒有主將血條）。
2. 依 50／10% 門檻三段變色（紫／琥珀／灰），百分比由名牌旁能量環顯示；歸零時底板變灰。
3. 奧義扣精力、戰法回復、沙漠扣精力時發出 GeneralVitalityChanged 事件，HUD 即時刷新。
4. 扣減演出：填色閃白、淡色殘影延遲追上、條身脈動、跳出「-N」字；回復時填色長回並跳「+N」。
5. 規格 doc_spec_0397 §3 門檻改為 50／10% 並註明出處；新增 §4 記錄 HUD 雙方精力條。

## 驗收
- 單元測試：三段門檻、百分比文字、變化跳字文字。
- 7456 實跑截圖：三段顏色各一張、放奧義前後對照一張。

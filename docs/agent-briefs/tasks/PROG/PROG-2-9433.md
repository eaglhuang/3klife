# [PROG-2-9433] 手機結算彈窗字級：小螢幕最小可讀字級

## 開單原因
總PM 11/21 指派：手機橫屏 812×375 檢查結算彈窗字級。設計解析度 1920×1080 依高度縮放約 0.347 倍，明細 26px 只剩約 9 CSS px、區段標題 28px 約 9.7、勝負說明 32px 約 11.1，低於手機可讀下限。

## 完整描述
1. 新增 `shared/ReadableFontSize.ts`（純邏輯）：畫面縮放比例取寬高較小者；縮放後低於 12 CSS px 時放大設計字級，行高等比。
2. 新增 `ui/core/ReadableText.ts`：讀 Cocos view 取目前縮放，供任何 UI 共用。
3. 結算彈窗明細列、區段標題、欄名寬度與頭像旁勝負說明套用；桌機縮放夠大時原字級不變（照網頁原稿）。

## 驗收
- 單元測試：縮放比例、手機放大到 ≥12 CSS px、桌機不變、行高等比、無效輸入。
- 7456 手機 812×375 前後截圖；桌機 1920×1080 字級維持 32／28／26。

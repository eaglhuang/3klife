## 開單原因
總PM 11/21 審核 9432 截圖（full-ult-mid.png）：敵方部隊集中在上方時，呂布名牌（94% 環、+20%、將 1692、精力條）與部隊資訊框（40 騎 100／騎兵、盾兵、35 步 120／步兵）互相重疊，「盾兵」與數字壓在精力條上。裁定以名牌為優先。

## 完整描述
1. 名牌層級：每幀確認武將名牌排在最上層部隊框之上；之後加入的傷害跳字等特效仍在名牌之上。
2. 避讓：部隊框與名牌外框（含左側能量環）重疊時，往上或往下推到名牌外並留 4px 間距，取位移較短方向；兩塊名牌夾住時跳到整群外側。
3. 位移每幀平滑逼近目標，部隊走動時資訊框不瞬間跳動；部隊框位置每幀由投影重設，位移不累積。
4. 純邏輯在 `battle/shared/GeneralPlateAvoidance.ts`，`UnitRenderer.avoidGeneralPlates` 套用。

## 驗收
- 單元測試：不重疊不動、上下推開、推開後無重疊、兩塊名牌、平滑逼近。
- 7456 同一場景前後截圖。

## 開單原因
總PM 11/21 指示實跑一場逐格看六項手感並修最差前三名。稽核結果：
1. 放招最差：暫代分鏡幾乎靜音；奧義打出的暈眩飄字比分鏡早到，被分鏡蓋住，分鏡收掉時字已淡完，敵兵看不出反應。
2. 跳字次差：狀態字 30px 細字、約 0.7 秒消失、全部無聲。
3. buff：增益減益同一聲、不分極性。

## 完整描述
1. `battle/shared/StatusApplyFeedback.ts`：狀態極性（控制／減益／增益）、控制與減益讓目標縮一下、依離施放方遠近錯開的震波延遲（每格 0.05 秒、上限 0.35 秒）、同聲 120ms 節流。
2. `BattleUIBridge._onBuffApplied` 改排進戰鬥動畫佇列（在奧義分鏡之後），依極性播 buffGained／debuffGained、縮一下、飄字。
3. `FloatTextStyle.status`：42px 粗體、1.5 秒、彈出放大，仍比一般傷害小一級。
4. 暫代分鏡第一格帶 whoosh／roar；`resolveCutinSfxClip` 把缺檔音效對到既有 clip（whoosh→wave、hit→hurt、hit_heavy→boom、roar→thunder），正式音檔進來後刪該列。

## 驗收
- 單元測試：極性、縮一下、震波方向與上限、節流、替代表、暫代分鏡有音效、status 樣式；StatusEffectFloat 改為等佇列。
- 7456 張飛「當陽怒吼」前後連拍並排（artifacts/playtest-checklist/prog-2-9435/）。

## 開單原因
總PM 11/21 手感審核缺音效清單：`BATTLE_AUDIO_CUE.shieldBlock` 有定義但從未播放。實測再發現：
1. 護盾把傷害整個吃掉時，畫面照樣飄「-N」紅字，玩家以為扣血。
2. 無敵（白馬銀槍·不滅）與單挑敗逃免戰時，結算直接略過、不發任何事件，攻擊方揮空沒聲沒字。

## 完整描述
1. `battle/shared/BlockFeedback.ts`：`shieldHitFeedback` 算實扣生命與是否格擋；擋下飄字表（格擋／無敵／免戰）。
2. `BattleCombatResolver`：`UnitDamaged` 加 `shieldAbsorbed`；無敵、敗逃免戰改發 `UnitDamageBlocked`（自己人的效果與 0 傷害不發）。結算數值不變。
3. `BattleUIBridge`：受傷命中當下，護盾有吸收就播盾擊聲、飄「格擋」，跳字只顯示實扣生命；`UnitDamageBlocked` 時攻擊方照樣出手，命中那一刻播盾擊聲、飄「無敵／免戰」，戰報記一行。

## 驗收
- 單元測試：吸收計算、結算事件帶吸收量、無敵改發擋下事件、畫面飄「無敵」。
- 7456 連拍：騎兵護盾全吸收只飄「格擋」、盾兵部分吸收飄「格擋」＋實扣、步兵無敵飄「無敵」。

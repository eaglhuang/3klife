# [PROG-2-9438] 基礎戰鬥手感：放招蓄力與出手音效

## 開單原因
總PM 11/21 手感審核缺音效清單：戰法放招（PROG-2-9410）有 0.4 秒蓄力與中央招式名橫幅，但蓄力全程無聲，出手那一刻只靠特效本身的長音（部分特效沒有聲音）。

## 完整描述
1. `BattleAudio`：新增 `skillCharge`（→ `skill1`）、`skillRelease`（→ `skill7`）兩個音效鍵與 `SKILL_CAST_SFX` 音量（0.7／0.85）。兩個檔原本都沒被戰場使用；依音量包絡挑選：`skill1` 由弱漸強、約 0.4 秒到頂，`skill7` 開頭最響。未實機聽過，不合適只改對照表。
2. `BattleUIBridge._castGeneralSkill`：蓄力開始播蓄力聲、蓄力結束播出手重音，再接原本的特效與命中。奧義走立繪分鏡，不經過這裡，不受影響。

## 驗收
- 單元測試：兩個音效鍵對到不同實體檔；放招時蓄力聲先播、出手重音等蓄力結束才播。
- 7456 實放「百騎劫營」：音效紀錄 skill1@0ms、skill7@425ms、特效 skill0@428ms（3.2 秒漸強長音，與開頭重擊互補）。

## 未解決
- 騎兵衝鋒蹄聲：音效包沒有馬蹄類素材（目前騎兵攻擊借用 footstep），需要來源授權清楚的新素材，待使用者或美術提供。

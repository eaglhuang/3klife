## 開單原因
11/21 手感全場複審：敵方騎、盾、步三隊集中時，頭頂資訊框疊成一團，「8 (-32) 騎 68」壓在別人身上，玩家看不出誰被打。總PM 改判為可讀性問題，由戰場專家接手。

## 完整描述
1. `GeneralPlateAvoidance.stackBadgeOffsets`：依優先序逐一擺放部隊框；先擺的留原位（只避開名牌），後擺的把名牌與已擺好的框都當障礙物，取最小垂直位移。同優先序依 id 排，每幀結果穩定。
2. `UnitRenderer`：每幀沿用 9434 的平滑逼近套用位移；受擊（`playHitAnimation`）時記下戰場時鐘，1.5 秒內該框優先留原位，並排到部隊框最上層（名牌與傷害跳字仍在其上）。不新建節點。

## 驗收
- 單元測試：不重疊不動、重疊時讓開、受擊優先、名牌仍是障礙物、三框全部分開、結果穩定。
- 7456 同流程（部署三路、結束回合兩次）第二回合前後對照：之前盾兵／步兵框互疊；之後各框分開可讀。

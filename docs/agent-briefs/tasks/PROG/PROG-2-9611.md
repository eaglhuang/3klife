## 任務背景與實測調查真相
在實測與程式碼追查中確認：
1. 任務大廳底層變數欄位原先命名為 `silver`，但底層綁定之 `_missionWallet` 實體呼叫的是 `gacha.getCurrencyAmount('gold')`，實質上讀取與扣發的是「黃金（幕府公庫）」，而非「銀兩（家族儲備）」。
2. UI 界面顯示直接寫為「黃金」，造成欄位命名（silver）與實際貨幣（gold）嚴重脫節，且家族真正之銀兩（silver）完全未接入任務大廳。
3. 依據 11/21 第 28 條裁決，必須將口徑徹底統一與分離：金歸國家、銀兩歸家族。

## 核心實作目標
1. **口徑規則統一（第 28 條裁決）**：
   - 幕府公務類任務（軍務、政務、外交）→ 獎勵「金」，入幕府公庫。
   - 新增商業、民生類任務 → 獎勵「銀兩」，入家族錢包。
   - 欄位名、入帳目標、顯示文字、結算飄字四處必須一致。統一稱「銀兩」，不寫「白銀」。
2. **第一年商業任務保底產出**：
   - 第一年每季任務池保底 1～2 個商業或民生任務（如市集巡察、特產運銷、平抑物價），成功後發放 30～80 銀兩。
   - 數值配置放入 JSON 資料檔，不寫死於邏輯程式碼中。
   - 派遣執行 OCC（人員占用）檢查（哺乳期、教官、出征中武將不得接任務）。
3. **年終典禮規格兩點 PM 修正順帶落地**：
   - Rookie 新人王 `enabled: true`，Mentor 名師移至第二階段 `enabled: false`。
   - Q2 跳過機制改回已定案 A，§8.1 只保留 Q1 與 Q3 待使用者裁決。
4. **多語系支援**：
   - 四語系（en/ja/zh-CN/zh-TW）完整支援任務與銀兩結算文字。

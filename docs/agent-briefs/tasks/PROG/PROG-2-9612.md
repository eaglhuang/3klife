## 開單原因
依據總 PM Claude 2026-11-22 08:30 核准之提案與 5 點調整需求，落實世界觀無主角年齡之首次結緣導流與年度春季說親引導。

## 完整描述
1. **世界觀硬規則適應**：
   - 主角不死不老無年齡欄位，移除任何及冠年齡判斷。
   - 首次觸發改為：開場教學（首戰教學、首子、貂蟬開場事件）結束後的第一次換季，排入一次性【紅娘叩門】（`promptType: 'first-visit'`），寫入存檔旗標 `save.flags['matchmakerFirstVisitDone'] = true`，讀檔不重複。
2. **每年常規導流**：
   - 春季（第 1 季）換季時，若主角配偶數未達幕府等級上限且本年媒人剩餘次數 `remaining > 0`，排入常規導流（`promptType: 'spring-visit'`），侍從頭頂出現「媒人求見」氣泡。
3. **大廳進場隊列通用化**：
   - 將原單純官職晉升之大廳導流抽象為通用 `LobbyGuideQueue`。
   - 進場彈窗嚴格順序：年終盛典 ➔ 官職晉升詔書 ➔ 紅娘叩門／媒人說親。
   - 內政侍從同人頭頂標記「！」與專屬氣泡。
4. **說親次數與種子決定論**：
   - 關閉對話框或點擊「稍後再議」不扣除次數，僅納入配偶時才扣除說親次數。
   - 候選人名單以年/季為種子決定論生成，同季重開名單完全一致，防止刷人。
5. **銀兩不足導流**：
   - 納入配偶需禮金 100 銀兩。
   - 若家族銀兩不足 100，按鈕反灰提示「家族銀兩不足，媒婆說她不賒帳」，點擊導流跳轉至任務大廳商業任務。

## 如何驗證
1. 全套單元測試覆蓋率：
   - 開場後首次換季觸發 `first-visit`，存檔旗標生效，再次讀檔換季不重複。
   - 春季換季觸發 `spring-visit`，配偶達上限或無次數時不觸發。
   - 候選人名冊種子決定論驗證。
   - 點擊稍後不扣次數，成功納入扣 100 銀兩並計入配偶名冊。
   - 銀兩不足 100 時無法納入並提示。
2. 靜態編譯 `npx tsc --noEmit` 0 錯。
3. `npm test` 通過。
4. `node tools_node/compute-gate.js --profile standard` 通過。

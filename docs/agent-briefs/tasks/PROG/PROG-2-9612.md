# [PROG-2-9612] 無頭試玩 lobby-commerce-silver 偶發失敗修正（報酬列受情報分層遮蔽）

## 根因
1. 商業任務初始情報 45±10（35～55），落在 vague 分層（30～59），報酬列只顯示「量級：★」；情報 ≥ 60 才顯示「銀兩 N～M」。不是時機問題，也不是遊戲 bug（情報遮蔽為既有設計）。
2. 順帶發現：結算時升官，官職晉升彈窗（RankUnlockPopupHost）會蓋住季報，輪詢彈窗的 helper 被擋住就直接丟錯。
3. 結算骰運：失敗不發銀兩，成功率越高越不易落空；回報給總 PM 觀察（顯示成功率 85～100% 仍見失敗）。

## 改法（只動 tools_node/playtest-online.js）
- 第 07 步：輪詢等報酬列（15 秒逾時），再用「再探」把情報推到上限 90（最多 3 次），報酬列須出現「銀兩 數字」，驗證強度不變。
- runSeasonPopups：季報被擋住時先試按官職晉升彈窗的「知道了」。

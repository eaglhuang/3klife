## 開單原因
總PM 11/21 指示在 current master 重拍框體重疊；仍疊就照 9440 避讓做法修。另要求跳字「-21」排在部隊框之上，「敵軍行動中」橫幅期間框可降透明度或橫幅避開框，細節自決。

## 重拍結論
- 以 9440 自己的矩形計算，17 框重疊 0 組（框本體已分開）。
- 肉眼仍疊的部分來自兩處不在避讓矩形內的東西：血條頂（本地 y≈51，矩形只到 39）與狀態圖示列「士／命」（本地頂 103、從 x=-90 起排），會壓到上方或左側的框。
- 跳字節點從池中回收時保留舊的兄弟索引，之後才建立的部隊框排在它後面，會把跳字蓋掉。
- 「敵軍行動中」橫幅（top 252、560×52）正好落在棋盤遠排，敵方部隊框都在那。

## 修改
1. `GeneralPlateAvoidance.ts`：新增 `LocalExtent`、`unionExtent`、`badgeRectFromExtent`（矩形中心依範圍中點位移）。
2. `UnitStatusIconBar.ts`：新增 `localExtent()` 回報圖示列在框座標下的範圍（含溢出字數估寬）。
3. `UnitRenderer.ts`：避讓矩形改為「框本體 ∪ 血條 ∪ 狀態圖示列」的本地範圍。
4. `FloatTextSystem.ts`：跳字掛到 uiRoot 後 `setSiblingIndex(最後)`，永遠畫在框之上。
5. `enemy-thinking-main.json`：橫幅改到頂部 HUD 深色帶、標題右側（top 24、hCenter 330），完全離開棋盤；不需改框透明度。

## 驗收
- `tests/BadgeStacking.test.ts` 新增 3 項：僅框本體時等同 9440 舊矩形；聯集血條與圖示後矩形向上長；下方框的圖示列侵入上方框時會被推開。
- 單元測試 8920 全過、`tsc -p tsconfig.test.json` 0 錯。
- 7456 實測：18 框以新範圍計算重疊 0 組；對 7 支部隊同時打出 -21，跳字節點索引 35–40 高於框最大 32，截圖可見 -21 壓在部隊框上；敵方回合連拍 6 張，橫幅位於頂部 HUD 帶，未遮任何部隊框。

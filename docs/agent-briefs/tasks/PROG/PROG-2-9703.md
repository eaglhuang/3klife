## 開單原因
總PM 回報年度試玩（PR #2449）非守城戰全在第 1 回合、0 擊殺 0 傷害結算為「失敗：敵方突破防線」。查證為試玩腳本每秒按 BtnAuto，自動鈕是極速決戰（瞬間依戰力模擬勝負）。`_onAutoBattleToggled` 發 BattleEnded 不帶 cause，結算窗落到預設文案「敵方突破防線」，城寨與主將其實都還在，真玩家也會誤以為壞掉。

## 修改
1. `BattleVictoryResolver.ts`：`BattleEndCause` 加 `'auto'`。
2. `BattleUIBridge.ts`：自動鈕發 BattleEnded 帶 `cause: 'auto'`。
3. `ResultPopupComposite.ts`：`RESULT_CAUSE_DESCRIPTION.auto` 勝／敗／平三種極速決戰文案。
4. `tests/BattleVictory.test.ts`：auto 文案與 cause 接線測試。

## 不在本卡
- 極速決戰只計已上場部隊、第 1 回合按自動幾乎必敗：規則選項已送總PM 裁決，另開卡。
- 試玩腳本不應按自動鈕：回報總PM（腳本屬 PR #2449）。

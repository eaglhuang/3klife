## 開單原因
使用者要求小兵與武將頭頂 HUD、左側虎符兵種卡、軍師面板、上方標題列，統一成格子 buff 徽章的質感（深色底、金圈、黑描邊字）。使用者裁定「先用你設計的試試看第一版本，後續還是要繼續優化下一版本」。

## 修改
1. `UnitRenderer.ts`：頭頂徽章底板改深色半透明＋圓角金圈＋內側淡金線；兵種段加深色圓盤金圈；名字與數字 Label 加黑描邊（寬 3）；血條與活力環加金框。顏色沿用 TileBuffMarkers 的金色系。
2. `tiger-tally-default.json`：虎符卡全部文字加黑描邊，名稱攻命白字、糧草淡金、星級金色。
3. `strategist-hud-battle.json`：軍師框改深底圓角金框，文字白字黑描邊。
4. `battle-hud-screen.skin.json`：回合、標題字黑描邊；頂欄加金色底線。

## 驗收
- 主目錄暫時套用後以 `capture-ui-screens.js --target BattleScene` 截圖，四處都呈現新風格；驗完以 tar 備份還原主目錄。
- 單元測試全過、`tsc -p tsconfig.test.json` 0 錯、compute-gate quick 4/4。

## 下一版待辦
- 頭頂框彼此重疊（同格多單位）要錯開或縮小。
- 兵種圓盤在戰場尺寸下辨識度偏低。
- 虎符卡外框仍是舊 sprite，可換成同系列金框。

# [PROG-2-9708] 格子 buff 標記畫到小兵身上（渲染層次倒置）

## 開單原因
使用者截圖回報：格子上的 buff 標記（圓圖示＋×N）畫在小兵身上，層次應該倒過來。

## 根因
- 格子標記與單位同在 `UnitOverlayRoot`，建立時 `setSiblingIndex(0)` 壓最底。
- 但 Spine 小兵建立時也 `setSiblingIndex(0)`，且 `SpineUnitOverlay.update` 每幀依前後把小兵排成 index 0..n，標記與落地揚塵因此被擠到小兵上方。

## 修改
1. `TileBuffMarkers.ts`：標記改放進地面層容器 `TileBuffGround`（座標系同根節點），提供 `groundNode()`。
2. `MoveDustEmitter.ts`：提供 `groundNode()`（揚塵容器）。
3. `SpineGeneralOverlay.ts`：排序改從小兵目前最低索引起排；新增 `setGroundNodes()`，每幀排序後把地面層依序送回 index 0、1（已在定位就不動，平常不重排）。
4. `UnitRenderer.ts`：onLoad 指定地面層為「格子標記在最底、揚塵在其上」。

## 驗收
- `tests/SpineUnitPool.test.ts` 新增：後部署的小兵插到 index 0 後，排序完標記仍在最底、揚塵其上、前後順序正確。
- 主目錄暫套用以無頭 Edge 實跑出兵交戰，截圖確認小兵與頭頂框都蓋在格子標記上方；驗完 tar 還原。

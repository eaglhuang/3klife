## 開單原因
使用者 2026-11-22 裁決：極速決戰（瞬間結算、不載入棋盤）目前必輸——戰力只算已上場部隊，戰場內按自動再按一次（9707 跳過）時我方尚未部署任何部隊；且沒有可用條件與次數限制。要修成可用、有節制的功能。

## 完整描述
1. `AutoResolve.sidePower` 計入預備兵力（`AutoResolveSide.reserveTroops` × `reservePowerPerTroop`）；新增 `finalizeQuickResolve`，首戰保證勝改判時戰報終局行換成援軍，不再同時寫「我軍不支」。
2. 新增 `core/systems/QuickResolveGate.ts`：關卡條件（`allowQuickResolve`：always／after-clear／never；守城與單挑永遠不可用）、每日免費次數與軍令狀、換日高水位、存檔正規化。
3. 資料：`data/quick-resolve-config.json`（每日 3 次、耗 1 張、預備兵力係數、敵方預備兵力暫定值）、`encounters.json` 加 `allowQuickResolve`、`item-config.json` 與 `ItemDef` 加軍令狀 `ITEM_QUICK_RESOLVE_WRIT`。
4. `GameSession`：`checkQuickResolve`／`spendQuickResolveUse`（軍令狀走 item.consume API）、`wonStageIds`、Boss 關勝利紀錄與存檔欄位 `quickResolve`（含 sync06 白名單）。
5. 呼叫端：`BattleUIBridge`（再按自動先過條件、不可用提示原因並維持自動代打、結算前計次、帶我方預備兵力）、`QuickSortieController`＋`LobbyScene`（按鈕灰掉顯示原因與今日次數、結算前計次、帶預備兵力）、`BattleScene` 設定 `encounterStage`。
6. 規格 doc_spec_1170 §二／§三-5／TC-AUTOBATTLE-04～06；測試 `tests/QuickResolveGate.test.ts`。

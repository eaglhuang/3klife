## 開單原因
使用者回報「玩起來很卡」。總PM 轉交 PROG-2-9800 效能量測（playtest-online.js --perf --gpu、tools_node/perf-probe.js）：非戰場部分已修完（全流程卡頓總時長 50.8 秒降到 24.3 秒），戰場內熱點由戰場專家處理。

## 完整描述
1. 戰鬥步驟 script 約 22 秒，BattleScene tick 連同引擎 inclusive 約 9 秒（40～45%）：量 tick 內各段（AI、移動、碰撞、HUD 更新）並修最大熱點。
2. 戰鬥中 Label 縮放 measureText 約 0.7～2 秒：不需要 SHRINK 的 Label 改 NONE／CLAMP；字串沒變不重設。
3. texSubImage2D 約 1.4～1.6 秒：檢查 CHAR 圖集或動態圖集是否反覆重建。
4. draw call 約 245～275、Mask 6、Graphics 8 打斷合批：減少不必要的 Mask／Graphics。
5. 戰鬥結束後 heap 仍有 171～222MB：確認離場時單位、特效節點與貼圖都有釋放。

## 如何驗證
1. 用同一套量測工具（playtest-online.js --perf --gpu）跑修改前後，附前後數據對照。
2. 戰場玩家視角截圖無視覺退化。
3. 單元測試、tsc（tsconfig.test.json）0 錯、compute-gate quick 全過。

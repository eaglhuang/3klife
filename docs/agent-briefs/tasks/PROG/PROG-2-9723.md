## 開單原因
總PM 11/22 裁決：(1) 敵方 AI 奧義精力門檻由絕對值改比例（精力 ÷ 最大精力），男將上限 120、女將 100，用比例才公平；(2) 委任代打（玩家方自動代打）主將 SP 滿時也要自動放奧義，套用與敵方同一套門檻與家族審批。

## 完整描述
- `AiUltimateDecision.ts`：中 IQ 精力門檻 `vitality > maxVitality × mediumVitalityRatio`（預設 50%）；高 IQ 落後門檻 `vitality > maxVitality × highLosingVitalityRatio`（預設 30%）。比例由 `parseAiUltimateRules` 讀入，不寫死。
- `assets/resources/data/ai-difficulty.json` 新增頂層 `ultimateRules`；`AiDifficultyTable.ts` 解析後掛到每列 `ultimateRules`；`BattleState.aiUltimateRules` 由 `configureAiDifficulty` 寫入。
- `BattleController.ts`：抽出 `shouldFactionCastUltimate(faction, general, iq, rules, ultimateId)`，敵方 `chooseEnemyUltimate` 與委任代打共用。
- 委任代打 `runDelegateSkillPhase`：SP 滿後先過 `shouldFactionCastUltimate`（IQ 由 `delegateAiIqOf(delegateQuality)` 對應：EXPERT→EXTREME、HIGH、MEDIUM、LOW），符合才放；未設難度表時不放。
- `DelegateAi.ts` 新增 `delegateAiIqOf`（PM 暫定映射）。
- 規格：`戰場AI奧義施放門檻與效果家族決策規格書.md`（doc_spec_0391）§1／§2 改比例並註明委任適用；`AI家族奧義釋放決策…規格書.md` §2 加歷史資料引言。

## 如何驗證
1. `tests/AiUltimateDecision.test.ts`：中 IQ 50% 邊界（男 60/120、女 50/100 皆不放，61/120、51/100 放）；高 IQ 落後 30% 邊界（男 36/120 不放、37/120 放）；比例改 JSON 即生效；`parseAiUltimateRules` 驗證。
2. `tests/AiDelegateUltimateFlow.test.ts`：委任 HIGH 落後且精力 > 30% 時 SP 滿放一次；未落後擊殺不足不放；精力 30% 邊界不放；MEDIUM 50%/51% 邊界；無難度表不放。
3. `tests/AiEnemyUltimateFlow.test.ts` 等既有敵方奧義流程測試維持通過。
4. run-cli 全過；`npx tsc -p tsconfig.test.json --noEmit` 0 錯；compute-gate standard 通過。

## 建議作法
- 比例化只動判斷式與 JSON，不改 IQ 分支結構。
- 委任放奧義抽共用 helper，不複製敵方判斷。
- 委任 IQ 映射暫定，見待裁決。

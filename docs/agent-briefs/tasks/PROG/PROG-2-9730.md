# [PROG-2-9730] 無頭試玩第 07 步 lobby-commerce-silver 仍偶發失敗（點擊瞬間被官職晉升彈窗蓋住）

## 根因
最新 master（PROG-2-9612 之後）本機約三成失敗，且連帶 08～11 失敗（console error 0）。不是遊戲退步（2507～2515 戰場 PR 與大廳無關），是 playtest helper 的競態：`runSeasonPopups` 先 `locate` 季報關閉鈕為可點，接著截圖與抓文字（數百毫秒），結算升官時官職晉升彈窗（RankUnlockPopupHost，全螢幕 BlockInputEvents）剛好在這段空檔蓋上來，後面的 `rm.click` 重新命中檢查被擋住就直接丟錯；步驟失敗後季報與季事件彈窗殘留，08～11 全被 SeasonEventHost 擋住。9612 只處理了「locate 階段就被擋住」的路徑，沒涵蓋這條點擊瞬間的路徑。

## 改法（只動 tools_node/playtest-online.js）
- `runSeasonPopups`：點擊時丟出「真滑鼠點不到」視為被擋住（不計處理過、不丟錯），交給下一輪的 rank-unlock 規格按「知道了」。

## 另記
- 另有一次「第一年內政牆沒有商業任務」（約 1/12），本機未能重現；已確認資料與 refillBoards 保底邏輯在單元測試的第 1～4 季皆成立，列觀察。

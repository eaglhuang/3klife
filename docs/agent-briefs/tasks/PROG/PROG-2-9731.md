## 開單原因

## 完整描述
1. 名牌戰鬥淡出：攻擊、受擊、閃避、擋下的演出期間名牌淡到 12%，結束後停留 0.35 秒再 0.3 秒淡回；治療演出不淡（血條在名牌上）。
2. 狀態圖示角標：燃燒層數 ×N（≥2 才顯示）與剩餘回合數；燃燒飄字第 2 層起附 ×N。
3. 奧義暫代：補上施放音效（原本靜音），中央加大字技能名，PLACEHOLDER 小字保留。
4. 毒箭上身：目標閃紫綠光暈＋「中毒」紫綠飄字；火焰字屬 B1，未動。
5. 治療三步：治療光 → 綠字與治療聲（+0.22 秒）→ 血條升（+0.5 秒）；期間任何刷新都顯示治療前血量。
所有秒數、顏色、大小在 assets/resources/data/battle-ui-feedback.json。光暈用 Graphics 節點池，無新貼圖。

## 開單原因
攻擊特效盤點（inventory-weapon-vfx-1124）發現：主將施法普攻仍播刀聲；暴擊只靠大字跳字，玩家不易感受；attack-vfx.json 的 sword／bow 武將模板從未有武將映射，實際不會播放。

## 完整描述
1. 主將普攻音效依武器分開（刀、槍、劍、弓、法術）。現有音檔對應：刀=weapon、槍=bite、弓=feijian、法術=skill2；劍暫借 weapon。劍揮音、法術專屬音檔待補。
2. 暴擊命中：critBurst 參數變體（金色、較大星形閃光），命中時加 critHitStopSec（0.04 秒）微頓幀，不新增大型資源。
3. 武將劍／弓映射：新增 `shared/GeneralWeapon.ts`，依兵種適性推算（弓兵適性最高且不低於 A → 弓；步兵適性最高 → 劍；支援型 → 法術；其餘 → 刀）。不新增 generals.json weapon 欄位，等總PM 定表。
4. 不改戰場核心規則，只動表現層與音效選擇。

## 如何驗證
1. `npx tsc -p tsconfig.test.json --noEmit` 錯誤數 0
2. 單元測試（tests/run-cli.ts）：GeneralWeaponVfx、GeneralAttackSfx 通過
3. compute-gate quick
4. 實跑建置＋playtest-online 全過
5. 暴擊探針截圖：暴擊與普通命中可區分，出現次數記錄於報告

# [PROG-2-9803] 首戰自動戰 QA 計數修正與教學戰參數調校（60–90 秒目標）

## 開單原因
- 線上實玩首戰（encounter-001 虎牢關，張飛 vs 呂布）自動戰耗 151 秒、endTurnFallbacks 37 次、結果失敗。
- 診斷（side-session-notes/first-battle-autobattle-diagnosis-1123.md）：37 次是 QA 腳本計數問題，推進演出中的結束回合點擊被遊戲靜默吃掉仍被計數；151 秒主因是每回合約 19 秒的推進演出。
- 總PM 已核准：(a) 修 QA 計數並加每段演出實測秒數；(b) 只動教學戰數值（Constants.ts／encounter-001）讓新手能贏，目標 60–90 秒。

## 範圍
- tools_node/playtest-online.js：endTurnFallbacks 計數條件、每回合各段演出秒數記錄。
- assets/scripts/core/config/Constants.ts：教學戰專用參數（tutorial*）。
- assets/resources/data/encounters.json：encounter-001 的敵初始配置。
- assets/resources/data/ai-general-templates.json：AI_LVBU Custom_Difficulty_Mod 標註或移除。
- 不縮短推進演出（BattlePresentationTiming 不動）；不動五路對撞與其他核心規則；不動 PROG-2-0124。

## 驗收
- endTurnFallbacks 只在推進演出結束、且確實可操作卻無進展時計數。
- 報告輸出每回合各段演出實測秒數。
- 首戰自動戰實測 60–90 秒內分勝負且勝利（未達標則如實回報最佳值）。
- 改前改後數值與理由寫入 notes。
- tsc -p tsconfig.test.json 0 錯；tests/run-cli.ts 全過；compute-gate quick 通過。

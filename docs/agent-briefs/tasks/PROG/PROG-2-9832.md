## 開單原因
使用者要求「幕府大廳」的 UI 風格與「大廳・內政」面板統一。參考風格：深色半透明玻璃面板、細金色描邊、標題米白宋體＋金色副標、分節標題小字距、卡片淡框深底、次要按鈕淡金框、主要按鈕深紅底。

## 來源與範圍
- 風格來源：`assets/resources/ui-spec/skins/domestic-screen.skin.json`（大廳・內政 layout：`layouts/domestic-main.json`，由 `LobbyScene` 以 `domestic-screen` 組裝）。
- 第二階段升級為通用 UI 主題系統：`ui-spec/themes/theme-registry.json`（default＋春夏秋冬＋節慶範例，只寫差異）、`UIThemeResolver.ts`／`ThemeService.ts`；hall-style-tokens 已併入 default 主題並刪除。規格見共用框架總綱規格書第 14 章（shard-f）。
- 套用函式：`assets/scripts/ui/core/ThemeSkinRestyle.ts`（純 TS，不依賴 cc）；`UISpecLoader.loadSkin` 在 skin 合併後呼叫，只對 `styleBinding.appliesToSkins` 內的 skin 生效。
- 本卡套用範圍：幕府大廳主畫面 `lobby-hall-screen.skin`。
- 不在本卡範圍（第二階段清單）：`hall-board-screen`（任務板）、`governor-hall-screen`（太守府）、`recruit-hall-screen`（招賢）、大廳子面板（wall-left／wall-right、altar、clan）。

## 不做的事
- 不改功能、不改文字內容、不改節點 id 與尺寸。
- 不新增大貼圖；sprite-frame 與陰影原樣保留。

## 驗證方式
1. `npx tsc -p tsconfig.test.json --noEmit` 0 錯。
2. `tests/HallStyleTokens.test.ts`：token 與內政 skin 數值一致；slot id 集合不變；字級行高保留；sprite-frame 不變；金框面板變深色玻璃；主按鈕深紅、次要按鈕淡金框。
3. 玩家視角實機截圖（待使用者開編輯器驗收，不由本卡自行開第二編輯器）。

## 已知限制
- 分類依 slot 的 kind 與欄位判斷，未逐節點對照角色；分節標題的小字距與上方細金線需要節點角色資訊，留第二階段。

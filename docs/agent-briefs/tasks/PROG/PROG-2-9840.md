# [PROG-2-9840] 寬螢幕兩側灰邊：皮膚整面背景層跟著父容器伸縮、清除色改深色

## 開單原因
網頁試玩版視窗比 16:9 寬時，標題畫面左右兩側露出淺灰色。根因：皮膚背景層（skinLayers）寫死設計稿尺寸 1920x1080 且沒掛伸縮 Widget，父容器被拉寬後背景層不跟著變寬，露出相機清除色（#333）。

## 完整描述
1. UIPreviewBuilder 皮膚層：尺寸與父容器同一軸等大、另一軸不超出的整面背景層，改掛四邊 0 的伸縮 Widget。
2. host 尺寸在建置後改變時（啟用或視窗改變），lateUpdate 由上往下重算一次 Widget 對齊。
3. 全螢幕背景圖（ScreenBackdrop）以可視區 cover，視窗改變時重算。
4. 四個場景主相機清除色由 #333 改為 #0B0906。

## 如何驗證
tsc 測試型別 0 錯、單元測試全過、compute-gate standard、無頭瀏覽器 2200x950／1024x768 標題與大廳截圖、playtest-online 12/12。

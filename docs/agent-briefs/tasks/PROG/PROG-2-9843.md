## 開單原因
使用者回饋：戰法詳情子視窗（技分頁）只有數值，缺少一段招式演出文字，吸引力不足。

## 完整描述
- 戰法資料 tactic-library 新增 descKey 欄位，文字放四語系 i18n 字典（非 zh-TW 先放複本並標記待翻）。
- SkillDetailView 在名稱下方顯示描述；缺 descKey 或字典缺字時不顯示。
- 文案以 Sonnet 試寫前 10 招（2～3 句、40～70 字、不寫數值），依 token 花費估算全部戰法與奧義總價。

## 如何驗證
1. 有 descKey 的戰法在四語系字典都查得到文字
2. SkillDetailView 單元測試（tests/SkillDetailView.test.ts、tests/TacticFlavorData.test.ts）通過
3. tsc -p tsconfig.test.json 0 錯
4. tests/run-cli.ts 全過
5. compute-gate standard 無阻擋

## 建議作法
- 欄位 descKey（例如 tactic.desc.<id>）在 tactic-library 資料；CharacterDs3TacticsChild 以 t(descKey) 取字，查無則不顯示。
- 文字風格：輕鬆現代口語、可小幽默、不悲劇、不寫數值。

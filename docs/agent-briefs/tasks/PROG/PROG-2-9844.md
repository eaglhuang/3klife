## 開單原因
使用者裁定：UI 有武將名稱的地方，旁邊顯示縮小的武將頭像，更有味道。

## 完整描述
- 頭像來源只用已入遊戲的正式頭像（`sprites/generals/avatars/*_avatar`，經 GeneralArtPaths.avatarCandidates）；不搬美術庫新檔。
- 共用元件 `GeneralNameTag`（ui/components）＋純模型 `GeneralNameTagModel`（ui/core）。頭像缺檔時畫名字首字圓章。
- 路徑與首字、樣式解析做成純函式，可單元測試。
- 顏色走主題 token（`nameTag.*`，登錄於 theme-registry default），缺 token 才用墊底色；不新增寫死文字。
- 節點重用，只建一次標籤節點；舊的非同步載入結果以序號丟棄。
- 第一個套用位置：幕府大廳內政任務列的「主事」（DomesticPanelController.nameTags → LobbyScene._refreshDomestic）。
- 其餘名單位置（招賢館列表等）列為後續卡，本卡不套。

## 如何驗證
1. tests/GeneralNameTagModel.test.ts 通過（首字、頭像候選、token 退回、主事 id 帶出）。
2. `npx tsc -p tsconfig.test.json --noEmit` 0 錯。
3. run-cli 全套 ALL PASS。
4. 未實機截圖；主事標籤位置需在 Cocos 預覽確認（本卡未開編輯器）。

# [PROG-2-9846] 幕府大廳風格統一第二階段：任務牆／太守府／招賢館套用主題＋分節標題小字距與金線

## 開單原因
PROG-2-9832 第一階段只讓幕府大廳主畫面套用統一風格；本卡把同一套主題 token 套到子畫面 `hall-board-screen`、`governor-hall-screen`、`recruit-hall-screen`，並補上分節標題小字距與上方細金線。

## 作法
- `theme-registry.json` 的 `styleBinding.appliesToSkins` 加入三個 skin（資料設定，程式不判斷 skin 名稱）。
- `styleBinding` 新增 `slotRoles`（slot id 後綴 → 風格角色：`.card.bg`／`.row.bg` 玻璃面板、`.label.section` 分節標題、`.divider.section` 細金線）與 `skipSlots`（`pg.*` 共用肖像牆不套）。
- 分節標題字距、顏色、金線色來自主題 token（`text.section`、`text.section.letterSpacing`、`divider.*`），季節／節慶主題疊加後自動跟著換。
- 任務牆「武將點位」、太守府三張資源卡標題改用 `*.label.section` slot，上方新增 `*.divider.section` 金線節點。
- 靜態文字補 `textKey`，四語系字典補 `ui.hall.board.*`、`ui.governor.title`、`ui.recruit.*`。

## 不做的事
- 不改功能與節點 id；不新增貼圖；控制器以 texts 覆寫的動態文字維持原狀。

## 驗證方式
1. `npx tsc -p tsconfig.test.json --noEmit` 0 錯。
2. `tests/ThemeSystem.test.ts` 新增 6 項（清單、玻璃面板、分節標題＋金線、pg.* 略過、季節換色、layout textKey 與四語系）。
3. 玩家視角實機截圖由使用者驗收。

# [PROG-2-9854] 修正幕府大廳任務牆／太守府套用主題後跑版

## 根因
PROG-2-9846 把 `hall-board-screen.skin`、`governor-hall-screen.skin` 加入 `appliesToSkins` 後：
- `hall.button.bg`／`hall.spot.bg` 的填色是 `primary`，命中 `fillRoles` 變成實心深紅（分頁鈕、詳情、接取、點位卡全紅）。
- `hall.card.bg`／`hall.row.bg` 被套成 `glassPanel`（alpha 118，為大廳主畫面疊在地圖上設計），子畫面面板半透明，後方牆面文字穿透。

## 作法
- 新增角色 `glassPanelSolid`（不透明深色玻璃）、`insetPanel`（內嵌淡色列／卡）；token `panel.solid.alpha`、`panel.inset.*`。
- `slotRoles`：`.panel.solid`、`.row.bg`、`.spot.bg`、`.button.bg`（次要鈕）；接取與升級鈕改用 `*.button.primary.bg`，仍走 `fillRoles` 深紅。
- 主題 token 決定外觀，季節／節慶可換，不寫 skin 名。

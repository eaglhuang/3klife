## 開單原因
戰場「感受盤點」殘餘兩項：①燃燒／中毒／火格的回合扣血 tick 只有跳字（PROG-2-9855 已分色），命中音卻和一般攻擊受擊同一顆 `hurt`，玩家分不出是被打還是被燒、毒；②毒箭命中回饋（PROG-2-9731）已有上身綠光、「中毒」字與 debuff 音，需確認是否仍有缺口。

## 完整描述
- DOT tick 專屬輕音：`damageSource` 為 `burn`／`hazard-fire` 用 `fireball`（燃燒）、`poison`／`mass-debuff-dot` 用 `hurt` 輕量版（中毒）；音量偏小，不新增音檔。
- 同一單位在同一回合內只響一次（`DotTickSfxThrottle`，依事件到達時刻判定）。
- DOT tick 不再走一般受擊音與分層受擊 clip，受擊動作與跳字維持原樣。
- 毒箭命中：程式讀確認已有 debuff 音（`debuffGained`→`teleport`，暫代）、閃避式受擊與上身回饋，本卡不改；缺口記入備註。

## 開單原因
使用者裁決：城市黃金產出＝本季商業內政任務產出，沒選商業任務時為 0。玩家看到黃金 0 不知道原因，需要新手引導提示「選商業任務才有黃金收入」。

## 完整描述
- 太守府黃金產出卡：黃金基礎值為 0（有經濟資料、本季沒選商業）時，多顯示一行提示（現代口語、輕鬆口吻）。基礎值大於 0 時該行隱藏。
- 提示文字走 i18n（`ui.governor.goldHint`，zh-TW／zh-CN／en），控制器未注入 t 時退回 zh-TW 預設字串。
- 只加提示，不改任何數值規則（CityEconomy、DomesticTasks 不動）。
- 內政任務牆商業列已有「黃金 +N」產出文字（DomesticPresenter 的 outputText），不另加小標，避免重複。

## 如何驗證
1. `npx tsc -p tsconfig.test.json --noEmit` 錯誤數 0。
2. `tests/run-cli.ts` 全部 PASS，GovernorHallController 測試覆蓋：基礎值 0 顯示提示、基礎值大於 0 隱藏、未注入 t 時用預設文字。
3. `node tools_node/compute-gate.js --profile standard --agent-feedback` 0 阻擋。

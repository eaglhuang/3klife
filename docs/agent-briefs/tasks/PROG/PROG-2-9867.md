## 開單原因
使用者裁決：友誼值範圍為 −100～+100（與私塾規格一致，負值為敵意區間）。現行 `FriendshipService` 下限為 0，段 0（≤ −30）台詞不可達。

## 完整描述
- `FriendshipService._minCap` 由 0 改為 -100（上限維持 100）。
- 台詞 `parseChatBook` 接受 -100～100 的 `minFriendship` 負值（原本負值被當成 0）。
- 存檔欄位註解更新；舊存檔皆 ≥0，載入不變。
- 友誼行為權重表規格書第 3 節與第 7 節改為已裁決。

## 如何驗證
1. `npx tsc -p tsconfig.test.json --noEmit` 錯誤數 0。
2. `tests/run-cli.ts` 新增負值測試通過；既有失敗基準 75 不增加。
3. `node tools_node/compute-gate.js --profile standard --agent-feedback` 0 阻擋。

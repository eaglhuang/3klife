## 開單原因
新玩家開局用 10 張連線券抽教官池十連，抽完後大廳教官卡（支援卡）清單是空的，培育與學府選卡也選不到。

## 根因
教官池走獎勵框架（reward.roll）：抽到的學府支援卡（SUP_*）以 item.grant 寫進物品庫存（category=supportCard）。
但大廳的教官卡清單、培育選卡、學府選卡三處都只讀舊的 legacy 教官卡存檔（LegacyService.getMentorCards），
全專案沒有任何 UI 讀 item.list 的支援卡；轉蛋後的舊橋接（queueGachaMentorDraw）又以武將 id 對照舊目錄，SUP_* 卡號對不上，什麼都沒寫。

## 修法
- 新增 assets/scripts/core/systems/SupportCardMentorBridge.ts：庫存支援卡列轉教官卡視圖（傳承次數當突破星等），與舊存檔合併去重。庫存仍是唯一真相，不寫回存檔。
- LobbyScene._loadAllMentorCards()：培育、學府、教官卡清單三處共用。
- 回歸測試 tests/SupportCardMentorBridge.test.ts。

## 如何驗證
1. tests/run-cli.ts 全綠；npx tsc -p tsconfig.test.json --noEmit 0 錯。
2. 實機：新玩家開局十連教官池，大廳教官卡清單有卡，培育與學府選卡可帶入。

## 交付物

- assets/scripts/ui/scenes/LobbyScene.ts（三處載入改接）

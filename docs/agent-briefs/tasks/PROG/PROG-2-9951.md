# PROG-2-9951: O-02 開局名將三選一

## 任務目標
1. 開局讓新玩家從 **趙雲（`zhao-yun`）／關羽（`guan-yu`）／諸葛亮（`zhuge-liang`）** 三位名將中三選一。
2. 選中者加入玩家名冊，並設為開局核心主將（`leadGeneralId`）與首戰推薦主將。
3. 與首戰（`encounter-001`）戰前編成銜接（沿用 `PROG-2-9912 / PROG-2-9913` 的推薦預填機制）。
4. 嚴禁修改 `encounter-001` 戰場數值資料（由戰場專家調整）。

## 實作計畫
1. 新增/擴充開局名將三選一配置資料與純邏輯服務（`StarterHeroChoiceService` / `StarterRosterService`）。
2. 在 `LobbyScene` 開局流程中串接「開局名將三選一」選角面板（可重用三選一面板架構並支援 i18n）。
3. 確認選中武將自動入列、設為 `leadGeneralId` 並於首戰戰前編成預填為主將。
4. 補齊單元測試、`tsc` 與 `compute-gate` 驗證。

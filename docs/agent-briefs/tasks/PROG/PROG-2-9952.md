# [PROG-2-9952] 大廳選卡器（手動已選）缺關閉鈕與 Esc，出征編組收起時殘留

## 基本資訊
| 欄位 | 值 |

| 優先級 | P1 |
| 開單時間 | 2026-11-24 |

| 狀態 | done |

## 開單原因
實測「手動已選 4/4」卡組選擇器（lobby-deck-select-screen）沒有關閉鈕，Esc 也無效；出征編組（sortie-setup）收起時，`LobbyScene._closeSortieSetup()` 未一併收起 DeckSelect／LeadSelect host，造成子視窗殘留。

## 完整描述
- `lobby-deck-select-main.json` 新增 `btnDeckClose`（沿用同專案 sortie 關閉鈕的 button 樣式，文字「關閉」）。
- `DeckSelectController.mount` 綁定 `btnDeckClose`，點擊後隱藏 host。
- `LobbyScene._onEscapeKeyUp` 的彈窗清單納入 deck／lead host，Esc 一次關最上層。
- `LobbyScene._closeSortieSetup()` 一併收起 deck／lead host。

## 如何驗證
1. `npx tsc -p tsconfig.test.json --noEmit` 錯誤數為 0。
2. 單元測試 tests/run-cli.ts 通過（含 DeckSelectController 關閉鈕、layout 有 btnDeckClose、LobbyScene 來源含關閉邏輯）。
3. Web 版實跑截圖：選卡器可用關閉鈕關閉、Esc 可關閉、出征編組收起後 host 不殘留。

## 交付物
- layout、DeckSelectController、LobbyScene 修正與單元測試 PR。

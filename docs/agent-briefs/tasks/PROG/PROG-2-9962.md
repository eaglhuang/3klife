## 開單原因
PR #2593 已把招式名改走 i18n（battle.skill_name.<id>）。但 effectStatus（效果說明）與 categoryTag（類別標籤）仍是繁中字面值，英文與日文介面會出現「英文招式名加中文效果說明」的混合文字。總PM 已核准為範圍內獨立卡。

## 做法
- 招式表（assets/scripts/shared/BattleSkillPresentation.ts）改存類別代號（categoryId）與繁中原文類別（categoryZh）。
- 效果說明鍵：battle.skill_effect.<battleSkillId>（含【類別】前綴）；未知招式走 battle.skill_effect.fallback（{0} 類別、{1} 招式 id）。
- 類別標籤鍵：battle.skill_category.<categoryId>。
- 四語系 i18n（zh-TW／zh-CN／en／ja）補齊，zh-TW 文字與改前一致。
- TileSkillCategory 的對照改用 categoryZh（語系無關），避免英文介面歸類錯誤。

## 如何驗證
1. `npx tsc -p tsconfig.test.json --noEmit` 錯誤數為 0。
2. 單元測試 tests/run-cli.ts 全過（tests/BattleSkillNames.test.ts 新增鍵齊全、四語系解析、zh-TW 原文、無 translator 退回測試）。
3. compute-gate quick 通過。
4. 實跑建置與 tools_node/playtest-online.js；en／ja 探針截圖證明面板與橫幅不再中英混雜。

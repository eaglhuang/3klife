# [PROG-2-9989] 計謀放不出來：沒起風時按鈕看似可按、點了只跳「發動失敗」

## 開單原因
手打補驗（虎牢關首戰、張飛火計 tactic-fire-scheme）計謀鈕點 5 次全回 false，且沒有原因提示。

## 根因（實機重現）
1. 火計施放條件是「起風（WINDY）」，虎牢關天氣固定晴天，整場不可能達成。
2. 計謀鈕「待風」灰顯由 BattleUIBridge.refreshBattleViews 判定，但 BattleScene.refreshBattleViews（選目標流程與場景事件走這條）只看計謀點，把灰顯蓋回可按；玩家看到亮著的「計謀 35點」。
3. 點下去進 beginPlayerSkillFlow：火計是自動瞄準，不進選格；施放被條件擋下後只丟泛用的「戰法發動失敗」。
→ 不是探針問題，也不是「選目標格」流程沒走完；正常流程是點鈕後自動點燃敵軍所在格。

## 修正
- BattleUIBridge 抽出 refreshTacticSummary，BattleScene 刷新改呼叫它（Presenter 單一判定）。
- beginPlayerSkillFlow 在戰法條件沒達成時先 Toast 條件文字（i18n 四語 ui.battle.skill.condition_unmet），不施放。

## 驗收
- tests/TacticConditionUnmetToast.test.ts；tsc 0 錯；run-cli 全過；實機：晴天點鈕有原因提示，起風後點鈕火計施放並出現燃燒。

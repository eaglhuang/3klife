# [PROG-2-9995] 戰場單位倒下／被擊殺演出（漫畫式、無血腥）

## 目標
小兵與武將倒下時播漫畫式演出：飄白煙、小星星、衝擊線、短字樣；武將略強。只加表現層，不改戰鬥結算與五路對撞等核心規則。

## 既有狀態
`BattleUIBridge._onUnitDied` 已播 `battle_death_burst`（爆光）與 `battle_death_vanish`（白煙，p3d_cfxr_smoke_white），`UnitRenderer.playDeath` 做消融。沒有星星、衝擊線與字樣。

## 做法
1. `AttackVfxPlayer` 新增 `defeatBurst` 種類與 `playDefeat(x, y, strong)`：衝擊線（前 0.24 秒由中心炸開）＋四芒小星星往上飄散漸隱，純 Graphics、不加貼圖；參數放 `attack-vfx.json` 的 `defeatBurst.troop／general`。沿用原有特效數量與粒子預算上限。
2. `UnitRenderer.playDeath` 掛 `playDefeatComic`：呼叫上述星星與衝擊線、FloatText 新類型 `defeat`（節點走既有飄字池）；武將另補一團放大的白煙（`p3d_cfxr_smoke_white`，有 prefabPath）。
3. 文案 `battle.defeat.troop／battle.defeat.general` 補 zh-TW／zh-CN／en／ja。
4. `BattleFlowVfx` 新增 `DEFEAT_VFX`、`defeatVfxStats`（QA 探針讀 `__DEFEAT_VFX_STATS__`、`__ATK_VFX_STATS__`）。
5. 測試 `tests/DefeatVfx.test.ts`。

## 驗收
- tsc -p tsconfig.test.json 0 錯；tests/run-cli.ts 全過；compute-gate quick。
- 實機（工作樹 web build＋playtest-online＋探針）截圖看到小兵與武將倒下時的煙與星，並記錄出現次數。

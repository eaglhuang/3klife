# [PROG-2-9997] 戰場 vfx-block 必須有 prefabPath 防回歸

## 開單原因
靜態盤點：83 塊 vfx-block 只有 texPath 無 prefabPath，playBlock 回 null。skills.json 28 步用到 7 種（glow_soft、impact_shock、impact_ring、fire_burst、trail_slash_w、fire_ringwave、ring_addatk）。

## 追蹤結論
戰場內無人呼叫 ActionSystem.playSkill（BattleSceneLoader 只讀 label／costSp）；唯一呼叫處是武將詳情技能分頁預覽（非戰場、未預熱池）。戰場實際特效走 vfx-effects.json battle_*（playFullEffect）、TACTIC_GRID_VFX_BLOCKS、ATTACK_SLASH_EFFECT_ID，皆有 prefab。故不改資料，只加守門測試。

## 驗收
- tests/BattleVfxPrefabGuard.test.ts 通過；tsc 0 錯；run-cli 全過。

## 開單原因
重繪甘寧名將立繪，採趙雲、關羽、張飛原始正式圖的高完成度二次元幻想手繪；依既有記錄加強日曬深膚、窄長稜角臉、突出顴骨、深眼窩、銳利目光與成熟短鬚；維持吳紅基底，衣裝與飄帶收束，為甘寧打造錦帆銅鈴與水軍短刀的專屬識別物，更新正式立繪、頭像及 Cocos 資源。

## 完整描述
- 甘寧512x768正式立繪
- 甘寧兩種256x256正式頭像
- reviewed crop索引
- 甘寧配色與專屬錦帆武器紀錄
- 任務卡、manifest及Cocos驗證紀錄

## 如何驗證
1. 高完成度二次元幻想手繪，避免寫實3D
1. 臉部呈日曬深膚、窄長稜角臉、突出顴骨、深眼窩、成熟短鬚，與孫策、凌統、徐盛、周瑜明確不同
1. 吳國低飽和紅為基底，配炭黑、舊銅等個人副色
1. 錦帆銅鈴與水軍短刀組合是甘寧專屬代表物，Q版仍清晰且不與虎頭雙鉤等武器重複
1. 服裝收束無長飄帶；雙手、武器與鞋履完整
1. 正式立繪512x768透明，兩種256x256頭像，reviewed crop驗證通過
1. Cocos正式資產匯入有效，角色立繪與頭像採用標準資源路徑

## 建議作法
1. 備份既有立繪，生成全身透明候選並以125px、必要時250px檢視臉部、武器、手指與全身構圖。
2. 按新立繪更新reviewed crop，執行指定武將頭像生成與驗證。
3. 覆蓋正式立繪及兩種頭像，不更動既有 `.meta` UUID；同步到正式 Cocos 專案。
4. Refresh Assets 並重新匯入三項 PNG，確認標準武將路徑可載入及 Library 資產有效。
5. 更新角色配色／特徵台帳、任務 shard、manifest 與索引。
6. 通過裁切、資產匯入與計算閘門後，提交、推送並回報隊長。

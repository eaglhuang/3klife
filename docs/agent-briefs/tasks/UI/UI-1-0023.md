## 開單原因

## 如何驗證
1. 高完成度二次元幻想手繪，避免寫實3D
1. 青年窄橢圓臉、圓亮眼、細直眉、尖下巴、無鬚，與吳將其他四人明確區分
1. 灰朱紅為基底，石板灰和暖白為第二色，延續既定色票
1. 紅繩三節鎖棍為凌統專屬武器，三段棍身與短連節Q版仍易辨，且不與刀、槍、虎頭雙鉤重複
1. 衣帶收束，無長飄帶；手指、武器、雙靴完整
1. 正式立繪512x768透明，兩種256x256頭像，reviewed crop驗證通過
1. Cocos正式資產匯入有效並使用角色標準路徑

## 建議作法
1. 備份舊立繪，依名將二次元幻想手繪基準生成透明全身候選並檢視臉部與三節鎖棍輪廓。
2. 確認灰朱紅、石板灰、暖白與既定凌統五官特徵，更新 reviewed crop。
3. 生成兩種正式頭像並同步立繪、頭像與裁切資料至正式 Cocos 專案。
4. Refresh Assets、重新匯入三項資產並檢查標準立繪／頭像路徑。
5. 驗證裁切、Cocos import 狀態與計算閘門，更新角色台帳及任務索引。
6. 完成後提交、推送並回報隊長，再接續孫權／周瑜等未完成名單。

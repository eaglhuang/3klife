## 如何驗證
1. 新立繪為原創新構圖、無水印文字且符合參考圖的粉白羽飾、銀藍鱗甲、扇與歷史人物辨識
1. 大喬 full portrait 與 256x256 頭像正確匯入 assets/resources，Cocos metadata 可重建
1. 人物介紹頁展示大喬立繪及正確姓名、稱號、稀有度；趙雲原有呈現無退化
1. 轉蛋人物預覽可固定指定大喬與趙雲，實際網頁畫面均正確且不改抽取邏輯
1. 保存 GeneralDetail 與 GachaHero 對趙雲、大喬共四張實機截圖
1. 記錄 prompt、尺寸、裁切座標、資產匯入及預覽驗收步驟

## 建議作法
1. 對照正式大喬資料與 smoke state，產生原創、無水印的 2:3 直幅候選圖。
2. 以縮圖先行檢查角色構圖與參考風格，再收斂為正式立繪尺寸；記錄模型、prompt、尺寸與輸出色彩設定。
3. 使用 `general-avatar-crop` 設定與工具產生 256×256 頭像，確認頭冠、頭髮與肩頸完整置中。
4. 將立繪與頭像匯入正式資產路徑，依 Cocos Creator Preview 確認 metadata，並接上 GeneralDetail 與 GachaHero 固定角色變體。
5. 以 Browser Preview 分別擷取趙雲與大喬的人物介紹、轉蛋主頁畫面；逐張檢查圖文一致、裁切、清晰度與版面平衡。
6. 回寫美術設定與可重現的產圖、裁切、Refresh Assets、Preview 步驟。

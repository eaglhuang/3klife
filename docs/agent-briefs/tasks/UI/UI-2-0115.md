## 交付
1. `assets/resources/sprites/generals/<id 底線>_portrait.png`：512×768 透明背景全身立繪，風格與既有男將（張飛、呂布、司馬懿）一致；用 Codex 月額度生圖。魏延、夏侯惇優先（開局主將會出現在結算窗）。
2. `general-avatar-crops.json`：每位補裁切框與 `face`（top／chin／eyeY／cx，source: reviewed），依 general-avatar-crop SOP 產出 `avatars/<id>_avatar.png`。

## 配色索引
- 使用預設陣營色時，以低飽和勢力色作辨識錨點，再配第二色與中性色；不得整身單色或高飽和主導。
- 五虎將、諸葛亮、大喬、小喬沿用既有專屬色票，不套用一般預設。
- 此卡八人的 palette ID 與色票登錄於 [character-palette-ledger.md](../../../art/character-palette-ledger.md)。

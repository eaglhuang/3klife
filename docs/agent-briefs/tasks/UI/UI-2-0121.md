依使用者要求，依 generals-base 全名冊逐張稽核武將立繪的人臉五官、髮型綁法、髮飾、妝容、陣營主色與衣帶；缺少立繪者新增全身立繪，辨識度不足或不符合角色定位者完成修正。

## 完整描述
- 武將立繪差異度稽核紀錄；需要修正角色的正式立繪與頭像；更新色票索引與裁切資料；全體頭像驗證結果。
- 每位人物都要有專屬、可辨識的武器或代表物；樂器、文房四寶也可採用，Q 版縮小後仍須一眼可認，且不可與其他人物重複。
- 名將畫風對齊趙雲、關羽、張飛早期正式立繪的高完成度二次元幻想手繪；普通人物可延後，優先完成名將。

## 如何驗證
1. 盤點 generals-base 全名冊及現有立繪；逐張檢視臉型、眉眼、髮型／綁髮、髮飾、妝容、配色、衣帶與專屬武器／代表物；名冊中缺少立繪者新增全身立繪，辨識度不足者完成修正並更新頭像裁切。確認蜀國綠、吳國紅、魏國藍為預設主色錨點，名將特例沿用既定專屬色票；所有交付立繪維持512×768透明PNG，全體頭像驗證通過並留存視覺驗收紀錄。
2. 同系列全身立繪統一取景與頭身比例：顱頂至下巴（不含頭冠、羽飾等高聳裝飾）為一頭，人物有效高度目標7.5頭，容許7.2–7.8頭；逐張量測並排除超出區間者，125px並排檢視名將五官風格與臉部大小的一致性。

## 建議作法
- 先以 125px 縮圖檢查目標立繪；不足以判斷手勢時再逐級放大至 250px 或 500px。
- 修正時保留角色臉型、髮型、服裝配色及透明全身構圖，只調整有明確回饋的辨識元素；同步檢查頭像裁切座標。
- 每次交付前確認立繪為 512×768 透明 PNG，產生頭像並執行全名單驗證；可用的 Cocos Editor 專案切回本工作樹後刷新資產。

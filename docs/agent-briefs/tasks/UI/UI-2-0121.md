## 開單原因
依使用者要求，逐張稽核現有武將立繪的人臉五官、髮型綁法、髮飾、妝容、陣營主色與衣帶，找出仍相似或不符合武將定位者並修正。

## 完整描述

## 如何驗證
1. 盤點現有武將立繪清單及總數；逐張檢視臉型、眉眼、髮型／綁髮、髮飾、妝容、配色與衣帶；確認蜀國綠、吳國紅、魏國藍為預設主色錨點，特殊色票有明確角色理由；對辨識度不足者完成修正並更新頭像裁切；所有交付立繪維持512×768透明PNG；全體頭像驗證通過並留存視覺驗收紀錄。

## 建議作法
- 先以 125px 縮圖檢查目標立繪；不足以判斷手勢時再逐級放大至 250px 或 500px。
- 修正時保留角色臉型、髮型、服裝配色及透明全身構圖，只調整有明確回饋的辨識元素；同步檢查頭像裁切座標。
- 每次交付前確認立繪為 512×768 透明 PNG，產生頭像並執行全名單驗證；可用的 Cocos Editor 專案切回本工作樹後刷新資產。

# UI-2-0133 比對預覽 style 屬性雙引號跳脫

UI-2-0123 子項：dom-to-ui-compare 高擬真預覽把擷取到的樣式直接寫進 `style="…"`，
font-family 堆疊含雙引號（如 `"Songti TC"`）時屬性被截斷，之後的字型、`text-align` 等全部失效。
幕府大廳底欄按鈕、展開軍務牆等文字因此在預覽中靠左、字型掉回預設，拉低像素相似度。

處置：輸出 style 屬性前一律做屬性跳脫（img／svg／一般 div 三處），並在 dom-to-ui 自測加入回歸檢查。

notes: 狀態: 完成。驗證: dom-to-ui-self-test ALL PASS（新增 R-9b）；重跑幕府大廳轉換，預覽底欄按鈕與展開軍務牆文字恢復置中、字型與來源一致。待辦（續 UI-2-0123）: 背景與勢力圖待編輯器匯入後再驗。

# UI-2-0134 幕府大廳資產 meta

UI-2-0123 子項：四季背景、勢力圖預覽圖與 hall-map 資料夾（佈局、事件、十三州遮罩／地形／資料）在 master 上沒有 .meta，
執行期 resources.load 與 HTML→UCUF 的資產庫檢查都找不到，各機器開編輯器時也會各自產生不同 uuid。

處置：以 Cocos Creator 3.8.8 開工作樹由編輯器匯入，只提交上述 11 個 .meta（圖片為 texture 型，
ResourceManager.loadSpriteFrame 會以 Texture2D 回退建立 SpriteFrame）。編輯器同時替 master 上其他缺 meta 的檔案補產生的 meta 不屬本卡，未提交。

另修比對工具兩個讓本機圖片消失的通用缺口：
- image-waiver：擷取到的網址是 file:///…，被當相對路徑接在 repo 根目錄後，永遠判 asset-not-in-db，分數被假性豁免成 100%。改為解析 file: URL。
- snapshot-to-slots：只有單一 url() 圖層、沒有底色的背景不產任何 slot，預覽中圖片直接消失。改為仍產 multi-layer-rect。
dom-to-ui 自測新增 R-9c、R-9d。

notes: 狀態: 完成。驗證: dom-to-ui-self-test ALL PASS；重跑幕府大廳轉換，圖片豁免 2→0，背景與勢力圖出現於預覽，像素相似度 33.1%→86.4%。待辦（續 UI-2-0123）: Q 版圖與頭像仍為設計稿相對路徑；編輯器實跑比對；runtime 部署。

# UI-2-0144 幕府大廳主題解析

UI-2-0123 子項：HTML→UCUF 只轉出設計稿的預設狀態（春、白天），季節背景、夜色遮罩、夏日光束、勢力圖季節色調、粒子季節都要在 runtime 依狀態切換。
規格依據：大廳系統規格書 doc_spec_0002 E-6（白天與夜晚至少兩套光色與背景；節慶採背景／裝飾／前景粒子三層分離；不得為每個節慶硬寫分支，以主題配置驅動）。

交付：
- assets/resources/data/hall-map/hall-theme.json：季節對照、背景路徑樣板、夜間時段、夜色／季節色調／光束設定、節慶覆寫槽（平時空）。
- assets/scripts/core/systems/HallTheme.ts：純 TS resolveHallTheme(輸入, 設定) → 畫面要套的主題。
- tests/HallTheme.test.ts

notes: 完成。resolveHallTheme 依 GameClock 季節序號（1~4）與當地小時算出季節、晝夜（18~6 為夜，可跨午夜）、背景路徑、夜色遮罩、夏日光束（夜間關閉）、勢力圖季節色調、粒子季節與節慶裝飾槽；節慶只靠 festivals 設定覆寫，未知節慶 id 視為無節慶。測試 5/5、測試型別檢查 0 錯。尚未掛進 LobbyScene（等大廳入口位置決定）。

# UI-2-0154 幕府大廳許願祭壇面板顯示即時許願池

- ui/core/LobbyHallAltarView.buildLobbyHallAltarView：目前巡次、距下一巡剩餘時間、前 3 個許願插槽（品名×數量；可收取／剩餘時間／空位）。

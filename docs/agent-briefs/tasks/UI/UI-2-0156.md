# UI-2-0156 遊戲入口（標題畫面）設計稿

使用者 2026-11-04 指示：先把遊戲入口跟大廳 UI 做好，再做相關功能。
現況盤點（Cocos 預覽實跑）：LoginScene 為灰底佔位畫面，正中有一顆預設「button」節點，「開始遊戲」只有文字；開場四分鏡、信件、名將登場皆為黑框文字。
本卡先出入口第一站「標題畫面」的 HTML 設計稿，供使用者審稿後再走 HTML→UCUF 轉換與 LoginScene 接線。

## 交付

- `Design System/design_handoff/title-screen/index.html`（1920×1080）：
  - 視覺依新手開場規格書 (doc_spec_0031) §2.3 祖紋命篆：墨色底、緩轉篆字雙環、左右名將立繪（孫權、劉備）入墨淡出、餘燼。
  - 標題＋朱砂印章、英文副標、標語「血脈不滅　英靈長存」、金色「開始遊戲」主鈕、點擊任意處提示。
  - 左下公告／設定／帳號，右下版本與伺服器，右上年齡分級。
  - 互動節點帶 `title-screen.*` 綁定 id，供轉換器與 runtime 接線。
  - 遊戲名稱未定：`body[data-title]` 切換「三國傳承」（規格 §2.2）／「三國志・生存」（設計系統色票檔），`?title=survival` 或按 T 切換；切換鈕標 `data-draft-only`。

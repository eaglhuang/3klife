# UI-2-0164 字型檔名改為全域唯一

Cocos web 以「字型檔名_LABEL」當 font-family。notosans_tc、manrope、newsreader 三個資料夾的檔案都叫 font.ttf／font-bold.ttf，
瀏覽器只載入其中一套（實測為 newsreader），NotoSansTC 從未載入，中文字退回系統字或顯示空白。

## 交付

1. 三套字型改名為 fonts/<family>/<family>.ttf 與 <family>-bold.ttf，保留 .meta uuid。
2. 更新 ui-spec、design tokens、轉換器引擎設定、字型稽核、self-test、Design System 的路徑。
3. validate-ui-specs 加 font-basename-unique 檢查，防止再次撞名。
4. 無頭截圖確認 document.fonts 有各自的字型，人物頁換到趙雲時中文正常顯示。
5. 字元圖集預算：字距 CHAR 模式共用 1024x1024 圖集，滿了新字空白；改為短文字且預算內才用 CHAR。

## notes

- 變更：三套字型改唯一檔名並更新約 95 個引用；validate-ui-specs 加 font-basename-unique；新增 LabelCharAtlasBudget（超出預算改走 TTF，只少字距不缺字）；人物概覽標籤不走 CHAR。
- 驗證：無頭截圖 document.fonts 七套字型各自 loaded；趙雲、傳記全文、屬性頁與命頁固定文字正常顯示，分頁高亮隨切換移動。strict UI 驗證、self-test、型別檢查通過。

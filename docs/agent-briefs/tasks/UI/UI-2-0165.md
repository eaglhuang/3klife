# UI-2-0165 人物頁屬性分頁接真實武將資料

v3 轉換版的屬性分頁節點都是自動編號，舊子面板找不到名字而掛載失敗，畫面停在設計稿範例值，換將不變。

## 交付

1. 綁定表支援 whenText：只在畫面含指定文字時才套名，切分頁時清掉舊名，避免結構選擇器誤中其他分頁。
2. 屬性分頁節點改用固定名稱（Stats_*），重轉 v3。
3. CharacterDs3StatsChild 依固定名稱接資料：六圍、武力值條、生命狀態、雷達圖、評等、頁首評語、標籤。
4. 依揭露階段（HIDDEN／TENDENCY／RANGE／EXACT）決定顯示內容。
5. 教官群沒有武將資料可接，先隱藏。
6. Cocos 實跑截圖確認張飛與趙雲數值不同。

# UI-2-0170 人物頁兵分頁虎符槽接真實資料與裝備操作

規格 doc_ui_0012 §9 要求兵頁有虎符槽（裝備、替換、卸下、查看詳情）與摘要；目前虎符卡因只有設計稿範例被隱藏，執行期建的插卡按鈕沒有定位，玩家看不到也按不到。

## 交付

1. 虎符卡顯示目前武將的虎符：名稱、品質、星級、兵種、糧耗、投入兵力、虎符分；沒裝備時顯示空狀態。
2. 更換、卸下、查看詳情三個按鈕可用，走忠誠度與每季一次限制；受限時可二段確認沒收。
3. 裝備、卸下、忠誠下降顯示 doc_spec_0012 §G 的句子。

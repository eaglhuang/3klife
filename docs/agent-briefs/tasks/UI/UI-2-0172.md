## 如何驗證
1. GeneralArtPaths 提供 battle 預設路徑及 battleCandidates，並同時支援武將 id 與 portraitKey
1. 戰法特寫優先載入 battle 資源，缺少時回退 standing 資源
1. 單元測試涵蓋 battle 路徑解析與載入回退
1. TypeScript、相關單元測試及 compute-gate standard 通過

## 建議作法
- 把武將立繪與戰法特寫資源解析抽成 `BattleArtController`，讓元件只保留場景狀態與事件協調。
- `BattleArtController` 透過 `GeneralArtPaths` 取得 battle 候選，逐一載入；沒有戰鬥圖時回退 standing。
- 只保留必要的影像載入與呼叫接線，不搬入、不改名任何圖片。

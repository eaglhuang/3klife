## 開單原因
為袁尚補齊差異化全身立繪與頭像，以海松青、燒陶赭、骨白與夜鐵建立不同於袁譚鈷藍霜銀的色彩識別；採年輕寬橢圓臉、無鬚與低位扁平編髻。

## 如何驗證
1. 立繪為 512×768 RGBA 透明全身圖
1. 頭像為 256×256，採 reviewed 裁切且 generate-general-avatars verify 通過
1. 海松青 #3F6C66、燒陶赭 #A96A4D、骨白 #D4C7B1、夜鐵 #353A3D，與袁譚鈷藍霜銀及既有魏藍色票區隔
1. 年輕寬橢圓臉、較飽滿下顎、直眉、清潔無鬚，不複用袁譚長心形窄下頜、鷹鉤鼻與垂尾細鬚
1. 黑髮低位束成單一扁平橫向編髻，以海松青玉梳與短銅扣固定，不使用高折髻、三環後髻或羽冠
1. 肩甲、腰甲與衣襟固定收束，不加長飄帶與鬆垂衣帶，雙手自然且全身完整

## 建議作法
1. 生成透明背景候選稿，以寬橢圓青年臉、清潔無鬚、低位橫向編髻及海松青／燒陶赭建立辨識度。
2. 依縮圖優先流程檢查全身輪廓、雙手、靴子與透明邊界，再與袁譚縮圖比較臉型、髮式及色彩。
3. 等比例縮放置中留透明邊，輸出 512×768 正式立繪；設定 reviewed 裁切並輸出 256×256 頭像。
4. 更新色票台帳，執行頭像裁切驗證，刷新正確工作樹的 Cocos Asset DB。

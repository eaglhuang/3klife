## 開單原因
依名冊順序為中立勢力名士禰衡補齊正式立繪與列表頭像。以墨紫、紙白和少量青玉作士人專屬色盤。定位三十歲左右清瘦名士：窄菱形長臉、銳利細眼、高而直的鼻梁、微挑眉與克制的不屑神情，清剃無鬚；黑髮束成略鬆的單髻，以一支青玉短簪固定。著收束袖口的簡潔墨紫短外袍、紙白交領與少量青玉佩飾；手持短簡和一枚木質擊節板，姿態自然。可留一層短垂袖褶呈文士感，但不畫長披帛、複雜衣帶或武將甲胄。

## 如何驗證
1. 透明背景512×768 RGBA立繪
1. 正式與列表頭像均為256×256 RGBA
1. reviewed square crop 經125px檢視
1. 蜀綠為基底，臉部與髮型設計美麗且具辨識度
1. 與趙雲、關羽、張飛同級精緻二次元幻想手繪風

1. 單人avatar verify通過
1. GeneralList/GeneralDetail canonical 路徑正確

## 建議作法
1. 以125px與250px逐級檢視立繪及頭像，確認面容與髮型清楚。
2. 以general-avatar-crops.json記錄 reviewed face crop，重產兩路256px頭像。
3. 覆蓋正式資源，保留有效 Cocos metadata UUID，並刷新 AssetDB。
4. 執行單人 avatar verify 與 canonical path / Cocos import 狀態核對。
5. 回寫色票、任務狀態及驗證結果。

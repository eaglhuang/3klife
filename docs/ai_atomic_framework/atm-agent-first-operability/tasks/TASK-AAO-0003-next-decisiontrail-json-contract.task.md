# TASK-AAO-0003 — next decisionTrail JSON contract

## Goal

讓 next 輸出可機器讀取的 routing decisionTrail，而不是只給人看 summary。

## Why

如果 AI 看不懂 next 為什麼選這張卡，它就會自己猜流程。decisionTrail 要把選擇、拒絕、fallback 都說清楚。

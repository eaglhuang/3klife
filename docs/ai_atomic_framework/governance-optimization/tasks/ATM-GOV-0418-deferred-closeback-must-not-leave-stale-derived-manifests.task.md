# ATM-GOV-0418 Deferred closeback must not leave stale derived manifests

## Intent

Make a deferred taskflow close transaction distinguish foreign staged state
from derived manifests generated by the same close. A successful close must
not restore an older snapshot over a newer derived manifest, and an unsafe or
unproven case must fail closed with an executable recovery route. Foreign WIP
must remain byte-identical and outside the delivery bundle.

## Acceptance

- [ ] A deferred close with a derived manifest leaves no stale dirty manifest;
      if proof is unavailable, it emits a governed recovery command.
- [ ] Foreign staged and worktree files remain byte-identical and excluded.
- [ ] Red and green runs exercise the same public closeback seam and receipt
      lineage, with no direct index mutation in the test harness.

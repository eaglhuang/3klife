# 武將立繪配色索引

本表追蹤角色立繪的 palette ID、陣營辨識色與個人第二色。色票是生成與審稿的色彩目標；金屬、皮革、布料明暗可依材質變化，不要求整張圖只用列出的平面色。

## 通用原則

- 沒有既定角色特例時，以低飽和陣營色作辨識錨點：蜀綠、吳紅、魏藍；再配第二色與金屬、皮革或中性色。
- 勢力色不應高飽和主導全身，也不可把同陣營角色做成同一套換色造型；透過輪廓、姿勢、武器與局部配色保留個人辨識。
- 五虎將、諸葛亮、大喬、小喬已有專屬配色，沿用其既有設計，不套用本表的通用陣營配色。
- 服裝衣帶以功能與收束感為先：武將避免多層長飄帶與繁複飄逸衣帶；僅少數文人角色可保留簡潔飄帶，且不得影響角色輪廓辨識。
- 每位武將必須有專屬且易辨認的武器或代表道具；可用兵器、樂器、文房四寶或專業工具，但不可彼此沿用同一識別物，並須能簡化成Q版仍一眼可辨的外形。
- 女性成人角色的體態需表現S型曲線與飽滿胸線，以合身剪裁呈現商業化比例並配合角色氣質；維持成熟端莊，不畫幼態比例。
- 名將立繪以趙雲、關羽、張飛及使用者確認的參考圖為風格標準：臉部五官帶微動漫感，服裝與金屬材質採半寫實光影渲染，保留清晰遊戲插畫輪廓；不可把整體做成照片級真人，也不可把服裝做成平面卡通色塊。女性名將須美麗且彼此有別，透過臉型、五官、妝容、膚色、髮型與飾物建立辨識；一般角色可延後優化。

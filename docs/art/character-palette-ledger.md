# 武將立繪配色索引

本表追蹤角色立繪的 palette ID、陣營辨識色與個人第二色。色票是生成與審稿的色彩目標；金屬、皮革、布料明暗可依材質變化，不要求整張圖只用列出的平面色。

## 通用原則

- 沒有既定角色特例時，以低飽和陣營色作辨識錨點：蜀綠、吳紅、魏藍；再配第二色與金屬、皮革或中性色。
- 勢力色不應高飽和主導全身，也不可把同陣營角色做成同一套換色造型；透過輪廓、姿勢、武器與局部配色保留個人辨識。
- 五虎將、諸葛亮、大喬、小喬已有專屬配色，沿用其既有設計，不套用本表的通用陣營配色。
- 服裝衣帶以功能與收束感為先：武將避免多層長飄帶與繁複飄逸衣帶；僅少數文人角色可保留簡潔飄帶，且不得影響角色輪廓辨識。

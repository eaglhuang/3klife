# 戰場 Q 版騎兵／盾兵美術規格（給 Codex）

目的：戰場小兵目前只有槍兵與弓兵兩套外型，騎兵、盾兵等兵種暫用槍兵素材，玩家無法從外型分辨兵種。本文件列出補齊騎兵與盾兵所需的全部交付物。整合方式見 `docs/battle-chibi-integration.md`。

## 共同規格

| 項目 | 規定 | 來源／理由 |
|---|---|---|
| 檔案格式 | Spine 4.2 JSON＋`.atlas`＋PNG | 與現有 `soldier_spear_blue`（4.2.40）一致 |
| 骨架畫布 | 寬 320、高 640，原點在腳底中線（`x:-160, y:-10`） | 現有小兵骨架，換兵種不必重調腳底偏移 |
| 視角 | 3/4 側面、面向右；左右翻面由程式鏡像 | 戰場定案視角 |
| 圖集 | 單頁 512×512、`pma: false`、Linear 濾波 | 現有槍兵圖集；手機記憶體預算 |
| 戰場顯示高度 | 約 110～180 像素 | 這個尺寸看不到的細節（瞳孔、紋飾）不要畫 |
| 陣營配色 | 交付藍色版；紅色版由 `tools_node/battle-chibi/recolor_soldier.py` 換色產生 | 換色靠色相位移，主色請集中在同一色相、避免藍紅混搭 |
| 動畫方式 | 骨骼動畫，不用逐幀 | 記憶體 |
| 腳底 | 站立時雙腳腳底貼 y=0 地面線，全程不可陷地或浮空 | 程式以腳底對位 |
| 動作命名與長度 | 必須與下表完全相同 | 程式用名稱與秒數對拍；缺任一動作整隻會退回舊 3D 模型 |

### 必備動作（兩個兵種都要）

| 動作名 | 長度 | 循環 | 用途 | 要點 |
|---|---|---|---|---|
| `idle` | 1.6 秒 | 是 | 待機 | 呼吸起伏，首尾相接 |
| `walk` | 0.8 秒 | 是 | 行軍 | 一個完整步伐週期 |
| `dash_in` | 0.8 秒 | 是 | 戰場移動／衝鋒 | 程式會依實際位移調播放速度，地面步幅請均勻 |
| `retreat` | 0.8 秒 | 是 | 後撤 | 面向不變、向後退 |
| `duel_attack` | 見各兵種 | 否 | 攻擊 | 命中點要有頓格，結尾回到待機姿勢 |
| `hit` | 0.9 秒 | 否 | 受擊 | 後仰再回正 |
| `dodge` | 0.6 秒 | 否 | 閃避 | 側閃後回原位 |
| `fall` | 1.8 秒 | 否 | 陣亡 | 倒地後停在最後一格 |

審查順序由大到小：全程不斷肢 → 大動作輪廓 → 武器與手 → 細節。上一層沒過不看下一層。

## 盾兵 `soldier_shield_blue`

沿用現有小兵骨架（骨頭：`root, hip, torso, head, arm_f, arm_n, leg_n, leg_f, weapon, shield, shin_n, foot_n, shin_f, foot_f` 與鏡像用的 `m_*`），只換分件圖，不新增骨頭。現有骨架已含 `shield` 骨頭與 `attack_shield` 動作（0.9 秒）可當底稿。

| 分件 | 建議尺寸（像素） | 說明 |
|---|---|---|
| `head`／`helmet_back` | 153×161／142×163 | 可沿用槍兵，頭盔加護頰以示重裝 |
| `torso` | 132×155 | 重甲，肩甲加寬 |
| `arm_n`／`arm_f` | 57×108／50×106 | 前手握短兵、後手持盾 |
| `leg_n`／`leg_f` | 73×146／92×148 | 可沿用 |
| `shield` | 約 170×210（現為 130×148） | 大方盾或塔盾，遮住軀幹一半以上，這是辨識兵種的主要輪廓 |
| `weapon_sword` | 約 40×180 | 短刀或短矛，長度明顯短於槍兵的 62×333 |

- `duel_attack`：0.9 秒。盾先前頂（盾擊）、短兵從盾側刺出、收回。盾全程在身前。
- `idle`：盾立於身前、重心低，與槍兵的站姿輪廓要一眼可分。
- `hit`：以盾格擋的受擊，後退半步。

## 騎兵 `soldier_cavalry_blue`

人與馬是同一個骨架。騎兵比步兵寬，骨架畫布放寬為 480×640，原點仍在馬的前後蹄中點、y=0 為地面。

新增骨頭（在現有小兵骨架之上；騎士的 `hip` 改掛在 `horse_body` 下）：

`horse_body, horse_neck, horse_head, horse_tail, horse_leg_fl, horse_shin_fl, horse_leg_fr, horse_shin_fr, horse_leg_bl, horse_shin_bl, horse_leg_br, horse_shin_br`

| 分件 | 建議尺寸（像素） | 說明 |
|---|---|---|
| `horse_body` | 約 260×140 | 含馬鞍與披甲，陣營色放在披甲 |
| `horse_neck`／`horse_head` | 約 90×120／100×90 | |
| `horse_leg_*`／`horse_shin_*` | 各約 40×90 | 四條腿各分上下兩節，共 8 件；左右兩側可共用貼圖、遠側調暗 |
| `horse_tail` | 約 60×110 | |
| 騎士 `head`、`torso`、`arm_n`、`arm_f` | 比步兵縮為約 80% | 單頁圖集放得下的前提 |
| 騎士 `leg_n` | 約 60×110 | 跨坐姿勢；遠側腿被馬身遮住可省略 |
| `weapon_lance` | 約 50×340 | 騎槍，長於步兵槍 |

- 圖集上限仍為單頁 512×512；放不下時優先縮騎士細節，不得加頁。
- `idle`：馬原地踏蹄、甩尾。
- `walk`／`dash_in`：馬四蹄跑動的完整週期，`dash_in` 為疾馳（前傾、槍前指）。四蹄落地要貼 y=0。
- `duel_attack`：1.0 秒。持槍前衝突刺，雙手握槍、肘後拉、全伸、命中頓格，前手不可離桿。
- `fall`：人馬一起側倒，停在最後一格。
- 這套動作必須讓第二匹不同配色的騎兵直接套用同一骨架，不為單一外型調動畫。

## 交付位置與驗收

1. 交到私有倉庫 spine-trial 的 `battle-chibi-spec` 分支：`characters/soldier_shield_blue/out/` 與 `characters/soldier_cavalry_blue/out/`，各含 `<名稱>.json`、`atlas/<名稱>.atlas`、`atlas/<名稱>.png`。素材不進公開倉庫。
2. 另附每個動作的預覽影片或動圖各一段（側面、背景純色），供審查。
3. 驗收：八個動作名稱與長度相符；全程不斷肢、腳底貼地；鏡像後持械手合理；縮到 150 像素高仍能一眼分出槍兵／弓兵／盾兵／騎兵。
4. 程式端接入由戰場專家處理：在 `assets/scripts/battle/shared/UnitPresentationConfig.ts` 加兵種對應、匯入工具加入這兩個名稱。之後每個小隊會顯示 3 人，同兵種共用同一份骨架與圖集，所以單一素材的大小直接乘上場上隊數，請勿超過上述圖集上限。

# 武將大招漫畫分鏡繪圖規範（1/3）交付與連貫

> 本規範分三份：[01 交付與連貫](美術-武將大招分鏡規範-01-交付與連貫.md)、[02 拍點畫風與接入](美術-武將大招分鏡規範-02-拍點畫風與接入.md)、[03 提示詞與驗收](美術-武將大招分鏡規範-03-提示詞與驗收.md)。

給 Codex 或繪師出圖用。可整段複製到提示詞。與播放器核心 `assets/scripts/shared/cutin/cutinCore.ts` 共用同一套命名與張數規則（任務卡 PROG-2-2250，來源 Issue #2139）。

風格參考：趙雲三連分鏡示範（墨線 + 水彩、淺色紙底、無框無字）。示意影片未進 repo。

**設定檔與清單的位置見 02 的第 8 節「遊戲內接入」**：新武將只要交圖、放一份 JSON、在清單加一行 id，不改程式。


---

## 1. 交付物

- **每位武將各交獨立 PNG，不要交一張連在一起的總表。**
- **預設 3 張**，節奏為蓄力 → 出招 → 特效爆發。這是建議的標準拍數。
- **也允許 2 至 6 張或更多。** 播放器讀的是設定檔裡的 `panels` 陣列，張數沒有寫死。少於 2 張會顯得單薄，多於 8 張在戰場裡會拖慢節奏，需搭配 replay 縮短。
- 畫布：**16:9，1920×1080 PNG**（sRGB、不透明或紙底填滿）。這與手機橫屏戰場一致，也方便鏡頭微推與震動時向外出血。
- 不要留黑邊、白框、描邊外框。背景要畫到畫布邊緣，讓 zoom / shake 時不會露出版框。
- 檔案內**不准有任何文字、招牌、浮水印、簽名、面板編號**。武將名與招式名由播放器疊加。

### 1.1 主體與安全區

以 1920×1080 計算：

- **內安全區**：距四邊各留 80 px，重要的臉、手、兵器刃尖與神獸頭部必須在此之內（即 1760×920 的中心區域）。
- **招式名橫幅區**（播放器會疊字）：底部 200 px 高的橫帶（y = 880–1080）。不要把臉、兵器焦點放在這條帶的正中央。底部可以有衣角、地面、氣流。
- 若該張要疊招式名（通常是最後一張，也可以是任意一張），**右側約 1/3**（x = 1280–1920）再避開主要臉部與神獸頭部，讓橫幅不擋臉。神獸、氣流可往左上發展。
- 主體大致置中略偏左或偏右皆可，但同一套分鏡的站位與面向要連貫。

### 1.2 檔名與資料夾

```
artwork/ult-cutin/<general_id>/        # 原稿與清單（進 repo 供對帳）
  manifest.json
  01_charge.png      # 或 01_<beat>，見下方
  02_strike.png
  03_burst.png
  …
```

- `<general_id>` 用英文小寫加底線（遊戲武將 id 的 `-` 換成 `_`，與武將立繪檔名規則相同），例如 `zhao_yun`、`guan_yu`、`zhang_fei`。驗收通過後同一批 PNG 複製到 `assets/resources/sprites/ult_cutin/<general_id>/`（見 02 的第 8 節）。
- 檔名以兩位數字開頭，從 `01` 連續編號，後接底線與拍號英文：

  | 預設拍號 | 檔名建議 | 用途 |
  |---|---|---|
  | 蓄力 | `01_charge` | 起手、蓄勢、表情 |
  | 出招 | `02_strike` | 動作最高點、速度線 |
  | 爆發 | `03_burst` | 主題色能量或神獸 |

- 若不是標準 3 拍，仍用 `01_`、`02_`、`03_`、`04_`… 編號，拍號可用 `windup`、`step`、`thrust`、`follow`、`burst` 等英文，並在 `manifest.json` 與播放設定裡列出。
- 播放設定的 `imageKey` 建議寫成 `ult_cutin/<general_id>/01_charge`（不含副檔名）。

### 1.3 清單檔 `manifest.json`（必要）

列出這套分鏡的張數、檔名、面向與技能名（技能名僅為建議時請標明）。播放器真正使用的是 `cutinConfig.*.json` 的 `panels` 陣列；清單檔給繪圖與驗收對帳。

```json
{
  "generalId": "zhao_yun",
  "generalName": "趙雲",
  "skillName": "龍膽·破軍",
  "skillNameSuggested": false,
  "facing": "right",
  "cameraSide": "left",
  "panels": [
    { "file": "01_charge.png", "beat": "charge", "holdHintSec": 0.6 },
    { "file": "02_strike.png", "beat": "strike", "holdHintSec": 0.5 },
    { "file": "03_burst.png", "beat": "burst", "holdHintSec": 0.6 }
  ]
}
```

`facing` 為角色主要衝向（畫面左或右）。一套分鏡必須全張相同。

## 2. 連貫規則（務必遵守）

1. **三張（或 N 張）是同一招的連續瞬間，不是三個不同招式的選項。**
2. **鏡頭在角色的同一側**，不可中途改成反面或背面（除非整套都是背面）。
3. **畫面方向一致**：若第 1 張武器向右上蓄力，第 2、3 張也要向右（或沿同一弧線）出招，不能左右對調。
4. **兵器軌跡要接得起來**：下一張的刀／矛位置，應是上一張動作的合理延續（更高、更前、或已揮過身前），不要無故換手或換持械姿勢。
5. **角色設計鎖定該武將的正式立繪**：臉型、鬍鬚、髮型、頭飾、鎧甲分件、披風、主色與兵器造型都要對得上立繪。同一套分鏡的每一張都必須是同一個人。
6. **畫風一致**：線條粗細、墨色、水彩渲染、紙紋、光向與色盤全套統一，不要一張偏厚塗、一張偏線稿。

出圖前先準備一張該武將的立繪作為唯一角色參考，每張提示詞都附上。

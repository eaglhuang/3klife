# 武將大招漫畫分鏡繪圖規範（2/3）拍點、畫風、武將表與遊戲內接入

> 本規範分三份：[01 交付與連貫](美術-武將大招分鏡規範-01-交付與連貫.md)、[02 拍點畫風與接入](美術-武將大招分鏡規範-02-拍點畫風與接入.md)、[03 提示詞與驗收](美術-武將大招分鏡規範-03-提示詞與驗收.md)。

## 3. 各拍定義

以下為**預設 3 拍**。若增加到 4–6 拍，在蓄力與出招之間、或出招與爆發之間插入過渡拍（例如踏步、兵器剛觸及氣流、神獸初現），仍須是同一招的連續瞬間。若只有 2 拍，建議保留「出招 + 爆發」，或「蓄力 + 爆發」，並在清單裡註明。

### 3.1 蓄力（charge）— 建議鏡頭：中景（medium）

- 身體積蓄力量：踏穩、扭腰、兵器舉起或後拉。
- 表情清楚：眼神、咬牙或吐氣，讓人看出這一招的個性。
- 可有輕微氣流或衣袂，但不要在這一張就放完整神獸。
- 構圖留出頭部與兵器全長；頭不要貼上緣。

### 3.2 出招（strike）— 建議鏡頭：中近景（medium-close）

- 動作最高點：揮砍、突刺或砸擊的瞬間。
- 加速度線、殘影或氣流條，方向與兵器軌跡一致。
- 臉仍可辨識，不要完全被袖或氣流蓋住。
- 比蓄力更靠近主體，但仍留給四肢與兵器空間。

### 3.3 爆發（burst）— 建議鏡頭：中遠景或略寬（medium-wide）

- 出現該武將主題色的能量或神獸（龍、虎、鳳等，見第 5 節）。
- 神獸／能量與兵器、招式方向一致（例如矛尖刺出處噴出冰龍）。
- 角色仍在畫面裡，不要只剩特效。
- 預留底部橫幅與（若疊字）右側空間，見 01 的 1.1。

鏡頭可微調，但不要一套裡突然改成極端仰角或完全不同的透視。

## 4. 畫風

- **墨線 + 水彩漫畫風**，淺色宣紙或米色紙底，可保留輕微紙紋。
- 線條清楚、有輕重；水色在鎧甲與氣流上可有渲染，但不要塗死成厚塗電繪。
- 光向統一（建議主光從畫面上方或前上方來）。
- **禁止**：寫實照片風、Q 版變形（這套分鏡是戰場上的「演出立繪」，不是大廳小人）、日文假名或中文字、Logo、外框、黑邊、塗白背景留不規則透明。
- 背景以紙色與氣流為主，不要畫完整戰場場景，以免跟遊戲裡的 Q 版戰場搶戲。切換時由播放器用變暗與信箱黑框來分隔風格。

## 8. 遊戲內接入（交圖之後）

播放器已在戰場奧義施放點接好：奧義發動 → 先播武將的漫畫分鏡 cut-in（戰場暫停）→ 再播既有奧義特效。新武將不改程式，只做三件事：

1. **放圖**：驗收通過的 PNG 放到 `assets/resources/sprites/ult_cutin/<general_id>/`，檔名 `01_charge.png`…（不含副檔名即為 `imageKey` 的尾段）。第一次放進去要讓 Cocos 編輯器匯入一次，產生 `.meta`。
2. **放設定**：複製 `assets/resources/data/ult-cutin/zhao_yun.json` 改成新武將（`id`、`generalId`、`generalName`、`skillName`、`panels`…）。`panels[].imageKey` 寫成 `ult_cutin/<general_id>/01_charge`；每格可各自設定停留秒數 `hold`、鏡頭縮放 `zoomFrom`／`zoomTo`、閃白、震動、音效 `sfx`；語音 `voice` 與音效分開設定；武將名與招式名可放在任一格（`textOverlays[].panelIndex`）。
3. **登記**：把武將 id 加進 `assets/resources/data/ult-cutin/index.json` 的 `generals`。沒登記的武將施放奧義時直接播奧義特效。

行為備忘（驗收用）：

- 張數不寫死，設定檔有幾格就播幾格（已測 1、2、3、5 格）。
- 點一下畫面：跳到收尾爆發，再接奧義特效。
- 同一場戰鬥同一武將第二次施放：播縮短重播（約 0.8 秒，可只留部分格，見 `replay.panelIndices`），預設不重播語音。
- 圖沒匯入或缺幾張：缺的那格略過；全缺就整段略過，不報錯，只播奧義特效。
- 語音或音效檔缺：只記一行 log，畫面照播。
- 手機橫屏：招式名文字避開瀏海與 Home bar，位置在下方黑邊之上。

## Q14. 退役武將是否仍保留「因子媒介 / 靈魂傳承」作為教官之外的第二出口？ B

來源衝突：`血統理論系統.md` (doc_spec_0011) 仍保留「退役時可選擇教官或因子媒介路徑」，但 `keep.summary.md` (doc_index_0012)、`教官系統（支援卡）.md` (doc_spec_0027)、`武將壽命系統.md` (doc_spec_0018) 目前已把退役主路線收斂到教官，死亡時才正式結算英靈卡 / 虎符卡。若不先拍板，後續 Data Schema 與 UI 入口會繼續雙軌並存。

A. 保留雙路：退役時可選教官或因子媒介，死亡時另照正式規則補發雙卡。

B. 收斂成單路：退役一律轉教官，因子媒介概念取消或併入教官 / 培育事件。

C. 僅史實名將或女性名將可走因子媒介，其餘角色只能轉教官。

D. 單機 / 長局模式保留因子媒介，正式主線伺服器世界線只保留教官。

## Q15. 名士預言、血統模擬器與 `Revelation_Level` 的正式關係要收斂到哪一層？ C

來源不清：`培育系統.md` (doc_spec_0026) 已把子嗣揭露收斂為 `隱藏 → 傾向 → 區間 → 精確值`，但 `名士預言系統.md` (doc_spec_0006)、`結緣系統（配種）.md` (doc_spec_0028) 目前只寫「方向性提示 / 矛盾批語」，尚未明定它們是否能推進 `Revelation_Level`，還是只能當作獨立敘事提示。

A. 名士預言永遠只屬方向性提示，不直接推進 `Revelation_Level`。

B. 名士預言可把子嗣從 `0` 推進到 `1`（傾向），但不能到區間或精確值。

C. 高階名士 / 特殊工具可推進到 `2`（區間），但 `3`（精確值）仍只能靠成年 / 鑑定事件。

D. 名士預言、血統模擬器、成年鑑定都可推進揭露，只是成本與誤差率不同。

## Q16. 場景戰法（Scene Gambit）的正式入口要收斂到哪裡？ B

來源衝突：`戰法場景規格書.md` (doc_spec_0039) B-1 仍寫「唯一觸發來源」是治理大廳軍事任務，但 `大廳系統.md` (doc_spec_0002)、`官職系統.md` (doc_spec_0014)、`治理模式他國AI系統.md` (doc_spec_0020) 已把雙牆任務、世界沙盤與軍事任務品質都拉進同一條大廳 / 官職 / 沙盤鏈。若不拍板，之後大廳與沙盤會各自長出平行入口。

A. 維持唯一入口：只有治理大廳軍事任務可正式觸發場景戰法。

B. 大廳雙牆任務與世界沙盤遠征共用同一條場景戰法入口，治理大廳只是 UI 呈現面。

C. 世界沙盤成為唯一正式入口，大廳只顯示任務摘要與推薦，不直接發動。

D. 大廳、世界沙盤、特定關卡都可各自直接發動，允許多入口並存。

## Q17. 組合奧義應歸屬哪一層正式規格？ C

來源不清：`戰法場景規格書.md` (doc_spec_0039) 的 J 節已列出赤壁大火、桃園結義、五虎將降臨，但標成「詳細規則未定」；目前也未釐清它是 `場景戰法`、`格子戰法`、`一般戰法`，還是獨立的全屏演出系統。

A. 歸在 `場景戰法`：只要進入特定場景，符合組合條件就由場景層統一觸發。

B. 歸在 `戰法系統`：當作角色帶入的高階組合技，場景只提供加成或演出載體。

C. 另開獨立 `組合奧義` 子系統，由戰法系統與場景規格共同引用。

D. 先不做正式規則，只保留敘事型全屏演出，數值與觸發延後定義。

## Q18. 混種戰法（Hybrid Skills）的母規格要以哪份文件為權威？ A

來源衝突：`戰法系統.md` (doc_spec_0038) 目前未正式承接混種戰法，實際定義散落在 `血統理論系統.md` (doc_spec_0011)。若不先收斂，未來 Data Schema、技能圖鑑與培育事件會不知道該以戰法母系統還是血統母系統為準。

A. 以 `戰法系統.md` (doc_spec_0038) 為母規格；`血統理論系統.md` (doc_spec_0011) 只描述來源與解鎖條件。

B. 以 `血統理論系統.md` (doc_spec_0011) 為母規格；`戰法系統.md` (doc_spec_0038) 只保留交叉引用與 UI 顯示。

C. 新開 `混種戰法 / 血統戰法` 獨立規格書，讓兩邊都只引用。

D. 暫不升格正式規格，只保留少數白名單案例，不建立通用系統。

## Q19. 宿敵配對的正式懲罰要採哪一套？ A

來源衝突：`家族關係（史實相性）系統.md` (doc_spec_0024) 一處寫宿敵「不再直接給固定 EP 加成」，但關係類型表又保留 `RIVAL = -10 EP`；`正式規格矛盾審查.md` (doc_spec_0001) 也已將此列為跨文件衝突。若不拍板，配種 UI、數值公式與文案會繼續不一致。

A. 保留 `-10 EP + 受孕率 -30% + 狼性因子` 的三重懲罰。

B. 取消固定 EP 懲罰，只保留 `受孕率 -30% + 狼性因子`。

# 結緣事件文案範例（20 則，分片索引） — 一、結緣好感納配偶（7 則）與 二、外交聯姻求親（6 則）

> 這是 `結緣事件文案範例.md` 的「一～二」分片。完整索引見 `docs/遊戲規格文件/文案/結緣事件文案範例.md`。

## 一、結緣好感納配偶（`source: bond`，7 則）

1. **[BOND-01] 信箱爆滿警告（通用高好感）**
   - 內文：「{name}跟你的好感條早就滿到溢出來了，她剛才在史境大廳私訊問：『主公，我把你設成特別關注三年了，什麼時候轉正？』」
   - 選項：`馬上納為配偶` / `再等等，我還在看通知`
2. **[BOND-02] 戰後同袍告白（武將系／並肩出征）**
   - 內文：「剛打完仗連甲冑都還沒脫，{name}扛著武器走過來：『剛剛替你擋箭的時候我算了一下，娶我比再抽十次卡還划算，考慮一下？』」
   - 選項：`這筆帳我簽了！` / `先去包紮一下好嗎`
3. **[BOND-03] 深夜追更共鳴（文官／書香系）**
   - 內文：「半夜三點大廳只剩你跟{name}還沒下線，她推過來半壺熱茶：『關羽那本小說我跟你一起追更完了，接下來想跟你一起寫我們家的故事。』」
   - 選項：`把家族大門鑰匙交給她` / `先熬完這季再說`
4. **[BOND-04] 他國名將辭官追愛（SP1 移籍情境）**
   - 內文：「{name}抱著一箱打包好的離職證明站在城門口：『我已經把原本勢力的工作交接完、群組也退光了，今天起只歸你管，不退貨喔！』」
   - 選項：`歡迎入列，順便進家譜！` / `等一下，你原來老闆知道嗎？`
5. **[BOND-05] 禮物收太多不好意思（送禮滿額觸發）**
   - 內文：「{name}看著倉庫裡堆成山的禮物盒嘆了口氣：『主公再送下去，系統都要判定你在對我洗經驗值了。乾脆結婚吧，以後你的就是我的！』」
   - 選項：`好，庫房密碼改你生日` / `這叫戰略投資，不算洗分`
6. **[BOND-06] 直播間起鬨助攻（世界觀彩蛋）**
   - 內文：「張飛在旁邊開直播起鬨：『全服見證！{name}對主公好感破表啦！』{name}紅著臉把鏡頭遮住：『別理他……但你到底點不點確定？』」
   - 選項：`在全服彈幕見證下成親` / `先幫張飛關掉麥克風`
7. **[BOND-07] 單純直球型（傲嬌／爽朗系）**
   - 內文：「{name}雙手抱胸盯著你：『我可不是因為沒人要才來問你，只是看你家譜還空著一格很難受。要就現在點頭，過這村沒這店！』」
   - 選項：`感謝強迫症成全，娶了！` / `我再整理一下版面`

## 二、外交聯姻求親（`source: diplomatic`，6 則）

8. **[DIP-01] 友好交流暗語（標準聯姻彈窗）**
   - 內文：「{nation}特使笑嘻嘻地送來一位宗室千金{name}，附帶一封官方公文：『此乃友好交流，白話文就是：請多多關照，順便別打我們。』」
   - 選項：`收下這份「和平禮」` / `我們先保持純友誼`
9. **[DIP-02] 跨服雲端和親（高好感盟友）**
   - 內文：「{nation}君主遠端發來全息語音：『老哥，咱們邦交這麼鐵，不如親上加親！把我妹{name}嫁過去，以後國戰我幫你點讚！』」
   - 選項：`就這麼說定了！` / `點讚可以，妹子先慢點`
10. **[DIP-03] 邊境停火見面禮（軍事強權對談）**
    - 內文：「{nation}使者擦著汗遞上紅帖：『主公軍容實在太嚇人，我家君主決定把{name}風光嫁過來當外交大使，只求貴軍明年繞道走。』」
    - 選項：`看在千金面上，今年休兵` / `公事公辦，不談感情`
11. **[DIP-04] 母國開戰防呆預警（SP2 提示文案）**
    - 內文：「{name}行禮入府時小聲提醒：『雖然我現在是你的人了，但哪天你真要打{nation}，我還是會心情跌到谷底、拒絕上戰場的喔！』」
    - 選項：`放心，和平共處` / `了解，家國分開算`
12. **[DIP-05] 文化互訪變定情（歌劇外交堂會後）**
    - 內文：「自從上次外交堂會合作演完一齣戲，{nation}的{name}就常傳訊問戲本進度。今天國書正式送到：『貴我兩家合組聯姻伺服器吧！』」
    - 選項：`批準併服，迎娶過門` / `再多辦幾場堂會看看`
13. **[DIP-06] 聯姻額度將滿提醒（`marriagePerNation` 提示）**
    - 內文：「{nation}媒使搓著手笑道：『算上這位{name}，咱們兩家已經結了第二門親事啦，再娶下去貴國宗室都要變我們家親戚群組了。』」
    - 選項：`親戚不嫌多，迎娶！` / `留點額度給別國`

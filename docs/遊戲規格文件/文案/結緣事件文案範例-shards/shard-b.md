## 三、媒人說親（`source: matchmaker`，7 則）

14. **[MAT-01] 媒婆拿號碼牌（未開放 / 價格待定共用）**
    - 內文：「史小境跳出系統公告：『媒婆還在排隊領號碼牌兼等財務部定價，本服務「即將開放」，請先去結緣或聯姻逛逛！』」
    - 選項：`好，我去存銀兩`
15. **[MAT-02] 年度重置開張（春季 Q1 說親首刷）**
    - 內文：「媒婆拎著三大疊履歷表推門進來：『新年新氣象！今年共有兩次嚴選配對機會，我連夜幫主公篩了三位零負評千金，快來看！』」
    - 選項：`展開三位候選履歷` / `下次再相親`
16. **[MAT-03] 書香門第推薦（家世提示範本）**
    - 內文：「這位{name}出自{clan}，嫁妝是三車竹簡。媒婆小聲補充：『她打字很慢但識字很多，以後寫年報和教小孩絕對省心！』」
    - 選項：`就選這位才女` / `看看下一位`
17. **[MAT-04] 商賈世家推薦（家世提示範本）**
    - 內文：「這位{name}出自{clan}，算盤打得比系統伺服器還快。媒婆提醒：『娶了她，記得以後買東西別跟她虛報價格，會被當場拆穿。』」
    - 選項：`家裡正缺財務長，娶！` / `壓力有點大，看看別位`
18. **[MAT-05] 將門之後推薦（家世提示範本）**
    - 內文：「這位{name}出自{clan}，騎射滿分、嘴砲也滿分。媒婆抹汗說：『雖然吵架贏不了她，但要帶兵出征絕對幫你把對面拆光光！』」
    - 選項：`就要這麼猛的，迎娶！` / `我再考量一下`
19. **[MAT-06] 小戶人家推薦（家世提示範本）**
    - 內文：「這位{name}出自{clan}，擅長精打細算持家。媒婆豎起大拇指：『別看她低調，有她在，你家銀兩錢包永遠比別人穩三倍！』」
    - 選項：`勤儉持家最實在，選她！` / `再看其他候選`
20. **[MAT-07] 保底奇女子登場（第 3 次說親保底 EP ≥ 65）**
    - 內文：「媒婆今天神秘兮兮地拉開布簾：『主公，看您誠心相親這麼多回，這回特邀一位隱世奇女子{name}——評級直接金色閃光，錯過不再！』」
    - 選項：`這就是天命保底！立刻下聘` / `先冷靜確認銀兩夠不夠`

# INT智力戰法發動率檢核器與成功率加成數值規格書

## 1. 核心定位與職責邊界
本規格書定義《三國人生》武將智力屬性（INT）對主動戰法發動判定機率（Tactic Trigger Rate）的數學檢核模型與成功率加成協議（WBS `FORM-05`，代碼落位於 `TacticTriggerRate.ts` 與 `BattleCombatResolver.ts`）。
戰鬥系統將智力屬性作為施法意願與心智決策的直接轉化器，隨智力提升呈現邊際效益平滑遞減之漸近線曲線，為各階層武將建立嚴密且符合直覺的施法頻率體系。

```
              ┌──────────────────────────────────────────────┐
              │          TacticTriggerRate 智力發動檢核       │
              └──────────────────────┬───────────────────────┘
                                     │
          ┌──────────────────────────┴──────────────────────────┐
          ▼                                                     ▼
   【雙錨點漸近曲線】                                    【額外加成與邊界】
   • INT = 300  → 70.0% 發動率                           • 戰法專屬 Success_Bonus
   • INT = 1200 → 92.5% 發動率                           • 最終截斷 clamp01(Rate + Bonus)
   • 核心常數 K = 90 (1 - 90 / INT)                      • INT ≤ 0 或無效值: 強制歸 0
```

## 2. 戰法發動率雙錨點公式

### 2.1 數學模型與常數推導
戰法基礎發動率由武將當前智力值（INT）決定：
$$\text{BaseRate} = 1 - \frac{K}{\text{INT}} \quad (K = \mathbf{90}, \text{TACTIC\_TRIGGER\_K})$$

> **規格常數對位備忘**：手冊文字條目表記為「$1 - \frac{9000}{\text{INT}}$」，實為百分制表達式（$\frac{9000\%}{\text{INT}} = \frac{90}{\text{INT}}$）；本系統小數點標準運算以 $K = 90$ 同時完美吻合規格指定之兩大數值錨點。

### 2.2 智力階層數值錨點表

| 武將智力 (INT) | 階層心智定位 | 基礎發動率計算式 | 實測發動率 (`BaseRate`) | 戰場施法行為特徵 |
| :---: | :--- | :--- | :---: | :--- |
| **$\le 90$** | 弱智/蠻勇莽夫 | $1 - \frac{90}{90} = 0$ | **$0.0\%$** | 毫無戰術思維，無法主動組織計謀 |
| **150** | 粗通兵法將領 | $1 - \frac{90}{150} = 1 - 0.60$ | **$40.0\%$** | 戰機偶露，偶有靈光一閃 |
| **300** | **合格軍師入門** | $1 - \frac{90}{300} = 1 - 0.30$ | **$70.0\%$** | **規格錨點 A**：多數回合能正常施策 |
| **600** | 郡國一流良策 | $1 - \frac{90}{600} = 1 - 0.15$ | **$85.0\%$** | 洞悉戰局，計謀行雲流水 |
| **1200** | **天下絕頂謀士** | $1 - \frac{90}{1200} = 1 - 0.075$ | **$92.5\%$** | **規格錨點 B**：極致穩定，罕有失算 |
| **2000** | 轉生登峰造極 | $1 - \frac{90}{2000} = 1 - 0.045$ | **$95.5\%$** | 逼近天花板，心如明鏡 |

## 3. 戰法專屬加成與極限安全夾限

### 3.1 成功率加成（`Success_Bonus`）
特定簡易戰法、專屬特訓詞條或教官支援效果可附加專屬發動加成（`successBonus`）：
$$\text{FinalRate} = \max(0.0, \min(1.0, \text{BaseRate} + \text{successBonus}))$$
- 例如 INT 300 武將若裝備 `successBonus = 0.10` 之戰法，最終發動率提升至 $70\% + 10\% = 80\%$。

### 3.2 異常邊界防護
1. **零值與負值**：若武將因極端 Debuff 或未初始化導致 $\text{INT} \le 0$，發動率恆為 **0%**。
2. **無效數值**：若傳入為 `NaN` 或非有限數字，防禦性回傳 **0%**，絕不中斷戰鬥生命週期。

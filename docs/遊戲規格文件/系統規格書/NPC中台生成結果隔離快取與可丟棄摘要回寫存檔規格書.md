# NPC中台生成結果隔離快取與可丟棄摘要回寫存檔規格書

> **所屬模組**：`3.6 數值、架構與底層支援 (NPC-10 / BRAIN-12)`  
> **單一真相來源**：確立「中台 AI / LLM 生成文本不得作為遊戲底層唯一真相」架構原則，定義可丟棄本地對話快取層、清理協議，以及結構化互動摘要回寫存檔之契約。

---

## 1. 隔離架構原則與職責劃分

為防止 AI 生成文字之隨機性、幻覺或伺服器連線波動損害核心遊戲邏輯，系統建立嚴格的雙層數據隔離：

```
+-------------------------------------------------------------------------+
| [中台 / 服務端 (NPC Brain Service)]                                      |
| - LLM 動態對話生成、向量檢索 (RAG)、情境選項推薦                       |
+-------------------------------------------------------------------------+
                                    |
                            [非同步 HTTP 傳輸]
                                    |
+-------------------------------------------------------------------------+
| [客戶端表現層: 可丟棄快取 (DispensableDialogueCache)]                   |
| - 僅供 UI 對話氣泡動態展示                                              |
| - 記憶體/暫存檔 LRU 最多 50 筆，支援一鍵清空或過期丟棄                  |
| - 嚴禁將未經校驗之原始對話長文字寫入核心存檔                           |
+-------------------------------------------------------------------------+
                                    |
                    [結構化過濾與狀態提煉 (Extractor)]
                                    |
+-------------------------------------------------------------------------+
| [客戶端核心存檔 (PlayerSave: Data.NPC_Memory)]                          |
| - 唯一真相來源，僅保存 100% 確定性之互動摘要 (InteractionDigestEvent)    |
| - 包含: 關係變更、好感增減、事件代碼 (ActionEnum)，字元長度 < 120 bytes |
+-------------------------------------------------------------------------+
```

---

## 2. 可丟棄本地快取層規範（DispensableDialogueCache）

1. **容量與置換策略**：
   - 採最近最少使用（LRU）原則，客戶端本地上限快取 **50 筆** 對話與情境對話包。
   - 超過 50 筆時，自動淘汰最舊之非收藏對話。
2. **安全清理機制**：
   - 玩家於系統設定介面點擊「清理快取」，或遊戲大版本升級時，系統安全抹除 `DispensableDialogueCache`；
   - 清除快取後，武將關係、好感度、名冊資訊與歷史事蹟不受任何影響。

---

## 3. 結構化互動摘要回寫契約（InteractionDigestEvent）

對話或互動結束時，系統自中台回傳結果中提取出結構化資料，回寫至玩家存檔：

```typescript
export interface InteractionDigestEvent {
  digestId: string;               // 唯一流水號
  timestamp: number;              // 時間戳記
  generalId: string;              // 目標武將 ID
  contextKey: string;             // 情境標籤，如 "CHANGBAN_BRIDGE"
  outcomeType: "BOND_INCREASED" | "TACTIC_SHARED" | "DISAGREED" | "IDLE_TALK";
  statChanges: {
    bondDelta: number;            // 好感變化 (-5 ~ +10)
    loyaltyDelta: number;         // 忠誠變化 (-10 ~ +10)
  };
  compactSummary: string;         // 精簡摘要 (限定 30 字以內，如: "於長坂橋與將軍論兵法，甚合")
}
```

- **單一真相約束**：`compactSummary` 為存檔中唯一允許保存之文本欄位，長度不得超過 30 個中文字，禁止將動態生成之數千字 prompt 或 LLM raw tokens 寫入存檔。

---

## 4. 斷網與異常降級時序

當客戶端無法連線至 NPC Brain 或中台回應超時（超過 2.5 秒）時：
1. **靜態模板代打**：前端立即調用 `OfflineTemplateEngine`（`doc_spec_0333`），由本地預置之核心台詞庫生成對話；
2. **提煉摘要入庫**：靜態模板對話同樣輸出合法之 `InteractionDigestEvent` 回寫存檔；
3. **體驗零中斷**：玩家在離線狀態下仍可流暢對話與推進好感，達成高容錯、高強韌之系統架構。

# Q版街上偶遇他國武將規格書（QENC-01）

> **規格代碼**：`QENC-01`　**任務卡**：PROG-2-10264　**裁決來源**：使用者 2026-11-28 本人核准「逛市井大街會隨機偶遇他國武將，可聊天、切磋、招攬」；前提裁決＝QLIFE-01 2.4「街上太冷清時，多放他國武將遊歷」、審-6「不做無名路人 Q 頭」。
> **狀態**：規格草案（只有規格，不含程式；數值是 PM 暫定，全放 JSON 可調，不用問使用者）
> **定位**：「Q 版社會」的第 5 份。QLIFE-01 把「他國武將遊歷事件」留給企劃另寫，本書就是那份事件規格。
> **依賴**：Q版生活系統規格書（`doc_spec_1356`，QLIFE-01：搭話、單挑、每季 6 次互動）、Q版社會總規格書（`doc_spec_1357`，QSOC-01：情報 Lv0～5、首訪任務）、共用框架總綱（`doc_spec_1182`）、人員占用 Base（`doc_spec_1248`）、友誼行為權重表（`friendship-action-weights.json`）、武將私塾補習班（`doc_spec_1280`：AI 間友誼推算）、武將台詞系統（共用框架）、他國 AI 外交決策模型（`doc_spec_0497`，外交與勢力關係）。
> **姊妹篇**：Q版武將作息表與喜好查看規格書（QSCHED-01，同一批核准）。
> **世界觀**：遊歷的他國武將都是標準古人，照正史演自己；不因玩家招攬而改正史走向，被招攬只代表「這一輪遊戲裡他轉投你家」。

## 0. 結論（先看這段）

1. 玩家在**市井大街**停留時，每個生活時段開始會抽一次「有沒有他國武將來遊歷」。基礎機率 **35%**，家臣少時加碼、家臣多時減半；**每季最多 4 位**（冷清時最多 6 位）。
2. 來的是誰，看三件事：**他國武將與我方家臣的 AI 間友誼**（愛找老朋友）、**勢力關係**（交戰中不來）、**天下大勢**（瘟疫、豐收、衰落的國家人才外流）。
3. 遇到之後有三個選項：**聊天**、**切磋**、**招攬**。切磋的模式（點到為止／認真切磋）在邀約時自選，沿用 QLIFE-01 6.4。
4. 招攬不是一次砸錢就成：要**友誼夠、情報看得到、對方不是死忠、遊歷見面次數夠（名將要三顧）**，再付招攬禮（銀兩）擲成功率。成功＝他離開原勢力、轉入我方家臣；失敗扣友誼、冷卻兩季。
5. **每次互動都算每季 6 次免費額度之一**（聊天、切磋、招攬各算 1 次）；情報 Lv 不夠時只能先「搭話認人」。
6. 演出沿用 Q 頭加對話泡泡：入場、剪影識破、三種互動各有簡短演出；台詞全部走 i18n，**帶說話者性別與主角性別參數**。
7. 全部資料驅動，數值放 `life-encounter.json`、`life-encounter-recruit.json`；遊歷名單與招攬結果屬伺服器權威（單機走本機 adapter）。

## 1. 名詞

| 名詞 | 意思 |
|---|---|
| 遊歷者（wanderer） | 他國在世武將，因遊歷事件暫時出現在市井大街，**不是**訪客、傭兵、浪人，也不是家臣 |
| 遊歷抽籤 | 每個生活時段開始，對「市井大街」擲一次的出現判定 |
| 遊歷停留 | 一位遊歷者在街上待的時間，預設 **1 個時段**（真實 90 秒），可互動；時段結束離場 |
| 識破 | 遊歷者在情報 Lv0～2 時只是剪影；玩家對他搭話後，他自報家門，該次停留內身分公開 |
| 見面次數 | 同一位遊歷者與玩家「有互動地」見面的**不同停留次數**（沒互動的不算），招攬用 |
| 招攬禮 | 招攬時付出的銀兩（家族私房，不是金） |
| 老朋友 | 與我方任一家臣的 AI 間友誼 prior ≥ +30 的他國武將 |

## 2. 出現規則

### 2.1 在哪裡出現

| 項目 | 規則（PM 暫定） |
|---|---|
| 場地 | **只有「市井大街」大圖（`mkt`）**。官署、軍事、文教、住宅、郊外、深山不出現；日後想放到驛站、客棧只改 `areas` 資料 |
| 玩家在場 | 玩家**正在看這張大圖**時才抽籤；不在不模擬、不補算（沿用 QLIFE-01 3.2「離線／不看」）。進入大圖時以「當下時段」直接補抽一次，避免剛進來沒人 |
| 時段 | 第 1～6 時段（晨～夜）可出現；第 7 時段（深夜）不出現。夜市、酒館晚間遊歷者多一些（`slotWeight`） |
| 落腳場景 | 從大街 14 個場景挑：依遊歷者喜好（`life-profile` 的 `affinityTag`）加權；沒有他的 profile 就用預設表（酒館、茶館、鐵匠鋪、書肆、馬市各自權重） |
| 同時上限 | 同一時段大街最多 **2 位**遊歷者同時在場 |

### 2.2 出現機率與每季上限

抽籤公式：

```
P(出現) = clamp( baseP × slotWeight(t) × crowdFactor × eventFactor , 0 , maxP )
```

| 項目 | 規則（PM 暫定，放 `life-encounter.json`） |
|---|---|
| `baseP` | **0.35** |
| `slotWeight` | 晨 0.8、上午 1.0、午 1.2、下午 1.2、傍晚 1.0、夜 0.8、深夜 0 |
| `crowdFactor`（街上熱鬧程度）| 我方家臣數 < 3：**×1.6**（補冷清，審-6）；3～7：×1.0；≥ 8：×0.5 |
| `eventFactor`（大勢）| 無事 ×1.0；豐收／大喜 ×1.3；戰爭中 ×0.6；瘟疫 ×0.4 |
| `maxP` | 0.7（任何加成都不超過）|
| 每季上限 | **4 位**（不同武將；換季重置）；`crowdFactor` 取冷清檔時上限 **6 位** |
| 時段內重抽 | 一時段只抽一次；同時段已有 2 位就不抽 |
| 同一人冷卻 | 同一位遊歷者**離場後 2 季內不再來**（他國 AI 也要出去辦事）；招攬失敗者見 5.4 |
| 首次保底 | 玩家**第一次**進市井大街且大街沒有任何家臣在場，必出 1 位老朋友或最近的鄰國武將，不抽籤（承接 `doc_spec_1357` 9.5.1「找 3 位」）|
| 確定性 | 亂數用共通底層確定性亂數，`seed＝(playerId, 季度序號, 時段序號, "enc")`，方便重現與驗證 |

> 抓個感覺：玩家每個生活日看大街，可抽 6 個時段；中等熱鬧時每時段約 0.35 × 1.0～1.2，一個生活日約出 2 位，所以約兩個生活日就會頂到每季 4 位的上限；冷清期 ×1.6 加上限 6 補人，熱鬧期 ×0.5 讓位給自家家臣。

### 2.3 戰爭與勢力關係

| 與玩家勢力關係 | 能不能來 |
|---|---|
| 同盟 | 可（權重 +20）|
| 中立 | 可（權重 +10）|
| 交戰中 | **不來**，除非是老朋友（友誼 prior ≥ +30），以「微服私訪」身分來，頭上掛「便服」符號，不能招攬（5.1 條件 5）|
| 對玩家宣戰的那一季 | 該勢力所有遊歷者當季立刻離場 |

## 3. 名單來源（誰會來）

### 3.1 候選池

候選＝全部他國在世武將，過濾後剩下的才進權重表：

| 過濾（任一成立就排除）| 說明 |
|---|---|
| 君主、勢力首領 | 不外出遊歷（`isRuler`）|
| 出征中、被擒、學府、陣亡、年齡 < 15（未成年）| 沿用 QLIFE-01 6.4 資格過濾與 OCC |
| OCC 有未結束的占用（`campaign`、`academy`、`medical:pregnant／nursing`、`tutorTeach`…）| 走人員占用 Base 判斷 |
| 冷卻中 | 2.2 的同一人冷卻、5.4 的招攬失敗冷卻 |
| 本季已出現 | 同季不重複 |
| 勢力交戰中且非老朋友 | 2.3 |

### 3.2 權重（誰比較容易來）

```
w(g) = base(10)
     + 老朋友加成      = max over 我方家臣 h { FRDprior(g,h) } × 0.30      // AI 間友誼，只取正值
     + 與主角友誼      = max(0, FRD(player,g)) × 0.50                       // 已有交情的更常來
     + 勢力關係        = 同盟 +20 / 中立 +10 / 交戰（老朋友）+0
     + 大勢加成        = 見 3.3
     + 愛逛街          = sociability(g) × 0.10                              // 沿用 life-profile
     × 稀有度係數      = N 1.0 / R 0.9 / SR 0.7 / SSR 0.45 / UR 0.25        // 名將比較難遇到
```

抽法同 QLIFE-01 2.3：機率 ∝ `w^k`，`k=1.6`，用確定性亂數。

**AI 間友誼的來源**：沿用武將私塾規格（`doc_spec_1280`）的**即時推算 prior**（同門、同窗、陣營、血緣、性格相性、共同經歷、史實），AI–AI 之間**不存檔、只推算**；只有「與我方接觸者」才存稀疏偏移量。本書**不新增 AI–AI 存檔**：遊歷抽籤時即算 `FRDprior(g,h)`，結果快取在當季。

**「他是來找人的」**：若 `FRDprior(g,h) ≥ 30` 的那位家臣 `h` 存在，這位遊歷者的 `visitTarget = h`：
- 他頭上帶「找人」符號，抽籤成立當時 `h` 若沒被占用，就在**同一場景**加一次「老友相逢」雙人演出（沿用 QLIFE-01 5.5 雙人互動符號），玩家可旁觀偷聽（走偷聽規則與說溜嘴）。
- 這是被動事件，**不扣互動次數**。

### 3.3 大勢加成（天下大勢怎麼影響誰會來）

| 大勢 | 加成（`eventBias`）|
|---|---|
| 該勢力國力排名後段（人才外流）| 該勢力武將 +15 |
| 該勢力剛被併或失去城池（本季）| 該勢力武將 +25，且招攬成功率 +0.10（5.2）|
| 瘟疫 | 醫術專長武將（華佗、董奉、張仲景類）+30，其餘 −10 |
| 豐收／大喜 | 全體 +5，酒鬼類（`affinityTag.drink ≥ 70`）+15 |
| 戰爭（非與玩家交戰）| 武力 ≥ 80 的武將 −10（忙著打仗）|
| 世界大事件舉辦中（比武大會、節慶疊層）| 對應專長武將 +20 |

## 4. 三種互動

> 互動入口沿用 QLIFE-01 第 6 章：點 Q 頭 → 圍著頭的小圓選單（按鈕 ≥ 44 像素）。遊歷者專屬三顆：**聊天、切磋、招攬**，另保留「偷聽」（要 Lv4）。送禮、邀約同行、搶物品**對遊歷者不開放**（避免物品流向他國、同行跨出大街）；送禮只出現在招攬流程裡當加碼（5.2）。

### 4.1 聊天 `chat`

| 項目 | 規則 |
|---|---|
| 做法 | 點「聊天」→ 武將跳一句台詞泡，玩家選一個話題（三選一：本國近況、閒話家常、打聽人事），武將回一句，共 2～3 句 |
| 友誼 | `enc_chat` +2（每武將每季最多 3 次）；Playful ×1.5；沿用 QLIFE-01 6.1 的個性倍率 |
| 情報 | 每次聊天 +0.3 `intel`（走 `reward.grant`，貨幣 `intel`，每季上限 +1.5）；打聽人事選項額外揭露「他最近跟誰好」（寫入該武將的作息表已知喜好，見 QSCHED-01 4.4）|
| 識破 | 對剪影（Lv0～2）聊天＝識破，該次停留內公開身分；這次聊天**不重複扣**次數 |
| 說溜嘴 | 沿用 `doc_spec_1348`，不加機率 |
| 見面次數 | 完成一次聊天算 1 次有效見面 |

### 4.2 切磋 `duel`

| 項目 | 規則 |
|---|---|
| 做法 | 沿用 QLIFE-01 6.4：邀約時**自選模式**，「點到為止」（血量 30% 收手＝`draw`，無後果）或「認真切磋」（打到 0，**預設**）；呼叫 QACT-01 單挑模組（純函式回傳 `DuelResult`）|
| 資格 | 要情報 Lv3 以上或已識破；遊歷者「便服」（交戰中老朋友）可切磋但友誼加成減半；輕傷者可應戰（接受率 −20%）|
| 接受率 | `0.35 + 友誼/100 + 武力好鬥加成(Brave +0.2) − 稀有度難度(SSR −0.1、UR −0.2)`；在市井大街的酒館前空地加成 +0.1 |
| 友誼 | 沿用 `life_duel_win`／`life_duel_lose`／`life_duel_draw`；遊歷者每季最多 2 次（比 QLIFE-01 的 3 次少，因為只待一個時段）|
| **後果** | 他國武將**不寫傷勢旗標**（避免寫進他國 AI 狀態；伺服器不信任客戶端對他國武將的傷勢寫入）。我方家臣代打落敗才依 QLIFE-01 6.4.1 進傷勢；主角代理頭落敗不寫傷勢 |
| 贏的好處 | 勝：該武將 `recruitBonusDuel = +0.10`（5.2，本次遊歷停留有效，下次再遇見要重打）；名聲 +5（走 `reward.grant`，每季上限 +20）|
| 見面次數 | 完成一場（含 draw）算 1 次有效見面 |

### 4.3 招攬 `recruit`

詳細條件與公式見第 5 章。這裡只列入口規則：

| 項目 | 規則 |
|---|---|
| 按鈕狀態 | **灰色**：情報不到 Lv3、遊歷者不是第一次見且尚未達見面次數、冷卻中。**紅字不可點**：死忠（`loyalty ≥ 90`）或君主。灰色與紅字都會用一句白話說明為什麼（5.5）|
| 流程 | 點招攬 → 顯示成功率（Lv4 以上顯示百分比，Lv3 只顯示「高／中／低」）→ 選要不要送加碼禮 → 確認付招攬禮 → 演出 → 結果 |
| 成功 | 該武將轉入我方家臣，走 5.3 流程 |
| 失敗 | 5.4 |

## 5. 招攬條件

### 5.1 硬條件（五項都要，缺一個就不能擲骰）

| # | 條件 | 說明 |
|---|---|---|
| 1 | 友誼 ≥ 招攬門檻 | N／R **+25**、SR **+35**、SSR **+45**、UR **+55**（`life-encounter-recruit.json`）|
| 2 | 見面次數 ≥ 要求 | N／R **1**、SR **2**、SSR／UR **3**（名將要「三顧」，每次是不同遊歷停留；同一停留只算一次）|
| 3 | 情報等級 ≥ Lv3 | 看得到是誰才能招；顯示等級用「熟人例外」後的等級（友誼 ≥ +30 顯示等級 +1）|
| 4 | `loyalty < 90` | 死忠名單與君主不可招攬，只能結交（`recruitable=false`，白話說明：「主公待我恩重，這事別提。」）|
| 5 | 非「便服」身分 | 交戰中的老朋友私訪不可被招攬（否則變成敵國白給武將，破壞外交）|

另外玩家端要有：本年招攬額度 < **3**（每年最多成功 3 位，防止爆兵）、本季成功招攬 < **1**、家臣數 < 家臣上限（家臣上限看世家與官職，沿用現行規則）。

### 5.2 成功率

```
P(招攬成功) = clamp( 0.15
                   + 友誼 / 200
                   + 主角魅力 / 500
                   + recruitBonusDuel        // 切磋贏 +0.10
                   + giftBonus               // 送喜好禮每件 +0.05，最多 2 件
                   + eventBonus              // 剛被併或失去城池 +0.10
                   + 官職吸引力              // 我方官職高於他現職 +0.05，反之 −0.05
                   − loyalty / 250
                   − 稀有度難度              // N 0 / R 0.03 / SR 0.07 / SSR 0.12 / UR 0.18
                   , 0.05 , 0.85 )
```

| 項目 | 規則 |
|---|---|
| 招攬禮（銀兩，家族私房）| N 20、R 40、SR 80、SSR 160、UR 320 兩；失敗退回 50%，成功不退 |
| 加碼禮 | 從背包（ITM）選最多 2 件，**命中對方 `likes`** 才有 +0.05；送出的物品**收進**該武將（走 `inventory.transfer`），失敗不退（這是禮不是押金）。傳世名器、任務道具、綁定物品不可送 |
| 顯示 | Lv3 顯示「高（≥ 0.6）／中（0.3～0.6）／低（< 0.3）」；Lv4 以上顯示百分比；Lv5 另顯示「對方在意什麼」（`recruitHint`：想要官位、想要名酒、想要被賞識…，由資料欄位 `motive` 給）|
| 亂數 | 伺服器擲骰，`seed＝(playerId, generalId, 季度序號, 嘗試序號)`，客戶端只顯示結果 |

### 5.3 成功之後

1. **STY 劇情演出**：奉茶、遞禮盒、泡泡「我願意」，成功撒花，頭上旗幟換成我方色（5.1 演出）。
2. 武將**離開原勢力、成為我方家臣**（`factionId` 改寫；伺服器權威）。**初始忠誠 60**；友誼保留；`bondPoints` 不歸零。
3. 對他國的影響：該勢力武將數 −1；**與該勢力關係 −10（挖角）**；若是老朋友遊歷者，關係只 −5。他國 AI 在下一次外交推演（`他國AI外交決策模型…`）用到這個變化。
4. 原勢力若是**同盟**：關係 −10 之外，當季不能再互送使者（避免連環挖角）。
5. 加入我方後走既有家臣流程（登用、官職、生活層從 `wanderer` 轉成 `retainer`，以後作息表永遠可見，見 QSCHED-01）。
6. 獎勵（RWD）：首位招攬某勢力武將得名聲 +30（`reward.grant`，每個勢力一次）。

### 5.4 失敗之後

| 項目 | 規則 |
|---|---|
| 友誼 | `enc_recruit_fail` −5（個性 Loyal 加倍 −10）|
| 冷卻 | 該武將 **2 季**內不再來遊歷；再來時見面次數**重算** |
| 招攬禮 | 退回 50% |
| 連續失敗 | 同一位失敗 2 次後，成功率 −0.10（他覺得你很煩），永久 |
| 狀態 | 失敗不影響他的忠誠與勢力關係 |

### 5.5 白話說明句（按鈕灰了給玩家看）

|---|---|
| 情報不夠 | 「還看不清他是誰，先多打聽打聽。」 |
| 友誼不夠 | 「交情還淺，再多聊幾次。」 |
| 次數不夠 | 「這位大人物，要三顧才見誠意。」 |

## 6. 與好感、情報等級的關係

### 6.1 好感（友誼）

| 影響點 | 規則 |
|---|---|
| 出現權重 | 與主角友誼 ×0.5 加進權重（3.2），交情越深越常來 |
| 切磋接受率 | 友誼 /100 |
| 招攬 | 門檻、成功率都吃友誼（5.1、5.2）|
| 顯示 | 友誼 ≥ +30 的熟人，顯示等級 +1（沿用 QSOC-01 5.4）；友誼 ≤ −20 且避開主角者顯示等級 −1 |
| 行為代號 | 一律走 `FriendshipService.add(generalId, delta, reason)`，**新行為要在實作卡時補進 `friendship-action-weights.json`**（見 7.2）|

### 6.2 情報等級

換算沿用 QSOC-01 5.2（`life-intel-levels.json`）。**遊歷者是非自家武將**，適用「Lv0～2 剪影＋?」。

| 等級 | 在街上看到 | 能做什麼 |
|---|---|---|
| Lv0 | 剪影＋「?」，只知道街上來了個外地人 | 只能「搭話」（識破）；識破後該次停留內視為 Lv3 |
| Lv1 | 剪影＋「?」，知道他在大街（大區）| 同上 |
| Lv2 | 剪影＋「?」，知道在哪個店（場景）| 同上 |
| Lv3 | 臉與名字、勢力徽 | 聊天、切磋、招攬（招攬只顯示成功率高／中／低）|
| Lv4 | ＋頭上符號（他在逛什麼）、可偷聽、招攬顯示百分比 | 同上 |
| Lv5 | ＋下一時段預測（他會離開大街或去哪家店）、招攬顯示 `motive` | 同上；可預先到下一家店堵人 |

**識破的規則**：

- 識破只對**那一次停留**有效；離場後再遇見，仍照目前情報等級顯示。
- 識破讓身分公開，但**不揭露**招攬百分比與符號（那些還是看 Lv）。
- 熟人例外：友誼 ≥ +30 者顯示等級 +1，所以老朋友常常 Lv0～2 也能直接認出。

## 7. 與每季 6 次互動額度的關係

沿用 QLIFE-01 6.0／QSOC-01 4.4.1，**不新增額度**。

| 動作 | 扣次數 | 備註 |
|---|---|---|
| 聊天（含識破搭話）| 扣 1 | 識破與這次聊天是同一次，不重複扣 |
| 切磋 | 扣 1 | 點到為止與認真切磋一樣扣 1 |
| 招攬 | 扣 1 | 擲骰一次扣 1；送加碼禮、付招攬禮**不另扣** |
| 偷聽 | 扣 1 | 沿用原規則 |
| 老友相逢（`visitTarget` 演出）、遊歷者主動打招呼、離場時的告別 | **不扣** | 被動事件 |
| 看、點符號、切換場景 | 不扣 | 只看不算 |
| 被友誼季上限擋下 | **不扣次數、不收銀兩、不收招攬禮** | 沿用「被上限擋下不扣」|

額外次數的價格（第 7 次 5 兩、之後每次 +2 兩，上限 15 兩）完全沿用，**招攬禮與額外次數是兩筆獨立扣款**。

## 8. 演出（Q 頭加對話泡泡）

### 8.1 演出一覽

| 階段 | 演出 | 時長 |
|---|---|---|
| 入場 | 從大街左右街口走進；頭上掛「遊」小旗符號（單色簡單圖形，與兵種符號同風格）；剪影者全黑輪廓帶「?」| 走 2.5 秒 |
| 識破 | 搭話後剪影**褪色變臉**（0.4 秒），跳一句自報家門的泡泡 | 0.4 秒＋泡泡 |
| 聊天 | 雙泡泡來回 2～3 句；泡泡 ≤ 18 個中文字、停留 2.5 秒；選項三顆按鈕（≥ 44 像素）| 約 8 秒 |
| 切磋 | 走 QACT-01 單挑模組；開場兩句對嗆泡泡，結束一句勝敗泡泡 | 依單挑 |
| 招攬 | STY 短演出：奉茶（茶碗符號）→ 遞禮盒（禮盒符號飛向對方）→ 思考泡泡「…」→ 結果。成功：撒花＋旗幟換色＋泡泡「好，我跟你走」；失敗：搖頭符號＋泡泡 | 約 6 秒 |
| 離場 | 時段結束走向城門方向，泡泡「後會有期」；有 `visitTarget` 者跟那位家臣互拱手 | 2 秒 |
| 老友相逢 | 兩頭靠近、拱手符號、雙泡泡一人一句 | 4 秒 |

### 8.2 泡泡規格

| 項目 | 規則 |
|---|---|
| 位置 | 頭上，跟 QLIFE-01 偷聽泡泡同層級；離螢幕邊 < 24 像素時自動翻到另一側 |
| 字數 | 單句 ≤ 18 個中文字（英文 ≤ 40 字元），超過截兩行 |

### 8.3 台詞與性別參數

**要求：所有台詞要有說話者性別與玩家稱謂參數。**

| 參數 | 來源 | 用途 |
|---|---|---|
| `{speakerGender}` | 武將資料 `gender`（`m`／`f`）| 選台詞變體（語氣、自稱：「在下」「本姑娘」「妾身」）|
| `{playerGender}` | 玩家主角性別設定（`m`／`f`）| 稱謂 |
| `{callPlayer}` | 查 `life.title.player.<playerGender>`（例：公子／姑娘；依勢力與官職可再細分）| 武將稱呼玩家 |
| `{pronoun}` | 查 `life.pronoun.<speakerGender>`（他／她）| 旁白、提示句指稱武將 |
| `{name}` | 武將名 | 稱呼 |
| `{faction}` | 武將勢力名 | 自報家門 |
| `{scene}` | 場景名 | 提示句 |

key 規則：`life.enc.line.<lineId>.<m|f>`，**缺 `.f` 時退回 `.m`**，再缺就退回中性 `<lineId>`；稱謂**不寫死在台詞裡**，一律用 `{callPlayer}`，避免「說話者 2 × 玩家 2」的組合爆炸。範例（zh-TW）：

```
life.enc.line.introduce.m   = "在下{name}，路過貴地遊歷，{callPlayer}請多指教。"
life.enc.line.introduce.f   = "小女子{name}，遊歷至此，{callPlayer}請多指教。"
life.enc.line.recruit_no_loyal.m = "我家主公待我恩重，{callPlayer}這事就別提了。"
life.enc.line.recruit_no_loyal.f = "我家主公待我恩重，{callPlayer}莫再提起。"
life.enc.hint.recruit_loyal = "{pronoun}忠心耿耿，勸不動的。"
```

台詞同時要依性格（Brave、Loyal、Wise、Playful）、友誼段位（陌生／熟／摯友）、場景分變體，走武將台詞系統的 AI 生成＋中台共用快取＋遊戲端快取，**參數表照台詞系統現有欄位，不另開管線**；冷啟動回退到上述靜態 key。白話寫作：不要文言，使用者給的方向「台詞要白話不文學」。


> 每筆補進既有檔時要帶該檔的 `label` 欄位（走 i18n key）。`enc_old_friends` 是玩家旁觀「老友相逢」的小獎勵，與玩家和遊歷者的友誼不同方向，實作時確認是否需要，不需要就拿掉。

## 12. 驗收

1. 家臣 < 3 的存檔，進市井大街連續看 3 個生活日，一季遊歷者數量達上限 6、不超過 6；家臣 ≥ 8 的存檔不超過 4。
2. 同一 `seed` 重跑，出現名單與順序完全一致（可重現）。
3. 交戰中的勢力（非老朋友）整季零出現；老朋友以「便服」出現，招攬鈕紅字不可點，提示「微服私訪」。
4. 君主、死忠（`loyalty ≥ 90`）、出征中、被擒、學府、未成年武將從不出現在名單。
5. 同一人離場後 2 季內不再出現；失敗招攬後 2 季內不再出現。
6. 情報 Lv0～2：遊歷者是剪影＋?，只有「搭話」可用；搭話後識破，當次停留內可聊天、切磋、招攬（招攬只看高／中／低），離場後恢復剪影。
7. 情報 Lv3 看到臉名；Lv4 看到符號與百分比；Lv5 看到下一時段預測與 `motive`。
8. 友誼 ≥ +30 的老朋友在 Lv2 時顯示成 Lv3（熟人例外）。
9. 每次聊天、切磋、招攬各扣 1 次免費額度；老友相逢、告別、偷聽之外的被動事件不扣；第 7 次起收銀兩；被友誼季上限擋下者不扣次數、不收銀兩、不收招攬禮。
10. 切磋輸贏友誼、心情、名聲正確；他國武將不產生任何傷勢寫入；我方家臣代打落敗才依 QLIFE-01 進傷勢。
11. 招攬：硬條件缺任一項，鈕灰且有白話說明；N 與 UR 各完整走一次成功與失敗，成功後家臣名單、勢力武將數、勢力關係 −10、銀兩、背包全部正確，重新登入後一致。
12. UR 或 SSR 只有「三次不同停留的有效見面」之後才能招攬。
13. 一年內第 4 位招攬被擋，提示「今年已挖三個人」；一季內第 2 位被擋。
14. 所有台詞每則都有 `.m`／`.f` 變體或中性回退；用女性武將 × 男性主角、男性武將 × 女性主角各跑一次，稱呼與代名詞正確；四語系 key 都存在。
15. 低階機畫面最多 2 個泡泡同屏，撒花降級為星星；切到市井大街再切走，遊歷者 Q 頭節點被重用、不增加記憶體。
16. 所有重要數值（名單、見面次數、招攬結果）經 API 寫入，客戶端無直接修改路徑。

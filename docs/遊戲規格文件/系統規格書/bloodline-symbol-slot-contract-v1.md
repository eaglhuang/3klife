# 血脈符號插槽契約 v1（bloodline-symbol-slot-contract-v1）

來源：[角色血脈符號插槽規格補遺 2026-04-02](角色血脈符號插槽規格補遺_2026-04-02.md)
對應卡：BSS-01

本契約把補遺中的第一波固定 slot 列成正式定義，共 8 種。每位核心武將的角色本體都必須承載這些 slot 中的符號，不能只放在 UI 背景或故事文案裡。

## Slot 定義

| # | 層級 | Slot | 說明 |
|---|------|------|------|
| 1 | 主 | 胸甲核 | 角色本體胸甲中央的血脈符號承載點 |
| 2 | 主 | 腰封核 | 角色本體腰封中央的血脈符號承載點 |
| 3 | 副 | 髮飾 / 髮冠 | 頭部裝飾，女武將優先強化 |
| 4 | 副 | 玉佩 / 掛飾 | 腰側或胸前垂掛飾物 |
| 5 | 副 | 肩甲扣件 / 披肩扣件 | 肩部扣件，男武將優先強化 |
| 6 | 延伸 | 武器掛飾 | 武器上的掛飾，男武將優先強化 |
| 7 | 延伸 | 外袍邊紋 / 裙甲紋 | 衣袍或裙甲邊緣的紋樣 |
| 8 | 延伸 | 虎符 / 兵牌 | 與 UI 虎符、兵牌識別同源的符號 |

層級含義：主 slot 必備且最醒目；副 slot 次之；延伸 slot 為補強，用於增加辨識度。

## 落地原則

- 男武將優先強化胸甲核、腰封核、肩甲扣件與武器掛飾。
- 女武將優先強化胸甲核、腰封核、髮飾、玉佩與肩甲扣件，但不能只做成珠寶裝飾。
- 血脈面 / 英靈面可在胸口、腰封、額心、武器脈紋上增加命紋浮現，但不能變成恐怖裂痕。
- 同一角色的 slot 語言需回流到 UI crest、badge、虎符兵牌、特種軍隊識別。

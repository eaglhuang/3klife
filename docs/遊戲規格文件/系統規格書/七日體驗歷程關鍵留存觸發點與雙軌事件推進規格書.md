# 七日體驗歷程關鍵留存觸發點與雙軌事件推進規格書

## 1. 核心定位與設計理念
本規格書定義三國生活（3KLife）新玩家成長與留存引導系統之「前七天體驗歷程（Seven-Day Journey）關鍵觸發點與雙軌推進」規範（對應 WBS `RET-12` 與 `PROG-2-1443`）。
七日歷程作為引導新手玩家度過前 7 天關鍵生命週期、沉澱核心情感記憶與確立長線追求目標之重要骨架，堅持**里程碑驅動、漏登容錯補觸發、雙軌共生**原則：
1. **四大關鍵心流里程碑**：聚焦於「第1天初讀日報、第2天子嗣誕生、第4天大器晚成批語、第7天三代血脈同堂」四大震撼點。
2. **斷登容錯不漏失機制**：觸發點採「天數已達且事實成立」判定，即使玩家中間漏登數日，再次登入時依然順延觸發，不遺失任何成長紀念。
3. **無課與課長雙軌架構**：系統架構原生支援無課大眾軌與課長尊爵軌，確保不同客群均獲得專屬沉浸體驗。

## 2. 歷程天數計算與時間窗模型 (`journeyDayOf`)
系統以新玩家首次登入日期（`firstLoginDay`，UTC+8）為起點計算歷程進度：
- **歷程天數計算公式**：
  $$\Delta \text{Days} = \text{round}\left(\frac{\text{Date}(\text{today}) - \text{Date}(\text{firstLoginDay})}{86,400,000\text{ ms}}\right)$$
  $$\text{JourneyDay} = \begin{cases}
  \Delta \text{Days} + 1, & \text{若 } 0 \le \Delta \text{Days} < 7 \\
  \text{null}, & \text{若 } \Delta \text{Days} \ge 7 \text{（歷程圓滿結束）}
  \end{cases}$$
- 歷程長度固定為 7 天（`SEVEN_DAY_JOURNEY_LENGTH = 7`），第 8 天起自動轉入常態大廳流程。

## 3. 四大關鍵留存觸發點矩陣 (`SEVEN_DAY_TRIGGERS`)
系統維護純資料驅動之觸發點設定表：

| 識別碼 (`id`) | 最早觸發天數 | 依賴遊戲事實 (`fact`) | 適用軌道 (`tracks`) | 沉浸式劇本摘要文案 (`summary`) |
| :--- | :---: | :--- | :--- | :--- |
| **DAY1_DAILY_NEWS** | **Day 1** | `DAILY_NEWS` (首次日報) | 全軌道 | 「三國日報首次生成，今晚的報紙記下了你的第一天。」 |
| **DAY2_CHILD_BORN** | **Day 2** | `CHILD_BORN` (子嗣誕生) | 全軌道 | 「子嗣誕生，天象異變，府中眾人都說這孩子不凡。」 |
| **DAY4_DAQI** | **Day 4** | `DAQI_BORN` (大器晚成) | 全軌道 | 「名士為天才子嗣寫下批語：『此子晚成，必有大器。』」 |
| **DAY7_THREE_GENERATION** | **Day 7** | `THREE_GENERATION` (三代血脈) | 全軌道 | 「血統樹已長出三代，百年世家的藍圖初現。」 |

## 4. 歷程推進與系統日誌生成 (`advanceSevenDayJourney`)
登入時傳入當前事實狀態 `JourneyFacts`（由存檔即時計算）推進歷程：
```typescript
export interface SevenDayJourneyState {
    firstLoginDay: string | null;
    firedIds: string[];          // 已觸發過之事件 ID 清單（全域防重）
}
```

### 4.1 觸發判定演算法
遍歷 `SEVEN_DAY_TRIGGERS`，若同時滿足：
1. 當前天數 $\text{JourneyDay} \ge \text{trigger.day}$。
2. 適用於當前玩家軌道（`trigger.tracks.includes(track)`）。
3. 該觸發點依賴之客觀事實已成立（`facts[trigger.fact] === true`）。
4. 該事件從未觸發過（`!next.firedIds.includes(trigger.id)`）。
滿足條件之觸發點被加入觸發清單，並記入 `firedIds`；呼叫端隨後為每則觸發點生成 `category = 'SYSTEM'`、`priority = 60` 之標準日誌寫入主檔。

## 5. Unity 與 Cocos Creator 概念對照
| 概念維度 | Cocos Creator 實作架構 | Unity 引擎對照架構 |
| :--- | :--- | :--- |
| **體驗歷程總控** | `SevenDayJourney.ts` 純資料結構與過濾函式 | C# `OnboardingJourneyTracker` 系統類別 |
| **里程碑觸發** | 比對事實標籤產生 `fired` 觸發清單 | Timeline Marker 或 Achievement 事件廣播 |
| **日誌持久化** | 寫入 `JournalLog` 並持久化於存檔 | 寫入 EventLog 並由 SaveService 儲存 |

## 6. 驗證條件與測試矩陣 (Acceptance Gate)
1. **TC-SDJ-01 第1天日報初次觸發**：第 1 天登入且日報生成，驗證觸發 `DAY1_DAILY_NEWS` 且加入 `firedIds`。
2. **TC-SDJ-02 跨天漏登順延補發**：第 1 天登入後斷登至第 3 天，第 3 天有子嗣誕生事實，驗證成功補觸發 `DAY2_CHILD_BORN`。
3. **TC-SDJ-03 全域單次防重保護**：已觸發過之事件，再次登入即使事實依然成立，驗證絕不重複觸發。
4. **TC-SDJ-04 第8天歷程圓滿封存**：第 8 天登入時，驗證 `journeyDayOf` 回傳 `null`，不再判定七日歷程。

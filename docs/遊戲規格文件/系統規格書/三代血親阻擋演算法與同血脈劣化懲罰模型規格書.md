# 三代血親阻擋演算法與同血脈劣化懲罰模型規格書

> **模組識別碼**：`BRD-05`  
> **系統歸屬**：血統家族培育（Breeding）血脈倫理與近親懲罰  
> **單一真相來源**：本規格書確立 14 人祖譜 3 代以內共同祖先禁婚阻擋演算法、同 Bloodline_ID 配對精力上限 70% 劣化、負面特質率 +50%、以及 30% 血脈純化補償模型之唯一權威標準。

---

## 一、系統概述與架構原則

三國世家大族極度重視譜牒宗法。為模擬古代優生觀念與避免基因過度純化引發退化，遊戲建立「三代近親絕對禁婚阻擋」與「同血脈（Bloodline_ID）配對劣化懲罰」機制。同時引入「險中求純」的純化補償，兼顧倫理限制與策略博弈。

### Unity / 架構對照
- **圖譜搜尋器**：類似 Unity 中的 `PedigreeGraphValidator`，在 14 人二元樹祖譜節點上進行 BFS/DFS 共同祖先距離檢索。
- **純量懲罰修飾**：子嗣生成時套用乘率修飾器，不影響外部原始父母實體。

## 二、三代近親禁婚檢驗演算法

```typescript
export const INBREEDING_BLOCK_GENERATIONS = 3; // 禁婚世代深度（含父母、祖父母、曾祖父母共 3 代）
```

### 1. 祖譜世代距離定義
- 世代距離 $D = 1$：直系親屬（父女、母子）。
- 世代距離 $D = 2$：二代內共同祖先（親兄妹、姐弟、爺孫）。
- 世代距離 $D = 3$：三代內共同祖先（堂表兄妹、姑侄、叔姪）。

### 2. 禁婚判定狀態機
```typescript
export function isBlockedByInbreeding(
    fatherId: string,
    motherId: string,
    pedigreeSource: PedigreeSource
): { blocked: boolean; distance: number | null } {
    if (fatherId === motherId) {
        return { blocked: true, distance: 0 };
    }
    
    // 查詢雙方在 3 代內的共同祖先最小距離
    const distance = pedigreeSource.commonAncestorDistance(fatherId, motherId, INBREEDING_BLOCK_GENERATIONS);
    
    if (distance !== null && distance <= INBREEDING_BLOCK_GENERATIONS) {
        return { blocked: true, distance };
    }
    
    return { blocked: false, distance: null };
}
```

- 若 `blocked === true`，結緣資格檢驗回傳 `reasons: ['inbreeding']`，強制阻絕發起。

## 三、同 Bloodline_ID 配對劣化與純化模型

若透過特殊旁系（如超過 3 代之同源遠親）進行同家族血脈（`Bloodline_ID` 相同）配對，將啟動「血脈劣化與純化」雙刃劍機制：

```typescript
export const INBREEDING_VITALITY_MULTIPLIER = 0.70;  // 子嗣最大精力上限縮減為 70%
export const INBREEDING_NEGATIVE_TRAIT_BONUS = 0.50; // 負面特質出現機率激增 +50%
export const INBREEDING_PURIFICATION_CHANCE = 0.30;  // 同名因子純化升級機率（30%）
```

### 1. 精力天花板劣化
子嗣繼承出生時，其精力上限強制打折：

$$\text{VitalityMax}_{\text{child}} = \left\lfloor \text{BaseVitalityMax} \times 0.70 \right\rfloor$$

### 2. 負面特質出現率激增
子嗣在 5 歲開獎與後續培育中，負面特質（如病弱、頑劣、短命）之權重乘數增加 $+50\%$（`negativeTraitRateBonus = 0.5`）。

### 3. 血脈純化補償（Kin Purification）
在承受劣化的同時，近親血脈使得優良遺傳因子具備純化可能。子嗣繼承同名因子時，每個因子有 $30\%$ 機率觸發星級提升：

$$\text{Star}_{\text{purified}} = \min(5, \text{Star} + 1)$$

## 四、驗收條件與測試案例 (Test Cases)

- **TC-BRD-09（三代堂表近親強制阻絕）**：
  - 父母雙方共有一名祖父（距離 $D = 2$），資格檢驗回傳 `inbreeding`，無法發起結緣。
- **TC-BRD-10（四代以上遠親合法放行）**：
  - 共同祖先出現在第 4 代（高祖父），超過 3 代禁婚門檻，檢驗回傳 `blocked: false`。
- **TC-BRD-11（精力上限打七折）**：
  - 同血脈子嗣基準精力上限為 100，套用劣化後最終上限精確為 70。
- **TC-BRD-12（純化升星機率檢驗）**：
  - 注入隨機值 0.20（$<0.30$），子嗣身上三星因子成功純化晉升為四星因子。

# 三國日報事件效果復仇代勞自主特訓與團購獎勵結算規格書

## 1. 核心定位與設計理念
本規格書定義三國生活（3KLife）留存與大廳系統之「三國日報（Daily News）事件效果、實質數值回饋與存檔結算閉環」規範（對應 WBS `RET-05` 與 `PROG-2-1169`）。
三國日報絕非純文字裝飾，而是將玩家昨日遭遇之挫折或長線閒置轉化為具體補償與成長動能之實質機制，堅持**痛點補償、數值真實、原子結算、防重複領取**原則：
1. **失利挫折動態反搶（Revenge）**：戰敗或缺糧時，家臣自主帶隊反搶取回 5%~20% 損失資源，撫平負面體驗。
2. **長線閒置自動代勞（Auto Task）**：長時間離線時，自動為玩家完成簡單內政任務並奉上基礎報酬。
3. **日常進度自主特訓（Training）**：破敵大捷時激勵武將自主苦練，五維屬性隨機永久微幅提升。

## 2. 四大日報事件實質效果數值模型

### 2.1 復仇反搶效果 (`REVENGE`)
- **觸發背景**：前 24 小時存在戰敗（`BATTLE_LOSE`）或資源短缺（`RESOURCE_LOW`）。
- **返還比例區間 (`REVENGE_RECOVER_PCT`)**：
  $$\text{RecoverPct} \in [5\%,\, 20\%]$$
- **返還數量計算公式**：
  $$\text{RecoveredAmount} = \max\left(10,\, \left\lfloor \text{LostAmount} \times \frac{\text{RecoverPct}}{100} \right\rfloor\right)$$
  若損失資源未標註數量，安全預設返還 50~200 單位糧草。

### 2.2 家臣代勞效果 (`AUTO_TASK`)
- **觸發背景**：玩家超過 24 小時未上線（`IDLE_LONG`）。
- **實質效益**：系統自動標記完成 1 項大廳初階（`basic`）內政巡視或治安任務，結算發放 100% 基礎任務獎勵（銅錢與名聲）。

### 2.3 自主特訓效果 (`TRAINING`)
- **觸發背景**：前 24 小時取得戰勝（`BATTLE_WIN`）或虎符精煉升星（`TALLY_UPGRADE`）。
- **屬性提升規則**：
  隨機選定 1 位活躍武將，五維能力（武力/智力/統率/政治/魅力）隨機挑選 1 項屬性，增加 **$+1 \sim +3$ 點**。
  $$\text{NewStat} = \min\left(\text{AttributeCap},\, \text{OldStat} + \text{randomInt}(1, 3)\right)$$
  嚴格受當前武將轉生上限（`attributeCap`）約束，不可越界。

### 2.4 商隊團購採辦 (`SHOPPING`)
- **觸發背景**：資源低落或離線休整。
- **實質效益**：大廳雜貨舖當日解鎖 1 筆 5 折或 7 折限時物資，或直接贈予鍛造材料（竹簡 `ITEM_BAMBOO_SLIP` 1~2 件）。

## 3. 獎勵結算事務與防重複發放 (`claimDailyNewsRewards`)
日報獎勵由 `GameSession` 在大廳開啟時進行原子發放：
```typescript
export interface DailyNewsClaimResult {
    claimedResources: Record<string, number>;
    statBoosts: Array<{ generalUid: string; stat: string; delta: number }>;
    completedTasks: string[];
}
```
- **一次性領取防刷**：
  日報在當日首次彈窗展示時，系統即時結算獎勵並記錄 `claimed = true`。重複點開日報介面僅供文字回看，絕不重複觸發資源發放。

## 5. 驗證條件與測試矩陣 (Acceptance Gate)
1. **TC-RET05-01 復仇反搶比例夾回**：損失 1,000 糧草，驗證反搶取回數量精確落在 $[50, 200]$ 區間內。
2. **TC-RET05-02 自主特訓屬性不破上限**：武將屬性已達 1000 上限，驗證特訓提升後數值維持 1000，不發生溢出越界。
3. **TC-RET05-03 一次性領取標記**：發放日報獎勵後再次查詢，驗證不再重複派發資源。
4. **TC-RET05-04 代勞任務獎勵完整交付**：驗證觸發 `AUTO_TASK` 時，對應任務基礎銅錢全額入帳玩家錢包。

# 3KLife 上方谷葫蘆盲端預置火雷引爆與暴雨驟降熄火狀態機規格書

## 1. 系統概述與設計哲學
在險峻山地谷道戰中，利用地形構造實施毀滅性圍困火攻為兵家絕技。三國著名戰例「上方谷火雷陷阱與暴雨天象反轉」（VALLEY-FIRE-TRAP-RAINSTORM01）。
上方谷（葫蘆谷）入口狹窄如瓶頸、內部寬闊卻無後路，為天然絕地。主帥預先於谷內堆積引火桐油、硫磺乾柴與陶罐黑火藥地雷，並以小部隊偽裝糧草誘使敵軍主力大將（如司馬懿父子）引軍入谷。敵軍入彀後，伏兵引爆地雷並推倒滾木堵死谷口，火勢沖天窒息困敵；然而極端高溫引發強烈垂直熱對流，具備微小概率催生突發暴雨將火海澆滅，為被困將領提供唯一一線生機。

## 4. 燃燒缺氧與微氣候對流物理模型

### 4.1 盲端封閉燃燒窒息傷害公式
密閉山谷火攻造成劇烈耗氧：
$$\text{Damage}_{\text{choke}} = \text{BaseBurn} + (\text{HeatCelsius} \times 0.08) + (\text{DurationSec} \times 2.5)$$
- 敵軍無法藉由盾牌或護甲格擋窒息傷害，士氣每 5 秒暴跌 20 點，直至全員陷入瀕死絕望。

### 4.2 熱對流降水反轉動力學
1. **山谷微氣候擾動**：谷底劇烈燃燒形成極強上升熱氣流，在特定濕度條件下凝結成深厚積雨雲。
2. **天命逆轉效應**：若暴雨成功觸發，敵將獲得「天不亡我」命運護體，移動速度暫時提升 $50\%$，突圍生還。

## 5. 單元驗收測試標準
1. **TC-GOURD-01 (誘敵入谷引爆與谷口封閉)**：
   - 模擬敵主將率軍進入葫蘆谷。
   - 驗證觸發引爆後谷口封死，谷內溫度升至 1100℃，轉入 `DETONATE_SEAL_EXIT`。
2. **TC-GOURD-02 (極限驟雨降臨與火勢熄滅)**：
   - 注入暴雨觸發條件，驗證轉入 `EXTREME_HEAT_CONVECTION`。
   - 暴雨 30 秒內火勢歸零，敵帥逃出生天並切換至 `FIRE_QUENCH_ESCAPE`。
3. **TC-GOURD-03 (晴空無雨全殲結算)**：
   - 模擬未觸發對流雨情境，驗證谷內敵軍在缺氧火海中全滅，達成完勝。

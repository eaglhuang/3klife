# 3KLife 上游投毒斷絕水源與圍城飲水枯竭疫病狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 圍城攻防之水源戰略打擊系統（`POISON-WATER-01`）。重現三國歷史中「決河改道、截斷上游、投毒污染水脈」之殘酷圍攻戰術。進攻方在城外水源上游築壩斷流、或投入砒石毒草腐屍，切斷城內軍民飲用水來源，引發大規模脫水、腹瀉疫病，瓦解城防抗性。

## 4. 斷水推演、中毒傷亡與深井搶救公式

### 4.1 截水斷流所需回合與枯竭進程
上游工兵築壩截斷入城水脈所需時間：
$$T_{\text{dam}} = \max\left(1, \left\lceil \frac{\text{RiverFlowVolume}}{100 + \text{UpstreamPioneers} \times 2} \right\rceil\right)$$
- 築壩完成後，城內清潔飲水儲備每回合扣減 $35\%$；
- 儲備降至零後，全城進入 `THIRST_COLLAPSE`，士氣每回合狂跌 25 點，戰鬥力下降 $60\%$。

### 4.2 投毒致病傷亡計算公式
城內飲用被投毒水脈後之傷亡：
$$\text{CasualtiesPerTurn} = \text{TotalCityPopulation} \times \left(0.05 + \frac{\text{ToxicityPotency}}{200}\right) \times \left(1.0 - \frac{\text{DoctorHerbalSkill}}{100}\right)$$
- 若城內有名醫張仲景、華佗或配置「銀針驗毒」，中毒傷亡減免 $85\%$，並及時封閉污染水井。

### 4.3 工兵鑿掘百尺深井成功率
城內工兵在枯竭期間搶挖深井：
$$P_{\text{deep\_well}} = \left(\frac{\text{CivilEngineerSkill} \times 0.6 + \text{GroundwaterGeology}}{100}\right)$$
- 鑿穿深井泉脈後，強制轉入 `DEEP_WELL_RELIEF`，保證每日最低軍民飲水，阻斷乾渴潰敗。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-WATER-01**：在「梅雨」或「暴雨」節氣，天降甘霖，截水與投毒效果強制無效化，城內蓄水池瞬間回滿。
2. **驗收 CASE-WATER-02**：非河流依傍之山城若僅靠天池蓄水，一旦蓄水池遭毒化且無深井，5 回合內全城強制觸發開門降伏。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

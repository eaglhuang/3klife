### 6.6 放置效果預覽規則
- **預覽只顯示真的會生效的效果**。每個州在資料檔有 `effect`，由 GameSession 每季結算（`settleSeason`）讀取；沒有 `effect` 的州，該列小字顯示 `（暫無好處，先放著）`，且不可標示為建議。
- 小字文案由 `effect.type` 對應 i18n 模板填 `{value}`，不寫死於程式。
- 效果型別（暫定三類＋挑戰賽加成，數值為暫定，可只改 JSON）：
  | type | 說明 | i18n 小字模板（zh-TW） |
  |---|---|---|
  | `grain_per_season` | 每季軍糧 +value | `插旗後：每季多收 {value} 軍糧` |
  | `recruit_pct` | 本城徵兵上限 +value% | `插旗後：徵兵上限提高 {value}%` |
  | `fame_per_season` | 每季名聲 +value | `插旗後：每季多 {value} 點名聲` |
  | `tournament_power_pct` | 名將挑戰賽陣容總戰力 +value%（只在 `cupRegion` 命中本季杯賽時生效；與 `cupSpecialPowerMultiplier` 相乘） | `插旗後：{cupName}陣容戰力 +{value}%` |
- 同一州可同時有主效果與一條挑戰賽加成；小字最多兩條，用 `；` 連接，超過兩條截斷。
- 多面旗同型別效果相加，上限 `effectCaps`（資料檔欄位，暫定 grain 100、recruit 15%、fame 30、tournament 6%）。
- 效果自「插旗當季的下一季」起算，避免同季重複刷（教學文案已寫「下一季起」）。

### 6.7 資料欄位（JSON，不寫死於程式）
`assets/resources/data/sandtable-territories.json` 擴充（既有 id／nameKey 不動，新增可選欄位，向下相容；`parseSandtableTerritories` 加驗證）：
```json
{ "id": "jing", "nameKey": "territory.jing.name",
  "effect": { "type": "grain_per_season", "value": 20 },
  "cupBonus": { "cupRegion": "chibi", "type": "tournament_power_pct", "value": 3 } }
```
新增 `assets/resources/data/sandtable-guide.json`：
```json
{ "version": 1, "unlockYearIndex": 2, "minStageAtUnlock": "S1", "firstShowAnchor": "lobby.menu.sandtable",
  "pages": ["sandtable.guide.p1","sandtable.guide.p2","sandtable.guide.p3","sandtable.guide.p4"],
  "effectCaps": { "grain_per_season": 100, "recruit_pct": 15, "fame_per_season": 30, "tournament_power_pct": 6 } }
```
`cupRegion` 與杯賽對應（暫定）：赤壁盃=`chibi`（荊州、揚州）、官渡盃=`guandu`（兗州、冀州）、長坂盃=`changban`（荊州）、夷陵盃=`yiling`（益州、荊州）；放在 `data/sandtable-guide.json` 的 `cupRegions`，杯名來源 `TOURNAMENT_CUPS`。
13 州初始效果表（暫定）：司隸 fame 3、豫州 grain 20、兗州 grain 20＋官渡 +3、徐州 grain 20、青州 recruit 3、冀州 recruit 3＋官渡 +3、幽州 recruit 4、并州 recruit 3、涼州 recruit 4、益州 grain 25＋夷陵 +3、荊州 grain 20＋赤壁／長坂 +3、揚州 fame 3＋赤壁 +3、交州 fame 2。

### 6.8 UI 排版（錨點／相對比例，保留直式彈性）
- 彈窗卡 `DialogCard` 用錨點置中，寬高取畫面比例（橫式約 0.62W×0.78H；直式改 0.92W×0.80H，由 layout 檔的 `orientation` 區段切換，不在 ts 寫死像素）。
- `ScrollView` 的列高 = 卡內容高 / 6.5（露半列提示可捲動），每列內兩行文字用 `Layout vertical`，第二行字級 = 第一行 0.75 倍，不寫死 px。
- 右側 `SeasonCard`：橫式靠右欄（寬 0.22W）；直式移到列表上方橫條（高 0.12H），同一份節點，只改錨點。
- 教學彈窗 `SandtableGuideCard` 錨點置中，台詞區 0.8 卡寬，翻頁鈕置底。
- 13 列固定上限（`SANDTABLE_PICKER_ROWS`）改為由 `sandtableTerritories().length` 動態產生。

# 3KLife 主帥秘不發喪雕木偶推車臨陣反退多疑追兵狀態機規格書

## 1. 系統概述與設計哲學
在遠征敵國期間，若三軍統帥（如諸葛亮於五丈原）因病或創傷突然逝世，大軍極易在撤退途中被敵方精銳追兵全殲。三國頂級心理逆擊防禦機關「秘不發喪與木偶退敵」（EFFIGY-WOODEN-DECEPTION-RETREAT01）。
主帥逝世後，副將秘不發喪，嚴密封鎖死訊以防軍心動搖；同時工匠依主將生前儀容連夜雕刻木偶，披鶴氅、戴綸巾、手執羽扇，端坐於中軍四輪車上。當敵方多疑名將（如司馬懿）率大軍全力追擊時，撤退軍突然反旗鳴金、推車回頭逆向迎敵。敵帥誤判「亮尚在世，此乃誘敵中伏之計」，驚駭之下勒馬狼狽狂奔奔逃數十里，為撤退大軍贏得全師安然回國之寶貴時間。

## 4. 心理博弈與多疑性格心理模型

### 4.1 頂級名將心理互克公式
敵方主帥智謀越高、心思越縝密，反而越容易受制於假象：
$$P_{\text{retreat}} = \frac{\text{EnemyParanoia} \times \text{DeceptionQuality}}{100} \times (1.0 - \text{RashnessFactor})$$
- 司馬懿生平極度忌憚諸葛亮神機妙算，其多疑性格係數高達 $95$，在此博弈模型下觸發中伏恐慌撤退率為 $98\%$。

### 4.2 全軍安然撤退保障
1. **士氣鎖定保全**：全軍在進入本土前不知主帥死訊，撤退速度與陣型維持常態，無自亂陣腳踩踏現象。
2. **追兵心理陰影**：「死諸葛走生仲達」傳聞擴散，敵全軍士氣在接下來一個月內承受 $-20\%$ 威懾減益。

## 5. 單元驗收測試標準
1. **TC-EFFIGY-01 (秘不發喪與雕木偶迎敵閉環)**：
   - 模擬主帥陣亡，觸發死訊封鎖與木偶雕刻。
   - 驗證 4 小時內木偶完成，敵追兵迫近時順利切換至 `CHARIOT_COUNTER_ADVANCE`。
2. **TC-EFFIGY-02 (多疑敵帥嚇退與狂奔五十里判定)**：
   - 設定追擊敵帥多疑值為 90。
   - 驗證判定觸發 `PARANOID_RETREAT_TRIGGER`，敵軍全線後撤 50 里，追擊中斷。
3. **TC-EFFIGY-03 (魯莽敵將識破死戰兜底機制)**：
   - 設定敵將多疑值低於 75（莽夫性格），驗證系統正確轉入 `RUSE_EXPOSED_CLASH` 並觸發斷後掩護戰。

# 3KLife 二十四節氣與四時農桑耕作收穫氣候連動規格書

## 1. 模組概述與核心定位
本模組為 3KLife 宏觀沙盤之天時曆法引擎（`CALENDAR-SOLAR-01`），將一年四季十二個月細分為傳統二十四節氣。每個節氣直接連動全圖氣候偏好（降雨、乾旱、風力、霜凍）、城池農桑產出週期（播種、灌溉、秋收、入庫）以及屯田兵糧消耗效率，徹底體現「順天應時，農戰合一」之三國戰略縱深。

---

## 2. 二十四節氣時序與農桑狀態機

### 2.1 節氣時序拓撲
一年 12 月共分為 24 個節氣週期，每節氣持續 15 日（遊戲內每回合即半個月 / 1 個節氣）：

```
[春季: 孟春/仲春/季春]
立春(1月上) ──> 雨水(1月下) ──> 驚蟄(2月上:春播) ──> 春分(2月下) ──> 清明(3月上:整田) ──> 穀雨(3月下)
      │
[夏季: 孟夏/仲夏/季夏]
立夏(4月上:夏耘) ──> 小滿(4月下) ──> 芒種(5月上:搶種) ──> 夏至(5月下) ──> 小暑(6月上:防旱) ──> 大暑(6月下:灌溉)
      │
[秋季: 孟秋/仲秋/季秋]
立秋(7月上:早收) ──> 處暑(7月下) ──> 白露(8月上:監割) ──> 秋分(8月下:秋收) ──> 寒露(9月上:入庫) ──> 霜降(9月下:冬整)
      │
[冬季: 孟冬/仲冬/季冬]
立冬(10月上:休耕) ──> 小雪(10月下) ──> 大雪(11月上:封凍) ──> 冬至(11月下:儲冰) ──> 小寒(12月上:冬防) ──> 大寒(12月下:歲暮)
```

### 2.2 農桑階段狀態機（`AgriculturalStage`）
```
  [休耕蓄力 DORMANT]
         │ (驚蟄觸發春播)
         ▼
  [春耕播種 SOWING] ──(春分未足水)──> [播種延誤 DELAYED]
         │ (立夏轉夏耘)
         ▼
  [夏耘護苗 WEEDING] ──(小暑遇旱)───> [乾旱萎縮 DROUGHT_STUNT]
         │ (白露成熟)
         ▼
  [秋收搶割 HARVESTING] ──(秋分遇澇)──> [爛穗減產 WATERLOG_LOSS]
         │ (寒露入庫)
         ▼
  [冬藏入庫 GRANARY_STORE]
```

## 4. 計算模型與結算公式

### 4.1 驚蟄春播與夏至長勢增益
農作物長勢隨各節氣之適時勞作與水利評定遞增：
$$\Delta \text{CropHealth} = (\text{WorkEffort} \times 0.4 + \text{Irrigation} \times 0.3 + \text{WeatherFit} \times 0.3) \times \text{TermCoeff}$$

### 4.2 秋分收穫與糧秣入庫公式
在「秋分」至「寒露」期間進行年度收穫結算：
$$\text{HarvestYield} = \text{BaseFarmland} \times \text{CropHealth} \times \left(1.0 + \frac{\text{SoilFertility}}{200}\right) \times \text{WeatherLossCoeff}$$
- 若遭遇秋雨過盛（爛穗），$\text{WeatherLossCoeff} = 0.6 \sim 0.8$；
- 若風調雨順且內政官有「農政」特技，$\text{WeatherLossCoeff} = 1.25$（大豐收）。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-SOLAR-01**：進入「驚蟄」節氣時，系統自動觸發春耕指派事件，若玩家城池未配置屯田督糧官，作物初始健康度懲罰 -20。
2. **驗收 CASE-SOLAR-02**：在「秋分」完成結算後，農作物狀態機平滑過渡至「冬藏入庫」，冬三月糧秣產出降為零，但防寒維護費啟用。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，純文本不含冗餘歷史紀錄。

# 五大UI入口共用血脈徽記元件BloodlineCrestWidget與渲染契約規格書

> **所屬模組**：`3.7 UI 介面與視覺工程 (BVC-03 / BVC-02)`  
> **單一真相來源**：定義共用血脈徽記元件（`BloodlineCrestWidget`）、跨五大 UI 入口（角色頁、血統樹、血脈卡、英靈虎符、特種軍隊）之標準尺寸階梯、合批渲染協議與動態換裝契約。

---

## 1. 五大 UI 入口共用架構與職責劃分

為徹底杜絕各面板私自製作直白獸首或切版割裂之痛點，全專案血脈徽記收攏為單一通用視覺組件（`BloodlineCrestWidget`）：

```
+-------------------------------------------------------------------------+
|                  [共用血脈徽記組件: BloodlineCrestWidget]                |
|                  - 依據 bloodline-sigil-and-beast-contract-v1           |
|                  - 支援三層金石拓印: 底板 + 錯金金石紋樣 + 靈光外框     |
+-------------------------------------------------------------------------+
                                    |
     +--------------+---------------+--------------+--------------+
     |              |               |              |              |
     v              v               v              v              v
[1.日常人物頁]  [2.十四人祖譜]  [3.血脈卡槽位]  [4.英靈虎符]  [5.特種兵軍旗]
- 命頁頂部徽記  - 14 祖輩節點   - 鑲嵌插槽      - 符面中央金印 - 軍隊戰旗圖騰
- 尺寸: 64x64   - 尺寸: 32x32   - 尺寸: 48x48   - 尺寸: 56x56  - 尺寸: 40x40
```

---

## 2. 標準尺寸階梯與外觀樣式規範

`BloodlineCrestWidget` 支援四種標準尺寸階梯，各入口依規格指定：

| 尺寸階梯 | 像素大小 | 適用場景 | 渲染層次 | 特效支援 |
|:---:|:---:|:---|:---|:---:|
| **SIZE_XL** | `64x64 px` | 日常人物頁 Overview、血脈覺醒大彈窗 | 底板 + 錯金 + 外框 + 稀有度環 | 支援覺醒呼吸光 |
| **SIZE_LG** | `56x56 px` | 英靈卡詳情、虎符中央神獸金印 | 底板 + 錯金 + 外框 | 支援暗金微光 |
| **SIZE_MD** | `48x48 px` | 血脈槽位插卡、特種軍隊軍旗 | 底板 + 錯金 | 靜態展示 |
| **SIZE_SM** | `32x32 px` | 十四人血統樹（Gen2/Gen3 節點） | 純錯金向量線條（低 DrawCall 合批） | 無特效 (極致合批) |

---

## 3. 圖集打包與 DrawCall 合批優化協議

1. **圖集單一化 (Atlas Packing)**：
   - 所有六大靈獸（玄武/朱雀/麒麟/白虎/青龍/應龍）之青銅紋樣切片收錄於單一 SpriteAtlas：
     `assets/resources/sprites/ui_families/crests/crest_family.pac`。
   - 確保在十四人祖譜展開或特種部隊清單渲染時，無論呈現何種靈獸因子，均維持 **1 個 DrawCall**。
2. **三層結點動態配置**：
   ```typescript
   export interface CrestWidgetConfig {
     beastId: "AZURE_DRAGON" | "WHITE_TIGER" | "VERMILION_BIRD" | "BLACK_TORTOISE" | "KIRIN" | "WINGED_DRAGON";
     sizeTier: "SIZE_XL" | "SIZE_LG" | "SIZE_MD" | "SIZE_SM";
     unlocked: boolean;            // 未解鎖自動套用 30% 灰階石刻材質
     showAuraGlow?: boolean;       // 是否開啟外圈微透靈光
   }
   ```

## 4. 未解鎖與隱私遮罩渲染

當子嗣處於剪影期（Level 0，`doc_spec_0643`）或該靈獸命格尚未覺醒時：
- **視覺降級**：組件自動隱藏中層錯金紋樣，底板套用未解鎖玄鐵石刻材質（`crest_plate_locked.png`），中央覆蓋半透明青銅問號或無字符印。
- **無資料保護**：禁止在節點掛載任何具體靈獸之 SpriteFrame，防止客戶端記憶體被第三方外掛偷看提前劇透。

# 五大地形格特殊效果與沙漠精力消耗數值規格書

## 1. 核心定位與設計哲學
本規格書定義《三國人生》五大核心戰場地貌（平原、山地、林地、水域、沙漠）之特殊環境規則與主將精力侵蝕機制（WBS `APT-05`，代碼落位於 `DesertVitality.ts`、`BattleTileEffectPhase.ts` 與 `BattleAptitude.ts`）。
戰場地形不僅作為阻擋與路徑規劃圖層，更是決定軍隊攻防轉換、移動設值與戰略資源損耗的動態系統。

                     └────────────────────┬────────────────────┘
          ┌─────────────────┬─────────────┴─────────────┬─────────────────┐
          ▼                 ▼                           ▼                 ▼
     【水域河川】       【林地茂林】                【沙漠炎地】      【平原/山地】
   • S級: 解鎖水戰合攻  • S級: 迴避 +30%            • 每回合精力扣除  • 步兵/騎兵固有加成

## 2. 水域（River/Water）專屬適性規則

水域地形具有嚴苛之自然阻隔特性，部隊於水域格上交戰時直接套用專屬覆蓋規則，不與通用 D 級懲罰重複疊加：

### 2.1 水域 S 級：水戰合攻特權（Naval Combined Attack）
- **發動條件**：部隊站在水域格上，且其水域適性等級為 **`S`** 級（或持有 `naval-combined-attack` 因子，兩者取聯集）。
- **特權效果**：突破常規合攻限制，解鎖於河流地形上執行合攻戰法與夾擊打擊之能力。非 S 級部隊且無水戰因子者，即便處於夾擊位置亦嚴禁發動合攻。
- **地形硬閘門**：合攻判定必須確認實體單位實際座標位於水域格；若移出至平原或山地則立即喪失水戰合攻判定。

### 2.2 水域 D 級：專屬覆蓋規則（取代通用 D 表）
部隊水域適性為 **`D`** 級且停留於水域格時，全面啟動保護性專屬覆蓋，**不再扣除防禦與命中**：
1. **攻擊力減半**：$\text{AttackMultiplier} = 0.50$（攻擊輸出直接腰斬）。
2. **防禦力與命中不扣**：$\text{DefenseMultiplier} = 1.0$、$\text{AccuracyDelta} = 0$。
3. **移動力強制歸 1**：$\text{MoveSetTo} = 1$。
   - 不論基礎移動力為 3 或 5，亦不論兵種加減修正，最終可用移動力強制鎖定為 1 格。
   - 例外防護：若部隊處於「定身/麻痺」狀態（基礎移動力為 0 格），則維持 0 格不動，不得因設值而解除定身。

## 3. 沙漠（Desert）精力消耗與減速模型

沙漠環境極度惡劣，會對交戰陣營產生持續性體力枯竭效應，於大回合推進之 `BattleTileEffectPhase`（第 5 階段）進行結算：

### 3.1 沙漠精力侵蝕公式
當陣營所屬之存活部隊停留於沙漠地形格時，每回合對該陣營主將（Commander）扣除精力值（Vitality）：
$$\text{BaseDrain} = 4 \quad (\text{DESERT\_BASE\_VITALITY\_DRAIN})$$
$$\text{Drain}_{\text{unit}} = \begin{cases} \lfloor \text{BaseDrain} \times 0.5 \rfloor = 2, & \text{沙漠適性 } \mathbf{S} \text{ 級} \\ \text{BaseDrain} = 4, & \text{沙漠適性 } \mathbf{A / B / C / D} \text{ 級} \end{cases}$$

### 3.2 陣營結算與防護四守則
1. **同陣營取最大值（MAX 取代累加）**：
   $$\text{TotalDrain}_{\text{faction}} = \max_{u \in \text{AliveUnits}} (\text{Drain}_{\text{unit}})$$
   同陣營縱有 5 支先鋒部隊身陷沙漠，單回合亦僅扣除一次最大值（最多 4 點），**嚴格禁止線性疊加扣除**。
2. **陣營隔離保護**：敵方部隊處於沙漠格時，僅扣除敵方主將精力，絕不扣除我方主將精力。
3. **陣亡部隊豁免**：已死亡（`isDead = true`）之單位殘骸不觸發精力侵蝕。
4. **零值保底不穿透**：精力不足時最多扣減至 0 點，嚴禁出現負數精力值。

### 3.3 沙漠 D 級移動減速
部隊沙漠適性為 **`D`** 級時，行軍移動力扣減 **2 格**（$\text{moveDelta} = -2$），遵循通用 D 表懲罰，且最低保留 1 格行軍保底。

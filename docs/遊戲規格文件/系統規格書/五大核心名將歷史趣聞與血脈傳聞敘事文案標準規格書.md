# 五大核心名將歷史趣聞與血脈傳聞敘事文案標準規格書

> **所屬模組**：`3.5 血統、家族與培育傳承 (STORY-03 / STORY-01)`  
> **單一真相來源**：針對五大核心名將（趙雲、甄姬、孫尚香、關羽、諸葛亮）確立零「???」標準，制定二層敘事結構（歷史趣聞＋血脈傳聞）與六格故事條（`storyStripCells`）文本契約。

---

## 1. 敘事結構與品質標準

所有核心名將必須滿足嚴格的敘事分層架構，嚴禁任何佔位符或空字串：
1. **歷史趣聞 (`historicalAnecdote`)**：聚焦正史或演義著名典故，強調人物性格特質（80~110 字）。
2. **血脈傳聞 (`bloodlineRumor`)**：結合神話靈獸、祖靈命篆與戰魂，作為子嗣傳承伏筆（80~110 字）。
3. **六格故事條 (`storyStripCells`)**：
   - 格 1 (`origin`)：鄉土出生與微末年少。
   - 格 2 (`faction`)：亂世抉擇與陣營歸屬。
   - 格 3 (`role`)：立功受封與天下顯名。
   - 格 4 (`awakening`)：命運介入與生死頓悟（重大轉折）。
   - 格 5 (`bloodline`)：靈獸共鳴與戰魂外顯。
   - 格 6 (`future`)：世代守護與傳承誓約。

---

## 2. 五大核心名將標準文本契約

### 2.1 趙雲（常山真定 · 龍膽白袍）
- **historicalAnecdote**:「當陽長坂百萬軍中，單騎救幼主，銀槍起處血染征袍。操歎曰：真虎將也！身經百戰無一敗績，世稱常勝將軍。」
- **bloodlineRumor**:「相傳趙氏先祖曾得應龍金鱗，子龍生而胸懷天龍戰魂。凡其血脈嫡傳，遇危難時銀槍出鞘隱隱作龍吟之響。」
- **storyStripCells**:
  1. `origin`:「真定少年，騎射無雙，誓隨仁義之師。」
  2. `faction`:「初依公孫瓚，終識劉玄德，託付生死一生不渝。」
  3. `role`:「長坂單騎救主，加封翊軍將軍。」
  4. `awakening`:「血戰長坂坡，生死一線之際見應龍護體。」
  5. `bloodline`:「龍膽戰魂覺醒，周身如銀鎧天覆，矢石不侵。」
  6. `future`:「子孫受其血胤，皆心存赤誠與忠勇。」

### 2.2 甄姬（中山無極 · 洛神仙韻）
- **historicalAnecdote**:「容姿秀麗，才思敏捷，幼知讓糧濟民。曹丕見而傾心。後人作《洛神賦》，盛讚翩若驚鴻、婉若游龍之仙姿。」
- **bloodlineRumor**:「中山甄氏傳為洛水神女後裔，甄氏血脈若逢明月之夜，常有靈波環珮之聲。其女嗣容姿端雅且通曉水行術算。」
- **storyStripCells**:
  1. `origin`:「世族千金，九歲能詩，博涉群書好行善舉。」
  2. `faction`:「初歸袁熙，鄴城破後入魏宮，榮寵冠於六宮。」
  3. `role`:「母儀天下，以德安內，稱文昭甄皇后。」
  4. `awakening`:「於洛水之濱獨坐，澈悟神女遺澤。」
  5. `bloodline`:「洛水凌波血脈初成，步步生蓮滌世間戾氣。」
  6. `future`:「後代女子傳承神秀天賦，於文壇皆為翹楚。」

### 2.3 孫尚香（吳郡富春 · 江東梟姬）
- **historicalAnecdote**:「孫夫人志勝男兒，侍婢百人執刀侍立，常與將士縱馬獵獸。跨江結姻之際，赤壁烽火中展巾幗英豪之烈性。」
- **bloodlineRumor**:「孫氏乃兵聖之後，尚香更承朱雀離火真靈。弓弦鳴動如鳳凰啼血，其後人弓馬之術天授，性烈如火不受拘束。」
- **storyStripCells**:
  1. `origin`:「生於江東將門，自幼弓馬嫻熟，不愛紅妝愛武裝。」
  2. `faction`:「兄長作伐聯姻劉備，身在蜀漢心繫江東。」
  3. `role`:「披甲執弓隨軍征討，稱江東第一烈婦。」
  4. `awakening`:「臨大江遇風浪翻覆，引離火弓引動江東潮鳴。」
  5. `bloodline`:「朱雀真靈灌頂，雙弓連珠可落九天雲外飛鴻。」
  6. `future`:「傳承者性烈如火，於沙場征戰百折不屈。」

### 2.4 關羽（河東解良 · 義絕青龍）
- **historicalAnecdote**:「溫酒斬華雄，單刀赴會，威震華夏。雖困曹營不忘桃園舊誓，挂印封金千里走單騎。春秋大義世奉為武聖。」
- **bloodlineRumor**:「解良鹽池赤龍轉世，三縷美髯如蒼龍吐信。關氏血脈重義薄雲天，凡其後人純陽罡氣護體，刀法有劈山破浪之威。」
- **storyStripCells**:
  1. `origin`:「解良亡命，豪俠仗義，結識玄德翼德。」
  2. `faction`:「桃園結義共扶漢室，誓同生死披荊斬棘。」
  3. `role`:「斬顏良水淹七軍，封前將軍漢壽亭侯。」
  4. `awakening`:「刮骨療毒之夜，劇痛中見青龍傲立蒼穹。」
  5. `bloodline`:「武聖真魂凝聚，青龍偃月刀芒化為百丈罡氣。」
  6. `future`:「血脈代代忠勇蓋世，廟堂江湖皆尊為先範。」

### 2.5 諸葛亮（瑯琊陽都 · 臥龍奇策）
- **historicalAnecdote**:「隆中高臥，一策定天下三分。草船借箭、舌戰群儒。出師表字字血淚，鞠躬盡瘁死而後已。」
- **bloodlineRumor**:「瑯琊諸葛承伏羲奇門之秘，孔明出山夜有紫微星墜。諸葛血脈通曉天象陰陽，後人研習奇門陣法事半功倍。」
- **storyStripCells**:
  1. `origin`:「躬耕南陽，抱膝長吟，好為梁父吟待天下有識。」
  2. `faction`:「三顧茅廬定三分大計，出山輔佐先帝定蜀漢。」
  3. `role`:「官拜丞相，撫百姓示儀軌，七擒孟獲平南中。」
  4. `awakening`:「五丈原點七星天燈，參悟星宿興衰生死之道。」
  5. `bloodline`:「臥龍玄機血脈顯化，羽扇輕搖逆轉風雷之勢。」
  6. `future`:「傳世子孫承神算奇才，世代為經天緯地之柱石。」

# 3KLife 五格命運故事帶長卷圖資產生產與慢速橫移動態契約規格書

> **規格代碼**：SPEC-ART-BML10

> **文件版本**：v1.0.0 (單一真相來源，無補丁整併版)

## 1. 核心宗旨與設計哲學

命運故事帶（Fate Story Strip）為呈現名將一生波瀾壯闊之沉浸式水墨長卷。位於命鏡介面背景層，以 5 格連續畫卷敘述宿命歷程。為杜絕生硬分格與粗暴動效，本規格書規範長卷之**五格敘事節點**、**美術生產規格**、**血脈徽記一致性審核**與**超慢速無感橫移（Subtle Pan）動態契約**。

---

## 2. 五格敘事長卷結構與生產規範

### 2.1 五格敘事節點定性

長卷由左至右橫向展開，以淡墨雲煙作為天然銜接過渡：
1. **第一格：宿命初現 (The Awakening)**：少年家世、奇人授書或異象降生。
2. **第二格：初出茅廬 (The Debut)**：初露鋒芒、起兵結義或投效明主。
3. **第三格：命途轉折 (The Crucible)**：人生巨變、生死試煉或血統逆境。
4. **第四格：巔峰對決 (The Zenith)**：威震華夏、力挽狂瀾之歷史高光時刻。
5. **第五格：終局傳承 (The Legacy)**：開創宗族、封侯拜相或血脈不滅之意象。

### 2.2 資產規格與命紋一致性 (BMV3-06)

| 規格維度 | 標準數值與約束 | 說明 |
|---|---|---|
| **畫布尺寸** | $2560\times 512\text{px}$ | 橫向 5 等分（每格約 $512\text{px}$），上下各留 $32\text{px}$ 水墨虛化邊界。 |
| **色彩體系** | 古籍淡墨白描 + 局部青綠/赭石淡彩 | 背景色階鎖定 `#1A1816` 至 `#2B2620`，嚴禁刺眼純白。 |
| **銜接規範** | 漢風流雲墨韻遮罩 | 格與格之間嚴禁硬切直線分界，必須以流雲墨痕重疊融合。 |
| **徽記一致性** | 依循 `doc_spec_0671` 之 Crest | 畫卷內出現之旗幟、佩玉、長槍刃文，必須嚴格採用該將之血脈徽記。 |

## 3. 慢速橫移動態契約 (Subtle Drift Animation)

為避免動態背景干擾前景文字閱讀，位移必須維持在視覺「無感察覺」之極致平滑狀態：

```typescript
export interface FateStripMotionContract {
  stripNodeName: 'fate_story_strip_content';
  scrollMode: 'UV_SHADER_OFFSET' | 'TRANSFORM_TWEEN';
  driftSpeedPxPerSec: 0.5;            // 每秒位移 0.5 像素 (無感漂移)
  maxDriftDistancePx: 128.0;          // 單向最大移動 128 像素
  driftPeriodSeconds: 512.0;          // 單次往返週期 512 秒
  easing: 'sineInOut';                // 極度平滑之正弦往返
  pauseOnTouch: true;                 // 玩家手動滑動檢視時自動暫停漂移
}
```

- **效能約束**：優先採用 Material Shader 之 `uvOffset.x` 累加，嚴禁在 Update 函式中頻繁變更頂點座標。GPU 渲染開銷 $\le 0.05\text{ms}$。

## 4. 驗收測試案例 (Test Cases)

- **TC-BML-10-01【長卷平移平滑度檢驗】**：以 60fps 監控 5 分鐘，畫卷漂移過程中無任何抖動（Jitter）、掉幀或撕裂現象。
- **TC-BML-10-02【前景閱讀無干擾測試】**：盲測 10 位測試者閱讀命鏡前景說明文，無一人因背景極慢橫移產生暈眩或分心。
- **TC-BML-10-03【徽記圖騰一致性檢驗】**：檢查關羽之長卷第四格「水淹七軍」，其先鋒戰旗印鑑完全符合青龍玄武雙象血脈徽記。

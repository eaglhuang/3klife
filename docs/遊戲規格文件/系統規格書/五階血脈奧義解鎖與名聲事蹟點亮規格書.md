# 五階血脈奧義解鎖與名聲事蹟點亮規格書

> **責任邊界**：本檔為血脈奧義階級狀態機（BloodlineTransmissionUltimate）、升星分流與事蹟點亮的單一真相來源。
> **關聯 WBS**：GDUI-07（五階血脈奧義邏輯）、GDUI-08（譜牒印記升星分流）、GEN-08（因子覺醒）。
> **整併裁決**：確立 Stage_Cap（升星開上限）與 Stage_Current（事蹟點亮階）雙軌制，定案子嗣譜牒印記升星管道。

---

## §1. 雙軌狀態架構 (Cap & Current Separation)

血脈傳承奧義嚴格區分「階級上限」與「當前實效」：

1. **`Stage_Cap` (階級上限，1~5 階)**：
   - 僅由**「武將升星 (Star Up)」**擴展。初始為 1 階，每提升 1 星增加 1 階，最高 5 階。
2. **`Stage_Current` (當前階級，0~5 階)**：
   - 需滿足特定的**「家族名聲門檻」**並達成**「歷史事蹟成就」**方可手動點亮。
   - 約束邊界：$\text{Stage\_Current} \le \text{Stage\_Cap}$。若 Cap 未開，即使名聲達標亦無法點亮。

## §3. 升星分流與素材消耗協議 (GDUI-08 裁決)

武將升星為提高 `Stage_Cap` 的唯一途徑。為保護非抽卡產出之子嗣傳承價值，實施素材分流：

```
[武將升星請求] ─── 是否為史實名將?
      │
      ├──> [是: 史實名將] ──> 消耗: 同名武將卡 或 專屬名將魂石
      │
      └──> [否: 世代子嗣] ──> 消耗: 「譜牒印記 (Lineage_Seal)」 (祠堂功勳兌換)
```

1. **史實名將升星**：
   - ★1→★2：消耗同名卡 1 張或 20 魂石。
   - ★2→★3：消耗同名卡 2 張或 50 魂石。
   - ★3→★4：消耗同名卡 3 張或 100 魂石。
   - ★4→★5：消耗同名卡 5 張或 200 魂石。
2. **世代子嗣升星**：
   - 消耗宗族祠堂祭祀產出的**「譜牒印記（Lineage_Seal）」**：
   - ★1→★2：消耗 1 枚譜牒印記。
   - ★2→★3：消耗 2 枚譜牒印記。
   - ★3→★4：消耗 4 枚譜牒印記。
   - ★4→★5：消耗 8 枚譜牒印記。
   - 徹底杜絕培育子嗣無法升星的斷層，使世代經營回饋於核心戰力！

## §4. UI 符印節點點亮呈現規範

在武將人物介面「技 / Skills」分頁中，以五邊形命盤節點呈現：

```
      [V 化神]
     /        \
[IV 附魔]    [I 啟蒙]
   |            |
[III 昇華]──[II 威能]
```

- **已點亮 (`●`)**：金色或藍色火焰粒子脈動，點擊可查看奧義詳細數值。
- **已開上限未點亮 (`◐`)**：白金外框呼吸閃爍，提示「名聲或事蹟未達標」，點擊導航至達成路徑。
- **未開上限 (`○`)**：石化灰色鎖孔，提示「需先將武將提升至 ★N 星解鎖」。

# 伺服器同步限流速率429與請求封包5MB超限413防護規格書

> **所屬模組**：`3.6 數值、架構與底層支援 (SYNC-05 / SYNC-02)`  
> **單一真相來源**：定義資料同步 API 之流量防護規則、滑動窗口速率限制演算法（每分鐘 10 次）、5MB 壓縮封包體積檢驗，以及 HTTP 429 / 413 錯誤處置狀態機。

---

## 1. 流量控制與安全防護目標

為防止惡意刷請求、網路風暴及客戶端離線佇列積壓過大導致伺服端記憶體耗盡，同步中樞實施兩道硬性安全防護：
1. **頻率上限（Rate Limit）**：單一帳號（`playerId`）或單一裝置（`deviceId`）每 60 秒上限 10 次同步請求。
2. **大小上限（Payload Limit）**：請求 Body 之 Gzip 壓縮二進位體積上限為 5MB（解壓縮後上限 25MB）。

---

## 2. 滑動窗口速率限制演算與 429 回應

### 2.1 滑動窗口計數演算法 (Sliding Window Counter)
伺服端以 60 秒為一週期，計算當前時間點前推 60 秒內之請求總數：
$$\text{CurrentRate} = \text{RequestsInCurrentBucket} + \text{RequestsInPreviousBucket} \times (1 - \text{OverlapRatio})$$
- 當 $\text{CurrentRate} > 10$ 時，伺服端立即拒絕處理後續請求，並回傳 HTTP 429：
  ```http
  HTTP/1.1 429 Too Many Requests
  Content-Type: application/json
  Retry-After: 35

  {
    "errorCode": "E008",
    "message": "請求過於頻繁，請稍後再試。",
    "retryAfterSeconds": 35
  }
  ```

### 2.2 客戶端 429 退避狀態機
1. **暫停同步**：客戶端 `SyncManager` 接收到 E008 錯誤時，立即將狀態切換為 `RATE_LIMIT_COOLDOWN`。
2. **定時喚醒**：依據回應之 `Retry-After` 數值啟動本地計時器（若標頭缺失則預設退避 60 秒），冷卻期間所有內部產生的同步事件僅寫入本地離線佇列（`offlineActionQueue`），不發出網路請求。
3. **冷卻解除**：計時結束後，自動將狀態還原為 `READY`，並發起一次合併後的批次同步。

---

## 3. 5MB 封包大小檢驗與 413 拆分處置

### 3.1 伺服端 413 判定規則
伺服端在接受請求時進行兩階段大小校驗：
- **階段一（傳輸層）**：HTTP 請求之 `Content-Length > 5 \times 1024 \times 1024` bytes (5MB)，Web 閘道（Express / Nginx）直接返回 HTTP 413。
- **階段二（解析層）**：解壓後之 JSON 字元串長度超過 25MB，返回業務錯誤碼 E007。
```http
HTTP/1.1 413 Payload Too Large
Content-Type: application/json

{
  "errorCode": "E007",
  "message": "同步封包體積超過 5MB 上限，請拆分批次上傳。"
}
```

### 3.2 客戶端大封包自我防護與拆分上傳
客戶端在封裝 `SyncDeltaRequest` 或 `SyncFullRequest`（`doc_spec_0655`）前，必須執行預檢：
1. **行動紀錄分段（Batch Chunking）**：
   - 當待上傳之 `actionRecords` 超過 200 筆或估計體積超過 3MB 時，自動以每 100 筆為一個子批次分割上傳。
2. **過期日誌修剪（Journal Pruning）**：
   - 若單次全量快照因歷史日誌累積逼近 5MB，觸發 `DataGrowthMonitor` 自動將 30 天以前且已完成之戰鬥詳情報告進行摘要收攏，保留關鍵 Hash，釋放存檔空間。

## 4. 資料模型與監控指標

```typescript
export interface RateLimitPolicy {
  maxRequestsPerWindow: 10;
  windowDurationSeconds: 60;
  maxPayloadCompressedBytes: 5242880;     // 5 * 1024 * 1024
  maxPayloadUncompressedBytes: 26214400;  // 25 * 1024 * 1024
  cooldownDefaultSeconds: 60;
}
```

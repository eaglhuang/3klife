# 傭兵插畫五階段好感戰鬥解鎖與只進不退規格書

## 1. 核心定位與設計理念
本規格書定義三國生活（3KLife）留存與傭兵系統之「傭兵插畫五階段情感進度、解鎖條件判定與只進不退」規範（對應 WBS `RET-01` 與 `PROG-2-1400`）。
插畫進度作為深化玩家與麾下傭兵的情感羈絆、激勵戰鬥出征與長線留存之核心圖鑑系統，堅持**階段清晰、取最高階、只進不退**原則：
1. **五階段漸進式羈絆**：從初識、交手、認同、信任到金蘭結義，每階段對應明確的遊戲行為（出戰、獲勝、親密、轉永久）。
2. **條件獨立取最高階**：各階段條件獨立評估，若玩家直接將武將轉為永久，直接解鎖第 5 階段，無需逐階解鎖。
3. **歷史榮耀只進不退**：已解鎖的插畫階段永久固化於圖鑑中，絕不因契約過期、解約或好感度波動而降階。

---

## 2. 五階段解鎖條件對照表 (`MercenaryIllustration`)
系統以五階階梯（`ILLUSTRATION_STAGE_MIN = 1`, `ILLUSTRATION_STAGE_MAX = 5`）管理插畫解鎖：

| 階段 (Stage) | 階段名稱 | 核心解鎖門檻 | 數值常數定義 | 介面展示與回饋 |
| :---: | :--- | :--- | :--- | :--- |
| **第 1 階** | 初見結緣 | 獲得該傭兵武將 | 初始取得 (0 門檻) | 解鎖基礎人物半身立繪與生平背景 |
| **第 2 階** | 陣前交手 | 參與至少 1 場戰鬥 | `ILLUSTRATION_BATTLES_FOR_STAGE_2 = 1` | 解鎖戰鬥行軍動態立繪與第一句語音 |
| **第 3 階** | 戰陣認同 | 累計取得 3 場勝利 | `ILLUSTRATION_WINS_FOR_STAGE_3 = 3` | 解鎖拔劍作戰全圖與必殺特寫插畫 |
| **第 4 階** | 莫逆信任 | 親密度 (Bond) $\ge 40$ | `ILLUSTRATION_AFFECTION_FOR_STAGE_4 = 40` | 解鎖私下對飲/夜讀常服插畫（滿值 60） |
| **第 5 階** | 金蘭結義 | 契約轉為永久武將 | `progress.bonded = true` | 解鎖金蘭結義典藏金卡與終生誓言語音 |

## 3. 階段判定與單調晉升演算法

### 3.1 當前進度推算 (`illustrationStageOf`)
傳入玩家當前與該傭兵之互動進度物件：
```typescript
export interface IllustrationProgress {
    battles: number;      // 參戰次數
    wins: number;         // 戰勝次數
    affection: number;    // 當前好感度（0 ~ 60）
    bonded: boolean;      // 是否已轉為永久家臣
}
```
演算法由高至低比對門檻，回傳最高達成階位：
$$\text{CalculatedStage} = \begin{cases}
5, & \text{若 } \text{bonded} = \text{true} \\
4, & \text{若 } \text{affection} \ge 40 \\
3, & \text{若 } \text{wins} \ge 3 \\
2, & \text{若 } \text{battles} \ge 1 \\
1, & \text{其餘情況}
\end{cases}$$

### 3.2 只進不退保全演算法 (`advanceIllustrationStage`)
已解鎖之歷史階位記錄於圖鑑存檔中：
$$\text{NextStage} = \max\left(\text{safeCurrent},\, \text{CalculatedStage}\right)$$
- 即使傭兵 6 日試用期滿離隊（未轉永久），圖鑑內已解鎖至第 4 階的插畫依舊永久亮起，供玩家隨時翻閱紀念。

## 4. Unity 與 Cocos Creator 概念對照
| 概念維度 | Cocos Creator 實作架構 | Unity 引擎對照架構 |

## 5. 驗證條件與測試矩陣 (Acceptance Gate)
1. **TC-RET01-01 初始狀態保底第1階**：零戰鬥、零好感之新傭兵，驗證回傳階段精確為 1。
2. **TC-RET01-02 跨階直接達成**：零戰鬥但直接贈禮至好感 45，驗證直接跳轉解鎖至第 4 階。
3. **TC-RET01-03 結義直接登頂**：`bonded = true` 時，無論戰鬥與好感數值為何，驗證必然回傳第 5 階。
4. **TC-RET01-04 只進不退防降階**：已記錄為第 4 階，傳入全為 0 的重置進度，驗證最終階位依然維持為 4。

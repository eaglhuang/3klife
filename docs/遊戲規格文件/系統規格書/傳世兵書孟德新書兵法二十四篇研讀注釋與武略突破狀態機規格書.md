# 3KLife 傳世兵書孟德新書兵法二十四篇研讀注釋與武略突破狀態機規格書

> **規格代碼**：SPEC-TREAT-STRAT01  
> **關聯 WBS**：TREATISE-STRATEGY-01（三國三大傳世兵書資料結構、研讀注釋閉關狀態機與武略天花板突破機制）  
> **系統分類**：學府文化 / 兵書典籍與武略繼承管線  
> **狀態**：正式生效（單一真相來源，嚴禁尾端追加補丁）

---

## 1. 系統架構定位與千秋武略之傳承

書中自有百萬兵，一卷兵書安社稷。曹操著《孟德新書》總結百戰兵法，諸葛亮臨終將《兵法二十四篇》手授姜維。《三國人生》（3KLife）寶物典籍系統超越純數值道具，實裝**傳世兵書研讀閉關、親筆注釋與武略極限突破狀態機（Treatise Study & Limit Break）**。

本系統核心價值：
1. **三大傳世兵學聖典（Three Sacred Treatises）**：《孟德新書》、《兵法二十四篇》、《孫子兵法十三篇》。
2. **閉關修撰研讀狀態機（Retreat & Annotation）**：名將需進駐學府閉關靜修，消化兵法精義。
3. **突破常規五維天花板（Stat Limit Break）**：研讀透徹者可打破 500 點單項屬性極限，踏入半聖境地。

## 2. 三大傳奇兵書資料定義

```typescript
export enum AncientTreatiseId {
  MENGDE_TREATISE = 'MENGDE_TREATISE',       // 孟德新書 (曹操撰：破甲撕裂，戰役戰術速決)
  TWENTY_FOUR_CHAPTERS = 'TWENTY_FOUR_CH',   // 兵法二十四篇 (諸葛亮撰：陣法通神，軍團合圍)
  SUN_TZU_THIRTEEN = 'SUN_TZU_THIRTEEN'     // 孫子兵法十三篇 (兵聖之祖：全知全能，全兵種大師)
}

export interface IAncientTreatiseDef {
  readonly id: AncientTreatiseId;
  readonly name: string;
  readonly authorGeneralId: string;         // 著書原作者
  readonly baseLeadBonus: number;            // 統率屬性增益 (+8 ~ +12)
  readonly baseIntBonus: number;             // 智力屬性增益 (+6 ~ +10)
  readonly signatureBattleEffect: string;    // 專屬戰場生效光環
  readonly limitBreakStat: 'LEAD' | 'INT';   // 可突破上限之屬性類別
}
```

兵書專屬戰術光環：
- **《孟德新書》【短兵速決】**：全軍近戰破甲提升 $+15\%$，戰鬥前 5 回合部隊行軍移動力額外 $+1$ 格。
- **《兵法二十四篇》【八陣通幽】**：戰場陣型維持度永久提升 $+20\%$，且無條件解鎖【八卦陣】陣型。
- **《孫子兵法》【不戰屈人】**：全軍所有兵種適性無條件提升一階（A 升 S 級），全軍抗計謀率 $+35\%$。

## 3. 兵書研讀閉關與親筆注釋狀態機

武將獲取傳奇兵書後，進駐書院太學開啟「閉關研讀」：

```
       [OBTAINED 初獲秘笈] ──進駐學府太學──> [IN_STUDY 閉關靜修中 (耗時 3 季度)]
                                                          │
                 ┌────────────────────────────────────────┴────────────────────────────────────────┐
                 ▼ (智力 >= 85: 領悟精義)                                                          ▼ (智力不足: 僅獲皮毛)
      【ANNOTATED 親筆批注作序】                                                        [STANDARD_MASTERY]
      解鎖【武略極限突破】，上限突破至 550 點！                                         僅獲得常規統率與智力加成
```

1. **研讀耗時代價**：研讀期間名將處於「閉門謝客」狀態，不可出征作戰或出任太守。
2. **親筆批注（Master Annotation）**：若名將智力與統率均 $\ge 85$，研讀圓滿時撰寫專屬注釋（如「曹操注孫子兵法」），獲得**武略上限突破（Limit Break）**：
   - 該名將的統率或智力屬性單項上限**由 500 點硬頂放寬至 550 點**！

## 4. 傳家寶訓與世代傳承機制

1. **託付繼承（Legacy Will）**：著書名將臨終時，可發動「傳承遺訓」，將批注兵書傳授給親傳弟子或嫡長子（如諸葛亮傳姜維）。
2. **幼童早慧啟蒙**：繼承兵書之子嗣在入學潁川書院培育時，起始統率與智力基礎點數**額外獲贈 $+30$ 點**，並先天自帶專屬兵法光環。

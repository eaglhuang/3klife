## 1. 系統架構定位與濁酒論英雄之豪情

對酒當歌，人生幾何；何以解憂，唯有杜康。三國亂世中，桃園結義定千秋誓約、青梅煮酒識天下英雄、割袍斷義斷生死同盟。《三國人生》（3KLife）構建**傳世名酒宴飲社交與金蘭生死契約系統（Wine Diplomacy & Sworn Brotherhood）**。

本系統核心價值：
1. **三大傳奇名酒文化（Legendary Wines）**：杜康酒（解憂釋懷）、青梅酒（煮酒試探）、屠蘇酒（歲旦辟邪安康）。
2. **桃園結義金蘭誓約（Sworn Brotherhood Pact）**：不求同年同月同日生，但求同年同月同日死之全戰場連鎖共鳴。
3. **大義背馳割袍斷義狀態機（Severance of Ties）**：一旦犯下弒親殺兄大罪，誓盟化為刻骨仇恨。

## 3. 金蘭結義盟約（Sworn Brotherhood）

兩位或三位名將親密度達 $100$ 時，可於桃花林設案焚香發動**桃園結義**：

```typescript
export interface ISwornBrotherhoodPact {
  readonly pactId: string;
  readonly swornBrotherIds: string[];  // 結義兄弟名單 (2~3 人，如: 劉關張)
  isPactActive: boolean;               // 盟約是否依然生效
  mutualAuraCombatBonus: number;       // 戰場並肩作戰攻防加成 (+25%)
}
```

1. **同生共死戰場光環**：結義兄弟身處同一戰場時，彼此相距 $\le 3$ 格自動觸發「兄弟齊心」：
   - 物理攻擊與防禦力提升 **$+25\%$**，暴擊率提升 $+15\%$。
2. **千里奔援義務**：若其中一人守城告急，其餘兄弟軍團無條件獲得「星夜奔馳」增益，行軍速度提升 $50\%$ 前往馳援。

## 4. 割袍斷義（Severance of Ties）決裂狀態機

義字當頭，背義者誅。若結拜兄弟中某人犯下**不可饒恕之悖德大罪**（如投敵斬殺義兄部屬、弒殺故主君主）：

```
       [SWORN_BROTHERS 生死同心] ──── 觸發弒主背信/陣前殺弟大罪
                                            │
                                            ▼
       【SEVERANCE 拔劍割袍・斷絕恩義！】
                                            │
       ┌────────────────────────────────────┴────────────────────────────────────┐
       ▼                                                                         ▼
 [好感度直接鎖死為 -100 (不共戴天)]                                      [觸發專屬戰場宿敵對決]
 結義光環徹底碎裂，永不可再修復                                          交鋒時攻擊傷害 +40%，必定不死不休！
```

1. **斷義儀軌演出**：觸發經典「割袍斷席」CG，雙方好感度直接永久鎖死在 **$-100$**。
2. **仇深似海戰意**：兩軍陣前相遇時，雙方自動獲得【血仇宿敵】被動，對彼此造成的暴擊率提升至 $50\%$，直至一方倒在血泊中。

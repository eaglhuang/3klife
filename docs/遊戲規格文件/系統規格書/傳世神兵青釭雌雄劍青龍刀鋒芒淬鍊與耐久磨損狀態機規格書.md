## 1. 系統架構定位與神兵傳世特性

寶刀配英雄，青龍偃月照千秋。《三國人生》（3KLife）寶物裝備系統超越靜態屬性面板，為三國傳奇神兵實裝**專屬武器機制與動態鋒刃磨損系統（Weapon Durability & Quenching）**。

本系統核心價值：
1. **非凡專屬被動（Signature Weapon Traits）**：青釭削鐵、雌雄雙刺、偃月前三刀重斬，再現原著鋒芒。
2. **戰鬥真實磨損物理（Combat Wear & Tear）**：激烈格擋與破甲劈砍會加速消耗武器耐久。
3. **名匠淬鍊與銘文覺醒（Master Artisan Reforging）**：透過古法淬火維持神兵吹毛斷髮之鋒銳度。

## 2. 三大傳世神兵資料定義

```typescript
export enum AncientWeaponId {
  QINGGANG_SWORD = 'QINGGANG_SWORD',       // 青釭劍 (削鐵如泥，專破重甲)
  DUAL_PAIR_SWORDS = 'DUAL_PAIR_SWORDS',   // 雌雄雙股劍 (陰陽合璧，雙段連擊)
  GREEN_DRAGON_BLADE = 'GREEN_DRAGON_BLADE'// 青龍偃月刀 (冷豔鋸，起手三刀暴擊)
}

export interface IAncientWeaponDef {
  readonly id: AncientWeaponId;
  readonly name: string;
  readonly baseWarBonus: number;           // 武力加成 (+10 ~ +15)
  currentDurability: number;               // 當前耐久度 (0 ~ 100)
  readonly maxDurability: number;          // 最大耐久度 (100)
  readonly uniqueTraitDescription: string; // 專屬特性描述
}
```

神兵專屬特性矩陣：
- **青釭劍【削鐵如泥】**：攻擊重甲步兵或具備鐵甲之敵將時，**無視目標 $80\%$ 物理護甲**；代價為每次破甲攻擊耐久消耗 $+1$ 點。
- **雌雄雙股劍【陰陽雙舞】**：普通近戰打擊時必定發動**兩段連續追擊**（左劍破勢、右劍取命），近戰格擋招架率提升 $+25\%$。
- **青龍偃月刀【前三合威震】**：戰鬥開始之前 3 回合（前三刀），每次攻擊**傷害額外暴增 $+60\%$**；第 4 回合起回歸標準加成。

## 3. 武器耐久度流轉狀態機

```
       [PRISTINE 鋒芒畢露 (耐久 80~100)] ──── 全額神兵專屬特效，暴擊 +10%
                        │
                        │ 戰鬥劈砍累積消耗
                        ▼
       [WORN 刃口磨損 (耐久 30~79)] ──────── 特效維持，但破甲威力折減 25%
                        │
                        │ 持續劇烈撞擊
                        ▼
       [BLUNTED 鋒刃鈍化 (耐久 < 30)] ────── 專屬破甲特效完全暫時失效！
                        │
                        │ 尋訪名匠蒲元淬火修復
                        ▼
       [REFORGED 重煥新生] ────────────────── 恢復滿耐久，有機率淬鍊出【破甲】銘文
```

1. **破刃與鈍化機制**：當耐久跌破 30 點時，青釭劍無法削鐵，青龍刀喪失前三刀威勢，僅保留基礎武力白值加成。
2. **神兵永不損毀原則**：傳世神兵耐久降至 0 時進入「鈍化封印」，絕不會永久碎裂消失，保障玩家心血資產。

## 4. 古法淬鍊與蒲元鍛造工藝

玩家可於城池鐵匠鋪指派名匠（如蒲元後人）進行神兵保養：
- **磨礪回春（Honing）**：消耗極品油石與黃金，1 個季度內恢復滿耐久。
- **百鍊淬火（Quenching）**：消耗「南中冷泉水」與「百鍊精鐵」，有 $30\%$ 機率為神兵淬出額外詞條（如【嗜血汲魂】吸血 $10\%$ 或【破鋒】破甲 $+15\%$）。

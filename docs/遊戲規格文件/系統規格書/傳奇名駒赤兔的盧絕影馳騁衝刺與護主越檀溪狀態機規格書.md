## 1. 系統架構定位與千軍辟易之駿足

人中呂布，馬中赤兔；乘風破浪，絕影飛電。《三國人生》（3KLife）將名駒坐騎自純粹的「移動力白值飾品」昇華為具備**獨立護主邏輯與戰場空間位移的靈性戰駒體系（Legendary Steed System）**。

本系統核心價值：
1. **傳奇名駒專屬特權（Signature Mount Traits）**：赤兔神速、的盧飛躍、絕影免控、飛電威嚴。
2. **空間障礙飛躍演算法（Obstacle Leap）**：特殊危局下跨越常規水系與懸崖天塹。
3. **生死存亡坐騎替死護主（Mount Fallback Sacrifice）**：在名將落馬殞命瞬間挺身代死。

## 2. 四大傳奇名駒資料結構

```typescript
export enum LegendarySteedId {
  RED_HARE = 'RED_HARE',       // 赤兔馬 (日行千里，夜行八百，神速第一)
  HEX_MARK = 'HEX_MARK',       // 的盧馬 (妨主化護主，一躍三丈過檀溪)
  SHADOW_RUNNER = 'SHADOW_RUNNER', // 絕影 (身中三箭不失蹄，免疫減速)
  YELLOW_LIGHTNING = 'YELLOW_LIGHTNING' // 爪黃飛電 (威儀萬方，全軍激勵)
}

export interface ILegendarySteedDef {
  readonly id: LegendarySteedId;
  readonly name: string;
  readonly bonusMovement: number;        // 移動力常駐加成 (+2 ~ +3 格)
  currentStamina: number;                // 當前耐力值 (0 ~ 100)
  readonly maxStamina: number;           // 最大耐力值 (100)
  readonly signatureTrait: string;       // 專屬傳奇被動技能
}
```

## 4. 戰馬護主犧牲（Mount Sacrifice）狀態機

戰場上當主將承受致命傷害（致死一擊使得 HP 歸零）時，名駒觸發「護主捨身」保護邏輯：

```
       [主將承受致死傷害 HP <= 0]
                   │
                   ▼
       【戰馬護主檢定 (判定率 100%)】
                   │
       ┌───────────┴───────────┐
       ▼                       ▼
 [戰馬代受全部致死傷害]   [將主將拋送至相鄰安全格]
 戰馬陷入重傷狀態         主將保留 1 點生命生還
       │                       │
       └───────────┬───────────┘
                   ▼
        【名將成功突圍撤離戰場】
```

1. **護主生還保底**：傳奇名駒代受致命打擊，主將保留 $1$ 點體力免除陣亡，並強制後撤脫離戰場。
2. **戰馬療養週期**：護主後名駒進入「重創療養（Grooming）」狀態，需在馬廄休養 **2 個季度**，期間由普通戰馬暫代出征。

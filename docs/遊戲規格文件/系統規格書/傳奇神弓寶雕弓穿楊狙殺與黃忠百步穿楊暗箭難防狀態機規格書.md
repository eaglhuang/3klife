# 3KLife 傳奇神弓寶雕弓穿楊狙殺與黃忠百步穿楊暗箭難防狀態機規格書

## 1. 系統架構定位與引弓落鵰之神技

轅門射戟震群雄，百步穿楊射盔纓；元戎十矢發連弩，暗箭難防將星傾。《三國人生》（3KLife）為神射名將（黃忠、太史慈、呂布）實裝**傳奇神弓狙殺與超視距部位致殘系統（Legendary Bow & Snipe Mechanics）**。

本系統核心價值：
1. **三大傳奇神弓神弩（Legendary Bows & Crossbows）**：寶雕弓（極限射程）、鐵胎弓（部位破防）、元戎神弩（十矢連破）。
2. **屏息瞄準狙擊姿態（Sniper Aim Stance）**：無視前排肉盾阻擋，定點鎖定敵方大將咽喉。
3. **精準部位致殘結算（Targeted Disabling Strike）**：射盔退敵、射臂繳械、射心致命一擊。

## 3. 屏息狙殺姿態（Snipe Stance）狀態機

攜帶神弓之名將可在戰場上發動「屏息狙擊（ENTER_SNIPE_STANCE）」：

```
       [NORMAL 戰陣齊射] ──宣告屏息狙殺──> [AIMING 屏息鎖定中 (耗費 1 回合蓄力)]
                                                    │
                 ┌──────────────────────────────────┴──────────────────────────────────┐
                 ▼ (中途遭遇敵軍近戰打斷)                                              ▼ (蓄力完畢，扣動扳機)
        [AIM_BROKEN 瞄準中斷]                                                 【UNLEASH 穿楊一擊！】
        蓄力消散，退回常規姿態                                                 無視前排掩體阻擋，直取敵酋！
```

1. **無視肉盾阻擋（Shield Bypass）**：狙擊判定中，子彈/箭矢射線穿透路徑上的常規小兵護衛隊，直接對敵將本體進行結算。
2. **射程無衰減**：寶雕弓在第 5 格極限距離射擊，傷害與命中完全不折減。

## 4. 精準部位打擊（Targeted Disabling）結算

當穿楊一擊判定命中時，依精準度骰中目標三個關鍵部位之一：
1. **射落頂盔（Helm Strike）**：利箭精準射斷敵將頂盔紅纓，敵將亡魂皆冒，其全軍部隊士氣瞬間**暴跌 25 點**！
2. **射傷右臂（Arm Severance）**：箭鏃穿透護臂，敵將武器脫手，當前戰鬥內**完全喪失主動攻擊與反擊能力**。
3. **百步穿心（Heart Pierce）**：直接命中咽喉或心窩，結算 $300\%$ 毀滅暴擊傷害，高機率觸發「當場落馬陣亡」。

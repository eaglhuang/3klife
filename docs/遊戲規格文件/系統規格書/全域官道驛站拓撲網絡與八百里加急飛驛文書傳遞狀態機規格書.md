> **規格代碼**：SPEC-INFRA-POST01  
> **關聯 WBS**：INFRA-POST-SYSTEM01（全域馳道官道網格拓撲、換馬不換人八百里加急與驛站維護狀態機）  
> **系統分類**：帝國基建 / 交通馳道與軍機飛驛傳訊管線  
> **狀態**：正式生效（單一真相來源，嚴禁尾端追加補丁）

## 1. 系統架構定位與車同軌書同文交通命脈

一騎紅塵妃子笑，無人知是荔枝來；羽檄飛馳八百里，金牌急遞百萬兵。《三國人生》（3KLife）為各大郡縣都城實裝**全域帝國官道驛站拓撲網絡與八百里加急飛驛管線（Highway & Relay Station Network）**。

本系統核心價值：
1. **三階官道升級體系（Three-Tier Imperial Highway）**：泥濘荒道、平整碎石官道、帝國青石馳道。
2. **換馬不換人八百里加急（Relay Courier Express）**：軍政密函傳遞效率提升 5 倍，千里告急一夕可達。
3. **驛站基建動態維護（Post Station Upkeep）**：若地方無庫銀修繕，官道荒廢滋生盜賊山匪。

## 2. 官道三階升級與行軍速度矩陣

城池之間的主要交通幹線可由太守撥款修築：

```typescript
export enum HighwayQuality {
  DIRT_TRAIL = 'DIRT_TRAIL',         // 泥濘荒徑 (基礎速度 1.0x，雨天極度泥濘)
  GRAVEL_ROAD = 'GRAVEL_ROAD',       // 碎石官道 (行軍速度 1.4x，雨天不陷車)
  PAVED_HIGHWAY = 'PAVED_HIGHWAY'    // 帝國青石馳道 (行軍速度 2.0x，兩馬並馳)
}

export interface IRelayStationNode {
  readonly stationId: string;
  readonly roadId: string;
  highwayTier: HighwayQuality;       // 當前路面品質
  postHorsesStock: number;           // 儲備快馬數量 (通常為 10~20 匹)
  maintenanceCostQuarterly: number;  // 每季修繕維護銀兩
  isOperable: boolean;               // 是否維持運轉狀態
}
```

## 3. 八百里加急（Urgent Courier）傳訊狀態機

當前線遭遇敵軍閃擊包圍或爆發緊急軍情時，主帥可消耗快馬啟動「八百里加急金牌飛驛」：

```
       [前線軍情告急] ──點燃驛騎金牌──> [COURIER_RUSH 換馬不換人日夜狂奔]
                                                  │
                 ┌────────────────────────────────┴────────────────────────────────┐
                 ▼ (馳道完備、驛站充盈)                                            ▼ (路面破損、快馬匱乏)
      【ARRIVED 極速抵達中樞】                                            [DELAYED 半道阻滯]
      2 回合內調撥中樞援軍與糧草救兵                                      耗時翻倍，貽誤軍機陷孤城！
```

1. **速度躍升 500%**：八百里加急使朝廷政令下達、援軍徵調之時間成本自原本的 **整季（3個月）壓縮至 1~2 回合內**！
2. **快馬損耗代價**：每次八百里加急飛驛將沿途驛站快馬耐力榨乾，需由都城撥款採買戰馬補充。

## 4. 驛站荒廢與修繕維護機制

1. **國庫虧空荒廢（Post Decay）**：若勢力連續 2 季度無法支付驛站修繕費，青石馳道將退化為 `GRAVEL_ROAD`，最終坍塌為雜草叢生的 `DIRT_TRAIL`。
2. **治安聯動阻斷**：荒廢官道極易吸引黑山賊與流民設卡收稅，商隊通過時遭遇劫掠率高達 **$60\%$**，倒逼君主必須修明政理、廣通馳道。

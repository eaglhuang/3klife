## 1. 系統架構定位與運河漕運戰略動脈

兵馬千里，饋糧不繼，此古今用兵之大患。曹操引漳水開白溝、穿平虜渠以平北方，孫權築濡須塢、通江淮水運。《三國人生》（3KLife）構建**全域天然水系漕運與人工運河開鑿調度管線（Canal Logistics Pipeline）**。

本系統核心價值：
1. **水陸物流懸殊效能比（Water vs Land Efficiency）**：水運速度為陸路 3 倍，途中糧損耗由 $20\%$ 暴降至 $3\%$。
2. **戰略重大工程開鑿（Canal Engineering Projects）**：玩家可調集民伕鑿通太行山麓與江淮阻隔，逆天改寫地理版圖。
3. **前線無損直達補給（Zero-Depletion Supply Line）**：運河貫通後，千里遠征不再受「糧盡退兵」之困。

## 2. 水陸物流損耗比對矩陣

```typescript
export interface ILogisticsRouteMetrics {
  readonly routeType: 'LAND_PACK_HORSE' | 'WATER_GRAIN_BARGE';
  readonly transitSpeedMultiplier: number; // 移動運載速度乘數
  readonly perQuarterSpoilageRate: number; // 每季糧草途中腐敗損耗率
  readonly capacityTonsPerFleet: number;   // 單次船隊/車隊運載總量
}

export const LOGISTICS_STANDARDS: Record<string, ILogisticsRouteMetrics> = {
  LAND_PACK_HORSE:  { routeType: 'LAND_PACK_HORSE',  transitSpeedMultiplier: 1.0, perQuarterSpoilageRate: 0.20, capacityTonsPerFleet: 500 },
  WATER_GRAIN_BARGE:{ routeType: 'WATER_GRAIN_BARGE',transitSpeedMultiplier: 3.0, perQuarterSpoilageRate: 0.03, capacityTonsPerFleet: 3000 }

```

水運相比陸運具備壓倒性後勤優勢：
- **速度躍升 300%**：長途調糧僅需 1 季度抵達，陸路需 3 季度。
- **損耗驟降 85%**：陸運「運糧者半道食其半」，水運千斛漕船日行百里，糧草損耗僅 $3\%$。

## 3. 人工運河開鑿重大工程狀態機

在原本互不連通之相鄰水系之間（如黃河與白溝、淮河與長江巢湖），可宣告啟動**開鑿運河工程**：

```typescript
export interface ICanalProjectDef {
  readonly canalId: string;
  readonly name: string;                 // 運河名稱 (如: 白溝、平虜渠、濡須渠)
  readonly startWaterwayNode: string;    // 起點水系
  readonly endWaterwayNode: string;      // 終點水系
  totalTurnsRequired: number;            // 總需工期 (通常為 4 個季度)
  currentProgressTurns: number;          // 當前已開挖季度
  costGoldPerQuarter: number;            // 每季消耗黃金
  laborCivilianRequired: number;         // 徵調民伕工役數額 (如 20,000人)
}
```

## 4. 前線直達調度與戰略破局結算

1. **戰略瓶頸突破**：
   - 運河竣工後，原本需要翻越險峻棧道之重裝糧隊，直接轉由千艘漕船直泊前線城下碼頭。
   - 處於運河網覆蓋下的前鋒軍團，戰場「斷糧崩潰」狀態被永久阻斷，軍隊士氣常駐維持在 $80$ 以上高昂狀態。
2. **通航被截擊風險**：
   - 運河雖快，但若沿岸要塞被敵軍水鬼或騎兵突襲截斷，運河漕船將成為活靶，進攻方需設立水寨（Water Fort）沿途護航。

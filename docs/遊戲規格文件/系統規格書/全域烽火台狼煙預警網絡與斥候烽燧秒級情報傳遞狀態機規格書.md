# 3KLife 全域烽火台狼煙預警網絡與斥候烽燧秒級情報傳遞狀態機規格書

> **規格代碼**：SPEC-MIL-BEACON01  
> **關聯 WBS**：MILITARY-BEACON-01（長城要塞烽火台網格拓撲、晝煙夜火情報秒傳與防禦動員狀態機）  
> **系統分類**：邊防預警 / 烽燧通訊與邊境早期情報管線  
> **狀態**：正式生效（單一真相來源，嚴禁尾端追加補丁）

---

## 1. 系統架構定位與塞外邊防之耳目

烽火連三月，家書抵萬金；晝則燔燧，夜則舉烽。《三國人生》（3KLife）為邊防要塞與長城防線實裝**全域烽火台網格拓撲與早期情報預警系統（Beacon Tower Warning Network）**。

本系統核心價值：
1. **網格化節點拓撲（Mesh Topology）**：相鄰烽火台沿隘口山脊鏈路相連，實現超視距軍情瞬傳。
2. **晝煙夜火物理演算（Smoke by Day, Fire by Night）**：白晝燃點狼糞之濃煙，夜半高舉熊熊之烽火。
3. **早期防禦動員態勢（Mobilization Advantage）**：提前 2 季度探明敵軍主力動向，免受奇襲突防之苦。

---

## 2. 烽火台網格資料結構與相鄰鏈路

邊防線上每隔 3~5 格修築一座**標準烽火台（Beacon Node）**：

```typescript
export interface IBeaconNode {
  readonly nodeId: string;
  readonly position: { x: number; y: number };
  linkedNodeIds: string[];               // 拓撲相鄰連通之烽火台識別碼 (通常 2~4 座)
  isIgnited: boolean;                    // 當前是否正在燃放烽煙
  garrisonStrength: number;              // 守台斥候兵力 (50 人)
  isSabotaged: boolean;                  // 是否被敵軍細作死士破壞斷烽
}
```

```
 [邊塞敵軍出沒] ──► [前哨烽火台 A] ══(晝煙/夜火)══► [中繼烽火台 B] ══► [大本營都城]
                         │
                         ▼ (若被敵方死士暗殺斷烽)
                  【情報阻滯，都城不備受襲！】
```

## 3. 晝夜信號機制與動態傳導速度

1. **白晝燔狼煙（Wolf Smoke by Day）**：白晝時段（`DAY`），烽火台燃燒艾草狼糞，青煙筆直沖天直上雲霄，風吹不斜，白晝可視距離達 15 格。
2. **夜半舉烽火（Beacon Fire by Night）**：黑夜時段（`NIGHT`），烽火台高懸油火籠，烈火熊熊照亮夜空，夜間可視距離達 20 格。
3. **瞬間連鎖反應（Instant Cascade）**：前哨台一旦發現敵軍主力行軍，在 **1 個戰略回合（同次回合結算前）** 即完成全線連鎖傳導，情報直達都城中樞。

---

## 4. 戰略防禦動員與敵軍斷烽特種戰

1. **防備齊整增益（Fortification Ready）**：
   - 經由烽火台提前探知敵軍入侵路線的城池，守軍自動獲得【備戰完畢】狀態：
   - 城門護甲免傷提升 **$+25\%$**，城頭箭塔齊射傷害提升 **$+35\%$**，且完全免疫敵軍「夜襲突防」之營嘯混亂。
2. **敵軍死士斷烽（Sabotage Beacon）**：
   - 敵軍進攻前可派遣精銳刺客（如魏國校事、吳國錦帆細作）暗殺前哨守卒，熄滅烽火。
   - 若烽火台鏈路斷裂，情報無法傳回都城，守軍將遭遇「不意之襲」，城內第一回合全軍士氣下挫 $15$ 點。

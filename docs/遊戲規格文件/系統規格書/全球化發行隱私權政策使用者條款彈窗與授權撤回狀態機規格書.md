# 3KLife 全球化發行隱私權政策使用者條款彈窗與授權撤回狀態機規格書

> **規格代碼**：SPEC-OPS-LEGAL01

> **文件版本**：v1.0.0 (單一真相來源，無補丁整併版)  
> **所屬系統**：數值、架構與底層支援（Formula, Architecture & Backend）

## 1. 核心宗旨與設計哲學

本遊戲發行面向全球跨國市場，必須嚴格恪守蘋果 App Store 審查指南 5.1.1、Google Play 開發者政策、歐盟 GDPR、美國加州 CCPA 與台灣個人資料保護法。本規格書制定首次啟動之**使用者協議（EULA）與隱私權條款（Privacy Policy）強制彈窗**、**零默認主動授權機制**與**設定面板一鍵撤銷授權狀態機（Consent Revocation FSM）**。

---

## 2. 首次啟動合規彈窗互動時序

在啟動場景進入主大廳前，系統優先檢查本地是否具備有效授權簽名：

```
[首次啟動遊戲] -> [本地無合法授權簽名] -> [展示隱私權與條款彈窗 (PrivacyModal)]
                                                   |
             +-------------------------------------+-------------------------------------+
             |                                                                           |
             v                                                                           v
    [玩家主動勾選同意]                                                          [玩家點擊不同意拒絕]
             |                                                                           |
             v                                                                           v
[寫入本地授權簽名，解鎖主按鈕]                                              [彈出二次確認：無法進入遊戲]
             |                                                                           |
             v                                                                           v
     [進入遊戲主大廳]                                                       [呼叫 cc.game.end() 安全退出]
```

### 2.1 彈窗元件幾何與強制約束

| 元件名稱 | Cocos 節點命名 | 互動行為與約束 (Interaction Rule) |
|---|---|---|
| **彈窗根容器** | `modal_privacy_root` | 全屏模態遮罩（BlockRaycast: true），屏蔽 ESC / 安卓返回鍵。 |
| **條款超連結** | `btn_terms_link` / `btn_privacy_link` | 點擊調用系統原生瀏覽器打開官方條款網頁，遊戲內不阻斷進程。 |
| **主動勾選框** | `toggle_agree_terms` | **嚴格禁止默認勾選**（預設 isChecked = false），必須由玩家手動點擊。 |
| **同意進入按鈕** | `btn_confirm_consent` | 勾選前處於置灰禁用狀態（interactable = false）；勾選後即刻亮起。 |

## 3. 設定面板授權撤回狀態機 (Revocation FSM)

玩家可在遊戲內「設定 $\rightarrow$ 帳號與隱私」隨時撤回資料授權：

```typescript
export interface PrivacyConsentRecord {
  consentVersion: '2026.1';           // 條款版號
  agreedTimestamp: number;
  locale: string;                     // 如 "zh-TW"
  userHashId: string;
}

export interface ConsentRevokeResult {
  hasRevoked: boolean;
  clearedLocalDataBytes: number;
  needAppRestart: boolean;            // 強制重啟回到登入授權頁
}
```

- **撤回處置時序**：玩家確認撤回後，客戶端立即清空本地 `localStorage` 存檔快照、刪除崩潰日誌暫存、發送向伺服端註銷日誌之請求，並調用 `cc.game.restart()` 重新載入，退回條款確認彈窗。

## 4. 驗收測試案例 (Test Cases)

- **TC-LEGAL-01【首次啟動無授權阻斷進度】**：新安裝環境啟動遊戲，在未勾選協議前，點擊全屏任意區域均無法跳過彈窗進入大廳。
- **TC-LEGAL-02【拒絕條款安全退出遊戲】**：點擊「不同意」並於二次提示窗點擊「確認退出」，原生遊戲進程安全終止，無崩潰當機。
- **TC-LEGAL-03【設定面板撤銷授權與快照清除】**：在已登入狀態下執行撤回授權，驗證本地快照資料被 100% 清除，遊戲重啟後正確重新呈現隱私彈窗。

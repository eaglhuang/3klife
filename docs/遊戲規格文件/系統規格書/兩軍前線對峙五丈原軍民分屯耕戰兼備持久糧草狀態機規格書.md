# 3KLife 兩軍前線對峙五丈原軍民分屯耕戰兼備持久糧草狀態機規格書

## 1. 系統概述與設計哲學
在敵我兩軍於邊境或險要平原長期對峙（如諸葛亮出武功駐五丈原、司馬懿堅壁拒戰）之戰局中，大軍深入敵國數百里，後方千里棧道轉運糧草耗損極大（十鍾致一石）。為求立於不敗之地，三國統帥採取「軍民分屯耕戰兼備」（CAMP-TUNTIAN-FARMING-FORT01）之戰略持久體系。
大軍進駐渭水之濱後，三分之一部隊修築深溝高壘守營值更，三分之二部隊解甲執耒耜，與當地居民雜處屯田。大軍開挖灌溉水渠，大規模翻土開墾荒原播種粟米與麥豆。屯田部隊「耕者雜於百姓之間，百姓安堵，軍無私焉」，每季度直接在敵國前線就地產出大量軍糧，徹底免除糧盡退兵之憂，對固守不出之敵軍施加巨大戰略壓迫。

## 4. 農業產出與後勤運力經濟模型

### 4.1 屯田糧食自給產出公式
前線就地產糧完全取代長途損耗：
$$\text{Yield}_{\text{total}} = \text{Area}_{\text{hectares}} \times \text{Yield}_{\text{base}} \times (1.0 + \text{Bonus}_{\text{canal}}) \times (1.0 - \text{Damage}_{\text{raid}})$$
- 產出之糧食無需支付長途運糧之「十鍾致一石」運費損耗，後方蜀道或中原農民徭役負擔降低 $80\%$。

### 4.2 耕戰一體化防禦機制
1. **十步一哨防突襲**：田埂之間插立烽火哨臺與鹿角拒馬，農具均為長柄鐵器，隨時可作兵器格鬥。
2. **民心向背定勢**：當地百姓因不被搶掠且獲耕作指點，民心安定度維持在 90 以上，主動向我軍提供敵情情報。

## 5. 單元驗收測試標準
1. **TC-TUNTIAN-01 (五丈原分兵開墾與秋收全流程)**：
   - 模擬 3 萬蜀軍進駐五丈原，實施 65% 兵力屯田。
   - 驗證開闢千頃農田，歷經季度結算收割 350 萬斤糧食，糧道依賴降低 80%。
2. **TC-TUNTIAN-02 (守營值更部隊防騷擾快速反應)**：
   - 注入敵軍魏騎 500 騎襲擊農田事件。
   - 驗證留守警戒部隊於 10 分鐘內整隊出擊，在莊稼被破壞前殲滅敵騎。
3. **TC-TUNTIAN-03 (糧倉充實與持久戰士氣加成)**：
   - 糧食入庫轉入 `FORTIFIED_GRANARY_SECURE`，全軍免除「糧盡退兵」倒計時限制，士氣恆定維持滿值。

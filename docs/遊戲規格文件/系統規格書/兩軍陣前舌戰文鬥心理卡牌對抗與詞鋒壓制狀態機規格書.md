# 3KLife 兩軍陣前舌戰文鬥心理卡牌對抗與詞鋒壓制狀態機規格書

> **規格代碼**：SPEC-BAT-DEBATE01  
> **關聯 WBS**：BATTLE-DEBATE-01（兩軍陣前舌戰文鬥心理卡牌博弈、三系詞鋒環形相剋與罵死敵將狀態機）  
> **系統分類**：外交謀略 / 陣前舌戰與心理對決管線  
> **狀態**：正式生效（單一真相來源，嚴禁尾端追加補丁）

---

## 1. 系統架構定位與三國舌戰文化

文死諫，武死戰；諸葛亮舌戰江東群儒、兩軍陣前罵死王朗，舌戰為三國智謀對決之最高境界。《三國人生》（3KLife）在武將單挑之外，獨立構建**軍師陣前舌戰文鬥對弈引擎（Debate Duel Engine）**。

本系統核心價值：
1. **三系詞鋒環形相剋（Rhetorical Triad）**：道義（Moral）、雄辯（Rhetoric）、威壓（Intimidation）互相壓制。
2. **心理防線血條化（Psychological Resilience HP）**：以智力與辯才計算心防上限，詞窮理屈則心防瓦解。
3. **怒氣反駁與吐血氣絕（Wrath & Fatal Collapse）**：積累怒氣可發動致命【大喝駁倒】，心理崩潰者直接落馬斃命。

## 2. 三系詞鋒相剋卡牌資料結構

```typescript
export enum DebateCardCategory {
  MORAL = 'MORAL',             // 道義牌 (大義名分、漢室宗親，克制威壓)
  RHETORIC = 'RHETORIC',       // 雄辯牌 (引經據典、以史為鑑，克制道義)
  INTIMIDATION = 'INTIMIDATION'// 威壓牌 (雄兵百萬、利害剖析，克制雄辯)
}

export interface IDebateCardDef {
  readonly cardId: string;
  readonly category: DebateCardCategory;
  readonly cardLevel: number;        // 卡牌位階 1~5
  readonly argumentPower: number;    // 辯才殺傷力 (扣除敵方心防值)
  readonly agitationGeneration: number; // 增加自身怒氣點數
}
```

```
           [道義 MORAL] ───剋──► [威壓 INTIMIDATION]
                ▲                      │
                │ 剋                   │ 剋
                └───── [雄辯 RHETORIC] ◄┘
```

出牌博弈規則：
- **相剋獲勝**：造成 $150\%$ 詞鋒暴擊傷害，且完全抵消對手出牌效果。
- **同系平手**：雙方依據卡牌位階（`cardLevel`）與智力差值計算差額傷害。
- **被剋受挫**：承受對手全額傷害，且自身怒氣槽激增。

## 3. 心理防線與怒氣爆發狀態機

辯論雙方初始配置「心智耐久值（Resilience HP）」與「怒氣槽（Agitation Gauge，0~100）」：

$$\text{HP}_{\text{resilience}} = \text{INT} \times 15 + \text{Charm} \times 10$$

```
      [CALM 冷靜交鋒] ──承受詞鋒重擊──> [AGITATED 惱羞成怒 (怒氣 100%)]
             │                                   │
             │ 心智 HP 跌破 0                    │ 發動【大喝駁倒】
             ▼                                   ▼
      【DESPAIR 詞窮吐血】 ◄────────── 造成雙倍破防暴擊
```

1. **怒氣滿槽爆發（Wrath Refutation）**：當怒氣值達 100 時，強制打斷對手回合，發動名場面【大喝駁倒】（如「皓首匹夫，蒼髯老賊！」），對敵方造成必中破防 $300\%$ 暴擊。
2. **終極氣絕判定（Fatal Collapse）**：若敵方心智 HP 被削扣至 $0$ 點：
   - 辯論判定為**大獲全勝（Decisive Debate Victory）**。
   - 敵將高達 $35\%$ 機率「氣絕落馬身亡」（王朗式陣亡）；其所屬全軍士氣瞬間重挫扣除 **$40$ 點**並陷入大混亂！

## 4. 戰場實戰應用與收益結算

1. **陣前喊話誘降**：兩軍交鋒前發動舌戰，勝方可直接迫使敵方前鋒部隊後撤 3 格並繳械投降。
2. **說降名將門檻**：在外城談判中舌戰獲勝，敵城守將開城投誠概率提升 $+60\%$。

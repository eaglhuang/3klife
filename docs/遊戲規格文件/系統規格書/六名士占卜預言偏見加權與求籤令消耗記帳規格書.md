# 六名士占卜預言偏見加權與求籤令消耗記帳規格書

## 1. 模組職責與架構定位
本規格書規範結緣懷孕期間的「六位歷史名士占卜資料表（`SageRegistry`）」、「預言生成與偏見加權採樣引擎（`SageDivination`）」以及「求籤令資產扣除與累計記帳狀態機（`SageOracleController`）」。模組在結緣前瞻階段為玩家提供趣味性的子嗣因子走向預測。

## 3. 預言生成偏見加權演算法

### 3.1 偏好色系權重加成（Weighted Sampling）
系統解析父母基因庫計算各色系的天然分佈權重。選定名士後，該名士所偏好之因子色系權重乘以 **$3.0\times$**：
$$\text{Weight}_{\text{Favored}} = \text{BaseWeight} \times 3.0$$
依據加權後之總權重進行確定性隨機輪盤抽樣（`WeightedSample`）。

### 3.2 準確率與預言歪曲（Distortion）
抽樣得出主要預言方向後，根據名士基礎準確率 `baseAccuracy` 進行校驗：
- 若隨機值 $\text{roll} < \text{baseAccuracy}$，預言準確命中真實偏向，給予正向斷語。
- 若隨機值 $\text{roll} \ge \text{baseAccuracy}$，預言發生偏折（`Distort`），輸出模稜兩可或誇大批語。

```typescript
export interface DivinationResult {
  predictedColor: GeneColor;
  isAccurate: boolean;
  commentKey: string;
}

export function generateDivination(
  sage: SageProfile,
  colorWeights: Record<GeneColor, number>,
  accuracyRoll: number
): DivinationResult {
  const isAccurate = accuracyRoll < sage.baseAccuracy;
  return {
    predictedColor: sage.favoredColor,
    isAccurate,
    commentKey: isAccurate ? `SAGE_${sage.sageId}_TRUE` : `SAGE_${sage.sageId}_DISTORT`
  };
}
```

## 4. 求籤令消耗與解鎖記帳狀態機
1. **扣款審查**：發起占卜前檢查背包 `oracleTokens >= 1`，不足時拋出 `INSUFFICIENT_ORACLE_TOKENS` 阻斷。
2. **原子扣除**：執行成功後扣除 1 枚求籤令，玩家存檔之 `totalOracleCount` 加算 $+1$。
3. **名士即時解鎖**：當 `totalOracleCount` 達到對應名士之 `unlockOracleCount` 時，自動在 UI 點亮該名士頭像與占卜通道。

## 5. 單元測試驗證規範
1. **TC-ORAC-TOKEN（扣款與阻斷）**：持有 0 枚求籤令無法占卜；持有 1 枚占卜後剩餘 0 枚，累計次數加 1。
2. **TC-ORAC-UNLOCK（名士門檻解鎖）**：占卜次數達 10 次時，諸葛亮解鎖；未達 15 次時，司馬徽維持鎖定。
3. **TC-ORAC-ACCURACY（準確率命中檢驗）**：諸葛亮準確率 0.85，roll = 0.80 時 `isAccurate = true`；roll = 0.90 時回傳歪曲批語。

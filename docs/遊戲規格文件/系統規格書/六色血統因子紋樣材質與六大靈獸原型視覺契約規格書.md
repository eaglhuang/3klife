## 2. 水墨金石材質規範 (Ink-Bronze Material Protocol)

為杜絕現代卡通化或獸首頭像之低幼感，所有靈獸與紋樣呈現一律遵守**「漢代金石拓印（Ink Rubbing）」**材質規範：
1. **抽象拓印風格**：
   - 禁止使用直白之寫實動物獸首插畫；
   - 一律萃取漢代青銅鏡背、瓦當、石闕畫像磚之抽象圖騰線條。
2. **三層材質疊加結構**：
   - **底層 (`Base Plate`)**：玄鐵水墨底板（深灰水墨微噪點）。
   - **中層 (`Sigil Inlay`)**：錯金金石紋樣（依因子色彩微調之暗金線條）。
   - **頂層 (`Aura Breath`)**：因子靈光（僅在覺醒與突破時以 Low Opacity 0.3 呼吸微透）。

## 3. 共用資料契約結構（bloodline-sigil-and-beast-contract-v1.json）

定義落檔於 `assets/resources/data/contracts/bloodline-sigil-and-beast-contract-v1.json` 之標準資料格式：

```typescript
export interface BloodlineSigilBeastContract {
  contractVersion: "1.0.0";
  beasts: Record<string, {
    beastId: "AZURE_DRAGON" | "WHITE_TIGER" | "VERMILION_BIRD" | "BLACK_TORTOISE" | "KIRIN" | "WINGED_DRAGON";
    geneColor: "RED" | "WHITE" | "PINK" | "BLUE" | "GREEN" | "PURPLE";
    statCategory: "LEA" | "STR" | "CHA" | "INT" | "POL" | "LUK";
    chineseName: string;           // 如 "青龍"
    patternMotif: string;          // 如 "回首蟠龍紋"
    colorHex: string;              // 如 "#C53030"
    crestSpritePath: string;       // 如 "sprites/ui/crest/crest_azure_dragon"
    auraColorRgba: [number, number, number, number];
  }>;
}
```

- **單一真相約束**：
  - 日常人物頁（`CharacterDs3BloodlineChild`）、血統十四人樹（`BloodlineTreePanel`）、英靈卡與特種軍隊（`EliteTroopCodex`），一律經由此契約統一解析紋樣與顏色，嚴禁私自定義第二套顏色對映表。

# 兵種地形強弱勢加成與移動懲罰數值規格書

## 1. 核心定位與職責邊界
本規格書定義《三國人生》戰場實體部隊站在特定地形格時所觸發的固有強弱勢修正數值模型（WBS `APT-04`，代碼落位於 `TerrainTroopRules.ts`）。
本系統作為底層純邏輯查表引擎，與武將個別之「適性等級修正」採乘區疊加，為部隊行軍移動、攻防結算、遠程射程與林地伏擊提供確定性數值依據。

```
              ┌──────────────────────────────────────────┐
              │        TerrainTroopRules 查表引擎         │
              └─────────────────────┬────────────────────┘
                                    │ 輸出固定加成與懲罰
          ┌─────────────────────────┼────────────────────────┐
          ▼                         ▼                        ▼
  【移動力修正 (move)】     【防禦乘區 (defMult)】    【射程與隱蔽 (range/stealth)】
  • 騎兵平原 +2 格          • 步兵山地防禦 +30%       • 弓兵林地隱蔽 +20%
  • 騎兵山地 -2 格                                    • 弓兵水域射程 -1 格
  • 騎兵林地 -1 格                                    • 林地 D 級射程封頂 1 格
```

## 2. 兵種 × 地形強弱勢數值矩陣

### 2.1 基礎修正表（`RULES` 定義）
僅對規格具體明確之組合進行修正，無規則之組合回傳全 0（`NO_TERRAIN_TROOP_EFFECT`）：

| 兵種 (TroopType) | 地形 (TerrainType) | 移動修正 (`moveDelta`) | 防禦乘區 (`defenseMult`) | 射程修正 (`attackRangeDelta`) | 隱蔽加成 (`stealthBonus`) |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **騎兵 (Cavalry)** | 平原 (Plain) | **+2 格** | 0% | 0 | 0% |
| **騎兵 (Cavalry)** | 山地 (Mountain) | **-2 格** | 0% | 0 | 0% |
| **騎兵 (Cavalry)** | 林地 (Forest) | **-1 格** | 0% | 0 | 0% |
| **步兵 (Infantry)** | 山地 (Mountain) | 0 | **+30% (+0.3)** | 0 | 0% |
| **弓兵 (Archer)** | 林地 (Forest) | 0 | 0% | 0 | **+20% (+0.2)** |
| **弓兵 (Archer)** | 水域/河流 (River) | 0 | 0% | **-1 格** | 0% |

> **說明**：步兵於山地之 `+30%` 防禦為獨立加成乘區；弓兵於水域之射程扣減直接作用於普通攻擊與單體定向戰法。

## 3. 地形等級特殊邊界約束（林地專屬）

除基礎兵種對應外，林地格針對部隊之林地適性等級（Forest Aptitude Grade）設有兩項全局戰鬥邊界：

### 3.1 林地 D 級「視野受限」（`FOREST_D_ATTACK_RANGE_CAP`）
- **約束規則**：當部隊站在林地（Forest）且其林地適性等級為 **`D`** 級時，其攻擊射程強制封頂為 **1 格**。
- **裁決行為**：
  $$\text{AttackRangeCap} = 1$$
- **影響範圍**：禁止對距離 $\ge 2$ 格之目標發動任何普通攻擊或定向戰法，僅能與相鄰 1 格之敵軍交戰；非林地或非 D 級部隊回傳 `null`（不設上限）。

### 3.2 林地 S 級「林地迴避」（`FOREST_S_EVASION_BONUS`）
- **約束規則**：當防守方部隊站在林地（Forest）且其林地適性等級為 **`S`** 級時，觸發茂林掩蔽效應。
- **數值折減**：使攻擊方對該部隊之攻擊命中率降低 **30%**：
  $$\text{EvasionBonus} = 0.30 \implies \text{Accuracy}_{\text{attacker}} = \text{Accuracy}_{\text{attacker}} - 30\%$$
- **安全邊界**：扣減後之最終命中率仍須遵循全局命中保底下限（50%），不得擊穿防禦底線。

## 4. 計算管線整合與呼叫端契約

1. **純邏輯無副作用**：`getTerrainTroopEffect(troop, terrain)` 僅回傳唯讀之 `TerrainTroopEffect` 物件，絕不就地變更傳入之部隊實體。
2. **戰鬥結算調用順序**：
   - 行軍階段：`BattleAutoMovePhase` 於計算最終可移動距離時，將 `moveDelta` 納入累加（需遵循保底移動力 1 格規則）。
   - 傷害結算階段：`BattleCombatResolver` 將步兵山地防禦加成 `+30%` 納入防禦乘區結算。
   - 索敵階段：弓兵林地隱蔽 `+20%` 提升敵方 AI 索敵忽視機率；水域射程 `-1` 於瞄準有效性檢核時扣減。

### 兵種符號視覺規範（使用者 2026-11-22 裁決）

全遊戲（戰場、部署卡、虎符、UI 兵種標示）共用同一套兵種符號：

- **風格**：單色象牙白剪影，一兵種一個物件，顏色不跟等階變，疊在金圈圓章上。
- **對照**：騎＝馬頭、步＝直劍、盾＝盾、弓＝弓、槍＝長槍、工＝錘、醫＝葫蘆、水＝帆船。**刀保留給未來的刀兵**，現有兵種不得使用刀。
- **尺寸**：以實際顯示約 20px 設計；外輪廓要能彼此區分（縮小後仍一眼分辨）。
- **失敗退回**：符號圖載入失敗時，退回顯示兵種單字（騎、步、盾、弓、槍、工、醫、水）。

## A. 系統描述

兵種系統定義遊戲中所有可指揮的部隊類型，分為「基礎兵種」（騎兵/步兵/弓兵/長槍兵/盾兵/水軍/機械）與「特殊兵種」（透過虎符裝備後方可指揮的精銳部隊）。虎符卡是名將死亡結算時產出的稀有道具，屬於**武將私人裝備**——必須裝備在特定武將身上，該武將才能指揮對應的特殊兵種。虎符可卸下轉交給其他武將，但同一枚虎符同時只能由一名武將持有。兵種搭配武將的兵種適性（粉色因子），決定戰場上的部隊組成與戰術策略。

正式世界觀補充後，虎符同時也是 `英靈虎符 / 血脈卡` 的軍勢化身：

- 名將壽命盡後，可同步留下英靈卡與虎符卡
- 插卡出戰時，喚出的不一定是完整活人，而是對應名將的 `血脈面 / 英靈面`
- 虎符、卡面、旗幟、特種軍隊外觀，必須共用同一套命紋靈獸與祖紋命篆語言

正式取得邊界與永續存在規則：

1. 虎符卡**不來自轉蛋**。
2. 名將生前退役只進入教官 / 傳承路徑，不直接生成虎符卡。
3. 舊討論若仍寫「退役產虎符」，正式實作一律以「死亡結算產虎符卡」為準。
4. **永恆傳承道具**：全世界的虎符是一種特殊道具，可以賞賜給任何武將，不會因為持有者死亡而消失。若裝備的武將陣亡或老死，該虎符會自動退回給當時的君主（包含 AI 君主），並由君主重新賞賜給旗下適合的其他武將。
5. **裝備唯一限制**：每個武將僅能裝備**一個**特殊虎符部隊，不可疊加。
6. **沒收與降忠**：君主可以強行沒收手下武將當前配戴的虎符，但這項行為會導致該武將的忠誠度大幅下降。沒收的虎符君主可自由再次賞賜。
7. **敵方天生裝備**：敵方陣營（AI）的武將如果星級達到三星（★★★）以上，天生就會自動裝備並帶著對應的虎符（特殊部隊）出戰。
8. **虎符來源三進路（Q61=C 補充）**：虎符卡只能隨名將死亡 / 招降 / 戰場封賞產出，共三種來源：
   - **死亡結算**：特定正式名將（史實武將 / 正式女性名將）死亡時產出對應虎符卡，品質以 `TigerTallyScore` 決定。
  - **招降移交**：成功招降敵方武將後，該武將隨身攜帶的虎符於隔季結算時移交到玩家虎符庫；在正式交出前，仍視為該武將裝備中的虎符。
  - **封賞結算**：戰勝沒有退路的方伯 / 君主時，由勝方公開封賞對方旗下可交出的最高品質虎符；對方投降或待決時也適用。

> **Unity 對照**：兵種系統相當於 Unit Type + Prefab Factory 架構。每種兵種是一個 Unit Prefab（帶有不同的 Stats、Skin、Ability），虎符則是 Equipment Item（裝備道具），裝備在武將的 Equipment Slot 上才能啟用對應 Prefab 的使用權限，類似 RPG 中裝備武器才能使用武器技能的概念。

## B. 系統目的

1. **戰術多樣性**：七大基礎兵種＋多種特殊兵種提供豐富的陣容搭配
2. **身後傳承**：名將死亡結算產出虎符卡，讓死亡不再只是「失去」而是「傳承」
3. **收藏驅動**：特殊兵種虎符的稀有性驅動名將收集與培育
4. **裝備配置策略**：虎符為武將私人裝備，需思考「哪位武將裝哪枚虎符」的最優化搭配
5. **適性連動**：武將的兵種適性決定指揮效率，形成配種策略需求
6. **視覺差異化**：特殊兵種具有獨特外觀，增加展示慾望
7. **世界觀一體化**：虎符、英靈面、血脈卡與專屬軍勢共用同一套血脈符號與故事

## C. 商業套路

| 商業點 | 說明 |
|---|---|
| 名將虎符稀有性 | SSR 名將死亡時才產出頂級虎符卡，驅動名將收集 |
| 虎符品質 | 高戰績死亡結算產出高品質虎符→戰場投入驅動補元散消耗 |
| 裝備槽壓力 | 每位武將只能裝備一枚虎符 → 多虎符需更多武將 → 驅動養成與名將池抽卡 |
| 兵種外觀 | 特殊兵種的獨特外觀為社交炫耀元素 |
| 多隊需求 | 不同地形需不同兵種組合，驅動武將與虎符的多樣化配置 |
| 限時虎符 | 活動限定死亡結算 / 劇本結算產出限定虎符，製造稀缺性 |
| 虎符升級材料 | 4~5★ 突破需消耗「虎符精華」（戰場掉落/商城）+ 黃金，課長加速空間 |
| 虎符拔除經濟 | 拔除虎符降忠誠度 → 玩家需謹慎操作或消耗忠誠回復道具 |
| 虎符適性差異 | 不同虎符的地形/家族/性別適性造就配隊深度，驅動多虎符收集 |

## D. 系統 TA

| 玩家類型 | 使用情境 |
|---|---|
| 策略玩家 | 根據地形配置「哪位武將裝哪枚虎符」的最佳組合 |
| 課長 | 收集所有 SSR 虎符，為多位武將配備頂級特殊兵種 |
| 三國迷 | 體驗「白馬義從」「陷陣營」等經典部隊 |
| 收藏家 | 填滿虎符圖鑑，每枚虎符都裝備展示 |
| 培育控 | 培養高價值名將並在死亡結算後留下高品質虎符 |

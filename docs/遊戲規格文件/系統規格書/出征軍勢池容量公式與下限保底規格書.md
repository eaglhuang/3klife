# 出征軍勢池容量公式與下限保底規格書

## 1. 核心定位與出征容積契約

本規格書為玩家出征軍勢池容積計算（Sortie Troop Pool Max，代號 `DEP-01`）的單一真相來源（Single Source of Truth）。在進入戰役或編制軍隊前，出征介面透過純邏輯函式 `computeSortiePoolMax` 綜合裁定本次戰鬥玩家可投入之最大兵力上限。

```typescript
export interface SortiePoolContract {
  commandCapacityFloor: 8000;     // 初期統御容量保底 8000
  defaultStageSortieCap: 8000;    // 預設關卡出征上限 8000
  calculationFunction: 'computeSortiePoolMax';
}
```

---

## 2. 統御容量公式（Command Capacity）

主將統御容量代表武將個人軍事威望與帶兵極限：

$$\text{CommandCapacity} = \max\left(8000, \text{Base}_{\text{Rank}} + (\text{LEA} \times 50) + \text{Fame} + \text{Equip} + \text{Event}\right)$$

1. **官階基底（$\text{Base}_{\text{Rank}}$）**：
   - 依照武將官階（Rank 0~5）階梯遞增：
     $$\text{RankBase} = [1000, 2000, 3500, 5000, 7500, 10000]$$
2. **統率屬性縮放**：每點統率（LEA）提供 50 名帶兵額度。
3. **附加加成**：名聲聲望（Fame）、寶物裝備（Equip）與重大事件（Event）之帶兵擴充值。
4. **初期保底（Floor）**：無論計算結果為何，統御容量下限強制鎖定為 8,000，確保初階白身武將亦能攜帶基本軍勢出陣。

---

## 3. 出征軍勢池木桶原理公式（Sortie Pool Max）

玩家單場戰役實際可用之軍勢上限，取決於「統御容量」、「城市兵源」與「關卡容積」三者之最小值：

$$\text{SortieTroopPoolMax} = \min\left(\text{CommandCapacity}, \text{CityTroops}, \text{StageSortieCap}\right)$$

- **統御約束**：不可超越主將帶兵上限。
- **城市庫存約束**：不可超越當前本城兵營之可用兵源（$\text{CityTroops}$）。若城市兵源枯竭，出征軍勢池強制受限。
- **關卡地形約束**：關卡依地形設有容納上限（$\text{StageSortieCap}$，預設 8,000；狹谷關隘可能下修至 4,000，平原會戰可放寬至 20,000）。
- **負數安全防護**：若輸入之兵源或容量為負數或非法值，系統一律強制歸零（$\text{nonNegInt}$ 防護），杜絕負數兵力溢位。

---

## 4. 戰場部署與兵力分配調度

1. **先鋒部隊配額**：
   - 每支上陣特種部隊或常規部隊固定佔用 1,500 兵力（例如 4 支先鋒消耗 6,000 兵力）。
2. **軍勢池扣除檢定**：
   - 上陣部隊總兵力不得超過 $\text{SortieTroopPoolMax}$。
   - 若出征軍勢池餘額不足 1,500，無法再部署新部隊出陣。

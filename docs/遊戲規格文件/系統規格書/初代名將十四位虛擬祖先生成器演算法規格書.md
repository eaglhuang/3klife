# 初代名將十四位虛擬祖先生成器演算法規格書

> 標籤：`BLT-02` · `M2` · `始祖溯源` · `虛擬祖先` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統體系中，對於無父母資料之史實初代名將，藉由「始祖溯源演算法（`VirtualAncestorGenerator`）」自動補齊上三代共 14 位虛擬祖先（`V_PID_{GeneralID}_{Position}`）之資料模型、地域限制、世代因子分佈權重與確定性生成規則。

本生成器為純函式無副作用運算，以武將 ID 作為隨機種子，確保所有客端與存檔重放之生成結果完全一致。

---

## 2. 虛擬祖先識別碼與基準參數

```typescript
export const VIRTUAL_ANCESTOR_PREFIX = 'V_PID_';
export const VIRTUAL_ANCESTOR_EP_BASE = 48;
```

1. **命名規範**：`V_PID_{GeneralID}_{Position}`。例：`V_PID_zhao-yun_FF`（趙雲之祖父）、`V_PID_guan-yu_M`（關羽之母親）。
2. **血統基準分**：所有虛擬祖先之 `ep_base` 統一固定為 48 點，避免初代虛擬祖先分數虛高或失衡。
3. **不可結緣性**：虛擬祖先為歷史譜牒投影，標記 `isVirtual = true`，禁止參與遊戲內配種結緣。

## 3. 出生地與六大地域推導

祖先分佈受到名將史實出生地域限制，不可脫離地理背景：

### 3.1 六大地域劃分表

| 地域代碼 | 地域名稱 | 管轄州郡 | 地域特色因子 (粉) |
|---|:---:|---|---|
| `north` | 北境 | 幽州、并州、冀州 | 騎兵適性 (`gene_cavalry`)、神速 (`gene_dash`) |
| `central` | 中原 | 司隸、豫州、兗州、青州、徐州 | 騎兵適性、神速 |
| `wuyue` | 吳越 | 揚州 | 水戰適性 (`gene_naval`) |
| `jingchu` | 荊楚 | 荊州、交州 | 水戰適性 |
| `bashu` | 巴蜀 | 益州 | 山地適性 (`gene_mountain`)、林地適性 (`gene_forest`) |
| `xiliang` | 西涼 | 涼州、雍州 | 騎兵適性、神速 |

### 3.2 地域歸屬演算法
1. 優先取用武將顯式設定 `birthRegion`。
2. 若無設定，掃描 `historicalAnecdote`（歷史傳記）前 80 字，由郡縣清單映射至正體州名，再映射至所屬地域。
3. 若仍無結果，以武將初始所屬勢力之首都州郡進行兜底推導。
4. **親緣偏向**：父系祖先 100% 隸屬於本地域；母系祖先 70% 來自本地域、30% 來自相鄰地理區域（`REGION_NEIGHBORS`）。

## 4. 世代因子色系與星等權重模型

虛擬祖先依插槽所在世代（Gen 1~3），依階梯機率抽取因子顏色與星等：

| 世代 (Generation) | 因子顏色分佈機率 | 星等階梯分佈機率 | 特徵說明 |
|:---:|---|---|---|
| **Gen 1 (父母)** | 藍色 50% / 綠色 50% | ★3 80% / ★4 20% | 繼承名將主屬性與戰法雛形 |
| **Gen 2 (祖輩)** | 藍色 40% / 粉色 30% / 白色 30% | ★2 70% / ★3 30% | 出現地域適性與門風特質 |
| **Gen 3 (曾祖輩)** | 藍色 20% / 白色 80% | ★1 90% / ★2 10% | 稀釋為泛用基礎特質 |

## 5. 主屬性回溯與變異位點

### 5.1 史實極限回溯保底
若名將單項屬性極其卓越，祖輩必定帶有對應核心因子，以符合血統邏輯：
- **武力 $> 90$**：祖輩必定攜帶「勇猛」、「體魄」標籤因子。
- **智力 $> 90$**：祖輩必定攜帶「謀略」標籤因子。

### 5.2 變異點位（Mutation Spot）
在 14 個祖譜插槽中，依隨機種子隨機抽取 **1 個專屬位點**，賦予紫色天命／福運因子（`mutation = true`），代表名將家族在三代之內曾出現之隱藏天命奇觀。

# 初始六名將正式古典台詞與開場信件契約規格書

<!-- doc_id: doc_spec_0622 -->

> 本規格書依據 WBS `COPY-01`（開場信件定稿）與 `COPY-03`（六名將登場台詞資料化）制定，為開場信件、名將展示台詞與語音鍵值之單一真相來源（Single Source of Truth）。

---

## 1. 業務定位與裁決定案

### 1.1 開場信件定稿（`COPY-01`）：原創幽默情懷版（Win95 全息時光頭盔版）
依據最高設計裁決，開場信件必須契合《新手開場規格書》之 **Win95 書房分鏡與全息時光頭盔** 設定，打破第四面牆、帶老玩家幽默情懷感（廢除嚴肅古典傳家書版）：
- **標題鍵值 (`copy.letter.opening.title`)**：`致你的一封信`（英文：`A letter for you`，日文：`あなたへの一通の手紙`）。
- **內文鍵值 (`copy.letter.opening.body`)**：
  > 朋友，剛才看到你又在玩《三國志2》……還是劉備？
  >
  > 讓我猜，這次又被曹操追到哪座城了？落鳳坡的哀傷、五丈原的遺憾，難道你要在虛擬世界裡重複一輩子嗎？
  >
  > 只要戴上這臺全球首發的全息時光頭盔，我就能帶你親身走一遭那滾滾長江。
  >
  > 那些你一直想登用、卻忠誠度鎖死100的名將，搜尋再久也不會有美女的年代，這次機會終於站在你這邊。
  >
  > 準備好了，就按下：啟動宿命轉蛋。

### 1.2 初始六名將登場台詞定稿（`COPY-03`）
當玩家戴上全息頭盔進入三國沙場召喚名將時，名將登場台詞採用具沙場豪氣之經典台詞，與現代幽默開場信形成反差張力。

## 4. 驗收測試案例

| 測試編號 | 測試情境 | 預期輸出 |
|---|---|---|
| `TC-COPY-01` | 開場信件搞笑情懷版驗證 | 包含「又在玩《三國志2》……還是劉備？」與「全息時光頭盔」、「忠誠度鎖死100」 |
| `TC-VOICE-01` | 張飛正式台詞讀取 | 回傳「燕人張翼德在此，誰敢與我決一死戰！」 |
| `TC-VOICE-02` | 資源鍵值命名規範 | `portraitKey` 結尾為 `_formal`，`battleVoiceKey` 結尾為 `_intro` |
| `TC-VOICE-03` | 非法 ID 優雅回退 | 回傳 `null` |

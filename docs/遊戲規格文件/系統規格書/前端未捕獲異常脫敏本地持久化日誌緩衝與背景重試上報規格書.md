# 3KLife 前端未捕獲異常脫敏本地持久化日誌緩衝與背景重試上報規格書

> **規格代碼**：SPEC-OPS-QA01  
> **關聯 WBS**：QA-CRASH-01（客戶端崩潰日誌脫敏、本地暫存與重傳）  
> **文件版本**：v1.0.0 (單一真相來源，無補丁整併版)  
> **所屬系統**：數值、架構與底層支援（Formula, Architecture & Backend）

---

## 1. 核心宗旨與設計哲學

前端運行期未捕獲異常（`window.onerror` 與 `unhandledrejection`）為排查線上偶發 Bug 與黑屏問題之關鍵證據。為確保日誌收集具備高可靠性，同時防止敏感個資外洩與斷網下日誌雪崩打垮後端，本規格書制定全域**崩潰日誌守衛（Crash Log Guard）**、**堆疊 PII 脫敏規則**、**本地環形緩衝區（Circular Buffer）**與**滑動窗口去重上報協議**。

---

## 2. 全域異常攔截與 PII 脫敏機制

### 2.1 雙通道異常捕獲

客戶端在啟動時註冊全域監聽器：
1. `window.addEventListener('error', handleGlobalError)`：捕獲同步語法錯誤與運行期運行時異常。
2. `window.addEventListener('unhandledrejection', handlePromiseRejection)`：捕獲非同步 Promise 未捕獲異常。

### 2.2 堆疊脫敏處置 (Sanitization)

在寫入緩衝區前，堆疊文字強制通過脫敏正則過濾：
- **路徑遮蔽**：所有本地磁碟路徑（如 `C:\Users\Admin\...`）一律替換為 `[PATH_MASKED]`。
- **參數去敏**：URL 中的 Token、密鑰或玩家自訂參數一律正則擦除。

```typescript
export interface CrashReportPayload {
  reportId: string;                   // 隨機 UUID
  errorType: 'JAVASCRIPT_ERROR' | 'PROMISE_REJECTION' | 'NATIVE_EXCEPTION';
  errorMessage: string;               // 錯誤訊息 (前 120 字)
  sanitizedStack: string;             // 脫敏後堆疊追蹤
  appVersion: string;                 // 如 "1.4.2"
  activeScene: string;                // 當前場景 (如 "BattleScene")
  timestamp: number;
  duplicateCount: number;             // 5 分鐘內同指紋錯誤聚合次數
}
```

## 3. 本地持久化緩衝與防雪崩上報協議

### 3.1 本地 50 筆環形緩衝區 (Circular Buffer)

- **存儲載體**：Web 環境使用 IndexedDB，原生環境使用沙盒私有檔案 `crash_logs.json`。
- **上限約制**：最多保留 50 筆最新異常；若超過 50 筆，以先進先出（FIFO）淘汰最舊紀錄，避免佔用玩家手機存儲。

### 3.2 錯誤指紋去重與滑動窗口限流

1. **錯誤指紋演算**：`Fingerprint = SHA256(errorType + errorMessage + stackTopLine)`。
2. **聚合去重**：若在 5 分鐘時間窗口內重複觸發相同指紋之錯誤，只累加 `duplicateCount`，不重複發送網路請求。
3. **滑動窗口上報**：每 60 秒最多允許向 `/api/telemetry/crash` 發送 3 次上報請求。連線失敗自動指數退避重傳（最多 3 次）。

## 4. 驗收測試案例 (Test Cases)

- **TC-QA-CRASH-01-01【未捕獲 Promise 異常攔截與脫敏】**：刻意拋出含有開發者電腦路徑之 Promise 異常，系統成功捕獲並脫敏寫入本地緩衝區，路徑標記為 `[PATH_MASKED]`。
- **TC-QA-CRASH-01-02【5 分鐘相同錯誤去重聚合】**：在循環中連續拋出 100 次相同 NullReferenceException，日誌守衛僅記錄 1 筆報告且 `duplicateCount = 100`，無日誌雪崩。
- **TC-QA-CRASH-01-03【離線暫存與連網背景回傳】**：在斷網狀態下產生 3 筆異常，寫入本地緩衝；連網恢復後，後台排程自動於 5 秒內非阻塞補發上報並清空本機緩衝。

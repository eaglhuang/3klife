# 動態人際關係建立狀態機與戰場治理共鳴事件規格書

## 1. 模組職責與架構定位
本規格書規範武將間的「動態人際關係建立狀態機（`KinDynamicRelations`）」以及關係成立後的「戰場援護與內政治理共鳴事件引擎（`RelationEvents`）」。模組負責追蹤遊戲進行中產生的情誼、婚配與結義，並轉化為實質的戰力加護與治理加乘。

```
┌─────────────────────────────────────────────────────────────┐
│                 Dynamic Kinship & Events                    │
├──────────────────────────────┬──────────────────────────────┤
│ 動態關係建立狀態機           │ 戰場與內政治理共鳴           │
│ 共鬥5次→戰友 / 好感100→義兄弟│ 義兄弟同陣士氣+20 / 傷害分攤 │
│ 婚禮→夫妻 / 出生→親子       │ 夫妻同郡太守產出+15%         │
└──────────────────────────────┴──────────────────────────────┘
```

## 2. 動態人際關係建立狀態機

```typescript
export type DynamicRelationType = 'COMRADE' | 'SWORN_BROTHER' | 'SPOUSE' | 'PARENT_CHILD';

export interface DynamicRelationRecord {
  relationId: string;
  sourceGeneralId: string;
  targetGeneralId: string;
  relationType: DynamicRelationType;
  intimacy: number;           // 0 ~ 100
  formedTimestamp: number;
}
```

### 2.1 四大動態關係轉換準則
1. **戰友（`COMRADE`）**：兩位武將同編於同一軍團且累積共同作戰場次 $\ge 5$ 場時，自動建立戰友關係，初始親密度 40 點。
2. **義兄弟（`SWORN_BROTHER`）**：雙方親密度達 100 點且滿足結義劇情時手動發起，永久雙向綁定。
3. **夫妻（`SPOUSE`）**：完成家族結緣儀式後由系統原子寫入，初始親密度 60 點。
4. **親子（`PARENT_CHILD`）**：子嗣登錄註冊時自動建立，親密度恆定保底 $\ge 80$ 點。

```typescript
export function checkComradePromotion(battleCount: number, existingRelation: DynamicRelationType | null): boolean {
  if (existingRelation !== null) return false;
  return battleCount >= 5;
}
```

## 3. 戰場援護與內政治理共鳴事件

### 3.1 戰場實戰共鳴
- **義兄弟同陣**：出征時，該部隊初始士氣上限提升 **$+20$ 點**。
- **生死相隨（相鄰援護）**：戰友或義兄弟在戰場相鄰九宮格時，若一方承受致命傷害，另一方有 **$50\%$ 機率** 介入援護，替其分攤 **$30\%$** 傷害。

### 3.2 內政治理共鳴
- **琴瑟和鳴（夫妻同郡）**：若夫妻同時指派為同一郡城之太守與郡丞，該郡每季度之金錢與糧草產出提升 **$+15\%$**。
- **門楣光大（親子同朝）**：父子或母子同時在朝廷任官，宗族聲望季度結算額外獲得 **$+10$ 點**。

```typescript
export interface GovernanceSynergy {
  copperProductionMultiplier: number;
  foodProductionMultiplier: number;
  prestigeBonus: number;
}

export function evaluateGovernanceSynergy(
  hasSpouseCoRule: boolean,
  hasParentChildCoRule: boolean
): GovernanceSynergy {
  return {
    copperProductionMultiplier: hasSpouseCoRule ? 1.15 : 1.0,
    foodProductionMultiplier: hasSpouseCoRule ? 1.15 : 1.0,
    prestigeBonus: hasParentChildCoRule ? 10 : 0
  };
}
```

## 4. 單元測試驗證規範
1. **TC-REL-COMRADE（共鬥 5 次晉升戰友）**：共鬥 4 次不觸發；共鬥 5 次回傳 `true`，成功建立 `COMRADE` 關係。
2. **TC-REL-BATTLE（義兄弟士氣加乘）**：義兄弟同陣出征，軍團起始士氣基礎 100 自動提升為 120。
3. **TC-REL-GOV（夫妻同郡 1.15 倍產出）**：`hasSpouseCoRule = true`，產出乘數回傳 1.15，宗族聲望無額外加成。

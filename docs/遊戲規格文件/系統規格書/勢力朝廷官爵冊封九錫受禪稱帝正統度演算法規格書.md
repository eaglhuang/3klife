## 1. 系統架構定位與天命所歸王道

設使國家無有孤，不知當幾人稱帝，幾人稱王。《三國人生》（3KLife）構建深度的**朝廷官爵天梯、挾天子號令諸侯與受禪稱帝正統度引擎（Imperial Legitimacy Engine）**。

本系統核心價值：
1. **嚴謹漢官晉升天梯（Imperial Ranks Ladder）**：自雜號將軍逐步累積威望至王爵加九錫。
2. **正統度量化模型（Legitimacy Index）**：以玉璽、二京、天子在握與宗室血脈計算法理大義。
3. **僭越反噬 vs 天命受禪（Usurpation vs Ascension）**：袁術式僭越引發天下共討，曹丕式受禪天下歸心。

## 2. 朝廷官爵位階天梯資料結構

玩家勢力依據佔領城池數與名望（Prestige）逐步獲得朝廷冊封：

```typescript
export enum ImperialTitleTier {
  COLONEL = 'COLONEL',           // 校尉 / 中郎將 (佔領 1~2 城)
  GENERAL_MISC = 'GENERAL_MISC', // 雜號將軍 (討虜、破虜、伏波)
  GENERAL_FOUR = 'GENERAL_FOUR', // 四征四鎮將軍 (征東、鎮西，佔領 1 州)
  SUPREME_COMMANDER = 'SUPREME', // 大將軍 / 驃騎將軍 (佔領 2 州)
  CHANCELLOR = 'CHANCELLOR',     // 丞相 / 司空 (錄尚書事，掌握朝綱)
  KING_NINE_BESTOWS = 'KING_NINE', // 封王加九錫 (魏王、漢中王，稱帝前奏)
  EMPEROR = 'EMPEROR'            // 九五之尊・受禪稱帝
}

export interface IImperialLegitimacyDef {
  readonly factionId: string;
  currentTitle: ImperialTitleTier;
  legitimacyPoints: number;      // 正統度指數 (0 ~ 100)
  holdsEmperorInCustody: boolean;// 是否挾天子以令諸侯
  holdsImperialJadeSeal: boolean;// 是否持有傳國玉璽
  occupiesLuoyangOrChangAn: boolean; // 是否收復洛陽或長安古都
  isHanDynastyLineage: boolean;  // 是否為漢室宗親
}
```

## 3. 正統度（Legitimacy）加權演算法

欲行稱帝大典，勢力之正統度 $L_{\text{legitimacy}}$ 必須達到檢核門檻：

$$L_{\text{legitimacy}} = \text{Base}_{\text{prestige}} + L_{\text{emperor}} (40) + L_{\text{seal}} (30) + L_{\text{capital}} (20) + L_{\text{lineage}} (15)$$

```
     正統度 L                稱帝後果態勢
  ┌──────────────┐        ┌────────────────────────────────────────┐
  │ L >= 80 點   │ ─────> │ 【天下歸心】受禪登基，文武百官朝賀，國泰民安  │
  │ 50 <= L < 80 │ ─────> │ 【群雄抗衡】部分諸侯不服，但內部政局平穩      │
  │ L < 50 點    │ ─────> │ 【天下共討】被列為國賊，爆發反賊同盟圍攻！    │
  └──────────────┘        └────────────────────────────────────────┘
```

1. **奉迎天子（挾天子以令諸侯）**：將漢獻帝迎至本方都城，正統度直接激增 **$+40$ 點**；享有「代頒天子討伐密詔」特權，宣戰無外交信譽懲罰。
2. **傳國玉璽（受命於天）**：獲取孫堅/袁術遺留之傳國玉璽，正統度激增 **$+30$ 點**。

## 4. 九錫受禪與袁術式僭越反噬

1. **加九錫儀軌（The Nine Bestowments）**：晉升為王爵後，朝廷賜予車馬、袞冕、樂則、朱戶、納陛、虎賁、鈇鉞、弓矢、秬鬯九種帝王禮器，軍隊士氣永久 $+10$ 點。
2. **袁術式僭越（Usurpation Catastrophe）**：
   - 若勢力在正統度 $< 50$ 且無大義名分下強行僭越稱帝（如袁術稱「仲家帝」）：
   - 全天下所有周邊諸侯好感度全部降至 **$-100$**，立即成立「討逆討賊大同盟」。
   - 麾下高義理名將（如荀彧、趙雲）忠誠度暴跌 35 點，有 $50\%$ 機率辭官出走或自立。

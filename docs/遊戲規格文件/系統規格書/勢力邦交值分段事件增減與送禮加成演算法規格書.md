# 勢力邦交值分段事件增減與送禮加成演算法規格書

> 標籤：`系統規格` `國家天下` `他國AI` `外交邦交` `RAI-04`
> 狀態：`正式生效` · 責任模組：`RivalAiDiplomacy` · 參照：`RAI-04` / `PROG-2-1476`

---

## 1. 模組定位與設計理念

在三國割據的沙盤大勢中，玩家與各大 AI 勢力（如曹魏、蜀漢、孫吳等）以及 AI 勢力彼此之間，透過動態「邦交值（Relation）」維繫複雜的政治與軍事平衡。
邦交值不僅是好感度數值，更是驅動主動結盟、經濟貿易、宣戰背叛與反霸權同盟的底層神經中樞。

本規格書定義邦交值系統的核心數值模型與事件演算法（`RivalAiDiplomacy.ts`），堅持：
1. **封閉區間與數值邊界**：邦交值嚴格鎖定在 $[-100, +100]$ 整數區間內，絕不溢出。
2. **史實羈絆初始賦值**：依照三國歷史演義賦予勢力間先驗的情感基調（如魏蜀宿敵、吳蜀同盟）。
3. **明確事件增減（Event Deltas）**：所有外交行為與軍事衝突皆有確定性的量化衝擊。
4. **送禮線性平滑效益**：杜絕零碎洗好感與無限制堆疊，透過黃金門檻區間與線性內插折算誠意增量。

## 2. 邦交值區間與歷史初始配置

```mermaid
flowchart LR
    Hostile["-100 (極度敵對 / 宣戰勢同水火)"] --- RivalInit["-30 (史實宿敵初始值)"]
    RivalInit --- Neutral["0 (中立 / 互不侵犯)"]
    Neutral --- AllyInit["+20 (史實盟友初始值)"]
    AllyInit --- Friendly["+100 (堅定盟友 / 永結同好)"]
```

### 2.1 數值邊界與夾取常數
- `RELATION_MIN`: `-100`（最低值，通常伴隨立即宣戰與軍事進攻）
- `RELATION_MAX`: `+100`（最高值，享有深度貿易折扣與堅實軍事聯防）
- 夾取函式：
  $$\text{clampRelation}(V) = \max(-100, \min(100, V))$$

### 2.2 歷史關係初始基準
在時代開局或新勢力登場時，依據歷史背景注入初始基底：
- **史實宿敵 (`HISTORICAL_RIVAL_INITIAL`)**：預設為 **`-30`**（例如：劉備陣營與曹操陣營初始見面即帶有高度戒備）。
- **史實盟友 (`HISTORICAL_ALLY_INITIAL`)**：預設為 **`+20`**（例如：赤壁之戰時期的孫權與劉備陣營）。
- **常規勢力**：預設為 **`0`**（彼此相安無事）。

## 3. 外交事件衝擊表 (RELATION_EVENT_DELTA)

每次外交或軍事實質行為發生時，透過 `applyRelationEvent(current, event)` 立即結算：

| 事件代碼 (RelationEvent) | 中文事件名稱 | 邦交值變化量 ($\Delta$) | 說明與後續連鎖影響 |
|---|---|:---:|---|
| `ALLIANCE` | 締結盟約 | **+30** | 正式簽署同盟，互相開放通商與軍事支援 |
| `TRADE` | 達成通商貿易 | **+5** | 每季正常物資互通有無之漸進增益 |
| `DEFEAT_NEMESIS_TOGETHER` | 共同擊破宿敵 | **+20** | 於同一戰場或同季度內瓦解共同威脅勢力 |
| `REFUSE_TRADE` | 拒絕通商請求 | **-5** | 輕微外交碰壁，累積多次將損害信賴 |
| `INVADE` | 邊界武力侵犯 | **-30** | 未經宣戰之越境劫掠或先制攻擊 |
| `ATTACK` | 正式宣戰攻擊 | **-50** | 全面發動攻城掠地之戰役衝突 |
| `BETRAY_ALLIANCE` | 撕毀盟約背叛 | **-80** | 盟友背刺之毀滅性打擊，極高機率跌破 -50 |

## 4. 送禮加成線性內插演算法 (giftRelationGain)

為避免玩家利用少量黃金頻繁洗好感，或以天文數字一鍵拉滿關係，送禮系統設定了嚴格的價值門檻與效益區間：

```mermaid
flowchart TD
    GoldIn[傳入禮金價值 giftValue] --> RangeCheck{giftValue 範圍評估}
    RangeCheck -->|giftValue <= 1000| MinGain[回傳保底 +10 好感]
    RangeCheck -->|giftValue >= 3000| MaxGain[回傳上限 +30 好感]
    RangeCheck -->|1000 < giftValue < 3000| Interp[計算標準化比例 t = (giftValue - 1000) / 2000]
    Interp --> CalGain[計算增量 = 10 + 20 * t 並四捨五入 round]
    CalGain --> OutGain([回傳整數好感增量])
    MinGain --> OutGain
    MaxGain --> OutGain
```

### 4.1 數學計算模型
定義常數物件 `GIFT_RELATION_RANGE`：
- `minValue`: 1000（黃金最低門檻）
- `maxValue`: 3000（黃金最高收益上限）
- `minGain`: 10（最低保底好感）
- `maxGain`: 30（最高好感上限）

計算步驟：
$$t = \max\left(0, \min\left(1, \frac{\text{giftValue} - 1000}{3000 - 1000}\right)\right)$$
$$\text{Gain} = \text{round}\left(10 + (30 - 10) \times t\right)$$

- **範例一**：送禮 500 黃金 $\implies t = 0 \implies \text{Gain} = 10$。
- **範例二**：送禮 2000 黃金 $\implies t = 0.5 \implies \text{Gain} = 10 + 20 \times 0.5 = 20$。
- **範例三**：送禮 5000 黃金 $\implies t = 1.0 \implies \text{Gain} = 30$。

## 5. 季度自然衰退與單元測試契約

1. **季度自然衰退回歸（Quarterly Decay）**：
   - 處於非同盟狀態下的雙方，若無任何外交或軍事互動，每季邦交值自動朝 0（中立）衰退 2 點（正值減少 2 點，負值增加 2 點），防止世界格局長期僵化。
2. **單元測試驗收標準**：
   - 史實宿敵初始值 $-30$ 遭遇 `BETRAY_ALLIANCE`（$-80$），結算後嚴格夾取為 $-100$，不出現 $-110$。
   - 邦交值 $+90$ 執行 `ALLIANCE`（$+30$），結算後夾取為 $+100$。
   - 送禮 1000、2000、3000 金分別精確產出 $+10$、$+20$、$+30$ 點增益。

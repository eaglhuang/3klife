# 十四人祖譜標籤共鳴純血判定與宿敵繁育修正規格書

## 1. 模組職責與架構定位
本規格書規範宗族繁衍體系中的「14 人祖先相性標籤共鳴引擎（`KinAffinityEngine`）」、「同族純血極限判定」以及「宿敵配種之受孕折減模型（`EnemyBreedingModifier`）」。模組以純函式結構比對親代祖譜特質，提供透明且確定性的爆發力 EP 與受孕率修正。

```
┌─────────────────────────────────────────────────────────────┐
│                 KinAffinity & Enemy Modifier                │
├──────────────────────────────┬──────────────────────────────┤

```

## 2. 14 人祖先標籤共鳴與純血判定模型

### 2.1 共有標籤計數與共鳴階梯
繁衍時，系統遍歷父母雙方完整 14 人祖譜（`Ancestors_JSON`），提取各自祖先之特質標籤集合（`TagSet`）並求交集：
$$\text{SharedTags} = \text{TagSet}_{\text{Father}} \cap \text{TagSet}_{\text{Mother}}$$
$$\text{SharedCount} = |\text{SharedTags}|$$

- **標籤共鳴（$\text{SharedCount} \ge 3$）**：
  子嗣爆發力加算 **$\text{EP} + 15$** 點。
- **家風觸發（$\text{SharedCount} \ge 5$）**：
  子嗣額外解鎖宗族固有「家風傳承（`FamilyPrestigeTrait`）」專屬被動。
- **極限純血加成（`Pureblood`）**：
  若雙方 14 人祖譜之始祖宗源完全一致（同屬同一原初古族門閥且未混入雜血），判定為極限純血，加算 **$\text{EP} + 30$** 點。

```typescript
export interface AncestorTagMatchResult {
  sharedTagCount: number;
  hasTagResonance: boolean; // ≥ 3
  hasFamilyPrestige: boolean;// ≥ 5
  isPureblood: boolean;     // 14 人全同宗
  epBonus: number;
}

export function evaluateAncestorTags(
  fatherTags: string[],
  motherTags: string[],
  isPurebloodAncestry: boolean
): AncestorTagMatchResult {
  const motherTagSet = new Set(motherTags);
  const shared = fatherTags.filter(t => motherTagSet.has(t));
  const count = shared.length;

  let ep = 0;
  if (isPurebloodAncestry) {
    ep += 30;
  } else if (count >= 3) {
    ep += 15;
  }

  return {
    sharedTagCount: count,
    hasTagResonance: count >= 3,
    hasFamilyPrestige: count >= 5,
    isPureblood: isPurebloodAncestry,
    epBonus: ep
  };
}
```

## 3. 宿敵配種受孕率懲罰模型

### 3.1 宿敵名單比對與受孕折減
當繁育雙方登錄於史實宿敵資料表（`ENEMY_PAIR`，例如「曹操 ＋ 袁紹」、「周瑜 ＋ 諸葛亮」）時：
- **受孕率折減**：基礎受孕率直接乘以 **$0.70$（七折）**：
  $$\text{EnemyConceptionRate} = \text{BaseConceptionRate} \times 0.70$$
- **狼性因子突變鉤子**：繁育成功時，子嗣有 $35\% \sim 50\%$ 機率觸發白色「狼性」因子變異，獲得絕境不潰戰場特權。

```typescript
export function applyEnemyPairConception(
  baseRate: number,
  isEnemyPair: boolean
): { effectiveRate: number; isEnemyPenalized: boolean } {
  if (isEnemyPair) {
    return {
      effectiveRate: Number((baseRate * 0.70).toFixed(4)),
      isEnemyPenalized: true
    };
  }
  return { effectiveRate: baseRate, isEnemyPenalized: false };
}
```

## 4. 單元測試驗證規範
1. **TC-TAG-RESONANCE（共有 3 標籤 EP+15）**：父方 `[智, 勇, 義]`，母方 `[智, 勇, 義, 仁]`，共有 3 標籤，回傳 `epBonus = 15`，`hasFamilyPrestige = false`。
2. **TC-TAG-PUREBLOOD（純血最高優先 EP+30）**：`isPurebloodAncestry = true`，回傳 `epBonus = 30` 且 `isPureblood = true`。
3. **TC-ENEMY-PENALTY（宿敵 7 折折減）**：基準受孕率 0.80，判定為宿敵配對，有效受孕率精確折減為 $0.80 \times 0.70 = 0.56$。

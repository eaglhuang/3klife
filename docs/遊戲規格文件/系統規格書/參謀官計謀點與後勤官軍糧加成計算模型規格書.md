# 參謀官計謀點與後勤官軍糧加成計算模型規格書

## 1. 核心定位與幕僚職能契約

本規格書為出征編制中參謀官（Strategist）與後勤官（Deputy）戰術資源加成演算法（Staff Support Bonus Model，代號 `DEP-09`）的單一真相來源（Single Source of Truth）。參謀官主要提供戰場計謀點（Tactic Points）之容積擴充與開局補點；後勤官則依據統率與政治素養，擴大戰略軍糧上限並提供開局補給燃料。

```typescript
export interface StaffBonusContract {
  maxTacticCapBonus: 30;          // 參謀計謀點上限加成天花板 30
  maxTacticStartBonus: 15;        // 參謀開局補點加成天花板 15
  maxDeputyFoodRate: 0.18;        // 後勤軍糧加成比率天花板 18%
}
```

---

## 2. 參謀官計謀點加成模型（Strategist Bonus）

參謀官之智力（INT）與政治（POL）共同決定戰場計謀點的擴充能力：

### 2.1 謀略評分公式

$$\text{Score} = (\text{INT} \times 0.7) + (\text{POL} \times 0.5)$$

### 2.2 計謀上限與開局補點

$$\text{MaxTacticBonus} = \min\left(30, \left\lfloor \frac{\text{Score}}{10} \right\rfloor\right)$$

$$\text{StartTacticBonus} = \min\left(15, \left\lfloor \text{MaxTacticBonus} \times 0.5 \right\rfloor\right)$$

- **上限封頂**：計謀點上限擴充最高不超過 30 點。
- **開局補點**：開局直接獲得上限增量的一半（最高 15 點）。
- **數值範例**：
  - 諸葛亮（智力 100、政治 95）：$\text{Score} = 70 + 47.5 = 117.5$。上限加成 $\lfloor 11.75 \rfloor = 11$ 點，開局補給 $\lfloor 5.5 \rfloor = 5$ 點。
  - 神話級謀士（智力 400、政治 200）：$\text{Score} = 280 + 100 = 380$。觸發天花板，上限加成 30 點，開局補給 15 點。

## 3. 後勤官軍糧補給加成模型（Deputy Food Bonus）

後勤官主要依據統率（LEA，軍紀調配）與政治（POL，後勤輜重治理）擴大軍糧儲備：

### 3.1 補給係數公式

$$\text{Rate} = \min\left(0.18, 0.03 + (\text{LEA} \times 0.001) + (\text{POL} \times 0.0006)\right)$$

### 3.2 軍糧上限與開局補給額度

$$\text{FoodCapBonus} = \lfloor \text{BaseFoodCap} \times \text{Rate} \rfloor$$

$$\text{StartingFoodBonus} = \text{FoodCapBonus}$$

- **基礎補給底線**：只要指派後勤官，即便屬性極低，亦享有至少 3% 基礎加成。
- **18% 邊界天花板**：補給比率強制封頂於 $18\%$（$\text{Rate} \le 0.18$），避免高屬性導致戰場軍糧無限溢出。
- **數值範例**：
  - 曹仁（統率 80、政治 50）：$\text{Rate} = 0.03 + 0.08 + 0.03 = 0.14$（$14\%$）。基礎糧草 1,000 時，上限擴充 140 糧，開局額外補給 140 糧。
  - 頂級後勤官（統率 300、政治 300）：$\text{Rate} = 0.03 + 0.30 + 0.18 = 0.51$，觸發天花板截斷為 $18\%$（加成 180 糧）。

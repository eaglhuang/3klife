# 同名武將多版本資料模型與戰場名號限定排他規格書

## 1. 模組職責與架構定位
本規格書規範名將在遊戲中的「同名多時期多版本資料結構（`GeneralVersion`）」以及出征作戰時的「名號限定編隊排他閘門（`SortieDeploy.validateSortieLoadout`）」。系統支援不同年份、戰役時期的名將獨立抽樣與養成，同時在戰場編隊層施加血統唯一性硬性約束，徹底杜絕「雙趙雲同場」的邏輯違和。

```
┌─────────────────────────────────────────────────────────────┐
│                 General Version & Sortie Guard              │
├──────────────────────────────┬──────────────────────────────┤
│ 同名多版本資料結構           │ 戰場名號限定排他閘門         │
│ 同一 bloodlineId 錨定歷史本體│ 出征隊列 bloodlineId 唯一性   │
│ 獨立 templateId 與初始因子   │ 重複者阻斷出征並標記衝突     │
└──────────────────────────────┴──────────────────────────────┘
```

## 2. 同名多版本資料結構與 Schema

```typescript
export interface GeneralVersionConfig {
  templateId: string;       // 具體版本唯一鍵（如 GEN_ZHAO_YOUTH, GEN_ZHAO_SSR）
  bloodlineId: string;      // 歷史本體血脈錨點（如 BLD_ZHAO_YUN）
  title: string;            // 稱號（如「白馬先鋒」、「常山真龍」）
  isLimited: boolean;       // 是否為限定活動卡
  initialGenePool: string[];// 該時期專屬初始因子庫
  baseLifespanModifier: number;
}
```

- **歷史血脈錨點（`bloodlineId`）**：跨版本一致，用於家族譜系繼承、近親判定與戰場排他。
- **時期範本鍵（`templateId`）**：版本專屬，用於立繪掛載、專屬台詞與戰法初始槽位配置。

## 3. 戰場名號限定編隊排他狀態機

### 3.1 出征隊列唯一性審查
玩家在戰備介面配置出征名單時，系統在確認點擊「全軍出征」瞬間觸發驗證器：
$$\text{UniqueBloodlines} = \text{Unique}\left(\left\{ \text{unit.bloodlineId} \mid \text{unit} \in \text{SortieRoster} \right\}\right)$$
$$\text{IsLoadoutValid} = \left( |\text{UniqueBloodlines}| = |\text{SortieRoster}| \right)$$

- 若 $|\text{UniqueBloodlines}| < |\text{SortieRoster}|$，判定整隊失敗。
- 拋出錯誤代碼 `SAME_BLOODLINE_FORBIDDEN`，並於 UI 彈出：
  `UI_SAME_NAME_REJECT: 同一名號武將不可同時編入同一戰場！`

```typescript
export interface SortieValidationResult {
  isValid: boolean;
  conflictingBloodlineId?: string;
  conflictingNames?: string[];
  errorMessage?: string;
}

export function validateSortieBloodlineUnique(
  roster: Array<{ generalId: string; name: string; bloodlineId: string }>
): SortieValidationResult {
  const seenBloodlines = new Map<string, string>(); // bloodlineId -> name

  for (const unit of roster) {
    if (seenBloodlines.has(unit.bloodlineId)) {
      const prevName = seenBloodlines.get(unit.bloodlineId)!;
      return {
        isValid: false,
        conflictingBloodlineId: unit.bloodlineId,
        conflictingNames: [prevName, unit.name],
        errorMessage: 'UI_SAME_NAME_REJECT'
      };
    }
    seenBloodlines.set(unit.bloodlineId, unit.name);
  }

  return { isValid: true };
}
```

## 4. 單元測試驗證規範
1. **TC-SORTIE-PASS（無衝突順利出征）**：編隊包含趙雲（BLD_ZHAO）、關羽（BLD_GUAN）、張飛（BLD_ZHANG），回傳 `isValid = true`。
2. **TC-SORTIE-REJECT（同名雙版本攔截）**：編隊同時納入青年趙雲與常山趙雲（同為 BLD_ZHAO），回傳 `isValid = false`，且標記衝突名字。
3. **TC-VERSION-MODEL（多版本血脈錨定）**：檢查青年版與常山版，其 `templateId` 不同但 `bloodlineId` 嚴格相等。

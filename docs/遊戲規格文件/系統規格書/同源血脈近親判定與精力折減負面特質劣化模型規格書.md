# 同源血脈近親判定與精力折減負面特質劣化模型規格書

> 標籤：`BLT-05` · `M2` · `近親判定` · `血脈劣化` · `純化升星` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，父母具備相同血脈標識（`bloodlineId`）時觸發之「近親血脈判定（`isSameBloodline`）」、子嗣精力上限打折、學府育成負面特質機率激增之劣化懲罰模型，以及伴隨之「30% 因子純化升星」補償機制。

本模組為純邏輯無副作用運算，嚴格區隔合法結緣與數值懲罰邊界。

---

## 2. 同源血脈判定規則

當結緣雙方同時具備有效且相同的家族血脈標籤時，判定為同源血脈結緣：

```typescript
export function isSameBloodline(father: GeneralConfig, mother: GeneralConfig): boolean {
    return !!father.bloodlineId && father.bloodlineId === mother.bloodlineId;
}
```

- 若任一方無血脈 ID 或雙方血脈 ID 不一致，則視為異脈通婚（Outcross），不觸發近親懲罰。
- 三代內共同祖先禁婚阻絕（`BRD-05`）屬於硬前置阻擋；本規格書處理跨過禁婚檢查但隸屬同宗世族之同源近親數值懲罰。

---

## 3. 三重近親劣化懲罰機制

經確認為同源血脈孕育之子嗣，出生時強制套用三重劣化修正：

```typescript
export const INBREEDING_VITALITY_MULTIPLIER = 0.7;
export const INBREEDING_NEGATIVE_TRAIT_BONUS = 0.5;
```

### 3.1 先天精力上限折減（打七折）
子嗣之最大精力值（`maxVitality`）受到 $0.70$ 乘區懲罰：
$$\text{MaxVitality}_{\text{child}} = \left\lfloor \frac{\text{Vigor}_{\text{father}} + \text{Vigor}_{\text{mother}}}{2} \times 0.70 \right\rfloor$$
子嗣天生耐力受損，在後續學府 36 回合育成中體力恢復速度受限，大幅提高疲憊判定頻率。

### 3.2 育成負面特質機率激增（$+50\%$）
子嗣資料結構中寫入 `negativeTraitRateBonus = 0.50`：
- 在學府育成狀態機（`NurtureSystem`）各回合結算時，出現厭學、驕縱、殘暴等負面特質之判定機率直接疊加 $+50\%$。

### 3.3 隱藏標記懲罰存檔
子嗣 `hiddenFlags` 陣列中主動寫入 `'inbreeding-penalty'`，作為後續成就審計與世家名望結算之永久記錄。

## 4. 近親血脈純化補償機制（Purification）

為還原世家大族強化特定門風天賦之策略性，近親孕育具備孤注一擲之「純化」收益：

```typescript
export const INBREEDING_PURIFICATION_CHANCE = 0.3;
```

1. **同名因子檢測**：若子嗣繼承之因子中，父方與母方皆提供相同之特質因子（如雙方祖輩皆帶有神速或謀略）。
2. **純化擲骰判定**：每個重疊同名因子享有 **$30\%$ 機率** 觸發血脈純化。
3. **星等提升**：命中純化之因子，初始星等額外 $+1$ 星（例如 ★3 升為 ★4，受限於單項上限 ★5）。

## 5. 介面契約與策略反饋

結緣面板（`BondingSetupController`）在玩家選定同源血脈父母時，即時響應以下展示：

| 欄位 / 狀態 | 介面展示文案 | 風險與收益提示 |
|---|---|---|
| **血脈警告** | `【同源近親】血脈純度過高` | 提示精力上限 $\times 0.7$、負面特質 $+50\%$ |
| **純化博弈** | `具備 30% 因子純化升星潛質` | 高亮顯示父母共有之因子，供硬核玩家挑戰極限數值 |
| **協同限制** | `禁用 Lineage Synergy 外部加成` | 阻絕跨世族聯姻之特權收益 |

> **系統分類**：人物政治 / 託孤攝政與宮廷權力轉移管線  
> **狀態**：正式生效（單一真相來源，嚴禁尾端追加補丁）

## 1. 系統架構定位與臨終託孤千古悲壯

君才十倍於曹丕，必能安國，終定大事。若嗣子可輔，輔之；如其不才，君可自取。《三國人生》（3KLife）重現三國最高規格之政治權力交接，實裝**白帝城臨終託孤與相父攝政輔臣狀態機（Deathbed Entrustment & Regency）**。

本系統核心價值：
1. **託孤誓約資料綁定（Orphan Pact Protocol）**：先帝臨終指定輔臣，確立政治合法性。
2. **幼主期主政特權（Regency Authority）**：幼主成年（未滿 18 歲）前，攝政輔臣全權代行君權，免除主少國疑之動盪。
3. **鞠躬盡瘁 vs 權臣篡立的分野**：由攝政名將的底層義理與野心光譜決定其最終歸宿。

## 2. 託孤誓約資料結構

當君主天年耗盡或重傷彌留之際，觸發「臨終託孤」大典：

```typescript
export interface ITrustOrphanPact {
  readonly pactId: string;
  readonly dyingMonarchId: string;       // 駕崩先帝 (如: 劉備、曹叡)
  readonly regentGeneralId: string;       // 受託相父/攝政輔臣 (如: 諸葛亮、司馬懿)
  readonly heirGeneralId: string;         // 繼位幼主 (如: 劉禪、曹芳)
  isHeirAdult: boolean;                  // 幼主是否已年滿 18 歲成年
  regentLoyaltyToDynasty: number;        // 攝政對王朝忠誠度 (0 ~ 100)
  courtStabilityBonus: number;           // 朝廷穩定度加成 (+20)
}
```

## 3. 相父攝政特權與「主少國疑」免疫

幼主未成年期間，國策系統啟動「相父執政態勢（Regency Stance）」：
1. **全權軍政決策**：玩家直接操作攝政輔臣（而非幼主）進行城市建設、調兵遣將、宣戰外交與下發《出師表》。
2. **文武百官敬服**：只要攝政統率與智力 $\ge 85$，全國所有太守與武將**忠誠度不因君主年幼而衰減**，免疫「少主登基、地方自立」之內戰事件。
3. **相父激勵光環**：攝政出征時，部隊獲得「奉先帝遺詔出師」增益，全軍士氣每回合自然回復 $+2$。

## 4. 鞠躬盡瘁 vs 權臣篡立（Regent Alignment）

幼主年滿 18 歲成年之際，觸發「歸政親政（Handover of Power）」檢定，依攝政之性格光譜迎來雙重命運：

```
                 [幼主年滿 18 歲成年大典]
                             │
       ┌─────────────────────┴─────────────────────┐
       ▼ (義理 >= 85: 諸葛亮模範)                   ▼ (野心 >= 80: 司馬昭模範)
【鞠躬盡瘁，奉還大政】                       【指洛水為誓，權臣篡位！】
主動交割兵權玉璽，功成身退                   架空廢黜幼主，自立為帝改朝換代！
```

1. **忠貞烈士型（諸葛亮）**：
   - 遵守先帝重託，上表還政於幼主，自身以宰相身分繼續輔政。
   - 獲得【千秋武侯】稱號，全勢力民心與凝聚力鎖定滿值 100。
2. **野心梟雄型（司馬懿、司馬昭）**：
   - 拒絕交出兵符，指洛水為誓誅殺幼主親信黨羽，發動「高平陵事變」。
   - 幼主被軟禁或禪讓，攝政輔臣**黃袍加身正式登基稱帝**，改立新國號！

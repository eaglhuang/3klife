# 名將占卜因子定向覺醒與先知陷阱扭曲預言規格書

> 標籤：`FUL-07` · `FUL-08` · `M8` · `M9` · `名士占卜` · `因子覺醒` · `先知陷阱` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，玩家消耗「求籤令」委託當世六大名士進行天機占卜，定向催化鎖定因子覺醒，或因名士個人盲點觸發「先知陷阱（扭曲預言）」之機率模型（`SageDivination`）。

本模組為純邏輯無副作用運算，負責計算占卜結果與偏好加權抽選，道具消耗與累積占卜計數由 `GameSession` 總控。

## 3. 占卜雙分支狀態機與先知陷阱

每次占卜嚴格依循名士準確率（`accuracy`）進行二元分支：

```
                    ┌─────────────────────────┐
                    │      名士占卜請求       │
                    └────────────┬────────────┘
                                 │
                   [ 武將是否有可覺醒之候選因子? ]
                   ├── 否 ──> no-candidate (不扣求籤令, 不消耗)
                   └── 是
                                 │
                   ┌─────────────┴─────────────┐
                   │ 消耗求籤令 (consumed = true) │
                   │ 擲骰: random() <= accuracy │
                   └─────────────┬─────────────┘
                                 │
                     [ 命中準確率 (非扭曲)? ]
                     ├── 是 ──> pickWeighted 加權抽樣 ──> awakenFactor (覺醒成功)
                     └── 否 ──> 先知陷阱: distorted (不覺醒, 僅給予偏見提示)
```

### 3.1 分支詳細行為說明
1. **合理預言（`awakened`）**：
   - 名士洞察天機，自武將當前可覺醒之候選因子中抽樣。
   - 吻合名士偏好色系（`biasColors`）之因子享有 **3 倍加權**，顯著提高定向覺醒指定因子的機率。
   - 抽中因子立即執行 `awakenFactor` 點亮生效。
2. **先知陷阱扭曲（`distorted`）**：
   - 名士受自身認知偏誤所限，預言失準；
   - 本次**不覺醒任何因子**，僅回傳名士偏見方向之提示色（如諸葛亮回傳藍色、華佗回傳紅色、司馬徽回傳 `null`），生動模擬古代方士誤判之隨機趣味。

## 4. 求籤令消耗防護守則

- **零無辜扣款**：若武將身上無任何符合當前發現等級（`discoveryLevel`）之可覺醒因子，系統回傳 `outcome: 'no-candidate'`，`consumed` 強制設為 `false`，嚴禁扣除玩家之求籤令。
- **解鎖前置檢查**：若玩家累計占卜次數未達龐統（50次）或左慈（100次）之解鎖門檻，直接駁回請求（`sage-locked`），不觸發擲骰。

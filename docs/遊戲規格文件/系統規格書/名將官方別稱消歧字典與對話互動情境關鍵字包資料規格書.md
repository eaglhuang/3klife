# 3KLife 名將官方別稱消歧字典與對話互動情境關鍵字包資料規格書

> **規格代碼**：SPEC-DATA-BRAIN03  
> **關聯 WBS**：BRAIN-03（M11 武將主名冊/稱呼表與消歧）、BRAIN-05（M11 互動關鍵字抽取與 keyword pack）、NPC-02（M10 Context Option 情境鍵清單）  
> **文件版本**：v1.0.0 (單一真相來源，無補丁整併版)  
> **所屬系統**：數值、架構與底層支援（Formula, Architecture & Backend）

---

## 1. 核心宗旨與設計哲學

在三國歷史語境中，同一名將常具備姓名、字號、官職、封爵與民間尊稱等多重稱謂（如劉備為「玄德/使君/先主/皇叔」）。為確保客戶端在離線狀態下依然能精確消歧實體，並為對話介面提供結構化之情境關鍵字標籤（Keyword Chips），本規格書制定全域**官方別稱消歧字典（General Alias Dictionary）**與**對話情境關鍵字包（Context Keyword Pack）**資料規範。

---

## 2. 官方別稱消歧字典資料模型 (BRAIN-03)

字典以 JSON 格式部署於 `assets/resources/data/master/general-aliases.json`：

```typescript
export interface GeneralAliasEntry {
  canonicalGeneralId: string;         // 標準 ID (如 GEN_ZHAOYUN)
  officialName: string;               // 趙雲
  courtesyName: string;               // 子龍
  historicalHonorifics: string[];     // ["常山趙子龍", "虎威將軍", "順平侯"]
  relationshipAliases: string[];      // ["四弟", "子龍將軍"]
  prohibitedConfusions: string[];     // 嚴格禁止誤判之相似稱呼 (如趙範)
}

export interface OfficialAliasRegistry {
  version: '1.0.0';
  lastUpdated: number;
  entries: Record<string, GeneralAliasEntry>;
}
```

### 2.1 客戶端 O(1) 雙向消歧演算法

客戶端於啟動時建立逆向查表映射（`AliasInvertedMap: Record<string, string>`）：
- 輸入自然語言文本（如「請子龍出戰」），斷詞後比對映射表，直接將「子龍」消歧為 `GEN_ZHAOYUN`，查找複雜度為 $O(1)$，杜絕正則遞迴導致之卡頓。

## 3. 對話情境關鍵字包規範 (BRAIN-05 / NPC-02)

情境關鍵字包為對話介面提供一鍵發起話題之標籤集合（Keyword Pack）：

```typescript
export interface DialogueKeywordItem {
  keywordId: string;
  category: 'PERSON' | 'EVENT' | 'LOCATION' | 'ITEM' | 'CREATURE';
  displayLabel: string;               // 顯示文字 (長度限制 2~6 字)
  relevanceWeight: number;            // 關聯權重 (0.1 ~ 1.0)
  associatedContextKey: string;       // 如 "CTX_CHANG_BAN_PO"
}

export interface GeneralKeywordPack {
  generalId: string;
  keywords: DialogueKeywordItem[];
}
```

### 3.1 關鍵字五大分類約束

| 分類類別 | 範例標籤 (Labels) | 字數限制 | 前端 UI 晶片呈現 (Chip Style) |
|---|---|---|---|
| **PERSON** | 【劉備】、【諸葛孔明】、【曹孟德】 | 2 ~ 5 字 | 雅緻玄藍水墨標籤 |
| **EVENT** | 【長坂突圍】、【白馬之圍】、【單騎救主】 | 3 ~ 6 字 | 赤紅戰意印泥標籤 |
| **LOCATION** | 【當陽橋】、【漢水之濱】、【常山真定】 | 2 ~ 6 字 | 青綠山水印鑑標籤 |
| **ITEM** | 【青釭古劍】、【照夜玉獅子】、【白羽扇】 | 2 ~ 6 字 | 鎏金寶物暗紋標籤 |
| **CREATURE** | 【九天靈狐】、【玄武水精】、【墨鱗應龍】 | 2 ~ 6 字 | 紫微靈光浮雕標籤 |

## 4. 驗收測試案例 (Test Cases)

- **TC-BRAIN-03-01【多別稱精確消歧檢驗】**：分別輸入「先主」、「皇叔」、「玄德」、「漢中王」，消歧器 100% 準確解析為唯一 ID `GEN_LIUBEI`。
- **TC-BRAIN-03-02【相似名防混淆隔離】**：輸入「趙範」，消歧器比對 `prohibitedConfusions`，正確拒絕映射為趙雲，回傳無相符或獨立武將 ID。
- **TC-BRAIN-05-01【關鍵字標籤點擊填槽】**：在大廳對話介面點擊【長坂突圍】Chip，對話輸入框即時填入該主題，並自動附加 `associatedContextKey = "CTX_CHANG_BAN_PO"`。

# 名將挑戰賽九州盃極端場景賽特殊規則與戰力倍率規格書

> **模組識別碼**：`TRN-14`  
> **系統歸屬**：名將挑戰賽（Tournament）九州盃特殊賽制  
> **單一真相來源**：本規格書確立名將挑戰賽九州盃極端場地環境定義、四大史實戰役特殊規則標籤、以及戰力倍率動態疊乘演算法之唯一權威標準。

---

## 一、系統概述與架構原則

九州盃為名將挑戰賽中具備極端戰場環境之特別賽事。在九州盃中，戰場除了常規的地形與天氣修正外，額外套用特定「戰役專屬特殊規則（Special Rule）」。符合特殊標籤之武將或戰法將獲得強大的攻擊增幅或遭受嚴苛壓制，顛覆常規戰術平衡。

### Unity / 架構對照
- **環境修飾器**：類似 Unity 戰鬥管線中的 `BattleFieldModifier`，以唯讀 Dictionary 配置標籤倍率。
- **純量乘法模型**：戰力倍率計算為純數學累乘，不依賴物理碰撞或特定動畫狀態。

## 三、戰力倍率動態累乘演算法

當出戰武將或陣容快照計算其九州盃實效總戰力時，遍歷武將具備之所有攻擊標籤，並將命中之規則乘數進行鏈式累乘：

$$\text{FinalMultiplier} = \prod_{t \in \text{AttackTags}} (\text{table}[t] \text{ if exists else } 1.0)$$

```typescript
export function cupSpecialPowerMultiplier(
    specialRule: SpecialRuleConfig | undefined,
    attackTags: readonly string[] | undefined
): number {
    if (!specialRule || !specialRule.tagMultipliers || !attackTags || attackTags.length === 0) {
        return 1.0;
    }
    
    const table = specialRule.tagMultipliers;
    return attackTags.reduce((multiplier, tag) => {
        const factor = table[tag];
        return typeof factor === 'number' && Number.isFinite(factor) ? multiplier * factor : multiplier;
    }, 1.0);
}
```

- **複合標籤抵消範例**：
  在夷陵盃中，若武將同時具備 `RANGED` 與 `TRAP` 標籤，其倍率為 $0.5 \times 2.0 = 1.0$。

---

## 四、陣容總戰力結算整合

在登錄陣容快照（`registerTournamentTeam`）時，每位武將的基準戰力依此演算法即時加權，形成該盃賽之專屬快照總戰力：

$$\text{TotalPower} = \sum_{i=1}^{N} \left\lfloor \max(0, P_i) \times \text{Multiplier}_i \right\rfloor$$

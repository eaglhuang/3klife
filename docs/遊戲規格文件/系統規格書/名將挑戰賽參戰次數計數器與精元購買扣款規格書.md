# 名將挑戰賽參戰次數計數器與精元購買扣款規格書

> **模組識別碼**：`TRN-08`  
> **系統歸屬**：名將挑戰賽（Tournament）參戰額度與精元經濟  
> **單一真相來源**：本規格書確立名將挑戰賽每日 1 次免費參戰、額外參戰每次固定 30 精元、每日 5 次總上限與原子交易扣款狀態機之唯一權威標準。

---

## 一、系統概述與架構原則

為了兼顧平民玩家的每日參與感與付費玩家的競逐空間，名將挑戰賽實施嚴格的「階梯式每日入場門票配額機制」。所有參戰次數與貨幣扣款均由純邏輯狀態機驗證，杜絕超額參戰與重複扣款。

### Unity / 架構對照
- **經濟閘門**：類似 Unity 中的 `TournamentEntryService`，與背包貨幣系統以回調介面（Closure Callback）解耦。
- **事務保護**：確保「扣款成功」與「次數累加」具備原子性（Atomicity），若付費失敗絕不推進次數。

## 二、每日參戰配額與定價標準

```typescript
export const TOURNAMENT_ENTRY_CONFIG = {
    dailyFreeEntries: 1,  // 每日免費參戰次數
    extraEntryCost: 30,   // 額外參戰消耗精元（Spirit Jade）
    maxDailyEntries: 5,   // 每日參戰次數總上限（1 免費 + 4 付費）
} as const;
```

### 每日參戰階梯表

| 序號 | 參戰次數標籤 | 門票消耗 | 是否需要付費確認 | 說明 |
|:---:|---|:---:|:---:|---|
| 第 1 次 | 每日首戰 | **免費 (0)** | 否 | 每日登入重置後享有 |
| 第 2 次 | 額外參戰 #1 | **30 精元** | 是 (`payExtra`) | 扣款成功方可入場 |
| 第 3 次 | 額外參戰 #2 | **30 精元** | 是 (`payExtra`) | 扣款成功方可入場 |
| 第 4 次 | 額外參戰 #3 | **30 精元** | 是 (`payExtra`) | 扣款成功方可入場 |
| 第 5 次 | 額外參戰 #4 | **30 精元** | 是 (`payExtra`) | 當日最後一次參戰 |
| 第 6 次起 | 超額被拒 | **禁止參戰** | - | 強制阻絕，提示明日再來 |

## 三、參戰次數判定與跨日維護狀態機

### 1. 今日已用次數解析
```typescript
export function getEntriesUsedToday(
    currentDay: number,
    recordedEntryDay: number,
    recordedEntriesToday: number
): number {
    // 若記錄的日序與當前日序不同，代表已跨日，今日已用次數歸零
    return currentDay === recordedEntryDay ? recordedEntriesToday : 0;
}
```

### 2. 參戰資格驗證與原子扣款狀態轉移
```typescript
export type TournamentEntryCheckResult = 
    | { allowed: true; isPaid: boolean }
    | { allowed: false; reason: 'DAILY_LIMIT_REACHED' | 'PAYMENT_DECLINED' };

export function verifyAndDeductEntry(
    usedToday: number,
    payExtraFn: (cost: number) => boolean
): TournamentEntryCheckResult {
    const cfg = TOURNAMENT_ENTRY_CONFIG;
    
    // 1. 上限檢驗：是否達到每日 5 次上限
    if (usedToday >= cfg.maxDailyEntries) {
        return { allowed: false, reason: 'DAILY_LIMIT_REACHED' };
    }
    
    // 2. 免費門票檢驗：尚未用完免費額度
    if (usedToday < cfg.dailyFreeEntries) {
        return { allowed: true, isPaid: false };
    }
    
    // 3. 付費門票檢驗：需支付 30 精元
    const paymentSuccess = payExtraFn(cfg.extraEntryCost);
    if (!paymentSuccess) {
        return { allowed: false, reason: 'PAYMENT_DECLINED' };
    }
    
    return { allowed: true, isPaid: true };
}
```

- **原子性保證**：若 `payExtraFn` 回傳 `false`（例如玩家餘額不足或於彈窗點擊取消），入場驗證立即中斷，狀態機不進行任何變更。

## 四、驗收條件與測試案例 (Test Cases)

- **TC-TRN-21（每日首次免費）**：
  - 今日已用 0 次，參戰直接成功，`isPaid` 為 `false`，不調用 `payExtraFn`。
- **TC-TRN-22（付費參戰扣除 30 精元）**：
  - 今日已用 1 次，參戰調用 `payExtraFn(30)`；若回傳 `true`，參戰成功，次數累加至 2。
- **TC-TRN-23（付費失敗次數不累加）**：
  - 今日已用 2 次，`payExtraFn(30)` 回傳 `false`，參戰被拒回傳 `PAYMENT_DECLINED`，次數仍維持 2。
- **TC-TRN-24（達到 5 次上限絕對阻絕）**：
  - 今日已用 5 次，再次請求參戰直接回傳 `DAILY_LIMIT_REACHED`，不調用 `payExtraFn`。

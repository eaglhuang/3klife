# 名將挑戰賽月度場景賽十二月主題與評分演算法規格書

> **模組識別碼**：`TRN-15`  
> **系統歸屬**：名將挑戰賽（Tournament）月度場景賽特別賽制  
> **單一真相來源**：本規格書確立名將挑戰賽月度場景賽 1~12 月完整主題與限制規則、參賽資格防護、Monthly_Score 積分評定模型與歷史存檔之唯一權威標準。

---

## 一、系統概述與架構原則

月度場景賽（Monthly Scenario Cup）為每個月定期舉行之特色限制賽事。每月指定特定戰場限制（如特定兵種適性要求、戰法禁用或指定屬性威力加成）。月度場景賽**獨立計分（Monthly_Score），不計入常規主賽排名積分（Points）**，為多樣化陣容培育提供展示舞台。

### Unity / 架構對照
- **獨立賽制控制器**：類似 Unity 中的 `MonthlyCupController`，與主賽控制器並行運作。
- **純規則檢驗器**：無介面耦合，支援單元測試快速驗證 12 個月份的所有限制。

## 三、參賽資格檢驗狀態機

```typescript
export type MonthlyScenarioViolation = 'banned-tactic' | 'missing-aptitude';

export function monthlyScenarioViolationOf(
    scenario: Readonly<MonthlyScenario>,
    entrant: { troopAptitude?: Readonly<Record<string, string>>; tacticTags?: readonly string[] }
): MonthlyScenarioViolation | null {
    const rule = scenario.rule;
    
    // 1. 禁用戰法檢驗
    if (rule.kind === 'ban-tactic-tag') {
        if (entrant.tacticTags && entrant.tacticTags.includes(rule.tag)) {
            return 'banned-tactic';
        }
    }
    
    // 2. 必要適性檢驗（限定 S 或 A 級）
    if (rule.kind === 'require-aptitude') {
        const aptTable = entrant.troopAptitude ?? {};
        const hasRequired = rule.aptitudes.some(t => ['S', 'A'].includes(aptTable[t] ?? ''));
        if (!hasRequired) {
            return 'missing-aptitude';
        }
    }
    
    return null; // 無違規，允許參賽
}
```

## 四、Monthly_Score 評分演算法與歷史存檔

### 1. 評分公式
$$\text{Monthly\_Score} = \sum_{i=1}^{M} \left[ (\text{StatTotal}_i \times \text{TerrainMult}) + (\text{TacticPoints}_i \times \text{SceneCounter}) \right] \times \text{SurvivalFactor}$$

- `SceneCounter`：場景克制係數，預設基準為 $1.0$。

### 2. 歷史歸檔（同月僅留最高分）
```typescript
export function recordMonthlyScenario(
    history: readonly MonthlyScenarioHistoryEntry[],
    entry: MonthlyScenarioHistoryEntry
): MonthlyScenarioHistoryEntry[] {
    const existing = history.find(h => h.monthKey === entry.monthKey);
    if (existing && existing.score >= entry.score) {
        return [...history]; // 現有分數更高，不更新
    }
    return [...history.filter(h => h.monthKey !== entry.monthKey), entry];
}
```

## 五、驗收條件與測試案例 (Test Cases)

- **TC-TRN-45（1 月禁用騎兵戰法）**：
  - 1 月賽事中，武將若攜帶 `cavalry` 戰法標籤，回傳 `banned-tactic`；更換為純步兵戰法後回傳 `null` 通過。
- **TC-TRN-46（2 月赤壁水軍適性篩選）**：
  - 2 月賽事中，水軍適性為 B 且弓兵適性為 C，回傳 `missing-aptitude`；水軍適性為 A 則順利通過。
- **TC-TRN-47（同月份最高分保留）**：
  - 2026-06 賽季初次取得 8000 分，再次挑戰取得 7500 分，歷史紀錄仍維持 8000 分；若取得 9200 分則覆蓋。
- **TC-TRN-48（月份超限保護）**：
  - 傳入 month 為 0 或 13，回傳 `null`，不拋出未捕獲例外。

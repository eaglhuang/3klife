# 名將挑戰賽段位獎勵黃金階梯表與單次發放防重複規格書

> **模組識別碼**：`TRN-10`  
> **系統歸屬**：名將挑戰賽（Tournament）賽季獎勵發放與結算  
> **單一真相來源**：本規格書確立名將挑戰賽歷史賽季結算之六階段位黃金獎勵標準、領取資格三要件驗證、以及單次全額領取防重複刷取狀態機之唯一權威標準。

---

## 一、系統概述與架構原則

名將挑戰賽在每季賽事正式結束並跨入新賽季後，依據玩家在已結算賽季之最終段位發放對應之黃金獎勵。為杜絕重複領獎與資料競爭，獎勵領取採嚴格的狀態標記防護，確保「已參賽者必得、未參賽者不發、領取後永久失效」。

### Unity / 架構對照
- **獎勵結算器**：類似 Unity 中的 `TournamentRewardClaimService`，產出不可變發獎 DTO，交由資產服務入庫。
- **冪等設計**：任何重複呼叫 `claimTournamentRewards` 皆具備冪等性（Idempotence），不重複產出貨幣。

## 三、待領取資格三要件驗證演算法

系統在提供玩家領獎介面或執行結算時，對歷史紀錄進行嚴格篩選：

```typescript
export interface TournamentSeasonReward {
    seasonIndex: number;
    tier: RankTier;
    gold: number;
}

export function pendingTournamentRewards(state: Readonly<TournamentState>): TournamentSeasonReward[] {
    return state.history
        // 篩選三要件：
        // 1. 已是歷史紀錄（封存於 state.history 中）
        // 2. 必須曾有參賽快照（snapshotId !== null），未登錄未參賽者不予發獎
        // 3. 該賽季尚未領取獎勵（!h.rewardClaimed）
        .filter((h) => h.snapshotId !== null && !h.rewardClaimed)
        .map((h) => ({
            seasonIndex: h.seasonIndex,
            tier: h.finalTier,
            gold: TOURNAMENT_SEASON_REWARD_GOLD[h.finalTier],
        }));
}
```

## 四、一次性領取與防重複狀態機

```typescript
export function claimTournamentRewards(state: Readonly<TournamentState>): {
    state: TournamentState;
    rewards: TournamentSeasonReward[];
} {
    const rewards = pendingTournamentRewards(state);
    
    // 若無任何待領取項目，直接原樣回傳，避免產生多餘物件拷貝
    if (rewards.length === 0) {
        return {
            state: { ...state, history: state.history.slice() },
            rewards: [],
        };
    }
    
    // 翻轉歷史標記：將所有符合資格項目的 rewardClaimed 設為 true
    const updatedHistory = state.history.map((h) =>
        h.snapshotId !== null && !h.rewardClaimed
            ? { ...h, rewardClaimed: true }
            : h
    );
    
    return {
        state: { ...state, history: updatedHistory },
        rewards,
    };
}
```

- **貨幣交付契約**：外層呼叫端（如 `LobbyScene` 或 `TournamentPanelController`）取得 `rewards` 陣列後，累加 `gold` 並寫入玩家資產存檔。

## 五、驗收條件與測試案例 (Test Cases)

- **TC-TRN-33（段位獎勵金額對齊）**：
  - 歷史紀錄為傳說段位（`LEGEND`），待領清單回傳 1500 金；白銀段位（`SILVER`）回傳 200 金。
- **TC-TRN-34（未參賽賽季無獎勵）**：
  - 歷史條目之 `snapshotId` 為 `null`，即便段位顯示青銅，待領清單亦不包含該賽季。
- **TC-TRN-35（單次領取後標記已領）**：
  - 首次呼叫 `claimTournamentRewards` 回傳待領獎勵，且狀態中 `rewardClaimed` 變為 `true`。
- **TC-TRN-36（重複領取回傳空清單防刷）**：
  - 連續第二次呼叫 `claimTournamentRewards`，回傳之 `rewards` 長度必定為 0，金幣不再重複增加。

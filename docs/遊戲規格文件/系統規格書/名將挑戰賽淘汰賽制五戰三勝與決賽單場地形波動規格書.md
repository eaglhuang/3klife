# 名將挑戰賽淘汰賽制五戰三勝與決賽單場地形波動規格書

> **模組識別碼**：`TRN-06`  
> **系統歸屬**：名將挑戰賽（Tournament）淘汰賽制與對局模擬  
> **單一真相來源**：本規格書確立名將挑戰賽單機對戰樹四輪晉級架構、初賽/複賽/準決賽五戰三勝、決賽單場定勝負與單局 $\pm 5\%$ 地形臨場戰力波動判定之唯一權威標準。

---

## 一、系統概述與架構原則

名將挑戰賽以「單機階梯式對戰樹」為核心晉級機制。常規輪次採五戰三勝制，提供戰力微弱落後時的翻盤空間；決賽則採單場驟死賽，強調一戰定乾坤的高張力競爭。每局戰鬥引入 $\pm 5\%$ 的地形與天候臨場浮動，模擬真實戰場之瞬息萬變。

### Unity / 架構對照
- **賽事狀態機**：類似 Unity 中的 `TournamentBracketController`，維護當前輪次索引與奪冠統計。
- **純數值決策**：不調用物理或渲染組件，以純函式模擬多局勝負。

## 二、四輪對戰樹與賽制局數規則

對戰樹定義為四個連續輪次：

```typescript
export const TOURNAMENT_BRACKET_ROUNDS = ['初賽', '複賽', '準決賽', '決賽'] as const;
export const TOURNAMENT_FINAL_ROUND = TOURNAMENT_BRACKET_ROUNDS.length - 1; // 索引 3
```

### 輪次局數與勝場門檻表 (`bracketSeriesRule`)

```typescript
export interface SeriesRule {
    bestOf: number;    // 最大局數
    winNeeded: number; // 獲勝所需勝場
}

export function bracketSeriesRule(round: number): SeriesRule {
    return round >= TOURNAMENT_FINAL_ROUND
        ? { bestOf: 1, winNeeded: 1 } // 決賽：一場定勝負
        : { bestOf: 5, winNeeded: 3 }; // 前三輪：五戰三勝制
}
```

| 輪次索引 (`round`) | 輪次名稱 | 最大局數 (`bestOf`) | 獲勝門檻 (`winNeeded`) | 賽制說明 |
|:---:|---|:---:|:---:|---|
| 0 | 初賽 | 5 | 3 | 五戰三勝，最先取得 3 勝者晉級 |
| 1 | 複賽 | 5 | 3 | 五戰三勝，最先取得 3 勝者晉級 |
| 2 | 準決賽 | 5 | 3 | 五戰三勝，最先取得 3 勝者晉級 |
| 3 | 決賽 | 1 | 1 | 單場定勝負，贏者奪冠 |

## 三、單局 $\pm 5\%$ 地形與臨場戰力波動

在系列賽中的每一單局，雙方戰力各自受到地形天候影響產生 $[-5\%, +5\%]$ 浮動：

```typescript
export const TOURNAMENT_COMBAT_CONFIG = {
    terrainVariance: 0.05, // 地形波動範圍 5%（即 0.95 ~ 1.05 倍）
} as const;
```

給定基礎戰力 $P$，該局實效戰力 $P_{\text{eff}}$ 公式如下：

$$P_{\text{eff}} = P \times \left(1 - 0.05 + \text{random}() \times 0.10\right)$$

### 單局勝負判定準則
- 當局我方實效戰力 $P_{\text{mine}} \ge P_{\text{theirs}}$ 時，判定我方獲勝（平手亦視為進攻方獲勝）。
- 雙方持續對戰，直到任一方勝場數達到 `winNeeded` 或局數達到 `bestOf`。

## 四、晉級、奪冠與淘汰狀態轉移狀態機

```typescript
export interface BracketProgression {
    nextRound: number;
    championshipsDelta: number;
    isChampion: boolean;
}

export function evaluateBracketResult(currentRound: number, seriesWon: boolean): BracketProgression {
    const isFinal = currentRound >= TOURNAMENT_FINAL_ROUND;
    
    if (seriesWon) {
        if (isFinal) {
            // 決賽獲勝：奪冠！次數 +1，重置回初賽
            return { nextRound: 0, championshipsDelta: 1, isChampion: true };
        } else {
            // 前三輪獲勝：晉級下一輪
            return { nextRound: currentRound + 1, championshipsDelta: 0, isChampion: false };
        }
    } else {
        // 任一輪次落敗：淘汰，重置回初賽
        return { nextRound: 0, championshipsDelta: 0, isChampion: false };
    }
}
```

## 五、驗收條件與測試案例 (Test Cases)

- **TC-TRN-17（決賽與常規局數判定）**：
  - 輸入 round 0、1、2 回傳 `bestOf: 5, winNeeded: 3`。
  - 輸入 round 3 回傳 `bestOf: 1, winNeeded: 1`。
- **TC-TRN-18（系列賽搶三即停）**：
  - 若我方連贏 3 局，系列賽總局數為 3（不進行第 4、5 局），判定勝出。
- **TC-TRN-19（決賽奪冠狀態轉移）**：
  - 在 round 3 獲勝，`championships` 累加 1，`round` 歸零重回初賽。
- **TC-TRN-20（淘汰重置）**：
  - 在 round 2（準決賽）戰敗，`round` 立即重置為 0，奪冠數不變。

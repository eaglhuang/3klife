### L.2 目的
讓玩家一眼知道：比賽什麼時候開打、這屆是什麼場地、我該先練哪一類武將、一鍵就能去練。

### L.3 卡片兩態與玩家每步看到什麼
**培育期（dayInSeason 0–6）**
1. 標題 `名將挑戰賽・第 {n} 屆【{cup}】`；副標 `快開打了！還有 {daysToCompetition} 天進入競賽期`（`daysToCompetition = 7 - dayInSeason`，新增計算，不再顯示整季剩餘）。
2. 場地行 `場地：{terrain}、{weather}；{ruleLabel}`（例：`場地：水域、大風；火攻傷害 ×2`）。
3. 推薦區 `先練這些：` 後接兵種小標（最多 2 個，例 `弓兵`、`水軍`）與武將類型小標（最多 1 個，例 `火攻謀士`），每項下一行理由小字（例 `水域弓兵站得穩`）。
4. 一個主按鈕 `去培育`（→ 開啟大廳 `nurture` 分類並高亮「開獎・培育」；可帶 `focusHint` 供培育列表排序，選做）。**培育期不出現參戰鈕**。
5. 報名行維持 `競賽期第一次參戰會自動報名，不用先跑去報名`。

**競賽期（dayInSeason 7–13）**
1. 副標 `開打啦！還剩 {daysLeft} 天`。
2. 推薦區收合成一行 `這屆主打：{兵種}`（保留參考）。
3. 出現 `參戰` 主鈕；尚未報名時按下自動報名並鎖陣容（沿用現行 `register`，文案 `已幫你報名，陣容鎖定為目前戰力前三`）。
4. 已報名顯示 `出戰：{名單}（戰力 {n}）`。
**結束（≥14 日）**：沿用現行賽季結算文案，不顯示推薦與參戰。

### L.4 培育期推薦邏輯（地形天氣 → 兵種／武將類型）
每個候選分數 = 地形加分 + 天氣加分 + BOSS 弱點加分 + 杯賽特殊規則加分；兵種取前 2、武將類型取前 1，同分依資料檔順序；分數 ≤0 的不推薦。
- 地形（暫定）：平原 CAVALRY2／INFANTRY1；水域 NAVY3／ARCHER2；山地 PIKE2／INFANTRY1／ARCHER1；關隘 SHIELD2／SIEGE1／ARCHER1；沙漠 CAVALRY1／ARCHER1；林地 INFANTRY2／ARCHER1。
- 天氣（暫定）：晴天 無；雨天 SHIELD1；大霧 INFANTRY1；大風 ARCHER1；夜戰 INFANTRY1；雷暴 SHIELD1。
- BOSS 弱點標籤（對應 `TournamentBossTag`）：RANGED→ARCHER+1；FIRE→武將類型「火攻謀士」+2；SLOW→「控速型」+2；ANTI_CONTROL→「抗控型」+2；ANTI_CAVALRY→PIKE+2、「剋騎型」+1；CAVALRY→CAVALRY+1。
- 特殊規則標籤倍率（`specialRule.tagMultipliers`）：倍率 ≥1.5 的標籤給同標籤對應項 +2（FIRE→火攻謀士、CAVALRY→CAVALRY）；倍率 <1 的標籤（如夷陵 RANGED 0.5）給對應項 -2（弓兵不推薦）。
- 武將類型（暫定五種）：火攻謀士、控速型、抗控型、剋騎型、弓將；每類在資料檔列出判定欄位（技能標籤／兵種適性），供培育列表篩選使用。

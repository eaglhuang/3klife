### L.6 UI 排版（錨點／相對比例）
卡片在大廳側卡與沙盤右側卡共用同一組節點：標題、副標、場地、推薦區（橫向 Layout，小標自動換行）、主按鈕置底錨點。橫式為右欄（寬 0.22W）；直式移為列表上方橫條，不寫死像素；推薦小標寬度由文字量測，最多 3 個。

### L.7 四語系 i18n 鍵
`tournament.card.title`、`tournament.card.prepSubtitle`（{days}）、`tournament.card.compSubtitle`（{days}）、`tournament.card.venueLine`（{terrain}{weather}{rule}）、`tournament.card.recommend`、`tournament.card.recommendShort`、`tournament.card.autoEnroll`、`tournament.card.btnPrepare`、`tournament.card.btnPlay`、`tournament.prep.reason.<terrain|weather|tag>`、`tournament.prep.type.<id>`、`tournament.prep.troop.<code>`（沿用 AptitudeView 名稱）。zh-TW／zh-CN／en／ja 皆需。

### L.8 與新手第 1 年不卡關的關係
挑戰賽卡片只提供建議，培育期沒有強制動作；競賽期自動報名，不需先報名才能參戰，新手即使完全不看推薦也能打。第 1 年沙盤入口隱藏，故第 1 年卡片只出現在挑戰賽面板；推薦文字不得使用尚未解鎖玩法的詞（如沙盤、虎符進階功能）。

### L.9 算例（第 1 屆赤壁盃，培育期第 0 日）
- `daysToCompetition = 7 - 0 = 7`（舊卡顯示「剩 14 日」是整季，修正後顯示「還有 7 天進入競賽期」）。
- 兵種：ARCHER＝水域 2＋大風 1＋BOSS RANGED 1＝4；NAVY＝水域 3＝3；其他 0。取前 2 → 弓兵、水軍。
- 武將類型：火攻謀士＝BOSS FIRE 2＋規則 FIRE×2（≥1.5）2＝4 → 推薦「火攻謀士」。
- 卡片文字：`先練這些：弓兵（水域弓兵站得穩）、水軍；火攻謀士（赤壁火攻傷害 ×2）`。
- 官渡盃（平原晴天，BOSS 弱點 ANTI_CAVALRY／FIRE，規則 CAVALRY×1.8）：CAVALRY＝平原 2＋規則 2＝4；INFANTRY＝1；PIKE＝2；取前 2 → 騎兵、長槍兵；武將類型：火攻謀士 2、剋騎型 1 → 火攻謀士。

### L.10 驗收清單
1. 培育期卡片顯示 `還有 N 天進入競賽期`，N＝7－dayInSeason，不顯示整季剩餘。
2. 赤壁盃培育期推薦弓兵＋水軍＋火攻謀士（算例相符），官渡盃相符。
3. 培育期無參戰鈕、有 `去培育`，點擊開啟培育入口；競賽期有 `參戰`，未報名時自動報名。
4. 競賽期推薦收合為一行。
5. 推薦全由 `tournament-prep-hints.json` 產生，改 JSON 即改結果；JSON 格式錯時卡片不報錯、不顯示推薦區。
6. 四語系鍵齊全、直式排版錨點可切換。

### L.11 待使用者決定（選擇題）
1. `去培育` 落點：**A（建議）開培育分類並高亮「開獎・培育」**／B 直接進培育開獎畫面。
2. 培育列表是否依推薦武將類型自動排序置頂：**A（建議）做（選做項，第二批）**／B 不做。
3. 賽季為真實 14 天，而遊戲 1 年＝4 季；玩家可能把「培育期 7 天」誤認為遊戲季：**A（建議）文案固定寫「天」不寫「季」**／B 改為遊戲內日曆換算。

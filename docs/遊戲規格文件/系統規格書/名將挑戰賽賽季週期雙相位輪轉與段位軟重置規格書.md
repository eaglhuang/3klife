# 名將挑戰賽賽季週期雙相位輪轉與段位軟重置規格書

> **模組識別碼**：`TRN-01`  
> **系統歸屬**：名將挑戰賽（Tournament）核心賽季管理  
> **單一真相來源**：本規格書確立名將挑戰賽賽季雙相位時間軸、六階段位判定門檻與賽季結算軟重置之唯一權威標準。廢棄所有歷史文件中關於非 14 天賽季或混亂扣分之暫定描述。

---

## 一、系統概述與架構原則

名將挑戰賽以 **14 天（兩週）為一固定賽季週期**，採純邏輯、無副作用狀態機驅動，與畫面渲染（Cocos/Unity）完全解耦。

### Unity / 設計架構對照
- **狀態管理**：類似 Unity 專案中的 `TournamentSeasonScriptableObject`，具備確定性純函式 Reducer。
- **時間相位**：類似 Timeline 驅動的時間軸控制器，依照伺服器時間或本機時間日數精確切換狀態。

---

## 二、賽季週期與雙相位切換模型

賽季以天數（0 起算）嚴格劃分為三大相位：

```
第 0 天               第 7 天               第 14 天
│◄───── 培育期 ─────►│◄───── 競賽期 ─────►│ 賽季結算/過季
│   PREPARATION      │    COMPETITION     │    ENDED
└────────────────────┴────────────────────┴───────────►
```

### 1. 常數定義
```typescript
export const TOURNAMENT_SEASON_DAYS = 14;      // 單季總天數
export const TOURNAMENT_PREPARATION_DAYS = 7;  // 培育期天數（0 ~ 6）
export type TournamentPhase = 'PREPARATION' | 'COMPETITION' | 'ENDED';
```

### 2. 相位判定演算法
```typescript
export function tournamentPhaseOf(dayInSeason: number): TournamentPhase {
    if (dayInSeason < TOURNAMENT_PREPARATION_DAYS) return 'PREPARATION';
    if (dayInSeason < TOURNAMENT_SEASON_DAYS) return 'COMPETITION';
    return 'ENDED';
}
```
- **邊界保護**：若 `dayInSeason < 0`（如賽季前置準備階段），一律回傳 `'PREPARATION'`。
- **行為規範**：
  - **培育期（0~6 天）**：公告當季場地與 BOSS 弱點，開放陣容登錄與每日 1 次免費重新登錄；禁用正式積分對戰。
  - **競賽期（7~13 天）**：開放每日積分對戰，陣容進入鎖定狀態（整季僅限 1 次替換）。
  - **結束期（$\ge 14$ 天）**：所有戰鬥與替換操作強制關閉，等待或自動觸發跨季結算。

## 三、六階段位門檻與判定規則

排名分數（Points）為非負整數，依嚴格區間階梯判定當前段位：

| 段位識別碼 (`RankTier`) | 中文名稱 | 分數門檻下限 (`minPoints`) |
|---|---|---|
| `LEGEND` | 傳說 | $\ge 3000$ |
| `DIAMOND` | 鑽石 | $\ge 2500$ |
| `PLATINUM` | 白金 | $\ge 2000$ |
| `GOLD` | 黃金 | $\ge 1500$ |
| `SILVER` | 白銀 | $\ge 1000$ |
| `BRONZE` | 青銅 | $0 \sim 999$ |

```typescript
export type RankTier = 'BRONZE' | 'SILVER' | 'GOLD' | 'PLATINUM' | 'DIAMOND' | 'LEGEND';

const RANK_TIER_FLOORS: readonly { tier: RankTier; min: number }[] = [
    { tier: 'LEGEND', min: 3000 },
    { tier: 'DIAMOND', min: 2500 },
    { tier: 'PLATINUM', min: 2000 },
    { tier: 'GOLD', min: 1500 },
    { tier: 'SILVER', min: 1000 },
    { tier: 'BRONZE', min: 0 },
];

export function rankTierOf(points: number): RankTier {
    const safe = Number.isFinite(points) ? points : 0;
    const hit = RANK_TIER_FLOORS.find(entry => safe >= entry.min);
    return hit ? hit.tier : 'BRONZE';
}
```

## 四、賽季結算軟重置（Soft Reset）演算法

當賽季進入結算跨季（Rollover）時，為避免高端玩家開季壓制新進玩家，同時保留玩家既有實力階梯，執行「階梯式軟重置扣分」：

```typescript
const SOFT_RESET_BY_TIER: Readonly<Partial<Record<RankTier, number>>> = {
    LEGEND: 250,   // 傳說扣 250 分
    DIAMOND: 200,  // 鑽石扣 200 分
    PLATINUM: 150, // 白金扣 150 分
    // GOLD / SILVER / BRONZE 不扣分（保留原有積分）
};

export function softResetPoints(points: number): number {
    const safe = Number.isFinite(points) ? Math.max(0, points) : 0;
    const reset = SOFT_RESET_BY_TIER[rankTierOf(safe)] ?? 0;
    return Math.max(0, safe - reset);
}
```

## 五、跨季結算狀態機與歷史記錄合約

```typescript
export interface SeasonHistoryEntry {
    seasonIndex: number;
    finalPoints: number;
    finalTier: RankTier;
    highestStreak: number;
    totalBattles: number;
    teamSnapshotId: string;
    closedAtTimestamp: number;
}
```

1. **獎勵封存**：記錄結算當季之最終段位獎勵為待領狀態（`pendingRewardTier = finalTier`），防止跨季被覆蓋或重複領取。
2. **狀態推進**：
   - 賽季序號遞增：`seasonIndex = seasonIndex + 1`。
   - 新賽季起始積分：`points = softResetPoints(points)`。
   - 重置日常限制：當日參戰次數歸零、陣容替換配額重置。

## 六、驗收條件與測試案例 (Test Cases)

- **TC-TRN-01（相位精確切換）**：
  - 輸入第 0、6 天回傳 `'PREPARATION'`；第 7、13 天回傳 `'COMPETITION'`；第 14、15 天回傳 `'ENDED'`。
- **TC-TRN-02（段位邊界判定）**：
  - 輸入 2999 判定為 `DIAMOND`，輸入 3000 判定為 `LEGEND`；輸入負數判定為 `BRONZE`。
- **TC-TRN-03（軟重置扣分）**：
  - 3200 分（傳說）重置後為 2950 分；2100 分（白金）重置後為 1950 分；1200 分（白銀）重置後仍為 1200 分。
- **TC-TRN-04（無副作用純函式）**：
  - 重複呼叫 `softResetPoints` 與 `rankTierOf`，輸入資料不變，回傳值保持冪等。

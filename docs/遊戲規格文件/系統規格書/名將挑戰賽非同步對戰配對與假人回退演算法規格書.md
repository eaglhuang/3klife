# 名將挑戰賽非同步對戰配對與假人回退演算法規格書

> **模組識別碼**：`TRN-04`  
> **系統歸屬**：名將挑戰賽（Tournament）對抗配對  
> **單一真相來源**：本規格書確立名將挑戰賽在競賽期非同步離線對戰之總戰力 $\pm 15\%$ 配對區間、對手積分估算與假人回退（Fallback）演算法之唯一標準。

---

## 一、系統概述與架構原則

名將挑戰賽採非同步離線對抗機制（Asynchronous Offline PvP），玩家出戰時由系統即時配對戰力相近之對手快照。若玩家庫存快照不足或伺服端離線時，啟動確定性假人生成演算法，確保各分段玩家隨時具備流暢且具挑戰性之對手。

### Unity / 架構對照
- **配對器**：類似 Unity 伺服器端的 `AsyncMatchmakerService`，輸入我方戰力與積分，以純數學區間過濾候選池。
- **無狀態純函式**：所有隨機皆透過依賴注入 `random: () => number`，保障單元測試可重播。

## 二、總戰力 $\pm 15\%$ 配對演算法

### 1. 常數與參數配置
```typescript
export const TOURNAMENT_MATCH_CONFIG = {
    matchPowerRange: 0.15, // 戰力上下浮動 15%（即 0.85 ~ 1.15 倍）
} as const;
```

### 2. 對手戰力生成公式
給定我方隊伍總戰力 $P_{\text{my}} \ge 1$，對手戰力 $P_{\text{opp}}$ 計算如下：

$$P_{\text{opp}} = \left\lfloor P_{\text{my}} \times (1 - 0.15 + \text{random}() \times 0.30) \right\rfloor$$

```typescript
export function generateOpponentPower(myPower: number, random: () => number): number {
    const safeMyPower = Math.max(1, Math.round(myPower));
    const range = TOURNAMENT_MATCH_CONFIG.matchPowerRange;
    const factor = (1 - range) + random() * (range * 2);
    return Math.max(1, Math.round(safeMyPower * factor));
}
```

## 三、對手排名積分（Points）估算模型

在非同步單機模擬與假人回退模式下，對手積分依我方現有積分與雙方戰力比值進行線性估算，以維持 ELO 演算法之數學穩定性：

$$\text{OpponentPoints} = \max\left(0, \left\lfloor \text{MyPoints} \times \frac{P_{\text{opp}}}{P_{\text{my}}} \right\rfloor\right)$$

```typescript
export function estimateOpponentPoints(myPoints: number, myPower: number, opponentPower: number): number {
    const safeMyPower = Math.max(1, myPower);
    const safeMyPoints = Math.max(0, myPoints);
    return Math.max(0, Math.round((safeMyPoints * opponentPower) / safeMyPower));
}
```

- **動態平衡**：
  - 若對手戰力高於我方（如 $1.15$ 倍），其預估積分等比例提高，我方勝出時將獲得較多 ELO 增量。
  - 若對手戰力低於我方（如 $0.85$ 倍），其預估積分等比例降低，我方失敗時將受到適度懲罰。

## 四、確定性假人回退（Deterministic Fallback）機制

當配對池中無合適真實玩家快照時，系統依據當季杯賽場地生成史實陣營假人：

```typescript
export interface DummyOpponentProfile {
    dummyId: string;
    factionName: string;
    leaderName: string;
    power: number;
    estimatedPoints: number;
}

export function createFallbackOpponent(
    seasonIndex: number,
    myPower: number,
    myPoints: number,
    random: () => number
): DummyOpponentProfile {
    const power = generateOpponentPower(myPower, random);
    const points = estimateOpponentPoints(myPoints, myPower, power);
    
    const factions = ['曹魏驍騎營', '蜀漢無當飛軍', '江東解煩衛', '西涼鐵騎', '河北精銳'];
    const factionIndex = Math.floor(random() * factions.length) % factions.length;
    
    return {
        dummyId: `DUMMY_S${seasonIndex}_${Math.floor(random() * 100000)}`,
        factionName: factions[factionIndex],
        leaderName: `敵軍校尉·${factions[factionIndex].slice(0, 2)}`,
        power,
        estimatedPoints: points,
    };
}
```

## 五、驗收條件與測試案例 (Test Cases)

- **TC-TRN-13（戰力區間嚴格落點）**：
  - 輸入我方戰力 10000，隨機值 0.0 時對手戰力為 8500（下界 $0.85$ 倍）。
  - 輸入我方戰力 10000，隨機值 1.0 時對手戰力為 11500（上界 $1.15$ 倍）。
  - 輸入我方戰力 10000，隨機值 0.5 時對手戰力為 10000（中點 $1.00$ 倍）。
- **TC-TRN-14（積分估算比例）**：
  - 我方積分 2000、戰力 10000，對手戰力 11000，對手預估積分應為 2200。
- **TC-TRN-15（邊界防禦）**：
  - 我方戰力為 0 或負數時，保底以 1 運算，禁止發生除以零或 NaN 錯誤。
- **TC-TRN-16（假人回退確定性）**：
  - 注入固定亂數產生器，假人 ID、陣營、戰力與積分輸出結果 100% 相同。

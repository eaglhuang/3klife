# 名將本體資料結構與多型轉型規格書

> **責任邊界**：本檔為武將本體模型（GeneralUnit）、規格契約（GeneralMainSchema）與多型狀態轉換的單一真相來源。
> **關聯 WBS**：DS-02（General 主結構欄位）、GEN-01（基礎資料結構）、GEN-07（生命週期狀態機）。
> **整併裁決**：徹底消除 PROG-2-0497 之 11 欄位分叉；確立 Talent/Prowess 雙軌制與 235 筆 Master 對齊協議。

## §1. 武將二十二核心欄位契約

所有武將資料實例（無論是 235 位史實名將或動態培育子嗣）落盤時均依循以下契約規格：

| 欄位名稱 (Key) | 資料型別 (Type) | 說明與約束 | 預設或來源 |
|:---|:---:|:---|:---|
| `UID` | `string` | 實例唯一識別碼（如 `GEN_7A8B9C`） | 系統生成唯一 UUID |
| `Template_ID` | `string` | 史實母卡 ID（如 `liu_bei`、`custom_offspring`） | 參照 generals.json |
| `Title` | `string` | 稱號（如「漢昭烈帝」） | 預設同名或空白 |
| `Gender` | `'M' \| 'F'` | 性別標籤 | 繼承自母卡或開獎決定 |
| `Age` | `number` | 當前生理年齡（季更推進） | 出生為 0，史實預設 20 |
| `Phase` | `GeneralPhase` | 生命週期階段：`BABY \| CHILD \| YOUTH \| PEAK \| DECLINE \| RETIRED \| SPIRIT` | 依年齡與事件動態轉換 |
| `Talent_Stats` | `SixDimensionStats` | 先天天賦上限（五維/六維能力天花板） | 開獎或母卡基礎值 |
| `Prowess_Stats` | `SixDimensionStats` | 後天培育實績（當前生效戰力） | 培育畢業快照寫入 |
| `Genes` | `GeneSlot[]` | 遺傳因子槽（3~5 槽，含鎖定狀態） | 基因庫抽樣生成 |
| `Ancestors_JSON` | `AncestryTree` | 14 人三代祖譜樹結構 | 引用自 BloodlineGraph |
| `Role` | `'Combat' \| 'Mentor'` | 職能定位（戰鬥武將或純教學教官） | 轉職後不可逆 |
| `Role_Boundary` | `'Normal' \| 'TeachingOnly'` | 教官邊界旗標（防血脈污染） | 教官固定 TeachingOnly |
| `Has_Retired_Before`| `boolean` | 是否曾進行榮退結算 | 預設 false |
| `Female_Role_Type` | `'COMBAT' \| 'SUPPORT'` | 女性名將定位標籤 | 區分前線或輔助 |
| `Vitality` | `number` | 當前精力點數（0~100） | 預設 100 |
| `Vitality_Max` | `number` | 精力上限 | 基礎 100，因子修正 |
| `Max_Lifespan` | `number` | 預期天年極限歲數 | 基礎 65，延壽丹可加 |
| `Loyalty` | `number` | 忠誠度（0~100） | 預設 80，虎符換裝增減 |
| `Personality` | `string` | 性格代碼（影響事件決策機率） | 參照性格字典 |
| `Current_Suitability`| `SuitabilityMap` | 各兵種指揮適性（S/A/B/C/D） | 基礎+培育加成 |
| `Father_ID` / `Mother_ID` | `string \| null` | 父母親 UID（史實名將為 null） | 配種註冊回填 |
| `Profile_Presentation` | `PresentationMeta` | 立繪、外觀與音效資源索引 | 參照美術資產表 |

## §2. Talent（先天）與 Prowess（實績）分離架構

為杜絕傳統養成數值直接覆寫基礎天賦導致的資料污染，採雙軌數值架構：

1. **Talent_Stats (天賦上限)**：
   - 決定武將各維度之理論極限（Cap）。
   - 揭露階段受 `Child_Preview.Revelation_Level` 控制（`HIDDEN → TENDENCY → RANGE → EXACT`）。
2. **Prowess_Stats (實績數值)**：
   - 在學府/書院培育期間動態成長。
   - 僅在第 36 回合**「結業快照（Graduation Snapshot）」**落盤時固化，作為戰場出征與戰力評分依據。
   - 計算公式：$\text{FinalStat} = \min(\text{ProwessStat}, \text{TalentCap})$。

## §3. 生命週期七大階段狀態機 (GeneralPhase)

武將生命週期轉換嚴格由年齡季更與身後事件驅動：

```
[BABY: 0~4歲] ──(5歲開獎)──> [CHILD: 5~11歲] ──(入學)──> [YOUTH: 12~19歲]
      │                                                         │
      └───────(弱冠成年 20歲)────────────────────────────────────┘
                                │
                                ▼
[SPIRIT: 英靈/虎符] <─── [RETIRED: 60+歲] <─── [DECLINE: 50+歲] <─── [PEAK: 20~49歲]
```

1. **BABY (幼年)**：僅受安胎藥與幼年環境影響，五維資訊隱藏。
2. **CHILD (童年)**：5 歲天象開獎，確立骨骼天賦與職能分流傾向。
3. **YOUTH (青年)**：進入潁川書院等學府，執行 36 回合策論修業。
4. **PEAK (巔峰)**：弱冠畢業，出征作戰與婚配結緣之黃金期。
5. **DECLINE (衰退)**：年過半百，每年精力回復率減半，屬性開始衰減。
6. **RETIRED (榮退)**：60 歲以上可自主退役，轉為宗族教官卡。
7. **SPIRIT (英靈)**：天年壽終或戰死，結算產出英靈卡與虎符卡。

# 名將身後傳承英靈虎符雙卡結算與退役轉教官規格書

## 1. 模組職責與架構定位
本規格書規範武將身故時的「身後傳承英靈與虎符雙卡結算引擎（`Legacy`、`LegacyTally`）」以及年滿 65 歲時的「主動退役轉教官流程（`RetireToMentor`）」。模組確保名將生前武勳能轉化為宗族長遠遺產，同時規範退役榮休的資產生命週期邊界。

```
┌─────────────────────────────────────────────────────────────┐
│                    Posthumous & Retirement                  │
├──────────────────────────────┬──────────────────────────────┤
│ 死亡身後傳承 (Death Legacy)  │ 65 歲退役榮休 (Retirement)   │
│ 英靈卡 (Spirit) + 虎符 (Tally)│ 轉化教官卡 (Source=RETIRED) │
│ 原子入庫祠堂與虎符倉         │ 延後產出英靈 / 保留保種權   │
└──────────────────────────────┴──────────────────────────────┘
```

## 2. 身後傳承雙卡結算狀態機

### 2.1 死亡快照與雙卡分裂生成
當武將狀態切換為 `DEAD` 時，系統在換季結算前瞬間凍結其生前最後數據，生成 `DeathSnapshot`，並原子分裂產出兩大核心宗族卡片：
1. **名將英靈卡（`SPIRIT_CARD`）**：
   - 記錄武將生前巔峰五維、固有奧義與血脈因子。
   - 自動登錄於玩家宗族祠堂（`AncestralShrine`），可作為「名將傳道（`MENT-15`）」之發起英靈。
2. **兵種虎符卡（`TALLY_CARD`）**：
   - 依據該武將專屬兵種（如趙雲「白馬義從」、曹操「虎豹騎」）生成。
   - 自動歸入玩家兵符倉（`TallyDepot`），提供出征軍團該特殊兵種的常態調用權限。

### 2.2 先退役後死亡補發協議
若武將於 65 歲時已先辦理退役轉教官，其後續壽終死亡時，系統觸發補發流程：
- 補發英靈卡與虎符卡至對應倉庫。
- 既有已生成之退役教官卡不受影響，繼續在支援名冊中留存。

```typescript
export interface DeathLegacyResult {
  generalId: string;
  spiritCardId: string;
  tallyCardId: string;
  wasPreviouslyRetired: boolean;
}

export function processDeathLegacy(generalId: string, generalName: string, isRetired: boolean): DeathLegacyResult {
  const spiritId = `SPIRIT_${generalId}`;
  const tallyId = `TALLY_${generalId}`;

  return {
    generalId,
    spiritCardId: spiritId,
    tallyCardId: tallyId,
    wasPreviouslyRetired: isRetired
  };
}
```

## 3. 65 歲退役轉教官榮休流程

### 3.1 退役確認與教官轉化
當武將年齡 $\ge 65$ 歲且尚未身故時，玩家可主動在武將詳情頁點擊「榮休歸田」：
1. **角色狀態切換**：狀態由 `ACTIVE` 轉為 `RETIRED`。
2. **生成退役教官卡**：
   - 卡片來源標記為 `source = 'RETIRED'`。
   - 繼承生前最高兩項五維作為教學特長。
3. **資產產出限制（Boundary Rule）**：
   - 退役當下 **不產出英靈卡與虎符卡**，避免資產提前溢出。
   - 退役武將仍保留參與宗族「保種結緣（`Breeding`）」的權利，直至壽終正寢。

## 4. 單元測試驗證規範
1. **TC-LEG-01（死亡雙卡原子生成檢驗）**：活躍名將死亡，回傳 `spiritCardId` 與 `tallyCardId`，且標記 `wasPreviouslyRetired = false`。
2. **TC-LEG-02（先退役後死亡補發檢驗）**：已退役名將死亡，正確補發雙卡，標記 `wasPreviouslyRetired = true`。
3. **TC-RET-BOUNDARY（退役不預支英靈卡）**：執行退役榮休時，英靈卡生成數為 0，教官來源為 `RETIRED`。

# 3KLife 名山險隘太行秦嶺大別山行軍補給損耗與棧道修築狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 戰略地理空間之高山地貌與工程工兵系統（`TERRAIN-MOUNTAIN-01`）。覆蓋太行八陘、秦嶺斜谷/子午谷、大別山隘口、劍閣蜀道等著名天險。規範大軍翻越山嶺時之極端糧草耗損、非山地特種兵之體力疫病減員、以及軍隊在懸崖峭壁間「修築棧道、火焚絕道、工兵開山」之戰略工程狀態機。

## 4. 行軍損耗與棧道修復工程公式

### 4.1 山地行軍非戰損耗公式
大軍在未全通棧道之山徑行軍，非山地專屬兵種之減員率：
$$\text{AttritionRate} = \left(0.05 + \frac{\text{BaseElevationM}}{20000}\right) \times \left(1.0 - \frac{\text{LeaderSurvivalStat}}{150}\right) \times \text{TroopMountainFitness}$$
- 山地特種兵（如白毦兵、無當飛軍、山越勇士）$\text{TroopMountainFitness} = 0.1$；
- 重裝鐵騎 $\text{TroopMountainFitness} = 3.5$（戰馬難行，嚴重折損）。

### 4.2 棧道工期修築與火焚阻斷
- **工期計算**：
$$T_{\text{repair}} = \frac{\text{PassLengthKm} \times 10}{\text{PioneerCount} \times (1.0 + \text{EngineerSkill}/100)}$$
- **火焚斷道**：部隊撤退時發動「焚燒棧道」，瞬間將地格轉為 `BURNED_CUT`，敵軍追擊部隊無法通行，強制原路折返或滯留山巔斷糧。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-PASS-01**：在陰平摩天嶺小道，嚴禁大型投石車與重裝騎兵通行；僅允許步兵團丟棄重甲裝備輕裝裹氈偷渡，部隊攻擊力暫時 $-30\%$。
2. **驗收 CASE-PASS-02**：當棧道狀態為 `BURNED_CUT` 時，若敵方軍隊糧草告罄，每回合觸發 $20\%$ 大潰散逃亡判定。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

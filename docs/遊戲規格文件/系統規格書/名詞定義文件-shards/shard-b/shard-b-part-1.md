# 名詞定義文件（分片索引） — 全系統名詞總表

> 這是 `名詞定義文件.md` 的「全系統名詞總表」分片。完整索引見 `docs/遊戲規格文件/系統規格書/名詞定義文件.md`。

## 全系統名詞總表

### 武將系統
| 名詞 | 代碼/Key | 定義 |
|---|---|---|
| 武將 | General | 遊戲核心實體，具有五維+因子 |
| UID | UID | 武將唯一識別碼 |
| Template_ID | Template_ID | 武將版本模板 |
| Bloodline_ID | Bloodline_ID | 血源識別碼（同名武將共用） |
| 五維 | Stats (STR/INT/POL/CHR/LUK) | 武力/智力/政治/魅力/運氣 |
| 精力 | Vitality | 武將的統一行動力資源 |
| 職能雙軌 | Dual_Track | 武官+文官的並行職能 |
| 個人奧義 | General Ultimate | 武將個人絕招，消耗 SP。由武將模板固定，培育不可變更。 |
| 格子戰法 | Grid Tactic | 部隊級技能，消耗 TP。改變地圖格狀態或造成傷害。來源含：虎符、培育習得、血統遺傳。 |

### 武將人物頁 / 裝配頁
| 名詞 | 代碼/Key | 定義 |
|---|---|---|
| 將頁 | Overview_Tab | 武將人物頁的首頁，承接角色主視覺、身份摘要與故事條，不承接裝配操作 |
| 屬頁 | Stats_Tab | 武將人物頁的六維與雙層數值頁 |
| 命頁 | Bloodline_Tab / Fate_Tab | 武將人物頁的血脈、祖紋命篆、命紋靈獸、14 人祖先血統圖與英靈卡操作頁 |
| 技頁 | Tactics_Tab | 武將人物頁的戰法、奧義與習得狀態頁 |
| 寶頁 | Equip_Tab / Gear_Tab | 武將人物頁的一般裝備、傳家寶與道具頁；不承接英靈卡與虎符槽 |
| 兵頁 | Aptitude_Tab | 武將人物頁的兵種、地形、天氣適性、戰鬥定位與虎符裝備操作頁 |
| 命頁故事條 | Bloodline_StoryDock / StoryDock | `命頁` 底部可抽拉故事條，顯示 5~6 格血脈逸聞；展開時須與 14 人血統圖 reflow，不得直接覆蓋主圖 |
| 血脈傳承奧義 | Bloodline_Ultimate | 命頁右側的五階血脈能力軌；升星決定階段上限，名聲與符合命紋靈獸傾向的事蹟推動階段進度 |
| 命紋靈獸 | Bloodline_Beast | 血脈深層人格與覺醒傾向的徽記，不是單純裝飾；與血脈傳承奧義、性格標籤與覺醒條同區顯示 |
| 命槽 | Destiny_Slot | 英靈卡的單插槽語意；資料層屬命系統，人物頁裝配入口位於 `命頁` 的英靈卡槽 |
| 虎符槽 | Tally_Slot | 每位武將唯一的虎符裝備槽；人物頁裝配入口位於 `兵頁` 的虎符卡 |
| 裝配主入口 | Gear_Loadout_Entry | 武將人物頁中處理一般裝備、英靈卡與虎符更換 / 查詢的分流入口，分別指向 `寶頁 / 命頁 / 兵頁` |

### 教官系統（支援卡）
| 名詞 | 代碼/Key | 定義 |
|---|---|---|
| 教官 | Mentor / Mentor_Card | 培育模式中的輔助角色 |
| TP（才能點數） | TP (Training Point) | 教官提供的培育加成數值 |
| 突破 | Breakthrough | 教官卡等級上限提升 |
| 教學職能分離 | Teaching_Line_Only | 教官只負責培育事件、TP 與友情訓練，不介入血統親傳 |
| 虎符 | Tiger_Tally | 名將死亡時同步留下的戰場卡，裝備後可指揮對應特殊兵種；不屬於轉蛋池，退役也不直接產出。 |
| 竹簡 | Bamboo_Scroll | 退役產物（若退役角色主職為「文官」），代表智識教官類型；品質由 `scholarship_score` 類別指標決定，與武官的 `retire_score` 分流。 |
| 英靈歸位 | Spirit_Return | 名將死亡後英靈回歸世家 / 英靈系統的結算流程 |

### 英靈世家系統
| 名詞 | 代碼/Key | 定義 |
|---|---|---|
| 英靈陳列室 | Spirit_Collection_Room | 家族層的英靈集合瀏覽頁，承接多卡管理與展示 |
| 英靈展示列 | Spirit_Display_Row | 家族英靈列表中的單列展示語意，直接顯示快照與切換狀態 |
| 展示權重 | Display_Weight | 英靈陳列室的預設排序權重，用來決定展示列的先後順序 |

# 3KLife 周瑜打黃蓋苦肉計身受重刑博取敵酋信任狀態機規格書

## 1. 系統概述與設計哲學
在兩軍決戰面臨兵力懸殊、敵軍水寨嚴密無懈可擊時，常規間諜難以打消敵方梟雄之疑慮。三國傳奇謀略工程「苦肉計自殘偽裝」（BITTER-MEAT-SELF-HARM-RUSE01）。
大都督周瑜與老將黃蓋於軍帳密謀，利用全軍點卯之機故意激化矛盾。周瑜當眾以違反軍紀為由下令推出斬首，後在諸將苦諫下改判脊杖五十。老將當眾身受重杖，打得皮開肉綻、數次氣絕。此等非肉體偽飾之「真實重創」徹底蒙蔽敵方潛伏細作。黃蓋隨後派親信密使修書請降，敵酋深信不疑，敞開水寨相迎，為後續艨艟火攻直搗中軍奠定不可逆之決勝契機。

## 4. 傷勢可信度與詐降博弈物理模型

### 4.1 敵酋疑心消除演算法
傳統假降之所以失敗，在於詐降者無切膚之痛：
$$\text{Trust}_{\text{gain}} = \text{BaseTrust} + (\text{DamageReceived} \times 1.2) - (\text{EnemyCunning} \times 0.3)$$
- 唯有身受真實 $65\%$ 生命損害且經由敵方潛伏密探親眼驗證，敵酋多疑天性（如曹操）方能完全被壓制消除。

### 4.2 突刺發難與火攻連鎖
1. **水門防禦清空**：因敵酋下達接納降將命令，沿江水柵、箭樓巡邏隊強制解除戒備狀態。
2. **近程毀滅點燃**：走舸抵達零距離後引燃，敵艦隊規避概率為 $0$，必定觸發連環戰艦殉爆。

## 5. 單元驗收測試標準
1. **TC-BITTER-01 (苦肉行杖與真傷結算全流程)**：
   - 模擬主帥對老將施加苦肉計杖刑。
   - 驗證將領 HP 扣減 65%，附加 8 回合重傷流血，敵方細作核銷率達 98%。

   - 遞交降書後結算，敵酋信任度躍升至 95 點，水寨防禦射程關閉。
3. **TC-BITTER-03 (抵達發難火攻致命突刺)**：
   - 詐降船隊進入接舷位，觸發 `SURPRISE_FATAL_STAB`。
   - 驗證第一波火攻傷害獲得 100% 暴擊，直接引燃敵連環主力戰艦。

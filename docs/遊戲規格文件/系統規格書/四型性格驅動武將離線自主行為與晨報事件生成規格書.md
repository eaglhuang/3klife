# 四型性格驅動武將離線自主行為與晨報事件生成規格書

> **所屬模組**：`3.7 UI 介面與視覺工程 (HUM-03 / HUM-01)`  
> **單一真相來源**：定義義/豪/睿/貪四型性格（`doc_spec_0664`）在玩家離線時之加權自主行為抽樣狀態機、晨報日誌（Morning Report）插槽組裝，以及防通膨數值反饋防線。

---

## 1. 離線行為驅動架構與觸發時序

當玩家離線超過 4 小時且武將精力值 $\ge 30$ 時，系統在每日早晨登入結算階段，依據武將性格觸發一次自主離線事蹟：

```
+-------------------------------------------------------+
|  [玩家離線結算: 離線時長 >= 4 小時]                    |
|                         |                             |
|          [取得未派遣武將之性格 (Personality)]         |
|                         |                             |
|    +--------------------+--------------------+        |
|    |                    |                    |        |
|  [義: 尋訪/撫民]    [豪: 演武/豪飲]    [睿: 治理/推演] [貪: 通商/探寶]
|    |                    |                    |        |
|    +--------------------+--------------------+        |
|                         |                             |
|          [計算輕微回饋與寫入晨報暫存佇列]             |
|                         |                             |
|          [玩家登入: MorningReport 彈窗彙整呈現]        |
+-------------------------------------------------------+
```

## 2. 四型性格離線行為權重與反饋矩陣

每種性格依預設機率抽樣一項行為，並產出輕量反饋：

| 性格 | 自主行為類別 | 觸發機率 | 敘事文本範例 | 數值與資源微量回饋 |
|:---:|:---|:---:|:---|:---|
| **義** | 尋訪隱士<br>撫慰流民 | 60%<br>40% | 「於郊野偶遇名士，促膝長談軍略。」<br>「私撥少許餘糧周濟鄉閭，百姓感念。」 | 武將 EXP +150<br>城池民心 +2 |
| **豪** | 校場演武<br>酒肆豪飲 | 65%<br>35% | 「率親兵於校場痛快搏殺，士氣大振。」<br>「與軍中健兒痛飲十壇，豪氣干雲。」 | 戰鬥入場士氣 +5 (持續1場)<br>武將精力回復 +10 |
| **睿** | 研閱卷宗<br>推演陣圖 | 50%<br>50% | 「夜讀兵法至三更，於治水安民略有所得。」<br>「於沙盤反覆推演八卦陣，略通奧妙。」 | 城市糧草產出 +1% (當季)<br>武將 TP 上限 +5 (當季) |
| **貪** | 護送商賈<br>坊市尋寶 | 55%<br>45% | 「巧遇過境商隊，順道護送得厚酬。」<br>「於西市古董攤淘得舊兵書殘卷。」 | 銅錢 +3,000<br>鍛兵材料 x 1 |

## 3. 防通膨上限與精力安全鎖 (Safety Bounds)

為杜絕利用長時間離線刷屬性破壞平衡，行為結算恪守嚴格的安全邊界：
1. **單日收益上限**：
   - 每位武將單日最多觸發 1 次性格自主行為。
   - 玩家帳號所有武將單日合計獲取之銅錢上限為 `50,000`，糧草加成上限為 `+5%`。
2. **精力耗竭保護**：
   - 若武將精力 $<30$ 或處於「待產（`Is_Pregnant`）」狀態，**絕對禁止** 觸發任何離線行為，強制進入休息靜養。

---

## 4. 晨報日誌插槽組裝契約

晨報生成器（`MorningReport`）依循固定模板組裝文字：
$$\text{Line} = \text{[時段]} + \text{[武將姓名]} + \text{[性格行為插槽]} + \text{[結算成果]}$$
- **組裝範例**：
  `「昨夜三更，常山趙子龍（豪）於校場率親衛徹夜演武，全軍受其激勵，下場戰役起始士氣 +5 點！」`
- **點擊連動**：點擊晨報條目可直接跳轉至該名將詳情頁之生平實錄（`doc_spec_0667`）。

# 四季特色環境修正表與數值加成規格書

> **模組識別碼**：`TIME-08`  
> **系統歸屬**：遊戲時間（GameClock）四季特色環境修正  
> **單一真相來源**：本規格書確立遊戲內春夏秋冬四季節點之環境數值修正參數、建設效率翻倍、秋收糧草加成、冬日結緣與行軍阻滯等唯一定義標準。

---

## 一、系統概述與架構原則

為了營造三國時代「春耕、夏築、秋收、冬聚」之季節韻律，遊戲時鐘在流轉不同季度時，賦予全域系統特定的環境修正倍率。所有數值由純配置表驅動，並支援外部 JSON 設定檔覆寫與安全回退。

### Unity / 架構對照
- **環境設定表**：類似 Unity 中的 `SeasonModifierScriptableObject`，以季節索引（1~4）查表取得倍率物件。
- **純量安全修正**：所有倍率皆具備非負約束與整數/浮點正規化校驗。

## 二、四季環境修正資料模型

```typescript
export interface SeasonModifier {
    taxMultiplier: number;              // 春：稅收收益倍率
    constructionMultiplier: number;     // 夏：領地建設效率倍率（工期加速）
    trainingStaminaMultiplier: number;  // 夏：書院訓練體力消耗倍率
    foodMultiplier: number;             // 秋：全域糧草補給收成倍率
    conceptionMultiplier: number;       // 冬：結緣生子受孕率倍率
    travelTurnsDelta: number;           // 冬：地圖行軍趕路回合增加量
}

export type SeasonModifierConfig = Record<1 | 2 | 3 | 4, SeasonModifier>;
```

## 三、標準四季數值配置矩陣

```typescript
const NEUTRAL: SeasonModifier = {
    taxMultiplier: 1.0,
    constructionMultiplier: 1.0,
    trainingStaminaMultiplier: 1.0,
    foodMultiplier: 1.0,
    conceptionMultiplier: 1.0,
    travelTurnsDelta: 0,
};

export const DEFAULT_SEASON_MODIFIERS: Readonly<SeasonModifierConfig> = {
    // 1: 春季 — 歲首萌發，基準穩定
    1: { ...NEUTRAL, taxMultiplier: 1.0 },
    // 2: 夏季 — 盛夏築城，工期翻倍；炎熱使訓練耗體力提升
    2: { ...NEUTRAL, constructionMultiplier: 2.0, trainingStaminaMultiplier: 1.25 },
    // 3: 秋季 — 秋收萬顆子，糧草撥補 1.5 倍
    3: { ...NEUTRAL, foodMultiplier: 1.5 },
    // 4: 冬季 — 歲暮宴飲，結緣受孕率 1.1 倍；大雪封山使趕路多 1 回合
    4: { ...NEUTRAL, conceptionMultiplier: 1.1, travelTurnsDelta: 1 },
};
```

### 四季環境特色一覽表

| 季節 | 節令主題 | 核心特化效果 | 數值修正 | 系統連動模組 |
|:---:|---|---|:---:|---|
| **春 (1)** | 春耕納稅 | 萬物復甦，全域各項指標為標準基準 | 稅收 $\times 1.0$ | 內政經濟庫 |
| **夏 (2)** | 盛暑築城 | 城防修築與擴建效率翻倍；高溫增加訓練耗損 | 建設 $\times 2.0$、體力消耗 $\times 1.25$ | 領地建設、學府培育 |
| **秋 (3)** | 秋高馬肥 | 糧草大豐收，農耕收益達到頂點 | 糧草收成 $\times 1.5$ | 軍糧儲備庫 |
| **冬 (4)** | 歲暮結緣 | 圍爐夜話促成良緣；嚴寒行軍步調減緩 | 結緣 $+10\%$、行軍 $+1$ 回合 | 結緣生子、地圖趕路 |

## 四、設定檔載入與安全正規化演算法

```typescript
export function normalizeSeasonModifiers(raw: unknown): SeasonModifierConfig {
    const seasons = raw && typeof raw === 'object' && !Array.isArray(raw) 
        ? (raw as Record<string, unknown>).seasons : undefined;
    const source = seasons && typeof seasons === 'object' ? (seasons as Record<string, unknown>) : {};
    
    const out = {} as SeasonModifierConfig;
    for (const s of [1, 2, 3, 4] as const) {
        const item = source[s] && typeof source[s] === 'object' ? (source[s] as Record<string, unknown>) : {};
        const def = DEFAULT_SEASON_MODIFIERS[s];
        
        out[s] = {
            taxMultiplier: typeof item.taxMultiplier === 'number' && item.taxMultiplier >= 0 ? item.taxMultiplier : def.taxMultiplier,
            constructionMultiplier: typeof item.constructionMultiplier === 'number' && item.constructionMultiplier >= 0 ? item.constructionMultiplier : def.constructionMultiplier,
            trainingStaminaMultiplier: typeof item.trainingStaminaMultiplier === 'number' && item.trainingStaminaMultiplier >= 0 ? item.trainingStaminaMultiplier : def.trainingStaminaMultiplier,
            foodMultiplier: typeof item.foodMultiplier === 'number' && item.foodMultiplier >= 0 ? item.foodMultiplier : def.foodMultiplier,
            conceptionMultiplier: typeof item.conceptionMultiplier === 'number' && item.conceptionMultiplier >= 0 ? item.conceptionMultiplier : def.conceptionMultiplier,
            travelTurnsDelta: typeof item.travelTurnsDelta === 'number' && Number.isInteger(item.travelTurnsDelta) ? item.travelTurnsDelta : def.travelTurnsDelta,
        };
    }
    return out;
}
```

## 五、驗收條件與測試案例 (Test Cases)

- **TC-TIME-21（夏季雙倍建設驗證）**：
  - 夏季（2）之 `constructionMultiplier` 為 2.0，工程消耗回合折半或進度加倍。
- **TC-TIME-22（秋季糧草增益驗證）**：
  - 秋季（3）之 `foodMultiplier` 精確為 1.5，季末補給撥發 150 糧草。
- **TC-TIME-23（冬季行軍延遲驗證）**：
  - 冬季（4）之 `travelTurnsDelta` 為 $+1$，原本 3 回合到達之旅程延長為 4 回合。
- **TC-TIME-24（異常負數配置防禦）**：
  - 若設定檔輸入 `foodMultiplier: -1`，正規化後自動安全回退為預設值 1.5。

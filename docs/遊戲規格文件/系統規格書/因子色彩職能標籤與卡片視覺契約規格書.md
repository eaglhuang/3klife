# 因子色彩職能標籤與卡片視覺契約規格書

> **責任邊界**：本檔為遺傳因子七色渲染、職能標籤（Role Tag）映射與武將卡片視覺表現的單一真相來源。
> **關聯 WBS**：FATE-09（因子色彩對應職能視覺化）、FATE-05（因子色彩定義）、GEN-02（遺傳因子槽）。
> **整併裁決**：徹底裁定歷史「未定義哪種因子色對應哪個職能」之缺口；確立七曜色彩與七大職能映射單一標準。

---

## §1. 七曜因子色彩與七大職能映射總表

武將卡片、詳情頁角標與因子槽位，依據因子主要光譜呈現特定色彩與職能標籤：

| 因子色彩系 | Design Token 參照 | 對應職能標籤 (`RoleTag`) | 核心定位與職能特性 | UI 視覺代表符號 |
|:---|:---|:---:|:---|:---:|
| **藍色 (Blue)** | `color-gene-combat` | **戰鬥武官** (`COMBAT_OFFICER`) | 正規軍攻防、陣地指揮、統率步騎迎擊 | 龍雀大刀 |
| **粉紅 (Crimson)** | `color-gene-vanguard`| **猛將先鋒** (`VANGUARD_BERSERKER`) | 單挑斬將、暴擊突圍、士氣突破與死戰 | 虎煞雙戟 |
| **綠色 (Emerald)**| `color-gene-tactics` | **儒將智囊** (`TACTICAL_STRATEGIST`)| 火攻水計、奇門八卦、戰場控場與識破 | 羽扇綸巾 |
| **金色 (Imperial)**| `color-gene-supreme` | **統帥三軍** (`SUPREME_COMMANDER`) | 全軍光環、兵力增幅、史實名將傳奇主帥 | 傳國玉璽 |

## §2. 卡片視覺呈現規範 (Card Visual Contract)

武將卡片（包括抽卡開牌、名冊卡片、出征選角框）必須遵循以下層級渲染：

```
+------------------------------------------+
| [職能徽章 Role Badge] (對應色+圖標)        |
|                                          |
|            [武將全身/半身立繪]            |
|       (依主因子色散發微光邊緣 Halo)       |
|                                          |
|------------------------------------------|
| 武將姓名・稱號                 稀有度標籤 |
| [●][●][●][○][○] (五格因子槽，依色彩點亮)  |
+------------------------------------------+
```

1. **職能徽章 (Role Badge)**：
   - 位於卡片左上角，尺寸固定 36×36 px。
   - 底色採用對應因子色之 80% 透明漸層，圖標採白金描邊向量圖。
2. **光暈邊緣 (Rim Light / Halo)**：
   - 當武將擁有 ★4 以上主因子時，立繪輪廓散發對應色呼吸光暈（週期 2.4 秒）。
3. **因子槽位列 (Gene Slots)**：
   - 依因子清單順序渲染 3~5 顆發光光玉（`●`）；未覺醒槽位呈灰色鎖孔（`○`）。

## §3. 職能判定與色彩優先權協議

單一武將可能同時擁有多個不同顏色之因子，其對外顯示的「主要職能標籤」依下列權重判定：

1. **金色傳奇優先**：只要擁有金色因子，職能標籤強制為「統帥三軍」。
2. **星級與加成最高者**：若無金色，則比較藍/紅/綠/紫/白/銀因子中「星級總和最高者」。
3. **同分仲裁順序**：若星等平手，依 `先鋒 (紅) > 武官 (藍) > 智囊 (綠) > 清貴 (紫) > 敢死 (白) > 民官 (銀)` 順序裁定。

## §4. UI Design Token 引用守則

所有介面控制器（`GeneralDetailView`, `GeneralCardItem`）嚴格透過 Token 引用色值：

```typescript
export const GENE_ROLE_THEME_TOKENS = {
  COMBAT_OFFICER:     { token: 'color-gene-combat',   hex: '#2E6BE6', label: '戰鬥武官' },
  VANGUARD_BERSERKER: { token: 'color-gene-vanguard', hex: '#E63956', label: '猛將先鋒' },
  TACTICAL_STRATEGIST:{ token: 'color-gene-tactics',  hex: '#28A745', label: '儒將智囊' },
  SUPREME_COMMANDER:  { token: 'color-gene-supreme',  hex: '#D4AF37', label: '統帥三軍' },
  NOBLE_SAGE:         { token: 'color-gene-noble',    hex: '#8A2BE2', label: '名流清貴' },
  ELITE_COMMANDO:     { token: 'color-gene-commando', hex: '#E0E0E0', label: '特戰敢死' },
  CIVIL_GOVERNOR:     { token: 'color-gene-civil',    hex: '#A8B2C1', label: '執政民官' },
} as const;
```

> **禁止硬編碼原則**：嚴禁在 TypeScript 組件直接填寫 `#hex` 色碼，一律走 `ThemeService.resolveToken()`。

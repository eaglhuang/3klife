# 因子視覺遮罩與玩家發現等級三階段模型規格書

> 標籤：`FUL-01` · `FUL-02` · `M2` · `因子遮罩` · `發現等級` · `雙旗標分離` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，遺傳因子之「視覺可見性（`revealed`）」與「實質生效性（`active`）」雙旗標解耦模型（`FactorMask`），以及依據玩家等級（`Player_Level`）分三階段循序解開因子資訊之遮罩演算法。

本模組為純邏輯無副作用運算，負責提供介面層統一之字串契約與狀態旗標，不直接操作 Cocos 渲染節點。

---

## 2. 發現等級三階段門檻模型（Discovery Phases）

為保障新手期認知負荷平緩，全域六色因子依玩家等級劃分為三個解鎖階段：

```typescript
export const FACTOR_DISCOVERY_LEVEL: Record<FactorColor, number> = {
    blue: 1,    // 藍色 (基礎屬性): 玩家等級 >= 1
    pink: 1,    // 粉色 (兵種/地形適性): 玩家等級 >= 1
    green: 1,   // 綠色 (戰法種子): 玩家等級 >= 1
    white: 20,  // 白色 (性格/特質): 玩家等級 >= 20
    red: 20,    // 紅色 (體魄/壽命): 玩家等級 >= 20
    purple: 45, // 紫色 (天命/奇觀): 玩家等級 >= 45
};
```

### 2.1 階段權重與開放內容對照表

| 階段序號 | 門檻等級 | 開放因子色系 | 涵蓋範疇 |
|:---:|:---:|---|---|
| **Phase 1 (初入亂世)** | Lv 1 | 藍色 (`blue`)、粉色 (`pink`)、綠色 (`green`) | 武力/智力等屬性加成、騎兵/水戰適性、戰法種子 |
| **Phase 2 (一方諸侯)** | Lv 20 | 白色 (`white`)、紅色 (`red`) | 名將人格特質、長壽/鐵壁等體魄因子 |
| **Phase 3 (開天辟地)** | Lv 45 | 紫色 (`purple`) | 天命之子、神佑、極致血脈奇觀因子 |

## 3. 雙旗標解耦狀態模型（FactorMaskView）

因子之資訊展示與戰鬥/內政生效完全解耦，由兩組獨立旗標控制：

```typescript
export interface FactorMaskView {
    revealed: boolean;      // 是否看得到名稱 (受 Player_Level 限制)
    active: boolean;        // 是否實質生效 (受 gene.isLocked 限制)
    requiredLevel: number;  // 發現所需之玩家等級門檻
    label: string;          // 介面展示文字
}
```

### 3.1 雙旗標狀態四態表

| 發現狀態 (`revealed`) | 鎖定狀態 (`active`) | 介面視覺表現 | 遊戲數值影響 |
|:---:|:---:|---|---|
| **未發現 (`false`)** | **未生效 (`false`)** | 顯示 `??? (Lv N 解鎖)` | 無任何屬性或技能加成 |
| **已發現 (`true`)** | **未生效 (`false`)** | 顯示因子名稱，圖標覆蓋**灰色鎖頭** | 資訊可見，但數值尚未啟用 |
| **已發現 (`true`)** | **已生效 (`true`)** | 因子圖標**彩色高光點亮** | 屬性加成與戰法技能完全生效 |
| **未發現 (`false`)** | **已生效 (`true`)** | 顯示 `??? (生效中)`（極罕見保底狀態） | 實質提供數值，隱藏名稱 |

## 4. 介面字串展示合約

```typescript
export function factorMaskView(gene: GeneralGeneConfig, playerLevel: number): FactorMaskView {
    const requiredLevel = factorRequiredLevel(gene);
    const revealed = isFactorLevelUnlocked(playerLevel, requiredLevel);
    const label = revealed
        ? gene.displayName ?? gene.id ?? ''
        : `??? (Lv${requiredLevel + 1} 解鎖)`;
    return { revealed, active: gene.isLocked === false, requiredLevel, label };
}
```

- **動態提示字串**：當玩家等級未達門檻時，明確指示下階段解鎖等級，激發玩家推進主線與升級成就之動力。

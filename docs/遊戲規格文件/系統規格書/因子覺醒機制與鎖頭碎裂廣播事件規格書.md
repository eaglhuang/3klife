# 因子覺醒機制與鎖頭碎裂廣播事件規格書

> 標籤：`FBR-04` · `M5` · `因子覺醒` · `碎鎖機制` · `全域廣播` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，武將身上處於灰鎖狀態（`isLocked: true`）之遺傳因子，在滿足特定觸發途徑（`AwakeningTrigger`）與玩家發現等級門檻時，執行原子態解鎖（`awakenFactor`）並拋送 `FactorAwakenedEvent` 全域事件之狀態機。

本模組為純邏輯無副作用運算，負責驗證解鎖合法性並組裝新武將資料副本，動畫表現與存檔落盤由上層管理項調度。

---

## 2. 四大觸發途徑與色系白名單（Invariants）

因子覺醒嚴格依據色系限制合法之觸發途徑，防範非法途徑越權解鎖：

```typescript
export type AwakeningTrigger = 'nurture-peek' | 'battle' | 'mentor' | 'sage';

export const AWAKENING_TRIGGERS_BY_COLOR: Record<FactorColor, readonly AwakeningTrigger[]> = {
    blue: ['nurture-peek', 'battle', 'sage'],
    pink: ['nurture-peek', 'battle', 'sage'],
    green: ['mentor', 'battle', 'sage'],
    white: ['mentor', 'battle', 'sage'],
    purple: ['battle', 'sage'],
    red: ['battle', 'sage'],
};
```

### 2.1 色系白名單對照表

| 因子色系 | 涵蓋範疇 | 合法觸發途徑 | 說明 |
|---|---|---|---|
| **藍色 / 粉色** | 基礎屬性 / 兵種適性 | 培育窺探、戰場實戰、名士占卜 | 常規成長核心，觸發途徑最廣 |
| **綠色 / 白色** | 戰法種子 / 人格特質 | 教官傳授、戰場特定動作、名士占卜 | 需特定導師引導或沙場極限激發 |
| **紫色 / 紅色** | 天命奇觀 / 長壽體魄 | 戰場極限條件、名士占卜 | 極致天賦，嚴禁於常規窺探中輕易獲得 |

## 3. 覺醒合法性驗證狀態機（awakenFactor）

當觸發覺醒時，系統依序進行五重前置排他校驗：

```
                    ┌─────────────────────────┐
                    │      觸發覺醒請求       │
                    └────────────┬────────────┘
                                 │
                   [ 武將/因子存在? 因子未解鎖? ]
                   ├── 否 ──> 拒絕: no-such-general / no-such-factor / already-unlocked
                   └── 是
                                 │
                   [ 途徑在色系白名單內? (trigger) ]
                   ├── 否 ──> 拒絕: trigger-not-allowed
                   └── 是
                                 │
                   [ discoveryLevel >= 門檻? ]
                   ├── 否 ──> 拒絕: level-too-low
                   └── 是
                                 │
                    ┌────────────┴────────────┐
                    │ 翻轉: isLocked = false  │
                    │ 拋出 FactorAwakenedEvent│
                    └─────────────────────────┘
```

1. **`no-such-general` / `no-such-factor`**：對象武將或指定因子不存在。
2. **`already-unlocked`**：該因子之 `isLocked === false`，已處於生效狀態。
3. **`trigger-not-allowed`**：嘗試以非法途徑解鎖該色系（例如用培育窺探解鎖紫色天命）。
4. **`level-too-low`**：玩家當前 `discoveryLevel` 低於該因子所需門檻（藍粉綠 1、白紅 20、紫 45）。
5. **成功解鎖**：建立武將新副本，將指定因子之 `isLocked` 設為 `false`，並回傳 `{ ok: true }`。

## 4. 全域廣播事件與專屬題詞

覺醒成功時拋出之 `FactorAwakenedEvent` 攜帶完整元數據：

```typescript
export interface FactorAwakenedEvent {
    generalId: string;
    factorId: string;
    color: FactorColor | null;
    level: number;
    trigger: AwakeningTrigger;
    displayName: string;
}
```

UI 層監聽事件並調用 `factorAwakeningLines`，播放鎖頭碎裂特效與戰術題詞：
- **綠色戰法**：「祖傳戰法種子萌發！習得 綠色戰法 所需 TP 減半！」
- **紫色天命**：「天命之力覺醒！未來爆發力將不可限量！」
- **白色特質**：「隱藏天賦顯現：{displayName}。」

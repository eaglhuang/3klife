# 因子覺醒碎裂狀態機與條件判定規格書

> **責任邊界**：本檔為武將遺傳因子槽狀態機（GeneSlot）、因子覺醒判定（FactorAwakening）與碎裂特效管線的單一真相來源。
> **關聯 WBS**：GEN-08（因子覺醒與碎裂特效）、GEN-02（遺傳因子槽）、REC-06（里程碑隱藏因子）。
> **整併裁決**：確立因子三態轉換協議（鎖定/裂紋/覺醒）；定案戰鬥、培育與里程碑三大覺醒觸發判定公式。

---

## §1. 因子槽三態生命週期狀態機

武將身上的 3~5 個遺傳因子槽位，依序遵循以下三態轉換：

```
[LOCKED 灰色石化帶鎖] ──(算命窺探/培育引導)──> [PEEKED 金色裂紋窺探]
          │                                              │
          └───────────(滿足條件並判定成功)────────────────┘
                                  │
                                  ▼
                     [AWAKENED 碎裂綻放光玉] (永久生效)
```

| 狀態代碼 | 屬性標記 | UI 視覺外觀 | 屬性與戰術效益 |
|:---:|:---:|:---|:---|
| **`LOCKED`** | `isLocked: true, isPeeked: false` | 灰色石卵表面封閉，中央有金屬銅鎖 | **完全無效**：不提供任何屬性、戰法或被動加成 |
| **`PEEKED`** | `isLocked: true, isPeeked: true` | 石卵產生細密金色裂紋，隱約透出底色 | **資訊揭示**：可查看因子名稱與傾向，仍不生效 |
| **`AWAKENED`** | `isLocked: false, isPeeked: true` | 外殼徹底碎裂，呈現七曜光玉持續燃燒脈動 | **完全激活**：常駐提供攻防增幅、特殊特技與適性修正 |

## §2. 三大覺醒觸發源與判定公式

因子解鎖嚴格受系統等級門檻（`discoveryLevel`）管制，並由以下三大情境觸發：

### 2.1 戰場特殊戰功判定 (`rollBattleAwakening`)

戰鬥中當武將完成「單挑斬將」、「首次破城」或「以少勝多」時，回合結束立即執行一次覺醒判定：
$$\text{AwakenChance} = \text{BASE\_BATTLE\_AWAKEN\_RATE} + \left(\frac{\text{LUK}}{10}\right) \times 0.01$$
- 基礎覺醒機率：$\text{BASE\_BATTLE\_AWAKEN\_RATE} = 15\%$。
- 若幸運值 $\text{LUK} = 80$，則額外提升 $+8\%$，最終機率達到 $23\%$。

### 2.2 書院策論修業奇遇 (`rollNurtureAwakening`)

在 36 回合學府培育中，當教官好感度滿 100 觸發「七日頓悟」或遭遇名士點撥時，指定一個鎖定槽位強制覺醒。

### 2.3 史實里程碑達成 (`HiddenFactorAwakening`)

達成生涯極限成就時（如「累計出征 50 戰全勝」），自動解鎖對應隱藏白色/紅色傳奇因子（如 `gene_hidden_undefeated`），去重後直接寫入。

## §3. 碎裂視覺動效與音效契約 (Shatter VFX Contract)

當因子狀態由 `LOCKED/PEEKED` 翻轉為 `AWAKENED` 時，UI 播放專屬碎裂動畫：

```
[點擊覺醒 / 戰報揭曉] 
       │
       ▼ (0.00s ~ 0.20s) 石卵劇烈震顫，金色光芒自裂紋透出
       ▼ (0.20s ~ 0.35s) 外殼向外炸裂成 6~8 塊多邊形碎片，播放 sfx_crystal_shatter
       ▼ (0.35s ~ 0.65s) 核心光玉騰空而起，釋放因子光芒衝擊波，數值彈跳浮現
```

1. **粒子擴散 (Particle Burst)**：碎片淡出消失，周圍伴隨 24 顆對應因子色（如武官藍、先鋒紅）星芒粒子環形擴散。
2. **文字通告 (Broadcast)**：畫面正下方顯示 Toast `【因子覺醒！】獲得特技：[因子名稱]`。
3. **無損回存**：狀態變更即時透過 `GameSession.awakenFactor()` 落盤，中途斷線重啟保持已覺醒狀態。

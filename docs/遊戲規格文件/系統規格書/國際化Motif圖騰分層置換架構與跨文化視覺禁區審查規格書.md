# 3KLife 國際化Motif圖騰分層置換架構與跨文化視覺禁區審查規格書

> **規格代碼**：SPEC-ART-BML11  
> **關聯 WBS**：BML-11（M10 國際化 motif layer 可替換與視覺禁區審查）  
> **文件版本**：v1.0.0 (單一真相來源，無補丁整併版)  
> **所屬系統**：UI 介面與視覺工程（UI Architecture & Art Pipeline）

---

## 1. 核心宗旨與設計哲學

為支援遊戲跨國全球化發行（包含繁中、簡中、日韓、歐美市場），並遵循各發行地區之法規分級審查標準（如中國防血腥暴力審查、德國嚴禁特定符號法規），本規格書建立**主題圖騰分層置換架構（Motif Layer Decoupling Architecture）**。將文化敏感與風格適配圖騰自基礎骨架抽離，實現零代碼更動之 JSON 動態切換，並規範**跨文化視覺禁區審查標準**。

---

## 2. Motif Layer 分層可替換架構

### 2.1 介面骨架與圖騰層解耦

所有命鏡、虎符、角色頁與戰旗介面，一律劃分為「核心骨架」與「文化圖騰」雙層結構：

```
+-------------------------------------------------------+
| Core Skeleton (不變)  | 漢風青銅外框、佈局排版、互動按鈕 |
+-----------------------+-------------------------------+
| Motif Layer   (動態)  | 頂部銘文印鑑、家徽紋樣、靈獸圖騰 |
+-------------------------------------------------------+
```

### 2.2 多語系 Motif 替換配置 (locale-motif-manifest.json)

```typescript
export interface LocaleMotifMapping {
  componentId: string;                // 元件識別碼 (如 MIRROR_HEADER_SIGIL)
  variants: {
    'zh-TW': string;                  // 繁體中文標準漢風篆印
    'zh-CN': string;                  // 簡體中文合規版 (去骨骸/合規字形)
    'ja': string;                     // 日版和風水墨家紋微調
    'en': string;                     // 歐美版高對比古典雕塑版
  };
}
```

- **置換保證**：替換前後圖資尺寸、錨點與頂點座標嚴格保持 1:1，確保切換時**零排版震顫（Zero Layout Reflow）**。

## 3. 跨文化視覺禁區審查清單 (Cross-Cultural Taboo Checklist)

所有進入海外版本發佈管線之視覺資產，必須通過自動化靜態與人工 Checklist 審查：

| 禁區編號 | 限制類型 | 嚴格禁止元素 (Prohibited) | 合規替代方案 (Prescribed) |
|---|---|---|---|
| **CC-01** | **骨骸白骨限制** | 骷髏頭骨、外露白骨、腐肉死屍。 | 魂魄青燈、古劍折戟、金石斷甲、幽微水墨靈光。 |
| **CC-02** | **宗教敏感符號** | 卐/卍字紋變體、逆十字、特定宗教神像。 | 漢代正統雲雷紋、夔龍紋、饕餮金石回形紋。 |
| **CC-03** | **赤紅血腥噴濺** | 鮮紅色血液大面積噴濺、斷肢內臟殘片。 | 濃黑水墨揮毫飛濺、金羽碎裂或星芒消散粒子。 |
| **CC-04** | **現代地緣衝突** | 涉及現代爭議之邊界地圖、現代國旗色系。 | 嚴格限定漢末三國十三州古籍手繪輿圖。 |

## 4. 驗收測試案例 (Test Cases)

- **TC-BML-11-01【動態語系 Motif 切換驗證】**：在命鏡介面運行期切換語系為 `ja`，頂部印鑑無縫切換為日版雅緻水墨家徽，整體介面無尺寸抖動。
- **TC-BML-11-02【簡體合規去血化自動驗證】**：切換為 `zh-CN` 環境，戰場暴擊傷害特效自動由紅色水墨轉為金色曜石粒子，通過文化部防血腥審查。
- **TC-BML-11-03【未配置語系回退保底】**：傳入未明確定義之語系（如 `fr`），系統自動安全回退至 `en` 國際通用高對比 Motif，避免缺圖紫黑塊。

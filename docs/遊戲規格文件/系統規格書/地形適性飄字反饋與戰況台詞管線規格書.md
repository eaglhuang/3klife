# 地形適性飄字反饋與戰況台詞管線規格書

> **責任邊界**：本檔為部隊地形踏入即時飄字反饋（Floating Feedback）、適性台詞管線（AptitudeDialogue）與戰報 Toast 的單一真相來源。
> **關聯 WBS**：APT-14（適性劇本台詞）、APT-14b（地形視覺與飄字反饋）、APT-05（地形特殊效果）。
> **整併裁決**：確立踏上 S/A/D 地形之三色動態飄字規範；定案回合開場適性台詞六級嚴格優先序。

---

## §1. 部隊移動踏入地形飄字反饋規範

當部隊在戰場棋盤完成移動並定格時，系統即時讀取同陣營主將之該地形適性等級（S ~ D），於部隊頭頂觸發微動態飄字：

| 地形適性等級 | 飄字文字內容 | 視覺樣式與色彩 Token | 戰術效果簡要 |
|:---:|:---|:---|:---|
| **S 級** | `【地利優勢】` | 金綠漸層微光 (`#48C774`)，帶向上光塵粒子 | 攻防 +20%，平原騎兵衝鋒傷害再 +10% |
| **A 級** | `【適應良好】` | 淺天藍色高亮 (`#3273DC`)，標準淡出 | 攻防 +10% |
| **B / C 級** | *(不飄字)* | 無特效（杜絕戰場視覺資訊噪音） | 常規基準攻防（1.0 / 0.9） |
| **D 級** | `【寸步難行】` | 深紅色警示 (`#F14668`)，帶輕微震顫動效 | 攻防 -20%，部隊移動力強制 -1 |

### 飄字渲染契約 (Motion Spec)

- **動畫軌跡**：自單位中心錨點向上浮動 35 像素，歷時 0.85 秒（前 0.25 秒線性加速，後 0.6 秒二次緩動並淡出）。
- **防重疊限制**：若多支部隊於同一秒移動（如 AI 批次移動），飄字依部隊行動順序間隔 120ms 錯峰呈現。

## §2. 回合開場適性台詞六級調度器 (AptitudeDialogue)

戰鬥回合開始階段（Turn Start），系統評估當前最前線主將之座標與天候，自六大類別中依**唯一嚴格優先序**選擇一句觸發：

```
[天氣劇變 wind] (優先級 1)
       │
       ▼
[水戰大師 water-s] (優先級 2: 水域且水戰 S)
       │
       ▼
[山林名將 mountain-s] (優先級 3: 山地且山地 S)
       │
       ▼
[霧隱奇襲 fog] (優先級 4: 大霧且霧戰 S / 識破)
       │
       ▼
[夜幕先鋒 night] (優先級 5: 夜戰且夜戰 S)
       │
       ▼
[深陷險境 insufficient] (優先級 6: 地形/天氣為 D 級適性不足)
```

## §3. 畫面載體與戰鬥日誌管線協議

1. **戰場抬頭 Toast**：台詞選出後，於畫面中央偏上方浮現透明黑底金邊對話條，停留 1.6 秒後淡出。
2. **戰鬥日誌整合 (Combat Log)**：台詞同步寫入 `BattleCombatResolver.actionLog`，並標註標籤 `[適性機略]`。
3. **音效觸發**：伴隨台詞彈出，播放 0.4 秒輕竹簡翻閱聲（`sfx_bamboo_scroll`）。

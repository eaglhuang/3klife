# 地窖保護機制與戰敗保底資源不可掠奪規格書

## 1. 核心定位與設計理念
本規格書定義《三國人生》玩家在軍事戰鬥失敗或城池防守失利後，觸發的「地窖資源保護（Cellar Protection）」保底不可掠奪機制（WBS `ECO-05`，代碼落位於 `CellarProtection.ts` 與 `GameSession.ts`）。
系統建立一道不可逾越之物理儲備底線，防止玩家因遭遇強敵連敗導致糧盡金絕、兵力真空而徹底喪失翻盤希望，為新手與逆境玩家提供最關鍵的生存護城河。

```
              ┌──────────────────────────────────────────────┐
              │          CellarProtection 地窖保護機制       │
              └──────────────────────┬───────────────────────┘
                                     │ 戰敗結算觸發 (enemy-win)
          ┌──────────────────────────┴──────────────────────────┐
          ▼                                                     ▼
   【地窖保底底線 (Floor)】                              【扣減夾回公式 (Keep)】
   • foodFloor: 1,500 單位                               • keep = min(before, floor)
   • goldFloor: 600 單位                                 • after < keep: 強制夾回 keep
   • 被保護量不可被掠奪                                  • 戰前已低於保底: 不再扣亦不補
```

---

## 2. 地窖保護基準數值矩陣（`CELLAR_PROTECTION`）

| 資源項目 | 地窖保底底線 (`Floor`) | 戰敗保護戰略意向 |
| :--- | :---: | :--- |
| **糧草 (`foodFloor`)** | **1,500 單位** | 確保戰敗後仍保有足夠軍糧維持至少 1~2 場小規模出征或鄉勇徵集 |
| **黃金 (`goldFloor`)** | **600 單位** | 保留基礎流通貨幣，確保能支付基礎修繕與行商最低週轉資金 |

- **觸發開關**：`triggerAfterFailedDefense = true`，僅在出征戰敗（`enemy-win`）或領地防守破城時啟動。

## 3. 戰敗扣減保底運算模型（`protectedAfterLoss`）

戰鬥扣除戰損與出征軍糧後，依據戰前存量與保底底線計算最終保留量：

$$\text{Keep} = \max(0, \min(\text{Before}, \lfloor \text{Floor} \rfloor))$$
$$\text{FinalAfter} = \begin{cases} \text{After}, & \text{After} \ge \text{Keep} \ (\text{未擊穿保底}) \\ \text{Keep}, & \text{After} < \text{Keep} \ (\text{觸發地窖防護}) \end{cases}$$
$$\text{Saved} = \begin{cases} 0, & \text{After} \ge \text{Keep} \\ \text{Keep} - \text{After}, & \text{After} < \text{Keep} \end{cases}$$

### 3.1 關鍵運作邊界
1. **未擊穿保底（常規扣減）**：若戰前有 3,000 糧，戰敗扣除 1,000 糧，扣後剩餘 2,000 糧（$\ge 1,500$），地窖保護不觸發，`Saved = 0`。
2. **擊穿保底（強制夾回）**：若戰前有 3,000 糧，戰敗扣除 2,500 糧，扣後算得 500 糧，系統強制夾回至 1,500 糧，回報保住資源 `Saved = 1,000` 糧。
3. **戰前已貧困（不二度扣減、不憑空補給）**：若戰前原本僅存 800 糧（$< 1,500$），戰後 `Keep = 800`。系統保證其資源不會被扣到低於 800 糧，但**絕不自動憑空灌水補滿至 1,500 糧**（資源缺口由每日補貼承接）。

---

## 4. 戰後會話（`GameSession`）結算協議

1. **戰報反饋**：戰鬥結算紀錄中保存 `lastCellarProtectedFood`，並於結算面板彈出「地窖隱蔽庫存發揮效用，保全糧草 X 單位！」之安心提示。
2. **勝利豁免原則**：若戰鬥結果為玩家獲勝（`player-win`），出征糧草為正常軍事開銷，一律實質扣除，絕不觸發地窖保護。

## 1. 系統架構定位與暗度陳倉戰法

善攻者動於九天之上，善守者藏於九地之下。官渡之戰袁紹掘地道攻曹操、陳倉之戰郝昭聽甕破諸葛亮，《三國人生》（3KLife）構建**地下工兵掘進與地聽反制系統（Sapping & Counter-Sapping）**。

本系統核心價值：
1. **三維地底維度（Subterranean Vector）**：避開正面箭雨，沿地底向城垣下方推進。
2. **聽甕地聽偵測博弈（Acoustic Surveillance）**：守軍透過地聽甕捕捉地底震動，佈設反制水煙。
3. **終結性城崩破土（Catastrophic Breach）**：貫通後可選擇死士城內奇襲或焚柱使城牆垮塌。

## 2. 地道掘進生命週期資料定義

進攻方指派工兵部隊在城外隱蔽處挖掘地道口（Tunnel Entrance）：

```typescript
export interface ISappingTunnel {
  readonly tunnelId: string;
  readonly entranceCoords: { x: number; y: number };
  targetCoords: { x: number; y: number };  // 目標城牆或城內地格
  tunnelProgressRatio: number;             // 掘進進度 (0.0 ~ 1.0)
  readonly turnsToComplete: number;        // 總需工期 (通常為 4 回合)
  isDetectedByDefender: boolean;           // 是否已被敵方聽甕捕捉
  isFloodedOrSmoked: boolean;              // 是否已被灌水或毒煙摧毀
}
```

## 3. 守軍「聽甕地聽」與反制陷阱

守軍在城牆下埋設青銅大甕，由盲人聽金辨聲：
1. **地鳴預警（Seismic Warning）**：
   - 當地道推進至距離城牆 $\le 3$ 格時，守軍觸發「地鳴異響」情報，小地圖標註地道大致走向半徑。
2. **雙重反制戰術（Counter-Measures）**：
   - **橫渠灌水（Water Injection）**：引護城河水灌入地道，地道進度歸零，地道內部工兵溺斃全滅。
   - **皮橐熏煙（Poison Smoke）**：以風箱向地道口鼓吹狼煙艾草，地道內工兵陷入窒息潰退，3 回合內無法再次挖掘。

## 4. 終結成果結算：破土奇襲 vs 城牆塌陷

若進攻方在未被反制的情況下進度達成 **$100\%$**，可二選一引爆戰果：

1. **暗度陳倉・城內奇襲（Infiltration Assault）**：
   - 精銳死士直接自城內無防備之糧倉地格破土現身。
   - 奇襲部隊直接切斷城門吊橋絞盤，**城門強制向外敞開**，敵軍全城守衛陷入恐慌。
2. **天崩地裂・城牆塌陷（Wall Collapse）**：
   - 抽薪焚燒地底支撐柱，上方城牆發生結構性連鎖崩塌。
   - 該城牆地格耐久直接清零，並由障礙物轉變為「坍塌碎石斜坡（Rubble Ramp）」，全軍步騎均可直接馳騁攀登入城！

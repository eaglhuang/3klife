# 3KLife 城垣崩塌緊急背土搶築半月弧形月城第二防線狀態機規格書

## 1. 系統概述與設計哲學
在敵軍以霹靂車暴擊、地道爆破或大水浸泡導致城垣外牆發生坍塌潰口時，若任由敵部隊直貫城心，城池必破無疑。三國名將（如郝昭守陳倉、曹仁守江陵）常實施「背土搶築半月弧形月城」（CRESCENT-INNER-RETRENCHMENT01）。
守城主將在警覺外牆結構失穩之瞬間，立即徵調城內精壯軍民，於潰口後方十餘步處，拋擲裝滿沙石之麻袋、插立粗重柳木柵欄、填塞碎石黏土，連夜搶築起一道內凹之「半月弧形重壁」（月城）。月城不僅將坍塌缺口重新圍合，更誘使敵衝鋒部隊湧入缺口後陷入半圓形口袋殺傷區，城頭與月城居高臨下形成交叉射界，將攻城前鋒盡數聚殲於甕底。

## 4. 交叉火力與袋形幾何物理模型

### 4.1 半月弧形交叉射擊幾何加成
月城內凹弧形結構使防守方獲得無死角向心包圍視界：
$$\text{Damage}_{\text{crossfire}} = \text{BaseDamage} \times 2.2 \times (1.0 + \frac{\text{ArcDensity}}{180^\circ})$$
- 湧入缺口之敵軍失去陣型掩護，其所受箭雨、投石及長槍截殺傷害大幅攀升 $220\%$，且後路被湧入人潮堵死無法迅速撤退。

### 4.2 應急沙袋抗衝擊吸能機制
1. **沙袋緩衝吸震**：沙袋土包面對敵方床弩巨箭及小型拋石時，具備優異之塑性變形吸能效果，不易產生二次碎石濺射傷害。
2. **木樁阻截撕裂**：斜向深植地下三尺之鹿角木樁，能徹底截斷敵軍先登甲士之衝鋒慣性。

## 5. 單元驗收測試標準
1. **TC-RETRENCH-01 (外垣崩塌連夜搶築全流程)**：
   - 注入外城垣坍塌事件，觸發軍民緊急築牆。
   - 驗證在 8 小時倒計時內完成月城搭建，精準轉換至 `CRESCENT_CROSSFIRE_ALIGN`。
2. **TC-RETRENCH-02 (口袋殺傷區三面交叉火力殲敵)**：
   - 注入 150 名敵先鋒湧入缺口。
   - 驗證敵軍受困於月城前地格，承受 2.2 倍向心射擊傷害，部隊於 3 回合內崩潰。
3. **TC-RETRENCH-03 (夯實封閉與陣線穩定)**：
   - 擊退敵軍後啟動 `BREACH_PERMANENT_SEAL`，驗證缺口阻絕防禦度恢復至常態水準。

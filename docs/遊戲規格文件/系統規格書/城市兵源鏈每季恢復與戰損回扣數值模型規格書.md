# 城市兵源鏈每季恢復與戰損回扣數值模型規格書

## 1. 核心定位與戰略兵源契約

本規格書為城市兵源與糧草戰略儲備生命週期（Military Reserve Chain，代號 `DEP-02`）的單一真相來源（Single Source of Truth）。涵蓋出征前讀取、戰後實質戰損寫回、每季自然徵兵回補，以及戰損恢復週期（$\text{TurnsToRecover}$）數值模型。

```typescript
export interface MilitaryReserveContract {
  foodPerSeasonBase: 150;         // 每季基礎糧草補給 150
  starterCityTroops: 10000;       // 初始城市兵源 10000
  starterCityTroopsCap: 30000;    // 初始城市兵源上限 30000
  starterRecruitRegen: 1500;      // 初始每季補兵速度 1500
}
```

---

## 2. 戰後結算原子回扣（Sortie Result Apply）

戰役結束後，由 `applySortieResult` 執行一次性原子結算，將戰場消耗與戰損直接回扣至城市儲備：

### 2.1 兵源戰損扣除

$$\text{CityTroops}_{\text{new}} = \max\left(0, \text{CityTroops}_{\text{current}} - \lfloor \text{LostTroops} \rfloor\right)$$

- **戰損核算**：實質陣亡之部隊兵力直接永久銷毀。傷兵營收容之傷兵不計入陣亡，不在此處重複扣除。
- **負數防護**：若單役戰損超過城市當前兵源，城市兵源強制歸零保底，不產生負數負債。

### 2.2 糧草出征消耗扣除

$$\text{Food}_{\text{new}} = \max\left(0, \text{Food}_{\text{current}} - \lfloor \text{FoodSpent} \rfloor\right)$$

- 戰役中虎符部隊部署所耗費之糧草，自主城糧倉原子扣除。

---

## 3. 每季季節推進與自然回補（Season Regen）

在大地圖時間跨越一季或數季時（`regenMilitaryOneSeason`），城市自動徵兵與糧草產出回流：

### 3.1 城市兵源徵召回補

$$\text{CityTroops}_{\text{new}} = \min\left(\text{CityTroopsCap}, \text{CityTroops} + (\text{RecruitRegen} \times N)\right)$$

- 每季固定徵召 $\text{RecruitRegen}$ 兵力（預設 1,500/季）。
- 嚴格受限於城市兵源上限（$\text{CityTroopsCap}$），達到上限後停止回補。

### 3.2 糧草儲備回補

$$\text{Food}_{\text{new}} = \min\left(\text{FoodCap}, \text{Food} + \lfloor 150 \times N \times M_{\text{season}} \rfloor\right)$$

- 基礎補給：每季 150 糧草。
- 季節乘數：秋收季節享有產出倍率加成（$M_{\text{season}} = 1.5$），冬荒季節可能降權（$M_{\text{season}} = 0.8$）。

---

## 4. 戰損恢復回合預估模型（Turns To Recover）

為提供軍師決策面板與玩家戰後評估情資，系統即時計算補滿戰損所需耗費之時間季度：

$$\text{TurnsToRecover} = \left\lceil \frac{\text{LostTroops}}{\text{RecruitRegen}} \right\rceil$$

- **向上取整（Ceil）**：確保即便只有少許兵力缺額，亦必須耗費完整一季完成招募整編。
- **戰術警示**：若預估恢復週期 $\text{TurnsToRecover} \ge 4$（即超過 1 年方能補齊），介面跳出【兵源空虛】警戒提示。

1. **單元測試對齊**：
   - 對齊 `tests/BattleRecordStats.test.ts` 與 `tests/SeasonModifiers.test.ts`。
   - 驗收條件 1：驗證兵源 5000 遭受 2000 戰損時，寫回後城市兵源嚴格等於 3000。
   - 驗收條件 2：驗證每季推進後兵源增加 $\text{RecruitRegen} \times N$ 且不突破上限。
   - 驗收條件 3：驗證無效或損毀之存檔資料經 `normalizeMilitaryReserve` 能夠完美回退至起始安全配置。

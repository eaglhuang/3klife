# 3KLife 城池巷戰街壘工事搭建與街道狹路交鋒狀態機規格書

> **規格代碼**：SPEC-BAT-STREET01  
> **關聯 WBS**：BATTLE-STREET-01（城池內部巷戰街壘工事、街道狹窄走廊通行約束與居民民心協防狀態機）  
> **系統分類**：攻城作戰 / 城內巷戰與空間物理管線  
> **狀態**：正式生效（單一真相來源，嚴禁尾端追加補丁）

## 1. 系統架構定位與破門後的第二戰場

城門雖破，戰事未休。三國攻堅戰中，城門淪陷往往只是殘酷血戰的起點，如合肥之戰、襄樊巷戰。《三國人生》（3KLife）構建**城內巷戰街壘與狹窄街道交鋒模型（Urban Warfare & Barricades）**。

本系統核心價值：
1. **狹窄走廊空間約束（Narrow Corridor Trap）**：城內街道寬度僅 1~2 格，騎兵大軍無法展開衝鋒。
2. **街壘工事防禦陣地（Barricade Construction）**：守軍可利用廢墟與木石臨時架設街壘，構成第二道防線。
3. **民心向背動態響應（Civilian Alignment）**：城內百姓可化為協防民兵，亦可化為開門帶路之內應。

## 2. 街壘工事資料結構與搭建狀態機

守軍工兵或步兵部隊可在關鍵十字路口搭建**臨時街壘（Barricade）**：

```typescript
export interface IBarricadeNode {
  readonly position: { x: number; y: number };
  currentHp: number;                     // 街壘當前耐久值 (通常為 1500)
  readonly maxHp: number;                // 街壘最大耐久值
  readonly coverDamageReduction: number; // 掩體免傷率 (50%)
  blocksCavalryCharge: boolean;          // 是否強制阻斷騎兵衝鋒 (true)
  isFlammable: boolean;                  // 木質結構易燃 (可被火攻破壞)
}
```

```
 [民居建築 A] ───────────────不可通行牆面───────────────
 [狹窄街道   ] ===> [ 臨時木石街壘 (免傷 50%) ] <=== 守軍步弩集火
 [民居建築 B] ───────────────不可通行牆面───────────────
```

1. **搭建耗時**：部隊進駐地格宣告「搭建街壘」，耗時 1 完整回合；期間部隊無法攻擊。
2. **掩體免傷特權**：處於街壘後方的部隊獲得 **$50\%$ 遠程與近戰免傷**，且完全免疫正面衝擊擊退。
3. **騎兵衝鋒阻斷**：任何敵對騎兵在撞擊街壘時，衝鋒動能立即歸零，並受到反震傷害 15%。

## 3. 瓦礫廢墟（Rubble）通行約束

被投石車砸毀或火災燒毀的民居轉化為**瓦礫廢墟地格**：
- **行軍阻滯**：廢墟地格崎嶇難行，步兵通行額外消耗 $+2$ 點移動力。
- **車輛禁入**：所有重型攻城器械（衝車、霹靂車）與騎兵部隊**完全禁止駛入廢墟地格**。

## 4. 城內民心（Public Sentiment）動態協防機制

城內交戰時，系統檢核該城池當前的「民心歸屬指數 $S_{\text{civil}} \in [0, 100]$」：

```typescript
export enum CivilianStance {
  MILITIA_DEFENSE = 'MILITIA_DEFENSE', // 民心 >= 80：百姓自發落石助守
  NEUTRAL_FLEEING = 'NEUTRAL_FLEEING', // 民心 40~79：百姓閉門自保避難
  GUIDE_INVADERS = 'GUIDE_INVADERS'    // 民心 < 40：百姓充當敵軍嚮導引路
}
```

1. **同仇敵愾（民心 $\ge 80$）**：
   - 侵略軍每踏入一處民居巷道，有 $40\%$ 機率遭遇屋頂百姓拋擲滾木擂石，損失 5% 兵力並扣除士氣 3 點。
   - 守軍部隊每回合在民宅獲得糧水救護，傷兵自癒率提升 $+10\%$。
2. **簞食壺漿開門引路（民心 $< 40$）**：
   - 百姓主動向入侵軍指引城內隱密暗道，進攻方獲得「民夫引路」增益：直接無視 2 處街壘阻隔，開闢繞後突襲通道。

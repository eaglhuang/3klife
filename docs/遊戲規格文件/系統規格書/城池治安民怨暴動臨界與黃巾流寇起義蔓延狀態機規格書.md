# 3KLife 城池治安民怨暴動臨界與黃巾流寇起義蔓延狀態機規格書

> **規格代碼**：SPEC-CITY-RIOT01  
> **關聯 WBS**：CITY-RIOT-01（城池治安指數模型、民怨暴動觸發閥值與黃巾流寇跨郡蔓延狀態機）  
> **系統分類**：內政統治 / 治安民意與農民暴動管線  
> **狀態**：正式生效（單一真相來源，嚴禁尾端追加補丁）

---

## 1. 系統架構定位與水能載舟亦能覆舟

民為貴，社稷次之，君為輕。東漢末年蒼天已死、黃巾當立之根源，皆在於民不聊生。《三國人生》（3KLife）為各州郡城池實裝**動態治安民怨與暴動起義演算法（Public Order & Rebellion System）**。

本系統核心價值：
1. **多因數民怨反饋（Grievance Multi-Vector）**：重稅、強行徵兵、天災大旱、長年征戰直接侵蝕民心。
2. **三階治安惡化狀態機（Three-Tier Deterioration）**：自民間微有怨言逐步升級為府衙暴動。
3. **流寇滾雪球蔓延（Bandit Contagion）**：若未及時撫卹剿滅，暴民將勾結黃巾黑山殘黨，形成蔓延數郡之軍閥級叛軍。

## 2. 城池治安指數資料結構與增減算式

每座城池在季度結算時計算當前治安值 $O_{\text{order}} \in [0, 100]$：

```typescript
export interface ICityPublicOrderState {
  readonly cityId: string;
  publicOrder: number;              // 治安指數 (0: 暴動淪陷 ~ 100: 夜不閉戶)
  grievancePoints: number;          // 民怨累積點數 (0 ~ 100)
  taxRateTier: 'LOW' | 'MEDIUM' | 'HEAVY' | 'EXTORTION'; // 賦稅等級
  hasNaturalDisaster: boolean;      // 是否遭遇旱災、蝗災或瘟疫
  isGarrisoned: boolean;            // 是否有足額守備軍隊駐紮
}
```

每季治安波動算式：
$$\Delta O_{\text{order}} = \text{Bonus}_{\text{governor\_charm}} - \text{Penalty}_{\text{tax}} - \text{Penalty}_{\text{disaster}} + \text{Bonus}_{\text{garrison}}$$

1. **加稅剝削（Extortion）**：採取極端苛稅每季治安直接 $-25$ 點，民怨 $+30$ 點。
2. **天災肆虐（Disaster）**：遭遇蝗旱且府庫未開倉放糧者，每季治安 $-20$ 點。
3. **太守德政（Governance）**：指派仁德魅力型太守（如劉備、陶謙、魯肅），每季治安自然回復 $+15$ 點。

## 3. 三階治安惡化與暴民起義狀態機

```
       [ORDERLY 安居樂業 (治安 80~100)] ──── 稅賦全額徵收、商業繁榮
                        │
                        │ 治安跌破 60
                        ▼
       [UNREST 治安不靖 (治安 40~59)] ───── 盜賊出沒、商隊遭遇劫掠率 +40%
                        │
                        │ 治安跌破 30
                        ▼
       [RIOTOUS 暴動邊緣 (治安 20~39)] ───── 百姓罷市抗稅、徵兵招募直接歸零
                        │
                        │ 治安跌破 20 點臨界線
                        ▼
       【REBELLION 揭竿而起暴民起義！】 ─── 暴民攻破府衙，太守被圍困！
```

1. **府衙陷落危機**：治安跌破 20 觸發【起義暴動】，城內刷出「暴民義軍（兵力 8,000~15,000）」，城內所有商業與農業產出暫停。
2. **太守平暴檢核**：
   - 駐軍若擊潰暴民，治安強制鎖定回升至 35，但民怨指數暫不消退。
   - 若守軍不足被暴民擊破，太守被驅逐或斬殺，**城池脫離玩家控制轉為中立暴動城**。

## 4. 黃巾流寇跨郡蔓延機制（Bandit Spillover）

暴動城池若在 **2 個季度內未被平定收復**，暴民組織度質變升級：
1. **黃巾殘黨合流**：起義暴民擁戴「天公將軍信徒」或黑山賊于毒、白繞為渠帥，番號正式轉化為「黃巾復興軍」。
2. **向外跨郡擴散**：黃巾軍每季分裂出一支掠奪支隊，主動進攻相鄰治安低於 50 的周邊郡縣，引爆「連鎖民變（Contagion Riots）」，造成整個州郡陷入火海。

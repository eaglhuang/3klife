# 3KLife 城防地聽甕深埋坑道伏耳探聽敵軍掘穴地道狀態機規格書

## 1. 系統定位與設計意圖

在三國攻城戰役（如審配守鄴城、郝昭守陳倉）中，進攻方常常藉由挖掘地下地道（穴攻）試圖避開護城河與城垛，直通城內或掘空城牆根基。本系統規範要塞反地道偵測防禦系統「深埋地聽青銅甕聲學定位網（Acoustic Jar Tunnel Listening）」之深井預埋、皮膜共振、聲學測向與反穴工兵交戰狀態機：
- **深掘地井與倒扣大甕**：沿城內女牆內側每二十步挖掘深達二丈之豎井，井底倒扣大口青銅甕或厚壁陶缸，口蒙極薄熟羊皮膜。
- **固體傳聲與聲學共振**：土壤與岩層對鐵鎬破土之低頻振動傳遞遠優於空氣，地聽兵伏耳於羊皮膜上，利用空腔共鳴放大微弱敲擊聲。
- **精準測向與迎頭橫掘截殺**：藉由相鄰三座地聽甕之音量衰減與時間差，三點定位敵地道方位，守軍即刻挖掘垂直橫井實施灌水、薰煙反制。

## 2. 狀態機架構與轉換生命週期

地聽防禦狀態機（代碼：`ACOUSTIC-JAR-TUNNEL-LISTENING01`）管理自日常監聽至地底阻擊之完整週期：

```
[ WELL_ACOUSTIC_CALIBRATION ] (深井倒扣青銅甕羊皮膜張緊校準)
          │
          ▼
[ VIGILANT_LISTENING_LOOP ] (盲人地聽老兵輪替伏耳探測地底震動)
          │
          ├── 捕獲微弱鐵鎬刨土聲 ──> [ SIGNAL_FILTER_RUMBLE ]
          ▼
[ TRIANGULATION_LOCALIZE ] (相鄰三井測距交叉計算地道座標)
          │
          ▼
[ COUNTER_TUNNEL_DIGGING ] (工兵依標記斜向挖掘攔截對沖豎井)
          │
          ├── 兩軍地底鑿穿貫通
          ▼
[ SUBTERRANEAN_COUNTER_ATTACK ] (灌入毒煙江水或死士短刃地底近戰)
          │
          ▼
[ TUNNEL_COLLAPSE_NEUTRALIZE ] (炸毀支護原木徹底回填塌陷掩埋)
```

### 狀態細部定義

1. **WELL_ACOUSTIC_CALIBRATION（校準調諧）**：
   - 工兵檢查豎井乾燥度，將直徑三尺之厚壁陶甕倒扣緊貼井底生土，羊皮膜塗抹熟桐油防潮，共鳴頻率鎖定在 80~250 Hz。
2. **VIGILANT_LISTENING_LOOP（日常聆聽）**：
   - 挑選聽覺專精之盲人斥候日夜輪值，每半刻鐘貼耳一次，過濾地面車馬輜重雜音。
3. **SIGNAL_FILTER_RUMBLE（信號辨識）**：
   - 辨識出節奏固定的鐵鎬掘土聲（每分鐘 25~35 次鈍擊），確認敵軍工兵已推進至距城牆 40 步範圍內。
4. **TRIANGULATION_LOCALIZE（三點定位）**：
   - 記錄相鄰 A、B、C 三號深井之音強分貝值，以聲波衰減公式精準推算敵地道前端之三維空間深度（誤差小於 2 步）。
5. **COUNTER_TUNNEL_DIGGING（迎擊對掘）**：
   - 守軍工兵以最快速度反向挖掘迎擊井，在敵軍抵達城基前 15 步截斷其前進軸線。
6. **SUBTERRANEAN_COUNTER_ATTACK（地下殲滅）**：
   - 鑿通瞬間向敵穴內灌入滾燙金汁或鼓吹艾草硫磺毒煙，瓦解敵掘穴死士，隨後引爆坑木實施封死。

## 3. 關鍵數值與計算判定公式

### 3.1 土壤固體傳聲與聲強衰減模型

地聽甕接收到之震動音強 $I_{listen}$（分貝）：
$$I_{listen} = I_{source} - 20 \log_{10}(D_{distance}) - \alpha_{soil} \times D_{distance} + G_{jar}$$
- $I_{source}$：地底鐵鎬敲擊岩石之源端音強（約 $85\,\text{dB}$）。
- $D_{distance}$：地道前端至聽甕之直線歐幾里得距離（公尺）。
- $\alpha_{soil}$：夯土岩層吸收衰減係數（砂土約 $0.35\,\text{dB/m}$，黏土約 $0.18\,\text{dB/m}$）。
- $G_{jar}$：青銅空腔與羊皮共鳴增益（固定補償 $+16\,\text{dB}$）。
- 當 $I_{listen} \ge 22\,\text{dB}$ 時，地聽兵即可 100% 辨別敵掘土訊號。

### 3.2 三點交叉定位誤差半徑

空間定位誤差半徑 $\sigma_{loc}$（步）：
$$\sigma_{loc} = \frac{\sigma_{sound\_sensor}}{\sqrt{N_{wells}}} \times \left(1.0 + \frac{V_{surface\_noise}}{40}\right)$$
- 三井連鎖監控下，定位精度在 2.5 步以內，足以精準引導反擊橫井。

## 4. 戰術連鎖與攻防克制

1. **徹底封殺奇襲穴攻**：使進攻方耗費數月挖掘的地道完全暴露，轉為致命埋骨陷阱。
2. **天敵與敵方反制**：
   - **地面奔馬干擾**：敵軍在地面組織騎兵連續奔馳踏地，製造強烈雜波淹沒地聽微弱信號。
   - **軟木包鐵鎬消音**：敵掘穴工兵以厚生牛皮包裹鐵鎬柄部並以水浸潤土層，使敲擊噪音衰減 55%。

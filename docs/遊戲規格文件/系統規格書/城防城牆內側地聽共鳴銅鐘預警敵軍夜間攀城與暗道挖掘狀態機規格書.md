# 城防城牆內側地聽共鳴銅鐘預警敵軍夜間攀城與暗道挖掘狀態機規格書

> **來源**：《墨子·備穴》與中國古代守城聲學預警機關「共鳴銅鐘／懸鐘地聽」（於城牆根部每隔十丈埋入連通牆體之空心陶管，管口上方懸掛薄壁青銅共鳴鐘並置乾豆或銅丸；無論敵軍於地下掘進震動城基，或夜間死士以飛虎爪摳擊外牆攀登，微弱震波皆會引發銅鐘嗡鳴與銅丸跳落，瞬間驚醒守軍）、WBS `FORM-152` 城防全域聲學反潛行模組。
> **關聯文件**：`doc_spec_0887`（城防地聽甕探穴）、`doc_spec_0870`（飛虎爪攀絕壁奇襲）、`doc_spec_0864`（城垛懸燈白磷破夜隱）。

## 一、 設計目標與戰術定位

傳統「地聽甕（`doc_spec_0887`）」需依賴專職盲人聽師伏耳傾聽地下暗道，對城牆外表的「夜間飛爪攀爬」或「多點同時滲透」反應較慢。「城牆內側地聽共鳴銅鐘」則將導音陶管直接嵌入夯土城牆與地基，利用薄壁銅鐘與銅丸的機械共振，達成全天候、全城段自動觸發的立體反隱預警網。

1. **雙維度震波偵測（地下穴攻 + 牆面攀爬）**：同時監控地下 `5` 格內之掘道震動與外牆表面之飛虎爪／雲梯搭靠震動。
2. **銅丸墜盤自動報警（Auto-Trigger Alarm）**：無需消耗守軍專注力，一旦震動超標，銅丸滾落銅盤發出清脆巨響，立即破除該城段敵軍之「夜間潛行」。
3. **聯動城頭燈火與擂石（Defense Chain Reaction）**：鐘聲響起瞬間，該城段守軍自動解除「夜間疲倦／視野縮減」，並對牆外攀爬者獲得先制落石加成。

## 二、 狀態機生命週期（5 階段）

```
[1. 埋管懸鐘 Acoustic_Bell_Calibrated]
       │ (敵軍於 5 格內掘道，或夜間死士搭爪攀爬外牆)
       ▼
[2. 震波共鳴 Vibration_Resonance_Detect]
       │ (陶管放大結構震波，鐘頂銅丸失衡滾落)
       ▼
[3. 金聲驚夜 Bronze_Chime_Alarm]
       │ (鐘聲傳遍城頭：強制破除 4 格內敵軍潛行狀態)
       ▼
[4. 燈火鎖定 Flare_And_Boulder_Lock]
       │ (聯動懸燈照亮牆面，守軍對攀城敵軍傷害 +40%)
       ▼
[5. 重置銅丸 Reset_Pendulum_Standby]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `ACOUSTIC_BELL_CALIBRATED` | 埋管懸鐘 | 守軍沿城牆內側每隔 `4` 格設置一具共鳴銅鐘，處於靜音靈敏監測狀態。 |
| `VIBRATION_RESONANCE_DETECT` | 震波共鳴 | 當敵軍工兵在距離城牆 $\le 5$ 格挖掘地道，或敵方先登死士對城牆投擲飛虎爪／架設竹梯時，牆體導音管立即捕捉微震。 |
| `BRONZE_CHIME_ALARM` | 金聲驚夜 | 鐘頂平衡銅丸墜入下方青銅承盤，鐘鳴聲覆蓋城牆周圍 `4` 格，**100% 強制破除**範圍內所有敵軍之「夜行隱匿／潛行」狀態。 |
| `FLARE_AND_BOULDER_LOCK` | 燈火鎖定 | 預警觸發後，該城段守軍免疫「背刺奇襲」，夜戰視野懲罰歸零，且當回合對牆下／牆面敵軍投擲礌石與射擊傷害 `+40%`。 |
| `RESET_PENDULUM_STANDBY` | 重置銅丸 | 警報結束後，值守兵卒重新放回銅丸，1 回合後恢復 `ACOUSTIC_BELL_CALIBRATED`。 |

## 三、 核心數值與判定公式

### 3.1 微震捕捉靈敏度公式（Vibration Sensitivity）
$$S_{\text{detect}} = \text{clamp}\left(0.95 - 0.08 \times D_{\text{source}} - 0.20 \times \mathbb{I}_{\text{heavyRain}},\ 0.35,\ 0.98\right)$$
- $D_{\text{source}}$：震源距離城牆格數（貼牆攀爬 $D=0$ 時捕捉率高達 `95%`）。
- $\mathbb{I}_{\text{heavyRain}}$：若處於傾盆大雨或雷暴天氣，雨聲干擾使靈敏度下降 `20%`。

### 3.2 反制夜間奇襲增傷公式（Counter-Raid Damage Bonus）
$$D_{\text{counter}} = D_{\text{defBase}} \times \left(1 + 0.40 \times \mathbb{I}_{\text{alarmActive}}\right)$$
- 一旦銅鐘鳴響（$\mathbb{I}_{\text{alarmActive}} = 1$），敵方死士原本享有的「夜間破隱暴擊」被完全剝奪，反而承受守軍 `1.40x` 迎頭痛擊。

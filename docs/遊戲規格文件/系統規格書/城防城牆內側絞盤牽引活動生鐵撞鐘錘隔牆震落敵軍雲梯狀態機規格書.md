# 城防城牆內側絞盤牽引活動生鐵撞鐘錘隔牆震落敵軍雲梯狀態機規格書

> **來源**：《武經總要》守城篇「撞車／隔牆撞鐘錘」與三國守城反雲梯器械（於城牆女牆上架設雙柱懸臂木架，以粗麻繩懸吊前端包覆生鐵球頭之千斤檀木撞錘；當敵軍飛梯或竹雲梯搭扣城垛時，守軍於女牆內側拉動絞盤將撞錘向後高高拽起，隨即鬆索使撞錘穿過垛口向外猛力擺擊，一錘撞斷雲梯上端或將整架雲梯向後震翻）、WBS `FORM-158` 城頭重擺錘反梯模組。
> **關聯文件**：`doc_spec_0845`（懸索狼牙鐵拍）、`doc_spec_0906`（夜叉擂滾動下墜）、`doc_spec_0903`（懸臂翻斗潑灑沸油）。

---

## 一、 設計目標與戰術定位

「狼牙拍（`doc_spec_0845`）」與「夜叉擂（`doc_spec_0906`）」皆為順著城牆外立面垂直向下砸落之器械，對於斜角極大、僅頂端鐵鉤搭在女牆垛口上的「長竹飛梯」，垂直下墜器械往往只能擦過梯頂而無法將其推翻。「活動生鐵撞鐘錘」則利用鐘擺水平向外擺動的巨大衝量，直接從垛口由內向外正面猛撞雲梯頂端，專司「斷鉤、折梯、推翻整架雲梯」。

1. **水平向外鐘擺衝擊（Horizontal Outward Pendulum）**：針對斜靠城牆之雲梯，提供垂直於梯身的水平推力，推翻成功率遠高於垂直落石。
2. **生鐵球頭震波傳導（Shockwave Along Ladder）**：縱使敵軍雲梯以鐵爪死鎖未倒，千斤生鐵錘頭撞擊梯頂的劇烈震波也會沿木梯傳導，將梯上攀爬的敵兵全部震落摔死。
3. **擺動自動回腔（Pendulum Auto-Return）**：撞擊完畢後撞錘隨重力自然擺回女牆內側，無需像狼牙拍般費力從城下絞盤拉升，冷卻極快。

## 二、 狀態機生命週期（5 階段）

```
[1. 懸架待擊 Pendulum_Frame_Ready]
       │ (敵雲梯搭扣該城段垛口，守軍拉索後曳蓄勢)
       ▼
[2. 滿弦曳錘 Winch_Pull_Back_Max]
       │ (將千斤生鐵撞錘拉至 60 度仰角，鎖定垛口外梯頂)
       ▼
[3. 穿垛轟梯 Outward_Pendulum_Smash]
       │ (撞錘向外擺出垛口：對雲梯造成 280% 結構破壞)
       ▼
[4. 震落傾覆 Ladder_Topple_Or_Shake]
       │ (梯上敵兵 100% 震落墜地；雲梯仰角 >75 度則向後翻倒)
       ▼
[5. 擺回待命 Swing_Back_Reset]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `PENDULUM_FRAME_READY` | 懸架待擊 | 城頭走馬道架設門字形雙柱木架，懸吊八百斤包鐵撞鐘錘，對正女牆垛口。 |
| `WINCH_PULL_BACK_MAX` | 滿弦曳錘 | 偵測到敵軍雲梯搭上垛口，4 名守軍拉動後曳索將撞錘拉起至 `60` 度高位。 |
| `OUTWARD_PENDULUM_SMASH` | 穿垛轟梯 | 脫鉤釋放，生鐵撞錘加速穿出垛口正面轟擊雲梯頂端，對雲梯造成 `280%` 結構粉碎傷害，並直接撞斷普通鐵鉤。 |
| `LADDER_TOPPLE_OR_SHAKE` | 震落傾覆 | 劇烈水平衝擊使正在該雲梯上攀爬之敵軍 **100% 脫手墜落城下**（承受 `190%` 墜落摔傷）；若雲梯未釘地樁，直接向後仰翻砸傷城下後隊。 |
| `SWING_BACK_RESET` | 擺回待命 | 撞錘依鐘擺慣性自動擺回女牆內側，僅需 `1` 回合即可重新拉起再次撞擊。 |

## 三、 核心數值與判定公式

### 3.1 鐘擺位能轉水平衝擊力公式（Pendulum Impact Force）
$$F_{\text{impact}} = M_{\text{hammer}} \times g \times (1 - \cos\theta) \times 2.80 \quad (\theta = 60^\circ)$$
- 轉化為遊戲內對攻城雲梯之結構傷害：$D_{\text{ladder}} = \text{ATK}_{\text{siegeDef}} \times 2.80$；若雲梯剩餘耐久 $\le 40\%$，一錘直接折斷梯頂。

### 3.2 雲梯後翻與連環砸傷公式（Ladder Topple Crush）
$$P_{\text{topple}} = \text{clamp}\left(0.85 - 0.35 \times \mathbb{I}_{\text{ironHooked}},\ 0.30,\ 0.95\right)$$
- 若雲梯被向後撞翻，梯身拍落地面對城牆根部 `2` 格內之敵軍候補梯隊造成 `145%` 範圍鈍擊壓傷。

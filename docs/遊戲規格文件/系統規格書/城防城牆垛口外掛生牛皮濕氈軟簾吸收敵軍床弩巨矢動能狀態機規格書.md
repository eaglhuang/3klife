# 城防城牆垛口外掛生牛皮濕氈軟簾吸收敵軍床弩巨矢動能狀態機規格書

> **來源**：《墨子·備城門》、《武經總要》守城篇「護城軟簾／牛皮流蘇濕氈幕」（於城牆女牆外側以鐵橫桿懸掛三層浸水生牛皮與厚毛氈編織之重型軟簾，下端垂懸不固定；當敵軍三弓床弩巨矢或投石機石彈迎面射來時，軟簾隨衝擊向內凹陷擺動，以柔性阻尼卸去八成以上動能，使巨矢無力墜入護城河）、WBS `FORM-164` 城防柔性卸力護幕模組。
> **關聯文件**：`doc_spec_0847`（城防伏遠床弩）、`doc_spec_0795`（三弓床弩連珠重矢）、`doc_spec_0930`（女牆內側活動木製遮矢棚）。

---

## 一、 設計目標與戰術定位

面對敵軍攻城部隊架設的「三弓床弩（`doc_spec_0795`）」或「踏張強弩」，堅硬的木盾與磚石女牆往往會因剛性對撞而被直接鑿穿崩裂。「城牆垛口外掛生牛皮濕氈軟簾」則運用「以柔克剛、懸垂擺動卸力」的物理機制：軟簾上端固定於出挑鐵臂、下端自然懸空垂掛（與牆面保持三尺緩衝間距）。當床弩巨矢高速射中軟簾時，三層濕牛皮包裹箭鏃並隨之向後擺動緩衝，將剛性穿刺動能轉化為軟簾抬升的重力位能，令巨矢無法穿透女牆。

1. **懸垂擺動柔性卸力（Pendulum Cushion Absorption）**：專門克制高穿甲之「床弩巨矢」與「投石機石彈」，吸收 `82%` 剛性穿甲動能。
2. **三尺緩衝氣隙（Three-Foot Buffer Air-Gap）**：軟簾與女牆之間留有三尺空隙，巨矢縱使刺破外層牛皮，動能亦在氣隙擺動中耗盡，不會傷及牆後守軍。
3. **掀起射擊與放下防禦無縫切換**：守軍射擊時以竹竿撐開軟簾下角射孔，射畢鬆手軟簾即刻垂落封閉。

## 二、 狀態機生命週期（5 階段）

```
[1. 挑臂垂簾 Curtain_Outrigger_Hung]
       │ (女牆外挑鐵桿掛起三層濕牛皮氈簾，保持三尺氣隙)
       ▼
[2. 遇矢兜裹 Soft_Curtain_Wrap_Impact]
       │ (敵床弩/投石命中：軟簾向內凹陷擺動，包裹彈體)
       ▼
[3. 擺動卸能 Pendulum_Kinetic_Dissipate]
       │ (轉化動能為位能：吸收 82% 穿甲與攻城傷害)
       ▼
[4. 無力墜落 Spent_Projectile_Drop]
       │ (巨矢/石彈失去動能滑落城下，女牆與守軍零貫穿傷)
       ▼
[5. 淋水保潤 Water_Drench_Maintenance]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `CURTAIN_OUTRIGGER_HUNG` | 挑臂垂簾 | 守軍於重點城段女牆外懸掛寬 `4` 格之三層生牛皮濕氈軟簾，城牆正面進入柔性防護狀態。 |
| `SOFT_CURTAIN_WRAP_IMPACT` | 遇矢兜裹 | 當敵方床弩巨矢、神臂弓或投石機平射命中該城段時，韌性極強的生牛皮瞬間兜住彈頭而不碎裂。 |
| `PENDULUM_KINETIC_DISSIPATE` | 擺動卸能 | 軟簾向內擺動至極限角度，卸去 `82%` 物理穿甲傷害與攻城結構傷害，且**完全免疫床弩之「直線貫穿串刺（Pierce-Through）」特效**。 |
| `SPENT_PROJECTILE_DROP` | 無力墜落 | 軟簾回擺時，耗盡動能之巨矢與石彈順著光滑濕牛皮滑落護城河，守軍可於城下回收羽箭。 |
| `WATER_DRENCH_MAINTENANCE` | 淋水保潤 | 城頭守軍每 `3` 回合自頂部水槽淋水一次，維持軟簾濕潤（火抗 `+80%`）與皮革柔韌度。 |

## 三、 核心數值與判定公式

### 3.1 柔性卸力對重型穿甲減傷公式（Soft Curtain Kinetic Absorption）
$$D_{\text{wall}} = D_{\text{ballistaRaw}} \times (1 - 0.82) \times \left(1 + 0.40 \times \mathbb{I}_{\text{sickleCut}}\right)$$
- 對床弩、強弩與投石減傷高達 `82%`；但若敵軍使用前端帶寬刃彎鉤之「割簾鉤矢（$\mathbb{I}_{\text{sickleCut}} = 1$）」專割懸掛麻繩，軟簾耐久消耗增加 `40%`。

### 3.2 破除串刺貫穿判定（Anti-Piercing Interception）
$$\text{PierceCount}_{\text{effective}} = 0 \quad (\text{When Curtain Active})$$
- 原本能一次貫穿城頭前後兩排守軍之伏遠床弩巨矢（`doc_spec_0847`），在軟簾生效期間貫穿人數強制歸零。

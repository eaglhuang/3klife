# 城防城牆女牆內側活動木製遮矢棚防禦敵軍拋射箭雨狀態機規格書

> **來源**：《武經總要》守城篇「遮矢棚／女頭慢」（於城牆女牆內側走馬道上架設傾斜四十五度之活動厚木板棚頂，外覆生牛皮與濕氈；專門抵禦敵軍攻城井闌、雲梯弓手及拋射箭雨對守城兵頂部的殺傷，並可隨戰況收折讓開拋石射界）、WBS `FORM-149` 城防頂部防空掩體模組。
> **關聯文件**：`doc_spec_0865`（生牛皮木幔盾牆）、`doc_spec_0885`（投石機碎石散彈壓制）、`doc_spec_0843`（攻城臨衝高樓俯瞰壓制）。

---

## 一、 設計目標與戰術定位

城頭守軍雖有女牆垛口保護正面，但在面對敵軍「高角度拋射箭雨」、「井闌高樓俯射」以及「投石機碎石散彈（`doc_spec_0885`）」時，頭頂與後背往往暴露無遺。「活動木製遮矢棚」便是架設在城頭走馬道上方的傾斜防護頂棚，能將自天而降的箭矢與碎石彈開滑落城外，同時保留守軍從垛口向外平射的視線。

1. **四十五度斜頂卸力（Sloped Roof Deflection）**：高空拋射之羽箭與小型散彈撞擊覆皮斜木棚後自動滑落，提供 `75%` 遠程防空減傷。
2. **濕氈覆頂防火矢（Wet Felt Fire-Proofing）**：棚頂鋪設浸水毛氈，使敵軍拋射之火矢無法點燃木棚。
3. **活動鉸鏈開合切換（Hinged Fold Mechanism）**：當守軍需操作城頭重型投石機或木鶴高拋反擊時，可迅速收折遮矢棚讓出天空射界。

## 二、 狀態機生命週期（5 階段）

```
[1. 折棚待命 Shed_Folded_Standby]
       │ (偵測敵軍弓弩齊射、井闌靠近或散彈拋射)
       ▼
[2. 撐桿展棚 Canopy_Unfold_Lock]
       │ (斜撐木桿頂起 45 度牛皮濕氈棚，覆蓋城頭 1x4 格)
       ▼
[3. 卸矢防空 Arrow_Rain_Deflection]
       │ (遠程拋射與俯射減傷 75%，免疫火矢點燃)
       ▼
[4. 垛口還擊 Embrasure_Counter_Volley]
       │ (守軍於棚下安全平射，命中率 +15%、免疫壓制)
       ▼
[5. 收棚讓界 Fold_For_Heavy_Artillery]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `SHED_FOLDED_STANDBY` | 折棚待命 | 遮矢棚平時向下折疊貼靠內牆，不影響城頭守軍快速移動與重型器械高仰角拋射。 |
| `CANOPY_UNFOLD_LOCK` | 撐桿展棚 | 當敵軍弓弩團或井闌進入射程時，守軍支起生鐵斜撐桿展開頂棚，覆蓋城頭 `1x4` 格走馬道。 |
| `ARROW_RAIN_DEFLECTION` | 卸矢防空 | 處於遮矢棚下之守軍，承受敵方「拋射箭雨」、「井闌俯射」與「碎石散彈」傷害降低 `75%`，且頂部濕氈完全免疫火矢引燃。 |
| `EMBRASURE_COUNTER_VOLLEY` | 垛口還擊 | 守軍免受頭頂箭雨干擾，可從容依托女牆射孔向外精準還擊，遠程命中率 `+15%`，且免疫「散彈壓制低頭」狀態。 |
| `FOLD_FOR_HEAVY_ARTILLERY` | 收棚讓界 | 若該城段需發動「城頭重型投石機」或「游動木鶴（`doc_spec_0915`）」，可消耗 `0.5` 回合折收頂棚；若遭敵軍千斤獨石直接命中則頂棚損毀。 |

## 三、 核心數值與判定公式

### 3.1 棚下遠程傷害減免公式（Canopy Ranged Mitigation）
$$D_{\text{received}} = D_{\text{rangedRaw}} \times \left(1 - 0.75 \times \mathbb{I}_{\text{canopyActive}}\right) \times \left(1 + 1.50 \times \mathbb{I}_{\text{heavyBoulder}}\right)$$
- 遮矢棚對羽箭、連弩、碎石散彈減傷 `75%`；但若敵軍使用重型霹靂車發射「單枚千斤巨石（$\mathbb{I}_{\text{heavyBoulder}} = 1$）」，巨石將直接砸穿木棚並造成破棚碎片傷害。

### 3.2 濕氈含水耐久衰減（Wet Felt Moisture Decay）
$$M_{\text{moisture}}(t) = \max\left(0,\ 100 - 15 \times N_{\text{fireArrowHits}}\right)$$
- 每次承受敵軍火矢齊射扣除 `15` 點濕度；當 $M_{\text{moisture}} > 0$ 時完全免疫點燃，歸零後需消耗 1 桶清水重新澆濕。

# 3KLife 城防城牆羊馬牆外圍矮垣阻滯騎兵與壕溝雙重射界夾擊狀態機規格書

## 1. 系統定位與設計意圖

在三國堅城外圍縱深防禦工事（如襄陽、合肥新城與長安城防之羊馬牆體系）中，於主城牆根向外十步、護城河內岸之間築起高八尺、厚五尺之磚石矮牆「羊馬牆（Sheep-Horse Outer Barrier Wall）」，是構成城防「高低雙重射界」與遲滯攻城器械的核心屏障。本系統規範羊馬牆之河岸狙擊、阻斷騎兵衝鋒、甕道夾擊與退守主城暗門狀態機：
- **外貼護城河內隔十步甕道之八尺矮牆**：羊馬牆位於主城牆與護城河之間，牆頂設女牆垛口與射孔；戰時駐紮第一線輕裝弓弩手與長矛手。
- **高低雙層立體火網無死角壓制**：羊馬牆守軍水平直射渡河敵兵，後方主城牆守軍則越過矮牆實施高空拋射，形成上下雙層立體箭雨。
- **甕道絕地夾擊與暗門撤離**：敵軍翻越羊馬牆跳入十步寬夾道（甕道）時，前衛守軍立即經由主城牆根暗門撤入主城並落閘鎖死，使夾道敵軍腹背受敵。

---

## 2. 狀態機架構與轉換生命週期

城防羊馬牆雙重射界狀態機（代碼：`SHEEP-HORSE-OUTER-WALL-BARRIER01`）流程如下：

```
[ OUTER_WALL_GARRISON_READY ] (羊馬牆垛口駐紮前衛弩手與主城牆構成雙層防線)
           │
           ├── 敵軍渡過護城河逼近內岸
           ▼
[ DUAL_ELEVATION_CROSSFIRE ] (羊馬牆平射與主城牆高空俯射同步覆蓋河岸)
           │
           ├── 敵軍先登架短梯強行翻越八尺羊馬牆 ──> [ LOW_WALL_SCALING_BREACH ]
           ▼
[ SALLY_PORT_TACTICAL_RETREAT ] (前衛守軍經主城牆根暗門迅速退入主城落閘)
           │
           ├── 敵軍湧入主牆與羊馬牆間之十步狹窄夾道
           ▼
[ CORRIDOR_KILLZONE_TRAPPED ] (敵攻城槌被矮牆擋在河岸步兵困於夾道無掩體)
           │
           ▼
[ HIGH_WALL_PLUNGE_ANNIHILATE ] (主城牆居高臨下傾瀉滾木火油全殲夾道敵軍)
```

### 狀態細部定義

1. **OUTER_WALL_GARRISON_READY（前衛駐防）**：羊馬牆內部走廊部署 20 名強弩手與刀盾兵，受八尺磚牆保護免受敵軍平射傷害。
2. **DUAL_ELEVATION_CROSSFIRE（高低合擊）**：羊馬牆距河岸僅兩步，貼臉平射穿甲率極高；主城牆高三丈，俯射壓制敵後隊，火力密度翻倍。
3. **LOW_WALL_SCALING_BREACH（矮牆遭越）**：敵軍付出慘重傷亡後爬上八尺羊馬牆，前衛守軍完成遲滯任務。
4. **SALLY_PORT_TACTICAL_RETREAT（暗門疾退）**：前衛守軍開啟主城牆底部秘密暗門，於 5 秒內全數安全撤入主城內，隨即放下生鐵小閘門。
5. **CORRIDOR_KILLZONE_TRAPPED（夾道受困）**：跳下羊馬牆之敵軍發現自己身處寬僅十步、兩側皆牆之死胡同，且大型衝車與雲梯被八尺羊馬牆死死卡在外面無法運入。
6. **HIGH_WALL_PLUNGE_ANNIHILATE（居高聚殲）**：主城牆守軍對準毫無遮蔽之十步夾道傾倒金汁、滾石與火箭，夾道內敵軍無處可逃。

## 3. 數值模型與物理演算

### 高低雙層射界命中與傷害疊加公式

$$D_{dual} = D_{low\_flat} \times 1.25_{\text{point\_blank}} + D_{high\_plunge} \times \left(1.0 + 0.03 \times H_{main\_wall}\right)$$

- 羊馬牆近距平射享有 $1.25$ 倍貼臉破甲加成，主城牆享有高度加成；敵軍渡河部隊無法同時用盾牌遮擋「水平正面」與「頭頂上方」兩個角度，格擋率強制減半。

### 夾道受困密集度懲罰與器械阻絕公式

$$\text{SiegePassable} = \begin{cases} \text{true}, & \text{if } \text{HP}_{sheep\_wall} \le 0 \\ \text{false}, & \text{otherwise} \end{cases}$$

- 只要羊馬牆尚未被轟塌（`HP > 0`），敵軍任何帶輪重型攻城器械（衝車、井闌、呂公車）均100% 無法進入內層接觸主城牆。

## 4. 戰場戰術連鎖與部隊生剋

1. **攻城重器械天然屏障**：八尺高之磚石羊馬牆雖不算高聳，但足以徹底卡死敵軍所有輪式衝車與大型雲梯車，逼迫敵軍先浪費大量時間拆毀矮牆。
2. **雙角度破除舉盾**：正面平射加頭頂落箭，使敵軍龜甲陣顧此失彼。
3. **前衛守軍零傷亡回收**：透過主城牆根暗門機制，前衛部隊可在矮牆失守瞬間全身而退，不給敵軍斬獲戰功的機會。

## 6. 驗證標準與測試用例 (TC)

- **TC-SHEEP-WALL-01（雙角度破盾判定）**：同時受羊馬牆平射與主城牆俯射之敵兵，其盾牌格擋率必須扣減 50%。
- **TC-SHEEP-WALL-02（重器械阻絕）**：當 `wallDurabilityHp > 0` 時，敵方衝車尋路目標無法穿過羊馬牆抵達主城門。
- **TC-SHEEP-WALL-03（暗門無損撤退）**：觸發 `SALLY_PORT_TACTICAL_RETREAT` 後，前衛部隊於 5 秒內移入主城並將 `isSallyPortLocked` 設為 `true`。

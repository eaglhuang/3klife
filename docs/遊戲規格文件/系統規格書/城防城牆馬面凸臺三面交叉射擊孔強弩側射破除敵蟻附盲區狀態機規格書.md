# 3KLife 城防城牆馬面凸臺三面交叉射擊孔強弩側射破除敵蟻附盲區狀態機規格書

## 1. 系統定位與設計意圖

在三國堅城築城工事與防禦戰術（如曹魏鄴城與合肥新城之馬面設計）中，平直城牆弱點在於敵軍衝至牆根死角（蟻附盲區）時，主城牆守軍須探身垂直射擊，易被敵弓手仰射反殺。本系統規範城牆每隔百步外凸之矩形墩臺「城牆馬面凸臺三面交叉射擊孔強弩側射清盲區系統（Bastion Flanking Crossbow Crossfire）」狀態機：
- **城牆外凸三丈矩形馬面墩臺**：每隔百步自城牆向外突出三丈、寬兩丈之實心包磚馬面臺，內設上下兩層暗堡射擊孔。
- **左右兩翼水平側射消除牆根死角**：當敵軍貼近兩座馬面間之主城牆根部架梯攀爬時，左右馬面側面射孔同時向內水平齊射，箭矢平行橫掃整個牆根。
- **無視正面舉盾之側後背刺貫穿**：攀爬雲梯或面向主城牆頂盾之敵兵，雙肋完全暴露於 90 度側射火網下，盾牌格擋率強制歸零，承受雙倍側襲暴擊。

## 2. 狀態機架構與轉換生命週期

城牆馬面交叉側射狀態機（代碼：`BASTION-FLANKING-CROSSBOW-CROSSFIRE01`）流程如下：

```
[ BASTION_EMBRASURE_STANDBY ] (左右馬面暗堡強弩手透過內小外大射孔待命)
           │
           ├── 敵軍突破正面箭雨貼近主城牆根死角
           ▼
[ WALL_BASE_DEADZONE_ENTERED ] (敵步兵進入兩座馬面間之牆根盲區架梯)
           │
           ├── 左右馬面側射孔掀開鐵擋板 ──> [ FLANKING_SHUTTER_OPEN ]
           ▼
[ INTERLOCKING_CROSSFIRE_VOLLEY ] (雙側重型踏張弩呈九十度角對向平射橫掃)
           │
           ├── 箭矢自敵兵側面無盾肋部貫穿
           ▼
[ UNSHIELDED_RIB_PENETRATION ] (無視正面大盾格擋造成連環穿刺暴擊)
           │
           ▼
[ DEADZONE_CORPSE_PURGE ] (牆根與雲梯中段敵兵被交叉火網徹底清空)
           │
           ▼
[ SHUTTER_CLOSE_RELOAD ] (放下生鐵護板隔絕敵反擊於暗堡內安全上弦)
```

### 狀態細部定義

1. **BASTION_EMBRASURE_STANDBY（暗堡待命）**：每座馬面配置 12 名踏張強弩手，藏身於四尺厚磚石射孔後方，免疫外部箭雨。
2. **WALL_BASE_DEADZONE_ENTERED（盲區觸發）**：敵軍衝入距離主城牆 0 至 5 公尺之垂直死角，主城牆上方守軍俯角受限。
3. **FLANKING_SHUTTER_OPEN（開孔鎖定）**：左右相鄰兩座馬面之側面射孔鐵板同步拉起，形成覆蓋牆根走廊之雙向水平射界。
4. **INTERLOCKING_CROSSFIRE_VOLLEY（交叉齊射）**：兩翼強弩手以近距離平射彈道發射破甲重箭，初速極高無需拋物線修正。
5. **UNSHIELDED_RIB_PENETRATION（側肋貫穿）**：敵兵正面朝向主城牆或攀附於雲梯上，雙側毫無遮擋，重箭直接自側肋貫穿。
6. **DEADZONE_CORPSE_PURGE（盲區清場）**：持續 6 秒之交叉齊射將牆根死角化為絞肉走廊，敵軍先登梯隊傷亡率超過 80%。
7. **SHUTTER_CLOSE_RELOAD（閉板裝填）**：齊射完畢後放下鐵擋板，弩手於掩體內安全踏張上弦，冷卻 12 秒。

## 3. 數值模型與物理演算

### 側射無視盾牌與暴擊傷害公式

$$\text{EffectiveBlock} = \text{ShieldBlock}_{base} \times \max\left(0, \; \cos(\theta_{attack\_angle})\right)$$

$$D_{crossfire} = D_{bolt} \times \left(1.0 + 0.5 \times \text{IsDualBastionActive}\right) \times 1.8_{\text{flank\_crit}}$$

- $\theta_{attack\_angle}$：馬面側射線與敵兵正面朝向夾角（貼牆時為 $90^\circ$，$\cos 90^\circ = 0$，正面盾牌格擋率強制為 0）。
- 若左右馬面同時完好並構成雙向夾擊（`IsDualBastionActive = true`），側射總傷害提升 50% 並必出 1.8 倍側襲暴擊。

### 射孔掩體防護減傷公式

$$P_{hit\_defender} = P_{base\_accuracy} \times 0.08 \times (1.0 - 0.9 \times \text{IsShutterClosed})$$

- 因射擊孔採「內寬外窄」設計，城下敵弓手仰射命中馬面內部弩手之機率壓低至 8% 以下。

## 4. 戰場戰術連鎖與部隊生剋

1. **正面大盾兵與先登梯隊夢魘**：瓦解敵軍「頂大盾貼牆根避箭」的攻城戰術，越靠近城牆根部死傷越慘重。
2. **雙馬面互保機制**：若敵軍轉而攀爬左側馬面，右側馬面與主城牆可立即對左側馬面外壁實施側射支援。
3. **發石車集火坍塌威脅**：攻城方需先以重型投石機集中轟塌其中一座馬面，方能切斷交叉火網。

## 6. 驗證標準與測試用例 (TC)

- **TC-BASTION-01（九十度側射破盾）**：持盾率 90% 敵兵進入牆根盲區遭受馬面側射時，實際格擋率強制結算為 0%。
- **TC-BASTION-02（雙馬面交叉加成）**：左右馬面同時存活射擊時，盲區內敵軍承受傷害為單座馬面之 $1.5$ 倍以上。
- **TC-BASTION-03（暗堡射孔高閃避）**：城下敵弓手對馬面內弩手射擊時，92% 以上箭矢被外窄射孔石壁擋下。

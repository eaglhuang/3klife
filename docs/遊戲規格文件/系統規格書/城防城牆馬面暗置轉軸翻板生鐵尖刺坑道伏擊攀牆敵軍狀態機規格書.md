# 城防城牆馬面暗置轉軸翻板生鐵尖刺坑道伏擊攀牆敵軍狀態機規格書

> **來源**：《墨子·備蛾傳》與古代要塞馬面城頭陷阱「轉軸踏板刺坑」（於城牆馬面或女牆內側走馬道預留暗坑，上方鋪設中間穿鐵軸之活動木踏板，坑底密植三尺倒刺生鐵尖樁；當敵軍雲梯先登死士好不容易翻越女牆跳上城頭時，踩中踏板瞬間翻轉墜入鐵刺坑道）、WBS `FORM-155` 城頭反先登陷阱模組。
> **關聯文件**：`doc_spec_0900`（甕城絞盤重力翻板）、`doc_spec_0918`（城牆馬面三面交叉射擊）、`doc_spec_0878`（戰場深溝枯枝覆土刺坑）。

---

## 一、 設計目標與戰術定位

當敵軍攻城雲梯或臨衝高樓（`doc_spec_0843`）強行搭上城垛，往往會派遣高武力之「先登死士」跳入女牆內側搶佔立足點。「城牆馬面暗置轉軸翻板刺坑」專為獵殺這批翻越垛口的敵軍精銳而設。守軍主動後撤半步讓出垛口內側踏板，敵先登躍入城頭落地瞬間，腳下轉軸木板因失去插銷支撐而 90 度翻轉，將其直接吞入城牆夾層之生鐵尖刺坑中，隨即由配重塊自動回彈閉合，繼續坑殺下一波登城者。

1. **誘敵登堞與插銷解鎖**：守軍平時插死鐵銷可安全站立；見敵將登城時抽銷後退，化城頭立足點為死亡陷阱。
2. **轉軸自動復位（Counterweight Auto-Reset）**：踏板兩端設有生鐵配重塊，敵兵墜坑後踏板於 `0.2` 秒內自動回平，外觀毫無破綻，可連續觸發。
3. **夾層刺坑隔絕救援**：墜入城牆內部夾層刺坑之敵兵承受高額穿刺重傷，且與城外雲梯後續部隊徹底隔絕。

## 二、 狀態機生命週期（5 階段）

```
[1. 插銷固板 Pin_Locked_Walkway]
       │ (敵雲梯/臨衝搭城，守軍拔銷退守內側)
       ▼
[2. 虛位誘登 Armed_Pivot_Trapdoor]
       │ (敵先登部隊翻越垛口，踏上城頭第 1 格)
       ▼
[3. 轉軸吞噬 Pivot_Drop_Impale]
       │ (踏板 90 度翻轉：敵兵墜入夾層鐵刺，承受 230% 穿刺傷)
       ▼
[4. 配重回彈 Counterweight_Snap_Shut]
       │ (配重塊拉回踏板重新閉合，隔絕坑內敵軍並可再次觸發)
       ▼
[5. 坑道清剿 Chute_Spear_Finish]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `PIN_LOCKED_WALKWAY` | 插銷固板 | 平時鐵銷鎖死轉軸，我方守軍可於馬面城頭自由走動與射擊，無誤觸風險。 |
| `ARMED_PIVOT_TRAPDOOR` | 虛位誘登 | 當敵軍雲梯搭上該城段時，守軍拔除鐵銷並退至內側第 2 格，使緊鄰女牆之第 1 格處於待觸發陷阱狀態。 |
| `PIVOT_DROP_IMPALE` | 轉軸吞噬 | 敵方登城部隊翻越垛口落腳瞬間，踏板向下翻開，敵軍墜入城體夾層刺坑，承受 `230%` 無視護甲穿刺傷害並強制中斷其登城衝鋒。 |
| `COUNTERWEIGHT_SNAP_SHUT` | 配重回彈 | 轉軸配重塊立即將木板拉回水平閉合狀態（每具陷阱最多可連續吞噬 `3` 波登城小隊），坑內敵軍陷入「密室禁錮（無法移動與求援）」。 |
| `CHUTE_SPEAR_FINISH` | 坑道清剿 | 城體夾層兩側設有刺孔，守軍以長矛向坑內殘敵補刀，每回合追加 `120%` 必中刺殺傷害。 |

## 三、 核心數值與判定公式

### 3.1 登城墜坑穿刺傷害公式（Trapdoor Impale Damage）
$$D_{\text{impale}} = D_{\text{base}} \times 2.30 \times \left(1 + 0.15 \times W_{\text{armor}}\right)$$
- $W_{\text{armor}}$：登城敵兵之護甲重量（重甲先登死士墜落時重力勢能更大，生鐵尖刺穿透甲縫造成的傷害額外提升 `15% ~ 30%`）。

### 3.2 連續觸發次數與卡死檢定（Trap Durability & Jam Check）
$$N_{\text{maxTriggers}} = 3,\quad P_{\text{jam}} = \max(0,\ 0.10 \times (N_{\text{used}} - 1))$$
- 每具轉軸翻板最多可觸發 `3` 次；第 3 次觸發後坑底填滿，需守軍清理後方可重置。

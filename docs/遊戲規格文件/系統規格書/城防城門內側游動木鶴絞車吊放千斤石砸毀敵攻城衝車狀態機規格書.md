# 3KLife 城防城門內側游動木鶴絞車吊放千斤石砸毀敵攻城衝車狀態機規格書

## 1. 系統定位與設計意圖

在三國堅城防禦攻堅戰（如陳倉之戰郝昭以重石擊碎諸葛亮衝車、合肥守城戰破壞吳軍攻城重器）中，敵軍攻城衝車往往覆蓋厚重濕牛皮與雙層圓木屋頂，城頭拋擲之普通二十斤擂石與火箭均被其斜頂彈開。本系統規範專門部署於城門樓正上方或城牆內側的「旋轉長臂游動木鶴絞車垂直吊放千斤磨盤巨石砸車系統（Crane Boulder Drop Anti-Ram）」狀態機：
- **三丈旋轉木鶴懸臂與滑輪絞車**：於城門樓頂部架設以粗壯柏木製成之可旋轉長臂吊車（木鶴），前端滑輪穿過雙股生鐵鏈，爪鉤牢牢抓扣一塊重達八百至一千二百斤之花崗岩大磨盤或方巨石。
- **伸出城牆正上方對準衝車頂脊**：當敵軍雙層牛皮衝車推抵城門洞下方、正欲擺動撞木轟門時，守軍轉動木鶴長臂將千斤巨石懸停於衝車屋脊正上方。
- **脫鉤自由落體一擊粉碎衝車**：守軍拉動快拆脫鉤索，千斤巨石自三丈高空垂直加速砸落，高達十萬焦耳之重力位能瞬間壓垮衝車牛皮斜頂並砸斷其核心懸掛撞木。

## 2. 狀態機架構與轉換生命週期

木鶴吊石砸車狀態機（代碼：`CRANE-BOULDER-DROP-ANTI-RAM01`）流程如下：

```
[ CRANE_CLAW_GRIP_BOULDER ] (城內地面鐵爪扣緊千斤花崗岩巨石絞升)
           │
           ├── 絞車將巨石提舉至城垛高度上方
           ▼
[ BOOM_SWING_OVER_GATE ] (轉動木鶴長臂將巨石旋出城牆外沿正上方)
           │
           ├── 敵軍攻城衝車抵近城門下方撞擊區
           ▼
[ PLUMB_LINE_TARGET_LOCK ] (鉛垂線校準敵衝車屋脊核心承重樑)
           │
           ├── 守將拉動脫鉤銷 ──> [ QUICK_RELEASE_FREEFALL ]
           ▼
[ ROOF_CRUSH_RAM_SHATTER ] (千斤石垂直轟落砸穿牛皮屋頂折斷撞木)
           │
           ▼
[ CREW_PINNED_DISABLED ] (衝車內部推車兵遭巨石壓死器械徹底癱瘓)
           │
           ▼
[ WINCH_RETRACT_RELOAD ] (旋回木鶴長臂降下鐵爪吊起下一塊備用巨石)
```

### 狀態細部定義

1. **CRANE_CLAW_GRIP_BOULDER（抓石絞升）**：六名守兵踩動大踏輪絞車，四爪生鐵鉤咬緊千斤巨石提升至城頭高度。
2. **BOOM_SWING_OVER_GATE（旋臂出牆）**：推動木鶴尾部配重橫桿，將長臂向外旋轉 90 度，使巨石懸空於城門洞外上方。
3. **PLUMB_LINE_TARGET_LOCK（鉛垂鎖定）**：觀測手透過重錘鉛垂線對準下方正在撞門之敵軍衝車中心軸線，耗時 1.5 秒完成瞄準。
4. **QUICK_RELEASE_FREEFALL（脫鉤下墜）**：拔除鐵爪閉鎖銷，四爪張開，千斤巨石以自由落體垂直墜下，完全不受風偏影響。
5. **ROOF_CRUSH_RAM_SHATTER（粉碎車頂）**：巨石命中衝車頂棚，抗箭防滾石之牛皮木頂在絕對質量面前瞬間坍塌，核心懸吊撞木當場折斷。
6. **CREW_PINNED_DISABLED（癱瘓塞道）**：衝車解體化為沉重廢墟並死死卡在城門前，阻擋敵軍第二輛衝車上前。
7. **WINCH_RETRACT_RELOAD（收回重裝）**：木鶴旋回城內重新吊裝巨石，每次裝填冷卻時間為 40 秒。

## 3. 數值模型與物理演算

### 千斤石重力位能與破甲粉碎公式

$$E_{impact} = M_{boulder} \times g \times H_{wall}$$

$$D_{siege} = E_{impact} \times 0.08 \times (1.0 - 0.15 \times \text{IsIronRoofed})$$

- $M_{boulder}$：巨石質量（500kg）；$H_{wall}$：城牆高度（10 公尺）。
- 落地動能高達 $49,000\,\text{J}$，換算攻城器械結構傷害達 3,920 點，普通衝車（耐久 2,500）承受一擊即 100% 徹底粉碎。

### 旋轉對準角速度與瞄準時間公式

$$T_{aim} = \frac{\Delta \theta_{boom}}{\omega_{swing}} + 1.0 \quad (\text{秒})$$

- 木鶴旋轉角速度 $\omega_{swing} = 15^\circ/\text{s}$，旋轉 90 度加鉛垂校準僅需 7 秒即可完成致命打擊。

## 4. 戰場戰術連鎖與部隊生剋

1. **重型衝車與轒轀車終結者**：專門克制任何免疫箭矢與普通擂石之近戰重型攻城車輛，一擊必殺。
2. **製造門前障礙物**：被砸毀之衝車殘骸與千斤巨石留在城門正前方，敵軍必須耗費 60 秒清理殘骸才能派下一輛衝車接近。
3. **懼怕遠程發石車對狙**：木鶴高聳於城門樓頂，目標明顯，易成為敵軍後方重型投石機優先集火摧毀的目標。

## 6. 驗證標準與測試用例 (TC)

- **TC-CRANE-DROP-01（千斤石一擊毀車）**：500kg 巨石自 10 公尺城頭砸中耐久 2500 之衝車，衝車耐久直接歸零並標記為 `DESTROYED`。
- **TC-CRANE-DROP-02（殘骸阻擋判定）**：衝車被砸毀後，城門前座標格自動生成 `WRECKAGE_BLOCK` 阻礙後續車輛。
- **TC-CRANE-DROP-03（彈藥耗盡停機）**：當 `stockpileBouldersCount` 扣減至 0 時，木鶴無法再次進入 `CRANE_CLAW_GRIP_BOULDER`。

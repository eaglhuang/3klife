# 城防城門內側絞盤牽引生鐵尖刺閘門雙重落鎖夾碎敵軍衝車撞頭狀態機規格書

> **來源**：《墨子·備城門》與《武經總要》城門防衝車機關「雙重懸門千斤閘／夾車鐵閘」（於城門洞內設外、內兩道包鐵鑲刺懸門；待敵衝車將撞頭與前半車身探入門洞時，同時斬斷雙閘吊索，外閘砸斷衝車懸索與車頸，內閘封死門洞）、WBS `FORM-161` 城門防衝車夾殺模組。
> **關聯文件**：`doc_spec_0845`（狼牙拍與甕城千斤閘）、`doc_spec_0869`（雙層牛皮木屋衝車）、`doc_spec_0915`（游動木鶴吊放千斤石砸衝車）。

## 一、 設計目標與戰術定位

面對覆有雙層牛皮與厚木屋脊的「重型攻城衝車（`doc_spec_0869`）」，一般弓弩與礌石難以損其分毫。「雙重落鎖生鐵尖刺閘門」利用衝車「撞頭必須深入門洞方能撞擊內門」的特性設下前後雙閘陷阱：待衝車撞頭伸入第一道閘槽瞬間，雙閘齊落——前閘底部三尺生鐵尖齒直接砸穿衝車腰部並卡死車輪，後閘徹底堵住進城通路，把敵軍衝車變成塞死城門洞的廢木障。

1. **誘入門洞與雙閘齊落（Twin-Gate Guillotine Trap）**：前閘專司「腰斬咬死衝車」，後閘專司「封門斷絕突入」。
2. **斷索廢錘（Ram Cable Severing）**：前閘底部呈巨型生鐵鋸齒狀，四千斤重力垂直砸下時，直接砸斷衝車內部懸掛鐵撞頭之粗麻繩，使衝車永久喪失撞門能力。
3. **化敵衝車為塞門路障（Wreckage Gate Blockade）**：被夾碎卡死在門洞內的衝車殘骸，反而成為阻擋敵軍後續步騎湧入城門的天然路障。

## 二、 狀態機生命週期（5 階段）

```
[1. 雙閘高懸 Twin_Portcullis_Poised]
       │ (敵軍衝車貼近城門並探入撞頭開始撞擊)
       ▼
[2. 斷索鍘落 Guillotine_Drop_Clamp]
       │ (前後雙閘同時斬索墜落：前閘砸中衝車前半部)
       ▼
[3. 碎梁廢錘 Sever_Ram_Cable_And_Axle]
       │ (對衝車造成 360% 結構粉碎傷，撞頭掉地永久廢除)
       ▼
[4. 殘骸堵門 Wreckage_Choke_Blockade]
       │ (衝車卡死於門洞：敵後續部隊無法通過，門洞防禦 +60%)
       ▼
[5. 頂孔澆油 Top_Murder_Hole_Purge]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `TWIN_PORTCULLIS_POISED` | 雙閘高懸 | 城門洞拱頂暗槽內高懸前、後兩道四千斤生鐵尖刺閘門，絞盤插銷待命。 |
| `GUILLOTINE_DROP_CLAMP` | 斷索鍘落 | 當敵軍攻城衝車對城門發動第 1 次撞擊（車頭探入門洞）時，守軍揮斧斬斷控索，雙閘以千鈞之勢垂直砸落。 |
| `SEVER_RAM_CABLE_AND_AXLE` | 碎梁廢錘 | 前閘生鐵尖齒直接砸穿衝車牛皮屋頂與大梁，造成 `360%` 器械粉碎傷害，並 **100% 砸斷撞錘懸索**（衝車永久失去攻城撞擊力，且被死死釘在原地無法後退）。 |
| `WRECKAGE_CHOKE_BLOCKADE` | 殘骸堵門 | 後閘完全落地封死內門，被前閘釘死的衝車殘骸堵滿門洞，使敵軍後續步騎無法進入該城門格，且城門額外獲得 `+60%` 物理防禦。 |
| `TOP_MURDER_HOLE_PURGE` | 頂孔澆油 | 守軍自雙閘之間的拱頂射孔向下傾倒沸油或攢射強弩，每回合對困在衝車內的敵軍工兵造成 `180%` 必中清剿傷害。 |

## 三、 核心數值與判定公式

### 3.1 生鐵閘門垂直鍘擊傷害公式（Guillotine Crush Damage）
$$D_{\text{crush}} = \text{ATK}_{\text{fort}} \times 3.60 \times \left(1 + 0.50 \times \mathbb{I}_{\text{isSiegeRam}}\right)$$
- 當目標為攻城衝車或塞門車（$\mathbb{I}_{\text{isSiegeRam}} = 1$）時，額外獲得 `+50%` 破械加成（總計 `5.40x` 毀滅性打擊）。

### 3.2 雙閘封鎖耐久與破障工時（Twin-Gate Barrier HP）
$$\text{HP}_{\text{twinGate}} = \text{HP}_{\text{baseGate}} \times 1.60 + \text{HP}_{\text{ramWreckage}} \times 0.80$$
- 敵軍若想繼續從該城門攻入，必須先花費工時拆毀「自己被卡死的衝車殘骸」與兩道生鐵閘門。

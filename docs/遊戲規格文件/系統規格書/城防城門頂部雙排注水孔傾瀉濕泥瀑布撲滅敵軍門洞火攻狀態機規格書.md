# 城防城門頂部雙排注水孔傾瀉濕泥瀑布撲滅敵軍門洞火攻狀態機規格書

> **來源**：《墨子·備穴／備蛾傳》與《武經總要》城門防火構造「門頂五星池／雙排注水孔」（於城門樓底板、木質城門正上方鑿設雙排貫通石槽孔洞，連接城頭大水池與泥漿池；當敵軍推火車或堆積乾柴焚燒城門時，拔開木塞傾瀉大量清水與稠泥漿，瞬間撲滅烈火並為城門披覆防燃濕泥層）、WBS `FORM-146` 城防反火攻模組。
> **關聯文件**：`doc_spec_0869`（牛皮木屋衝車）、`doc_spec_0909`（塞門刀車）、`doc_spec_0911`（風帆火輪車）。

## 一、 設計目標與戰術定位

木質包鐵城門是城防體系中最懼怕「堆積乾柴膏油縱火」或「火輪車嵌合焚燒」的弱點。若守軍僅從女牆外探身潑水，不僅水量有限，更極易遭敵軍強弩射殺。「城門頂部雙排注水孔（五星池）」則在城門洞拱頂內部鑿出垂直貼門的雙排石孔，守軍在城門樓室內安全拔栓，即可將數百石清水與黃土稠泥沿門板垂直淋下。

1. **室內安全注水（零暴露抗狙擊）**：操作守軍位於城門樓內部，完全不受城下敵軍弓弩散彈壓制。
2. **瞬時滅火與清洗火油**：第一波高壓水柱直接沖散門前燃燒之柴草，熄滅門洞地格之火焰。
3. **濕泥掛壁防復燃護盾（Wet Mud Fireproof Coating）**：第二波傾瀉高黏度黃泥漿，附著於城門表面形成「濕泥防火層（火焰傷害減免 `85%`，持續 3 回合）」。

## 二、 狀態機生命週期（5 階段）

```
[1. 滿池蓄泥 Reservoir_Ready]
       │ (偵測到城門正前方 1 格處於燃燒狀態或城門起火)
       ▼
[2. 拔栓注水 Sluice_Plug_Release]
       │ (雙排石孔傾瀉瀑布，瞬間撲滅門前 1x3 格火焰)
       ▼
[3. 泥漿覆門 Wet_Mud_Coating_Shield]
       │ (黃泥漿附著門板：城門火抗 +85%，持續 3 回合)
       ▼
[4. 泥淖阻車 Mud_Quagmire_Slowdown]
       │ (門前地格化為深泥淖：敵衝車/步騎移速 -50%)
       ▼
[5. 汲水回填 Water_Refill_Cooldown]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `RESERVOIR_READY` | 滿池蓄泥 | 城門樓內置百石水池與黃泥槽蓄滿待命（儲量 `100%`）。 |
| `SLUICE_PLUG_RELEASE` | 拔栓注水 | 當敵軍以火攻焚燒城門時，守軍拔開雙排共十處石孔木塞，瀑布傾瀉而下，立即清除城門本身及門前 `1x3` 格之所有「燃燒／猛火油」狀態。 |
| `WET_MUD_COATING_SHIELD` | 泥漿覆門 | 緊隨水柱傾倒稠密黃泥漿，於城門表面凝結為半寸厚濕泥層，賦予城門 `3` 回合「濕泥防火壁（火焰與爆炸傷害減免 `85%`，免疫點燃）」。 |
| `MUD_QUAGMIRE_SLOWDOWN` | 泥淖阻車 | 大量泥水匯聚於城門洞前 `2x3` 格區域，形成「深滑泥淖」，使敵軍攻城衝車推進行動力 `-50%`、撞擊動能衰減 `35%`。 |
| `WATER_REFILL_COOLDOWN` | 汲水回填 | 傾瀉完畢後需由民夫自城內水井汲水回填 `2` 回合，方可再次啟動。 |

## 三、 核心數值與判定公式

### 3.1 城門火焰減傷與泥層耐久公式（Fire Damage Mitigation）
$$D_{\text{gateFire}} = D_{\text{rawFire}} \times \left(1 - 0.85 \times \mathbb{I}_{\text{mudCoated}}\right)$$
- 當 $\mathbb{I}_{\text{mudCoated}} = 1$（處於濕泥覆門狀態）時，任何火箭、火球或火車對城門僅能造成 `15%` 微量傷害。

### 3.2 門前泥淖對衝車動能衰減公式（Ram Kinetic Attenuation）
$$E_{\text{ramEffective}} = E_{\text{ramBase}} \times (1 - 0.35 \times \mathbb{I}_{\text{quagmire}})$$
- 門前化為泥淖後，敵軍雙層牛皮衝車車輪打滑下陷，撞門破壞力直接下降 `35%`。

## 四、 資料結構契約（TypeScript Interface）

```typescript
/**
 * 城門頂部雙排注水孔防火狀態枚舉
 */
export enum GateWaterSluiceState {
  RESERVOIR_READY = 'RESERVOIR_READY',
  SLUICE_PLUG_RELEASE = 'SLUICE_PLUG_RELEASE',
  WET_MUD_COATING_SHIELD = 'WET_MUD_COATING_SHIELD',
  MUD_QUAGMIRE_SLOWDOWN = 'MUD_QUAGMIRE_SLOWDOWN',
  WATER_REFILL_COOLDOWN = 'WATER_REFILL_COOLDOWN',
}

/**
 * 城門注水孔泥漿防火配置契約
 */
export interface GateWaterSluiceConfig {
  /** 規格書識別碼 */
  specId: 'GATE-WATER-SLUICE-FIRE-QUENCH01';
  /** 濕泥層火焰傷害減免比例 (0.85) */
  mudFireReductionRatio: number;
  /** 濕泥防火層持續回合數 (3) */
  mudCoatingDurationTurns: number;
  /** 門前泥淖對衝車撞擊衰減比例 (0.35) */
  quagmireRamPenaltyRatio: number;
  /** 水池汲水回填冷卻回合數 (2) */
  refillCooldownTurns: number;
}
```

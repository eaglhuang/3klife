# 3KLife 城防懸索搭扣夜叉擂滾動下墜生鐵尖刺碾壓攻城梯隊狀態機規格書

## 1. 系統定位與設計意圖

在三國雄關險隘防守（如劍閣阻截鍾會、陳倉阻擊蜀軍大隊）中，面對敵軍密布於城牆根部的密集登城梯隊與先登步兵，常規落石難以做到大面積持續清場。本系統規範三國城防致命守城重器「生鐵尖刺懸索搭扣夜叉擂滾動碾壓下砸系統（Yaksha Spiked Roller Defense）」狀態機：
- **圓柱原木外嵌密布生鐵狼牙釘**：以直徑二尺、長約一丈之沉重榆木或櫟木整幹為軸心，外包熟鐵皮並錯落鑲嵌上百枚長半尺之淬火生鐵三棱狼牙利刺，重達八百斤。
- **雙端粗鐵鏈懸吊與絞盤連動**：兩端以粗大生鐵索扣套於城樓絞盤之上，常態懸掛於城堞下方蓄勢待發。
- **沿城牆垂直翻滾碾壓下砸**：解開搭扣時，夜叉擂藉由自身重力沿城牆外壁垂直高速旋轉滾落，鐵刺絞碎攻城梯桄並將沿途攀爬之敵兵碾壓撕碎。

## 2. 狀態機架構與轉換生命週期

夜叉擂滾壓防衛狀態機（代碼：`YAKSHA-SPIKED-ROLLER-DEFENSE01`）流程如下：

```
[ ROLLER_SUSPENDED_PRIMED ] (雙端鐵索懸吊八百斤夜叉擂於城堞下)
           │
           ├── 敵軍數具雲梯搭靠且步兵密布牆面
           ▼
[ LADDER_WALL_CLUSTER_ALERT ] (城牆表面攻城步兵密集度達標)
           │
           ├── 守軍揮斧斬斷懸索安全搭扣 ──> [ TRIP_LATCH_DISENGAGED ]
           ▼
[ VERTICAL_ROLL_DESCENT ] (沿垂直城牆高速自旋翻滾呼嘯下墜)
           │
           ├── 生鐵狼牙尖刺暴力絞碎雲梯木桄
           ▼
[ LADDER_SHRED_IMPALEMENT ] (梯身斷裂攀爬兵遭受穿刺碾碎)
           │
           ├── 滾落至牆根地面重砸聚集敵兵
           ▼
[ BASE_IMPACT_CRUSH_PURGE ] (在城下人群中犁出十步血肉真空帶)
           │
           ▼
[ CHAIN_RETRACT_HOIST ] (城樓四名壯漢搖動絞盤緩慢拉回重置)
```

### 狀態細部定義

1. **ROLLER_SUSPENDED_PRIMED（懸索待命）**：夜叉擂懸掛於城垛突出部，雙側生鐵索受力平衡，隨時可解扣釋放。
2. **LADDER_WALL_CLUSTER_ALERT（目標鎖定）**：敵軍在 10 步牆面上連續搭設 3 架以上雲梯，步兵攀爬密度超過閾值。
3. **TRIP_LATCH_DISENGAGED（解鎖釋放）**：搭扣卡榫瞬間彈開，生鐵巨軸在重力加速度下沿磚石外牆飛速滾動。
4. **VERTICAL_ROLL_DESCENT（旋轉下墜）**：巨木以 8m/s 末端速度旋轉下墜，鐵刺劃過城磚火星四濺，動能達 25,000 焦耳。
5. **LADDER_SHRED_IMPALEMENT（絞碎雲梯）**：生鐵釘如巨大滾筒齒輪，瞬間將木質雲梯切碎成木屑，攀爬者全員重傷墜亡。
6. **BASE_IMPACT_CRUSH_PURGE（落地碾碎）**：落至地面形成強烈震波，十步直徑範圍內敵軍承受高額碾壓粉碎傷害。
7. **CHAIN_RETRACT_HOIST（絞盤復位）**：粗鐵索受絞盤牽引，以每秒 0.5 公尺速度將夜叉擂緩慢拉回城頂，冷卻 60 秒。

## 3. 數值模型與物理演算

### 夜叉擂滾動動能與破壞力公式

$$E_{roll} = \frac{1}{2} M_{roller} \times V_{descent}^2 + \frac{1}{2} I \times \omega^2$$

- $M_{roller}$：夜叉擂總重量（約 400kg）。
- $V_{descent} = \sqrt{2 \times g \times H_{wall}}$：城牆高 8 公尺時落地速度約 $12.5\,\text{m/s}$。總動能超越 30,000 焦耳，任何步兵護甲減免直接歸零。

### 雲梯結構粉碎機率判定公式

$$P_{destroy\_ladder} = \min\left(1.0, \; 0.85 + 0.05 \times \text{SpikeHardness} - 0.10 \times \text{IsIronReinforced}\right)$$

- 普通木雲梯遭受夜叉擂碾過時，結構破壞率達 95%；即使帶有鐵皮加固，破壞率依然不低於 75%。

## 4. 戰場戰術連鎖與部隊生剋

1. **先登精銳絕命剋星**：對抗高階先登死士或魏國突擊步兵時，無視護甲直接秒殺梯上士兵，重挫敵攻城士氣。
2. **懸索受火箭燒斷風險**：若敵方神射手以火箭精確集火吊索麻繩，可能使夜叉擂過早脫落偏離攻擊軌道。
3. **絞盤回拉期防禦空洞**：回拉夜叉擂之 60 秒冷卻期內，該段城垛缺乏重型守城兵器，易被敵軍趁隙突擊。

## 6. 驗證標準與測試用例 (TC)

- **TC-YAKSHA-01（解扣下墜加速度）**：解鎖後夜叉擂下墜末速度必須達 $12\,\text{m/s}$，符合重力加速度物理規律。
- **TC-YAKSHA-02（雲梯摧毀判定）**：下墜覆蓋路徑上之所有雲梯耐久度歸零，攀爬人員死亡判定率 100%。
- **TC-YAKSHA-03（絞盤回拉狀態機轉換）**：觸底後自動轉入 `CHAIN_RETRACT_HOIST`，耗時 60 秒回位並轉回待命狀態。

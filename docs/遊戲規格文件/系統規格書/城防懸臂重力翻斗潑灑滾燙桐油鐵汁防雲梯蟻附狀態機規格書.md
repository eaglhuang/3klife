# 3KLife 城防懸臂重力翻斗潑灑滾燙桐油鐵汁防雲梯蟻附狀態機規格書

## 1. 系統定位與設計意圖

在三國殘酷的攻城防禦作戰（如郝昭防守陳倉挫諸葛亮雲梯衝車、合肥新城滿寵禦吳）中，敵方步兵依靠大型摺疊雲梯密集附蟻登城是守方最大的威脅。傳統石塊難以精確打擊梯身盲區。本系統規範城垛專屬特種防禦重器「懸臂式槓桿重力翻斗潑灑滾燙桐油鐵汁系統（Cantilever Molten Oil Dump Ladder Defense）」狀態機：
- **城垛懸臂外伸結構與配重**：城頭突出部安裝堅固生鐵懸臂樑，臂端懸吊三口大型生鐵翻斗，內盛煮沸至二百五十度之高溫桐油或生鐵汁液。
- **拉索解鎖重力瞬間傾瀉**：守軍在雲梯搭上城堞、敵先登兵蜂擁攀爬至半空時抽拔保險拉索，翻斗受重力傾倒九十度，熱油鐵汁呈扇形垂直傾瀉。
- **高溫灼傷破甲與梯身引燃**：滾燙油汁灌入敵兵甲冑縫隙，高溫瞬間熔毀皮革並灼穿皮膚，同時引燃雲梯木質梯桄，造成敵先登部隊全員墜梯。

## 2. 狀態機架構與轉換生命週期

城防翻斗潑油狀態機（代碼：`CANTILEVER-MOLTEN-OIL-DUMP-LADDER01`）流程如下：

```
[ CANTILEVER_STOWED_BOILING ] (城頭灶臺持續加熱翻斗桐油至沸點)
           │
           ├── 敵軍雲梯搭上城堞且敵兵蟻附半空
           ▼
[ LADDER_CLIMBER_DENSITY_LOCK ] (雲梯上攀爬士兵密度達到五人以上)
           │
           ├── 守軍抽拔配重鎖定拉索 ──> [ LEVER_RELEASE_TIPPING ]
           ▼
[ GRAVITY_DUMP_CASCADE ] (翻斗傾側高溫熱油如瀑布垂直當頭淋下)
           │
           ├── 熱油滲透皮甲鐵甲縫隙引發重度灼傷
           ▼
[ SEVERE_SCALD_MASS_FALL ] (敵先登慘叫失手全員墜落城下骨折)
           │
           ├── 殘油引燃雲梯木梁與繩索
           ▼
[ LADDER_IGNITION_COLLAPSE ] (雲梯結構燒焦斷裂徹底喪失登城功能)
           │
           ▼
[ COUNTERWEIGHT_REARM_RESET ] (工兵絞盤拉回翻斗注入新油重新裝填)
```

### 狀態細部定義

1. **CANTILEVER_STOWED_BOILING（沸油保溫）**：懸臂翻斗置於城垛內側，灶火維持油溫於 220 至 260 度，隨時待命。
2. **LADDER_CLIMBER_DENSITY_LOCK（密度鎖定）**：雲梯勾扣城垛，觀測鏡鎖定梯身上有 5 名以上先登兵處於 3 至 7 公尺高度。
3. **LEVER_RELEASE_TIPPING（抽銷傾倒）**：守軍扳動快拆扳柄，生鐵翻斗順旋轉軸自由傾翻，耗時 0.4 秒。
4. **GRAVITY_DUMP_CASCADE（垂直傾瀉）**：百斤滾油化為寬三步之滾燙油幕，垂直灌頂覆蓋梯頂與梯身中部。
5. **SEVERE_SCALD_MASS_FALL（燙傷墜梯）**：熱油穿透防具，造成無視護甲之持續真實傷害，攀爬士兵全數失足墜落。
6. **LADDER_IGNITION_COLLAPSE（雲梯燒毀）**：油漬滲透木料引發大火，雲梯主結構耐久度每秒扣減 15%，6 秒內瓦解坍塌。
7. **COUNTERWEIGHT_REARM_RESET（重裝復位）**：配重繩索將空斗拉回，輔兵提桶補充新桐油，冷卻時間為 45 秒。

## 3. 數值模型與物理演算

### 沸油傾瀉覆蓋與燙傷公式

$$D_{scald} = D_{base\_hot} \times \left(1.0 + 0.005 \times (T_{oil} - 100)\right) \times (1.0 - 0.4 \times \text{ArmorWaterproof})$$

- $T_{oil}$：油溫（常態 250 度）。
- $\text{ArmorWaterproof}$：防具防水／防液滲透係數（普通重甲僅 0.15，高溫油汁可完全浸透內部襯甲）。

### 梯身起火斷裂判定公式

$$P_{burn} = \min\left(0.95, \; 0.60 + 0.002 \times T_{oil} - 0.20 \times \text{IsFlameRetardant}\right)$$

- 若雲梯無防火鐵皮包裹，引燃機率高達 90%，每秒承受 120 點高溫灼燒結構傷害。

## 4. 戰場戰術連鎖與部隊生剋

1. **極度剋制蟻附登城**：任何試圖藉由雲梯強攻城牆之步兵單位，遭受潑油後生還率低於 10%，登城攻勢瞬間中斷。
2. **盾牌遮擋無效**：頂盾攀爬之士兵無法防禦自上而下漫延流動之熱油液體，頂盾防禦判定完全無效。
3. **投石機精確砸毀懸臂**：敵方若調配精確投石機集中轟擊城頭懸臂，可摧毀翻斗支架使其失去功能。

## 6. 驗證標準與測試用例 (TC)

- **TC-CANTILEVER-01（翻斗傾角響應）**：拉動拉索後，翻斗必須在 0.5 秒內旋轉至 90 度並觸發液體流體生成。
- **TC-CANTILEVER-02（攀登者全滅墜落）**：處於雲梯 3 至 7 公尺範圍內之 5 名步兵，承受熱油後必須 100% 觸發跌落判定。
- **TC-CANTILEVER-03（雲梯燃毀坍塌）**：受油淋洗之木質雲梯必須在 8 秒內耐久度歸零並觸發結構斷裂動畫。

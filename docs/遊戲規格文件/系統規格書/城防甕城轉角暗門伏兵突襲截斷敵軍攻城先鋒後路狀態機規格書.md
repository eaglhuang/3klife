# 城防甕城轉角暗門伏兵突襲截斷敵軍攻城先鋒後路狀態機規格書

> **來源**：《武經總要》城制篇「甕城轉角暗門（突門）」與三國守城反擊戰術（於甕城或馬面內側隱蔽處砌築薄磚暗門，待敵攻城先鋒主隊湧入外破口時，精兵撞開暗門自側後腰斬敵軍隊列）、WBS `FORM-143` 城防近戰反擊模組。
> **關聯文件**：`doc_spec_0900`（甕城重力翻板）、`doc_spec_0845`（狼牙拍與千斤閘）、`doc_spec_0909`（塞門刀車）。

## 一、 設計目標與戰術定位

「甕城轉角暗門（突門）」是城防體系中「守中帶攻、截頭斷尾」的戰術機關。守軍在城牆轉角或甕城側面預留拱門，外部僅封砌一層薄磚並塗泥偽裝成實心城牆。當敵軍攻破外層城門、前鋒與後續大隊在城門通道內首尾相連時，守軍敢死隊從暗門驟然殺出，瞬間將敵軍切為兩截。

1. **薄磚偽裝與零預警破壁**：暗門平時完全不可見（敵方偵察視野無法識別），開啟瞬間對貼牆敵軍造成碎磚震懾。
2. **腰斬敵軍陣列與孤立先鋒**：突門兵橫插敵軍隊列中央，使已入甕城之敵先鋒喪失後隊增援與指揮官光環連線。
3. **前後夾擊與士氣雪崩**：配合塞門刀車或千斤閘封死通道，對孤立無援的敵先鋒實施三面合圍殲滅。

## 二、 狀態機生命週期（5 階段）

```
[1. 薄磚偽裝 Brick_Camouflage_Sealed]
       │ (敵先鋒 >= 1 隊踏入城門內側，且敵後隊仍在門道)
       ▼
[2. 撞木破門 Batter_Hidden_Sally_Port]
       │ (內部巨木撞破薄磚外牆，1 格內敵軍驚愕定身)
       ▼
[3. 橫插斷後 Flank_Wedge_Cutoff]
       │ (守軍刀盾精兵橫向切入，截斷敵前後隊連線)
       ▼
[4. 絕地合圍 Isolated_Vanguard_Annihilation]
       │ (孤立敵先鋒喪失主帥光環，承受 +45% 夾擊傷害)
       ▼
[5. 砌石重封 Masonry_Reseal_Defense]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `BRICK_CAMOUFLAGE_SEALED` | 薄磚偽裝 | 守軍於甕城轉角預置暗門，內駐精銳刀盾死士；敵方未擁有「內應情報」時完全視為普通城牆。 |
| `BATTER_HIDDEN_SALLY_PORT` | 撞木破門 | 當敵軍先鋒深入甕城、後隊正在通過外城門洞時，守軍以撞木從內向外轟碎薄磚牆，震暈門前 `1` 格敵軍 1 回合。 |
| `FLANK_WEDGE_CUTOFF` | 橫插斷後 | 守軍死士自暗門魚貫而出，橫向佔領外城門內側地格，物理截斷敵軍「甕城內先鋒」與「城外主力」之連結（`Connection_Severed = true`）。 |
| `ISOLATED_VANGUARD_ANNIHILATION` | 絕地合圍 | 被截斷在甕城內的敵先鋒陷入「孤軍絕境（喪失主帥光環、士氣每回合 `-20`、承受側後夾擊傷害 `+45%`）」。 |
| `MASONRY_RESEAL_DEFENSE` | 砌石重封 | 殲滅孤立敵先鋒後，死士退回暗門，工兵推出預製生鐵柵與石塊封堵暗門破口，防止敵軍反順暗門攻入。 |

## 三、 核心數值與判定公式

### 3.1 突襲奇襲加成公式（Ambush Flank Multiplier）
$$M_{\text{ambush}} = 1.45 + 0.15 \times \mathbb{I}_{\text{unspotted}} + \frac{\text{LEA}_{\text{def}} - \text{INT}_{\text{atk}}}{250}$$
- $\mathbb{I}_{\text{unspotted}}$：若暗門開啟前未被敵方斥候識破，額外獲得 `+15%` 首回合奇襲暴擊加成。

### 3.2 先鋒孤立崩潰檢定（Vanguard Isolation Rout）
$$P_{\text{rout}} = \text{clamp}\left(0.40 + (1.0 - R_{\text{hp}}) \times 0.50 - \frac{\text{LEA}_{\text{vanguard}}}{200},\ 0.15,\ 0.90\right)$$
- 當甕城內敵先鋒與後隊斷絕超過 2 回合且兵力比率 $R_{\text{hp}} < 0.50$ 時，每回合依 $P_{\text{rout}}$ 機率直接棄械投降。

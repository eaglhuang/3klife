# 3KLife 城防絞盤升降活動懸空弔橋斷絕護城河渡河衝鋒狀態機規格書

## 1. 系統定位與設計意圖

在三國堅城要塞護城河防禦體系（如許昌、鄴城、建業等大城）中，橫跨三丈寬護城河的「絞盤鐵索升降活動弔橋（Winch-Operated Drawbridge）」是控制通道開闔與保護主城門的第一道咽喉機關。本系統規範城防弔橋之放橋通行、誘敵半渡、緊急絞升傾翻與立橋護門狀態機：
- **厚櫟木包鐵橋板與雙鐵鏈配重絞盤**：橋身長三丈、寬丈二，底鋪雙層硬櫟木包覆生鐵皮；前端兩角繫粗鐵鏈，穿入城樓暗室千斤石配重絞盤。
- **半渡緊急抽銷傾翻落水**：當敵軍先鋒步騎踏上弔橋正中企圖直撲城門時，守軍釋放配重千斤石急速拉起橋頭，橋面在 3 秒內陡升至 60 度以上，橋上敵兵與衝車全數滑落深水護城河溺斃。
- **九十度垂直立橋化為外層副城門**：弔橋拉起後垂直貼合於主城門外側，為城門額外增加一層厚達一尺之包鐵護盾，並徹底隔絕護城河兩岸交通。

## 2. 狀態機架構與轉換生命週期

城防升降弔橋狀態機（代碼：`DRAWBRIDGE-WINCH-MOAT-CUTOFF01`）流程如下：

```
[ BRIDGE_LOWERED_PASSABLE ] (弔橋平放搭接護城河對岸供友軍出入)
           │
           ├── 敗軍退入城內且敵先鋒追至橋面中段
           ▼
[ ENEMY_MIDSPAN_OVERLOAD ] (橋面敵軍人數或衝車重量進入傾覆區)
           │
           ├── 守將斬斷配重止動索 ──> [ COUNTERWEIGHT_RAPID_HOIST ]
           ▼
[ STEEP_INCLINE_SLIDE_DUMP ] (橋面陡升六十度敵軍失足墜入深水河溝)
           │
           ├── 絞盤持續收鏈拉平至九十度垂直
           ▼
[ VERTICAL_SEAL_GATE_SHIELD ] (弔橋垂直緊貼城門化為外層包鐵裝甲牆)
           │
           ├── 敵軍投擲飛鉤鐵索企圖硬拉放橋
           ▼
[ GRAPPLE_CONTEST_DEFENSE ] (守軍砍斷敵飛鉤鐵索維持弔橋緊閉)
           │
           ▼
[ WINCH_RELEASE_LOWERING ] (戰況解除或出城反擊時緩放弔橋復位)
```

### 狀態細部定義

1. **BRIDGE_LOWERED_PASSABLE（平放通行）**：弔橋水平架設於護城河兩岸石墩，尋路網格標記為可通行陸橋。
2. **ENEMY_MIDSPAN_OVERLOAD（半渡鎖定）**：城外潰兵入城完畢，敵軍前鋒 15 至 30 人已衝上橋面中央。
3. **COUNTERWEIGHT_RAPID_HOIST（配重急升）**：城樓暗室兩顆千斤墜石垂直落下，透過滑輪組瞬間拉動雙鐵鏈，橋頭急速抬升。
4. **STEEP_INCLINE_SLIDE_DUMP（滑落溺水）**：橋面傾角突破 45 度摩擦極限，橋上所有敵方步騎與衝車翻滾墜入兩丈深護城河。
5. **VERTICAL_SEAL_GATE_SHIELD（立橋護門）**：弔橋呈 90 度垂直鎖死於城門外框，通道斷絕，主城門獲得 3,000 點額外裝甲值。
6. **GRAPPLE_CONTEST_DEFENSE（防鉤爭奪）**：對岸敵軍若投擲飛爪鐵鉤硬拉放橋，城頭守軍可傾倒熱油或揮斧斬斷敵繩。
7. **WINCH_RELEASE_LOWERING（放橋出擊）**：守軍派奇兵出城突襲時，鬆開絞盤棘輪，橋面於 5 秒內平穩放下。

## 3. 數值模型與物理演算

### 橋面傾角滑落與溺水判定公式

$$P_{slide}(\theta) = \max\left(0, \; \min\left(1.0, \; \frac{\sin\theta - \mu_s \cos\theta}{0.5}\right)\right)$$

$$P_{drown} = 0.35 + 0.55 \times \text{IsHeavyArmor}$$

- $\theta$：弔橋當前抬升仰角（度）；$\mu_s$：橋板靜摩擦係數（0.45）。
- 當仰角 $\theta \ge 50^\circ$ 時滑落率達 100%；身披重甲之敵兵墜入護城河後，溺水暴斃率高達 90%。

### 鐵鏈配重抬升角速度公式

$$\omega_{hoist} = \frac{M_{counterweight} \times g - \frac{1}{2} \left(M_{bridge} + M_{enemies}\right) \times g \cos\theta}{I_{bridge}}$$

- 若橋面敵軍總重未超過配重上限（3,500kg），弔橋可在 4 秒內完成 0 至 90 度垂直閉合。

## 4. 戰場戰術連鎖與部隊生剋

1. **攻城衝車與重騎絕路**：弔橋拉起後，敵軍地面攻城器械（衝車、塞門車、盾車）均被阻隔於對岸，無法接觸城門。
2. **迫使敵軍轉為填河作業**：敵方必須指派工兵冒箭雨進行「沙袋填河」或架設「飛橋」，攻城節奏延緩 120 秒以上。
3. **鐵鏈弱點防護**：雙側吊橋鐵鏈免疫普通弓箭與劈砍，唯獨懼怕重型投石機連續砸擊同一鐵鏈節點。

## 6. 驗證標準與測試用例 (TC)

- **TC-DRAWBRIDGE-01（半渡傾翻落水）**：橋上有 10 名重步兵時啟動急升，仰角超過 50 度瞬間全數滑落護城河並觸發 90% 溺亡判定。
- **TC-DRAWBRIDGE-02（立橋尋路阻斷）**：仰角達 90 度時，`isMoatPassable` 變為 `false`，主城門獲得 3,000 點額外護盾。
- **TC-DRAWBRIDGE-03（超載卡滯判定）**：若橋面擠滿超過 3,500kg 敵軍與衝車，抬升速度衰減 75%，需額外人手搖動絞盤。

# 3KLife 城防絞盤牽引生鐵塞門刀車堵死城門破口防步騎突入狀態機規格書

## 1. 系統定位與設計意圖

在三國城池攻防最危急的破門階段（如陳倉保衛戰郝昭以重器堵門、襄陽守城戰木門被衝車撞破），當厚重城門或千斤閘被敵軍衝車轟碎出現致命缺口時，守軍最後的防線便是預置於門洞內側的「生鐵塞門刀車（Bladed Gate-Plug Cart）」。本系統規範塞門刀車之緊急推入、破口封死、利刃反刺與門洞絞肉防禦狀態機：
- **丈二寬重型硬木車體密排百柄生鐵尖刀**：車寬與城門洞等齊，正面立設五層交錯橫木，每層向外斜伸十餘柄長三尺之雙刃生鐵尖刀與狼牙倒刺，形同移動刺蝟鐵牆。
- **地樁鎖死與雙側絞盤鐵鏈固定**：刀車推入城門破口瞬間，車底四根生鐵地腳釘砸入石縫，門洞兩側石壁絞盤拉緊粗鐵鏈，使敵軍衝車亦無法將其撞退。
- **門洞狹窄空間零死角穿刺**：擁擠突入城門洞之敵軍步騎因後方部隊推擠無法煞車，直接撞上塞門刀車之密集刀林，瞬間將城門破口化為敵軍無法逾越的鐵刺死地。

## 2. 狀態機架構與轉換生命週期

塞門刀車封門狀態機（代碼：`BLADED-GATE-PLUG-CART-DEFENSE01`）流程如下：

```
[ GATE_BREACH_EMERGENCY ] (主城門遭衝車轟破耐久歸零形成缺口)
           │
           ├── 守將下達塞門死守令 ──> [ CART_WINCH_FORWARD_RAM ]
           ▼
[ BREACH_PLUG_INTERLOCK ] (刀車頂著敵前鋒強行塞滿城門破口)
           │
           ├── 車底地釘砸入青石板且側壁鐵鏈鎖死
           ▼
[ IRON_SPIKE_WALL_ANCHORED ] (刀車徹底錨定化為不可移動之鐵刺障壁)
           │
           ├── 敵軍後續部隊盲目向前推擠衝撞
           ▼
[ CROWD_CRUSH_IMPALEMENT ] (敵前排士兵被後方推擠撞入刀叢穿刺斃命)
           │
           ▼
[ REAR_SPEAR_THRUST_SUPPORT ] (守軍自刀車縫隙伸出長矛與強弩精準點殺)
           │
           ▼
[ MASONRY_REPAIR_SEAL ] (工兵於刀車後方砌石築起內層新牆)
```

### 狀態細部定義

1. **GATE_BREACH_EMERGENCY（城門告破）**：主城門生命值歸零碎裂，門洞內側待命之 8 名大力士立即解開刀車剎車。
2. **CART_WINCH_FORWARD_RAM（推車迎撞）**：結合斜坡重力與滑輪牽引，重達兩千斤之塞門刀車呼嘯前衝，將剛踏入門檻之敵先鋒直接撞飛穿刺。
3. **BREACH_PLUG_INTERLOCK（嚴密塞門）**：刀車精準卡入一丈二尺寬之門洞，左右縫隙小於半尺，徹底封死通行路徑。
4. **IRON_SPIKE_WALL_ANCHORED（錨定鎖死）**：四根地釘入石，雙側生鐵鏈繃緊，刀車獲得 90% 抗撞擊與免疫擊退特性。
5. **CROWD_CRUSH_IMPALEMENT（推擠穿刺）**：敵軍後隊不知前路已堵，持續往前衝鋒，導致前排士兵承受雙倍擠壓穿刺真實傷害。
6. **REAR_SPEAR_THRUST_SUPPORT（車後刺殺）**：守軍盾牌手與長槍手依託刀車掩護，自刀縫間無傷刺殺與射擊受困敵兵。
7. **MASONRY_REPAIR_SEAL（築牆封門）**：若刀車持續堅守超過 180 秒，後方工兵可完成磚石內牆修築，永久封閉該城門。

## 3. 數值模型與物理演算

### 塞門刀車推擠穿刺傷害公式

$$D_{impale} = D_{blade\_base} \times \left(1.0 + 0.25 \times N_{rear\_push}\right) \times (1.0 + 0.5 \times \text{IsCavalry})$$

- $N_{rear\_push}$：門洞後方緊鄰推擠之敵軍排數（每增加 1 排，前排承受之穿刺傷害增加 25%）。
- 騎兵一旦撞上塞門刀車，額外承受 50% 致命穿刺傷害。

### 刀車抗衝車撞擊耐久耗損公式

$$\Delta \text{HP}_{cart} = \max\left(10, \; E_{ram\_impact} \times 0.05 \times (1.0 - 0.7 \times \text{IsChainAnchored})\right)$$

- 當側壁鐵鏈與地釘完整錨定時（`IsChainAnchored = true`），敵軍衝車對刀車造成的結構損傷減免 70%。

## 4. 戰場戰術連鎖與部隊生剋

1. **逆轉破門危機**：在城門失守後強行續命，完全阻斷敵軍精銳騎兵與先登死士利用破口快速湧入城內的企圖。
2. **火油焚車威脅**：刀車主體仍為硬木結構，若敵軍放棄強衝改投擲猛火油罐焚燒，守軍必須自城頭澆水滅火。
3. **巨斧破障工兵**：敵方若派持大鐵錘與長柄板斧之破障工兵貼近劈砍刀柄，可緩慢削減刀車的反傷倍率。

## 6. 驗證標準與測試用例 (TC)

- **TC-PLUG-CART-01（破門瞬時推入）**：城門耐久歸零後 2 秒內，塞門刀車自動進入 `BREACH_PLUG_INTERLOCK` 並阻斷尋路網格。
- **TC-PLUG-CART-02（後隊推擠加傷）**：當後方有 4 排敵軍推擠時，前排受刺傷害必須達到基礎值之 $2.0$ 倍。
- **TC-PLUG-CART-03（內牆修築永久封門）**：刀車存活滿 180 秒後，`innerWallRepairProgressPct` 達 100%，該門洞轉為永久不可通行。

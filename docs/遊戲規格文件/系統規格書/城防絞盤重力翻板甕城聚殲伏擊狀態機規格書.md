# 3KLife 城防絞盤重力翻板甕城聚殲伏擊狀態機規格書

## 1. 系統定位與設計意圖

在三國險要城池與雄關要塞守衛戰（如襄陽合肥甕城防守、陳倉郝昭禦敵）中，甕城作為主城門外的月牙形半封閉工事，是誘敵入死地的絕殺陷阱。本系統規範「絞盤配重重力翻板陷阱與千斤閘門斷後甕城伏擊系統（Barbican Gravity Trapdoor Ambush）」狀態機：
- **偽裝板面與配重卡榫釋放**：甕城地面鋪設厚櫟木翻板，由城樓暗室青銅絞盤連動卡榫鎖定；待敵中軍重裝踏入時抽銷釋放。
- **重力翻板深坑地刺絕殺**：翻板受重力失衡翻轉九十度，落入兩丈深坑，坑底密布淬毒生鐵拒馬與竹籤，墜落瞬殺破甲。
- **千斤雙閘斷路與箭雨聚殲**：外閘千斤排石閘門垂直斷落切斷後路，內閘緊閉，城垛弓箭手、滾木擂石傾瀉而下聚殲敵軍。

## 2. 狀態機架構與轉換生命週期

甕城重力翻板伏擊狀態機（代碼：`BARBICAN-GRAVITY-TRAPDOOR-AMBUSH01`）流程如下：

```
[ BARBICAN_LURE_GATE_OPEN ] (主外門大開佯敗誘引敵軍前鋒追擊)
           │
           ├── 敵軍前鋒與重裝精銳進城過半
           ▼
[ TRAPDOOR_WEIGHT_CAPACITY ] (翻板上方敵軍載重達到閾值臨界點)
           │
           ├── 守將切斷青銅配重銷 ──> [ WINCH_RELEASE_TRIGGER ]
           ▼
[ FLIP_TRAP_RAPID_DROP ] (木板失衡垂直翻落敵軍摔入深坑地刺)
           │
           ├── 外城門雙千斤閘急速滑落
           ▼
[ PORTCULLIS_SEAL_TRAPPED ] (外閘轟然落地徹底截斷後續部隊)
           │
           ├── 城垛頂端四方射擊孔全開
           ▼
[ BATTLEMENT_KILLZONE_PURGE ] (高空滾石火油金汁無死角覆蓋聚殲)
           │
           ▼
[ CLEANUP_RESET_MECH ] (清理深坑殘骸工兵絞盤復位重置機關)
```

### 狀態細部定義

1. **BARBICAN_LURE_GATE_OPEN（佯敗誘敵）**：守軍外城門虛掩佯裝潰敗，敵軍前鋒與重步兵縱隊被誘入狹窄甕城內。
2. **TRAPDOOR_WEIGHT_CAPACITY（載重觸發）**：地面承重感應達極限（30 人或 2 匹戰馬），進入絕殺窗口。
3. **WINCH_RELEASE_TRIGGER（抽銷觸發）**：守將拔除鎖定槓桿，支撐橫樑抽回，翻板失去軸心力矩。
4. **FLIP_TRAP_RAPID_DROP（翻板下墜）**：翻板受重力翻轉 90 度，中軍 20 至 40 人在 0.6 秒內墜入深坑受重傷。
5. **PORTCULLIS_SEAL_TRAPPED（千斤閘落）**：外閘重達五千斤千斤閘砸落阻斷門道，外部增援無法突入。
6. **BATTLEMENT_KILLZONE_PURGE（箭雨覆蓋）**：城堞射手與滾石組全速輸出，形成 360 度交叉絕命殺戮區。
7. **CLEANUP_RESET_MECH（清理復位）**：甕城敵軍全滅後，工兵啟動主絞盤將翻板拉平重新入銷復位。

## 3. 數值模型與物理演算

### 翻板瞬時傾覆力矩公式

$$M_{net} = \sum_{k=1}^{N} \left( W_k \times x_k \right) - M_{counter\_weight}$$

- $W_k$：翻板上方士兵重量（輕步兵 80kg，重甲步兵 150kg，戰馬 500kg）。
- $x_k$：距中心轉軸距離。抽銷時 $M_{counter\_weight} \to 0$，若 $M_{net} > 500\,\text{N}\cdot\text{m}$，翻板在 0.5 秒內完成九十度傾倒。

### 甕城絕殺區傷害倍率公式

$$D_{zone} = D_{base} \times \left(1.0 + 0.35 \times H_{ratio}\right) \times \left(1.0 + 0.5 \times \text{IsTrapped}\right)$$

- $H_{ratio}$：居高臨下高度差（每高 6 公尺提升 35% 傷害）。
- $\text{IsTrapped}$：若處於封閉狀態，傷害提升 50%，閃避率強制歸零。

## 4. 戰場戰術連鎖與部隊生剋

1. **重裝先登部隊剋星**：敵軍高甲重裝步兵陷入甕城後移速緩慢，承受滾石重砸時護甲減免失效 70%。
2. **名將脫險與輕功跳脫**：敏捷（AGI）$\ge 90$ 之名將有 40% 機率在翻板傾斜瞬間施展輕功攀爬逃脫。
3. **工兵鑿破排石閘**：外部敵方高級破障工兵可使用鐵錐敲擊外閘鉸鏈破壞閘門。

## 6. 驗證標準與測試用例 (TC)

- **TC-BARBICAN-01（重量閾值判定）**：載重達到 2500kg 且拔銷時，翻板 0.6 秒內翻落完成判定。
- **TC-BARBICAN-02（千斤閘截斷判定）**：千斤閘落下後，甕城內敵軍狀態標記為 `TRAPPED`，外圍停止入內尋路。
- **TC-BARBICAN-03（絕殺傷害倍率）**：驗證高空拋石砸擊受困敵軍時，傷害命中率與破甲倍率符合 $\ge 1.5\times$ 效果。

# 3KLife 城防護城河開鑿引水灌壕與吊橋起落防禦狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 城池防禦與攻城突破之壕溝防禦系統（`MILITARY-SIEGE-DEF01`）。規範三國重鎮（如襄陽、合肥、壽春、許昌）之第一道防線——「深塹護城河」與「重鐵吊橋」。涵蓋守軍引水灌濠、起吊飛橋拒敵，以及攻城方「沙袋填壕、引河改道破防、敢死隊泅渡砍斷絞盤鐵索」之工程攻防動態。

export enum MoatWaterSource {

}

## 4. 填壕推演、引水改道與斷索奪橋公式

### 4.1 攻城方沙袋填壕進程公式
每回合攻城兵團投入土囊沙包之填平進度：
$$\Delta \text{FillPercent} = \frac{\text{LaborTroopCount} \times 0.2}{\text{WidthMeters} \times \text{WaterDepthMeters}} \times \left(1.0 - \frac{\text{DefenderArcheryDPS}}{100}\right)$$
- 若為天然活水（`NATURAL_RIVER`），泥沙易被水流沖刷，填平速度 $-50\%$；
- 填壕進度達 $100\%$ 後，護城河防線瓦解，攻城器械可直接推進至城下。

### 4.2 敢死隊泅渡砍斷絞盤成功率
深夜派遣水性精熟死士泅渡剪除絞盤鐵索：
$$P_{\text{cut\_chain}} = \left(\frac{\text{InfiltratorWaterSkill} \times 0.6 + \text{NightDarknessCoeff} \times 0.4}{100}\right) \times \left(1.0 - \frac{\text{MoatWatchtowerAlert}}{150}\right)$$
- 成功時，吊橋瞬間砸落，造成壕邊人員小幅衝擊，城門直面衝車攻擊。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-MOAT-01**：在護城河填平進度未達 $70\%$ 且吊橋高懸時，衝車與雲梯車禁止進入城門攻擊格，若強行推進則直接墜入深壕沉沒。
2. **驗收 CASE-MOAT-02**：守軍在城樓傾倒「滾油火把」時，正在過橋之部隊承受 $300\%$ 火焰傷害，且吊橋表面耐久每回合扣除 150 點。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

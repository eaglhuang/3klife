# 培育36回合學府育成與外界一季時間凍結銜接規格書

> **模組識別碼**：`TIME-06`  
> **系統歸屬**：遊戲時間與培育模式銜接總控  
> **單一真相來源**：本規格書確立學府 36 回合育成期間「外界遊戲時間嚴格凍結」與「結業後外界僅步進 1 季」之宏觀/微觀時間映射權威標準。廢棄所有關於每回合推進外界時間或每 9 回合推 1 季之歷史混亂推論。

---

## 一、系統概述與架構原則

遊戲架構劃分為兩種尺度之時間流：
1. **宏觀世界時間（Macro World Time）**：以 `GameClock` 季度為單位（1 季 = 3 個月），驅動天下大勢、領地治理、年齡增長與武將壽命。
2. **微觀學府時間（Micro Academy Time）**：子嗣在書院中進行的 36 回合精細培育（回合策論、清談、期中考評、弱冠禮）。

為了避免玩家在進行長篇培育時，外界武將急速老化或敵國過度擴張，確立「**培育期外界時間凍結協議（Nurture Time Freezing Protocol）**」。

### Unity / 架構對照
- **時間維度隔離**：類似 Unity 中的 `Sub-scene Time Domain`，培育場景使用本地 Turn Counter，外界主循環暫停發送 SeasonAdvance 事件。
- **事務性結算**：培育完成時透過單一事務（Transaction）完成屬性回寫與外界時鐘步進。

## 二、時間凍結與單季步進映射模型

```
外界宏觀時間軸 (GameClock):
══════════════════════════════════════════════════════════════════════►
第 N 年 2 季 (作戰季) ──► 第 N 年 3 季 (培育季) ──► 第 N 年 4 季 (治理季)
                             │
                             ▼ (進入學府，外界時鐘完全凍結)
學府微觀時間軸 (Nurture Turn):
┌──────┬──────┬──────┬──────┬───────┬──────┬──────┐
│ 回合1 │ 回合2 │ ...  │第12回 │  ...  │第24回 │第36回│
│ 策論 │ 清談 │      │期中考 │       │弱冠禮 │ 結業 │
└──────┴──────┴──────┴──────┴───────┴──────┴──────┘
                             │
                             ▼ (結業結算，外界 GameClock 僅推進 1 季)
```

### 1. 核心映射常數
```typescript
export const ACADEMY_TOTAL_TURNS = 36;          // 書院標準培育總回合數
export const MACRO_SEASONS_PER_NURTURE = 1;     // 單次完整培育對應外界季度數（固定 1 季）
```

### 2. 狀態機約束規則
- **培育期間**：
  - 模式鎖定為 `GameTimeMode.Nurture`。
  - 學府內的每一回合行動（打牌、答題、教官指派、休養）**絕對不呼叫** `GameClock.advanceSeason()`。
  - 全域所有武將年齡、城池軍糧產能、敵國 AI 行動完全暫停推進。
- **結業結算點**：
  - 當子嗣完成第 36 回合（或中途達到重大共鳴提早結業/放棄退學）：
    1. 將培育所得之最終五維、特質、專屬戰法寫入該武將實體。
    2. 呼叫 `GameClock.advanceSeason()` **恰好 1 次**。
    3. 全域武將年齡增加 $0.25$ 歲（滿 1 季）。
    4. 模式自然輪轉至下一模式 `GameTimeMode.Governance`。

## 三、異常中斷與防 SL 安全還原

```typescript
export interface NurtureSessionPersistence {
    generalId: string;
    currentTurn: number;           // 1 ~ 36
    frozenGameTime: GameTimeState; // 進入培育時之外界時鐘快照
    isCompleted: boolean;
}
```

1. **斷線/重開防護**：
   - 讀檔時若偵測到未完成的 `NurtureSession`，外界時間直接還原為 `frozenGameTime`，防止重開機刷出跳季錯誤。
2. **未完成放棄處置**：
   - 玩家若在培育中途主動退學，視同本季培育結束，依當前已完成回合結算殘存成長，外界時鐘依然僅推進 1 季。

## 四、驗收條件與測試案例 (Test Cases)

- **TC-TIME-13（36 回合時間凍結）**：
  - 培育自第 1 回合推至第 35 回合，檢驗 `GameClock.totalSeasonsElapsed` 保持不變。
- **TC-TIME-14（結業推進單季）**：
  - 第 36 回合結算完成後，`GameClock.advanceSeason()` 恰好被調用 1 次，總季數增加 1。
- **TC-TIME-15（武將增齡精確對齊）**：
  - 進入培育時武將年齡 15.0 歲，結業後外界時鐘推進 1 季，武將年齡精確更新為 15.25 歲。
- **TC-TIME-16（模式正確轉移至治理）**：
  - 培育季（Nurture）結算後，當前模式精確流轉至治理季（Governance）。

## N. 血脈保底機制補遺（2026-04-12）

> **正式共識**：依 MCQ Q32 裁決（選項 D），世家血脈連動機制為正式規則。

### N-1. 血脈保底（Family Priority）

| 條件 | 效果 |
|---|---|
| 子嗣姓氏 == 支援卡家族（如 關家子弟裝備 SSR 關羽卡） | 連續事件觸發優先排程至最高、**36 回合前保證第 3 段事件觸發且 100% 成功**、金戰法 PT 需求 -20% |
| 異姓子弟裝備同名卡（如 非關姓人裝備關羽）| 回歸 RNG 邏輯，無保底 |

**TypeScript 邏輯參考**：
```typescript
if (child.surname === supportCard.familyID) {
  eventManager.forceTrigger(supportCard.continuousEventID); // 強制觸發
  skillManager.applyDiscount(supportCard.goldSkill, 0.8);  // 8 折優惠
}
```

### N-2. 重修機制

| 規則 | 說明 |
|---|---|
| 保留記錄上限 | 最多 3 份畢業評量記錄 |
| 重修代價 | **完全無代價**（MCQ Q31 選項 B）。玩家自由選最佳成績單，不附加任何負面因子或疲勞懲罰 |
| 重修消耗 | 消耗「體力藥水（補腦湯）」×1 |
| 畢業鎖定 | 選定成績單後按「正式畢業」，該評量永久定型，其餘記錄銷毀 |

## O. 實作狀態與使用者裁定（2026-10-26 回寫）

> 本節只記錄已合併實作與裁定，不改寫上方設計內容。對應任務卡 PROG-2-1136。

### O-1. 使用者裁定（2026-10-26）

- **入學教官**：入學至少需帶 1 位教官（自有最多 5 位＋好友借用 1 位，合計最多 6 位）。無教官時入學鈕停用並提示「至少需帶 1 位教官」。`教官系統（支援卡）.md` 尚未分片（單檔超過 doc-shard 門檻），故此裁定與 §F-3／§F-4／§L-2 的實作狀態暫記於本分片；待教官規格分片後再回寫至該處。

### O-3. 已知差異

- 戰法靈感 id（例如 `TAC_LANCE_THRUST`）尚未登錄於戰法庫，畫面暫以 id 顯示。名稱與戰場效果另由 PROG-2-1135 處理，本分片不定義其設計。
- 支援卡資料：諸葛亮補「緩速（TAC_SLOW）」★0 事件；龐統、凌統、徐盛、張苞首個靈感事件降為 ★0（對應教官系統 §F-4「★0 解鎖事件組 1」，PR #927）。

## 🗳 MCQ 決策記錄

### Q31：重修代價機制
- **裁決**：選項 B — 無代價版本（三張成績單純靠運氣，不附加負面因子）

### Q32：戰法提示隨機性保底機制
- **裁決**：選項 D — 世家血脈連動（姓氏匹配支援卡家族，36回合內保證觸發，PT-20%）

### Q47：培育外界時間換算
- **裁決**：選項 A — 外界1季=培育36回合（維持鏡像壓縮）

### Q48：培育教官槽位定義
- **裁決**：選項 C — 固定6教官槽（入學快照鎖定）

### Q69：子嗣紀錄上限
- **裁決**：系統最多紀錄該子嗣的 3 次培育結業狀態。玩家決定「正式畢業」時必須從中選擇其一。

## 雙層數值培育
培育主要提升的是實力層 (Prowess, 0~2000+)，並受制於先天的資質層 (Talent, 0-100)。

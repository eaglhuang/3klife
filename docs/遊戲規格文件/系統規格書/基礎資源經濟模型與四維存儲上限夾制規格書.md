# 基礎資源經濟模型與四維存儲上限夾制規格書

## 1. 核心定位與職責邊界
本規格書定義《三國人生》主公勢力基礎資源經濟模型、初始存儲上限夾制與資源匱乏告急提示機制（WBS `ECO-01` 與 `ECO-11`，代碼落位於 `ResourceCap.ts` 與 `GameSession.ts`）。
系統管理遊戲運轉之四大命脈資源：糧草、黃金、城市兵源與名聲，透過嚴格之上限夾制防範數值溢出膨脹，並在資源告急時主動向 UI 與戰報層發出防禦性警告。

## 3. 資源邊界夾制模型（`clampResource`）

所有經濟產出、戰後收益與市場購買入帳時，均須通過純邏輯夾制函式：
$$\text{ClampedAmount} = \begin{cases} 0, & \text{amount} < 0 \text{ 或非有限數字} \\ \min(\text{amount}, \text{BASE\_RESOURCE\_CAPS}[\text{key}]), & \text{其他} \end{cases}$$

1. **零值保底不穿透**：資源存量嚴格禁止為負數。
2. **上限封頂溢出丟棄**：未經倉庫擴建前，超出初始上限之產出自然截斷，防止離線掛機過度囤積。

## 4. 資源匱乏告急與防呆警示（`resourceShortageWarning`）

### 4.1 通用不足檢定
當玩家嘗試執行消耗行為（如出征出兵、鍛造裝備、設施升級）時，調度器檢驗當前持有量是否滿足所需：
$$\text{WarningText} = \begin{cases} \text{null}, & \text{have} \ge \text{need} \\ \text{「⚠ } + \text{RESOURCE\_NAMES}[\text{key}] + \text{ 存量不足！」}, & \text{have} < \text{need} \end{cases}$$

### 4.2 季末糧草斷絕專屬警訊
若季度切換時糧草歸零或不足以支應封地開銷，觸發沉浸式劇本警語：
$$\text{FOOD\_LOW\_LINE} = \text{「主公，糧草告急！將士們快要餓肚子了。」}$$
提醒主公立即調撥金幣平糶購糧或尋求每日補貼救濟。

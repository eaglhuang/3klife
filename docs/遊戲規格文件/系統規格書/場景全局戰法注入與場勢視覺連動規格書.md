# 場景全局戰法注入與場勢視覺連動規格書

## 1. 核心定位與轉譯契約

本規格書為戰場全局環境場勢戰法注入機制（Scene Gambit Injection，代號 `TAC-13`）的單一真相來源（Single Source of Truth）。透過 `SceneGambitAdapter` 將戰役所選之大場景戰術（`BattleTactic`）轉化為戰場核心之標準 `BattleSkillRequest`，在戰鬥開局時完成地盤鋪設與全域規則變更。

```typescript
export interface SceneGambitContract {
  sourceType: SkillSourceType.SceneGambit;
  targetMode: BattleSkillTargetMode.GlobalStage;
  timing: BattleSkillTiming.StartOfBattle;
  supportedTactics: [
    BattleTactic.FireAttack,
    BattleTactic.FloodAttack,
    BattleTactic.RockSlide,
    BattleTactic.AmbushAttack,
    BattleTactic.NightRaid,
    BattleTactic.Siege
  ];
}
```

## 2. 六大場景全局戰法規則模型

| 場景戰術代碼 | 戰法識別碼 | 預設棋盤地格佈局 | 戰術機制與數值規則 |
|---|---|---|---|
| `FireAttack`（火攻） | `scene-fire-attack` | 縱深中線佈設火海格（`Hazard_Fire`） | 停留地格部隊每回合初承受當前 HP 8% 灼燒傷害；強風助燃擴散 1 格。 |
| `FloodAttack`（水淹） | `scene-flood-attack` | 棋盤橫向貫穿 2 格河道（`ForceMove_Water`） | 進入水域單位強制順流推移 1 格；騎兵移動力 $-1$，水師兵種免役。 |
| `RockSlide`（落石） | `scene-rock-slide` | 峽谷中段配置 2~3 處落石障礙物 | 落石具備 HP 800 與硬性路徑阻絕；擊破後戰後打撈石材 100~300。 |
| `AmbushAttack`（伏兵） | `scene-ambush-attack` | 兩側邊緣配置叢林隱匿格（`Stealth_Bush`） | 前 2 回合我方伏兵進入隱身；敵方 AI 索敵強制忽略；主動攻擊後破隱。 |
| `NightRaid`（夜襲） | `scene-night-raid` | 全棋盤夜間低能見度遮罩 | 前 2 回合我軍傷害 $\times 1.5$、暴擊率 $+20\%$；敵軍命中率下降 $25\%$。 |
| `Siege`（攻城） | `scene-siege` | 底線配置城牆（Wall）、城門（Gate）與護城河 | 城牆提供守軍 30% 減傷；衝車破門傷害 $\times 2.0$；器械可破壞阻擋。 |

## 3. 開局注入生命週期流水線（Injection Pipeline）

1. **參數傳遞（Lobby $\to$ Battle）**：
   - 玩家或軍事任務指派 `battleTactic`，經 `BattleEntryParams` 注入戰場建構上下文。
2. **開局時序（`StartOfBattle`）調度**：
   - 在任何部隊行動前，`SceneGambitAdapter.buildRequest()` 產出全局請求。
   - `BattleController` 執行地盤初始化，依據 `SceneTilePresets` 將常態格覆蓋為 Hazard / Stealth / Water 等狀態。
3. **安全回退（Normal Fallback）**：
   - 若 `battleTactic == BattleTactic.Normal`，Adapter 回傳 `null`，棋盤維持標準空白地格，不產生任何全域副作用。

## 4. HUD 場勢提示與視覺渲染契約

1. **頂部 HUD Badge**：
   - 畫面頂部常駐顯示場勢標籤（例如【火攻場勢】、【夜襲奇襲】）。
   - 點擊展開懸浮情資（Summary）：簡明陳述「中線火海已展開，停留其中的部隊會持續受傷」。
2. **動態材質與漣漪連動（Ripple & Decal）**：
   - 若為 `FloodAttack`，棋盤渲染器動態載入水波粒子與 `water-ripple` 貼花；若載入失敗，秒級回退底層藍色填充（`floodBaseFillMaterial`），杜絕黑屏破圖。
   - 若為 `NightRaid`，全場景覆蓋深藍夜間色階與邊緣微弱火把光暈。

## 5. 自動化測試與驗收標準

1. **單元測試對齊**：
   - 對齊 `tests/BattleSkillSourceTranslator.test.ts` 與 `tests/SceneGambitTrigger.test.ts`。
   - 驗收條件 1：驗證 6 種場景戰術皆能轉譯為具備 `GlobalStage` 與 `StartOfBattle` 之請求。
   - 驗收條件 2：驗證伏兵狀態下前 2 回合敵軍索敵完全忽略我方潛伏單位。
   - 驗收條件 3：驗證水淹場景漣漪載入失敗時正確觸發 Fallback 材質而不拋出未捕獲例外。

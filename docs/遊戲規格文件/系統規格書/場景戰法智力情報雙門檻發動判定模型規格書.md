# 場景戰法智力情報雙門檻發動判定模型規格書

## 1. 核心定位與判定契約

本規格書為戰場特殊場景戰法發動判定與成功率計算模型（Scene Gambit Trigger Check，代號 `SCN-03`）的單一真相來源（Single Source of Truth）。在戰役開局或軍事任務銜接階段，軍師或主將需同時滿足「智力門檻（$\text{intThreshold}$）」與「情報門檻（$\text{intelThreshold}$）」，方能嘗試發動場景戰法。

```typescript
export interface SceneTriggerContract {
  baseSuccessRate: 0.50;          // 基礎成功率 50%
  ratePerIntelligencePoint: 0.02; // 每點超額智力 +2%
  maxSuccessRate: 0.95;           // 成功率硬頂上限 95%
  failureFallbackRate: 0.00;      // 門檻未達直接歸零 0%
}
```

---

## 2. 雙重門檻判定流水線（Two-Gate Validation Pipeline）

發動檢定分為兩道連續關卡：

### 2.1 第一關：情報門檻檢定（Intelligence Gathering Gate）

- 戰場前置偵查所獲取之軍事情報值 $\text{Intel}$ 必須達到該場景之要求：
  $$\text{Intel} \ge \text{Threshold}_{\text{intel}}$$
- **阻絕裁定**：若情報值不足，代表敵方佈防或地形細節尚未探明，無法實施伏擊或夜襲，發動判定立即中斷，成功率為 $P = 0$。

### 2.2 第二關：智力門檻檢定（Tactician Wisdom Gate）

- 實施戰法之主將或軍師智力 $\text{INT}$ 必須達到該計策之施展底線：
  $$\text{INT} \ge \text{Threshold}_{\text{INT}}$$
- **阻絕裁定**：若智力未達門檻，計策無法籌劃，發動判定中斷，成功率為 $P = 0$。

---

## 3. 成功率浮動計算公式與 95% 上限模型

當雙重門檻皆通過後，依據軍師智力超越門檻之幅度，線性賦予成功率加成：

$$P = \min\left(0.95, 0.50 + (\text{INT} - \text{Threshold}_{\text{INT}}) \times 0.02\right)$$

- **基礎保底成功率**：剛好達標時（$\text{INT} = \text{Threshold}_{\text{INT}}$），成功率為 $50\%$。
- **邊際增幅係數**：每多具備 1 點智力，成功率提升 $+2\%$。
- **95% 硬性天花板（Hard Cap）**：即便智力遠超門檻（例如超出 25 點以上達 100%），系統強制保底保留 $5\%$ 之戰場不可預測風險（天候突變、敵將直覺警覺等），最高成功率鎖定為 $95\%$。

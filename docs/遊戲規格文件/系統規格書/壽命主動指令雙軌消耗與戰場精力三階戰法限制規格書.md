# 壽命主動指令雙軌消耗與戰場精力三階戰法限制規格書

## 1. 模組職責與架構定位
本規格書規範武將的「主動指令壽命雙軌消耗模型（`LifespanCost`，不老哲學）」以及戰鬥實戰中的「精力三階戰法軟懲罰閘門（`VitalityBattleGate`）」。模組確保玩家能放鬆體驗內政與待命，僅在執行重大決策時承受壽命代價，並在戰場上藉由精力高低動態影響戰法釋放權限。

```
┌─────────────────────────────────────────────────────────────┐
│                 Lifespan Cost & Vitality Gate               │
├──────────────────────────────┬──────────────────────────────┤
│ 壽命雙軌消耗 (不老哲學)      │ 戰場精力三階戰法限制         │
│ 待命不扣 / 主動指令扣月數     │ >50% 全開 / 10~50% 禁奧義    │
│ (培育 1月 / 攻城 3月 / 結緣 6月)│ <10% 禁戰法 + 撤退高風險    │
└──────────────────────────────┴──────────────────────────────┘
```

## 2. 壽命主動指令雙軌消耗模型

### 2.1 不老哲學核心原則
- **放置與待命零消耗**：武將駐守城池、調整裝備、閒逛客棧或在後方待命，不扣除任何專屬壽命月數。
- **高強度主動指令精密扣除**：僅當玩家主動指派武將執行高耗能行動時，依表扣除壽命月數：

| 主動決策行為 | 扣除壽命月數 | 換算折算歲數 | 消耗原由與說明 |
| :---: | :---: | :---: | :--- |
| **學府培育（`NURTURE`）** | 1 個月 | $\approx 0.083$ 歲 | 擔任入學導師或親自入學修煉 |
| **出征攻城（`SIEGE`）** | 3 個月 | $0.25$ 歲 | 兵戈征伐、行軍風霜消耗氣血 |
| **家族結緣（`BONDING`）** | 6 個月 | $0.50$ 歲 | 洞房結締、精元傳承孕育後代 |

```typescript
export type LifespanActionType = 'NURTURE' | 'SIEGE' | 'BONDING' | 'IDLE';

export function getActionLifespanCostInMonths(action: LifespanActionType): number {
  switch (action) {
    case 'NURTURE': return 1;
    case 'SIEGE': return 3;
    case 'BONDING': return 6;
    case 'IDLE': default: return 0;
  }
}
```

## 3. 戰場精力三階戰法軟懲罰模型

### 3.1 戰法權限動態判定階梯
武將出陣時將當前精力（`Vitality`，滿額 100 點）帶入戰場，戰鬥中施放戰法受以下分段約束：
- **階段 I：氣定神閒（$\text{Vitality} > 50$）**：
  - 普攻、移動、全部主動戰法與終極奧義均正常施放，無任何懲罰。
- **階段 II：氣力透支（$10 \le \text{Vitality} \le 50$）**：
  - **禁用終極奧義**（`DisableUltimate`），奧義技能按鈕反灰。
  - 普通主動戰法仍可使用，但氣力消耗增加 $+20\%$。
- **階段 III：力竭垂危（$\text{Vitality} < 10$）**：
  - **禁用所有主動戰法與奧義**（僅允許普攻與基礎移動）。
  - 若部隊遭到擊破，撤退判定失敗率加算 **$+50\%$**（極易被敵方生擒俘虜）。

```typescript
export interface VitalityBattlePermission {
  canCastNormalTactics: boolean;
  canCastUltimate: boolean;
  tacticCostMultiplier: number;
  retreatFailureRiskBonus: number;
}

export function evaluateVitalityBattleGate(vitality: number): VitalityBattlePermission {
  if (vitality > 50) {
    return { canCastNormalTactics: true, canCastUltimate: true, tacticCostMultiplier: 1.0, retreatFailureRiskBonus: 0.0 };
  }
  if (vitality >= 10) {
    return { canCastNormalTactics: true, canCastUltimate: false, tacticCostMultiplier: 1.20, retreatFailureRiskBonus: 0.0 };
  }
  return { canCastNormalTactics: false, canCastUltimate: false, tacticCostMultiplier: 1.0, retreatFailureRiskBonus: 0.50 };
}
```

## 4. 單元測試驗證規範
1. **TC-LIFE-COST（主動指令精準扣除）**：IDLE 扣 0 個月；SIEGE 扣 3 個月；BONDING 扣 6 個月。
2. **TC-VIT-TIER-2（透支禁用奧義）**：精力 45 點，`canCastUltimate = false`，且 `tacticCostMultiplier = 1.20`。
3. **TC-VIT-TIER-3（力竭禁用全戰法）**：精力 9 點，`canCastNormalTactics = false`，`canCastUltimate = false`，撤退風險額外 $+50\%$。

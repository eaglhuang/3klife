# 3KLife 夜觀天象紫微垣太白晝見與熒惑守心天譴預警規格書

## 1. 模組概述與核心定位
本模組為 3KLife 戰略情報與天命天象預測系統（`ASTROLOGY-OMEN-01`）。透過欽天監、太史令或隱士高人（如管輅、司馬徽、諸葛亮）於夜間巡觀周天星宿，捕獲太白晝見、熒惑守心、紫微隱曜、客星犯帝座等重大天象異動。系統提前 1 至 3 個節氣向主公呈遞天命預警，並提供「改元、大赦、禳星、避位」等因應策論。

## 3. 資料結構與介面定義

```typescript
export enum CelestialOmenType {
  YING_HUO_SHOU_XIN = 'YING_HUO_SHOU_XIN', // 熒惑守心 (君王之災/政變)

export interface CelestialOmenConfig {
  omenType: CelestialOmenType;
  severityLevel: 'MINOR' | 'MODERATE' | 'CATASTROPHIC';

  observerId: string;                     // 占星師武將 ID
  observedTerm: string;                   // 觀測節氣

  secretReportText: string;               // 密奏文案
  recommendedAction: 'AMNESTY' | 'RITUAL_SACRIFICE' | 'WAR_READINESS' | 'DEFENSIVE_HOLD';

export interface FactionAstrologyState {
  factionId: string;
  activeOmens: CelestialOmenType[];
  moraleModifier: number;                 // 士氣動盪修正 (-20 ~ +20)
  generalsLoyaltyDecayRate: number;       // 忠誠自然流失加成
}
```

## 4. 占驗推演與災厄消弭公式

### 4.1 太史令星象察覺機率
$$\text{DetectProbability} = \left(\frac{\text{ObserverWisdom} \times 0.5 + \text{ObserverDivinity} \times 0.5}{100}\right) \times \text{OmenProminenceCoeff}$$
- 若占星師擁有「知天命」或「奇門遁甲」特技，檢定直接獲得 $+30\%$ 命中補償。

### 4.2 熒惑守心天譴消解公式
當出現「熒惑守心」時，君主可選擇「引咎自責下罪己詔」或「將災禍轉移於三公宰輔」：
$$\text{MitigationSuccess} = \text{ScapegoatPrestige} \times 0.6 + \text{SacrificeJadeValue} \times 0.4$$
- 若選擇轉嫁三公（如殺司徒以應天變），主公免除暴卒死劫，但該派系世家忠誠度全面暴跌 25 點。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-OMEN-01**：在太白晝見期間發動主動進攻，部隊行軍速度 $+15\%$、攻擊力 $+10\%$，但防禦力 $-20\%$ 且軍糧消耗翻倍（全軍陷入亢奮殺伐）。
2. **驗收 CASE-OMEN-02**：預警節氣倒數歸零時，若未執行對應消弭對策，所屬君主或主帥有機率扣除壽元 3 年或爆發領地叛亂。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，架構嚴整無多餘歷史附錄。

## 1. 業務定位與熱點可見性閘門

大廳主介面右側屏風區域設有「世家總覽」互動熱點（Noble House Hotspot）。為避免過早暴露複雜血統系統導致新手認知過載，該熱點受雙重解鎖閘門保護：

```mermaid
flowchart TD
    Enter[進入幕府大廳] --> CheckTier{主公官職 Tier >= 3 (偏將軍)?}
    CheckTier -- 是 --> Unlock[解鎖: 顯示金色世家徽記熱點]
    CheckTier -- 否 --> CheckFame{家族名聲 Fame >= 1000?}
    CheckFame -- 是 --> Unlock
    CheckFame -- 否 --> Hide[隱藏: 屏風維持純中式山水裝飾]
```

- **官職門檻**：官職等級達 `OFFICER_TIER_3`（偏將軍）。
- **名聲門檻**：即使官職未達標，若家族在天下積累名聲 $\text{Fame} \ge 1,000$ 點，亦可提前破鎖。
- **未解鎖表現**：大廳畫面節點 `node_noble_hotspot` 設為 `active = false`，不渲染徽記且無點擊判定。

## 2. 世家資料聚合與五級郡望階梯

點擊解鎖之世家熱點，彈出 800×900 阻斷式「天下世家總覽」面板。資料聚合器由存檔讀取全量武將譜牒，依血脈始祖進行家族分組：

### 2.1 家族四大核心指標契約
1. **`FamilyName`（家族堂號）**：始祖郡望標識（如「潁川荀氏」、「譙縣曹氏」）。
2. **`CurrentPatriarch`（當代家督）**：家族中官職或武力最高之代表主卡快照（姓名、頭銜、五維評分）。
3. **`LineageDepth`（傳承代數）**：譜牒由始祖延續之最高世代數（1~5 代）。
4. **`FameTier`（郡望階梯）**：

| 階梯等級 | 稱謂標籤 | 名聲門檻 ($\text{Fame}$) | 家族特權加成 |
|:---:|:---:|:---:|---|
| Tier 1 | 寒門草芥 | $< 500$ | 無特權 |
| Tier 2 | 鄉土豪紳 | $500 \sim 999$ | 領地每季黃金產出 $+5\%$ |
| Tier 3 | 郡中名門 | $1,000 \sim 2,999$ | 解鎖大廳世家熱點，子嗣培育起始點 $+20$ |
| Tier 4 | 朝廷門閥 | $3,000 \sim 5,999$ | 婚配交涉成功率 $+15\%$，官職考評加分 |
| Tier 5 | 傳世世家 | $\ge 6,000$ | 解鎖家族專屬雙奧義繼承與先祖祠堂神位 |

## 3. 資料模型與純邏輯介面

```typescript
export interface IFamilyMemberRecord {
    readonly id: string;
    readonly name: string;
    readonly familyId: string;
    readonly generation: number;
    readonly isPatriarch: boolean;
    readonly fame: number;
}

export interface IFamilyGroupSummary {
    readonly familyId: string;
    readonly familyName: string;
    readonly patriarchName: string;
    readonly lineageDepth: number;
    readonly totalFame: number;
    readonly fameTierLabel: string;
}

export function isNobleHotspotVisible(officerTier: number, totalFame: number): boolean {
    return officerTier >= 3 || totalFame >= 1000;
}

export function resolveFameTierLabel(fame: number): string {
    if (fame >= 6000) return '傳世世家';
    if (fame >= 3000) return '朝廷門閥';
    if (fame >= 1000) return '郡中名門';
    if (fame >= 500)  return '鄉土豪紳';
    return '寒門草芥';
}

export function aggregateFamilySummaries(
    members: readonly IFamilyMemberRecord[],
    familyNameMap: Readonly<Record<string, string>>
): readonly IFamilyGroupSummary[] {
    const grouped = new Map<string, IFamilyMemberRecord[]>();
    for (const m of members) {
        const list = grouped.get(m.familyId) ?? [];
        list.push(m);
        grouped.set(m.familyId, list);
    }

    const summaries: IFamilyGroupSummary[] = [];
    for (const [fId, mList] of grouped.entries()) {
        const patriarch = mList.find(m => m.isPatriarch) ?? mList[0];
        const maxGen = Math.max(...mList.map(m => m.generation), 1);
        const totalFame = mList.reduce((sum, m) => sum + m.fame, 0);

        summaries.push({
            familyId: fId,
            familyName: familyNameMap[fId] ?? '未知氏族',
            patriarchName: patriarch ? patriarch.name : '虛位以待',
            lineageDepth: maxGen,
            totalFame,
            fameTierLabel: resolveFameTierLabel(totalFame),
        });
    }

    return summaries.sort((a, b) => b.totalFame - a.totalFame);
}
```

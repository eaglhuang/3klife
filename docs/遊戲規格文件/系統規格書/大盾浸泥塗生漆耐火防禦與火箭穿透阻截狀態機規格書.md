# 3KLife 大盾浸泥塗生漆耐火防禦與火箭穿透阻截狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 步兵陣地防護與反制火箭系統（`SHIELD-FIREPROOF-01`）。重現古代重裝步兵營抗擊漫天火雨之專門技術：利用厚重柞木、榆木大盾，表面塗刷多層耐磨熟生漆，並於臨戰前將盾面深入水壕浸透黏稠黃泥漿。當漫天火箭射來時，黏泥隔絕高溫熱量使火焰瞬間窒息熄滅，阻絕火箭貫通穿透與陣型被焚潰滅。

## 4. 隔熱阻燃、穿透阻截與泥層脫落公式

### 4.1 火箭阻燃窒息與穿透阻截率
火箭命中覆泥生漆大盾時：
$$\eta_{\text{extinguish}} = \min\left(0.98, \frac{\text{MudSlurryThicknessMm} \times 5 + \text{LacquerLayers} \times 15}{100}\right)$$
- 覆泥厚度達 $15\text{mm}$ 且維持龜甲陣，火雨熄滅率達 $98\%$；
- 箭鏃穿透率被厚木板與韌性生漆阻擋，步兵實際承受傷害下壓 $90\%$。

### 4.2 火雨持續炙烤泥層脫落速率
每回合承受火雨淋打時，泥層之水分蒸發與乾裂剝落：
$$\Delta \text{MudLossPercent} = \left(15 + \text{IncomingVolleyIntensity} \times 2\right) \times \left(1.0 - \text{AmbientHumidityFactor}\right)$$
- 連續承受 3 回合集中火雨覆蓋，泥層全部脫落轉為 `LACQUER_EXPOSED`；
- 此時若未派遣輔兵「提桶補泥」，大盾將開始承受木質碳化損壞。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-SHIELD-01**：在移動突擊衝鋒過程中，無法維持嚴密龜甲陣，泥漿阻燃率強制下降 $50\%$，火箭穿透率增加 $30\%$。
2. **驗收 CASE-SHIELD-02**：大盾浸泥塗漆部隊，因自重增加 $40\%$，其基礎戰場移動速度每回合扣減 1 格。

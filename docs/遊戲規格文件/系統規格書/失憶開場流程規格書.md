# 失憶開場流程規格書

> **規格代碼**：`AMN-01`　**任務卡**：PROG-2-10184　**裁決來源**：使用者 2026-11-27 晚本人裁決（主線開場改成失憶醒來）
> **狀態**：規格定案（只有規格；盡量沿用現有開場流程，只改包裝）
> **依賴**：新手開場規格書（`doc_spec_0031`）、首子誕生與少年名將開場流程（`doc_spec_1233`，第 1 章開場總順序）、開局出身選擇（`ORG-01`）、神秘圖鑑總規格（`MYS-01`）、武將介紹古文白話吐槽（`doc_spec_1344`）、新手第一年樂趣四功能（`doc_spec_1347`）
> **被取代／搬走**：開場方案 B「AI 武將搶先連線」（PR #2721，`doc_spec_1346`）不進主線，搬到番外篇（`EXT-01`）

## 0. 結論

1. 主線開場改成：**主角失憶醒來**，穿古裝，張口就是流利古語（自己都嚇一跳），被一位老驛卒撿到。
2. **不改現有開場步驟順序與必要點擊數**，只改每一幕的包裝與文案。唯一新增：出身選擇多 1 次點擊（`ORG-01`）。
3. 開場信保留使用者親手原稿，包裝成「主角懷裡掉出的一封信，寫給失憶前的自己」。
4. 內心 OS（主角心聲）從這一刻開始成立：古人講古話，主角心裡用白話吐槽。**不是武將講現代話**。
5. 第一個記憶碎片就在開場裡拿（舊信），讓玩家一開始就知道「這遊戲要慢慢想起來」。

## 2. 醒來（新增畫面，約 15 秒，可略過）

| 項目 | 內容 |
|---|---|
| 畫面 | 黑場淡入，驛站柴房的屋頂，模糊轉清楚 |
| 被誰撿到 | **依出身不同**（11/27 深夜裁決），一律是**無名 NPC**（不是名將，避免跟宿命轉蛋抽到的人打架，不佔名冊）：士族子弟→家僕、遊俠→同伴、醫者→師父、商人→商隊老闆；預留出身另定。因為出身是醒來後才選，所以順序改成：先醒來（撿到的人尚未定）→ 選出身 → 撿到者以出身身分現身並接台詞。下文台詞中的「老驛卒」以對應 NPC 代入（`pickerNpcByOrigin`） |
| 第一句古語（主角脫口而出） | 「在下……何處？有勞老丈。」 |
| 內心 OS | 「欸？我怎麼會講這種話。這張嘴比我還懂。」 |
| 老驛卒 | 「客官醒了？前夜暈倒在驛道旁，是老朽把你扛進來的。」 |
| 主角內心 OS | 「我是誰？我叫……算了，先別想。」 |
| 失憶說明 | 主角記不起自己的名字與來歷，只有「身體記得古語」。名字由玩家取（沿用現有取名流程） |
| 偽裝 | 主角穿的是古裝（不是現代衣服），外表融入；這一幕只用台詞暗示「我其實不是這裡的人」 |

## 3. 開場信（原稿一字不動，只改包裝）

- 使用者原稿（`正式版劇本文案.md`、`NewPlayerOpening.ts` 的 `INTRO_PANELS`）保持不改。
- 包裝：老驛卒遞上一封折得皺皺的信，說「你昏倒時懷裡掉的」。主角打開讀：信裡寫的是主角看得懂又看不懂的怪話（三國舊作、頭盔、遺憾可改寫）。
- 內心 OS 在信的前後各一句：「這字我都認得，湊在一起就不懂了。」「寫信的人好像很了解我……又不像我。」
- 信的說法解釋成「失憶前的自己寄給未來的自己」，**不需要頭盔、AI、天命之人這些舊設定**。信裡「頭盔」是第一個謎，記憶線慢慢回收。
- 老驛卒看不懂字，只說「怪裡怪氣的字，收好便是」。**古人不深究、不起疑**。
- 第一個記憶碎片（#1「舊信」）在關閉信時給。

## 4. 六名將亮相的包裝

- 六位名將（張飛、孫策、甘寧、夏侯惇、魏延、張郃）照舊，古文介紹照舊。
- 武將介紹後面那句白話吐槽（`doc_spec_1344`）：**定位改為主角內心 OS**，顯示在畫面下方「心聲框」（小字、斜體、帶頭像小圖示），不是武將開口。
- 例（張飛）：古文「吾乃燕人張翼德……」→ 主角心聲「這音量，隔壁村都聽得到。」
- 武將台詞本身全是古代口吻（對齊 SLIP-01：預設古代，現代是破綻）。

## 5. 宿命轉蛋的古風包裝

- 機制完全不動（無限重置十連、鎖定一位核心）。
- 說法改成「問天籤筒」：老驛卒說「驛站旁有座老廟，求籤最靈」，轉蛋盤在畫面上是一個大籤筒。
- 十連叫「連抽十支籤」，抽中名將叫「籤上寫著某某」。重複叫「再籤」。
- 這是包裝，要不要用待使用者裁決（Q-AMN-1）。

## 6. 首戰教學的包裝

- 現有首戰教學（五路對撞）不改。
- 包裝：驛站遭山賊襲擾，名將與少年一起守驛站。勝利後老驛卒說「這驛站保住了」。
- 戰鬥結算後閃回（碎片 #2）：主角腦中閃過一個陌生畫面（白色房間一角），一秒就過。主角內心 OS：「剛剛……是什麼？」
- 戰場相關不動，交戰場專家。

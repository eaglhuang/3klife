# 3KLife 奇襲烏巢式糧倉重地放火焚糧與全軍斷炊雪崩狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 戰役後勤戰略打擊之焚糧與士氣雪崩系統（`ARSON-DEPOT-01`）。重現官渡之戰曹操親率步騎夜襲烏巢、焚毀袁紹大軍百萬斛糧草之戰局逆轉大捷。規範戰役中後方核心糧倉地格之防禦脆弱性、火攻焚糧蔓延速率、以及前線十萬大軍一旦斷炊所引發之士氣雪崩與將領倒戈連鎖反應。

## 4. 火勢蔓延、斷糧衝擊與倒戈公式

### 4.1 奇襲縱火成功率與糧草損毀速度
夜襲部隊投擲火油攻擊乾草糧垛：
$$\Delta \text{GrainBurnRatePerTurn} = \left(0.35 + \frac{\text{ArsonFireStrength}}{200}\right) \times \left(1.0 - \frac{\text{WaterSupply}}{100}\right)$$
- 守糧官醉酒弛懈（$\text{SoberRating} \le 30$），縱火首回合直接燒毀 $50\%$ 糧草；
- 連續燃燒 2 回合未被撲滅，糧倉判定為 `BURNT_TO_ASH`，糧草全損。

### 4.2 前線軍心雪崩與大將倒戈率
前線主力部隊得知糧倉化為灰燼後：
$$\Delta \text{FrontlineMorale} = -60 - \text{GrainLostPercent} \times 0.3$$
- 前線各軍團每回合產生 $25\%$ 潰兵逃亡；
- 若前線大將義理值 $\le 65$ 且受到君主猜忌（如袁紹疑張郃），倒戈率直接攀升：
$$P_{\text{defection}} = \left(0.50 + \frac{\text{SuspicionIndex}}{100}\right) \times \left(1.0 - \frac{\text{GeneralLoyalty}}{150}\right)$$
- 倒戈將領率本部兵馬直接倒戈易幟，反戈一擊直撲原主軍中軍。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-DEPOT-01**：在暴雨或大雪天候，縱火命令失效，火勢自動熄滅，糧草損毀不超過 $10\%$。
2. **驗收 CASE-DEPOT-02**：當糧倉全毀且前線軍隊攜帶隨身乾糧 $\le 1$ 日，部隊防禦力下降 $50\%$、攻擊力下降 $40\%$，且所有戰法無法發動。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

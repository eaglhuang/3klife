# 女性武將品質分級來源標記與受孕率修正模型規格書

## 1. 模組職責與架構定位
本規格書規範女性武將的「品質分級（`QualityGrade`）」、「五大歷史與遊戲來源標記（`FemaleSourceType`）」，以及結緣受孕率的「多重來源與年齡衰退修正演算法」。本模組隸屬 `BreedingService` 與 `FemaleSystemState`，為純邏輯運算層，不包含任何外部 UI 渲染。

```
┌─────────────────────────────────────────────────────────────┐
│                      BreedingService                        │
│  ┌──────────────────────┐        ┌───────────────────────┐  │
│  │ Base Conception Rate │  ───>  │  Female Source & Age  │  │
│  └──────────────────────┘        └───────────┬───────────┘  │
└──────────────────────────────────────────────┼──────────────┘
                                               ▼
                         ┌─────────────────────────────────────────┐
                         │   Conception Modifiers Calculation      │
                         │   (QualityMod × AgeMod × ItemMod)       │
                         │   Cap: min(0.95, Result)                │
                         └─────────────────────────────────────────┘
```

## 2. 品質分級與來源標記資料結構

```typescript
export type QualityGrade = 'SSR' | 'SR' | 'R' | 'N';

export type FemaleSourceType =
  | 'GACHA'            // 轉蛋女將卡池（天降奇女子）
  | 'CIVILIAN_RESCUE'  // 地下城或鄉野救美（民間女）
  | 'PRISONER_OF_WAR'  // 破城戰場俘虜歸降
  | 'MERCENARY'        // 酒館傭兵結義
  | 'LINEAGE_DAUGHTER';// 家族自繁後代子嗣女兒

export interface FemaleProfile {
  femaleId: string;
  name: string;
  age: number;
  qualityGrade: QualityGrade;
  sourceType: FemaleSourceType;
  baseConceptionModifier: number; // 基礎倍率，預設 1.0
}
```

## 3. 受孕率多重修正演算法

### 3.1 來源品質係數（QualityModifier）
不同來源與品質之母體具備先天受孕倍率差異：
- **SSR 名女將（如貂蟬、大喬、甄姬等）**：$1.20\times$。
- **SR / R 女將**：$1.00\times$。
- **民間救美民女（CIVILIAN_RESCUE）**：$0.80\times$。
- **後代及笄子嗣（LINEAGE_DAUGHTER）**：$1.10\times$。

### 3.2 年齡衰退修正（AgeModifier）
女性生育機率隨年齡呈分段階梯式遞減，避免高齡無限制生育：
- **16 ~ 35 歲（黃金生育期）**：$1.00\times$。
- **36 ~ 40 歲（熟齡期）**：$0.85\times$。
- **41 ~ 48 歲（高齡期）**：$0.70\times$。
- **49 歲以上（晚期臨界）**：$0.20\times$。

### 3.3 道具增益與全域保底封頂
- **安胎藥（TocolyticMedicine）**：使用後當次結緣獲得額外 $1.50\times$ 受孕倍率。
- **封頂保護**：無論疊加後之數值多高，最終結算受孕率上限嚴格封頂於 **0.95（95%）**，保留 5% 確定性天意未中機率：
$$\text{FinalRate} = \min\left(0.95, \text{BaseRate} \times \text{QualityMod} \times \text{AgeMod} \times \text{ItemMod}\right)$$

```typescript
export function computeConceptionRate(
  baseRate: number,
  profile: FemaleProfile,
  hasMedicine: boolean
): number {
  let qualityMod = 1.0;
  if (profile.qualityGrade === 'SSR') qualityMod = 1.20;
  else if (profile.sourceType === 'CIVILIAN_RESCUE') qualityMod = 0.80;
  else if (profile.sourceType === 'LINEAGE_DAUGHTER') qualityMod = 1.10;

  let ageMod = 1.0;
  if (profile.age > 48) ageMod = 0.20;
  else if (profile.age > 40) ageMod = 0.70;
  else if (profile.age > 35) ageMod = 0.85;

  const itemMod = hasMedicine ? 1.50 : 1.0;
  const rawRate = baseRate * qualityMod * ageMod * itemMod;
  return Number(Math.min(0.95, Math.max(0.01, rawRate)).toFixed(4));
}
```

## 4. 單元測試驗證規範
1. **TC-FEM-01（SSR 與安胎藥封頂 0.95 檢驗）**：基準受孕率 0.70，SSR（1.2）搭配安胎藥（1.5），理論值為 $0.70 \times 1.2 \times 1.5 = 1.26$，受上限約束強制回傳 0.95。
2. **TC-FEM-02（42 歲高齡衰退檢驗）**：基準受孕率 0.50，年齡 42 歲，品質 R（1.0），無藥品，回傳 $0.50 \times 0.70 = 0.35$。
3. **TC-FEM-03（民女來源折減檢驗）**：基準受孕率 0.50，民間救美來源（0.80），25 歲，回傳 $0.50 \times 0.80 = 0.40$。

# 好友教官每日借用快照與戰場戰法來源轉換規格書

## 1. 模組職責與架構定位
本規格書規範社交與學府培育的跨界連動：「好友教官每日借用狀態機（`NpcFriendMentor`）」以及培育戰法在戰鬥實戰中的「戰場戰法來源轉換適配器（`MentorTacticAdapter`）」。模組確保玩家能善用盟友或 NPC 好友教官資產，並在戰場上精確辨識 Mentor 來源戰法特權。

```
┌─────────────────────────────────────────────────────────────┐
│               Friend Mentor & Battle Adapter                │
├──────────────────────────────┬──────────────────────────────┤
│ Daily Friend Mentor Borrow   │ Mentor Tactic Battle Adapter │
│ (每日 1 次 / 快照複製 / +50)  │ (SkillSourceType.Mentor 轉換)│
└──────────────────────────────┴──────────────────────────────┘
```

## 2. 好友教官每日借用狀態機

### 2.1 每日借用配額與快照複製
- **每日限用 1 張**：玩家每日伺服器換日（00:00:00）刷新借用配額，一次培育會話最多容納 1 張借用教官卡。
- **快照隔離（Snapshot Isolation）**：借用瞬間讀取好友教官當前星等與數值，複製為本地獨立快照，好友本人的卡片不受鎖定或任何影響。
- **結義點數回饋（Friendship Reward）**：借用成功時，系統自動向出借好友發放 **50 點結義點數（`FriendshipPoints`）**，可在點數商店兌換社交道具。

```typescript
export interface FriendMentorBorrow {
  success: boolean;
  borrowedCardSnapshot: MentorCardRecord | null;
  friendRewardPoints: number; // 50
  errorCode?: 'DAILY_LIMIT_REACHED' | 'FRIEND_NOT_FOUND' | 'CARD_UNAVAILABLE';
}

export function executeFriendMentorBorrow(
  dailyBorrowedCount: number,
  friendCard: MentorCardRecord | null
): FriendMentorBorrow {
  if (dailyBorrowedCount >= 1) {
    return { success: false, borrowedCardSnapshot: null, friendRewardPoints: 0, errorCode: 'DAILY_LIMIT_REACHED' };
  }
  if (!friendCard) {
    return { success: false, borrowedCardSnapshot: null, friendRewardPoints: 0, errorCode: 'CARD_UNAVAILABLE' };
  }

  const snapshot: MentorCardRecord = { ...friendCard, source: 'MERCENARY_SWEAR' };
  return {
    success: true,
    borrowedCardSnapshot: snapshot,
    friendRewardPoints: 50
  };
}
```

## 3. 戰場端 Mentor 戰法來源轉換

### 3.1 來源標記列舉與適配
武將進入戰場執行出征（`SortieDeploy`）時，系統將其已覺醒之戰法槽位包裝為戰鬥技能請求，並標記精確的技能來源類型：
```typescript
export enum SkillSourceType {
  Innate = 'INNATE',     // 史實自帶
  Mentor = 'MENTOR',     // 學府教官傳授
  Scroll = 'SCROLL',     // 戰法秘笈習得
  Heritage = 'HERITAGE'  // 家族血脈繼承
}

export interface BattleSkillInstance {
  tacticId: string;
  sourceType: SkillSourceType;
  mentorId?: string;
  damageMultiplier: number;
}
```

### 3.2 Mentor 戰法專屬加護
凡標記為 `SkillSourceType.Mentor` 之戰法，在實戰結算時享有師門榮耀加護：
$$\text{DamageMultiplier} = 1.0 + 0.10 = 1.10\times$$
釋放該戰法時造成的傷害提升 **$10\%$**，若為輔助或治療戰法則其效果增強 $10\%$。

```typescript
export function adaptMentorTactic(tacticId: string, isFromMentor: boolean, mentorId?: string): BattleSkillInstance {
  if (isFromMentor) {
    return {
      tacticId,
      sourceType: SkillSourceType.Mentor,
      mentorId,
      damageMultiplier: 1.10
    };
  }
  return {
    tacticId,
    sourceType: SkillSourceType.Innate,
    damageMultiplier: 1.00
  };
}
```

## 4. 單元測試驗證規範
1. **TC-BORROW-01（每日 1 次配額攔截）**：當日已借用 1 次，再次嘗試借用回傳 `DAILY_LIMIT_REACHED`。
2. **TC-BORROW-02（結義點數正確回饋）**：初次借用成功回傳 `friendRewardPoints = 50`，且快照具備完整屬性。
3. **TC-ADAPT-01（Mentor 來源 1.10 倍傷害加成）**：經 `adaptMentorTactic` 轉換為 Mentor 來源之技能，其 `damageMultiplier` 恆為 1.10。

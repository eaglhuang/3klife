## 7. 產出、稀有度、與因子印記互動

### 7.1 職業屬性如何取得與累積

- 歷練中隨格子與事件累加到 `careerAttr`，每條路單獨計；一趟歷練只走一條路，其他路只有副屬性的少量點數。
- 歷練結束寫入子嗣資料，永久保存（成長履歷顯示），15 歲入學時一次轉成起始加成（第 8 章）。
- 職業屬性只屬於該子嗣，不遺傳、不進 14 人祖譜，不影響子代。

### 7.2 稀有度

| 對象 | 檔位 | 備註 |
| --- | --- | --- |
| 屬性格 | 凡、良、精、絕（4 檔） | 影響點數 |
| 寶物 | 稀有度 1~4（凡、良、精、珍） | 對應 ItemDef.rarity；寶物歸「寶物」分類，進寶物圖鑑（doc_spec_0433），圖鑑顯示來源「十歲歷練」 |
| 路線稱號 | 評級絕才有 | 例：「後山小虎」「市井領袖」「神童」「小太傅」 |

### 7.3 與因子、印記的互動：避免重複計算

| 規則 | 內容 |
| --- | --- |
| R1 不新增因子 | 歷練不新增因子、不改因子星等、不直接給生平白因子印記 |
| R2 印記不改 | 印記種類由學府決定（潁川學者…），機率由結業評級與共鳴決定；歷練不加印記機率，避免與印記系統重疊計算。歷練評級只顯示在成長履歷與稱號 |
| R3 因子引只加權 | 出生禮的「因子引」與歷練寶物的因子傾向只在覺醒擲點上加權（旗標 `awakenBias`），與教官突破星、幸運加速併入同一個乘區並受既有「每回合最多覺醒 1 個」限制；學府引擎目前沒有窺探覺醒（見學府介紹第 8.3 節），因此第一版只存旗標，不消耗 |
| R4 來源標籤去重 | 所有前期加成依來源標籤（`grasp`、`envItem`、`birthGift`、`trial`、`ancestor`）記錄；同一來源對同一五維只計一次 |
| R5 前期加成總上限 | 對單一五維的「入學前起始加成」合計上限（+20 點）；抓周與環境道具是開獎時的百分比，歷練與出生禮是入學時的定值，形式不同不相疊 |
| R6 學戰法折扣 | 學戰法折扣上限 60% 不變（綠因子與印記），歷練不加入 |
| R7 寶物不加戰鬥數值 | 綁定寶物只提供成長與學府用途（入學時由「信物槽」兌現，第 7.4 節），不進戰場裝備槽、不加戰場數值，避免干擾戰場平衡 |
| R8 歲月成長點 | 第 16.5 節的歲月成長點（`growth` 來源標籤）在入學時轉成起始五維，併入 R5 的單項 +20 上限；與抓周、環境道具、出生禮、歷練各自獨立計算，不重複 |

### 7.4 寶物、道具與信物槽清單（定案）

**信物槽**：每個孩子有 1 個「信物槽」。歷練結算時玩家從已得寶物中選 1 件放入（預設放最高稀有度），入學建立快照時兌現該寶物的效果（只兌現 1 件）。其餘寶物仍綁定該孩子，進寶物圖鑑，結業後一併轉為武將紀念欄的收藏。效果量依稀有度：凡總計 +2、良 +4、精 +6、珍 +10（分給兩條屬性），精以上另有附加效果。效果與第 7.3 節 R5 上限（單項 +20）合併計算。

## 16. 分齡加速成長（下）：特殊食物、廚師接口、10 歲起派內政、歲月補償

### 16.1 5~15 歲：特殊食物

沿用第 15.1 節原則：食物也是「只讓這個孩子的年紀長得比較快」，其他人不受影響。

| 年齡 | 手段 | 食物效果 |
| --- | --- | --- |
| 0~5 歲 | 母乳、乳母、藥水（第 15 章） | 不可吃特殊食物（嬰幼兒） |
| 5~10 歲 | 特殊食物、藥水 | 食物效果 ×1.0 |
| 10~15 歲 | 特殊食物、藥水（只剩這兩種） | 食物效果 ×0.6（骨架已成，補品見效較慢）；被派內政時再 ×0.5（第 16.4 節） |

規則：吃下後該孩子在 4 季內每季額外歲數 = 食物數值；同一孩子同時只生效 1 份（吃第二份時取數值較高者、不疊加、不延長）；每季開始時可吃，吃下先扣庫存；所有手段加總後每季總額外上限 +0.5（第 15.1 節）。

### 16.3 廚師與家族酒店接口（預留，第一版只留資料欄位與介面）

家族酒店與廚師、做菜的完整規格由另一位企劃在「幕府家業規格書」（PROG-2-9199）撰寫；**本規格只固定食物資料欄位與接口，兩份規格交叉引用**（9199 合併後在兩邊補上 doc_id 與連結）。

| 項目 | 定案 |
| --- | --- |
| 供應者類型 | `market`（市集）、`quest`（任務）、`chance`（機緣）、`chef`（廚師）、`familyHotel`（家族酒店）。第一版實作前三種；後兩種標 `reserved: true` |
| 廚師由誰擔任 | 預留 `chefId`：任一在朝人物，具有新專長標籤 `cuisine`（廚藝，0~20；與孩子的 8 種專長不同）；由幕府家業規格決定廚師如何培養、任命與解鎖 |
| 解鎖 | 膳房或家族酒店建成（由 9199 規格定義建築與等級）；供應者等級 `level` 決定可做食物的上限：良 1 級、精 2 級、絕 3 級 |
| 品質 | 供應者等級高於食物需求時，該食物數值 +0.01／級（上限 +0.03）；寫在食物實例 `qualityBonus` |
| 介面 | `IChildFoodProvider.listAvailable(ctx) → FoodStock[]`；`IChildFoodProvider.produce(recipeId, supplierId, qty) → FoodItem[]`；`ctx = { clanId, childId, season }` |
| 食物實例 | `{ foodId, tier, boost, durationSeasons, compRate, madeBy: { supplierType, supplierId, level }, qualityBonus }` |
| 家族酒店產出 | 以「每季自動產出 N 份」或「點名製作」兩種方式提供，由 9199 決定；本規格只要求產出的食物實例符合上面格式，進入既有 ItemDef「消耗品」分類 |
| 不實作的部分 | 廚師培養、酒店經營、食材市場、料理小遊戲都不在本卡範圍 |

### 16.4 10 歲起可派內政，以及與成長的取捨

修訂 doc_spec_1172 第二章第 2 節：原「5~14 歲低效內政實習」改為「**10 歲起**可派內政實習」。5~9 歲孩子在家玩耍與讀書，不可派（過小）。

| 項目 | 規則（定案） |
| --- | --- |
| 資格 | 年齡 ≥ 10 歲（實齡）、已完成歷練或歷練可延後但不在進行中；15 歲入學時自動撤回 |
| 崗位 | 農耕、商業（沿用 1172 與 doc_spec_0638） |
| 產出 | 該崗位 50%（低效內政） |
| 經驗 | 每季 30% 機率使對應屬性經驗 +5（沿用 1172） |
| 對成長的取捨 | 孩子「忙於公務」：食物的催長效果 ×0.5（藥水不受影響）；不派則食物全效 |
| 與補償 | 派內政不影響歲月補償（第 16.5 節）；派內政的 10~14 歲年份，生日事件照常（完整或簡版依催長占比） |
| 玩家選擇 | 「派去幫忙拿產出與經驗」或「專心長大、用食物加速」；兩者不能兼顧全效。委託方針（第 14.4 節）可設定「孩子不派內政」 |
| 與歷練 | 歷練期間不可派；歷練不擋派遣，也不擋入學（Q4=A） |

### 16.5 歲月補償：加速 ≈ 不吃虧，但不比慢養更賺

道理：孩子慢慢長大，每年都在累積歷練數值（見聞、體魄、人情）；若加速長大卻沒有補償，就少了那幾年，玩家吃虧。反過來補償若與慢養一樣，加速就是白賺。

**歲月成長點（YP）**：孩子 0~15 歲每經過 1 年資歷（基礎流速下每季 +0.25）累積 1.0 點（`naturalPointsPerYear = 1.0`）。慢養滿 15 年 = 15 點。入學建立學府快照時，一次轉成起始五維加成：1 點 = +1 五維點，平均分給抓周志向的兩條主五維（小木劍 STR／LEA、小竹簡 INT／POL、青玉珮 CHA／LUK），每項取整，來源標籤 `growth`，併入第 7.3 節 R5 的「前期加成總上限（單項 +20）」，不與歷練（`trial`）、出生禮（`birthGift`）重複計算。

**補償公式（定案）**：每季累積 `YP = 0.25 + Σ(各手段額外歲數 × 該手段補償率)`。補償率全部小於 1，因此催長的孩子每「歲」得到的 YP 少於慢養：

| 手段（單獨使用） | 額外歲數／季 | 每長 1 歲得到的 YP | 與慢養相比 |
| --- | --- | --- | --- |
| 慢養（基礎） | 0 | 1.00 | 基準 |
| 乳母／名門乳母 | 0.12／0.20 | 0.84／0.82 | −16%／−18% |
| 食物 凡／良／精／絕 | 0.08／0.12／0.18／0.25 | 0.88／0.87／0.87／0.90 | −12%～−10% |
| 時光藥水 | 0.25 | 0.80 | −20% |
| 母乳 | 0.25 | 0.85 | −15% |
| 母乳 + 藥水（滿上限） | 0.50 | 0.77 | −23% |

換成「每跳過 1 年補多少」：補償率就是每跳過的 1 年補回的 YP：母乳 0.7、藥水 0.6、乳母 0.5／0.6、食物 0.5／0.6／0.7／0.8。範例：孩子 0~5 歲全程母乳，約少 0.75 點、5 歲時比慢養少 4.25 對 5.0；全程積極催長到 15 歲，總 YP 約 11.5~13.5，慢養 15，差約 1.5~3.5 點、分到兩條主五維約各差 1~2 點，是「加速的代價」而不是「大虧」。

**慢養保留的專屬收益**（加速時拿不到或打折，兩種玩法各有理由）：

| 項目 | 慢養 | 催長 |
| --- | --- | --- |
| 完整生日事件 | 有選項、加親子好感、記性格標籤 | 該年催長占比（`boostShare`）≥ 50% 時只有簡版：沒有選項、不加好感、不記標籤 |
| 親子好感 `bond` | 每個完整生日 +2，另每自然年 +2；入學時 `bond ≥ 16` 解鎖學府「家書」事件選項（`TRIAL_FAMILY_LETTER`，第 8.4 節） | 簡版年份不加；通常湊不到 16 |
| 心願貼合度 | 性格標籤使心願更貼合（每標籤 +5，上限 +15，第 5.4 節） | 標籤少，心願多由抓周與出生禮決定 |
| 歲月補償 | 100% | 74%～90% |
| 成本 | 無 | 母乳的母親代價、食物與乳母金錢、藥水限量 |

催長的好處是時間：15 歲入學從約 3 小時（一般節奏）縮到約 1.6 小時（第 3.5 節）。

**套用範圍**：母乳、乳母、時光藥水、食物**全部套用同一套補償**，只是補償率不同（母乳因母親代價重，補償率 0.7；藥水因限量且無其他代價，0.6；食物依等階 0.5～0.8；乳母 0.5～0.6）。

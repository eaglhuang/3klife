# 子嗣及笄十四歲職能分流狀態機與女官教官儲備規格書

## 1. 模組職責與架構定位
本規格書規範宗族子嗣中女性後代年滿 14 歲時的「及笄禮分流狀態機（`DaughterComingOfAge`）」演算法與業務流程。該模組負責評估子嗣之資質五維、遺傳因子與門閥需求，提供三條不可逆的生涯發展路線，並將結果原子寫入存檔狀態。

## 2. 三通道職能門檻與評估邏輯

```typescript
export type DaughterBranchChoice = 'COMBAT_GENERAL' | 'COURT_OFFICER' | 'MENTOR_RESERVE';

export interface DaughterStatsSnapshot {
  daughterId: string;
  name: string;
  age: number;
  war: number;
  ldr: number;
  int: number;
  pol: number;
  cha: number;
  hasTeachingGene: boolean; // 是否持有綠色「傳道」或「授業」因子
  hasProcessedComingOfAge: boolean;
}

export interface BranchEligibility {
  canBeCombat: boolean;
  canBeCourt: boolean;
  canBeMentor: boolean;
  recommendedBranch: DaughterBranchChoice;
}
```

### 2.1 門檻判定準則
- **前線征戰名將（`COMBAT_GENERAL`）**：
  $$\text{war} \ge 65 \quad \lor \quad \text{ldr} \ge 65$$
  核准後解鎖兵種編制與裝備穿戴權，直接登錄於武將名冊。
- **府邸內政女官（`COURT_OFFICER`）**：
  $$\text{pol} \ge 65 \quad \lor \quad \text{cha} \ge 65$$
  核准後進駐家族府邸，獲得季度產出加乘與商業交涉特權。
- **宗族教官儲備（`MENTOR_RESERVE`）**：
  $$\text{int} \ge 65 \quad \lor \quad \text{hasTeachingGene} = \text{true}$$
  核准後移轉為教官卡資產，可用於指派培育學府下代子嗣。

### 2.2 推薦首選演算法
若滿足多重條件，系統依據「最高分維度」自動推薦最佳分支：
$$\text{MaxCombat} = \max(\text{war}, \text{ldr})$$
$$\text{MaxCourt} = \max(\text{pol}, \text{cha})$$
$$\text{MaxMentor} = \text{int} + (\text{hasTeachingGene} ? 20 : 0)$$

```typescript
export function evaluateDaughterBranches(stats: DaughterStatsSnapshot): BranchEligibility {
  const canBeCombat = stats.war >= 65 || stats.ldr >= 65;
  const canBeCourt = stats.pol >= 65 || stats.cha >= 65;
  const canBeMentor = stats.int >= 65 || stats.hasTeachingGene;

  const combatScore = Math.max(stats.war, stats.ldr);
  const courtScore = Math.max(stats.pol, stats.cha);
  const mentorScore = stats.int + (stats.hasTeachingGene ? 20 : 0);

  let recommendedBranch: DaughterBranchChoice = 'COURT_OFFICER'; // 保底首選
  if (combatScore >= courtScore && combatScore >= mentorScore && canBeCombat) {
    recommendedBranch = 'COMBAT_GENERAL';
  } else if (mentorScore >= combatScore && mentorScore >= courtScore && canBeMentor) {
    recommendedBranch = 'MENTOR_RESERVE';
  }

  return { canBeCombat, canBeCourt, canBeMentor, recommendedBranch };
}
```

## 3. 狀態機與存檔防呆規範
1. **年齡精確鎖定**：僅在 `age === 14` 且 `hasProcessedComingOfAge === false` 時允許執行狀態轉移。
2. **單向終身定型**：玩家或 AI 選擇分支後，將 `hasProcessedComingOfAge` 標記為 `true`，永久鎖定不可逆回滾。
3. **低維保底保護**：若五維均未達 65 且無特質，系統強制賦予 `COURT_OFFICER` 保底，避免角色無職能死鎖。

## 4. 單元測試驗證規範
1. **TC-AGE-01（武勇少女首推前線）**：女兒武力 80、其餘 50，`evaluateDaughterBranches` 回傳 `canBeCombat = true`，首推 `COMBAT_GENERAL`。
2. **TC-AGE-02（傳道特質優先教官）**：女兒智力 60 但持有 `hasTeachingGene = true`，`canBeMentor = true` 且獲得加分首推。
3. **TC-AGE-03（重複分流阻斷）**：若 `hasProcessedComingOfAge === true`，再次發起及笄請求時立即拋出 `ALREADY_PROCESSED` 錯誤中斷。

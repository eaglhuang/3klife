# 子嗣家傳奧義覺醒與因子機率規格書

> **文件狀態**：單一真相來源（Single Source of Truth）  
> **系統代碼**：`ULT-15`、`SYS-CHILD-ULTIMATE-AWAKEN`  
> **核心職責**：確立子嗣在培育期（書院學習、家族傳道）中覺醒雙親家傳奧義之觸發機率公式、綠色因子加成機制、繼承元數據標記與戰鬥釋放特性。

---

## 1. 核心傳承機制原則

1. **隔代基因與血脈共鳴**：
   - 子嗣不自動無條件繼承雙親之全量奧義，而是必須於培育期歷經「頓悟事件」或「弱冠禮考評」時進行覺醒判定。
2. **綠色因子（氣運特質）直接加權**：
   - 武將配戴或遺傳之綠色特質因子（如「靈光乍現」、「天縱奇才」）直接線性擴大覺醒機率。
3. **單一來源追溯（Provenance Tracking）**：
   - 覺醒之家傳奧義必須於存檔與戰鬥實體中明確標記 `Source_Parent_UID` 與 `Inherited_Gen`，作為譜牒圖鑑與先祖召喚演出的資料憑證。

---

## 2. 覺醒機率公式與參數標準

### 2.1 覺醒判定公式
在培育期指定考評回合（如第 12 回合期中、第 24 回合弱冠），系統依下列公式計算判定機率 $P_{\text{awaken}}$：
$$P_{\text{awaken}} = \min(0.80, \; P_{\text{base}} + L_{\text{green}} \times 0.05 + B_{\text{affinity}})$$

- **基礎覺醒率**：$P_{\text{base}} = 0.05$（5% 保底機率）
- **綠色因子等級加成**：$L_{\text{green}} \times 0.05$
  - 綠色因子 Lv.1：$+5\%$
  - 綠色因子 Lv.3：$+15\%$
  - 綠色因子 Lv.5（滿級）：$+25\%$
- **雙親親密度加成**：$B_{\text{affinity}}$
  - 親密度 $\ge 80$ 時：$+0.10$（+10%）
  - 親密度 $< 80$ 時：$+0.00$
- **機率硬上限**：單次判定上限為 $80\%$。

## 3. 資料結構契約與持久化標識

```typescript
export interface InheritedUltimateRecord {
  ultimateId: string;
  isInherited: true;
  sourceParentUid: string;
  inheritedGen: number;       // 距初祖世代差（如 1 代表嫡子，2 代表孫輩）
  vitalityCostDiscount: number; // 家傳奧義精力折扣，固定為 0.20 (扣減 20%)
}

export interface ChildAwakenContext {
  childUid: string;
  parentUid: string;
  parentUltimateId: string;
  greenGeneLevel: number;
  parentAffinity: number;
  randomRoll: number;         // 由確定性亂數產生器（PRNG）提供 [0, 1)
}

export function evaluateUltimateAwakening(ctx: ChildAwakenContext): InheritedUltimateRecord | null {
  const baseRate = 0.05;
  const geneBonus = ctx.greenGeneLevel * 0.05;
  const affinityBonus = ctx.parentAffinity >= 80 ? 0.10 : 0.0;
  const finalProbability = Math.min(0.80, baseRate + geneBonus + affinityBonus);

  if (ctx.randomRoll < finalProbability) {
    return {
      ultimateId: ctx.parentUltimateId,
      isInherited: true,
      sourceParentUid: ctx.parentUid,
      inheritedGen: 1,
      vitalityCostDiscount: 0.20
    };
  }
  return null;
}
```

## 4. 戰鬥演出與驗收標準（Acceptance Criteria）

1. **先祖虛影護持演出**：
   - 釋放帶有 `isInherited: true` 標籤之奧義時，戰鬥鏡頭於武將背後浮現先祖之半透明立繪虛影。
2. **確定性回放保障**：
   - 判定亂數必須消費入學初始種子之 PRNG 序列，禁止使用非受控之 `Math.random()`。
3. **單元測試涵蓋**：
   - 包含滿級綠色因子必出（受上限截斷）、親密度未達門檻無加成、及繼承資料完整性驗證。

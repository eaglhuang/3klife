# 子嗣滿5歲自動開獎五維揭曉與武官文官推薦演算法規格書

> 標籤：`BRD-07` · `M3` · `子嗣育成` · `開獎演算法` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，子嗣年滿 5 歲（`UNVEILING_AGE = 5`）自神祕期（`Mystery`）步入開獎（`Unveiled`）之確定性揭曉流程與宿命職能推薦演算法。

開獎階段為純資料狀態推導，完全無亂數介入，不依賴 Cocos 引擎介面節點，確保所有客端與存檔重放的一致性。

---

## 2. 開獎觸發資格檢查（Invariants）

每季季度時鐘推進時，系統遍歷子嗣名冊，僅對滿足以下條件之個體觸發開獎：

```typescript
export const UNVEILING_AGE = 5;
export const GENERAL_STATUS_UNVEILED = 'Unveiled';

export function isUnveilingDue(general: UnveilingGeneral): boolean {
    if ((general.status ?? '').toLowerCase() === GENERAL_STATUS_DEAD) return false;
    if (general.status !== CHILD_STATUS_MYSTERY) return false;
    return typeof general.age === 'number' && general.age >= UNVEILING_AGE;
}
```

1. **存活校驗**：已身故（`status == 'dead'`）之子嗣不觸發開獎。
2. **神祕期狀態**：子嗣狀態必須為 `CHILD_STATUS_MYSTERY`（`'Mystery'`）。若已開獎則直接略過。
3. **年齡門檻**：年齡數值必須大於或等於 5 歲。

---

## 3. 開獎資料揭曉與標記清理

當子嗣滿足開獎條件時，執行原子態資料轉移：

### 3.1 狀態與標記更替
- `status` 由 `'Mystery'` 轉移為 `GENERAL_STATUS_UNVEILED`（`'Unveiled'`）。
- 從 `hiddenFlags` 陣列中移除 `'mystery-phase'` 標籤。
- 記錄開獎時之遊戲季度序號 `unveiledSeason`。

### 3.2 六維資質精確揭曉（Exact Revelation）
遍歷 `['str', 'int', 'lea', 'pol', 'cha', 'luk']`，將雙層屬性中的模糊遮罩解除：
- `revelationLevel` 強制寫入為 `'EXACT'`。
- `base` 與 `current` 屬性數值對玩家介面完全公開可視。

### 3.3 初始遺傳因子灰鎖解鎖（Level $\le$ 1）
子嗣繼承之因子池中，僅解鎖初階因子，進階因子保持灰鎖：
- 因子之 `discoveryLevel <= 1`（藍色屬性因子、粉色特質因子）：解鎖（`isLocked: false`），並發出解鎖通知。
- 因子之 `discoveryLevel > 1`（綠色戰法因子、紫色名號因子）：維持鎖定（`isLocked: true`），待入學培育或實戰覺醒事件方可解鎖。

---

## 4. 武官／文官宿命職能推薦演算法

系統依據子嗣之基因傾向與五維數值，自動推導最佳職能推薦（`recommendFate`）：

```
                    ┌─────────────────────────┐
                    │ 統計偏武與偏文因子星等和 │
                    └────────────┬────────────┘
                                 │
                     [martialScore != civilScore]
                     ├── 是 ──> martialScore > civilScore ? 'Warrior' : 'Scholar'
                     └── 否 (打平)
                                 │
                    ┌────────────┴────────────┐
                    │ 比較五維: (武+統) vs (智+政) │
                    └────────────┬────────────┘
                                 │
                     [(武+統) != (智+政)]
                     ├── 是 ──> (武+統) > (智+政) ? 'Warrior' : 'Scholar'
                     └── 否 (仍打平) ──> 終極分支: 'Scholar' (文官)
```

### 4.1 因子偏向分類表

| 偏向類別 | 因子 Category / Tags | 權重計算 |
|---|---|---|
| **偏武 (Martial)** | `attribute`, `leadership`, `weapon-proficiency`, `aptitude`, `mobility`, `terrain` | 累加 `gene.level`（星等） |
| **偏文 (Civil)** | `governance`，或 `tactic-seed` 標籤含 `politics`, `scheme`, `resource`, `stability` | 累加 `gene.level`（星等） |
| **中立 (Neutral)** | 人格特質、天命奇觀等無法歸類者 | 略過（不計入職能推薦） |

### 4.2 打平退化決策
1. **因子優先**：若武系總星等與文系總星等分出勝負，即以較高者為推薦（`source = 'factors'`）。
2. **五維第二層比對**：若因子星等完全打平，比對基礎五維（`source = 'stats'`）：
   $$\text{MartialStats} = \text{str} + \text{lea}$$
   $$\text{CivilStats} = \text{int} + \text{pol}$$
3. **終極歸屬**：若五維數值仍完全相等，系統依規格預設分流至文官（`'Scholar'`），保障演算法確定性。

## 5. 批次名冊開獎介面契約

名冊中所有到期子嗣由 `unveilDueGenerals` 批次執行，並產出事件佇列：

```typescript
export interface UnveilingEvent {
    generalId: string;
    recommendation: FateRecommendation;
    unlockedFactorIds: string[];
    season?: number;
}
```

UI 層監聽 `UnveilingEvent`，觸發五維數值揭曉動畫、因子解鎖特效，並彈出「宿命分流抉擇視窗」。

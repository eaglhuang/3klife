# 子嗣生成五維遺傳公式與0歲神祕期資料結構規格書

> **模組識別碼**：`BRD-04`  
> **系統歸屬**：血統家族培育（Breeding）子嗣生成中樞  
> **單一真相來源**：本規格書確立父母屬性均值與實際 EP 乘積之五維基礎遺傳公式、遺產加成補正、0 歲神祕期（Mystery）資料模型與祖譜繼承之唯一權威標準。

---

## 一、系統概述與架構原則

結緣成功並經過 4 季待產後，系統透過確定性純函式生成 0 歲新生子嗣。子嗣基礎能力奠定於雙親之平均五維與血統爆發潛力值（EP），並在 0~4 歲期間處於「神祕期（Mystery Phase）」，隱藏精確數值與高階因子，營造期待感。

### Unity / 架構對照
- **工廠模式生成**：類似 Unity 中的 `ChildGenerationFactory` 靜態工廠，輸入雙親資料與隨機種子，產出不可變的新武將資料物件。
- **神祕期遮罩**：介面層依據 `status === 'Mystery'` 自動套用問號遮罩，不暴露內部實際儲存的數值。

---

## 二、五維基礎屬性遺傳演算法

子嗣的各項基礎能力（武力、智力、統率、政治、魅力）依父母雙親平均值與實際 EP 比例計算：

$$\text{BaseStat} = \max\left(1, \left\lfloor \frac{\text{Stat}_{\text{father}} + \text{Stat}_{\text{mother}}}{2} \times \frac{\text{EP}_{\text{actual}}}{100} + 0.5 \right\rfloor\right)$$

```typescript
export function childBaseStat(fatherStat: number, motherStat: number, ep: number): number {
    return Math.max(1, Math.round(((fatherStat + motherStat) / 2) * (ep / 100)));
}
```

### 遺產加成與幸運值封頂
1. **世代遺產加成（Legacy EP Bonus）**：
   除幸運（`luk`）外，武智統政魅五維在 `childBaseStat` 基礎上，額外套用父母世代累積之遺產浮動加成：
   $$\text{FinalStat} = \text{applyEpBonus}(\text{BaseStat}, \text{Bonus})$$
2. **幸運值紫因子天花板（LUK Cap）**：
   子嗣幸運值受限於自身繼承之紫色天命因子上限：
   $$\text{LUK}_{\text{child}} = \min\left(\text{BaseLUK}, \text{lukMaxForGenes}(\text{genes})\right)$$

## 三、0 歲神祕期子嗣資料結構

```typescript
export const CHILD_STATUS_MYSTERY = 'Mystery';

export interface CreateChildInput {
    id: string;
    father: BreedingGeneral;
    mother: BreedingGeneral;
    ep: { ep: number; rating: string };
    factors: InheritedFactor[];
    pedigree: Pedigree;
    random: () => number;
    dictionary?: FactorDictionary;
    diversity?: number;
}
```

### 子嗣初始屬性契約
- **性別**：以注入之 `random() < 0.5` 判定為男性或女性（各 50% 機率）。
- **年齡**：初始為 0 歲（`age = 0`）。
- **狀態**：初始標記為神祕期（`status = CHILD_STATUS_MYSTERY`）。
- **血量與精力**：
  $$\text{MaxVitality} = \left\lfloor \frac{\text{MaxVigor}_{\text{father}} + \text{MaxVigor}_{\text{mother}}}{2} \times (\text{近親時 } 0.70 \text{ 否則 } 1.0) \right\rfloor$$
  $$\text{HP} = \max\left(1, \left\lfloor \frac{\text{HP}_{\text{father}} + \text{HP}_{\text{mother}}}{2} \times \frac{\text{EP}}{100} \right\rfloor\right)$$
- **隱藏標籤**：寫入 `hiddenFlags: ['mystery-phase']`（若為近親則追加 `'inbreeding-penalty'`）。

## 四、祖譜與血統 ID 繼承

子嗣的血統標識符與祖譜繼承遵循父系宗法：
1. **血脈 ID**：`child.bloodlineId = father.bloodlineId`。
2. **14 人祖譜鏈**：
   - 父位（F）與母位（M）分別指向雙親 ID。
   - 其餘 12 個祖先槽位由父方與母方的祖譜往上平移一代填入。

## 五、驗收條件與測試案例 (Test Cases)

- **TC-BRD-13（標準五維遺傳倍率）**：
  - 父親武力 80、母親武力 60（平均 70），EP 為 120，子嗣基礎武力精確為 $70 \times 1.2 = 84$。
- **TC-BRD-14（保底非零約束）**：
  - 父母屬性極低且 EP 只有 10，計算結果下限保底為 1，嚴禁為 0 或負數。
- **TC-BRD-15（0 歲神祕期標籤驗證）**：
  - 剛生成之子嗣其 `age` 為 0，`status` 必定為 `'Mystery'`，`hiddenFlags` 包含 `'mystery-phase'`。
- **TC-BRD-16（性別等機率分布）**：
  - 注入隨機值 0.49 產出男嗣；注入隨機值 0.51 產出女嗣。

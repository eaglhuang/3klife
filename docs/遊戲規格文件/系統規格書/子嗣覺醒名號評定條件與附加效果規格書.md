# 子嗣覺醒名號評定條件與附加效果規格書

> 標籤：`BLT-08` · `M3` · `覺醒名號` · `天才評定` · `血統特性` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，子嗣於學府育成 36 回合結業時，針對突破極限之卓越個體觸發之「天才評定（`isAwakeningGenius`）」及四大「覺醒名號（Awakening Title）」順序匹配演算法（`evaluateAwakeningTitle`）。

本模組為純邏輯無副作用運算，輸入結業數據與祖譜矩陣，輸出名號字串與附加特權效果代碼。

---

## 2. 天才資格兩段式前置審查（Invariants）

子嗣必須在結業時滿足以下三項條件之**任一項**，方可獲准晉升為「天才」資質：

```typescript
export const AWAKENING_GENIUS_TOTAL = 460;
export const AWAKENING_GENIUS_EP = 95;
export const AWAKENING_GENIUS_TAG_RUN = 5;

export function isAwakeningGenius(input: AwakeningTitleInput): boolean {
    const total = Object.values(input.graduationStats ?? {}).reduce((sum, v) => sum + (v ?? 0), 0);
    if (input.graduationRank === 'S' && total >= AWAKENING_GENIUS_TOTAL) return true;
    if (input.ep >= AWAKENING_GENIUS_EP) return true;
    const maxRun = Math.max(0, ...Object.values(input.ancestorTagCounts ?? {}));
    return maxRun >= AWAKENING_GENIUS_TAG_RUN;
}
```

### 2.1 天才三通道審查表

| 通道類別 | 判定門檻 | 設計意圖 |
|---|---|---|
| **後天修為極致** | 結業評級為 `S`，且五維基礎值總和 $\ge 460$ 點 | 獎勵玩家極致育成操作與全能培育 |
| **先天血統天命** | 血統潛力值 $\text{EP} \ge 95$ 點 | 獎勵多代純化、外婚與高幸運天命 |
| **家族門風共鳴** | 14 人祖譜中同一標籤出現次數 $\ge 5$ 位祖先 | 獎勵專精家族傳承與滿連鎖共鳴 |

- 若三者皆未滿足，子嗣直接判定為常態名將，不賦予任何名號（`isGenius: false`）。

## 3. 四大覺醒名號順序匹配模型

晉升為天才之子嗣，依固定優先順序逐一檢驗四項專屬名號規則，取**第一個命中者**生效：

```typescript
export type AwakeningTitleName = '常山真龍' | '麒麟' | '虎膽龍威' | '鬼才後裔';
```

### 3.1 規則對照與附加效果表

| 順位 | 覺醒名號 | 命中條件 | 附加效果代碼 (`effectId`) | 特權效果說明 |
|:---:|:---:|---|---|---|
| **1** | **常山真龍** | 14 位祖先全部帶有騎兵標籤（`cavalry`，滿貫） | `cavalry-aptitude-s` | 騎兵兵種適性永久鎖定為最高 S 級 |
| **2** | **麒麟** | 總血統潛力值 $\text{EP} \ge 98$ | `training-x1.1` | 學府訓練與歷練經驗值全域 $+10\%$ |
| **3** | **虎膽龍威** | 結業武力數值 $\text{str} \ge 90$ | `duel-burst-plus-10` | 戰場單挑爆發率與會心一擊率 $+10\%$ |
| **4** | **鬼才後裔** | 結業智力數值 $\text{int} \ge 80$ | `secret-event-plus-20` | 戰場奇謀密策觸發率 $+20\%$ |

## 4. 特殊分支與資料契約

1. **天才無名號（Fallback）**：若滿足天才條件但未滿足上述四項特殊名號（例如五維總和 465 但武力 88、智力 79），系統回傳：
   ```typescript
   { isGenius: true, title: null, effectId: null }
   ```
   保留天才身分標籤，供後續史實稱號擴充。
2. **名號唯一性**：每位武將終生僅限獲得一個覺醒名號，一經確立寫入存檔永久生效，不隨年齡增長或退役而消失。

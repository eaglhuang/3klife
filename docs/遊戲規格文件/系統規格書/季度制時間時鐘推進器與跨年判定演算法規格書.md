# 季度制時間時鐘推進器與跨年判定演算法規格書

> **模組識別碼**：`TIME-01`  
> **系統歸屬**：遊戲時間總控（GameClock）  
> **單一真相來源**：本規格書確立遊戲最小時間單位（1 季）、四季跨年邊界條件、時鐘資料模型與大廳中文格式化之唯一權威標準。廢棄所有以「天」或「月」為宏觀週期的歷史廢棄草案。

---

## 一、系統概述與架構原則

遊戲時間系統以「季度（Season）」為世界演變之原子時間步進單位。每 4 季為 1 遊戲年（春 1、夏 2、秋 3、冬 4）。時鐘推進器為純邏輯無副作用類別，不依賴每幀 Update 或渲染引擎（Cocos/Unity），完全由上層 `GameSession` 主動驅動推進。

### Unity / 架構對照
- **時鐘核心**：類似 Unity 專案中的 `PureTimeManager`，具備確定性 `AdvanceSeason()` 輸出結算 DTO。
- **無狀態漂移**：時間狀態完全由整數計數驅動，不產生浮點累積誤差。

## 二、時間資料模型與常數定義

```typescript
export const SEASONS_PER_YEAR = 4; // 每年固定 4 季

export type SeasonIndex = 1 | 2 | 3 | 4; // 1: 春, 2: 夏, 3: 秋, 4: 冬

export interface GameTimeState {
    currentYear: number;           // 當前年份（從 1 起算，正整數）
    currentSeason: SeasonIndex;    // 當前季節序號（1~4）
    totalSeasonsElapsed: number;   // 歷史累計推進總季數（從 0 起算）
    currentMode: GameTimeMode;     // 當前季度輪轉模式
}

export interface SeasonAdvanceResult {
    previous: GameTimeState;       // 推進前快照
    current: GameTimeState;        // 推進後新狀態
    yearEnded: boolean;            // 本次推進是否跨年（冬 -> 春）
}
```

## 三、季度推進與跨年演算法

當玩家完成當季主目標並發起「推進下一季」時，時鐘依照以下確定性邏輯流轉：

```typescript
export function advanceGameClock(previous: GameTimeState): SeasonAdvanceResult {
    // 1. 檢驗是否為冬季結算（跨年邊界）
    const yearEnded = previous.currentSeason === SEASONS_PER_YEAR;
    
    // 2. 計算新季節與年份
    const nextSeason = (yearEnded ? 1 : previous.currentSeason + 1) as SeasonIndex;
    const nextYear = yearEnded ? previous.currentYear + 1 : previous.currentYear;
    const nextTotal = previous.totalSeasonsElapsed + 1;
    
    // 3. 推進模式輪轉
    const nextMode = rotateMode(previous.currentMode);

    const current: GameTimeState = {
        currentYear: nextYear,
        currentSeason: nextSeason,
        totalSeasonsElapsed: nextTotal,
        currentMode: nextMode,
    };

    return {
        previous,
        current,
        yearEnded,
    };
}
```

- **年末觸發合約**：唯有 `yearEnded === true` 時，上層系統方可發布年度回顧（`YearReport`）、徵收年稅或發布年度成就。

## 四、格式化與存檔正規化合約

### 1. 介面字串展示
```typescript
export function formatSeasonLabel(state: Pick<GameTimeState, 'currentYear' | 'currentSeason'>): string {
    return `第 ${state.currentYear} 年 ${state.currentSeason} 季`;
}
```

### 2. 存檔合法性校驗與正規化（Normalize）
```typescript
export function normalizeGameTimeState(raw: unknown): GameTimeState {
    if (!raw || typeof raw !== 'object') return createInitialGameTimeState();
    const s = raw as Partial<GameTimeState>;
    const year = typeof s.currentYear === 'number' && s.currentYear >= 1 ? Math.floor(s.currentYear) : 1;
    const season = s.currentSeason === 1 || s.currentSeason === 2 || s.currentSeason === 3 || s.currentSeason === 4
        ? s.currentSeason : 1;
    const total = typeof s.totalSeasonsElapsed === 'number' && s.totalSeasonsElapsed >= 0
        ? Math.floor(s.totalSeasonsElapsed) : 0;
    const mode = s.currentMode && ['Governance', 'Battle', 'Nurture'].includes(s.currentMode)
        ? s.currentMode : GameTimeMode.Governance;
        
    return { currentYear: year, currentSeason: season, totalSeasonsElapsed: total, currentMode: mode };
}
```

## 五、驗收條件與測試案例 (Test Cases)

- **TC-TIME-01（一般季推進）**：
  - 輸入第 1 年 1 季，推進後為第 1 年 2 季，`yearEnded` 為 `false`，總季數為 1。
- **TC-TIME-02（跨年冬轉春）**：
  - 輸入第 1 年 4 季，推進後為第 2 年 1 季，`yearEnded` 為 `true`，總季數為 4。
- **TC-TIME-03（格式化字串對齊）**：
  - 輸入 `{ currentYear: 3, currentSeason: 4 }`，回傳 `'第 3 年 4 季'`。
- **TC-TIME-04（異常存檔安全修復）**：
  - 輸入 `{ currentSeason: 5, currentYear: -2 }`，正規化後安全修正為第 1 年 1 季。

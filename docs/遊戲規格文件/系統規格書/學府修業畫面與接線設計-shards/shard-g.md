## 12. 學府人源缺口方案（PROG-2-9213 追加）

> **【依 2026-11-21 裁決修訂（PROG-2-9224）】Q13 已裁決：學府人源只靠自家子嗣（親生、義子養子、家臣子嗣）。方案 A「少年名將持續來投」未被選用，12.3 方案 A、12.4 比較表中方案 A 的欄位、12.5 建議組合、12.6 暫定時間表、12.7 Q13 推薦項全部作廢，只留作歷史紀錄。方案 B、C 的精神由新規則吸收（家臣子嗣、義子）；方案 D（對外招生）不做。新人源規則、前十幾年的子嗣節奏、空窗處理見第 13 章（shard-h）與《家族子嗣與血統總規格書》。**

> 只寫方案與待決題，不改程式、不開卡。數值（頻率、門檻、名單）屬企劃權限，放 JSON；大方向（用哪一種人源）列為待決題 Q13，推薦項放第一個。

### 12.1 問題

學府主玩法要「新玩家第 2 年就能玩」，但目前只有一位入學者：

| 項目 | 現況 |
| --- | --- |
| 第 2 年第 1 季 | 開局 14 歲投靠少年名將（趙雲、關羽、諸葛亮三選一，PROG-2-9194）滿 15 歲入學，修業 36 回合 |
| 自家首子 | 基礎流速下第 16 年才滿 15 歲；用催長最快第 6 年第 4 季入學（doc_spec_1180 第 3.4 節） |
| 空窗 | 第 3～15 年（催長路線第 3～5 年）學府沒有任何入學者；1180 第 3.6 節的每年約 2 位是第 10 年以後多房穩定期 |
| 成年武將與轉蛋少年 | 沒有入學規格（只有 9166 轉職入口與 0567 二十歲成人禮） |

### 12.2 硬限制（所有方案都不可違反）

1. **時間流速全體一致**：不為學員加速或減速，所有人每季 +0.25 歲。
2. **15 歲入學**：不論人源怎麼來，入學年齡一律 15（doc_spec_1172 的 `ENROLL_AGE`）。
3. **首子由系統安排成婚**：本章不改第 1 年第 1 季的首子流程，也不新增第二位系統配偶。
4. **後期大量出小孩就不用加速**：人源要能在自家子嗣陸續滿 15 歲後自動退場，不得變成與自家子嗣搶入學令的永久來源。
5. 入學令沿用 doc_spec_0557（每季發 1、封頂 3）；潁川同一時間只有一位修業（修業期外界凍結，結業只推 1 季），所以每年入學上限是 4 位，不是瓶頸。

### 12.3 方案

#### 方案 A（推薦）：少年名將持續來投

| 欄位 | 內容 |
| --- | --- |
| 人源怎麼來 | 沿用開局「投靠少年名將」的做法：玩家在名聲或官職階位達門檻後，每隔一段時間觸發「少年來投」事件，一位 14 歲少年名將前來投靠，隔年年初滿 15 歲入學。優先順序：開局沒選的另外兩位少年（例如選趙雲，則關羽、諸葛亮在第 3、4 年先後來投）→ 企劃另列的 12～16 位史實少年名單（例：姜維、陸遜、鄧艾、鍾會、關興、張苞；需對照現有名冊，沒有立繪或資料者進美術與資料待辦，與 9194 少年立繪同批）。自家首子年滿 10 歲、進入歷練期起，來投事件暫停；首子入學後永久停止（自動退場） |
| 和既有裁決怎麼相容 | 時間流速：少年來投時 14 歲，之後正常老化，不加速。15 歲入學：與開局少年同款（第 N 年來投、第 N+1 年入學）。首子系統成婚：不碰。後期大量出小孩：以「自家待入學子嗣」為停止條件，天然不搶。少年名將適用性（1179 第 9 章／1180 第 9 章）：直接沿用，不補歷練、結業還原完整屬性 |
| 對一年循環的影響 | 第 3～6 年每年都有一位入學者（對應第 2～5 年來投），第 7 年起隔年一位；偶數年 8、10、12、14 仍有空窗，由方案 B 疊加補上（見 12.5）。對新玩家：第 2 年之後學府不再是一次性內容。每位少年結業等於入隊一位名將，要在 12.6 的頻率裡控制名將供給量 |
| 用哪套共用框架 | **劇情（STY）**：來投事件與選項（接納、婉拒、延後）；**獎勵（RWD）**：「少年來投池」做成轉蛋系統的一個池（記憶：所有轉蛋都是轉蛋系統的一池，邏輯共用、UI 可依池調整），用確定性亂數與保底（保底：第 N 年必來）；**物品庫存（ITM）**：入學令；**任務（QST）**：`taskKind=academy`；**技能（SKL）**：結業戰法 |
| 風險 | 少年名單要有資料與立繪；來投太頻繁會稀釋名將稀有度。兩者都靠 JSON 頻率與名單控制 |

#### 方案 B：家臣子弟或門生入學

| 欄位 | 內容 |
| --- | --- |
| 人源怎麼來 | 玩家名冊中的家臣（在籍武將）有「子弟」資料：開局起為每位有史實子嗣的家臣建立一位幼子，年齡錯開 5～13 歲，滿 15 歲時發「家臣推薦入學」事件，玩家花入學令讓他入學。另可在官職階位 3（開府）後開放「收門生」：領地人才池每年出現一位 15 歲門生，可推薦入學 |
| 和既有裁決怎麼相容 | 時間流速一致、15 歲入學：天然符合。首子系統成婚：不碰，家臣子弟不是玩家子嗣，不計入首子。後期出小孩：家臣子弟數量固定（有限），不會擴張，不需要加速 |
| 對一年循環的影響 | 第 3～12 年依家臣幼子年齡自然錯開入學，內容穩定；但新玩家的家臣組成靠轉蛋運氣，第 3 年可能剛好沒人。需要「逐將子嗣表」資料（他國逐將名冊另有待辦，可併案）。結業後名將對家臣有好感加成，提供「家臣忠誠」玩法 |
| 用哪套共用框架 | **物品庫存**（入學令）、**任務**（academy）、**劇情**（推薦事件、人才池事件）、**技能** |
| 風險 | 資料工作量最大；玩家陣容差異大，體驗不均。適合當疊加層而非唯一人源 |

#### 方案 C：收養孤兒或遠親子弟

| 欄位 | 內容 |
| --- | --- |
| 人源怎麼來 | 兩個入口：(1)年終守城或戰役勝利後的「戰後遺孤」事件，可收養 8～13 歲孤兒；(2)領地事件「遠親來投」，同姓或同鄉的 8～13 歲少年子弟。收養後進家譜（標記「養子」），滿 15 歲入學 |
| 和既有裁決怎麼相容 | 時間流速一致、15 歲入學：養子照常老化。首子系統成婚：不碰。後期出小孩：收養事件可降頻，且養子需要額外裁決是否進血統系統——**建議暫採「進家譜、標記非血親、不參與血統遺傳」**，避免動到 doc_spec_1180 血統相關裁決 |
| 對一年循環的影響 | 養子要等 2～7 年才能入學，第 3～4 年仍有空窗；情感連結強（從小養大），但與「首子驚喜」定位重疊，且玩家目標是「自己的孩子」。適合作為低頻劇情事件（全局 1～3 次），不適合作為穩定人源 |
| 用哪套共用框架 | **獎勵**（遺孤池、確定性抽選）、**劇情**（收養儀式，`MilestoneFlow` 模板候選）、**任務**（academy）、**物品庫存**（入學令） |
| 風險 | 牽動血統與家譜顯示；養子是否算「後代」要另裁 |

#### 方案 D：學府對外招生

| 欄位 | 內容 |
| --- | --- |
| 人源怎麼來 | 學府每季刷新「招生榜」3 位 15 歲學員（史實少年或民間人才），玩家花入學令加金或名聲招收，立刻入學，沒有等待 |
| 和既有裁決怎麼相容 | 時間流速一致、15 歲入學：符合。首子系統成婚：不碰。後期出小孩：入學令（季發 1、封頂 3）限制每年最多 4 位，但不會自動退場，會和自家子嗣搶入學令，需另設規則 |
| 對一年循環的影響 | 空窗最少、見效最快，第 2 年起每年都能招生。缺點：失去「從小到大」的養成情感；少年名將稀有度被稀釋；功能上等於第二個轉蛋池，依「所有轉蛋都是一池」的定案應走轉蛋系統，而非獨立商店；價格與招生費涉及商業化，需先問 |
| 用哪套共用框架 | **獎勵**（榜單池）＋**物品庫存**（入學令）＋**任務**；若用商店型招生榜則需 **商店（SHP）**，而 SHP 已排在 MVP 之後（doc_spec_1182 第 12 章） |
| 風險 | 稀釋名將、牽涉價格、依賴延後的商店框架。不推薦做主要人源 |

### 12.5 建議組合與分階段

1. **第一批（A3 卡，接 doc_spec_1182 第 12.4 節）做方案 A**：只依賴 STY、RWD、ITM，不等商店，且延續 9194 的少年名將設計意圖。
2. **第二批疊加方案 B**：補偶數年空窗，並與逐將名冊、他國名冊同批。
3. 方案 C 當低頻劇情事件，之後有餘裕再做；方案 D 不推薦。

# 學府培育三十六回合三階段推進與訓練效果公式規格書

> 標籤：`NUR-03` · `NUR-04` · `M3` · `三十六回合` · `階段推進` · `訓練公式` · `單一真相來源`

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，子嗣於學府進行 36 回合育成之「三階段推進狀態機（`phaseOfRound`）」與各科目專注訓練（`executeRound`）之五維屬性增益乘法精算公式。

本模組為純邏輯無副作用運算，每回合依確定性隨機種子消耗序列計算數值，確保各客端與存檔回放一致性。

## 2. 三十六回合三階段階梯推進

36 回合嚴格劃分為三大育成修業階段，基礎點數隨階段逐步遞增：

```typescript
export type PhaseBlock = 'Foundation' | 'Midterm' | 'Sprint';

export const TRAINING_BASE_RANGE: Record<PhaseBlock, readonly [number, number]> = {
    Foundation: [10, 15],  // 啟蒙期 (第 1~12 回合)
    Midterm:    [15, 25],  // 發奮期 (第 13~24 回合)
    Sprint:     [25, 40],  // 衝刺期 (第 25~36 回合)
};

export function phaseOfRound(round: number): PhaseBlock {
    if (round <= 12) return 'Foundation';
    if (round <= 24) return 'Midterm';
    return 'Sprint';
}
```

- **第 12 回合期中考核**：第 12 回合結束觸發期中考評，審視五維成長並指派方針。
- **第 24 回合弱冠之禮**：第 24 回合結束舉行弱冠禮，開放高階戰法領悟三選一。
- **第 36 回合結業大考**：完成全部 36 回合修業，進行最終畢業評級結算。

## 3. 訓練屬性增益乘法精算公式

當玩家選擇進行五維科目訓練（`str`, `int`, `lea`, `pol`, `cha`）且通過精力失敗率判定時，該科目獲得之屬性點數依下式計算：

$$\text{StatGain} = \text{TrainingBase} \times (1 + \text{MentorBonus}) \times (1 + \text{SynergyBonus}) \times \text{BurstMultiplier} \times \text{GrowthModifier}$$

```typescript
export const BASE_TP_PER_TRAINING = 10;
export const MENTOR_BURST_MULTIPLIER = 1.5;
export const SYNERGY_BONUS_PER_EXTRA_MENTOR = 0.1;
```

### 3.1 乘區要素拆解與定義

| 乘區項目 | 數值範圍 | 計算規則與設計意圖 |
|---|:---:|---|
| **$\text{TrainingBase}$** | $10 \sim 40$ | 依當前所屬階段區間，均勻隨機抽取整數點數 |
| **$\text{MentorBonus}$** | $0.0 \sim 1.5$ | 駐守該格之教官加成總和，套用突破星等倍率（`MENTOR_STAR_EFFECT`） |
| **$\text{SynergyBonus}$** | $0.0 \sim 0.5$ | 同格協同加成：該格每多一位駐守教官，獲得 $+10\%$ 額外加成 |
| **$\text{BurstMultiplier}$** | $1.0 \text{ 或 } 1.5$ | 若教官恰好站在其擅長科目格（`specialty`），激發爆發亮彩，乘區 $\times 1.5$ |
| **$\text{GrowthModifier}$** | $0.8 \sim 1.5$ | 子嗣宿命修正：順天 $1.0$、抗命 $0.8$、大器晚成巔峰期 $1.5$ |

## 4. TP 技巧點累積與上限防護

1. **基礎獲取**：每次訓練成功固定產出基礎 10 點技巧點（`BASE_TP_PER_TRAINING = 10`）。
2. **教官技巧加成**：套用教官之 `tpBonus` 百分比放大（例如教官提供 $+20\%$ TP，則獲得 12 TP）。
3. **雙向存檔記帳**：
   - 當前可用技巧點 `tp`：用於學習各階戰法技能（學習扣除）；
   - 歷史累積總點數 `totalTp`：只增不減，作為畢業評級之硬性權重考量。

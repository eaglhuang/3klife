# 學府培育事件系統受傷好感控流與入學令發放規格書

## 1. 模組職責與架構定位
本規格書定義學府培育系統（`NurtureSystem`）中「回合隨機事件分派」、「受傷狀態機與懲罰」、「教官好感與請益事件」，以及經濟層「官學入學令季度控流」的核心邏輯。本模組屬於純邏輯層，不依賴 UI 渲染與第三方狀態，支援確定性亂數種子回放。

```
┌─────────────────────────────────────────────────────────────┐
│                     NurtureRoundExecutor                    │
│  ┌──────────────────────┐        ┌───────────────────────┐  │
│  │  Round Training/Rest │  ───>  │   Roll Nurture Event  │  │
│  └──────────────────────┘        └───────────┬───────────┘  │
└──────────────────────────────────────────────┼──────────────┘
                                               ▼
                         ┌─────────────────────────────────────────┐
                         │          Event Type Dispatcher          │
                         ├────────────────────┬────────────────────┤
                         │ Injury Events      │ Mentor Events      │
                         │ (輕傷 / 重傷)      │ (好感提升 / 傳道請益)│
                         └────────────────────┴────────────────────┘
```

## 2. 培育事件分派狀態機

### 2.1 三階段事件權重表
培育共 36 回合，依階段權重隨機抽選事件類型：
- **啟蒙期（第 1 ~ 12 回合）**：無事件 60%、教官請益 25%、體能鍛鍊 10%、受傷風險 5%。
- **發奮期（第 13 ~ 24 回合）**：無事件 45%、教官請益 30%、頓悟契機 15%、受傷風險 10%。
- **衝刺期（第 25 ~ 36 回合）**：無事件 40%、教官請益 25%、極限突破 20%、受傷風險 15%。

### 2.2 受傷判定與懲罰機制
受傷事件僅在當前回合精力（`vigor < 30`）且執行高強度訓練時觸發：
```typescript
export interface InjuryResult {
  hasInjury: boolean;
  injurySeverity: 'NONE' | 'LIGHT' | 'SEVERE';
  vigorPenaltyRate: number; // 輕傷為 1.5（下回合精力消耗 +50%）
  forceRestRounds: number;  // 重傷為 1（強制休息 1 回合）
}

export function evaluateInjuryRisk(vigor: number, roll: number): InjuryResult {
  if (vigor >= 30) {
    return { hasInjury: false, injurySeverity: 'NONE', vigorPenaltyRate: 1.0, forceRestRounds: 0 };
  }
  // 當精力 < 30 時：roll < 0.15 輕傷，roll < 0.02 重傷
  if (roll < 0.02) {
    return { hasInjury: true, injurySeverity: 'SEVERE', vigorPenaltyRate: 1.0, forceRestRounds: 1 };
  }
  if (roll < 0.15) {
    return { hasInjury: true, injurySeverity: 'LIGHT', vigorPenaltyRate: 1.5, forceRestRounds: 0 };
  }
  return { hasInjury: false, injurySeverity: 'NONE', vigorPenaltyRate: 1.0, forceRestRounds: 0 };
}
```

### 2.3 教官好感與請益事件
當學員與教官位於相同訓練格時，觸發請益事件：
1. **羈絆值增加**：指定教官羈絆值 $+10$ 點。
2. **額外 TP 贈送**：獲得額外戰法點數 $\text{TP} + 15$。
3. **同屬性加成**：若教官擅長領域與當前訓練相同，該回合五維獲得額外 $+20\%$ 結算補正。

## 3. 官學入學令季度控流模型

為確保資源產出受控，入學令採取嚴格的季度發放與倉庫封頂控管：
- **發放頻率**：每年四季（春、夏、秋、冬）初季結算時，宗族自動核發 **1 枚**「官學入學令」。
- **最大庫存上限**：玩家背包最多容納 **3 枚** 入學令。
- **溢出轉化規則**：若領取時庫存已達上限，多餘入學令自動折算為 **5,000 銅錢** 入庫，並記錄轉化事件記錄。

```typescript
export interface AdmissionTokenGrant {
  tokensGranted: number;
  tokensOverflowed: number;
  copperRefund: number;
  newInventoryTotal: number;
}

export function grantQuarterlyAdmissionToken(currentTokens: number): AdmissionTokenGrant {
  const MAX_TOKENS = 3;
  const REFUND_COPPER_PER_TOKEN = 5000;
  if (currentTokens >= MAX_TOKENS) {
    return {
      tokensGranted: 0,
      tokensOverflowed: 1,
      copperRefund: REFUND_COPPER_PER_TOKEN,
      newInventoryTotal: MAX_TOKENS
    };
  }
  return {
    tokensGranted: 1,
    tokensOverflowed: 0,
    copperRefund: 0,
    newInventoryTotal: currentTokens + 1
  };
}
```

## 4. 單元測試驗證規範
1. **TC-NUR-EVT-01（精力充足免受傷保護）**：當精力 $\ge 30$ 時，無論隨機 roll 為何，受傷嚴重度恆為 `NONE`。
2. **TC-NUR-EVT-02（重傷強制休息判定）**：當精力 $< 30$ 且 roll $< 0.02$ 時，回傳 `SEVERE` 且 `forceRestRounds = 1`。
3. **TC-NUR-EVT-03（入學令滿額折抵銅錢）**：庫存為 3 時執行發放，入學令數維持 3，並正確折算獲得 5,000 銅錢。

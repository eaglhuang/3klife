# 學府培育會話資料結構與鏡像快照狀態機規格書

> 標籤：`NUR-01` · `NUR-02` · `M3` · `培育會話` · `鏡像快照` · `教官鎖定` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，子嗣進入學府進行 36 回合育成之「會話資料結構（`NurtureSession`）」、入學「鏡像快照（Snapshot）」生成、6 位教官鎖定與結業本體寫回之狀態機。

本模組為純邏輯無副作用運算，育成期間外界世界時間與武將本體屬性嚴格隔離，結業前任何育成過程數據皆不污染存檔中之武將主檔。

---

## 2. 鏡像快照隔離不變量（Invariants）

當子嗣年滿 5 歲且完成宿命抉擇後，呼叫 `createNurtureSession` 啟動育成，系統執行原子態鏡像隔離：

```typescript
export const NURTURE_TOTAL_ROUNDS = 36;
export const NURTURE_MENTOR_SLOTS = 6;
export const VIGOR_MAX = 100;
```

1. **資質快照（Talent）**：複製子嗣五維基礎值作為不可變鏡像（`talent`），36 回合內嚴禁改動，作為各科目實力成長之天花板依據。
2. **實力累積（Prowess）**：育成期所獲得之所有五維數值增益，皆獨立累積於實力層（`prowess`），實力上限受限於資質折算值（$\text{ProwessCap} = \text{Talent} \times 20$）。
3. **外界時間凍結**：培育會話於獨立沙盒中步進（Round 0~36），外界大地圖沙盤嚴格凍結，待結業時單次結算一季。

## 3. 教官指派與合法性校驗（validateMentors）

入學時鎖定指派之教官群組，嚴格執行防呆校驗：

```typescript
export function validateMentors(mentors: readonly TrainingMentor[]): void {
    if (mentors.length > NURTURE_MENTOR_SLOTS) {
        throw new NurtureError(`教官最多 ${NURTURE_MENTOR_SLOTS} 位，收到 ${mentors.length} 位`);
    }
    const seen = new Set<string>();
    for (const mentor of mentors) {
        if (seen.has(mentor.id)) throw new NurtureError(`教官 ${mentor.id} 重複指派`);
        seen.add(mentor.id);
        if (!(mentor.burstRate >= 0 && mentor.burstRate <= 1)) {
            throw new NurtureError(`教官 ${mentor.id} 的 burstRate 必須在 0~1：${mentor.burstRate}`);
        }
        if (!TRAINING_KINDS.includes(mentor.specialty)) {
            throw new NurtureError(`教官 ${mentor.id} 的擅長科目不合法：${mentor.specialty}`);
        }
    }
}
```

- **槽位上限**：至多鎖定指派 6 位教官（`NURTURE_MENTOR_SLOTS = 6`）。
- **唯一性驗證**：同一位武將/教官卡嚴禁重複指派至多個槽位。
- **擅長科目合法**：擅長科目（`specialty`）必須屬於五維科目之一（`str`, `int`, `lea`, `pol`, `cha`），爆發機率必須介於 $[0, 1]$ 之間。

## 4. 培育會話核心資料模型（NurtureSession）

```typescript
export interface NurtureSession {
    sessionId: string;
    childId: string;
    startSeason: number;
    round: number;                               // 已完成回合 0~36
    vigor: number;                               // 當前精力 0~100
    talent: Record<TrainingKind, number>;        // 鏡像資質層 (不變)
    prowess: Record<TrainingKind, number>;       // 累積實力層
    tp: number;                                  // 當前可用技巧點
    totalTp?: number;                            // 歷史累積獲得 TP
    growthModifier: number;                      // 宿命成長率修正
    mentors: TrainingMentor[];                   // 鎖定之 6 位教官
    mentorSlots: Record<string, TrainingKind>;   // 當前回合教官站位
    negativeFactors: string[];                   // 獲得之負面特質
    log: NurtureRoundLog[];                      // 36 回合歷程記錄
    status: 'active' | 'completed' | 'abandoned';
}
```

- **畢業寫回（`graduate`）**：第 36 回合結束時，將實力層以公式折算合成為最終五維，寫入子嗣本體主檔，翻轉狀態為 `completed`，育成沙盒隨即銷毀。

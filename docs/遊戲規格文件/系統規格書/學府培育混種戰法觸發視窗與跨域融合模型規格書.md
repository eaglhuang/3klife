# 學府培育混種戰法觸發視窗與跨域融合模型規格書

> 標籤：`BLT-09` · `M3` · `學府育成` · `混種戰法` · `跨域融合` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，子嗣於學府 36 回合育成之青年成熟期（第 15~25 回合），依據雙親傳承之異域戰法因子觸發「混種戰法（Hybrid Skill）」領悟之判定模型。

本模組為純邏輯無副作用運算，精確守護確定性隨機種子序列，不在視窗內或未達條件時嚴格阻絕隨機數消耗。

---

## 2. 觸發時間視窗（Hybrid Window）

混種戰法僅在子嗣入學後之技藝融會貫通階段開放判定：

```typescript
export const HYBRID_WINDOW_START_ROUND = 15;
export const HYBRID_WINDOW_END_ROUND = 25;

export function isHybridWindowRound(round: number): boolean {
    return round >= HYBRID_WINDOW_START_ROUND && round <= HYBRID_WINDOW_END_ROUND;
}
```

- **視窗區間**：學府第 15 回合至第 25 回合（共 11 次判定機會）。
- **非視窗保護**：小於 15 回合（基礎奠定）或大於 25 回合（弱冠衝刺），判定機率嚴格歸零。

---

## 3. 雙親跨域戰法來源條件（Domain Divergence）

子嗣能領悟跨界混種戰法之前提，為雙親各自提供不同專業領域之戰法根基：

```typescript
export type HybridSkillSource = { domain: string } | undefined;

export function hybridTriggerChance(
    round: number,
    father: HybridSkillSource,
    mother: HybridSkillSource
): number {
    if (!isHybridWindowRound(round)) return 0;
    if (!father || !mother) return 0;
    if (father.domain === mother.domain) return 0;
    return HYBRID_TRIGGER_BASE_CHANCE;
}
```

### 3.1 來源領域推導規則（hybridSourceFromFactors）
1. **綠色因子篩選**：遍歷武將繼承之因子，僅取用色系為綠色（`color === 'green'`，即 `tactic-seed`）之戰法種子。
2. **最高星優先**：若身上有多個綠色因子，取等級最高者（`level` 最大）；星等相同時取索引較前者。
3. **領域標籤映射**：取因子字典設定中 `defaultTags[0]` 作為該戰法所屬之專業領域（例如騎兵突襲、智謀奇策、水軍破陣）。若無標籤則以因子 ID 兜底。
4. **領域相異約束**：父方領域與母方領域必須嚴格相異（`father.domain !== mother.domain`）。若雙方皆為騎兵戰法，則不屬於混種範疇。

## 4. 判定機率與確定性隨機保護

```typescript
export const HYBRID_TRIGGER_BASE_CHANCE = 0.05; // 基準觸發率: 5%

export function rollHybridTrigger(
    round: number,
    father: HybridSkillSource,
    mother: HybridSkillSource,
    random: RandomSource
): boolean {
    const chance = hybridTriggerChance(round, father, mother);
    if (chance <= 0) return false;
    return random() < chance;
}
```

- **單回合機率**：滿足條件時，每回合擁有 **$5\%$ 機率** 命中。
- **免消耗保護**：當 `chance <= 0` 時，函式立即回傳 `false`，嚴禁調用 `random()`，確保存檔隨機流不因缺少條件而產生位移偏移。
- **觸發後處置**：單次育成中一旦成功觸發一次混種戰法領悟，寫入子嗣戰法槽，後續回合自動閉鎖該事件。

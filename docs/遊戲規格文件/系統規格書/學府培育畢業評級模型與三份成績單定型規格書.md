# 學府培育畢業評級模型與三份成績單定型規格書

> 標籤：`NUR-07` · `NUR-08` · `M3` · `畢業結算` · `評級模型` · `成績單重修` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，子嗣完成 36 回合學府育成後之「畢業評級結算模型（`graduate`）」、畢業生涯標籤推導（`graduationTags`），以及最多保留 3 份成績單、自由重修與自主擇優定型之狀態機（`ReportCardBook`）。

本模組為純邏輯無副作用運算，負責計算結算分數與維護成績單收納盒，數值覆蓋本體與道具扣除由外層事務管理器處理。

---

## 2. 畢業評級換算模型與階梯門檻

結業評級並非單純加總實力層數值，而是將各科實力層折算為 $[0, 100]$ 標準分後進行綜合評價：

$$\text{RatingScore} = \sum_{\text{kind} \in \{\text{str},\text{int},\text{lea},\text{pol},\text{cha}\}} \min\left(100, \left\lfloor \frac{\text{prowess}[\text{kind}]}{2} \right\rfloor \right)$$

```typescript
export const PROWESS_PER_RATING_POINT = 2;
export const RATING_STAT_CAP = 100;
export const RATING_THRESHOLDS = { S: 450, A: 350, B: 250 } as const;
```

### 2.1 評級階梯標準表

| 畢業評級 (`Rating`) | 綜合得分門檻 (`RatingScore`) | 培養水準與評價 |
|:---:|:---:|---|
| **S 級 (卓絕群倫)** | $\ge 450$ 分 | 全能型不世奇才，達到天才覺醒名號前置審查門檻 |
| **A 級 (出類拔萃)** | $350 \sim 449$ 分 | 核心科目極其卓越，國家級棟樑之才 |
| **B 級 (中規中矩)** | $250 \sim 349$ 分 | 具備合格實戰作戰或郡縣治理能力 |
| **C 級 (差強人意)** | $< 250$ 分 | 基礎不牢或遭遇重度受傷，需仰賴後天補救 |

## 3. 畢業生涯標籤推導演算法（graduationTags）

結算時自動依據實力層最高之兩項科目（若同分，按武力、智力、統率、政治、魅力之優先順序），結合宿命職能生成畢業榮譽標籤：

```typescript
const TAG_BY_KIND: Record<TrainingKind, string> = {
    str: '猛將預備',
    lea: '統帥預備',
    int: '謀士預備',
    pol: '內政幹才',
    cha: '魅力人選',
};
```

1. **專長標籤**：挑選實力點數最高的兩項科目，分別映射為專長稱謂（如「猛將預備」、「謀士預備」）。若點數為 0 則不授予。
2. **路線標籤**：依子嗣開獎時所選之宿命路線，追加「武官路線」或「文官路線」。

## 4. 三份成績單收納與重修定型狀態機

為降低玩家隨機性挫敗感，系統提供成績單暫存與重修機制：

```typescript
export const REPORT_CARD_SLOTS = 3;
export const RETAKE_ITEM_COST = 1;
```

```
                   ┌───────────────────────────┐
                   │       學府培育第36回合    │
                   └─────────────┬─────────────┘
                                 │
                   ┌─────────────┴─────────────┐
                   │ keepReportCard (最多3份)   │
                   │ 超過 3 份自動 FIFO 丟棄最舊 │
                   └─────────────┬─────────────┘
                                 │
                     [ 玩家決策: 重修 或 定型? ]
                     ├── 重修 ──> 消耗補腦湯×1, 重新開啟新會話 (保留原成績單)
                     └── 定型 (commitReportCard)
                                 │
                    ┌────────────┴────────────┐
                    │ 擇優選中 1 份成績單     │
                    │ 實力層寫入武將主檔      │
                    │ 其餘成績單銷毀, committed=true│
                    └─────────────────────────┘
```

1. **容量限制（FIFO）**：單一子嗣至多同時保留 3 份成績單。若嘗試存入第 4 份，系統自動丟棄最早產生之第 1 份。
2. **重修無損代價**：重修培育不會清除既有成績單，每次重修僅消耗 1 碗「補腦湯」（`RETAKE_ITEM_COST = 1`）。
3. **終生唯一承諾（Commit）**：玩家確認定型時，選定其中 1 份成績單作為最終武將主檔資料，其餘記錄全數銷毀，標記 `committed = true`，後續永久關閉該子嗣之培育與重修通道。

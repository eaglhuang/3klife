# 學府培育窺探與戰場特定動作因子覺醒機率模型規格書

> 標籤：`FUL-04` · `FUL-05` · `M3` · `M5` · `因子覺醒` · `培育窺探` · `戰場動作` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，武將身上處於灰鎖狀態（`isLocked: true`）之遺傳因子，藉由學府培育日常訓練之「心智窺探（`nurturePeekChance`）」以及戰場實戰中做出「特定戰術動作（`rollBattleAwakening`）」激發碎鎖覺醒（`awakenFactor`）之機率計算模型與候選抽選規則。

本模組為純邏輯無副作用運算，負責計算覺醒命中與標的因子，資料寫入與動畫演出由外層控制項調度。

## 2. 學府培育心智窺探模型（Nurture Peek）

在學府 36 回合育成中，子嗣於每次進行各項專注「訓練」時，皆有機會窺探並覺醒先天鎖定之遺傳因子：

```typescript
export const NURTURE_PEEK_BASE_CHANCE = 0.08;
export const NURTURE_PEEK_RANK_STEP = 0.1;
export const LUK_AWAKENING_SPEED_DIVISOR = 300;

export function nurturePeekChance(mentorRank: number): number {
    const rank = Math.max(0, Math.min(5, Math.floor(Number.isFinite(mentorRank) ? mentorRank : 0)));
    return NURTURE_PEEK_BASE_CHANCE * (1 + rank * NURTURE_PEEK_RANK_STEP);
}

export function awakeningSpeedModifier(luk: number): number {
    const safe = Number.isFinite(luk) ? Math.max(0, luk) : 0;
    return 1 + safe / LUK_AWAKENING_SPEED_DIVISOR;
}

export function nurtureAwakeningChance(mentorRank: number, luk = 0): number {
    return Math.min(1.0, nurturePeekChance(mentorRank) * awakeningSpeedModifier(luk));
}
```

### 2.1 雙重放大乘區
1. **教官星等階梯加成**：基準機率為 $8\%$。本場指派教官之最高突破星等（0~5 星）每星提供 $+10\%$ 乘區加成（5 星教官提升至 $12\%$）。
2. **幸運天資加速修正**：子嗣之幸運值 LUK 提供速度修正（$1 + \frac{\text{LUK}}{300}$）。LUK 達到 90 時，覺醒速度額外獲得 $+30\%$ 加成。
3. **訓練格專屬共鳴**：若教官本人親自駐足於子嗣所選之訓練格上，除一般藍色屬性與粉色適性外，額外開放**綠色戰法**與**白色人格**因子之覺醒候選。

## 3. 戰場實戰特定動作覺醒模型（Battle Awakening）

武將踏上沙場後，生死交鋒之極限動作能劇烈刺激體內潛伏血脈：

```typescript
export const BATTLE_AWAKENING_CHANCE = 0.05;         // 常規結算機率: 5%
export const BATTLE_AWAKENING_SPECIAL_CHANCE = 0.15; // 特定動作機率: 15%
```

### 3.1 戰場兩種觸發強度對照表

| 戰場觸發情境 | 覺醒機率 | 開放候選色系 | 特殊規則說明 |
|---|:---:|---|---|
| **一般戰鬥結算** | $5\%$ | 藍色 (`blue`)、粉色 (`pink`) | 戰役獲勝常態結算，僅限基礎屬性與適性 |
| **達成特定戰術動作** | **$15\%$** | 全色系（藍、粉、綠、白、紫、紅） | 騎兵突進、單挑斬將、智謀伏擊等高光動作觸發 |

### 3.2 動作標籤定向匹配（Action Tag Affinity）
當觸發特定戰術動作時，系統優先檢索標籤吻合之鎖定因子：
- 例如：做出「騎兵大縱深突進」動作時，優先從帶有 `cavalry` 標籤之粉色/綠色因子中隨機抽取。
- 若無相符標籤之因子，退回全體可覺醒候選池均勻抽取。

---

## 4. 確定性與防禦邊界守則

1. **單回合 / 單場上限**：每位武將每回合學府培育或每場戰役結算，至多僅限覺醒 **1 個** 因子。
2. **隨機種子免消耗防護**：若武將身上所有因子皆已覺醒，或當前等級未達任何鎖定因子之發現門檻（`candidates.length === 0`），系統立即回傳 `null`，嚴禁調用 `random()`，確保存檔隨機流絕對純淨。

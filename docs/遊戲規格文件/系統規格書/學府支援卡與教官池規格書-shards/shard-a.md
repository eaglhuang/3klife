## 1. 結論與使用者裁決（2026-11-21 下午，PROG-2-9230）

1. **恢復教官池**，推翻當日早上「不設教官卡」的部分，但不推翻其餘：
   - **教官武將**照舊（doc_spec_1179 第 14 章）：名冊武將經 OCC `mentorAssign` 指派，傳授自己的戰法、建立師徒羈絆，不給屬性加成。
   - **另設支援卡**（本書）：學府修業專用的卡，提供屬性成長、解鎖學府戰法、觸發專屬事件。**不出征、不上戰場。**
2. 支援卡放進**課程槽位**（第 7 章「到場」與第 10 章「師門」）。
3. 卡面三類：**歷史名師名士**、**武將特別版**、**紅顏教官**。三類全放同一個**教官池**；紅顏池（POOL_HEROINE）仍只抽女將本人。
4. 三類都是「教學投影」，**不是本人**，可與武將本人並存（第 21 章）。
5. 重複卡用來**突破**（本書叫「傳承」）；傳承滿了，重複卡轉成「學分」材料。
6. 轉蛋共**四池**：名將、紅顏、宿命、教官（POOL_SUPPORT）。全走獎勵框架 RWD（doc_spec_1186 第 12 章），硬保底加軟保底，公開完整機率表。教官池貨幣（連線券、靈玉）與銀兩**永遠分開**（doc_spec_1247 §2）。
7. 價格與付費不在本書定案，一律標「**待使用者**」。

**PM 授權企劃自決**：稀有度與機率、保底、槽位數、加成幅度、傳承次數、材料轉換、初版 25 張名單。全放 JSON（第 22 章），可調。

**共用框架原則（硬規則）**：本書**不另起一套**。繼承哪個 base、只寫哪些差異，見第 20 章；等級、傳承、材料走物品 ITM，點撥與卡效果走技能 SKL，事件走劇情 STY，抽取與材料轉換走獎勵 RWD。

## 2. 世界觀與定位

**世界觀（全遊戲定調，11/21）**：主角是未來的少年，戴上頭盔進入歷史漩渦，去完成自己的夢想；主角不死也不老。

**支援卡的說法：「頭盔連線」**。頭盔系統把歷史名人的教學資料「連線」進來：名師在夢裡開直播課、發推文、帶健身打卡。卡面叫**連線卡**（正式名稱仍是「支援卡」），名師是「連線中的投影」，不是本人，所以才能和本人並存。UI 小字：「連線中，請勿截圖（他們不想被剪成迷因）」。

| 這本書的用語 | 對應機制 | 一句話 |
| --- | --- | --- |
| 連線卡 | 支援卡 | 頭盔連線來的名師投影 |
| 教官池（UI 副標「連線抽選」） | `POOL_SUPPORT` | 抽名師的池 |
| 師門 | 支援卡牌組 | 把名師拉進同一個群組 |
| 傳承 | 突破 | 重複抽到，名師多傳你一招 |
| 學分 | 溢出材料 | 傳承滿了還抽到，轉成學分 |
| 促膝論道 | 單次修業內羈絆滿 | 聊太嗨，忘記下課 |
| 點撥 | 戰法提示 | 名師嘴上說隨便看看，其實全是重點 |
| 階：初窺、入門、登堂、入室、出師（終於可以出去騙吃騙喝） | 等級分段 | Lv1～9／10～19／20～29／30～39／40+ |

## 3. 文案語氣指南（給所有系統的文案參考）

### 3.1 五條原則

1. **機制嚴謹，包裝輕鬆**：數值與規則按規格走，只有名稱、台詞、事件情境用輕鬆口吻。
2. **現代口語講古代人物**：反差越大越好笑。名師像網紅、教練、評審、主揪、客服。
3. **梗要長壽**：只用不容易過時、不涉政治爭議、不影射真實個人的類型：**網紅業配、直播彈幕、健身打卡、外送、追劇與追更、選秀評審、團購、已讀不回、病假**。不寫時事人物、不寫政黨、不寫真實品牌名、不諷刺族群與性別。
4. **短**：卡片介紹 ≤ 30 字、事件情境 ≤ 30 字、選項 ≤ 10 字；一眼看完。
5. **不悲劇、不說教、不考據**：不寫死亡、不寫遺憾；歷史只當梗的底，不做考據長文。玩家看不懂典故也能笑（梗要放在表面）。

### 3.2 寫法模板

| 步驟 | 做法 | 範例 |
| --- | --- | --- |
| 1 取典故一個特徵 | 這人最有名的一件事 | 司馬徽：什麼都說「好」；推薦臥龍與鳳雛 |
| 2 換成現代身分 | 網紅、教練、評審、主揪 | 「好好先生」→ 好好好大 V，推薦臥龍鳳雛 → 業配推文 |
| 3 情境一句 | 一個畫面、一個反差 | 「他發文推薦臥龍鳳雛，結尾小字：#合作」 |
| 4 選項二選一 | 一個乖、一個皮，各 ≤ 10 字 | 「轉發加愛心」／「檢舉業配」 |
| 5 結果不判對錯 | 兩個選項都有好處（第 8 章） | 穩的給羈絆，皮的給多一點獎勵 |

### 3.3 五個範例事件（可直接當其他系統文案的樣板）

| # | 標題 | 情境 | 選項 | 為什麼成立 |
| --- | --- | --- | --- | --- |
| 1 | 好好好（司馬徽） | 你問課講得如何？他說好。問作業全抄呢？也說好。 | 追問「那零分呢」／開心收下這個好 | 特徵「好好先生」＋口頭禪梗，零時事 |
| 2 | 春秋書衣（關羽·夜讀） | 你偷看他螢幕，書衣下是《我在三國當武聖》。 | 陪他追更／假裝沒看到 | 「夜讀春秋」換成「追更網路小說」，反差大 |
| 3 | 開幕優惠（華佗） | 辦卡就送五禽戲，不運動也要來打卡拍照。 | 乖乖報名／想辦法請假 | 五禽戲換成健身房，打卡文化人人懂 |
| 4 | 選秀評審（蔡文姬） | 她聽你唱第一句就嘆氣：「五音不全，但很有勇氣。」 | 再唱一次／改當伴舞 | 辨琴換成選秀評審；吐槽留有餘地，不羞辱玩家 |
| 5 | 三顧茅廬（諸葛亮） | 你傳了三次訊息，他三次已讀，第四次才回「在忙」。 | 再傳一次／直接去敲門 | 三顧換成已讀不回；通用梗，不影射任何真人 |

**反例**（不要這樣寫）：長篇引經據典；用現任政治人物或具體品牌當梗；用死亡、背叛、戰爭悲劇當笑點；說「歷史上其實是……」的考據註解；嘲笑玩家本人的外貌或能力。

## 4. 卡面三類與資料模型

### 4.1 三類卡

| `kind` | 名稱 | 內容 | 範例 | 張數 |

### 4.2 卡片資料 `support-card.v1`（放 `assets/resources/data/support-cards.json`）

| 欄位 | 型別 | 說明 |
| --- | --- | --- |
| `schema` | `"support-card.v1"` | |
| `cardId` | string | 例：`SUP_SIMA_HUI` |
| `itemId` | string | ITM 的 `ITEM_SUPCARD_<cardId 去掉前綴>` |
| `kind` | `sage`／`general`／`beauty` | 第 4.1 節 |
| `rarity` | `R`／`SR`／`SSR` | 決定初始等級上限（第 5 章） |
| `projectionOf` | `personId`／null | `general`、`beauty` 必填；`sage` 若名冊有同名人物也填（用於第 21 章並存規則） |
| `focus` | `武`／`智`／`統`／`政`／`魅`／`陣`／`醫`／`藝` | 主屬性；`陣` 映射統率、`醫` 映射體力上限（每 +1 屬性＝體力上限 +2）、`藝` 映射魅力 |
| `favoredCourse` | `武`／`文`／`兵法`／`禮樂`／`午睡` | 得意課程；`午睡` 是休息課堂 |
| `school` | `水鏡門下`／`鄭學`／`黃老`／`兵家`／`散修` | 師承（第 11 章）；`散修` 不計入任何師承組合 |
| `role` | `A` 專科／`B` 羈絆／`C` 養生／`D` 點撥 | 決定三個效果欄的種類（第 6 章） |
| `mult` | 數字 | 主欄倍率，0.9～1.1，做同稀有度的差異 |
| `hintTactics` | string[2] | 點撥的學府戰法 id（第 15 章） |
| `events` | string[] | `SUPEVT_<cardId>_1..n`（第 8 章） |
| `nameKey`、`introKey`、`artKey` | i18n | 簡介 ≤ 30 字 |
| `usage` | `"academyOnly"` | 固定值：不出征、不上戰場、不進出征編制 |

卡片**實例**（玩家持有）由 ITM 的 `instanceState` 記：`level`、`exp`、`limitBreak`（傳承 0～4）。持有者是**家庭倉庫**（doc_spec_1184），帳號級卡池取得後進家族倉庫。

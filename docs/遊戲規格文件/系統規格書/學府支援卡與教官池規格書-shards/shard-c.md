# 學府支援卡與教官池規格書（分片索引） — 10–13 師門牌組、師承譜系組合、學府風格加權、結業稱號與學閥

> 這是 `學府支援卡與教官池規格書.md` 的「10–13」分片。

## 10. 師門（牌組）與借用

### 10.1 槽位

| 項目 | 值 | 說明 |
| --- | --- | --- |
| 師門席數 | 6 | 自選 5 席＋**借用 1 席** |
| 同卡重複 | 不可 | 同一張 `cardId` 不可放兩席 |
| 編組時機 | 入學畫面「編師門」，修業開始前鎖定；修業中不可換 | 修業中換卡會破壞羈絆，故鎖定 |
| 預設編組 | 提供 3 組存檔位 | UI 記憶，走存檔 |
| 與教官武將 | 互不占用；教官武將走 OCC（教官槽 3），師門卡不走 OCC | 第 21 章 |

### 10.2 借用席

| 來源 | 規則 | 狀態 |
| --- | --- | --- |
| **系統客座** | 每季輪替 3 張 R／SR（不含 SSR），固定 Lv20、傳承 0；只能借 1 張；修業結束歸還；不占玩家收藏 | 單機版即可做 |
| **好友借用** | 借好友持有的卡（顯示好友的等級與傳承，上限 Lv35）；好友得「師門人氣」小獎勵 | **需網路；待使用者**（第 25 章 Q-S2）；單機版先不做 |

### 10.3 牌組類型（取代速度、耐力那一類分法，改成屬性）

卡的 `focus` 決定牌組類型：

| 類型 | `focus` | 玩法 |
| --- | --- | --- |
| 屬性型 | 武、智、統、政、魅 | 衝單一屬性 |
| 謀略型 | 陣（含 `role=D` 點撥型） | 多學戰法、拿點撥折扣 |
| 技藝型 | 醫、藝 | 體力與壓力管理、羈絆與事件 |

**牌組成型加成**（可疊加，放 `support-deck-rules.json`）：

| 名稱 | 條件 | 效果 |
| --- | --- | --- |
| 專精 | 同一 `focus` ≥ 3 張 | 該屬性對應課堂 `trainBoost` ×1.10；≥ 4 張 ×1.18 |
| 均衡 | 武、智、統、政、魅 中 ≥ 4 種不同 | 入學全屬性 +2（梗：「全能學霸，朋友都很怕」） |
| 技藝班 | 同時含 醫、藝、陣 各 ≥ 1 | 每回合壓力 −2（梗：「下課後的社團活動」） |

## 11. 師承譜系組合

卡的 `school` 決定「同一師門」。同派卡**同時編入師門**達到張數即觸發組合加成（只算在師門內的卡，與羈絆無關）：

| 師承 | 成員（初版） | 2 張 | 3 張 | 4 張以上 |
| --- | --- | --- | --- | --- |
| **水鏡門下** | 司馬徽、龐德公、諸葛亮·草廬、徐庶·單福、黃月英 | 羈絆成長 +10% | 點撥頻率 +8 百分點 | 「好好好」：每回合壓力 −2 |
| **鄭學** | 鄭玄、盧植、馬融、關羽·夜讀、蔡文姬 | 事件加強 +15% | 文課、禮樂課修業 +8% | 「家法」：逃學機率 −5 百分點 |
| **黃老** | 華佗、左慈、管輅、司馬懿·病假中 | 體力消耗 −8% | 午睡回復 +15% | 「無為」：每屆一次，體力補滿 |
| **兵家** | 孫武、孫臏、吳起、周瑜·曲有誤、呂蒙·三日不見、趙雲·全勤獎、孫尚香 | 兵法課修業 +8% | 武＋兵法 組合加成 +5 個百分點 | 「奇正」：促膝同心加成 +10% |
| 散修 | 張飛·畫室、貂蟬、甄宓、祝融夫人 | 無組合 | 無組合 | 無組合 |

**雜學**（博採眾長，梗：「百家飯吃遍了」）：師門內有 ≥ 3 種不同師承（`散修` 不計）時，入學全屬性 +2（與「均衡」不疊加，取較高）。

組合加成都是**加法型百分點**，併入 7.2 節的 `trainBoost` 與既有組合加成區，不另開乘區。

**多卡同時羈絆修業的疊加**：見 7.4 節（促膝同心加算、上限 +100%）。師承組合不影響促膝，只有 4 張的兵家「奇正」會改變促膝加成。

## 12. 學府風格加權

三座學府（潁川、荊州、江東，第 13.5.4 節）對卡的類型各有偏好。符合就得**主場加成**：

| 學府 | 偏好師承 | 偏好主屬性 | 風格一句話 |
| --- | --- | --- | --- |
| 潁川書院 | 鄭學、水鏡門下 | 智、政、魅、藝 | 清談與策論，上課像線上研討會 |
| 荊州學館 | 水鏡門下、黃老 | 智、陣、醫、統 | 隱士論兵，上課像戶外探險 |
| 江東督府 | 兵家、散修 | 武、統、陣 | 水文天時，上課像體能訓練營 |

| 符合條件 | 效果（`styleMul`） |
| --- | --- |
| 師承符合 | `trainBoost` ×1.10、到場權重 ×1.2 |
| 主屬性符合 | `trainBoost` ×1.10、到場權重 ×1.2（與師承符合時各自相乘，權重只乘一次 ×1.2） |
| 兩者皆符合 | `trainBoost` ×1.21 |
| 主場組合 | 同一師承組合在偏好學府達到「3 張」以上，其組合效果 ×1.5（梗：「主場加成，彈幕全是自己人」） |
| 不符合 | 無懲罰（不扣分） |

風格表放 `academy-styles.json` 的 `supportAffinity` 欄；第一批只開潁川，荊州與江東第二批開放（沿用 13.5.4 開放批次）。

## 13. 結業稱號與學閥派系

**師承稱號**（走 RWD `reward.grant` 的 `title`，效果由 SKL `status-effect` 結算，與第 13.7.1 節學府稱號並存，不互斥）：

| 條件（結業時） | 稱號 | 效果 |
| --- | --- | --- |
| 師門內同師承卡 ≥ 3 張且各卡羈絆 ≥ 60 的合計 ≥ 3 | 水鏡門生 | 智力 +1 |
| 鄭學同上 | 鄭門弟子 | 政治 +1 |
| 黃老同上 | 黃老居士（梗：看起來很會養生） | 體力上限 +5 |
| 兵家同上 | 兵家傳人 | 統率 +1 |
| 師承 ≥ 3 種且無任何一派達 3 張 | 百家飯博士（梗：吃遍百家飯） | 全屬性 +1 |

- 同時多派達標：取羈絆合計最高者；平手取符合所畢業學府偏好者。
- 稱號只給 B 評級以上（沿用 13.7.1）。

**接學閥派系**（第 13.7.2 節）：師承稱號額外增加**對應派系影響力 +0.5**：

| 師承 | 派系 |
| --- | --- |
| 水鏡門下、黃老 | 荊襄派 |
| 鄭學 | 潁川派 |
| 兵家 | 江東派 |
| 百家飯 | 不加 |

影響力以 `blocInfluence` 儲存，階段 10／30／60 規則不變；公式只加權，不另開派系。

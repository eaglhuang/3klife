# 學府精力消耗失敗率分段模型與教官同格協同規格書

> 標籤：`NUR-05` · `NUR-06` · `M3` · `精力模型` · `失敗率曲線` · `教官站位` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，子嗣於學府 36 回合育成之「精力值（Vigor）消耗與回復規則」、三段式「訓練失敗率曲線（`failureRateForVigor`）」、失敗負面特質懲罰，以及每回合教官站位與同格協同演算法（`rollMentorSlots`）。

本模組為純邏輯無副作用運算，負責計算每回合精力波動與失敗率門檻，不涉及畫面節點渲染。

---

## 2. 精力邊界、訓練消耗與休息回復

子嗣精力值以整數形式維護於 $[0, 100]$ 封閉區間：

```typescript
export const VIGOR_MAX = 100;
export const TRAINING_VIGOR_COST: readonly [number, number] = [15, 25];
export const REST_VIGOR_RECOVER: readonly [number, number] = [40, 60];
export const RED_VIGOR_RECOVER_PER_LEVEL = 0.1;
```

1. **訓練消耗**：每次執行五維科目訓練，精力隨機扣減 $[15, 25]$ 點（無論訓練成功或失敗皆扣除）。
2. **休息回復**：選擇「休息（`rest`）」動作，精力隨機回復 $[40, 60]$ 點。
3. **紅色體魄因子加速**：子嗣身上已覺醒之紅色因子總等級，每級額外提供 $+10\%$ 回復量加成：
   $$\text{RecoverVigor} = \text{BaseRecover} \times (1 + \text{RedGeneLevel} \times 0.10)$$
4. **上限截斷**：精力回復後絕對封頂為 100 點（`VIGOR_MAX`），不產生溢出積累。

## 3. 三段式訓練失敗率精算模型

訓練失敗率依執行動作當下之精力值（`Vigor`）劃分為三段階梯：

```typescript
export function failureRateForVigor(vigor: number): number {
    if (vigor > 70) return 0;
    if (vigor >= 30) return 0.01 + ((70 - vigor) / 40) * 0.14;
    return 0.2 + ((30 - Math.max(0, vigor)) / 30) * 0.4;
}
```

```
     失敗率
      60% ┼                                                ┌─── (Vigor = 0)
          │                                           . '
      20% ┼                                      . '   (Vigor < 30 危險區: 20%~60%)
      15% ┼                           ┌─────── '
          │                      . '
       1% ┼                 . '   (30 <= Vigor <= 70 過渡區: 1%~15%)
       0% ┼─────────────────┴─────────────────────────────
          0                30                    70       100  精力值 (Vigor)
```

### 3.1 三大區間特性
- **充足安全區（$\text{Vigor} > 70$）**：失敗率嚴格為 **$0\%$**，保證 100% 成功。
- **疲乏過渡區（$30 \le \text{Vigor} \le 70$）**：失敗率由 $1\%$ 線性上升至 $15\%$。
- **枯竭危險區（$\text{Vigor} < 30$）**：失敗率急遽攀升至 $20\% \sim 60\%$（0 精力時達 $60\%$ 封頂）。
- **教官 ★2 特權抵扣**：駐守該科目之教官若解鎖突破 ★2，取最高之「訓練成功率加成」直接抵減失敗率。

## 4. 訓練失敗懲罰與負面特質生成

當隨機擲骰大於成功率時，判定本次訓練失敗：
1. **零增益**：本回合屬性增益與技巧點 TP 歸零，但精力消耗照常扣除。
2. **負面因子抽取**：以 $50\%$ 基準機率（`NEGATIVE_FACTOR_CHANCE = 0.5`）抽取獲得「挫敗」或「厭學」負面因子。
3. **近親劣化加成**：若子嗣具有近親標籤（`negativeTraitRateBonus = 0.5`），負面因子機率提升至 **$100\%$**，必定獲得負面特質。

## 5. 每回合教官站位與同格協同演算法

每回合開始時，系統為鎖定之 6 位教官分配駐守格（`rollMentorSlots`）：

```typescript
export function rollMentorSlots(
    mentors: readonly TrainingMentor[],
    random: RandomSource
): Record<string, TrainingKind> {
    const slots: Record<string, TrainingKind> = {};
    for (const mentor of mentors) {
        if (random() < mentor.burstRate) {
            slots[mentor.id] = mentor.specialty; // 站在擅長科目 (爆發)
        } else {
            const others = TRAINING_KINDS.filter((k) => k !== mentor.specialty);
            slots[mentor.id] = others[Math.floor(random() * others.length)];
        }
    }
    return slots;
}
```

- **同格協同（Synergy）**：玩家選擇某一科目訓練時，若該格聚集了 $N$ 位教官（$N \ge 2$），該科目獲得額外 $(N - 1) \times 10\%$ 屬性乘區加成。

# 3KLife 守城自高擲拋陶罐生石灰細粉隨風迷盲敵目狀態機規格書

## 1. 系統定位與設計意圖

在三國殘酷的要塞守城與關隘抗登城戰役中（如合肥之戰、江陵保衛戰），當敵軍登城雲梯搭上城堞、死士即將翻越垛口時，常規滾木擂石往往因梯根死角無法直接砸中已攀至城頂之敵。本系統規範古代守城特種化學致盲防禦武器「陶罐生石灰粉風向擴散屏障（Lime Powder Jar Blinding Screen）」之居高拋擲、碰撞碎裂、粉塵彌散與眼部灼傷致盲狀態機：
- **薄胎脆陶罐封裝生石灰**：以未經高溫深燒之薄胎泥陶罐，封裝研磨成極細微粒之生石灰（氧化鈣，CaO）與乾花椒辣椒辛辣細粉。
- **居高臨下拋砸與隨風漫散**：自三丈城樓朝雲梯頂端登城敵卒砸落，陶罐觸碰皮甲或梯柱瞬間粉碎，白霧石灰粉塵隨風迅速擴散。
- **遇淚水劇烈放熱致盲**：敵軍眼部與鼻腔吸入石灰粉後，與眼淚汗水接觸瞬間發生水化反應放出高熱，灼痛難耐且短暫失明，被迫自梯端墜落。

## 2. 狀態機架構與轉換生命週期

石灰陶罐防禦狀態機（代碼：`LIME-POWDER-JAR-BLINDING-SCREEN01`）管理自高處拋擲至敵軍致盲失足之完整週期：

```
[ POT_SHELF_STAGING ] (女牆內側堆疊百枚生石灰薄陶罐)
          │
          ▼
[ WIND_VECTOR_READING ] (觀測城頭旗幟判定順逆風向夾角)
          │
          ├── 逆風吹向守軍 ──> [ ABORT_HOLD_THROW ]
          ▼
[ HIGH_ANGLE_DROP_RELEASE ] (自垛口向雲梯先登人群砸下)
          │
          ▼
[ IMPACT_SHATTER_AEROSOL ] (陶罐碎裂白煙石灰粉塵懸浮漫散)
          │
          ├── 敵軍吸入接觸汗淚 ──> [ CHEMICAL_THERMAL_BURN ]
          ▼
[ TEMPORARY_BLINDING_PANIC ] (雙目劇痛灼傷視力喪失失控哀嚎)
          │
          ▼
[ LADDER_FALL_CASUALTY ] (雙手掩目自雲梯失足跌落粉身碎骨)
```

### 狀態細部定義

1. **POT_SHELF_STAGING（整備列置）**：
   - 守軍於每個箭垛平台堆放 10 具生石灰泥罐，每罐重約 5 斤，罐口以蠟封厚桑皮紙扎死防潮。
2. **WIND_VECTOR_READING（風向檢驗）**：
   - 垛口哨長觀察靠旗，若為向外吹拂之順風或側風方准發射；若為強烈逆風則暫停，防止反嗆己陣。
3. **HIGH_ANGLE_DROP_RELEASE（高空砸落）**：
   - 守兵雙手抱罐，自城垛垂直向下砸向梯頂攀登先登敵兵（距離約 5~10 步）。
4. **IMPACT_SHATTER_AEROSOL（撞擊爆粉）**：
   - 陶罐砸中頭盔或木梯脆裂，生石灰粉受撞擊氣流噴射，形成直徑 2 丈之白色懸浮粉塵迷霧屏障。
5. **TEMPORARY_BLINDING_PANIC（灼痛致盲）**：
   - 生石灰微粒進入敵兵眼瞼，遇淚水迅速反應生成氫氧化鈣並放熱高達 80 度，引發強烈刺痛與暫時性全盲，持續 60 秒。
6. **LADDER_FALL_CASUALTY（失足墜梯）**：
   - 先登死士本能鬆手揉眼，重心失控自百尺長梯翻滾墜落，撞翻下方後續攀登部隊，雲梯登城攻勢徹底中斷。

## 3. 關鍵數值與計算判定公式

### 3.1 石灰粉塵覆蓋與致盲機率公式

梯頂敵軍遭受生石灰致盲之概率 $P_{blind}$：
$$P_{blind} = \text{clamp01}\left(\frac{N_{jars} \times C_{dispense} \times (1.0 + V_{wind} \times 0.15)}{D_{distance} \times (1.0 + \text{FacialArmor})} \times 0.85\right)$$
- $N_{jars}$：連續投擲陶罐數量（1~3 罐）。
- $\text{FacialArmor}$：敵軍面甲防護等級（全覆式生鐵面罩可抵禦 60% 粉塵）。
- 輕裝先登部隊（通常不戴全封閉面罩）被致盲率達 92%。

### 3.2 墜梯重創傷害模型

失足墜落造成之跌落物理傷害 $D_{fall}$：
$$D_{fall} = M_{soldier} \times g \times H_{ladder} \times (1.0 - \text{BelowCushion})$$
- 自 8 公尺高城牆失足跌落，衝擊傷害足以直接使先登部隊重傷陣亡，登梯威脅瞬間歸零。

## 4. 戰術連鎖與攻防克制

1. **近身登城絕殺底牌**：在敵軍即將突上城垛的千鈞一髮之際，以極低成本瞬間逆轉局部危機。
2. **天敵與敵方反制**：
   - **濕面巾防護**：老練攻城軍團以醋水浸濕麻布蒙面裹頭，可大幅中和生石灰鹼性灼傷。
   - **逆風自噬風險**：若風向突轉為逆風吹拂，白煙倒灌城樓，守軍自身有 30% 機率遭受致盲減益。

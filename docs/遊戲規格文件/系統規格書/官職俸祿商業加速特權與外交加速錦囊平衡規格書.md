## 1. 系統定位與商業化平衡裁決

本規格確立官職系統商業化特權（月卡加成、假節鉞試用特權）與外交加速錦囊之平衡邊界。
**歷史封鎖裁決（Single Source of Truth）**：
- 堅守「付費不買階位、特權不破壞天下大勢」底線，解鎖過往封鎖之商業化爭議。
- 試用 Buff 僅臨時解鎖功能入口，絕不永久改寫底層正式官階。

```mermaid
flowchart TD
    Player[玩家激活商業特權] --> Choice{特權類別}
    Choice -- 月卡加成 --> ExpBonus[官職任務結算經驗 +15%]
    Choice -- 假節鉞試用券 --> TempBuff[獲得 24 小時高階功能入口]
    Choice -- 外交刷新令 --> ResetCool[重置本季貿易冷卻 (季限 1 次)]
    TempBuff --> CheckExpire{24 小時倒數是否結束?}
    CheckExpire -- 是 --> SafeRevert[平滑回退至正式階位，零殘留]
```

## 3. 假節鉞高階試用狀態機（TrialBuffStateMachine）

```typescript
export interface OfficerTrialBuffState {
  isTrialActive: boolean;
  actualTier: number;         // 玩家正式官階 (例: TIER_2 偏將軍)
  effectiveTier: number;      // 試用虛擬官階 (例: TIER_3 衛將軍)
  expireTimestamp: number;    // 到期時間戳
}

export interface OfficerPermissionSnapshot {
  viewableQuestLevels: number[];
  canInitiateAlliance: boolean;
  canAccessS2Sandbox: boolean;
  isTrialGranted: boolean;
}
```

### 3.1 安全回退機制（Fail-Safe Revert）
1. **權限快照計算**：`OfficerPermissions` 讀取時，若 `isTrialActive && now < expireTimestamp`，以 `effectiveTier` 計算功能許可權。
2. **到期無感回滾**：當計時結束（`now >= expireTimestamp`），權限自動降回 `actualTier`。
3. **進行中任務保護**：若玩家在試用期間已承接高階任務，該任務允許正常結算，但結算後任務牆立即恢復原階限制。

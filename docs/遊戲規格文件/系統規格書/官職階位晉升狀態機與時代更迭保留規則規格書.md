# 官職階位晉升狀態機與時代更迭保留規則規格書

> 標籤：`系統規格` `國家官職` `狀態機` `時代更迭` `OFC-03` `OFC-09`
> 狀態：`正式生效` · 責任模組：`OfficerState` · 參照：`OFC-03` / `OFC-09` / `PROG-2-0826`

---

## 1. 核心定位與設計理念

本規格書定義官職狀態機（`OfficerState`）之資料結構、多階晉升判定及時代更迭時的進度保全規則。
官職系統作為全域權限快照的權威中樞，遵循以下核心鐵律：
1. **只升不降與經驗溢出保留**：玩家官職一旦達成特定階位，絕不因戰敗或處罰倒退；升級後經驗持續累加，不扣減歸零。
2. **連升多階平滑計算**：當單次獲取巨額經驗一口氣跨越多個門檻時，狀態機精準捕捉每一階的晉升事件，確保獎勵完整派發。
3. **解鎖歷史一次性激勵**：每階晉升僅在首次達成時記錄進 `unlockHistory`，防止手滑或重覆領取晉升賞金。
4. **天下大亂資產保全（EraShift Preservation）**：遊戲世界發生劇變、皇帝倒台或勢力洗牌進入新時代時，玩家已獲得的官職階位、經驗總量與歷史解鎖紀錄 100% 保留。

## 2. 官職階位門檻與獎勵配置表

系統共設 5 個官職階位（Tier 1 至 Tier 5），階位 1 為初始狀態：

|:---:|---|:---:|:---:|---|
| **1** | 白身 / 里正 | 0（初始無門檻） | - | 大廳基礎委託、EASY 難度 |
| **2** | 縣丞 / 督郵 | 100 經驗 | 200 黃金 | NORMAL 任務、雙牆第 2 欄位 |
| **3** | 郡守 / 偏將軍 | 260 經驗 | 400 黃金 | ELITE 任務、沙盤 S1 階段、第 3 欄位 |
| **4** | 刺史 / 中郎將 | 520 經驗 | 800 黃金 | HIGH 任務、沙盤 S2 階段、聯盟文書權限 |

## 3. 狀態機核心結構與運作流程

```mermaid
flowchart TD
    GainExp[獲取官職經驗 gain] --> AddExp[累積經驗: officerExp = state.officerExp + gain]
    AddExp --> QueryTier[查表計算對應階位: reached = tierForExp(officerExp)]
    QueryTier --> CheckPromote{reached > currentTier?}
    CheckPromote -->|否| NoChange[無晉升 promotedTiers = []]
    CheckPromote -->|是| MultiCheck[迴圈收集跨越之階位: currentTier+1 .. reached]
    MultiCheck --> MergeHistory[合併至 unlockHistory 並去重排序]
    MergeHistory --> NewState[產出全新不可變 OfficerState]
    NoChange --> NewState
```

### 3.1 狀態物件契約 (TypeScript)
```typescript
export interface OfficerState {
    currentTier: number;    // 目前階位 (1~5)
    officerExp: number;     // 累計官職經驗
    unlockHistory: number[];// 已解鎖過的階位歷史 (唯一、升序)
}

export interface OfficerExpResult {
    state: OfficerState;
    promotedTiers: number[];// 本次觸發晉升之階位清單 (空陣列表示未晉升)
}
```

### 3.2 晉升推進純函式 (`addOfficerExp`)
1. 傳入當前 `state` 與增加經驗 `gain`（防禦性過濾負數與小數）。
2. 計算全新累計值：`officerExp = state.officerExp + Math.max(0, Math.floor(gain))`。
3. 呼叫 `tierForExp` 遍歷門檻表，確認能達到的最高階位 `reached`。
4. 若 `reached > state.currentTier`，收集區間 $[currentTier + 1, reached]$ 內所有階位至 `promotedTiers`。
5. 將新晉升階位與舊有 `unlockHistory` 透過 `Set` 聯集並遞增排序，確保紀錄嚴格遞增且不重複。

## 4. 時代更迭保留鐵律 (EraShift)

三國天下大勢推進至「天下大亂 / 時代更迭（EraReset）」時，世界版圖與 AI 勢力全面重構，但玩家個人政治資本受憲章保護：

```typescript
export function applyEraShiftToOfficerState(state: OfficerState): OfficerState {
    return {
        currentTier: state.currentTier,
        officerExp: state.officerExp,
        unlockHistory: [...state.unlockHistory]
    };
}
```
- **保留內容**：`currentTier`、`officerExp` 與 `unlockHistory` 全量深層複製保留。
- **UI 與系統相容性**：大廳快照 `toOfficerSnapshot` 依然輸出穩定之 `OFFICER_TIER_X`，沙盤已解鎖階段不因時代更迭而關閉。

## 5. 存檔容錯與單元測試契約

1. **讀檔規格化 (`normalizeOfficerState`)**：
   - 遭遇 null、undefined 或非純物件時，安全退回 `initialOfficerState()`。
   - 若存檔中 `currentTier` 與 `officerExp` 不一致（例如經驗足夠但階位未更新），強制取兩者之較大值（`Math.max(savedTier, tierFromExp)`）。
   - 解鎖歷史必包含階位 1，並補齊直至當前階位的所有中間階位。
2. **單元測試斷言**：
   - 初始經驗 0 $\to$ 增加 99 經驗：階位維持 1，`promotedTiers = []`。
   - 接續增加 1 經驗（總 100）：階位晉升為 2，`promotedTiers = [2]`。
   - 單次注入 1000 經驗：直接從 1 連升至 5，`promotedTiers = [2, 3, 4, 5]`，歷史完整記錄。

# 家族子嗣與血統總規格書（分片索引） — 5 繼承、6 主角不死、7 分家與外嫁、8 義子、9 家臣子嗣

> 這是 `家族子嗣與血統總規格書.md` 的「5–9」分片。完整索引見 `docs/遊戲規格文件/系統規格書/家族子嗣與血統總規格書.md`。

## 5. 繼承

### 5.1 三項繼承（裁決 20）

| 項目 | 內容 | 規格來源 |
| --- | --- | --- |
| 屬性潛力 | 子嗣五維潛力由雙親五維、幸運、天命波動決定，0 歲神祕期、5 歲開蒙揭曉 | 沿用「子嗣生成五維遺傳公式」、doc_spec_1172、0531 |
| 血統天賦 | 因子（六色）、家傳奧義、血脈戰法；十四人祖譜與世交合譜 | 沿用 doc_spec_0011、0181~0185、0532 |
| 隨機突變：家門奇才 | 小機率出現潛力或因子超出雙親上限的孩子 | **本文新增**，見 5.2 |

**不納入遺傳**：外貌（立繪、髮色、五官）、個性（性格標籤、語氣）。立繪由美術範本池依性別與年齡階段指派，個性由出生時固定種子抽取，兩者都與雙親無關。

### 5.2 家門奇才（隨機突變）

| 欄位 | 暫定值 | 說明 |
| --- | --- | --- |
| 觸發機率 `geniusChance` | 3% | 每位親生子嗣出生時判定一次，固定種子 |
| 雙親加成 | 雙親任一方 EP ≥ 85 → +1%；兩方都是 → +2%；上限 6% | 好血統更容易出奇才，但不保證 |
| 同血脈劣化 | 近親判定未通過（doc_spec_0532、1090）→ 機率 ×0.5 | 近親既有懲罰之外的額外抑制 |
| 保底 `geniusPityEvery` | 家族累計每 12 位親生子嗣若仍無奇才，下一位必出 | 硬保底，累計計數存家族檔 |
| 效果 | 一項隨機潛力星等 +1（上限 5 星）；加一個家傳奧義候選槽；名號「家門奇才」 | 不改個性與外貌 |
| 顯示 | 5 歲開蒙揭曉時才顯示，之前 0 歲神祕期不洩漏 | 與 doc_spec_1172 揭曉節奏一致 |
| 義子 | 不判定（義子沒有血統遺傳） | 義子潛力由其來源範本決定（第 8 章） |

### 5.3 義子與家臣子嗣的潛力

- 義子：潛力取自來源範本（歷史名將義子用史實屬性 × 年齡係數；劇情來投與招賢館征募的義子用範本池 `adopteeTemplates`，EP 範圍見第 11 章），不判定家門奇才。
- 家臣子嗣：潛力＝其家臣父母五維的 `retainerChildInheritPct`（暫 60%）加隨機，不吃主家血統。

### 5.4 與血統企劃的介面

血統與結緣企劃（Antigravity 線）負責因子與遺傳公式。本文要求其公式提供三個介面，才能讓本總綱成立：
1. `inheritPotential(parentA, parentB, seed)`：回傳五維潛力。
2. `inheritBloodline(parentA, parentB, seed)`：回傳因子與家傳奧義候選。
3. `rollGenius(parentA, parentB, familyState, seed)`：本文新增，回傳是否奇才與加成。

## 6. 主角不死，不做世代交替（裁決 21）

1. 家主（主角）不進壽命結算（`lifespanApplies=false`），年齡欄不顯示死亡預告；劇情可寫「歲月催人」但不終局。
2. 不做「換主角」「繼承人接位」流程；子嗣成年後成為**武將**，服務主公、可任太守、可當教官、可退役，但不接家主位。
3. 更替的是武將：老死、陣亡、退役、被擒由既有規格處理（doc_spec_0310、0482、0498）。
4. 對「血統」的意義：血統樹顯示以**家主為根**的多代家譜，代數不設終點；世代功業傳承（doc_spec_0310）改為「武將世代」概念，不涉及主公換代。
5. 舊規格若有「世代交替」「主公死亡」字樣，由修訂註記標明作廢（見第 12 章清單）。

## 7. 分家與外嫁（裁決 22）

子嗣太多（`crowdThreshold`）或單純想外交、想擴張時的兩條出口。

### 7.1 分家（成為家臣家族）

| 項目 | 規則 |
| --- | --- |
| 資格 | 親生子嗣或義子已成年（20 歲成人禮後）；本人沒有進行中的學府、歷練 |
| 玩家操作 | 在家譜畫面對該成員選「分家」，確認後付一次性銀兩補貼（`branchGrantSilver`，暫 以家業等級計，**價格待使用者**；本文只定欄位） |
| 結果 | 該成員（與其配偶、未成年子女）轉為**家臣家族**：仍是名冊武將；從家譜移到「家臣家」畫面；**之後出生的孩子是家臣子嗣**（第 9 章），不入家譜；血統資料仍保留（因子紀錄不刪），只是不算本家人頭 |
| 世家積分 | 本家人頭分移除；改記「分家」加成一次：`branchPrestige`（暫 +40，一次性，不重複）。不得用「過繼、分家」複製功績（沿用 doc_spec_0183 防刷規定） |
| 好處 | 在養人數下降、解除人丁壓力；分家家主忠誠起始 80；可擔任領地太守的專屬加成（1181 家業） |
| 反悔 | 不可。要回歸只能走「招回」劇情（待之後企劃），本版不做 |

### 7.2 聯姻外嫁（換外交）

| 項目 | 規則 |
| --- | --- |
| 資格 | 子嗣已成年（及笄、冠禮後）；未婚；近親檢查通過（doc_spec_0532） |
| 流程 | 外交事件：選擇對象國與對象人選（他國 AI 名冊，doc_spec_0498）；成婚後離開家譜，家譜保留灰色節點「嫁／娶於 X 國」 |
| 外交效果 | 與該國關係 +`marriageRelation`（暫 +25）；解鎖「姻親」外交選項（求援、借道）；若該國後來與家主開戰，姻親關係下降並觸發劇情 |
| 世家積分 | 沿用 doc_spec_0446（外嫁隨母姓者 120%）；男子入贅外國則以 100% 計 |
| 血統回流 | 外嫁後代是他國血脈，可在 G3 外戚純化（doc_spec_0185）以「表親回流」身分再聯姻 |
| 人數限制 | 同一國同時只能有 `marriagePerNation`（暫 2）位外嫁姻親，避免單點刷關係 |

### 7.3 兩條出口比較

| | 分家 | 外嫁 |
| --- | --- | --- |
| 留在名冊 | 是（家臣） | 否（離開） |
| 換到什麼 | 人丁壓力解除、家臣忠誠、地方戰力 | 外交關係 |
| 可逆 | 否 | 否 |

## 8. 義子（裁決 17，三種來源，不放轉蛋）

義子進家譜，標記「義子」，人頭權重 80%（doc_spec_0446），不參與血統遺傳，15 歲起可入學。

| 來源 | 觸發 | 內容 | 框架 |
| --- | --- | --- | --- |
| 劇情來投 | 戰役或守城勝利後、領地事件、託孤事件 | 8～14 歲少年來投：戰後遺孤、遠親、故人之託；玩家可接納、婉拒、延後；全局次數上限 `adoptStoryMax`（暫 3） | **劇情**：事件卡與選項；**獎勵**：事件池抽選與保底（第 N 年必有一次） |
| 招賢館征募 | 招賢館（`RecruitHallController`）新增「收義子」分頁；每年最多征募 `recruitAdoptPerYear`（暫 1）位 | 招賢館每季刷新 2 位 8～14 歲少年候選（範本池抽選）；花銀兩收為義子（價格待使用者）；固定種子防 SL | **任務**（`taskKind=recruit`）＋**獎勵**（候選池與保底）＋**商店**（銀兩費用，延後項） |
| 歷史名將義子 | 條件：名望階達標，或名冊有其史實義父 | 關平（關羽義子）、劉封（劉備義子）、曹真、何晏、諸葛喬等；以史實屬性與立繪入名冊；名冊內有其義父時，同場出征有「父子同心」加成（比照師徒羈絆，數值第 11 章） | **劇情**：收義子儀式；**獎勵**：給予歷史義子 |

規則：
1. **不放轉蛋**：義子 id 不得出現在任何轉蛋池 JSON；資料載入時檢查，重複則拒絕載入並記錯誤。
2. 年齡：8～14 歲者在 15 歲可入學；15 歲以上的歷史義子（例：劉封）以成年武將入名冊，沒有學府戰法（入學是加分選項）。
3. 義子與開局「14 歲少年名將」的關係：開局少年（趙雲、關羽、諸葛亮，doc_spec_1233 第 2 章）視為「開局義子」的特例，沿用已實作的 9194；Q-F1 已決（11/21）：標記義子（來源 `starter`）、進家譜、可入學府、不遺傳血統，資料模型由 PROG-2-9441（F1）支援。
4. 義子與親生子嗣一視同仁：抓周、歷練、成人禮、分家、外嫁都可用，唯不遺傳血統因子、不判家門奇才。

## 9. 家臣子嗣（裁決 17）

家臣（名冊武將）的孩子。**屬家臣家，不入家譜**。

### 9.1 產生

- 開局名冊武將依 `retainer-children.json`（逐將子嗣表，企劃另列）建立未成年子嗣，年齡錯開 5～14 歲；之後家臣在名冊期間每 `retainerChildEveryQuarters`（暫 12）季有機率再添一子（固定種子，上限每人 3 位）。
- 家臣子嗣不占家主的子嗣名額，不影響人數成本倍率。

### 9.2 入學：玩家出入學令，換取家臣忠誠

| 項目 | 規則 |
| --- | --- |
| 觸發 | 家臣子嗣滿 15 歲，出現「家臣請託入學」事件（劇情框架） |
| 玩家選擇 | 出入學令：消耗 1 枚入學令（物品框架），孩子入學；婉拒：不消耗 |
| 忠誠 | 出令：家臣忠誠 +`loyaltyOnEnroll`（暫 +12）；結業再依評級 +（S +10、A +6、B +3、C +1）；婉拒：−3（可被「撫慰」劇情抵消） |
| 入學令競爭 | 入學令季發 1、封頂 3（doc_spec_0557）；親生與義子優先，家臣子嗣排隊，系統不替玩家決定 |
| 不入學 | 20 歲照樣成年成為武將，屬性較低（第 2.2 節） |

### 9.3 家臣忠誠低時帶孩子離開

| 項目 | 規則 |
| --- | --- |
| 離開風險 | 家臣忠誠 < `leaveLoyalty`（暫 25）時，每季判定離開機率 `leaveChancePerQuarter`（暫 8%，固定種子）；< 10 時 ×2 |
| 預警 | 忠誠 < 40 時家臣詳情出現「心有去意」標籤；< 25 時彈一次劇情挽留（可用銀兩、官職、入學令挽留） |
| 離開 | 家臣與其未成年子嗣一起離開名冊；子嗣已結業者仍隨家臣離開（歸屬跟父母），已成年且已獨立的武將依忠誠自行判定 |
| 不可逆 | 離開後可成為他國武將（他國 AI 名冊 doc_spec_0498），不另做「追回」 |

### 9.4 父母異動

| 狀況 | 孩子歸屬 |
| --- | --- |
| 家臣退役 | 孩子仍屬家臣家，隨父母 |
| 家臣陣亡 | 未成年者轉「遺孤」：可走義子「劇情來投」事件，由玩家決定收為義子（進家譜）或繼續託家臣家 |
| 家臣被擒 | 孩子暫留名冊，不入學；贖回或斬首後依上列處理 |

### 9.5 與分家的關係

分家家臣的後代視同家臣子嗣；他們的忠誠與入學規則完全同第 9.2、9.3 節。

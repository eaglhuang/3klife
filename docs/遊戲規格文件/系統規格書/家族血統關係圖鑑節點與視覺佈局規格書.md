# 家族血統關係圖鑑節點與視覺佈局規格書

> **責任邊界**：本檔為武將人際網絡圖鑑（RelationGraph）、節點圓周佈局演算法與連線視覺樣式的單一真相來源。
> **關聯 WBS**：KIN-07（關係圖鑑 UI 節點+連線）、KIN-02（史實相性）、KIN-06（動態關係）。
> **整併裁決**：確立以武將為中心之 240px 半徑圓周拓撲佈局；定案史實與動態連線的色彩與線型契約。

---

## §1. 中心輻射圓周拓撲演算法 (Radial Graph Layout)

人際網絡圖鑑以單一武將為原點，將所有具備羈絆關係之武將均勻投影於圓周：

```
                    [12點鐘: 史實第 1 節點]
                         /       \
     [10點鐘: 史實節點] /         \ [2點鐘: 史實節點]
                     /             \
       [9點鐘: 動態]───[中心: 本人]───[3點鐘: 動態]
                     \  (R=240px)  /
     [8點鐘: 動態節點] \         / [4點鐘: 動態節點]
                         \       /
                     [6點鐘: 動態節點]
```

1. **中心節點 (Center Node)**：
   - 座標 `(0, 0)`，尺寸 80×80 px，展示當前檢視武將立體金框頭像與姓名稱號。
2. **圓周節點 (Surrounding Nodes)**：
   - 尺寸 56×56 px，固定分佈於半徑 $R = 240\text{ px}$ 圓周上。
   - **排列角計算**：總關係節點數為 $N$ 時，第 $i$ 個節點角度為：
     $$\theta_i = -\frac{\pi}{2} + \frac{2\pi \cdot i}{N} \quad (i = 0, 1, \dots, N-1)$$
   - **排序優先權**：史實關係（夫妻 $\to$ 義兄弟 $\to$ 宿敵）優先排於上方，隨後依動態親密度由高至低順時針排列。

---

## §2. 關係連線視覺樣式契約 (Edge Visual Contract)

連結中心與圓周節點之連線，依據關係類型與有效狀態實施分層渲染：

| 關係分類 | 具體類型 (`RelationType`) | 線型與寬度 | 線條色彩 Token | 中央徽章裝飾 |
|:---|:---|:---:|:---|:---:|
| **史實** | **夫妻** (`SPOUSE`) | 3px 實線 | 玫瑰粉紅 (`#FF69B4`) | 連理同心印 |
| **史實** | **義兄弟** (`SWORN_BROTHER`)| 3px 實線 | 璀璨金黃 (`#FFD700`) | 桃園雙劍印 |
| **史實** | **宿敵** (`ENEMY`) | 2px 鋸齒折線 | 赤黑深紅 (`#8B0000`) | 斷魂裂刃印 |
| **動態** | **戰友** (`COMRADE`) | 2px 虛線 | 晴空天藍 (`#00BFFF`) | 疾風鐵盾印 |
| **動態** | **結緣/結義中** | 2px 虛線 | 翡翠碧綠 (`#2ECC71`) | 同心青竹印 |
| **失效** | **親密度歸零** (`Intimacy=0`)| 1px 點狀虛線 | 黯淡深灰 (`#666666`, Alpha 40%) | 裂隙鎖孔 |

## §3. 互動交互與視角導航規範

1. **單擊節點 (Single Click Peek)**：
   - 於被點擊節點旁彈出 220×140 px 的半透明「情誼簡卡（Relation Peek）」：
   - 顯示：對方武將姓名、當前官職、親密度進度條（如 `85/100`）、共同出征次數與生效中之加成效果。
2. **雙擊節點 (Double Click Re-Center)**：
   - 執行 0.4 秒平滑過渡動畫（Camera Tween），將視角原點平移至該武將，重繪以其為核心的人際網絡圖鑑。
3. **縮放與平移 (Pan & Zoom)**：
   - 支援雙指/滾輪縮放（範圍 0.6x ~ 1.5x），超出畫布邊界具備彈力回彈防呆。

## A. 系統描述

家族關係系統負責定義武將之間的「人際連結」——包含史實關係（義兄弟、夫妻、主從、師徒）與動態遊戲內關係（結義傭兵、子嗣血緣、戰場緣份）。系統透過「相性標籤」驅動爆發力加成、合攻觸發、事件劇情分歧等核心玩法。

> **Unity 對照**：相當於 ScriptableObject 驅動的 Relationship Graph；節點是武將 UID，邊是關係類型與親密度權重，類似 Unity 的 Dialogue / Quest Graph 但用在人際網路。

---

## B. 系統目的

1. **爆發力加成來源**：史實配對（如周瑜＋小喬）觸發名將契合 +25 EP，是養成天花板的關鍵因子
2. **敘事黏著度**：讓玩家感受到「我的武將不只是數值，而是有關係網、有恩怨情仇的角色」
3. **策略配種引導**：相性標籤影響血脈共鳴與排斥，引導玩家研究最佳配種方案
4. **社交與收藏**：集齊特定關係組觸發英靈牆全局 Buff，驅動長線收集

## C. 商業套路

| 商業點 | 說明 |
|---|---|
| 名將配對抽卡 | 周瑜＋小喬、劉備＋孫尚香等史實配對需分別抽到，驅動轉蛋消耗 |
| 血脈排斥風險 | 趙雲血統×曹操血統降低受孕率，玩家可購買「安胎藥」突破 |
| 關係圖鑑 | 完成特定關係線（如桃園三結義全員 5 轉）解鎖專屬稱號與全局加成 |
| 相性占卜 | 消耗「求籤令」請名士分析兩武將相性，付費功能 |
| 世代傳承 | 同族三代觸發「家風傳承」被動，需長線多世代累積 |

## D. 系統 TA

| 玩家類型 | 使用情境 |
|---|---|
| 三國迷 | 享受史實關係還原，如桃園三結義、臥龍鳳雛的人際網路 |
| 數值控 | 研究標籤共鳴最佳化，追求 14 人 ≥3 標籤觸發血脈共鳴 +15 |
| 課長 | 為了打出名將契合 +25，需同時擁有配對雙方 |
| 收藏家 | 解鎖所有史實關係線、完成關係圖鑑 |
| 無課 | 透過戰場結緣與俘虜系統建立動態關係網 |

## E. 製作功能清單

| # | 功能 | 優先級 | 說明 |

| 1 | 關係類型定義 | P0 | 父子/母子/夫妻/義兄弟/主從/師徒/宿敵/戰友 |

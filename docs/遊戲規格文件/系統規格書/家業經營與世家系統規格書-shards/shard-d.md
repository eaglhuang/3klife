## 6. 六大家業逐項

### 6.1 家族商店（`familyShop`，買賣）

| 項目 | 值 |
| --- | --- |
| 職缺 Lv1~5 | 1、2、2、3、3 |
| 角色 | 掌櫃（政、魅）、夥計（魅、智；學徒位 10 歲起，低效） |
| 適合職業 | 領袖（魅）、文官（政、算術專長） |
| 基礎收益（金／季） | 120、200、320、500、760 |
| 聲望（／季） | 1、2、3、4、6 |
| 專屬產出 | 商貨 `goodsStock`、每季「掌櫃挑貨」1 件雜貨（補給箱、竹簡、絲帛、鐵料等，見 12 章物品表）；Lv4 起可上架貿易進口貨 |
| 經驗 | 掌櫃每季政務經驗、魅力經驗（小量，走歷練專長 `號召`、`算術`） |

**經營操作（方針）**
- 薄利多銷：收益 ×1.00，聲望 +2，風險低。
- 精品高價：收益 ×1.25（貨架需有 tier≥2 商貨，否則 ×0.90）。
- 囤貨待漲：本季 ×0.40，下季 ×1.80（同一商店一年最多 1 次）。
- 上下架、打折：走 ShopBase。打折 10~30%，打折期內收益 ×(1 + 折數 × 0.5)，聲望 +1，免得玩家無腦全打折。
- 進貨：用金購買雜貨（酒店共用的「雜貨市集」`market:grocery`）或貿易進口貨上架，進口貨上架售價 ×1.2。

**升級 perk**（SkillBase）：Lv2「精打細算」（採買 −5%）、Lv3「熟客」（聲望 +1）、Lv4「通達商路」（可上架進口貨）、Lv5「名號招牌」（精品方針 ×1.35）。

**風險事件**（節錄）：竊賊（損失一批貨，付錢可免）、稅吏刁難（花錢或降一季收益）、同業壓價（需選方針）、貴客上門（好事，聲望加成）、倉庫受潮（食材與雜貨保鮮減少）、年關搶購（好事，冬季）。

### 6.2 家族酒店（`familyTavern`，做菜）

| 項目 | 值 |
| --- | --- |
| 職缺 Lv1~5 | 1、2、3、3、4 |
| 角色 | 主廚（`cook` 廚藝）、副廚（`cook`，每個副廚讓主廚「專長需求」放寬 1 點）、跑堂（魅）、掌櫃（政）；學徒位 10 歲起 |
| 適合職業 | 廚師（1180 預留接口 `careerAttr.cook`）、領袖（跑堂、掌櫃）、文官（掌櫃） |
| 基礎收益（金／季） | 100、170、270、420、640 |
| 聲望（／季） | 2、3、5、7、10 |
| 席數（一般菜／季） | 8、12、18、26、36（每席耗 1 份食材） |
| 成長膳席數（／季） | 0、1、1、2、2（見第 7 章） |
| 乾糧加工（／季） | 0、10、20、35、50（每份耗 1 份糧，給出征、傭兵團、航次補給，降風險） |

**主廚資格與菜色階（要點，詳見第 7 章）**：酒店等級決定「能開哪一階」，主廚 `cook` 與專長決定「這位能不能做」。
**方針**：家常（客單 ×1.0，穩定）、宴席（高階菜為主，客單 ×(階數倍率)，耗食材多）、犒軍乾糧（收益 ×0.7，乾糧產量 ×1.5，傭兵團與航次風險 −）。
**升級 perk**：Lv2「老湯底」（成長膳解鎖）、Lv3「宴席承辦」（可接外交宴，第 9 章）、Lv4「冷鹽保鮮」（食材保鮮 +1 季）、Lv5「名廚招牌」（菜色階 5 解鎖）。
**風險事件**：食材不新鮮（該批菜損失；**成長膳受膳孩子該季加速失效但不受傷，且補一次免費重做**）、食客鬧事（花錢或降聲望）、名廚上門（好事：可招募客卿廚師 1 季）、美食評鑑（好事，聲望）、爐灶失火（停業 1 季，只在無「防火 perk」時）。

### 6.3 家族歌劇廳（`familyTheater`，表演）

| 項目 | 值 |
| --- | --- |
| 職缺 Lv1~5 | 2、2、3、4、5 |
| 角色 | 主演（魅、禮樂專長）、樂師（智）、編劇（智、政；每 2 季產「新戲本」）、舞監（統） |
| 適合職業 | 領袖（魅）、教官（禮樂）、文官（編劇） |
| 基礎收益（金／季） | 90、150、240、380、570 |
| 聲望（／季） | 3、5、8、12、18（最高，主打名望） |
| 專屬產出 | 魅力經驗；「戲本」物品（`rarity` 2~4，走庫存）；英靈劇目解鎖（家中有該武將或英靈卡才能演） |

**經營操作**：季初選「檔期劇目」與主演。劇目庫 12 齣（空城計、草船借箭、長坂坡、鳳儀亭、赤壁、單刀赴會等，第一版放 6 齣，其餘資料卡補）。
```text
票房 = baseIncome[lv] × 劇目熱度 × (1 + 主演魅力/100) × 季節 × 連演衰減
連演衰減 = 1 − 0.10 × 連續演出季數（下限 0.6）；換劇目重置
```
**方針**：賣座戲（票房 ×1.15，聲望 ×0.8）、名劇（票房 ×0.9，聲望 ×1.3）、新戲試演（需新戲本，票房 ×0.8，聲望 ×1.0，演完該戲本熱度 +）。
**升級 perk**：Lv2「樂班」（樂師加成）、Lv3「名角班底」（主演魅力 +5）、Lv4「堂會」（可接外交堂會）、Lv5「御前獻藝」（聲望 +3／季）。
**風險事件**：倒彩（聲望小損，可花錢請托）、名角鬧脾氣（需選擇安撫或換人）、戲台失火（停業 1 季，Lv3 起有防火 perk 免）、諷喻戲波及（若演影射他國劇目，外交好感 −小量，聲望 +；選擇題）、貴族包場（好事）、新戲大紅（好事）。

### 6.4 家族學院（`familyAcademy`，教書）

**與學府的分工（避免重複）**：學府＝36 回合正式培育，玩家主動操作、使用教官支援卡槽、扣入學令；學院＝日常被動經營，只教「學前孩子」與「進修專長」，**不佔教官槽、不發教官卡、不扣入學令、不做 36 回合**。

| 項目 | 值 |
| --- | --- |
| 職缺 Lv1~5 | 1、2、2、3、4 |
| 角色 | 掌教（`mentor` 教官屬性、治學、傳道、禮樂）、助教（智、魅）；榮養位（退役老將，見第 10 章） |
| 適合職業 | 教官（掌教）、文官（助教）、退役英靈未轉化者 |
| 基礎收益（金／季，學費） | 60、100、160、250、380 |
| 聲望（／季） | 2、4、6、9、13 |
| 專屬產出 | 「家學點」`homeSchoolPoints`、師徒緣、竹簡等文房雜貨 |

**經營操作（家學課）**：季初選學科（武藝、經史、禮樂、算術）與學生（5~14 歲、不在歷練、不在學府的孩子，同時最多 `Lv` 名）。季末該孩子該學科專長獲得家學點。
- 家學點寫入孩子 `homeSchoolPoints[specialty]`，**入學時**由 1180 第 8 章的起始加成讀取；每個專長上限 +4、全專長合計上限 +10，且入學前先過 1180 專長 0~20 與學府成長上限（500／2000）。歷練仍是專長主來源，家學只是補。
- 師徒緣：掌教與學生每季相處產生 `bondSeed`（0~5）；入學選到該掌教本人作為教官卡來源時，起始好感 +`bondSeed`，**與 1180 教官相性 +10 取較大者，不疊加**。
- 學生人數越多收益越高（學費），但每名學生要掌教 `mentor` 與 `fit`，人多教不好（`staffFactor` 下降 0.05／超額 1 人）。
**方針**：蒙學（人多、學費高、家學點少）、精修（人少、家學點多）、遊學（外出，每年冬季無課，聲望加成）。
**升級 perk**：Lv2「藏書」（家學點 +10%）、Lv3「名師講席」（掌教 `mentor` +5）、Lv4「家塾聯名」（可與他國學府通信，外交加成小）、Lv5「書院名」（聲望 +4／季）。
**風險事件**：學生染病（該孩子停課 1 季，無傷害）、掌教請辭（選擇加薪留任或換人）、名師拜訪（好事）、學費拖欠（小損）。

### 6.5 家族傭兵團（`mercCompany`，義勇營，去戰鬥歷練）

**與傭兵系統（試用，doc_spec_0029）的差別**：傭兵系統是「別人的武將來幫你打」，6 日結義、有好感與插圖；義勇營是「你家的人去外面接活歷練」，不涉及結義、好感、插圖。

| 項目 | 值 |
| --- | --- |
| 職缺 Lv1~5 | 2、3、4、5、6 |
| 角色 | 團長（武、統）、隊員（武、統；少年 15 歲起） |
| 適合職業 | 武將（武、統）、領袖（團長，統） |
| 基礎收益（金／季，固定酬勞） | 80、140、230、360、540 |
| 聲望（／季） | 2、3、5、8、12 |
| 專屬產出 | 戰功 `merit`（打折計入世家功勳，見下）、武將歷練經驗、戰利品（獸肉、皮、鐵礦，走庫存）、獵獲食材（山珍 tier 3、珍獸 tier 5 少量） |

**經營操作（接活）**：QuestBase 的 `mercContract`。每季委託榜刷出 3 個委託（護送商隊、剿匪、獵熊虎、協防守城、押運糧草），玩家挑，最多同時接 `Lv` 個，每個派 2~4 人。補給：帶乾糧（酒店產）可降風險。
```text
clashScore = Σ(隊員 武或統 × fit × ageEff) × 補給係數(0.9~1.1) × 種子浮動(0.9~1.1)
結果 = clashScore 對 委託 powerRequired 的比值：≥1.3 大勝、≥1.0 勝、≥0.7 小敗、<0.7 敗
```
- 大勝：酬勞 ×1.3、戰功 ×1.5、戰利品多一份；勝：標準；小敗：酬勞 ×0.5、隊員「輕傷」（本季結束可恢復，不影響下季）；敗：酬勞 0、隊員「重傷」1 季（不可派任何職缺，無永久傷害）。
- 戰功計入世家功勳分（doc_spec_0446）時只算 ×0.5，並套質重於量防火牆遞減，避免刷分。
- **戰場接口（第一版不做，只預留）**：玩家可選擇「領命親征」，系統送出 `battleEntryRequest{contractId, lineup[], seed}` 給戰場，戰場回 `battleResult{win, kills, injuries[], loot[]}`，本規格只做結算，**不改任何戰場核心規則**，交由「戰場專家」排程（Q5，使用者 11/21 裁決：第一版只自動作戰）。
**方針**：穩紮穩打（只接勝率高委託，收益 ×0.9，傷病 −）、冒險犯難（高風險委託，收益 ×1.3）、護航商隊（專接貿易護航，與貿易商行連動，第 8 章）。
**升級 perk**：Lv2「軍旗」（團長統率 +5）、Lv3「軍醫」（輕傷自動痊癒）、Lv4「獵戶隊」（獵獲食材 +1 檔）、Lv5「義勇名號」（高階委託開放）。
**風險事件**：敵方伏擊（需選擇突圍或撤退）、軍糧不足（無乾糧時）、被僱主賴帳（小損）、貴人賞識（好事，贈名駒或兵器雛形）。

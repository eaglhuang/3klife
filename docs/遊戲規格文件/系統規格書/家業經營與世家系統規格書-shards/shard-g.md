## 10. 人力取捨與退役

### 10.1 占用狀態與互斥矩陣

每個人同一時間只有一個占用狀態 `occupation`（暫存於人物欄位，第 3.4 節候選 A 成立後改走占用登記）：

| 狀態 | 說明 | 與「家業職缺」關係 |
| --- | --- | --- |
| `idle` | 待命 | 可派 |
| `sortie` | 出征 | 互斥：派家業的人不能出征；出征指令前要先「召回」（當季產出 ×0.5，之後 1 季不能再派回同職缺） |
| `gov` | 太守府政務槽 | 互斥 |
| `academy` | 學府培育（36 回合） | 入學即自動卸任，職缺空出；結業後可直接回任，無冷卻 |
| `adventure` | 10 歲歷練 | 互斥，歷練期間自動卸任 |
| `hallMission` | 大廳任務、派遣 | 互斥 |
| `estate` | 家業職缺 | 本狀態 |
| `pregnant` | 待產（2 季） | **例外可任**商店、酒店、學院、歌劇廳（低風險崗位）；不可任傭兵團、貿易 |
| `injured` | 輕傷／重傷（傭兵團、航次造成） | 不可派 |
| `prisoner` | 被擒 | 不可派 |

- 派去家業前 UI 要顯示「此人目前狀態」與「派去後會失去的選項」（出征、入學、政務）。
- 換職缺：同家業內換 0 冷卻；跨家業換需冷卻 1 季（避免每季套利）。

### 10.2 年齡門檻與低效

| 職缺 | 最低年齡 | 說明 |
| --- | --- | --- |
| 學徒位（商店夥計、酒店廚徒、歌劇廳習藝） | 10 歲（`minAgeRef=9198`） | 低效 0.5，累積專長與 `cook` |
| 一般職缺 | 15 歲 | 全效 |
| 傭兵團隊員 | 15 歲 | |
| 貿易領隊／護航 | 18 歲 | |
| 學院掌教 | 20 歲 | |

### 10.3 退役與老年去處（榮養位）

- 55 歲以上或已退役者可任「榮養位」`emeritus`：每個家業 1 個（Lv3 起 2 個）。
- 榮養者提供「閱歷加成」：家業收益 +8%（每人，上限 2 人）、事件中小損自動減半；不受出征互斥影響（退役者不出征）。
- 學院的榮養位同時是「掌教」候選，不受 `mentor` 年齡門檻限制。
- **與教官卡轉化的關係**（以 doc_spec_0482、0570、0310 為準）：已轉化為教官卡或英靈雙卡者**封存**，不可再派家業；未轉化者可任榮養位，之後仍可再選擇轉化（轉化後自動卸任並領回該季收益）。兩者不重複產出。
- 孩子轉職（20 歲成人禮，doc_spec_0567）時，在酒店累積的 `cook` 保留，成人後可選「廚師」標籤（接 9198 與 1180 的廚師路預留）。

## 11. 畫面概念與美術需求（手機記憶體優先）

### 11.1 畫面

- **入口**：大廳新增「幕府後院」熱點（未達幕府 Lv2 時隱藏，沿用 doc_spec_0615 熱點可見性寫法）；世家總覽增加「家業招牌」一行。
- **幕府後院（主畫面，`EstateYardScreen`）**：一張後院俯視背景，六個建築位。未解鎖＝地塊剪影加鎖與「幕府 Lv N 開放」；已解鎖＝建築圖加等級徽章。頂部顯示公庫金與建材、世家聲望階；底部「年度方針」與「年報」按鈕。
- **家業詳情（共用面板 `EstatePanel`）**：同一個面板模板，內容槽依家業切換：職缺槽（頭像加屬性加成提示）、方針選擇、本季預估收益、事件紀錄、升級按鈕。**不做六張各自的面板**。
- **酒店點菜台**：菜單卡（階、可做／缺什麼）、食材欄（顯示存量與保鮮季數）、孩子頭像選擇、資格原因碼提示。
- **出海海圖**：一張海圖加五個航線標記；出海中顯示船影圖示與倒數季數；回港結算彈出盈虧條。
- **家業年報彈窗**：一頁摘要（六家業收支條、聲望階進度、重大事件、下年建議），年末只彈一次。
- **獎勵演出**：寶箱、藏寶圖、轉盤由「獎勵」框架提供，家業只傳入獎池與演出類型。

### 11.2 記憶體與效能原則

- 後院背景 1 張（1280×720，壓縮）＋海圖 1 張；不用逐幀動畫、不用 Spine。
- 建築等級用 5 張共用等級徽章疊加，不為每級各畫一張建築；建築彩色版與剪影版共用同一張圖，剪影用染色（走 `setSpriteFillColor`，不另畫）。
- 所有圖示合進**一張 UI 圖集**（≤2048²）：建築圖示 6、航線圖示 5、船影 3、食材 18、菜餚 10、商貨 14、戲本卡面 6、事件類型圖示 8；不佔角色圖集。
- 職缺槽、菜單卡、列表列全部重用節點（物件池），畫面關閉即釋放面板，只保留資料。
- 事件第一版只用文字加類型圖示，不做每事件插圖。

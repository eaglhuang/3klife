# 3KLife 將領立軍令狀背水出征失利軍前正法狀態機規格書

## 1. 系統概述與設計哲學
在承擔極端高危險或關鍵性戰役任務（如把守華容道、堅守街亭孤山隘口）時，主帥常以白紙黑字軍法契約約束部將。三國軍令體系核心機制「生死軍令狀與軍前正法」（MILITARY-COMMISSION-PLEDGE01）。
出征將領於中軍大帳當眾具結畫押，立下軍令狀。立狀期間，將領及其統率部隊進入「背水狂熱」狀態，攻擊力激增且士氣強制鎖定不潰敗。然而，若戰略目標未能達成（如關隘失守、糧草被劫或縱走敵主將），主帥將依軍法無情啟動「軍前正法」或「降階戴罪立功」裁決，依據將領之義理值與人脈關係在全軍引發軍紀肅然與忠誠震盪。

## 4. 誓約心理動能與軍紀震懾模型

### 4.1 背水狂熱狀態機數值修正
簽署死生狀後，將領戰鬥意識轉化為殊死抵抗：
$$\text{Damage}_{\text{boost}} = \text{BaseDamage} \times 1.20 \times (1.0 + \frac{100 - \text{CurrentHP}}{200})$$
- 生命值越低，瀕死狂怒額外加成越高，但若戰術決策失誤造成陣地失守，其法律懲罰判定為硬性不可逆。

### 4.2 軍法嚴明之陣營效益
1. **全軍軍紀整肅**：揮淚執法後，陣營逃兵率於接下來 30 天內降低 $80\%$，部隊抗恐慌檢定 $+30\%$。
2. **忠誠反噬風險**：若處斬名將過於苛烈，與該將親密度高之部屬叛變概率提升 $15\%$。

## 5. 單元驗收測試標準
1. **TC-PLEDGE-01 (立狀加成與士氣鎖底全流程)**：
   - 模擬將領簽訂軍令狀，驗證部隊攻擊力即刻提升 20%，士氣在承受連環打擊下不跌破 60。
2. **TC-PLEDGE-02 (任務失敗軍法問斬與求情豁免)**：
   - 模擬陣地失守，轉入問罪判定。
   - 驗證求情好感度不足時強制執行斬首，全軍紀律提升 25 點。
3. **TC-PLEDGE-03 (戴罪立功勝場計數)**：
   - 判定求情成功改為 `DEMOTION_PARDON`，驗證需連續贏得 3 場戰役方能恢復原將軍銜。

# 3KLife 山地戰工兵鐵索扣吊巨木橫掃攻山步兵陣列狀態機規格書

## 1. 系統定位與設計意圖

在三國險要山隘攻防（如定軍山之戰、劍閣天險、陽平關之戰）中，進攻方步兵常藉助重藤牌與盾牆結成密集陣型，沿山道斜坡徐徐仰攻。單純由高處拋擲滾木容易順地表溝壑滑偏，難以正面衝碎步兵陣列。本系統規範山地守城重型機械工程「鐵索雙吊懸空巨木鐘擺橫掃機關（Suspended Log Sweep Mountain Defense）」之崖頂索系架設、位能蓄積、橫擺攔截與陣列粉碎狀態機：
- **雙鐵索橫向懸吊千斤重木**：在山道兩側天然巨石或生鐵樁之間，以兩根粗麻包生鐵鏈橫向懸吊重逾二千斤、直徑三尺之老櫟木整幹。
- **重力位能與鐘擺式弧線橫掃**：巨木被鉸盤拉高至山崖頂端形成三十尺垂直位能差；待敵軍先鋒大隊行進至半山腰隘口時，斬斷阻鐵扳機，巨木沿弧線貼地疾速呼嘯橫掃。
- **橫向動能粉碎密集盾牆**：巨木鐘擺橫掃面寬達三丈，其龐大動能直接擊碎前排盾牆、將仰攻步兵整排打飛滾落深谷，阻斷全軍攻勢。

## 2. 狀態機架構與轉換生命週期

懸索巨木橫掃狀態機（代碼：`SUSPENDED-LOG-SWEEP-MOUNTAIN-DEFENSE01`）管理自蓄力懸吊至巨木撞擊之完整週期：

```
[ LOG_RIGGING_WINCH_HOIST ] (絞盤拉升二千斤巨木至崖頂高位)
          │
          ▼
[ CABLE_TENSION_LOCKED ] (生鐵插銷扣死扳機進入蓄力待發狀態)
          │
          ├── 敵軍仰攻步隊進入預設撞擊扇面
          ▼
[ TRIGGER_PIN_RELEASE ] (守將揮斧斬斷引索巨木順重力呼嘯擺落)
          │
          ▼
[ PENDULUM_SWEEP_VELOCITY ] (鐘擺弧線加速貼地三尺高度狂暴掠過)
          │
          ├── 撞擊敵密集盾牆 ──> [ IMPACT_KINETIC_SHATTER ]
          ▼
[ MASSIVE_KNOCKBACK_TUMBLE ] (仰攻部隊整排被擊飛骨折滾落山崖)
          │
          ▼
[ PENDULUM_DAMPED_RESET ] (巨木往復擺動動能衰減工兵絞盤回收)
```

### 狀態細部定義

1. **LOG_RIGGING_WINCH_HOIST（絞盤起吊）**：
   - 4 名工兵轉動雙側青銅齒輪絞盤，將兩端固接於峭壁鐵環之巨木拉升至距坡面 25 尺之高空釋放點。
2. **CABLE_TENSION_LOCKED（卡榫鎖定）**：
   - 插入生鐵釋放卡榫，雙鐵索繃緊承受拉力，巨木處於高位能靜止姿態。
3. **TRIGGER_PIN_RELEASE（扳機釋放）**：
   - 敵軍步兵方陣推進至山道轉彎狹窄處（撞擊區），工兵揮動鐵斧敲落卡榫。
4. **PENDULUM_SWEEP_VELOCITY（加速橫掃）**：
   - 巨木受重力加速度下墜，在擺動最低點（距山道表面 3 尺）達到極限速度 16 m/s，帶起狂暴氣浪。
5. **IMPACT_KINETIC_SHATTER（動能粉碎）**：
   - 巨木橫面正向砸中敵第一排包鐵大盾，瞬間擊潰盾陣鎖扣，將前兩排 16 名甲士連人帶盾攔腰砸斷。
6. **MASSIVE_KNOCKBACK_TUMBLE（崩潰滾落）**：
   - 受擊部隊向後翻滾，引發骨牌效應撞倒後排隊友，山道仰攻攻勢全面瓦解。

## 3. 關鍵數值與計算判定公式

### 3.1 鐘擺極限撞擊動能公式

巨木在擺動最低點之瞬時衝擊動能 $E_{pendulum}$（焦耳）：
$$E_{pendulum} = M_{log} \times g \times \Delta h_{height} \times (1.0 - \text{ChainFriction})$$
- $M_{log}$：巨木質量（約 $1100\,\text{kg}$）。
- $\Delta h_{height}$：釋放點與最低點高度差（約 $7.5\,\text{m}$）。
- $\text{ChainFriction}$：鐵索鉸接摩擦損耗（取 0.08）。
- 計算得衝擊動能高達 $E_{pendulum} \approx 74,400\,\text{J}$，遠超任何重型步兵盾牆所能承受之極限（約 $12,000\,\text{J}$）。

### 3.2 敵軍擊飛擊退距離與致死率

受撞擊部隊擊退距離 $D_{knockback}$（步）：
$$D_{knockback} = \frac{E_{pendulum}}{N_{targets} \times M_{soldier} \times g \times \sin(\theta_{slope})} \approx 8.5\,\text{步}$$
- 仰攻陡坡上擊退 8 步將直接跌落山澗，墜崖致死率達 95%。

## 4. 戰術連鎖與攻防克制

1. **狹道一擊必殺防禦**：在無法展開大部隊的山崖羊腸小道，單一機關即可扼殺敵數千精銳先鋒。
2. **天敵與敵方反制**：
   - **工兵冷箭射索**：敵軍若派遣神射手以火箭射燒懸索麻芯或射殺絞盤工兵，可提前引爆或癱瘓機關。
   - **分段散開推進**：若敵將採取三三制極度分散站位，橫掃巨木僅能傷及零星士兵，性價比下降。

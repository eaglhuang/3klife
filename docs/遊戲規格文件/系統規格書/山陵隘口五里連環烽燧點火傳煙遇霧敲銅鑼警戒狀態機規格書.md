# 3KLife 山陵隘口五里連環烽燧點火傳煙遇霧敲銅鑼警戒狀態機規格書

## 1. 系統定位與設計意圖

在三國漫長邊防線（如隴右祁山道、漢中子午道、合肥濡須邊界）中，邊陲一旦遭遇大軍犯境，千里軍情必須在數個時辰內通傳至國都大營。本系統規範邊境預警骨幹工程「山陵連環烽燧要塞網絡（Beacon Tower Smoke & Gong Chain）」之晝煙、夜火、霧鑼與連鎖預警狀態機：
- **晝夜多重載體**：白天燃燒狼糞艾草釋放「直衝九霄、凝而不散」之黑色濃煙；夜間點燃柴草油松堆產生「火光照耀三十里」之沖天烽火。
- **雨霧金石聲響補盲**：遇狂風暴雨、長江漫天大霧能見度歸零時，敲擊百斤青銅八音警世鑼，聲震深谷，以聲音波紋接力通傳。
- **千里一日警報網絡**：每隔五里置一烽燧台，駐紮烽卒五人，形成無死角、高冗餘的戰略情報接力動脈。

## 2. 狀態機架構與轉換生命週期

連環烽燧預警狀態機（代碼：`BEACON-TOWER-SMOKE-GONG-CHAIN01`）管理從邊哨發現敵蹤至全境總動員之傳播週期：

```
[ BORDER_VIGIL_PATROL ] (日常瞭望與五里哨卡巡邏)
          │
          ├── 發現敵軍小股斥候 ──> [ LOG_SCOUT_CONTACT ]
          ├── 發現敵軍主力大隊 ──> [ ENEMY_INVASION_VERIFIED ]
          ▼
[ WEATHER_MODE_SELECT ] (判定天候選擇傳訊載體)
          │
          ├─────────────────────┼─────────────────────┐
          ▼                     ▼                     ▼
[ DAY_WOLF_SMOKE_IGNITE ] [ NIGHT_BONFIRE_LIGHT ] [ RAIN_FOG_GONG_BEAT ]
 (晝燃狼煙黑柱沖天)         (夜燃松柴火光十里)       (霧敲銅鑼聲波貫谷)
          │                     │                     │
          └─────────────────────┼─────────────────────┘
                                ▼
                   [ RELAY_CONFIRM_CHAIN ] (相鄰五里烽火台接力點火)
                                │
                                ▼
                   [ GARRISON_MOBILIZATION ] (後方郡城全城戒嚴備戰)
```

### 狀態細部定義

1. **BORDER_VIGIL_PATROL（邊卡警戒）**：
   - 烽台常駐伍長一人、烽卒四人，配備水囊、乾糧、狼糞包、油脂柴堆與百斤青銅警鑼。
2. **WEATHER_MODE_SELECT（天候分流）**：
   - 晴晝（06:00~18:00）啟用狼糞煙墩；夜間（18:00~06:00）啟用石塊烽火台柴籠；遇濃霧能見度 $<50$ 步或大暴雨，轉入敲鑼警報模式。
3. **DAY_WOLF_SMOKE_IGNITE（點燃狼煙）**：
   - 灶內先燃枯草，繼投乾燥狼糞與艾蒿，產生熱升浮力強大的直立黑煙柱，受側風吹拂仍能保持五里外清晰可辨。
4. **NIGHT_BONFIRE_LIGHT（夜燃烽火）**：
   - 淋下松脂生油引燃架空柴垛，火苗竄高丈餘，火光在黑夜中可直達八至十里外相鄰烽燧。
5. **RAIN_FOG_GONG_BEAT（鳴鑼穿霧）**：
   - 兩名力士持生鐵裹氈大槌，依「三長兩短」特定密碼急促重擊銅鑼，低頻聲波穿透峽谷水汽，相鄰烽台聞聲即刻接力鳴鑼。
6. **RELAY_CONFIRM_CHAIN（連鎖接力）**：
   - 相鄰烽燧接獲信號後，必須在 90 秒內點起同等數量之煙火，並向後方下一站傳送，直至邊關軍司馬大營。

## 3. 關鍵數值與計算判定公式

### 3.1 煙火信號傳播速度與時延

軍情跨越全境傳播總歷時 $T_{relay}$（分鐘）：
$$T_{relay} = \sum_{k=1}^{N_{beacons}} \left(T_{ignite} + \frac{D_{dist\_k}}{V_{light}} + T_{verify\_k}\right)$$
- $T_{ignite}$：點火或起鑼準備耗時（平均 1.5 分鐘）。
- $T_{verify\_k}$：相鄰烽卒確認並防誤報判定時間（約 1.0 分鐘）。
- 連續 60 座烽燧（橫跨 300 里山陵防線），總通報時間僅需約 150 分鐘（2.5 小時），速度遠超快馬驛傳。

### 3.2 敵情規模與烽火數量編碼契約

- **單烽起（一煙/一火/單鑼）**：敵軍騎兵斥候 $<500$ 人，周邊哨卡就地戒備。
- **雙烽起（二煙/二火/雙鑼）**：敵軍先鋒部隊 $500 \sim 3000$ 人，各關隘拉起吊橋。
- **五烽齊起（五煙合一/狂鑼連鳴）**：敵大軍主力壓境（$>10,000$ 人），全境進入一級臨戰動員。

## 4. 戰術連鎖與攻防克制

1. **防禦方戰略主動**：大後方主力在敵前鋒尚未抵達關前時，即已完成城防物資調配與軍團集結。
2. **進攻方破襲反制**：
   - **斬首截斷烽火**：進攻前派遣特種死士夜潛翻牆，拔除關鍵隘口的一至兩座烽燧，製造長達三十里的通信盲區。
   - **潮濕木料破壞**：暗中破壞烽燧貯木庫，使其浸水無法點燃，拖延情報傳遞。

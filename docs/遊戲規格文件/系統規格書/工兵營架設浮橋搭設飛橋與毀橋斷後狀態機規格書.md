# 3KLife 工兵營架設浮橋搭設飛橋與毀橋斷後狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 戰地工程與渡河交通系統（`PIONEER-BRIDGE-01`）。重現三國歷史中曹操渡渭水「作浮橋以濟」、張飛長坂坡「斷橋退敵」、鄧艾「造飛橋越澗」等經典工程戰例。部隊在遭遇江河阻斷且無既有石橋時，可由工兵營就地伐木組裝浮橋、鐵索懸橋或壕溝飛橋，實現兵團快速強渡，並可在撤退時焚毀拆除以阻截敵軍追兵。

## 3. 資料結構與介面定義

```typescript
export enum BridgeEngineeringType {
  PONTOON_WOOD = 'PONTOON_WOOD',       // 浮舟木板橋
  CHAIN_SUSPENSION = 'CHAIN_SUSPENSION',// 鐵索飛橋 (峽谷急流)
  TRENCH_FLYING = 'TRENCH_FLYING'      // 攻城壕溝飛橋 (輕型)
}

export interface BridgeConstructionConfig {
  bridgeType: BridgeEngineeringType;
  riverGridCoord: { x: number; y: number };
  pioneerTroopSize: number;            // 工兵部隊人數 (50 ~ 300)
  pioneerSkillLevel: number;           // 工匠/工程等級 (0..100)
  woodResourceAvailable: number;       // 木材儲量
  targetTurnsRequired: number;         // 基準所需工期
}

export interface BridgeRuntimeState {
  bridgeId: string;
  durabilityCurrent: number;           // 橋體耐久度 (0..1000)
  maxWeightCapacityKg: number;         // 最大載重 (承載投石車/重騎兵)
  turnPassedWeightAccumulated: number; // 本回合已通行重量
  isSevered: boolean;                  // 是否已砍斷斷後
  movementPenaltyRate: number;         // 通行速度懲罰 (0.0 ~ 0.5)
}
```

## 4. 造橋工期推演與承載超載斷裂公式

### 4.1 實際搭設工期計算
$$T_{\text{bridge}} = \max\left(1, \left\lceil \frac{T_{\text{base}} \times \text{RiverWidthCoeff}}{1.0 + \frac{\text{PioneerTroopSize} \times \text{PioneerSkill}}{10000}} \right\rceil\right)$$
- 若隨軍攜帶「墨家機巧」或有劉曄、馬鈞等巧匠督造，工期天數直接減半；
- 遭遇狂瀾汛期（流速 $\ge 2.5\text{ m/s}$），定位錨錠難度翻倍，工期 $+1$ 回合。

### 4.2 浮橋超載垮塌判定
重裝鐵騎或巨型霹靂車通行時：
$$\text{OverloadRatio} = \frac{\text{TurnPassedWeightAccumulated}}{\text{MaxWeightCapacityKg}}$$
- 若 $\text{OverloadRatio} \le 1.0$：安全通車；
- 若 $1.0 < \text{OverloadRatio} \le 1.5$：橋體耐久每回合扣減 $30\%$；
- 若 $\text{OverloadRatio} > 1.5$：浮橋瞬間斷裂崩塌，當期通行部隊 $30\%$ 人馬墜江溺斃，重型攻城器械全損沉沒。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-BRIDGE-01**：大軍渡河完畢後，執行「斷橋」指令，地格於本回合立即重置為 `NO_BRIDGE`，緊隨其後的敵方騎兵追兵被強制阻隔於河岸。
2. **驗收 CASE-BRIDGE-02**：在敵方遠程弓弩射程內架橋，工兵部隊每回合承受 $25\%$ 傷亡，若無盾牌兵掩護，工期進度每回合倒退 $20\%$。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

# 師友同場羈絆對聯動與名將傳道令一生一次奧義規格書

## 1. 模組職責與架構定位
本規格書規範學府培育體系中教官間的「師友羈絆對同場連動（`MentorSynergy`）」與死亡名將英靈的「名將傳道令奧義傳承（`LegendaryMentoring`）」狀態機。模組確保同陣營教官協同帶來專屬事件與屬性飛躍，並為先烈英靈提供莊嚴且嚴格受控的一生一次傳承機會。

```
┌─────────────────────────────────────────────────────────────┐
│                 Mentor Synergy & Mentoring                  │
├──────────────────────────────┬──────────────────────────────┤
│ Mentor Synergy Pair (R1~R12) │ Legendary Mentoring Order    │
│ 羈絆對同場 (Min_Friendship≥60)│ 消耗傳道令 / 100% 傳授奧義  │
│ 四大特權效果一次性觸發       │ 一生限一次 / 雙向防呆鎖定   │
└──────────────────────────────┴──────────────────────────────┘
```

## 2. 師友同場羈絆對狀態機

### 2.1 羈絆對配置清單
系統預載經典歷史共鳴教官對（`MentorPairDefinition`）：
1. **王佐鬼才**：荀彧（`SUP_XUNYU`）＋ 郭嘉（`SUP_GUOJIA`）。
2. **義薄雲天**：關羽（`SUP_GUANYU`）＋ 張飛（`SUP_ZHANGFEI`）。
3. **江東雙璧**：周瑜（`SUP_ZHOUYU`）＋ 魯肅（`SUP_LUSU`）。
4. **鳳雛水鏡**：龐統（`SUP_PANGTONG`）＋ 司馬徽（`SUP_SIMAHUI`）。
5. **五子良將**：張遼（`SUP_ZHANGLIAO`）＋ 徐晃（`SUP_XUHUANG`）。

### 2.2 觸發條件與四類效果分派
- **判定時機**：限定於 **第 12 回合前（包含第 12 回合）** 結算時進行一次性檢定。
- **門檻要求**：羈絆對雙方均在當前 6 位指派教官席中，且兩人與學員之友情羈絆值均達 $\ge 60$。
- **四類增益效果（隨機或依組合固定）**：
  - `STAT_BOOST`：全五維屬性立即額外 $+20$ 點。
  - `TP_INJECTION`：戰法修煉點數立即注入 $\text{TP} + 50$ 點。
  - `BURST_PERMANENT`：該場培育後續所有訓練格基礎爆發率永久 $+5\%$。
  - `DUAL_TACTIC_UNLOCK`：解鎖專屬組合戰法候選（例如「神火連環」）。

```typescript
export interface SynergyCheckResult {
  hasTriggered: boolean;
  synergyId?: string;
  effectType?: 'STAT_BOOST' | 'TP_INJECTION' | 'BURST_PERMANENT' | 'DUAL_TACTIC_UNLOCK';
}

export function checkMentorSynergy(
  round: number,
  mentorA_Id: string,
  mentorB_Id: string,
  friendshipA: number,
  friendshipB: number,
  alreadyTriggered: boolean
): SynergyCheckResult {
  if (alreadyTriggered || round > 12) return { hasTriggered: false };
  if (friendshipA < 60 || friendshipB < 60) return { hasTriggered: false };

  return {
    hasTriggered: true,
    synergyId: `${mentorA_Id}_${mentorB_Id}`,
    effectType: 'TP_INJECTION'
  };
}
```

## 3. 名將傳道令一生一次奧義傳授

### 3.1 傳承資格與消耗
當家族中擁有已陣亡或壽終之「死亡名將英靈卡（`DEAD_GENERAL_SPIRIT`）」時，玩家可消耗 **1 枚「傳道令（`LEGENDARY_TOKEN`）」** 發起傳道：
1. **100% 確定性成功**：必定將該名將之核心奧義戰法注入學員之待習得戰法槽中，免除任何隨機擲骰。
2. **一生一次防呆（Single-Use Guard）**：
   - 培育學員本體記錄 `hasReceivedLegendaryMentoring = true`，終身不得接受第二次名將傳道。
   - 英靈卡標記 `hasConductedLegendaryMentoring = true`，消耗後英靈光芒定型，不可重複用於多名子嗣。

```typescript
export interface LegendaryMentoringResult {
  success: boolean;
  awardedTacticId: string;
  errorCode?: 'ALREADY_MENTORED' | 'NO_TOKEN' | 'SPIRIT_EXHAUSTED';
}

export function executeLegendaryMentoring(
  studentMentored: boolean,
  spiritExhausted: boolean,
  tokenCount: number,
  tacticId: string
): LegendaryMentoringResult {
  if (studentMentored) return { success: false, awardedTacticId: '', errorCode: 'ALREADY_MENTORED' };
  if (spiritExhausted) return { success: false, awardedTacticId: '', errorCode: 'SPIRIT_EXHAUSTED' };
  if (tokenCount < 1) return { success: false, awardedTacticId: '', errorCode: 'NO_TOKEN' };

  return { success: true, awardedTacticId: tacticId };
}
```

## 4. 單元測試驗證規範
1. **TC-SYN-01（第 13 回合超時阻斷）**：兩位教官羈絆均為 100，但在第 13 回合發起檢定，回傳 `hasTriggered = false`。
2. **TC-SYN-02（羈絆 59 分未達門檻阻斷）**：教官 A 羈絆 60、教官 B 羈絆 59，回傳 `hasTriggered = false`。
3. **TC-LEG-01（重複傳道嚴格拒絕）**：若學員已標記 `studentMentored = true`，呼叫 `executeLegendaryMentoring` 立即回傳 `ALREADY_MENTORED` 錯誤。

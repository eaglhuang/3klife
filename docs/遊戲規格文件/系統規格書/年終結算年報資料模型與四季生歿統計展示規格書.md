# 年終結算年報資料模型與四季生歿統計展示規格書

> **模組識別碼**：`TIME-07`  
> **系統歸屬**：遊戲時間（GameClock）年終結算  
> **單一真相來源**：本規格書確立每年第 4 季結束時觸發之年報（YearReport）資料結構、老化事件計數模型、存檔正規化與 UI 展示合約之唯一權威標準。

---

## 一、系統概述與架構原則

在遊戲時鐘每推進滿 4 季（冬季結束跨入新春）時，系統自動觸發「年終年報結算流程」。年報中樞彙總該年度所有武將之生理老化事件，統計年度壽終正寢（身故）與屆齡退役候選人數，提供玩家年度成就反思與世代傳承預警。

### Unity / 架構對照
- **年報資料層**：類似 Unity 中的 `YearReportPresenter` 資料模型，將一年四季累積之事件進行計數與 DTO 封裝。
- **純字串代換**：透過 `buildYearReportTexts` 綁定 i18n 語系表，介面只負責將格式化文字寫入 Label。

## 二、年報觸發判定與資料模型

```typescript
import { SEASONS_PER_YEAR } from './GameClock';

export function isYearEndSeason(season: number): boolean {
    return season === SEASONS_PER_YEAR; // 第 4 季結束時觸發
}

export interface YearReport {
    readonly year: number;                  // 結算之遊戲年份
    readonly seasons: number;               // 包含季數（固定為 4）
    readonly deaths: number;                // 本年度身故人數
    readonly retirementCandidates: number;  // 本年度滿 65 歲屆齡退役人數
}
```

## 三、四季事件累積與年報生成演算法

在春夏秋冬四個季度中，武將增齡產生的所有 `AgingEvent` 由 `GameSession` 累積儲存：

```typescript
export function buildYearReport(year: number, events: readonly AgingEvent[]): YearReport {
    let deaths = 0;
    let retirementCandidates = 0;
    
    for (const event of events) {
        if (event.type === 'died') {
            deaths++;
        } else if (event.type === 'reached-retirement-age') {
            retirementCandidates++;
        }
    }
    
    return {
        year,
        seasons: SEASONS_PER_YEAR,
        deaths,
        retirementCandidates,
    };
}
```

- **事件重置契約**：年報生成並展示給玩家後，當年度事件清單 `yearAgingEvents` 立即清空，準備迎接新的一年。

## 四、存檔容錯與正規化保護

```typescript
export function normalizeYearAgingEvents(raw: unknown): AgingEvent[] {
    if (!Array.isArray(raw)) return [];
    const validTypes = ['reached-retirement-age', 'died', 'entered-growth-stage'];
    
    return raw.flatMap((item): AgingEvent[] => {
        if (!item || typeof item !== 'object') return [];
        const e = item as Partial<AgingEvent>;
        if (typeof e.generalId !== 'string' || typeof e.age !== 'number' || !Number.isFinite(e.age)) {
            return [];
        }
        if (!validTypes.includes(e.type as string)) return [];
        return [{
            type: e.type as AgingEventType,
            generalId: e.generalId,
            age: e.age,
            ...(e.stage ? { stage: e.stage } : {}),
        }];
    });
}
```

## 六、驗收條件與測試案例 (Test Cases)

- **TC-TIME-17（年末季精確觸發）**：
  - 第 4 季呼叫 `isYearEndSeason(4)` 回傳 `true`；第 1、2、3 季回傳 `false`。
- **TC-TIME-18（年報人數計數正確）**：
  - 輸入 2 筆 `died` 事件與 1 筆 `reached-retirement-age` 事件，年報 `deaths` 為 2，`retirementCandidates` 為 1。
- **TC-TIME-19（零事件安全回退）**：
  - 無任何人老化異常（事件清單為空），年報數值皆為 0，文字正常生成不報錯。
- **TC-TIME-20（損毀存檔容錯清理）**：
  - 存檔包含無效物件與字串型別錯誤，`normalizeYearAgingEvents` 自動過濾，不造成計算崩潰。

# 延壽丹使用上限次數約束與演武聖境精華快照繼承規格書

## 1. 模組職責與架構定位
本規格書規範武將壽命延續系統中的「延壽丹道具使用與累計上限狀態機（`LongevityPill`）」以及武將身故後宗族資產保值的「演武聖境精華快照繼承模型（`LegacyArena`）」。模組確保玩家能透過丹藥挽救關鍵宿將，同時避免無限延壽破壞代際傳承節奏。

```

│                 Longevity & Legacy Arena                    │
├──────────────────────────────┬──────────────────────────────┤

└──────────────────────────────┴──────────────────────────────┘
```

## 2. 延壽丹道具使用與累計上限狀態機

### 2.1 丹藥品階與延壽效果
宗族丹房可獲取三種品階之延壽丹藥：
- **凝神小延壽丹**：每次使用延長壽命 **1 歲**。
- **純陽金丹**：每次使用延長壽命 **3 歲**。
- **天元九轉神丹**：每次使用延長壽命 **5 歲**。

### 2.2 次數與累計上限雙重防護
為防止單一武將跨時代存活破壞遊戲平衡，施加嚴格的邊界約束：
1. **次數限制**：每位武將一生最多僅能服用 **3 次** 延壽丹（`maxUseCount = 3`）。
2. **總年限封頂**：累計延壽總年限嚴格限制為 **10 歲**（`maxLifespanExtension = 10`），超額部分不予生效。
3. **身故阻斷**：已死亡（`isDead === true`）之武將禁止服用延壽丹。

```typescript
export interface LongevityPillResult {
  success: boolean;
  actualYearsAdded: number;
  newMaxLifespan: number;
  newPillCount: number;
  errorCode?: 'ALREADY_DEAD' | 'MAX_COUNT_REACHED' | 'EXTENSION_CAPPED';
}

export function applyLongevityPill(
  currentMaxLifespan: number,
  baseMaxLifespan: number,
  currentPillCount: number,
  isDead: boolean,
  pillYears: number
): LongevityPillResult {
  if (isDead) {
    return { success: false, actualYearsAdded: 0, newMaxLifespan: currentMaxLifespan, newPillCount: currentPillCount, errorCode: 'ALREADY_DEAD' };
  }
  if (currentPillCount >= 3) {
    return { success: false, actualYearsAdded: 0, newMaxLifespan: currentMaxLifespan, newPillCount: currentPillCount, errorCode: 'MAX_COUNT_REACHED' };
  }

  const currentExtension = currentMaxLifespan - baseMaxLifespan;
  const remainingExtension = Math.max(0, 10 - currentExtension);
  if (remainingExtension <= 0) {
    return { success: false, actualYearsAdded: 0, newMaxLifespan: currentMaxLifespan, newPillCount: currentPillCount, errorCode: 'EXTENSION_CAPPED' };
  }

  const actualYears = Math.min(pillYears, remainingExtension);
  return {
    success: true,
    actualYearsAdded: actualYears,
    newMaxLifespan: currentMaxLifespan + actualYears,
    newPillCount: currentPillCount + 1
  };
}
```

## 3. 演武聖境精華快照繼承模型

武將死亡時，其生前之武勳與屬性並不完全消散，系統透過演武聖境（`LegacyArena`）提取「武道精華（`MartialEssence`）」：
- **精華點數精算**：
  $$\text{MartialEssence} = \left\lfloor \frac{\text{PeakFiveStatTotal}}{10} \right\rfloor + \text{BattleVictories} \times 2 + (\text{HasUltimate} ? 50 : 0)$$
- **精華資產運用**：
  - 匯入宗族寶庫，供後代子嗣在學府培育時兌換專屬修煉指導。
  - 在演武聖境中激活先祖幻影，作為後代試煉對手（戰勝可直接覺醒因子）。

## 4. 單元測試驗證規範
1. **TC-PILL-01（三品丹藥正常延壽）**：基礎壽命 65 歲，服用純陽金丹（3 歲），壽命增至 68 歲，服藥次數標記為 1。
2. **TC-PILL-02（第 4 次服用嚴格拒絕）**：已服用 3 次，再次嘗試使用回傳 `MAX_COUNT_REACHED`。
3. **TC-PILL-03（10 歲累計上限截斷）**：已延壽 8 歲，服用天元神丹（5 歲），實質僅增加 2 歲達 10 歲上限，並成功完成操作。

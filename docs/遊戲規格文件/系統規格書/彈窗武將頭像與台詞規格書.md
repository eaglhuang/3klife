# 彈窗武將頭像與台詞規格書

> **規格代碼**：`POP-AVT-01`　**任務卡**：PROG-2-10129　**裁決來源**：使用者 2026-11-27 本人裁決
> **狀態**：正式定案　**依賴**：武將台詞性別化（SpeakerVoice，PROG-2-10083）、GeneralArtPaths 頭像路徑規則

## 1. 目的

「少年投靠」「名士占卜」「家族血統樹」三個彈窗原本只有文字或黑框，缺少人味。三個彈窗都掛上一位武將的大頭像，加上那位武將說的一句台詞。戰場彈窗不在範圍（交戰場專家）。

## 2. 說話的人與位置

| 彈窗 | 說話者 | 頭像位置 | 台詞位置 |
| --- | --- | --- | --- |
| 少年投靠（youth-pick） | 三位候選少年各自一位 | 每一列選項按鈕左側 | 併入該列文字第二行（取代原本的「就決定是你」按鈕提示，整列本身就是按鈕） |
| 名士占卜（sage-oracle） | 目前翻到的那位名士 | 名士欄左側 | 名士欄右上角對話框；換名士時一起換 |
| 家族血統樹（bloodline-tree） | 本代武將（人物頁正在看的那位） | 血統樹左區右下角 | 頭像左側對話框 |

所有位置用「父節點尺寸的比例」（x、y 為 0~1 的中心點，大小佔父節點高度比例），父節點尺寸變動時重排，不寫死像素座標，保留日後改直式的彈性。

## 3. 頭像來源與退階

1. `sprites/generals/avatars/{id}_avatar`（含自動裁切頭像）
2. 立繪 `sprites/generals/{id}_portrait`
3. 預設剪影 `unknown_avatar_{男／女}`

只重用既有貼圖，不新增圖集。節點依 slot 名稱重用，再開彈窗只換圖與文字。

## 4. 台詞規則

- 一句、不隨機：同一彈窗＋同一性格固定一句（四型性格 Brave／Wise／Loyal／Playful）；換說話者才換句。
- 樣板放 i18n：`ui.popup_speaker.<youth-pick|sage-oracle|bloodline-tree>.<性格>`，四語系（zh-TW、zh-CN、en、ja）齊備。
- 中文樣板的第一人稱一律寫 `{self}`，由 SpeakerVoice 依性別、性格、年齡代入：女將用妾身／本姑娘／人家、少年（未滿 16）用「我」、年長者用老夫／老身。en、ja 不使用 `{self}`。
- 口吻輕鬆現代口語，不悲劇。
- 查不到樣板時回空字串，不畫對話框，不用萬用句硬補。
- 名冊沒填性格時，依武將 id 穩定雜湊挑一型（同一人永遠同一型）；連武將都查不到才用義氣。
- 名士在名冊裡多半沒有性格欄位，聲線固定在 `SAGE_VOICE`（性別、性格、年齡）。

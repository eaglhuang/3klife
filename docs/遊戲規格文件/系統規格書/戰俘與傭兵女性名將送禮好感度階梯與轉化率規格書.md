## 1. 系統定位與架構

本規格確立戰後俘虜與酒館傭兵女性武將之「送禮好感度（Affection）」系統、禮品偏好加成演算法、四階段位狀態機以及勸降/結緣轉化率精算契約。
補齊過往「僅有呼叫殼、缺乏數值與轉化公式」的缺口。

```mermaid
flowchart TD
    PlayerGift[玩家向女性武將贈送禮品] --> CheckPref{是否為專屬偏好信物?}
    CheckPref -- 是 --> BonusAff[基礎好感 x 1.5 倍加成 + 特殊台詞]
    CheckPref -- 否 --> NormalAff[獲得常態好感點數]
    BonusAff --> CheckDecay{單季送禮次數 > 3 次?}
    NormalAff --> CheckDecay
    CheckDecay -- 是 --> HalfGain[衰減 50% 防疲勞刷分]
    CheckDecay -- 否 --> FullGain[全額好感增加 (上限 100)]
    FullGain --> UpdateTier[更新四階段位: 冷漠/友善/信任/知己]
    UpdateTier --> ConvertAction[提高戰俘勸降率 或 傭兵直接結義]
```

## 4. 轉化率公式與反刷頻率控制

1. **最終勸降成功率**：
   $$\text{FinalPersuadeRate} = \min\left(0.95, \text{BaseRate} + \frac{\text{Affection}}{100} \times 0.40 + \text{LUK\_Mod}\right)$$
2. **單季送禮防疲勞限制**：
   - 每位女性武將每季度最多接受 3 次全額好感餽贈。
   - 第 4 次起好感增量強制減半（$\times 0.5$），第 6 次起當季不再接受送禮，提示「心意已領，無功不受重祿」。

# 戰前情報偵查面板與戰法對策槽位容量規格書

> **文件狀態**：單一真相來源（Single Source of Truth）  
> **系統代碼**：`LVL-03`、`LVL-05`、`SYS-LOADOUT-SCOUT`  
> **核心職責**：確立進入戰鬥前之偵查面板四塊情報佈局（Enemy_Name / Core_Mechanic / Risk_Tags / Recommended_Loadout_Check）、嚴禁洩漏敵方站位之隱私防火牆，以及出陣主將戰法對策槽位容量計算公式與高風險挑戰許可協議。

---

## 1. 偵查情報四塊佈局與防火牆

戰前偵查面板（Scout Panel）提供情報以利玩家配置兵種與戰法，嚴格切分為四大區塊：

```
┌────────────────────────────────────────────────────────┐
│ [區塊 1: 敵首情報] 敵將姓名、頭銜、戰力評級、兵種屬性   │
├────────────────────────────────────────────────────────┤
│ [區塊 2: 核心機制] 關卡戰術特性（如：水攻、夜襲、伏兵）│
├────────────────────────────────────────────────────────┤
│ [區塊 3: 風險標籤] 致命威脅（如：【騎兵衝擊】【高火傷】） │
├────────────────────────────────────────────────────────┤
│ [區塊 4: 推薦檢核] 對策兵種/虎符三態狀態機檢核清單     │
└────────────────────────────────────────────────────────┘
```

> **情報防火牆鐵律**：偵查面板僅呈現宏觀情資，**絕對禁止提前洩漏敵軍初始九宮站位、埋伏坐標與 AI 行進路徑**，確保戰局探索懸念。

---

## 2. 推薦對策三態檢核（Recommended_Loadout_Check）

系統比對玩家「當前已裝備出征配置（Current Loadout）」，而非整體庫存收藏：
1. **READY（已具備）**：已裝備克制該關卡核心機制之兵種或戰法（顯示綠色打勾標籤）。
2. **MISSING（缺少）**：未裝備對策配置，但戰鬥力持平（顯示黃色警示標籤）。
3. **HIGH_RISK（高風險）**：完全遭關卡機制剋制且戰力不足（顯示紅色骷髏標籤）。

> **高風險挑戰協議**：處於 `HIGH_RISK` 時，系統跳出【兵勢凶險，仍可強行出征】確認對話框，**絕不可鎖死出征按鈕**，尊重玩家極限操作自由。

---

## 3. 戰法對策槽位容量計算模型

主將出陣可攜帶之戰法槽位數（$N_{\text{slots}} \in [2, 6]$）由智力、培育畢業評級與關卡階級共同決定：
$$N_{\text{slots}} = \min\left(6, \; 2 + \left\lfloor \frac{\text{INT}}{30} \right\rfloor + B_{\text{nurture}} + B_{\text{stage}}\right)$$

- **基礎保底**：固定 2 個基礎槽位。
- **智力階梯加成 ($\lfloor \text{INT} / 30 \rfloor$)**：
  - $\text{INT} \ge 30$：+1 槽
  - $\text{INT} \ge 60$：+2 槽
  - $\text{INT} \ge 90$：+3 槽
- **培育評級加成 ($B_{\text{nurture}}$)**：潁川書院畢業達 S 級評定：+1 槽（A/B 級為 0）。
- **關卡突破加成 ($B_{\text{stage}}$)**：通關連環破決戰關卡：+1 槽。

---

## 4. TypeScript 檢核與槽位計算範例

```typescript
export interface GeneralLoadoutCapacityInput {
  intelligence: number;
  nurtureRank: 'S' | 'A' | 'B' | 'C';
  stageChainCompleted: boolean;
}

export function computeTacticSlotCapacity(input: GeneralLoadoutCapacityInput): number {
  const base = 2;
  const intBonus = Math.floor(input.intelligence / 30);
  const nurtureBonus = input.nurtureRank === 'S' ? 1 : 0;
  const stageBonus = input.stageChainCompleted ? 1 : 0;
  return Math.min(6, base + intBonus + nurtureBonus + stageBonus);
}
```

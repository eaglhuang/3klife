# 戰場AI戰法施放智力分級與情境打分決策規格書

## 1. 核心定位與設計理念
本規格書定義《三國人生》敵方與委任 AI 在戰鬥階段中主動挑選並施放戰法（Tactics）之決策狀態機（WBS `AIS-06`，代碼落位於 `AiTacticDecision.ts` 與 `TacticAiRules.ts`）。
戰鬥系統將 AI 智力等級（`AiIqLevel`: LOW / MEDIUM / HIGH / EXTREME / PERFECT）作為首要決策分流閘門，實現從「愚蠢遲鈍、隨機失誤」到「冷血計算、精準斬殺」之動態心智表現。

```
              ┌──────────────────────────────────────────────┐
              │          AiTacticDecision 戰法分流決策       │
              └──────────────────────┬───────────────────────┘
                                     │ 依據 AI 智力 (IQ)
          ┌──────────────────────────┼──────────────────────────┐
          ▼                          ▼                          ▼
     【低智力 LOW】            【中智力 MEDIUM】         【高智力 HIGH 及以上】
   • 30% 機率出手            • 純數值唯傷害論           • 全面接入情境評分
   • 其餘回合按兵不動        • 挑選預估傷害最高         • 斬殺急救 +1000 權重
   • 候選池隨機選 1 招       • 無傷害戰法安全退回       • 天候不相容 0 分剔除
```

## 2. 智力三階決策狀態機

### 2.1 低智力（LOW IQ）遲鈍決策
低階武將或草莽盜匪戰術素養低下，戰法出手受到嚴重機率壓制：
1. **按兵不動檢核（`aiHoldsTactic`）**：
   $$\text{出手判定} = (\text{Random}() < \mathbf{0.30}) \quad (\text{AI\_LOW\_IQ\_TACTIC\_RATE} = 0.3)$$
   單回合僅有 **30%** 機率嘗試施放戰法；其餘 70% 回合強制放棄施法，回傳 `null`（按兵不動）。
2. **盲目挑選**：一旦決定出手，不計算戰場任何敵我數值，直接於可用候選清單（`candidates`）中隨機抽取 1 招施放。

### 2.2 中智力（MEDIUM IQ）貪婪傷害導向
中階將領懂得運用戰法殺敵，但缺乏宏觀大局觀：
1. **最高預估傷害優先**：遍歷所有可用候選戰法，比較其預估傷害（`estimatedDamage`），**無條件挑選傷害數值最高者**：
   $$\text{SelectedTactic} = \arg\max_{c \in \text{candidates}} (c.\text{estimatedDamage})$$
2. **安全回退防護**：若所有可用戰法皆為輔助、治療、位移等無預估傷害屬性之技能（$\max(\text{damage}) = 0$），中智力 AI 不擅處理複雜時機，回傳 `null` 並安全退回武將常規普攻。

### 2.3 高智力（HIGH / EXTREME / PERFECT IQ）大局情境評分
謀士級武將全面接入 `pickTacticByAiRule` 情境評分引擎，對每項候選戰法進行多維效用評估（Utility Scoring）：

| 戰法類型 | 情境評估條件 | 評分公式與權重修正 | 戰術意圖 |
| :--- | :--- | :--- | :--- |
| **單體傷害** | 目標血量 $\le$ 技能傷害（斬殺線） | $\text{Damage} + \mathbf{1000}$ | **絕對斬殺**：迅速使敵減員 |
| **單體傷害** | 目標血量 $>$ 技能傷害（常規消耗） | $\text{Damage} \times 1.0$ | 常規集火壓制敵方防線 |
| **群體傷害** | 範圍內敵軍部隊 $\ge 2$ 支 | $\text{TotalDamage} \times \mathbf{1.2}$ | **聚居打擊**：重創敵軍密集陣列 |
| **治療/增益** | 目標部隊血量 $\le 35\%$（瀕危狀態） | $\text{HealValue} + \mathbf{1000}$ | **極限急救**：保全核心精銳部隊 |
| **治療/增益** | 目標部隊血量 $> 70\%$（健康狀態） | $\text{BaseScore} \times \mathbf{0.5}$ | **避免溢出**：抑制低效益過度治療 |
| **天候違逆** | 氣象禁制（如雨天火計、大風逆吹） | 強制歸 **0 分**（立即排除） | **恪守天時**：防呆攔截無效施法 |

## 3. 資源與前置約束協議

1. **TP 能量預檢**：AI 進入戰法挑選管線前，底層調度器（`BattleController`）必須確認施法者當前戰技點（TP/SP）已達標，未達門檻者不得進入候選池。
2. **同分破平原則**：若高智力評分出現相同最高分，遵循「陣列首位優先（First-Match Wins）」原則，維持 100% 確定性重播。
3. **未指定智力（Default Fallback）**：若輸入之 `iq` 為 `null`（如遭遇特殊劇本或舊存檔無難度標記），系統自動回退至 **HIGH IQ** 邏輯執行情境評分，保障戰鬥強度底線。

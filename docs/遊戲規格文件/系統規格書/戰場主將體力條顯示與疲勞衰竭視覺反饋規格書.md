# 戰場主將體力條顯示與疲勞衰竭視覺反饋規格書

## 1. 核心定位與職責邊界
本規格書定義《三國人生》戰鬥介面中主將體力條（Vitality Bar）的數值渲染比例、枯竭變灰機制與精力能量環視覺反饋契約（WBS `FORM-11`，代碼落位於 `VitalityBarView.ts` 與 `VitalityBattleGate.ts`）。
系統忠實反映主將在行軍、施法與「破釜沉舟」體力燃燒後的精力耗損狀況，透過清晰之視覺分段為玩家提供關鍵的戰術疲勞預警。

```
              ┌──────────────────────────────────────────────┐
              │          VitalityBarView 體力反饋渲染         │
              └──────────────────────┬───────────────────────┘
                                     │
          ┌──────────────────────────┴──────────────────────────┐
          ▼                                                     ▼
   【血條下方體力細條】                                  【名牌旁精力能量環】
   • 填充比例 ratio = current / max                      • high (充足紫光): [180, 120, 255]
   • 歸零 (current ≤ 0): 底板強制灰化                    • mid (琥珀弱火): [230, 170, 80]
   • 灰化象徵虛脫喘氣、無法發動大招                      • exhausted (灰暗): [120, 120, 120]
```

## 2. 體力條數值填充與灰化規則（`VitalityBarView`）

戰場 HUD 主將頭像血條正下方設有 4px 高度之體力細條，即時反映當前精力比率：

### 2.1 填充比例公式（`vitalityBarRatio`）
$$\text{Ratio} = \begin{cases} 0, & \max \le 0 \text{ 或非有限數} \\ \min(1.0, \max(0.0, \frac{\text{Current}}{\text{Max}})), & \text{其他} \end{cases}$$
- **防禦性保護**：當輸入為 `NaN`、負數或上限為 0 時，嚴格歸 0，絕不拋出未捕捉異常。

### 2.2 歸零灰化狀態機（`isVitalityBarGrayed`）
當主將當前精力值滿足以下條件時，體力條底板與邊框立即進入灰化鎖定狀態（Grayed Out）：
$$\text{isGrayed} = (\text{Current} \le 0) \lor (\text{Current is NaN})$$
- **戰鬥意義**：體力歸零象徵主將陷入戰術虛脫（喘氣狀態），無法再發動需要消耗體力的武將專屬奧義與強力軍師計謀。

## 3. 名牌精力能量環視覺契約（`VitalityRingView`）

於名將頭像與血條名牌旁繪製之環形精力進度光環（Ring Arc），採用三級色彩調度：

| 精力分段 (`VitalityBand`) | 判定條件 | 能量環 RGB 顏色值 | 視覺與戰鬥語意詮釋 |
| :--- | :--- | :---: | :--- |
| **`high`（精力充足）** | 精力比例 $\ge 60\%$ | `[180, 120, 255]` | **飽和紫光**：神采奕奕，奧義施放無阻 |
| **`mid`（精力中段）** | $20\% \le$ 精力比例 $< 60\%$ | `[230, 170, 80]` | **琥珀微火**：略顯疲憊，注意體力控管 |
| **`exhausted`（精力枯竭）** | 精力比例 $< 20\%$ 或歸零 | `[120, 120, 120]` | **灰暗無光**：全軍疲憊，瀕臨衰竭崩潰 |

### 3.1 渲染資料結構
```typescript
export interface VitalityRingView {
    ratio: number;             // 弧長比例 0.0 ~ 1.0
    band: VitalityBand;        // 'high' | 'mid' | 'exhausted'
    text: string;              // 環中百分比文字，例如「72%」
    color: [number, number, number]; // RGB 顏色值
}
```
純邏輯運算層透過 `vitalityRingView(current, max)` 提供計算結果，畫面層 View 元件直接套用其顏色與百分比文字，不含引擎相依性。

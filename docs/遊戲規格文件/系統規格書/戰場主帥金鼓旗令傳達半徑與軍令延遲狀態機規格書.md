## 1. 系統架構定位與古代戰場通訊物理

聞鼓則進，聞金則退；旌旗所指，萬眾所向。《三國人生》（3KLife）拒絕無視空間距離之全圖瞬時心電感應指揮，正式引入**金鼓旌旗通訊物理模型（Drums & Banners Command System）**。

本系統核心價值：
1. **主帥統率光環（Command Aura Radius）**：主帥統率值（LEAD）決定有效傳令半徑。
2. **通訊距離延遲（Order Latency）**：遠離主帥大營之孤軍面臨指令延遲與自主 AI 代管。
3. **金鼓即時指揮指令**：擂鼓激勵全軍、鳴金緊急收兵，體現陣型開闔之真實感。

## 2. 主帥指揮半徑計算與光環矩陣

戰場主帥之指揮有效半徑 $R_{\text{cmd}}$ 由其基礎統率值決定：

$$R_{\text{cmd}} = \left\lfloor \frac{\text{LEAD}_{\text{commander}}}{15} \right\rfloor + 2 \quad (\text{格數，通常為 } 4 \sim 8 \text{ 格})$$

```typescript
export interface ICommanderAuraDef {
  readonly commanderId: string;
  readonly leadStat: number;              // 統率值
  readonly commandRadius: number;         // 指揮半徑 (格數)
  readonly moraleAuraBonus: number;       // 光環內部隊士氣加成 (+5)
  readonly drumCooldownTurns: number;     // 擂鼓冷卻回合
}
```

## 3. 超距指令延遲與自主 AI 代管狀態機

當作戰部隊移動至主帥指揮半徑之外（$\text{dist} > R_{\text{cmd}}$）時，進入超距通訊狀態：

```typescript
export enum UnitOrderState {
  IN_SYNC = 'IN_SYNC',         // 光環內：玩家指令當前回合即時生效
  DISPATCHING = 'DISPATCHING', // 傳令兵奔馳中：指令延遲至下次回合開始生效
  OUT_OF_RANGE = 'OUT_OF_RANGE'// 失去聯繫：完全由副將性格自主 AI 代管
}
```

1. **傳令兵延遲（Dispatching Latency）**：玩家向超距部隊發布之變更指令（如「停止前進轉為防守」），需由輕騎傳令兵遞送，耗費 1 完整回合。
2. **部隊長性格自律決策（Autonomous Stance）**：
   - 魯莽性格（如張飛、魏延）：失去主帥約束時，每回合有 $45\%$ 機率自主向最近敵軍發動猛攻。
   - 沉穩性格（如趙雲、徐晃）：就地採取「固守防禦」姿態，等待後續軍令。

## 4. 金鼓實時號令：擂鼓進軍與鳴金收兵

主帥每回合可消耗 1 點全域軍令點，發動專屬金鼓號令：
1. **擂鼓進軍（Drum of War）**：
   - 戰鼓雷鳴，全指揮光環內部隊當前回合士氣強制提升 **$+8$ 點**。
   - 近戰部隊衝鋒傷害提升 $+15\%$，移動力臨時 $+1$ 格。
2. **鳴金收兵（Gong of Retreat）**：
   - 金鑼齊鳴，下達脫離戰鬥撤退信號。光環內部隊在後撤移動時**免除敵軍藉機反擊（Opportunity Attack）**，且後撤成功率提升至 95%。

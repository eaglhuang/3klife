# 3KLife 戰場伏兵誘敵隱蔽判定演算法與背刺夾擊傷害結算規格書

> **規格代碼**：SPEC-BAT-AMBUSH01  
> **關聯 WBS**：BATTLE-AMBUSH-01（戰場伏兵隱蔽判定演算法、誘敵深入狀態機與空間背刺夾擊傷害結算）  
> **系統分類**：戰鬥系統 / 戰術計謀與微觀碰撞演算  
> **狀態**：正式生效（單一真相來源，嚴禁尾端追加補丁）

## 1. 系統架構定位與戰術哲學

「十面埋伏」、「誘敵深入」為兵家上乘之謀略。《三國人生》（3KLife）戰場擺脫了單純數值對撞之單調模式，將地格地形隱蔽度（Concealment Rating）與部隊朝向（Facing Direction）深度納入幾何傷害判定。

本系統核心價值：
1. **迷霧隱匿（Stealth Concealment）**：善用山林草澤將主力部隊完全自敵方小地圖抹除。
2. **奇襲先手壓制（Surprise Strike）**：破隱一擊必定暴擊並附帶「驚駭恐慌」，打亂敵方戰陣。
3. **空間朝向幾何結算**：引入背刺（Backstab）與前後合圍夾擊（Pincer Attack），重塑走位戰略深層次。

---

## 2. 地格隱蔽度與伏兵狀態機

戰場不同地格賦予進駐部隊相應之隱蔽評級 $C_{\text{rate}} \in [0, 1.0]$：
- **茂密山林（DENSE_FOREST）**：隱蔽度 $0.85$（步兵/弓兵可隱匿，騎兵無法隱匿）
- **高草蘆葦（REED_GRASS）**：隱蔽度 $0.70$
- **陡峭峽谷（VALLEY_PASS）**：隱蔽度 $0.60$
- **開闊平原（PLAIN）**：隱蔽度 $0.00$（無法進入隱形）

部隊進駐具隱蔽度地格並宣告「伏兵待命」後，進入狀態機流轉：

```
      [VISIBLE 常規顯形] ──進駐森林且宣告伏兵──> [CONCEALED 隱匿中]
             ▲                                            │
             │ 主動現身或被破隱                             │ 敵軍踏入 1 格警戒區
             │                                            ▼
      [REVEALED 破隱現身] ◄── 執行奇襲一擊 ──── [AMBUSH_READY 誘敵觸發]
```

1. **`CONCEALED`（隱匿狀態）**：部隊自敵軍畫面與小地圖完全消失（僅友軍半透明可見），禁止移動，不可被遠程部隊直接點選。
2. **`AMBUSH_READY`（誘敵觸發）**：當敵軍任何部隊行軍踏入伏兵相鄰 $1$ 格範圍時，觸發「中伏」警報，敵軍立即強制停止移動。
3. **`REVEALED`（破隱結算）**：伏兵部隊發動「奇襲突擊」，結算奇襲加成後回歸正常部隊顯形狀態。

## 3. 奇襲先手傷害與驚駭恐慌結算

伏兵發動奇襲突擊時，享受三大特權結算：
1. **必定暴擊（Guaranteed Critical）**：破隱之第一擊無視目標閃避率，判定必中且傷害固定按暴擊倍率（$1.5\sim 2.0$ 倍）結算。
2. **無反擊權限（Counterattack Suppressed）**：被奇襲部隊因措手不及，**當前回合完全無法進行任何反擊**。
3. **驚駭恐慌（Panic Status）**：被奇襲部隊士氣瞬間重挫扣除 **$20$ 點**；若部隊當前士氣跌破 $30$，直接陷入潰散混亂，無法接收軍令 1 回合。

## 4. 空間朝向背刺（Backstab）與前後合圍夾擊

每支戰場部隊均具備目前面對方向向量 $\vec{V}_{\text{facing}}$（四方向或八方向）。攻擊判定時依攻擊者與防守者之向量夾角 $\theta$ 計算空間幾何修正：

```
                [背刺角度: 135° ~ 225°]
                    攻擊傷害 +40%
                          ▼
                  ┌───────────────┐
  [側面夾擊: 45°~135°]  │  防守部隊目標  │  [側面夾擊: 45°~135°]
   傷害 +15%, 防禦 -10% │    朝向向前   │   傷害 +15%, 防禦 -10%
                  └───────┬───────┘
                          ▼
                     [正面迎敵: 0°]
                    標準 100% 結算
```

1. **正向背刺（Backstab）**：當攻擊者處於目標後方夾角 $135^\circ \le \theta \le 225^\circ$ 時：
   - 物理傷害提升 $+40\%$。
   - 破甲率提升 $+30\%$，目標格擋（Block）完全失效。
2. **前後合圍夾擊（Pincer Attack）**：
   - 當同一防守目標之正面（$\pm 45^\circ$）與背面（$180^\circ \pm 45^\circ$）同時存在敵對部隊夾攻時，目標觸發「受制於敵」懲罰：
   - 全局免傷率下降 **$35\%$**，且防守者受擊時士氣額外扣除 3 點/每次打擊。

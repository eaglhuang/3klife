## 1. 系統架構定位與真實創傷代價

刀槍無眼，沙場染血。《三國人生》（3KLife）摒棄了傳統戰鬥「扣血即純粹減員、出戰即滿血復活」之街機化設定，實裝**戰場傷兵二元分流與武將創傷後遺症系統（Casualty & Trauma System）**。

本系統核心價值：
1. **陣亡與負傷二元動態分流（Dead vs Wounded）**：被擊破的兵力中，高達 $40\%$ 為可被救治之傷員。
2. **野戰救護所即時搶救（Field Hospital Recuperation）**：隨軍醫官在戰鬥期間持續將傷兵轉化回可用戰力。
3. **武將重傷與永久殘疾狀態機（Permanent Trauma）**：核心名將受到致命打擊時，可能留下名垂青史的戰創印記。

---

## 2. 戰損二元分流演算法

部隊在戰場上承受傷害導致兵力減損時，即時寫入傷員監控隊列：

$$\Delta \text{Loss} = \text{Soldiers}_{\text{dead}} (60\%) + \text{Soldiers}_{\text{wounded}} (40\%)$$

```typescript
export interface IFieldCasualtyTracker {
  readonly unitId: string;
  totalKilledInAction: number;       // 永久陣亡 (無法恢復)
  currentWoundedPool: number;        // 當前重輕傷兵池
  recoveredTroops: number;           // 戰場急救成功回隊兵力
}
```

若部隊攜帶「金創散/神農百草」軍資，或隨軍配備「醫者」兵牌，**傷兵轉化率自 40% 躍升至 60%**，大幅減少戰後兵源枯竭之壓力。

## 3. 野戰救護所（Medic Depot）運行機制

大本營常設**野戰救護所**，由隨軍醫師（如華佗、董奉弟子）主理：
1. **每回合急救搶修**：每回合結算時，救護所自全軍傷兵池搶救出 **$15\%$** 傷員，以預備役形式補充進大營守備軍。
2. **神醫駐陣特權**：若隊伍指派青囊傳人駐陣，每回合搶救率翻倍至 **$30\%$**，且全軍戰場士氣每回合自然回復 $+2$（將士無後顧之憂）。

## 4. 名將重傷後遺症與殘疾狀態機

當核心名將生命值歸零、落馬潰敗時，觸發創傷檢定狀態機：

```
      [正常健全 HEALTHY] ──遭受致死打擊──> [臨界搶救 CRITICAL]
                                                  │
                 ┌────────────────────────────────┴────────────────┐
                 ▼ (70% 概率)                                      ▼ (30% 概率)
        [輕傷休養 WOUNDED]                                 【殘疾後遺症 TRAUMA】
        (休養 1 季度屬性 -10%)                             ┌───────┴───────┐
                                                           ▼               ▼
                                                     [獨目 BLIND]    [毒傷 POISONED]
```

```typescript
export enum GeneralTraumaType {
  NONE = 'NONE',
  BLIND_EYE = 'BLIND_EYE',     // 獨目 (夏侯惇拔矢噉睛：命中率 -10%，但暴擊率 +20%，震懾敵膽)
  BONE_POISON = 'BONE_POISON', // 骨毒 (關羽刮骨療毒：雨天全屬性 -15%，但意志力 +30%)
  LIMP_LEG = 'LIMP_LEG'        // 跛足 (步兵戰術移動力永久 -1 格)
}
```

1. **戰創非純粹懲罰**：部分戰傷（如「獨目」）會轉化為武將的傳奇威嚴標記，帶來狂戰士般的暴擊增益。
2. **名醫神方治癒**：尋得「五禽戲譜」或「麻沸散」後，可向華佗求醫進行刮骨手術，有 $80\%$ 機率徹底消除後遺症負面影響。

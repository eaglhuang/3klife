# 3KLife 戰場內外雙重長圍深溝高壘絕外援困內死狀態機規格書

## 1. 系統概述與設計哲學
在《三國生生不息》的大型城池圍困戰中，強攻常伴隨巨大兵力消耗。三國統帥（如曹操圍鄴城、司馬懿圍襄平、羊祜圍步闡）多採取「深溝高壘、內外雙重長圍」（CIRCUMVALLATION-TRENCH-DOUBLE01）之戰略圍城法。
該戰術工程在圍困目標周圍環形構築兩道平行防禦體系：內圈長圍（環城壕塹配木柵）專注封鎖城內守軍突圍求糧；外圈長圍（深溝拒馬配瞭望箭樓）則專門阻截敵方外圍大軍奔襲馳援（即「圍點打援」）。整套工程結合土石防禦、守衛巡邏視野與絕糧懲罰機制，迫使城內士氣崩潰降服。

## 4. 戰場攻防與圍困絕糧物理運算

### 4.1 雙向長圍阻絕效力公式
敵軍無論自內向外或自外向內衝擊長圍，所受動能與防護折減如下：
$$E_{effective} = E_{initial} \times (1.0 - \text{TrenchDepth} \times 0.15) \times (1.0 - \text{StockadeDefense})$$
- 任何騎兵強行越溝衝壘，強制陷入 `DISMOUNT_STUMBLE`（人仰馬翻）狀態，所受近戰傷害暴增 $200\%$。

### 4.2 內外情報完全隔絕機制
1. **快馬突圍阻斷**：內圈深溝密集立鹿角拒馬，城內單騎斥候突圍成功率降至 $1\%$ 以下。
2. **心理戰加成**：長圍外圍每隔百步樹立大纛旌旗，對城內進行全天候戰鼓疲勞轟炸，加速敵軍投降進程。

## 5. 單元驗收測試標準
1. **TC-TRENCH-01 (雙重長圍構築閉環驗證)**：
   - 模擬圍城部隊完成測線、掘溝與立柵全流程。
   - 驗證合攏瞬間城內 `cityFoodStockDays` 開始單向線性遞減，外部補給完全歸零。
2. **TC-TRENCH-02 (外援衝壘防禦懲罰)**：
   - 注入 5000 敵方外部援軍騎兵衝擊外圈防線。
   - 驗證援軍動能遭折減 65%，且箭樓集火重創其前鋒，迫使其進入擊退判定。
3. **TC-TRENCH-03 (糧盡士氣崩解終局)**：
   - 設定城內糧草歸零，驗證每日扣除 8 點士氣，至第 15 天強制觸發 `ATTRITION_COLLAPSE`。

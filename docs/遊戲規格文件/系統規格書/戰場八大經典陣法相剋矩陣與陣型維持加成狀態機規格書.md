## 1. 系統架構定位與陣法兵學傳承

八陣圖名成八陣，陣法為三國古代軍團作戰之精髓。《三國人生》（3KLife）擺脫無序單兵肉搏，將部隊在 2D 棋盤上的相對幾何座標抽象為**結構化戰鬥陣法（Tactical Formation）**。

本系統核心價值：
1. **動態環形相剋（Rock-Paper-Scissors Loop）**：沒有絕對無敵之陣型，陣法互制創造戰略縱深。
2. **幾何維持度演算（Formation Integrity）**：依據部隊間距與站位即時計算陣型完整度，提供動態攻防增益。
3. **破陣連鎖崩潰（Broken Formation）**：一旦陣眼（Core Pivot）被敵軍突破，觸發全陣潰散。

## 3. 陣型幾何維持度（Integrity）演算法

每回合開始時，系統計算陣中各部隊之幾何拓撲距離偏差值 $\sigma$：

$$\text{Integrity} = 100\% - \sum_{i=1}^{M} \frac{\text{dist}(U_i, \text{IdealSlot}_i)}{K_{\text{tolerance}}} \times 10\%$$

```typescript
export enum FormationState {
  PERFECT = 'PERFECT',       // 維持度 90%~100%：獲 120% 全額陣法效果
  MAINTAINED = 'MAINTAINED', // 維持度 60%~89%：獲 100% 標準陣法效果
  SHAKEN = 'SHAKEN',         // 維持度 40%~59%：陣法效果折半 (50%)
  BROKEN = 'BROKEN'          // 維持度 < 40%：陣型徹底瓦解 (破陣狀態)
}
```

1. **`PERFECT`（神形兼備）**：陣型嚴整無缺，全軍士氣每回合自然 $+3$。
2. **`MAINTAINED`（標準運作）**：享有陣法預設之攻防與移動修正。
3. **`SHAKEN`（動搖拉扯）**：部隊走位分散，部分增益失效。
4. **`BROKEN`（破陣瓦解）**：全體成員喪失所有陣法加成；且在破陣瞬間全陣成員士氣扣除 **$15$ 點**，並陷入易傷 $+20\%$ 狀態持續 1 回合。

## 4. 陣眼核心破壞與戰術切換

1. **陣眼樞紐（Formation Pivot）**：陣型中心通常為隨軍主將或軍師。若陣眼部隊陣亡、潰退或陷入混亂，陣型維持度直接**扣除 50%**，通常引發瞬間破陣。
2. **變陣耗費（Formation Morphing）**：戰鬥中切換陣法（如自「雁形陣」變更為「方圓陣」）需耗費主將 1 次軍令，且需要 1 回合過渡期；在過渡期內維持度固定降為 `SHAKEN`。

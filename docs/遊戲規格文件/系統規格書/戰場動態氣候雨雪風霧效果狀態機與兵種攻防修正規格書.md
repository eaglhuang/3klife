# 3KLife 戰場動態氣候雨雪風霧效果狀態機與兵種攻防修正規格書

> **規格代碼**：SPEC-BAT-WEATHER01  
> **關聯 WBS**：BATTLE-WEATHER-01（戰場動態氣候狀態機、州郡氣候分佈機率與兵種環境攻防修正）  
> **系統分類**：戰鬥系統 / 即時環境動態機制  
> **狀態**：正式生效（單一真相來源，嚴禁尾端追加補丁）

---

## 1. 系統架構定位與設計哲學

三國戰場之勝負歷來取決於天時、地利、人和。《三國人生》（3KLife）戰場氣候系統並非單純的視覺背景貼圖，而是直接接入戰鬥物理演算的核心機制。

氣候系統具有三大設計特性：
1. **州郡地理偏好（Regional Affinity）**：戰鬥發生地點決定氣候起始概率（江淮易雨、北方多雪、西北起風沙）。
2. **回合動態演化（Turn Progression）**：每 3 回合結算一次氣候遷移動態，避免氣候僵化。
3. **兵種與戰法立體干涉**：氣候直接干預射程、行軍速度、視野及火攻水計之成立條件。

## 2. 氣候列舉與狀態轉移矩陣

```typescript
export enum BattleWeather {
  CLEAR = 'CLEAR',       // 晴天：無環境減益，視野不受限，火計威力 100%
  RAIN = 'RAIN',         // 暴雨：路面泥濘，火計傷害 -60%，弓箭命中 -15%
  SNOW = 'SNOW',         // 大雪：極度嚴寒，騎兵衝鋒移動力 -1，每回合全軍扣士氣 2 點
  FOG = 'FOG',           // 濃霧：全軍視野壓制為 2 格，遠程射程上限降為 2，伏兵必暴擊
  SANDSTORM = 'SANDSTORM'// 風沙：移動力全面 -1，物理近戰命中率 -20%，防禦力 +10%
}
```

```
               ┌────────── 晴天 (CLEAR) ──────────┐
               │ 30%                  40%         │
               ▼                                  ▼
        暴雨 (RAIN) ◄─── 20% ─── 濃霧 (FOG) ───► 大雪 (SNOW)
               │                  ▲               ▲
               │ 10%              │ 15%           │ 15%
               └────────► 風沙 (SANDSTORM) ───────┘
```

戰鬥回合推進至第 $3k$ 回合（第 3、6、9... 回合）開始時，依當前州郡權重矩陣重新擲骰判定氣候遷移。若氣候發生更替，觸發全域廣播事件 `EVENT_WEATHER_TRANSITION`。

## 3. 兵種攻防修正與戰法干涉矩陣

各氣候對三大常規兵種（步、騎、弓）及特殊戰略指令產生乘法修正：

| 氣候狀態 | 步兵部隊修正 | 騎兵部隊修正 | 弓兵部隊修正 | 火計 / 水計戰略干涉 |
| :--- | :--- | :--- | :--- | :--- |
| **晴天 (CLEAR)** | 標準 100% | 標準 100% | 射程標準，命中標準 | 火計傷害 100%，擴散率標準 |
| **暴雨 (RAIN)** | 泥濘移動消耗 +1 | 移動力 -1，衝鋒傷害 -20% | 弓弦受潮，命中 -15% | **火計強制熄滅**，水計傷害 +35% |
| **大雪 (SNOW)** | 防禦 +10% | 衝鋒速度 -25% | 射程 -1 | 火計傷害 -30%，全軍士氣每回合 -2 |
| **濃霧 (FOG)** | 伏兵攻擊必暴擊 | 索敵距離降為 2 格 | **射程硬性上限 2 格** | 無法執行火箭遠程引燃 |
| **風沙 (SAND)** | 移動消耗 +1 | 衝鋒路徑偏轉 10% | 命中 -25% | 火計沿順風方向強制擴散 2 格 |

## 4. 客戶端渲染表現與效能降級守則

1. **視覺圖層分拆**：氣候效果由頂層獨立全螢幕節點 `WeatherFXLayer` 統一渲染（雨絲、飄雪、風沙粒子），DrawCall 預算固定為 **1**。
2. **音效交替**：氣候更換時，BGM 環境音效軌道（Ambient Channel）平滑淡入對應環境音（雷雨聲、呼嘯風聲），淡入淡出時長 1.2 秒。
3. **低階設備自動降級**：當 `VfxQualityTier` 判定為 `LOW` 或 `POTATO` 時，立即關閉 3D 飄雪與雨絲粒子，改為靜態螢幕濾鏡遮罩（Screen Tint Overlay），保證零額外 GPU 填充率消耗。

## 1. 系統定位與架構

本模組規範 $5 \times 8$ 戰術棋盤地塊狀態機（`TileStateRules`）中「危害傷害格（Hazard Tile）」的傷害結算與動態延燒擴散演算法。危害地格包含「烈焰火海（Hazard Fire）」與「峽谷落石（Hazard Rock）」兩大典型形態，在戰鬥回合結算階段（`BattleTileEffectPhase`）主動對停留或進入該地格的單位施加生命值懲罰，並支援受風向與地表可燃性影響的擴散機制。

```mermaid
flowchart TD
    TurnPhase[回合結算 BattleTileEffectPhase] --> ScanBoard[掃描戰術棋盤全地格]
    ScanBoard --> CheckTile{地格是否為 Hazard?}
    CheckTile -- 否 --> NextTile[跳過]
    CheckTile -- 是 --> DispatchType{危害類型判斷}

    DispatchType -- 火海 Hazard Fire --> ApplyBurn[停留單位扣除 10% 最大 HP]
    ApplyBurn --> RollSpread{向相鄰草地/森林延燒判定 (30%)}
    RollSpread -- 成功 --> NewFire[相鄰地格轉化為 Hazard Fire]

    DispatchType -- 落石 Hazard Rock --> ApplyRock[進入單位扣除固定 300 點高傷]
    ApplyRock --> ApplyArmorBreak[附加持續 2 回合破甲 Debuff]
```

## 3. 火燒延燒與傷害精算演算法

### 3.1 烈火傷害結算
當戰鬥單位在回合結束時停留在火海地格，或在移動中穿過火海地格時觸發結算：
$$\text{BurnDamage} = \max(50, \lfloor \text{MaxHP} \times 0.10 \rfloor)$$
- 傷害屬性為火系計策傷害，無視常規物理護甲。
- 若目標單位為「藤甲兵」或攜帶可燃裝備，傷害額外承受 $\times 2.0$ 弱點倍率。

### 3.2 相鄰延燒擴散機制
- 在每回合火海結算後，系統檢視火海周圍上下左右 4 個鄰接格。
- 若相鄰地格為「森林（Forest）」或「草地（Grass）」且尚未著火：
  - 基礎延燒機率為 $30\%$。
  - 若戰場當前天候為「大風（Gale）」，順風方向延燒機率提升至 $60\%$。
  - 判定成功後，相鄰地格立即轉化為 `HAZARD_FIRE`，持續時間重置為 3 回合。

## 4. 峽谷落石觸發與破甲結算

### 4.1 落石觸發與高額固定傷
落石為一次性埋伏或機關觸發型危害地格：
- **觸發時機**：部隊進入落石地格瞬間立即結算。
- **固定傷害**：造成 $300$ 點固定物理鈍擊傷害（對輕裝騎兵/弓兵造成 $\times 1.3$ 壓制）。
- **附加狀態**：目標部隊陷入「甲冑破碎（Armor Break）」狀態，防禦力下降 $25\%$，持續 2 回合。
- **地貌轉化**：落石結算後，該地格轉化為「碎石阻擋格（Blocker）」，部隊後續移動力消耗 $+1$。

## 5. 核心計算函式實作

```typescript
export function resolveHazardTileEffect(
  tile: IHazardTileData,
  unit: { maxHp: number; currentHp: number; isRattanArmor?: boolean },
  windDirection?: 'UP' | 'DOWN' | 'LEFT' | 'RIGHT'
): { damage: number; armorBreak: boolean } {
  let damage = 0;
  let armorBreak = false;

  if (tile.hazardType === 'HAZARD_FIRE') {
    const baseDamage = Math.max(50, Math.floor(unit.maxHp * 0.10));
    const rattanMod = unit.isRattanArmor ? 2.0 : 1.0;
    damage = Math.floor(baseDamage * rattanMod);
  } else if (tile.hazardType === 'HAZARD_ROCK') {
    damage = 300;
    armorBreak = true;
  }

  return { damage, armorBreak };
}
```

## 6. 驗收與測試標準

1. **火海生命百分比傷害檢驗（TC-GRD-02-01）**：
   - 單位最大血量 2,000，停留在火海地格回合結束時，檢核扣血精確為 200 點；藤甲兵扣血為 400 點。
2. **延燒擴散機率與邊界（TC-GRD-02-02）**：
   - 驗證岩石/泥沼等不可燃地貌延燒機率嚴格為 0%；草地在擲骰 $\le 0.30$ 時成功轉化為火海。
3. **落石一次性觸發與破甲（TC-GRD-02-03）**：
   - 驗證部隊踏入落石格承受 300 點傷害且附加 `armorBreak = true`，結算後地格狀態正確降級。

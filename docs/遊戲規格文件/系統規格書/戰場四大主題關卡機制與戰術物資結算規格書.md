# 戰場四大主題關卡機制與戰術物資結算規格書

> **文件狀態**：單一真相來源（Single Source of Truth）  
> **系統代碼**：`LVL-10`、`SYS-THEME-STAGE-SALVAGE`  
> **核心職責**：確立連環破戰役中四大經典主題關卡（峽谷落石/水淹圍堵/夜襲掠奪/森林埋伏）之核心戰術機制、地圖互動物件分佈，以及戰後打撈物資（Stage_Salvage）一次性結算入庫協議。

---

## 1. 四大主題關卡機制與場景特性

| 主題關卡 (Theme) | 核心戰術機制 | 核心互動物件配置 | 推薦對策部隊與兵種 | 戰術通關目標 |
|---|---|---|---|---|
| **峽谷落石 (Canyon)** | 狹窄通道，滾石陷阱阻截衝鋒 | 2處 `Rockfall_Node` (落石機關) | 山地步兵 (S適性)、盾兵陣列 | 擊毀高處機關或強行推進衝破隘口 |
| **水淹圍堵 (Floodgate)**| 河道水位暴漲，奔流沖退陣型 | 1處 `Floodgate` (蓄洪水閘) | 水軍精銳 (白毦兵/橫江射手) | 搶佔水閘閘台或利用浮橋迂迴合圍 |
| **夜襲掠奪 (Night_Raid)**| 視野受限（半徑3格），暗夜劫營 | 2處 `Camp_Target` (敵營糧倉) | 輕騎兵 (虎豹騎/白馬義從) | 斬殺敵巡哨，焚毀糧倉使敵軍崩潰 |
| **森林埋伏 (Ambush)** | 密集林地，遠程無效與伏兵突襲 | 3處 `Trap_Cluster` (毒刺暗樁) | 伏兵偵查兵、藤甲兵/先鋒部隊 | 誘敵出林或使用火攻戰法破除掩體 |

## 2. 戰後打撈物資結算模型（Stage_Salvage）

戰鬥結束勝利後，系統彙總戰鬥中透過佔領、擊破機關與斬將獲取之戰術物資，一次性寫入玩家帳號資源倉：

$$\text{SalvageGain} = \text{BaseStageReward} + \sum \text{ObjectDestroyedBonus} + \text{CommanderProwessBonus}$$

### 2.1 物資產出對照表
- **石材 (Stone)**：主要產自破壞 `Rockfall_Node`，用於宗族防禦要塞修繕（每座 +150 點）。
- **木材 (Wood)**：主要產自焚毀 `Camp_Target` 與水閘拆解（每座 +200 點）。
- **糧草 (Grain)**：主要產自攻破敵營糧倉（每座 +500 點，直接補償出征損耗）。
- **軍事情報 (Intel)**：全殲敵軍精銳或斬將俘虜（每名 +1 卷情報，解鎖後續連環破關卡）。

> **原子結算鐵律**：戰鬥進行期間，所有打撈物資僅存在於暫存記憶體；只有在戰後結算介面（BattleVictoryPanel）點擊【收兵回營】時，才執行一次性原子資料庫寫入，防止戰中斷線產生經濟回滾漏洞。

## 3. TypeScript 資料契約範例

```typescript
export interface StageThemeConfig {
  themeId: string;
  themeName: string;
  defaultWeather: string;
  interactiveObjectIds: string[];
  baseSalvage: { wood: number; stone: number; grain: number; intel: number };
}

export interface StageSalvageResult {
  woodCollected: number;
  stoneCollected: number;
  grainCollected: number;
  intelCollected: number;
  isFlawlessVictory: boolean; // 無陣亡加成 (x1.2)
}
```

## 4. 驗收標準與 CI 閘門（Acceptance Criteria）

1. **四主題配置齊全**：
   - 關卡配置庫中 100% 齊備峽谷、水淹、夜襲、埋伏四大關卡情資與物件座標。
2. **戰中經濟不污染**：
   - 單元測試驗證戰鬥進行中強制退出或失敗，帳號倉庫物資變更量為 0。
3. **無陣亡加成校驗**：
   - 全軍無陣亡完美通關時，所有 Salvage 收益正確享有 20% 增幅（向下取整）。

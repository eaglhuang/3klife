# 戰場地格狀態機四態轉換與圖層資料結構規格書

> **文件狀態**：單一真相來源（Single Source of Truth）  
> **系統代碼**：`GRD-01`、`SYS-TILE-STATE-MACHINE`  
> **核心職責**：確立戰場網格之四態生命週期（Normal / Hazard / ForceMove / Stealth）、動態相互作用消長矩陣與圖層資料結構，為戰鬥技能、環境災害與戰術掩體提供單一真相來源。

---

## 1. 四大基礎地格狀態定義

| 狀態名稱 | 列舉代碼 | 行為特徵 | 觸發鉤子 (Hooks) | 典型環境範例 |
|---|:---:|---|---|---|
| **常規地表** | `Normal` | 依據地形類型（平原/山地/水域/森林）計算基礎攻防與移動適性 | `onEnter`, `onExit` | 標準戰場地表 |
| **危害地格** | `Hazard` | 進入或於回合結束停留在格內之單位受到固定傷害或持續燃燒扣血 | `onEnterDamage`, `onTurnTick` | 火海、落石、毒沼、陷阱 |
| **位移地格** | `ForceMove` | 單位進入時強制朝特定向量推移指定格數，受阻時轉化為撞擊傷害 | `onEnterPush`, `onObstacleHit` | 洪水奔流、狂風推擠 |
| **掩體地格** | `Stealth` | 格內單位獲得掩蔽狀態，遠程攻擊無法鎖定，離開地格後狀態解除 | `onEnterHide`, `onExitReveal` | 密林埋伏、迷霧帷幕 |

## 2. 狀態消長與相互覆蓋矩陣

當不同戰法或環境效果施加於同一地格時，依下列消長優先級處理：
1. **水火互克**：
   - 處於 `Hazard(Fire)` 之地格若施加水系戰法，立即解除火海狀態，並產生持續 1 回合之 `Stealth(Steam)` 濃霧掩體。
2. **位移覆蓋危害**：
   - 強力水淹（`ForceMove`）可沖刷並覆蓋地表毒沼與普通陷阱。
3. **燃燒焚林**：
   - 處於 `Stealth(Forest)` 之地格遭受火攻時，立即轉變為 `Hazard(Fire)`，並強制逼出隱匿單位。

## 3. 資料結構契約（TileStateData）

```typescript
export enum TileStateType {
  Normal = 'Normal',
  Hazard = 'Hazard',
  ForceMove = 'ForceMove',
  Stealth = 'Stealth'
}

export interface TileStateData {
  tileIndex: number;
  coord: { x: number; y: number };
  currentType: TileStateType;
  durationTurns: number;       // 剩餘持續回合（-1 表示永久環境）
  intensity: number;           // 效果強度（傷害量或推移格數）
  directionVector?: { x: number; y: number }; // 位移方向（ForceMove 專用）
  sourceGeneralUid?: string;   // 施加此效果之武將實體 ID
  tag?: string;                // 具體標籤（如 "fire", "poison", "water_surge", "ambush"）
}

export interface TileInteractionResult {
  damageDealt: number;
  finalCoord: { x: number; y: number };
  isStunned: boolean;
  stealthApplied: boolean;
}
```

## 4. 執行週期與驗收標準（Acceptance Criteria）

1. **回合生命週期輪轉（Tick Cycle）**：
   - 每回合結束由 `BattleTileEffectPhase` 遞減 `durationTurns`，耗盡時自動還原為 `Normal`。
2. **撞擊結算安全保護**：
   - `ForceMove` 推移至地圖邊緣或不可跨越障礙時，安全中止位移，並按 `remainingSteps * intensity * 0.5` 結算撞擊傷害。
3. **單元測試涵蓋**：
   - 測試覆蓋四狀態進出鉤子、水滅火轉濃霧消長機制，及障礙撞擊傷害邊界。

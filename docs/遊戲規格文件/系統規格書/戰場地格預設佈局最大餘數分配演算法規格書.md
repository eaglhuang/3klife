# 戰場地格預設佈局最大餘數分配演算法規格書

## 1. 核心定位與演算法目標

本規格書為戰場棋盤地格初始佈局生成演算法（Tile-State Distribution Generator，代號 `SCN-02`）的單一真相來源（Single Source of Truth）。戰場棋盤由固定車道與縱深組成（標準棋盤為 $5 \text{ 車道} \times 8 \text{ 縱深} = 40 \text{ 格}$）。為解決百分比浮點數折算造成總格子數不吻合之捨入偏差，本系統嚴格採用「最大餘數法（Largest Remainder Method）」，確保地格分配總數嚴格等於棋盤總格數。

```typescript
export interface TileAllocationContract {
  boardDimensions: { lanes: 5; depth: 8; totalCells: 40 };
  algorithm: 'LARGEST_REMAINDER_METHOD';
  supportedTileKinds: ['normal', 'stealth', 'hazard', 'forceMove'];
}
```

---

## 2. 最大餘數分配演算法步驟

設棋盤總格數為 $N_{\text{total}}$（預設 40），場景預設百分比為 $P_k$（$k \in \{\text{normal}, \text{stealth}, \text{hazard}, \text{forceMove}\}$，$\sum P_k = 100$）。

### 2.1 步驟一：整數基底分配（Base Integer Allocation）

對每一種地格種類 $k$，計算其浮點精確值 $E_k$ 與基底整數配額 $I_k$：

$$E_k = \frac{N_{\text{total}} \times P_k}{100}$$

$$I_k = \lfloor E_k \rfloor$$

同時計算小數餘數：$R_k = E_k - I_k$。

### 2.2 步驟二：未分配餘額補齊（Remainder Priority Allocation）

計算初始已分配總格數：$N_{\text{assigned}} = \sum I_k$。
未分配差額為：$\Delta = N_{\text{total}} - N_{\text{assigned}}$。

1. 將四種地格按小數餘數 $R_k$ 由大至小降序排列。
2. 依序為餘數最高的前 $\Delta$ 個地格種類追加 $+1$ 格。
3. 若餘數嚴格相等，按預設順序優先級補齊：`stealth > hazard > forceMove > normal`。

## 4. 棋盤坐標放置與種子重現契約（Seed Placement）

1. **確定性洗牌放置（Deterministic Fisher-Yates）**：
   - 地格生成後，依據戰鬥隨機種子（`BattleSeed`）執行洗牌放置。
   - 同一種子與相同場景配置，所產出之棋盤地格坐標分佈嚴格一致，支援重播（Replay）與防 SL 機制。
2. **安全邊界約束（Deployment Zone Protection）**：
   - 雙方部署底線（Depth 0 與 Depth 7）強制鎖定為 `normal`，嚴禁生成 `hazard` 或 `forceMove`，杜絕開局直接掉血或被沖出邊界之極端不良體驗。

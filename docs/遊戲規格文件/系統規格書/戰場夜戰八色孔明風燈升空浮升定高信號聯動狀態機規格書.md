# 3KLife 戰場夜戰八色孔明風燈升空浮升定高信號聯動狀態機規格書

## 1. 系統定位與設計意圖

在三國夜戰（如赤壁火攻、夜襲烏巢、夷陵夜半火起）與大縱深山地作戰中，黑夜阻隔旗語傳遞，金鼓之聲易暴露部隊動向。本系統規範三國特種空中信號指揮系統「戰場八色孔明風燈（Kongming Lantern Signal Chain）」之升空熱浮力、陣形定高、夜間通信與全軍調度狀態機：
- **熱氣浮升定高**：以細篾竹篾為骨架，糊以浸桐油阻燃綿紙，底部懸掛松脂雄黃油盤，點燃產生熱氣騰空。
- **八色信號編碼**：外罩不同礦物浸染之透光紗罩（赤火、蒼青、玄黑、皓白、金黃等），以燈色與排列構形指示戰術指令。
- **長效滯空聯動**：藉由定長蠶絲引線牽繫或定時燃盡墜落，實現跨越十里戰場之夜間無聲指揮聯動。

## 2. 狀態機架構與轉換生命週期

孔明風燈信號狀態機（代碼：`KONGMING-LANTERN-SIGNAL-CHAIN01`）管理從地面充氣預熱至信號接收解碼之完整週期：

```
[ GROUND_PREHEAT_FILL ] (地面點火充填熱氣膨脹)
          │
          ├── 風力過強骨架扭曲 ──> [ RE-STABILIZE_FRAME ]
          ▼
[ RELEASE_ASCENT ] (鬆開固定索浮升爬升)
          │
          ├── 空中側風偏移 ──> [ DRIFT_TRAJECTORY_CALC ]
          ▼
[ HOVER_ALTITUDE_LOCK ] (抵達預定信號高度懸停發光)
          │
          ├── 遭遇敵方火箭射墜 ──> [ PREMATURE_INTERCEPTION ]
          ▼
[ MULTI_COLOR_CODE_EMIT ] (八色燈光組合陣列傳遞軍令)
          │
          ▼
[ FUEL_DEPLETION_DESCENT ] (油盤燃盡冷卻自然墜毀)
```

### 狀態細部定義

1. **GROUND_PREHEAT_FILL（充氣預熱）**：
   - 地面斥候固定風燈四角，點燃底座浸透桐油松脂之棉芯，熱氣灌入燈籠內部歷時 25 秒。
2. **RELEASE_ASCENT（釋放爬升）**：
   - 浮力克服自重後以每秒 2.5 公尺速度向上攀升，細蠶絲繫繩依絞盤逐步放線以控制爬升軌跡。
3. **HOVER_ALTITUDE_LOCK（定高懸停）**：
   - 攀升至 30~50 丈高空（水面或地面障礙之上），蠶絲繫留繩鎖定，風燈在夜空中維持相對靜止。
4. **MULTI_COLOR_CODE_EMIT（信號傳遞）**：
   - 燈光依據任務指令呈現預設顏色與多燈陣列（如三盞赤燈代表「火起全軍突擊」，雙盞蒼燈代表「向左翼迂迴」）。
   - 有效可視半徑達 15 里，夜間無遮蔽時辨識率達 95%。
5. **FUEL_DEPLETION_DESCENT（燃盡墜落）**：
   - 油盤可維持燃燒 15 分鐘，燃盡後空氣冷卻，風燈順風降落於無人荒野，不留軍事機密。

## 3. 關鍵數值與計算判定公式

### 3.1 浮升熱力平衡與有效載重

風燈淨浮力 $F_{net}$（牛頓）計算公式：
$$F_{net} = V_{envelope} \times g \times (\rho_{cold} - \rho_{hot}) - M_{structure} \times g$$
- $V_{envelope}$：風燈內部容積（標準直徑 1.2 公尺，約 $0.90\,\text{m}^3$）。
- $\rho_{cold}$：夜間冷空氣密度（約 $1.225\,\text{kg/m}^3$）。
- $\rho_{hot}$：燈內加熱空氣平均密度（約 $0.85\,\text{kg/m}^3$）。
- $M_{structure}$：竹篾骨架、油紙與油盤總重（約 $0.22\,\text{kg}$）。
- 淨浮力 $F_{net} \approx 1.15\,\text{N} > 0$，確保風燈可穩定懸帶信號彩紗與細引線上升。

### 3.2 夜間信號辨識成功率

跨戰場友軍瞭望哨辨認燈號成功率 $P_{decode}$：
$$P_{decode} = \text{clamp01}\left(\frac{I_{lumens} \times \cos(\theta_{sight})}{D_{dist}^2 \times (1.0 + \sigma_{fog})} \times C_{spec}\right)$$
- $I_{lumens}$：油盤光源發光強度。$D_{dist}$：瞭望距離（公里）。
- $\sigma_{fog}$：夜間江面水霧消光係數。$C_{spec}$：軍規夜視鏡或望遠銅筒倍率增益。

## 4. 戰術連鎖與攻防克制

1. **多路突襲精準協同**：伏兵部隊在不發一言、不起擂鼓的情況下，見燈號即刻同時合圍發動突襲。
2. **反制與誘敵風險**：
   - **敵軍偽造燈號**：若信號密碼本洩漏，敵方亦可升起同色風燈誘使伏兵過早出擊陷入陷阱。
   - **神射手火箭截擊**：若風燈升空過低（$<20$ 丈），敵方精銳弓手以燃燒火箭可凌空射穿氣囊引燃墜落。

## 1. 系統架構定位與夜色迷霧戰術

甘寧百騎劫曹營、張飛夜戰馬超，夜戰為三國戰役中最具懸念之戰術情境。《三國人生》（3KLife）戰場擺脫了全域光明之靜態視角，實裝動態**晝夜交替與火把視野光錐演算（Dynamic Torchlight & Fog of War）**。

本系統核心價值：
1. **晝夜交替動態循環（Day-Night Cycle）**：光影每 6 回合為一週期，重構戰場視野地圖。
2. **火把照明的雙刃劍（Torch Dual Nature）**：照亮周遭的同時，自身成為暗處敵軍的活靶標記。
3. **銜枚夜襲與營嘯混亂（Camp Riot）**：在敵方缺乏警戒時夜襲突防，引爆敵軍自相殘殺。

## 2. 晝夜交替時序與視野衰減矩陣

戰鬥回合按 6 回合為一輪迴循環流轉：

```
       [回合 1 ~ 3: 白晝 DAY] ──── 視野半徑標準 4~6 格，無夜戰加成
                │
                │ 進入第 4 回合
                ▼
       [回合 4 ~ 6: 黑夜 NIGHT] ── 視野半徑全面壓制為 1 格！
                │
                │ 滿 6 回合，破曉晨光
                ▼
       [循環重啟: 白晝 DAY]
```

```typescript
export enum TimeOfDay {
  DAY = 'DAY',       // 白晝：陽光明媚，標準視野與射程
  DUSK = 'DUSK',     // 黃昏：過渡 1 回合，視野半徑 -1 格
  NIGHT = 'NIGHT'    // 黑夜：伸手不見五指，基礎視野僅 1 格
}

export interface INightCombatVision {
  readonly currentPhase: TimeOfDay;
  readonly baseSightRange: number;   // 黑夜狀態下基礎視野為 1 格
  isTorchEquipped: boolean;          // 當前部隊是否點燃火把
  torchVisionRadius: number;         // 火把照亮半徑 (通常為 3 格)
}
```

## 3. 火把照明（Torchlight）雙刃劍機制

夜戰期間，部隊可自由選擇「點燃火把（LIGHT_TORCH）」或「熄火潛行（EXTINGUISH_TORCH）」：

```
  [暗處伏擊者: 匿於陰影] ────── 攻擊命中率 +20%, 暴擊率 +30% ─────►
                                                                  ▼
                                                      [持火把部隊: 處於明處]
                                                      照亮周遭 3 格, 但自身暴露
```

1. **照亮周遭**：點燃火把後，以部隊為中心半徑 $3$ 格範圍之地格迷霧被驅散，敵我皆可見。
2. **明處致命暴露代價（Exposed Penalty）**：
   - 持火把部隊在全戰場小地圖上強制標註顯形。
   - 處於黑暗陰影中的敵軍遠程部隊射擊該持火把部隊時，**命中率提升 $+20\%$，暴擊率提升 $+30\%$**。
   - 若部隊遭遇火箭攻擊，火把直接被引爆，部隊額外承受 $15\%$ 灼傷傷害。

## 4. 銜枚夜襲（Silent Raid）與「營嘯」自相殘殺

熄滅火把並攜帶特質「銜枚疾走」之精銳部隊，在夜戰中享有專屬夜襲特權：
1. **無聲突防**：夜行部隊行軍時不發出任何音訊提示，穿透敵軍常規警戒線，直到進入敵軍部隊相鄰 $1$ 格前**完全不可見**。
2. **夜襲突營判定**：夜襲部隊直接殺入敵方大營地格並發動突襲：
   - 守軍部隊立即觸發士氣檢定（$\text{Morale Check}$）。
   - 若守軍士氣 $\le 70$，有高達 **$60\%$ 機率觸發「營嘯（Camp Riot Panic）」**：
   - 守軍陷入極度恐慌，敌我不分互相砍殺，每回合部隊自損 $15\%$ 兵力，且 2 回合內無法響應任何軍令指令。

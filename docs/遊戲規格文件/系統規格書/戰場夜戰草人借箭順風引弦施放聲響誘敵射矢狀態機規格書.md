# 3KLife 戰場夜戰草人借箭順風引弦施放聲響誘敵射矢狀態機規格書

## 1. 系統定位與設計意圖

在三國經典水戰與大霧夜戰（如赤壁大戰草船借箭、合肥夜戰虛張聲勢）中，利用夜色、大霧與密集草人誘使敵軍在恐慌中盲目耗盡箭矢，是極具戰略價值的佯動戰術。本系統規範「大霧草人誘射與箭矢收割再生系統（Straw Man Arrow Deception）」狀態機：
- **輕舟排布覆甲草人模型**：戰船或前沿陣地兩舷密密麻麻排列以乾燥稻草扎結、外披粗麻布甲之假人，受箭面積大且能完整嵌留箭頭。
- **擂鼓吶喊偽造夜襲聲勢**：透過順風方向連續擂響戰鼓、搖動旗幟並以機械牽引空弦引發銳利破空嘯聲，營造千軍壓境之虛擬聲場。
- **誘敵恐慌覆蓋盲射集矢**：引導敵軍守將誤判敵情下達無差別盲射指令，待草人插滿箭矢後調轉船頭受箭，滿載萬支精鋼羽箭安全返航。

## 2. 狀態機架構與轉換生命週期

草人借箭誘射狀態機（代碼：`STRAW-MAN-ARROW-DECEPTION01`）流程如下：

```
[ STRAW_FIGURE_RIGGING ] (船舷兩側密扎稻草人披掛頭盔甲冑)
           │
           ├── 借濃霧夜色逼近敵水寨百步線
           ▼
[ ACOUSTIC_FEINT_WAR_DRUM ] (擂鼓吶喊機械空弦齊鳴製造假夜襲)
           │
           ├── 敵軍哨塔探明黑影誤判大軍突入 ──> [ ENEMY_BLIND_VOLLEY_ORDER ]
           ▼
[ ARROW_HARVEST_ABSORPTION ] (草人密集嵌留敵軍射來之羽箭)
           │
           ├── 單舷草人受箭飽和重心偏移
           ▼
[ TACTICAL_VESSEL_ROTATE ] (調轉船頭以另一舷草人迎受箭雨)
           │
           ├── 敵軍箭庫耗盡或天色破曉
           ▼
[ RETREAT_INVENTORY_RESTOCK ] (滿載箭矢順流返航登記入庫補給全軍)
```

### 狀態細部定義

1. **STRAW_FIGURE_RIGGING（草人布設）**：每艘輕舟兩舷各扎設 20 具仿真草人，頭戴皮盔身披破氈，受箭截面覆蓋率達 85%。
2. **ACOUSTIC_FEINT_WAR_DRUM（聲東擊西）**：軍士齊聲呼喝，銅鑼巨鼓連環敲響，破空空弦器高頻振動模仿箭雨呼嘯。
3. **ENEMY_BLIND_VOLLEY_ORDER（誘發盲射）**：敵將受大霧視距限制（視距小於 15 步），下達三軍弓弩手全力覆蓋射擊之軍令。
4. **ARROW_HARVEST_ABSORPTION（吸納箭矢）**：每具草人每秒吸收 12 支羽箭，稻草韌性防止箭桿折斷，箭簇完整保留。
5. **TACTICAL_VESSEL_ROTATE（調頭均重）**：一側草人受箭逾 500 支後，舵手擺舵 180 度，平衡船身重量並繼續收割。
6. **RETREAT_INVENTORY_RESTOCK（收穫返航）**：單次行動收割羽箭可達 10,000 至 15,000 支，敵軍遠程箭矢存量直接衰退 40%。

## 3. 數值模型與物理演算

### 誘射成功率判定公式

$$P_{deception} = \min\left(0.95, \; 0.40 + 0.25 \times \text{IsHeavyFog} + 0.15 \times \text{IsNight} - 0.003 \times \text{INT}_{enemy\_commander}\right)$$

- 若處於「大霧且夜間」環境，基礎欺騙成功率達 80%；敵將智力大於 90 時，機率每點扣減 0.3%。

### 箭矢收割數量結算公式

$$N_{arrows} = \sum_{t=1}^{T} \left( N_{archers} \times R_{firerate} \times P_{hit\_straw} \right)$$

- $N_{archers}$：敵軍參戰弓弩手總數（通常 300~500 人）。
- $R_{firerate}$：每分鐘射速（約 6 支/人）。
- $P_{hit\_straw}$：草人受箭命中截面比例（0.75）。10 分鐘誘射即可回收 13,500 支可用箭矢。

## 4. 戰場戰術連鎖與部隊生剋

1. **戰略耗空敵軍儲備**：受騙敵水寨在接下來 3 場戰役中，遠程部隊彈藥量上限降低 50%，無法進行持續火力壓制。
2. **己方庫存無本暴增**：收割之箭矢直接轉化為全軍通用的【精鋼破甲箭】，我軍遠程部隊下一輪戰鬥暴擊率提升 15%。
3. **火箭火攻反制**：若敵將識破並改用火箭射擊，草人將迅速起火，誘射部隊必須立即斬斷纜繩棄船撤退。

## 6. 驗證標準與測試用例 (TC)

- **TC-STRAW-DECEPT-01（大霧誘射判定）**：在大霧環境下敵將智力 75，誘發盲射機率必須 $\ge 80\%$。
- **TC-STRAW-DECEPT-02（雙舷調頭均重）**：左舷受箭達 500 支時，自動觸發 `TACTICAL_VESSEL_ROTATE` 並平滑轉換受箭面。
- **TC-STRAW-DECEPT-03（箭矢回補入庫）**：任務成功返航後，庫存箭矢數量精準增加收割總額，無遺失或溢位。

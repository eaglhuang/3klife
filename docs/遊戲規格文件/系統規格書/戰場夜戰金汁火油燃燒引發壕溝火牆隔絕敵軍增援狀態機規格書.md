# 3KLife 戰場夜戰金汁火油燃燒引發壕溝火牆隔絕敵軍增援狀態機規格書

## 1. 系統定位與設計意圖

在三國攻防戰役（如郝昭陳倉圍城、張遼合肥孤軍拒敵）中，敵方往往擁有數倍於守軍之後續援軍，若正面承受連續波次衝擊必告失守。本系統規範防守工程與火攻特種機制「戰場壕溝猛火油阻絕火牆（Trench Firewall Reinforcement Block）」之燃料預置、引信爆發、火幕隔絕與包夾聚殲狀態機：
- **深壕暗置火油與金汁**：在主陣地前沿壕溝內預先鋪滿乾柴草束，澆灌稠化石脂（猛火油）與生石灰硫磺粉，並混入發酵生金汁。
- **割裂敵軍前後陣列**：放過敵先鋒部隊跨越壕溝進入內圈預設戰場後，火箭凌空引燃整條壕溝，瞬時騰起丈餘高之熾烈火牆。
- **孤立圍殲與增援阻絕**：後續大隊援軍被高溫火牆阻隔於外達數個時辰，前鋒淪為瓮中之鱉被守軍完全圍殲。

## 2. 狀態機架構與轉換生命週期

壕溝火牆狀態機（代碼：`TRENCH-FIREWALL-REINFORCEMENT-BLOCK01`）管理從燃料鋪設至火勢熄滅之完整週期：

```
[ FUEL_TRENCH_PREPARATION ] (壕溝鋪設乾柴猛火油與硫磺石脂)
          │
          ▼
[ ENEMY_VANGUARD_PASS ] (敵先鋒越過預設線引君入瓮)
          │
          ├── 先鋒過境規模達到臨界點
          ▼
[ FIRE_ARROW_IGNITION ] (守軍齊射硫磺火箭引燃火油壕溝)
          │
          ▼
[ BLAZING_FIREWALL_BARRIER ] (十里壕溝騰起丈高烈焰火牆)
          │
          ├── 敵援軍試圖強渡 ──> [ HEAT_REPULSION_DAMAGE ]
          ├── 敵工兵擔土填火 ──> [ CHEMICAL_TOXIC_SMOKE_FLARE ]
          ▼
[ ISOLATION_ANNIHILATION ] (分割包圍完全聚殲壕內孤立前鋒)
          │
          ▼
[ FUEL_EXHAUSTION_SMOLDER ] (火油燃盡餘燼悶燒留下焦黑溝壑)
```

### 狀態細部定義

1. **FUEL_TRENCH_PREPARATION（預置火料）**：
   - 工兵於寬八尺、深六尺之防禦壕內注入稠化猛火油 40 桶，鋪墊易燃松木柴排，表層撒薄土防蒸發。
2. **ENEMY_VANGUARD_PASS（誘敵深入）**：
   - 守軍故意放慢箭雨，放任敵軍先鋒部隊（約 1500~3000 人）跨越壕溝搭板或淺處挺進核心開闊地。
3. **FIRE_ARROW_IGNITION（火箭點火）**：
   - 守將一聲令下，十支浸染硫磺白磷之巨型火箭精準射入壕溝引燃點，烈火於 3 秒內沿溝渠蔓延三里。
4. **BLAZING_FIREWALL_BARRIER（火牆隔絕）**：
   - 火焰高度竄升達 1.5 丈（約 4.5 公尺），溫度突破 800 度，高溫熱浪形成天然不可逾越的屏障。
   - 敵後續援軍因烈焰灼燒與戰馬受驚無法前進，衝入火牆者每秒承受 65 點真實火焰傷害與馬匹潰散。
5. **ISOLATION_ANNIHILATION（分割聚殲）**：
   - 進入內側之敵先鋒退路全斷、背靠火海，士氣驟跌 40 點，守軍精銳合圍全殲。
6. **FUEL_EXHAUSTION_SMOLDER（熄火餘燼）**：
   - 燃燒維持 45 分鐘，燃盡後溝內高熱餘炭仍維持封鎖狀態 30 分鐘。

## 3. 關鍵數值與計算判定公式

### 3.1 熱輻射阻絕與士氣潰退公式

敵軍援軍被火牆阻退之意志檢定 $W_{resist}$：
$$W_{resist} = \text{Morale}_{troop} \times \left(1.0 - \frac{T_{fire} - 200}{1000}\right) - \text{SmokeSuffocation} \times 0.35$$
- $T_{fire}$：火牆中心溫度（最高 $850^\circ\text{C}$）。
- 當 $W_{resist} \le 25$ 時，敵軍後隊進入混亂推擠、拒絕推進狀態，踩踏逃離火線。

### 3.2 阻隔時間與燃料消耗平衡

火牆持續封鎖時間 $T_{burn}$（分鐘）計算：
$$T_{burn} = \frac{V_{oil\_volume} \times \rho_{density} \times Q_{combust}}{A_{trench} \times R_{burn\_rate} \times (1.0 + W_{wind} \times 0.15)}$$
- 確保在標準 40 桶猛火油配置下，火牆持續燃燒時長不少於 40 分鐘，足以完成內圈決戰。

## 4. 戰術連鎖與攻防克制

1. **戰略分割逆轉劣勢**：徹底化解敵軍總兵力優勢，將十萬大軍的龐大推力切斷為分散的小塊各個擊破。
2. **弱點與反制手段**：
   - **大風反噬**：若遭遇強烈逆風（如西北風呼嘯且向守軍營地吹拂），火煙將倒灌主陣地，迫使守軍放棄陣線。
   - **沙袋壓火**：敵軍若組織特種死士投擲數千包生土沙袋掩埋，可於 10 分鐘內強行砸開一條寬丈餘的冷卻缺口。

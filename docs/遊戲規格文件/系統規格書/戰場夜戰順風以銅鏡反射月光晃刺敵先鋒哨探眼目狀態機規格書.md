# 3KLife 戰場夜戰順風以銅鏡反射月光晃刺敵先鋒哨探眼目狀態機規格書

## 1. 系統定位與設計意圖

在三國夜戰對峙與要隘暗夜攻防中，黑夜既是進攻方偷營摸哨的天然掩護，也是防守方識別敵蹤的巨大盲點。本系統規範古代特種光學防禦偵查戰術「高坡青銅鏡聚光晃眩與哨探致盲系統（Moonlight Mirror Blinding Scout）」之月光反射追蹤、焦點晃射、先鋒短暫致盲與神射狙殺狀態機：
- **高位青銅凹凸反射鏡陣列**：守軍在制高點排設十二面磨光生生青銅曲面大鏡，由斥候旋轉木質萬向底座追蹤月相角度。
- **瞬時聚光晃射敵軍先鋒眼目**：當敵軍先鋒部隊暗夜潛伏摸索前進至開闊地時，青銅鏡群合力將反射月光聚焦於敵軍面部，製造強烈的白眩眩光。
- **破除夜間隱匿與引導狙擊**：敵先鋒被強光刺目陷入暫時性視雪症，瞳孔驟縮無法視物，戰馬驚足，我軍神射手藉由反射光暈精準點射敵軍領隊。

## 2. 狀態機架構與轉換生命週期

銅鏡光學防禦狀態機（代碼：`MOONLIGHT-MIRROR-BLINDING-SCOUT01`）管理自角度校準至破隱狙殺之完整週期：

```
[ LUNAR_PHASE_CALIBRATION ] (校準銅鏡底座仰角鎖定月光反射錐)
          │
          ▼
[ PERIMETER_SHADOW_WATCH ] (暗哨於盲區探測敵軍偷營微弱動靜)
          │
          ├── 捕捉敵先鋒移動輪廓 ──> [ TARGET_VECTOR_LOCK ]
          ▼
[ CONVERGENT_BEAM_FOCUS ] (十二面銅鏡聯動旋轉光斑聚焦敵目)
          │
          ▼
[ FLASH_BLINDING_DISORIENTATION ] (敵先鋒雙眼灼眩視力喪失失控失衡)
          │
          ├── 敵軍戰馬受驚嘶鳴 ──> [ STEED_PANIC_STALL ]
          ▼
[ ILLUMINATED_SNIPER_VOLLEY ] (光暈勾勒輪廓神射手居高精準點殺)
          │
          ▼
[ AMBUSH_COLLAPSE_RETREAT ] (敵夜襲偷營部隊徹底暴露狼狽撤退)
```

### 狀態細部定義

1. **LUNAR_PHASE_CALIBRATION（月相校準）**：
   - 觀天斥候依據滿月或弦月天頂角，調整銅鏡木架齒輪，使反射光錐在敵軍必經谷口投射出半徑五步之預備聚光點。
2. **PERIMETER_SHADOW_WATCH（暗影警戒）**：
   - 哨探隱於暗處，藉助地聽與微弱月光觀察三十步外草木晃動。
3. **CONVERGENT_BEAM_FOCUS（聚焦晃射）**：
   - 發現敵蹤瞬間，旗官打手勢，六組銅鏡同時旋動，將集中光斑投向敵軍領隊面部，照度瞬間提升 40 倍。
4. **FLASH_BLINDING_DISORIENTATION（強光致盲）**：
   - 敵先鋒自極暗環境突入強光直射，視網膜紫紅質瞬間漂白，陷入長達 20 秒之「白盲眩暈」狀態，命中率與閃避率歸零。
5. **STEED_PANIC_STALL（戰馬驚足）**：
   - 戰馬眼中突然出現閃爍光斑，本能受驚揚蹄長嘶，打亂整支偷營小隊的靜默潛行陣型。
6. **ILLUMINATED_SNIPER_VOLLEY（光暈點殺）**：
   - 銅鏡光暈反向照亮敵軍甲冑反光，我方崖頂強弩手連發射殺敵軍軍官，敵軍群龍無首潰退。

## 3. 關鍵數值與計算判定公式

### 3.1 銅鏡反射光照度與致盲判定

反射匯聚焦點光照度 $E_{focus}$（勒克斯，lux）計算公式：
$$E_{focus} = E_{moon} \times N_{mirrors} \times \eta_{polish} \times \frac{A_{mirror}}{S_{spot}} \times \cos(\theta_{inc})$$
- $E_{moon}$：月光自然基準照度（晴夜滿月約 $0.2\,\text{lux}$）。
- $N_{mirrors}$：聯動銅鏡數量（12 面）。
- $\eta_{polish}$：青銅研磨拋光率（約 0.78）。
- $A_{mirror} / S_{spot}$：鏡面至聚焦點面積比（聚光增益約 45 倍）。
- $\theta_{inc}$：光線入射夾角。
- 計算得焦點照度可達約 $35 \sim 50\,\text{lux}$，在全黑夜戰環境下足以對暗適應人眼形成致盲衝擊。

### 3.2 敵軍夜襲隱匿值破除效率

敵軍潛行隱匿評級 $\text{Stealth}_{enemy}$ 之破除折減：
$$\text{Stealth}_{after} = \max\left(0.0, \text{Stealth}_{base} - 0.75 \times \frac{E_{focus}}{30.0}\right)$$
- 強光覆蓋下，敵軍暗殺隱匿加成強制扣減 75%，完全喪失偷襲奇襲優勢。

## 4. 戰術連鎖與攻防克制

1. **低成本夜戰反制殺手鐧**：無須耗費火油木柴，僅憑自然月光與青銅鏡即可實現大範圍戰場防護。
2. **天敵與戰術反制**：
   - **烏雲遮月與大霧**：若遇陰天無月或長江濃霧，月光被阻斷，銅鏡光學系統完全失效。
   - **反光弓手盲射**：敵精銳老兵可依據高處銅鏡反射點，朝光源方向施放密集拋射盲箭。

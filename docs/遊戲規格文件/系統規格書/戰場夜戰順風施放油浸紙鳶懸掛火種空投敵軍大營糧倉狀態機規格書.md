# 3KLife 戰場夜戰順風施放油浸紙鳶懸掛火種空投敵軍大營糧倉狀態機規格書

## 1. 系統定位與設計意圖

在三國深溝高壘營寨對峙與堅城圍困戰（如官渡相持期、諸葛亮圍陳倉）中，敵軍大營外圍挖有多道壕溝並立起高聳木柵，地面火攻器械難以越過防線觸及敵軍核心糧倉。本系統規範三國特種空中奇襲裝置「順風施放大型桐油竹骨紙鳶懸掛定時火種空投糧倉系統（Incendiary Kite Airdrop Granary）」狀態機：
- **丈二翼展輕竹骨架與桐油宣紙鳶面**：以苦竹劈篾扎成巨燕形骨架，糊以三層浸塗熟桐油之加厚麻紙，升力強勁且夜間塗黑難以被肉眼察覺。
- **腹下懸掛慢燃香引與松脂猛火油竹籃**：紙鳶重心下方以浸硝麻繩懸吊裝滿固態松脂膏、硫磺顆粒與炭火球之輕竹籃，麻繩連接定長慢燃火香。
- **順風定距放索與燒斷懸繩精準空投**：工兵於上風處借夜色放飛紙鳶，透過絞車刻度計算飛抵敵軍糧倉正上方之斜距，待慢燃火香燒斷懸吊麻繩，火種竹籃垂直墜落糧垛頂部引發大火。

## 2. 狀態機架構與轉換生命週期

紙鳶空投火攻狀態機（代碼：`INCENDIARY-KITE-AIRDROP-GRANARY01`）流程如下：

```
[ KITE_FRAME_OIL_ASSEMBLY ] (工兵組裝丈二竹骨油紙鳶懸掛松脂火種籃)
           │
           ├── 夜間順風三級以上點燃定時香引升空
           ▼
[ NIGHT_UPDRAFT_CLIMB_GLIDE ] (紙鳶借夜風升至二十丈高空越過敵外圍寨牆)
           │
           ├── 絞車放索達預定斜距 ──> [ OVERHEAD_GRANARY_HOVER ]
           ▼
[ FUSE_CORD_BURN_SEVER ] (定時香引燒斷懸吊硝繩或地面主動剪斷主索)
           │
           ├── 火種竹籃垂直墜落砸中糧倉草頂
           ▼
[ PAYLOAD_FREEFALL_IGNITION ] (竹籃碎裂松脂硫磺膏爆燃引燃乾燥糧垛)
           │
           ▼
[ GRANARY_CONFLAGRATION_SPREAD ] (糧倉內部熱空氣對流形成沖天火柱)
           │
           ▼
[ ENEMY_REAR_CHAOS_DIVERSION ] (敵軍主力被迫回援救火前線防禦空虛)
```

### 狀態細部定義

1. **KITE_FRAME_OIL_ASSEMBLY（紙鳶整備）**：工兵校準竹骨對稱度，將 8 斤重之松脂硫磺火籃掛於重心點，依目標距離裁切香引。
2. **NIGHT_UPDRAFT_CLIMB_GLIDE（暗夜升空）**：借夜間穩定順風拉起紙鳶，升至 30 公尺高度，跨越敵軍護城河、鹿角與箭樓射界。
3. **OVERHEAD_GRANARY_HOVER（頂空懸停）**：絞盤停止放索，紙鳶穩定懸停於敵營後方糧草囤積區正上方。
4. **FUSE_CORD_BURN_SEVER（斷索投擲）**：慢燃香引燒至浸硝繩結處瞬間熔斷，火種竹籃脫離紙鳶自由落體。
5. **PAYLOAD_FREEFALL_IGNITION（墜地爆燃）**：竹籃砸穿糧倉茅草頂棚，內部炭火球與松脂膏劇烈噴火，點燃率達 90%。
6. **GRANARY_CONFLAGRATION_SPREAD（糧倉大火）**：乾燥糧袋與草料助長火勢，每秒燒毀敵軍 2% 總糧草儲備。
7. **ENEMY_REAR_CHAOS_DIVERSION（調虎離山）**：後營火起引發敵軍恐慌，敵將必須抽調 30% 前線守軍回救，創造正面攻城戰機。

## 3. 數值模型與物理演算

### 紙鳶升力與載重平衡公式

$$L_{lift} = \frac{1}{2} \rho_{air} \times V_{wind}^2 \times A_{kite} \times C_L \ge \left(M_{kite} + M_{payload} + M_{rope}\right) \times g$$

- $A_{kite}$：紙鳶翼面積（$4.5\,\text{m}^2$）；$M_{payload}$：火種籃重量（4kg）。
- 需順風風速 $V_{wind} \ge 4.5\,\text{m/s}$（3 級風以上）方可穩定升空；若低於 $3.0\,\text{m/s}$ 則失速墜落。

### 空投落點散佈圓機差（CEP）公式

$$R_{scatter} = 2.0 + 0.04 \times H_{altitude} + 0.8 \times \sigma_{turbulence}$$

- $H_{altitude}$：投擲高度（公尺）。在 30 公尺高度投擲時，落點誤差半徑約 4 公尺，足以精準命中大型糧垛。

## 4. 戰場戰術連鎖與部隊生剋

1. **無視地面一切防禦工事**：直接跨越高牆、深溝與塞門刀車，從高空直擊敵軍後勤心臟。
2. **夜戰隱蔽性極高**：黑色油紙鳶在夜空中無聲滑翔，被提前射落率低於 10%。
3. **強風扯斷風箏線風險**：若遇 6 級以上狂風，麻繩張力超標可能崩斷，導致紙鳶飄離目標區。

## 6. 驗證標準與測試用例 (TC)

- **TC-KITE-AIRDROP-01（起飛風速門檻）**：風速 $5.0\,\text{m/s}$ 時紙鳶爬升至 30 公尺；風速 $2.0\,\text{m/s}$ 時禁止升空。
- **TC-KITE-AIRDROP-02（定時斷繩空投）**：`fuseRemainingSeconds` 歸零時，立即觸發 `FUSE_CORD_BURN_SEVER` 並計算落點。
- **TC-KITE-AIRDROP-03（糧倉起火扣糧）**：命中糧倉後，`isGranaryIgnited` 為 `true`，敵軍糧草儲備每秒穩定扣減。

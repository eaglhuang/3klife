# 戰場夜戰順風施放油浸蘆葦浮筏偽裝暗藏水鬼奇襲敵軍水門狀態機規格書

> **來源**：三國江東與荊州水戰奇襲戰術「荻葦浮筏藏兵」（於竹木小筏上方厚鋪天然蘆葦與油浸乾荻，外觀如江面隨波逐流之荒草浮島；水鬼精兵潛伏於筏底水下呼吸，待浮筏順風漂抵敵軍水寨柵門時，水鬼自水底暴起砍斷門栓，同時引燃頂部油浸蘆葦焚毀水門）、WBS `FORM-151` 水戰兩棲偽裝奇襲模組。
> **關聯文件**：`doc_spec_0871`（水鬼口銜蘆管鑿船）、`doc_spec_0891`（輕舟荻草火帆衝撞）、`doc_spec_0902`（載油皮筏撞擊水門）。

---

## 一、 設計目標與戰術定位

一般火船或載油皮筏在接近敵軍水寨時，容易因體積醒目或火光早露而被水寨哨塔提前以床弩擊沉。「油浸蘆葦偽裝浮筏」則採取「未接敵前不點火、水下暗藏精兵」的雙層滲透設計：上半部為未點燃的天然青乾蘆葦（與夜間江岸葦蕩融為一體），下半部懸吊 1 隊精銳水鬼。直到浮筏緊貼敵軍水門，才同步觸發「水鬼破栓開門」與「引燃蘆葦火障」。

1. **漂流荒草偽裝（Drifting Reed Camouflage）**：未點火前在敵方視野中顯示為中立自然漂流物，不會觸發敵方箭塔與巡邏艇之自動警戒射擊。
2. **筏底掛載水鬼（Submerged Frogman Escort）**：水鬼匿於筏底竹框內順流省力漂行（體力消耗為 `0`），免除長距離潛泳之窒息風險。
3. **破門與火障雙重打擊**：抵達水門時，水鬼自水底潛入斬殺守門兵並拔除門栓，隨即點燃筏面油浸蘆葦，阻絕敵軍回援奪門。

## 二、 狀態機生命週期（5 階段）

```
[1. 編葦藏兵 Reed_Raft_Submerge]
       │ (夜間順流 + 水鬼掛載於筏底 + 不點火隱蔽)
       ▼
[2. 隨波偽裝 Camouflaged_River_Drift]
       │ (免疫敵方哨塔自動索敵，每回合順流漂移 3 格)
       ▼
[3. 抵門暴起 Water_Gate_Infiltration]
       │ (貼靠敵水門：水鬼登岸背刺守衛，強制開啟水門)
       ▼
[4. 點葦封路 Ignite_Reed_Fireblock]
       │ (引燃筏面油浸蘆葦：於水門內側形成 2x2 火障)
       ▼
[5. 主力貫入 Fleet_Breach_Entry]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `REED_RAFT_SUBMERGE` | 編葦藏兵 | 我方水鬼編隊於上游鑽入油浸蘆葦浮筏底部，進入完全隱匿狀態（`Stealth_Level = 3`）。 |
| `CAMOUFLAGED_RIVER_DRIFT` | 隨波偽裝 | 浮筏順水流與微風每回合漂進 `3` 格；敵方若未派遣斥候船貼身至 `1` 格內強行探查，哨塔與弓兵將完全忽略此浮筏。 |
| `WATER_GATE_INFILTRATION` | 抵門暴起 | 浮筏觸碰敵軍水寨大門時，水鬼自水下暴起突襲門樓守軍（首擊必定暴擊 `2.0x`），並於 1 回合內拉開水門鐵栓（`Gate_Opened = true`）。 |
| `IGNITE_REED_FIREBLOCK` | 點葦封路 | 水鬼開門後立即擊碎火石點燃空筏，將燃燒的油浸蘆葦推入水寨內側通道，形成持續 `3` 回合之 `2x2` 格水上火牆，阻斷敵寨主隊回救。 |
| `FLEET_BREACH_ENTRY` | 主力貫入 | 我方後續蒙衝鬥艦順著敞開的水門長驅直入，對水寨內部船隻獲得 `+25%` 奇襲增傷。 |

## 三、 核心數值與判定公式

### 3.1 偽裝識破檢定公式（Camouflage Detection Check）
$$P_{\text{detect}} = \text{clamp}\left(0.10 + \frac{\text{INT}_{\text{sentry}} - 70}{200} - 0.25 \times \mathbb{I}_{\text{nightFog}},\ 0.02,\ 0.65\right)$$
- 僅當敵方哨兵進入浮筏 `1` 格內時才執行此檢定；若處於夜間或江霧（$\mathbb{I}_{\text{nightFog}} = 1$），識破率極低（最低 `2%`）。

### 3.2 水鬼破門背刺傷害公式（Gate Ambush Backstab）
$$D_{\text{ambush}} = \text{ATK}_{\text{frogman}} \times 2.0 \times \left(1 + 0.30 \times \mathbb{I}_{\text{undetected}}\right)$$
- 若浮筏直到貼靠水門均未被識破，水鬼額外獲得 `+30%` 破隱背刺加成。

## 五、 驗收測試案例（Acceptance Tests）

| 測試代號 | 測試場景與輸入條件 | 預期輸出與狀態轉移結果 |
| :--- | :--- | :--- |
| `TC-RRFR-01` | 蘆葦浮筏於夜間經過敵方水寨箭塔射程（距離 `2` 格）。 | 因距離 $>1$ 格且處於 `CAMOUFLAGED_RIVER_DRIFT`，箭塔不開火，水鬼體力零消耗。 |
| `TC-RRFR-02` | 浮筏未被識破並成功漂抵敵軍水門。 | 觸發 `WATER_GATE_INFILTRATION`，水鬼對守門兵造成 $2.0 \times 1.3 = 2.6$ 倍背刺傷害並打開水門。 |
| `TC-RRFR-03` | 水門開啟後執行 `IGNITE_REED_FIREBLOCK`。 | 水門內側 `2x2` 格化為火障 3 回合，阻擋敵軍水寨內營援兵靠近水門。 |
| `TC-RRFR-04` | 浮筏漂行途中被敵方巡邏快艇貼近至 `1` 格且通過識破檢定。 | 偽裝解除，水鬼被迫提前於江心棄筏潛水應戰，無法直接觸發無傷開門。 |

# 3KLife 戰場夜戰順風施放竹筒毒煙瘴氣迷霧削弱敵軍視野與體力狀態機規格書

## 1. 系統定位與設計意圖

在三國南方山地叢林與夜戰攻防（如諸葛亮七擒孟獲南中瘴氣之戰、山越密林伏擊戰）中，利用順風燃放裝填川烏、狼毒、硫磺與乾燥艾草之巨型毛竹煙筒，製造貼地蔓延的濃烈辛辣迷霧，是癱瘓敵軍陣型視野並急速消耗其體力的奇兵戰術。本系統規範「順風燃放竹筒毒煙瘴氣迷霧削弱系統（Bamboo Miasma Smoke Weaken）」狀態機：
- **三節大毛竹裝填辛辣草藥發煙劑**：選用直徑半尺之老毛竹筒，內層分格夯實硫磺、焰硝、乾辣椒、狼毒草末與濕松針，點燃後只出濃密黃黑煙霧而不起明火。
- **順風貼地平流形成百步毒瘴帶**：煙氣比重較空氣略重，順風緊貼地表三尺高度平流推進，迅速籠罩敵軍步騎陣列，使視距壓縮至五步以內。
- **劇烈嗆咳削弱體力與命中率**：未佩戴濕布面巾之敵兵吸入辛辣毒煙後涕淚橫流、劇烈喘咳，體力恢復完全中斷，近戰格擋與遠程射擊精準度大幅衰退。

## 2. 狀態機架構與轉換生命週期

竹筒毒煙瘴氣狀態機（代碼：`BAMBOO-MIASMA-SMOKE-WEAKEN01`）流程如下：

```
[ BAMBOO_TUBE_ARRAY_SETUP ] (上風處密林工兵排布百具三節發煙毛竹筒)
           │
           ├── 夜間或順風三級以上引信點火
           ▼
[ SMOLDERING_FUME_GENERATION ] (硫磺草藥陰燃噴湧高濃度黃黑辛辣濃煙)
           │
           ├── 順風貼地推進籠罩敵陣 ──> [ DOWNWIND_MIASMA_ADVECTION ]
           ▼
[ VISION_OCCLUSION_BLINDNESS ] (煙幕完全遮蔽視線敵軍遠程索敵失效)
           │
           ├── 敵兵持續吸入毒煙引發劇烈嗆咳
           ▼
[ RESPIRATORY_CHOKING_DRAIN ] (體力急速流失且移動與揮砍速度驟降)
           │
           ▼
[ FORMATION_DISORDER_PANIC ] (陣列前後失去聯繫陷入混亂盲目互撞)
           │
           ▼
[ WIND_DISPERSION_DISSIPATE ] (九十秒後藥盡煙散我軍伏兵趁勢掩殺)
```

### 狀態細部定義

1. **BAMBOO_TUBE_ARRAY_SETUP（竹筒排布）**：工兵於上風口陣線每隔兩步斜插一具大竹筒，筒口對準敵軍主力集結區。
2. **SMOLDERING_FUME_GENERATION（陰燃發煙）**：引信點燃後內部草藥受熱陰燃，每具竹筒每秒釋放 15 立方公尺濃煙。
3. **DOWNWIND_MIASMA_ADVECTION（順風平流）**：煙霧隨風以每秒 3 公尺速度貼地席捲，10 秒內覆蓋前方百步寬、八十步深之戰區。
4. **VISION_OCCLUSION_BLINDNESS（視野剝奪）**：煙區內敵軍視野半徑由 60 步強制壓縮至 5 步，弓弩手失去遠程目標鎖定能力。
5. **RESPIRATORY_CHOKING_DRAIN（嗆咳虛弱）**：暴露於毒煙中之敵軍每秒流失 3 點體力，攻擊力與防禦力雙雙下降 25%。
6. **FORMATION_DISORDER_PANIC（陣型潰亂）**：持續受煙熏超過 20 秒之部隊，指揮傳令中斷，陷入【混亂失控】狀態。
7. **WIND_DISPERSION_DISSIPATE（煙散突擊）**：竹筒藥料燃盡後濃煙隨風消散，我軍口銜解毒含片與濕巾之伏兵立即發起總攻。

## 3. 數值模型與物理演算

### 毒煙濃度擴散與視野衰減公式

$$C_{smoke}(d, t) = C_0 \times e^{-\frac{d}{20 \times W_{speed}}} \times \min\left(1.0, \frac{t}{10}\right)$$

$$\text{VisionRange} = \max\left(5, \; V_{base} \times (1.0 - 0.85 \times C_{smoke})\right)$$

- $C_{smoke}$：距離發煙源 $d$ 公尺處之煙霧濃度（$0 \sim 1.0$）。
- 當 $C_{smoke} \ge 0.7$ 時，敵軍遠程命中率直接扣減 70%。

### 體力流失與抗性減免公式

$$\Delta \text{Stamina}_{sec} = -3.5 \times C_{smoke} \times (1.0 - 0.6 \times \text{HasWetMask})$$

- 若敵軍預先裝備【浸水麻布面巾（`HasWetMask = true`）】，體力流失與屬性懲罰可減免 60%。

## 4. 戰場戰術連鎖與部隊生剋

1. **遠程弓弩陣列剋星**：徹底廢除敵軍強弩營與連弩手之射程優勢，迫使其在致盲狀態下被近戰步兵貼身收割。
2. **風向逆轉反噬風險**：若戰場突發【風向逆轉（逆風）】，毒煙將倒灌回己方陣地，工兵必須立即以泥土封堵竹筒口。
3. **大雨天氣減效**：在豪雨環境下，煙霧微粒受雨水沖刷沉降，擴散距離與持續時間均縮減 50%。

## 6. 驗證標準與測試用例 (TC)

- **TC-MIASMA-01（順風視野壓縮）**：濃度達 0.8 時，煙區內敵軍視野必須壓縮至 $\le 8$ 步，遠程命中率下降 $\ge 60\%$。
- **TC-MIASMA-02（持續體力扣除）**：未戴濕巾之敵兵在煙區停留 10 秒，體力必須累計扣除 $\ge 25$ 點。
- **TC-MIASMA-03（逆風緊急封堵）**：當風向轉為逆風時，自動觸發封堵警告並計算煙霧反向漂移向量。

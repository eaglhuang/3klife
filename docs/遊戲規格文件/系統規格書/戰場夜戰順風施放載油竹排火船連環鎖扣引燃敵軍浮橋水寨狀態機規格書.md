# 戰場夜戰順風施放載油竹排火船連環鎖扣引燃敵軍浮橋水寨狀態機規格書

> **來源**：三國水戰破除浮橋與水寨之「連環火排」（以兩具或多具巨型毛竹排滿載浸油柴草、硫磺火塊，首尾以長鐵鏈相連，順流張帆漂放，使鐵鏈呈一字橫攔兜住敵軍浮橋橋墩或水寨柵柱，兩翼火排順水勢向內合攏夾擊焚燒）、WBS `FORM-145` 水戰夜襲火攻模組。
> **關聯文件**：`doc_spec_0834`（火炬大筏燒熔橫鎖）、`doc_spec_0835`（水寨浮橋攻防）、`doc_spec_0902`（載油皮筏撞擊水門）。

---

## 一、 設計目標與戰術定位

單艘火船或火筏順流衝擊敵軍浮橋時，往往容易從橋孔縫隙穿過或被守軍以長竿撐開。而「連環鎖扣載油竹排」則利用兩具竹排之間長達十丈的生鐵橫鏈，在江面上形成寬達 `3` 格的攔截網。一旦中間鐵鏈勾住浮橋橋舟或水寨中心木樁，兩端竹排便會受水流推力自動向內旋擺合抱，死死貼住目標猛烈燃燒。

1. **雙排連環橫向掃掠（3 格寬攔截帶）**：鐵鏈連接兩具火排，橫向覆蓋 3 格水域，敵軍水鬼或撐篙兵無法單點推開。
2. **水流旋擺合抱鎖死（Hydro-Clamp Lock）**：鐵鏈觸碰橋墩後，左右兩具火排順水勢向內合攏夾死浮橋，使火勢集中於同一橋段。
3. **順風燒斷浮橋與截斷兩岸**：浮橋燒斷後，正在橋面上通行的敵軍步騎全數落水，兩岸敵軍指揮與增援徹底斷絕。

## 二、 狀態機生命週期（5 階段）

```
[1. 上游聯排 Twin_Raft_Chain_Link]
       │ (夜間順流 + 順風 Wind >= 2 + 點燃引火硫磺)
       ▼
[2. 張帆漂掠 Downriver_Wide_Sweep]
       │ (橫向 3 格寬度順流推進，無視單點撐篙推離)
       ▼
[3. 鐵鏈兜樁 Chain_Snag_Pontoon_Pier]
       │ (中段鐵鏈兜住浮橋/水柵，兩翼火排向內旋擺合抱)
       ▼
[4. 烈焰斷橋 Pontoon_Bridge_Conflagration]
       │ (每秒結構火傷 3.5x，橋面敵軍落水溺亡)
       ▼
[5. 江道斷絕 River_Crossing_Severed]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `TWIN_RAFT_CHAIN_LINK` | 上游聯排 | 我方水軍於敵浮橋上游佈署兩具載油竹排，中間以十丈生鐵鏈橫連，展開寬 `3` 格之火攻正面。 |
| `DOWNRIVER_WIDE_SWEEP` | 張帆漂掠 | 順流加順風（`Wind >= 2`）每回合前進 `4` 格；因雙排連環配重，敵方單隊「長竿撐離」判定直接失效。 |
| `CHAIN_SNAG_PONTOON_PIER` | 鐵鏈兜樁 | 鐵鏈率先撞上敵軍浮橋錨舟或水寨木樁，左右兩具火排受水流推力向內 `90` 度合攏，死死夾住橋體（`Clamped = true`）。 |
| `PONTOON_BRIDGE_CONFLAGRATION` | 烈焰斷橋 | 雙排桐油火海夾擊橋身，對浮橋或水柵造成 `3.5x` 焚燒傷害，並引燃鄰近 `2` 格橋段。 |
| `RIVER_CROSSING_SEVERED` | 江道斷絕 | 浮橋耐久歸零斷裂，橋上敵軍全數墜江（重甲部隊溺亡率 `85%`），敵軍兩岸增援路線中斷。 |

## 三、 核心數值與判定公式

### 3.1 旋擺合抱焚橋傷害公式（Hydro-Clamp Burn Damage）
$$D_{\text{pontoon}} = D_{\text{fireBase}} \times 3.5 \times \left(1 + 0.20 \times V_{\text{current}} + 0.15 \times V_{\text{wind}}\right)$$
- $V_{\text{current}}$：江水流速等級（`1 ~ 4`）；流速越快，雙排向內夾緊力道越強，火油滲透越深。

### 3.2 斷橋落水傷亡率公式（Bridge Collapse Drowning Rate）
$$R_{\text{drown}} = \text{clamp}\left(0.45 + W_{\text{armor}} \times 0.20 - S_{\text{navy}} \times 0.15,\ 0.15,\ 0.90\right)$$
- $W_{\text{armor}}$：落水部隊護甲重量（輕甲 `0.5`、重甲 `2.0`）；$S_{\text{navy}}$：部隊水戰適性等級（`0 ~ 3`）。

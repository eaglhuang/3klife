# 戰場夜戰順風施放雙層油浸竹編火籠滾落山坡焚毀敵軍鹿角營寨狀態機規格書

> **來源**：《武經總要》守城與山地火攻器械「火籠」（以青竹編織雙層圓球籠，內實乾草、松脂、硫磺火塊，外塗猛火油，順山坡滾落衝破敵軍鹿角拒馬並引燃營寨）、WBS `FORM-142` 戰場山地夜戰火攻模組。
> **關聯文件**：`doc_spec_0896`（斜坡滾放生鐵火雷）、`doc_spec_0880`（鹿角拒馬防禦）、`doc_spec_0911`（風帆火輪車）。

---

## 一、 設計目標與戰術定位

「雙層油浸竹編火籠」為山地與高坡夜戰中極具毀滅性的低成本重力火攻器械。不同於沉重但數量稀少的生鐵火雷，竹編火籠重量輕、彈性佳、體積碩大（直徑五尺），能跳躍越過小型溝坎，專門用於清理敵軍在山坡下密集架設的「鹿角拒馬」與「木柵前哨」。

1. **順坡滾動加速與彈性跳躍**：雙層交錯竹篾具備結構彈性，滾落途中遇到碎石不致碎裂，反而能彈跳壓入敵陣深處。
2. **嵌合鹿角拒馬與持續爆燃**：竹籠空隙極易與鹿角枝杈咬合卡死，使敵軍工兵無法用長鉤推開，直接將整排拒馬化為火牆。
3. **順風火舌延燒營帳**：夜間順風（`Wind_Speed >= 2`）時，火籠內的松脂硫磺塊隨滾動甩出火星，在滾動軌跡上留下一條連續燃燒帶。

## 二、 狀態機生命週期（5 階段）

```
[1. 坡頂列籠 Cage_Slope_Array]
       │ (夜間 + 高地落差 >= 2 + 點燃內芯松脂)
       ▼
[2. 順坡彈滾 Rolling_Bounce_Descent]
       │ (沿坡面滾落 4~6 格，軌跡鋪設火焰地格)
       ▼
[3. 咬合焚障 Entangle_Abatis_Burn]
       │ (撞擊鹿角/木柵：卡死不可推開，耐久每秒 -30%)
       ▼
[4. 順風燎營 Downwind_Camp_Conflagration]
       │ (順風引燃鄰近 2 格營帳，敵軍驚惶逃散)
       ▼
[5. 灰燼破口 Ash_Breach_Opened]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `CAGE_SLOPE_ARRAY` | 坡頂列籠 | 我方佔領高坡（高度差 $\Delta H \ge 2$），工兵於坡頂並列架設 6 具直徑五尺之雙層油浸竹火籠。 |
| `ROLLING_BOUNCE_DESCENT` | 順坡彈滾 | 斬斷攔木同時推落，火籠沿斜坡滾動 `4 ~ 6` 格；途經步兵時造成 `130%` 碾壓火傷，並在軌跡上留下持續 2 回合之「火徑」。 |
| `ENTANGLE_ABATIS_BURN` | 咬合焚障 | 撞擊敵軍鹿角拒馬或木柵時，竹篾與木刺死死咬合（免疫敵工兵「長鉤推離」），對障礙物造成 `3.2x` 結構灼燒傷害。 |
| `DOWNWIND_CAMP_CONFLAGRATION` | 順風燎營 | 若處於順風（`Wind >= 2`），火籠爆裂噴出松脂火球，引燃後方 `2` 格內之敵軍營帳，觸發「火嘯驚營（士氣 `-25`，防禦 `-20%`）」。 |
| `ASH_BREACH_OPENED` | 灰燼破口 | 鹿角與木柵燒成灰燼，清理出寬 `3` 格之進攻破口，我方山地步騎下坡衝鋒移動消耗減半。 |

## 三、 核心數值與判定公式

### 3.1 滾動距離與火徑擴散公式（Rolling Distance & Trail）
$$L_{\text{roll}} = \min\left(7,\ 3 + \lfloor \Delta H \times 0.8 \rfloor + \lfloor V_{\text{wind}} \times 0.5 \rfloor\right)$$
- $\Delta H$：坡頂與敵營之高度差；$V_{\text{wind}}$：順風風速等級（`0 ~ 5`）。

### 3.2 對木質工事焚毀傷害公式（Obstacle Burn Damage）
$$D_{\text{abatis}} = D_{\text{fireBase}} \times 3.2 \times (1 + 0.15 \times V_{\text{wind}}) \times (1 - 0.5 \times \mathbb{I}_{\text{bitumenCoated}})$$
- $\mathbb{I}_{\text{bitumenCoated}}$：若敵軍鹿角塗有防火泥漿則減傷 `50%`；若塗抹易燃瀝青則反向增傷 `+40%`。

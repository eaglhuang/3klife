# 戰場夜戰順風施放雙層油浸竹編飛火流星索滑降焚毀敵軍峽谷吊橋狀態機規格書

> **來源**：三國山地與峽谷攻防戰術「飛索溜火」（於高崖頂端與峽谷吊橋或敵寨支撐柱之間，以強弩射出帶生鐵倒鉤之浸水生牛皮包鐵芯長索固定，再將滿裝松脂、硫磺、猛火油之雙層竹編火籃掛上青銅滑輪，沿斜拉飛索凌空高速滑降，精準撞擊峽谷木吊橋或懸崖棧道樞紐）、WBS `FORM-160` 山地高空溜索火攻模組。
> **關聯文件**：`doc_spec_0852`（秦嶺木棧道斷柱縱火）、`doc_spec_0914`（油浸紙鳶空投火種）、`doc_spec_0923`（雙層竹編火籠滾坡）。

## 一、 設計目標與戰術定位

在深谷、斷崖或護城河極寬的險要地形中，地面火車無法跨越深淵，而紙鳶或木鵲又容易受峽谷亂流影響偏離目標。「飛火流星索滑降」則透過重型床弩先行發射抓鉤鐵索釘入對岸吊橋主塔，建立一條空中導軌，隨後連續滑放數十枚「雙層油浸竹編火流星籃」，100% 必中敵軍吊橋橋頭堡或棧道木柱。

1. **鐵鉤飛索導軌鎖定（Grapple Zip-Line Lock）**：一旦床弩鉤索命中目標建築（射程 `4 ~ 8` 格），後續滑放之火流星籃完全無視風向偏折，達成 `100%` 軌跡必中。
2. **高空滑降無視地形與地面攔截**：火流星籃懸空沿索滑行，地面拒馬、壕溝與盾牆均無法攔截。
3. **橋頭疊加爆燃與斷橋孤立**：多枚火籃連續撞擊同一吊橋錨點，迅速燒斷承重藤索與木梁，使正在過橋之敵軍墜谷並切斷峽谷通道。

## 二、 狀態機生命週期（5 階段）

```
[1. 弩射鉤索 Ballista_Grapple_Anchor]
       │ (高地落差 >= 2，射出包鐵飛索釘入 4~8 格吊橋/棧道)
       ▼
[2. 掛輪點籃 Pulley_Fire_Basket_Ignite]
       │ (青銅滑輪掛載松脂猛火油竹籃，引燃內芯)
       ▼
[3. 凌空流星 Zip_Line_Meteor_Glide]
       │ (沿斜索高速滑降：無視地面阻擋，100% 必中錨點)
       ▼
[4. 撞塔焚索 Bridge_Tower_Conflagration]
       │ (對吊橋/木棧道造成 340% 結構火傷，橋面鋪設火海)
       ▼
[5. 索斷墜淵 Canyon_Bridge_Collapse]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `BALLISTA_GRAPPLE_ANCHOR` | 弩射鉤索 | 我方工兵於高崖（高度差 $\Delta H \ge 2$）以床弩射出包皮鐵芯飛索，釘入 `4 ~ 8` 格遠之敵方峽谷吊橋或木寨（建立 `Zip_Line_Connected = true`）。 |
| `PULLEY_FIRE_BASKET_IGNITE` | 掛輪點籃 | 將雙層油浸竹火籃透過青銅雙槽滑輪扣上飛索，點燃松脂硫磺引信。 |
| `ZIP_LINE_METEOR_GLIDE` | 凌空流星 | 火籃受重力沿斜索極速滑下，無視沿途深谷、河流與地面敵軍盾陣，當回合直達目標錨點（命中率固定 `100%`）。 |
| `BRIDGE_TOWER_CONFLAGRATION` | 撞塔焚索 | 火籃猛烈撞擊吊橋主纜與橋面板，造成 `340%` 結構火傷，並使整座吊橋 `1x3` 格化為烈焰通道。 |
| `CANYON_BRIDGE_COLLAPSE` | 索斷墜淵 | 吊橋耐久歸零崩塌，橋上敵軍全數墜入百丈深淵（直接陣亡率 `95%`），峽谷通道徹底封死。 |

## 三、 核心數值與判定公式

### 3.1 溜索滑降動能與火傷加成公式（Zip-Line Kinetic Fire Damage）
$$D_{\text{zipFire}} = D_{\text{fireBase}} \times 3.40 \times \left(1 + 0.15 \times \Delta H + 0.10 \times V_{\text{wind}}\right)$$
- $\Delta H$：發射崖頂與目標吊橋之高度差（落差越大，滑降撞擊碎裂時火油噴濺範圍越廣）。

### 3.2 敵軍斬索反制檢定（Cable Cut Counter-Check）
$$P_{\text{cut}} = \text{clamp}\left(0.20 + (\text{STR}_{\text{defender}} - 80) \times 0.02,\ 0.05,\ 0.60\right)$$
- 飛索外表裹有浸水生牛皮與鐵絲，普通刀劍極難砍斷；唯有橋頭駐守高武力猛將（`STR >= 85`）持重斧大刀專職劈砍，方有機率在火籃抵達前斬斷飛索。

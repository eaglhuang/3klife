# 3KLife 戰場夜戰順風施放雙輪連環風力旋轉火叉車破除敵軍藤牌步兵陣狀態機規格書

## 1. 系統定位與設計意圖

在三國南方山地與平原攻堅作戰（如諸葛亮平定南中破藤牌蠻兵、吳軍討伐山越藤盾陣）中，敵軍常持浸油藤牌或輕木圓盾結成高機動密集陣列，普通火箭容易被盾面斜角彈開。本系統規範三國特種機械火器「順風推放雙輪連環齒輪傳動旋轉火叉車破除藤牌陣系統（Wind-Rotary Fire-Fork Cart）」狀態機：
- **車輪軸心木齒輪連動前方十字旋轉鐵叉**：雙輪滾動時透過生鐵包裹之木製傘齒輪組，帶動車頭前方伸出之四支長六尺、倒刺分叉之生鐵火叉作高速風車式旋轉。
- **火叉纏繞浸油麻繩與松脂膏球**：四支鐵叉尖端死死捆紮浸滿熟桐油、松脂與硫磺之麻絨火球，隨車輪前進在空中畫出直徑一丈之烈焰火環。
- **順風助推高速絞碎並引燃藤牌**：火叉車借順風與微坡推入敵陣時，高速旋轉之倒刺火叉直接勾住並撕扯敵兵手中藤牌與皮盾，將火球強行嵌貼於藤牌表面，瞬間引發全排藤牌手連環爆燃。

## 2. 狀態機架構與轉換生命週期

風力旋轉火叉車狀態機（代碼：`WIND-ROTARY-FIRE-FORK-CART01`）流程如下：

```
[ GEAR_AXLE_FORK_ENGAGE ] (工兵扣合車軸傘齒輪點燃前端四支松脂火叉)
           │
           ├── 順風推放火叉車加速滾進
           ▼
[ WHEEL_DRIVEN_BLAZE_SPIN ] (車輪帶動十字火叉高速旋轉形成丈寬火輪)
           │
           ├── 衝入敵軍密集藤牌步兵陣列 ──> [ RATTAN_SHIELD_SNAG_HOOK ]
           ▼
[ CENTRIFUGAL_WRENCH_IGNITE ] (倒刺鐵叉扯飛藤牌並將松脂火膏甩貼敵身)
           │
           ├── 順風吹動火焰沿藤牌陣橫向蔓延
           ▼
[ SHIELD_WALL_CHAIN_CONFLAGRATION ] (整排藤牌兵起火潰散防線徹底瓦解)
           │
           ▼
[ AXLE_LOCK_STATIONARY_PYRE ] (車體卡入敵陣中心化為固定旋轉火柱)
```

### 狀態細部定義

1. **GEAR_AXLE_FORK_ENGAGE（齒輪咬合）**：工兵扳動離合木桿使車輪主軸與前伸火叉軸咬合，點燃四端松脂火球。
2. **WHEEL_DRIVEN_BLAZE_SPIN（風輪疾轉）**：車體每前進一丈，前方十字火叉旋轉三圈，離心力將火星向四周甩射三步。
3. **RATTAN_SHIELD_SNAG_HOOK（勾盾絞刺）**：火叉衝撞敵方盾牆，三棱倒刺直接刺穿並勾住藤牌與木盾邊緣，無法被彈開。
4. **CENTRIFUGAL_WRENCH_IGNITE（扯盾貼火）**：旋轉扭力強行將敵兵手臂扭傷並扯脫藤牌，黏稠松脂火膏直接糊滿敵兵胸腹。
5. **SHIELD_WALL_CHAIN_CONFLAGRATION（連環焚陣）**：藤牌與藤甲遇松脂火膏瞬間達成 100% 引燃，火勢在 3 秒內傳遍前排十名步兵。
6. **AXLE_LOCK_STATIONARY_PYRE（定點火柱）**：火叉車深入敵陣三丈後停止前進，車體本身劇烈燃燒持續 45 秒，封鎖敵軍重整陣型。

## 3. 數值模型與物理演算

### 車速轉換火叉角速度與扯盾機率公式

$$\omega_{fork} = \frac{V_{cart}}{R_{wheel}} \times G_{ratio}$$

$$P_{snag\_shield} = \min\left(0.95, \; 0.50 + 0.04 \times \omega_{fork} + 0.25 \times \text{IsRattanOrWood}\right)$$

- $G_{ratio}$：齒輪加速比（2.5）；當車速 $V_{cart} = 6\,\text{m/s}$ 時，火叉轉速高達 $25\,\text{rad/s}$。
- 對藤牌與木盾之勾扯破防率高達 95%，完全無視藤牌之箭矢彈開特性。

### 旋轉火環範圍灼燒傷害公式

$$D_{rotary\_fire} = \left(D_{pierce} + D_{fire\_base} \times 2.2\right) \times (1.0 + 0.15 \times W_{wind})$$

- 兼具機械穿刺與雙倍松脂火傷，藤牌兵承受時額外觸發 3.5 倍弱點放大。

## 4. 戰場戰術連鎖與部隊生剋

1. **藤牌兵與藤甲軍天敵**：徹底解決普通火箭被藤牌彈開的難題，以機械勾刺強行將火種送入藤甲內部。
2. **長柄大錘砸軸反制**：若敵軍派持長柄鐵錘或大砍刀之重裝勇士自側面砸斷火叉木齒輪軸，可使火叉停止旋轉。
3. **泥濘地面打滑限制**：在雨天泥濘地形中，車輪打滑會導致火叉轉速下降 60%。

## 6. 驗證標準與測試用例 (TC)

- **TC-FIRE-FORK-01（車輪連動轉速）**：車速達 $6\,\text{m/s}$ 時，`forkAngularVelocityRad` 必須 $\ge 20\,\text{rad/s}$。
- **TC-FIRE-FORK-02（無視藤牌彈開）**：衝擊擁有 95% 箭矢彈開率之藤牌兵時，火叉必須 100% 命中並觸發扯盾引燃。
- **TC-FIRE-FORK-03（齒輪受損停轉）**：當 `isGearIntact` 被打成 `false` 時，火叉轉速立即歸零，僅保留基礎碰撞。

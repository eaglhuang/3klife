# 戰場夜戰順風施放雙輪連環風力鼓風毒煙車推進壓制敵軍弓弩陣狀態機規格書

> **來源**：《墨子·備穴》與《武經總要》火攻煙戰器械「行煙車／風箱毒煙車」（以雙輪木車裝載生鐵炭爐與車軸連桿驅動之雙動木風箱，爐內焚燒狼毒、皂角、川烏、硫磺與濕艾草；工兵於車後生牛皮盾牌掩護下順風推車前行，車輪轉動自動壓動風箱噴出三十步濃密貼地黃黑毒煙，專門廢除敵軍強弓勁弩陣列之視線與呼吸）、WBS `FORM-157` 戰場移動毒煙掩護模組。
> **關聯文件**：`doc_spec_0868`（皮風箱毒煙薰窒地道）、`doc_spec_0908`（竹筒毒煙瘴氣迷霧）、`doc_spec_0911`（風帆火輪車）。

## 一、 設計目標與戰術定位

固定燃放的「竹筒毒煙（`doc_spec_0908`）」一旦釋放便留在原地，我方步兵若向前衝鋒離開煙幕區，仍會暴露於敵軍後排強弩火力之下。「雙輪連環風力鼓風毒煙車」則透過「車軸曲柄連動皮風箱」與「前置生牛皮防矢木幔」，實現「車隨兵進、煙隨車噴」的動態移動掩護。車輪每滾動一圈，風箱便向正前方噴射高壓濃縮毒煙，始終在我方衝鋒步兵前方維持一道移動毒霧屏障。

1. **車軸連動自動鼓風（Axle-Driven Auto-Bellows）**：無需額外人力拉風箱，推車前進時車軸曲柄自動往復壓縮風箱，將毒煙定向噴射至前方 `3x3` 格。
2. **前盾防矢與移動煙幕**：車體正面裝設厚牛皮斜盾（遠程減傷 `80%`），保護推車工兵與隨行步兵免受敵軍迎面箭雨殺傷。
3. **弓弩致盲與窒息斷弦**：濃煙含皂角辣煙與川烏毒氣，使籠罩區內敵軍弓弩手陷入「淚流不止（射程縮減至 `1` 格、命中率 `-55%`）」與持續體力流失。

## 二、 狀態機生命週期（5 階段）

```
[1. 熾炭投藥 Furnace_Poison_Ignite]
       │ (夜間順風 Wind >= 1 + 裝填狼毒皂角硫磺丸)
       ▼
[2. 盾車推進 Shielded_Cart_Advance]
       │ (每回合推進 2 格，車軸曲柄連動風箱高壓噴煙)
       ▼
[3. 移動煙障 Moving_Toxic_Curtain]
       │ (正前方 3x3 格隨車籠罩，我方後隨部隊獲得遠程隱蔽)
       ▼
[4. 嗆盲廢弩 Archer_Blind_Choke]
       │ (煙區敵弓弩：射程強制壓至 1 格、命中 -55%、每回合扣血)
       ▼
[5. 步騎突陣 Escorted_Infantry_Charge]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `FURNACE_POISON_IGNITE` | 熾炭投藥 | 工兵點燃車載生鐵爐並投入毒煙藥丸，正面牛皮木幔展開（自身遠程減傷 `+80%`）。 |
| `SHIELDED_CART_ADVANCE` | 盾車推進 | 毒煙車每回合向前推進 `2` 格，車輪帶動雙風箱持續向正前方噴吐高濃度貼地毒煙。 |
| `MOVING_TOXIC_CURTAIN` | 移動煙障 | 毒煙覆蓋車前 `3x3` 格並隨車體移動；位於毒煙車後方 `2` 格內之我方友軍獲得「煙幕遮蔽（被遠程索敵率 `-70%`）」。 |
| `ARCHER_BLIND_CHOKE` | 嗆盲廢弩 | 處於 `3x3` 毒煙區內之敵軍承受每回合 `6%` 最大兵力毒傷，且弓弩單位陷入「劇咳流淚（射程強制降為 `1` 格、遠程命中率 `-55%`、無法齊射）」。 |
| `ESCORTED_INFANTRY_CHARGE` | 步騎突陣 | 我方含口濕布之近戰精兵緊隨毒煙車後方無傷抵近敵陣，穿出煙幕瞬間對嗆盲敵軍發動奇襲（暴擊率 `+30%`）。 |

## 三、 核心數值與判定公式

### 3.1 鼓風毒煙射程與濃度公式（Bellows Smoke Reach & Density）
$$L_{\text{smoke}} = 3 + \lfloor V_{\text{wind}} \times 0.5 \rfloor,\quad \Delta \text{ACC}_{\text{enemy}} = -\text{clamp}(0.55 + 0.05 \times V_{\text{wind}},\ 0.35,\ 0.75)$$
- 順風風速 $V_{\text{wind}}$ 越高，風箱噴出的毒煙延伸越遠（最高 `5` 格），敵方弓弩手命中率懲罰最高可達 `-75%`。

### 3.2 逆風反噬安全鎖（Headwind Safety Interlock）
- 若戰場風向突變為「大逆風（`Wind <= -2`）」，工兵必須立即關閉爐門停止鼓風（轉入待機），否則毒煙倒灌將使自身周圍 `1` 格承受同等嗆盲減益。

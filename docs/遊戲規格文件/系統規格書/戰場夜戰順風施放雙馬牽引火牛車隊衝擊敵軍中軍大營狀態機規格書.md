# 戰場夜戰順風施放雙馬牽引火牛車隊衝擊敵軍中軍大營狀態機規格書

> **來源**：戰國田單「火牛陣」演進至三國之「火牛重車突擊」（於健牛雙角捆縛利刃、身披五彩龍紋油布、尾繫浸油葦束，並於牛後掛接滿載硫磺火藥乾柴之雙輪輕車，夜間鑿開營牆缺口點燃牛尾，驅使狂牛拖曳火車直衝敵軍中軍大帳）、WBS `FORM-148` 戰場夜襲狂獸火攻模組。
> **關聯文件**：`doc_spec_0819`（南蠻戰象受驚狂暴）、`doc_spec_0911`（風帆火輪車）、`doc_spec_0828`（營嘯炸營心理崩壞）。

---

## 一、 設計目標與戰術定位

「火牛車隊」結合了「巨獸狂暴衝撞」與「火車延燒爆破」雙重特性。單純的無人火輪車需仰賴斜坡或強風推進，而由受驚狂牛牽引的火車則不受平坦地形限制，牛角尖刀能主動頂穿敵軍前排步兵與木柵，身後拖曳的燃燒車廂則將沿途敵軍營帳化為火海。

1. **燒尾狂奔（Scorched-Tail Stampede）**：牛尾點火後，火牛因劇痛進入極限狂奔狀態（每回合強制直線衝刺 `5` 格，無視普通步兵 ZOC 阻擋）。
2. **角刃破陣與彩衣驚魂（Horn-Blade & Dragon-Robe Panic）**：牛角雙刀造成高額穿刺傷害，夜間五彩油布映照火光如鬼神突降，使沿途敵軍陷入「驚駭潰散」。
3. **終點撞帳殉爆（Command Tent Detonation）**：火牛力竭或撞上敵軍中軍大帳／重型壁壘時，後方火車翻覆引爆硫磺膏油罐，形成 `3x3` 格烈焰火海。

## 二、 狀態機生命週期（5 階段）

```
[1. 披衣縛刃 Oxen_Blade_Rigging]
       │ (夜間 + 牛角縛刀 + 牛尾點燃浸油葦束)
       ▼
[2. 劇痛狂奔 Scorched_Tail_Stampede]
       │ (每回合直線狂衝 5 格，無視輕步兵 ZOC)
       ▼
[3. 角刃穿陣 Horn_Blade_Goring]
       │ (沿途敵軍承受 180% 穿刺+火傷，士氣 -20)
       ▼
[4. 撞帳翻車 Tent_Crash_Explosion]
       │ (撞擊敵營帳/壁壘：3x3 格 240% 爆炸火海)
       ▼
[5. 炸營大潰 Night_Camp_Rout]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `OXEN_BLADE_RIGGING` | 披衣縛刃 | 我方於夜間秘密集結火牛車隊（角綁雙刃、身披彩布、尾繫油葦、後掛火車），處於隱蔽待發狀態。 |
| `SCORCHED_TAIL_STAMPEDE` | 劇痛狂奔 | 點燃牛尾葦束，火牛受痛直線狂奔，移動力固定為 `5` 格／回合，完全無視輕裝步兵與木柵之阻擋（ZOC）。 |
| `HORN_BLADE_GORING` | 角刃穿陣 | 衝刺路徑上所有敵軍承受 `180%`（牛角穿刺 + 火車刮擦）複合傷害，並因夜間五彩火影陷入「見鬼驚駭（士氣 `-20`、混亂 1 回合）」。 |
| `TENT_CRASH_EXPLOSION` | 撞帳翻車 | 當火牛衝至第 5 格終點或撞上敵軍中軍帥帳／石牆時，身後火車翻覆引爆，對周圍 `3x3` 格造成 `240%` 爆炸火傷並鋪設火海。 |
| `NIGHT_CAMP_ROUT` | 炸營大潰 | 若敵軍中軍帥帳被火牛車撞毀且順風（`Wind >= 2`），直接誘發敵全營「夜間炸營（全軍士氣額外 `-30`，自相踩踏）」。 |

## 三、 核心數值與判定公式

### 3.1 角刃衝撞與火車複合傷害公式（Stampede Composite Damage）
$$D_{\text{stampede}} = \left(D_{\text{pierce}} \times 1.10 + D_{\text{fire}} \times 0.70\right) \times \left(1 + 0.12 \times V_{\text{wind}}\right)$$
- 沿途敵軍同時承受物理角刃穿刺（`110%`）與側翼火車烈焰灼燒（`70%`），順風時火勢外擴增傷。

### 3.2 拒馬與陷坑反制判定（Counter-Measure Check）
- 火牛車隊雖無視步兵阻擋，但若衝刺路徑上存在「梅花陷馬井（`doc_spec_0897`）」或「深溝地刺（`doc_spec_0878`）」，火牛將直接墜坑翻車並提前於原地觸發 `TENT_CRASH_EXPLOSION`。

# 戰場夜戰順風施放雙馬絞盤火獸車噴吐松脂硫磺烈焰焚毀敵軍木幔狀態機規格書

> **來源**：《武經總要》火攻篇「火獸車／行爐噴火車」（於四輪包鐵木車前端鑄造張口銅製獸首，車腹內置大型生鐵炭爐與融化之松脂、硫磺、猛火油釜，後方連接雙人手搖絞盤風箱；夜間順風抵近敵軍木幔盾車或營柵時，搖動風箱將高溫火油霧化自銅獸口中噴吐三丈烈焰）、WBS `FORM-163` 戰場近距攻堅噴火裝甲車模組。
> **關聯文件**：`doc_spec_0839`（水上雙管猛火油噴筒）、`doc_spec_0850`（攻城木幔摺疊壕橋）、`doc_spec_0938`（風力鼓風毒煙車）。

---

## 一、 設計目標與戰術定位

面對敵軍外覆厚木板與生牛皮的「木幔車（`doc_spec_0850`）」、「塞門刀車（`doc_spec_0909`）」或「重型包鐵塔盾陣」，普通火箭與輕型火球極易被彈開。「雙馬絞盤火獸車」則定位為陸地近戰破障之重型噴火戰車：車體外包生鐵葉片防箭，前端青銅獸首連接高壓風箱與滾沸松脂油釜，能向正前方 `2x3` 格持續噴射黏附性極強的松脂硫磺火柱，連濕牛皮也能瞬間烤乾燒穿。

1. **高溫烤乾濕皮（Moisture Evaporation）**：持續高壓噴射之松脂火柱能在一回合內蒸發敵方木幔或遮矢棚之水分，直接破除其防火塗層。
2. **扇形火舌覆蓋（2x3 Cone Flame）**：獸首寬口噴嘴配合擺頭轉軸，單次噴吐覆蓋正前方深 `2` 格、寬 `3` 格之扇形區域。
3. **銅獸威懾驚馬（Bronze Beast Roar）**：風箱鼓風通過銅獸咽喉簧片時發出震耳欲聾之咆哮聲，配合三丈火舌使敵方戰馬驚駭退卻。

## 二、 狀態機生命週期（5 階段）

```
[1. 熔脂蓄壓 Resin_Boiler_Pressurize]
       │ (車腹炭爐熔化松脂硫磺，車披鐵葉甲推進)
       ▼
[2. 獸首抵陣 Beast_Muzzle_Lock]
       │ (抵近敵木幔/盾牆 <= 2 格，搖動絞盤鼓風)
       ▼
[3. 咆哮噴焰 Roaring_Flame_Cone_Spray]
       │ (正前方 2x3 格 210% 黏著火傷 + 蒸發濕皮防火層)
       ▼
[4. 焚幔破盾 Burn_Mantlet_And_Shield]
       │ (木質/藤甲/木幔目標承受 3.0x 結構焚毀傷害)
       ▼
[5. 閉閥換氣 Valve_Close_Cooldown]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `RESIN_BOILER_PRESSURIZE` | 熔脂蓄壓 | 火獸車進場，車體披覆鐵葉甲（遠程減傷 `65%`），爐內松脂硫磺保持滾沸液態。 |
| `BEAST_MUZZLE_LOCK` | 獸首抵陣 | 雙馬推進至敵軍防線前方 `1 ~ 2` 格，鎖死車輪並開啟銅獸喉部止回閥。 |
| `ROARING_FLAME_CONE_SPRAY` | 咆哮噴焰 | 絞盤風箱全開，銅獸口噴出 `2x3` 格扇形火海，造成 `210%` 火焰傷害；銅簧咆哮使範圍內敵方騎兵陷入「驚馬後退（強制後撤 1 格）」。 |
| `BURN_MANTLET_AND_SHIELD` | 焚幔破盾 | 黏稠松脂附著於敵方木幔、盾車、鹿角或藤甲上持續燃燒，直接清除目標「濕泥／濕氈防火狀態」，並對木質器械造成 `3.0x` 毀滅性結構火傷。 |
| `VALVE_CLOSE_COOLDOWN` | 閉閥換氣 | 每次猛烈噴射後需關閉銅閥重新加壓 `1` 回合；若油釜被敵軍重錘砸破則於原地發生自爆。 |

## 三、 核心數值與判定公式

### 3.1 松脂黏著噴火傷害公式（Resin Spray Flame Damage）
$$D_{\text{spray}} = D_{\text{fireBase}} \times 2.10 \times \left(1 + 0.15 \times V_{\text{wind}}\right) \times \left(1 + 2.00 \times \mathbb{I}_{\text{woodenMantlet}}\right)$$
- 當目標為木幔車、盾車、井闌或藤甲兵（$\mathbb{I}_{\text{woodenMantlet}} = 1$）時，承受總計 `3.0x` 級別之焚毀倍率。

### 3.2 破除濕皮防火層公式（Moisture Strip Formula）
$$\Delta M_{\text{moisture}} = -100 \quad (\text{Instant Strip})$$
- 普通火矢每次僅能扣除濕氈 `15` 點水分（見 `doc_spec_0930`），而火獸車的高溫松脂火柱能直接扣光 `100` 點水分，當回合立即引燃木構。

# 戰場夜戰順風施放雙馬絞盤火龍彈車拋射松脂硫磺連珠火球狀態機規格書

> **來源**：《武經總要》火攻篇與三國野戰「行砲車／連珠火球車」（以雙馬牽引四輪重木車架，車載扭力絞盤與多槽長梢竹木砲桿，一次裝填五枚麻布裹松脂、硫磺、乾漆之「引火球」，夜間順風對敵軍步騎大陣實施扇形連珠拋射）、WBS `FORM-154` 戰場機動遠程火砲模組。
> **關聯文件**：`doc_spec_0802`（擂石霹靂車重油火球）、`doc_spec_0884`（水上拋射生鐵火球）、`doc_spec_0885`（投石機碎石散彈壓制）。

---

## 一、 設計目標與戰術定位

固定式重型「霹靂車（`doc_spec_0802`）」雖威力驚人，但架設緩慢、無法隨野戰步騎機動轉移。「雙馬絞盤火龍彈車」則採用四輪車載設計與五槽連珠盛兜，單發火球重量較輕（十斤松脂硫磺球），但具備「隨軍移動」與「單次五發扇形覆蓋」的戰術優勢，專用於夜間順風洗地壓制敵軍密集陣列。

1. **雙馬牽引快速轉移（Mobile Artillery Deployment）**：每回合可移動 `2` 格並於下一回合立即定位射擊，無需漫長土木築臺。
2. **五連珠扇形火幕（Five-Orb Fan Volley）**：單次絞盤釋放同時拋出 5 枚松脂硫磺火球，覆蓋目標十字形 `5` 格區域，點燃率極高。
3. **順風煙火迷障（Sulfur Smoke Blindness）**：硫磺與乾漆燃燒產生刺鼻黑煙，順風時使受擊區域敵軍遠程命中與視野同步下降。

## 二、 狀態機生命週期（5 階段）

```
[1. 雙馬馳車 Twin_Horse_Mobility]
       │ (進入射程 3~6 格，落栓固定四輪車架)
       ▼
[2. 絞盤裝珠 Winch_Five_Orb_Load]
       │ (棘輪絞緊牛筋繩，五槽盛兜裝填松脂硫磺球)
       ▼
[3. 連珠齊拋 Five_Orb_Fan_Barrage]
       │ (十字 5 格覆蓋：150% 火焰傷害 + 鋪設火海)
       ▼
[4. 硫煙迷目 Sulfur_Smoke_Choke]
       │ (順風黑煙籠罩：目標命中率 -30%、視野 -2)
       ▼
[5. 解栓轉移 Unpin_And_Relocate]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `TWIN_HORSE_MOBILITY` | 雙馬馳車 | 雙馬牽引四輪砲車隨軍行進（移動力 `2`），抵達距離敵陣 `3 ~ 6` 格時打入鐵栓定位。 |
| `WINCH_FIVE_ORB_LOAD` | 絞盤裝珠 | 砲手轉動雙側棘輪絞盤拉緊牛筋扭力索，將 5 枚點燃引信之松脂硫磺火球置入五連皮兜。 |
| `FIVE_ORB_FAN_BARRAGE` | 連珠齊拋 | 敲開機括，5 枚火球呈十字扇形落入敵陣 `5` 格，造成 `150%` 火焰爆炸傷害並將地格轉化為持續 2 回合之火海。 |
| `SULFUR_SMOKE_CHOKE` | 硫煙迷目 | 松脂硫磺劇烈燃燒釋放濃烈毒黑煙，順風（`Wind >= 1`）時使受擊 `5` 格內敵軍陷入「硫煙嗆盲（遠程命中率 `-30%`、視野 `-2` 格）」。 |
| `UNPIN_AND_RELOCATE` | 解栓轉移 | 射擊完畢後冷卻 1 回合裝填，或立即拔除車輪鐵栓隨隊撤離，避免遭敵方輕騎突襲。 |

## 三、 核心數值與判定公式

### 3.1 順風射程延伸與散佈公式（Wind Range & Spread）
$$R_{\text{max}} = 6 + \lfloor V_{\text{wind}} \times 0.5 \rfloor,\quad D_{\text{volley}} = D_{\text{fireBase}} \times 1.50 \times (1 + 0.12 \times V_{\text{wind}})$$
- 順風風速 $V_{\text{wind}} \ge 2$ 時，最大射程由 `6` 格延伸至 `7` 格，且每級風速提升 `12%` 火球延燒傷害。

### 3.2 車載結構脆弱性檢定（Cart Vulnerability）
- 火龍彈車為求輕便未覆重型生鐵裝甲，若遭敵方騎兵貼身近戰突擊，承受之近戰物理傷害額外 `+40%`，需步兵方陣於前排掩護。

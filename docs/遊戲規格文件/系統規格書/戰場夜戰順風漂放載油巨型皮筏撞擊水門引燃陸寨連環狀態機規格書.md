# 3KLife 戰場夜戰順風漂放載油巨型皮筏撞擊水門引燃陸寨連環狀態機規格書

## 1. 系統定位與設計意圖

在三國江河水網要塞攻防（如孫策平定江東攻拔皖城水寨、曹仁守荊州阻關羽水攻）中，臨江而建的水寨外圍通常設有高聳的水門寨柵與連環浮木。本系統規範「順風順流夜放載油巨型牛皮筏撞擊水門引爆陸寨連鎖燃燒系統（Oil Raft Water Gate Breach）」狀態機：
- **巨型牛皮充氣浮筏載重**：以數十具完整牛皮吹氣密閉扎結成扁平大筏，筏面鋪設乾燥松脂柴草並密布八口千斤桐油儲罐，吃水淺且耐撞。
- **暗夜順風順流無人漂送**：夜深人靜時於上游五里順東南風放下，借江心急流高速漂向水門，防禦守軍在百步之內難以憑肉眼或水聽察覺。
- **撞擊引信起爆破門漫延**：筏頭裝設生鐵撞角連動燧石刮火引信，猛烈撞擊木質水門寨柵時瞬間引爆八千斤火油，高溫烈焰隨風勢倒灌陸上營寨。

## 2. 狀態機架構與轉換生命週期

水門皮筏火攻狀態機（代碼：`OIL-RAFT-WATER-GATE-BREACH01`）流程如下：

```
[ RAFT_INFLATE_STOWAGE ] (上游淺灘皮筏充氣捆紮裝載千斤火油)
           │
           ├── 暗夜三更順風順流放纜
           ▼
[ CURRENT_DRIFT_STEALTH ] (江心急流無人漂送隱匿迫近水寨外圍)
           │
           ├── 逼近水門五十步觸發警報 ──> [ SENTRY_DETECT_ALARM ]
           ▼
[ COLLISION_RAM_IMPACT ] (筏頭生鐵撞角猛烈轟擊水門木柵橫樑)
           │
           ├── 燧石引信刮擦引燃核心火油
           ▼
[ OIL_VOLATILIZATION_BURST ] (八千斤桐油瞬間劇烈爆燃吞噬水門)
           │
           ├── 狂風捲帶烈焰越過寨牆蔓延陸寨
           ▼
[ SHORE_CAMP_FIRE_PROPAGATION ] (沿江陸上步兵營寨陷入火海連鎖)
           │
           ▼
[ WATER_GATE_BREACH_CLEAR ] (水門徹底坍塌水陸主力趁勢突入)
```

### 狀態細部定義

1. **RAFT_INFLATE_STOWAGE（裝載整備）**：工兵於上游隱蔽港灣將牛皮吹脹扎結，灌裝高度揮發性桐油與生鐵破片。
2. **CURRENT_DRIFT_STEALTH（順流隱匿）**：皮筏借每秒 2 公尺之江流高速滑行，無槳無帆，聲響極低，夜間被察覺率僅 15%。
3. **SENTRY_DETECT_ALARM（哨兵示警）**：水寨哨樓借火把微光在 50 步距發現黑影，但敵筏已進入極速衝撞末端。
4. **COLLISION_RAM_IMPACT（撞擊破障）**：生鐵撞角以 12 萬焦耳動能砸入水門木柵，木料碎裂並觸發燧石打火。
5. **OIL_VOLATILIZATION_BURST（油爆爆燃）**：八口油罐同時炸裂，火柱騰空三丈，水門寨柵本體生命值在 3 秒內歸零。
6. **SHORE_CAMP_FIRE_PROPAGATION（火勢蔓延）**：大火借風勢向陸上營寨撲擊，相鄰帳篷與輜重堆每 4 秒觸發一次點燃判定。
7. **WATER_GATE_BREACH_CLEAR（水門洞開）**：水門化為焦炭殘骸漂散，防禦節點失效，攻方戰船與步騎順暢突入。

## 3. 數值模型與物理演算

### 皮筏順流衝撞動能公式

$$E_{k} = \frac{1}{2} M_{raft} \times \left( V_{current} + 0.3 \times W_{wind} \right)^2$$

- $M_{raft}$：皮筏總重（約 4,000kg）。
- $V_{current}$：江流速度（常態 $1.5 \sim 2.5\,\text{m/s}$）。
- $W_{wind}$：順風等級（4 級順風可額外疊加 $1.2\,\text{m/s}$ 漂速）。若 $E_k > 80,000\,\text{J}$，直接震裂水門主支撐柱。

### 火勢向陸寨擴散機率公式

$$P_{spread} = \min\left(0.90, \; 0.40 + 0.10 \times \max(0, W_{wind} - 2) - 0.05 \times D_{shore}\right)$$

- $D_{shore}$：水門至陸寨第一道防線之距離（公尺）。距離每增加 2 公尺，蔓延機率衰減 5%。

## 4. 戰場戰術連鎖與部隊生剋

1. **毀滅防禦節點**：水門破壞後，該區域水寨的防禦加成（護甲 +30%、減傷 25%）徹底失效，敵守軍士氣直接扣減 20 點。
2. **水鬼截流反制**：若防守方預先派遣水鬼在水中設置攔江鐵索，可提前在 100 步外攔截皮筏並引發早爆。
3. **火箭提前引爆**：守軍若擁有神射手於 80 步外精準以火箭命中皮筏，可在其接觸水門前引燃自毀。

## 6. 驗證標準與測試用例 (TC)

- **TC-OIL-RAFT-01（順流航速與動能）**：在江流速度 2.0m/s 下，皮筏衝撞水門動能必須 $\ge 80,000\,\text{J}$。
- **TC-OIL-RAFT-02（水門瞬時破壞）**：撞擊引爆後，水門木柵耐久度於 3 秒內扣減 100% 並標記為 `BREACHED`。
- **TC-OIL-RAFT-03（陸寨火勢蔓延）**：順風 4 級環境下，水門起火後陸寨首排營帳在 8 秒內完成引燃判定。

# 3KLife 戰場夜戰順風火矢點燃敵軍糧秣輜重車隊引發連環爆炸狀態機規格書

## 1. 系統定位與設計意圖

在三國大型野戰與後勤劫糧作戰（如官渡之戰烏巢劫糧）中，糧秣輜重車隊滿載乾燥草料、精製黑豆、軍械油脂與隨軍守城桐油罐。本系統規範夜襲部隊於特定風向（順風四級以上）發動火箭集火射擊輜重隊列，引發單車起火、熱能擴散、油脂爆裂與全縱隊連環殉爆之狀態機架構：
- **順風增程火矢精準拋射**：弓弩部隊於夜戰逆風處盲區隱蔽，順風發射浸透松脂桐油之倒鉤火箭，射程提升二十步且抗風吹熄。
- **糧草輜重分層燃燒傳導**：乾草蓬布先行起火，引燃隨車油脂罐與火藥陶甕，產生高溫破片與火海飛濺。
- **骨牌式連環爆炸與炸營**：相鄰車距在五步以內的輜重車輛逐次被破片與流火引爆，導致押糧部隊士氣瞬間雪崩並潰散夜驚。

## 2. 狀態機架構與轉換生命週期

輜重連環引爆狀態機（代碼：`FIRE-ARROW-SUPPLY-EXPLOSION-CHAIN01`）流程如下：

```
[ CONVOY_TRANSIT_ROUTINE ] (糧秣輜重長蛇陣夜間常規行進)
           │
           ├── 遭遇順風火箭齊射命中 ──> [ VOLLEY_IGNITION_HIT ]
           ▼
[ SMOLDERING_CANVAS_BURST ] (乾草蓬布迅速陰燃並起明火)
           │
           ├── 車內油脂陶罐受熱沸騰脹裂
           ▼
[ OIL_POT_RUPTURE_DETONATION ] (油脂陶甕炸裂噴濺高溫火油)
           │
           ├── 烈焰破片引燃前後五步相鄰車輛
           ▼
[ CHAIN_EXPLOSION_PROPAGATION ] (車隊縱隊骨牌式連環劇烈殉爆)
           │
           ▼
[ CONVOY_COLLAPSE_PANIC ] (押糧輜重民夫炸營全軍潰散潰敗)
           │
           ▼
[ CHARRED_CARCASS_DENIAL ] (原地化為焦黑火海阻斷後續路徑)
```

### 狀態細部定義

1. **CONVOY_TRANSIT_ROUTINE（輜重行進）**：
   - 糧車以十車為一隊結長蛇陣緩行，車距三至五步，護衛步兵持火把警戒。
2. **VOLLEY_IGNITION_HIT（火矢命中）**：
   - 伏兵射手自順風坡頂拋射火矢，命中覆蓋油布的草料車頂，瞬間點燃表層。
3. **SMOLDERING_CANVAS_BURST（明火擴散）**：
   - 火勢向下侵徹乾燥草料垛，燃燒值突破警戒閾值，濃煙遮蔽護衛視線。
4. **OIL_POT_RUPTURE_DETONATION（油脂爆裂）**：
   - 車載儲油陶罐受熱脹裂，滾燙火油混同木刺破片以半徑 6 步擴散，引燃相鄰車輛。
5. **CHAIN_EXPLOSION_PROPAGATION（連環殉爆）**：
   - 相鄰車輛按連鎖機率（每跳 85%）依次引爆，火勢迅速向後延伸成百步火龍。
6. **CONVOY_COLLAPSE_PANIC（炸營潰散）**：
   - 輜重役伕受巨響火光驚駭，士氣歸零四散潰逃，護衛編制徹底瓦解。
7. **CHARRED_CARCASS_DENIAL（焦黑阻滯）**：
   - 車體骨架燒塌橫阻於狹道，形成持續 120 秒高溫燃燒障礙區阻絕追兵。

## 3. 數值模型與物理演算

### 順風火箭引燃判定公式

$$P_{ignite} = \min\left(0.95, \; B_{arrow} \times \left(1.0 + 0.15 \times \max(0, W_{speed} - 3)\right) \times M_{dry}\right)$$

- $B_{arrow}$：火箭基礎引燃係數（0.65）。
- $W_{speed}$：風速等級（順風 $>3$ 級每級增加 15% 機率）。
- $M_{dry}$：物料乾燥指數（乾草車 1.4，米糧車 1.0，軍械車 0.7）。

### 連環爆破熱傳導判定

相鄰第 $i$ 號車受第 $i-1$ 號車影響之引爆延遲 $T_{chain}$ 與傳導機率 $P_{chain}$：

$$P_{chain} = \max\left(0.1, \; 0.90 - 0.12 \times \max(0, D_{gap} - 3)\right)$$

$$T_{chain} = 2.5 + 0.8 \times D_{gap} \quad (\text{秒})$$

- $D_{gap}$：前後車輛間距（公尺）。若間距大於 8 公尺，機率驟降至 15% 以下。

## 4. 戰場戰術連鎖與部隊生剋

1. **破襲後勤與斷糧**：連環爆破每毀 1 車，前線軍團補給維持度扣減 5 點，扣滿 50 點觸發士氣持續衰退。
2. **夜戰火光致盲與驚馬**：爆炸半徑 20 步內戰馬未蒙眼立即陷入驚駭奔踏，反向衝撞友軍後衛。
3. **工兵救火與塗料防禦**：若配備工兵隊並塗抹防火白泥，引燃機率降低 50%，傳導時間延長 3 倍。

## 6. 驗證標準與測試用例 (TC)

- **TC-SUPPLY-EXP-01（順風火箭點火）**：4 級順風下齊射 20 支火矢，乾草車引燃率 $\ge 85\%$。
- **TC-SUPPLY-EXP-02（五步內連鎖殉爆）**：車距 4 公尺含油脂車，爆炸後相鄰車輛 5 秒內引燃連鎖。
- **TC-SUPPLY-EXP-03（焦黑地形阻斷）**：殉爆後道路節點生成通行阻斷標記，部隊途經遭受持續灼傷。

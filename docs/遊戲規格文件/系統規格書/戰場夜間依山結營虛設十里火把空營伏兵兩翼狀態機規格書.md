# 3KLife 戰場夜間依山結營虛設十里火把空營伏兵兩翼狀態機規格書

## 1. 系統定位與設計意圖

在三國夜戰與誘敵深入戰術（如街亭撤退疑兵、諸葛亮減灶增灶逆向應用）中，當我方兵力處於劣勢或急需拖延敵軍主力推進時，常採取大縱深虛實欺敵戰術。本系統規範夜戰特種疑兵工程「虛設火把空營引誘與兩翼伏擊系統（Campfire Deception Empty Fort Flank）」之營火佈置、稻草疑兵、誘敵夜襲與兩翼合圍狀態機：
- **十里連營虛設火把**：在依山傍險之假營地插立數百面戰旗與稻草草人，每五步插設一支松脂長明火炬，營內金鼓不定時擂動，營造大軍集結假象。
- **誘敵夜襲中軍空營**：敵軍誤以為抓獲主力宿營良機，集中優勢兵力發動深夜偷營，破門衝入後方知營內空無一人。
- **高處兩翼滾木合圍**：當敵軍在空營混亂擁擠之際，埋伏於兩側山崖高處之我方主力萬弩齊發，並推下滾木礌石徹底封鎖營門，展開毀滅性聚殲。

## 2. 狀態機架構與轉換生命週期

空營誘敵狀態機（代碼：`CAMPFIRE-DECEPTION-EMPTY-FORT-FLANK01`）管理自設疑誘敵至聚殲撤離之完整週期：

```
[ DECEPTION_CAMP_CONSTRUCTION ] (依山搭建空營木柵插設草人戰旗)
          │
          ▼
[ NIGHT_CAMPFIRE_ILLUMINATION ] (每五步點燃松脂火把金鼓間歇擂動)
          │
          ├── 敵探哨遠程偵察 ──> [ RECON_MISINFORMATION_RESOLVE ]
          ▼
[ ENEMY_NIGHT_RAID_ENGAGE ] (敵軍主力發動夜襲全軍突入空營)
          │
          ├── 發現營中無人陷入混亂 ──> [ AMBUSH_TRAP_TRIGGERED ]
          ▼
[ FLANK_CLIFF_ROLLING_ROCKS ] (兩翼高崖滾木雷石轟頂封死退路)
          │
          ▼
[ CROSSFIRE_VOLLEY_ANNIHILATION ] (兩側步弩居高臨下交叉齊射)
          │
          ▼
[ STRATEGIC_WITHDRAWAL_SECURE ] (全殲敵先鋒我軍從容後撤入關)
```

### 狀態細部定義

1. **DECEPTION_CAMP_CONSTRUCTION（構築空營）**：
   - 斥候與工兵利用廢舊木料快速圍起連綿木柵，紮設草人披掛鎧甲頭盔，安置於中軍各個帳篷外圍。
2. **NIGHT_CAMPFIRE_ILLUMINATION（火把點亮）**：
   - 點燃 300 支長效松脂火炬，每隔一刻鐘以繩索拉動木槌敲擊銅鑼戰鼓，十里外望之若十萬大軍整軍備戰。
3. **RECON_MISINFORMATION_RESOLVE（誤導判定）**：
   - 敵軍夜間偵察斥候遠程觀測到燈火通明與規律更鼓，主將判定為我方主力夜宿，決策調動精銳發動夜襲。
4. **ENEMY_NIGHT_RAID_ENGAGE（敵軍突入）**：
   - 敵先鋒衝破營門斬殺草人，深入核心大帳後方驚覺中計，部隊在狹小營道中互相推擠。
5. **FLANK_CLIFF_ROLLING_ROCKS（兩翼滾木）**：
   - 埋伏於兩側山坡之我軍工兵砍斷繩索，千斤擂木與巨石順陡坡呼嘯滾落，砸毀營門封死撤退路線。
6. **CROSSFIRE_VOLLEY_ANNIHILATION（交叉聚殲）**：
   - 兩翼居高臨下拋射火箭與連弩，敵軍在火海中陷入踩踏潰滅，我軍以逸待勞大獲全勝。

## 3. 關鍵數值與計算判定公式

### 3.1 敵軍夜襲中計機率公式

敵軍主帥決策夜襲之誤判機率 $P_{ruse}$：
$$P_{ruse} = \text{clamp01}\left(0.45 + \frac{\text{TorchCount}}{600} + \frac{\text{Tactics}_{strat} - \text{Int}_{enemy}}{80} - \text{Caution}_{def}\right)$$
- $\text{TorchCount}$：點燃火把數量（300 支時加成 $+0.50$）。
- $\text{Tactics}_{strat}$：我方佈陣策士之謀略智力值。
- $\text{Caution}_{def}$：敵將謹慎性格修正（急躁好功將領此項為 0，多疑將領為 0.25）。

### 3.2 兩翼高處伏擊傷害加成

自高地向下射擊與滾石之傷害增益 $\beta_{high\_ground}$：
$$\beta_{high\_ground} = 1.0 + \frac{H_{cliff\_meters}}{25} \times 0.65 + \text{EnclosedPanic} \times 0.40$$
- 高度差 30 公尺且處於密閉營寨時，傷害加成達原本之 2.18 倍，敵軍防禦護甲減免率強制失效 70%。

## 4. 戰術連鎖與攻防克制

1. **以空制實逆轉戰局**：不費一兵一卒在前沿硬拼，以少量火料換取敵主力毀滅性傷亡。
2. **天敵與敵方反制**：
   - **火箭試探**：敵軍若先以千支燃燒火箭自遠處拋射引燃木柵，空營內部無人救火將提前暴露。
   - **兩翼搜山**：經驗老練之名將夜襲前必派輕裝斥候搜查兩側制高點，伏兵若被提前摸索將轉入混戰。

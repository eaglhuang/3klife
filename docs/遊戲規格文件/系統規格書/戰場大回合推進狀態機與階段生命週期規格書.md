# 戰場大回合推進狀態機與階段生命週期規格書

## 1. 核心定位與回合契約

本規格書為戰場回合制核心狀態機與多階段生命週期流水線（Turn-Based Battle Runtime Pipeline，代號 `BAT-01`）的單一真相來源（Single Source of Truth）。戰鬥系統由確定性排程器（`TurnBasedTempoController`）主導，將每個大回合（Turn）依序拆解為我方、敵方與全域結算共 14 個微階段（Micro-Phases）。

```typescript
export interface BattleTurnPipelineContract {
  phaseOrder: typeof TURN_BASED_RUNTIME_PHASE_ORDER;
  maxTurnsDefault: 30;            // 超過 30 回合強制平局
  stopProcessingOnVictory: true;  // 勝負分曉時立即截斷後續階段
}
```

---

## 2. 大回合十四微階段標準調度順序

大回合依照嚴格順序推進，任一階段觸發勝負或中斷標記（`stopProcessing`）時，立即終止後續階段執行：

| 順序 | 微階段識別碼 (`phaseName`) | 階段責任核心與結算邏輯 |
|:---:|---|---|
| **1** | `player-auto-move` | 我方存活部隊依據尋路向量前進（受移速、地利、阻擋限制）。 |
| **2** | `player-tile-effect` | 我方部隊觸發站立格之地貌結算（火海扣血、毒沼中毒、陷阱定身）。 |
| **3** | `player-combat-resolve` | 我方部隊索敵、戰法施放、普攻結算、暴擊與近戰反擊。 |
| **4** | `player-special-resolve` | 我方器械攻城打擊、戰場物資打撈（Salvage）與連鎖反應。 |
| **5** | `enemy-deploy` | 敵方增援進場、Boss 瀕危親衛隊召喚（BossGuardSummon）。 |
| **6** | `enemy-auto-move` | 敵方存活部隊 AI 尋路移動（避開 Choke Point 或推進）。 |
| **7** | `enemy-tile-effect` | 敵方部隊觸發地貌結算（水流強制位移、落石阻隔）。 |
| **8** | `enemy-combat-resolve` | 敵方部隊 AI 選技、戰法施放與部隊交火結算。 |
| **9** | `enemy-special-resolve` | 敵方特殊戰術效果結算與反噬連動。 |
| **10** | `auto-move` | 中立第三方部隊或潰逃單位位移。 |
| **11** | `tile-effect` | 全域地格狀態生命週期演進（火海擴散、暴雨熄火、障礙消退）。 |
| **12** | `combat-resolve` | 全域持續性 DoT 傷害結算與狀態機 Tick。 |
| **13** | `special-resolve` | 軍師智謀能量累積（WisdomMeter）與全域場景機制。 |
| **14** | `victory-check` | 全面檢核主將存亡、敵陣大營佔領狀態與最大回合超限。 |

---

## 3. 勝負檢定與中斷終止協議（Victory Check）

在 `victory-check` 或任何微階段中，若檢測到以下條件，立即產出 `BattleResult` 並終止循環：

1. **我方大獲全勝（Player Victory）**：
   - 敵方全體部隊陣亡（`enemyGeneralKilled` 或 `allEnemyTroopsDead`）。
   - 我方部隊成功佔領敵方大營（`campCaptured`）。
2. **我方全軍覆沒（Player Defeat）**：
   - 我方主將陣亡或全軍覆沒。
3. **戰局超限平局（Draw / Timeout）**：
   - 回合數超過關卡上限（$\text{Turn} > 30$），裁定為攻方撤退失敗。

---

## 4. 運行期狀態保存與事件廣播

1. **狀態快照（BattleState Snapshot）**：
   - 每個微階段執行完畢後，`BattleState` 保持確定性落盤，支援斷線重連與 Replay 重播。
2. **UI 表現解耦**：
   - 邏輯層透過 `BattleUIBridge` 派發視覺事件（`damageLog`、`moraleAnim`、`vfxBurst`），純運算核心不依賴 Cocos 畫面幀率。

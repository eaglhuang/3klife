## §2. AI 虎符自動評分與選配公式 (AiTallySelection)

AI 武將在出征備戰階段，自可用虎符池（`AiTallyPool`）中依下列公式計算最佳裝備：

$$\text{Score} = \text{AptitudeEff} \times \text{QualityMod} \times (1 + \text{Star} \times 0.08)$$

1. **血脈共鳴優先 (Resonance Override)**：
   - 若某虎符為該武將之**專屬個人虎符**（如關羽配青龍鐵衛、趙雲配常山龍騎），評分強制賦予最高權重（$\text{Score} \times 2.0$），優先選用。
2. **常規適性乘區**：
   - 適性等級：S 級（1.20）、A 級（1.00）、B 級（0.85）、C 級（0.70）、D 級（0.50）。缺值預設為 B 級。
3. **品質倍率 (QualityMod)**：
   - R 級（1.0）、SR 級（1.25）、SSR 級（1.50）、UR 級（1.80）。
4. **星級增幅**：
   - 每提升 1 星增加 8% 戰力評分（$\text{Star} \times 0.08$）。

## §3. 章節難度權重縮放協議 (ChapterAIConfig)

關卡戰鬥時，AI 決策精度（IQ）隨玩家進度平滑縮放：

- **第一章 (黃巾之亂)**：AI IQ = 40，剋制決策率 20%，隨機出兵，不主動保留糧草。
- **第二章 (董卓進京)**：AI IQ = 60，剋制決策率 45%，優先出剋制兵種。
- **第三章 (群雄逐鹿)**：AI IQ = 80，剋制決策率 70%，開始評估場景 Preset 與器械保留。
- **第四章起 (三國鼎立)**：AI IQ = 100，剋制決策率 90%，完整套用九大武將性格與最佳虎符選配。

# 3KLife 戰場射箭傳書勸降圍城守軍與瓦解軍心狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 圍城攻防之心理戰術引擎（`PSYWAR-SURRENDER-01`）。重現三國歷史中「兵臨城下，射書城中，陳說利害，士卒思歸」之攻心戰略。進攻方透過強弓將勸降檄文射入城樓或兵營，動搖守軍基層士氣、引發將士反目，甚至促成守城副將斬首主帥、開門納降。

## 4. 攻心判定與內訌結算公式

### 4.1 勸降動搖強度計算公式
進攻方傳書射入城內後，每回合造成之士氣折損：
$$\Delta \text{MoraleLoss} = \left(\text{PersuaderEloquence} \times 0.4 + \text{SiegeTurns} \times 2.5\right) \times \left(1.0 - \frac{\text{CommanderLoyalty} + \text{CommanderVirtue}}{200}\right)$$
- 若城內斷糧（$\text{SupplyDays} \le 0$），士氣折損加乘 $2.0$ 倍；
- 若主將義理值 $\ge 90$（如關羽、張嶷），主帥士氣折損豁免 $70\%$，但底層士卒仍會動搖。

### 4.2 副將內訌斬將投降機率
當城池士氣 $\le 25$ 且副將忠誠度 $\le 60$ 時觸發判定：
$$P_{\text{mutiny}} = \left(0.30 + \frac{60 - \text{DeputyLoyalty}}{100} + \frac{\text{SiegeTurns}}{30}\right) \times \text{BriberyFactor}$$
- 判定成功時，副將發動夜間兵變斬殺主將，城防耐久直接歸零，城市和平開城納降，減少 $90\%$ 屠城浩劫破壞。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-PSY-01**：在守軍餘糧充沛（$\ge 60$ 日）且城防滿值時發動射箭傳書，僅扣除士氣 3~5 點，且主將可斬信使提振士氣 $+10$。
2. **驗收 CASE-PSY-02**：圍城超過 10 回合且敵主帥陣亡時，傳書勸降成功率強制提升至 $95\%$，守軍全員轉化為受編俘虜。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

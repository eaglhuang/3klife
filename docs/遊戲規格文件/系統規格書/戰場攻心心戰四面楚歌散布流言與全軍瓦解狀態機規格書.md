## 1. 系統架構定位與攻心為上戰略哲學

夫用兵之道，攻心為上，攻城為下；心戰為上，兵戰為下。《三國人生》（3KLife）構建深度的**戰場精神心理與士氣侵蝕模型（Psychological Warfare & Morale Collapse）**。部隊作戰不僅消耗體力與兵員，更隨時承受恐慌、鄉愁與絕望之精神重擊。

本系統核心價值：
1. **多維心戰手段（Multi-Vector PsyOps）**：透過夜半歌聲、偽報死訊與武聖怒吼擊碎敵膽。
2. **士氣連鎖傳導（Morale Contagion）**：鄰近部隊潰逃時，恐慌情緒如瘟疫般在軍陣中傳染。
3. **兵敗如山倒雪崩機制（Total Collapse）**：全軍士氣跌破臨界線引發集體卸甲投降。

## 3. 士氣連鎖傳染（Morale Contagion）演算法

戰場上任何一部隊潰退或全滅時，觸發周圍幾何擴散恐慌波：

$$\Delta \text{Morale}_{\text{adjacent}} = -10 \times \left(1.0 - \frac{\text{dist}}{R_{\text{panic}}}\right) \times \left(1.5 - \frac{\text{LEAD}_{\text{friendly}}}{100}\right)$$

1. **骨牌傳導**：若相鄰部隊統率值低於 60，承受恐慌傳染時有 $40\%$ 機率隨之動搖潰逃。
2. **名將中流砥柱（Anchor Stance）**：若周遭存在特性為「沈毅/豪傑」之名將（如趙雲、張遼），可直接吸收恐慌波，阻斷連鎖傳染。

## 4. 兵敗如山倒（Total Army Collapse）終極狀態機

當陣營的平均士氣指標跌入臨界深淵時，進入不可逆之軍陣瓦解狀態機：

```typescript
export enum ArmyMoraleTier {
  HIGH_SPIRITS = 'HIGH_SPIRITS', // 士氣 >= 80：亢奮狀態，攻擊 +15%，暴擊 +10%
  STEADY = 'STEADY',             // 士氣 50~79：正常作戰態勢
  WAVERING = 'WAVERING',         // 士氣 25~49：軍心動搖，防禦 -20%，無法發動奧義
  PANIC = 'PANIC',               // 士氣 15~24：恐慌混亂，每回合 20% 逃兵
  ROUT = 'ROUT'                  // 士氣 < 15：兵敗如山倒，全軍徹底崩潰潰散！
}
```

1. **`ROUT` 觸發條件**：全軍平均士氣跌破 **$15$ 點**，或主將陣亡且全軍無人接替指揮。
2. **潰滅結算**：
   - 戰場畫面彈出「兵敗如山倒」全屏震顫特效。
   - 所有在場敵軍部隊自動解除戰鬥姿態，拋棄兵器化為逃兵奔向地圖邊緣。
   - 獲勝方自動俘獲戰場上遺留之全部輜重、器械與落馬將領，以**輝煌大捷（Decisive Victory）**提前結束戰役。

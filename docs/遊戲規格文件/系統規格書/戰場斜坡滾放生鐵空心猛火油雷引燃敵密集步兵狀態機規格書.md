# 3KLife 戰場斜坡滾放生鐵空心猛火油雷引燃敵密集步兵狀態機規格書

## 1. 系統定位與設計意圖

在三國山隘防禦與險要斜坡爭奪戰（如陳倉攻防、上方谷誘敵、劍閣天險）中，敵方步兵常結成厚重密集方陣沿坡仰攻，常規弓箭受限於拋射仰角難以貫穿前排巨盾。本系統規範斜坡重力滾雷特種火器工程「斜坡滾放生鐵空心猛火油雷（Slope Iron Fire Bomb Roll）」之坡頂堆儲、引信點火、重力加速滾進、撞擊碎裂與火海蔓延狀態機：
- **生鐵薄壁空心滾雷**：以薄壁生鐵鑄造直徑二尺之球體，內部注滿稠化猛火油、硫磺粉與生松脂，球體表面鍛造凸起防滑破片紋。
- **重力勢能轉化狂暴動能**：自三十度陡坡頂端沿滑軌推下，巨球在重力加速度驅動下滾速達到每秒 15 公尺，產生不可阻擋之橫向碾壓推力。
- **碰撞炸裂與全坡面火海**：撞擊敵密集盾牆時生鐵外殼碎裂，黏稠火油四濺爆發，沿斜坡順勢向下漫流燃燒，吞噬敵仰攻隊列。

## 2. 狀態機架構與轉換生命週期

斜坡滾雷狀態機（代碼：`SLOPE-IRON-FIRE-BOMB-ROLL01`）管理自高坡推落至烈焰阻絕之完整週期：

```
[ BOMB_RAMP_STAGING ] (坡頂木軌架設空心鐵球裝填火油)
          │
          ▼
[ FUSE_TORCH_IGNITION ] (點燃耐磨延期引信工兵合力推入滑軌)
          │
          ▼
[ GRAVITY_ACCELERATION_ROLL ] (沿三十度斜坡狂暴滾進動能飆升)
          │
          ├── 沿途撞碎散兵 ──> [ SLOPE_OBSTACLE_CRUSH ]
          ▼
[ SHOCK_COLLISION_BURST ] (正面撞擊密集盾牆鐵殼粉碎炸裂)
          │
          ▼
[ STICKY_FIRE_CASCADE_DOWN ] (高溫猛火油順斜坡向下漫流覆蓋)
          │
          ▼
[ FORMATION_SCATTER_ROUT ] (敵仰攻陣型瓦解踐踏滾落山腳)
```

### 狀態細部定義

1. **BOMB_RAMP_STAGING（滑軌整備）**：
   - 工兵於山脊防線架設原木滑道，將重達 120 斤之生鐵火球推至發射位，檢查封泥氣密性。
2. **FUSE_TORCH_IGNITION（點火推落）**：
   - 守軍以火炬點燃外置慢燃麻線引信，四名力士同時發力撬動制動木楔，火球滑入陡坡。
3. **GRAVITY_ACCELERATION_ROLL（重力滾馳）**：
   - 火球在坡道滾動 40 步後達到終端速度，外殼火繩因摩擦與空氣流通劇烈燃燒，如同一團烈火流星。
4. **SHOCK_COLLISION_BURST（撞擊爆裂）**：
   - 火球以 18 m/s 初速直接轟中敵步兵大盾，巨大衝擊力撞碎盾牌骨架，生鐵薄殼在衝擊應力下四分五裂。
5. **STICKY_FIRE_CASCADE_DOWN（火油下瀉）**：
   - 稠化猛火油在爆炸壓力和坡度重力雙重作用下，順著山坡向下流淌覆蓋寬達四丈之山道，燃燒溫度超 750 度。
6. **FORMATION_SCATTER_ROUT（潰退潰滅）**：
   - 仰攻敵兵退路被滾滾火流阻斷，衣甲著火陷入極度恐慌，相互踩踏翻滾墜崖。

## 3. 關鍵數值與計算判定公式

### 3.1 滾雷撞擊衝擊動能公式

鐵球在撞擊瞬間之總動能 $E_{total}$（焦耳）：
$$E_{total} = \frac{1}{2} M_{bomb} V_{roll}^2 + \frac{1}{2} I_{sphere} \omega_{rot}^2 = \frac{7}{10} M_{bomb} \times g \times \Delta h \times (1.0 - \mu_{ground})$$
- $M_{bomb}$：鐵球總質量（60 kg）。
- $\Delta h$：垂直落差（約 20 公尺）。
- $\mu_{ground}$：地面滾動阻力係數（砂石坡面約 0.12）。
- 計算得撞擊動能高達 $E_{total} \approx 7,200\,\text{J}$，足以撞穿三層重步兵大盾陣列。

### 3.2 斜坡火焰向下擴散速度

烈火沿坡面下瀉速度 $V_{fire\_down}$（m/s）：
$$V_{fire\_down} = V_{base} \times \left(1.0 + \sin(\theta_{slope}) \times 2.4\right) \times \frac{100}{\text{Viscosity}}$$
- 在 $30^\circ$ 陡坡上，下瀉火浪速度達 4.2 m/s，遠超步兵負重後撤之極限奔跑速度。

## 4. 戰術連鎖與攻防克制

1. **一夫當關萬夫莫開**：在單一山路咽喉處形成絕對滅絕性障礙，化解敵軍兵力數量優勢。
2. **天敵與敵方反制**：
   - **挖橫溝引流**：老練敵軍於坡道預先挖掘深一尺之截水橫溝，滾雷落入橫溝卡死自爆，無法波及後隊。
   - **雨水泥濘減速**：暴雨天氣坡面深泥將大幅吸收滾雷動能，導致其提前停滯在半山腰。

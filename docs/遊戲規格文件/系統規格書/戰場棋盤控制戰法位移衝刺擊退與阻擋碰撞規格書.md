# 戰場棋盤控制戰法位移衝刺擊退與阻擋碰撞規格書

## 1. 核心定位與分類契約

本規格書為戰鬥棋盤控制包（P1 Board Control Package，代號 `TAC-05`）的單一真相來源（Single Source of Truth），涵蓋位移衝刺（`TMOVE`）、擊退推擠（`TPUSH` / `push` / `push-fire`）與地形阻擋連動（`TTILE`）。

```typescript
export interface BoardControlSkillContract {
  category: 'BOARD_CONTROL';
  effectKinds: 'push' | 'push-fire' | 'tile-buff';
  targetModes: BattleSkillTargetMode.Self | BattleSkillTargetMode.Single;
  pushStepsDefault: 1 | 2;
  collisionDamageMultiplier: 0.5; // 碰撞阻擋傷害比例
}
```

## 2. 擊退位移幾何向量演算法

擊退以施放者為錨點，將命中範圍（`pushRadius`，預設 $3 \times 3$ 或周身 8 格）內的敵方單位沿向量背離方向推擠。

### 2.1 方向向量判定（Push Vector Priority）

設目標座標為 $(L_t, D_t)$，施放者座標為 $(L_c, D_c)$：

1. **縱深軸優先（Depth Axis First）**：
   - 若 $D_t \neq D_c$，位移方向向量 $\vec{V} = (0, \text{sign}(D_t - D_c))$。
2. **水平車道軸次之（Lane Axis Fallback）**：
   - 若 $D_t = D_c$，位移方向向量 $\vec{V} = (\text{sign}(L_t - L_c), 0)$。
3. **同格重疊防禦**：若 $(L_t, D_t) = (L_c, D_c)$，位移向量為零，不產生位移。

### 2.2 逐格探測與阻擋狀態（Step-by-Step Raycast）

推擠步數為 $S = \text{pushSteps}$。目標部隊沿方向向量 $\vec{V}$ 逐格推進：
- 每前進 1 格需通過 `isCellFreeForPush(lane, depth)` 檢定（未越界且無其他部隊或不可通行障礙）。
- 一旦次格不可通行，立即終止位移，部隊停留於最後合法格，並標記 `blocked = true`。

## 3. 碰撞衝擊傷害與智力壓制門檻

### 3.1 撞擊阻擋衝擊（Push Blocked Impact）

當推擠過程中遭遇邊界、友軍或其他障礙物而導致 `blocked = true` 時，目標因劇烈衝撞承受額外衝擊傷害：

$$D_{\text{impact}} = \lfloor D_{\text{base}} \times 0.5 \rfloor$$

- 衝擊傷害記錄鍵值：`deltas.notes: 'push-blocked'`。
- 避免無限位移穿牆，確保戰術卡位（Choke Point）具備實質傷害收益。

### 3.2 智力壓制門檻（Int Advantage Check）

若戰法標記 `pushRequiresIntAdvantage: true`（如空城計擊退）：
- 施放方主將智力必須高於目標方智力（$\text{INT}_{\text{caster}} > \text{INT}_{\text{target}}$）。
- 若智力未達壓制，敵方識破計策，位移判定自動失效。

## 4. 力量霸體推進與危險地形連動

### 4.1 豪勇推入陷阱（Extend Push Into Hazard）

當武將展現壓倒性力量時，可突破常規擊退極限，將敵軍貫入危險地形：

$$\text{Threshold}_{\text{STR}} = 90$$

- 當 $\text{STR}_{\text{caster}} \ge 90$ 且前段推擠未受阻（`plan.blocked == false`），若沿推擠向量再前進 1 格為危險地格（`isHazard(lane, depth) == true` 且為空地），則強制追加 1 格位移。
- 成功將敵軍強制推入火海（Hazard Fire）、落石區或毒沼。

### 4.2 火神狩獵複合連動（Push-Fire Synergy）

戰法 `push-fire`（如祝融火神狩獵）：
1. 先將目標部隊向後推擠 $S$ 格。
2. 於目標脫離之原起始格（`originCell`）即時點燃火海地形（`Hazard_Fire`）。
3. 目標若在後方受阻，既受碰撞傷害，又無法回撤原安全格。

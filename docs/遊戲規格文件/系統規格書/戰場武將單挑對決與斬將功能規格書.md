## 1. 系統目標與設計哲學

單挑（Duel）是三國演義中最具戲劇性的武勇對決，也是戰場局勢瞬間逆轉的關鍵樞紐：
1. **臨陣亮劍的高風險博弈**：拒絕單挑有恥辱性的軍心代價，接受則以命相搏。
2. **客觀綜合決策模型**：AI 與玩家依主將生命、部隊兵力與總戰力計算接受分數（`DuelScore`）。
3. **拒絕單挑嚴懲（畏戰懲罰）**：膽怯拒戰導致全軍攻防與主將 HP 減半。
4. **斬將晉升即時閉環**：單挑勝利斬將立刻提供 $+15$ 點即時功業名聲，驅動 `InBattleAscension` 觸發即時升階！

## 2. 單挑發起與接受決策模型 (NUM-01 + NUM-02)

### 2.1 接受評分公式 (Duel Score Formula)
$$\text{DuelScore} = 0.45 \times \text{HpRatio} + 0.35 \times \text{SquadRatio} + 0.20 \times \text{PowerRatio} + \text{Jitter}$$
- $\text{HpRatio} = \text{CurrentHP} / \text{MaxHP}$（主將當前生命比，權重 0.45）
- $\text{SquadRatio} = \text{SquadTroops} / \text{MaxTroops}$（分隊現存兵力比，權重 0.35）
- $\text{PowerRatio} = \text{CombatPower} / \text{EnemyPower}$（總體戰力對比，權重 0.20）
- $\text{Jitter} \in [-0.05, +0.05]$（依確定性亂數注入之隨機抖動）

### 2.2 接受閾值 (Thresholds)
- **NORMAL / HARD / HELL 難度**：$\text{Threshold} = 0.58$（分數 $\ge 0.58$ 接受，否則拒絕）。
- **EASY 難度**：$\text{Threshold} = 0.45$（防守方更容易迎戰）。

## 3. 拒絕單挑之懲罰機制 (Cowardice Penalty)

防守方若拒絕單挑，全軍士氣崩潰並受到嚴厲戰場懲罰：
1. **全軍攻防減半**：防守方在場全體部隊攻擊力 $-50\%$、防禦力 $-50\%$，持續 2 回合。
2. **主將受挫懲罰**：主將因軍心渙散與威名掃地，當前生命值扣減 $-50\%$。
3. **戰場廣播提示**：UI 播報「拒絕將導致全軍攻防減半！全軍士氣受挫！」。

## 4. 單挑對決回合與勝負結算 (NUM-03)

單挑進入獨立對決演出，進行三回合馬背死鬥（普攻、格擋、暴擊、武將戰法）：

### 4.1 勝利方福祉 (Victory Spoils)
- **即時功業名聲**：獲勝主將立刻獲得 $+15$ 點斬將戰功名聲，計入 `InBattleAscension` 晉升門檻。
- **全軍士氣如虹**：勝方全軍士氣拉滿至 $100$，獲得暴擊率 $+15\%$ 加成持續 2 回合。
- **斬將神效**：若單挑中直接擊殺敵將，敵全軍陷入【潰散混亂】，直接喪失當回合行動。

### 4.2 戰敗方代價 (Defeat Penalty)
- 若主將被斬殺：進入陣亡結算，依 `doc_spec_0313` 產出對應品質之傳承虎符卡。
- 若負傷落荒而逃：當前 HP 歸 1，分隊兵力崩潰 $50\%$。

### 驗收條件 (Acceptance Criteria)
- [ ] **TC-DUEL-01**：決策分數精準依 $0.45\text{HP} + 0.35\text{兵力} + 0.20\text{戰力} \pm 0.05$ 計算。
- [ ] **TC-DUEL-02**：分數 $\ge 0.58$ 接受單挑；拒絕時防守方全軍攻防減半、主將 HP 減半。
- [ ] **TC-DUEL-03**：單挑獲勝精準提供 $+15$ 點功業名聲並推動將階晉升。
- [ ] **TC-DUEL-04**：斬將死亡時正確調用虎符卡產出與陣亡遺書流程。

## 1. 系統架構定位與戰役歷史背景

關羽水淹七軍、曹操引漳水灌鄴城，水攻為三國戰略中最具毀滅性之環境計謀。《三國人生》（3KLife）戰場水攻系統基於 2.5D 高度場與流體拓撲擴散演算，將堤壩破壞轉化為瞬態地質災害。

本系統核心價值：
1. **海拔驅動淹沒（Elevation-Driven Flooding）**：洪水沿著低窪谷底（`LOWLAND`）與平原地勢流動，天然丘陵與高地免受波及。
2. **非對稱兵種殺傷**：對缺乏舟船之陸地重裝部隊造成毀滅性淹溺與兵器浸濕懲罰。
3. **退水後次生泥濘（Mud Sluggish）**：洪水退去之地轉為深泥沼澤，永久改變戰場機動力。

## 2. 堤壩蓄水結構與決堤擴散演算法

戰場水系地圖中包含一至數個戰略堤壩節點（`DamNode`）：

```typescript
export interface IDamNode {
  readonly damId: string;                // 堤壩唯一識別碼
  readonly position: { x: number; y: number }; // 堤壩地格座標
  currentHp: number;                     // 堤壩當前耐久值
  readonly maxHp: number;                // 堤壩最大耐久值 (如 2000)
  readonly waterCapacity: number;        // 蓄水總量 (決定淹沒格數半徑)
  isBreached: boolean;                   // 是否已被破壞決堤
}
```

當堤壩受工兵破壞、計謀引爆或耐久歸零（`currentHp <= 0`）時，立即觸發 `EVENT_DAM_BREACHED`，啟動洪水擴散狀態機：

```
                    [決堤源頭: DamNode]
                            │
               ┌────────────┴────────────┐
               ▼                         ▼
      [LOWLAND 低窪地格]         [PLAIN 平原地格]
      100% 淹沒為深水湖泊        依地勢波及為淺水泥沼
      (持續 3 回合)              (持續 2 回合)
               │                         │
               └────────────┬────────────┘
                            ▼
                  [轉化為 MUD 泥濘地格]
                  移動力消耗 +2，迴避率歸零
```

擴散判定演算法：洪水自堤壩座標向外執行廣度優先搜尋（BFS），優先填入相鄰地格之海拔差 $\Delta H \le 0$ 的節點，直到消耗完畢 `waterCapacity` 總水量。

## 3. 部隊受災與淹溺傷害結算

當部隊所在格遭遇洪水湧入（`FLOODING`）時，依兵種防具與裝備執行即時傷害判定：

```typescript
export interface IFloodCasualtyModifier {
  readonly immediateDamageRatio: number; // 洪水衝擊瞬間扣除兵力上限比例
  readonly turnsInundated: number;       // 淹溺無法行動回合數
  readonly weaponDrenched: boolean;      // 是否浸濕弓弦與火藥 (遠程戰法失效)
}
```

1. **陸戰重甲與騎兵（Heavy Infantry & Cavalry）**：
   - 遭遇衝擊立即損失當前兵力 **$25\%$**，且因戰馬受驚與甲冑沉重，部隊陷入 `INUNDATED`（淹溺無法行動）$1$ 回合。
   - 所有火系戰法與火器強制失效；弓兵部隊弓弦浸濕，射程硬性降為 $1$ 格。
2. **舟師與水軍（Navy / Marines）**：
   - 若部隊攜帶「走舸/蒙衝」水戰裝備，**完全免疫洪水傷害**。
   - 反而在水域地格上獲得「如魚得水」增益：移動力 $+2$ 格、物理命中率 $+25\%$。

## 4. 次生泥濘（MUD）狀態機與退水規則

1. **洪水退潮轉換**：洪水自然持續滿定義回合後，水流退去，地格不會直接還原為平原，而是轉化為 `MUD`（泥濘）沼澤地形。
2. **泥濘阻滯懲罰**：
   - 任何非舟師部隊進入泥濘地格，通行移動力消耗額外 $+2$ 點。
   - 部隊迴避率強制歸零，且騎兵無法發動任何衝鋒突刺技能。

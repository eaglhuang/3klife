# 3KLife 戰場深溝伏兵以枯枝覆土偽裝踩踏塌陷地刺殺傷狀態機規格書

## 1. 系統定位與設計意圖

在三國曠野伏擊與隘口防禦作戰（如潼關誘敵、定軍山伏擊）中，單純正面硬碰極易遭敵精銳重騎兵鑿穿。本系統規範三國特種隱蔽陷阱工程「偽裝深溝陷馬坑與地刺破陣陣列（Concealed Pitfall Spike Trap）」之隱蔽開挖、覆土偽裝、踩踏崩塌與混亂殺傷狀態機：
- **深溝暗樁工兵開挖**：工兵於敵軍騎兵必經隘道前沿開挖寬丈二、深八尺之連續溝槽，底層密植生鐵淬火地刺或削尖硬木樁。
- **枯枝蘆席擬態偽裝**：以細韌生枝架空為橫梁，上鋪蘆葦草席，最外層撒薄土與周遭雜草碎石，視覺上與自然地表無異。
- **踩踏誘爆與連鎖擠壓**：敵前鋒重騎兵奔馳踏過時，假地表瞬間崩塌，引發連鎖踩踏與後隊衝撞癱瘓。

## 2. 狀態機架構與轉換生命週期

深溝陷坑狀態機（代碼：`CONCEALED-PITFALL-SPIKE-TRAP01`）遵循嚴密工程與觸發週期：

```
[ TRENCH_EXCAVATION ] (工兵掘土成深溝與釘立生鐵地刺)
          │
          ▼
[ CAMOUFLAGE_LAYERING ] (架設柳木橫梁鋪設蘆席與雜草覆土)
          │
          ├── 敵軍斥候探測 ──> [ DETECTION_PROBABILITY_CHECK ]
          ▼
[ CONCEALED_WAITING ] (偽裝完畢融入地形等待敵騎進入)
          │
          ├── 誘敵先鋒佯敗引誘 ──> [ ENEMY_CHARGE_TRIGGER ]
          ▼
[ STRUCTURAL_COLLAPSE ] (馬蹄承重過載橫梁斷裂全線崩塌)
          │
          ▼
[ IMPALEMENT_CASUALTY ] (跌落深坑刺穿馬腹引發踩踏擠壓)
          │
          ▼
[ AMBUSH_VOLLEY_ENGAGE ] (周邊伏兵突起弩箭齊發圍殲殘敵)
```

### 狀態細部定義

1. **TRENCH_EXCAVATION（掘坑設刺）**：
   - 工兵排成三班輪替掘土，溝底密釘削尖竹樁 120 根，每根塗抹生烏頭汁液，增強創傷致死率。
2. **CAMOUFLAGE_LAYERING（覆土偽裝）**：
   - 以易斷細柳枝橫向架設，覆蓋雙層蘆席後鋪設 2 寸浮土，周圍撒野花枯草消除新土氣味與反光。
3. **CONCEALED_WAITING（靜默潛伏）**：
   - 陷阱陣列進入隱蔽待命姿態，敵軍斥候騎兵肉眼偵測機率壓低至 6%。
4. **STRUCTURAL_COLLAPSE（過載崩塌）**：
   - 當單一斷面承載重量超過 $350\,\text{kg}$（單騎戰馬衝擊力道）時，柳枝橫梁瞬間脆斷，頂蓋徹底凹陷。
5. **IMPALEMENT_CASUALTY（穿刺殺傷）**：
   - 跌落深溝戰馬承受 3.5 倍動能衝擊，馬腹被地刺貫穿，騎兵受困坑底動彈不得，後續跟進部隊因避讓不及發生疊壓。
6. **AMBUSH_VOLLEY_ENGAGE（伏兵發起）**：
   - 兩側埋伏步弩手聽聞崩塌呼喊，齊射連弩壓制敵軍中軍，展開分割包夾。

## 3. 關鍵數值與計算判定公式

### 3.1 偽裝辨識概率公式

敵軍探哨識別深溝偽裝之機率 $P_{spot}$：
$$P_{spot} = \max\left(0.03, \frac{\text{Perception}_{scout} \times (1.0 - \text{RainMuck})}{\text{Skill}_{engineer} \times 1.4 + \text{DuskBonus}}\right)$$
- $\text{Perception}_{scout}$：敵軍斥候偵查感知值。
- $\text{Skill}_{engineer}$：我方掘壕工兵之偽裝工程技能等級。
- $\text{RainMuck}$：泥濘雨天視覺混淆加成（取 0.35）。
- $\text{DuskBonus}$：黃昏薄暮視覺減益（取 0.25）。

### 3.2 騎兵衝擊連鎖踩踏損傷

前鋒騎隊跌落引發之後續混亂傷害 $D_{cascade}$：
$$D_{cascade} = N_{fallen\_horses} \times M_{horse} \times V_{charge}^2 \times 0.045 \times \text{DensityFactor}$$
- $N_{fallen\_horses}$：首波墜坑戰馬數（通常 8~16 匹）。
- $V_{charge}$：衝鋒初速度（約 10~14 m/s）。
- $\text{DensityFactor}$：敵軍騎兵行軍密集度（錐形陣為 1.6，鶴翼散陣為 0.8）。
- 混亂狀態持續時間固定為 45 秒，期間防禦力下降 40%。

## 4. 戰術連鎖與攻防克制

1. **撕碎騎兵衝鋒勢頭**：徹底打斷敵方重騎兵的破陣衝量，將戰場主動權轉移至伏兵長槍陣手中。
2. **天敵與反制手段**：
   - **驅趕牛羊探路**：敵方若驅趕大群牲畜先行踐踏，可提前誘爆深溝陷阱，使伏兵徒勞無功。
   - **工兵長矛探地**：謹慎的主帥會令先鋒步卒持丈八長矛連續戳刺地面，有 75% 機率探出虛浮空腔。

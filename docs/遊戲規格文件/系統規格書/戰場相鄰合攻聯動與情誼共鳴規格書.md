# 戰場相鄰合攻聯動與情誼共鳴規格書

> **責任邊界**：本檔為戰場格位相鄰判定、合攻聯動機率（ComboAttackKin）與情誼援護追擊的單一真相來源。
> **關聯 WBS**：KIN-09（合攻聯動+30%）、KIN-06（動態關係建立）、KIN-08（戰場關係事件）。
> **整併裁決**：確立一般部隊無合攻（觸發率 0）；僅義兄弟、夫妻等深厚羈絆在相鄰格時生效，多重羈絆採 Max 不累乘。

---

## §1. 合攻聯動觸發條件與機率公式

戰場上武將主動發起普通攻擊或物理突擊後，系統即時判定相鄰友軍是否發動「合攻聯動（Combo Attack）」：

1. **相鄰判定**：以發起主將所在格子為中心，九宮格相鄰 8 格（切比雪夫距離 $\le 1$）內之友軍部隊。
2. **羈絆資格約束**：
   - 一般非史實/非特殊關係友軍：合攻觸發率為 **0%**（杜絕路人隨機合攻）。
   - 僅擁有**義兄弟（Sworn Brother）**、**夫妻（Spouse）**或**生死戰友**關係者具備合攻資格。
3. **機率計算公式**：
   $$\text{FinalChance} = \min\left(1.0, \text{COMBO\_ATTACK\_BASE\_CHANCE} \times \max_{r \in \text{AdjacentRelations}}(\text{comboAttackRateMod})\right)$$
   - 基礎合攻觸發率：$\text{COMBO\_ATTACK\_BASE\_CHANCE} = 20\%$。
   - 義兄弟 / 夫妻加成倍率：$\text{comboAttackRateMod} = 1.3$（即 $+30\%$，觸發率達到 $26\%$）。
   - **多重相鄰仲裁 (Max Rule)**：若周遭同時有 2 位以上義兄弟，**僅取最大倍率 1.3**，嚴禁疊乘（如不得算 $1.3 \times 1.3$）。

## §2. 援護追擊結算與冷卻約束

判定觸發合攻後，相鄰羈絆部隊立即介入結算：

| 結算項目 | 數值與規則約束 | 說明 |
|:---|:---:|:---|
| **援護傷害** | 主動普攻之 **60%** | 不受距離反擊懲罰，但若目標已陣亡則追擊無效 |
| **行動力損耗** | **不消耗** 行動力 (AP) | 援護方本回合仍可正常移動與發動自身技能 |
| **每回合上限** | 單支部隊每回合最多 **2 次** | 防止無限連續合攻產生戰力失衡 |
| **精力扣減** | 援護部隊扣 **3 點精力** | 精力低於 10 時強制無法響應合攻 |
| **士氣反饋** | 雙方全軍士氣 **+5 點** | 成功合攻提振同陣營軍心 |

## §3. 戰場演出與情誼共鳴契約

當合攻判定成功時，戰場進入情誼共鳴演出流程：

```
[主攻部隊攻擊命中] ──> [合攻判定成功] ──> [雙武將切屏剪影 (0.6s)]
                                               │
[戰果跳字與士氣提升] <── [援護部隊突進斬擊 (0.8s)] <──┘
```

1. **雙武將切屏 (Split-Screen Cue)**：
   - 畫面中央出現金色刀光裂痕，兩側分別浮現主攻武將與援護武將特寫剪影。
2. **情誼共鳴專屬台詞**：
   - 劉備／關羽／張飛：「桃園同心，共破頑敵！」
   - 周瑜／小喬：「琴瑟相和，烈火焚營！」
   - 趙雲／馬超：「雙龍會聚，誰攖其鋒！」
3. **無縫銜接**：演出全程控制在 1.4 秒內，支援點擊跳過（Fast Forward），保證戰鬥節奏流暢。

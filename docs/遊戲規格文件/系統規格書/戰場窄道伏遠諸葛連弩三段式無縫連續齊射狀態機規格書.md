# 3KLife 戰場窄道伏遠諸葛連弩三段式無縫連續齊射狀態機規格書

## 1. 系統定位與設計意圖

在三國蜀道峽谷、隘口阻擊與平原防禦戰中（如木門道張郃之死、街亭斷後），面對敵重騎兵高速穿透突擊，單發強弩裝填時間過長（需蹬弓張弦達 8~12 秒），極易在射擊間隙被敵騎兵貼身碾壓。本系統規範特種遠程機械陣列「諸葛連弩三段式無縫連射陣型（Zhuge Crossbow Three-Volley Interlock）」之箭匣供彈、槓桿往復、三列交替循環與無死角壓制狀態機：
- **元戎連弩十矢連續供彈**：以頂置十矢木製箭匣自重落箭，推拉槓桿一次即完成張弦與落矢，單人三秒即可射出一矢。
- **三段式梯隊無縫交替循環**：陣列分為前列（齊射壓制）、中列（壓桿張弦）、後列（更換滿裝箭匣），鼓點節奏指揮無縫接替。
- **狹窄通道金屬風暴封鎖**：在寬度受限的隘道咽喉，形成每秒數十枚塗毒鐵羽箭鏃的密不透風彈幕，徹底壓制衝鋒動能。

## 2. 狀態機架構與轉換生命週期

連弩三段齊射狀態機（代碼：`ZHUGE-CROSSBOW-THREE-VOLLEY-INTERLOCK01`）管理自列陣張弦至彈幕覆蓋之完整週期：

```
[ VOLLEY_DEPLOY_LINEUP ] (三列橫隊交錯站位鎖定隘口射角)
          │
          ▼
[ RANK1_AIM_FIRE_BURST ] (第一排持弩齊射傾瀉十矢箭雨)
          │
          ├── 第一排彈匣打空下蹲 ──> [ RANK1_RELOAD_SWAP ]
          ▼
[ RANK2_STEP_FORWARD_FIRE ] (第二排踏前接替射擊無縫銜接)
          │
          ├── 第二排彈匣打空下蹲 ──> [ RANK2_RELOAD_SWAP ]
          ▼
[ RANK3_CONTINUOUS_CHAIN ] (第三排補位射擊完成連鎖閉環)
          │
          ▼
[ ENEMY_CHARGE_DECIMATED ] (敵先鋒人馬疊壓衝擊動能完全崩解)
```

### 狀態細部定義

1. **VOLLEY_DEPLOY_LINEUP（三段列陣）**：
   - 弩手依「前中後」三排密集排列，每排 30 名連弩士，兩側配備持大盾矛手提供側翼護衛。
2. **RANK1_AIM_FIRE_BURST（前排射擊）**：
   - 聽聞旗鼓急促三響，前排連弩手推動拉桿連續發射，8 秒內每人傾瀉 10 枚鐵矢，覆蓋敵先鋒 80 步距離。
3. **RANK1_RELOAD_SWAP（蹲伏換匣）**：
   - 前排射空後迅速單膝下蹲，自腰間拔出預裝滿十矢之新箭匣滑入滑道，拉動推桿就位。
4. **RANK2_STEP_FORWARD_FIRE（中排接力）**：
   - 第二排跨前一步將弩機架於前排肩側，在第一排停射後 0.5 秒內即刻續射，維持彈道密度不中斷。
5. **RANK3_CONTINUOUS_CHAIN（後排連鎖）**：
   - 第三排緊隨其後完成第三輪射擊，此時第一排已完成整裝，重新起身接替，形成完美的無限射擊閉環。
6. **ENEMY_CHARGE_DECIMATED（衝鋒覆滅）**：
   - 衝鋒騎兵在 15 秒內正面承受超過 900 支鐵箭貫穿，馬匹倒地堆疊成肉牆阻絕後續部隊。

## 3. 關鍵數值與計算判定公式

### 3.1 彈幕密度與火力間隔時間

三段射擊陣列之射擊間隔時間 $\Delta t_{gap}$（秒）：
$$\Delta t_{gap} = \max\left(0.15, T_{switch} - \frac{N_{ranks} \times T_{burst}}{N_{ranks} - 1}\right)$$
- $T_{switch}$：行排切換步幅延遲（約 0.6 秒）。
- $T_{burst}$：單排連射總時長（約 8.0 秒）。
- $N_{ranks}$：交替排數（3 排）。
- 計算得 $\Delta t_{gap} \le 0.2\,\text{s}$，在敵軍視角幾乎等同於毫無停頓之持續金屬風暴。

### 3.2 狹道破甲衝量衰減模型

衝鋒部隊剩餘動能 $E_{charge}(t)$ 隨承受連弩彈雨之衰減：
$$E_{charge}(t) = E_0 \times \exp\left(-\lambda_{arrow} \times \Phi_{density} \times t\right)$$
- $\Phi_{density}$：單位截面箭雨密度（約 12 支/$\text{m}^2$）。
- $\lambda_{arrow}$：鋼鏃穿甲阻滯係數（0.28）。
- 敵騎兵在穿越 30 步死亡射擊區後，剩餘衝鋒動能衰減達 92%，完全喪失破陣衝擊力。

## 4. 戰術連鎖與攻防克制

1. **以步制騎極致戰術**：使輕裝弩兵在峽谷狹地中以純火力徹底擊潰重甲西涼騎兵。
2. **天敵與戰術反制**：
   - **箭矢補給耗盡**：連弩極度依賴箭矢儲備，每名弩士僅隨身配備 3 匣（30 矢），若無輜重車源源不斷供彈，一刻鐘內即彈盡。
   - **兩側崖頂伏兵夾擊**：若敵方斥候自兩側山崖居高臨下拋投滾木雷石，密集三排連弩陣列極易遭受範圍重創。

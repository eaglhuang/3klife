# 戰場糧草即時扣除模型與虎符糧耗矩陣規格書

## 1. 核心定位與糧草體系契約

本規格書為戰場部署糧草即時扣除演算法與虎符品質星級糧耗矩陣（Battle Grain Supply Model，代號 `DEP-04`）的單一真相來源（Single Source of Truth）。在戰鬥體系中，糧草全面取代傳統動作點（Action Points / DP），作為部隊入場、維持補給與施展精銳戰法之實質戰略燃料。

```typescript
export interface GrainSupplyContract {
  costFormula: 'getDeployCost';
  shortageFoodThreshold: 50;      // 季末低於 50 糧啟動折損保護
  shortageDiscountRatio: 0.80;    // 糧草不足次場 8 折優惠
  militiaFoodCost: 5;             // 民兵保底 5 糧
}
```

## 3. 糧荒折損扶持機制（Food Shortage Discount）

當玩家所屬勢力遭遇大旱、蝗災或連續戰敗導致糧草極度匱乏時，觸發戰略扶持規則：

1. **觸發臨界點**：
   - 當季結算前，城市剩餘可用糧草存量：
     $$\text{Food}_{\text{reserve}} < 50$$
2. **次場 8 折優惠（80% Cost）**：
   - 進入下一場戰鬥時，標記 `tallyFoodDiscount = true`。
   - 所有虎符特殊部隊出陣糧耗直接套用 8 折優惠（向下取整）：
     $$\text{FoodCost}_{\text{discounted}} = \lfloor \text{FoodCost}_{\text{base}} \times 0.8 \rfloor$$
   - 例：SSR 3★ 原糧耗 92，打折後僅需 $\lfloor 92 \times 0.8 \rfloor = 73$ 糧草！
   - 一般常規兵種不打折；優惠僅在該單場戰鬥生效一次，不可多季累加。

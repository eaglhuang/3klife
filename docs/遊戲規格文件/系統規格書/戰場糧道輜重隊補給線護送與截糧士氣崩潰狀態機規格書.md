# 3KLife 戰場糧道輜重隊補給線護送與截糧士氣崩潰狀態機規格書

> **規格代碼**：SPEC-BAT-SUPPLY01  
> **關聯 WBS**：BATTLE-SUPPLY-01（戰場糧道拓撲連通度、輜重隊行軍護送與斷糧士氣崩潰狀態機）  
> **系統分類**：戰鬥系統 / 後勤補給與戰略圍困演算法  
> **狀態**：正式生效（單一真相來源，嚴禁尾端追加補丁）

---

## 1. 系統架構定位與兵馬未動糧草先行

兵馬未動，糧草先行；官渡之勝在烏巢，街亭之敗在斷道。《三國人生》（3KLife）戰役層面引入**空間糧道動態連通度演算（Dynamic Supply Line Topology）**。

本系統核心價值：
1. **空間拓撲連通（Topological Connectivity）**：作戰部隊必須與主營地保持連續通行路徑。
2. **輜重實體化護送（Supply Wagon Escort）**：糧車不再是抽象數值，而是戰場可被攔截、摧毀與搶奪之物理實體。
3. **飢餓與譁變恐慌（Starvation & Mutiny）**：部隊一旦失去補給，將急速陷入士氣瓦解與自相踩踏。

---

## 2. 糧道拓撲連通度演算法

戰鬥每回合結算時，系統對陣營內所有作戰部隊執行拓撲連通檢測：

```typescript
export interface ISupplyLineState {
  readonly unitId: string;
  readonly baseCampPosition: { x: number; y: number };
  isConnected: boolean;              // 當前是否保持補給連通
  starvationTurns: number;           // 已持續斷糧回合數
  supplyPath: Array<{ x: number; y: number }>; // 最短補給地格路徑
}
```

```
   [大本營 BASE_CAMP] ──(安全平原格)──► [地格 A] ──(安全路徑)──► [前線先鋒部隊]
                                           ▲
                                           │ (若敵軍部隊卡位或路徑起火)
                                           ▼
                                    【補給線截斷 CUT-OFF】
```

連通條件定義：  
自部隊所在座標至大本營之間，必須存在至少一條無障礙路徑。若路徑被敵軍作戰單元阻擋（Zone of Control, ZoC 壓制）、被大火燃燒阻隔或被洪水切斷，判定為**糧道中斷（Disconnected）**。

## 3. 三階斷糧瓦解狀態機

部隊一旦處於 `isConnected = false`，進入斷糧狀態機流轉：

```
       [SUPPLIED 補給充足] ──────── 糧道暢通、全屬性正常 ────────
                │
                │ 糧道中斷 1 回合
                ▼
      [STARVING_L1 飢疲] ─── 每回合士氣 -10，移動力 -1
                │
                │ 持續斷糧 2 回合
                ▼
      [STARVING_L2 潰散臨界] ─ 每回合士氣 -20，全攻防屬性 -30%
                │
                │ 累計斷糧 3 回合
                ▼
      [MUTINY 全軍譁變] ───── 部隊失控潰散、無法接收軍令、逃兵 50%
```

1. **第 1 回合（飢疲）**：部隊士氣扣除 $10$ 點，將士腹中飢餒，行軍移動力 $-1$ 格。
2. **第 2 回合（潰散臨界）**：部隊士氣再扣 $20$ 點，全軍攻防屬性強制折減 $30\%$，且所有怒氣與奧義戰法強制封印。
3. **第 3 回合（全軍譁變）**：部隊陷入徹底失控狀態（Mutiny）。每回合 $50\%$ 兵力直接潰逃消散，剩餘兵力無法聽從玩家指令，朝地圖外緣四散奔逃。

## 4. 實體輜重車隊（Supply Wagon）與截獲結算

每 4 回合雙方大本營自動派出一支**輜重車隊（HP: 800，防禦: 0，移動力: 2 格）**：
1. **運送補給**：車隊抵達前線部隊所在格時，立即修復部隊所有斷糧狀態，並為該部隊恢復 $20\%$ 兵力與 $15$ 點士氣。
2. **劫掠結算（Pillage）**：若敵軍擊破或佔領輜重車隊所在格：
   - 截糧方陣營立即獲得 **$50$ 點 SP** 計略點數與 $10$ 點全軍士氣激勵。
   - 被截糧方該批輜重全毀，全軍收到「輜重被劫」急報，全陣營部隊士氣集體下跌 $8$ 點。

# 戰場視覺四層渲染與互動戰術物件狀態機規格書

> **文件狀態**：單一真相來源（Single Source of Truth）  
> **系統代碼**：`LVL-07`、`LVL-08`、`SYS-BATTLE-LAYERS-OBJECTS`  
> **核心職責**：確立戰鬥場景「四層獨立替換渲染管線」（遠景背景/棋盤貼花/立牌粒子/戰鬥 HUD），以及四大戰術互動物件（落石機關/水閘/營帳糧倉/陷阱叢）之血量與觸發/擊破狀態機。

---

## 1. 戰場視覺四層渲染管線（Four-Layer Pipeline）

所有戰鬥地圖資產嚴格遵循四層獨立替換架構，禁止將動態互動元素畫死在背景中：

| 渲染層級 (Layer) | 負責內容與元件 | 替換機制與特性 | 深度排序 (Z-Order) |
|---|---|---|:---:|
| **Layer 0: 遠景背景** | 山脈、峽谷天際線、遠方城池 (`scene-backgrounds.json`) | 靜態平鋪，支援天氣濾鏡與晝夜著色器 | Z = 0 |
| **Layer 1: 棋盤貼花** | 地形網格、燃燒焦土、毒水潭、水波波紋 (`Decal`) | 資料驅動貼花，不影響尋路網格坐標 | Z = 10 ~ 20 |
| **Layer 2: 立牌與粒子**| 部隊站位立牌、機關實體、火海粒子 (`VFX` / `Spine`) | 依 Y 軸排序實現遮擋，可被攻擊擊破 | Z = 100 ~ 200 |
| **Layer 3: 戰場 HUD** | 血條、部隊標籤、路徑箭頭、技能施放按鈕 | 螢幕空間 UI，關鍵格微光低於 HUD | Z = 1000+ |

## 2. 四大戰術互動物件狀態機（Interactive_Object）

戰場存在四大可被普攻、戰法或走位觸發之實體物件：

```
[NORMAL (完好待命)] ──(遭受攻擊/踩踏)──> [DAMAGED (受損裂痕)] ──(HP歸零)──> [TRIGGERED/DESTROYED (觸發/覆滅)]
```

| 物件類別 (Type) | 基礎 HP | 觸發/摧毀條件 | 引發之地格連動效果 | 戰術用途與收益 |
|---|:---:|---|---|---|
| **落石節點 (Rockfall_Node)** | 800 | 遭受遠程計策或重擊至 HP=0 | 於下方 3 格生成持續 2 回合之 `Hazard(Rock)` 高傷 | 封鎖敵軍峽谷通道 |
| **蓄洪水閘 (Floodgate)** | 1200 | 破壞閘門或觸發水系戰法 | 沿低窪河道產生 4 格衝退之 `ForceMove(Water)` | 沖散重裝步兵陣型 |
| **敵營糧倉 (Camp_Target)** | 2000 | 近戰部隊佔領或火攻擊破 | 敵全軍士氣 -20，戰後增加 500 糧草 Salvage | 斷敵補給，速破敵心 |
| **陷阱暗樁 (Trap_Cluster)**| 1 | 敵方或我方部隊踏入該格 | 立即扣除 15% 當前兵力並施加持續 1 回合定身 | 阻截騎兵突擊衝鋒 |

## 3. 資料結構契約（InteractiveObjectState）

```typescript
export enum InteractiveObjectType {
  Rockfall = 'Rockfall_Node',
  Floodgate = 'Floodgate',
  CampTarget = 'Camp_Target',
  TrapCluster = 'Trap_Cluster'
}

export enum ObjectLifecycleState {
  Normal = 'Normal',
  Damaged = 'Damaged',
  Triggered = 'Triggered',
  Destroyed = 'Destroyed'
}

export interface InteractiveObjectEntity {
  objectId: string;
  type: InteractiveObjectType;
  tileCoord: { x: number; y: number };
  maxHp: number;
  currentHp: number;
  state: ObjectLifecycleState;
  targetHazardEffect?: string; // 擊破後觸發之 TileEffectId
}
```

## 4. 驗收標準與 CI 閘門（Acceptance Criteria）

1. **分層替換無破圖**：
   - 背景切換為夜戰或雪景時，Layer 1~3 貼花與立牌不受影響，正常渲染。
2. **擊破狀態機即時連動**：
   - 當 `Camp_Target` 之 HP 歸零時，即刻由 `Damaged` 轉為 `Destroyed`，並向戰場日誌發送糧倉覆滅事件。
3. **單元測試涵蓋**：
   - 測試覆蓋四大互動物件受擊扣血、閘門蓄洪推進判定與陷阱踏入觸發邏輯。

### 天氣對戰法與機制的強約束 (Weather Constraints)

這是一切天氣對戰鬥底層影響的 Truth Source。在特定天氣條件下，武將指令面板的操作會被直接鎖定，以呈現真實戰場環境的嚴苛。

| 受影響行為/戰法 | 晴天 | 雨天 | 大霧 | 大風 | 夜戰 | 雷暴 |
|---|---|---|---|---|---|---|
| **火計 / 火箭** | 正常 | 🛑 **禁用/變灰** | 🛑 **禁用/變灰** | ⭐ 傷害 ×2 | 正常 | 🛑 **禁用/變灰** |
| **水攻** | 正常 | ⭐ 範圍擴大 | 正常 | 正常 | 正常 | 正常 |
| **遠程攻擊命中** | 正常 | -20% | -30% | 正常 | -25% | 正常 |
| **遠程射程** | 正常 | 正常 | 正常 | 射程 -2 | 正常 | 正常 |

> **UI 強約束格式**：當環境條件列為 [🛑 禁用] 時，戰場 HUD 選單中的該戰法圖標應 **Gray-out (變灰)** 且不可點擊，點擊時彈出 Toast 提示：「當前天氣不符合施放限制」。

### 戰場天氣來源與戰前顯示（使用者 2026-11-22 裁決）

- **劇情關**：天氣照關卡劇本固定，不隨機。例：赤壁之戰固定為東風（大風，`WINDY`）。固定天氣寫在關卡資料的 `weather` 欄位。
- **其他戰鬥**：依「當前季節」的機率表隨機抽出開戰天氣；同一場戰鬥開戰後天氣不再重抽（戰鬥中回合變天仍歸上表 P1「天氣變化系統」，與本條互不覆蓋）。
- **戰前顯示**：出戰前的環境偵察畫面（上表 P1「戰場環境偵察」）一定要顯示本場天氣；劇情關也顯示，讓玩家知道為什麼是這個天氣。
- **機率放 JSON**：各季節對六種天氣的機率表放資料檔（建議 `assets/resources/data/battle-weather.json`，結構 `season → { SUNNY, RAINY, FOG, WINDY, NIGHT, THUNDER }`，每季總和 1），程式不寫死；數值由企劃調整。
- 與 `doc_spec_0388`（天氣對戰法強約束）的關係：本節只決定「今天是什麼天氣」，戰法禁用與加成仍照上表。

### 適性計算公式

```
// 最終戰鬥修正
terrain_mod = TERRAIN_TABLE[general.terrain_aptitude][current_terrain]
weather_mod = WEATHER_TABLE[general.weather_aptitude][current_weather]
troop_mod = TROOP_TABLE[general.troop_aptitude][assigned_troop_type]

final_attack = base_attack × (1 + terrain_mod.atk) × (1 + weather_mod.atk) × (1 + troop_mod.atk)
final_defense = base_defense × (1 + terrain_mod.def) × (1 + weather_mod.def) × (1 + troop_mod.def)
final_move = base_move + terrain_mod.move + troop_mod.move
final_accuracy = base_accuracy + terrain_mod.acc + weather_mod.acc
```

### 競技場積分公式（名將挑戰賽用）

> **來源**：遊戲機制優化與策略建議.md (doc_spec_0065)、賽馬娘機制轉化三國戰場.md (doc_spec_0067)

在名將挑戰賽等 PvP 競技場景中，武將的參考戰力分數使用以下複合公式計算：

```
Score = Σ[(屬性總和 × 地形適性倍率) + (戰法點數 × 剋制係數)] × 存活係數

// 地形適性倍率（對應等級）
TERRAIN_MULTIPLIER = { S: 1.5, A: 1.2, B: 1.0, C: 0.85, D: 0.70 }

// 存活係數 = 當前HP / MaxHP（0.0~1.0）
SURVIVE_FACTOR = current_hp / max_hp

// 說明：
// - 屬性總和 = STR + INT + LEA + LUK（不含 HP/DEF 等防守屬性，側重輸出面）
// - 戰法點數 = 已配備的戰法等級總和
// - 剋制係數 = 戰法對當前地形/天氣的克制倍率（1.0~1.5）
```

**設計意圖**：此積分反映武將在「特定戰場環境」下的綜合貢獻，而非純粹強弱排名，促使玩家根據賽季場地特性針對性培育。

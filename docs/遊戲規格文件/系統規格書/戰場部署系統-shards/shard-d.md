## 🗳 MCQ 決策記錄（Q63）

- **問題**：英靈虎符vs精銳虎符商業差異化是否正式化
- **衝突說明**：doc_spec_0107 與 doc_spec_0109 均建議將虎符分為「英靈虎符（Heritage Seal）= 名將死亡轉化，有招牌技能但冷卻長/糧耗高」與「精銳虎符（Gacha Seal）= 常態數值穩定，低冷卻低糧耗」。此二元差異化是兩份文件的核心商業主張。但現行 doc_spec_0012 只有「死亡傳承虎符」和「名將專屬虎符」兩張表，兩者都走相同的星級/品質公式，沒有「英靈主動技能爆發 vs 精銳持續輸出」的明確規格。若採 A，需在 TigerTally 新增 TallyCategory（SPIRIT/ELITE）欄位並配合冷卻/糧耗欄位；若採 B，維持現有 schema 不動，但失去討論文件的核心商業亮點。
- **裁決**：**選項 B** — 維持現有統一品質體系（R/SR/SSR/UR），不做英靈/精銳概念二分

## 戰場部署與操作體驗最新定案（2026-11-06）

### 1. 部署半透明預覽（Ghost Preview）
- **互動反饋**：玩家在拖曳部隊卡牌或點擊戰場格子時，目標格即時顯示 **50% 半透明之部隊模型／立繪預覽（Ghost Preview）**：
  - **合法可部署格**：半透明模型 ＋ 淺綠色呼吸光圈。
  - **非法不可部署格**（障礙格、超出部署深度、已有單位、兵力糧草不足）：半透明模型 ＋ 紅色禁止叉號提示。

### 2. 兵籍卡長按檢視與規格
- **長按觸發時長**：固定為 **0.5 秒（500ms）**（防誤觸標準閾值）。長按後彈出該部隊之攻防生命、當前兵力、將階加成與專屬技能詳情。
- **卡片高度規格**：固定為 **219px**（容納將階標籤、名聲進度條、兵種圖標與兵力文字，避免 202px 中文字體貼邊溢出）。

### 3. 戰場環境加成（第一階段 MVP）
- 第一階段嚴格收斂為**「純攻擊加成 $+15\%$」**，避免多重環境乘區疊加失控。
- 各兵種於適性地形（如騎兵於平原、水軍於水域、弓兵於山林）直接獲得 $+15\%$ 攻擊力；全場景全局增幅與動態蔓延留待後續專題模組擴充。

### 4. 幕府軍事任務戰法跨場景注入機制
- 當武將完成幕府特定軍事任務（如「先遣伏兵」或「斷敵糧道」）時，於 `GameSession` 記錄一次性加成快照：
  ```typescript
  export interface MilitaryTaskBattleBonus {
    sourceTaskId: string;
    bonusType: 'AMBUSH_READY' | 'MORALE_BOOST' | 'FIRE_TRAP';
    grantedTacticId: string;    // 例如臨時戰法【伏兵襲殺】或【士氣鼓舞】
    expiresAtBattleCount: 1;   // 僅限下一場戰鬥出征有效
  }
  ```
- 下一場出征戰鬥初始化時，`SortieDeploy` 讀取並將該戰法注入操作欄（標註「幕府任務加成·一次性」），戰鬥結算後即刻註銷。

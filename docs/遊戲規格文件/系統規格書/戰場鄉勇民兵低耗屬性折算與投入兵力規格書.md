# 戰場鄉勇民兵低耗屬性折算與投入兵力規格書

## 1. 核心定位與民兵契約

本規格書為戰場低階應急兵源鄉勇民兵（Militia Unit Specification，代號 `DEP-07`）的單一真相來源（Single Source of Truth）。民兵作為在糧草極度匱乏或正規軍耗盡時的應急部隊，具備極低的軍糧門檻與投入兵力，不具備特殊戰法、奧義或兵種剋制特能。

```typescript
export interface MilitiaContract {
  statRatio: 0.40;                // 攻防為基礎兵種的 40%
  foodCost: 5;                    // 出陣消耗 5 糧
  troopCost: 300;                 // 投入兵力 300 人
  isElite: false;                 // 不佔用精銳上限
  hasSpecialTactics: false;       // 無特殊技能
}
```

---

## 2. 數值折算與戰鬥屬性模型

民兵出陣時，其戰鬥屬性由對應基礎正規步兵屬性折算而來：

### 2.1 攻防折算公式

$$\text{ATK}_{\text{militia}} = \lfloor \max(0, \text{ATK}_{\text{base}}) \times 0.40 \rfloor$$

$$\text{DEF}_{\text{militia}} = \lfloor \max(0, \text{DEF}_{\text{base}}) \times 0.40 \rfloor$$

- **40% 戰力係數**：民兵攻擊與防禦均為正規步兵的 40%，數值採無條件捨去（Floor）。
- **負數防護**：若輸入屬性為負數，強制歸零保底。

### 2.2 投入資源與出陣成本

- **糧草消耗**：固定 5 點軍糧（`MILITIA_FOOD_COST = 5`），為全遊戲最低出兵糧耗（正規步兵需 10 糧）。
- **軍勢池扣除**：固定投入 300 兵力（`MILITIA_TROOP_COST = 300`），相比正規部隊（500 兵力）更易於殘局補位。

---

## 3. 戰場定位與戰術限制

1. **豁免精銳上限**：
   - 民兵為純基層步卒（`isElite = false`），即便場上精銳名額已滿（4~6 隊），依然可以自由調派民兵入場。
2. **無兵種特性（Vanilla Unit）**：
   - 民兵不享有長槍反騎、騎兵衝鋒、弓兵齊射等兵種專屬特性，亦無法發動虎符戰法。
3. **戰術墊線與吸引火力（Cannon Fodder）**：
   - 適合用於戰術咽喉卡位（Choke Point Blocking）、替主將肉身吸收敵方先手爆發傷害，或觸發敵方陷阱。

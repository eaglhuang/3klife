# 3KLife 戰場重型投石機連續拋射碎石散彈壓制城垛弓弩手狀態機規格書

## 1. 系統定位與設計意圖

在三國攻城作戰（如官渡之戰曹操發石車破高櫓、下邳圍城戰）中，常規單顆千斤整石雖然能破壞城門或夯土城牆，但對於藏身於城垛與望樓射孔後的守軍弓弩手殺傷覆蓋面狹窄。本系統規範攻城器械特種壓制彈種「碎石散彈面狀壓制彈幕（Catapult Grapeshot Battlement Suppression）」之彈袋裝填、空中解體散佈、城頭彈幕壓制與射手擊退狀態機：
- **粗麻編織碎石散彈網包**：將 40 至 60 枚如拳頭大小之堅硬青石與生鐵碎塊裝入粗麻繩袋，袋口以定時易斷草索束緊。
- **拋射空中解體與錐形散佈**：發石車梢桿拋出後，散彈網包於空中受強大離心力與氣流阻力解體，彈丸呈錐形大扇面覆蓋城頭。
- **立體火力壓制與步兵先登登城**：密集如雨的碎石彈幕迫使城垛守軍無法探頭射擊，為攻城先登死士爭取登梯奪垛的關鍵時間窗口。

## 2. 狀態機架構與轉換生命週期

投石散彈壓制狀態機（代碼：`CATAPULT-GRAPESHOT-BATTLEMENT-SUPPRESSION01`）管理從彈藥配重至城頭壓制之完整週期：

```
[ GRAPESHOT_BUNDLE_LOAD ] (麻網包裹數十枚青石裝入皮兜)
          │
          ▼
[ LEVER_TRAJECTORY_RELEASE ] (梢桿回彈拋向城牆城垛上空)
          │
          ├── 空中提前散解 ──> [ PREMATURE_SCATTER_CALC ]
          ▼
[ MID_AIR_BURST_DISPERSAL ] (離心力拉斷束繩形成錐形彈幕)
          │
          ▼
[ BATTLEMENT_SURFACE_SWEEP ] (無數碎石猛烈撞擊女牆與射孔)
          │
          ├── 守軍弓弩手受創 ──> [ ARCHER_PINNED_DOWN ]
          ▼
[ SUPPRESSION_WINDOW_ACTIVE ] (城頭防禦火力歸零長達一分鐘)
          │
          ▼
[ LADDER_INFANTRY_ASSAULT ] (攻城先登部隊無阻礙快速登城)
```

### 狀態細部定義

1. **GRAPESHOT_BUNDLE_LOAD（裝填網包）**：
   - 拋石手將總重 80 斤的碎石網包置於皮兜內，檢查易斷草索結扣，確保在拋射至最高彈道頂點前保持整體。
2. **LEVER_TRAJECTORY_RELEASE（梢桿釋放）**：
   - 重錘配重箱下墜帶動梢桿瞬間發力，散彈網包以 50 度仰角高拋向敵城頭，初速約 26 m/s。
3. **MID_AIR_BURST_DISPERSAL（空中散網）**：
   - 飛抵城垛前方 15 步之空中軌跡頂點時，草索在氣動應力下崩斷，數十枚石塊如雨散開，覆蓋寬達 12 步之城垛表面。
4. **BATTLEMENT_SURFACE_SWEEP（彈幕覆蓋）**：
   - 碎石高速砸擊女牆外緣與雉堞，跳彈在城牆走道上二次彈射，城垛守軍無處遁形。
5. **ARCHER_PINNED_DOWN（射手壓制）**：
   - 敵軍遠程部隊防禦姿態強制轉入抱頭隱蔽（Pinned Down），攻擊中斷且無法進行任何遠程還擊。
6. **SUPPRESSION_WINDOW_ACTIVE（壓制窗口）**：
   - 壓制狀態持續 45 秒，期間我方推動雲梯與衝車之攻城部隊遠程傷害免除率提升 85%。

## 3. 關鍵數值與計算判定公式

### 3.1 散彈錐形散佈面半徑公式

碎石落地散佈半徑 $R_{spread}$（步）計算公式：
$$R_{spread} = R_{burst\_offset} \times \tan(\theta_{cone}) \times (1.0 + \text{ScatterAngle} \times 0.25)$$
- $R_{burst\_offset}$：空中解體點距城垛之距離（標準為 15 步）。
- $\theta_{cone}$：散彈錐角（約 $22^\circ$）。
- 計算得散佈半徑約為 6.0 步（直徑 12 步），剛好覆蓋一座城防望樓與相鄰兩座箭垛。

### 3.2 守軍壓制恐慌檢定

城垛守軍進入抱頭壓制狀態之成功率 $P_{suppress}$：
$$P_{suppress} = \text{clamp01}\left(0.50 + \frac{N_{stones} \times 0.015}{\text{ShieldCoverage}} - \frac{\text{Morale}_{def}}{200}\right)$$
- $N_{stones}$：有效覆蓋石塊數量（標準 50 枚）。
- $\text{ShieldCoverage}$：城垛女牆護盾掩護率（通常為 0.70）。
- 計算得常規守軍受壓制率高達 82%，唯有滿士氣精銳守軍可勉強維持探頭。

## 4. 戰術連鎖與攻防克制

1. **掩護先登突破防線**：將攻城戰中死亡率最高的「搭梯登牆階段」傷亡率降低 70% 以上。
2. **天敵與反制手段**：
   - **重型生鐵木幔棚**：守軍若於城垛上方架設斜向木幔盾棚，碎石砸擊棚面滑落護城河，無法傷及棚內射手。
   - **投石機精度偏差**：若解體過早，石塊四散落入護城河中無法對城垛形成有效覆蓋。

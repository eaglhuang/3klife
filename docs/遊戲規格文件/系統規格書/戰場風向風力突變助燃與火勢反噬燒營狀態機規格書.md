# 3KLife 戰場風向風力突變助燃與火勢反噬燒營狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 戰場動態微氣象與火勢反噬物理系統（`WIND-ASSISTED-FIRE01`）。重現三國歷史中「借東風火燒赤壁」以及因風向驟變導致「玩火者自焚、烈焰倒灌回燒本陣」之動態戰場演化。規範沙盤上風向、風力之隨機波動或計謀干預、火舌擴散之扇形幾何扇面，以及陣地遭遇烈火反撲時之緊急割草斷火機制。

## 4. 風向扇面推演、蔓延速率與反噬判定公式

### 4.1 火勢沿風向擴散之幾何扇面
火舌向前蔓延之幾何擴散半角：
$$\theta_{\text{spread}} = \theta_{\text{base}} \times \left(1.0 + \frac{V_{\text{wind}}}{10}\right)$$
- 強風下（$V_{\text{wind}} \ge 12\text{ m/s}$），火勢呈 $60^\circ$ 扇形向前高速席捲，蔓延速度提升 3 倍；
- 沿風向下游 3 格內之枯草營盤，次級引燃判定率達 $90\%$。

### 4.2 風向突變反噬判定公式
自然環境中風向每回合轉向之機率：
$$P_{\text{shift}} = 0.15 \times \left(1.0 - \text{SeasonalStability}\right)$$
- 若主將不通天時天文（智力 $\le 60$）盲目放火，遭遇逆轉反噬機率翻倍；
- 風向突變逆吹本陣時：
$$\text{FriendlyBurnRate} = \text{CombustionIntensity} \times \left(1.0 - \frac{\text{FireTrenchDepthMeters}}{2.0}\right)$$
- 若未提前開挖深達 2 米之防火壕溝，本陣在 1 回合內被大火吞噬，士氣直接暴跌 50 點。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-WIND-01**：在江東「冬至」節氣發動赤壁火攻，若無祭風儀軌，大風預設為西北風，強行放火必定直接燒毀自身戰船。
2. **驗收 CASE-WIND-02**：泥濘沼澤或石質地格具備天然阻燃性，火勢蔓延至該地格時強制中斷停止。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

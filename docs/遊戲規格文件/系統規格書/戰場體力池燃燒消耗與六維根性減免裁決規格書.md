# 戰場體力池燃燒消耗與六維根性減免裁決規格書

> 本規格書依據 WBS `FORM-07`（體力池/燃燒率/根性減免）制定，為戰場體力消耗與殘血根性免死之單一真相來源（Single Source of Truth）。
> 核心約束：歷史 VIT/WILL 屬性正式裁決收斂至專案六維、無副作用純邏輯架構、統領武力映射體力池、魅力運氣映射根性減免、全繁體中文台灣慣用術語。

---

## 1. 歷史矛盾裁決定案（Single Source of Truth）

早期舊草案引進賽馬娘機制時殘留 `VIT`（體力）與 `WILL`（根性）未定義屬性，與專案核心六維（`LEA` 統領、`STR` 武力、`INT` 智力、`POL` 政治、`CHA` 魅力、`LUK` 運氣）衝突。

**正式裁決收斂結論**：
1. **體力池容量（Stamina Pool, $SP_{\max}$）**：由武力與統領共同提供，$\text{StaminaMax} = \text{LEA} \times 8 + \text{STR} \times 4$。
2. **體力燃燒消耗率（Burn Rate）**：部隊每回合行動與奔襲消耗體力，受統領 `LEA` 紀律治軍減免。
3. **根性防禦減免（Guts Defense）**：殘血狀態下受到的傷害減免，由魅力 `CHA`（主帥威望、軍心凝聚）與運氣 `LUK`（天命庇佑）加權決定。

## 2. 數值模型與精算公式

### 2.1 每回合體力燃燒率
部隊每回合基礎消耗 15 點體力，若執行強行軍衝刺或施展高階戰法額外增加消耗：

$$\text{Burn} = \max\left(5, (\text{BaseCost} + \text{SprintCost}) - \lfloor \text{LEA} \times 0.10 \rfloor\right)$$

> **體力耗盡懲罰（Exhaustion）**：當體力降為 0 時，部隊進入「疲乏力竭」狀態，移動力 $-1$，受到的物理傷害 $+20\%$。

### 2.2 殘血根性減免公式（Guts Damage Reduction）
當部隊當前生命值跌破 $30\%$ 時，立即啟動「背水根性」被動減傷：

$$\text{ResilienceScore} = \text{CHA} \times 0.60 + \text{LUK} \times 0.40$$
$$\text{ReductionRate} = \min\left(40\%, \max\left(10\%, \lfloor \text{ResilienceScore} \times 0.25\% \rfloor\right)\right)$$

### 2.3 致命傷鎖血免死（Once-per-battle Death Defiance）
當部隊受到足以致死（Damage $\ge$ CurrentHP）之重擊時：
- 若此時體力庫存 $\ge 30$ 點，且本場戰鬥尚未觸發免死：
- **生命值強制鎖定為 1 點存活**。
- 扣除 30 點體力，並生成持續 1 回合相當於最大生命值 15% 之「破釜沉舟護盾」。

## 3. 資料模型與純邏輯計算函式

```typescript
export interface IGeneralCombatAttributes {
    readonly lea: number; // 統領
    readonly str: number; // 武力
    readonly cha: number; // 魅力
    readonly luk: number; // 運氣
}

export interface IStaminaState {
    readonly currentStamina: number;
    readonly maxStamina: number;
    readonly hasDefiedDeath: boolean;
}

export function initStaminaPool(attr: IGeneralCombatAttributes): number {
    return attr.lea * 8 + attr.str * 4;
}

export function calculateTurnBurn(baseCost: number, isSprint: boolean, lea: number): number {
    const rawCost = baseCost + (isSprint ? 10 : 0);
    const leaReduction = Math.floor(lea * 0.10);
    return Math.max(5, rawCost - leaReduction);
}

export function calculateGutsReduction(currentHP: number, maxHP: number, attr: IGeneralCombatAttributes): number {
    if ((currentHP / maxHP) > 0.30) {
        return 0.00; // 未達 30% 不觸發根性
    }
    const score = attr.cha * 0.60 + attr.luk * 0.40;
    const rate = Math.floor(score * 0.0025);
    return Math.min(0.40, Math.max(0.10, rate));
}

export interface IIncomingDamageResult {
    readonly finalHP: number;
    readonly finalStamina: number;
    readonly deathDefied: boolean;
    readonly barrierGranted: number;
}

export function resolveIncomingDamageWithGuts(
    incomingDamage: number,
    currentHP: number,
    maxHP: number,
    staminaState: IStaminaState,
    attr: IGeneralCombatAttributes
): IIncomingDamageResult {
    const reduction = calculateGutsReduction(currentHP, maxHP, attr);
    const effectiveDamage = Math.floor(incomingDamage * (1 - reduction));

    if (effectiveDamage < currentHP) {
        return {
            finalHP: currentHP - effectiveDamage,
            finalStamina: staminaState.currentStamina,
            deathDefied: false,
            barrierGranted: 0,
        };
    }

    // 致命傷害判定
    if (staminaState.currentStamina >= 30 && !staminaState.hasDefiedDeath) {
        return {
            finalHP: 1,
            finalStamina: staminaState.currentStamina - 30,
            deathDefied: true,
            barrierGranted: Math.floor(maxHP * 0.15),
        };
    }

    return {
        finalHP: 0,
        finalStamina: staminaState.currentStamina,
        deathDefied: false,
        barrierGranted: 0,
    };
}
```

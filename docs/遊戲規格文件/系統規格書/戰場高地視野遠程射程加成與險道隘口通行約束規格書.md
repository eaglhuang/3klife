## 1. 系統架構定位與戰術價值

三國戰史上，街亭之失、劍閣之險皆印證了高地與隘口對戰局之決定性影響。《三國人生》（3KLife）戰場採用 2.5D 高度場（Heightfield）與拓撲格網（Topological Grid）模型。

本規格書確證高地與險道之核心物理與空間運算規則：
1. **立體高度優勢（Elevation Advantage）**：處於高地之部隊獲得視野穿透與重力動能加成。
2. **險道瓶頸約束（Chokepoint Constraint）**：隘口僅允許單一部隊駐留，禁止重疊或穿透行軍，形成「一夫當關，萬夫莫開」之防禦結界。
3. **動態 A* 尋路權重修正**：尋路演算法自動識別坡度與阻塞隘口，動態計算避讓或突破成本。

## 2. 高地高度等級與空間戰術矩陣

戰場地格依據海拔高度劃分為三級立體圖層：

```typescript
export enum TileElevation {
  LOWLAND = 0,    // 低窪水系 / 谷底 (海拔 0m)
  PLAIN = 1,      // 標準平原地帶 (海拔 10m)
  HIGHLAND = 2,   // 丘陵高地 (海拔 25m)
  CLIFF = 3       // 峻嶺懸崖 (海拔 50m，不可通行，僅供視野偵察)
}

export interface IElevationCombatModifier {
  readonly rangeBonus: number;           // 遠程部隊射程加成 (格數)
  readonly sightBonus: number;           // 戰場迷霧視野偵測半徑加成 (格數)
  readonly downwardDamageBonus: number;  // 俯攻向下衝擊傷害乘數
  readonly upwardDamagePenalty: number;  // 仰攻向上受挫傷害折減
}
```

高度差計算公式與戰術反饋：
$$\Delta H = H_{\text{attacker}} - H_{\text{defender}}$$

1. **俯衝居高臨下（$\Delta H \ge 1$）**：
   - 弓兵部隊射程強制 $+1$ 格；視野半徑 $+2$ 格（無視障礙物遮擋）。
   - 騎兵與步兵衝擊傷害提升 $+30\%$；受到下方反擊傷害折減 $25\%$。
2. **仰攻艱難跋涉（$\Delta H \le -1$）**：
   - 仰攻部隊無法發動衝鋒戰法；近戰物理命中率折減 $20\%$。
   - 遠程向上射擊射程強制 $-1$ 格（最低保底 1 格）。

## 3. 險道隘口通行約束與「一夫當關」機制

險道地格（如劍閣棧道、葫蘆口、赤壁林道）寬度定義為 **1 格**：

```
 [山壁 CLIFF] ───────────────不可通行───────────────
 [隘口 PASS ] ===> [ 守將: 魏延 (一夫當關) ] <=== 敵軍行軍受阻
 [山壁 CLIFF] ───────────────不可通行───────────────
```

1. **單一容納限制**：同一時刻隘口地格僅能容納 1 支作戰部隊，任何友軍或敵軍禁止重疊駐留。
2. **防禦加固「一夫當關」**：部隊駐留於隘口地格時，自動獲得防禦結界狀態：
   - 物理免傷率提升 $+40\%$，且完全免疫側面與背刺夾擊判定。
   - 敵軍無法穿透隘口地格執行繞後突襲，必須將隘口守將完全擊潰或逼退。
3. **撤退踩踏懲罰**：處於隘口內的部隊若遭受火攻或潰敗撤退，由於退路狹窄，士氣額外扣除 $15$ 點，並引發後續緊隨部隊混亂（Confusion）1 回合。

## 4. 迷霧視野（Fog of War）穿透與演算法實裝

1. **高地視線投影（Raycasting）**：處於 `HIGHLAND` 節點之部隊，以射線檢驗（Raycast）偵測周圍地格，可直接穿透隔壁 `PLAIN` 森林之樹冠隱蔽，使埋伏部隊強制現形。
2. **邊界防呆**：當兩高地之間夾有 `CLIFF` 峻嶺時，視線射線受阻，兩端部隊互不可見，維持局部戰術迷霧。

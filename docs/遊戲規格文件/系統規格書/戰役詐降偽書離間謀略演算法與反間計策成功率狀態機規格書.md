## 1. 系統架構定位與攻心為上兵學

上兵伐謀，其次伐交，其次伐兵，其下攻城。《三國人生》（3KLife）戰役沙盤具備深度**諜戰反間與詐降心戰系統（Espionage & Subversion System）**。真正的謀者，在兩軍尚未交鋒之前，便已在敵陣埋下傾覆之種。

本系統核心價值：
1. **將帥猜忌指數（Suspicion Index）**：量化君臣信任裂痕，偽造密信挑動內訌。
2. **苦肉計詐降三步曲（Feigned Defection Lifecycle）**：承擔自殘代價，換取直插敵陣心臟之特權。
3. **戰場瞬時倒戈與軍陣癱瘓**：在戰局最高潮處引爆內應，造成敵軍指揮鏈雪崩。

## 2. 偽書離間演算法與猜忌指數

在戰前或戰役相持階段，軍師可消耗 SP 與黃金發動「偽造降書/離間計」：

```typescript
export interface IAlienationTarget {
  readonly generalId: string;       // 目標敵將 (如: 馬超、韓遂、周瑜)
  readonly monarchId: string;       // 其所屬君主
  loyalty: number;                  // 當前忠誠度 (0 ~ 100)
  suspicionIndex: number;           // 君臣猜忌指數 (0 ~ 100)
  isAlienated: boolean;             // 是否成功中計產生嫌隙
}
```

離間成功率判定公式：
$$P_{\text{alienate}} = \frac{\text{INT}_{\text{caster}} - \text{INT}_{\text{target}}}{2} + \left(100 - \text{Loyalty}\right) \times 0.4\% + \text{Bonus}_{\text{forged\_letter}}$$

1. **輕度中計（猜忌值 $+30$）**：敵將在戰場上陷入「消極觀望」狀態，拒絕主動支援友軍，且每回合移動力上限強制降為 1 格。
2. **重度中計（猜忌值 $\ge 80$）**：君臣決裂，戰鬥進行至第 3 回合時，該將有 **$65\%$ 機率直接陣前倒戈投降**，轉為友方控制！

## 3. 苦肉詐降生命週期狀態機

為複製「周瑜打黃蓋、一願打一願挨」之絕世神謀，詐降計謀嚴格遵循三階段狀態機流轉：

```
       [PHASE 1: 苦肉代價] ───── 發動自殘受刑，部隊當前兵力強制扣除 35%
                │
                │ 獲得敵方信任 (信賴度達 90%)
                ▼
       [PHASE 2: 順利滲透] ───── 部隊作為「降兵」合法駛入敵方陣地核心
                │
                │ 抵達約定回合或引爆信號
                ▼
       [PHASE 3: 裡應外合] ───── 全軍破隱發動火攻，敵軍防禦力歸零並陷入大混亂！
```

```typescript
export enum DefectionPhase {
  SELF_HARM = 'SELF_HARM',   // 苦肉自損：主將體力與兵力驟降，製造假象
  INFILTRATED = 'INFILTRATED', // 成功潛入：不受敵方箭塔防衛攻擊
  DETONATION = 'DETONATION'    // 信號引爆：火燒連營，造成周遭 2 格敵軍陷入混亂
}
```

## 4. 識破反制（Counter-Espionage）機制

1. **神謀識破檢定**：若敵方陣營擁有智力 $\ge 95$ 之神級謀士（如司馬懿、賈詡），在詐降部隊抵達之際執行識破判定：
   $$P_{\text{detect}} = (\text{INT}_{\text{defender}} - \text{INT}_{\text{caster}}) \times 1.2\%$$
2. **將計就計（Counter-Plot）**：若判定識破成功，敵軍順勢設伏，詐降部隊進入「關門打狗」重圍，所受傷害提升 $+50\%$ 且無法撤退。

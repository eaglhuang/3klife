# 戰後俘虜處置四項延伸分支與高齡轉教官判定規格書

> **模組識別碼**：`POW-09`  
> **系統歸屬**：戰後俘虜處理（PrisonerOfWar）延伸分支  
> **單一真相來源**：本規格書確立戰後俘虜處置四選一之後續延伸分支：結義金蘭卡勸降加成、60 歲高齡入仕優先轉教官、無期徒刑季度傳家寶掉落、以及義釋傳道頓悟戰法傳承之唯一權威標準。

---

## 一、系統概述與架構原則

在完成戰後俘虜四選一（勸降、招募、關押、放走）核心判定後，系統根據武將生理年齡與處置決策，觸發相應之延伸策略分支。所有數值採「資料驅動（Data-Driven）」架構，依注入之調優參數 `PowBranchTuning` 計算，保持純邏輯解耦。

### Unity / 架構對照
- **處置管線外掛**：類似 Unity 中的 `PostBattlePrisonerExtension`，結算主流程結束後觸發後續回饋事件。
- **純狀態函式**：所有擲骰與機率皆由依賴注入 `random: () => number` 決定，保證測試完全可重現。

## 二、分支參數調優模型與門檻定義

```typescript
export const POW_INSTRUCTOR_AGE_DEFAULT = 60; // 預設優先轉教官年齡門檻（花甲之年）

export interface PowBranchTuning {
    bondingCardBonus: number;     // 結義金蘭卡提高勸降率之百分點（如 20 代表 +20%）
    heirloomDropChance: number;   // 無期徒刑關押每季掉落傳家寶機率（0.0 ~ 1.0）
    enlightenmentChance: number;  // 義釋放走時觸發傳道/頓悟之機率（0.0 ~ 1.0）
    instructorAge?: number;       // 轉教官年齡門檻（缺省使用 60 歲）
}
```

## 三、四大延伸分支演算法

### 1. 結義金蘭卡勸降加成
```typescript
export function persuadeRateWithBondingCard(
    baseRate: number,
    useCard: boolean,
    tuning: Readonly<PowBranchTuning>
): number {
    const base = Number.isFinite(baseRate) ? baseRate : 0;
    const bonus = useCard && Number.isFinite(tuning.bondingCardBonus) 
        ? Math.max(0, tuning.bondingCardBonus) : 0;
    return Math.min(100, Math.max(0, base + bonus)); // 0~100 區間夾取
}
```

### 2. 60 歲高齡勸降/招募優先轉教官
年滿 60 歲之名將若獲取成功，考量其即將屆臨天年，優先轉化為學府先祖/名師教官卡，培育下代子嗣：

```typescript
export function shouldBecomeInstructor(
    decision: 'persuade' | 'recruit' | 'imprison' | 'release',
    success: boolean,
    age: number,
    tuning: Readonly<PowBranchTuning>
): boolean {
    if (!success || (decision !== 'persuade' && decision !== 'recruit')) {
        return false;
    }
    const threshold = Number.isFinite(tuning.instructorAge) 
        ? (tuning.instructorAge as number) : POW_INSTRUCTOR_AGE_DEFAULT;
    return Number.isFinite(age) && age >= threshold;
}
```

### 3. 無期徒刑季度傳家寶掉落
```typescript
export function rollHeirloomDrop(random: () => number, tuning: Readonly<PowBranchTuning>): boolean {
    const chance = Math.min(1, Math.max(0, tuning.heirloomDropChance));
    return random() < chance;
}
```

### 4. 義釋名將之傳道與頓悟
放走名將時，感佩主公仁德，對方可能傳授生平絕學，由我方在役武將隨機 1 人習得其代表戰法：

```typescript
export interface EnlightenmentResult {
    learnerId: string;    // 我方頓悟武將 ID
    techniqueId: string;  // 習得之代表戰法 ID
}

export function rollReleaseEnlightenment(
    allyIds: readonly string[],
    techniqueId: string | null,
    random: () => number,
    tuning: Readonly<PowBranchTuning>
): EnlightenmentResult | null {
    if (!techniqueId || allyIds.length === 0) return null;
    const chance = Math.min(1, Math.max(0, tuning.enlightenmentChance));
    if (random() >= chance) return null;
    
    const pickedIndex = Math.floor(random() * allyIds.length) % allyIds.length;
    return {
        learnerId: allyIds[pickedIndex],
        techniqueId,
    };
}
```

## 四、驗收條件與測試案例 (Test Cases)

- **TC-POW-25（金蘭卡增幅覆蓋）**：
  - 基礎勸降率 40%，使用金蘭卡（+20%），最終成功率為 60%；若基礎 90%，加成後夾取為 100%。
- **TC-POW-26（高齡轉教官判定）**：
  - 勸降 62 歲武將成功，`shouldBecomeInstructor` 回傳 `true`；若招募 45 歲武將成功，回傳 `false`。
- **TC-POW-27（傳家寶隨機掉落）**：
  - 設定掉落率 0.3，隨機值 0.25 觸發掉落；隨機值 0.35 不觸發。
- **TC-POW-28（義釋頓悟我方隨機獲技）**：
  - 放走攜帶戰法之名將且機率檢定通過，隨機挑選我方 1 名在役武將習得該戰法。

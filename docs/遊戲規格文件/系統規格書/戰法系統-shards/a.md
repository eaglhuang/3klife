> **2026-04-26 覆寫裁定：覺醒與戰法解鎖**
>
> 1. `覺醒` 是因子、戰法提示、培育事件與戰場觸發的解鎖語意，不是武將突破，也不是武將 Level。
> 2. 戰法慢慢解鎖應回到 `培育事件 / TP / 因子覺醒 / 支援卡連續事件 / 血統條件`，不得用武將突破階段硬開槽。
> 3. 若 UI 需要呈現進度，使用 `覺醒進度`、`提示段數`、`戰法槽可用狀態`，不使用 `突破一階 / 二階`。

## A. 系統描述

戰法系統管理所有部隊級的可施放技能。**戰法 (Tactic)** 指部隊級的變動技能，消耗 **TP**，會改變地圖格狀態或造成傷害。這與消耗精力且由模板固定的 **個人奧義 (General Ultimate)** 不同。

# 戰績統計模型勝率守護力精算與退役戰績評分規格書

## 1. 模組職責與架構定位
本規格書規範武將全生涯軍事戰功的「戰績資料結構（`BattleRecordStats`）」、「勝率與守護力精算演算法」，以及年滿 65 歲卸甲時的「退役戰績評分分級模型（`RetireScore`）」。模組負責精確記錄武將在戰場上的每一次勝敗、擊殺與奉獻，並將生涯戰功映射為退役兵種虎符之初始品質。

## 2. 戰績資料模型與實時統計演算法

```typescript
export interface BattleRecordData {
  wins: number;
  losses: number;
  draws: number;
  kills: number;
  damageDealt: number;
  damageTaken: number;
  healingDone: number;
}
```

### 2.1 勝率精算公式（WinRate）
為避免武將未出戰時發生除以零異常，分母施加保底保護：
$$\text{TotalBattles} = \text{wins} + \text{losses}$$
$$\text{WinRate} = \frac{\text{wins}}{\max(1, \text{TotalBattles})}$$
輸出為 $0.0 \sim 1.0$ 之浮點數，無出戰記錄者勝率回傳 0.0。

### 2.2 守護力精算公式（GuardianPower）
守護力表徵肉盾先鋒與輔助醫者為軍團承受傷害與拯救同袍的貢獻：
$$\text{GuardianPower} = \left\lfloor \frac{\text{damageTaken} + \text{healingDone}}{100} \right\rfloor$$

```typescript
export function computeBattleMetrics(record: BattleRecordData): {
  winRate: number;
  guardianPower: number;
  totalBattles: number;
} {
  const total = record.wins + record.losses;
  const winRate = total === 0 ? 0 : Number((record.wins / total).toFixed(4));
  const guardianPower = Math.floor((record.damageTaken + record.healingDone) / 100);

  return { winRate, guardianPower, totalBattles: total };
}
```

## 3. 退役戰績評分與虎符品質分級

武將退役榮休時，系統綜合其一生勝場、擊殺數與守護力，計算終生「退役戰績評分（`RetireScore`）」：
$$\text{RetireScore} = \text{wins} \times 10 + \text{kills} \times 2 + \text{GuardianPower} \times 1$$

依據評分區間決定生成的兵種虎符（`LIFE-06`）初始階級：
- **SSR 極限神將**：$\text{RetireScore} \ge 800$。
- **SR 名震天下**：$500 \le \text{RetireScore} < 800$。
- **R 歷經百戰**：$200 \le \text{RetireScore} < 500$。
- **N 歸隱田園**：$\text{RetireScore} < 200$。

```typescript
export type TallyQualityTier = 'SSR' | 'SR' | 'R' | 'N';

export function evaluateRetireScore(record: BattleRecordData): {
  score: number;
  tallyTier: TallyQualityTier;
} {
  const { guardianPower } = computeBattleMetrics(record);
  const score = record.wins * 10 + record.kills * 2 + guardianPower;

  let tallyTier: TallyQualityTier = 'N';
  if (score >= 800) tallyTier = 'SSR';
  else if (score >= 500) tallyTier = 'SR';
  else if (score >= 200) tallyTier = 'R';

  return { score, tallyTier };
}
```

## 4. 單元測試驗證規範
1. **TC-REC-WINRATE-ZERO（零場次除零防護）**：勝 0 負 0，`totalBattles = 0`，`winRate = 0.0`，不拋出 NaN。
2. **TC-REC-GUARDIAN（承傷與治療精算）**：承傷 45,000，治療 15,500，守護力精確回傳 $\lfloor 60500 / 100 \rfloor = 605$。
3. **TC-RETIRE-TIER-SSR（SSR 虎符門檻檢驗）**：勝 60 場（600分）、擊殺 80 人（160分）、守護力 50（50分），總分 810，回傳 `tallyTier = 'SSR'`。

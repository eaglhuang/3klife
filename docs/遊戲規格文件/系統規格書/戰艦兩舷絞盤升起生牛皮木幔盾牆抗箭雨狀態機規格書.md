# 3KLife 戰艦兩舷絞盤升起生牛皮木幔盾牆抗箭雨狀態機規格書

## 1. 系統概述與設計哲學
在長江水戰中，戰艦交戰接舷前必經漫長之箭雨火矢對射階段。若兩舷划槳手與底艙甲士暴露於敵方連弩與火箭下，極易在接舷前傷亡殆盡導致戰艦失控。三國艨艟鬥艦必備舷側防禦工程「兩舷絞盤生牛皮木幔盾牆」（NAVAL-BULWARK-SHIELD-WALL01）。
戰艦兩舷女牆上方安裝活動式雙層硬木防護板，外層釘覆厚重浸水生牛皮，以青銅鉸鏈與手搖絞盤拉索連動。敵艦放箭時，水手轉動絞盤將盾牆升起並閉鎖，兩舷形成無縫硬質防矢木幔，能吸收並彈開九成以上流矢與火箭，內部水手透過木幔射孔持續操槳與射殺，保障戰艦以滿額速度衝破敵軍箭幕。

## 4. 複合防護與抗剪力物理模型

### 4.1 雙層牛皮複合減傷公式
浸水生牛皮具備優異之黏彈性，能吸收箭矢衝量並擴散應力：
$$F_{\text{transmitted}} = F_{\text{incoming}} \times (1.0 - \text{Reduction}_{\text{leather}}) \times \cos(\phi_{\text{impact}})$$
- 敵軍火矢命中外層時，水汽蒸發吸收熱能，無法引燃內層厚木板，保護艙內槳手安全率達 $95\%$。

### 4.2 活動式升降結構穩定度
1. **防傾覆設計**：木幔自重合理配置於重心下部，升起時不破壞戰艦橫向穩心高，抗風浪等級不變。
2. **快速收放效率**：拔出插銷後木幔在配重重錘牽引下 3 秒內自動順暢降落，不阻礙先登甲士跳幫速度。

## 5. 單元驗收測試標準
1. **TC-BULWARK-01 (絞盤升起與遠程火矢防護全流程)**：
   - 模擬進入火箭密集射界，6 秒內完成木幔升起鎖定。
   - 驗證承受 200 支火箭攻擊，傷害減免 88%，無任何內部划槳手減員。
2. **TC-BULWARK-02 (射孔反擊穩定度加成)**：
   - 轉入 `ARROW_SLITS_COUNTER`，驗證內艙射手反擊命中率提升 15%。
3. **TC-BULWARK-03 (重擊折斷與跳幫轉換)**：
   - 模擬遭樓船拍竿直接命中，驗證耐久歸零後正確轉入 `BULWARK_SHATTER_BREACH`，觸發白刃肉搏。

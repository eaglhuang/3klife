# 3KLife 戰艦水上拋射生鐵猛火油火球碰撞碎裂附著燃燒狀態機規格書

## 1. 系統定位與設計意圖

在三國長江大型水戰中，常規火箭射程有限且易被敵艦生牛皮盾幔阻擋，難以引發大面積艙面烈火。本系統規範水戰特種艦載燃燒武器「生鐵猛火油破甲燃燒火球（Naval Incendiary Bombard Fireball）」之配重拋射、碰撞碎裂、黏稠附著與拒水燃燒狀態機：
- **薄生鐵脆殼火球**：以生鐵薄壁鑄造直徑一尺之空心球體，球內注入稠化猛火油、硫磺粉與松香生漆，外接延期緩燃引信。
- **撞擊碎裂與油液飛濺**：火球由中型艦載梢砲拋出，撞擊敵艦甲板、女牆或桅杆時生鐵薄殼瞬間炸裂，高溫黏稠火油四濺附著。
- **水澆不滅之特種燃燒**：因含有生漆與石脂成分，比重小於水且黏度極高，守軍汲長江水澆淋反而導致燃油浮於水面順甲板擴散，加劇火勢。

## 2. 狀態機架構與轉換生命週期

水上火球狀態機（代碼：`NAVAL-INCENDIARY-BOMBARD-FIREBALL01`）管理自填裝拋射至全艦引燃之完整週期：

```
[ BALL_CHAMBER_LOAD ] (填裝生鐵火球與引信長度校準)
          │
          ▼
[ WHIP_LAUNCH_TRAJECTORY ] (梢砲釋放高仰角弧線拋射)
          │
          ├── 空中引信早爆 ──> [ AIR_BURST_SCATTER ]
          ▼
[ HIGH_VELOCITY_IMPACT ] (高速砸中敵艦女牆或甲板)
          │
          ├── 穿透牛皮木幔 ──> [ CRUSH_PENETRATION ]
          ▼
[ FRAGMENT_OIL_SPLASH ] (生鐵殼碎裂高黏度火油黏附船體)
          │
          ├── 敵軍打水撲救 ──> [ WATER_SPREAD_ACCELERATION ]
          ▼
[ BLAZING_STICKY_FIRE ] (高溫猛火向底艙與船帆蔓延)
          │
          ▼
[ VESSEL_ABANDON_CRITICAL ] (戰艦全面失控被迫跳江棄船)
```

### 狀態細部定義

1. **BALL_CHAMBER_LOAD（裝填校準）**：
   - 砲手將 30 斤生鐵火球置入拋網皮兜，依目標距離（60 至 120 步）剪定麻線引信長度，點火引燃。
2. **WHIP_LAUNCH_TRAJECTORY（甩彈拋射）**：
   - 梢桿受配重箱下墜驅動瞬時彈起，火球以 45 度仰角劃破長空，初速度達 28 m/s。
3. **HIGH_VELOCITY_IMPACT（撞擊破裂）**：
   - 火球命中敵艦女牆或硬木甲板，生鐵薄殼因脆性承受劇烈剪應力粉碎成數十枚生鐵破片，對甲板守卒造成穿刺殺傷。
4. **FRAGMENT_OIL_SPLASH（黏稠飛濺）**：
   - 內部猛火油在爆炸壓力下向四周飛濺覆蓋方圓丈餘，高黏度使燃油牢牢黏附於垂直木板與船帆纜繩之上。
5. **WATER_SPREAD_ACCELERATION（拒水蔓延）**：
   - 敵軍汲江水澆灌時，油水不互溶且水沉油浮，燃燒油層順著水流流向兩舷下層艙室，燃燒面積瞬間暴增 80%。
6. **VESSEL_ABANDON_CRITICAL（焚毀棄船）**：
   - 舵樓與主帆燒毀，全艦陷入不可控大火，艦載部隊士氣清零，紛紛跳江逃生。

## 3. 關鍵數值與計算判定公式

### 3.1 黏著火焰擴散與水撲反作用模型

撲救失誤後火勢蔓延速率 $R_{spread}$（$\text{m}^2/\text{s}$）：
$$R_{spread} = R_{base\_oil} \times \left(1.0 + \frac{W_{water\_poured}}{100} \times 1.8\right) \times (1.0 + V_{wind} \times 0.22)$$
- $W_{water\_poured}$：守軍盲目傾倒之江水量（桶數）。
- 每傾倒一桶生水，非但無法滅火，反而使燃燒面積擴散半徑增加 0.3 公尺。
- 正確滅火方式必須使用生沙、濕毛氈覆蓋窒息，或以長鉤將著火構件直接推入江中。

### 3.2 生鐵破片飛濺殺傷半徑

火球碎裂時生鐵破片殺傷動能 $E_{frag}$（焦耳）：
$$E_{frag} = \frac{1}{2} M_{frag} \times V_{burst}^2 \approx \frac{1}{2} (0.15\,\text{kg}) \times (42\,\text{m/s})^2 \approx 132.3\,\text{J}$$
- 足以直接擊穿輕裝水兵皮甲，造成周圍 3 步內 3~5 名水兵重度外傷失能。

## 4. 戰術連鎖與攻防克制

1. **破除敵艦盾幔掩護**：徹底解決弓箭射不穿牛皮木幔的僵局，以面狀烈火燒毀防禦結構。
2. **天敵與戰術反制**：
   - **濕泥沙桶應急**：精銳水軍在甲板預備十石濕泥細沙，火球命中後迅速覆蓋壓滅，抑制蔓延。
   - **迎風逆射自焚**：若在順風處遭敵反制或側風過猛，火球煙霧倒灌，發射艦自身有 8% 機率被火花引燃。

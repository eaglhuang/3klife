# 3KLife 戰艦水上雙管猛火油噴筒噴吐火舌火浪狀態機規格書

## 1. 系統概述與設計哲學
在《三國生生不息》江面水戰體系中，火攻為水軍決勝核心。除走舸衝撞與火矢遠射外，大型主力艨艟與樓船常前置安裝「雙管猛火油噴筒」（FIRE-SIPHON-WATER01）。
該機關由純銅油壓活塞筒、水火密封墊、雙聯旋轉噴嘴與火信預燃裝置組成。藉由水手協力踩踏槓桿或手搖絞盤，將調配有桐油、石脂水與硫磺的黏稠猛火油以高壓噴射而出，在江面上形成長達十丈的噴薄火舌與浮江火浪，為水戰破陣、封鎖敵艦航道及引燃敵軍風帆之近程毀滅重器。

## 3. 狀態機生命週期轉換

```
[ IDLE_CHARGING ] (加壓儲液)
       │
       ▼ (壓力達標且火信引燃)
[ SIPHON_IGNITING ] (預燃蓄勢)
       │
       ▼ (閥門驟開高壓噴射)
[ STREAM_EJECTING ] (火舌噴吐與水浪覆蓋)
       │
       ▼ (油液排空/達到噴吐週期)
[ NOZZLE_COOLING ] (江水注入降溫清膛)
       │
       ▼ (溫度降至安全線以下)
[ RELOAD_DRAINING ] (殘液排除與重新灌油)
       │
       └─────► 回到 [ IDLE_CHARGING ]
```

### 3.1 狀態轉移詳細規則表
| 起始狀態 | 觸發事件 | 終止狀態 | 轉移條件與防禦邏輯 |
| :--- | :--- | :--- | :--- |
| **IDLE_CHARGING** | `PUMP_PRESSURE` | **SIPHON_IGNITING** | 蓄壓 $\ge 8.0$ bar，猛火油 $\ge 20$ 升，且開啟引燃暗火夾。 |
| **SIPHON_IGNITING**| `RELEASE_VALVE` | **STREAM_EJECTING** | 噴嘴引信確定點著，發射閥破銷開啟，全推力噴注。 |
| **STREAM_EJECTING**| `PRESSURE_EXHAUST` | **NOZZLE_COOLING** | 儲壓歸零或連續噴射達 3 ticks，立刻閉鎖隔板阻斷回火。 |
| **STREAM_EJECTING**| `BACKFIRE_TRIGGER` | **SYSTEM_DAMAGED** | 噴嘴溫度 $> 220℃$ 且密封破損，誘發回火自爆，重創艦首。 |
| **NOZZLE_COOLING** | `FLUSH_COMPLETED` | **RELOAD_DRAINING**| 灌入清涼江水洗膛，使金屬溫度下降至 $75℃$ 以下。 |
| **RELOAD_DRAINING**| `REFILL_READY` | **IDLE_CHARGING** | 廢水排盡，注入新一批調和猛火油，進入待命加壓循環。 |

## 4. 戰術交互與水面燃燒物理

### 4.1 江面水油漂浮擴散公式
猛火油密度小於水，噴灑於江面後將隨水流方向延伸：
$$L_{slick} = L_{base} \times (1.0 + 0.3 \times V_{river\_current})$$
- 敵艦若強行穿越水面燃燒區，每秒扣除 $150$ 點耐久，船底焦黑，水手划槳效率減退 $60\%$。

### 4.2 遇雨與風向抑制機制
1. **大雨/暴雨天氣**：火焰直接傷害降低 $40\%$，水面燃燒時間縮減為 $6$ 秒，但產生濃重白霧，遮蔽雙方視野。
2. **逆風噴射限制**：當船隻向風角 $< 30^\circ$ 時，禁止進行全功率噴射，避免火舌遭強風倒吹引燃自艦帆檣。

## 5. 單元驗收測試標準
1. **TC-SIPHON-01 (加壓噴射閉環驗證)**：
   - 注入 40 升猛火油，加壓至 10.0 bar 觸發噴射。
   - 驗證直線 4 格與 45 度角內敵船受到 300 點直接火傷，江面地格留下 18 秒持續火浪。
2. **TC-SIPHON-02 (高溫回火防禦保護)**：
   - 連續強制噴射導致噴嘴溫度升至 230℃。
   - 驗證系統正確判定自爆損害或安全閥斷保機制。
3. **TC-SIPHON-03 (冷卻清膛週期)**：
   - 噴吐完畢後進入冷卻，確認冷卻江水耗盡前無法重新加壓。

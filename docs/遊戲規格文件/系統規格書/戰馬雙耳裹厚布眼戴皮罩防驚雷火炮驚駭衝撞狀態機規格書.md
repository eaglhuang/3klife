# 3KLife 戰馬雙耳裹厚布眼戴皮罩防驚雷火炮驚駭衝撞狀態機規格書

## 1. 系統定位與設計意圖

在三國混戰（如西涼鐵騎衝擊中原大軍、諸葛亮火器與床弩破騎兵）中，未經特殊受訓與防護的戰馬對火光、爆炸震響與白刃閃光有強烈的本能恐慌，一旦受驚暴走將踩踏自家中軍。本系統規範重裝騎兵特種裝備「戰馬防驚皮罩與裹耳消音護具（Warhorse Blind & Muffled Panic-Proof Gear）」之視覺遮蔽、聽覺降噪、驚駭抑制與受控衝鋒狀態機：
- **生牛皮窄角眼罩（盲眼皮罩）**：安裝於馬頭籠頭兩側，完全遮蔽左右側向與後方視線，僅保留前方約 35 度直視視野，避免戰馬看見兩側血腥混亂與火球飛竄。
- **棉絮麻布雙層裹耳（降噪裹耳）**：以浸透黃蠟的厚密棉布層層包裹馬耳，並塞入柔軟羊毛團，將外界爆炸與擂鼓聲壓衰減 70% 以上。
- **絕對冷靜穿透力**：即便戰場火光沖天、霹靂巨響，戰馬仍能無視周邊干擾，忠實依照騎兵韁繩引導直線破陣。

## 2. 狀態機架構與轉換生命週期

戰馬防驚護具狀態機（代碼：`WARHORSE-BLIND-MUFFLED-PANIC-PROOF01`）管理從裝具著裝至穿透火線之完整週期：

```
[ GEAR_HARNESSING ] (戰馬佩戴眼罩與棉絮裹耳校準)
          │
          ▼
[ RESTRICTED_VISION_MARCH ] (限制側向視野專注前方正向隊列)
          │
          ├── 遭遇床弩雷石轟鳴 ──> [ ACOUSTIC_DAMPING_RESIST ]
          ├── 遭遇火球流矢側掠 ──> [ PERIPHERAL_BLIND_IGNORE ]
          ▼
[ CHARGE_INTO_CHAOS ] (穿透火光硝煙無畏直線衝鋒)
          │
          ├── 護具鬆脫或被利刃割破 ──> [ GEAR_COMPROMISED_PANIC ]
          ▼
[ SHOCK_PENETRATION_HIT ] (高速正面破陣撞翻敵步兵陣列)
          │
          ▼
[ CONTROLLED_DISENGAGE ] (遵循繮繩輕巧勒馬掉頭回撤)
```

### 狀態細部定義

1. **GEAR_HARNESSING（穿戴防護）**：
   - 騎兵在出擊前為戰馬繫緊熟牛皮眼罩，調整前方狹縫開度，並以軟蠟棉布緊裹雙耳，歷時 3 分鐘完成整備。
2. **RESTRICTED_VISION_MARCH（限制行進）**：
   - 戰馬視野盲區擴大至 325 度，僅能凝視正前方目標，無法察覺側方受創戰友倒地，杜絕同伴潰敗引發的群體恐慌傳染。
3. **ACOUSTIC_DAMPING_RESIST（聽覺抗震）**：
   - 面對霹靂車砲石砸地（110 分貝）或雷鼓齊鳴，進入馬耳之聲壓被壓制在 60 分貝以下，戰馬心率平穩不跳蹄。
4. **PERIPHERAL_BLIND_IGNORE（無視火光）**：
   - 兩側漫天火箭與地面燃燒火盆因在眼罩盲區內，戰馬無視烈焰幻影，無畏向前狂奔。
5. **SHOCK_PENETRATION_HIT（破陣衝撞）**：
   - 騎兵隊以完整密集的楔形衝擊敵步兵方陣，造成敵步卒大面積擊飛與潰散。
6. **GEAR_COMPROMISED_PANIC（護具破損異常）**：
   - 若遭遇敵軍長戟勾破眼罩，戰馬視野突開看見火海，有 65% 機率轉入立足狂嘶、不受控制打轉狀態。

## 3. 關鍵數值與計算判定公式

### 3.1 驚駭指數判定公式

戰馬在極端火器與震響環境下之受驚概率 $P_{panic}$：
$$P_{panic} = \max\left(0.01, \frac{\text{FearStress}_{raw} \times (1.0 - \eta_{muffle}) \times (1.0 - \eta_{blind})}{\text{HorseMorale} \times 1.2}\right)$$
- $\text{FearStress}_{raw}$：戰場刺激原始恐懼值（霹靂雷石落地為 85，火海為 70）。
- $\eta_{muffle}$：棉絮裹耳聽覺衰減率（達 0.72）。
- $\eta_{blind}$：生牛皮眼罩視覺屏蔽率（達 0.88）。
- 計算得配戴護具之戰馬受驚機率自原本的 78% 銳降至 2.4%，達到「泰山崩於前而馳騁自若」。

### 3.2 側向感知犧牲代價

防驚護具帶來的代價為側向閃避率 $\Delta Evade$ 下降：
$$\text{Evade}_{flank} = \text{Evade}_{base} \times (1.0 - 0.55)$$
- 戰馬無法主動躲避側翼刺來的短矛與飛斧，需由相鄰騎兵長槊形成掩護互保。

## 4. 戰術連鎖與攻防克制

1. **破除步兵火攻屏障**：使常規以火盆、火把阻騎的防禦陣列徹底失去嚇阻功效。
2. **天敵與戰術反制**：
   - **正面強光灼目**：敵軍若於正面投擲白磷生石灰閃光彈，正向強光直接照射馬眼，引發暫時性失明與狂奔。
   - **鐵蒺藜刺足痛覺**：眼罩防得了聲光，防不了地面生鐵蒺藜；馬蹄受扎之劇痛會繞過大腦直覺直接引發悲鳴跪地。

# 戰鬥AI擊殺SP充能難度倍率縮放規格書

## 1. 核心定位與職責邊界
本規格書定義《三國人生》敵方 AI 在戰鬥中擊殺我方部隊時獲得戰技點（SP / 能量）的難度倍率修正機制（WBS `AIS-12`，代碼落位於 `AiSpCharge.ts` 與 `AiDifficultyTable.ts`）。
戰鬥系統將玩家方與敵方 AI 之 SP 獲取管線嚴格解耦：玩家擊殺部隊固定獲得基準 SP 點數；而敵方 AI 之擊殺 SP 收益則受關卡難度設定驅動，確保高難度戰局中敵將能更頻繁釋放武將技與奧義，建立階梯式壓迫感。

```
              ┌──────────────────────────────────────────────┐
              │          AiSpCharge 擊殺充能計算引擎          │
              └──────────────────────┬───────────────────────┘
                                     │ 擊殺結算事件 (onUnitKilled)
          ┌──────────────────────────┴──────────────────────────┐
          ▼                                                     ▼
   【玩家部隊擊殺】                                       【敵方部隊擊殺】
   • 固定獲得基準 SP (20點)                               • 依難度表 spGainModifier 縮放
   • 嚴格不受 AI 難度倍率影響                            • 無條件捨去 (floor) 取整數
```

## 2. 擊殺充能數值公式與難度縮放矩陣

### 2.1 數值計算公式
每次成功擊殺目標部隊時，敵方主將獲得之 SP 充能點數：
$$\text{BaseSP} = 20 \quad (\text{SP\_PER\_KILL})$$
$$\text{AI\_SP\_Gain\_Per\_Kill} = \lfloor \text{BaseSP} \times \text{spGainModifier} \rfloor$$

> **整數向下取整**：透過 $\lfloor \dots \rfloor$ 進行無條件捨去，嚴格杜絕戰場能量槽出現浮點數小數點。

### 2.2 五大難度等級充能矩陣（`ai-difficulty.json`）

| 難度代碼 (`AiDifficulty`) | 難度中文標識 | SP 充能倍率 (`spGainModifier`) | 每次擊殺實得 SP (`aiSpGainPerKill`) | 難度曲線說明 |
| :--- | :---: | :---: | :---: | :--- |
| **`easy`** | 簡單 (EASY) | **0.8** | **16 點** | 敵將充能滯緩，大幅寬容玩家佈陣失誤 |
| **`normal`** | 普通 (NORMAL) | **1.0** | **20 點** | 基準對稱充能，與玩家獲得量完全一致 |
| **`hard`** | 困難 (HARD) | **1.2** | **24 點** | 充能加速 20%，加快敵將奧義爆發頻率 |
| **`nightmare`** | 噩夢 (NIGHTMARE) | **1.3** | **26 點** | 高壓戰術壓制，敵將戰技週轉顯著提升 |
| **`hell`** | 地獄 (HELL) | **1.5** | **30 點** | 極限瘋狂壓迫，每擊殺 3~4 支部隊即可施放奧義 |

## 3. 戰鬥入口難度解析與繼承協議（`resolveAiDifficulty`）

為確保戰鬥狀態機初始化的確定性，戰鬥控制器於加載階段依序解析難度來源：

1. **優先序檢定（`resolveAiDifficulty`）**：
   $$\text{Difficulty} = \text{FirstValid}(\text{battleEntryParam}, \text{encounterData}, \text{'normal'})$$
   - 第一優先：戰場直接傳入之入口參數（如名將挑戰賽指定難度）。
   - 第二優先：關卡遭遇節點資料（`encounterData`）設定。
   - 保底回退：若無參數或字串拼寫異常，一律安全回退至 `'normal'`（標準倍率 1.0）。
2. **生命週期隔離**：
   - 每次調用 `initBattle` 重啟新戰鬥時，戰場狀態機（`BattleState`）之 `aiSpGainModifier` 立即重置回預設值 1.0，嚴格防止上一場高難度殘留倍率污染下一場戰局。
3. **玩家防護屏障**：
   - 玩家擊殺部隊獲得之能量**恆定等於 20 點（`SP_PER_KILL`）**，嚴禁套用 `spGainModifier`，確保玩家基礎操作手感與技能節奏之純粹性。

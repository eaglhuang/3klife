# 戰鬥反應連鎖連環計傷害共享與反擊再動規格書

## 1. 核心定位與分類契約

本規格書為戰鬥反應連鎖包（P1 Reaction Chain Package，代號 `TAC-06`）的單一真相來源（Single Source of Truth），涵蓋連環計傷害共享（`TLINK` / `link`）、受擊近戰反擊（`TCOUNTER` / `counter`）與擊殺再動重置（`TRESET` / `reset`）。

```typescript
export interface ReactionChainContract {
  category: 'REACTION_CHAIN';
  effectKinds: 'link' | 'counter' | 'reset';
  linkShareRatioDefault: 0.5;       // 連環計預設分攤 50%
  counterRatioDefault: 2.0;         // 近戰反擊預設 2.0 倍反噬
  resetFirstHitMultiplierDefault: 2.0; // 首擊雙倍爆發
}
```

---

## 2. 連環計傷害共享鏈機制（TLINK）

連環計將敵軍多個單位締結為連鎖共振網絡，主目標受擊時，連鎖單位承擔次級連鎖傷害。

### 2.1 索敵與連鎖單位篩選（Link Target Topology）

1. **主目標鎖定**：依據戰法選定首要敵方部隊 $U_{\text{primary}}$。
2. **拓撲鄰近檢定（Chebyshev Distance）**：
   - 搜尋半徑 $R_{\text{link}} = \text{linkRadius}$（預設 1，即以主目標為中心之 $3 \times 3$ 區域）。
   - 鄰近判定條件：$\max(|L_i - L_p|, |D_i - D_p|) \le R_{\text{link}}$。
   - 排除已陣亡單位與主目標本體，按距離由近至遠排序，截取上限 $\text{linkMaxTargets}$。

### 2.2 傷害傳導與分攤公式

當主目標 $U_{\text{primary}}$ 承受實際傷害 $D_{\text{actual}}$ 時：

$$D_{\text{linked}} = \lfloor D_{\text{actual}} \times R_{\text{share}} \rfloor \quad (R_{\text{share}} = \text{linkShareRatio} = 0.5)$$

- 連鎖傳導傷害無視防禦（True Damage），直接扣除被連鎖部隊之當前兵力。
- 戰鬥記錄記錄格式：`skill.link.tally:primaryId->linkedId:0.5`。

## 3. 幼麒天算近戰反擊反應（TCOUNTER）

受擊反擊屬於被動觸發式反應條件（Reactive Trigger），在友軍遭受近身近戰打擊時觸發致命反擊。

### 3.1 觸發條件約束

1. **近戰限制（Melee Only）**：
   - `counterMeleeOnly: true`：僅當敵方為相鄰 1 格之近戰普攻或衝鋒時觸發；遠程箭矢不觸發。
2. **次數與時效管制**：
   - 作用回合：`counterStatusTurns`（預設 1 回合）。
   - 最大觸發次數：`counterTriggers`（預設每回合 1 次），防範雙方互反無限死迴圈。

### 3.2 反擊傷害倍率與虛弱附帶

$$D_{\text{counter}} = \lfloor \text{ATK}_{\text{defender}} \times \text{counterRatio} \rfloor \quad (\text{counterRatio} = 2.0)$$

- 反擊結算優先於攻擊方之追擊判定。
- 附帶 Debuff：反擊成功後，攻擊方附加 `Weak` 虛弱狀態 1 回合（攻擊力降低 30%）。

## 4. 威震華夏首擊雙倍與擊殺再動（TRESET）

專屬於萬人敵勇將之戰場連續突破機制，以首擊壓制與破陣再動為核心。

### 4.1 首擊雙倍爆發（First Hit Multiplier）

武將進入戰場首回合或初次出擊時，獲得強烈破軍增幅：

$$D_{\text{first}} = \lfloor D_{\text{normal}} \times \text{resetFirstHitMultiplier} \rfloor \quad (M = 2.0)$$

### 4.2 斬將破陣再動（Reset On Kill）

若該次攻擊成功致死敵方部隊（`target.isDead() == true`）：
1. 立即觸發再動重置：`deltas.notes: 'reset-on-kill'`。
2. 施放者獲得額外行動回合（`extraActions += 1`），行動條（Action State）刷新為可用。
3. 單一回合最多觸發 1 次再動，杜絕單回合無限連斬清場。

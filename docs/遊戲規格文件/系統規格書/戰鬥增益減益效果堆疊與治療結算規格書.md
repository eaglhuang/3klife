# 戰鬥增益減益效果堆疊與治療結算規格書

> **文件狀態**：單一真相來源（Single Source of Truth）  
> **系統代碼**：`TAC-04`、`SYS-BUFF-DEBUFF-HEAL`  
> **核心職責**：確立戰鬥中增益（TBUFF）、減益（TDEBUFF）與持續傷害（TDOT）之最大堆疊層數（3層）、同類刷新覆蓋規則，以及醫療急救戰法（THEAL）以「25%已損失HP」為核心之生命回補計算模型。

---

## 1. 增益與減益堆疊與刷新覆蓋規則

為維護戰鬥數值平衡並防止無限屬性膨脹，全域狀態效果嚴格遵守「雙限約束」：

```
[新狀態施加] ──> [檢核當前層數 < 3] ──(是)──> [層數 +1，持續回合重置為 max(舊, 新)]
                       │
                      (否，已達3層)
                       ↓
            [僅刷新持續回合，數值不再疊加]
```

1. **最大堆疊層數上限（Stack Cap）**：
   - 任何同名 Buff/Debuff（如【攻擊提升】、【破甲弱化】）**最多疊加 3 層**。
2. **持續時長刷新機制（Duration Refresh）**：
   - 當單位已存在該狀態時，再次受到相同效果影響，剩餘持續回合數刷新為：
     $$\text{Turns}_{\text{remain}} = \max(\text{Turns}_{\text{current}}, \; \text{Turns}_{\text{new}})$$
   - 禁止持續回合直接相加延長，防止玩家永久維持滿層增益。

---

## 2. 醫療戰法生命回補模型（THEAL）

戰場急救與醫療戰法不僅提供固定治療，更具備「逆境急救」之傷員收攏特性：
$$\text{HealAmount} = \left\lfloor \text{BaseHeal} + (\text{MaxHp} - \text{CurrentHp}) \times 0.25 \right\rfloor$$

- **基礎治療量 ($\text{BaseHeal}$)**：依戰法品質固定為 $150 \sim 400$ 點。
- **已損生命回補係數 ($0.25$)**：目標部隊已損失兵力/生命值之 $25\%$。
  - 當部隊僅剩 20% 殘血時，治療效益達到最大化，逆轉瀕死危機。
- **治療上限截斷**：最終生命值絕不可突破部隊上限（$\le \text{MaxHp}$）。

---

## 3. 持續性傷害結算時機（TDOT: Burn & Poison）

- **燃燒 (Burn)**：每回合開始階段（Turn Start Tick），扣除當前生命值 $8\%$（對機械單位加倍為 $16\%$）。
- **中毒 (Poison)**：每回合結束階段（Turn End Tick），扣除最大生命值 $5\%$ 並降低移動力 1 格。

## 4. TypeScript 核心實作模組

```typescript
export interface HealCalculationInput {
  baseHeal: number;
  currentHp: number;
  maxHp: number;
}

export function computeHealAmount(input: HealCalculationInput): number {
  const lostHp = Math.max(0, input.maxHp - input.currentHp);
  const scalingHeal = lostHp * 0.25;
  const rawTotal = input.baseHeal + scalingHeal;
  const finalHeal = Math.min(input.maxHp - input.currentHp, Math.floor(rawTotal));
  return Math.max(0, finalHeal);
}

export function applyBuffStack(
  currentStacks: number,
  currentTurns: number,
  newDuration: number
): { stacks: number; remainingTurns: number } {
  const updatedStacks = Math.min(3, currentStacks + 1);
  const updatedTurns = Math.max(currentTurns, newDuration);
  return { stacks: updatedStacks, remainingTurns: updatedTurns };
}
```

## 5. 驗收標準與 CI 閘門（Acceptance Criteria）

1. **三層封頂單元測試**：
   - 連續施加 5 次相同 Buff，檢驗最終堆疊層數恆等於 3，時長正確刷新。
2. **25% 已損生命加成精度**：
   - 滿血單位僅獲得 BaseHeal；半血單位精確獲得 BaseHeal + 0.25 損耗回補。
3. **無過量溢出**：
   - 治療後生命值嚴格 $\le \text{MaxHp}$，無生命數值溢出破圖。

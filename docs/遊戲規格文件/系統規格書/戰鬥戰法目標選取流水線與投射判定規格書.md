# 戰鬥戰法目標選取流水線與投射判定規格書

> **文件狀態**：單一真相來源（Single Source of Truth）  
> **系統代碼**：`TAC-03`、`TAC-07`、`SYS-TACTIC-TARGETING-RESOLVER`  
> **核心職責**：確立戰法施放之「目標選取流水線」（Targeting Flow）、P0 投射傷害包（TDIR / TLINE / TFAN）、距離衰減（Falloff）與穿甲算法，以及前置環境條件檢核（TCOND）與隱匿索敵過濾契約。

---

## 1. 目標選取流水線架構（Targeting Pipeline）

戰法觸發至造成實質傷害，嚴格遵循四階管線過濾：

```
[1. 條件閘門 (TCOND)] ──> [2. 投射集合計算 (Pattern)] ──> [3. 距離衰減 (Falloff)] ──> [4. 穿甲傷害結算]
  (鄰格/天氣/兵種限制)          (TDIR / TLINE / TFAN)           (每格衰減 10%)              (無視30%防禦)
```

1. **條件檢核閘門（TCOND 檢驗）**：
   - **兵種限制**：如突擊類限定騎兵，若部隊兵種不符立即阻絕。
   - **天氣限制**：大雨/暴雪天候強制禁用火矢與火攻計策。
   - **隱身索敵過濾**：目標若處於 `Stealth` 狀態且我方無真視特性，索敵集合自動剔除該目標。

## 2. P0 投射模式與幾何覆蓋矩陣

| 投射模式 (Pattern) | 覆蓋幾何定義 | 命中單位上限 | 距離衰減規則 (Falloff) |
|---|---|:---:|---|
| **TDIR (單體定向)** | 射程內指定單一坐標 | 1 隊 | 無距離衰減，全額 100% 傷害 |
| **TLINE (直線穿透)**| 朝目標向量延伸 3 格直線 | 貫穿路徑上所有單位 | 每貫穿 1 格，後續目標傷害 $-15\%$ |
| **TFAN (扇形散佈)** | 朝前方延伸 60度 扇形 5 格 | 區域內所有敵軍 | 距離原點每增加 1 格，威力 $-10\%$ |

---

## 3. 穿甲算法與數值結算（Armor Piercing）

具備【破甲】或【銳器】標籤之戰法，於計算目標護甲時實施部分穿透：
$$\text{EffectiveDef} = \text{TargetDef} \times (1 - \text{PiercingRatio})$$

- 常規穿甲戰法：$\text{PiercingRatio} = 0.30$（無視 30% 目標防禦力）。
- 神兵專屬戰法（如方天畫戟·霸者橫掃）：$\text{PiercingRatio} = 0.50$。

## 4. TypeScript 核心管線實作

```typescript
export enum TargetPatternType { TDIR = 'TDIR', TLINE = 'TLINE', TFAN = 'TFAN' }

export interface TacticTargetingContext {
  pattern: TargetPatternType;
  sourceCoord: { x: number; y: number };
  targetCoord: { x: number; y: number };
  currentWeather: string;
  hasTruesight: boolean;
}

export function isTacticConditionMet(ctx: TacticTargetingContext, tacticType: string): boolean {
  if (tacticType === 'FIRE' && (ctx.currentWeather === 'RAINY' || ctx.currentWeather === 'SNOW')) {
    return false; // 天候禁用
  }
  return true;
}

export function computeDistanceFalloff(distance: number, pattern: TargetPatternType): number {
  if (pattern === TargetPatternType.TDIR) return 1.0;
  if (pattern === TargetPatternType.TLINE) return Math.max(0.5, 1.0 - (distance - 1) * 0.15);
  return Math.max(0.6, 1.0 - (distance - 1) * 0.10);
}
```

## 5. 驗收標準與 CI 閘門（Acceptance Criteria）

1. **扇形與直線覆蓋單元測試**：
   - 驗證直線貫穿 3 格之傷害衰減依序為 1.0、0.85、0.70 倍率。
2. **天候硬阻斷校驗**：
   - 單元測試驗證暴雨天下發動火攻戰法，回傳 `Condition_Failed: WEATHER_MISMATCH`。
3. **隱身索敵免疫**：
   - 驗證無真視情況下，直線穿透自動掠過隱蔽地格中的伏兵單位。

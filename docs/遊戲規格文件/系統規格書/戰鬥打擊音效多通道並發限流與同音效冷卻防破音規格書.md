# 3KLife 戰鬥打擊音效多通道並發限流與同音效冷卻防破音規格書

> **規格代碼**：SPEC-AUDIO-SFX01  
> **關聯 WBS**：AUDIO-SFX-01（戰鬥打擊音效並發限流、同音效防破音冷卻與優先級搶佔）  
> **文件版本**：v1.0.0 (單一真相來源，無補丁整併版)  
> **所屬系統**：全域架構總控（Global Architecture & Audio Pipeline）

---

## 1. 核心宗旨與設計哲學

在大規模戰棋戰場中，箭雨齊射或全屏範圍戰法常於同一影格內並發數十個打擊音效。未經限制之音效重疊會引發音頻振幅溢出破表（Audio Clipping），產生刺耳爆音甚至造成 Web Audio API 線程死鎖。本規格書制定戰鬥音效之**同音效 60ms 防破音冷卻**、**全域 16 通道最大並發上限**與**三級音效優先級搶佔機制**。

---

## 2. 音效限流與防破音雙重防線

音效調用請求在輸出前必須依序通過兩道過濾防線：

```
[業務元件發起: playSfx("sfx_blade_clash")]
                    |
                    v
[防線 1: 同音效冷卻檢查 (Cooldown: 60ms)] -> 未滿 60ms 則直接安全丟棄
                    | (通過)
                    v
[防線 2: 全域並發通道數檢查 (Max: 16 通道)]
                    |
        +-----------+-----------+
        | (通道未滿)            | (通道已滿 16 個)
        v                       v
[立即分配通道播放]        [優先級搶佔仲裁 (Priority Arbitration)]
                                |
                    +-----------+-----------+
                    | (P0/P1 高優先級)      | (P2 普通音效)
                    v                       v
           [搶佔最舊/最低優先級]      [直接丟棄，防破音]
```

---

## 3. 優先級劃分與演算法契約

```typescript
export interface SfxPlayRequest {
  clipId: string;                     // 如 "sfx_arrow_volley"
  priority: 'P0_CRITICAL' | 'P1_COMBAT' | 'P2_NORMAL';
  volumeScale: number;                // 0.0 ~ 1.0
  playbackPosition?: number;
}

export interface SfxLimiterPolicy {
  sameClipCooldownMs: 60;             // 同音效冷卻時間 60ms
  maxConcurrentVoices: 16;            // 全局最大並發聲音通道
  preemptionMinPlayPercent: 0.50;     // 被搶佔音效必須已播放滿 50%
}
```

### 3.1 三級優先級定義表

| 優先級代號 | 適用音效清單 | 搶佔規則 (Preemption Behavior) |
|---|---|---|
| **P0_CRITICAL** | 終極奧義爆發、武將陣亡長嘆、戰役勝負結算音效 | **不可被搶佔**；通道滿載時強制搶佔最舊之 P2 或 P1 通道。 |
| **P1_COMBAT** | 戰法命中、暴擊破盾、單挑刀劍格擋金石聲 | 可搶佔播放滿 50% 之 P2 通道；同級之間先來後到。 |
| **P2_NORMAL** | 普通攻擊揮砍、弓弩搭弦、部隊行軍碎步聲 | **禁止搶佔**；通道滿載時自動安全丟棄，不引發異常。 |

## 4. 驗收測試案例 (Test Cases)

- **TC-AUDIO-SFX-01【同一影格 30 個箭矢音效防破音】**：同一幀內連續呼叫 30 次 `playSfx("sfx_arrow")`，限流器僅放行 1 次播放，其餘 29 次安全丟棄，輸出波形無任何削頂破音。
- **TC-AUDIO-SFX-02【16 通道並發硬上限檢驗】**：同時發起 25 個不同音效請求，系統嚴格僅啟用 16 個底層 `AudioSource`，無記憶體溢出。
- **TC-AUDIO-SFX-03【奧義音效高優先級順暢搶佔】**：在 16 個普通行軍音效佔滿通道時施放神算奧義（P0），系統成功搶佔已播放過半之行軍音效，奧義音效無延遲響起。

# 3KLife 戰鬥特效粒子上限與GPU繪製調用預算審計規格書

> **規格代碼**：SPEC-VFX-PERF01  
> **關聯 WBS**：VFX-PERF-01（戰鬥特效粒子預算審計、GPU 繪製調用 DrawCall 硬約束與動態降級狀態機）  
> **系統分類**：效能工程 / 戰鬥渲染優化  
> **狀態**：正式生效（單一真相來源，嚴禁尾端追加補丁）

---

## 1. 效能預算目標與設計準則

在《三國人生》（3KLife）戰鬥場景中，五對五名將同時交戰或連續施放怒氣奧義時，密集的粒子特效與多層材質極易引發 GPU 填充率（Overdraw）過載、DrawCall 暴增與嚴重掉幀。

為保障各階級行動裝置（包含 3GB 記憶體入門機型）均能維持 **55~60 FPS** 穩定幀率，特制定本預算審計與強制約束標準：
1. **單畫面總粒子數硬約束**：全場同時活躍之粒子總數不得超過 **120**。
2. **GPU 繪製調用（DrawCall）預算**：單次奧義全螢幕演出期間，戰鬥特效層 DrawCall 增量不得超過 **15**。
3. **材質與圖集零碎化禁止**：所有戰鬥特效粒子與貼圖必須合批至單一 `vfx-atlas`，嚴禁跨圖集渲染破壞動態合批（Dynamic Batching）。

## 2. 粒子預算模型與動態衰減演算法

戰鬥渲染管理器（`VfxRenderBudgetManager`）每幀統計場景中所有活體粒子發射器之粒子總數 $P_{\text{total}}$：

$$P_{\text{total}} = \sum_{i=1}^{N} P_{i}$$

```
                ┌───────────────────────────────────┐
                │        即時粒子數 P_total          │
                └─────────────────┬─────────────────┘
                                  │
         ┌────────────────────────┼────────────────────────┐
         ▼ (P <= 80)              ▼ (80 < P <= 120)        ▼ (P > 120)
┌──────────────────┐    ┌──────────────────┐     ┌──────────────────┐
│   安全放行區間    │    │   速率線性衰減   │     │   非關鍵粒子捨棄  │
│ 100% 發射速率    │    │ 降至 60%~80% 速率│     │ 僅保留核心打擊光  │
└──────────────────┘    └──────────────────┘     └──────────────────┘
```

1. **安全區間（$P_{\text{total}} \le 80$）**：所有特效區塊依預設發射速率 100% 正常發射。
2. **警戒衰減區間（$80 < P_{\text{total}} \le 120$）**：啟動線性衰減公式，動態降低新發射器之發射率：
   $$\text{EmissionRate}_{\text{adj}} = \text{EmissionRate}_{\text{base}} \times \left(1.0 - \frac{P_{\text{total}} - 80}{100}\right)$$
3. **硬頂防護區間（$P_{\text{total}} > 120$）**：立即壓制所有次級環境飄散粒子（如水墨煙霧、火星飛濺），新生成之特效僅播放核心 SpriteFrame 斬擊動畫，發射器發射數歸零。

## 3. 四階動態畫質降級狀態機

系統每 60 幀採樣一次平均渲染幀率（FPS）。當偵測到低階設備或發熱降頻時，依狀態機順序降級：

```typescript
export enum VfxQualityTier {
  HIGH = 'HIGH',         // 高階：全粒子開放、Bloom 疊加光暈、雙層殘影
  MEDIUM = 'MEDIUM',     // 中階：粒子發射速率 80%、單層殘影
  LOW = 'LOW',           // 低階：粒子發射速率 50%、關閉殘影與飄散煙霧
  POTATO = 'POTATO'      // 極速：全面停用粒子發射器，僅保留 Sprite 序列幀
}
```

```
┌──────┐  連續 3 秒 FPS < 45   ┌────────┐  連續 3 秒 FPS < 40   ┌─────┐  連續 3 秒 FPS < 30   ┌────────┐
│ HIGH │ ─────────────────────> │ MEDIUM │ ─────────────────────> │ LOW │ ─────────────────────> │ POTATO │
└──────┘                        └────────┘                        └─────┘                        └────────┘
    ▲                                │                                │                              │
    └────────────────────────────────┴────────────────────────────────┴──────────────────────────────┘
                         連續 10 秒 FPS >= 58 且未過熱時，逐級回升
```

## 4. 自動化審計門禁與違規防呆

在自動化測試與 CI 建置管線中（`npm run test:vfx-budget`），對所有 `vfx-effects.json` 配方進行靜態模擬審計：
1. **單配方峰值檢核**：任何單一奧義配方在獨立播放時，粒子峰值超過 60 或 DrawCall 超過 8 視為**建置失敗**。
2. **疊加峰值檢核**：模擬雙方名將同時施放奧義的最極端邊界，合併粒子峰值超過 120 時觸發報警並阻擋合併。
3. **紋理尺寸約束**：戰鬥特效圖集 `vfx-atlas.png` 尺寸不得超過 $2048 \times 2048$，壓縮格式強制採用 ETC2/ASTC。

# 戰鬥里程碑成就判定與隱藏因子覺醒狀態機規格書

## 1. 模組職責與架構定位
本規格書規範武將在實戰中達成的「戰鬥里程碑成就判定系統（`MilestoneRewards`）」以及成就觸發時的「隱藏遺傳因子破鎖覺醒狀態機（`HiddenFactorAwakening`）」。模組負責在戰後結算時即時掃描戰功，將傳奇作戰表現轉化為武將的永久天賦基因。

```
┌─────────────────────────────────────────────────────────────┐
│                 Milestones & Gene Awakening                 │
├──────────────────────────────┬──────────────────────────────┤
│ 戰鬥里程碑掃描               │ 隱藏遺傳因子破鎖覺醒         │
│ 千人斬 / 連勝 20 場 / 鐵壁   │ 鎖定槽位原子翻轉 (isLocked)  │
│ 發放戰法筆記與榮譽稱號       │ 永久激發修羅/不敗/鐵壁特效   │
└──────────────────────────────┴──────────────────────────────┘
```

## 2. 四大戰鬥里程碑成就判定模型

```typescript
export interface MilestoneEvaluationContext {
  totalKills: number;
  consecutiveWins: number;
  lifetimeGuardianPower: number;
  hasDesperateKillInBattle: boolean; // 殘血 <15% 斬殺敵將
}

export interface MilestoneAchievements {
  achievedKillMilestone: 'NONE' | 'HUNDRED' | 'THOUSAND' | 'MYRIAD';
  isUndefeatedAchieved: boolean; // 連勝 ≥ 20
  isIronWallAchieved: boolean;   // 守護力 ≥ 1000
  isKillingIntentAchieved: boolean;
  unlockedGeneIds: string[];
}
```

### 2.1 里程碑判定與因子映射矩陣
- **千人斬（`THOUSAND`）**：$\text{totalKills} \ge 1000$。解鎖白色因子「修羅（`GENE_ASURA`）」，全五維成長率 $+5\%$。
- **不敗神話（`UNDEFEATED`）**：$\text{consecutiveWins} \ge 20$。解鎖白色因子「不敗（`GENE_UNDEFEATED`）」，全天候豁免動搖與混亂。
- **守護之壁（`IRON_WALL`）**：$\text{lifetimeGuardianPower} \ge 1000$。解鎖紅色因子「鐵壁（`GENE_IRON_WALL`）」，受傷機率降為 0，每季精力回復 $+10$ 點。
- **絕境破軍（`KILLING_INTENT`）**：$\text{hasDesperateKillInBattle} === \text{true}$。解鎖白色因子「殺意（`GENE_KILLING_INTENT`）」，暴擊傷害 $+25\%$。

```typescript
export function evaluateMilestones(ctx: MilestoneEvaluationContext): MilestoneAchievements {
  let killTier: 'NONE' | 'HUNDRED' | 'THOUSAND' | 'MYRIAD' = 'NONE';
  if (ctx.totalKills >= 10000) killTier = 'MYRIAD';
  else if (ctx.totalKills >= 1000) killTier = 'THOUSAND';
  else if (ctx.totalKills >= 100) killTier = 'HUNDRED';

  const isUndefeated = ctx.consecutiveWins >= 20;
  const isIronWall = ctx.lifetimeGuardianPower >= 1000;
  const isKillingIntent = ctx.hasDesperateKillInBattle;

  const genes: string[] = [];
  if (killTier === 'THOUSAND' || killTier === 'MYRIAD') genes.push('GENE_ASURA');
  if (isUndefeated) genes.push('GENE_UNDEFEATED');
  if (isIronWall) genes.push('GENE_IRON_WALL');
  if (isKillingIntent) genes.push('GENE_KILLING_INTENT');

  return {
    achievedKillMilestone: killTier,
    isUndefeatedAchieved: isUndefeated,
    isIronWallAchieved: isIronWall,
    isKillingIntentAchieved: isKillingIntent,
    unlockedGeneIds: genes
  };
}
```

## 3. 隱藏因子破鎖覺醒狀態機

### 3.1 槽位查找與原子碎裂
當里程碑達成並輸出 `unlockedGeneIds` 時：
1. 遍歷武將之基因槽清單（`genes: GeneObject[]`）。
2. 若存在與達成成就對應且處於鎖定狀態（`isLocked === true`）之槽位：
   - 將該槽位之 `isLocked` 原子翻轉為 `false`。
   - 廣播全域事件 `GeneShatteredBroadcast`，通知前端播發金色碎裂粒子。
   - 該因子在武將存檔中永久啟動，並可在後續世代繁衍中作為遺傳因子傳遞。

## 4. 單元測試驗證規範
1. **TC-MILE-KILL（千人斬觸發修羅）**：擊殺 999 不觸發；擊殺 1,000 時回傳 `achievedKillMilestone = 'THOUSAND'` 且解鎖 `GENE_ASURA`。
2. **TC-MILE-UNDEFEATED（20 連勝觸發不敗）**：連勝 19 場不觸發；連勝 20 場回傳 `isUndefeatedAchieved = true`。
3. **TC-GENE-SHATTER（鎖定槽位精確翻轉）**：槽位初始 `isLocked = true`，匹配成功後翻轉為 `false`，重跑判定不重複翻轉。

# 3KLife 投石機拋擲瘟疫腐屍病畜與城內大疫爆發狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 攻城生物戰與瘟疫傳播系統（`PESTILENCE-CATAPULT-01`）。重現古代圍城戰中極其殘酷之生化戰術：進攻方利用重型拋石機，將患傷寒、霍亂暴卒之人畜腐屍包裹拋越城牆，砸落於城內密集街肆與軍營。腐屍破碎釋放惡臭屍毒，引發蠅蚋孳生與大疫流行，從內部瓦解守城軍民之生理與精神防線。

## 4. 傳染蔓延、病死減員與消殺阻斷公式

### 4.1 疫情爆發傳播速率公式
腐屍落地後，若未於 1 回合內全數收殮焚化：
$$R_0 = \left(1.5 + \frac{\text{PestilenceIntensity}}{50}\right) \times \left(1.0 + \frac{\text{CityDensityRating}}{100}\right) \times \text{SeasonHeatMultiplier}$$
- 夏季炎熱濕悶（`SeasonHeatMultiplier} = 1.6$；冬季嚴寒 $= 0.5$；
- 染疫百分比每回合依指數擴散：
$$\Delta \text{InfectedPercent} = \text{InfectedPercent} \times (R_0 - 1.0) \times 0.25$$

### 4.2 生石灰消毒與火化阻斷
城內守軍調集民夫與生石灰執行強制消殺：
$$\text{DisinfectionEfficiency} = \left(\frac{\text{LimeSupply} \times 0.5 + \text{MedicTroopCount} \times 0.5}{100}\right)$$
- 若 $\text{DisinfectionEfficiency} \ge 80$，疫情傳播率 $R_0$ 被強行壓制至 $0.2$ 以下，1 回合後轉為 `SANITIZED`，阻止全城崩潰。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-PLAGUE-01**：進攻方若連續 3 回合拋射腐屍且本營未做防護，自身軍隊有 $30\%$ 機率觸發「反噬染疫」，攻城兵團陷入傷寒。
2. **驗收 CASE-PLAGUE-02**：大疫蔓延達 `DECIMATION` 狀態時，城內守軍全屬性扣除 $50\%$，每回合有 $15\%$ 守軍因高燒棄械倒地。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

# 3KLife 拔箭清點矯直箭桿換羽磨鏃工坊批次翻新狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 軍械後勤製造與戰場物資回收翻新系統（`ARROW-REFURBISH-01`）。規範大軍在草船借箭或守城大戰繳獲數十萬箭矢後之工坊回收整飭流程：自草人及戰場遺存中拔出箭鏃、利用微火烘烤竹木箭桿矯直彎曲、以魚鰾鹿膠重新黏結損壞雕翎、並以油石磨礪開刃銹蝕生鐵鏃，使戰損箭矢以最低成本轉化為全新戰備物資。

## 4. 良品率演算法、工匠效率與成本節省公式

### 4.1 拔箭翻新良品率計算公式
稻草人或盾牌所截獲之箭矢修復良品率：
$$\eta_{\text{yield}} = \left(0.70 + \frac{\text{ArtisanSkillLevel}}{200}\right) \times \left(1.0 - \text{FiberFractureRate}\right)$$
- 稻草束受箭對箭桿緩衝良好，斷桿率僅 $10\%$；
- 翻新良品率一般可維持在 $80\% \sim 88\%$ 之間；
- 熟練工匠每人每日可精修翻新 200 枝箭矢。

### 4.2 資源成本節約模型
相比從伐竹採鐵從頭鍛造新箭：
$$\text{CostSavings} = 1.0 - \frac{\text{LaborCost} + \text{GlueCost}}{\text{NewArrowIronWoodCost}} \approx 75\%$$
- 翻新 10 萬支箭矢可節約國庫黃金數千兩、生鐵數萬斤，大幅加速決戰戰備籌備天數。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-REFURB-01**：在缺乏魚鰾膠或雕翎原料時，工坊僅能完成磨鏃矯直，箭矢射出後因無羽失速，射程扣減 $50\%$。
2. **驗收 CASE-REFURB-02**：經翻新入庫之箭矢，命中率與破甲值與全新制式鵰翎箭完全等同，無性能懲罰。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

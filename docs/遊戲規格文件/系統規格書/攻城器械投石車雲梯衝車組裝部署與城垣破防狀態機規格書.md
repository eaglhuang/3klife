# 3KLife 攻城器械投石車雲梯衝車組裝部署與城垣破防狀態機規格書

> **規格代碼**：SPEC-BAT-SIEGE01  
> **關聯 WBS**：BATTLE-SIEGE-01（攻城器械組裝架設狀態機、超遠程射程盲區與城垣城門破防機制）  
> **系統分類**：戰鬥系統 / 重型裝備與攻防演算  
> **狀態**：正式生效（單一真相來源，嚴禁尾端追加補丁）

## 1. 系統架構定位與攻城戰術範式

攻城掠地為三國群雄逐鹿之終極形式。傳統部隊若以血肉之軀硬攻堅固城垣，將承受高達 50% 免傷懲罰與滾木擂石之毀滅打擊。《三國人生》（3KLife）設計強型別**攻城器械體系（Siege Engine System）**。

本系統核心價值：
1. **角色分化明確**：投石車破牆、衝車破門、雲梯送登城步兵。
2. **部署架設成本（Deployment Latency）**：器械非隨走隨打，需經歷「打包運載 $\rightarrow$ 定點架設 $\rightarrow$ 開火打擊」之狀態機流轉。
3. **戰術死角與易燃性**：強大威力伴隨近身射程盲區與極度畏懼火箭火攻之物理特性。

## 2. 三大攻城重器資料定義

```typescript
export enum SiegeEngineType {
  CATAPULT = 'CATAPULT',       // 霹靂車 (超遠程拋石，專破城垣耐久)
  BATTERING_RAM = 'BATTERING_RAM', // 撞車 (近戰貼身，專破城門護盾)
  SIEGE_LADDER = 'SIEGE_LADDER'    // 雲梯 (掛載城牆，開闢登城跳板)
}

export interface ISiegeEngineDef {
  readonly engineType: SiegeEngineType;
  readonly maxHp: number;                // 器械本體生命值
  readonly movementPoints: number;        // 打包狀態下每回合移動力 (格數)
  readonly assembleTurns: number;         // 抵達定點後組裝所需回合數 (通常為 1)
  readonly minAttackRange: number;        // 最小射程盲區 (投石車為 3 格)
  readonly maxAttackRange: number;        // 最大打擊射程 (投石車為 6 格)
  readonly siegeDamageMultiplier: number; // 對建築與城門之破防傷害乘數
  readonly isWoodenStructure: boolean;    // 是否為木質易燃構造 (火傷害 200%)
}
```

## 3. 器械組裝架設狀態機

攻城器械在戰場上遵循嚴謹的生命週期流轉狀態機：

```
      [PACKED 打包運載] ──移動至陣地──> [ASSEMBLING 組裝架設中]
             ▲                                   │
             │ 打包收整 (耗費 1 回合)              │ 滿 1 回合
             │                                   ▼
      [PACKING 拆卸中] ◄──── disassemble() ─── [DEPLOYED 架設完畢]
                                                 │
                                                 │ 執行 strike()
                                                 ▼
                                           [開火拋射 / 衝撞]
```

1. **`PACKED`（打包狀態）**：部隊以車輛形式行軍，移動力為標準 2~3 格；此狀態下**完全無法發動攻擊**。
2. **`ASSEMBLING`（組裝中）**：抵達戰術目標點後宣告架設，耗費 1 完整回合。在此期間器械無法移動、無法反擊，受擊傷害額外增加 $20\%$。
3. **`DEPLOYED`（架設完畢）**：完成組裝進入攻擊陣地。移動力歸零，獲得專屬攻擊技能。
4. **`PACKING`（拆卸中）**：若需轉移陣地，必須執行拆卸命令，下次回合開始時方可恢復為 `PACKED`。

## 4. 城垣破防結算與戰術盲區機制

1. **投石車射程盲區（Blind Zone）**：
   - 投石車射程範圍為 $3 \sim 6$ 格。當敵軍騎兵或近戰突破至距離投石車 $\le 2$ 格內時，**投石車強制喪失反擊能力**，形同活靶。
2. **城垣破防與破門計算**：
   - 投石車攻擊城牆，觸發 `siegeDamageMultiplier: 3.0`，每次攻擊削弱城防耐久值 $15\%\sim 25\%$。
   - 衝車抵達城門格（相鄰 1 格），發動「巨木轟擊」，直接無視城門減傷結界，造成常規傷害 $400\%$ 暴擊。
3. **雲梯登城特例**：
   - 當雲梯架設於城牆地格後，相鄰之步兵部隊可直接執行「登城突擊」，無視城牆高度阻隔與護城河泥濘，直接切入城垛內部與守軍白刃肉搏。

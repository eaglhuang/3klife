# 攻城戰城門防禦城牆地利與器械破陣數值規格書

## 1. 核心定位與攻城架構契約

本規格書為攻城戰役核心機制（Siege Warfare Mechanics，代號 `SCN-08`）的單一真相來源（Single Source of Truth）。涵蓋城前護城河行軍減速、城牆居高臨下防禦地利加成、衝車雙倍破門、投石機範圍打擊與雲梯攀爬防禦抵消等數值模型。

```typescript
export interface SiegeWarfareContract {
  wallMinDepth: 6;                  // 城牆位於縱深 6 與 7
  moatDepth: 5;                     // 護城河位於縱深 5
  moatMoveDelta: -1;                // 護城河移動力減 1 格
  wallDefenseMultiplier: 1.5;       // 城牆守軍防禦力 1.5 倍
  batteringRamMultiplier: 2.0;      // 衝車破門雙倍傷害
  catapultDirectDamage: 10;         // 投石機固定每回合轟擊
}
```

## 2. 攻城三層防線結構與地形加成

攻城戰棋盤縱深由攻入守分為三層防禦工事：

### 2.1 第一道防線：護城河（Siege Moat）

- **坐標配置**：橫貫整個棋盤縱深 $\text{Depth} = 5$（`SIEGE_MOAT_DEPTH`）。
- **行軍泥濘減速**：
  - 任何非飛行部隊進入護城河地格時，該回合移動力強制扣減 1 格（$\Delta_{\text{move}} = -1$）。
  - 若部隊移動力僅為 1，扣減後保底可前進 1 格，不可原地鎖死。

### 2.2 第二道防線：城門與要塞障礙（Gate & Fortress）

- **城門結構**：位於中線車道（Lane 2），具備獨立耐久度（HP 3000）。
- **硬性阻絕**：城門未被擊破前，進攻方地面部隊無法穿透該格進入城內。

### 2.3 第三道防線：城牆地利（Siege Wall Advantage）

- **坐標配置**：縱深 $\text{Depth} \ge 6$（`SIEGE_WALL_MIN_DEPTH`）。
- **居高臨下防禦增幅**：
  - 處於城牆深處之守方部隊（`isSiegeWallDefender`），其物理與戰法受傷抗性大幅提升：
    $$\text{DEF}_{\text{effective}} = \lfloor \text{DEF}_{\text{base}} \times 1.5 \rfloor$$
  - 城牆守軍射程額外享有 $+1$ 格視野優勢。

## 3. 攻城器械攻擊與剋制模型

針對堅固城防，進攻方配置三大器械單位（`TroopType.Engineer` 或具備攻城虎符之先登部隊）：

### 3.1 衝車破陣（Battering Ram）

- **專屬效果**：對城門與城塞障礙物攻擊時，結算傷害直接翻倍：
  $$D_{\text{ram}} = \lfloor D_{\text{base}} \times 2.0 \rfloor$$
- 先登死士（`tiger-tally-xian-deng`）具備攻城乘數 $\times 2.0$ 且免疫恐懼。

### 3.2 投石機遠程壓制（Catapult AOE）

- **轟擊頻率**：工兵單位每回合行軍結束後，向敵方城牆深處發動落石投射。
- **無視護甲打擊**：造成固定 10 點穿甲部隊兵力傷亡（`SIEGE_CATAPULT_DAMAGE = 10`），並附帶周圍 1 格震波。

### 3.3 雲梯攀爬登城（Cloud Ladder）

- 步兵單位配備雲梯後，攀登進入城牆地格時，**直接消除城牆守軍之 $1.5\times$ 防禦加成**，恢復為 1.0 倍平地防禦結算。

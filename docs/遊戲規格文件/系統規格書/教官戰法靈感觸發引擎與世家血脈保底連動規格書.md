# 教官戰法靈感觸發引擎與世家血脈保底連動規格書

## 1. 模組職責與架構定位
本規格書規範學府培育中「教官戰法靈感事件觸發引擎（`MentorInspiration`）」以及「世家血脈靈感保底與點數折扣（`BloodlineGuarantee`）」的精算模型。該模組負責在 36 回合培育訓練中，根據學員屬性、教官星等與世家淵源，動態抽選靈感事件並提供保底機制。

```

```

## 2. 靈感事件動態觸發精算模型

### 2.1 觸發條件與硬性閘門
靈感事件非任意回合無限制觸發，必須通過三重防呆閘門：
1. **觸發回合視窗（`Trigger_Window`）**：限定於第 **6 ~ 30 回合** 之間，啟蒙初期（1~5 回合）與結業衝刺期（31~36 回合）不觸發。
2. **教官最低星等閘門（`minStarRequired`）**：部分高階戰法要求教官星等達 $\ge \text{★}2$ 或 $\ge \text{★}4$。
3. **家傳血統限制（`Bloodline_Required`）**：若戰法帶有世家限定標籤（如「趙家槍法」），學員姓氏必須相符或血統中持有對應傳承因子。

### 2.2 動態機率精算公式
通過閘門後，該回合的靈感觸發機率受教官羈絆（`Friendship`）與學員運氣（`LUK`）共同放大：
$$\text{FriendshipMod} = 1.0 + \frac{\text{Friendship}}{100}$$
$$\text{LuckMod} = 1.0 + \frac{\max(0, \text{LUK} - 50)}{150}$$
$$\text{FinalRate} = \min\left(0.60, \text{BaseRate} \times \text{FriendshipMod} \times \text{LuckMod}\right)$$

```typescript
export interface InspirationParams {
  currentRound: number;
  baseRate: number;         // 基準機率（例如 0.15）
  mentorStar: number;
  minStarRequired: number;
  friendship: number;       // 0 ~ 100
  luk: number;              // 0 ~ 100
  hasBloodlineMatch: boolean;
  bloodlineRequired: boolean;
}

export function evaluateInspirationTrigger(params: InspirationParams, roll: number): boolean {
  if (params.currentRound < 6 || params.currentRound > 30) return false;
  if (params.mentorStar < params.minStarRequired) return false;
  if (params.bloodlineRequired && !params.hasBloodlineMatch) return false;

  const friendshipMod = 1.0 + (params.friendship / 100);
  const luckMod = 1.0 + (Math.max(0, params.luk - 50) / 150);
  const finalRate = Math.min(0.60, params.baseRate * friendshipMod * luckMod);

  return roll < finalRate;
}
```

## 3. 世家血脈保底與 PT 研習折扣

### 3.1 第 25 回合強制保底狀態機
若學員與教官具備同源世家血脈（`hasBloodlineMatch === true`）：
- 系統全程追蹤該教官之靈感觸發次數。
- 若截至 **第 24 回合結束** 時，累計觸發次數仍為 **0**，則在 **第 25 回合** 進行訓練時，系統繞過隨機擲骰，**強制 100% 觸發** 家傳核心戰法靈感事件。

### 3.2 研習 PT 點數減免
透過世家血脈觸發之專屬戰法，結業研習時享有特權折扣：
$$\text{RequiredTP} = \left\lceil \text{OriginalTP} \times 0.80 \right\rceil$$
提供 $20\%$ 的 TP 點數優惠，加速子嗣即戰力定型。

## 4. 單元測試驗證規範
1. **TC-INSP-01（視窗外拒絕檢驗）**：在第 5 回合或第 31 回合，即便 roll 為 0.001 且條件完全具備，仍回傳 `false`。
2. **TC-INSP-02（星等不足與血統缺失阻斷）**：若 `minStarRequired = 2` 但教官為 ★1，或 `bloodlineRequired = true` 但血統不符，恆回傳 `false`。
3. **TC-INSP-03（第 25 回合世家強制保底）**：血統匹配且前 24 回合觸發次數為 0，第 25 回合執行判定強制回傳 `true`，且戰法 TP 折扣為 0.8。

# 教官支援卡五來源獲取管線與星等突破溢出轉化規格書

## 1. 模組職責與架構定位
本規格書規範學府培育體系核心資產「教官支援卡（`MentorCard`）」的完整生命週期管理。涵蓋「卡片資料結構與五大獲取來源標記」、「★0 ~ ★5 星等極限突破（Limit Break）」以及「滿星重複抽中之名師積分（`MentorPoints`）溢出轉化計算」。本模組隸屬 `MentorSupportSchema` 與 `MentorBreakthrough`。

## 2. 資料結構與五大獲取來源

```typescript
export type MentorRarity = 'SSR' | 'SR' | 'R';

export type MentorCardSource =
  | 'SUPPORT_GACHA'          // 支援卡池抽樣
  | 'COMING_OF_AGE_BRANCH'   // 子嗣 14 歲及笄弱冠分流
  | 'RETIRED_GENERAL'        // 60 歲退役武將卸甲執教
  | 'CAPTIVE_CONVERSION'     // 戰場名將俘虜感化轉任
  | 'MERCENARY_SWEAR';       // 酒館天下義士結義相助

export interface MentorCardRecord {
  cardId: string;
  mentorId: string;
  name: string;
  rarity: MentorRarity;
  currentStar: number;       // 0 ~ 5
  source: MentorCardSource;
  teachingStyle: 'WEATHER' | 'TERRAIN' | 'HUMAN'; // 天時、地利、人和
  supportTpBonus: number;    // TP 加乘係數（如 0.20 代表 +20%）
}
```

## 3. 星等突破與溢出點數轉化演算法

### 3.1 極限突破階梯（Limit Break）
重複獲得同名教官卡時，若星等小於 5，系統自動執行無損升星，星等加成隨之解鎖：
- **★0（基礎登錄）**：解鎖基礎訓練加成與 1 階靈感事件。
- **★1 ~ ★4（進階突破）**：每提升 1 星，友誼羈絆累積速度 $+5\%$、擅長訓練點數 $+5\%$。
- **★5（滿星圓滿）**：解鎖同格爆發率 $+10\%$，並開啟專屬金色神技傳授權。

### 3.2 滿星溢出轉化名師積分
當玩家持有之教官卡已達 ★5 極限星等，再次獲取該卡時，觸發自動溢出保護，轉化為全域通用之「名師積分（`MentorPoints`）」：
- **SSR 滿星溢出**：折算 **500 點** 名師積分。
- **SR 滿星溢出**：折算 **100 點** 名師積分。
- **R 滿星溢出**：折算 **20 點** 名師積分。

```typescript
export interface BreakthroughResult {
  cardId: string;
  previousStar: number;
  newStar: number;
  isMaxed: boolean;
  overflowPointsGranted: number;
}

export function processMentorDuplicate(
  existingCard: MentorCardRecord
): BreakthroughResult {
  const OVERFLOW_TABLE: Record<MentorRarity, number> = {
    SSR: 500,
    SR: 100,
    R: 20
  };

  if (existingCard.currentStar < 5) {
    const nextStar = existingCard.currentStar + 1;
    existingCard.currentStar = nextStar;
    return {
      cardId: existingCard.cardId,
      previousStar: nextStar - 1,
      newStar: nextStar,
      isMaxed: nextStar === 5,
      overflowPointsGranted: 0
    };
  }

  // 滿星溢出處理
  const points = OVERFLOW_TABLE[existingCard.rarity] || 20;
  return {
    cardId: existingCard.cardId,
    previousStar: 5,
    newStar: 5,
    isMaxed: true,
    overflowPointsGranted: points
  };
}
```

## 4. 單元測試驗證規範
1. **TC-MEN-01（初次突破正常升星）**：當前 ★2 的 SR 教官卡，處理重複後星等變為 ★3，溢出點數為 0。
2. **TC-MEN-02（★4 突破至滿星 ★5）**：當前 ★4 的 SSR 教官卡，處理重複後星等變為 ★5，`isMaxed = true`，溢出點數為 0。
3. **TC-MEN-03（SSR 滿星溢出獲得 500 點）**：當前已為 ★5 的 SSR 教官卡，再次處理重複卡時，星等維持 5，正確回傳獲得 500 點名師積分。

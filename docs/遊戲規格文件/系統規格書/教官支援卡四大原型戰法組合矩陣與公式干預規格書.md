# 教官支援卡四大原型戰法組合矩陣與公式干預規格書

## 1. 核心定位與職責邊界
本規格書定義《三國人生》教官支援卡體系中四大戰略原型（統帥、智謀、武藝、政德）的分類架構、對應戰法組合矩陣與對育成成長公式的精準干預切入點（WBS `FORM-04`，代碼落位於 `MentorSupportSchema.ts`、`MentorTacticAdapter.ts` 與 `TrainingGainFormula.ts`）。
系統依據歷史名將之功業特質，將支援卡劃分為四大專長原型，每類原型針對不同培育公式乘區與戰鬥適性提供專門的增益賦能。

## 3. 戰法靈感組合與戰場來源映射（`MentorTacticAdapter`）

教官卡所攜帶之專屬戰法在培育期滿足觸發視窗（`triggerWindow`）與星等條件後，靈感傳授給學員：

### 3.1 槽位載入與來源標記
學員於畢業或出征時，由教官傳授之技能進入學員之 `awakened` 技能槽位：
```typescript
{
  slotId: "slot-mentor-1",
  tacticId: "tac-eight-diagrams",
  source: "awakened"
}
```

### 3.2 戰鬥調度適配協議（`MentorTacticAdapter`）
戰鬥控制器於組裝部隊技能請求時，`MentorTacticAdapter` 執行嚴格來源校驗：
1. **優先選取 `awakened` 槽**：若未特別指定戰法 ID，適配器自動選取第一個 `source === 'awakened'` 之槽位，**防止一般常規種子戰法覆蓋教官技能**。
2. **來源型別鎖定**：請求結構中的 `sourceType` 強制標記為 **`SkillSourceType.Mentor`**，享有教官靈感戰法專屬的施法特效與演出文案。
3. **血統邊界安全防護**：教官戰法僅作為戰技傳授，**絕不寫入血統因子池（`GeneObject`）**，恪守 `roleBoundary: 'TeachingOnly'` 鐵律。

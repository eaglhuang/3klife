# 教官支援卡被動技能與碎片合成規格書

> **責任邊界**：本檔為培育模式（書院/學府）教官支援卡、被動技能驗證與碎片合成庫的單一真相來源。
> **關聯 WBS**：GCH-11（支援卡被動技能與碎片庫）、GCH-02（抽取與重複卡處理）、MENT-01（教官系統）。
> **整併裁決**：確立培育槽位裝備機制（上限 3 張），重複抽取自動轉化為精魂碎片，定向合成支援卡。

---

## §1. 教官支援卡裝備與定位

教官支援卡（Mentor Support Card）為培育系統核心裝備。學府入學或書院修業前，玩家最多可配置 **3 張支援卡**（1 主位 + 2 輔位）。

| 槽位 | 權重倍率 | 說明 |
|:---|:---:|:---|
| **主教官位 (Main)** | 100% | 完整享受主動策論指導、七日頓悟與專屬戰法傳授。 |
| **客座教官位 1 (Sub 1)** | 50% | 僅提供被動屬性與技能加成，不觸發專屬戰法傳授。 |
| **客座教官位 2 (Sub 2)** | 50% | 僅提供被動屬性與技能加成，不觸發專屬戰法傳授。 |

---

## §2. 五大被動天賦與驗證約束

支援卡被動技能（Passives）在回合開始與策論結算時靜態判定。驗證器必須對數值範圍執行嚴格檢查：

| 被動類型 (`PassiveType`) | 說明與作用階段 | 合法數值範圍 | 典型效果範例 |
|:---|:---|:---:|:---|
| `STAT_TRAIN_BONUS` | 訓練屬性增幅（六色五維） | +3% ~ +25% | 天時/地利/人和訓練單項成長提升 |
| `VITALITY_SAVE` | 策論與修業精力消耗減免 | 5% ~ 30% | 降低體力消耗，延緩疲憊爆發 |
| `EVENT_TRIGGER_RATE` | 奇遇與頓悟事件觸發機率 | +5% ~ +20% | 提升經典清談事件與七日頓悟發生率 |
| `TACTIC_HINT_RATE` | 特系策論手牌抽中權重加權 | +10% ~ +40% | 增加特定天時/地利/人和手牌出現率 |
| `COMBO_CHAIN_EXTEND` | 清談連擊容錯與倍率延伸 | +5% ~ +15% | 彩圈共鳴門檻由 180% 降至 165% |

> **驗證規則**：若被動技能數值超出上述範圍，或 `PassiveType` 不在五大清單內，驗證器直接拒絕載入並拋出 `ValidationError`。

---

## §3. 碎片分解與碎片庫合成機制

為杜絕重複抽取無效化與卡池死胡同，實施「精魂碎片（Mentor Shard）」雙向循環：

### 3.1 重複卡片自動分解

當抽取到玩家已滿星（或重複獲得）的支援卡時，系統於結算時自動分解入庫：

| 卡片稀有度 | 單張分解獲得碎片數 | 備註 |
|:---:|:---:|:---|
| **N** | 1 碎片 | 基礎消耗型 |
| **R** | 5 碎片 | 進階合成素材 |
| **SR** | 20 碎片 | 中堅主力過渡 |
| **SSR** | 100 碎片 | 核心名將教官（如荀彧、郭嘉） |

### 3.2 碎片庫定向合成

玩家可在「名士碎片庫（Mentor Shard Vault）」消耗碎片直接兌換指定支援卡，無購買次數上限：

| 目標卡片稀有度 | 所需碎片數量 | 解鎖條件 |
|:---:|:---:|:---|
| **R 級指定支援卡** | 30 碎片 | 帳號完成新手教學 |
| **SR 級指定支援卡** | 100 碎片 | 通關一次任意學府培育 |
| **SSR 級指定支援卡** | 500 碎片 | 家族名聲達 300 點以上 |

---

## §4. 資料結構與掛載點協議

教官支援卡背包與碎片庫掛載於 `Player_Save.Data` 根路徑下：

```typescript
export interface MentorSupportDataMount {
  /** 擁有的教官支援卡清單 (UID 索引) */
  Mentor_Support_Inventory: Record<string, {
    cardId: string;
    level: number;
    star: number;
    passives: Array<{ type: string; value: number }>;
  }>;
  /** 教官碎片庫通用持有數 */
  Mentor_Shard_Bank: {
    totalShards: number;
    lastSynthesisTimestamp: number;
  };
}
```

> **單一真相來源原則**：教官支援卡僅作用於培育輔助，嚴禁將戰鬥武將本體數值直接注入支援卡。

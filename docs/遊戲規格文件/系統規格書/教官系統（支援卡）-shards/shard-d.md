## K. 師友羈絆系統

> **設計理念**：仿《賽馬娘》的組合事件，鼓勵玩家收集互補的支援卡組合，提升培育多樣性並創造抽卡目標。

### K-1. 羈絆觸發條件

同一場培育中同時放入**指定 2 張支援卡**（羈絆對），且其中一張的**曉蔭情誼** ≥ 一定閾值時，觸發一次性「師友羈絆事件」。

```
// 羈絆觸發判定（每次培育只判定一次，於回合 12 前）
if (session.card_A.template_id ∈ synergy_group.partners &&
    session.card_B.template_id ∈ synergy_group.partners &&
    session.card_A.friendship >= synergy_group.min_friendship):
    trigger_synergy_event(synergy_group.event_id)
```

### K-2. 羈絆效果類型

| 效果 | 說明 |
|---|---|
| 額外靈感率 +20% | 當回合兩張卡的靈感事件觸發率各+20% |
| 額外 TP +30 | 本場培育總 TP +30（一次性） |
| 解鎖隱藏對話 | 觸發兩教官間的特殊對話劇情 |
| 特殊靈感事件 | 只有此羈絆才能觸發的稀有戰法靈感（如「赤壁共謀」） |

### K-3. 預設羈絆對（範例）

| 羈絆名稱 | 卡 A | 卡 B | 觸發效果 |
|---|---|---|---|
| 龍鳳之誼 | SSR 諸葛亮 | SSR 龐統 | 特殊靈感：八陣圖·完整版；對話劇情解鎖 |
| 桃園遺烈 | SSR 關羽 | SSR 張飛 | 額外 TP +50；靈感率 +15% |
| 赤兔共主 | SSR 趙雲 | SSR 呂布 | 靈感率 +25%；隱藏對話 |
| 江東雙璧 | SR 孫策 | SR 周瑜 | 額外 TP +25；江東戰法靈感率 +15% |
| 軍神武聖 | SSR 關羽 | SR 張遼 | 額外 TP +20；靈感率 +10% |

## L. 好友借用教官機制

> **設計理念**：降低無課/小課的培育天花板，讓好友的 SSR 教官在借用期發揮價值，強化社交性。

### L-1. 規則

| 規則 | 說明 |
|---|---|
| 每日借用次數 | 每位玩家每日可借入 **1 張**好友教官 |
| 借用來源 | 好友清單中，好友已設定的「展示教官」槽位 |
| 借用上限 | 同一好友的同一張卡在同一天只能借 1 次 |
| 借用期間鎖定 | 被借入的卡在借用中不影響原主（快照機制複製屬性） |
| 原主限制 | 被借出的卡若原主此時正在使用，不影響借用方（快照獨立） |
| 借用回饋 | 被借出後，原主獲得少量「結義點數」×1 |
| 星等繼承 | 借入卡以**當下星等**生效，不繼承突破後效果 |

### L-2. 借用流程（UI 視角）

```
培育編組頁 → 「+ 好友借用」按鈕 → 好友清單（顯示對方教官名稱+星等） 
  → 選擇一張 → 確認 → 進入培育（借用卡佔第 6 教官槽）
```

> **實作狀態（2026-10-26，PROG-2-1138，PR #931）**
> - 借用改在**入學前**的開始頁「＋ 好友借用」進行；借用卡佔第 6 教官槽，以好友**當下星等**參與培育，會觸發靈感與爆發。
> - 入學成功後才寫借用紀錄（每日 1 張、結義點數照舊）；入學後不再能借用。
> - 只帶借用教官也可以入學。
> - 程式對應：`NpcFriendMentor.friendMentorCard`（組好友教官卡）、`NurtureFlowController.setBorrowedMentor`、`LobbyScene._onClickStartBorrow`。

## M. 溢出轉化系統

> **設計理念**：升星機制回歸純粹——只能靠重複抽到同名支援卡來突破，無碎片庫。滿星（★5）溢出時自動轉化為資源，避免重複卡「白送」的挫敗感，同時提供額外回報誘因（類似《FGO》的龍鱗/聖晶石回饋）。

### M-1. 突破規則

| 操作 | 觸發條件 | 效果 |
|---|---|---|
| 自動突破 | 獲得重複支援卡，Current_Star < 5 | Current_Star +1，播放突破動畫 |
| 溢出轉化 | 獲得重複支援卡，Current_Star == 5（已滿） | 轉化為溢出獎勵（Overflow_Reward） |

> **突破動畫（B5 確認）**：抽到重複卡時直接播放演出動畫（無需玩家選擇），突破完成後顯示新星等與新解鎖效果。

### M-2. 溢出獎勵（Overflow_Reward）

> 滿 ★5 後再抽到同名支援卡，無法繼續突破，改為轉化分配以下獎勵：

| 稀有度 | 溢出獎勵 | 說明 |
|---|---|---|
| SSR | 積分 ×500（點數商店） | 可在點數商店兌換道具/材料 |
| SR | 積分 ×100 | |
| R | 積分 ×20 | |

> 積分商店後續可視收益調整獎勵內容（道具、培育加速令、入學令等）。

### M-3. 溢出觸發流程

```
獲得重複支援卡
  → Current_Star < 5 → 自動突破：Star +1 → 播放突破動畫 → 顯示新解鎖效果
  → Current_Star == 5 → 溢出動畫 → Overflow_Reward 入帳 → Toast：「{CardName} 已滿突破，轉化為積分×{N}」
```

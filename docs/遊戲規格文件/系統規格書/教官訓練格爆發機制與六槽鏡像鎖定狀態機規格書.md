# 教官訓練格爆發機制與六槽鏡像鎖定狀態機規格書

## 1. 模組職責與架構定位
本規格書規範學府培育中的「訓練格教官爆發機制（`SlotBurstEngine`）」與「六槽位教官鏡像快照與鎖定狀態機（`MentorLockLifecycle`）」。該系統確保學員在訓練中獲得隨機爆發驚喜，同時透過快照隔離防護機制，徹底避免外部卡片升星、分解或多處重複佔用引起的數據衝突。

## 2. 訓練格爆發率與增益結算模型

### 2.1 稀有度與星等爆發率公式
每位駐守於訓練格之教官，每回合具備獨立的爆發機率檢定：
- **SSR 稀有度**：基礎爆發率 15%。
- **SR 稀有度**：基礎爆發率 10%。
- **R 稀有度**：基礎爆發率 5%。
- **星等加成**：教官每具備 1 星，爆發率加算 $+1\%$（★5 SSR 達到 $20\%$ 極限爆發率）。

$$\text{SlotBurstRate} = \text{BaseBurstRate}(\text{rarity}) + \text{starLevel} \times 0.01$$

### 2.2 爆發回合成效乘區
當檢定通過（`roll < SlotBurstRate`）時，該訓練格觸發「金色閃光爆發」：
1. **點數加倍**：基礎訓練點數乘以 **1.5 倍**（$\text{Points} \times 1.5$）。
2. **友情加成**：獲得之友情羈絆值加算 $+10\%$。
3. **靈感加成**：當次回合之戰法靈感觸發率額外獲得 $+5\%$ 的加算補正。

```typescript
export interface SlotBurstResult {
  isBurst: boolean;
  pointMultiplier: number;
  friendshipBonusRate: number;
  inspirationBonusRate: number;
}

export function evaluateSlotBurst(rarity: 'SSR' | 'SR' | 'R', star: number, roll: number): SlotBurstResult {
  const baseMap = { SSR: 0.15, SR: 0.10, R: 0.05 };
  const base = baseMap[rarity] || 0.05;
  const burstRate = base + star * 0.01;

  if (roll < burstRate) {
    return {
      isBurst: true,
      pointMultiplier: 1.5,
      friendshipBonusRate: 0.10,
      inspirationBonusRate: 0.05
    };
  }
  return {
    isBurst: false,
    pointMultiplier: 1.0,
    friendshipBonusRate: 0.0,
    inspirationBonusRate: 0.0
  };
}
```

## 3. 六槽位教官快照隔離與鎖定狀態機

### 3.1 入學快照凍結（Snapshot Generation）
學員確認入學時，系統必須鎖定剛好 6 位不重複之教官卡。此時生成不可變快照：
- 複製當前之星等、五維加成與技能特質。
- 培育進行中（36 回合期間），即便玩家在主介面為該教官升星、突破，當前培育會話一律沿用入學快照數值，不發生動態漂移。

### 3.2 併發鎖定防護（Concurrency Guard）
- 入學時，被選定之 6 張教官卡在其主檔標記 `isLockedInTraining = true`。
- 若玩家試圖開啟第二場並行培育（如不同存檔或分身），系統拒絕選取已上鎖教官，拋出 `MENTOR_ALREADY_LOCKED` 異常。
- 當學員完成結業結算（`graduate()`）或確認放棄培育時，原子將 6 張卡片解鎖。

## 4. 單元測試驗證規範
1. **TC-BURST-01（★5 SSR 爆發率 20% 檢驗）**：★5 SSR 教官，burstRate 為 0.20；當 roll 為 0.19 時回傳 `isBurst = true` 且倍率 1.5。
2. **TC-BURST-02（★0 R 爆發率 5% 檢驗）**：★0 R 教官，burstRate 為 0.05；當 roll 為 0.06 時回傳 `isBurst = false`。
3. **TC-LOCK-01（重複入學鎖定攔截）**：教官卡已標記 `isLockedInTraining === true` 時，指派加入新會話立即被拒絕。

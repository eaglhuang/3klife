# 3KLife 敵國王都間諜細作潛伏情報網策反與流言暗殺狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 敵後特勤暗戰與情報網絡系統（`SPY-CELL-NETWORK01`）。勢力可派遣精幹密探潛伏於敵方王都及重鎮，建立地下情報站（酒肆、當鋪、醫館）。透過持續注資維繫密網，執行刺探調兵動向、散布君臣嫌隙流言、收買策反朝廷重臣、以及暗殺投毒等隱蔽作戰，重現「上智為間」之兵法精髓。

```typescript
export enum EspionageMissionType {

export interface EspionageMissionResult {
  missionId: string;

}
```

## 4. 暴露風險推演與暗殺毒殺公式

### 4.1 任務執行暴露機率
情報站發動主動任務時之搜捕檢定：
$$P_{\text{exposed}} = \left(\frac{\text{MissionRiskBase} + \text{TargetSecurity}}{100}\right) \times \left(1.0 - \frac{\text{ChiefDiscretion} \times 0.6 + \text{CoverRating} \times 0.4}{100}\right)$$
- 刺探軍情 $\text{MissionRiskBase} = 15$；散布流言 $= 35$；策反高官 $= 55$；刺殺投毒 $= 80$；
- 敵方主政官為司馬懿、荀彧、賈詡者，搜捕強度 $+30\%$。

### 4.2 投毒行刺致命度公式
$$\text{FatalScore} = \left(\text{ChiefMartial} \times 0.4 + \text{PoisonPotency} \times 0.6\right) - \left(\text{TargetBravery} \times 0.5 + \text{BodyguardQuality} \times 0.5\right)$$
- $\text{FatalScore} \ge 40$：目標當場斃命；
- $10 \le \text{FatalScore} < 40$：目標身中劇毒，重傷殘疾並扣壽 5 年；
- $\text{FatalScore} < 10$：刺殺失敗，刺客當場自裁或被擒。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-SPY-01**：在敵方王都維持經費中斷時，情報站立即停止運作且隱蔽度每回合衰退 15 點，連續 3 回合無資金自動解散。
2. **驗收 CASE-SPY-02**：被捕站長若義理值 $\le 50$，有 $50\%$ 機率轉化為敵國「雙面間諜」，向母國回傳虛假軍情。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

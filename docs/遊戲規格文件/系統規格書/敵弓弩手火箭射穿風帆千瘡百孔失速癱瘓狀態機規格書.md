# 3KLife 敵弓弩手火箭射穿風帆千瘡百孔失速癱瘓狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 水戰遠程戰術打擊與機動力癱瘓系統（`SAIL-SNIPER-DAMAGE01`）。重現三國長江水戰中「射人先射馬，打船先打帆」之精準狙擊戰術：交戰雙方之強弓硬弩手與床弩部隊，專門瞄準敵艦高懸之主帆射擊。箭矢射穿帆布竹篾造成千瘡百孔，風力自無數孔洞中漏散，迫使敵方戰艦逐步喪失氣動推進力並在江心淪為失速靶船。

## 4. 穿孔漏風、推力衰減曲線與攀桅修復公式

### 4.1 穿透孔洞與氣動推力衰減模型
風帆推力受孔洞率之非線性衰減曲線：
$$F_{\text{thrust\_damaged}} = F_{\text{thrust\_intact}} \times \left(1.0 - \frac{\text{CanvasDamagePercent}}{100}\right)^{1.5}$$
- 當帆面穿孔率超過 $50\%$ 時，有效推力已暴跌 $70\%$；
- 穿孔率達 $80\%$ 時，風力穿帆而過發出尖嘯悲鳴，航速清零轉入 `IMMOBILIZED`。

### 4.2 爬桅換帆作業與中箭風險演算法
在戰火中水手攀爬 15 米高桅更換主帆：
$$\text{RepairProgressPerTurn} = \frac{\text{MastSailorsCount} \times 20}{1.0 + \text{IncomingArrowDPS} / 50}$$
- 水手攀桅作業處於敵弓弩手無遮擋射界下，每回合承受 $20\%$ 狙擊中箭墜海傷亡；
- 換上全新備用帆面後，航速瞬間恢復至基準之 $90\%$。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-SAIL-01**：在無風或完全依靠水手划槳推進時，射破風帆不造成航速懲罰，但若轉入迎風搶風航道則立刻暴露失速。
2. **驗收 CASE-SAIL-02**：若遭受火箭命中且穿孔率已超 $40\%$，帆面在 1 回合內必定引燃焚毀，無法進行普通布料縫補修復。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

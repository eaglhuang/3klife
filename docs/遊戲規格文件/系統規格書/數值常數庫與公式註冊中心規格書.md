# 數值常數庫與公式註冊中心規格書

> **文件狀態**：單一真相來源（Single Source of Truth）  
> **系統代碼**：`NUM-04`、`SYS-FORMULA-REGISTRY`  
> **核心職責**：確立全域數值常數集中化架構（NumericalConfig）與公式註冊中心（FormulaRegistry），徹底根除業務邏輯程式碼中散落的 hardcode 常數，支援動態熱更新與安全邊界防護。

---

## 1. 架構原則與單一真相來源

1. **常數集中與資料驅動**：
   - 兵種剋制倍率、適性修正、年齡衰減曲線、精力扣減係數、虎符加成等全數抽離至 `NumericalConfig.json`。
   - 禁止在 TypeScript 類別或模組內部硬編碼任何數值魔術數字（Magic Numbers）。
2. **公式解耦與統一調度**：
   - 所有戰鬥傷害、EP 爆發、壽命計算、生育機率等核心算式一律註冊於 `FormulaRegistry`。
   - 業務模組一律透過註冊中心查詢與執行，享受統一的入參驗證與例外防護。
3. **安全回退與邊界保護（Fail-safe Fallback）**：
   - 當遠端或本機配置遺失某項鍵值時，自動使用安全基準常數（Base Baseline），並向日誌中樞發出警告，不得導致客戶端中斷崩潰。

## 3. 公式註冊中心協定（FormulaRegistry）

### 3.1 核心介面契約
```typescript
export interface FormulaContext {
  [key: string]: any;
}

export interface IFormula<TInput = FormulaContext, TOutput = number> {
  readonly id: string;
  readonly description: string;
  calculate(input: TInput, config: Record<string, any>): TOutput;
}

export class FormulaRegistry {
  private static formulas = new Map<string, IFormula<any, any>>();
  private static configCache: Record<string, any> = {};

  public static register<TInput, TOutput>(formula: IFormula<TInput, TOutput>): void {
    this.formulas.set(formula.id, formula);
  }

  public static loadConfig(config: Record<string, any>): void {
    this.configCache = Object.freeze({ ...config });
  }

  public static execute<TInput, TOutput>(formulaId: string, input: TInput): TOutput {
    const formula = this.formulas.get(formulaId);
    if (!formula) {
      throw new Error(`[FormulaRegistry] Formula ${formulaId} not registered!`);
    }
    return formula.calculate(input, this.configCache);
  }
}
```

## 4. 驗收標準與 CI 閘門（Acceptance Criteria）

1. **單一配置加載驗證**：
   - 啟動階段由 `NumericalConfig.load()` 完成載入，且物件被凍結（`Object.freeze`）防止執行期篡改。
2. **零硬編碼合規**：
   - 核心系統（`FormulaSystem`, `BreedingSystem`, `BattleCombatResolver`）全數改吃 `FormulaRegistry` 或 `NumericalConfig`，無裸露常數。
3. **熱更新支援**：
   - 重新呼叫 `loadConfig` 可動態替換運算係數，單元測試覆蓋配置重載即時生效情境。

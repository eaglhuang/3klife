# 3KLife 斥候改換敵軍軍服偽裝突襲詐開城門狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 特種部隊奇襲與偽裝奪城戰術規格書（`DISGUISE-INFILTRATE-01`）。重現三國歷史中呂蒙「白衣渡江」、關羽「偽作商賈」、鄧艾「裹氈奇襲」等經典特戰滲透範式。精銳斥候營繳獲敵方號衣鎧甲、偽作潰兵或運糧隊詐近城關，騙開門樞後暴起斬關，引導外圍主力騎兵突入。

```typescript
export enum DisguiseDisguiseType {
  ROUTED_SOLDIERS = 'ROUTED_SOLDIERS', // 偽裝敗退潰兵

  cityId: string;

  mainForceInvasionPermitted: boolean; // 是否允許騎兵零阻礙入城
}
```

## 4. 盤查檢定與奪門爆發公式

### 4.1 詐開城門成功率公式
深夜抵達城下時，守門官之破綻辨識檢定：
$$P_{\text{open}} = \left(\text{LeaderDeception} \times 0.4 + \text{UniformQuality} \times 0.3 + \text{PassphraseBonus}\right) \times \left(1.0 - \frac{\text{GateOfficerIntelligence}}{150}\right)$$
- 若掌握當夜真實口令，$\text{PassphraseBonus} = 30$；若口令過期，$\text{PassphraseBonus} = -40$；
- 遭遇風雨晦冥或濃霧天候，辨識難度大幅提升，成功率直接獲得 $+25\%$ 補正。

### 4.2 斬關奪門控制時間計算
詐開城門後，敢死隊必須在千斤閘落下前斬殺守將並卡死閘槽：
$$\text{ControlTurns} = 1 + \left\lfloor \frac{\text{SquadSize} \times \text{LeaderBravery}}{250} \right\rfloor$$
- 在 $\text{ControlTurns}$ 期間，若外圍主力先鋒騎兵未抵達，敢死隊將被全殲且千斤閘閉鎖；
- 若主力及時突入，城防耐久直接減免 $100\%$，直接轉入城內巷戰。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-DISGUISE-01**：在白晝陽光普照且城池警戒值 $\ge 80$ 時發動偽裝突襲，判定直接失敗且遭守城強弩狙殺。
2. **驗收 CASE-DISGUISE-02**：若守城將領具備「洞察」或「神眼」特技，偽裝成功率上限被強制鎖死在 $20\%$ 以下。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

# 日常人物頁視覺可行性邊界與排除常駐特效審查清單規格書

> **所屬模組**：`3.7 UI 介面與視覺工程 (GDV3-08 / GDV3-01)`  
> **單一真相來源**：確立日常人物頁（General Detail Unified Screen）「沉靜典雅古籍水墨、閱讀體驗優先」之視覺邊界，明文排除五大光污染常駐特效，並建立硬性渲染效能審查清單。

---

## 1. 視覺設計哲學與邊界原則

日常人物頁為玩家停留時間最長之核心養成面板，設計哲學恪守**「收斂、克制、典雅」**三大原則：
- **閱讀優先**：數值、技能與血脈資訊必須一眼可辨，背景與立繪不得喧賓奪主。
- **微動態反饋**：僅在按鈕點擊、分頁切換時提供柔和補間，常駐狀態維持低頻微動。
- **低功耗護航**：杜絕任何持續性重型著色器運算，確保千元手機維持 60 FPS 且不發燙。

---

## 2. 五大明文禁止之視覺禁區 (Visual Blacklist)

所有日常人物頁 Layout、Skin 與 Prefab 開發，嚴格受以下禁令約束：

| 禁區代碼 | 違規項目 | 禁令細則與設計初衷 | 正確替代方案 |
|:---:|:---|:---|:---|
| **FB-01** | **常駐全屏血脈虛影** | 禁止在人物身後常駐巨大半透明靈獸（如青龍/白虎），避免立繪與文字重疊干擾。 | 靈獸僅保留為靜態徽記（`crest_face_formal`）；虛影僅限命鏡覺醒瞬間綻放。 |
| **FB-02** | **高頻高亮發光粒子** | 禁止添加持續噴發之 Additive 光點、旋轉光圈或閃爍火花。 | 改用平滑靜態漸層底色（Gradient Tint）或低飽和微光邊框。 |
| **FB-03** | **跑馬燈走馬滾動文字** | 禁止標題或數值欄位採用跑馬燈（Marquee）滾動，避免視覺疲勞。 | 文字超長時以單行省略號（`...`）截斷，點擊開彈窗或抽屜閱覽全文。 |
| **FB-04** | **純白高對比硬切線** | 禁止使用純白（`#FFFFFF`）之粗硬外框，避免現代扁平感破壞水墨沉浸。 | 邊框採用古銅金（`#C5A059`）或玄墨灰（`#2D3748`）並套用九宮毛邊。 |
| **FB-05** | **科幻幾何與 HUD 符號** | 禁止出現科技風掃描線、雷達六角網格、DNA 雙螺旋等不符合漢代背景之元素。 | 採用八卦卦象、竹簡紋樣、雲紋或漢印金石篆刻作為修飾。 |

## 3. 渲染效能硬預算 (Performance Budget)

在 Cocos Creator Profiler 下，日常人物頁面必須通過以下極限測試：
- **DrawCall 總量**：$\le \mathbf{25}$（透過 UI 圖集與共用材質合批達成）。
- **常駐動態節點**：$\le \mathbf{2}$ 個（僅允許主將立繪呼吸微動 0.05 Scale 與名牌極慢金芒）。
- **紋理記憶體佔用 (VRAM)**：$\le \mathbf{35MB}$（大立繪採 1024x1024 RGB24 + ETC2/ASTC 壓縮）。
- **幀率底線**：主流測試機型維持 **60 FPS**（單幀渲染時間 $<16.6\text{ms}$）。

---

## 4. CI 與交付審查檢核清單 (Review Checklist)

每次針對 `general-detail-*.json` 或相關 ChildPanel 進行 PR 提交時，必須逐項核對：
- [ ] 1. 人物頁背景無全屏動態靈獸虛影覆蓋。
- [ ] 2. 粒子系統發射器節點數為 0 或已設為 `playOnAwake: false`。
- [ ] 3. 所有文字標籤（Label）無水平或垂直循環滾動腳本。
- [ ] 4. DrawCall 經實機或 Editor Preview 驗證小於等於 25。
- [ ] 5. 不含任何科幻科技幾何素材。

# 時代更迭60月地圖重組與養成資產保留清單規格書

> **模組識別碼**：`TIME-10`  
> **系統歸屬**：遊戲時間與天下大勢時代更迭（Era_Reset）  
> **單一真相來源**：本規格書確立每 60 個遊戲月（20 季）觸發一次的時代大更迭機制、養成資產永久保留白名單、以及世界地圖動態重組清單之唯一權威標準。

---

## 一、系統概述與架構原則

為了防止遊戲進入中後期形成死局或單一霸權永久固化，遊戲實施「時代更迭（Era Reset）」大輪迴機制。每經過 60 個遊戲月（即 5 年 / 20 季），天下大勢發生巨變，重新洗牌勢力版圖與外交關係，但**100% 永久保留玩家投入心血的養成與家族資產**。

### Unity / 架構對照
- **Roguelite Meta 重組**：類似 Unity 中的大輪迴架構，保留玩家 Meta 資料（武將、血脈、虎符），關卡與地圖 Scene 徹底重建。
- **純狀態事件**：以純事件 DTO `EraResetEvent` 廣播，各子系統獨立響應資產留存與重置。

## 二、觸發週期與判定演算法

```typescript
export const MONTHS_PER_SEASON = 3;            // 1 季固定等於 3 個遊戲月
export const ERA_RESET_INTERVAL_MONTHS = 60;   // 時代更迭週期：60 個月（20 季）
```

### 觸發季判定公式
給定累計推進總季數 `totalSeasonsElapsed > 0`：

$$\text{TotalMonths} = \text{totalSeasonsElapsed} \times 3$$
$$\text{isEraReset} = (\text{TotalMonths} \bmod 60 === 0)$$

```typescript
export function isEraResetSeason(totalSeasonsElapsed: number): boolean {
    if (!Number.isInteger(totalSeasonsElapsed) || totalSeasonsElapsed <= 0) return false;
    return (totalSeasonsElapsed * MONTHS_PER_SEASON) % ERA_RESET_INTERVAL_MONTHS === 0;
}
```
- **更迭節點**：第 20 季（第 5 年末）、第 40 季（第 10 年末）、第 60 季（第 15 年末）以此類推。

## 三、資產保留（Keep）與地圖重置（Reset）清單

```typescript
export interface EraResetEvent {
    eraIndex: number;            // 時代序號（1, 2, 3...）
    atSeason: number;            // 觸發時之累計總季數
    keep: readonly string[];     // 永久保留之資產白名單
    reset: readonly string[];    // 世界沙盤重置項目清單
}

export const ERA_RESET_KEEP: readonly string[] = [
    'descendantStats',           // 子嗣已培育五維屬性與戰法
    'bloodlineFactors',          // 六色家族遺傳血脈因子
    'tigerTallyAndSpiritCards',  // 已獲得之虎符與英靈名將卡
    'unlockedTech',              // 科技樹研發成果
    'playerAchievements',        // 歷史成就與稱號榮譽
];

export const ERA_RESET_RESET: readonly string[] = [
    'territoryOwnership',        // 全地圖城池郡縣歸屬權
    'diplomacy',                 // 各國好感度與同盟/交戰狀態
    'aiNationScale',             // 他國 AI 軍勢規模與資源儲備
];
```

## 四、事件建構演算法

```typescript
export function buildEraResetEvent(totalSeasonsElapsed: number): EraResetEvent | null {
    if (!isEraResetSeason(totalSeasonsElapsed)) return null;
    const months = totalSeasonsElapsed * MONTHS_PER_SEASON;
    return {
        eraIndex: months / ERA_RESET_INTERVAL_MONTHS,
        atSeason: totalSeasonsElapsed,
        keep: ERA_RESET_KEEP,
        reset: ERA_RESET_RESET,
    };
}
```

## 五、驗收條件與測試案例 (Test Cases)

- **TC-TIME-25（第 20 季精確觸發）**：
  - 輸入 `totalSeasonsElapsed = 20`（60 個月），`isEraResetSeason` 回傳 `true`，`eraIndex` 為 1。
- **TC-TIME-26（非更迭季安全回退）**：
  - 輸入 `totalSeasonsElapsed = 19` 或 21，`isEraResetSeason` 回傳 `false`，`buildEraResetEvent` 回傳 `null`。
- **TC-TIME-27（開局第 0 季不觸發）**：
  - 輸入 `totalSeasonsElapsed = 0`，回傳 `false`。
- **TC-TIME-28（雙白名單完整性）**：
  - 驗證 `keep` 清單包含子嗣屬性、因子、虎符、科技與成就 5 大項；`reset` 清單包含城池、外交與 AI 規模。

# 森林埋伏與夜襲奇襲戰場環境專屬規則規格書

## 1. 核心定位與場景契約

本規格書為森林埋伏（`AmbushAttack`）與夜襲奇襲（`NightRaid`）兩大特殊隱蔽戰術環境（代號 `SCN-06`）的單一真相來源（Single Source of Truth）。涵蓋前 2 回合部隊隱匿、地格陷阱定身觸發、夜間能見度視野限制與營帳佔領速勝機制。

```typescript
export interface CovertTacticsContract {
  tactics: [BattleTactic.AmbushAttack, BattleTactic.NightRaid];
  stealthTurns: 2;                // 伏兵前 2 回合隱蔽
  nightSightReduction: 1;         // 夜間遠程視野縮短 1 格
  campCaptureInstantWin: true;    // 佔領營帳即時獲勝
}
```

## 2. 森林埋伏專屬規則體系（Ambush Attack）

### 2.1 前兩回合伏兵隱匿（TSTEALTH Protocol）

1. **索敵忽略機制**：
   - 戰鬥開局（回合 1~2），我方配置於叢林地格（`Stealth_Bush`）之部隊附加 `Stealth` 隱匿狀態。
   - 敵方 AI 索敵流水線（`TargetSelector`）**強制將隱匿部隊自敵方候選陣列中剔除**，優先索敵未隱匿部隊。
2. **破隱條件**：
   - 若我方部隊主動發動普通攻擊或戰法，立即解除隱匿狀態。
   - 戰鬥推進至第 3 回合初，全軍隱身自然解除，恢復正常可索敵狀態。

### 2.2 叢林陷阱定身與傷害（Ambush Trap Clusters）

1. **陷阱佈設**：棋盤隨機分佈 2~4 處陷阱叢（`Trap_Cluster`）。
2. **踩中觸發結算**：
   - 當敵軍部隊移入陷阱地格時，立即觸發 `AMBUSH_TRAP_TILE_NOTE`。
   - 扣除固定兵力傷害：$D_{\text{trap}} = 100$ 點。
   - 附加 `StatusEffect.Root` 定身狀態 1 回合（該單位次回合移動力歸零，無法位移）。
   - 陷阱地格於觸發後轉為 `normal` 常態格，並回寫戰報 `triggeredAmbushTraps += 1`。

## 3. 夜襲奇襲專屬規則體系（Night Raid）

### 3.1 視線阻絕與夜戰數值修正

1. **視野縮短約束**：
   - 前 2 回合夜幕籠罩，敵方弓兵與投石器械之最大攻擊射程（`attackRange`）強制減 1 格（$\text{Range}_{\text{night}} = \max(1, \text{Range}_{\text{base}} - 1)$）。
2. **命中與暴擊環境修正**：
   - **我方奇襲增益**：全場享有暴擊率 $+20\%$ 加成（配合夜間混亂直擊要害）。
   - **敵軍混亂減益**：敵軍部隊在夜幕中命中率全域下降 $25\%$（失手率大增）。

### 3.2 敵陣營帳突襲佔領（Camp Infiltration）

1. **營帳座標配置**：敵方底線（Depth 6 或 7）配置敵軍大營（`Camp_Target`）。
2. **佔領速勝裁定**：
   - 只要我方任意部隊突破先鋒陣線，成功站上敵軍大營地格並維持至回合結束。
   - 系統立即裁定戰役勝利（`Decisive Victory`），豁免全殲敵軍殘餘部隊之要求。

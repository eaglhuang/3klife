# 極端天候遠程射程衰減與命中折減模型規格書

<!-- doc_id: doc_spec_0609 -->

> 本規格書依據 WBS `APT-08`（天氣對命中/射程影響：雨-20%、霧-30%、風射程-2、夜-25%）制定，為戰場天候環境影響遠程打擊之單一真相來源（Single Source of Truth）。
> 核心約束：無副作用純邏輯架構、六大天候打擊修正矩陣、射程保底不低於 1 格、命中率硬上下限約束（50%~100%）、全繁體中文台灣慣用術語。

## 1. 業務定位與天候影響矩陣

三國古代戰場中，風雨霧雪與黑夜對弓箭手、連弩營與攻城投石機之視距與彈道產生嚴格物理干擾。本模型規範各類天候下遠程攻擊之最大射程衰減與命中率折減係數。

| 天候類型代碼 | 天候名稱 | 射程修正 ($\Delta R$) | 命中率修正 ($\Delta Acc$) | 特殊彈道規則 |
|---|---|:---:|:---:|---|
| `CLEAR` | 晴朗萬里 | $+0$ | $+0\%$ | 基準常規射程與命中 |
| `RAIN` | 暴雨傾盆 | $+0$ | $-20\%$ | 弓弦受潮、箭羽沾水偏墜 |
| `FOG` | 濃霧迷漫 | $-1$ | $-30\%$ | 視野受限、超過 2 格需盲射 |
| `WIND` | 狂風呼嘯 | $-2$ | $-10\%$ | 強烈側風擾動，彈道大幅偏移 |
| `NIGHT` | 暗夜月蝕 | $-1$ | $-25\%$ | 夜間視野阻斷、火把暴露目標 |
| `SNOW` | 寒冬風雪 | $-1$ | $-20\%$ | 凍手遲緩、積雪折射視線 |

## 2. 數值精算公式與邊界保護

### 2.1 射程計算公式
設武將／兵種基礎最大射程為 $R_{\text{base}}$：

$$R_{\text{final}} = \max(1, R_{\text{base}} + \Delta R)$$

> **射程下限約束**：無論天候多端惡劣，遠程單位之最終射程 $R_{\text{final}}$ 嚴格保底為 $1$ 格（近身平射），不可降為 0 或負數。

### 2.2 命中率計算公式
設攻擊方基礎命中率為 $Acc_{\text{base}}$，受天候修正後：

$$Acc_{\text{raw}} = Acc_{\text{base}} + \Delta Acc$$
$$Acc_{\text{final}} = \min(1.00, \max(0.50, Acc_{\text{raw}}))$$

> **命中保底與天花板**：命中率在常規天候結算後，受硬邊界保護：最低命中率保底 $50\%$，最高命中天花板鎖定 $100\%$。

## 3. 資料結構與純邏輯介面

```typescript
export type WeatherType = 'CLEAR' | 'RAIN' | 'FOG' | 'WIND' | 'NIGHT' | 'SNOW';

export interface IWeatherCombatModifier {
    readonly rangeDelta: number;
    readonly accuracyDelta: number;
}

export const WEATHER_COMBAT_MODIFIERS: Readonly<Record<WeatherType, IWeatherCombatModifier>> = {
    CLEAR: { rangeDelta: 0, accuracyDelta: 0.00 },
    RAIN:  { rangeDelta: 0, accuracyDelta: -0.20 },
    FOG:   { rangeDelta: -1, accuracyDelta: -0.30 },
    WIND:  { rangeDelta: -2, accuracyDelta: -0.10 },
    NIGHT: { rangeDelta: -1, accuracyDelta: -0.25 },
    SNOW:  { rangeDelta: -1, accuracyDelta: -0.20 },
};

export interface IRangedCombatStats {
    readonly finalRange: number;
    readonly finalAccuracy: number;
    readonly isRangeReduced: boolean;
}

export function resolveWeatherRangedCombat(
    baseRange: number,
    baseAccuracy: number,
    weather: WeatherType
): IRangedCombatStats {
    const mod = WEATHER_COMBAT_MODIFIERS[weather] ?? WEATHER_COMBAT_MODIFIERS.CLEAR;
    
    // 射程計算：保底 1 格
    const finalRange = Math.max(1, baseRange + mod.rangeDelta);
    
    // 命中計算：保底 50%，天花板 100%
    const rawAccuracy = baseAccuracy + mod.accuracyDelta;
    const finalAccuracy = Math.min(1.00, Math.max(0.50, rawAccuracy));

    return {
        finalRange,
        finalAccuracy,
        isRangeReduced: mod.rangeDelta < 0,
    };
}
```

# 3KLife 樹林懸掛羊皮戰鼓羊蹄踢鼓虛張夜襲聲東擊西狀態機規格書

## 1. 系統定位與設計意圖

在三國經典謀略與心理戰術（如三國演義「懸羊擊鼓，餓馬提鈴」）中，主力部隊需要隱蔽轉移或聲東擊西時，常借助動物與器械發出擬真行軍噪聲。本系統規範偽裝詐術工程「懸羊擊鼓夜間疑兵裝置（Suspended Goat Drum Feint）」之動物掙扎頻率、夜戰音訊擬態、敵軍警戒疲勞與暗度陳倉狀態機：
- **倒懸掙扎踢鼓機制**：將成年山羊倒吊於林中枝枒，羊蹄下方精確架設雙面牛皮戰鼓，山羊因倒懸懸空恐慌而不停蹬腿，踢擊鼓面形成節律緊湊的戰鼓聲。
- **樹梢火把虛張聲勢**：林木間隔插設草人與數十支松脂火炬，隨夜風搖曳，營造大軍主力深夜集結、即將發動夜襲之視覺假象。
- **全營警戒與戰術轉移**：誘使敵軍主力連夜全副武裝進入壕溝戒備，消耗其士兵體力與精神，我方主力則悄然撤出或直插敵軍空虛要害。

## 2. 狀態機架構與轉換生命週期

懸羊擊鼓狀態機（代碼：`GOAT-DRUM-NOISE-FEINT01`）管理從設疑部署至詐術揭穿之完整週期：

```
[ APPARATUS_RIGGING ] (樹梢固定繩索與戰鼓高度精確校準)
          │
          ▼
[ SUSPENSION_RELEASE ] (倒吊山羊開始掙扎蹬腿連續擊鼓)
          │
          ├── 敵哨探聽聞鼓聲 ──> [ SOUND_PERCEPTION_ALERT ]
          ▼
[ NIGHT_CAMP_ALARM ] (敵全營吹響號角進入一級夜襲戒備)
          │
          ├── 敵軍盲目放箭壓制 ──> [ ARROW_DEPLETION_COUNTER ]
          ▼
[ SUSTAINED_FATIGUE_EXHAUSTION ] (敵軍整夜披甲持戈體力精神劇降)
          │
          ├── 破曉日光照射 ──> [ VISUAL_ILLUSION_DISPERSE ]
          ▼
[ FEINT_REVEALED_FALLBACK ] (敵軍發現虛設羊鼓，而我方主力已遠遁)
```

### 狀態細部定義

1. **APPARATUS_RIGGING（架設校準）**：
   - 斥候於密林邊緣選擇粗壯榆樹，以麻繩吊掛牛皮戰鼓，羊蹄距鼓面約 4 寸，確保每一下掙扎皆能重擊鼓面。
2. **SUSPENSION_RELEASE（啟動擊鼓）**：
   - 山羊倒懸後每分鐘蹬腿 45 至 60 次，雙蹄交替敲擊鼓面，發出如同三通鼓點般密集聲響，可維持 2 至 3 個時辰。
3. **NIGHT_CAMP_ALARM（誘敵驚營）**：
   - 敵軍夜巡官將鼓聲判斷為主力夜襲前奏，全軍金鼓大作，將士皆披掛甲冑進駐營寨前線，弓弩手朝林中漫無目的傾瀉羽箭。
4. **ARROW_DEPLETION_COUNTER（消耗箭矢）**：
   - 敵軍盲射徒然浪費 3000 至 5000 支軍用箭矢，林中樹木與草人反向收集箭鏃（草船借箭之變體效應）。
5. **SUSTAINED_FATIGUE_EXHAUSTION（熬夜疲勞）**：
   - 敵全軍整夜處於高度緊繃應激狀態，每小時體力值（Stamina）扣減 15%，士氣精神衰退 20%。
6. **FEINT_REVEALED_FALLBACK（真相大白）**：
   - 天明霧散後敵軍派遣先鋒入林，方知中計，此時全營疲憊不堪，遭遇我方以逸待勞之反擊時潰不成軍。

## 3. 關鍵數值與計算判定公式

### 3.1 詐術迷惑判定機率公式

敵軍主帥誤判為實兵夜襲之成功率 $P_{feint}$：
$$P_{feint} = \text{clamp01}\left(0.40 + \frac{\text{Tactics}_{strat} - \text{Int}_{enemy}}{100} + \text{NightMod} - \text{Suspicion}_{factor}\right)$$
- $\text{Tactics}_{strat}$：施計謀士之謀略智力值（如荀攸、徐庶）。
- $\text{Int}_{enemy}$：敵方主將智力值（若敵將多疑如曹操，誤判率反而提升 0.15）。
- $\text{NightMod}$：夜深漆黑環境增益（無月黑夜為 0.25）。
- $\text{Suspicion}_{factor}$：敵軍若派敢死斥候摸入林中探查，每組探哨扣減 0.35。

### 3.2 敵軍次日行軍戰力折減模型

整夜驚營後敵部隊次日戰鬥效率 $\eta_{fatigue}$：
$$\eta_{fatigue} = \max\left(0.50, 1.0 - 0.08 \times T_{alarm\_hours}\right)$$
- 若連續受驚 4 個時辰，$T_{alarm\_hours} = 4$，次日部隊命中率、格擋率與移動速度全面下調至原本之 68%。

## 4. 戰術連鎖與攻防克制

1. **暗度陳倉戰術掩護**：為我方主力秘密迂迴渡河或抄襲敵後糧倉爭取 6 個小時無干擾窗口期。
2. **反制與識破手段**：
   - **放火燒林破計**：果決之將領直接以投石機拋擲猛火油罈焚燒整片疑兵樹林，瞬間瓦解羊鼓裝置。
   - **音律辨識**：精通音律戰術之名將（如周瑜）可透過鼓聲節奏雜亂無統帥旗語暗號，判定為牲畜盲踢。

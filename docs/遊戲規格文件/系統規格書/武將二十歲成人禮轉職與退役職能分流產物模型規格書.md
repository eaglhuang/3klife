# 武將二十歲成人禮轉職與退役職能分流產物模型規格書

## 1. 模組職責與架構定位
本規格書規範武將在年滿 20 歲時的「弱冠禮副職追加狀態機（`JobChange`）」與壽終退役時的「職能分流產物轉化模型（`RetirementDistribution`）」。系統支援職能多樣化發展，並對副職收益施加平衡折減，在退役時原子生成門閥宗族專屬產物。

```
┌─────────────────────────────────────────────────────────────┐
│                 Job Change & Retirement Loops               │
├──────────────────────────────┬──────────────────────────────┤
│ 20 歲成人弱冠禮追加副職      │ 65 歲退役職能分流結算        │
│ 消耗轉職令 / 副職效益 × 0.60 │ 武職→虎符 / 文職→竹簡 / 雙職  │
└──────────────────────────────┴──────────────────────────────┘
```

## 2. 弱冠禮副職追加狀態機

### 2.1 轉職前置條件審查
武將年滿 20 歲時觸發成人禮事件，玩家可選擇維持單一職能或開啟副職：
1. **年齡門檻**：武將當前年齡 $\ge 20$ 歲。
2. **道具消耗**：消耗宗族寶庫中 **1 枚「轉職令（`JOB_CHANGE_TOKEN`）」**。
3. **互斥防呆規則**：所選之副職能代碼不得與其原始主職能相同（$\text{SubClass} \neq \text{PrimaryClass}$）。
4. **單一副職上限**：每位武將一生僅允許綁定 1 項副職能，已擁有副職者不得覆蓋。

### 2.2 副職能力折減精算模型
為維護職業專精度與天平平衡，副職能所附帶的所有數值加成、內政效率與被動戰法威力，統一施加 **$60\%$ 折減係數（$0.60\times$）**：
$$\text{EffectiveBonus} = \left\lfloor \text{BaseBonus} \times 0.60 \right\rfloor$$

```typescript
export type GeneralClassType = 'WARRIOR' | 'COMMANDER' | 'STRATEGIST' | 'GOVERNOR' | 'MERCHANT';

export interface JobChangeResult {
  success: boolean;
  assignedSubClass: GeneralClassType | null;
  effectiveRate: number; // 0.60
  errorCode?: 'TOO_YOUNG' | 'DUPLICATE_CLASS' | 'ALREADY_HAS_SUBCLASS' | 'NO_TOKEN';
}

export function performJobChange(
  age: number,
  primaryClass: GeneralClassType,
  subClassChoice: GeneralClassType,
  currentSubClass: GeneralClassType | null,
  tokenCount: number
): JobChangeResult {
  if (age < 20) return { success: false, assignedSubClass: null, effectiveRate: 0, errorCode: 'TOO_YOUNG' };
  if (currentSubClass !== null) return { success: false, assignedSubClass: null, effectiveRate: 0, errorCode: 'ALREADY_HAS_SUBCLASS' };
  if (primaryClass === subClassChoice) return { success: false, assignedSubClass: null, effectiveRate: 0, errorCode: 'DUPLICATE_CLASS' };
  if (tokenCount < 1) return { success: false, assignedSubClass: null, effectiveRate: 0, errorCode: 'NO_TOKEN' };

  return { success: true, assignedSubClass: subClassChoice, effectiveRate: 0.60 };
}
```

## 3. 退役職能分流產物轉化模型

當武將年滿 65 歲卸甲歸田時，系統根據其一生修為職能核發宗族資產：

| 職能屬性類型 | 判定標準 | 產出實體文物 | 產出支援教官卡 |
| :---: | :---: | :---: | :---: |
| **武職系統** | 主職為 WARRIOR / COMMANDER 且無文職副職 | 精金虎符（軍備鍛造材料） | 武道教官卡（擅長兵種/戰法） |
| **文職系統** | 主職為 STRATEGIST / GOVERNOR / MERCHANT 且無武職副職 | 七賢竹簡（經世治國典籍） | 儒道教官卡（擅長策論/政務） |
| **雙職雙修** | 兼備文武雙職能（例如 COMMANDER + STRATEGIST） | 雙份文物（虎符 ＋ 竹簡） | 全能教官卡（雙系加成） |

```typescript
export interface RetirementArtifacts {
  hasTigerTally: boolean;
  hasBambooScroll: boolean;
  mentorCardStyle: 'MARTIAL' | 'SCHOLAR' | 'ALL_ROUND';
}

export function resolveRetirementArtifacts(
  primary: GeneralClassType,
  sub: GeneralClassType | null
): RetirementArtifacts {
  const isMartial = (c: GeneralClassType) => c === 'WARRIOR' || c === 'COMMANDER';
  const hasMartial = isMartial(primary) || (sub !== null && isMartial(sub));
  const hasScholar = !isMartial(primary) || (sub !== null && !isMartial(sub));

  if (hasMartial && hasScholar) {
    return { hasTigerTally: true, hasBambooScroll: true, mentorCardStyle: 'ALL_ROUND' };
  }
  if (hasMartial) {
    return { hasTigerTally: true, hasBambooScroll: false, mentorCardStyle: 'MARTIAL' };
  }
  return { hasTigerTally: false, hasBambooScroll: true, mentorCardStyle: 'SCHOLAR' };
}
```

## 4. 單元測試驗證規範
1. **TC-JOB-01（未滿 20 歲轉職阻斷）**：19 歲武將請求轉職，回傳 `TOO_YOUNG` 錯誤。
2. **TC-JOB-02（主副職同名拒絕）**：主職為 WARRIOR，選擇副職亦為 WARRIOR，回傳 `DUPLICATE_CLASS`。
3. **TC-RET-01（雙職能雙份產出檢驗）**：主職 COMMANDER（武）、副職 STRATEGIST（文），退役時虎符與竹簡均為 `true`，教官風格為 `ALL_ROUND`。

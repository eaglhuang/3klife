# 武將人物介面規格書 2.0

> **版本**：2.0  
> **最後整理**：2026-04-29  
> **定位**：本文件是 `GeneralDetailComposite` 與武將人物頁 UI 的唯一母規格。舊版補遺、五頁版分工、`寶` 頁混放英靈卡 / 虎符、武將 Level / EXP / 本體突破等說法皆以本 2.0 版為準。

---

## 0. 最新裁定

1. 武將本體沒有傳統 `Level / EXP / 武將突破`。
2. 人物頁固定為六個 top-level tab：`將 / 屬 / 命 / 技 / 寶 / 兵`。
3. 內部 route key 固定為：`Overview / Stats / Bloodline / Tactics / Equip / Aptitude`。
4. `命 / Bloodline` 頁承接完整血脈畫面、英靈卡、命紋靈獸、五階血脈傳承奧義與可抽拉故事條。
5. `寶 / Equip` 頁只承接一般裝備、傳家寶與道具。
6. `兵 / Aptitude` 頁承接兵種、地形、天氣適性、戰鬥定位與虎符裝備操作。
7. `升星` 只開血脈奧義階段上限；`覺醒` 才點亮階段內容。
8. 史實名將升星吃同模板轉蛋卡；子孫武將升星吃同家族卡轉化出的 `譜牒印記 / Lineage_Seal`。
9. 覺醒主來源是 `名聲`，符合命紋靈獸傾向的戰績 / 事件給額外進度。

---

## 1. 設計目標

武將人物頁要讓玩家快速理解一名武將的四件事：

1. 他是誰，處於什麼生命階段。
2. 他強在哪，適合怎麼養。
3. 他的血脈來自哪裡，未來能覺醒什麼。
4. 他現在裝了什麼，能帶什麼兵，能上什麼戰場。

Unity 對照：這相當於一個 `Character Detail Prefab`，由多個 child panel 組成。Cocos 中以 `CompositePanel + JSON Layout + Data Read Model` 驅動，不手動散建節點。

---

## 2. 六頁分工

| Tab | Route key | 主責任 | 不承接 |
|---|---|---|---|
| 將 | `Overview` | 基本身份、生命 / 天命週期、史實名將升星入口、名聲、官職、統領軍勢 | 完整血統圖、裝備、虎符 |
| 屬 | `Stats` | 六色屬性、能力評語、培訓操作評價、六位養成教官群 | 戰法列表、虎符 |
| 命 | `Bloodline` | 14 人祖先血統圖、隱藏立繪、血脈傳承奧義、特殊傳承因子、出生爆發力、血脈覺醒進度、世家入口、英靈卡操作、故事條 | 一般裝備、虎符 |
| 技 | `Tactics` | 戰法列表與習得狀態：已習得 / 可習得 / 未解鎖 | 兵種 / 地形 / 天氣適性 |
| 寶 | `Equip` | 一般裝備、傳家寶、道具、裝備評價 | 英靈卡、虎符、Level / EXP |
| 兵 | `Aptitude` | 兵種、地形、天氣適性、戰鬥定位、虎符裝備操作 | 一般裝備、英靈卡 |

## 3. 外層結構

```text
GeneralDetailComposite
├─ Header
│  ├─ 武將名稱 / 稱號 / 陣營 / 稀有度
│  ├─ 狀態：Active / Training / Retired / Dead
│  └─ 返回 / 收藏 / 比較
├─ Summary Strip
│  ├─ HP / SP / 精力
│  ├─ EP / Prowess 摘要
│  └─ 當前 tab 的 1~2 個重點提示
├─ Tab Rail
│  └─ 將 / 屬 / 命 / 技 / 寶 / 兵
└─ Tab Content Host
   └─ 依 route key 載入 child panel
```

手機版可把 `Tab Rail` 改成右側圓形 rail 或底部 tab bar，但 tab 順序與 route key 不可改。

---

## 4. 將頁：Overview

### 顯示內容

1. 角色主立繪。
2. 姓名、稱號、陣營、身份、狀態。
3. 生命 / 天命週期：年齡、精力、壽命提示、退役 / 死亡狀態。
4. 名聲與官職：`General_Fame`、`General_Rank`、下一階官職條件。
5. 統領軍勢：`Command_Capacity`、可用城市兵源、預估出征軍勢。
6. 史實名將升星入口：只在可升星角色上顯示。
7. 故事入口：只顯示首格摘要或 `前往命頁故事條`，完整故事條不放在本頁。

### UI 規則

1. `升星` 不得成為所有武將固定按鈕。
2. 子嗣與一般隨機武將若沒有 `Lineage_Seal` 規則，不顯示升星。
3. `預估出征軍勢 = min(武將帶兵上限, 城市可用兵源, 關卡出征上限)`。

---

## 5. 屬頁：Stats

### 顯示內容

1. 六色屬性：`STR / INT / LEA / POL / CHA / LUK`。
2. 雙層數值：`Talent 0~100` 與 `Prowess 0~2000+`。
3. 能力評語：一句話定位，例如 `武力型 / 謀略型 / 統率型`。
4. 培訓操作評價：例如 `訓練反應快 / 壓力耐受高 / 易偏科`。
5. 六位養成教官群：教官名、擅長屬性、目前對該武將的評價影響。

### UI 規則

1. `Talent` 是成長上限層，`Prowess` 是培育定型 / 戰場定型實力層。
2. 不可把 `Talent` 直接放大當成戰力。
3. 未揭露欄位使用 `HIDDEN / TENDENCY / RANGE / EXACT` 四階狀態。

---

## 6. 命頁：Bloodline

`命` 頁是本 2.0 規格的重點頁。它不是一張雜物卡，而是一個血脈工作台：左側看血統來源，右側看血脈人格與奧義成長，底部看故事條。

### 6.1 桌面版配置

```text
BloodlineTabContent
├─ Top Context Bar（高度 44~56）
│  ├─ 血脈名 / 家族名
│  ├─ EP / 出生爆發力
│  └─ 世家入口 / 英靈卡狀態
├─ Main Bloodline Stage（扣除 StoryDock 後剩餘高度）
│  ├─ Left Bloodline Field（約 52% 寬）
│  │  ├─ Hidden Portrait Layer（左半面隱藏立繪）
│  │  ├─ 14 Ancestor Tree Overlay
│  │  └─ Ancestor Node Detail Peek
│  └─ Right Destiny Panel（約 48% 寬）
│     ├─ Bloodline Summary Card
│     ├─ Bloodline Beast Card
│     ├─ Bloodline Ultimate 5-Stage Track
│     ├─ Special Lineage Factors
│     ├─ Awakening Progress Card
│     └─ Spirit Slot Card
└─ StoryDock（底部 8%~22% 高，可抽拉）
```

### 6.2 左半區：隱藏立繪與 14 人祖先血統圖

1. `Hidden Portrait Layer` 放在左半區後景，使用半透明、墨暈或暗面處理。
2. 14 人祖先圖放在前景，不可被立繪遮斷。
3. 祖先節點分三代：父母、祖父母、曾祖輩。
4. 點擊祖先節點只開小型 detail peek，不跳走主畫面。
5. 若資料未揭露，祖先節點顯示鎖、問號、血脈傾向，不顯示假資料。

### 6.3 右半區：血脈資訊欄

右半區固定由上到下放六塊，順序不可亂：

1. `血脈摘要`：家族名、血源 ID、近親警告、歸宗狀態。
2. `命紋靈獸`：靈獸徽記、原型、人格標籤、覺醒傾向。
3. `血脈傳承奧義`：五階軌道，顯示目前星階上限、已覺醒階、下一階需求。
4. `特殊傳承因子`：顯示來源祖先、因子顏色、星級、是否已覺醒。
5. `出生爆發力與覺醒進度`：EP、Birth Burst、Awakening Progress。
6. `英靈卡操作`：命槽、主卡 / 副卡、插入、更換、卸下、設為主卡、查看詳情。

### 6.4 StoryDock

1. `StoryDock` 固定在 `命` 頁底部。
2. 支援三態：`COLLAPSED / HALF / EXPANDED`。
3. `COLLAPSED` 只露出標題、拖拉把手與第一格預覽。
4. `HALF` 顯示 3 格故事。
5. `EXPANDED` 顯示 5~6 格完整故事條。
6. 展開時必須透過 layout reflow 或 split resize 讓主血統區縮放。
7. 不可用 overlay 直接蓋住 14 人血統圖。
8. 故事條節奏固定為：歷史人生、命運轉折、血脈暗示、祖靈牽引、未來伏筆。

### 6.5 命紋靈獸與血脈奧義

命紋靈獸是深層人格區的核心，不是裝飾圖示。每個靈獸要綁定：

1. `Bloodline_Beast`：靈獸名稱。
2. `Beast_Archetype`：龍 / 虎 / 鶴 / 玄龜 / 狼 / 麒麟等原型。
3. `Bloodline_Persona_Tags`：2~3 個人格標籤。
4. `Awakening_Tendency`：容易推進覺醒的事蹟類型。
5. `Bloodline_Transmission_Ultimate`：五階能力樹。

### 6.6 五階血脈傳承奧義

| 階段 | 上限條件 | 點亮條件 | UI 顯示 |
|---|---|---|---|
| 1 | 初始 | 初始開放 | 已覺醒 |
| 2 | 2 星 | 名聲 100 + 1 次對應事蹟 | 可覺醒 / 未滿足 |
| 3 | 3 星 | 名聲 300 + 2 次對應事蹟 | 可覺醒 / 未滿足 |
| 4 | 4 星 | 名聲 700 + 3 次對應事蹟 | 可覺醒 / 未滿足 |
| 5 | 5 星 | 名聲 1500 + 1 次史詩事蹟 | 真名奧義 |

玩家理解口訣：`升星開上限，名聲與事蹟點亮內容`。

### 6.7 升星、覺醒、名聲的分工

1. `升星` 只提高 `Stage_Cap`。
2. `覺醒` 只提高 `Stage_Current` 或點亮某階效果。
3. `名聲` 是覺醒進度主來源。
4. 符合靈獸傾向的戰績 / 事件給額外進度。
5. 史實名將升星吃同模板轉蛋卡。
6. 子孫武將升星吃 `Lineage_Seal`，來源是同家族卡 duplicate 或家族傳承路徑。

## 7. 技頁：Tactics

### 顯示內容

1. 主戰法。
2. 已習得戰法列表。
3. 可習得戰法列表。
4. 未解鎖戰法列表。
5. 戰法等級、TP 消耗、類型、簡述。

### 三態規則

| 狀態 | 顯示方式 |
|---|---|
| 已習得 | 彩色，可點擊詳情 |
| 可習得 | 半透明，顯示需求與來源 |
| 未解鎖 | 灰階，顯示鎖定理由 |

兵種、地形與天氣適性不放在本頁，統一放到 `兵 / Aptitude`。

---

## 8. 寶頁：Equip

### 顯示內容

1. 一般裝備 2x3：`WEAPON / HEAD / BODY / BOOTS / ACCESSORY_A / ACCESSORY_B`。
2. 傳家寶欄。
3. 道具摘要。
4. 裝備評價與上下文操作。

### 禁止內容

1. 不顯示英靈卡槽。
2. 不顯示虎符槽。
3. 不顯示 Level / EXP。
4. 不顯示武將本體突破。

---

## 9. 兵頁：Aptitude

### 顯示內容

1. 兵種適性：騎 / 步 / 弓 / 機械 / 水軍等。
2. 地形適性：平原 / 山地 / 水域 / 林地 / 沙漠 / 城池。
3. 天氣適性：晴 / 雨 / 霧 / 風 / 夜 / 雷。
4. 戰鬥定位：先鋒、側翼、守城、控場、支援等。
5. 虎符槽：裝備、替換、卸下、查看詳情。
6. 虎符摘要：兵種、品質、星級、投入兵力、糧耗、`TigerTallyScore`。

## 12. 狀態與鎖定

| 狀態 | UI 表現 |
|---|---|
| `HIDDEN` | 問號或鎖，不顯示數值 |
| `TENDENCY` | 顯示傾向，不顯示精確值 |
| `RANGE` | 顯示區間或高低段 |
| `EXACT` | 完整顯示 |
| `BATTLE_LOCKED` | 戰鬥中不可更換英靈卡或虎符 |
| `NO_DATA` | 顯示空狀態，不填假資料 |

---

## 13. 過時規則

以下規則已廢止：

1. `將 / 屬 / 技 / 命 / 寶` 五頁版。
2. `技` 頁吸收兵種 / 地形 / 天氣適性。
3. `寶` 頁顯示英靈卡槽或虎符槽。
4. 武將本體 `Level / EXP / 突破`。
5. 完整故事條固定放在 `將` 頁。
6. 只靠抽卡就點亮血脈奧義。
7. 只靠名聲就突破星階上限。

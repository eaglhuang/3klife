# 武將介紹古文白話吐槽規格書

> **規格代碼**：`GEN-QUIP-01`　**任務卡**：PROG-2-10146　**裁決來源**：使用者 2026-11-27 本人裁決
> **狀態**：正式定案　**依賴**：遊戲定調與世界觀（輕鬆笑話、可引時事、不悲劇）

## 1. 規則

武將介紹（人物頁總覽「人物小傳」）顯示的古文段落（`historicalAnecdote`）保留不動，後面接一句現代口語白話吐槽，像翻譯又像吐槽。輕鬆笑話、可引時事、不悲劇、不酸辱。

## 2. 資料

- `generals.json` 每位武將新增 `historicalQuip`（zh-TW 原文，不覆蓋古文）。
- i18n 鍵 `ui.general.quip.<武將id>`，目前只有 zh-TW；顯示時 i18n 優先，查不到用 `historicalQuip`，兩者皆無則隱藏吐槽列。其他語系待補。
- 文案規則：每人逐一撰寫並抓該武將特色，不可同句換名；每句約 18～40 字；女將依性別用妾身／本宮／本姑娘／人家等語氣。
- 新增武將時必須同步補 `historicalQuip` 與 zh-TW 鍵。

## 3. UI

人物頁總覽「人物小傳」面板（`character-ds3-overview-content`）：古文 `OverviewBio` 高度由 128 縮為 84，其下新增 `OverviewBioQuip`（13px、金色 rarityGold、最多兩行、CLAMP）。色彩與字級走 skin `auto.character-ds3-tab-overview.overviewbioquip`。狀態由 `GeneralDetailOverviewMapper` 的 `biographyQuip`／`biographyQuipKey` 提供。

# 武將任務適合度徽章演算與大廳看板深層跳轉規格書

> **所屬模組**：`3.7 UI 介面與視覺工程 (HUM-07 / HUM-01)`  
> **單一真相來源**：定義武將大廳任務適合度（`TaskSuitability`）評分演算法、人物頁推薦徽章視覺契約，以及點擊深層跳轉至大廳任務彈窗並自動選將之協議。

---

## 1. 適合度演算與自薦加成規則

系統即時掃描當前大廳任務板（`HallMissionBoard`，`doc_spec_0453`）之可接取任務，為每位武將計算對應任務之適合度得分：

$$\text{SuitabilityScore} = (\text{MainStatMatch} \times 0.5) + (\text{PersonalityBonus} \times 0.25) + (\text{VolunteerFlag} \times 0.25)$$

1. **屬性契合度 (`MainStatMatch`)**：
   - 軍事征伐任務：以武力（STR）與統率（LEA）權重試算；
   - 內政安民任務：以政治（POL）與智力（INT）權重試算；
   - 外交商貿任務：以魅力（CHA）與政治（POL）權重試算。
2. **性格加成 (`PersonalityBonus`)**：
   - 豪性武將執掌軍事任務：加成 $+15\%$；
   - 睿性武將執掌政務任務：加成 $+15\%$；
   - 貪性武將執掌商貿任務：加成 $+20\%$；
   - 義性武將執掌巡防任務：加成 $+15\%$。
3. **自告奮勇加成 (`VolunteerFlag`)**：
   - 若觸發毛遂自薦（F-2 判定，`doc_spec_0455`），該武將直接賦予 `IS_VOLUNTEER = true`，任務成功率額外暴增 $+50\%$。

---

## 2. 人物頁適合度徽章（SuitabilityBadge）介面契約

在日常人物頁 Overview 區域，若當前有極度契合之任務（$\text{SuitabilityScore} \ge 0.85$ 或 `IS_VOLUNTEER === true`），動態浮現推薦徽章：

```
+-------------------------------------------------------+
|  [武將姓名: 關雲長]    [職能: 破陣騎]   [性格: 義·青綠]  |
|                                                       |
|  [推薦任務徽章: SuitabilityBadge]                     |
|  +-------------------------------------------------+  |
|  | ★ 毛遂自薦: 討伐黑山賊匪 (+50% 成功率)  [前往出征] |  |
|  +-------------------------------------------------+  |
+-------------------------------------------------------+
```

- **視覺階梯**：
  - **金色特薦（自薦）**：`[毛遂自薦 · 成功率+50%]`，帶金色火焰外發光呼吸微動。
  - **紫色優選（高契合）**：`[完美適配 · 產出+20%]`，淡紫玉石底紋。
  - **普通契合**：不主動浮現干擾視覺，維持簡潔水墨介面。

---

## 3. 深層跳轉與自動選將協議（Deep Link Navigation）

點擊徽章之【前往出征】按鈕時，觸發跨場景/跨面板深層跳轉：
1. **場景切換**：
   - 調用 `SceneRouter.navigate("LOBBY_MISSION", { missionId: string, preselectedGeneralUid: string })`；
   - 退出當前人物頁，平滑淡入幕府大廳（`LobbyScene`）。
2. **自動彈窗與預選**：
   - 大廳任務看板自動聚焦並開啟指定任務詳情彈窗（`LobbyMissionDetailDialogComposite`）；
   - 在武將派遣下拉選單中，自動將該武將置於首位並預設選中；
   - 介面播放金色自薦印章蓋印微動效（Stamp SFX），提示玩家可直接點擊「執行軍令」。

---

## 4. 資料模型與路由契約

```typescript
export interface TaskSuitabilityPayload {
  generalUid: string;
  recommendedMissionId: string;
  missionTitle: string;
  badgeTier: "VOLUNTEER" | "PERFECT_MATCH";
  successRateBonus: number;        // 如 0.50
  bonusDescription: string;
}
```

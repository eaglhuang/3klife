# 武將四型性格圖騰與忠誠度資料模型擴充規格書

> **所屬模組**：`3.7 UI 介面與視覺工程 (HUM-01 / HUM-02)`  
> **單一真相來源**：定義 `GeneralUnit` 資料模型向下相容擴充欄位（`personality` / `loyalty` / `recentLog` / `currentSuitability`）、四型性格圖騰視覺規範，以及轉蛋誓約鎖定機制。

---

## 1. 資料模型向下相容擴充

在維持既有存檔向後相容之前提下，`GeneralUnit` 實體擴充四個核心動態欄位：

```typescript
export interface GeneralUnitExtension {
  // 1. 武將性格四型
  personality?: "RIGHTEOUS" | "HEROIC" | "SAGACIOUS" | "GREEDY";
  
  // 2. 忠誠度 (0 ~ 100)，轉蛋武將鎖定 100
  loyalty?: number;
  isLoyaltyLocked?: boolean;       // 轉蛋抽得者固定為 true
  
  // 3. 近期生平事蹟快照 (最多 5 筆)
  recentLog?: Array<{
    timestamp: number;
    logKey: string;
    summaryText: string;
  }>;
  
  // 4. 當前大廳任務適合度 (任務類型 -> 加成係數，如 "RECON": 1.5)
  currentSuitability?: Record<string, number>;
}
```

---

## 2. 四型性格圖騰與視覺徽章規範

每位武將依據歷史特質與初始設定，綁定四型性格之一，於人物頁 Header 職能標籤旁渲染專屬圓徽：

| 性格類型 | 代表色 | 圖騰意象 | 核心性格特質 | 離線自主行為傾向 |
|:---:|:---:|:---|:---|:---|
| **義 (RIGHTEOUS)** | 青綠 (`#38A169`) | 堅韌竹簡 / 漢玉玉印 | 重信守諾、忠心耿耿，俸祿短缺亦不易叛變 | 尋訪地方名士、私訪民間疾苦 |
| **豪 (HEROIC)** | 赤紅 (`#E53E3E`) | 烈焰戰戟 / 奔狼戰紋 | 驍勇好鬥、臨危不懼，戰鬥士氣維持更高 | 校場領兵演武、酒肆暢飲結交豪傑 |
| **睿 (SAGACIOUS)** | 玄藍 (`#3182CE`) | 奇門八卦 / 靈動羽扇 | 沉著深謀、內政精通，戰術 TP 消耗更省 | 批閱郡縣卷宗、推演陣型陣圖 |
| **貪 (GREEDY)** | 紫金 (`#805AD5`) | 聚寶金猊 / 五銖錢紋 | 唯利是圖、精打細算，商業買賣收益提升 | 押送商隊通商、城中典當尋寶 |

## 3. 忠誠度狀態階梯與轉蛋誓約鎖定

### 3.1 忠誠度動態階梯
忠誠度直接影響武將服從性與陣營穩定度：

```
+-------------------------------------------------------+
| 忠誠度數值區間     UI 顏色標記    行為判定與懲罰      |
+-------------------------------------------------------+
|  80 ~ 100         [綠色] 穩固    自告奮勇機率 +20%    |
|  60 ~ 79          [淺綠] 正常    正常服從軍令         |
|  30 ~ 59          [橙色] 動搖    出征士氣 -10，有微詞 |
|   0 ~ 29          [紅色] 危機    拒絕調遣 / 下野叛離  |
+-------------------------------------------------------+
```

### 3.2 轉蛋名將誓約鎖定（Loyalty Lock）
- **永久滿額特權**：凡自常設池、限定池或紅顏池以求籤令/靈玉抽得之武將，其 `isLoyaltyLocked === true`。
- **UI 呈現**：忠誠度數值直接顯示金色 `100 🔒`，並附帶【天命誓約】標籤。
- **免除懲罰**：即使發生欠薪（`doc_spec_0620`）或遭玩家強行卸下專屬虎符（-30 忠誠懲罰），轉蛋名將之忠誠度永不衰減，絕不下野。

## 4. 人物頁 Header 佈局契約

在 `CharacterDs3OverviewChild` 與 `GeneralDetailComposite` 之 Header 區域，視覺排列固定為：
```
[武將姓名 (金階)]  [職能標籤: 破陣騎]  [性格徽章: 豪·赤紅]  [忠誠度: 100 🔒]
```
- 點擊性格徽章彈出 120 字性格簡評，讓玩家直觀理解武將脾性與出征偏好。

# 武將每季增齡壽命結算與天年死亡率演算法規格書

> **模組識別碼**：`TIME-03`  
> **系統歸屬**：武將生命週期（GeneralAging）  
> **單一真相來源**：本規格書確立每季 $+0.25$ 歲增齡模型、紅色因子壽命加成、確定性雜湊壽命變異、花甲（60歲）退役與天年超齡死亡率演算法之唯一權威標準。

---

## 一、系統概述與架構原則

遊戲中的武將具備真實的生老病死生命週期。時間時鐘每推進 1 季，所有非死亡武將之生理年齡增加 $0.25$ 歲（滿 4 季增長 1 歲）。系統透過純邏輯函數結算成長階段、巔峰期、退役候選與超齡天年死亡，產出結構化事件 DTO 交由上層處理。

### Unity / 架構對照
- **壽命服務**：類似 Unity 中的 `AgingLifecycleService`，純 C# 邏輯運算，不直接銷毀 GameObject。
- **確定性雜湊**：同一武將在不同存檔或重開機時，其壽命上限保持完全一致。

## 二、增齡常數與壽命上限計算模型

### 1. 核心常數定義
```typescript
export const AGE_PER_SEASON = 0.25;                // 每季增長年齡（歲）
export const BASE_LIFESPAN = 65;                   // 基準壽命（天年）
export const RETIRE_MIN_AGE = 60;                  // 榮譽退役許可年齡（花甲）
export const RETIREMENT_AGE = 65;                  // 強制退役候選事件年齡
export const LIFESPAN_VARIANCE_MIN = -5;           // 壽命下限變異
export const LIFESPAN_VARIANCE_MAX = 10;           // 壽命上限變異
export const MAX_DEATH_CHANCE_PER_SEASON = 0.80;   // 每季死亡率上限（80%）
export const DEATH_CHANCE_PER_OVER_YEAR = 0.10;    // 超齡每滿 1 年增加死亡率（10%）
```

### 2. 壽命上限演算法
$$\text{MaxLifespan} = \text{BASE\_LIFESPAN} + (\text{RedGeneLevel} \times 3) + \text{Variance}$$

```typescript
function hashId(id: string): number {
    let hash = 0x811c9dc5;
    for (let i = 0; i < id.length; i++) {
        hash ^= id.charCodeAt(i);
        hash = Math.imul(hash, 0x01000193) >>> 0;
    }
    return hash;
}

export function resolveMaxLifespan(general: { id: string; maxLifespan?: number; redGeneLevel?: number }): number {
    if (typeof general.maxLifespan === 'number' && Number.isFinite(general.maxLifespan)) {
        return general.maxLifespan;
    }
    const span = LIFESPAN_VARIANCE_MAX - LIFESPAN_VARIANCE_MIN + 1; // 16
    const variance = LIFESPAN_VARIANCE_MIN + (hashId(general.id) % span);
    const redBonus = Math.max(0, general.redGeneLevel ?? 0) * 3;
    return BASE_LIFESPAN + redBonus + variance;
}
```

## 三、人生階段與退役事件觸發

隨著年齡推進，當武將跨過特定年齡分界線時發布事件：

| 年齡閾值 | 人生階段 / 事件識別碼 | 遊戲功能解鎖 |
|:---:|---|---|
| **5 歲** | `grow-up`（少年成長） | 揭曉五維屬性與六色因子（`Unveiling`），開啟學府培育 |
| **15 歲** | 成年加冠（弱冠禮） | 允許派駐內政、加入軍勢出征、婚配結緣 |
| **40 歲** | `prime`（壯年巔峰） | 數值發揮達到最高峰，戰場能力巔峰期 |
| **55 歲** | `elder`（老年期） | 戰場能力開始平緩衰減，累積門風經驗 |
| **60 歲** | 花甲榮譽退役許可 | 玩家可在武將面板手動選擇榮譽退役轉先祖教官 |
| **65 歲** | `reached-retirement-age` | 系統強制發送退役候選事件，強烈建議退役轉傳承 |

## 四、超齡天年死亡率公式

當武將年齡超過其 `MaxLifespan`（即 $\Delta = \text{Age} - \text{MaxLifespan} > 0$）時，每季推進時進行死亡判定：

$$\text{DeathChance} = \min\left(0.80, \Delta \times 0.10\right)$$

```typescript
export function checkOverAgeDeath(age: number, maxLifespan: number, random: () => number): boolean {
    if (age <= maxLifespan) return false;
    const overYears = age - maxLifespan;
    const deathChance = Math.min(MAX_DEATH_CHANCE_PER_SEASON, overYears * DEATH_CHANCE_PER_OVER_YEAR);
    return random() < deathChance;
}
```

- 若死亡判定為 `true`，武將狀態標記為 `'dead'`，發布 `died` 事件，移出活躍陣容並歸入家族祠堂。

## 五、驗收條件與測試案例 (Test Cases)

- **TC-TIME-09（每季精確增齡 0.25 歲）**：
  - 武將年齡 20.0 歲，推進 1 季後變為 20.25 歲；推進 4 季後精確為 21.0 歲。
- **TC-TIME-10（紅色長壽因子加成）**：
  - 基準壽命 65 歲，紅色因子等級 2，變異值為 0 時，總壽命精確為 $65 + 6 = 71$ 歲。
- **TC-TIME-11（未超齡絕對不死）**：
  - 武將年齡 60 歲，壽命上限 68 歲，死亡率為 0%，絕對不觸發死亡。
- **TC-TIME-12（超齡階梯式死亡率）**：
  - 壽命上限 65 歲，武將年齡 67 歲（超齡 2 年），每季死亡率為 $2 \times 0.1 = 20\%$；超齡 9 年時死亡率夾取為上限 $80\%$。

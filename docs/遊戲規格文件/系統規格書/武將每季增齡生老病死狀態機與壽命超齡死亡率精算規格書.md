# 武將每季增齡生老病死狀態機與壽命超齡死亡率精算規格書

## 2. 壽命上限生成與增齡狀態機

### 2.1 壽命上限公式（Lifespan Generation）
武將初次登錄或誕生時，依據其唯一 ID 確定性計算原始壽命上限，紅色因子（長壽/益壽）提供穩定延壽：
$$\text{MaxLifespan} = 65 + \text{RedFactorLevel} \times 3 + \text{DeterministicOffset}(-5 \sim +10)$$
紅色因子每提升 1 星，壽命上限確定性延長 3 歲。

### 2.2 每季自然增齡與六階段能力修正
遊戲每推進 1 個季度（春、夏、秋、冬），武將年齡增加 **0.25 歲**。實力層輸出受當前年齡階段動態修正：

| 年齡階段代碼 | 年齡區間 | 能力修正係數 | 生涯特性說明 |
| :---: | :---: | :---: | :--- |
| `INFANT`（幼兒） | $0 \le \text{age} < 14$ | $0.60\times$ | 體魄未成，受保護狀態 |
| `JUVENILE`（少年）| $14 \le \text{age} < 20$ | $1.00\times$ | 及笄弱冠，基礎能力成熟 |
| `YOUNG_ADULT`（青年）| $20 \le \text{age} < 36$ | $1.10\times$ | 氣血巔峰，戰力溢出加成 |
| `PRIME`（壯年） | $36 \le \text{age} < 51$ | $1.00\times$ | 智謀成熟，穩健發揮 |
| `ELDER`（老年） | $51 \le \text{age} < 65$ | $0.80\times$ | 體力衰退，經驗猶存 |
| `OVERAGE`（超齡）| $\text{age} \ge 65$ | $0.50\times$ | 暮年力衰，具備退役資格 |

```typescript
export type AgePhase = 'INFANT' | 'JUVENILE' | 'YOUNG_ADULT' | 'PRIME' | 'ELDER' | 'OVERAGE';

export function resolveAgePhase(age: number): { phase: AgePhase; statMultiplier: number } {
  if (age < 14) return { phase: 'INFANT', statMultiplier: 0.60 };
  if (age < 20) return { phase: 'JUVENILE', statMultiplier: 1.00 };
  if (age < 36) return { phase: 'YOUNG_ADULT', statMultiplier: 1.10 };
  if (age < 51) return { phase: 'PRIME', statMultiplier: 1.00 };
  if (age < 65) return { phase: 'ELDER', statMultiplier: 0.80 };
  return { phase: 'OVERAGE', statMultiplier: 0.50 };
}
```

## 3. 65 歲一次性退役與超齡死亡精算

### 3.1 65 歲退役候選廣播（One-Shot Event）
- 當武將年齡跨過 **65.0 歲** 門檻時，系統發出全域事件 `GeneralReachedRetirementAge`。
- 本事件受 `hasEmittedRetirementEvent` 旗標嚴格防護，**終身僅發送 1 次**，避免後續季度重複彈出確認視窗。

### 3.2 超齡每季死亡率模型
當武將年齡超過其專屬之 `maxLifespan` 時，每季換季時執行死亡檢定：
$$\text{OverAgeYears} = \max(0, \text{age} - \text{maxLifespan})$$
$$\text{DeathChancePerSeason} = \min\left(0.80, \text{OverAgeYears} \times 0.10\right)$$
- 若隨機擲骰 $\text{roll} < \text{DeathChancePerSeason}$，武將狀態切換為 `DEAD`。
- 死者狀態永久鎖定，立即退出所有作戰軍團與官職，**不再繼續增齡**，自動轉入宗族祠堂英靈名冊。

```typescript
export function evaluateSeasonMortality(
  age: number,
  maxLifespan: number,
  roll: number
): { isDead: boolean; deathChance: number } {
  if (age <= maxLifespan) {
    return { isDead: false, deathChance: 0 };
  }
  const overAge = age - maxLifespan;
  const chance = Math.min(0.80, overAge * 0.10);
  return {
    isDead: roll < chance,
    deathChance: Number(chance.toFixed(4))
  };
}
```

## 4. 單元測試驗證規範
1. **TC-AGE-PHASE（年齡係數臨界檢驗）**：年齡 19.75 歲為少年（1.00）；年齡 20.0 歲跳升為青年巔峰（1.10）；65.0 歲為超齡（0.50）。
2. **TC-AGE-ONE-SHOT（65 歲退役單次廣播）**：跨過 65 歲發送廣播並將旗標置為 `true`；後續 65.25 與 66 歲時不再廣播。
3. **TC-AGE-MORTALITY（超齡死亡率精算）**：壽命 70 歲，武將 73 歲時超齡 3 歲，死亡率為 $0.30$；80 歲時超齡 10 歲，死亡率受限封頂於 $0.80$。

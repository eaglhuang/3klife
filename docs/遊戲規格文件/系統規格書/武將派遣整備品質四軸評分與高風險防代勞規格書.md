# 武將派遣整備品質四軸評分與高風險防代勞規格書

## 1. 核心定位與設計理念
本規格書定義三國生活（3KLife）內政與派遣系統之「武將派遣品質四軸評分演算法與高風險任務防代勞」規格（對應 WBS `JRN-03` 與 `PROG-2-1177`）。
武將派遣作為讓未出征之文臣武將自主發揮才能、產出物資與書寫個人日誌之長線玩法，堅持**多軸加權、拒絕二元成敗、高風險強制親裁**原則：
1. **多維四軸加權評分（0~100分）**：綜合角色身分標籤、五維數值契合、當前心情狀態與歷史日誌親和度進行精密算分。
2. **拒絕非黑即白（No Binary Success/Fail）**：品質等級僅決定額外驚喜產出與日誌措辭，絕不因低分沒收基礎主獎勵。
3. **高風險任務防代勞鐵律（Anti-Auto-Dispatch）**：涉及改變戰局走向或武將生死之高風險任務，嚴格禁止 AI 自動指派，必須玩家親自決策。

## 2. 派遣品質四軸加權評分演算法 (`getDispatchScore`)
系統傳入任務定義 `DispatchJob` 與出征武將 `DispatchGeneral`，計算評分（四捨五入整數）：
$$\text{Score} = \text{round}\left(F_{\text{role}} \times 45 + F_{\text{stat}} \times 25 + M_{\text{mood}} \times 15 + F_{\text{journal}} \times 15\right)$$

### 2.1 四軸權重細部維度 (`DISPATCH_SCORE_WEIGHTS`)
1. **角色身分契合 ($F_{\text{role}}$, 權重 45%)**：
   計算任務所需標籤（如 `['CAVALRY', 'SCOUT']`）與武將擁有標籤（`roleTags`）之重合比例：
   $$F_{\text{role}} = \frac{|\text{JobTags} \cap \text{GeneralTags}|}{|\text{JobTags}|} \quad (\text{無需求時為 } 1.0)$$
2. **能力屬性契合 ($F_{\text{stat}}$, 權重 25%)**：
   比對五維要求屬性，計算達成率平均值：
   $$F_{\text{stat}} = \frac{1}{K} \sum_{k \in \text{Keys}} \min\left(1.0,\, \frac{\text{ActualStat}_k}{\text{RequiredStat}_k}\right) \quad (\text{無要求時為 } 1.0)$$
3. **心情修飾係數 ($M_{\text{mood}}$, 權重 15%)**：
   心情狀態查表倍率：`LOW = 0.2`, `NORMAL = 0.6`, `HIGH = 1.0`。
4. **日誌歷史親和 ($F_{\text{journal}}$, 權重 15%)**：
   比對任務背景標籤與武將過往累積之日誌經歷標籤（`journalTags`）交集比例。

## 3. 四階品質區間與結果映射 (`dispatchQualityOf`)
依據計算出的總分，由高至低比對品質門檻區間：

| 品質區間 (`DispatchQuality`) | 總分門檻 (`Score`) | 結算表現與回饋效益 |
| :---: | :---: | :--- |
| **EXCELLENT (絕倫卓越)** | **$\ge 80$ 分** | 基礎獎勵全額發放，額外掉落稀有道具/秘寶，解鎖特殊高讚賞日誌，武將心情提升為 HIGH |
| **GOOD (優良圓滿)** | **$\ge 60$ 分** | 基礎獎勵全額發放，微幅額外銅錢/經驗，記錄滿意日誌 |
| **NORMAL (平穩達標)** | **$\ge 40$ 分** | 基礎獎勵正常交付，常態結案日誌 |
| **POOR (欠佳勉強)** | **$< 40$ 分** | 基礎獎勵保底交付，但無額外掉落，日誌提及波折艱辛 |

## 4. 高風險防代勞機制 (`canAutoDispatch`)
- **高風險旗標校驗**：
  若 `job.highRisk === true`，函式 `canAutoDispatch` 嚴格回傳 `false`。
- **委任阻斷**：
  大廳之「一鍵委派」或「AI 代勞」功能將主動過濾高風險任務，UI 顯示警示標籤並強制要求玩家手動指派將領與確認出發。
- **結算標準字串模板**：
  `{GeneralName} 已完成『{JobName}』，帶回 {RewardText}。`（`DISPATCH_COMPLETE_TEMPLATE`）。

## 5. Unity 與 Cocos Creator 概念對照
| 概念維度 | Cocos Creator 實作架構 | Unity 引擎對照架構 |
| :--- | :--- | :--- |
| **派遣評分器** | `DispatchQuality.ts` 純函式模組，資料驅動算分 | C# `DispatchEvaluator` 搭配 ScriptableObject 權重配置 |

## 6. 驗證條件與測試矩陣 (Acceptance Gate)
1. **TC-DISPATCH-01 四軸滿分計算**：標籤完全相符、屬性全達標、HIGH 心情、日誌完全親和，驗證得分精確為 100 分（EXCELLENT）。
2. **TC-DISPATCH-02 邊界品質分位判定**：79 分精確對應 GOOD；80 分精確躍升為 EXCELLENT。
3. **TC-DISPATCH-03 高風險任務阻斷代勞**：設定 `highRisk = true`，驗證 `canAutoDispatch` 回傳 `false`。
4. **TC-DISPATCH-04 無要求項目全額保底**：傳入無標籤與能力要求的輕鬆差事，驗證不扣分並回傳基準分。

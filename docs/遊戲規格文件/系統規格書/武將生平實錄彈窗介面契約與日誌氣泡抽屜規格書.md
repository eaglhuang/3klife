# 武將生平實錄彈窗介面契約與日誌氣泡抽屜規格書

> **所屬模組**：`3.7 UI 介面與視覺工程 (HUM-06 / HUM-01)`  
> **單一真相來源**：定義日常人物頁 `GeneralJournalPeek` 動態氣泡互動規範、完整生平實錄彈窗（`GeneralBiographyModal`）佈局結構與編年史時間軸資料契約。

## 2. GeneralJournalPeek 氣泡互動契約

1. **呈現規則**：
   - 提取武將存檔 `GeneralUnit.recentLog` 之最新一筆紀錄；
   - 限制單行顯示，超出 24 字時以省略號截斷；
   - 若該武將無任何歷史紀錄，氣泡顯示 `「初入幕府，尚無事蹟記載」`。
2. **動態微補間**：
   - 每隔 8 秒微浮動一次（Y 軸平移 3px，歷時 0.8s，EaseInOut），提示玩家可點擊交互。

## 3. 編年史事件資料結構與空狀態防呆

時間軸節點採強型別結構化契約：

```typescript
export interface BiographyTimelineNode {
  eventId: string;
  age: number;                     // 發生時武將歲數
  yearLabel: string;               // 如 "建安十三年"
  category: "ORIGIN" | "BATTLE" | "OFFICIAL" | "LINEAGE" | "IDLE_DAILY";
  title: string;                   // 4~6 字標題，如 "長坂救主"
  description: string;             // 40~80 字古雅簡評
  highlightTier: "NORMAL" | "KEY_MILESTONE" | "LEGENDARY"; // 金色/紫色/普通
}
```

### 3.1 空狀態處理（Empty State）
- 若武將剛由轉蛋抽得且尚未出戰（`recentLog` 為空），時間軸中央顯示古樸書卷插圖與水墨小楷：
  `「新將初逢明主，征程正待開卷。攜其出征拔營，方可書寫千秋功業。」`

# 武將稀有度五級分類與商業七色映射規格書

> **文件狀態**：單一真相來源（Single Source of Truth）  
> **系統代碼**：`TERM-02`、`SYS-RARITY-MAPPING`  
> **核心職責**：確立核心戰力「雙軸演算法」（maxStat + avg5）計算 RarityTier 與角色定位（characterCategory），並嚴格隔離「商業七色展示帶」（CommercialRarityBand），杜絕商業包裝反向污染核心數值平衡。

---

## 1. 雙軌隔離架構原則

1. **核心戰力雙軸決定（RarityTier）**：
   - 武將真實戰力等級僅由五維屬性（統率、武力、智謀、政治、魅力）經由雙軸演算法決定，全域唯一定義為五階：`N`、`R`、`SR`、`SSR`、`UR`。
2. **商業展示純解耦（CommercialRarityBand）**：
   - 商業化七曜色彩（`White`, `Green`, `Blue`, `Purple`, `Gold`, `Red`, `Rainbow`）僅負責外觀框體、抽卡光效、徽章呈現，**嚴禁作為戰鬥公式、屬性成長之輸入參數**。
3. **無硬編碼覆蓋**：
   - 所有名將與子嗣之階級評定由通用純函式動態推導，禁止在單一角色配置中寫死不符合數值門檻之特例。

---

## 2. 雙軸判定演算法與數值門檻

### 2.1 雙軸門檻公式
武將五維記為 $S = \{ \text{LDR}, \text{WAR}, \text{INT}, \text{POL}, \text{CHA} \}$：
- **最大極值**：$\text{maxStat} = \max(S)$
- **五維平均**：$\text{avg5} = \frac{1}{5} \sum S$

| RarityTier | 階級名稱 | 判定條件（滿足其一即晉階） | 設計定位與範例 |
|:---:|:---:|---|---|
| **UR** | 神將 | $\text{maxStat} \ge 98$ 或 $\text{avg5} \ge 90$ | 絕頂豪傑（如：呂布 武99、諸葛亮 智100、曹操 綜92） |
| **SSR** | 史詩名將 | $\text{maxStat} \ge 90$ 或 $\text{avg5} \ge 80$ | 頂尖名將（如：趙雲、關羽、周瑜、司馬懿） |
| **SR** | 菁英良將 | $\text{maxStat} \ge 80$ 或 $\text{avg5} \ge 70$ | 中堅骨幹（如：張遼、魏延、程昱、魯肅） |
| **R** | 偏將副校 | $\text{maxStat} \ge 70$ 或 $\text{avg5} \ge 60$ | 實用將領（如：李典、樂進、審配、周倉） |
| **N** | 尋常武夫 | 未達上述標準之其他數值 | 地方鄉勇、基層將吏 |

---

## 3. 角色定位（characterCategory）判定

依武將最高屬性類別劃分職能主導：
- **統帥 (Commander)**：$\text{LDR}$ 最高，擅長陣法協同、軍隊增益。
- **先鋒 (Vanguard)**：$\text{WAR}$ 最高，擅長衝陣突破、單挑斬將。
- **軍師 (Strategist)**：$\text{INT}$ 最高，擅長計策奇襲、戰場控場。
- **文官 (Statesman)**：$\text{POL}$ 最高，擅長治國安邦、內政後勤。
- **名流 (Celebrity)**：$\text{CHA}$ 最高，擅長結緣外交、士氣激勵。

## 4. 商業七色映射表（CommercialRarityBand）

| 商業色帶 (Band) | 中文標稱 | 介面色階 (Token) | 預設映射 RarityTier | 視覺外框樣式 |
|---|---|---|:---:|---|
| **White** | 凡品 | `--rarity-white` | N | 素面灰白木框 |
| **Green** | 良品 | `--rarity-green` | R | 青銅雕飾框 |
| **Blue** | 上品 | `--rarity-blue` | SR | 湛藍鎏銀框 |
| **Purple** | 極品 | `--rarity-purple` | SSR (常規) | 紫霄琉璃框 |
| **Gold** | 絕品 | `--rarity-gold` | SSR (巔峰) | 金絲盤龍雕花框 |
| **Red** | 神品 | `--rarity-red` | UR | 焚天熾焰赤金框 |
| **Rainbow** | 無雙天命 | `--rarity-rainbow` | UR (突破/特殊限定) | 七曜流光無雙神框 |

> **隔離鐵律**：展示層可將 SSR 透過覺醒呈現為金/紫，但核心公式讀取的永遠是 `RarityTier.SSR`。

## 5. TypeScript 參考實作

```typescript
export enum RarityTier { N = 'N', R = 'R', SR = 'SR', SSR = 'SSR', UR = 'UR' }
export enum CharacterCategory {
  Commander = 'Commander', Vanguard = 'Vanguard',
  Strategist = 'Strategist', Statesman = 'Statesman', Celebrity = 'Celebrity'
}

export function computeRarityTier(stats: { ldr: number; war: number; int: number; pol: number; cha: number }): RarityTier {
  const vals = [stats.ldr, stats.war, stats.int, stats.pol, stats.cha];
  const maxStat = Math.max(...vals);
  const avg5 = vals.reduce((a, b) => a + b, 0) / 5;

  if (maxStat >= 98 || avg5 >= 90) return RarityTier.UR;
  if (maxStat >= 90 || avg5 >= 80) return RarityTier.SSR;
  if (maxStat >= 80 || avg5 >= 70) return RarityTier.SR;
  if (maxStat >= 70 || avg5 >= 60) return RarityTier.R;
  return RarityTier.N;
}
```

# 武將結緣受孕率精算公式與五軸修正衰退模型規格書

> **模組識別碼**：`BRD-03`  
> **系統歸屬**：血統家族培育（Breeding）受孕率模型  
> **單一真相來源**：本規格書確立男女武將結緣受孕率基準（70%）、95% 封頂上限、魅力與幸運雙屬性增幅、精力充沛度、產次負擔與年齡衰退五軸精算公式之唯一權威標準。

---

## 一、系統概述與架構原則

結緣後的受孕判定並非單純隨機擲骰，而是綜合考量雙方氣質魅力、天命造化、當前體力精力與生理年齡之動態評估。所有計算採浮點乘積後進行上限夾取，提供明確的培育回饋與策略深度。

### Unity / 架構對照
- **數值模型**：類似 Unity 中的 `ConceptionProbabilityModel`，輸入雙方屬性快照，回傳 $[0.0, 0.95]$ 區間之精確機率。
- **純量計算**：以結緣發起時（扣除精力前）之屬性計算，確保預覽與實作無落差。

---

## 二、受孕率核心常數與封頂規則

```typescript
export const CONCEPTION_BASE_RATE = 0.70; // 基礎受孕率（70%）
export const CONCEPTION_RATE_CAP = 0.95;  // 受孕率絕對上限封頂（95%）
```

- **天命留白**：受孕率即使在各項加成極致疊加下，依然保留最低 5% 的「天命未至」失敗機率，杜絕數值溢出。

## 三、五軸修正乘數精算演算法

最終受孕率公式如下：

$$\text{FinalRate} = \min\left(0.95, \text{Base} \times \text{Mod}_{\text{CHA}} \times \text{Mod}_{\text{LUK}} \times \text{Factor}_{\text{Vigor}} \times \text{Factor}_{\text{Load}} \times \text{Factor}_{\text{AgeF}} \times \text{Factor}_{\text{AgeM}}\right)$$

### 1. 雙方魅力與幸運增幅
- $\text{CHA}_{\text{avg}} = \frac{\text{CHA}_{\text{father}} + \text{CHA}_{\text{mother}}}{2}$，增幅係數為 $\left(1 + \frac{\text{CHA}_{\text{avg}}}{200}\right)$。
- $\text{LUK}_{\text{avg}} = \frac{\text{LUK}_{\text{father}} + \text{LUK}_{\text{mother}}}{2}$，增幅係數為 $\left(1 + \frac{\text{LUK}_{\text{avg}}}{200}\right)$。

### 2. 精力因子（`vitalityFactor`）
取父母雙方當前精力比例（$\frac{\text{Vitality}}{\text{MaxVitality}}$）較低者：

$$\text{Factor}_{\text{Vigor}} = \begin{cases} 1.0 & \text{若 } \text{Ratio} > 0.50 \\ 0.5 & \text{若 } 0.30 \le \text{Ratio} \le 0.50 \\ 0.1 & \text{若 } \text{Ratio} < 0.30 \end{cases}$$

### 3. 母方產次負擔因子（`birthLoadFactor`）
母方每多生育一次，生理負擔增加，係數逐次遞減，但設有保底：

$$\text{Factor}_{\text{Load}} = \max\left(0.40, 1.0 - 0.15 \times \max(0, \text{BreedingCount}_{\text{mother}} - 1)\right)$$

### 4. 父母年齡衰退因子（`parentAgeFactor`）
雙方年齡各自計算生理衰減：

$$\text{Factor}_{\text{Age}} = \begin{cases} 1.0 & \text{若 } \text{Age} \le 40 \text{ 歲} \\ 0.8 & \text{若 } 41 \le \text{Age} \le 45 \text{ 歲} \\ 0.6 & \text{若 } \text{Age} > 45 \text{ 歲} \end{cases}$$

## 四、演算法實作參考

```typescript
export function conceptionRate(father: BreedingGeneral, mother: BreedingGeneral): number {
    const chaAvg = (statOf(father, 'cha') + statOf(mother, 'cha')) / 2;
    const lukAvg = (statOf(father, 'luk') + statOf(mother, 'luk')) / 2;
    
    const rate = CONCEPTION_BASE_RATE
        * (1 + chaAvg / 200)
        * (1 + lukAvg / 200)
        * vitalityFactor(father, mother)
        * birthLoadFactor(mother)
        * parentAgeFactor(father.age)
        * parentAgeFactor(mother.age);
        
    return Math.min(rate, CONCEPTION_RATE_CAP);
}
```

## 五、驗收條件與測試案例 (Test Cases)

- **TC-BRD-05（上限絕對截斷）**：
  - 父母魅力 100、幸運 100、滿精力且未滿 30 歲，理論乘積超過 1.10，計算結果精確封頂於 0.95。
- **TC-BRD-06（精力衰竭重度懲罰）**：
  - 雙方精力比例低於 30%，`vitalityFactor` 為 0.1，受孕率大幅降至 10% 以下。
- **TC-BRD-07（高齡生育遞減）**：
  - 父母雙方皆為 48 歲，雙重年齡因子為 $0.6 \times 0.6 = 0.36$，受孕率受到顯著壓制。
- **TC-BRD-08（母方初產無負擔）**：
  - 母方首次生育（`breedingCount = 0`），`birthLoadFactor` 精確回傳 1.0。

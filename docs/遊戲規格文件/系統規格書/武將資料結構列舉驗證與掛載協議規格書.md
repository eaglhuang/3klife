# 武將資料結構列舉驗證與掛載協議規格書

> **責任邊界**：本檔為全域存檔資料結構（Root Save Data）、§2-2 補充欄位約束與 Data.* 掛載點的單一真相來源。
> **關聯 WBS**：DS-07（2-2補充欄位列舉驗證）、DS-04（Data.* 掛載點骨架）、DS-01（資料結構規範）。
> **整併裁決**：徹底裁定 PROG-2-0499 阻塞之 24 條列舉與邊界定義；消除歷史模糊，確立機械驗證單一標準。

---

## §1. 核心補充欄位列舉字典 (Enum Master Registry)

全域存檔驗證器 `DataSchemaEnumRules` 依據下列權威列舉值執行驗證：

| 欄位路徑與編號 | 合法列舉值清單 (Allowed Enums) | 邊界約束與違規處理 |
|:---|:---|:---|
| **#5** `Rival_Nations[*].Coalition_State` | `HEGEMON`, `FORCED_ALLIED`, `NEUTRAL`, `HOSTILE` | 區分霸主、強制同盟、中立與敵對狀態；其餘字串拒絕 |
| **#6** `Child_Preview.Revelation_Level` | `HIDDEN`, `TENDENCY`, `RANGE`, `EXACT` | 依序揭露子嗣資訊；逆向倒退或非法值拋出錯誤 |
| **#13** `Battle_State.Reserved_Tally_Bands` | `R`, `SR`, `SSR`, `UR` | 僅記錄 AI 戰術保留之虎符品質階級，禁止存取完整虎符物件 |
| **#20** `Bonding_Sessions[*].Breeding_Mode` | `Standard`, `Peace_Lineage` | 和親模式仍受活力與懷孕鎖定約束，不得新增額外宗廟系統 |
| **#21** `Mentor_Pool[*].Role_Boundary` | 固定唯一值：`TeachingOnly` | **血統防污染**：嚴禁回寫父母 UID、基因或懷孕率欄位 |
| **#22** `Nurture_Sessions[*].Mentoring_Mode_Log` | `Support`, `Legendary_Mentoring` | 區分一般教官與名將親授，供 36 回合重播日誌檢索 |
| **#26** `Gacha_State.*.Pool_Positioning` | `Bloodline_Seed`, `Nurture_Depth` | 轉蛋定位雙軌；黑名單 `Tiger_Tally`, `Spirit_Card`, `DP` 嚴禁進入 |
| **#34** `Officer_Promotion.Rank_Track` | `CIVIL`, `MILITARY`, `SPECIAL` | 文官、武官與特職三軌，禁止跨軌重複授予官銜 |

## §2. 跨欄位與關聯完整性邊界規則

驗證器在資料落盤時必須同步校驗以下跨欄位依賴性：

1. **出征編制唯一性 (#12 / #18)**：
   - `Sortie_Loadout` 中 `Main_General_UID`, `Deputy_General_UID`, `Vanguard_General_UID` 三者 **不得重複**。
2. **棋盤預設對齊 (#12)**：
   - `Battle_State.Scene_Preset_ID` 必須與 `Scene_Gambit_State.Tile_Preset_ID` 完全一致，作為模組化戰場唯一 Preset 權威。
3. **英靈卡綁定互扣 (#18)**：
   - 武將裝備之 `Equipped_Spirit_UID` 必須在 `Spirit_Card_Inventory` 內存在且標註持有者為該武將 UID。
4. **離線同步校驗 (#10)**：
   - `General_Journal.Offline_Battle_Snapshots[*].Sync_Hash_Link` 必須能回扣至 `Action_Records` 序號或有效 Hash，禁止純字串快照。

## §3. Data.* 25 條系統掛載點協議 (Mount Registry)

所有子系統在存檔根節點 `Data` 下擁有專屬掛載點，缺漏時由遷移腳本（Migration）自動以預設結構初始化：

```typescript
export interface RootSaveDataMounts {
  Generals: Record<string, unknown>;               // 1. 武將母表
  Lobby_Hub: Record<string, unknown>;              // 2. 主大廳與沙盤
  Rival_Nations: Record<string, unknown>;          // 3. 諸侯與外交
  Child_Preview: Record<string, unknown>;          // 4. 子嗣揭露
  General_Journal: Record<string, unknown>;        // 5. 日誌與晨報
  Battle_State: Record<string, unknown>;           // 6. 戰鬥現況
  Scene_Gambit_State: Record<string, unknown>;     // 7. 地形與戰術
  Player_Economy: Record<string, unknown>;         // 8. 資源與地窖保護
  Tournament_Data: Record<string, unknown>;        // 9. 擂台與賽季
  Bonding_Sessions: Record<string, unknown>;       // 10. 結緣進度
  Mentor_Pool: Record<string, unknown>;            // 11. 教官名冊
  Nurture_Sessions: Record<string, unknown>;       // 12. 培育 36 回合
  Stage_Chain_Progress: Record<string, unknown>;   // 13. 關卡推展
  Officer_Promotion: Record<string, unknown>;      // 14. 官階爵位
  Spirit_Card_Inventory: Record<string, unknown>;  // 15. 英靈卡背包
  Tiger_Tally_Inventory: Record<string, unknown>;  // 16. 虎符背包
  Mentor_Support_Inventory: Record<string, unknown>;// 17. 支援卡背包
  Mentor_Shard_Bank: Record<string, unknown>;      // 18. 碎片庫
  Longevity_Pill_Usage: Record<string, unknown>;   // 19. 延壽丹歷史
  Gene_Awakening_Log: Record<string, unknown>;     // 20. 因子覺醒
  Gacha_State: Record<string, unknown>;            // 21. 轉蛋與保底
  City_Population_Registry: Record<string, unknown>;// 22. 城市人口
  Diplomacy_Truce_Records: Record<string, unknown>;// 23. 停戰協定
```

## §4. 機械驗證行為協議 (Verification Contract)

- **非侵入式檢驗**：輸入為 `Record<string, unknown>`，未提供之欄位不報錯（由對應子系統負責遷移補齊）。
- **嚴格型別斷言 (Fail-Closed)**：一旦欄位存在但值超出合法列舉或違反唯一性約束，驗證器一律返回 `isValid: false` 並詳細註記違規欄位路徑。

# 武將離線互動事件觸發判定與同登入窗去重規格書

## 1. 核心定位與設計理念
本規格書定義三國生活（3KLife）武將生涯與離線互動系統之「離線互動事件觸發條件、關係標籤篩選與登入窗去重」規範（對應 WBS `JRN-04`、`PROG-2-0984` 與 `PROG-2-1193`）。
離線互動旨在讓玩家離線期間感受到軍營營帳依然生生不息、將領之間自然交流生活，堅持**離線門檻、關係驅動、登入窗嚴格去重**原則：
1. **多重觸發閘門保護**：離線必須達到 4 小時以上，且未讀晨報不積壓，防止登入時資訊轟炸。
2. **在世動態關係驅動**：嚴格依據名冊在世武將之間的動態人際關係（同袍、結義、夫妻、父子）提取互動素材。
3. **同登入窗對稱去重**：同一登入視窗內，同一對角色嚴格僅生成 1 則主互動，杜絕重覆洗版。

## 2. 離線觸發四道閘門校驗 (`shouldTriggerOfflineInteraction`)
系統在玩家登入時傳入 `OfflineContext` 進行純邏輯校驗：
```typescript
export interface OfflineContext {
    offlineHours: number;                 // 離線總時數（由絕對時間戳計算）
    unreadMorningReport: number;          // 當前未讀晨報數量
    activeConflictTags: readonly string[];// 當前在世武將活躍關係標籤列表
    cooldowns: readonly string[];         // 全域冷卻鎖定清單
}
```

### 2.1 閘門規則清單
$$\text{CanTrigger} = (\text{offlineHours} \ge 4) \ \land\ (\text{unreadMorningReport} < 3) \ \land\ (|\text{activeTags}| > 0) \ \land\ (\neg \text{Locked})$$
1. **離線時長門檻 (`OFFLINE_INTERACTION_MIN_HOURS = 4`)**：離線滿 4 小時方有足夠時間醞釀營中故事。
2. **訊息防過載門檻 (`OFFLINE_MORNING_REPORT_LIMIT = 3`)**：若未讀晨報已達 3 則以上，暫緩觸發新互動。
3. **關係標籤存在**：必須至少有一對在世武將存在有效動態關係標籤。
4. **全域冷卻校驗**：冷卻清單中不得包含 `OFFLINE_INTERACTION_LOCK`。

## 3. 同登入窗對稱去重演算法 (`offlineInteractionKey`)
- **無序對稱鍵生成**：
  不論傳入參數為 $(A, B)$ 還是 $(B, A)$，統一透過字串排序保證生成的 Key 絕對對稱：
  $$\text{Key}(\text{windowId}, A, B) = \text{windowId} + \text{"|"} + \min(A, B) + \text{"|"} + \max(A, B)$$
- **紀錄與防重查驗 (`canStartOfflineInteraction`)**：
  查驗當前登入窗記錄陣列 `log` 是否已包含該 Key。若已存在，安全拒絕再次排程；若未存在，記錄 Key 並回傳不可變之新陣列（上限保留最新 20 筆）。

## 4. 動態關係候選與劇本填充 (`OfflineInteractionEvents`)
- **候選過濾 (`offlineInteractionCandidates`)**：
  僅當關係雙方均為名冊中「在世武將」時，方可列為有效候選對象。
- **四大人際關係劇本庫 (`OFFLINE_INTERACTION_DETAILS`)**：
  - `COMRADE`（同袍同僚）：校場切磋武藝、對著沙盤爭論昨日戰法。
  - `DYNAMIC_SWORN`（結義兄弟）：把酒論天下相約破敵、為玩笑話鬥嘴又和好。
  - `SPOUSE`（夫妻連理）：月下閒談家事相視而笑、為晚膳吃什麼爭執。
  - `PARENT_CHILD`（父子長幼）：長輩考校功課答得頭頭是道、晚輩纏著聽當年征戰往事。
- **日誌寫入**：
  組裝開篇句「`{GeneralA} 與 {GeneralB} 在你離席時發生了一段插曲。`」與細節句，生成 `category = 'INTERACTION'`、`priority = 50` 之標準日誌寫入主檔。

## 6. 驗證條件與測試矩陣 (Acceptance Gate)
1. **TC-JRN04-01 4小時與未讀閘門阻斷**：離線 3.9 小時或未讀晨報為 3 則，驗證 `shouldTriggerOfflineInteraction` 回傳 `false`。
2. **TC-JRN04-02 角色順序對稱去重**：以 $(A, B)$ 記錄後，以 $(B, A)$ 查詢，驗證判定為已存在且不重複排程。
3. **TC-JRN04-03 亡歿角色自動排除**：關係雙方中有一人已陣亡除名，驗證候選清單自動過濾該組合。
4. **TC-JRN04-04 標準日誌產出屬性**：驗證產出之條目分類精確為 `INTERACTION` 且優先級固定為 50。

# 歷年榮譽牆系統規格書

## 1. 系統目標
為《史境天下風雲榜與年終頒獎典禮》補齊跨年長期紀錄與回顧入口：玩家每次完成年終頒獎典禮後，系統自動將該年度「天下名門榜」前三名與玩家家族名次寫入存檔，並於大廳／典禮入口提供「歷年榮譽牆」檢視，強化「百年門閥、世代名門」的長期目標感。

## 2. 資料結構與存檔契約（JSON / Save）
- **存檔欄位**：`PlayerSaveService` 新增 `honorWallRecords: HonorWallYearRecord[]`（舊存檔預設為 `[]`）。
- **單年紀錄結構**：
  - `year` (`number`)：結算年份（第 1 年起）
  - `playerRank` (`number`)：玩家家族該年名次（1 起算）
  - `playerScore` (`number`)：玩家家族該年名門總分
  - `topThree` (`HonorWallEntry[]`)：該年前三名清單（`rank: 1 | 2 | 3`、`familyName`、`leaderGeneralId`、`score`、`isPlayer`）
  - `badgeUnlocked` (`string | null`)：該年獲得的特殊徽章鍵（如 `three_peat_famous_house` 天下名門三連霸）
- **設定檔（JSON）**：`assets/resources/data/master/honor-wall-config.json`
  - `maxStoredYears` (`number`, 預設 `50`)：榮譽牆最多保留年數（超過時保留前三名紀錄或依年份滾動）
  - `highlightTopRank` (`number`, 預設 `3`)：榮譽牆金框標示名次門檻

## 3. UI 與互動流程
- **入口**：於年終典禮主畫面右上角及幕府大廳「名門榜」頁籤新增「歷年榮譽牆」按鈕。
- **版面**：依年份倒序顯示年度卡片（年份、玩家名次／分數、前三名家族與代表武將頭像），點擊單年卡片可展開該年領獎台感言摘要。
- **i18n 鍵**：
  - `ui.honor_wall.title`：歷年榮譽牆
  - `ui.honor_wall.empty`：尚無歷年榜單紀錄，請先完成第 1 年年終典禮。
  - `ui.honor_wall.year_row`：第 `{year}` 年｜第 `{rank}` 名（`{score}` 分）

## 4. 驗收條件
1. 完成第 1 年年終典禮後，存檔立即寫入第 1 年紀錄，重開遊戲後仍可於榮譽牆查得。
2. 舊存檔無 `honorWallRecords` 欄位時向後相容為空陣列，不報錯。
3. 所有文案走 i18n，數值上限由 `honor-wall-config.json` 讀取。

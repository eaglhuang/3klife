# 每日資源貧困補貼判定與自動入帳規格書

## 1. 核心定位與設計理念
本規格書定義《三國人生》每日針對處於極度匱乏狀態之勢力發放「官府賑災補貼（Daily Subsidy）」的判定狀態機與入帳規則（WBS `ECO-06`，代碼落位於 `DailySubsidy.ts` 與 `DailySubsidyNotice.ts`）。
當玩家所持之糧草、黃金或城市兵源低於生存門檻時，系統於每日初次登入時自動注入固定賑濟物資，並受存儲上限夾制，確保破產玩家能持續進行遊戲。

```
              ┌──────────────────────────────────────────────┐
              │          DailySubsidy 每日貧困補貼            │
              └──────────────────────┬───────────────────────┘
                                     │ 每日初次檢核 (lastClaimDay)
          ┌──────────────────────────┴──────────────────────────┐
          ▼                                                     ▼
   【貧困判定門檻 (ifBelow)】                            【固定賑濟配額 (grant)】
   • food:   < 1,200 單位                                • food:   +400 糧草
   • gold:   < 500 單位                                  • gold:   +150 黃金
   • troops: < 600 人                                    • troops: +200 兵源
   • 三項獨立檢定，入帳後經 ResourceCap 夾制             • 無資源達標時不計領取
```

---

## 2. 每日補貼三維判定與發放矩陣（`DAILY_SUBSIDY_RULES`）

系統逐項檢核三類生存關鍵資源，符合低於門檻者分別發放固定數量補貼：

| 資源類別 (`SubsidyResourceKey`) | 貧困判定門檻 (`ifBelow`) | 每日固定補發額度 (`grant`) | 賑濟目的與效用說明 |
| :--- | :---: | :---: | :--- |
| **糧草 (`food`)** | **$<$ 1,200 單位** | **+400 單位** | 補給行軍軍糧，確保當日能進行至少 1 場出征戰役 |
| **黃金 (`gold`)** | **$<$ 500 單位** | **+150 單位** | 賑給流通銀兩，滿足基礎營房整修與民生週轉 |
| **城市兵源 (`troops`)** | **$<$ 600 人** | **+200 人** | 鄉野招募丁勇入庫，維持城防最基礎守備編制 |

## 3. 補貼判定狀態機與入帳流程（`dailySubsidyOf`）

### 3.1 自然日切日檢核
- 補貼以切日後的自然日序號 `today` 判定（依據 UTC+8 伺服器標準日曆時間）。
- **同日唯一領取限制**：若存檔記錄之上次領取日 $\text{lastClaimDay} == \text{today}$，系統立即中止審批，回傳 `claimed = false`。

### 3.2 逐項審批與多重入帳
```typescript
for (const rule of DAILY_SUBSIDY_RULES) {
    if (resources[rule.key] >= rule.ifBelow) continue;
    grants[rule.key] = rule.grant;
    next[rule.key] = clampResource(rule.key, resources[rule.key] + rule.grant);
}
```
1. **多重並發發放**：若玩家糧草（800）與黃金（300）皆低於門檻，則同日一次性獲得 400 糧草與 150 黃金。
2. **容量上限防護**：補貼入帳後強制調用 `clampResource` 夾制，嚴禁突破初始存儲容量。
3. **無效判定保護**：若三項資源存量皆高於門檻，`claimed = false`，**上次領取日 `lastClaimDay` 保持原值不變**，玩家若在當天稍後因作戰消耗而變貧困，當日仍可再次嘗試觸發補貼。

## 4. 介面彈窗反饋契約（`DailySubsidyNotice`）

當 `claimed === true` 時，主城介面於登入完成後自動彈出專屬賑災感謝彈窗：
- 列出實際獲得之資源清單與數量（`grants`）。
- 附帶文案：「朝廷下撥賑災恤銀，主公當勵精圖治，重振軍威！」

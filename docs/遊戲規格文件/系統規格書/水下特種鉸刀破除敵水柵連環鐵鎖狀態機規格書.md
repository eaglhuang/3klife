# 3KLife 水下特種鉸刀破除敵水柵連環鐵鎖狀態機規格書

## 1. 系統定位與設計意圖

在三國後期晉吳長江終局水戰（王濬伐吳）與濡須要塞攻防中，防守方於長江咽喉橫鎖粗逾人腿之生鐵巨索，並密植水柵、暗樁封死航道。本系統規範水工破障先鋒部隊「水下連環鎖鉸破工程（Underwater Shear Chain Cutter）」之作業與破拆狀態機：
- **水下雙柄巨型鉸刀**：長丈二之槓桿複式鋼刃剪刀，由水下 4 名死士合力搖動鉸盤施壓，對浸水鐵環實施機械剪切。
- **水底桐油熱熔輔助**：利用水下倒扣青銅鐘型聚熱罩，注入硫磺強烈燃劑，高溫炙烤鐵索使其軟化後瞬時剪斷。
- **航道清障連鎖**：斬斷主鎖後，江面連環攔江索瞬間繃斷崩解，為主力水軍樓船艦隊開闢突破通道。

## 2. 狀態機架構與轉換生命週期

水下鉸鎖狀態機（代碼：`UNDERWATER-SHEAR-CHAIN-CUTTER01`）管理自水下探摸至鎖鏈斷裂之完整流程：

```
[ SONAR_DIVE_SEARCH ] (水底摸索鐵索鏈環節點)
          │
          ├── 水流過急無法立足 ──> [ ANCHOR_STABILIZATION ]
          ▼
[ MOUNT_SHEAR_FRAME ] (安裝雙向卡爪固定於鐵索)
          │
          ├── 遭遇水鬼敵襲 ──> [ DEFENSIVE_DIRK_MELEE ]
          ▼
[ THERMAL_SOFTENING ] (鐘型罩蓄熱炙烤軟化生鐵)
          │
          ▼
[ SCREW_LEVER_SHEARING ] (四人合力旋動螺桿施加剪切壓)
          │
          ├── 剪刃崩口破損 ──> [ SWAP_SPARE_BLADE ]
          ▼
[ CHAIN_RUPTURE_BURST ] (鐵環剪斷崩裂與回彈避險)
          │
          ▼
[ WATERWAY_CLEAR_SIGNAL ] (水面浮標釋放報捷旗訊)
```

### 狀態細部定義

1. **SONAR_DIVE_SEARCH（水下探查）**：
   - 水工持探水竹篙與測鉛潛入江底 2 丈深處，沿暗礁尋找攔江鐵索固定之石犀地錨與水柵樞紐。
2. **MOUNT_SHEAR_FRAME（架設鉸架）**：
   - 將重達 120 斤的青銅鑄鐵鉸切機架卡入目標鐵環外圍，以插銷鎖定防滑卡齒。
3. **THERMAL_SOFTENING（高溫軟化）**：
   - 點燃倒扣銅罩內之密封硫磺火藥丸，高溫隔絕江水集中加熱鐵索達 450 度，使其降伏強度降低 60%。
4. **SCREW_LEVER_SHEARING（螺旋剪切）**：
   - 4 名壯士轉動加長雙向絞輪螺桿，利用 1:24 齒輪減速比產生超過 15 噸之局部剪應力。
   - 耗時約 90 秒，合金刃口逐步切入紅熱鐵環。
5. **CHAIN_RUPTURE_BURST（斷鎖回彈）**：
   - 鐵環斷裂瞬間，整條承受千斤水流拉力的攔江鐵索發生強烈縱向回彈，水下部隊必須於斷裂前 5 秒撤至掩體後方，避免被回彈巨索砸死。
6. **WATERWAY_CLEAR_SIGNAL（開道報捷）**：
   - 水工向水面釋放塗硃砂紅漆之充氣木標，通知後方樓船艦隊揚帆全速衝關。

## 3. 關鍵數值與計算判定公式

### 3.1 鐵索剪斷臨界應力公式

水下剪斷鐵索所需機械推力 $F_{shear}$ 計算：
$$F_{shear} = \tau_{yield} \times 2 \times \frac{\pi d_{link}^2}{4} \times (1.0 - \beta_{thermal})$$
- $\tau_{yield}$：生鐵屈服抗剪強度（約 $180\,\text{MPa}$）。
- $d_{link}$：鐵索鏈徑（約 $0.06\,\text{m}$）。
- $\beta_{thermal}$：高溫軟化折減因子（充分加熱時達 0.60）。
- 計算得熱剪切所需極限推力降至約 203 kN，落於 4 人手動齒輪螺桿極限承載範圍內。

### 3.2 破障工期與急流阻力衰減

完成單處攔江鐵索切斷之總工期 $T_{total}$（秒）：
$$T_{total} = T_{base} \times \left(1.0 + \frac{V_{current}^2}{8.0}\right) \times \left(\frac{100}{\text{EngSkill}}\right)$$
- $T_{base}$：基準剪切時間（180 秒）。
- $V_{current}$：長江斷面流速（m/s，峽口急流可達 2.8 m/s）。
- $\text{EngSkill}$：水工隊工程技術熟練度評級。

## 4. 戰術連鎖與攻防克制

1. **破江防核心陣線**：敵方依賴鐵索橫江之優勢完全瓦解，長江水道暢通無阻。
2. **戰術反制與風險**：
   - **兩岸滾木雷石襲擾**：水柵兩側若有敵軍崖頂砲臺，投擲巨石入江產生震波將重創水工。
   - **江底暗箭倒刺**：水柵柱底若插有塗毒竹籤，摸索時有 30% 機率刺破手足染毒。

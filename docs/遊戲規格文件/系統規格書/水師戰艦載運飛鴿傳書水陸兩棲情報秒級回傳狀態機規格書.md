# 3KLife 水師戰艦載運飛鴿傳書水陸兩棲情報秒級回傳狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 跨江跨海之水陸兩棲超遠程通訊系統（`PIGEON-DISPATCH-SHIP01`）。重現古代江防要塞與水師戰艦在孤懸江心、深陷敵重圍時之緊急情報網絡：主力戰艦配備遮雨通風之專用「船載信鴿籠舍」，隨軍豢養受訓馴化之軍用信鴿。遭遇敵襲時，將密碼軍情縮微書寫於蠟丸竹筒中放飛，越過水面敵軍封鎖線，秒級回傳岸上水寨基地以調動援軍。

## 4. 飛行巡航、獵鷹截擊與援軍響應公式

### 4.1 飛行速度與抵達時間推演
信鴿飛行時速一般在 70 至 90 公里/小時：
$$T_{\text{flight\_hours}} = \frac{\text{FlightDistanceKm}}{80 \times \left(1.0 + \frac{\text{TrainingGrade}}{10}\right)} \times \text{WeatherFlightCoeff}$$
- 晴空順風時，200 里水網僅需 1 至 2 個時辰即可傳達；
- 遭遇雷暴大風（$\text{WeatherFlightCoeff} = 2.5$），飛行時間加倍且折翼迷航機率上升。

### 4.2 空中被獵鷹金雕截擊機率
敵方若在江防要塞豢養獵鷹（「放鷹截信」）：
$$P_{\text{intercept}} = \left(0.15 + \frac{\text{EnemyFalconryLevel} \times 0.1}{1.0}\right) \times \left(1.0 - \frac{\text{TrainingGrade} \times 0.15}{1.0}\right)$$
- 5 級精訓軍鴿（高空避障穿雲），被截獲率強制降至 $5\%$ 以下；
- 成功抵達後，陸上守備步騎兵團響應速度提前 2 個回合，實現內外夾擊。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-PIGEON-01**：在江面戰艦起火燃燒（船體耐久度 $\le 20\%$）時，船載鴿舍受濃煙威脅，若未及時放飛，信鴿有 $80\%$ 機率窒息身亡。
2. **驗收 CASE-PIGEON-02**：當戰艦移動至距離母港要塞超過 500 公里之遠洋水域，超出信鴿本能導航半徑，放飛指令反灰禁用。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

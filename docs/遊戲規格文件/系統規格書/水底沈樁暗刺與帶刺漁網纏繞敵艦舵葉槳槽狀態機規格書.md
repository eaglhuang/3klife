# 3KLife 水底沈樁暗刺與帶刺漁網纏繞敵艦舵葉槳槽狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 水寨海防陣地之水下被動防禦工程系統（`WATER-OBSTACLE-NET01`）。重現古代水寨前沿於水面之下暗設之絕殺機關：斜削尖銳之堅硬硬木沈樁（沒於水下半尺，專刺船底）、以及垂掛沉石且綴滿生鐵倒鉤之粗麻浸油巨網。敵方戰艦高速突入時，舵葉、船槳被鐵鉤粗網死死纏絞，舵機瞬間卡死打轉，成為兩岸箭塔之固定活靶。

## 4. 穿刺破底、舵機纏絞與工兵排障公式

### 4.1 水底沈樁暗刺穿孔損害
敵艦吃水深度 $D_{\text{draft}}$ 超過沈樁水深 $D_{\text{spike}}$ 時：
$$\text{SpikePunctureDamage} = (\text{VesselSpeedMps})^2 \times \text{SpikesSharpnessLevel} \times 15$$
- 輕舟吃水淺可直接滑過沈樁上方；大型樓船吃水深（$>2.5\text{m}$），必定觸樁破底，船體耐久直接扣減 $35\%$。

### 4.2 帶刺巨網纏死槳槽機率
戰艦槳櫓高速划水時之纏繞檢定：
$$P_{\text{jam}} = \min\left(0.95, \frac{\text{IronHookNetDensity} \times 0.8 + \text{VesselOarsCount} \times 0.5}{100}\right)$$
- 判定纏死後，航速下降 $90\%$，舵機完全卡死，戰艦強制原地順水打轉；
- 岸防箭塔對該艦攻擊享有 $+50\%$ 命中率與暴擊率。

### 4.3 工兵乘輕舟割網清障
工兵部隊以鐵剪水斧排障：
$$\Delta \text{ClearPercent} = \frac{\text{PioneerCount} \times 10}{1.0 + \text{ArcherySuppressionOnPioneers}}$$
- 排障進度達 $100\%$ 後，該格水下障礙徹底清除，水道恢復平穩通行。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-NET-01**：在無清障先鋒探路時，主力戰艦群盲目突入沈樁區，前鋒 2 艘戰艦強制判定舵機絞死並擱淺於木樁之上。
2. **驗收 CASE-NET-02**：當沈樁遭火攻火筏高溫焚燒或洪水巨浪沖刷後，木樁折斷，暗刺傷害自動降低 $70\%$。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

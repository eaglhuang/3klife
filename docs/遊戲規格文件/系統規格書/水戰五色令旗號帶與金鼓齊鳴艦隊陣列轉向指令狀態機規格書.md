# 3KLife 水戰五色令旗號帶與金鼓齊鳴艦隊陣列轉向指令狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 大規模水戰艦隊協同指揮系統（`FLAG-SEMAPHORE-FLEET01`）。重現東吳水師周瑜、陸遜調度數百艘艨艟樓船之指揮體系：江上波濤翻滾、風聲雷動，軍令無法以口傳達，遂於中軍巨型旗艦之三層瞭望樓設立五色大旗（青、赤、白、黑、黃），配合巨型牛皮大鼓與銅鑼，實施遠距視覺旗語與金鼓協同轉向指令。

## 4. 視距辨識、傳令延遲與指揮混亂公式

### 4.1 旗語遠程識別成功率
各翼分艦隊瞭望手辨別主帥旗語之檢定：
$$P_{\text{read\_flag}} = \left(1.0 - \frac{\text{DistanceGrids}}{12}\right) \times \text{WeatherVisibilityCoeff} \times \left(1.0 + \frac{\text{LookoutSkill}}{200}\right)$$
- 距離大於 10 格且逢江面晨霧（$\text{Visibility} \le 0.4$），識別率驟降至 $20\%$ 以下；
- 識別失敗之分隊將維持原航向前進，導致主力陣列被拉扯撕裂。

### 4.2 轉向陣列協同耗時公式
全軍數十艘戰船完成編隊變更所需回合：
$$T_{\text{turn}} = \max\left(1, \left\lceil \frac{\text{VesselsCount} \times 0.05}{\text{AdmiralCommandStat} / 100} \right\rceil\right)$$
- 水師名都督（周瑜、陸遜、關羽）指揮值超過 90，可於 1 回合內如臂使指完成變形；
- 旗艦主旗桿若遭投石機砸斷，全水軍陷入 `UNGUIDED` 狀態，各艦戰力扣減 $30\%$。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-FLAG-01**：在黑夜戰場無火把照明之情況下，五色旗語指令強制失效，僅允許依靠大鼓銅鑼下達前進或後退之單一指令。
2. **驗收 CASE-FLAG-02**：當旗艦被敵軍艨艟接舷白刃搶奪時，旗語中斷，周邊護航戰艦強制放棄轉向，全速向旗艦靠攏實施保衛。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

## 1. 系統架構定位與水上作戰範式

大江東去，浪淘盡千古風流人物。三國水戰（赤壁之戰、夷陵之戰、濡須口之戰）具備完全迥異於陸戰平原的動態物理法則。《三國人生》（3KLife）實裝**水戰戰艦分級與風浪顛簸物理模型（Naval Fleet Physics）**。

本系統核心價值：
1. **四大艦艇層級生態位（Vessel Hierarchy）**：樓船如城堡、蒙衝如鐵鎚、鬥艦如重裝衛士、走舸如疾風刺客。
2. **水流水向與風浪牽引（Current & Waves）**：水流與波浪向量即時推動船隻位移，順流衝撞威力倍增。
3. **北方陸軍暈船狀態機（Seasickness Penalty）**：缺乏水性之將士登船承受持續性眩暈與戰力滑坡。

## 3. 風浪顛簸與「暈船眩暈」狀態機

當作戰部隊登船出征時，檢測主將與隨軍士卒的「水軍適性（Naval Aptitude）」：

```typescript
export enum NavalAptitude {
  S = 'S', // 舟師大都督 (周瑜、甘寧、陸遜)：風浪如平地，移動力 +1，水戰暴擊 +20%
  A = 'A', // 嫻熟水性 (東吳名將群)：無任何水上減益
  B = 'B', // 略通水戰 (荊襄降軍)：受大浪時有 20% 輕微眩暈
  C = 'C'  // 北方旱鴨子 (曹魏諸將)：極易陷入深度暈船
}
```

適性為 `C` 級之部隊在水上航行，每回合依當前水面風浪等級（Wave Force 1~3）執行眩暈檢核：
- **風浪 2 級以上**：旱鴨子部隊高達 **$75\%$ 機率陷入「暈船嘔吐（Seasick）」**：
  - 物理近戰命中率暴跌 $-35\%$，遠程射擊射程強制鎖定為 1 格。
  - 防禦力折減 $25\%$，部隊每回合士氣自然扣除 $3$ 點。

## 4. 水流漂移與衝撞拍竿結算

1. **水流向量推動（Current Drift）**：長江水流具備常駐向東流速向量 $\vec{V}_{\text{river}}$。回合結束時，所有錨泊未固定的船隻沿水流方向自然**向順流方向位移 1 格**。
2. **順流衝撞（Downstream Ramming）**：順流航行之蒙衝發動撞擊，傷害乘數為 $1.5 + \text{Speed}_{\text{vessel}} \times 0.2$；若擊中敵船側面，造成「船身破裂（Hull Breach）」，每回合扣除最大耐久 10%。
3. **水鬼鑿沉（Water Saboteurs）**：走舸部隊可施放「水鬼下水」，潛渡至相鄰大型樓船底盤，有 $40\%$ 機率直接鑿沉敵艦。

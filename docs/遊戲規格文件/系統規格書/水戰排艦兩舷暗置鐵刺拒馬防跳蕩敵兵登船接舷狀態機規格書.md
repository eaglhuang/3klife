# 3KLife 水戰排艦兩舷暗置鐵刺拒馬防跳蕩敵兵登船接舷狀態機規格書

## 1. 系統定位與設計意圖

在三國江面艦隊接舷肉搏戰（如甘寧百翎水鬼劫營、濡須口大艦對決）中，敵方輕快艨艟與走舸常利用航速優勢快速切入主力樓船兩舷盲區，投擲搭鉤牽引並架設飛梯木板（搭板），試圖發動跳蕩近身登船奪艦。本系統規範水戰艦體被動外防禦工程「兩舷暗置外伸鐵刺拒馬防登船阻絕陣列（Naval Boarding Abatis Denial）」之鉸鏈平推、外伸倒刺、搭板懸空與落水阻截狀態機：
- **舷側外掛式鉸鏈斜撐拒馬**：在樓船兩舷女牆下方半丈處，安裝十組以生鐵鉸鏈鉸接之重木刺排，表面密植四寸生鐵淬火三棱倒刺。
- **接舷前夕向外翻出鎖死**：敵船逼近至兩丈時，守軍拔出固定銷，刺排受自重與反拉索向舷外呈 45 度角翻下鎖定，外伸達四尺。
- **使敵跳板懸空與跳蕩摔落**：敵艦搭板搭上時無法搭至女牆垛口，而是被鐵刺架起懸空並戳穿；敵跳蕩兵盲目飛躍時直接被鐵刺貫穿或跌入長江激流。

## 2. 狀態機架構與轉換生命週期

舷側防登船狀態機（代碼：`NAVAL-BOARDING-ABATIS-DENIAL01`）管理自收納巡航至刺穿瓦解之完整週期：

```
[ RETRACTED_FLUSH_STOWAGE ] (航行中拒馬貼附兩舷減少水流阻力)
          │
          ▼
[ BOARDING_ALERT_ALIGNED ] (敵快艇意圖抵近兩舷發起接舷)
          │
          ├── 拔出安全插銷
          ▼
[ DEPLOY_OUTWARD_LOCK ] (刺排外翻四十五度生鐵斜撐自鎖)
          │
          ├── 敵飛爪木板拋來 ──> [ PLANK_TILT_SUSPENDED ]
          ▼
[ BOARDING_DENIAL_IMPALEMENT ] (跳蕩死士踏空摔落或被三棱刺穿透)
          │
          ▼
[ COUNTER_POLE_THRUST ] (女牆守軍長篙推拒敵船徹底掀翻走舸)
          │
          ▼
[ RETRACT_RESTOW_SECURE ] (解除接舷危機手搖絞盤收回拒馬)
```

### 狀態細部定義

1. **RETRACTED_FLUSH_STOWAGE（貼舷收納）**：
   - 拒馬平整貼合於女牆外板，兩端以生鐵鏈銷扣死，航行時不增加江面流阻，敵軍自遠處難以察覺。
2. **BOARDING_ALERT_ALIGNED（預警備戰）**：
   - 觀察哨吹響急促螺號，警告兩舷即將遭遇敵軍艨艟貼靠，甲板水手就位拉動解鎖拉環。
3. **DEPLOY_OUTWARD_LOCK（外翻鎖死）**：
   - 刺排向外翻落，三角斜撐木自動卡死在船殼加厚龍骨外肋之上，形成寬四尺之生鐵倒刺阻絕帶。
4. **PLANK_TILT_SUSPENDED（架空搭板）**：
   - 敵軍拋擲之接舷木板端部落在鐵刺尖端，滑偏並呈 30 度斜角傾覆，無法形成穩定通行平臺。
5. **BOARDING_DENIAL_IMPALEMENT（穿刺阻截）**：
   - 企圖強力跳躍之敵方跳蕩兵被三棱刺刺穿足掌與腿甲，90% 跌落至兩艦間狹窄夾縫被夾擊溺斃。
6. **COUNTER_POLE_THRUST（推離解危）**：
   - 守軍持丈八生鐵包頭長篙抵住敵艨艟側舷合力外推，破除其咬合搭鉤，敵船失去平衡漂離。

## 3. 關鍵數值與計算判定公式

### 3.1 敵軍登船跳蕩失敗與傷亡率模型

敵方跳蕩部隊登船失敗墜海率 $P_{fail}$ 計算：
$$P_{fail} = \text{clamp01}\left(0.40 + \frac{L_{abatis\_protrude}}{1.5} \times C_{spike} - \frac{\text{Agility}_{marine}}{200}\right)$$
- $L_{abatis\_protrude}$：拒馬外伸投影寬度（標準 1.2 公尺）。
- $C_{spike}$：生鐵三棱刺密度係數（取 0.85）。
- $\text{Agility}_{marine}$：敵軍跳蕩死士敏捷度。
- 計算得常態接舷敵軍登船失敗率高達 88%，近身肉搏威脅被化解於舷外。

### 3.2 結構抗撞擊剪應力容限

拒馬生鐵鉸鏈所能承受之最大衝撞剪應力 $\tau_{hinge}$：
$$\tau_{hinge} = \frac{M_{ram\_boat} \times V_{boat\_lateral}^2}{2 \times N_{brackets} \times A_{pin}} \le 220\,\text{MPa}$$
- 足以抵禦 15 噸輕型走舸在 3 節航速下之側向碰撞而不發生脫落。

## 4. 戰術連鎖與攻防克制

1. **守護主力戰艦心臟**：使大型樓船、旗艦免遭敵精銳死士突入斬首，保持遠程火砲輸出環境。
2. **天敵與敵方反制**：
   - **大斧橫砍鉸鏈**：若敵跳蕩兵配備超長柄開山斧，連續劈砍支撐斜木，可破壞單組拒馬。
   - **火箭點燃木構**：若被敵方火箭直接命中未浸水之拒馬主木，木構燒損將使其承重失效。

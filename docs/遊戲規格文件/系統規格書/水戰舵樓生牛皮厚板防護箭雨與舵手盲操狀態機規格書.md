# 3KLife 水戰舵樓生牛皮厚板防護箭雨與舵手盲操狀態機規格書

## 1. 系統概述與設計哲學
在長江水戰中，戰艦之航向掌控與陣列機動全繫於艦尾舵樓（HELM-ARMOR-BLIND-STEER01）。
敵軍交戰時多以重型床弩、淬毒漫天箭雨或火矢專門狙殺敵艦舵手，意圖癱瘓其機動舵效。為此，三國重型鬥艦與樓船舵樓採用夾層防護：外覆厚重生牛皮、中夾浸鹽青岡木板、內設雙重銅栓。在極端密集箭雨下，舵手放下瞭望鐵柵閉鎖射孔，轉入「盲操模式」——完全仰賴銅管傳聲筒、主檣觀旗兵號令與艙底沉浮刻度進行轉舵，保障全艦於烈火毒箭狂飆中始終維持航道與編隊隊形。

## 3. 狀態機生命週期轉換

```
[ OPEN_STEERING ] (開窗目視直接引航)
       │
       ▼ (遭遇密集火箭或敵艦接舷箭雨)
[ ARROW_HAIL_BATTEN ] (重甲護板放下鎖定)
       │
       ▼ (轉入盲操，銅管聲學傳令)
[ ACOUSTIC_BLIND_STEER ] (盲操聽音舵柄修正)
       │
       ├─────► (舵索中箭破裂) ──► [ RUDDER_CABLE_REPAIR ] (水手緊急搶修接索)
       │                                     │
       │                                     ▼ (修復完成恢復張力)
       │                                回到 [ ACOUSTIC_BLIND_STEER ]
       ▼ (箭雨平息或突破敵艦陣線)
[ COURSE_RESTORED ] (推開觀測柵回歸常態)
       │
       └─────► 回到 [ OPEN_STEERING ]
```

### 3.1 狀態轉移詳細規則表
| 起始狀態 | 觸發事件 | 終止狀態 | 轉移條件與防禦邏輯 |
| :--- | :--- | :--- | :--- |
| **OPEN_STEERING** | `UNDER_BARRAGE` | **ARROW_HAIL_BATTEN** | 艦尾遭火箭覆蓋，舵手拉動絞盤降下厚木生牛皮護板。 |
| **ARROW_HAIL_BATTEN**| `SEAL_COMPLETE` | **ACOUSTIC_BLIND_STEER**| 觀測孔全閉鎖，通話管開啟，轉入聽音引航模式。 |
| **ACOUSTIC_BLIND_STEER**| `CABLE_SEVERED` | **RUDDER_CABLE_REPAIR** | 遭重型弩箭射裂舵柄牽引索，舵機失控偏航，備用隊搶修。 |
| **RUDDER_CABLE_REPAIR** | `SPLICING_DONE` | **ACOUSTIC_BLIND_STEER**| 搶修隊於 10 秒內完成繩索重結，恢復 $85\%$ 轉向力。 |
| **ACOUSTIC_BLIND_STEER**| `ENEMY_CLEARED` | **COURSE_RESTORED** | 脫離箭雨射程，舵手推開側舷鐵柵，確認地標校正航向。 |
| **COURSE_RESTORED** | `ALL_CLEAR` | **OPEN_STEERING** | 戰艦舵角回正，重新納入艦隊常規指揮鏈。 |

## 4. 防護力學與聲學傳達機制

### 4.1 雙層牛皮抗燃與減震計算
生牛皮經鹽水浸透後具備高度防火延展彈性：
$$D_{taken} = \max(1, (Damage_{incoming} - Armor_{leather}) \times (1.0 - Resist_{core}))$$
- 當生牛皮潮濕度 $> 40\%$ 時，完全免疫點燃狀態；唯受巨石拍竿直接命中時，防護甲板整面崩解。

### 4.2 盲操轉舵誤差與校正
1. **指令傳達延遲**：聲學通話管自前檣傳遞至舵樓約有 $0.4$ 秒延遲，轉向反應略顯遲滯。
2. **偏航修正限制**：在盲操模式下，艦船航向角每回合有 $\pm 3^\circ$ 的微幅隨機漂移，需靠旗兵規律喊話修正。

## 5. 單元驗收測試標準
1. **TC-HELM-01 (密集箭雨防禦保護)**：
   - 注入敵軍連弩 100 矢齊射傷害。
   - 驗證在 `ARROW_HAIL_BATTEN` 模式下，舵手受創概率降至 1% 以下，舵樓耐久僅扣除折減後之微量傷害。
2. **TC-HELM-02 (轉向索斷裂應急修復)**：
   - 模擬重矢射穿舵索，驗證系統切換至 `RUDDER_CABLE_REPAIR`。
   - 搶修完成後航向操縱力恢復，不致產生永久停船。
3. **TC-HELM-03 (盲操轉目視全流程迴圈)**：
   - 模擬開窗 -> 遭襲封閉盲操 -> 脫險重開航向校正完整生命週期。
   - 驗證狀態無縫回歸 `OPEN_STEERING`。

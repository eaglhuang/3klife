# 3KLife 水戰輕舟滿載乾燥荻草膏油順風火帆衝撞敵排艦狀態機規格書

## 1. 系統定位與設計意圖

在三國長江著名水戰（如赤壁之戰黃蓋赤馬舟火攻、東吳火燒劉備夷陵水寨）中，面對敵軍以鐵鎖相連、體積龐大之連環戰艦，正面樓船對轟極難速勝。本系統規範水戰終極火攻突擊武器「滿載荻草火油之順風衝鋒火船（Fire Skiff Reed-Oil Ramming）」之乾料裝填、張帆順風加速、生鐵倒鉤撞入咬合與火勢連環蔓延狀態機：
- **艙內滿載乾燥荻草蘆葦與魚膏**：輕型赤馬舟內部塞滿極易引燃之蘆葦乾柴，通體澆透黏稠魚膏與猛火油，外蒙浸油絹布防江水打濕。
- **生鐵四爪倒鉤長撞釘**：船頭安裝長丈餘之生鐵巨釘與雙側倒爪，衝撞敵艦吃水木板後深深刺入並咬死，使敵艦無法將其撐開推離。
- **引火順風全速衝鋒與死士跳板脫離**：死士操舵借助東南順風全速衝刺至敵艦前 30 步，點燃艙內引信後跳入後方牽引之輕巧逃生小艇脫離。

## 2. 狀態機架構與轉換生命週期

水上火船衝撞狀態機（代碼：`FIRE-SKIFF-REED-OIL-RAMMING01`）管理自整備點火至連環引燃之完整週期：

```
[ DRY_REED_OIL_LOADING ] (艙內塞滿荻草澆灌魚膏安裝船頭倒鉤)
          │
          ▼
[ WIND_VECTOR_FULL_SAIL ] (借東南狂風全帆加速狂飆前進)
          │
          ├── 敵艦弓弩攔截 ──> [ BULL_HIDE_DECK_DEFLECT ]
          ▼
[ FUSE_IGNITION_ESCAPE ] (抵達三十步點燃引信死士跳登逃生艇)
          │
          ▼
[ RAM_LATCH_COLLISION ] (鐵倒鉤撞透敵艦船舷死死咬合不脫)
          │
          ▼
[ INFERNO_SPREAD_CHAIN ] (百尺烈焰吞噬敵艦順風引燃連環排船)
          │
          ▼
[ FLOTILLA_COLLAPSE_SINK ] (敵艦隊龍骨燒斷全線崩潰沉沒)
```

### 狀態細部定義

1. **DRY_REED_OIL_LOADING（裝料改裝）**：
   - 工兵將 12 艘快舟進行輕量化改裝，艙內裝入乾燥荻草三千斤，淋上稠化魚油猛火油，船艏安裝生鐵倒爪撞角。
2. **WIND_VECTOR_FULL_SAIL（借風全帆）**：
   - 舵手觀測風信，待東南風風速達到 5 級（約 8.5 m/s）以上時升起全帆，航速飆升至 9 節。
3. **FUSE_IGNITION_ESCAPE（點火脫離）**：
   - 衝至距敵艦隊 30 步時，三名舵手同時拉開硫磺引線，烈火瞬間吞噬主甲板；死士順後舷牽引繩躍入走舸小艇划槳脫離。
4. **RAM_LATCH_COLLISION（倒鉤咬死）**：
   - 無人火船攜帶巨大動能狠狠撞入敵巨艦吃水線木板，生鐵倒爪穿透入木三尺，敵長柄推篙根本無法推開。
5. **INFERNO_SPREAD_CHAIN（烈焰連鎖）**：
   - 火勢順狂風猛烈刮向敵艦桅杆與船帆，因敵排船以鐵鎖相連無法解散，烈火在 5 分鐘內蔓延相鄰八艘戰艦。
6. **FLOTILLA_COLLAPSE_SINK（全線沉沒）**：
   - 艦載敵軍士氣瞬間歸零跳水逃生，整支江防防線完全瓦解。

## 3. 關鍵數值與計算判定公式

### 3.1 衝撞倒鉤咬合力與防推開判定

倒鉤刺入木舷之拔出力 $F_{extract}$ 計算：
$$F_{extract} = N_{barbs} \times \sigma_{wood\_shear} \times A_{hook} \times (1.0 + \text{CharredFriction})$$
- $N_{barbs}$：倒刺數量（4 爪）。
- 敵軍需要輸出超過 3500 公斤之拉力方能拔除倒鉤，在烈火炙烤下普通長篙士兵完全無法接近。

### 3.2 順風火勢連環擴散時間模型

烈火自單艦蔓延至相鄰戰艦之擴散時間 $T_{spread}$（秒）：
$$T_{spread} = \frac{D_{inter\_ship} \times 12.0}{V_{wind\_speed} \times (1.0 + \text{ChainLockedBonus})}$$
- $D_{inter\_ship}$：相鄰戰艦間距（連環船間距僅 1~2 公尺）。
- $\text{ChainLockedBonus}$：鐵索連環狀態加成（取 0.85）。
- 在 5 級風速與鎖船條件下，單艦蔓延僅需 45 秒，形成「頃刻之間，煙炎張天」。

## 4. 戰術連鎖與攻防克制

1. **破江防巨無霸奇蹟戰術**：以百人代價摧毀十萬水軍之水上要塞，創造長江水戰最大逆轉。
2. **天敵與敵方反制**：
   - **逆風風向突變**：若天公不作美風向突轉，火船倒吹己陣將引火自焚。
   - **輕舟游弋截擊**：敵方若預先派出巡邏巡哨小艇於外圍以長鉤阻截，可提前迫使其減速偏航。

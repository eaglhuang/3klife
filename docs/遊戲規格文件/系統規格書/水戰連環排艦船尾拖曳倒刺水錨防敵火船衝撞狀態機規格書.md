# 3KLife 水戰連環排艦船尾拖曳倒刺水錨防敵火船衝撞狀態機規格書

## 1. 系統定位與設計意圖

在三國大型水戰泊地與連環船陣防禦（如赤壁戰役反省教訓、濡須口水塢陣地守護）中，排艦連環相鎖雖然提供了平穩的陸戰格鬥平臺，但最致命的破綻是極易遭受順風衝來的敵軍無人火船或自殺快艇直撞引燃。本系統規範長江水寨特種外圍阻隔裝置「兩舷拖曳倒刺水下攔截拖錨系統（Naval Trailing Grapnel Fire Defense）」之水下深懸、逆流拖曳、倒爪咬合牽絆與火船外圍引爆狀態機：
- **船尾外伸懸索生鐵四爪拖錨**：主力戰艦兩舷與尾樓外側以加長生鐵絞盤長索（長約三十步），於水面下四尺深處拖曳兩具重達兩百斤的生鐵帶刺抓錨。
- **水下攔截咬死敵火船底龍骨**：當敵軍輕快火船順風借浪全速直衝主力艦群時，尚未接觸船舷，其水下龍骨或木質龍骨已被水下拖錨倒刺死死勾住咬合。
- **強大拉力使火船偏航自焚**：巨艦龐大的錨泊阻力與長索牽引使火船瞬間失速並發生劇烈打轉偏航，在距離主力排艦二十步外的安全水域燃盡沉沒。

## 2. 狀態機架構與轉換生命週期

水下拖錨防禦狀態機（代碼：`NAVAL-TRAILING-GRAPNEL-FIRE-DEFENSE01`）管理自放索拖帶至火船截獲之完整週期：

```
[ ANCHOR_WINCH_DEPLOY ] (絞盤放索三十步兩百斤生鐵四爪錨入水)
          │
          ▼
[ SUBMERGED_TOW_EQUILIBRIUM ] (水深四尺維持拖曳水阻阻截屏障)
          │
          ├── 敵滿載火船順風高速衝來 ──> [ INCOMING_RAM_DETECTED ]
          ▼
[ UNDERWATER_GRAPPLE_LATCH ] (水下倒爪瞬間勾死敵火船龍骨)
          │
          ├── 長索受力繃緊拉扯
          ▼
[ KINETIC_ARREST_SWERVE ] (火船動能驟停強制大幅偏航打轉)
          │
          ▼
[ SAFE_DISTANCE_BURNOUT ] (在二十步外安全水面孤立燃盡沉底)
          │
          ▼
[ CABLE_REEL_IN_RESET ] (水兵手搖絞盤拉回拖錨清除殘骸)
```

### 狀態細部定義

1. **ANCHOR_WINCH_DEPLOY（放索懸錨）**：
   - 舵工操作船艉青銅手搖絞盤，將粗如人臂之生鐵長索放出三十步，兩具雙層四爪生鐵錨沉入水下定深位置。
2. **SUBMERGED_TOW_EQUILIBRIUM（定深巡曳）**：
   - 拖錨藉由專屬平衡水翼保持在吃水 1.2 至 1.5 公尺深度，在排艦外圍構築出一道看不見的水下攔截網。
3. **INCOMING_RAM_DETECTED（火船逼近）**：
   - 望樓發現敵火船借順風以 8 節極速直衝中軍旗艦，全艦進入防衝撞抗火戒備姿態。
4. **UNDERWATER_GRAPPLE_LATCH（水下咬合）**：
   - 火船衝入拖錨防禦圈，生鐵抓爪直接撕裂火船底艙外板，倒刺緊扣龍骨橫樑，咬合成功率達 92%。
5. **KINETIC_ARREST_SWERVE（牽引偏航）**：
   - 火船受到千斤巨艦拖拽力反衝，前進勢頭被硬生生扼止，在水流側力下被迫打轉橫置，無法繼續撞向艦舷。
6. **SAFE_DISTANCE_BURNOUT（安全自焚）**：
   - 火船烈焰在距離主艦二十步處劇烈燃燒，熾熱火舌被江風吹向無人水域，直至船體燒穿自沉。

## 3. 關鍵數值與計算判定公式

### 3.1 拖錨動能阻截與減速公式

敵火船被水下拖錨截獲後之速度衰減 $V(t)$ 計算：
$$V(t) = V_0 \times \exp\left(-\frac{T_{cable\_tension} + F_{anchor\_drag}}{M_{fireship}} \times t\right)$$
- $M_{fireship}$：輕型火船質量（約 2500 kg）。
- $T_{cable\_tension}$：生鐵鏈瞬時抗拉應力（可承受 80 kN）。
- $F_{anchor\_drag}$：四爪錨入水阻力（約 15 kN）。
- 計算得出火船在被咬死後 2.8 秒內速度降至 0.5 節以下，前衝動能完全歸零。

### 3.2 阻絕安全距離餘量檢定

主艦免遭熱輻射點燃之安全間距 $D_{safe}$（步）：
$$D_{safe} = L_{cable} \times \cos(\theta_{drift}) \approx 30 \times \cos(25^\circ) \approx 27.2\,\text{步}$$
- 遠大於猛火油烈焰輻射引燃半徑（約 12 步），確保主力艦生牛皮防護無恙。

## 4. 戰術連鎖與攻防克制

1. **破除火攻絕殺王牌**：徹底封堵以小搏大火攻奇襲之漏洞，捍衛大兵團水上要塞陣地。
2. **天敵與敵方反制**：
   - **潛水水鬼割索**：敵軍若先遣水鬼以鋼鋸切斷拖錨牽引生鐵索，攔截網將提前失效。
   - **極淺水灘擱淺**：若水寨設於枯水期淺灘，拖錨易刮擦江底泥沙淤塞，難以維持正常定深。

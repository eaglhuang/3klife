# 3KLife 水浸城池水上行舟調度與物資防潮保全狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 城池遭遇水浸災厄時之後勤應急與交通調度系統（`CITY-FLOOD-SURVIVE01`）。重現三國城邑遭大水漫灌時（如下邳被灌水、關羽圍襄陽），守城軍民將輜重糧草緊急搬遷至城樓垛口或高聳鼓樓，城內街道化為河道、改以輕舟木筏擺渡巡邏，全力維持防禦指揮與物資防潮保全之應急機制。

## 4. 舟筏調度、防潮損耗與濕冷抗疲勞公式

### 4.1 水浸街道通行效率演算法
城內街道化為水巷後之部隊調度速度：
$$\text{MobilityEfficiency} = \left(\frac{\text{AvailableRafts} \times 20}{\text{GarrisonTroopsCount}} \times 100\right) \times \left(1.0 - \frac{\text{StreetDebrisObstruction}}{100}\right)$$
- 若木筏小舟充裕（每百人配備 5 艘以上），城內行動效率可維持在 $65\%$；
- 無船隻者僅能涉水慢行，調度效率驟降至 $15\%$。

### 4.2 糧草防潮保全與霉變計算
$$\text{SpoiledGrainPerTurn} = \text{TotalGrain} \times \left(1.0 - \frac{\text{HighCapacityPercent}}{100}\right) \times 0.25$$
- 轉移至城樓高處之糧草完全防潮免損；留在地面低窪庫房之糧食每回合損毀 $25\%$；
- 士兵常年泡於水中，若無生薑熱湯驅寒，濕冷疲勞每回合扣除 10 點士氣。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-SURVIVE-01**：在積水消退且街道沉積淤泥時，部隊行軍轉入 `MUD_CLEARING` 狀態，需耗費 2 回合清理城門方能重新出兵。
2. **驗收 CASE-SURVIVE-02**：城內儲糧全部轉移至高樓（$\text{HighCapacity} = 100\%$）時，即使全城積水漫溢，仍可堅守 6 回合以上不失。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

# 3KLife 水軍接舷肉搏跳幫戰飛爪拋擲與奪艦斬將狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 水戰近距登船白刃戰系統（`BOARDING-ASSAULT-01`）。重現三國江東水軍（甘寧、周泰、太史慈、黃蓋）之看家本領：以敏捷之艨艟快船搶佔敵艦側舷上風位，拋擲精鋼飛爪死死鎖定敵艦甲板，水戰死士身披水靠皮甲、手持短刀盾牌騰空躍過跳板，在敵方搖晃之船板上展開血腥肉搏，斬殺敵艦舵手水將並奪取整艘戰艦。

## 3. 資料結構與介面定義

```typescript
export interface BoardingAssaultConfig {
  assaultId: string;
  attackerVesselId: string;
  targetVesselId: string;
  leadAssaultGeneralId: string;        // 跳幫主將 (甘寧、周泰等水軍猛將)
  marinesCount: number;                // 登船死士人數 (30 ~ 150)
  grapplingHookLevel: number;          // 飛爪索具等級 (1..3)
}

export interface ShipCaptureReport {
  targetVesselId: string;
  isCaptured: boolean;
  capturedVesselHealth: number;        // 繳獲戰船剩餘耐久
  attackerMarinesLost: number;         // 攻方死士傷亡
  defenderCrewKilled: number;          // 守方被殲水手
  isDefenderAdmiralBeheaded: boolean;  // 敵主將是否遭陣斬
  fleetMoraleShockApplied: boolean;    // 是否引發全水軍士氣震恐
}
```

## 4. 飛爪咬合、甲板白刃與奪艦斬將公式

### 4.1 飛爪扣舷鎖死機率
兩艦貼身交錯時之接舷鎖死檢定：
$$P_{\text{clamp}} = \left(0.40 + \frac{\text{AttackerWaterAptitude} - \text{DefenderWaterAptitude}}{100}\right) \times \left(1.0 + \text{GrapplingHookLevel} \times 0.15\right)$$
- 若鎖死成功，兩艦被纜繩強制綁定為同一移動坐標，雙方遠程弓弩火力停止，強制進入甲板白刃戰。

### 4.2 甲板白刃血戰與斬將勝率
跳幫部隊與守艦水手之肉搏戰損比：
$$\text{MarineCombatPower} = \text{MarinesCount} \times (1.0 + \text{GeneralBravery}/100) \times \text{WaterInfantryBonus}$$
- 若跳幫將領為甘寧（「錦帆霸氣」）或周泰（「肉身浴血」），個人戰鬥力加成 $+50\%$；
- 當守艦防禦力耗盡，判定主將單挑決鬥或遭斬首：
$$P_{\text{behead}} = \frac{\text{AttackerGeneralMartial} - \text{DefenderGeneralMartial} + 50}{100}$$
- 敵將被斬後，該艦立即掛起降旗轉化為俘獲戰利品（Prize），鄰近敵艦士氣扣減 30 點。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-BOARD-01**：走舸（小型輕舟）禁止對巨型樓船發動跳幫，甲板落差超過 3 丈，死士無法攀登且承受敵艦滾木雷石砸擊。
2. **驗收 CASE-BOARD-02**：若被跳幫戰艦引燃船尾火油意圖同歸於盡，接舷方可在 1 回合內砍斷飛爪纜繩強制脫離，否則兩艦同時焚毀。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

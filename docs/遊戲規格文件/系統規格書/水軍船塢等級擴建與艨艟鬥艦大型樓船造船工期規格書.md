# 3KLife 水軍船塢等級擴建與艨艟鬥艦大型樓船造船工期規格書

## 1. 模組概述與核心定位
本模組為 3KLife 水戰後勤裝備體系之製造核心（`SHIPYARD-NAVAL-01`）。規範沿江、沿海港口城市之水軍船塢升級體系（1 至 5 級）、各型軍艦（走舸、艨艟、鬥艦、樓船、連環巨艦）之物資消耗、建造工期天數，以及武將水戰督造才能之工期縮減機制。確保水戰戰力與城池工業底蘊深度掛鉤。

## 4. 工期推演與督造加速公式

### 4.1 實際造船工期計算
基準建造工期受督造官武將智力、工造及水軍適性共同縮減：
$$T_{\text{actual}} = T_{\text{base}} \times \left(1.0 - \frac{\text{OfficerWisdom} \times 0.2 + \text{NavalAptitudeGrade} \times 5}{100}\right) \times \text{DockLevelBonus}$$
- 其中水軍適性（S=20, A=15, B=10, C=5）；
- 4 級督造坊工期常駐加速 $\text{DockLevelBonus} = 0.85$；5 級天工巨閣 $= 0.70$。
- 工期下限不得低於基準工期之 $40\%$。

### 4.2 火攻燒塢戰損結算
當港口遭遇敵軍「火計」或水襲戰敗，船塢內正在建造之船隻：
$$\text{DamageRate} = \text{FireStrength} \times 0.8 - \text{DockDefense} \times 0.3$$
- 若 $\text{DamageRate} \ge 0.7$，建造中之船隻直接化為灰燼、材料全損；
- 若未全損，則進度強制倒退 $50\%$ 並轉入修繕狀態。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-DOCK-01**：非沿水系之內陸城池，船塢選項強制反灰隱藏；只有具備長江、黃河或海濱港口標籤之地格方能建造。
2. **驗收 CASE-DOCK-02**：當庫存「桐油」數量不足時，無法開工艨艟與鬥艦；若強行拼裝，下水後船體耐久度上限直接減半且漏水。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

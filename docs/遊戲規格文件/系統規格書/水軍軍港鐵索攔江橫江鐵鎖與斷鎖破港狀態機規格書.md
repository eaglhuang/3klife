# 3KLife 水軍軍港鐵索攔江橫江鐵鎖與斷鎖破港狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 長江峽谷防線之水上阻絕障礙系統（`CHAIN-BOOM-HARBOR01`）。重現西晉伐吳「千尋鐵鎖沉江底，一片降幡出石頭」以及東吳封鎖西陵峽之戰略工程。防守方於狹窄江面或軍港水門兩岸釘立生鐵地錨，拉扯巨型粗鐵鎖橫亙江面，阻截敵軍艦隊順流長驅直入；進攻方則須以巨型火炬木筏熔燒鐵索、或以重錘工兵破鎖。

## 4. 撞索衝擊、熔鐵斷鏈與拉力極限公式

### 4.1 戰艦盲目強衝撞索傷害
艦隊在鐵索未破時強行衝關：
$$\text{CollisionDamage} = \text{ShipMassTons} \times |\vec{V}_{\text{water}}|^2 \times 0.5$$
- 走舸、艨艟受衝擊直接翻覆沉沒；大型樓船龍骨劇烈變形，船體耐久直接扣減 $60\%$ 並被鎖死於江心動彈不得。

### 4.2 火筏高溫熔斷鐵索計算
進攻方動用塗滿松脂蠟油之巨型大筏（長數十丈）：
$$\Delta \text{MeltPercentPerTurn} = \left(\frac{\text{FlamingRaftsCount} \times 20}{1.0 + \text{WaterQuenchCoeff}}\right) \times \left(1.0 - \frac{\text{DefenderInterference}}{100}\right)$$
- 累積熔斷進度達 $100\%$ 後，生鐵在高溫下軟化斷裂，鐵索沉入江底；
- 長江天塹第一道物理阻絕徹底失效，大軍樓船順流無阻長驅直入。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-CHAIN-01**：在無火筏或巨型破障工兵掩護下，純水軍艦隊嚴禁強渡橫江鐵鎖地格，強行前進則先鋒 3 艘戰艦直接沉沒。
2. **驗收 CASE-CHAIN-02**：守軍在岸邊設有「投石絞盤機」時，可優先砸毀漂流而來之巨型火筏，使熔鎖效率降低 $70\%$。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

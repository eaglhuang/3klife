# 3KLife 水軍輕捷走舸江面哨戒探路與快艇追擊攔截狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 水戰戰場前哨斥候與高速截擊系統（`SCOUT-BOAT-SIGNAL01`）。重現三國歷史中「走舸往來如飛，一人操櫂，數人引弓，矢石所不能及」之輕舟游擊戰術。作為水師主力之眼目，走舸具備極高槳力重量比與極淺吃水，承擔江面水文探測、敵艦偵察、點火報警與包抄追擊殘敵之任務。

## 4. 航速優勢、偵察視野與脫離判定公式

### 4.1 極限航速與水流疊加演算法
走舸在順水全速划槳時之瞬間極速：
$$V_{\text{max}} = \left(V_{\text{base}} + \text{OarsmenLevel} \times 0.8\right) \times \left(1.0 + \frac{\text{SteersmanSkill}}{200}\right) + |\vec{V}_{\text{water}}| \cdot \cos\theta$$
- 走舸極速可達大型樓船之 $2.5$ 倍；
- 由於吃水不足半米，可完全忽視任何水下沈樁與暗礁傷害。

### 4.2 遭遇敵艦追擊脫困機率
當遭遇敵軍中型艨艟圍捕截擊時：
$$P_{\text{evade}} = \min\left(0.95, \left(0.50 + \frac{V_{\text{scout}} - V_{\text{pursuer}}}{5}\right) \times \left(1.0 + \frac{\text{MistCoverFactor}}{2}\right)\right)$$
- 濃霧天候下，走舸脫困機率高達 $95\%$；
- 成功脫離後，回傳敵軍陣列虛實，主帥旗艦獲得次回合 $+20\%$ 戰場主動權判定加成。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-SCOUT-01**：走舸禁止配備重型弩砲與投石機，若強行裝載，航速強制腰斬且遭遇風浪有 $40\%$ 機率直接傾覆。
2. **驗收 CASE-SCOUT-02**：當走舸小隊攜帶信號響箭，發現敵蹤當回合即可瞬時點亮迷霧中 3 格範圍內之敵軍動態。

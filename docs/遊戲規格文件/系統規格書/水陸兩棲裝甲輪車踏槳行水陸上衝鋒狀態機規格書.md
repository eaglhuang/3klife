# 3KLife 水陸兩棲裝甲輪車踏槳行水陸上衝鋒狀態機規格書

## 1. 系統定位與設計意圖

在三國時期江淮沼澤、荊襄水網與黃河淺灘作戰中，單純步騎遇水受阻，而傳統戰船無法登陸。本系統規範水陸兩用特種裝甲攻堅機械「水陸兩棲裝甲輪車（Amphibious Wheeled Chariot）」之戰鬥與轉換狀態機：
- **陸戰裝甲衝鋒**：由步卒或戰馬牽引，外覆生牛皮與柳葉鐵甲，衝擊敵步兵前沿陣列與鹿角。
- **入水形態切換**：抵達灘頭後無縫滑入水中，利用密封艙底浮力浮水，將輪軸棘輪傳動切換為腳踏雙側葉輪（踏槳）。
- **水網越障突擊**：克服淺灘暗泥、江河浮萍阻力，直接渡水實施側翼搶灘登陸或水上衝撞。

## 2. 狀態機架構與轉換生命週期

兩棲戰車狀態機（代碼：`AMPHIBIOUS-WHEELED-CHARIOT01`）管理從陸地行軍至水上航渡的全流程：

```
[ LAND_ASSAULT_MODE ] (陸上鐵甲推進衝擊)
          │
          ├── [ 抵達灘頭斜坡/水陸過渡區 ]
          ▼
[ TRANSITION_WATER_ENTRY ] (入水浮力檢測與棘輪切換)
          │
          ├── 浮力不足/底艙破漏 ──> [ SWAMP_STUCK / FOUNDER ]
          ▼
[ PADDLE_WHEEL_SAILING ] (腳踏側明輪水上推進)
          │
          ├── 遭遇江面射孔攻擊 ──> [ DEPLOY_SIDE_SHIELD ]
          ├── 遭遇暗礁水草纏繞 ──> [ REVERSE_CLEAR_WEED ]
          ▼
[ BEACH_LANDING_CHARGE ] (搶灘登陸與前輪咬地)
          │
          ▼
[ SECURE_BEACHHEAD ] (灘頭破陣與步卒出艙展開)
```

### 狀態細部定義

1. **LAND_ASSAULT_MODE（陸上衝擊）**：
   - 車輪直接接地滾動，受地表坡度與泥濘度影響。衝鋒速度達 12 步/秒，撞擊力道可摧毀輕型木柵。
2. **TRANSITION_WATER_ENTRY（入水轉換）**：
   - 衝入淺水區時，車身密封側板與桐油夾層提供 $3.2\,\text{m}^3$ 浮力儲備。
   - 工兵拉動離合拉桿，將動力輸出由車軸齒輪切換至兩側踏槳葉片（歷時 4 秒）。
3. **PADDLE_WHEEL_SAILING（踏槳航渡）**：
   - 艙內 4 名踏輪死士雙腳踩踏滾筒曲柄，驅動兩舷木質蹼輪葉片拍擊水面推進。
   - 水上航速最高 5 節，逆流時衰減至 2.5 節；轉向半徑依左右舷踏速差調整（最小 8 公尺）。
4. **BEACH_LANDING_CHARGE（搶灘衝鋒）**：
   - 接近對岸灘塗時，車輪底端率先接觸水底泥沙，前軸防滑刺輪咬死地面，推進力疊加陸地抓地力。
   - 以高動能直接衝破敵軍灘頭拒馬，對守軍造成擊飛與士氣壓制。
5. **SECURE_BEACHHEAD（展開防禦）**：
   - 車體前護板外翻降下作為登陸跳板，艙內 12 名跳蕩兵持短刃長盾躍出，建立灘頭陣地。

## 3. 關鍵數值與計算判定公式

### 3.1 浮水重力平衡與吃水深度

兩棲裝甲輪車之水面吃水深 $D_{draft}$ 計算公式：
$$D_{draft} = \frac{M_{vehicle} + M_{crew} + M_{cargo}}{\rho_{water} \times S_{bottom} \times C_{hull}}$$
- $M_{vehicle}$：車體淨重（1800 kg）。
- $M_{crew}$：乘員總重（16 人，約 1120 kg）。
- $M_{cargo}$：軍械配重（約 380 kg）。
- $S_{bottom}$：車底投影受浮面積（約 $5.4\,\text{m}^2$）。
- $C_{hull}$：船型線條浮力係數（取 0.88）。
- 當總重超載導致 $D_{draft} > 0.85\,\text{m}$ 時，水將漫過艙緣，觸發進水沉沒判定。

### 3.2 水陸過渡期動力傳遞效率

入水轉換過程中之推進力 $F_{prop}$：
$$F_{prop} = (1 - \alpha) \cdot F_{wheel\_ground} + \alpha \cdot F_{paddle\_water}$$
- $\alpha$：水深浸沒比例係數（$\alpha = \text{clamp01}\left(\frac{H_{water} - 0.2}{0.6}\right)$）。
- 確保在 $0.2 \sim 0.8\,\text{m}$ 沼澤混亂水域時，不會因單一動力脫鉤而陷入泥沼困死。

## 4. 戰術連鎖與攻防克制

1. **跨河奇襲優勢**：在無橋樑或敵重兵封鎖渡口時，兩棲輪車可於非指定斷面強渡，撕裂防線弱點。
2. **弱點與反制**：
   - **水下木樁阻截**：尖銳暗樁撞擊車底木板易引發結構性破裂。
   - **火箭點燃生牛皮**：若未及時浸潤江水，牛皮表面遭硫磺火箭集中命中時，引燃機率增加 45%。
   - **江底泥潭陷沒**：灘頭若為超深軟爛淤泥，車輪空轉無法咬合將轉入卡死狀態。

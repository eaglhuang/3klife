# 3KLife 江心定深鐵索橫江鐵環浮漂攔阻陣型狀態機規格書

## 1. 系統概述與設計哲學
在長江、漢水與西陵等險隘水域，守軍常藉由地勢鎖控江面通道。「江心定深鐵索浮漂攔阻陣型」（FLOATING-RING-BOOM01）為水戰重型防禦工程體系。
該工程結合兩岸懸崖生鐵地錨、江心重石固底水錨、中段巨大桐木浮漂、以及相扣的粗重熟鐵環鏈。透過配重沉石與浮力平衡機構，使粗大鐵索隨潮水水位動態起伏，維持在水面下 0.5 至 1.5 公尺之致命「吃水阻截深度」，能迫使順流疾馳之敵軍艨艟撞碎船首、衝角折斷或龍骨受阻擱淺，並配合兩岸望樓床弩進行集火殲滅。

## 4. 水文物理與力學計算模型

### 4.1 潮汐升降定深自平衡機制
利用配重沉子與桐木浮漂之相對浮力差進行吃水深度校正：
$$D_{effective} = D_{nominal} + (H_{tide} - H_{baseline}) \times (1.0 - \alpha_{buoyancy})$$
- 保持鐵索無論在枯水期或汛期，皆能維持在敵船底艙撞擊帶（吃水線下 $0.8 \pm 0.3$ 公尺）。

### 4.2 火攻破壞與抗熔特性
1. **耐火性判定**：鐵索本身具備極高熔點，普通火矢或小型走舸燃燒無法破壞索體。
2. **大火炬高溫烘烤弱化**：若遭遇大型桐油大筏持續炙烤（如王濬故事），金屬屈服強度每分鐘降低 $8\%$，連續受熱達 8 分鐘時，張力極限下降至 $30\%$。

## 5. 單元驗收測試標準
1. **TC-BOOM-01 (艨艟衝擊截停測試)**：
   - 設定標準中型艨艟以最高航速 12 節順流撞擊索陣。
   - 驗證鐵索張力在 1800 kN 內完成動能吸收，艨艟航速在 2 秒內降至 0 並受困原地。
2. **TC-BOOM-02 (極限斷索與備用沉錐聯動)**：
   - 超大型樓船連環衝撞觸發張力超載（$> 2500$ kN）。
   - 驗證觸發 `CHAIN_OVERLOAD_YIELDING` 後，立刻喚醒 `EMERGENCY_DROP_LOCK`，迫使江底鐵錐就位刺穿船底。
3. **TC-BOOM-03 (水文水位位移公差驗證)**：
   - 注入暴雨洪峰水情（水位暴漲 2.5 公尺）。
   - 驗證浮漂平衡模組保持索身在水下 $0.8$ 公尺深度公差範圍內，不致沉底或露空。

# 3KLife 江心險灘水底隱匿生鐵暗樁撞裂敵船龍骨狀態機規格書

## 1. 系統概述與設計哲學
在長江險隘要衝（如西陵峽、濡須口、赤壁外灘）之水域防禦中，水面鐵索浮排若被敵火筏燒斷，江面航道將面臨全面失守。三國江東水師核心暗水防禦工程「水底隱匿生鐵暗樁陣」（SUBMERGED-SPIKE-OBSTACLE01）。
水軍工兵乘重型平底駁船，在水流湍急之暗礁淺灘處，使用重錘沉箱將長逾丈餘之生鐵銳利尖錐或包鐵巨木樁斜向打入江底岩盤泥沙中。暗樁頂部隱沒於潮水吃水線下數尺，平日肉眼無法察覺。順流狂飆之敵軍重型樓船、艨艟一旦駛入暗樁地格，尖銳生鐵錐頭將以數萬焦耳動能直接豁穿船底木板並撕裂龍骨，造成江水洶湧倒灌、船體傾斜擱淺，隨後由沿江水鬼與走舸登船生擒。

## 4. 龍骨穿刺力學與水阻流體動力學

### 4.1 順流衝撞穿刺動能轉換
戰艦順水而下具備極大慣性動能：
$$E_{\text{impact}} = \frac{1}{2} M_{\text{ship}} \times (V_{\text{ship}} + V_{\text{current}})^2$$
- 龐大動能集中於尖銳生鐵錐尖，壓強超過木質龍骨屈服極限十倍以上，必引發船底縱向貫穿撕裂性破洞。

### 4.2 險灘水鬼打撈俘獲機制
1. **水鬼登艦優勢**：受創敵船水手全力排水救生，陷入混亂，水鬼跳幫時近戰攻擊力提升 $40\%$。
2. **完整戰艦繳獲**：若在 60 秒倒計時內擊潰敵甲板守兵並堵漏，該受損敵艦可被原樣繳獲修復。

## 5. 單元驗收測試標準
1. **TC-SPIKE-01 (水底暗樁隱匿與穿刺全流程)**：
   - 模擬敵軍千斛大艦順流全速駛入暗樁區。
   - 驗證龍骨承受 380 點穿刺傷害，航速驟減 80%，轉入 `SHIP_FLOODING_STRAND`。
2. **TC-SPIKE-02 (水鬼引航免撞驗證)**：
   - 本方戰艦配置熟知水情之水鬼領航，驗證避開暗樁成功率達 85% 以上，安全穿行。
3. **TC-SPIKE-03 (沉沒倒計時與繳獲俘獲)**：
   - 敵船進水觸發 60 秒倒計時，水鬼出動登船奪艦，驗證成功奪舵並終止沉沒。

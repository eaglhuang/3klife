# 3KLife 江面浮筒竹排載負投石機水上浮動砲臺轟擊水寨狀態機規格書

## 1. 系統定位與設計意圖

在三國攻打江東水寨、荊州江防堡壘時，沿岸險要陡峭，常規陸基投石機無法推近，而一般戰船甲板承受不住千斤梢桿配重甩投的反作用力。本系統規範大型水上攻城兵器「水上浮動投石砲臺（Floating Bamboo Catapult Battery）」之水上陣位部署、射擊配重穩定與水寨轟擊狀態機：
- **巨型浮動基座**：由百根粗壯南竹捆扎成多層井字竹排，兩側綁縛密封桐油木桶作為反傾覆浮筒，提供高達十噸之浮力。
- **水上反衝減震**：底排浸水緩衝與重型八向拖錨固定，化解投石機拋投瞬間引發的劇烈縱搖與橫搖。
- **水寨縱深摧毀**：以超遠射程（250 步）連續拋擲巨石與燃燒油罈，粉碎水寨外圍箭樓、望台與防護水棚。

## 2. 狀態機架構與轉換生命週期

水上浮動砲臺狀態機（代碼：`FLOATING-BAMBOO-CATAPULT-BATTERY01`）管理從江心拖曳布設至飽和轟擊之完整週期：

```
[ TOWING_DEPLOYMENT ] (小艇拖曳至預定江面錨位)
          │
          ├── 遭遇湍流逆浪 ──> [ DRIFT_WARNING / DROP_SEA_ANCHOR ]
          ▼
[ EIGHT_POINT_MOORING ] (八角定向拋錨絞盤繃緊定位)
          │
          ├── 錨爪滑脫/纜繩崩斷 ──> [ RE-TENSION_MOORING ]
          ▼
[ CRANK_TENSIONING ] (絞盤蓄力壓低梢桿裝填巨石)
          │
          ▼
[ WAVE_TIMING_CALC ] (波浪縱搖峰值相位瞄準校正)
          │
          ▼
[ LAUNCH_RECOIL_DAMP ] (引弦釋放砲彈與浮筒吃水吸震)
          │
          ├── 砲臺橫搖劇烈 ──> [ COUNTER_BALLAST_BALANCE ]
          ▼
[ CONTINUOUS_BOMBARDMENT ] (持續彈幕壓制與水寨防線瓦解)
```

### 狀態細部定義

1. **TOWING_DEPLOYMENT（拖曳就位）**：
   - 浮排自身無長途自航能力，由 4 艘艨艟以麻纜牽引至距離敵水寨 200~280 步之平緩江心。
2. **EIGHT_POINT_MOORING（八向定錨）**：
   - 四角與四舷拋下八具四爪生鐵重錨，工兵旋轉手搖絞盤將纜繩全部收緊，使浮臺位移誤差小於 0.5 公尺。
3. **CRANK_TENSIONING（絞盤裝填）**：
   - 六名甲士推動絞盤將砲梢扳低鎖死於擊發扳機，填彈槽裝載 80 斤磨圓青石或瀝青猛火油罈。
4. **WAVE_TIMING_CALC（波浪相位瞄準）**：
   - 水面浮臺受湧浪影響上下起伏，瞄準官需在浮臺縱搖歸零、浪峰轉平之瞬間擊發，修正角度偏差。
5. **LAUNCH_RECOIL_DAMP（釋放吸震）**：
   - 擊發瞬間，梢桿砸下產生 3.8 噸瞬時下壓衝力；浮排下沉 0.3 公尺，井字排下水阻格柵排開江水化解反衝力。
   - 浮筒彈性浮力於 2.5 秒內使砲臺重回水面水平基準。
6. **CONTINUOUS_BOMBARDMENT（持續轟擊）**：
   - 砲臺進入連續射擊循環，每 45 秒發射一發，精準覆蓋水寨望樓，造成結構碎裂與大火蔓延。

## 3. 關鍵數值與計算判定公式

### 3.1 浮排反傾覆穩心高度（GM）

浮動砲臺射擊瞬間之橫向穩定性判定：
$$GM = KB + BM - KG$$
- $KB$：浮心高度（約 $0.45\,\text{m}$）。
- $BM$：橫向穩心半徑（$BM = \frac{I_{waterplane}}{V_{displace}} \approx 2.1\,\text{m}$）。
- $KG$：總重心高度（含高聳投石機配重桿，約 $1.65\,\text{m}$）。
- 計算得 $GM \approx 0.90\,\text{m} > 0$，確保梢桿全力甩投時最大橫傾角不超過 7.5 度，絕對防翻。

### 3.2 湧浪干擾下之落點散佈半徑

巨石落點偏差半徑 $R_{scatter}$（步）：
$$R_{scatter} = R_{base} \times \left(1.0 + \theta_{wave} \times 1.8 - \text{Skill}_{aim} \times 0.01\right)$$
- $R_{base}$：基準散佈（約 3.5 步）。
- $\theta_{wave}$：擊發瞬間浮臺傾角（單位：度，理想抓浪時 $<0.5^\circ$）。
- $\text{Skill}_{aim}$：水軍投石令旗官瞄準專精（滿級 100）。

## 4. 戰術連鎖與攻防克制

1. **超視距拆寨威脅**：使水寨守軍弓弩完全無法還擊，逼迫敵軍主動出寨決戰。
2. **戰術克制與天敵**：
   - **火筏順流焚燒**：浮排固定定錨後無法快速移動，極度懼怕敵軍滿載柴草油脂的無人火船衝撞。
   - **水鬼水下斬錨**：敵方水鬼切斷八向錨纜中的 2 條以上時，平衡失守，射擊命中率暴跌 80%。
   - **急流暗浪翻覆**：若布設於峽谷急流或遭遇狂風暴雨，浮排結構可能承受扭曲應力過載解體。

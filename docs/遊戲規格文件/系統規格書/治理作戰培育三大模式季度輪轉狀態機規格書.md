# 治理作戰培育三大模式季度輪轉狀態機規格書

> **模組識別碼**：`TIME-02`  
> **系統歸屬**：遊戲時間總控（GameClock）模式狀態機  
> **單一真相來源**：本規格書確立遊戲內「治理 $\to$ 作戰 $\to$ 培育」三大模式之單向閉環輪轉順序、模式職責邊界與狀態機合法流轉之唯一權威標準。

---

## 一、系統概述與架構原則

為了構築明確的生活節奏與策略心流，遊戲將宏觀遊戲進程依季度切分為三大主題模式：**治理季（Governance）、作戰季（Battle）、培育季（Nurture）**。模式間採單向不可逆閉環輪轉，每季聚焦特定核心玩法，避免系統功能冗雜散亂。

### Unity / 架構對照
- **主模式狀態機**：類似 Unity 中的 `GamePhaseStateMachine`，透過事件通知切換大廳與子系統互動介面。
- **純列舉流轉**：狀態轉移為純列舉索引運算，不依賴場景切換或非同步載入。

## 二、模式定義與職責邊界

```typescript
export enum GameTimeMode {
    Governance = 'Governance', // 治理季
    Battle = 'Battle',         // 作戰季
    Nurture = 'Nurture',       // 培育季
}
```

### 三大模式職責劃分表

| 模式列舉 (`GameTimeMode`) | 中文名稱 | 核心聚焦功能 | 系統權責與限制 |
|---|---|---|---|
| `Governance` | **治理** | 領地內政、農業商業產出、太守指派、外交送禮 | 產出金幣/糧草/名聲；關閉大規模對外軍事出征 |
| `Battle` | **作戰** | 軍勢出征、名將挑戰賽對抗、討伐亂賊、城池攻防 | 消耗糧草與兵力；產生戰後戰功與俘虜處置 |
| `Nurture` | **培育** | 入學書院、36 回合策論清談、教官授課、弱冠禮 | 外界時間凍結為 1 季；完成後將五維屬性寫回武將本體 |

## 三、單向閉環輪轉演算法

三大模式依照固定順序單向循環流轉：

```
┌──────────────┐     推進 1 季     ┌──────────────┐
│  Governance  │ ──────────────► │    Battle    │
│   (治理季)   │                 │   (作戰季)   │
└──────────────┘                 └──────────────┘
       ▲                                │
       │ 推進 1 季                      │ 推進 1 季
       │                                ▼
       │                         ┌──────────────┐
       └──────────────────────── │   Nurture    │
                                 │   (培育季)   │
                                 └──────────────┘
```

```typescript
const MODE_ROTATION: readonly GameTimeMode[] = [
    GameTimeMode.Governance,
    GameTimeMode.Battle,
    GameTimeMode.Nurture,
];

export function rotateMode(currentMode: GameTimeMode): GameTimeMode {
    const currentIndex = MODE_ROTATION.indexOf(currentMode);
    if (currentIndex === -1) {
        // 非法狀態安全回退
        return GameTimeMode.Governance;
    }
    const nextIndex = (currentIndex + 1) % MODE_ROTATION.length;
    return MODE_ROTATION[nextIndex];
}
```

## 四、介面標籤與展示合約

大廳抬頭顯示器（HUD）依據當前模式即時展示中文本地化名稱：

```typescript
const MODE_LABELS: Record<GameTimeMode, string> = {
    [GameTimeMode.Governance]: '治理',
    [GameTimeMode.Battle]: '作戰',
    [GameTimeMode.Nurture]: '培育',
};

export function formatModeLabel(mode: GameTimeMode): string {
    return MODE_LABELS[mode] ?? String(mode);
}
```

## 五、驗收條件與測試案例 (Test Cases)

- **TC-TIME-05（常規輪轉順序）**：
  - 當前為 `Governance`，推進後精確轉移為 `Battle`。
  - 當前為 `Battle`，推進後精確轉移為 `Nurture`。
  - 當前為 `Nurture`，推進後精確轉移為 `Governance`。
- **TC-TIME-06（三季完成一次完整大循環）**：
  - 連續推進 3 季，模式狀態回到原點 `Governance`。
- **TC-TIME-07（未知模式防禦回退）**：
  - 輸入未知字串或不存在之模式，`rotateMode` 安全回退為 `Governance`。
- **TC-TIME-08（中文標籤對齊）**：
  - `formatModeLabel(GameTimeMode.Nurture)` 精確回傳 `'培育'`。

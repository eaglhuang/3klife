# 3KLife 泰山封禪天壇祈福與國家太廟宗祠祭祖規格書

## 1. 模組概述與核心定位
本模組為 3KLife 勢力正統性與禮制文化之最高治理系統（`SACRIFICE-RITUAL-01`）。涵蓋天子稱帝後的終極功業「泰山封禪」、軍國天災時的「天壇祈禳求雨」、以及鞏固血脈宗族凝聚力的「太廟春秋祭祖」。透過禮儀科儀調動國庫資源、消弭天譴民怨、並將世家福澤深植於歷代嗣子。

## 4. 數值模型與感應結算公式

### 4.1 泰山封禪天命加持公式
主祭國君必須滿足稱帝正統度 $\ge 90$ 且控制泰山郡（兗州泰安）：
$$\Delta \text{HeavenMandate} = 30 + \text{PriestVirtue} \times 0.2 + \text{AuspiciousScore} \times 0.1$$
- 獲得永久被動：境內全城池民怨成長速度下降 40%，外藩朝貢頻率翻倍。

### 4.2 天壇祈雨消災成功率
在遭遇極端旱災（乾旱值 $\ge 80$）時啟動祈禳：
$$\text{RainSuccessRate} = \left(\text{PriestWisdom} \times 0.4 + \text{PriestDivinity} \times 0.6\right) \times \left(1.0 - \frac{\text{LocalRiotIndex}}{200}\right)$$
- 成功時：次回合節氣強制轉為「雨水」或「穀雨」，旱情指數歸零，全城治安 $+25$；
- 失敗時：被士人視為「德不配位」，國君聲望 $-15$，民怨額外 $+10$。

# 3KLife 深夜百騎劫營甘寧式夜襲與敵營炸營驚潰狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 特種夜戰與敵營驚潰系統（`NIGHT-RAID-CAMP01`）。重現三國歷史中甘寧「百騎劫魏營，裹創白羽，折衝左右，無一傷亡」之傳奇戰役。精銳騎兵於三更半夜銜枚潛入，直插敵方中軍大帳，放火鳴金，誘發敵軍在黑夜中敌我不分、自相踐踏殘殺之「炸營（營嘯）」雪崩瓦解效應。

## 4. 潛入隱蔽、炸營判定與營嘯傷亡公式

### 4.1 避開外圍哨兵潛行成功率
$$P_{\text{stealth}} = \left(\text{GeneralBravery} \times 0.4 + \text{NightDarkness} \times 0.4 + \text{MuffleBitBonus}\right) \times \left(1.0 - \frac{\text{CampSentryVigilance}}{150}\right)$$
- 配備人銜枚馬裹蹄時，$\text{MuffleBitBonus} = 30$；
- 潛入成功時，突襲部隊直插敵軍中軍營帳，首輪突襲攻擊享有 $250\%$ 暴擊傷害。

### 4.2 營嘯（炸營）觸發機率公式
黑夜中大火驟起且中軍混亂時：
$$P_{\text{hysteria}} = \left(0.40 + \frac{\text{GeneralDreadStat}}{100} + \frac{\text{EnemyFatigue}}{200}\right) \times \left(1.0 - \frac{\text{EnemyLeaderComposure}}{150}\right)$$
- 敵主將鎮定值（$\text{Composure}$）低於 60 時，營嘯爆發；
- 營嘯爆發後，敵軍每回合造成大量自相砍殺：
$$\text{FriendlyFireDeaths} = \text{TotalCampTroops} \times (0.08 \sim 0.20)$$

## 5. 邊界約束與驗收準則
1. **驗收 CASE-RAID-01**：在敵營構築嚴密哨塔且未到子夜（如初更或黎明）發動夜襲，突襲部隊無法觸發營嘯，且必定陷入外圍拒馬包圍。
2. **驗收 CASE-RAID-02**：若敵方主帥為曹操、司馬懿等具備「臨危不亂」特技之名帥，營嘯在 1 回合內強制被彈壓平息，反擊追殺夜襲部隊。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

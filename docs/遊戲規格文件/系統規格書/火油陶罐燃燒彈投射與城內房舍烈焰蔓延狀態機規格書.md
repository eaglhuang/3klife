# 3KLife 火油陶罐燃燒彈投射與城內房舍烈焰蔓延狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 圍城攻堅之縱火打擊與火災擴散系統（`INCENDIARY-SHOT-01`）。重現古代攻城戰中以配重拋石機換裝「猛火油陶罐 / 瀝青硫磺燃燒彈」之戰術。陶罐點燃浸油火繩高拋越過城牆，砸落於城內木結構房舍、糧秣貨棧，陶罐碎裂猛火油飛濺數丈，引發難以撲滅之烈焰風暴，迫使守軍分散兵力救火。

## 4. 飛濺半徑、風力擴散與撲救隔離公式

### 4.1 陶罐碎裂油火擴散半徑
陶罐砸落地面後之火油飛濺引燃範圍：
$$R_{\text{splash}} = \left(2.5 + \frac{\text{SalvoVolume}}{4}\right) \times \left(1.0 + \frac{\text{DropAltitudeM}}{50}\right)$$
- 猛火油（石油原油）具備極強附著力，水澆不滅，燃燒溫度高達 $900^\circ\text{C}$；
- 飛濺範圍內之木結構建築，引燃機率達 $95\%$。

### 4.2 火勢沿風向擴散演算法
火點向周邊街區蔓延之傳播速度：
$$\vec{V}_{\text{fire}} = \text{BaseCombustionSpeed} \times \left(1.0 + \frac{V_{\text{wind}}}{5}\right) \times \text{BuildingDensityFactor}$$
- 若守城方未及時下令「拆毀臨近房舍開闢十丈隔離帶」，火勢每回合蔓延 2 格；
- 濃煙籠罩城池，守軍弓弩射擊命中率扣減 $30\%$。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-INCENDIARY-01**：在暴雨或大雪天候，火油燃燒持續時間由 5 回合驟降至 1 回合，且無法向周圍磚瓦建築蔓延。
2. **驗收 CASE-INCENDIARY-02**：投射命中石頭城牆或石鋪街道時，僅造成地面燃燒無建築損毀；命中木質城樓與糧倉時，防護耐久每回合扣減 $25\%$。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

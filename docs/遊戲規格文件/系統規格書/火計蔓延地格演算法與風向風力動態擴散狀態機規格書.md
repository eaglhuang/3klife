## 1. 系統架構定位與經典戰略意義

赤壁借東風、夷陵燒連營，火計為三國戰略中最具爆發力之逆轉手段。《三國人生》（3KLife）火計系統結合地形材質、風向風速與氣候狀態，構建動態地格擴散模型。

本系統核心價值：
1. **動態傳播（Dynamic Propagation）**：火焰非固定範圍傷害，而是沿著風向與可燃地格自主擴散蔓延。
2. **連鎖質變（Chained Reaction）**：部隊身陷火海每回合扣除最大兵力百分比與士氣，引發混亂。
3. **場景不可逆毀損（Scorched Earth）**：燃盡之地轉化為焦土，改變戰場地形屬性。

## 2. 地格可燃度矩陣與引燃條件

戰場各類地格之基礎可燃指數 $F_{\text{base}} \in [0, 1.0]$ 與燃燒時長：

```typescript
export interface ITileFlammability {
  readonly terrainType: string;
  readonly baseFlammability: number;     // 基礎引燃概率 (0.0 ~ 1.0)
  readonly burnDurationTurns: number;    // 持續燃燒回合數 (預設 3 回合)
  readonly turnDamageRatio: number;      // 處於火中每回合扣除兵力上限比例
}

export const TILE_FLAMMABILITY_CONFIG: Record<string, ITileFlammability> = {
  FOREST:       { terrainType: 'FOREST',       baseFlammability: 0.85, burnDurationTurns: 3, turnDamageRatio: 0.12 },
  GRASSLAND:    { terrainType: 'GRASSLAND',    baseFlammability: 0.60, burnDurationTurns: 2, turnDamageRatio: 0.08 },
  CAMP_WOODEN:  { terrainType: 'CAMP_WOODEN',  baseFlammability: 0.90, burnDurationTurns: 3, turnDamageRatio: 0.15 },
  WATER_CHAINED:{ terrainType: 'WATER_CHAINED',baseFlammability: 0.95, burnDurationTurns: 3, turnDamageRatio: 0.18 }, // 連環船
  PLAIN:        { terrainType: 'PLAIN',        baseFlammability: 0.30, burnDurationTurns: 1, turnDamageRatio: 0.05 },
  WATER:        { terrainType: 'WATER',        baseFlammability: 0.00, burnDurationTurns: 0, turnDamageRatio: 0.00 }  // 不可燃
};
```

## 3. 八方風向與動態擴散演算法

戰場全局風向風力向量由 `BattleWindState` 控管：
- **風向（Direction）**：北、東北、東、東南、南、西南、西、西北（8 方向）。
- **風力（Force）**：$0$ 級（無風）、$1$ 級（微風）、$2$ 級（強風）、$3$ 級（狂風）。

每回合環境結算時，對所有處於 `BURNING` 狀態之地格，向周圍相鄰 8 格計算引燃擴散機率：

$$P_{\text{spread}} = F_{\text{target}} \times \left(1.0 + \vec{D}_{\text{wind}} \cdot \vec{V}_{\text{tile}} \times \text{Force}_{\text{wind}} \times 0.35\right)$$

```
                    [順風擴散方向: 東南]
               [地格 A] ─── 強風加速 ───► [地格 B: 森林 98% 引燃]
                 ▲                            │
                 │ 微弱擴散                   │ 順風擴散
               [火源中心] ───────────────► [地格 C: 85% 引燃]
```

1. **順風推進（$\cos \theta > 0$）**：擴散機率大幅躍升，狂風（3 級）狀態下一次蔓延跨越 **2 格**。
2. **逆風受阻（$\cos \theta < 0$）**：擴散機率衰減 $80\%$，火焰極難逆風傳播。
3. **熄火條件**：
   - 自然燃燒滿 `burnDurationTurns` 後自動熄滅。
   - 遭遇氣候切換為 `RAIN`（暴雨）時，**全圖火焰於當次回合結束時立即強制熄滅**。

## 4. 焦土轉變（Scorched Earth）與部隊處罰

1. **地形永續轉化**：任何林地或營寨在燃燒結束後，自動轉型為 `SCORCHED_EARTH`（焦土）地格：
   - 該地格本場戰鬥永久喪失隱蔽與防禦加成。
   - 行軍通行消耗 $+1$ 點移動力；且焦土地格可燃度永久降為 $0.0$，無法重複引燃。
2. **部隊灼燒傷害與心理潰敗**：
   - 停留於燃燒地格之部隊每回合強制扣除兵力上限比例生命，無視一般護甲防禦。
   - 士氣每回合額外扣除 $10$ 點，累計 2 回合未脫離火場者，高達 $70\%$ 機率陷入混亂（無法行動且承受傷害 $+25\%$）。

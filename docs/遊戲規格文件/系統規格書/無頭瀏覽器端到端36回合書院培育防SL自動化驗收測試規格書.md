> **規格代碼**：SPEC-QA-E2E01

> **所屬系統**：數值、架構與底層支援（Formula, Architecture & Backend）

## 1. 核心宗旨與設計哲學

潁川書院策論引擎（PROG-2-1902）已在純邏輯層實作 HMAC-SHA256 確定性亂數與 36 回合防 SL 狀態機。為驗證前端 UI 點擊、動態渲染、彈窗打斷與中途強退存檔恢復之真實表現，本規格書制定基於 `puppeteer-core` 之**無頭瀏覽器端到端（E2E）自動化驗收測試規範**。

---

## 2. E2E 自動化驗收時序與中斷注入模型

測試腳本 `tests/e2e/academy-nurture-36turns.e2e.ts` 在無頭瀏覽器中自動推演 36 回合全流程：

```
[回合 0: 選擇教官與種子] -> [回合 1~11: 策論出牌與訓練]
                                     |
                                     v
[回合 12: 期中考評彈窗] -> [注入事件: 暴力關閉瀏覽器 Force-Kill]
                                     |
                                     v
[重開瀏覽器: 驗證存檔恢復] -> 確保持續停留在回合 12 考評點，無狀態穿幫
                                     |
                                     v
[回合 13~23: 清談 Combo] -> [回合 24: 弱冠禮戰法選擇]
                                     |
                                     v
[回合 25~35: 終考衝刺]   -> [回合 36: 結業典禮五維結算]
```

## 3. 測試設定與量化斷言矩陣

```typescript
export interface AcademyE2ETestConfig {
  headless: boolean;                  // CI 模式下為 true
  previewUrl: 'http://localhost:7456';// Cocos 本地預覽網址
  randomSeed: string;                 // 指定種子 (如 "TEST_SEED_YINGCHUAN_001")
  forceKillTurn: 12;                  // 模擬暴力退出之回合
  totalTurns: 36;
  timeoutMs: 45000;                   // 完整測試超時門檻 45 秒
}

export interface AcademyE2EResult {
  finalTurn: number;                  // 必須精準為 36
  hasMidtermResumedCorrectly: boolean;// 回合 12 恢復是否成功
  statsSummary: {
    singleMaxStat: number;            // 必須 <= 500
    totalStats: number;               // 必須 <= 2000
  };
  slPenaltyTriggered: boolean;        // 重複中斷是否成功觸發保底結算
  testVerdict: 'PASS' | 'FAIL';
}
```

### 3.1 關鍵斷言驗證清單

1. **確定性重播一致性**：使用相同種子與相同操作序列執行兩次 E2E 測試，第 36 回合產出之五維屬性值與戰法必須 100% 完全相同。
2. **防 SL 強退恢復**：在第 12 回合彈出期中考評時強制殺掉分頁，重啟讀檔後：
   - 畫面必須直接恢復至第 12 回合考評彈窗。
   - 若偵測到第 3 次強退，自動觸發保底懲罰（成長僅給 +5、精力扣 20、封鎖 2 回合彩圈）。
3. **數值上限硬封頂**：第 36 回合結算時，單項屬性不得突破 500，五維總和不得突破 2000。

## 4. 驗收測試案例 (Test Cases)

- **TC-QA-E2E-01【36 回合全自動流暢推演】**：在無頭瀏覽器中自動點選完成 36 回合，全程耗時 $28\text{s} \le 45\text{s}$，結業畫面順利呈現，無任何 JavaScript 錯誤。
- **TC-QA-E2E-02【期中考評強退防 SL 斷言】**：在第 12 回合觸發 `browser.close()`，重新打開後驗證前端狀態機精準鎖定於期中考評分支，無跳過回合漏洞。
- **TC-QA-E2E-03【單項 500 數值防爆驗證】**：在 E2E 過程中故意全選單一屬性加成，結算時驗證最高屬性被精確截斷於 500，無溢出。

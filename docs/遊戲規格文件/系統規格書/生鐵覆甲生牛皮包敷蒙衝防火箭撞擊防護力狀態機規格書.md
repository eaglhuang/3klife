# 3KLife 生鐵覆甲生牛皮包敷蒙衝防火箭撞擊防護力狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 重裝水戰防禦與突擊裝甲系統（`IRONCLAD-MENGCHONG01`）。針對三國水戰中敵軍密集的「火攻火箭、火船撞擊、拋石穿甲」打擊，對主力艨艟進行重裝防護改裝：船面與側舷通體包敷多層厚實濕潤生牛皮，核心吃水線及船艏覆蓋鍛打生鐵薄甲與鐵鉚釘加固，打造兼具高速衝撞與全面防火防矢之「水上鐵甲突擊艦」。

## 4. 複合裝甲防護、防燃阻絕與重量折損公式

### 4.1 火箭與撞擊防禦演算法
生鐵與生牛皮複合層之綜合防護效率：
$$\eta_{\text{defense}} = \left(0.70 + \text{IronThicknessMm} \times 0.05\right) \times \left(1.0 + \frac{\text{RawhideLayers}}{10}\right)$$
- 覆蓋 6mm 生鐵與 3 層熟牛皮，敵軍火箭引燃率強制壓制為零（$0\%$）；
- 彈開 $95\%$ 之遠程弩矢，承受敵艦撞角正面撞擊時吸收 $70\%$ 破壞動能。

### 4.2 航速折損與吃水深度平衡公式
裝甲自重對航行性能之負面懲罰：
$$V_{\text{armored}} = V_{\text{base}} \times \left(1.0 - \frac{\text{DisplacementIncreaseTons}}{\text{TotalDisplacementTons}} \times 0.6\right)$$
- 增重使航速下降約 $15\% \sim 25\%$，但獲得水上「重型坦克」般之推土機突破能力。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-IRON-01**：在江水長期浸泡超過 6 個月未進船塢維護，生鐵甲片銹蝕嚴重，鉚釘鬆動率達 $40\%$，衝撞時裝甲有 $30\%$ 機率直接脫落。
2. **驗收 CASE-IRON-02**：裝備鐵甲之艨艟因吃水增加 0.5 米，嚴禁駛入淺灘暗沙地格，若強行駛入必定擱淺。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

# 男女精力消耗差異待產凍結與紅因子上限精算規格書

## 1. 模組職責與架構定位
本規格書規範武將精力體系的「紅色因子精力上限精算公式（`VitalityCap`）」、「男女結緣非對稱精力消耗規則」以及「每季自然回復與女性待產凍結狀態機（`SeasonVitalityRecovery`）」。模組確保體力管理兼顧生理真實性與戰略代價。

```
┌─────────────────────────────────────────────────────────────┐
│                 Vitality Lifecycle & Pregnancy              │
├──────────────────────────────┬──────────────────────────────┤
│ 精力上限精算公式             │ 結緣非對稱消耗與待產凍結     │
│ (100 + 紅因子×20) × 近親(0.7) │ 男扣 50 / 女扣 100 (透支)    │
│ 最大上限 200 (★5 紅因子)     │ 懷孕 3 季內自然回補強制為 0  │
└──────────────────────────────┴──────────────────────────────┘
```

## 2. 精力上限精算公式

武將之最大精力（`maxVitality`）由其先天的紅色因子星等與血統近親判定共同約束：
$$\text{BaseCap} = 100 + \text{RedFactorLevel} \times 20$$
$$\text{MaxVitality} = \left\lfloor \text{BaseCap} \times (\text{IsInbreeding} ? 0.70 : 1.0) \right\rfloor$$

- **基礎基準值**：無紅因子時為 **100 點**。
- **紅色因子擴充**：每提升 1 星等增加 **$+20$ 點**，★5 極限時達到 **200 點**。
- **近親劣化懲罰**：若子嗣來自同源近親繁育（`IsInbreeding === true`），上限強制打 **$0.70$（七折）**。

```typescript
export function computeMaxVitality(redFactorLevel: number, isInbreeding: boolean): number {
  const boundedLevel = Math.max(0, Math.min(5, redFactorLevel));
  const base = 100 + boundedLevel * 20;
  const multiplier = isInbreeding ? 0.70 : 1.0;
  return Math.floor(base * multiplier);
}
```

## 3. 行動消耗非對稱模型與待產凍結

### 3.1 行動消耗標準
- **戰場出征（`BATTLE`）**：消耗 **30 點** 精力。
- **學府培育（`NURTURE`）**：每回合常態訓練消耗 **20 點** 精力。
- **家族結緣繁育（`BREEDING`，男女非對稱）**：
  - **男性武將**：消耗 **50 點** 精力。
  - **女性武將**：因承受懷胎生育之苦，直接消耗 **100 點** 精力（精力全額透支），並進入為期 **3 季** 之待產期（`pregnancyRemaining = 3`）。

### 3.2 每季自然回復與待產凍結
每季度換季時執行精力回復計算：
$$\text{BaseGain} = 20 + \text{RedFactorLevel} \times 5$$
$$\text{AgeMod} = (\text{isElder} ? 0.60 : 1.0)$$
$$\text{CalculatedGain} = \left\lfloor \text{BaseGain} \times \text{AgeMod} \right\rfloor$$

- **待產凍結規則（Pregnancy Lock）**：
  若女性武將處於待產中（`isPregnant === true` 且 `pregnancyRemaining > 0`）：
  - 該季度之精力回補量 **強制歸零（$\text{ActualGain} = 0$）**。
  - 待產倒數減 1 季（`pregnancyRemaining -= 1`）。
  - 當待產季數歸零時，解除懷孕狀態，下個季度起恢復常規回補。

```typescript
export interface VitalitySeasonRecoveryInput {
  currentVitality: number;
  maxVitality: number;
  redFactorLevel: number;
  isElder: boolean;
  isPregnant: boolean;
  pregnancyRemaining: number;
}

export function processSeasonRecovery(input: VitalitySeasonRecoveryInput): {
  newVitality: number;
  newPregnancyRemaining: number;
  isPregnantNow: boolean;
} {
  if (input.isPregnant && input.pregnancyRemaining > 0) {
    const nextRemaining = input.pregnancyRemaining - 1;
    return {
      newVitality: input.currentVitality, // 待產期精力凍結不回復
      newPregnancyRemaining: nextRemaining,
      isPregnantNow: nextRemaining > 0
    };
  }

  const baseGain = 20 + input.redFactorLevel * 5;
  const ageMod = input.isElder ? 0.60 : 1.0;
  const gain = Math.floor(baseGain * ageMod);
  const nextVitality = Math.min(input.maxVitality, input.currentVitality + gain);

  return {
    newVitality: nextVitality,
    newPregnancyRemaining: 0,
    isPregnantNow: false
  };
}
```

## 4. 單元測試驗證規範
1. **TC-VIT-CAP（紅因子與近親七折檢驗）**：★3 紅因子基礎上限 $100 + 60 = 160$；近親折算為 $\lfloor 160 \times 0.7 \rfloor = 112$ 點。
2. **TC-BREED-CONSUME（男女非對稱消耗）**：男武將結緣扣 50 點；女武將結緣扣 100 點並標記待產 3 季。
3. **TC-PREG-FREEZE（待產期精力零回補）**：懷孕武將當前精力 0，換季結算後精力仍為 0，剩餘季數由 3 降為 2。

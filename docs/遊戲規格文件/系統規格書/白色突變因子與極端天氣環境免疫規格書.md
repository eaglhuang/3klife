# 白色突變因子與極端天氣環境免疫規格書

> **責任邊界**：本檔為白色遺傳因子（White Genes）、性格突變與極端天氣環境抗性的單一真相來源。
> **關聯 WBS**：APT-10（白色因子天氣免疫）、APT-09（因子適性映射）、KIN-05（狼性白色因子）。
> **整併裁決**：確立白色因子作為極端環境抗性與性格突變的唯一載體，對齊戰場計算管線。

---

## §1. 三國四大極端天候戰場懲罰矩陣

戰場遭遇極端氣候時，常規部隊承受嚴重戰術減益：

| 極端氣候 (Weather) | 常規戰場環境懲罰 | 火攻與戰法限制 |
|:---|:---|:---|
| **大雨 (Heavy Rain)** | 陸地部隊移動力 -1；弓兵射程 -1 | 所有火攻戰法強制失效，點燃地形熄滅 |
| **大霧 (Dense Fog)** | 全軍視野強制縮小至 1 格；攻擊命中率 -25% | 遭敵軍伏擊時承受傷害 +30% |
| **暴雪 (Snowstorm)** | 騎兵移動力 -2；每回合結束受 5% 凍傷扣兵 | 部隊士氣每回合自然衰減 5 點 |
| **沙塵暴 (Duststorm)** | 全軍防禦力 -15%；遠程射擊命中率 -30% | 逆風方向遠程射程 -2 格 |

## §2. 五大白色突變因子與免疫效果總表

白色因子為罕見之環境適應與性格突變基因，可由遺傳變異（Mutation）或特定宿敵配種獲得：

| 因子代碼 (`GeneID`) | 因子中文名稱 | 稀有度 | 極端天候免疫與環境加成效果 |
|:---|:---|:---:|:---|
| `gene_rain_master` | **雨師踏浪** | ★3~★5 | **大雨免疫**：不受移速與射程懲罰；雨天/水域攻防額外 +15% |
| `gene_fog_seer` | **霧隱天眼** | ★3~★5 | **大霧免疫**：保留 3 格常態視野，無視命中懲罰，識破隱蔽伏擊 |
| `gene_snow_endure` | **傲雪寒骨** | ★3~★5 | **暴雪免疫**：完全免除 5% 凍傷扣兵；雪地作戰防禦力 +20% |
| `gene_sand_stalker` | **黃沙借勢** | ★3~★5 | **風暴免疫**：無視沙塵暴防禦與命中減益；暴風中暴擊率 +20% |
| `gene_wolf_feral` | **狼性狂化** | ★4~★5 | **全天候抗動搖**：免疫極端天候士氣扣減；兵力每降 20% 攻擊 +10% |

> **性格因子對齊**：既有 `gene_calm`（冷靜，每級減 10% 恐懼）與 `gene_fury`（暴躁，每級攻+3%/防-3%）維持並存，同屬白色性格光譜。

## §3. 戰鬥結算管線判定協議 (Combat Resolution)

戰鬥計算器 `BattleCombatResolver` 在結算環境減益時依循以下優先序：

```
[環境偵察 WeatherSchedule] ──> [讀取主將白色因子 WhiteFactorTraits]
                                           │
  ┌────────────────────────────────────────┘
  ▼
[比對當前天候是否具備對應白因子?]
  ├──> [是: 具備] ──> 強制抵銷該天候減益 (Penalty = 0) 並注入環境 Buff
  └──> [否: 缺失] ──> 正常扣除移動力/命中率/兵力凍傷
```

1. **先天天賦優先**：若武將持有多個白色因子，各天候免疫效果獨立判定。
2. **副將繼承機制**：出征編制中，若副將擁有白色因子，可為全隊提供 **50% 效果**（如凍傷減半為 2.5%）。
3. **無效抗性防呆**：常規晴天、陰天環境下，特定天氣抗性白因子不生效，避免數值無端膨脹。

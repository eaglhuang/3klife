# 祖譜因子繼承進池機率與星等階梯分佈規格書

> 標籤：`BLT-04` · `M2` · `因子繼承` · `進池機率` · `星等階梯` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，子嗣自 14 人祖譜中抽取遺傳因子（`inheritFactors`）之進池機率、運氣屬性加成、世代星等階梯分佈、同名因子擇優去重與上限約束演算法。

本模組為純邏輯無副作用運算，依確定性隨機序列消耗種子，確保跨平台回放與存檔重現一致性。

---

## 2. 世代進池基準率與運氣修正

14 人祖譜中各插槽之祖先因子，依世代深度（Gen 1~3）享有不同進池基準機率：

```typescript
export const FACTOR_POOL_RATE: Record<1 | 2 | 3, number> = {
    1: 1.0,   // G1 (父母): 100% 進入候選池
    2: 0.5,   // G2 (祖父母): 50% 機率進池
    3: 0.25,  // G3 (曾祖父母): 25% 機率進池
};

export function inheritanceLukRate(baseRate: number, parentAvgLuk: number): number {
    const luk = Number.isFinite(parentAvgLuk) ? Math.max(0, parentAvgLuk) : 0;
    return Math.min(1.0, baseRate * (1 + luk / 100));
}
```

### 2.1 運氣乘法放大公式
雙親平均運氣屬性（`parentAvgLuk = (LUK_father + LUK_mother) / 2`）提供乘法修正：
$$\text{PoolRate} = \min\left(1.0, \text{BaseRate} \times \left(1 + \frac{\text{ParentAvgLuk}}{100}\right)\right)$$
- 若雙親平均運氣達到 100 點，G2 進池率由 $50\%$ 翻倍為 $100\%$，G3 進池率由 $25\%$ 翻倍為 $50\%$。
- 最終進池機率絕對封頂為 $1.0$（$100\%$）。

## 3. 世代星等階梯分佈模型

成功進池之因子，其初始星等由提供該因子之祖先世代階梯決定：

```typescript
export const FACTOR_STAR_DISTRIBUTION: Record<1 | 2 | 3, { low: number; high: number; highRate: number }> = {
    1: { low: 3, high: 4, highRate: 0.2 }, // G1: ★3 (80%) / ★4 (20%)
    2: { low: 2, high: 3, highRate: 0.3 }, // G2: ★2 (70%) / ★3 (30%)
    3: { low: 1, high: 2, highRate: 0.1 }, // G3: ★1 (90%) / ★2 (10%)
};
```

### 3.1 藍色因子保底抬升（FORM-08）
若啟動藍色因子特殊保底（`blueFactorChance > 0`），藍色屬性因子具備機率將星等直接抬升至 $\ge 3$ 星，受限於單項因子之 `maxLevel` 夾取，只升不降。

## 4. 多來源擇優去重與上限約束

```
                  ┌─────────────────────────────┐
                  │ 遍歷 14 人祖譜之所有有效因子 │
                  └──────────────┬──────────────┘
                                 │
                   [ 同名因子首次進入候選池? ]
                   ├── 是 ──> 建立新記錄: { id, color, level, generation, sourceUids }
                   └── 否 (已存在同名因子)
                                 │
                  ┌──────────────┴──────────────┐
                  │ 比較星等: level > existing ?│
                  │ - 是: 更新 level 與 generation│
                  │ - 否: 維持原星等            │
                  │ 累加 sourceUids 來源清單    │
                  └──────────────┬──────────────┘
                                 │
                  ┌──────────────┴──────────────┐
                  │ 排序: 星等降序 > 世代升序 > ID│
                  │ 截取前 5 個因子 (MAX = 5)    │
                  └─────────────────────────────┘
```

1. **同因子擇優去重**：當同一因子出現在多位祖先（例如父方與母方曾祖父皆有 `gene_cavalry`）時，系統保留最高星等者，世代來源標記為最高星對應之世代，並將所有提供者之 UID 記錄於 `sourceUids`。
2. **容量約束**：子嗣身上最多保留 5 個遺傳因子（`DEFAULT_MAX_INHERITED_FACTORS = 5`）。超額部分依優先度截斷剔除。
3. **初始灰鎖**：所有繼承之因子在子嗣出生時狀態一律為鎖定（`isLocked: true`），依因子色系設定覺醒門檻（藍/粉/綠為 Level 1，白/紅為 Level 20，紫為 Level 45）。

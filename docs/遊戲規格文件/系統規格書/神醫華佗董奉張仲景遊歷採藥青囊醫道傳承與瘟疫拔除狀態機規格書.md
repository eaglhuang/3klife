## 1. 系統架構定位與懸壺濟世仁心

建安三神醫，杏林青囊傳千古。東漢末年戰亂頻仍，白骨露於野，千里無雞鳴，大疫流行。《三國人生》（3KLife）構建**建安三神醫遊歷、神農百草採集與全城大疫防治系統（Herbal Medicine & Epidemic Control）**。

本系統核心價值：
1. **三大神醫專屬術業（Three Divine Physicians）**：華佗神刀外科、張仲景傷寒理法、董奉杏林春暖。
2. **名山草藥採集採集演算法（Herbal Foraging）**：深入長白、終南、青城名山尋採野生靈藥。
3. **城池大疫動態傳播與拔除狀態機（Plague Eradication）**：控制人口死亡率，救拔萬民於水火。

## 3. 神農百草採集（Herbal Foraging）與煉丹配方

玩家或隨軍軍醫可派遣藥童前往名山地格採藥：
- **太白山野山參**：固本培元，調製【回陽返魂丹】（戰場瞬間搶救瀕死名將）。
- **南中野生三七**：散瘀止血，調製【金創生肌散】（傷兵轉化率永久提升至 $60\%$）。
- **長白極地雪蓮**：清熱祛毒，調製【清心百解飲】（免疫戰場毒箭與瘴氣沼澤）。

## 4. 城池大疫爆發與醫道拔除狀態機

夏秋之交或大戰過後，城池有 $25\%$ 機率觸發「傷寒大疫」：

```
       [HEALTHY 無恙] ──大戰後屍橫遍野──> [EPIDEMIC_OUTBREAK 瘟疫爆發]
                                                    │
                 ┌──────────────────────────────────┴──────────────────────────────────┐
                 ▼ (無神醫施救，放任不管)                                              ▼ (張仲景坐堂施藥，開倉熬湯)
      [DEVASTATION 生靈塗炭]                                                 [ERADICATED 疫情弭平]
      每季人口銳減 15%，治安跌至谷底                                         3 回合內拔除疫病，民心激增 +30 點
```

1. **疫情蔓延代價**：處於 `EPIDEMIC_OUTBREAK` 狀態之城池，商業與農業產出直接折半，每季人口自然折損 $15\%$，且該城士兵無法調派外調。
2. **名醫坐堂拔除**：指派張仲景出任長沙或疫情都城太醫，耗費 1 季度調配【傷寒金匱湯】，**徹底撲滅瘟疫**；救活百姓轉化為死忠民兵，城池民望鎖定滿值 100。

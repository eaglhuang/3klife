## 1. 業務定位與適性等級模型

武將在四類兵種（步、騎、弓、特）與五類地形（平原、森林、山地、水域、城鎮）中各具備基準適性等級：

$$\text{AptitudeRank} \in \{\text{D (0)}, \text{C (1)}, \text{B (2)}, \text{A (3)}, \text{S (4)}, \text{EX (5)}\}$$

粉色遺傳因子（`GENE_PINK`）專司兵種與地形之天賦進化，在子嗣誕生或名將轉生時注入命盤，直接提升對應適性階梯。

---

## 2. 粉色因子星階映射與計算

粉色因子按星階（1★ ~ 3★）提供線性階梯加成：

| 因子星階 | 加成階梯數 ($\Delta \text{Rank}$) | 映射效果說明 |
|:---:|:---:|---|
| **1★ (Lv 1)** | $+1$ 階 | 例：B 階晉升至 A 階 |
| **2★ (Lv 2)** | $+2$ 階 | 例：C 階晉升至 A 階 |
| **3★ (Lv 3)** | $+3$ 階 | 例：B 階晉升至 S 階（常規上限鎖定 S） |

> **常規上限約束**：單純透過粉色因子加成，最終適性等級最高鎖定於 `S` 階（4 級），不可跨入 `EX` 階。

## 3. 十四名將血脈共鳴突破協議（Bloodline Resonance）

遊戲設定十四大核心始祖血脈（如：關羽、張飛、趙雲、曹操、孫策、諸葛亮等）。

```mermaid
flowchart TD
    Gene[粉色因子注入] --> CheckResonance{同宗始祖血脈繼承者 >= 5人?}
    CheckResonance -- 否 --> NormalCap[常規上限: 最高 S 階]
    CheckResonance -- 是 --> Breakthrough[血脈共鳴爆發: 突破上限]
    Breakthrough --> UnlockEX[解鎖始祖專屬兵種 EX 階 (倍率 1.35)]
```

### 3.1 共鳴觸發閘門
- **同宗血脈門檻**：出征陣列或家族譜牒中，繼承同一始祖名將血脈因子之武將數量 $N_{\text{lineage}} \ge 5$ 人。
- **始祖專屬突破**：該始祖武將之核心本命兵種（如趙雲騎兵、關羽步兵、黃忠弓兵），其適性上限由 `S` 階突破至 `EX` 階。

## 4. 資料模型與純邏輯計算函式

```typescript
export type AptitudeRank = 'D' | 'C' | 'B' | 'A' | 'S' | 'EX';

const RANK_VALUES: Record<AptitudeRank, number> = { D: 0, C: 1, B: 2, A: 3, S: 4, EX: 5 };
const VALUE_TO_RANK: AptitudeRank[] = ['D', 'C', 'B', 'A', 'S', 'EX'];

export interface IAptitudeUpgradeParams {
    readonly baseRank: AptitudeRank;
    readonly pinkGeneStars: number; // 0..3
    readonly lineageCount: number;  // 同宗始祖血脈人數
    readonly isSignatureTroop: boolean; // 是否為該始祖之本命專屬兵種
}

export function resolveAptitudeWithPinkGene(params: IAptitudeUpgradeParams): {
    readonly finalRank: AptitudeRank;
    readonly isResonated: boolean;
    readonly statMultiplier: number;
} {
    const baseVal = RANK_VALUES[params.baseRank];
    const boostedVal = baseVal + Math.max(0, Math.min(3, params.pinkGeneStars));
    
    // 檢核血脈共鳴突破：>= 5人 且 為始祖專屬兵種 且 達到S階
    const canBreakthrough = params.lineageCount >= 5 && params.isSignatureTroop;
    
    let finalVal: number;
    let isResonated = false;

    if (canBreakthrough && boostedVal >= 4) {
        finalVal = 5; // 晉升為 EX
        isResonated = true;
    } else {
        finalVal = Math.min(4, boostedVal); // 常規鎖定 S
    }

    const finalRank = VALUE_TO_RANK[finalVal] ?? 'S';
    const multipliers: Record<AptitudeRank, number> = {
        D: 0.80, C: 0.90, B: 1.00, A: 1.10, S: 1.20, EX: 1.35
    };

    return {
        finalRank,
        isResonated,
        statMultiplier: multipliers[finalRank],
    };
}
```

# 精銳部隊部署上限與攻城器械保留槽計算規格書

## 1. 核心定位與編制上限契約

本規格書為戰場精銳部隊上陣配額與攻城專用器械保留槽位演算法（Elite Deployment Capacity & Reserve Slot，代號 `DEP-06`）的單一真相來源（Single Source of Truth）。為防止高強度精銳部隊無限鋪場破壞戰術平衡，戰場設定嚴格的精銳部隊在場上限（`Elite_Deploy_Cap`），並在特殊戰役中引入保留槽機制。

```typescript
export interface EliteCapContract {
  baseActiveCap: 4;               // 基礎在場精銳上限 4 隊
  siegeSceneBonus: 1;             // 攻城戰環境額外 +1 名額
  officerTierBonusCap: 1;         // 官職階級額外上限 +1
  maxPossibleCap: 6;              // 系統極限總配額 6 隊
}
```

---

## 2. 精銳部隊界定範圍（Elite Classification）

在部署檢核管線中，以下單位一律判定為精銳部隊（`isElite == true`），佔用精銳部署名額：

1. **三類常規精銳兵種（`ELITE_BASE_TYPES`）**：
   - 騎兵營（`CAVALRY`）：高機動高衝擊。
   - 水師營（`NAVY`）：水域特化專精。
   - 攻城器械（`SIEGE` / 工兵）：破門投石重型裝備。
2. **三十四營虎符特殊部隊**：
   - 所有源自虎符召喚之特殊兵種（如陷陣營、虎豹騎、白馬義從等）全數歸類為精銳。
3. **豁免對象**：
   - 常規步兵（`INFANTRY`）、弓兵（`ARCHER`）、長槍（`PIKE`）、大盾（`SHIELD`）與鄉勇民兵（`MILITIA`）為平民兵種，不佔用精銳名額。

---

## 3. 精銳上限計算公式與官職擴充

精銳部署上限由戰略基礎值、戰場環境與主將官職三者合成：

$$\text{EliteDeployCap} = \text{BaseActiveCap} (4) + \text{SiegeBonus} + \min(\text{OfficerTierBonus}, 1)$$

- **基礎容量**：常規野戰基礎配額固定為 4 隊。
- **攻城戰加成（SiegeBonus）**：若戰鬥場景為攻城戰（`SCENE_SIEGE`），配額強制 $+1$。
- **官職階級加成（OfficerTierBonus）**：若主將官職晉升至州牧、大將軍等一品高官，配額 $+1$（最高加成上限為 1）。
- **配額封頂**：一般戰役上限 4~5 隊，攻城決戰最高上限為 6 隊。

## 4. 攻城器械專屬保留槽機制（Siege Engine Reserve）

在攻城戰役中，為了確保破城器械具備進場空間，避免玩家誤將名額全數派遣騎兵導致無法攻破城門，系統引入「器械專屬保留槽」：

### 4.1 保留槽鎖定規則

- 攻城戰自動設定：$\text{siegeEngineReserve} = 1$。
- **名額凍結**：若場上尚未部署攻城器械，一般常規精銳部隊可佔用之名額上限為：
  $$\text{EliteAvailable}_{\text{general}} = \text{EliteDeployCap} - \text{UnfilledReserve}$$
- **器械豁免通行**：工兵與攻城器械（`isSiegeEngine == true`）不受凍結限制，可直接啟用該保留槽位入場。

### 4.2 動態退場名額回流（In-Field Dynamic Reclamation）

- 精銳部隊配額以「**當前戰場存活現有數**」為準，非整場累計召喚數。
- 當場上某隊精銳被擊潰退場時（`retireUnit`），該精銳槽位即刻釋放，玩家或委任 AI 可立即補派新精銳部隊增援入場。

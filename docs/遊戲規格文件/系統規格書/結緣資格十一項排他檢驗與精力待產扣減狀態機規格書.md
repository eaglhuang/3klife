# 結緣資格十一項排他檢驗與精力待產扣減狀態機規格書

> **模組識別碼**：`BRD-01`、`BRD-02`  
> **系統歸屬**：血統家族培育（Breeding）核心資格與生理狀態機  
> **單一真相來源**：本規格書確立男女武將結緣（配種）十一項嚴格排他性資格檢驗、確認結緣精力扣減（父-50/母-100）、一生生育上限與母方待產 4 季凍結之唯一權威標準。

---

## 一、系統概述與架構原則

結緣系統為家族血脈傳承之起點。為符合古代世家禮法與遊戲平衡機制，結緣發起時必須通過純邏輯資格閘門驗證。檢驗失敗時直接回傳具體原因代碼且**絕對不扣除精力**；一旦通過並確認結緣，立即執行原子精力扣減與母方待產狀態流轉。

### Unity / 架構對照
- **資格驗證器**：類似 Unity 中的 `BreedingRuleValidator` 靜態類別，輸入雙方武將 DTO，產出強型別驗證結果。
- **生理狀態機**：母方待產透過整數計數器（`pregnancySeasonsLeft`）倒數，與 `GameClock` 季度推進事件對齊。

## 二、結緣資格十一項排他檢驗規則

```typescript
export const BREEDING_MIN_AGE = 20;       // 結緣最低法定成年年齡（20 歲）
export const FATHER_VIGOR_COST = 50;      // 父親結緣消耗精力
export const MOTHER_VIGOR_COST = 100;     // 母親結緣消耗精力
export const PREGNANCY_LOCK_SEASONS = 4;  // 受孕後母方待產凍結季數（4 季 = 1 年）
```

### 十一項排他性阻絕代碼（`BreedingBlockReason`）

| 順序 | 阻絕原因識別碼 (`reason`) | 阻絕條件描述 | 規則依據 |
|:---:|---|---|---|
| 1 | `same-general` | 父方與母方為同一武將（自己與自己結緣） | 邏輯約束 |
| 2 | `father-not-male` | 父方性別非男性（非 `'男'` / `'male'`） | 生理約束 |
| 3 | `mother-not-female` | 母方性別非女性（非 `'女'` / `'female'`） | 生理約束 |
| 4 | `father-underage` | 父方年齡 $< 20$ 歲 | 禮制年齡 |
| 5 | `mother-underage` | 母方年齡 $< 20$ 歲 | 禮制年齡 |
| 6 | `father-dead` | 父方當前狀態為身故（`status === 'dead'`） | 生命週期 |
| 7 | `mother-dead` | 母方當前狀態為身故（`status === 'dead'`） | 生命週期 |
| 8 | `father-mentor-card` | 父方已退役轉化為先祖/特聘教官支援卡 | 傳承隔離 |
| 9 | `mother-mentor-card` | 母方已退役轉化為先祖/特聘教官支援卡 | 傳承隔離 |
| 10 | `father-low-vigor` | 父方當前精力不足 50（$V < 50$） | 精力門檻 |
| 11 | `mother-low-vigor` | 母方當前精力不足 100（$V < 100$） | 精力門檻 |
| 12 | `father-breeding-cap`| 父方親傳次數已達一生生育上限 | 生育天花板 |
| 13 | `mother-breeding-cap`| 母方親傳次數已達一生生育上限 | 生育天花板 |
| 14 | `mother-pregnant` | 母方正處於待產期（`pregnancySeasonsLeft > 0`） | 待產保護 |
| 15 | `inbreeding` | 雙方在 3 代祖譜內具備共同祖先（近親） | 倫理禁婚 |

## 三、一生親傳生育上限模型

武將一生可結緣親傳子嗣之最大次數由其最大精力上限（`maxVitality`）決定，並可透過珍稀道具「傳宗秘藥」永久 $+1$：

| 最大精力上限區間 (`maxVitality`) | 基礎生育上限次數 | 秘藥加成上限 | 總最大次數 |
|:---:|:---:|:---:|:---:|
| $< 90$ | **3 次** | $+1$ | 至多 4 次 |
| $90 \sim 119$ | **4 次** | $+1$ | 至多 5 次 |
| $\ge 120$ | **5 次** | $+1$ | 至多 6 次 |

```typescript
export function lifetimeBreedingCap(general: BreedingGeneral): number {
    const maxVigor = general.maxVitality ?? general.vitality ?? 100;
    const base = maxVigor >= 120 ? 5 : maxVigor >= 90 ? 4 : 3;
    const pillBonus = Math.min(1, Math.max(0, general.breedingCapBonus ?? 0));
    return base + pillBonus;
}
```

## 四、精力扣減與待產凍結流轉

1. **精力即刻扣除**：
   - 點擊「確認結緣」後，無論最終受孕擲骰是否成功，父方精力扣除 50，母方精力扣除 100（下限為 0）。
2. **受孕成功狀態機**：
   - 若受孕成功：
     - 父方已生育次數：`father.breedingCount += 1`。
     - 母方已生育次數：`mother.breedingCount += 1`。
     - 母方進入待產凍結：`mother.pregnancySeasonsLeft = PREGNANCY_LOCK_SEASONS`（4 季）。
3. **季度待產倒數**：
   - 世界時鐘每次推進 1 季，若 `mother.pregnancySeasonsLeft > 0`，計數 $-1$。
   - 倒數歸零時，正式接生並揭曉 0 歲子嗣。

## 五、驗收條件與測試案例 (Test Cases)

- **TC-BRD-01（未成年阻絕不扣精力）**：
  - 父方 19 歲，呼叫檢驗回傳 `ok: false, reasons: ['father-underage']`，父方精力不變。
- **TC-BRD-02（同性配對阻絕）**：
  - 雙方性別皆為男，回傳 `ok: false, reasons: ['mother-not-female']`。
- **TC-BRD-03（待產期阻絕再次結緣）**：
  - 母方 `pregnancySeasonsLeft = 2`，發起結緣回傳 `['mother-pregnant']`。
- **TC-BRD-04（確認結緣精力扣減）**：
  - 父精力 80、母精力 120，確認結緣後父精力精確為 30，母精力精確為 20。

# 職能雙軌分流不可逆鎖定與六維年齡衰退成長曲線規格書

## 1. 模組職責與架構定位
本規格書規範武將名冊體系中的「職能雙軌分流不可逆鎖定狀態機（`GeneralRole`、`RosterRoleLoad`）」以及「六維屬性年齡衰退成長曲線（`GeneralGrowth`）」。模組確保戰鬥名將與學府導師職能壁壘分明，並以細膩的年齡係數動態調整武將戰力輸出。

```
┌─────────────────────────────────────────────────────────────┐
│                 General Role & Growth Engine                │
├──────────────────────────────┬──────────────────────────────┤
│ 職能雙軌分流不可逆鎖定       │ 六維年齡階段動態修正曲線     │
│ Combat (戰鬥) vs Mentor(教官) │ 幼兒(0.6) / 青年巔峰(1.1)    │
│ 一旦定型嚴禁動態回滾切換     │ 老年衰減(0.8) / 超齡(0.5)    │
└──────────────────────────────┴──────────────────────────────┘
```

## 2. 職能雙軌分流不可逆鎖定狀態機

### 2.1 雙軌職能定義與互斥邊界
武將在 14 歲及笄弱冠、入學結業或俘虜招募時，必須確立其核心生涯路徑：
- **`Role = 'Combat'`（戰鬥武將）**：專職軍事征伐、出征攻城與要塞守備。**絕對禁止**被指派至學府教官槽位中。
- **`Role = 'Mentor'`（專業教官）**：專職宗族授徒、戰法傳承與靈感啟發。**絕對禁止**編入出征軍團或擔任戰場主將。

### 2.2 存讀檔校驗與防篡改防護
- 角色資料模型（`GeneralConfig`）中的 `role` 欄位為單向可寫一次。
- 存檔載入（`RosterRoleLoad`）時執行正規化校驗，若偵測到未定義值一律依屬性主動 fallback 保底，並鎖定防篡改。

```typescript
export type GeneralRoleType = 'Combat' | 'Mentor';

export interface RoleAssignmentCheck {
  isValid: boolean;
  assignedRole: GeneralRoleType;
  canEnterBattle: boolean;
  canEnterAcademy: boolean;
}

export function validateGeneralRole(role: GeneralRoleType): RoleAssignmentCheck {
  if (role === 'Combat') {
    return { isValid: true, assignedRole: 'Combat', canEnterBattle: true, canEnterAcademy: false };
  }
  return { isValid: true, assignedRole: 'Mentor', canEnterBattle: false, canEnterAcademy: true };
}
```

## 3. 六維屬性年齡衰退成長曲線

武將之六維實時面板（武力、統率、智力、政治、魅力、運氣）受當前年齡階段動態修正：
$$\text{EffectiveStat} = \left\lfloor \text{BaseStat} \times \text{AgeModifier}(\text{age}) \right\rfloor$$

| 年齡階段區間 | 係數 | 戰略特徵 |
| :---: | :---: | :--- |
| **0 ~ 13 歲（幼兒階段）** | $0.60\times$ | 體魄與智力未啟發，數值受限保護 |
| **14 ~ 19 歲（少年階段）** | $1.00\times$ | 基礎資質定型，標準輸出 |
| **20 ~ 35 歲（青年巔峰）** | $1.10\times$ | 氣血充沛，五維全項獲得 $+10\%$ 巔峰爆發 |
| **36 ~ 50 歲（壯年沉穩）** | $1.00\times$ | 智勇兼備，回歸平穩標準基準 |
| **51 ~ 65 歲（老年衰退）** | $0.80\times$ | 筋骨衰疲，數值下降 $20\%$ |
| **$> 65$ 歲（超齡暮年）** | $0.50\times$ | 年邁力衰，數值腰斬，建議退役榮休 |

```typescript
export interface GeneralSixStats {
  war: number;
  ldr: number;
  int: number;
  pol: number;
  cha: number;
  luk: number;
}

export function applyAgeGrowthModifier(stats: GeneralSixStats, age: number): GeneralSixStats {
  let mod = 1.0;
  if (age < 14) mod = 0.60;
  else if (age < 20) mod = 1.00;
  else if (age < 36) mod = 1.10;
  else if (age < 51) mod = 1.00;
  else if (age < 65) mod = 0.80;
  else mod = 0.50;

  return {
    war: Math.floor(stats.war * mod),
    ldr: Math.floor(stats.ldr * mod),
    int: Math.floor(stats.int * mod),
    pol: Math.floor(stats.pol * mod),
    cha: Math.floor(stats.cha * mod),
    luk: Math.floor(stats.luk * mod)
  };
}
```

## 4. 單元測試驗證規範
1. **TC-ROLE-MUTUAL（職能雙軌排他檢驗）**：`Combat` 武將 `canEnterAcademy = false`；`Mentor` 武將 `canEnterBattle = false`。
2. **TC-GROWTH-PEAK（青年巔峰加乘檢驗）**：25 歲武將武力 90，經修正後為 $\lfloor 90 \times 1.1 \rfloor = 99$。
3. **TC-GROWTH-ELDER（老年衰退折減檢驗）**：60 歲武將武力 90，經修正後為 $\lfloor 90 \times 0.8 \rfloor = 72$。

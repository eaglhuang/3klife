# 育成屬性增長總公式與傾囊相授連乘加成數值規格書

## 1. 核心定位與設計理念
本規格書定義《三國人生》武將入學培育（Nurture Session）單次訓練屬性成長結算之總公式與六大乘區架構（WBS `FORM-01`，代碼落位於 `TrainingGainFormula.ts` 與 `NurtureSystem.ts`）。
系統透過解耦之模組化公式鏈，將訓練設施等級、教官加值、武將天生資質、當前運勢、陪伴效果、傾囊相授（友情爆發）與同格人數補正精確整合，為確定性單元測試與畫面預測提供單一真相來源。

```
              ┌──────────────────────────────────────────────┐
              │          TrainingGainFormula 總成長公式鏈     │
              └──────────────────────┬───────────────────────┘
                                     │
          ┌──────────────────────────┼──────────────────────────┐
          ▼                          ▼                          ▼
   【加法基礎區 (Additive)】   【資質與運勢乘區】         【教官連攜乘區】
   • 設施基礎值 (Base)         • 武將資質 (1 + Gr)        • 陪伴加成 (1 + Σtraining)
   • 教官固定加值 (cardBonus)  • 運勢乘區 M_Morale        • 傾囊相授 Π(1 + burst) [唯一連乘]

```

## 2. 總公式定義與六大乘區結構

單次訓練結算之屬性最終獲得值（不取整、不隨機擲骰）：
$$\text{Gain} = \text{Additive} \times \text{Growth} \times M_{\text{morale}} \times M_{\text{training}} \times M_{\text{friendship}} \times M_{\text{crowd}}$$

### 2.1 各乘區數值模型拆解

1. **加法基礎區（`Additive`）**：
   $$\text{Additive} = \text{Base} + \sum_{i} \text{cardBonuses}_{i}$$
   - `Base`：由當前訓練設施等級提供（例如 Lv5 騎術營提供 15 點基礎 STR）。
   - `cardBonuses`：參與訓練之教官卡提供的固定屬性加值總和。
2. **武將資質乘區（`Growth`）**：
   $$\text{Growth} = 1 + \text{Gr}$$
   - `Gr`：學員武將之先天屬性成長率（如資質 $+20\%$ 則 $\text{Gr} = 0.2$）。
3. **運勢狀態乘區（$M_{\text{morale}}$）**：
   $$M_{\text{morale}} = 1 + \text{baseMorale} \times (1 + \sum_{i} \text{moraleBoosts}_{i})$$
   - `baseMorale`：基礎運勢係數，系統預設最佳運勢基準為 **0.2**（`DEFAULT_BASE_MORALE = 0.2`）。
   - `moraleBoosts`：同行教官所附帶之運勢效果提升加成總和。
4. **教官陪伴乘區（$M_{\text{training}}$）**：
   $$M_{\text{training}} = 1 + \sum_{i} \text{trainingBoosts}_{i}$$
   - 多位教官的陪伴訓練提升率採加法合併後一次乘入。
5. **傾囊相授乘區（$M_{\text{friendship}}$，全公式唯一連乘區）**：
   $$M_{\text{friendship}} = \prod_{k} (1 + \text{friendshipBursts}_{k})$$
   - 當教官好感羈絆達標並觸發「傾囊相授」時，每位爆發教官的加成倍率獨立連乘。若無人觸發則為 1.0。
6. **同格人數補正乘區（$M_{\text{crowd}}$）**：
   $$M_{\text{crowd}} = 1 + 0.05 \times \text{extraCrowd} \quad (\text{CROWD\_BONUS\_PER\_EXTRA} = 0.05)$$
   - 每位在同設施訓練但未觸發傾囊相授的閒雜角色或同儕，提供額外 **$+5\%$** 的激勵補正。

## 3. 呼叫端介面與純邏輯契約

```typescript
export interface TrainingGainBreakdown {
    additive: number;
    growth: number;
    morale: number;
    training: number;
    friendship: number;
    crowd: number;
    gain: number;
}
```
`trainingGainBreakdown(input)` 保證為純純函式計算，不擲骰、不改傳入參數，同時返回各乘區中間值，供 UI 面板展示成長來源解析。

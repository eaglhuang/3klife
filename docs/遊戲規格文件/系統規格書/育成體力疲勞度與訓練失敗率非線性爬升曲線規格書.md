# 育成體力疲勞度與訓練失敗率非線性爬升曲線規格書

## 1. 核心定位與設計理念
本規格書定義《三國人生》武將在學府培育歷程中，學員體力消耗（Stamina Ratio）對應訓練失敗率（Failure Rate）的三段非線性爬升曲線模型（WBS `FORM-02`，代碼落位於 `FatigueFailureRate.ts` 與 `NurtureSystem.ts`）。
系統透過「安全區 $\to$ 風險區 $\to$ 危險區」的分段曲線設計，營造資源管理與風險博弈平衡：體力充沛時 100% 成功，疲勞累積後失敗懲罰急遽惡化，引導玩家合理排程休息與訓練。

```
       失敗率 (Failure Rate)
        100% ┼─────────────────────────────────────────────● (0%體力, 99%失敗)
             │                                            /
             │                                           / (危險區：線性飆升)
         40% ┼──────────────────────────────────────────●
         35% ┼───────────────────────────────● (30%體力)
             │                              / (風險區：拋物線二次方加速)
          5% ┼─────────────────────────────● (70%體力)
          0% ┼─────────────────●───────────┴─────────────────
            100%              70%         30%              0%   體力比例 (Stamina)
               【   安全區   】 【  風險區  】 【   危險區   】
```

## 2. 三段體力區間數值模型（`fatigueFailureRate`）

輸入為學員當前體力比例 $s \in [0, 1]$（$s = \frac{\text{CurrentStamina}}{\text{MaxStamina}}$），非有限數或負值自動防呆夾限。

### 2.1 安全區（Safe Zone）：$s \ge \mathbf{0.70}$（`FATIGUE_SAFE_RATIO`）
- **失敗率**：$\text{FailureRate} = \mathbf{0\%}$
- **行為規範**：學員精力充沛，訓練絕不發生任何因疲勞引發之失敗事件。

### 2.2 風險區（Risk Zone）：$\mathbf{0.30} \le s < \mathbf{0.70}$
- **失敗率端點**：由 $s = 0.70$ 時的 **$5\%$** 爬升至 $s = 0.30$ 時的 **$35\%$**。
- **區間進度**：$t = \frac{0.70 - s}{0.70 - 0.30} \in [0, 1]$
- **拋物線加速公式**：
  $$\text{FailureRate} = 0.05 + 0.30 \times t^2$$
- **設計哲學**：初期疲勞（60%體力）失敗率僅約 $7\%$，越接近 30% 臨界點失敗率加速惡化，提供漸進式心理預警。

### 2.3 危險區（Danger Zone）：$s < \mathbf{0.30}$（`FATIGUE_DANGER_RATIO`）
- **失敗率端點**：由 $s = 0.30$ 臨界點之 **$40\%$** 陡峭爬升至體力歸零（$s = 0$）時的 **$99\%$**。
- **區間進度**：$t = \frac{0.30 - s}{0.30} \in [0, 1]$
- **線性飆升公式**：
  $$\text{FailureRate} = 0.40 + 0.59 \times t$$
- **設計哲學**：嚴重透支狀態下強行訓練將面臨近乎必敗的毀滅性風險，杜絕過度壓榨學員之非正常玩法。

## 3. 數學特性與呼叫端防禦合約

1. **單調不減保證**：隨體力比例 $s$ 自 1.0 下降至 0.0，失敗率曲線嚴格維持單調不減（Monotonically Non-Decreasing），絕不存在體力越低失敗率反而下降的異常反轉。
2. **防禦性夾限（Clamping）**：
   - 輸入 $s > 1.0$ 時視為 1.0，失敗率為 0%。
   - 輸入 $s < 0.0$ 時視為 0.0，失敗率為 99%。
   - 輸入 `NaN` 或非有限數字時，系統安全回退為 0% 失敗率，防止流程阻斷崩潰。

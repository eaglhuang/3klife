# 自動培育功能解鎖限制與太傅代管方針規格書

> 標籤：`NUR-14` · `M8` · `自動培育` · `太傅代管` · `評級封頂` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，玩家消耗「自動培育券」對已完成入學之子嗣進行一整季 36 回合修業託管之演算法模型（`AutoNurture`）、數值平衡約束，以及四大「太傅代管排程方針（`DelegatePolicy`）」。

本模組為純邏輯無副作用運算，負責執行自動批次輪轉與排程組裝，道具消耗與介面回放由外部控制項調度。

---

## 2. 功能解鎖與道具門檻（Invariants）

自動培育旨在為多代傳承後期減輕手動操作負擔，設立嚴格准入門檻：

```typescript
export const AUTO_NURTURE_TICKET_COST = 1;

export function isAutoNurtureUnlocked(mainlineNurtureSeasonClearedOnce: boolean): boolean {
    return mainlineNurtureSeasonClearedOnce === true;
}
```

1. **主線通關解鎖**：玩家歷史紀錄中必須至少手動完成並結算過一次主線培育季（`mainlineNurtureSeasonClearedOnce === true`），方可永久開放該功能。
2. **單次道具消耗**：每次執行自動培育消耗 1 張「自動培育券」（`AUTO_NURTURE_TICKET_COST = 1`）。若票券不足則阻絕執行（`NO_TICKET`）。

## 3. 四大平衡性約束模型

為保障手動極致操作的不可替代性，自動培育施加了嚴格的收益折減：

```typescript
export const AUTO_NURTURE_RATING_CAP: NurtureRating = 'A';
```

### 3.1 平衡性約束表

| 約束維度 | 折減幅度 / 規則 | 設計意圖 |
|---|:---:|---|
| **屬性點獲取** | 結算數值 $\times 0.70$ | 模擬代管教學無法達到親傳之專注度 |
| **技巧點 TP** | 教官 TP 加成 $\times 0.50$ | 限制戰法學習進度，避免全自動畢業神將 |
| **評級天花板** | **絕對封頂 A 級**（S 級強制降為 A） | **禁止通過自動培育獲得「S 級天才覺醒名號」** |
| **隨機事件閉鎖** | 不觸發任何好感、受傷、師友羈絆事件 | 確保排程絕對穩定無翻車，但喪失奇遇暴擊收益 |

## 4. 太傅代管四大事實排程方針

玩家可指派四種經典太傅代管方針，自動生成 36 回合完整課表：

```typescript
export type DelegatePolicy = 'balanced' | 'martial' | 'civil' | 'strategy';
```

### 4.1 方針課表循環對照表

| 代管方針 | 戰略定位 | 課表循環週期 (4 回合一循環) | 36 回合修業配比 |
|:---:|---|---|:---:|
| **均衡 (`balanced`)** | 補齊短板，平穩發育 | 每回合動態檢索當前實力最低之科目修業 | 動態智能配比 |
| **尚武 (`martial`)** | 邊疆大將，摧鋒陷陣 | `[武力, 武力, 統率, 休息]` | 27 訓練 / 9 休沐 |
| **經世 (`civil`)** | 宰輔之臣，富國安民 | `[政治, 政治, 魅力, 休息]` | 27 訓練 / 9 休沐 |
| **奇謀 (`strategy`)** | 軍師參謀，帷幄運籌 | `[智謀, 智謀, 統率, 休息]` | 27 訓練 / 9 休沐 |

```typescript
export function resolveAutoSchedule(
    prowess: Record<TrainingKind, number>,
    manualSchedule?: readonly NurtureAction[]
): NurtureAction[] {
    if (manualSchedule && manualSchedule.length === NURTURE_TOTAL_ROUNDS) {
        return [...manualSchedule];
    }
    const minValue = Math.min(...TRAINING_KINDS.map((k) => prowess[k]));
    const lowest = TRAINING_KINDS.filter((k) => prowess[k] === minValue);
    return Array.from({ length: NURTURE_TOTAL_ROUNDS }, (_, i) => lowest[i % lowest.length]);
}
```

- 若玩家曾儲存過個人 36 回合手動課表，系統優先沿用歷史自訂排程；否則套用代管方針。

# 英靈卡三階光效共鳴模型與家族封頂數值規格書

## 1. 核心定位與職責範圍

本規格書定義英靈卡插槽後的三階共鳴光效判定模型、屬性增幅倍率與世家等級封頂約束，對應 WBS **SPI-05**。
英靈卡所蘊含的先祖神威，依據宿主（佩戴武將）與先祖之間的血統親疏，呈現出層次分明的共鳴反應。
系統透過純邏輯判定演算法，將共鳴狀態嚴格劃分為三階：自我共鳴（`SELF`）、家族共鳴（`FAMILY`）與迴響共鳴（`ECHO`），並依世家門閥等級設定硬性封頂上限，杜絕跨世家過度膨脹。

---

## 2. 三階共鳴光效判定狀態機

```mermaid
flowchart TD
    EquipCheck[英靈卡裝入命鏡槽] --> CheckCarrier{檢查宿主身份}
    
    CheckCarrier -- 宿主模板ID === 先祖模板ID --> SelfLevel[SELF_RESONANCE 自我共鳴\n金色烈芒 100% 全額加成]
    CheckCarrier -- 宿主血脈鍵 === 先祖家族鍵 --> FamilyLevel[FAMILY_RESONANCE 家族共鳴\n暖橙輝光 80% 加成 (受世家等級封頂)]
    CheckCarrier -- 異姓外將 / 宗族無關 --> EchoLevel[ECHO_RESONANCE 迴響共鳴\n淡藍微光 30% 微量加成]
    
    FamilyLevel --> CapCheck{比對世家門閥封頂上限}
    CapCheck -- 超過上限 --> ApplyCap[數值截斷至世家上限值]
    CapCheck -- 未達上限 --> KeepValue[全額套用家族加成]
```

### 2.1 共鳴階級定義與光效視覺契約
| 共鳴階級代碼 | 觸發條件 | 視覺光效呈現 | 屬性轉換率 | 專屬血脈奧義權限 |
|---|---|---|:---:|:---:|
| **`SELF_RESONANCE`** | 宿主即先祖本人（轉生/復生形態） | **金色烈芒（神聖強光粒子）** | **100%** | 完全激活（100% 威力） |
| **`FAMILY_RESONANCE`** | 宿主為同宗本姓子嗣（血脈相連） | **暖橙輝光（祥和宗族光暈）** | **80%** | 激活（威力受家族階位調控） |
| **`ECHO_RESONANCE`** | 宿主為異姓或無血脈關聯外將 | **淡青微光（微弱先賢共鳴）** | **30%** | **鎖定（無法發動專屬奧義）** |

## 3. 世家門閥封頂（Family Caps）數值模型

為了保證遊戲平衡，同宗家族成員享受之加成不可無限制堆疊，必須受當前世家等級（Tier 1~4）硬性封頂：

### 3.1 四階世家封頂階梯表
$$Bonus_{\text{effective}} = \min(Bonus_{\text{calculated}}, Cap_{\text{Tier}})$$

| 世家等級代碼 | 門閥稱謂 | 家族名聲門檻 | 五維單項加成封頂（$Cap$） |
|:---:|:---:|:---:|:---:|
| **Tier 1** | 寒門寒士 | `0` | **`+15`** |
| **Tier 2** | 郡望望族 | `1,000` | **`+30`** |
| **Tier 3** | 州邦名門 | `5,000` | **`+50`** |
| **Tier 4** | 百年世家 | `20,000` | **`+80`** |

- *註：自我共鳴（`SELF`）視為本人重臨，不受世家等級封頂約束，直接套用卡面原始快照之 100% 數值。*

## 4. 動態推導介面契約（Read Model）

```typescript
export type ResonanceType = 'SELF_RESONANCE' | 'FAMILY_RESONANCE' | 'ECHO_RESONANCE';

export interface SpiritResonanceResult {
    readonly resonanceType: ResonanceType;
    readonly visualVfxTag: string;           // 前端粒子特效掛載識別
    readonly multiplier: number;              // 基礎倍率 (1.0 / 0.8 / 0.3)
    readonly effectiveBonus: Record<string, number>; // 經封頂截斷後之最終加成
    readonly ultimateUnlocked: boolean;       // 專屬奧義是否解鎖
}
```

- 該判定在武將屬性更新與戰場初始化時純記憶體即時演算，零存檔污染。

## 5. 邊界約束與驗收條件

1. **同宗判定依據**：以武將資料中之 `bloodlineId` 或家族譜系指針（`familyKey`）為唯一準繩，嚴禁以字串模糊比對姓氏。
2. **單元測試驗收覆蓋**：
   - 驗證趙雲穿戴趙雲英靈卡，必定得出 `SELF_RESONANCE`，乘率為 1.0。
   - 驗證趙統（子嗣）穿戴趙雲英靈卡，得出 `FAMILY_RESONANCE`，乘率為 0.8。若加成值為 35 且世家為 Tier 1（封頂 15），最終加成嚴格截斷為 15。
   - 驗證魏延穿戴趙雲英靈卡，得出 `ECHO_RESONANCE`，奧義解鎖標記為 `false`。

# 英靈卡與虎符紋章視覺契約與血脈紋樣規格書

> **文件狀態**：單一真相來源（Single Source of Truth）  
> **系統代碼**：`SPV-01` ~ `SPV-03`、`SYS-SPIRIT-SIGIL-CONTRACT`  
> **核心職責**：確立核心名將「四件組」視覺圖層契約（血脈槽、英靈立繪、虎符紋章、特種軍勢旗牌），以單一 `Sigil_Pattern_ID` 貫穿人物、宗族、兵符與戰場部隊之血脈圖騰家族（Bloodline Crest Family）。

---

## 1. 核心名將四件組視覺架構（The Grand Quad）

每位列入全域英靈錄與譜牒傳承之名將，視覺呈現嚴格綁定四件組契約：

```
[本體血脈槽位] ──> [英靈卡傳承立繪] ──> [虎符金屬紋章] ──> [戰場特種旗牌]
  (Bloodline)        (Spirit Card)        (Tally Crest)       (Troop Banner)
       └──────────────────── 全域共用同一 Sigil_Pattern_ID ──────────────────┘
```

1. **本體血脈槽位（Bloodline Slot）**：
   - 位於人物頁「命 / Bloodline」分頁，呈現家族始祖星象與宿命神獸底紋。
2. **英靈卡形象（Spirit Card Portrait）**：
   - 武將退休或陣亡後凝結之神魂卡面，背景帶有透明祖靈光環與半身立繪。
3. **英靈虎符紋章（Tally Crest）**：
   - 鑲嵌於青銅/赤金虎符中央之立體獸首浮雕（如龍首、虎首、玄武、朱雀）。
4. **特種軍隊旗紋與兵牌（Troop Sigil Banner & Token）**：
   - 戰場實體部隊頂部飄揚之戰旗紋樣與部隊資訊牌底紋。

## 3. 圖層與資產階層契約（Layering Hierarchy）

所有相關 UI 面板（`CharacterDs3AptitudeChild`, `TigerTallyPanel`）必須遵循以下堆疊順序：
1. **Layer 0 (Base)**：底板材質與紙紋（`paper_texture_parchment`）。
2. **Layer 1 (Sigil Decal)**：由 `Sigil_Pattern_ID` 載入之 30% 透明度家族暗紋。
3. **Layer 2 (Character / Crest)**：英靈立繪主體或虎符金屬浮雕（`crest_normal.png`）。
4. **Layer 3 (Overlay & Frame)**：九宮拉伸或固定花角金屬框體（`gold_dragon_frame`）。
5. **Layer 4 (VFX Particle)**：天命流光粒子特效（僅 SSR / UR 階級啟用）。

## 4. 驗收標準與 CI 閘門（Acceptance Criteria）

1. **圖騰唯一映射約束**：
   - 任何已登錄之英靈卡與虎符資料物件，其 `sigilPatternId` 必須於 `SigilRegistry` 中存在對應紋樣資產，無孤立參考。
2. **資產尺寸與格式統一**：
   - 虎符紋章 Crest 統一為 $128 \times 128$ RGBA PNG。
   - 旗紋 Banner 統一為 $64 \times 128$ 向量或點陣圖樣。
3. **單元測試涵蓋**：
   - 包含四件組映射完整性檢核、非法圖騰 ID 阻絕與資產路徑驗證。

### 2.2 戰鬥數值加成與星級相乘公式
虎符部隊之最終攻防倍率由「虎符卡自身星級（`1★ ~ 5★`，每星 `+8%`）」與「灌注累積層級（`linkedTallyLevel`，上限 `5` 階，每階攻防 `+6%`）」**相乘**計算：
$$\text{StarMultiplier} = 1.0 + (\text{Star} \times 0.08)$$
$$\text{InfusionTierMultiplier} = 1.0 + (\min(5, \text{LinkedTallyLevel}) \times 0.06)$$
$$\text{FinalArmyAtkDefMultiplier} = \text{StarMultiplier} \times \text{InfusionTierMultiplier}$$
$$\text{CounterBonus} = \text{LinkedTallyLevel} \times 0.015$$
- **獨立乘區原則**：虎符專屬戰法多為被動效果，**不做統一「發動率 +3%」修正**，統一以「灌注每階攻防 `+6%`（上限 5 階）× 星級每星 `+8%`」作為標準數值收益。
- 騎兵克步兵、步兵克弓兵、弓兵克騎兵之基準克制比為 $1.30$，在滿級 Lv.10 虎符加成下增至：
  $$1.30 + 0.15 = 1.45 \quad (145\%)$$

## 3. 重複卡與兵魂灌注機制

1. **灌注來源與固定獎勵（`INFUSION_RECORD`）**：
   - 來自抽卡重複分流之【血脈灌注】（`doc_spec_0649`），每次灌注固定給予：**英靈卡全屬性 `+5%`、綁定虎符經驗 `+150`、宗族聲望 `+50`**，並寫入會話與存檔之 `INFUSION_RECORD`。
   - 消耗戰鬥獲取之「兵魂精魄」或多餘虎符碎片手動注入。
2. **多武將虎符綁定規則**：
   - 每位名將僅能綁定一件專屬虎符；
   - 虎符等級歸屬於玩家帳號之「虎符軍械庫」，即使該名將進行轉數或重生，虎符等級與特種部隊強度永久保留。

## 4. 資料模型與持久化

```typescript
export interface TigerTallyUpgradeState {
  tallyId: string;                 // 如 "TALLY_WHITE_HORSE"
  boundGeneralUid: string;         // 綁定武將 UID
  linkedTallyLevel: number;        // 1 ~ 10
  currentExp: number;              // 當前累積點數
  nextLevelExp: number;            // 升階門檻點數
  unlockedTroopForm: string;       // 部隊當前形態識別碼
  counterModifier: number;         // 當前克制修正值 (0.015 ~ 0.150)
  armyPowerMultiplier: number;     // 當前部隊戰力倍率 (1.06 ~ 1.60)
}
```

# 虎符專屬戰法十四條落地數值模型與被動機制規格書

## 1. 核心定位與分類契約

本規格書為虎符特殊與名將專屬戰法（G-1 Tiger Tally Tactics Suite，代號 `TAC-10`）的單一真相來源（Single Source of Truth）。涵蓋死亡傳承通用虎符與名將專屬虎符共 14 條核心專屬戰法之數值模型、被動生效條件與戰場結算契約。

```typescript
export interface TigerTallyG1Contract {
  category: 'TIGER_TALLY_G1';
  totalActiveCount: 14;
  tallyGroups: 'general' | 'named';
  battleProfileMappingAuthority: 'BattleSkillProfiles.ts';
}
```

## 3. 戰鬥被動生效與屬性疊加規則

1. **出陣載入判定（Sortie Injection）**：
   - 虎符裝備於主將或先鋒部隊後，戰場初始化時透過 `TigerTallySpecTactics` 將 `tacticId` 轉譯為戰鬥技能 `battleSkillId`。
   - 若部隊兵力歸零（潰滅），該虎符專屬被動即刻失效。
2. **傷害乘區與上限約束**：
   - 百步穿楊（$+50\%$ 暴擊）與神射暴擊率累計，上限不得超越全域爆擊硬頂天花板（$95\%$）。
   - 裸衣決鬥之傷害翻倍（$\times 2.0$）與一般陣法增益採獨立乘算，但不影響奧義（Ultimate）基礎威力。

## 4. 戰場記錄與狀態機連動

1. **日誌記錄格式**：
   - 穿透命中：`skill.tally_defense_pierce.hit:{targetId}:{damage}`
   - 恐懼定身：`skill.tally_changban_root.root:{targetId}:1`
   - 連環傷害傳導：`skill.link.tally:{primaryId}->{linkedId}:{damage}`
2. **地格互動連動**：
   - 火神狩獵與火計連環產生的火海地格，受天候強約束（暴雨天氣即刻熄滅，強風天氣擴散 1 格）。

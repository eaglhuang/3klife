# 虎符忠誠度維護與戰場抗命背叛數值模型規格書

> **文件狀態**：單一真相來源（Single Source of Truth）  
> **系統代碼**：`NUM-13`、`SYS-TALLY-LOYALTY-MUTINY`  
> **核心職責**：確立三十四營特殊兵種虎符之忠誠度衰減與維護模型、連續頻繁更換主將之懲罰加權，以及忠誠度低落時引發「臨陣抗命（拒令）」與「戰場倒戈叛變」之確定性狀態機。

---

## 1. 忠誠度增減與動態衰退模型

虎符部隊並非無條件盲從之機械死士，而是具備部隊榮譽與專屬將領情誼之精銳軍勢：
- **初始忠誠度**：新解鎖或入庫之虎符預設為滿值 $100$ 點。
- **更換主將扣減（Reassignment Penalty）**：
  - 每次自主將身上卸下並轉授他人，扣除基礎忠誠度 $10$ 點。
  - **連續更換懲罰**：若在同一季度（Quarter）內連續更換主將超過 1 次，自第 2 次起扣除值乘以 $1.5$ 倍累進（第2次 -15點，第3次 -22點）。
- **季度自然修復**：
  - 史實專屬主將裝配出征：每季結束 $+10$ 點。
  - 同陣營主將常態裝配：每季結束 $+5$ 點。
  - 放置於倉庫待命：不增不減。

## 2. 忠誠度四態狀態機與戰場行為

依據部隊當前忠誠度數值（$\text{Loyalty} \in [0, 100]$），劃分四大戰場狀態：

```
[LOYAL (聽令如山)] ──> [RESTLESS (軍心浮動)] ──> [DISOBEDIENT (臨陣抗命)] ──> [MUTINOUS (反戈叛變)]
 (100 ~ 60)              (59 ~ 30)                 (29 ~ 10)                 (9 ~ 0)
```

| 狀態名稱 | 忠誠度區間 | 戰鬥負面影響 | 觸發機率與行為契約 |
|---|:---:|---|---|
| **LOYAL (忠心耿耿)** | $60 \sim 100$ | 無負面影響 | 100% 聽從玩家指揮，享有完整星級與共鳴加成 |
| **RESTLESS (軍心浮動)**| $30 \sim 59$ | 士氣低迷 | 部隊攻防屬性下降 $10\%$，無法觸發暴擊 |
| **DISOBEDIENT (臨陣抗命)**| $10 \sim 29$ | 拒絕調遣 | 每回合下達指令時，**50% 機率原地待命並彈出【軍士怨懟，拒不出擊】** |
| **MUTINOUS (倒戈叛變)**| $0 \sim 9$ | 戰場反噬 | 出陣開局時 **15% 機率直接倒戈轉化為中立暴民**，攻擊距離最近之友軍 |

## 3. TypeScript 數值演算模組

```typescript
export enum TallyLoyaltyStatus {
  Loyal = 'LOYAL',
  Restless = 'RESTLESS',
  Disobedient = 'DISOBEDIENT',
  Mutinous = 'MUTINOUS'
}

export function evaluateTallyLoyaltyStatus(loyalty: number): TallyLoyaltyStatus {
  if (loyalty >= 60) return TallyLoyaltyStatus.Loyal;
  if (loyalty >= 30) return TallyLoyaltyStatus.Restless;
  if (loyalty >= 10) return TallyLoyaltyStatus.Disobedient;
  return TallyLoyaltyStatus.Mutinous;
}

export function computeReassignmentDeduction(changeCountInQuarter: number): number {
  const baseDeduction = 10;
  if (changeCountInQuarter <= 1) return baseDeduction;
  const multiplier = Math.pow(1.5, changeCountInQuarter - 1);
  return Math.floor(baseDeduction * multiplier);
}
```

## 4. 驗收標準與 CI 閘門（Acceptance Criteria）

1. **連續更換懲罰單元測試**：
   - 模擬同一季更換 3 次，扣除值依序為 10、15、22 點，忠誠度扣至 0 時不為負數。
2. **抗命與叛變邊界判定**：
   - 當 $\text{Loyalty} = 29$ 時必須被正確分類為 `DISOBEDIENT`，並有機率拒絕指令。
3. **倒戈陣營切換驗證**：
   - 叛變發生時，部隊實體之陣營標籤（Faction）即刻由 Player 轉為 Neutral/Rogue，血條轉為黃色。

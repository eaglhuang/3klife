# 虎符戰力綜合評級與升星突破成本模型規格書

> **文件狀態**：單一真相來源（Single Source of Truth）  
> **系統代碼**：`NUM-12`、`SYS-TALLY-POWER-MODEL`  
> **核心職責**：確立三十四營特殊兵種虎符之戰力評分公式（品質/星級/共鳴/適性四重乘區）、升星突破成本消耗階梯（1~5 星碎片與精華）以及保底突破無碎裂原則。

---

## 1. 虎符戰力綜合評級公式（Tally Power Rating）

虎符為部隊帶來之綜合戰鬥力評分（$\text{TallyPower}$）由基礎數值與四重獨立乘區複合計算：
$$\text{TallyPower} = \left\lfloor \text{BaseRating} \times Q_{\text{mod}} \times \left(1 + (S - 1) \times 0.25\right) \times M_{\text{resonance}} \times M_{\text{aptitude}} \right\rfloor$$

- **基礎戰力 ($\text{BaseRating}$)**：三十四營部隊基底值，固定為 $500$ 點。
- **品質修飾係數 ($Q_{\text{mod}}$)**：
  - 凡品 (White)：$1.0$｜良品 (Green)：$1.2$｜上品 (Blue)：$1.5$
  - 極品 (Purple)：$2.0$｜絕品 (Gold)：$2.8$｜神品 (Red)：$4.0$
- **星級乘區 ($S \in [1, 5]$)**：每提升 1 星提供 $+25\%$ 獨立戰力增幅（5 星達 $+100\%$）。
- **血脈共鳴係數 ($M_{\text{resonance}}$)**：
  - 史實專屬主將裝配（如陳到裝配白毦兵）：$M_{\text{resonance}} = 1.35$（+35%）
  - 同國籍/陣營主將裝配：$M_{\text{resonance}} = 1.15$（+15%）
  - 無特定關係：$M_{\text{resonance}} = 1.00$
- **地形適性係數 ($M_{\text{aptitude}}$)**：
  - S: $1.20$｜A: $1.10$｜B: $1.00$｜C: $0.90$｜D: $0.80$

## 2. 升星突破成本與材料消耗階梯

虎符升星嚴格秉持「**百分之百成功、絕無碎裂與降階**」之保底保護原則：

| 目標星階 ($S$) | 專屬兵符碎片消耗 | 宗族功業精華 (Essence) | 銅錢消耗 (Copper) | 特性解鎖 |

| **2 星** | 20 | 100 | 5,000 | 部隊移動力 +1 |

## 3. TypeScript 數值評分演算法

```typescript
export interface TallyPowerInput {
  baseRating: number;
  quality: 'White' | 'Green' | 'Blue' | 'Purple' | 'Gold' | 'Red';
  starLevel: number; // 1 ~ 5
  resonanceType: 'Exclusive' | 'Faction' | 'None';
  aptitudeRank: 'S' | 'A' | 'B' | 'C' | 'D';
}

export function computeTallyBattlePower(input: TallyPowerInput): number {
  const qualityMap = { White: 1.0, Green: 1.2, Blue: 1.5, Purple: 2.0, Gold: 2.8, Red: 4.0 };
  const resonanceMap = { Exclusive: 1.35, Faction: 1.15, None: 1.0 };
  const aptitudeMap = { S: 1.2, A: 1.1, B: 1.0, C: 0.9, D: 0.8 };

  const starMod = 1 + Math.max(0, input.starLevel - 1) * 0.25;
  const rawPower = input.baseRating 
    * qualityMap[input.quality] 
    * starMod 
    * resonanceMap[input.resonanceType] 
    * aptitudeMap[input.aptitudeRank];

  return Math.floor(rawPower);
}
```

# 3KLife 虎符英靈卡特種軍隊三位一體視覺對應標準規格書

> **規格代碼**：SPEC-ART-BVC05  
> **關聯 WBS**：BVC-05（M10 虎符/英靈卡/特種軍隊視覺對應，對應 UI-2-0064）  
> **文件版本**：v1.0.0 (單一真相來源，無補丁整併版)  
> **所屬系統**：UI 介面與視覺工程（UI Architecture & Art Pipeline）

---

## 1. 核心宗旨與設計哲學

武將覺醒血脈後，在各系統中會具象化為三種不同表現形式之載體：
1. **虎符兵牌 (Tiger Tally)**：代表出征統御權柄，呈現於軍事編隊、虎符升階介面。
2. **英靈命卡 (Hero Spirit Card)**：代表血脈神魂與宿命傳承，呈現於血統樹、命鏡覺醒介面。
3. **特種軍隊 (Elite Troop)**：代表專屬精銳禁衛部隊（如白馬義從、虎豹騎、陷陣營），呈現於戰鬥與大地圖。

為解決歷史資產中「虎符雕白虎、英靈畫青龍、軍隊掛朱雀旗」之風格脫節現象，本規格書正式規範「三位一體視覺對應標準（Trinity Visual Mapping Standard）」，強制三者共享同一徽記、材質色階與靈獸圖騰。

---

## 2. 三位一體視覺對應規範 (Trinity Mapping)

### 2.1 視覺要素對照矩陣

| 視覺維度 | 虎符兵牌 (Tiger Tally) | 英靈命卡 (Hero Spirit Card) | 特種軍隊 (Elite Troop) |
|---|---|---|---|
| **主徽記 (Crest)** | 兵符腹部凹凸青銅陽文 | 卡面頂端中央血脈徽章 (`SIZE_MD`) | 軍隊大纛戰旗中央印鑑紋樣 |
| **靈獸圖騰 (Beast)** | 虎符首尾雕琢之六大靈獸形態 | 英靈背後浮現之靈獸水墨虛影 | 士兵披風與盾牌上之靈獸刺繡暗紋 |
| **金屬材質 (Material)** | 鍛造青銅/白銀/赤金兵牌質地 | 卡框青銅包角與鎏金浮雕外緣 | 將士肩甲胸鏡與長槍戟刃金石質地 |
| **動態光芒 (Aura)** | 兵符閉合時之微光咬合線條 | 卡面邊緣低頻流光呼吸效果 | 戰場集結時部隊頭頂之士氣微芒 |

### 2.2 稀有度色彩階梯同步規則

三者之配色與邊緣特效嚴格依循全域稀有度對映表（引自 `doc_spec_0670`）：
- **N（素銀）**：素銀古鐵、啞光未開刃質感，無動態光暈。
- **R（古銅）**：青銅暗綠、金石微雕，10% 水墨暗流。
- **SR（紫微）**：紫微冷玉、細緻金絲鑲嵌，20% 幽藍微芒。
- **SSR（流金）**：赤霄澄金、精鑄蟠龍雲紋，35% 鎏金流光。
- **UR（紫金）**：山河九鼎金珀、神獸真形立體浮雕，50% 靈韻升騰。

## 3. 資料契約與綁定介面

```typescript
export interface TrinityVisualBindingSpec {
  generalId: string;                  // 武將 ID (如 GEN_ZHAOYUN)
  bloodlineFactor: 'CIV' | 'CHARM' | 'VIRTUE' | 'MARTIAL' | 'COMMAND' | 'LUCK';
  rarityTier: 'N' | 'R' | 'SR' | 'SSR' | 'UR';
  sharedCrestId: string;              // 共用徽記資產 ID
  
  // 1. 虎符兵牌設定
  tally: {
    baseMesh: string;                 // 虎符 3D/2.5D 模型或 Sprite
    splitLineEffect: string;          // 陰陽合符咬合光效
    carvingStyle: 'bronze' | 'gold_inlaid' | 'jade';
  };
  
  // 2. 英靈命卡設定
  spiritCard: {
    cardFrameSkin: string;            // 命卡外框風格 (依稀有度)
    spiritBeastBackdrop: string;      // 背後靈獸水墨背景 (嚴禁科技 HUD)
    auraPulsePeriodSec: number;       // 光芒呼吸週期 (標準 2.4s)
  };
  
  // 3. 特種部隊設定
  eliteTroop: {
    troopId: string;                  // 特種兵 ID (如 TR_WHITE_HORSE)
    flagSigilSprite: string;          // 軍旗大纛印鑑 (同 sharedCrestId)
    shieldDecoration: string;         // 盾牌塗裝暗紋
    vanguardCapeColor: string;        // 先鋒披風主色階
  };
}
```

## 4. 驗收測試案例 (Test Cases)

- **TC-BVC-05-01【徽記跨系統一致性檢驗】**：以趙雲為例，驗證其虎符、英靈卡、白馬義從軍旗皆讀取同一筆 `CREST_BLUE_XUANWU`，無混用不同靈獸之情況。
- **TC-BVC-05-02【稀有度材質連動驗證】**：當武將由 SSR 升階至 UR 時，虎符兵牌金屬反射度、英靈卡框鎏金、特種軍隊大纛穗帶同步切換為九鼎金珀光澤。
- **TC-BVC-05-03【未覺醒狀態降級保底】**：未覺醒武將之特種軍隊軍旗自動回退為標準漢軍黑底紅字「漢」旗，避免無血脈武將出現空徽記缺圖錯誤。

# 3KLife 虛張聲勢擂鼓吶喊疑兵布陣逼退追兵狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 戰場心理欺瞞與斷後疑兵系統（`DECEPTION-DRUM-BOAT01`）。重現張飛長坂橋「據水斷橋，瞋目橫矛」、諸葛亮借箭後「二十隻船齊聲大噪，虛張聲勢」以及水上以少數空船拖曳柴草偽裝大軍合圍之疑兵戰術。在兵力劣勢或撤退時，利用心理博弈製造重兵伏擊假象，震懾迫使敵追兵猶豫逡巡不敢逼近。

## 4. 心理威懾、多疑檢定與拖延回合公式

### 4.1 疑兵欺瞞逼退成功率
敵方追擊部隊受聲勢威懾停止追擊之機率：
$$P_{\text{bluff}} = \left(\frac{\text{BluffCommanderInt} + \text{BluffCommanderBravery}}{150}\right) \times \text{EnemySuspicionFactor} \times \left(1.0 + \frac{\text{NoiseIntensity}}{100}\right)$$
- 敵將多疑（如曹操、司馬懿）$\text{EnemySuspicionFactor} = 1.6$；
- 敵將勇而無謀（如華雄、文醜）$\text{EnemySuspicionFactor} = 0.5$（易直衝識破）；
- 成功時，敵追軍原地駐足下錨，威懾率達 $90\%$。

### 4.2 爭取主力撤退安全距離
疑兵為主力爭取之撤退緩衝時間：
$$\text{DelayTurns} = \max\left(1, \left\lfloor \frac{\text{EnemySuspicionLevel}}{30} \right\rfloor\right)$$
- 敵軍逡巡期間，主力水師艦隊可在下游拉開 4 至 8 格安全航行距離，從容回泊水砦大本營。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-BLUFF-01**：同一場戰役中對同一敵將連續使用疑兵計策，敵將疑心加成清零，第 2 次成功率強制扣減 $60\%$。
2. **驗收 CASE-BLUFF-02**：當疑兵部隊數量 $\le 2$ 艘且無拖枝造勢時，聲勢不足，敵軍哨探可輕易望見虛實，疑兵計直接失效。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

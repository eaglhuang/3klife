# 血統傳承 G1 初代開局：直覺相馬與開蒙修業規格書

## A. 系統描述

本規格書定義玩家在 **第一代（G1 初代家主結婚 ～ 第一代子嗣成材）** 的核心體驗。
在 G1 階段，玩家的目標是「立身亂世、迎娶佳偶、教養長子」。為了避免新手被 14 祖位、上限 $m$、近親履歷 $h$ 等硬核數據嚇退，G1 採取 **「全直覺包裝」**：
1. **說親階段（直覺相人）**：只看對方的「門風評語（400/200 粗箱）」與「成名絕技（1～2 個顯性特質）」。
2. **開蒙修業（賽馬娘培育的三國化）**：子嗣出生僅兌現 $15\%$ 潛力，12 歲入學兌現 $20\%$，透過 **36 季開蒙修業（最多 27 課業 T + 9 休沐 R）** 決定最終能把先天潛力 $P$ 兌現多少（$A/P$ 覺醒比）。
3. **兩次先祖遺風覺醒（賽馬娘女神像的三國化）**：在 **12 歲開蒙禮** 與 **15/16 歲弱冠/及笄禮** 各有一次「先祖遺風覺醒」演出，讓玩家在不看複雜公式的情況下，親眼見證父母與外祖父的特質跳到孩子身上！

## B. 系統目的

1. **零公式門檻上手**：前 3 小時完全不出現任何數學符號或配種術語，全用三國古風語彙（「將門虎女」、「書香世家」、「開蒙拜師」、「加冠覺醒」）呈現。
2. **建立「光生不養沒用」的核心認知**：讓玩家明白先天 $P$ 只是天花板，必須透過名師（太傅）與 36 回合修業才能把潛力兌現為實質戰力 $A$。
3. **埋下血統深度的第一顆種子**：當孩子在 16 歲加冠禮突然跳出「隔代承襲外祖父之【水師統御 S】」時，自然引發玩家好奇：「如果我下一代故意找特定名將聯姻，會發生什麼事？」
4. **防範多子養成疲勞**：從 G1 第二胎開始即開放 **「太傅代管」**，確保玩家不會因為生了 3～5 個孩子而被迫重複打 5 次 36 回合小遊戲。

## F. 公式相關

### 1. 賽馬娘變數 → 三國開蒙修業對照與公式
| 賽馬娘變數 | 三國開蒙變數 | G1 規格公式與規則約束 |
|---|---|---|
| 初始屬性 | 幼年根骨 $B$ / 開蒙初值 $A_0$ | $B = \lfloor 0.15 \times P \rfloor$（0歲），$A_0 = \lfloor 0.20 \times P \rfloor$（12歲入學） |
| 72 回合養成 | **36 回合開蒙修業** | 嚴格共享預算 **36 回合**，其中訓練課業 $T \le 27$ 回合，休沐調養 $R \ge 9$ 回合（標準上限 27T9R） |
| 5 種訓練（速耐力根智） | **五維課業**（武/統/智/政/魅） | 每次課業提升對應維度覺醒進度 $\Delta A$ 與技能點 $TP$，但永遠受先天上限 $P$ 封頂（$A \le P$） |
| 支援卡 6 張 | **開蒙師資席**（主太傅 1 + 伴讀/副師 2~3） | 影響單次課業成長效率與教案池（可領悟戰法/內政技能），**嚴禁偷改先天潛力 $P$** |
| 出道前 + 經典年女神像 | **12 歲開蒙禮 + 16 歲加冠禮** | 兩次獨立形成檢定（基礎形成率 $q = 0.0591$），決定當胎因子最終落點與兵種適性升階（如騎 A → 騎 S） |

### 2. G1 說親資訊箱（Information Box）轉換表
在 G1 階段，未消耗查券時僅顯示 **400 箱（五維總和粗評）** 與 **最高單項傾向**：

| 五維先天總和區間（400 箱） | UI 顯示風聞評語 | 單項潛力區間（200/50 箱） | UI 顯示單維評語（不露數字） |
|---|---|---|---|
| $< 250$ | 「凡俗之姿」 | $< 50$ | 「平庸」 |
| $250 \sim 329$ | 「良家子弟」 | $50 \sim 69$ | 「幹練」 |
| $330 \sim 389$ | 「一時俊彥」 | $70 \sim 84$ | 「出眾」 |
| $390 \sim 439$ | 「國士之風」 | $85 \sim 94$ | 「絕倫」 |
| $\ge 440$ | 「天縱奇才」 | $\ge 95$ | 「曠世無雙」 |

{
  "Enlightenment_Session": {

    "Total_Budget_Turns": 36,
    "Max_Train_Turns": 27,
    "Min_Rest_Turns": 9,
    "Used_Train_Turns": 14,
    "Used_Rest_Turns": 5,

### Server / 存檔端
| 欄位 | 型別 | 說明 |
|---|---|---|
| `Child_UID` | `VARCHAR(32) PK` | 子嗣唯一 ID |
| `Innate_P_Ticks` | `BIGINT[5]` | 五維先天上限 $P$（以 `1 點 = 10000 ticks` 儲存，G1 UI 遮罩不直出） |
| `Current_A_Ticks` | `BIGINT[5]` | 當前已兌現五維能力 $A$（出生 $0.15P$ → 入學 $0.20P$ → 修業累加） |
| `Train_Turns_Used` | `TINYINT` | 已執行課業回合數（上限 27） |
| `Rest_Turns_Used` | `TINYINT` | 已執行休沐回合數（下限 9，與課業合計 36） |
| `Skill_TP_Pool` | `INT` | 修業累積之戰法/技能領悟點數 |

## J. 名詞定義

| 名詞 | 代碼/Key | 定義 |
|---|---|---|
| 先天潛力 $P$ | `Innate_Potential_P` | 出生瞬間由血統與雙親 `EP` 決定的五維天花板，後天培育不可超越此上限 |
| 開蒙初值 $A_0$ | `Enroll_Base_A0` | 12 歲入學時的初始能力，固定為 $\lfloor 0.20 \times P \rfloor$ |
| 覺醒比 $A/P$ | `Awakening_Ratio` | 18 歲成材時實際能力 $A$ 佔先天潛力 $P$ 的百分比，反映 36 回合培育品質 |
| 兩次覺醒禮 | `Dual_Awakening_Rites` | 12 歲開蒙與 16 歲加冠的兩次因子/適性跳出檢定（對標《賽馬娘》兩次女神像繼承） |
| 資訊箱 (400/200/50) | `Info_Mask_Boxes` | 控制未查驗角色能力揭露精度的迷霧區間（數字越小代表區間越窄、越精準） |

# 血統傳承 G2 二代傳承：功業回流與三代譜牒規格書

> **來源文件**：血統與家系漸進揭露里程碑總綱規格書 (doc_spec_0181)、血統理論系統規格書 (doc_spec_0011)、武將壽命系統規格書 (doc_spec_0027)、人物血統與家系工程驗收-C2-R4-評審稿 (`DEC-R4-01`, `DEC-R4-05`)

---

## A. 系統描述

本規格書定義當玩家跨入 **第二代（G2：首位子嗣滿 18 歲成材，或初代家主步入中老年/退位）** 時解鎖的核心深度系統。
在 G1 體驗過開蒙覺醒的爽感後，玩家在 G2 會面臨兩個核心問題：「為什麼我打天下立的戰功對後代有用？」以及「老武將年紀大了體力衰退怎麼辦？」。因此 G2 正式揭露以下四大機制：
1. **三代十四席宗族譜牒（14-Slot Pedigree）**：展開父母（2）＋祖父母（4）＋曾祖父母（8）共 14 席血統傳遞樹，並公開傳遞權重（`0.28 / 0.14 / 0.07`）。
2. **生平功業 `EP` 五錨點連續插值與戰役印記（白因子）**：初代人物的戰場與朝堂成就（`EP 0~100`）不再有分檔斷崖，而是透過 `0 / 25 / 50 / 75 / 95` 五錨點連續線性插值拉高子代先天 $P$ 分佈，並在退位時凝練「生平戰役印記」。
3. **天賦星級（`1~5★`）、上限 $m$（顯性/連攜）與「家學研習（確定補救）」**：揭露藍因子星數與當胎上限 $m$ 的關係；當繼承星數不理想時，開放消耗培育預算進行 **研習方案 A（確定補救 `1→2` 或 `2→3` 星，上限 3 星）**。
4. **文武分流巔峰曲線與「榮退太傅（自產 SSR 支援卡）」**：揭露早峰/中峰/晚峰年齡曲線，武力隨年齡體能下滑，但智政魅維持高平原；高 `EP` 老臣退居二線後可擔任家族「太傅」，把畢生絕學親授給第三代孫輩！

---

## B. 系統目的

1. **打通「外場戰功」與「內場繁衍」的閉環**：透過 `EP` 連續線性插值，讓玩家深刻感受到「每一場勝仗、每一次升官（哪怕只多 5 點 EP），都在實打實提高下一代的起跑線」。
2. **賦予中老年武將第二春**：解決三國遊戲老將衰老後淪為倉管的痛點——老將退居「宗學太傅」即成為最強自產支援卡。
3. **引入可控的保底養成策略**：開放「門風連攜（雙親互補/同持拔高上限 $m$）」與「家學研習（確定補救至 3 星）」，讓中度玩家不用賭純隨機也能穩定養出 3 星中堅世家。

## F. 公式相關

### 1. 生平功業 `EP` 五錨點連續線性插值（C2-R4 定案公式）
設有效功業為 $e = \min(\text{EP}, 95)$，五個錨點為 $A_0=0, A_1=25, A_2=50, A_3=75, A_4=95$。
當 $e \in [A_k, A_{k+1}]$ 時，插值權重 $\lambda \in [0, 1]$ 為：
$$\lambda = \frac{e - A_k}{A_{k+1} - A_k}$$
子代先天五維基準分佈 $F(e)$ 由相鄰兩錨點分佈 $F(A_k)$ 與 $F(A_{k+1})$ 線性合成：
$$F(e) = (1 - \lambda) F(A_k) + \lambda F(A_{k+1})$$
> **設計保護**：此公式保證每提升 1 點 `EP` 都有平滑正回饋（例如 `EP 86` 與 `EP 76` 的五維總和期望差距精確為 `112.5P`），不會發生舊版差 1 點跳 `190P` 或同檔差 10 點卻 0 差距的漏洞。

### 2. 三代 14 祖位傳遞權重與缺失補齊
- **父 / 母（2 席）**：各佔權重 `0.28`（合計 `0.56`）
- **祖父 / 祖母 / 外祖父 / 外祖母（4 席）**：各佔權重 `0.14`（合計 `0.56`）
- **曾祖輩（8 席）**：各佔權重 `0.07`（合計 `0.56`）
- **缺失祖位處理**：初代史實或創始武將若無記錄之祖位，固定由 `WorldBaselinePool`（世界基底池）依該角色出身門第生成確定性虛擬祖先，禁止留空導致分母失真。

### 3. 家學研習（方案 A：確定補救，`DEC-R4-01` 拍板）
$$\text{Star}_{\text{after}} = \begin{cases} 
\text{Star}_{\text{before}} + 1, & \text{if } \text{Star}_{\text{before}} \in \{1, 2\} \text{ and } \text{UsedStudy} = \text{false} \\
\text{Star}_{\text{before}}, & \text{if } \text{Star}_{\text{before}} \ge 3
\end{cases}$$
- **硬約束**：每名子嗣於 36 回合開蒙期間**僅限執行 1 次**家學研習；消耗 `2` 回合課業額度與家族文書工時；最高只能補救至 `3★`（`4★` 與 `5★` 必須靠血統連攜/純化與自然形成率 $q=0.0591$ 取得）。

### 4. 文武分流年齡曲線與健康任期 $H$（`DEC-R4-05` 補充）
- **健康任期總預算**：
  $$H = 25 + 40 m_1 + 20 m_2$$
  （其中 $m_1, m_2 \in [0, 1]$ 為兩項健康韌性藍因子正規化強度）。
- **年齡曲線分流**：
  - **武藝體魄（`STR`）**：在巔峰窗（早峰 `19–27` / 中峰 `24–35` / 晚峰 `29–42`）達 $100\%$；過峰後每年依衰退斜率下調表現上限。
  - **謀略治政（`INT / POL / CHA`）**：過峰後進入「老練高原期」，表現倍率維持 $95\% \sim 100\%$ 不下墜，但每季執政或隨軍出征額外消耗健康定額 $\Delta H_{\text{aging}}$。當健康 $H$ 耗盡時觸發「告老還鄉（轉任太傅）」或病篤。

# 血統樹十四人祖譜矩陣結構與字典引用規格書

> 標籤：`BLT-01` · `M2` · `血統譜牒` · `祖譜矩陣` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統體系中，武將向上追溯三代之「14 人祖譜矩陣（Pedigree）」資料結構、插槽位置代碼（Slots）以及基於人物全域名冊（PersonRegistry）之扁平化共享字典圖走訪演算法（`BloodlineGraph`）。

本架構全面廢除多層巢狀實體物件（Nested Structs），改以字典索引與鄰接表（Adjacency List）走訪，記憶體佔用降低 70% 以上，並提供純邏輯無副作用運算。

---

## 2. 14 人祖譜插槽定義（Pedigree Slots）

14 人祖譜嚴格依循二進位親緣樹展開，插槽字串長度即代表世代深度（Generation 1~3）：

```typescript
export const PEDIGREE_SLOTS = [
    'F', 'M',                                                   // Gen 1: 父母 (2人)
    'FF', 'FM', 'MF', 'MM',                                     // Gen 2: 祖父母/外祖父母 (4人)
    'FFF', 'FFM', 'FMF', 'FMM', 'MFF', 'MFM', 'MMF', 'MMM',     // Gen 3: 曾祖父母 (8人)
] as const;

export type PedigreeSlot = typeof PEDIGREE_SLOTS[number];
export type Pedigree = Record<PedigreeSlot, string | null>;

export function pedigreeSlotGeneration(slot: PedigreeSlot): 1 | 2 | 3 {
    return slot.length as 1 | 2 | 3;
}
```

### 2.1 插槽語義對照表

| 插槽代碼 | 世代 (Gen) | 親屬稱謂 | 親等關係 |
|---|:---:|---|---|
| `F` / `M` | 1 | 父親 / 母親 | 一等直系血親 |
| `FF` / `FM` | 2 | 祖父（父之父） / 祖母（父之母） | 二等直系血親 |
| `MF` / `MM` | 2 | 外祖父（母之父） / 外祖母（母之母） | 二等直系血親 |
| `FFF` ~ `FMM` | 3 | 父系曾祖父母（共 4 位） | 三等直系血親 |
| `MFF` ~ `MMM` | 3 | 母系曾外祖父母（共 4 位） | 三等直系血親 |

## 3. 扁平化共享字典資料結構

全域血統網由 `PersonRecord` 與 `BloodlineLink` 二元關係組成：

```typescript
export interface PersonRecord {
    uid: string;
    name: string;
    ep_base: number;
    tags?: string[];
    factorIds?: string[];
    isVirtual?: boolean;
}

export interface BloodlineLink {
    child_uid: string;
    parent_uid: string;
    relation: 'F' | 'M' | 'U'; // F: 父, M: 母, U: 未知
}
```

- **單一真相來源**：武將個體詳細設定統一收納於全域名冊字典 `_persons: Map<string, PersonRecord>`。
- **祖譜輕量索引**：`Pedigree` 僅記錄插槽至 `uid` 的鍵值對（未知填 `null`），避免物件重複複製。
- **近親重複可視**：與去重集合不同，`Pedigree` 保留每個插槽的實際指向；若同一祖先出現在多個插槽（如 `FF` 與 `MF` 同人），可直接用於近親交配檢測。

## 4. 圖走訪核心演算法（BloodlineGraph）

### 4.1 廣度優先祖先鏈檢索（getAncestorChain）
利用佇列進行 BFS 走訪，取得深度內所有不重複之祖先列表，按世代由近至遠排序：

```typescript
export function getAncestorChain(uid: string, depth = 3): string[]
```

### 4.2 14 人祖譜構建（getPedigree）
依序遍歷 14 個插槽，藉由父位插槽逐層向上追溯直系雙親：
```typescript
const parentSlot = slot.slice(0, -1);
const childUid = parentSlot === '' ? uid : pedigree[parentSlot];
```

### 4.3 最近共同祖先距離（commonAncestorDistance）
計算甲、乙兩人在指定代數（預設 3 代）內之親緣距離：
- 遍歷雙方祖先深度對照表，共同祖先距離定義為 $\max(\text{dist}_A, \text{dist}_B)$。
- 兄弟姊妹距離 $= 1$；堂表親距離 $= 2$；再從親距離 $= 3$。
- 若無共同祖先，回傳 `null`。

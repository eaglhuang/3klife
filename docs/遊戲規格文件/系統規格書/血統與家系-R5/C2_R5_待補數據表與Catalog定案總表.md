## 1. 出生與血統遺傳數據與候選分帳（對應 Q03、Q04、Q09、Q10）

### 1.1 `B-GAP-02`（對應 Q03）：幼兒幸運值 `childLUK`

#### A. 已核事實（`R5F-B02` §3.5 基線）
- `childLUK` 定義於 $[0, 100]$ 整數域，採**向 50 回歸 30%**、**離散擾動 $\Delta \in \{-10, 0, +10\}$（機率 `25% / 50% / 25%`）**，最後一次做 **`round-half-even`**。
- 歷史連代最大擾動序列（合法基底為 `70` 時）：
  $$70 \rightarrow 74 \rightarrow 77 \rightarrow 79 \rightarrow 80 \rightarrow 81 \rightarrow 82$$
- `R5F-B02` 同段明確記載：**雙親基底合成順序與完整抽樣細式在原始對話未齊，不得擅定父母均值為既定原契約**。

#### B. 更正與候選方案分帳（`C2-LUK` 診斷）
- 上述連代序列與單親/合成基底公式 $0.7 \times \text{base} + 15 + \Delta$ 相容，但**不能唯一證明雙親算術平均、所有邊界與取整規則**。
- 前版 C2 所寫的 $\lfloor(\text{LUK}_{\text{fa}}+\text{LUK}_{\text{mo}})/2\rfloor + \mathcal{N}(0,5)$ 缺少向 50 回歸，若 $\Delta=+10$ 將產生 $70 \rightarrow 80 \rightarrow 90 \rightarrow 100$，與 `R5F-B02` 連代序列衝突。
- **候選方案對照（待決）**：
  - **候選方案 A（優先推薦候選：對齊 `R5F-B02` 連代回歸結構之新候選擴充，撤回未定義常態抽樣）**：
    1. 雙親基底合成候選：$\text{base} = (\text{LUK}_{\text{fa}} + \text{LUK}_{\text{mo}}) / 2$（保留精確有理數 `Fraction` 或整數分子分母，不在中間步提前 `floor`；此為本次補出之候選設計，非舊序列已證明之唯一答案）。
    2. 向 50 回歸與離散擾動：
       $$\text{raw} = 0.7 \times \text{base} + 0.3 \times 50 + \Delta_{\text{disc}} = 0.7 \times \text{base} + 15 + \Delta_{\text{disc}}, \quad \Delta_{\text{disc}} \in \{-10 (25\%), 0 (50\%), +10 (25\%)\}$$
    3. 最終取整與夾限：$\text{childLUK} = \text{clamp}(\text{round\_half\_even}(\text{raw}), 0, 100)$。
    4. **整數權重抽樣與跨平台回放規格要求**：推薦固定 `rngVersion`，對命名流 `birth.childLUK` 產生均勻整數 $u \in \{0, 1, 2, 3\}$（`0 -> -10`、`1, 2 -> 0`、`3 -> +10`），並明定如何從 PRNG 位元取得該整數、抽取索引及交易重放規則。
    5. **Legacy 與未知親本邊界**：legacy `LUK=100` 本人保留 `100` 不回抽，其子代按新生兒 profile 計算；未知親本資料須先補來源或走明定的 legacy 分支，**嚴禁偷偷預設補 50**。

### 1.3 `B-GAP-05` 與 `DEC-R4-03`（對應 Q09）：近親距離、遺傳多樣性 $D$、多代近親負荷 $h$ 與當胎風險

#### A. 已核事實（`R5F-B04` §3.1 ~ §3.5 基線）
1. **概念嚴格分帳**：`R5F-B04` 明確區分四個不同變數與層次，不可混為單一距離參數（**嚴禁再將 $D$ 用作「第幾代共祖」**）：
   - **配對合法性與共同祖先距離 $(d_F, d_M)$**：按唯一 `personUID` 計算，保留全部路徑並取規定之最短距離（本人為 0，父母為 1，祖父母為 2，曾祖父母為 3）。
   - **遺傳多樣性 $D \in [0, 20]$**：進入出生主公式 $B = 0.25A + H + D + K$ 的多樣性加分項。
   - **多代近親負荷 $h \in [0, 3]$**：跨代累積與衰減的負荷狀態（對應 `DEC-R4-03`）。
   - **當胎近親缺陷風險 `risk`**：出生時觸發負面健康/體質結果的檢定機率。
2. **已核禁親底線**：
   - 先拒絕自配、直系血親、同父或同母手足。
   - R4 見證案例另拒絕共同祖先任一側距離 $\le 1$ 的叔姪／姑姪／舅甥等關係（如 $\min(d_F, d_M) \le 1$），但**不可只拿 $\min(d_F, d_M) \le 1$ 一條判式冒充整份婚配資格契約**，同 profile 完整禁親表仍屬 `B-GAP-05` 待補範圍。
   - **未知祖位與 Founder 守則**：「來源未知（`unknown`）」不得被當成乾淨外婚或 $h = 0$；開局 founder 應靠正式來源政策解決，不可憑空補造假祖先，亦不可因嚴格完整度讓合法開局人物永久無法配對。

#### B. 更正與優先推薦模擬候選（不可直接整組升格為已採健康政策）
- **多樣性 $D \in [0, 20]$ 候選算例**：無共祖 $D=20$；普通表親（單一組 $(2,2)$）扣 10 分得 $D=10$；雙重表親（兩組獨立 $(2,2)$）扣 20 分得 $D=0$；其他距離不擅猜。
- **多代負荷 $h \in [0, 3]$ 推薦候選（「新生一代才變」，等十年時間流逝不洗掉 $h$）**：
  - 內婚取 $\min(3, \max(h_{\text{fa}}, h_{\text{mo}}) + 1)$；完整外婚取 $\max(0, \max(h_{\text{fa}}, h_{\text{mo}}) - 1)$（此外婚恢復為推薦候選，非既定舊規定）。
- **當胎風險 `risk` 與健康後果推薦候選**：
  - 優先模擬已有來源之內婚 $h=1 / 2 / \ge 3$ 對應 **`12% / 20% / 30%`**（不混入另一套 `3% / 12%` 與 `-15 點 / -20%` 混合規則）；完整外婚之當胎額外親緣風險須另有明值（不得把未決的 `null` 當 `0`）。
  - 健康後果第一版推薦只選**一套有明確單位、有限下限的單一政策**，在缺乏完整生涯模擬前不同時扣體力上限與壽命。

### 1.4 `B-GAP-06` 與 `DEC-R4-01`（對應 Q10）：世交契合度 $K$

#### A. 已核事實（`R5F-B05` 基線）
- `R5F-B05` 保全 `family pair`（兩大家族配對）與**全 cohort 口徑**（合格後代數 $n$、有合格後代之不同世代數 $g$），主公式上限為 $K \in [0, 15]$。
- 世代窗口、合格後代定義、評估日與額外收益作用面，在 `R5F-B05` 與 `模組08` 均屬 **`DEC-R4-01` 待採範圍**。

#### B. 優先推薦候選（以 `Q06` 為第一個完整可比較候選，不採舊收縮案或連姻代數替代全 cohort）
1. **推薦候選核心公式（`Q06` 信心 × 表現模型）**：
   $$c = \min\left(1, \frac{n}{4}\right), \quad p = \frac{g + 1}{n + 2}, \quad \text{effect} = c \times p \times \text{base}$$
   - **樣本視窗與入帳候選**：保留所有出生帳，計分視窗推薦先用**最近 8 名已到期樣本**（按評估季度與固定 `personUID` 排序，不挑成績；未到期 `pending` 不算失敗，死亡者照原政策於原到期日入帳）。
2. **第一版收益收斂推薦候選**：
   - 第一版推薦**只做婚約基礎聘禮折扣，候選 $\text{base}$ 上限 `20%`**（暫不進入 $P$、$\text{LUK}$、$C$、太傅效率或 $\text{EP}$）：
     - `n=2, g=2`：係數 $c \times p = 0.5 \times 0.75 = 0.375 \Rightarrow$ 折扣 **`7.5%`**。
     - `n=4, g=4`：係數 $1.0 \times (5/6) \approx 0.8333 \Rightarrow$ 折扣約 **`16.67%`**（4 名全合格樣本即可接近有感效果，無須如舊案至少 16 名樣本）。
     - `n=8, g=6`：係數 $1.0 \times (7/10) = 0.70 \Rightarrow$ 折扣 **`14.0%`**。
   - **UI 與映射約束**：UI 不得把「樣本信心滿 ($c=1$)」寫成「收益滿」；$c \times p$ 與傳統 20 分／15 分制 $K$ 顯示及舊門檻需另訂明確映射，不可直接混充。
   - **必補可玩契約**：同版合格 catalog（應為可達成之遊戲任務／成長，不以稀有度或五星當後代好壞）、固定評估年齡（如 `18 歲` 候選，須先核 36 回合與世界時間映射是否已在該齡完成）、死亡原因處理、同季順序、基礎價格與折扣取整規則。

### 2.1 `G-GAP-04`（對應 Q05）：休息回復量與 36 回合訓練次數基線對照（`C2-REST` 診斷）

#### A. 已核事實（明示假設下的 DP 數學上界與期望成功訓練數分析）
1. **純精力上界（無失敗、無外部補給、初始／上限 $100$、訓練 $-20$、36 回合）**：
   - **基線（`R5F-G01` §5.3：休息回復 $+50$）**：最多可完成 **`27T + 9R`**（供給 $100 + 9 \times 50 = 550 \ge 540$）。
   - **前版 C2（休息回復 $+35$）**：`27T + 9R` 供給僅 $415 < 540$；最多僅能完成 **`24T + 12R`**。
2. **計入 `R5F-G01` 失敗率（`5% / 20%`）之期望成功訓練數新分析**：
   - 在無其他補給、加成或事件、僅最大化期望成功訓練數之純精力模型下，獨立重算結果為：**休息 `+50` 約 `25.5` 次成功訓練**，而**休息 `+35` 降至約 `22.8` 次成功訓練**（此為純精力模型分析，說明不能只改休息一格而維持原成果期望）。

#### B. 優先推薦候選
- **推薦維持 `R5F-G01` 基線（休息 `+50`、`cap 100`）**：精力 `< 20` 為當回合訓練前置拒絕條件，**不新增休息後仍持續的隱形「力竭」狀態**。`27T9R` 為明示資源假設下之次數上界而非強制排程，自動／半自動策略應逐回合檢查當前精力與目標。

## 1. 出生與血統遺傳數據表（B-GAP）

### 1.1 B-GAP-02: 幼兒幸運值 childLUK 與成長型 peakType 抽樣表
- **childLUK（幼兒隱藏幸運值）**：
  $$\text{childLUK} = \text{clamp}\left(\left\lfloor \frac{\text{LUK}_{\text{fa}} + \text{LUK}_{\text{mo}}}{2} \right\rfloor + \Delta_{\text{RNG}}, 0, 100\right)$$
  其中 $\Delta_{\text{RNG}} \sim \mathcal{N}(0, 5)$，且由獨立子嗣命名亂數種子生成。
- **peakType（能力成長巔峰型）**：
  依據雙親型態決定加權分佈：
  | 雙親組合 | 早熟型 (18~28歲) | 均衡型 (22~38歲) | 晚成型 (28~50歲) |
  | :--- | :---: | :---: | :---: |
  | 至少一方為早熟 | 60% | 30% | 10% |
  | 雙親皆為均衡 | 20% | 60% | 20% |
  | 至少一方為晚成 | 10% | 30% | 60% |

### 1.2 B-GAP-05: 28 祖位近親共祖深度與缺陷懲罰表
- **共祖深度 $D$ 判定**：掃描 28 真祖位重疊之最近代數：
  | 重疊深度 $D$ | 遺傳學對應 | 缺陷觸發機率 | 懲罰後果（收斂封閉） |
  | :--- | :--- | :---: | :--- |
  | **$D = 1$** | 一代直系 (父女/母子) | **100% 絕對禁止** | 系統阻擋聯姻，不可提交 |
  | **$D = 2$** | 二代兄妹/姐弟 | **100% 絕對禁止** | 系統阻擋聯姻，不可提交 |
  | **$D = 3$** | 三代表親 (外戚表兄妹) | 12% 檢定 | 觸發「先天體弱」：體力上限 $-15$，壽命 $-3$ 歲 |

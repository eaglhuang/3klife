## 1. 出生與血統遺傳數據與候選分帳（對應 Q03、Q04、Q09、Q10）

### 1.1 `B-GAP-02`（對應 Q03）：幼兒幸運值 `childLUK`

#### A. 已核事實（`R5F-B02` §3.5 基線）
- `childLUK` 定義於 $[0, 100]$ 整數域，採**向 50 回歸 30%**、**離散擾動 $\Delta \in \{-10, 0, +10\}$（機率 `25% / 50% / 25%`）**，最後一次做 **`round-half-even`**。
- 歷史連代最大擾動序列（合法基底為 `70` 時）：
  $$70 \rightarrow 74 \rightarrow 77 \rightarrow 79 \rightarrow 80 \rightarrow 81 \rightarrow 82$$
- `R5F-B02` 同段明確記載：**雙親基底合成順序與完整抽樣細式在原始對話未齊，不得擅定父母均值為既定原契約**。

#### B. 更正與候選方案分帳（`C2-LUK` 診斷）
- 上述連代序列與單親/合成基底公式 $0.7 \times \text{base} + 15 + \Delta$ 相容，但**不能唯一證明雙親算術平均、所有邊界與取整規則**。
- 前版 C2 所寫的 $\lfloor(\text{LUK}_{\text{fa}}+\text{LUK}_{\text{mo}})/2\rfloor + \mathcal{N}(0,5)$ 缺少向 50 回歸，若 $\Delta=+10$ 將產生 $70 \rightarrow 80 \rightarrow 90 \rightarrow 100$，與 `R5F-B02` 連代序列衝突。
- **候選方案對照（待決）**：
  - **候選方案 A（對齊 `R5F-B02` 連代回歸結構之新候選擴充）**：
    1. 雙親基底合成候選：$\text{base} = (\text{LUK}_{\text{fa}} + \text{LUK}_{\text{mo}}) / 2$（保留精確有理數 `Fraction` 或整數分子分母，不在中間步提前 `floor`）。
    2. 向 50 回歸與離散擾動：
       $$\text{raw} = 0.7 \times \text{base} + 0.3 \times 50 + \Delta_{\text{disc}} = 0.7 \times \text{base} + 15 + \Delta_{\text{disc}}, \quad \Delta_{\text{disc}} \in \{-10 (25\%), 0 (50\%), +10 (25\%)\}$$
    3. 最終取整與夾限：$\text{childLUK} = \text{clamp}(\text{round\_half\_even}(\text{raw}), 0, 100)$。
    4. **跨平台回放尚需補齊之規格**：即使使用 `Fraction` 避免浮點誤差，跨平台 deterministic replay 仍須固定 `rngVersion`、命名流（named stream）、位元/整數抽樣算法與測試見證（witness）。
  - **候選方案 B（前版 C2 常態擾動候選）**：
    - 以雙親均值加常態分佈擾動且不向 50 回歸。若改採此案，必須廢棄 `R5F-B02` 的 `74/77/79/80/81/82` 驗收測試並另立新 profile。

### 1.3 `B-GAP-05` 與 `DEC-R4-03`（對應 Q09）：近親距離、遺傳多樣性 $D$、多代近親負荷 $h$ 與當胎風險

#### A. 已核事實（`R5F-B04` §3.1 ~ §3.5 基線）
1. **概念嚴格分帳**：`R5F-B04` 明確區分四個不同變數與層次，不可混為單一距離參數：
   - **共同祖先距離 $(d_F, d_M)$**：父系與母系各自到共同祖先的世代步數（本人為 0，父母為 1，祖父母為 2，曾祖父母為 3）。
   - **遺傳多樣性 $D \in [0, 20]$**：進入出生主公式 $B = 0.25A + H + D + K$ 的多樣性加分項。
   - **多代近親負荷 $h \in [0, 3]$**：跨代累積與衰減的負荷狀態（對應 `DEC-R4-03`）。
   - **當胎近親缺陷風險 `risk`**：出生時觸發負面健康/體質結果的檢定機率。
2. **已核禁親底線**：
   - 先拒絕自配、直系血親、同父或同母手足。
   - R4 見證案例另拒絕共同祖先任一側距離 $\le 1$ 的叔姪／姑姪／舅甥等關係（如 $\min(d_F, d_M) \le 1$），但**同 profile 完整禁親表仍屬 `B-GAP-05` 待補範圍**。
   - **未知祖位守則**：「來源未知（`unknown`）」不得被當成合法遠親，亦不得直接當成 $h = 0$。

#### B. 更正與候選方案分帳（不可直接整組升格為已採健康政策）
- 前版 `doc_spec_0289` 用 $D = 1..5$ 代表世代深度，與 `R5F-B04` 主公式中的遺傳多樣性分數 $D \in [0, 20]$ 發生**符號撞名**。
- `R5F-B04` 內所列的以下數值均明確標示為 **`DEC-R4-03` 候選算例**，尚未升格為已採定的正式健康政策：
  - **多樣性 $D \in [0, 20]$ 候選扣分算例**：無共祖 $D=20$；普通表親（單一組 $(2,2)$）扣 10 分得 $D=10$；雙重表親（兩組獨立 $(2,2)$）扣 20 分得 $D=0$。
  - **多代負荷 $h \in [0, 3]$ 候選遞迴式**：$h_{\text{child}} = \text{clamp}(\max(h_{\text{fa}}, h_{\text{mo}}) + I_{\text{inbred}} - O_{\text{outbred}}, 0, 3)$。
  - **當胎風險 `risk` 候選階梯**：依 $h_{\text{child}} \in \{1, 2, 3\}$ 對應 `12% / 20% / 30%`（或依具體缺陷表分流）。

### 1.4 `B-GAP-06` 與 `DEC-R4-01`（對應 Q10）：世交契合度 $K$

#### A. 已核事實（`R5F-B05` 基線）
- `R5F-B05` 保全 `family pair`（兩大家族配對）與**全 cohort 口徑**（合格後代數 $n$、有合格後代之不同世代數 $g$），主公式上限為 $K \in [0, 15]$。
- `R5F-B05` 列出的比較候選包含：
  - **R4 舊收縮案**：$\min(15, 3n + 3g)$
  - **Q06 案**：$\min(15, 2n + 3g)$
  - **G3 案**：$\min(15, 5g)$
- 世代窗口、合格後代定義、評估日（成婚日 vs 出生日）與額外收益作用面，在 `R5F-B05` 與 `模組08` 均屬 **`DEC-R4-01` 待採範圍**。

#### B. 更正與候選分帳
- 前版 `doc_spec_0289` 寫入「變異度 $\sigma$ 下修 10%」與「入學初始實現度 $+0.03$」，與 `R5F-B02`（固定 $\sigma=6$）及 `R5F-G01`（入學 $C=0/1$）衝突，已在本次更正中移除。
- 至於將 $K$ 的額外收益限制於「聘禮減免最高 50% 與聯姻名望獎勵」，屬於**新增的候選收斂提案**，並非 `R5F-B05` 既定邊界；且移除 $C_0/\sigma$ 後，$K$ 的主公式選型（R4 / Q06 / G3）、評估窗口與合格定義仍待使用者就 `DEC-R4-01` 正式拍板。

### 2.1 `G-GAP-04`（對應 Q05）：休息回復量與 36 回合訓練次數基線對照（`C2-REST` 診斷）

#### A. 已核事實（明示假設下的 DP 數學上界）
在固定初始精力 $100$、上限 $100$、每次訓練消耗 $-20$、共 $36$ 回合、且**無其他外部補給／季節倍率／事件回復**的明示假設下：
- **基線（`R5F-G01` §5.3：休息回復 $+50$）**：
  - 36 回合內最多可完成 **27 次訓練 + 9 次休息（`27T + 9R`）**（合法次序見證如先連續訓練再穿插休息，總供給 $100 + 9 \times 50 = 550 \ge 27 \times 20 = 540$）。
- **前版 C2 變更（休息回復 $+35$）**：
  - 若採 `27T + 9R`，精力總供給上界僅 $100 + 9 \times 35 = 415 < 540$（缺口 $125$ 點），不可能達成 27 訓。
  - 在 $+35$ 下，36 回合最多僅能完成 **24 次訓練 + 12 次休息（`24T + 12R`）**。

#### B. 更正與候選分帳
- 上述比較屬於**「公式與路線基線改變（`CHANGED_FORMULA_WITH_SCHEDULE_IMPACT`）」**：不能把 DP 算法上界直接當成已納入所有季節倍率、補給與真實 caller 的最終遊戲平衡結果；在未確認作者意圖前，亦不直接武斷判定 `+35` 只是筆誤。
- **待決選項**：
  - **候選 A（維持 `R5F-G01` 基線）**：休息回復 `+50`，保留 `27T + 9R` 訓練預算基線。
  - **候選 B（改採 `+35` 並重算全套培育基準）**：休息回復 `+35`，同步將標準最大訓練回數下修為 `24T + 12R`，並重算實現度目標與關聯測試。

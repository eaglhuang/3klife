## 1. 體系概覽與設計哲學

本體系徹底終結千篇一律的「36 回合五維訓練點擊作業」，將三國天下名門學府轉化為具備**獨立小遊戲玩法循環（Core Gimmick）**的「賽季輪替劇本」：

1. **學府多樣化（Scenarios with Distinct Gimmicks）**：
   - 每個學府不只是屬性權重不同，而是擁有完全相異的決策小遊戲（如潁川的策論牌組連鎖、幽州的沙盤巡哨與煞氣突破、江東的水文天時與陣型推演、太學的經學注疏與公卿評第、隆中的八陣生剋與機巧部件）。
2. **生子機會稀缺與入學高戰略重量（High Stakes, High Value）**：
   - 夫妻每代平均僅誕生 2~4 名嫡系子嗣，每一次入學修業均為全家族傾力栽培的大事件，給予玩家如同開一局賽馬娘養成的高專注與高期待感。
3. **鐵律：防 SL 確定性狀態機（Anti-SL Ironclad Protocol）**：
   - 入學即生成專屬確定性 PRNG 種子鏈，重啟應用隨機結果完全重播；
   - 玩家點選決策「操作即落盤（WAL Checkpoint）」，落盤成功後才播放動畫，徹底封死 SL 洗結果。
4. **數值收斂防膨脹（Non-Power-Creep Guarantee）**：
   - 所有學府畢業生五維能力總量硬鎖在 $[0, 2000]$ 能力點（Talent 0~100，單項上限 500）。
   - 終生特性槽位硬鎖 3 戰法 + 2 門風特質，絕無跨學府洗澡刷滿神技的無底洞。

## 3. 賽季輪替週期表（Season Rotation Cycle）

遊戲世界時間每 3 年（12 季度，共 36 旬）輪替一次當期推薦學府：

```
[第 1~3 年：潁川書院季] ──> [第 4~6 年：幽州突騎營季] ──> [第 7~9 年：江東橫江督府季]
       │                                                                │
       └──────────────────< [第 13~15 年：隆中工造季] <── [第 10~12 年：洛陽太學季]
```

- **當期推薦學府特權**：
  - 家族免除引薦信要求，學費（束脩）減免 $30\%$。
  - 享有當季限定「客座名師巡講」專屬隨機事件（大幅提高彩圈出現率）。
- **非當期學府自費入學**：
  - 玩家家族需消耗「宗族功業點數 100 點」或使用朝廷大臣／外戚世交專屬舉薦信方可自費報名。

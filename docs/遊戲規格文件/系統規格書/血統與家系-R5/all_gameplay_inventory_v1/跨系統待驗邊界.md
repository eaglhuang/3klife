# 跨系統待驗邊界

固定版本：96a83124094d3b2485bfb749ef37d567ad834559。以下14條全部NOT_RUN。測試名稱只是定位候選，未確認其內部是否真正驗到此行為。

## 優先跨系統驗收案例

以下都是待設計/待跑案例，不是目前缺陷結論。

1. **抽卡交易重進。** 同一抽取雙擊、回應 pending、取消動畫或讀檔後，貨幣、保底、抽取記錄、名冊、重複轉數、教官溢出/結義點/灌注不得各自提交一半或重複入帳。測試定位：GachaAsyncWindowE2E、GachaPullToRosterE2E、GachaPityStorage、GachaSyncRecordFlow。
2. **出生跨資產。** 女性來源及資格→結緣配額/道具→同一出生事件→person 身份/雙親關係/因子/傳家寶/圖鑑；讀檔或重試不能再出生、改 seed 或洩漏尚未揭露的因子。定位：FemaleBreedingWire、BreedingBirthRecordSave、GearHeirRealBreedingE2E、HiddenFactorFlowE2E。
3. **角色占用競爭。** 派遣中、治理中、試用結束、被俘、退役或死亡角色同時嘗試出征/換主將/結緣；所有入口要尊重同一可用狀態，舊 UI 快照不能繞過。定位：RosterRoleLoad、DispatchInactiveGeneralE2E、GovernanceSessionFlowE2E、MercenaryDeparture。
4. **戰場效果到勝敗。** 控制變陣營＋復活、推移到危險格、隱身選目標、天候限制、持續傷害到期，必須穿過真實回合管線，正確計算殲滅/撤退與戰果。定位：UltControlReviveCrossFlow、StatusKindsE2E、StrengthPushHazard、StealthTargeting、WeatherTacticRestriction。
5. **戰果只結算一次。** 勝敗 callback、結果視窗重開、退出/重載→戰績、官職軍功、生命消耗、戰傷、虎符/俘虜/戰利品、關卡解鎖與季度排行應一致去重；不得因展示重播發獎。
6. **俘虜回歸。** 被俘/釋放/救援/復仇回收→原人物身份、所屬、出戰資格、虎符與寶物；牢位擴張和領地級別改動後也保一致。定位：PrisonerReturnSaveChainE2E、PrisonerTallyFlow、PrisonTreasureFlowE2E、RevengeRecoverSaveChainE2E。
7. **季末跨時鐘順序。** 同一步同時發生試用到期、供養不足、派遣結算、官職晉升、內政收益、年齡死亡、他國擴張、道具到期。檢查是否會「先死亡卻後出征/生產」、連跳季漏算/重算。14日賽季與月活動另以各自 clock 驗證，不拿四季結果替代。
8. **傭兵轉永久。** 最後一個試用日的結義、供養、出戰、離別以及讀檔衝突；永久 flag、名冊、戰績與告別信不能同時成立。定位：MercenaryOathWiring、MercenaryBattleSaveChainE2E、MercenarySaveWire。
9. **退役/死亡與傳承競爭。** 同一人物達壽命終點又選退役/復育時，虎符、英靈、精華、後代及歷史快照僅由合法路徑結算一次，舊身份不悄悄復活。
10. **物品與資源上限。** 使用長壽丹、精力丹、天候物、刷新物、轉職令，在無效目標/已達上限/容量不足時，是否扣物、改狀態、耗時間及產生日誌應遵守同一契約。需覆蓋舊檔缺欄位及倉庫滿。
11. **派遣→官職→權限→領地。** 任務成敗與難度映射、軍事/內政/遠征牆、一次跨多官階、同一次晉升獎勵、已解鎖權限及讀檔。不能只驗證獎勵計算表。
12. **結局、世界更替與家族延續。** 現有 Era 行為與 R5 主題季/首次統一/祖地保持分帳；有正式規則及 caller 才驗證存續/清盤/結局重播/首通獎勵，不自行用候選規格補新參數。
13. **手動/自動路徑等價。** 自動育成、委任治理、戰鬥自動結算與手動流程，核對消耗、RNG、時間、事件及保存差異；helper 結果相同不保證 orchestration 等價。
14. **公開資訊界線。** 預言、戰力預測、血統圖、歷代比較、結局或日誌只使用當時已知投影，不因隱藏屬性參與內部計算而全部展示。重載後已知進度不可倒退或憑空揭露。

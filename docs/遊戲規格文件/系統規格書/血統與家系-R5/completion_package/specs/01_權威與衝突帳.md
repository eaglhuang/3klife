## 3 衝突類型與處理

- EXPLICIT_RULING：已有同主題明示覆寫，可同步當前敘述；仍保歷史段。
- HISTORY_ANNOTATION：歷史決策或實作紀錄本身保留，只補適用版與後續引用。
- PROFILE_MAPPING：版本差異須建立使用範圍，不等產品bug。
- INTERNAL_CONFLICT：同文／同版互不相容，需來源選版，不猜公式。
- INTERFACE_GAP：各系統分別有規格，但缺共同身份／事件／權限接法。
- SOURCE_MISSING：原始契約或catalog未讀／缺失，批准不能代替來源。
- INDEX_DEFECT／STALE_GENERATED_COPY：引用或衍生索引錯，不另開玩法DEC。
- EVIDENCE_CLASSIFICATION：作者記載、靜態核查、實跑分層，不重新包裝PASS。

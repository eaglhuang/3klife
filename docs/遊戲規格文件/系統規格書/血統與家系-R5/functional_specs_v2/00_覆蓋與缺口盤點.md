# R4／R5 文件覆蓋與功能粒度盤點 v2

狀態：文件盤點階段。先補齊文件責任與衝突映射，再凍結功能清單，再產生獨立功能規格；尚未開始產品程式。

## 已有基線

前版15檔完整保留R4玩法17頁、工程43頁與R5七主題、決策及來源附錄。20個R5F功能及40條NOT_RUN測例已存在，但同一入口有多種狀態責任，不能把它們直接視作每功能可實作規格已齊。

19項DEC保持未採定：DEC-R4-01～09與DEC-R5-S01～10。本文不以外部規格的『定案』關閉DEC。

## 文件缺口的補法

每份獨立規格都要列：目的／非目標、同版來源章節、依賴能力／相關DEC、輸入輸出、欄位型別／unknown與0、狀態與事件、正常流程、失敗／邊界、儲存與遷移、重入、UI及GWT。不得把通用模板填滿視為具體設計完成。

可直接引用包內R4全文的精確表格，須列章節／頁碼且清楚保留原profile；只有已定基線可作回歸，不填未定R4/R5參數。每個產品consumer在本次未重核，接口均標擬接責任，不猜檔路徑。

原40條GWT須保留並對應承接功能；新增拆分需新增有條件正反例，全部NOT_RUN。R3T01–74、R4E01–32、M01–23仍是歷史案例／見證，不被新GWT取代，不把歷史PASS改成本次實跑。

## 已知衝突仍須隔離

P能力點／BodyTicks、H非健康、m非星數、14/28/30祖位、256十進位數字非256bit、入池概率非H深度權重、auto .5僅教官額外TP、K候選公式不混用、EP總分項未定、跨季時鐘不等季度／真代數、已知不藏回、死者不復活、roster／carry不默選。新功能不得再定義一套相反契約。

## 獨審修訂

- G04只負責童年自然／creditedGain；媒介不增A，另列B09，限制每子與來源次數。
- G06改為既有HP／休養／壽命／死亡；新G08負責職務年齡投影，只後者受DEC05。
- B10補世界季度NPC配對，不以S06跨季新族供給替代。
- B02明列出生LUK／peakType流；B07補終身新取得2個及四態；B08補兩次功業機會、首次成功停、有效+1。
- E03建立／封存首次統一快照，E01只讀，E02另處理獎勵，消除只有讀者沒有生成者的缺口。
- 原20功能ID均保留，標題調整與新增責任均有原入口對照，不增加正式工單或產品執行。

## 首階段審結

38功能與52列來源矩陣之本來源範圍清單完整性通過。原40條案例保留映射，歷史74/32/23案例逐條核驗仍待後續；每功能獨立規格尚未完成，產品程式未開始。

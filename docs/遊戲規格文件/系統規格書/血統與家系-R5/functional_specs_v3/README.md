## 整合接口裁定（規格層，不冒稱現行程式）

1. C01只驗型；C02解析時鐘；C04提供命名亂數；C03提供提交；C05管理遷移／閉包。此責任分工不可讓兩個owner各自扣同一筆成本。
2. B06擁有婚約／出生交易，B02/B03/B04提供計算候選，不能預覽就先產生另一份出生結果。
3. S04依已鎖規則產生有效勝利／成就資格。E03凍結成果，E01唯讀展示，S05保存積分，E02只結算獎勵，S03協調換季並查既有收據。
4. worldQuarterIndex／歷史worldSeason是季度；campaignSeasonId是主題季。換ID本身不推進年齡、不增真世代、不重抽P。DEC-R5-S04仍須決定是否以及如何跳時。
5. B10季度配對與S06跨季族群供給不同。familyUID與factionUID不同；敵我人物與婚姻、同一childUID跨季均保留。死者歷史保留不等復活。
6. G07社交R、B05相性K、B02出生EP三帳分離。缺總EP公式不能把R或K自行加回。
7. 每份僅引入實際消費能力所需決策；E01既有公開投影不等DEC07新教學政策已決，G06既有HP契約不依DEC05新增職務曲線。

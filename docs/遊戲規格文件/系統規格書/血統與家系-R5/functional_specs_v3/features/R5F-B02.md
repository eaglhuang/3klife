# R5F-B02 出生 H EP LUK 與巔峰型生成

本規格定義先天候選算法、命名亂數及出生日凍結內容。R5F-B02 是文件索引，不是正式 ATM 工單。全部工作文件與逐功能規格完成前不開始程式；DEC、真 consumer 與正常准入未核，implementationReady=false。

## 目的與非目標

以已核真祖源及完整 profile 計算 H、出生 bonus、Talent、P/B、LUK 與 peakType，一胎同來源只能得到同一結果。算法候選與正式出生交易分開，本功能不扣婚約成本、不管理四季孕期、不生成裝備或培育進度。生日、換季、成材演出、父母升星均不能再抽本人 P。

## 明確數值與單位

以下保留 R4 同 profile 基線，不把試作映射宣稱為永久不能改的產品常數。

- Talent 0..100；P=20×Talent，範圍 0..2000 **能力點**。1 能力點=10000 ticks，故 P 上限 20000000 BodyTicks。B=.15P；自然十五歲 A0=.20P 屬 G04，不是本功能再抽 A。
- 十藍 ID：B_STR_BODY/B_STR_ART；B_INT_INSIGHT/B_INT_LEARN；B_LEA_COMMAND/B_LEA_ORDER；B_POL_GOV/B_POL_SUPPLY；B_CHA_SPEECH/B_CHA_TRUST。各 Max5，各只對對應一維 relevance=1，其餘0。
- 每 ID 取 m=max(level/5×depthWeight×relevance)，父母／祖父母／曾祖父母權重1/.5/.25。每維不同 ID 的 m 排 m1≥m2；H=25+40m1+20m2，25..85。m 是0..1，不能寫成1..5星。
- 無來源 H25、父母單三星 H49、單五星 H65、雙三星 H61、雙五星 H85、祖輩單五星 H45。只可對已核完整而無該 ID 的清單取0；unknown 不取0。
- T=min(100,H+bonus)。中間全用精確 Fraction，出生日最後 round-half-even 到 ticks，不以 float 或 UI ppm 回灌。

| E 錨點 | bonus 0/5/10/15 機率 | mean bonus |
| --- | --- | --- |
| 0 | .80/.18/.02/0 | 1.10 |
| 25 | .65/.27/.08/0 | 2.15 |
| 50 | .50/.30/.18/.02 | 3.60 |
| 75 | .35/.30/.25/.10 | 5.50 |
| 95 | .20/.25/.35/.20 | 7.75 |

給定 E∈[0,100]，相鄰 a,b 間 w=(E−a)/(b−a)，混合四點機率後抽一次；95..100 固定末列。不得先各抽兩個錨點再平均。R3 分檔不連續測例 T04/T52/T53 屬待替換歷史，不能混入新插值。

LUK 基線：founder30/40/50/60/70 等機率；子代向50回歸30%，擾動−10/0/+10 機率25%/50%/25%，最後一次 half-even，保 legacy100。原冊未在本包完整列雙親基底合成運算順序及 peakType 機率表；正式生成需補同版來源，不擅定「父母均值」或三型等機率。給定合法基底70且連代最大擾動的歷史對照為74/77/79/80/81/82後停82。peakType 出生固定，只供畢業後外部投影，不影響學院成長。

## 流程與命名流

1. 驗來源閉包、十藍字典、精確分數與完整必要 profile；先完成 B04 可採政策的合法性檢查。
2. 依真來源先算每 ID 最佳 m；若同版政策允許純化，先對合法指定 ID 的 m 結算純化並套 cap1，再把該維兩個不同 ID 的最終 m 重新排序為 m1≥m2，最後才計 H=25+40m1+20m2。不得先算 H 後只改 m 卻漏重算，也不得沿用純化前的排序。純化不改 star kernel；未採 DEC-R4-03 不猜成功率。
3. 依 B08 提供的完整 EP 成分計 E；社交 R 退出後缺總成分即停止，不回填舊五分項。
4. H 確定後，依完整 E 分布用各維獨立 potential.STR/INT/LEA/POL/CHA 抽 bonus，再計 T=min(100,H+bonus) 與 P/B；整體順序是 m來源→合法純化與cap→重新排序m1/m2→H→bonus。LUK 用 childLUK，巔峰型用 peakType。purification／health 流獨立，不因某維幸運而全維一起最高。
5. 以固定 rngVersion 的無偏位元／整數拒絕抽樣處理 Fraction，U∈[0,1)、U<p；完成後一次投影 ticks，輸出 witness 交 B06 原子提交。

preview 不耗 RNG、不公布 seed；它呈分布或公開包絡，不提前固定一胎給玩家刷。來源與字典排序在抽樣前完成，加入無關展示欄位不改任何命名流。

## 錯誤 恢復 保存與 UI

EP越界、分數非法、未知 Max 或超位數回 VALIDATION_ERROR／PROFILE_UNSUPPORTED；跨單位回 UNIT_MISMATCH；缺來源回 SOURCE_INCOMPLETE。不可 clamp 壞 E；無效輸入不耗 RNG／回合／成本。B06 pending 先查原結果，不換 seed；同 birthEventId 的來源或 payload 改變回衝突。

保存 P/B/LUK/peakType、來源 revision、完整必要 witness 及 rngVersion，不只留 hash。遷移保 legacy 結果，未知 P 不設為 A，舊 LUK100 不降到新族群範圍，父母升星只影響新婚約。未知親本 LUK 時 UI 不輸出精確 E、機率權重或可反解 delta；已知者可看連續分布，不用「差一點升檔」。H 不能標健康任期。

### 共通重入順序

讀取既有提交紀錄先於新命令准入：同key與同payload已提交，或同businessEvent已有一致結果，先返回原結果，即使請求帶舊expectedRevision也不重新結算；同key異payload仍拒衝突。只有確定沒有既有提交的新操作才驗expectedRevision、資源與資格。唯讀功能不因此取得寫入權，pending先查commit marker，不換seed或key刷結果。

# R5F-B06 婚約孕期及出生交易

本規格將來源確認、四季孕期、出生一次提交及中斷恢復列為獨立責任，不再混在純數值算法。R5F-B06是文件功能索引，不是正式ATM工單。全部工作文件與逐功能規格完成前不得開始程式；DEC、真consumer及正式准入未核，implementationReady=false。

## 目的 非目標與 owner

讓玩家／NPC的合法婚約只鎖一次來源，一胎只建一位穩定childUID，孕期中父母能力、星數或陣營改變不重算本胎。owner為婚約／胎次交易協調者，C03負責耐久原子保存；B02/B03提供候選結果，不各自建立人物。實際產品接線與維護者待核。

不在確認婚約時暗生P，不把一次主題換季當四季過去，不因人口不足換母續生，不在失敗時自動選新seed或新配偶。新和親服務、軍隊資產或跨季地盤交易不屬此功能。

## 來源及基線

[R4 工程](../../publication_candidate/11_R4歷史基線_工程驗收.md) §4–7、§14、§16–17、R3T07–08/T32/T35/T68；[R4 玩法](../../publication_candidate/10_R4歷史基線_玩法.md) §3、§13、§15；[R5 模組01](../../publication_candidate/01_共同身份_時間與存檔契約.md) 時鐘與保存契約、[模組02](../../publication_candidate/02_出生_血統與聯姻.md) 出生管線、[模組06](../../publication_candidate/06_主題賽季與跨家族延續.md) 家族承接；[模組08](../../publication_candidate/08_決策_衝突與擴充邊界.md) DEC-R4-02／03／09、DEC-R5-S04；[模組09](../../publication_candidate/09_證據來源與驗收索引.md) R5S02/S05/S07/S13。

18歲成年婚配、懷孕4世界季度屬R4歷史基線；最早下一代出生間隔19年。當前完整R5profile未凍結，不能用G1的16歲或36季替換。費用、冷卻及取消退款未全文定值，必須有版本化政策，不能憑這份交易規格收費。

| confirmConception | parents、familyPair、sourceRevisionRefs、selectedSourceChoice、costPolicyRef、expectedRevision、businessEventId、idempotencyKey | 驗證後凍結來源與成本意圖，不能生成P |
| ConceptionSnapshot | conceptionId、parents、frozenFamilyPair、conceptionQuarter、dueQuarter、profileHash、EPComponents、choice、riskPaths、sourceDigest、sourceRefs | 正式確認後不可被父母新版本回灌 |

## 流程與交易不變量

1. 預覽：用公開資訊展示可知分布、禁親、風險、來源缺口及成本。無效資料不抽RNG或扣費。
2. 確認：在同一revision驗雙方成年／存活、有效婚姻與同意、禁親、孕期／冷卻／占用、來源完整度、唯一保留、資源與完整必要profile。不得因跨敵我勢力免除檢查。
3. 凍結：固定兩親sourceRevision、EP成分、familyPair、riskPaths與所選ID。費用何時扣／預留依已採政策，使用唯一ledger事件；不預生P或公示seed。
4. 推時：依C02的世界季度到期，不以學院turn或campaignSeasonId代替。重複處理同季不得多推孕期。
5. 出生：到期且母親未死亡時，讀凍結來源，由B02/B03與已採健康policy產生完整結果、childUID及witness。出生一次事實與來源引用綁同業務事件。
6. 原子提交：保存結果／成本意圖→驗核心引用→寫新槽→checksum通過→切pointer與commit marker。出生、家族雙方引用與B05cohort須同一完整提交或可恢復的同一事件，不允一方家族有孩子另一方沒有。
7. 成功回傳原結果；儲存結果不確定時RESULT_PENDING，先查commit marker，不退款後再抽。

母親死亡中止未出生胎並保存婚約來源／死亡事件，不能換母、復用seed或改原胎身份。父親死亡後是否仍出生、主動取消、流產、孕期占用與退款詳細政策未在本包明定，須取得正式來源；不能比照母親死亡自行擴大刪除。already born人物死亡不能退回pending。

## 跨季 重入與遷移

只切campaignSeasonId不改dueQuarter或人物年齡。若換季政策明示推進季度，須逐季處理出生／死亡／冷卻；DEC-R5-S04缺值時拒跨季提交，不免費完成孕期。玩家女兒嫁入敵家且生childUID，下一季兩家引用同一人物，不能依勢力複製新UID。

冪等需同鍵同payload返回原結果，同鍵異payload拒IDEMPOTENCY_CONFLICT；同conceptionId即使用新key亦不得二胎。expectedRevision不符回REVISION_CONFLICT，不能自動讀更新父母替換已凍結來源。保存sourceRevision與其引用實體，不只hash。

legacy人物保P/B/LUK與已知資料。legacy婚約若缺可映射來源，保持原profile／明示不可轉，不從父母目前A推P，不用新規則追扣。遷移在新snapshot驗閉包後才切換，失敗保舊槽或可恢復pending。

## 錯誤與 UI

SOURCE_INCOMPLETE顯示需查譜／來源補齊；PROFILE_UNSUPPORTED顯示待核政策；STATE_CONFLICT區分已懷孕／已出生／已中止；REVISION_CONFLICT要求讀新狀態；STORAGE_FAILURE不把未知結果說成功。錯誤訊息不含未知factorID、P、LUK或seed。

UI區分預覽、已確認來源、剩餘世界季度、待恢復、已出生／中止。成本、取消後果在確認前說明；不把未定費用顯0。再次點擊返回目前胎次狀態，不呈可刷結果的重新抽取。出生公告顯合法已知資訊，不一次揭露全部隱藏值。

### 共通重入順序

讀取既有提交紀錄先於新命令准入：同key與同payload已提交，或同businessEvent已有一致結果，先返回原結果，即使請求帶舊expectedRevision也不重新結算；同key異payload仍拒衝突。只有確定沒有既有提交的新操作才驗expectedRevision、資源與資格。唯讀功能不因此取得寫入權，pending先查commit marker，不換seed或key刷結果。

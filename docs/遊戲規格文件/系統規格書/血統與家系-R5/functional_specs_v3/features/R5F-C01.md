# R5F-C01 身份與單位契約｜獨立功能規格 v3（已審條件版）

## 狀態與範圍
文件內容狀態：CONTENT_REVIEWED_WITH_OPEN_DECISIONS。implementationReady：false。現行實作／consumer：NOT_VERIFIED；產品測試：NOT_RUN；產品驗收：NOT_ASSESSED。
R5F 僅文件功能 ID，非已登記 ATM 工單。全部範圍內工作文件、清單、獨立規格完成後，才能評估產品編碼；相關決策與正常施工准入另須滿足。以下擬議介面／狀態名稱不宣稱產品已存在。

## 1. 目的、責任與非目標
驗證人物／家族／政治勢力三種身份與數值單位，讓各領域只消費同版、可追溯的資料。驗證器不建立人物、不重算出生、不修補未知祖源。

## 2. 規範來源與優先關係
來源：R4工程§1–4；R5模組01。完整基線見 [R4 工程](../../publication_candidate/11_R4歷史基線_工程驗收.md) 與 [R4 玩法](../../publication_candidate/10_R4歷史基線_玩法.md)，R5 題目模組見 ../../publication_candidate/。本份細分原入口，不另計同一成果兩次。R5明示修正優先；原文標候選／legacy／待決者不因本份引用升格。歷史紙面驗算結果非本次產品PASS，可重跑歷史驗算附件未包含於原基線。

## 3. 輸入、輸出與資料契約
輸入：來源物件、要求的 schema/profile 版本、明示單位、引用可解析表。缺失、unknown、合法零必分開；不能把字串數字自動 parse 成合法能力值。

輸出：只有通過驗證的分型引用及規範值；或逐欄錯誤。任何失敗均不發布部分 normalized 人物。

擬議schema與型別：IdentityRef {kind: person|family|faction, uid}; ProfileRef {mechanicsProfile, dictionaryVersion, displayPaletteVersion, discoveryProfile}; StoredValue {unit: TalentTicks|BodyTicks, value: integer}; DisplayValue {unit: Talent|AbilityPoint, exactDecimalOrFraction}（點數可有小數，不能直接用integer限制）; Fraction {numerator: decimalString, denominator: decimalString}; ValidationResult {valid, normalizedRefs, errors}。上述外框是擬議介面；R4 欄位含義與限制為基線。

## 4. 正常流程及狀態邊界
1. 依 kind 驗 UID 引用，personUID 不因改名、婚姻、陣營或換季變更；familyUID 不當 factionUID 使用。
2. 確認所需 profile/dictionary 存在且完整；查詢某已定能力不必要求無關 DEC 值，執行待決計算則必須有該參數 revision。
3. 驗 Talent 0..100，每評分同樣以10000整數TalentTicks保存；顯示點數可有萬分之一精度，與BodyTicks必分型。計算用精確Fraction，出生凍結最後round-half-even到ticks；P20Talent 為 0..2000 能力點，每能力點 10000 BodyTicks，因此 P 上限 20000000 ticks。不要把 P1600 當 1600 ticks。
4. Fraction 分母>0、約分十進位字串；分子與分母各最多256十進位數字，零規範為0/1。超長拒絕，不用浮點壓回；其餘數值不收數字字串、NaN、Infinity。
5. 只有合法範圍才可套明定 cap；錯單位、未知、越界先拒絕，不能 clamp 成看似合法。

## 5. 失敗、取消與恢復
UNIT_MISMATCH：拒轉換及下游計算；SOURCE_INCOMPLETE：指出缺引用類型但不洩未知資料；PROFILE_UNSUPPORTED：不沿用R3或最近表值；VALIDATION_ERROR：不修猜值。錯誤碼沿R4；欄位外框為擬議。

## 6. 保存、遷移與可重入
純驗證無寫入 owner。由 C03 儲存已驗結果；C05 遷移另做 preview，不由此驗證器暗改 legacy。相同輸入及同版字典必回同結果。

## 7. UI／可見資訊
顯示單位與缺資料原因；未知為未知，合法0可顯0。展示層不能把錯誤訊息變成 hidden P/seed 探測器。

## 8. 依賴能力及待決閘門
無上游領域依賴；C03/C05/B/G/S 消費本功能，不反向觸發它們。

明列決策：無新增數值待決；仍須完成整組文件及正式實作前核查。
缺本次操作必要參數時回 PROFILE_UNSUPPORTED，不以0、R3舊值或較新G分冊衝突值補齊。已定只讀／不變量能力不自動繼承上游所有待決。任何仍需選定技術機制的schema屬實作設計提案，不冒稱使用者批准。

# R5F-C02 三時鐘與代數｜獨立功能規格 v3（已審條件版）

## 狀態與範圍
文件內容狀態：CONTENT_REVIEWED_WITH_OPEN_DECISIONS。implementationReady：false。現行實作／consumer：NOT_VERIFIED；產品測試：NOT_RUN；產品驗收：NOT_ASSESSED。
R5F 僅文件功能 ID，非已登記 ATM 工單。全部範圍內工作文件、清單、獨立規格完成後，才能評估產品編碼；相關決策與正常施工准入另須滿足。以下擬議介面／狀態名稱不宣稱產品已存在。

## 1. 目的、責任與非目標
統一世界季度、學院回合、主題賽季與家系親子代數的語義。只提供時間解析與已批准映射；不負責NPC配對或換季交易。

## 2. 規範來源與優先關係
來源：R4工程§14；R5模組01/06。完整基線見 [R4 工程](../../publication_candidate/11_R4歷史基線_工程驗收.md) 與 [R4 玩法](../../publication_candidate/10_R4歷史基線_玩法.md)，R5 題目模組見 ../../publication_candidate/。本份細分原入口，不另計同一成果兩次。R5明示修正優先；原文標候選／legacy／待決者不因本份引用升格。歷史紙面驗算結果非本次產品PASS，可重跑歷史驗算附件未包含於原基線。

## 3. 輸入、輸出與資料契約
輸入：具版本的世界時鐘、人物出生時點、訓練run狀態、真親子鏈；換季另須有生效timePolicy。

輸出：年齡／季度映射、學院進度投影、真親子邊數；或未決政策錯誤，不產生隱含時間前進。

擬議schema與型別：ClockContext {worldQuarterIndex:int, campaignSeasonId:string, training:{runId, turn:int}|null}; PersonTime {birthQuarter, ageAsOfQuarter}; TimePolicyRef {revision, advanceQuarters, orderedDueEventTypes}; GenerationPath {ancestorUID, descendantUID, parentEdges[]}。campaignSeasonId不是數值年齡。

## 4. 正常流程及狀態邊界
1. 辨識輸入的時間軸，不接受一個未分型season同時當季度與主題季。
2. 同版R3歷史基線：15歲入學、36回合耗一世界季、18成年婚配、孕期4季；保profile適用性，不把所有新模式固定成此時間方案。
3. 代數從實際親子邊導出；n5須5邊6人，不由訓練run數或賽季次數推得。
4. 正常世界季度前進產生到期清單，由B06/G03/B05/G06各owner處理；C02只提供排序所需時點，不自己提交出生或死亡。
5. 換主題季若無DEC-R5-S04採定之跳時與到期順序，只能生成預覽缺件；不可默認0季或全部到期。

## 5. 失敗、取消與恢復
PROFILE_UNSUPPORTED：缺timePolicy時拒換季時間映射；SOURCE_INCOMPLETE：出生季或親子鏈缺失不能以0歲/創始者補齊；REVISION_CONFLICT：時鐘已前進須重讀，不回退。

## 6. 保存、遷移與可重入
C03儲存世界前進與領域事件；C02解析無獨立可變時鐘副本。遷移保原出生季/run turn，新增campaignSeasonId命名空間不可覆worldSeason。legacy欄位歧義由C05標不可轉。

## 7. UI／可見資訊
同時標示世界年月季、主題季名及學院turn。比較後代時顯年齡；不寫「第3賽季＝第3代」。

## 8. 依賴能力及待決閘門
C01分型身份與版本；S03僅用已採timePolicy；G06/B06/G03/B05各自擁有健康、孕期、研習、K到期結果。

明列決策：DEC-R5-S04
缺本次操作必要參數時回 PROFILE_UNSUPPORTED，不以0、R3舊值或較新G分冊衝突值補齊。已定只讀／不變量能力不自動繼承上游所有待決。任何仍需選定技術機制的schema屬實作設計提案，不冒稱使用者批准。

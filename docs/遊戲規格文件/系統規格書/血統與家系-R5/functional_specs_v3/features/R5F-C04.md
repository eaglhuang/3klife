# R5F-C04 命名亂數與事件回放｜獨立功能規格 v3（已審條件版）

## 狀態與範圍
文件內容狀態：CONTENT_REVIEWED_WITH_OPEN_DECISIONS。implementationReady：false。現行實作／consumer：NOT_VERIFIED；產品測試：NOT_RUN；產品驗收：NOT_ASSESSED。
R5F 僅文件功能 ID，非已登記 ATM 工單。全部範圍內工作文件、清單、獨立規格完成後，才能評估產品編碼；相關決策與正常施工准入另須滿足。以下擬議介面／狀態名稱不宣稱產品已存在。

## 1. 目的、責任與非目標
固定版本、命名流與精確抽樣，讓同事件可回放且預覽不影響出生。只提供抽樣服務，不決定未採星核／風險公式。

## 2. 規範來源與優先關係
來源：R4工程§4/6/7。完整基線見 [R4 工程](../../publication_candidate/11_R4歷史基線_工程驗收.md) 與 [R4 玩法](../../publication_candidate/10_R4歷史基線_玩法.md)，R5 題目模組見 ../../publication_candidate/。本份細分原入口，不另計同一成果兩次。R5明示修正優先；原文標候選／legacy／待決者不因本份引用升格。歷史紙面驗算結果非本次產品PASS，可重跑歷史驗算附件未包含於原基線。

## 3. 輸入、輸出與資料契約
輸入：已正規化排序且凍結的來源、完整採定profile、固定rngVersion及事件身份。preview輸入不得呼叫有狀態抽樣。

輸出：可由同版來源重現的結果與內部回放參照；公開層僅收到授權可見結果，不回seed。

擬議schema與型別：RngEnvelope {businessEventId, rngVersion, sourceSnapshotDigest, profileRevision, streamInputs}; ReplayRecord {streamName, drawOrdinal, immutableResultDigest}; 有效流名沿R4：peakType、childLUK、purification、health、potential.STR/INT/LEA/POL/CHA、pool.sourceUID.factorID、retain.slotN、stars.factorID。seed僅內部核心資料。

## 4. 正常流程及狀態邊界
1. 在任何draw前完成資料驗證、canonicalID排序、來源去重；字典變更升profile，不藉無關欄位改抽樣序列。
2. U屬[0,1)，以U<p成功；p0永不、p1必成。多段表左閉右開；以固定版本無偏整數/位元拒絕採樣實作Fraction，不先轉float或ppm。
3. 權重不放回每槽從剩餘集合抽一項移除；家傳先保留且移除同ID，再填其他槽。H權重與來源入池機率分開。
4. 預覽不抽流；婚約只鎖來源，出生由B06提交唯一結果。已提交事件重試由C03回舊結果不重新draw。
5. 回放要求原字典、sourceRevision、rngVersion可取得；缺任一即標不可回放，不從現版重建假原件。

## 5. 失敗、取消與恢復
PROFILE_UNSUPPORTED在未採星核/風險分布時拒該draw；SOURCE_INCOMPLETE拒缺來源回放；IDEMPOTENCY_CONFLICT拒同事件不同來源。具體RNG演算法版本必由正式profile/fixture綁定，文件不新指定演算法。

## 6. 保存、遷移與可重入
C03保存結果與必需版本/seed；C05不得只存hash卻刪所指來源。壓縮後以解碼核心hash與出生重播核等價；回放不寫回現況人物。

## 7. UI／可見資訊
只允顯示可見機率包絡及回放完整性；不顯seed/流序號造成hidden推斷。偵錯輸出亦須權限隔離，不能當公開API。

## 8. 依賴能力及待決閘門
C01精確Fraction/字典；B01來源排序去重；B02/B03/B04提供採定分布；C03一次提交；C05來源閉包。依賴某能力不使所有出生DEC全阻無關回放讀取。

明列決策：無新增數值待決；仍須完成整組文件及正式實作前核查。
缺本次操作必要參數時回 PROFILE_UNSUPPORTED，不以0、R3舊值或較新G分冊衝突值補齊。已定只讀／不變量能力不自動繼承上游所有待決。任何仍需選定技術機制的schema屬實作設計提案，不冒稱使用者批准。

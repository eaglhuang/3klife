# R5F-C05 存檔遷移與引用閉包｜獨立功能規格 v3（已審條件版）

## 狀態與範圍
文件內容狀態：CONTENT_REVIEWED_WITH_OPEN_DECISIONS。implementationReady：false。現行實作／consumer：NOT_VERIFIED；產品測試：NOT_RUN；產品驗收：NOT_ASSESSED。
R5F 僅文件功能 ID，非已登記 ATM 工單。全部範圍內工作文件、清單、獨立規格完成後，才能評估產品編碼；相關決策與正常施工准入另須滿足。以下擬議介面／狀態名稱不宣稱產品已存在。

## 1. 目的、責任與非目標
管理存檔版本轉換、核心引用閉包、冷資料摘要與容量超負載；保留家族歷史，不為固定檔案大小刪必要資料。

## 2. 規範來源與優先關係
來源：R4工程§15–17。完整基線見 [R4 工程](../../publication_candidate/11_R4歷史基線_工程驗收.md) 與 [R4 玩法](../../publication_candidate/10_R4歷史基線_玩法.md)，R5 題目模組見 ../../publication_candidate/。本份細分原入口，不另計同一成果兩次。R5明示修正優先；原文標候選／legacy／待決者不因本份引用升格。歷史紙面驗算結果非本次產品PASS，可重跑歷史驗算附件未包含於原基線。

## 3. 輸入、輸出與資料契約
輸入：舊槽完整bytes/版本、字典與來源revision、目標schema、明示遷移政策和可用空間。

輸出：只讀preview及不可轉欄；驗證通過的新槽或維持舊槽／pending。容量報告須實測，不借估算當實測。

擬議schema與型別：MigrationPlan {fromVersion,toVersion,kept,added,unmappable,profileMapping,coreHashBefore}; ClosureReport {roots,missingRefs,checkedCount}; ArchiveBlock {eventOrder,checksum,decodedCoreHash}; CapacityReport {actualBytes,extensionsBytes,scenarioLabel,overCandidateLoad}。schema為擬議外框。

## 4. 正常流程及狀態邊界
1. 遍歷人物父母、婚約、出生、死亡、因子星變、LUK、功業資格獎勵、sourceRevision及影響未來的K/條約來源；所有引用可解才准轉版。
2. preview列保持/新增/不可轉；P/B/A不重算，unknown P不設P=A，已知資訊取聯集不免費全揭，舊券另帳。
3. 混合legacy能完整映射真ID與家譜才建新ConceptionSnapshot；不能映射保legacy路徑或明示合法模板/查譜，不把未知祖源創造成無共祖。
4. 普通非關鍵逐步日誌可依原profile最近4季或全局2MiB輪替，年度16B摘要是有損且不含完整初末狀態；出生等核心永不擠入摘要或按第9筆截斷。
5. 超50000人/200000來源版等候選負載先無損壓縮索引去重並提示容量增加；不能為100MiB目標取消出生。估算99726336B不是本次實測。
6. 以C03新槽驗checksum/核心閉包/decoded core hash及必要出生回放後切指標；保前槽。

## 5. 失敗、取消與恢復
缺來源停止轉版；計數>65535用擴充而非截斷；Fraction>256位仍拒不因擴充放寬；空間不足回STORAGE_FAILURE保舊槽；不可回放明示缺附件，不假還原。

## 6. 保存、遷移與可重入
C05擁有遷移計畫與歸檔編排，C03唯一提交。舊profile風險/研習不能與新候選疊加；新cap若日後採只套新plan不回扣已得星。圖片音效不嵌存檔。跨季E03快照屬核心可解析引用；詳細戰鬥錄影另包不能宣稱從摘要還原。

## 7. UI／可見資訊
預覽保留/不可轉欄及實際bytes；已知資料不遮回未知；顯示歷史版本legend。超候選容量提示不冒稱存檔壞掉。

## 8. 依賴能力及待決閘門
C01版本單位；C03新槽提交；C04出生回放；各B/G/S/E owner宣告其核心引用與遷移規則。

明列決策：無新增數值待決；仍須完成整組文件及正式實作前核查。
缺本次操作必要參數時回 PROFILE_UNSUPPORTED，不以0、R3舊值或較新G分冊衝突值補齊。已定只讀／不變量能力不自動繼承上游所有待決。任何仍需選定技術機制的schema屬實作設計提案，不冒稱使用者批准。

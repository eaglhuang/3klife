# R5F-E01 首次統一結局｜獨立功能規格 v3（已審條件版）

## 狀態與範圍
文件內容狀態：CONTENT_REVIEWED_WITH_OPEN_DECISIONS。implementationReady：false。現行實作／consumer：NOT_VERIFIED；產品測試：NOT_RUN；產品驗收：NOT_ASSESSED。
R5F 僅文件功能 ID，非已登記 ATM 工單。全部範圍內工作文件、清單、獨立規格完成後，才能評估產品編碼；相關決策與正常施工准入另須滿足。以下擬議介面／狀態名稱不宣稱產品已存在。

## 1. 目的、責任與非目標
唯讀呈現第一次統一及後續可重播的育成成果。結局播放不是領獎、換季、出生或快照建立。

## 2. 規範來源與優先關係
來源：使用者首次統一結局需求；R5模組05。完整基線見 [R4 工程](../../publication_candidate/11_R4歷史基線_工程驗收.md) 與 [R4 玩法](../../publication_candidate/10_R4歷史基線_玩法.md)，R5 題目模組見 ../../publication_candidate/。本份細分原入口，不另計同一成果兩次。R5明示修正優先；原文標候選／legacy／待決者不因本份引用升格。歷史紙面驗算結果非本次產品PASS，可重跑歷史驗算附件未包含於原基線。

## 3. 輸入、輸出與資料契約
輸入：E03已提交不可變結局快照、既有公開知識、顯示legend、E02獎勵只讀收據。

輸出：可重播成果頁與列傳連結；缺證據欄位標未記錄，不能用面板猜戰功。

擬議schema與型別：EndingViewRequest {snapshotId,viewerKnowledgeRef,displayVersion}; EndingView {victoryHeader,contributors,troopTypes,adultFamilyContributions,descendants,comparisons,claimStatus,nextActions}; all entries link personUID/eventRefs；視圖schema擬議。

## 4. 正常流程及狀態邊界
1. 驗snapshot checksum與版本引用，禁止以當前全圖或AI重建狀態替代歷史勝利。
2. 展示主題/當時世界日期/版圖，功臣主將軍師治理後勤、軍種、成年配偶家庭外交家學貢獻、自育後代雙親支系與代表戰績。
3. 當時已知能力快照與今天人物頁分開；歷代比較同尺度才排序，否則分組標profile/年齡/裝備外部值。未知P不因破關免費揭露。
4. 關閉重播完全唯讀；E02只提供領取狀態和明確領獎入口，動畫播放不得直接發獎。
5. 提供列傳、返回當季、下一季規則預覽；是否強制結季由S01待決，不藉關閉動畫清盤。收藏釘選/家徽列未採提案不成必做。

## 5. 失敗、取消與恢復
SOURCE_INCOMPLETE缺快照則不造結局；checksum錯顯可恢復讀取問題不改人物；不可比值標異版不可直接排名。

## 6. 保存、遷移與可重入
無mechanics寫入owner。可保存非mechanics的看過動畫偏好，但不可改首通唯一旗標；E03保存快照、E02保存獎勵。移轉顯示版本保原值與legend，不重算史。

## 7. UI／可見資訊
至少統一紀錄、功臣軍種、成年家庭貢獻、自育後代、歷代比較、獎勵狀態六區；每位後代可開親子鏈與當時戰績。歷史死者仍展示歷史身分不復活。

## 8. 依賴能力及待決閘門
E03凍結快照；C01身份/單位；U01既有公開投影，不傳染DEC07新階段；E02只讀領取狀態，獎勵缺政策仍可看結局。

明列決策：無新增數值待決；仍須完成整組文件及正式實作前核查。
缺本次操作必要參數時回 PROFILE_UNSUPPORTED，不以0、R3舊值或較新G分冊衝突值補齊。已定只讀／不變量能力不自動繼承上游所有待決。任何仍需選定技術機制的schema屬實作設計提案，不冒稱使用者批准。

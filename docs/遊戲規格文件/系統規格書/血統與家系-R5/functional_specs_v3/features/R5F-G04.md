## 目的與非目標

把童年自然成長與已授予額外增益分開保存，使年齡前進不覆掉合法事件成果，也不把已丟棄 overflow 在長大後補發。入學讀一份可追溯 A0，不用畫面能力逆算出生潛力。

本功能不選媒介、不抽因子、不改 held、不增祖位、不變更傳星來源。媒介因子傳授由 B09 負責，現媒介 profile 不給童年 A；不能因同列歷史 §8 就把兩項合併成一次雙收益。不涉及新健康字典或職務年齡投影。

## 必要依賴能力

C01 提供 P/B 的正確單位與完整五維，B02/B06 提供已凍結出生結果，C02 提供出生季度與真實已過季度，C03/C05 提供事件去重、保存與遷移；G01/G02 只消費已認可的入學 A0。U01 負責公開值包絡。B09 只發媒介成果通知作分帳核對，不向本功能傳 freeGain。

不依賴 DEC-R4-05 文武職務曲線，不由主題季切換推導童年年齡。若新童年事件收券或改成本，僅該事件需對應已採成本policy，不把缺成本當免費事件。

## 輸入輸出與建議 schema

輸入是 personUID、出生季度、asOf世界季度、出生 P/B、mechanicsProfile、合法童年事件 catalog與事件原始增益、expectedRevision。輸出為自然基線、credited ledger、當前 Achild、入學快照及 raw/credited/overflow。

```text
ChildhoodState { personUID, birthWorldQuarter, asOfWorldQuarter,
                 profileHash, birthSnapshotRef, PBodyTicks[5], BBodyTicks[5],
                 naturalBaselineRef, creditedTotal[5], gainReceiptRefs,
                 currentABodyTicks[5], revision }
ChildhoodGainReceipt { eventId, canonicalCatalogEventId, eventWorldQuarter,
                       profileHash, rawGain[5], creditedGain[5], overflow[5],
                       costReceiptRef, payloadDigest, committedMarker }
RecognizedAdmissionBaseline { personUID, a0Revision, asOfWorldQuarter,
                              naturalBaselineRef, gainReceiptRefs,
                              A0BodyTicks[5], PBodyTicks[5] }
```

此為建議 schema，不是現行程式。P能力點每點10000ticks；P=20×Talent的基線映射中 P1600=16000000ticks，不是1600ticks。事件來源缺失與確定零增益分開，不能用null當0。非整數中間值遵守所綁profile精度政策，不能自行逐季截小數後累加。

## 計算與流程

1. 驗出生快照及profile完整、asOf季度合法、事件已列catalog且在童年有效範圍。普通讀取只做as-of投影，不新增事件或成本。
2. 歷史自然曲線 g=clamp(ageSeasons/60,0,1)，naturalBaseline=.15P+.05P×g。出生B=.15P、15歲自然A0=.20P；5歲自然值P/6。ageSeasons指世界季度，不是主題賽季。
3. 若沿用 B+(P−B)Gg 的等價表示，G必為1/17，不能沿用舊示例.10。clamp只用於合法年齡曲線封頂，不能把負年齡或毀損出生資料洗成合法值。
4. 對合法額外事件逐維計算：剩餘額度=.05P−已有有效creditedTotal；credited=min(rawGain,剩餘合法額度)，overflow=raw−credited。只記當時真正接受的credited，額外累計每維最多.05P。
5. Achild=min(P,naturalBaseline+有效creditedTotal)。自然增長與事件分帳；不得用新自然值覆掉已授部分，也不得重試已丟棄overflow。
6. 事件成本、credited receipt與目前狀態原子提交。入學時產生認可A0Revision；同profile下A0≤.25P，無額外事件時A0=.20P。後續三份run共用這個已認可起點。

## 邊界 錯誤與恢復

- 合法P0是0能力，不是unknown；自然及額外上限均0，不給免費育成分。unknown P不可從A猜回。
- 負增益、跨單位、未知事件、越窗與缺來源先拒絕；不扣成本，不以cap包住壞資料。若需要損傷或外部衰減，屬其他功能，不能偽裝童年負增益。
- 媒介成功僅更新B09的held/future source；傳入童年A增益請求時無對應catalog就拒絕，不把媒介成功當已授credited事件。
- 舊年齡事件只用於as-of回放；不得讓目前A倒退。新發現遲到事件如何補登須有明示修訂政策，不能用回放端點暗補成本或增益。
- 相同事件ID只記一次；換idempotencyKey但同canonical businessEvent也不能再領。同鍵異payload、revision衝突拒絕，回讀而不重新授益。
- 存檔失敗先保結果與成本意圖，恢復查marker；已commit回原receipt，未commit續原交易。不能見UI未更新就再發一次。

## 保存 遷移與重入

保存自然曲線版本、出生快照、額外每筆credited與原overflow、事件時點及A0Revision。Achild可重新投影，但credited不能由目前A減自然值倒推；缺資料時保legacy或停該遷移。

歷史P/B/A及已授增益不因新版本重抽或倒扣；舊媒介如其profile真的有不同效果，保原事件版本，不能一面套新「不給A」一面刪舊能力。跨季保真出生季與ledger，不以新的seasonId刷新額度。核心引用閉包缺事件來源時不切換存檔指標。

## UI

可公開範圍內區分自然成長與額外教養成果，說明超額不保留待領。未知P時不顯精確.05P上限、B/A/delta組合或ledger數值以反推潛力，由U01產生公開包絡。媒介畫面寫因子／學習資格成果，不宣稱額外提升童年五維。

入學確認顯示起點版本與後續run共用同起點；5歲資訊事件不表示已可入學。

## 待決與核對條件

本功能未新增DEC；自然曲線是否就是現行consumer採用版本、額外事件catalog、投影捨入與A0凍結位置仍須核。不能因規格表列.05P便自造可取得該上限的新事件。產品、存讀與UI案例均未跑，全球文件門檻與正常准入仍未通過。

## 重入優先序與數值型別補充

所有會變更狀態的入口，先查同idempotencyKey＋payload及canonical businessEvent是否已有提交結果；已提交同內容必回原receipt，即使請求的expectedRevision已舊也不能先拒。相同key異payload必衝突；不同key同業務事件不得多領。只有尚未提交的新命令才驗目前expectedRevision；pending先查marker再續原交易，不重抽結果。這項順序優先於上文新操作驗證步驟，不能先套active／alive／未selected等前置條件把成功重送當非法新行動。

儲存型別BodyTicks為整數；Talent與能力點可有精確小數，不要求顯示點一律integer。一能力點＝10000ticks，跨單位先明確換算；中間Fraction不得從畫面ppm或浮點近似回灌。

## 目的與非目標

讓敵我雙方在同一世界中的人物、家系、婚姻與跨族子代跨主題季延續，產出可檢查的承接差異。換地盤不能把一個人變成另一人，也不能把歷史重新洗成開局名單。

非目標：本功能不生成地盤、不切當前存檔、不發獎、不決定軍隊或國庫承接比例，不實作新生育、K 或研習公式，也不把「保留人物」解釋為永生。永久保存的是身份與事件歷史；死亡狀態仍是終態。

## 責任 owner 與精確依賴能力

- 本功能 owner：唯讀承接分析器。建立 `CarryPreview` 與核心不變量檢查；不直接改正式狀態。
- C01：使用 personUID、familyUID、factionUID 分型與人物原 profile／單位驗證，無新增 DEC。
- C02：解讀 worldQuarterIndex 與 legacy worldSeason 的映射；campaignSeasonId 另型。只讀映射無新增 DEC；要求推進時間才消費 DEC-R5-S04。
- C03：讀來源 revision、事件終態與 pending marker，不在此重做提交協定。
- C05：驗證家系、婚姻、出生 witness、版本資料與待辦事件的引用閉包，保原版本及已知資料。
- B06、研習 owner 與 K owner：只讀原 conceptionId、studyPlanId、cohort/event refs、到期時鐘與已提交狀態，不繼承其全部未決公式。若換季需推進季度，必須由各 owner 按已採版本逐事件結算；S01 不另算或補領。
- S03：唯一正式承接與切檔 owner。S02／S06／A01 只消費各自需要的存續快照，不因此繼承 S01 的資源承接 DEC。

## 輸入與輸出

輸入為同一 sourceSaveRevision 的 season snapshot、核心人物與家族索引、婚姻／婚約與政治關係、所有進行中事件、來源版本，以及逐類 carry policy 和 time policy 的選擇／缺口。

輸出為只讀差異、必保引用、逐類政策缺口、核心完整性報告與可供 S03 綁定的 previewDigest。輸出區分「不變量已驗」和「正式承接尚不可提交」，不能以預覽成功冒充換季完成。

## 建議 schema 與不變量

- `CarryPreview`: previewId、fromCampaignSeasonId、toCampaignSeasonId、sourceSaveRevision、sourceWorldHash、policyVersion、decisionRevisionRefs、timePolicyRef、categoryDiffs、pendingEventRefs、coreAssertionResults、previewDigest、status。
- `CorePersonRef`: personUID、birthEventId、biologicalParentUIDs、birthFamilyUID、birthProfileRef、P/B resultRef、selectedGraduationRef、lifeState、deathEventRef。引用原實體，不按季複製新 UID。
- `RelationshipRef`: relationId、relationType、partyUIDs、sourceEventRef、validFromQuarter、validUntilQuarter/status。生物親子、婚姻、政治臣屬與軍事盟約分表或分型；家族合併／改姓只加映射與事件。
- `CarryCategory`: category、proposedAction、policyRef、beforeRef、afterRef、reason。action 只在已採 policy 下為 carry/reset/convert 等值；未採使用 `UNRESOLVED`，不能用 reset 作預設。
- `PendingContinuity`: eventId、ownerFeature、originalProfileRef、sourceRevisionRefs、clockType、dueQuarter、progressRef、commitState。必含婚約、孕期、研習、K 到期樣本、未完成 training run 及條約義務。

必保：雙親與已出生子女的 UID／出生 P／出生來源不變；婚姻／喪偶／離婚等只靠真事件更新；死者不復活；已知資料不遮回；已選 A、因子來源、n5 真親子鏈、K 的 family pair 與 cohort 不因主題 ID 重置。當季積分不覆生涯 EP。戰略陣營可依採定政策另做差異，但不可改生物家系。

## 流程與狀態

1. `requested → sourceValidated`：凍結只讀來源，驗 revision、身份分型與必要引用。存在未明 pending 先回復該事件，不能把它當未發生。
2. `sourceValidated → continuityChecked`：逐人、逐關係、逐未完事件比對，將生死與出生不變量列為不可被 carry policy 覆蓋的限制。
3. `continuityChecked → policyIncomplete | previewReady`：逐類列政策；缺兵力、國庫、庫存、政治關係或歷法政策時保留缺口。可呈現不變量預覽，但不出具正式可提交 token。
4. `previewReady → handedToS03`：交差異與 digest；S03 在確認與提交時重驗 revision。本功能無 committed 世界狀態。

campaignSeasonId 改變不自然推動 worldQuarterIndex；worldSeason 只作舊季度別名。DEC-R5-S04 若採跳時，須逐季度處理孕期、年齡、健康、研習、K 與條約，不得只改日期。若採不跳時，這些進度原樣承接。兩案均未選。

## 邊界 錯誤與恢復

- 缺父母、出生 witness 或必要來源：`SOURCE_INCOMPLETE`，保原檔；不能從同名人物或 A 推算 P 補齊。
- 同 UID 在候選中同時活／死、兩份實體或母親已死亡卻仍排出生：拒絕差異；保死亡／中止事件，交原 owner 處理。
- 來源在預覽後發生新出生、死亡或婚姻：`REVISION_CONFLICT`，撤銷舊確認；新預覽不得默沿舊確認。
- 缺承接／歷法政策：`PROFILE_UNSUPPORTED` 或 `POLICY_UNRESOLVED`，不耗回合、資源或 RNG。
- 政治盟約過期不能順便刪婚姻；家族滅絕不能刪除仍被敵我後代引用的祖源。

## 保存 遷移與重入

正式保存歸 S03/C05。預覽以來源 revision 和 policy digest 綁定，可重建但不得重抽人物；同輸入回同差異。核心閉包含敵家祖譜，不能為 100MiB 候選目標或冷存裁掉來源。遷移保 mechanicsProfile、dictionaryVersion、displayPaletteVersion、discoveryProfile；缺映射時列不可轉欄、保 legacy 路徑，不就地半改。新 schema 所需時鐘不能從主題季序號反推。

## UI 與可觀察結果

預覽分「人物與家系必保」「當季戰略變更」「時間與未完事件」「尚待決政策」。對跨族子女顯示原雙親與婚姻來源；死者標歷史紀錄，不能出現在可出征名冊。只用既有公開知識，不以 diff 曝露未知 P、LUK、seed 或隱藏因子。政策缺項時可返回本季，正式確認停用並指出缺哪類政策。

## 驗收案例

所有案例均為 `[NOT_RUN]`，需同版 profileHash、fixtureHash、來源 revision、真 consumer 與存讀證據。

- **R5F-S01-P 正例**：Given 玩家女兒甲 UID=a 嫁敵族乙 UID=b，孩子 UID=c 的 birthEventId=e、P resultRef=p；When 產生新季承接預覽；Then a/b/c、雙親、有效婚姻、e/p 完全相同，陣營差異另列而不改生物關係。
- **R5F-S01-N 反例**：Given 敵將 d 已有 deathEventId；When 開局模板要求同 UID d 活著回歸；Then 拒絕模板，保死史，不另造同名同 UID 活人。
- **R5F-S01-T01 時間邊界**：Given 世界季度 120、孕期到期 122、研習進度 2/已採 plan、K 到期 124；When 只預覽切主題季；Then 季度仍 120，各 eventId、到期日與進度不變，未將主題季當一代。
- **R5F-S01-T02 缺政策失敗**：Given 軍隊及國庫 carry policy 缺失；When 要求可提交差異；Then 回缺項，不默清空或全帶，不輸出可提交 token。
- **R5F-S01-T03 來源失敗**：Given 孩子 c 的母系祖源被冷存但缺塊；When 驗閉包；Then SOURCE_INCOMPLETE，原可讀檔維持，不能把未知祖源當空家系。
- **R5F-S01-T04 重入**：Given 同 revision、同政策的 preview 已產出；When 關閉後重開三次；Then digest 與差異一致、RNG draw 與成本零增加，婚約／研習不再結算。
- **R5F-S01-T05 遷移存讀**：Given legacy worldSeason=120 且人物曾精查；When 依明示別名映射讀入再存讀候選；Then worldQuarterIndex=120、知識聯集保留、舊 P/B/A 與版本不重算。

## 待決門檻

DEC-R5-S03 決定逐類資源及政治承接；DEC-R5-S04 決定是否及如何推進季度。必須有明確 policyVersion、decisionRevision、單位、前後差異、舊檔策略及反例後，才可宣告承接契約可供正式提交。19 項 DEC 整體仍保原身份，不能因本文件完成視為已關閉；也不把未消費的全部上游 DEC 無差別加到只讀快照上。

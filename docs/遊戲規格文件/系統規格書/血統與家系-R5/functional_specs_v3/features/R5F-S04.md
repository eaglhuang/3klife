## 目的與非目標

將主題選擇、規則鎖定、進度計數與結季資格設為可追溯責任，讓「達成目標」有事實證據而非 UI 按鈕自稱勝利。達標可開結算／下一季預覽，但是否立即結季、到期強制截止或自由延長均待 DEC-R5-S01。

非目標：不發獎、不建立結局快照、不切檔、不生成地盤、不把後勤或人才主題達標當統一天下，也不因主題季 ID 改變而推進 worldQuarterIndex。DEC-R5-S04 的換季歷法不是本功能 S04 的同名責任。

## 責任 owner 與精確依賴能力

- 本功能 owner：主題規則綁定與資格判定。唯一產生本主題 `ObjectiveQualifiedEvent`；勝利條件本身由已採劇本／主題 policy 定義，對實際城主、控制狀態與任務完成，只讀各領域已提交的事實事件。
- C01：theme／season／faction／family 身份、版本與單位分型，不能把主題季當季度。
- C02：讀 asOfWorldQuarter 與已提交的時間事件；不在本功能跳時，因此不為純資格判定加 DEC-R5-S04。
- C03/C05：按 canonical event 去重與保存資格證據、規則快照和來源閉包。
- U01：只讀公開進度與條件提示，未公開能力不成 UI 暗門，也不因教學層級改勝利判定。
- E03：僅真正統一事件可交其封存首次統一結局；E01 讀快照展示。
- E02：依資格及其 reward policy 唯一結算；S05 管當季積分，S03 管確認換季。本功能不自加分、不領獎。
- S02：使用所選 theme/rulesHash 建候選，但主題規則不能因地盤候選難生成而被默換。

## 輸入與輸出

輸入：theme catalog/version、modeRef、campaignSeasonId、已採目標與季終 policy、規則版本、來源世界 revision、canonical gameplay events、當前目標計數／event cursor。

輸出：鎖定規則的 campaign descriptor、逐目標進度及證據、資格狀態、唯一 objectiveQualifiedEvent 或未達原因。若條件未完整定義，輸出 policyIncomplete，不作合理猜測。統一資格需實際勝利證據，不只因世界中暫時沒 AI 或敵城在生成中。

## 建議 schema 與不變量

- `CampaignRulesBinding`: campaignSeasonId、themeId、themeVersion、modeId、rulesHash、mechanicsProfileRef、objectivePolicyRef、seasonEndPolicyRef、lockedAt、sourceRevision。
- `ObjectiveRule`: objectiveId、metricType、predicateRef、aggregationWindow、targetRef、requiredEvidenceKinds、completionKind。門檻以 policy ref 引用，不預設城市數／季度數／資源數。
- `ObjectiveProgress`: campaignSeasonId、objectiveId、metricValue、processedEventRefs、evidenceRefs、asOfRevision、progressStatus。
- `ObjectiveQualifiedEvent`: canonicalEventId、campaignSeasonId、objectiveId、completionKind、rulesHash、qualifiedAtQuarter、sourceWorldRevision、evidenceDigest、evidenceRefs。
- `SeasonEligibility`: active / policyIncomplete / qualified / eligibleForSettlement / settledRef；deadline、extensionChoice 僅在已採 policy 下存在。資格成立不自動等於已結算。

同一季 rulesHash 在開始後鎖定。中途調整目標、模式或門檻必須有版本化遷移／新季政策與預覽，不可用新規則回算舊勝利。進度計數由 canonical 事件重播，同一來源事件不因多次接收累加。生涯成就不因主題季重開而清空。

## 流程與狀態

1. 玩家查看可用主題與完整規則；未採提案不顯作可開始內容。選擇後準備規則綁定，正式開始的持久鎖定與 S03 的換季提交一致。
2. `active` 接收已提交領域事件，檢查 campaignSeasonId、rulesHash、證據類型與 cursor，更新可重播進度。
3. 全部必要 predicate 真且證據完備，產唯一 qualified event；假／未知則保 active 或 policyIncomplete。未定目標不是 0 目標而自動成功。
4. 根據已採 DEC-R5-S01 policy 決定是否 eligibleForSettlement。可開預覽不等自動結季；未定截止／延長不可擅離 active。
5. 給 E03/E02/S03 同一 canonical 事件與證據。接到已結算收據只掛引用，不再產新資格事件發第二份獎。

## 邊界 錯誤與恢復

- 來源事件屬別季或規則 hash 不符：拒計數，保原進度；不混不同主題成果湊目標。
- 控城事件沒有有效世界 revision／領主證據：SOURCE_INCOMPLETE，不因看板顯示 100% 推導真統一。
- 截止與最後一項達標同時發生：需已採事件排序規則；未定回 PROFILE_UNSUPPORTED，不自選對玩家有利／不利順序。
- 若 objective 會因失地而失效，須 policy 定義一次達成或持續持有及 qualification 撤回條件。已提交結算不可被 UI 自行取消；缺政策阻該目標提交，不猜。
- 持久化失敗進 pending，查已提交資格 marker；不從 UI 再點新建事件。

## 保存 遷移與重入

保存 rules binding、來源事件、聚合 cursor、目標證據、資格鍵與下游收據。進度可重算但需同版條件；不以目前世界覆蓋當時勝利事實。legacy 已有合法統一 evidence 可按明示映射封存，不能因缺新 counter 就否認舊事件，也不能缺勝利 evidence 而補造首通。worldSeason 遷移只作季度別名；主題 ID 有獨立映射。重入回同 canonical 資格，不再觸發 E02。

## UI 與可觀察結果

開始前展示 theme、rules 版本、具體達標條件、結季／延長政策及未決狀態。遊玩中顯可理解的進度與來源事件；完成按鈕只開證據／預覽，不能寫勝利。首次統一入口交 E03/E01；一般主題達標不得冒充首通畫面。詳情、搜尋與排序沿公開知識，不輸出隱藏因子／精確未知 P。

## 驗收案例

以下全部 `[NOT_RUN]`。

- **R5F-S04-P 正例**：Given 已採 theme t 的條件為 policy 中具名的兩個目標，兩項均有合法完成事件；When 最後事件提交；Then 產一個同 rulesHash 的 qualified event，開結算預覽但未切世界。
- **R5F-S04-N 反例**：Given AI 候選世界正在重建、畫面暫無敵軍，原世界未符合統一 policy；When 玩家點「完成」；Then 無統一事件、無首通快照或獎勵。
- **R5F-S04-T01 規則鎖定**：Given season s 已鎖 rulesHash=a；When catalog 更新為 b；Then s 仍以 a 計數，不能套新門檻補勝利。
- **R5F-S04-T02 截止未決**：Given 目標達成但強制截止／自由延長未採；When 玩家打開季終；Then 顯資格與待決，未擅清盤、推時間或宣告不能返回。
- **R5F-S04-T03 重送重入**：Given 事件 e 已增加一次進度並產 q；When 同 e 重送與存讀後再送；Then 進度不再加、q 的 ID 相同、E02 不收到新的業務成就。
- **R5F-S04-T04 故障恢復**：Given q 持久化成功但回覆遺失；When 恢復；Then 先查 marker 回 q，不換 canonical key。
- **R5F-S04-T05 主題分界**：Given 後勤主題已達標但領土未統一；When 分派 q；Then completionKind 為該主題完成，不送首次統一 E03 分支。
- **R5F-S04-T06 證據邊界**：Given 顯示目標已滿但缺一個領域來源 ref；When 判定；Then SOURCE_INCOMPLETE，不能以 UI 計數補證據。
- **R5F-S04-T07 時鐘**：Given campaignSeasonId=s、worldSeason 對應季度 100；When 只選看下一個 theme；Then 世界季度與人物年齡不變。

## 待決門檻

DEC-R5-S01 必須逐主題定義達成、失敗、截止、延長、結季入口及事件排序；尚未採定，不以舉例主題當正式內容。精確目標值、聚合窗、可否撤回資格與 evidence producer 應在 profile 及 consumer 核對時明示。E02 的獎勵 DEC 與 S03 的承接 DEC 不阻純進度／資格規格，但其產品提交仍各自受阻。全域文件先行與正式准入均仍有效。

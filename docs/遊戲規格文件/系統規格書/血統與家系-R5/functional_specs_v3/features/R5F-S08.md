## 目的與非目標

保留海外、外敵與跨時代幻想的可選入口及隔離設計，避免未選內容混入純三國家系、存檔與比較榜。**本項是 OPTIONAL_PROPOSAL_NOT_SELECTED，入口規格不是內容製作或啟用批准。**

非目標：不開工全球地圖、海外城市／文化外交模型、軍隊／立繪／動畫美術、不新增跨時代人物，不承諾工期價格或遊玩時數，不把外敵設計當敵方死者可復活的理由。中國地圖主題循環不以本項完成為前置。

## 責任 owner 與精確依賴能力

- 本功能 owner：模式採用狀態、內容相容性與進入／返回契約。未採時不提供可提交切換。
- C01/C05：mode/version、dictionary／profile 與存檔來源映射、closure、legacy 保全；未知模式不能用同名 ID 當相容。
- S01：只讀家系／生死／已知資料不變量，不授權全跨模式帶入。
- S02/S03：已採擴充未來若需要新世界候選／切檔，仍走候選驗證、明確預覽確認及交易；模式入口不能直接改 active pointer。
- S05：比較分組必含 mode/version 及影響規則；異模式不混榜。
- B07：外來因子若有映射，held／啟用／可傳與字典規則沿正式治理；未定映射不創新 canonical ID。

不繼承上述上游全部 DEC 作本地未採提案的阻擋；只有真正要求跨季、資源或新內容行為時才逐能力列所需政策。

## 輸入與輸出

輸入：當前 mode/version、target mode proposal、採用證據、內容 manifest、人物／因子／地圖相容性 policy、save compatibility、return policy、comparison policy、來源 revision。

目前輸出為未選提案及內容／政策缺口。將來明確採用後才可輸出 ModeCompatibilityReport 與只讀 ModeTransitionPreview；沒有新內容或映射時拒入，保原檔。不因入口存在就生成缺失人物、美術或軍隊。

## 建議 schema 與不變量

- `ModeDescriptor`: modeId、modeVersion、historicalScope、adoptionStatus、adoptionDecisionRef、contentManifestRef、supportedProfileRefs、leaderboardNamespace。
- `ModeContentManifest`: contentVersion、mapRefs、characterOriginRefs、troopAssetRefs、dictionaryRefs、availabilityStatus、validationDigest。只列資料契約，不列承諾資產數量。
- `ModeCompatibilityPolicy`: fromMode/toMode、characterTransferRulesRef、factorMappingRef、saveSharingPolicyRef、returnRulesRef、historicalRecordPolicyRef、decisionRevision。
- `ModeTransitionPreview`: previewId、sourceRevision、from/toMode、compatibilityResults、retainedRefs、excludedRefs、unmappedRefs、comparisonChanges、previewDigest、status。

modeId 與 campaignSeasonId／worldQuarterIndex 分型。純三國、守土外敵、海外遠征、跨時代幻想是來源列舉的候選分類，不代表四個已提供模式。未採各目標 descriptor 不得標 available。人物來源、出生 UID／P 與死亡不因模式改名重算；外來新人物必須新合法來源，不覆同名舊人。

## 流程與狀態

1. `notSelected`：僅保提案與成本顧慮，主循環繼續依原模式。
2. 未來先取得範圍採定，再核內容存在與 profile；缺任一項回 contentUnavailable/policyIncomplete，不降級成無提示半套模式。
3. 若已完整採定，產唯讀相容性／返回差異，列人、因子、地圖、資源與比較組改變。未決跨模式返回不可預設可往返。
4. 玩家確認後若涉及存檔轉換，交 S03/C05 依其正式交易處理；S08 不直接寫世界。
5. 返回亦須同樣預覽與驗證。不可只改 mode 標籤、保留外來效果卻重新進純三國榜。

上述未來流程不是本版已授權施工項。

## 邊界 錯誤與恢復

已安裝資料不等使用者選用；升版後不能自動注入幻想英雄。缺軍隊模型或地圖資源回 CONTENT_UNAVAILABLE；因子映射不全回 SOURCE_INCOMPLETE/PROFILE_UNSUPPORTED；原存檔仍可讀。若目標同名人物與舊人物衝突，驗真 UID／來源，不按名稱合併。模式隔離不能抹去原家系婚姻或把死者改活。

若已採的轉換結果 pending，查 S03 commit marker，不再次建分支或換 seed。若模式版號更新，已確認的 preview 過時應重新預覽，不能悄用新版相容性覆寫。線上服務與外送依然未授權。

## 保存 遷移與重入

存檔保 mode provenance、內容與規則版本、原 profile、映射 evidence 和來源 snapshot；缺映射保 legacy 模式，不截斷 foreign refs 偽裝轉換成功。舊記錄持續帶原 mode 及 comparisonGroupKey。若未來採分支存檔，分支／返回／人物同步政策需明示，不能複製同 UID 後在同一世界出現兩個實體。實際切檔由 S03 保雙槽與一次性收據，重開入口無副作用。

## UI 與可觀察結果

純三國主循環不主動推未採幻想人物。提案頁清楚標「可選方向，未採定／內容未備」，不做假可玩入口。將來可進入時先說明史實範圍、不可返回／可返回條件、人物與因子映射及榜單分組；使用者需明確選擇，更新安裝不能代表同意。展示資料守原知識權限，不因跨模式揭開隱藏值。

## 驗收案例

以下全部 `[NOT_RUN]`。

- **R5F-S08-P 停用正例**：Given 玩家在純三國模式且海外／幻想未選；When 載入新文件或瀏覽提案；Then 原人物、字典、地圖與排名組不變，未插入跨時代人物。
- **R5F-S08-N 反例**：Given 僅有幻想入口 schema、沒有採用證據或內容 manifest；When 要求開始；Then FEATURE_NOT_SELECTED/CONTENT_UNAVAILABLE，不創建缺失資產或假人物。
- **R5F-S08-T01 未來相容性**：Given 未來採定目標模式，但外來因子缺合法 mapping；When 預覽；Then 列 unmapped refs 並拒提交，原因子／P 不改。
- **R5F-S08-T02 比較邊界**：Given 同 theme/rulesHash 的兩筆歷史分屬不同 mode；When 交 S05；Then comparisonGroupKey 不同，不能混榜。
- **R5F-S08-T03 返回反例**：Given 未來幻想分支有外來因子但返回 policy 未採；When 要回純三國；Then 阻擋提交，不只改 mode label 後保留外來效果。
- **R5F-S08-T04 重入**：Given 已採轉換 t 已由 S03 commit 而回應遺失；When 重開入口；Then 回原 receipt，不建第二分支或複製人。
- **R5F-S08-T05 寫入失敗**：Given 目標新槽缺內容引用而 checksum／closure 失敗；When 恢復；Then 原模式存檔可用，不設半套新模式為 current。
- **R5F-S08-T06 歷史保存**：Given 人物在原模式已 dead；When 新模式模板有同名角色；Then 不復用該 UID 復活，需明示合法新身份或拒模板。

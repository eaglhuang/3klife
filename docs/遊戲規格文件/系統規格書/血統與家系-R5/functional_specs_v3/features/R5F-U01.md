# R5F-U01 知識投影與分階段教學｜獨立功能規格 v3（已審條件版）

## 狀態與範圍
文件內容狀態：CONTENT_REVIEWED_WITH_OPEN_DECISIONS。implementationReady：false。現行實作／consumer：NOT_VERIFIED；產品測試：NOT_RUN；產品驗收：NOT_ASSESSED。
R5F 僅文件功能 ID，非已登記 ATM 工單。全部範圍內工作文件、清單、獨立規格完成後，才能評估產品編碼；相關決策與正常施工准入另須滿足。以下擬議介面／狀態名稱不宣稱產品已存在。

## 1. 目的、責任與非目標
將同一公開知識投影提供UI、排序、推薦、匯出與教學，避免專家模式或世代教學暗洩未知資料。純讀，不發券不寫knowledge。

## 2. 規範來源與優先關係
來源：R4工程§13；R5模組04。完整基線見 [R4 工程](../../publication_candidate/11_R4歷史基線_工程驗收.md) 與 [R4 玩法](../../publication_candidate/10_R4歷史基線_玩法.md)，R5 題目模組見 ../../publication_candidate/。本份細分原入口，不另計同一成果兩次。R5明示修正優先；原文標候選／legacy／待決者不因本份引用升格。歷史紙面驗算結果非本次產品PASS，可重跑歷史驗算附件未包含於原基線。

## 3. 輸入、輸出與資料契約
輸入：人物公開可見資料、已知資訊帳、同版discoveryProfile、候選UID/arrivalSeq、教學資格。hidden值不可作公開tie-break。

輸出：穩定公開view、風險/成本/取消警示、教學推薦；不是新revealed值。

擬議schema與型別：PublicPersonView {personUID, knownFields, intervals, visibleFactors, evidenceRefs, asOfRevision}; TeachingContext {milestoneStage, eligibility, dismissedLessons}; ProjectionRequest {viewerKnowledgeRef, targetUID, purpose}; riskWarnings[]。介面擬議，knowledge權限不得由mode自行提升。

## 4. 正常流程及狀態邊界
1. 先按knowledge與profile組投影，再由所有展示路徑共用，不能每畫面重新讀hidden資料。
2. 未知LUK不可參與filter/排序/推薦/EP精確破同分/按鈕可用性；固定arrivalSeq/UID作穩定同分鍵。
3. 親本LUK未全已知時EP僅公開可行包絡；同一區間重查不能任意細分，保原profile公開箱而非擅採50細箱。
4. G1..G4是認知導引提案而非免費解密時程；禁親、健康風險、成本、取消後果從第一次操作即提示。已有合法歷史資格者不強等特定代數。
5. 結局E01消費既有公開投影不依新G階段解鎖決策；查驗完成由U02寫knowledge後再投影。

## 5. 失敗、取消與恢復
SOURCE_INCOMPLETE顯缺資訊但不帶hidden因子/精確P；PROFILE_UNSUPPORTED阻新揭露規則，不阻保守展示既已知資料。公開輸出同值測試須含tooltip/error/export而非只主表。

## 6. 保存、遷移與可重入
無人物或knowledge寫入owner；教學閱讀偏好若保存，為非mechanics展示狀態，不能推進worldQuarter或重設資訊。C05保知識聯集；換季不遮回已知。

## 7. UI／可見資訊
明列已知/區間/未知及來源時點，公式說明可展開但不得曝光seed。歷代比較標年齡、規則版、本體與外部裝備值不同尺度。

## 8. 依賴能力及待決閘門
C01分型身份/profile；U02提供已提交knowledge；E01僅需公開投影。DEC-R4-07阻新分階段開放政策，不阻現有保守公開讀取。

明列決策：DEC-R4-07
缺本次操作必要參數時回 PROFILE_UNSUPPORTED，不以0、R3舊值或較新G分冊衝突值補齊。已定只讀／不變量能力不自動繼承上游所有待決。任何仍需選定技術機制的schema屬實作設計提案，不冒稱使用者批准。

## 11. 公開箱與不可反解的完整邊界

R4工程§13歷史知識profile：五歲使用寬400能力點P箱，十五歲寬200；最後一箱包含2000，不另顯「2000」單點。這是版本化歷史profile，不因DEC06定價未決而改用50細箱。指定trait深查只揭指定trait，不連帶揭LUK或其他四維。

未精查時，B=.15P、A0=.20P、L=P−A0與delta不能以可直接反解的精確組合同時輸出。A/B由公開可行P箱及公開事件推可行包絡，不用真值縮窄。C、L、delta的內部ticks不公開；訓練成功、TP、精力和合法成本可精確展示。此能力不宣稱防止所有玩家合法觀察推理，但產品各輸出口必盤點，不能只遮一欄。

新增案例全部NOT_RUN：

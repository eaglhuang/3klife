# G23 他國治理外交與盛衰

版本：eaglhuang/3klife @ 96a83124094d3b2485bfb749ef37d567ad834559。2026-11-04 UTC。

## 結論與界線

本包把原有「候選檔盤點」推進到有界的規格、數值與原函式觀察：45/45 **觀察斷言**通過，包含正常契約與確認缺口的 characterization probes，不能解讀為 45 項遊戲功能正確，更不是整域驗收。

16 份 G23 候選原碼完整讀過；主規格《治理模式他國AI系統》完整讀過。另保存官職、AI強度與領地治理補充規格的相關取樣、GameSession/Lobby 真 caller 切片及依賴，共 63 份 exact-ref 來源。其餘 27 份候選既有測試沒有讀／跑，不拿檔案數當測試覆蓋。

最值得排修／裁定的已重現觀察：
1. 原 GameSession 交易方法能執行一個同季、兩筆、資源容量合法的雙向盟友折扣套利：100 金 → 250 糧 → 156 金。這是已測 API 路徑，不宣稱真 UI 可操作或全產品已利用。
2. 原 Lobby 按鈕 → RivalDiplomacyController → GameSession 的有界掛載 fixture，對合法可正規化的 0 兵／0 地敵國連按出征兩次，得 1000 金、2 次 save。這證明該路徑缺少「目標已覆滅／無可征服領土」守門；未證明真遊戲從新局能到達這份 0 兵狀態，也未聲稱玩家已可無限領取。
3. 年度天下大亂 reset 後 8 國都沒有 officerRoster；GameSession._tickRivals 沒有在該步重新補掛，雖然 _rivalOfficers context 還在。逐將軍力會因缺值退回全體兵力尺度。
4. 在已讀的季度路徑，0 領土國仍生兵、招募；age=100、vitality=0 的逐將官員會變成 age=100.25 並恢復精力。退休、死亡與俘虜決策 helper 有規則，但此季節路徑沒有使用它們完成淘汰。

## 已測數值與規格對照

### 內政、城市兵源、人口與維持費

- 固定四屬性 60 的五任務基礎產出：農耕220、商業230、外交140、軍備200、偵察150。MILITARIST 的農耕198、軍備240；intel 上限100。
- helper 的共用上限為 food10000、gold5000、troops3000、fame2000。真季度 tick 把 troops=0 送 helper 再加舊兵力成長，魏初始9000 → 9600，沒有總兵力3000上限。這段是原碼明示避免砍舊兵力的選擇，與 E-3 共用上限不一致；應裁定 AI 應採哪個 cap，而非直接把所有大於3000標作數值錯誤。
- 主規格 E-3 簡表與 F-1 詳細效率表不一致。實作遵循簡表；例 WARLORD 農耕／軍備為220／200，F-1則應176／280。屬於規格分歧，不把其中一表擅定為唯一正式答案。
- 原碼以主／次兩項任務、統一60屬性結算，沒有以該國逐將名冊分派內政。真官員資料影響逐將戰力，但本包未證明與國家內政屬性接線。
- 已測的魏攻擊季 food5000 → 5198、gold5000保持，事件確實產生。此路徑沒有扣行軍糧或薪俸；不推論全 repo 都沒有維持費。主規格也未給這條 AI 薪俸結算公式，需先補／確認權威規格。
- AIPopulationConfig 的 branch50、global500、depth8、retention2 與繁殖 `min(3+floor(vitality/30),5)` 已核；它是 AI 後裔人口控制設定，不等於國家城市兵源，也不等於 recruits 待命池。待命池501在低糧條件再招募為502，只證明 Rival 招募路徑不讀該 cap，不能將後裔人口預算直接套為這個池的正式限制。

證據：G23-01～10；RivalGovernance、RivalNations.advanceRivalSeason、AIPopulationConfig、ResourceCap。

### 外交、貿易與結緣

- 送禮1000金、+15邦交；≤-80拒收、999金拒收。結盟須邦交≥40、非交戰、非WARLORD/RAIDER，成功+30。一般 alliance 不等同官職第4階的「聯盟文書」。
- 每國每季交易2次、每次量先floor、無效量拒絕；收到資源超上限時 GameSession 整筆拒絕且不扣、不寫次數、不save。
- 原交易成功沒有 E-5 的「貿易完成邦交+5」；也未扣對國資源。例對國gold=0仍可換得100金。此結論限 RivalTrade→GameSession 已讀路徑。
- **套利兩筆公式與條件**：allied=true、relation≥0、atWar=false、當季剩2次額度、金至少100、糧容量至少250。正常可從適合結盟性格的邦交40提出結盟後升到70；本 probe 從已同盟70 fixture開始。
  - goldToFood 收250糧，付 `max(1, ceil(250 × 1/2 × 0.8 − 1e−9)) = 100` 金。
  - foodToGold 收156金，付 `max(1, ceil(156 × 2 × 0.8 − 1e−9)) = 250` 糧。
  - 金100→0→156、糧0→250→0，正好用完同國同季2次；GameSession 真方法成功save兩次。未追到交易 UI 控件，不將 API 重現說成已驗真 UI。
- 故障注入：wallet.spend 拋錯前，GameSession 已把收到的糧寫入，交易計數尚未寫；gift 扣金後 setWorld 拒絕沒有退款。這是 synthetic adapter exception 的失敗順序，未觀察到正式錢包真的故障，未測正式save rollback。
- RivalBonding 是「結緣」待命池配對，不是玩家結義系統：food>2000，品質優先、同品質早招募優先、每次一對、不扣糧。原碼明載不扣糧與無 roster/bonds上限為暫定。相同 season直接再次呼叫可再配一對；正式季caller每季只呼叫一次。沒有測後代生成或玩家結義扣款。

證據：G23-07～08、16～22、39；RivalTrade、RivalAiDiplomacy、RivalBonding、RivalDiplomacyController、GameSession.tradeWithRival。

### 擴張、霸權、軍力與官職

- 出征門檻 troops≥1500、food≥3000；未達時不耗意願骰。實作score≥0.75、WARLORD意願0.1、MILITARIST0.2，與規格0.6、0.9、0.7不同，但原碼標記 PROG-2-1505 暫定平衡調整，不當作已違反正式裁定的bug。
- 意願判斷 `random()>willingness` 才阻擋，因此正好等於意願會通過。外層攻擊骰另用 `< attackChance`，二者門檻不同且兩層都要過。
- 霸權≥30%、叛亂壓力helper≥40%；最高比例同分取先列者。反霸權成員正常邦交每季回零4，但已同盟或交戰完全跳過回歸。叛亂壓力實際落地、玩家被迫參盟、跨AI共同出征未驗。
- 所有國家有 officerPower 才用逐將戰力；任一缺就全體回兵力。弱勢是嚴格小於平均×0.7，攻擊率再乘0.5（暫定）。
- 逐將每季age+0.25、精力補待命比例並cap；虎符+50經驗（暫定）、各星升級後清exp，1→3星需9季；換裝一將一符；軍力是逐將總戰力總和。4/5星突破、戰法、轉生、LUK補正屬明示未納入，不把helper戰力合計稱完整戰力驗收。
- 官職門檻100/260/520/920；S1/S2/S3於tier3/4/5；聯盟文書tier4、反霸權高階會盟tier5；解鎖歷史不重複、天下大亂保留。規格未明說所有基本結盟必須有聯盟文書，tier1結盟成功僅列觀察。
- assignGovernor只查名冊存在，dead項也能暫時委派，之後季結過濾移除；槽數、重複任務／武將守門由原函式處理。UI是否已擋死者未驗。

證據：G23-11～17、27～32；RivalExpansion、RivalHegemony、RivalMilitaryIndex、RivalOfficerSeason、OfficerState/Permissions/Snapshot、GameSession.assignGovernor。

### 盛衰、重跑與真季caller

- 國力=`troops + generals×200 + territories×500 + fame`；嚴格>10000/6000/3000/1000分級。年評估用season%4=0，包含0。天下大亂helper支援90%領土或玩家≤2領土且崩潰3季；正式applyEraShift把collapseSeasons固定0並註記延後，因此後一支未接線。
- 真advanceSeason先推GameClock，接玩家生命週期fixture、再_tickRivals、存檔，最後發SeasonAdvanced事件；一次公開呼叫完成一次季度成長。給相同原世界與相同RNG可重播相同純函式結果；把輸出再輸入會前進，沒有season/idempotency key。
- 私有_tickRivals在同一clock=1直接跑兩次，governedSeasons從0到2。這不是公開advanceSeason同季重複UI操作的證明。
- save故障後clock與rivals已前進但SeasonAdvanced尚未發出；重新呼叫public advanceSeason會再進一季。本包只展示fixture故障邊界，不主張正式儲存服務沒有其他復原機制。
- _tickRivals迎戰勝利：AI減1地、結果territoryGained=true，但該方法沒有加玩家領土，玩家城市兵源也不扣。2026-04-26規格覆寫要求實際Sortie_Troop_Pool；RivalNations註解則記載2026-10-25 MVP自動戰鬥簡化。該MVP「使用者裁定」只見於原碼註解，未取原始裁定證據，應保留差異讓正式規格主責確認。
- 年度reset後清掉roster的狀況如上；新局/讀檔/設定context的方法有_withRivalOfficers，但_tickRivals沒有在applyEraShift後用它。本包不主張任何後續UI載入一定不會補掛。
- 真Lobby季節callback在GameSession.save之後才grant本季勝利金：fixture順序為 recordBattle → Rival事件 → save → SeasonAdvanced → grant554。錢包可能自存，這裡未測，不能直接稱獎金遺失。
- 真Lobby出征按鈕兩按0兵0地的測試包括原mount callback、controller、rivalBattleSquad、recordRivalCampaign、recordAutoResolveBattle、setRivals、normalize及原離線快照純函式。依賴仍為合成screen、event、wallet、journal/save adapter；只有2次有界呼叫，不是遊戲E2E或長時間無限領證明。

證據：G23-23～26、33～45；逐個method的原文/hash/行號在probes/results.json與extracted目錄。

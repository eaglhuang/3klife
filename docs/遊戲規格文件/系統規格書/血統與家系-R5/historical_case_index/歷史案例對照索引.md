# R4歷史案例與R5逐功能規格對照索引

本索引逐條整理R4工程§25–42的129個歷史條目，連到38項R5功能及既有v3案例；另附38功能與346個v3案例的反向索引。這是文件追溯補件，不是產品測試結果，也未配正式doc_id或完成正式入庫准入。

原R4來源、v2清單、v3規格與已交ZIP均未更改。規格中缺少逐值GWT的歷史數學／人口fixture如實列為部分、僅契約相關或無對應編號案例；沒有偽造原runner或新測試正文。

## 分母與狀態

- 129歷史條目＝74 R3T＋32 R4E＋23 M；工程§37是證據標準，不另造案例。
- 38功能＝36主體／基線＋2未採提案；新賽季功能不必硬湊R4案例。
- 346個v3文件案例、原40個舊引用另行保留。三個集合有重疊，不能相加成已跑或通過數。
- 全部產品測試仍NOT_RUN，產品驗收NOT_ASSESSED，implementationReady=false；19待決、17補件檢查及正式索引／准入未因此解除。
- 對照分類：無v3案例 33；部分期望 50；直接期望 29；僅契約相關 17。

## 對照分類

- 直接期望：該歷史列主要輸入與期望均有列出的v3 GWT直接支持，僅代表文件對照，不代表實跑或採定。
- 部分期望：v3 GWT覆蓋部分斷言；未覆蓋的數值、分支、負控或fixture在uncovered_expectation明列。
- 僅契約相關：列出的編號GWT與同一機制相關，但沒有直接覆蓋原歷史具體fixture；不得當完整案例替代。
- 無v3案例：未找到可列入對照的編號v3 GWT，因此case清單為空；該機制可能已在正文，feature責任仍可定位，不代表功能契約必然缺漏。

[R4工程歷史基線](../publication_candidate/11_R4歷史基線_工程驗收.md)含全部歷史表列。JSON每列記原冊頁碼、章節、案例ID所在行、來源SHA，以及對應功能與v3案例的檔案SHA及行號。原始可執行數學附件、完整fixture與runner未隨來源交付；歷史表中的已核／PASS不得讀成本輪執行結果。

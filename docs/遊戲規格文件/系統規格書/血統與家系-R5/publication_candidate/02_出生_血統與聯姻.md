## 能力量尺與先天後天分帳

R4 的 P=20×Talent 是能力點，不是 ticks。Talent 為 0–100 的資質量尺；本體潛力 P 為 0–2000 能力點；BodyTicks 每能力點 10,000 ticks，因此合法 P 範圍為 0–20,000,000 ticks。Q09 將 0–2000 直接稱 ticks 是單位誤植，不能送入存檔。

| 變數 | 角色 | 沿用基線或不變量 |
| --- | --- | --- |
| P | 出生先天上限 | 出生一次固定；不由裝備、退休、換季或教官重抽 |
| B | 出生本體基礎 | 回歸基線 B=0.15P |
| A0 | 入學認可起點 | 無額外事件時十五歲 A0=0.20P；合法童年增益另帳 |
| C | 本 run 開發剩餘缺口的比例 | 精確有理數 0–1，不從畫面百分比反推 |
| A | 後天已開發能力 | A=A0+(P−A0)C；不超 P；年齡傷病只作外部投影 |

例：P1600 能力點即 16,000,000 ticks；B240、A0 320。C=0.70 時 A1216，而非 P 的 70%；寶物+120 可展示 1336，但本體 A 與下一代來源仍分帳。C=1 時直接寫 P；C<1 投影向下取整至 ticks。出生凍結依原規則最後 round-half-even；計算過程不用浮點反覆取整。

童年自然成長與已授 creditedGain 並存；合法額外增益累計基線至多 0.05P，超額丟棄，不因長大後又有空間就補領。現媒介基線不額外增加 A。P 未知不可設 P=A，合法零值與資料缺失分開。

五維固定 STR／INT／LEA／POL／CHA。高先天不代表五維可在同一 run 練滿；育成評價是開發完成度，不是實戰戰力。R4 ΣC 評價與技能槽尺度保留為原 profile 回歸，不能把 Talent 舊 450／460 合計門檻直接套到能力點或 ticks。

來源：R4 工程 §2、§4、§8、§11；玩法 §1。完整舊評級、名號候選與精度邊界依原冊，未因本版新增賽季而修改。
## 祖位 因子與出生管線

子代向上三代是 2＋4＋8＝14 個位置；加本人為 15 節點。風險比對看雙親各 14 位置，合計 28 位置。子代向上四代則為 30 位置，不能稱「高祖 28 格」。同 UID 可占多個祖位，位置仍保留；來源抽取與效果另行去重。

| 五維 | 十藍 canonical ID | 最大星數 |
| --- | --- | --- |
| STR 武力 | B_STR_BODY 體力；B_STR_ART 武藝 | 各 5 |
| INT 智力 | B_INT_INSIGHT 洞察；B_INT_LEARN 博學 | 各 5 |
| LEA 統率 | B_LEA_COMMAND 指揮；B_LEA_ORDER 軍紀 | 各 5 |
| POL 政治 | B_POL_GOV 治理；B_POL_SUPPLY 籌糧 | 各 5 |
| CHA 魅力 | B_CHA_SPEECH 辯才；B_CHA_TRUST 仁望 | 各 5 |

每個藍 ID 的 m 取合法來源 level/5×depthWeight×relevance 的最大值；父母、祖父母、曾祖父母深度權重為 1、0.5、0.25。m 在 0–1，不是 1–5 星級上限。每維兩個不同 ID 的 m 排成 m1≥m2，H=25+40m1+20m2，範圍 25–85。H 是遺傳底值，不是健康任期。已核沒有來源可取 0；未知資料不可當 0。

無來源 H25、父母單三星 H49、單五星 H65、雙三星 H61、雙五星 H85、祖輩單五星 H45。T=min(100,H+birthBonus)，再換算 P。其他 kind 不直接加入 H；不以 BLUE_STR 一個粗 ID 取代兩個既有 ID，也不新增「健康韌性藍因子」偷換字典。

出生順序：驗真來源與合法性 → 凍結婚約來源及成本 → 到期依命名流結算出生 → 一次提交 P/B、held 與 witness。Carrier 依 sourceUID＋canonicalID 去重及最近深度入池；不同來源同 ID 在入池後按最高 level、最淺深度、穩定 UID 選一版。父母／祖輩／曾祖的入池機率 1／0.5／0.25 與 H 權重是不同步驟，不能乘一次代替兩者。

持有總槽 held≤6；字典十藍不等每人持十藍。保留 ID 從普通候選移除，餘槽不放回抽取；空池可為零，不補造因子。持有、發現、啟用、可傳四狀態分開。來源 §3、§7、§12。
## 功業回流與星級變化

給定 E∈[0,100] 時，R4 的出生 bonus 分布以五個錨點線性插值。社交 R 退出直接遺傳後，總 EP 分項仍待 DEC-R4-09，不以舊五分項填洞。插值算法可獨立驗，不代表完整出生 profile 已具備。

| E | bonus0 | bonus5 | bonus10 | bonus15 | 平均 bonus |
| --- | --- | --- | --- | --- | --- |
| 0 | 0.80 | 0.18 | 0.02 | 0 | 1.10 |
| 25 | 0.65 | 0.27 | 0.08 | 0 | 2.15 |
| 50 | 0.50 | 0.30 | 0.18 | 0.02 | 3.60 |
| 75 | 0.35 | 0.30 | 0.25 | 0.10 | 5.50 |
| 95 | 0.20 | 0.25 | 0.35 | 0.20 | 7.75 |

相鄰錨點先混合四種機率，再抽一次 bonus；不是各抽一次再平均。95–100 固定末列；缺成分或越界 E 拒結算，不任意 clamp。五維使用不同命名亂數流；同一 EP 不代表五項必一起跳最高。

回歸檢核：E74 的 mean5.424、E75 為5.5、E76 為5.6125，不能恢復跨檔跳升。EP75或85作金因子資格若另採，應與連續 bonus 分開；新資格門檻不會讓出生分布突然多一份獎勵。

星級變化順序為來源 → 出生傳星 T → 功業形成 F → 研習 G → 未來傳承來源。源版本鎖定後父母再升星，不回改本胎。保 ID 不等保星、不等啟用；純化只 m 不改此星核。q=1−0.97²=0.0591 是兩次合格 3% 機會且首次成功停的解析控制組，不得把每次演出都設為 5.91% 再多抽兩次。

原條件鏈在 n5 四星+.02、每低星單次.5、cap3 下五星比例33.625679%；確定補救 cap3 為34.351259%。這些限單 ID 每代必保留、指定生育前順序；不含配偶供給、人口死亡、媒介與工時。不是自然人口分布，不是產品平衡通過。

來源：R4 工程 §18、§19、§38–42；新五份對「二次覺醒」的演出不得額外增加出生或傳星抽樣。
## 聯姻 保留席位與近親履歷

玩家同時考慮三軸：選誰婚配、這胎保哪個合法 ID、有限教養投入如何分配。世交、新來源與合法表親可以重疊，不是互斥職業。需要真實用途的代價交換，而非每條路都免費加同一個 EP。

父系家傳、兼收、母門擇承、缺位復興若採，都只能競逐同一保留保證；總 held6 不增加。母門方向限母親、外祖母、外曾祖母的合法來源鏈。外祖父仍在一般祖位來源，不因「外家」文字就取得另一保證槽。缺位復興需真祖源、合法三代窗、父母缺位等明列的候選資格條件；不得永久存祖父五星、保底送兩星或直接沿用已斷 streak。

新五份提出母門不占婚約槽、入學三回合另添 ID，復興與研習共用一次但保底2星，均屬改規則，與 R4／Q08／Q13 不同。R5 不採為預設。費用、時間與是否保留原免費家傳依 DEC-R4-02 裁決，不能先收費再稱只是文案。

近親評估先排自配、直系、同父或同母手足等不合法關係，再計真共同 UID。姓名、陣營、收養或師徒不是血緣證據；同姓禁婚若作額外文化規則須另定，異姓也不保證無共祖。unknown 不等乾淨。普通表親兩個唯一共同祖父母各扣5，多樣性候選20→10；雙重表親四個各扣5，可到0，不等 G3 才開始算。

履歷候選 I 取 max(h父,h母)+1，完整 O 取 max(0,max(h父,h母)−1)。回復靠真正外婚世代，不靠等待。近胎12／20／30%為 R4 候選方向；G3改12／20／32／48%、外胎1%、h上限10皆未採。R4 原有限族譜外胎風險為 null；Q07補1%是待決提案，不是既有事實。

純化僅作用指定 m：m1=.6成功+.2且排序不變、未撞cap時，單項 P+160能力點；25%成功率的期望為五維合計+40，不是每項+40。其費用與健康成本仍需同資源比較。來源：玩法 §3、§5–6、§13；工程 §7、§20–21、§24。

K 不使用 factor lineageRoot 作家族身份。按穩定 familyUID pair 記錄所有出生 cohort，固定到期日一次 finalize；改姓、過繼、換家傳或跨賽季不移分母。未到期不算失敗，死亡到期記結果與原因；這是遊戲任務達標紀錄，不是人類遺傳品質判斷，也不能據低 K 減少孩子教育資源。

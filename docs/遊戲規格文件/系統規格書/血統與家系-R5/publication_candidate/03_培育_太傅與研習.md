# C2 R5 模組 03　培育 太傅與研習
版本：2026-11-03 整合評審稿

R5F-* 僅為文件功能索引，不是正式施工工單。
規格可拆不等已獲施工准入；所有產品測試均未由本次文件工作執行。
共同契約以模組01為準；未決參數不得以0、舊R3或最近表值補齊。

## R5F-G01 共享培育回合
- **目的：** 一個run內成長及資源一次結算
- **輸入：** A0/L/C/stamina/turn；已定教官事件catalog；action與weights
- **輸出：** 新C/A/TP/stamina；成本與overflow ledger
- **功能依賴：** R5F-C01, R5F-C03
- **決策依賴：** 無新增數值決策；仍須核實同版現有consumer
- **規格狀態：** 同profile回歸可拆
- **施工狀態：** 未核目前產品准入，不宣稱可直接施工
- **現行caller：** 未在本次重新核對，不填猜測檔路徑。
- **擬接責任：** 驗證行動後一次結算回合、成本與成長。實際接線前須另列真caller。
### 驗收 R5F-G01-P [NOT_RUN]
- **Given** 精力足且合法單項訓練
- **When** 成功結算
- **Then** 只扣一回合，C不超1，A不超P
### 驗收 R5F-G01-N [NOT_RUN]
- **Given** 28T8R基線計畫
- **When** 准入
- **Then** 拒不可行，不以5項各20次繞預算

## 共享育成與太傅代管

一個 run 只有36個主行動，訓練、休息及明列事件共用預算；不能為母門、復興、研習各加一套免費回合。基線精力100，訓練耗20、休息回50且cap100；行動前<20拒訓練，不耗回合或亂數。≥40失敗率5%，20–39為20%；合法失敗仍耗資源，休息不給TP。

27T9R是這組資源下可構造的上界路線，不是每人必須9休息，更不是任意排列都合法。28T8R耗560而供給僅500，拒絕。若玩家選20次訓練與其餘休息／事件，不能因不足27次訓練被判錯。五維不能各20次冒充36回合。

基線每次成功 C 增量=.05×u×outcome×w；五項w總和≤1。u=autoMultiplier×min(2,(1+mentorBonus)(1+synergyBonus)(1+eventBonus))。manual為1、auto為.7；同家族依正式familyUID，不按姓氏。事件進度共用每run .10／每回合.02上限，預算是guard不是白送。

太傅代管減少重複操作，但開放資格仍有衝突：R4為三位不同人物手動畢業選定且至少一位A／S；G1為第二胎即開。R5不先選新門檻，列DEC-R4-07。代管最高育成A、不觸發原manual鼓舞／考核／事件覺醒；若希望代管也播儀式，演出不得偷偷新增抽樣。

TP必須分帳：成功基礎10、失敗2、休息0；匹配教官成功額外2×Rank，auto .5只作用這筆教官額外，並非全部TP打五折。Rank3匹配同家族且manual鼓舞時C+.069575、TP16；auto無鼓舞C+.044275、TP13。Q03若被讀成全部TP×.5，應依原R4此完整規則修正。

畢業只能選一份完成候選，最多三份，不能拼最強五項。技能兌換需本run見習與inspiration、空槽、足夠TP，選定畢業後不新增無限購買入口。既有精確教官表、技能槽、媒介及HP規則完整依R4工程§8–14，不由新五份的示意schema替換。

研習專節
研習只能對已 held 的1或2星合法 ID 提升，cap3候選；不能補入未繼承 ID，不是保 ID 的替代。一生一個 StudyPlan，A確定補救與B單次機率互斥；工時4／8季度及n5+.02／.04尚未組合定版。若 B 改兩次保底，須新 plan版本與完整成本，不是加重試鈕就沿用一次語義。

研習途中因功業已超過目標時，完成取 max(current,target)，不降、不另加一星。取消、死亡、未完成跨季如何續辦綁時間政策；既有星與已付成本不能因換季再發一次。來源：工程 §5、§19、§22–23；Q06、Q13；G3 F/I。

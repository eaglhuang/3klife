# C2 R5 模組 04　知識投影與漸進介面
版本：2026-11-03 整合評審稿

R5F-* 僅為文件功能索引，不是正式施工工單。
規格可拆不等已獲施工准入；所有產品測試均未由本次文件工作執行。
共同契約以模組01為準；未決參數不得以0、舊R3或最近表值補齊。

## R5F-U01 知識投影與分階段教學
- **目的：** 教學權限不等數值知識
- **輸入：** knowledgeTier；公開可行區間；milestone stage與eligibility
- **輸出：** public view model；risk/cost warnings
- **功能依賴：** R5F-C01
- **決策依賴：** DEC-R4-07
- **規格狀態：** 不變量可先拆
- **施工狀態：** 未核目前產品准入，不宣稱可直接施工
- **現行caller：** 未在本次重新核對，不填猜測檔路徑。
- **擬接責任：** 唯讀公開知識投影與教學提示，不寫hidden值或改角色。實際接線前須另列真caller。
### 驗收 R5F-U01-P [NOT_RUN]
- **Given** G1遇親緣風險
- **When** 開提親預覽
- **Then** 即告知不等G3
### 驗收 R5F-U01-N [NOT_RUN]
- **Given** 公開資料相同只換hidden LUK
- **When** 排序/tooltip/export
- **Then** 輸出相同，expert不免費揭露

- **輸出：** 已知增量；query event/result
- **功能依賴：** R5F-U01, R5F-C03
- **決策依賴：** DEC-R4-06
- **規格狀態：** 需求帳可拆；定價待決
- **施工狀態：** 未核目前產品准入，不宣稱可直接施工

## 四階段揭露與三國包裝

採納五份新規格的可用方向是分階段降低認知負擔，不是延後底層正確性，也不是世代一到就揭露所有隱藏數值。教學階段、功能資格、資料知識權限三個判斷必須分離。

| 階段 | 建議呈現的玩家問題 | 必須守住的邊界 |
| --- | --- | --- |
| G1 建立家業 | 如何挑選已知合適配偶、培養第一位接班人 | 風險和成本立即提示；不假設新手必無共祖 |
| G2 功業與譜牒 | 前代功業怎麼影響後代，老將如何繼續有用 | 十藍與14祖位沿原定義；不把m改為星上限 |
| G3 通婚與支系 | 如何在保留家學、新來源與教養成本間取捨 | 單保留槽、真28位置風險、K未決不得給收益 |
| G4 家族長線 | 我家哪些支系成材，如何留下門風與紀錄 | 門閥稱號不等永久遺傳保證；跨季仍有挑戰 |

出生P的知識投影沿已知範圍，未查者保400／200寬等原profile公開箱；新五份的50細箱、免費前20%精英名單、每年6–10券即可最優等均是提案，需先做需求、供給與工時帳，不能稱DEC-R4-06已定案。不能把400能力點的箱偷換為五維Talent總和之任意評語門檻。

專家模式可展開更多欄位與公式說明，但不能免費揭未知P、LUK、seed或未查因子。排序、推薦、tooltip、比較、錯誤訊息與匯出都使用同一公開投影；已知資料永久保留，不因新賽季遮回去。固定公開資料只換未知LUK／seed，輸出應相同。

風險提示說明已知親緣、尚缺資料、可能代價與可取消路徑；不寫「異姓必安全」或「1%所以康健無虞」。教學晚解鎖不能免除禁親與雙重表親計算。反過來，玩家已有完整歷史資格，不應被強迫等第五代才使用合法功能。

月旦評與求親市場可做減負：先以可公開條件篩選，再合法取得更多資料。前20%的母數必須寫清是全體4000、適齡未婚者還是已入選池；不能把4000×20%=800直接宣稱只有10–20人。來源：工程§13、§24；五份D–I；Q10–11。

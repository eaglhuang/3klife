## R5F-E01 首次統一結局
- **目的：** 展示首通與家族育成成果
- **輸入：** 已凍結的有效統一快照/劇本勝利policy；已知角色與戰史refs；ending view version
- **輸出：** 唯讀結局視圖；列傳與軍種/成年家庭貢獻展示
- **功能依賴：** R5F-C01, R5F-U01
- **決策依賴：** 無新增數值決策；仍須核實同版現有consumer
- **規格狀態：** 展示規格可獨立拆，不依K
- **施工狀態：** 未核目前產品准入，不宣稱可直接施工
- **現行caller：** 未在本次重新核對，不填猜測檔路徑。
- **擬接責任：** 只讀已凍結統一快照並呈現既有公開資料；不新建快照、不發獎、不改人物或戰績。持久快照的建立屬勝利事件來源與C03，須另核consumer。實際接線前須另列真caller。
### 驗收 R5F-E01-P [NOT_RUN]
- **Given** 有效首次統一事件及已知功臣
- **When** 開結局
- **Then** 快照指回原UID與當時數值
### 驗收 R5F-E01-N [NOT_RUN]
- **Given** 關閉再重播結局
- **When** 再次開啟
- **Then** 只重播不觸發出生或重算戰績

## 首次統一破關與家族榮譽

使用者明確要求第一次統一天下就有第一次破關畫面。這是正式成就的結算，不代表家族存檔終止。畫面先讓玩家看見自己養成了誰、完成了什麼，再說明續玩方式與將保留的內容。

| 結算區塊 | 應展示的資料 | 防止誤導或重複的要求 |
| --- | --- | --- |
| 統一紀錄 | 主題、世界日期、版圖與統一事件來源 | 判定條件依劇本policy，不只因AI世界被重建就算統一 |
| 功臣與軍種 | 主將、軍師、治理與後勤貢獻、使用軍種 | 有實際事件佐證，不能以最高面板取代戰功 |
| 配偶與後宮成就 | 成年配偶、家庭／外交／家學貢獻與玩家關注紀錄 | 連回同一personUID與婚姻，避免只剩外貌排行 |
| 自育後代 | 本人、雙親、支系、已知能力快照、代表戰績 | 公開知識仍守界線，不在結局免費洩未知P |
| 歷代比較 | 相同尺度的最佳紀錄、角色年齡與版本 | 標示裝備外部值／本體值、規則版本，不混比 |
| 首通獎勵 | 獎勵種類、唯一事件與領取狀態 | 重播畫面／讀檔不重發；具體內容與數額待定 |

推薦結局操作為「查看列傳」「返回本季」「查看下一季規則」。是否達標即結季、可自由延長或到截止才結算仍由DEC-R5-S01決定，不能點開破關動畫就不可逆清盤。

保存兩種紀錄：當時快照不可變，現況人物頁可繼續成長；後代改名、投靠敵人或死亡不改寫過去的功臣表。跨季優秀後代可釘選，但釘選只增加展示／詳細紀錄，不自動取得永生、復活或額外傳承槽。

首通事件與一般季成就分開。首次統一最多一次首通獎勵；之後每季可形成新統一紀錄與當季獎勵。排行榜若為連網服務，需另有服務與隱私範圍；本版先定資料契約，不視為外部上傳授權。可先本地紀錄，避免把線上營運當作循環必要前置。

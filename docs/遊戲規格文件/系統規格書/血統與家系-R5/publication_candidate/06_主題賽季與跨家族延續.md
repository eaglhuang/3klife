# C2 R5 模組 06　主題賽季與跨家族延續
版本：2026-11-03 整合評審稿

R5F-* 僅為文件功能索引，不是正式施工工單。
規格可拆不等已獲施工准入；所有產品測試均未由本次文件工作執行。
共同契約以模組01為準；未決參數不得以0、舊R3或最近表值補齊。

## R5F-S01 永久家系與當季世界承接
- **目的：** 保敵我人物通婚連續
- **輸入：** season snapshot；person/family/marriage refs；carry policy per category
- **輸出：** 承接diff；core integrity assertions
- **功能依賴：** R5F-C01, R5F-C02, R5F-C03
- **決策依賴：** DEC-R5-S03, DEC-R5-S04
- **規格狀態：** 不變量可拆；承接政策待決
- **施工狀態：** 未核目前產品准入，不宣稱可直接施工
- **現行caller：** 未在本次重新核對，不填猜測檔路徑。
- **擬接責任：** 唯讀產生承接diff與完整性檢查，正式寫入交S03。實際接線前須另列真caller。

## 玩家主循環與長線目標

R5 將單人養成、家族傳承與領土競爭串接，但三者不必在同一時刻結束。強人物可以死亡，家學可以斷傳，王朝可以完成一季；家族的歷史仍然保留。下個賽季要讓玩家用累積的家族資產選擇新策略，而不是靠重抽更大的數字取消上季努力。

建議主循環：選擇本季主題與規則 → 在當季世界配置家族班底 → 聯姻與育成補足人才缺口 → 出仕、治理與征戰 → 完成主題或結束競爭 → 結算功業及家族紀錄 → 預覽下一季的規則與承接內容 → 確認後進入新一輪。

| 累積層 | 玩家可追求的進展 | 下一輪不能偷改的內容 |
| --- | --- | --- |
| 人物 | 把先天潛力開發成職務能力，取得合法技能與功業 | 出生 P、已選畢業結果、死亡終態 |
| 家族 | 新支系、聯姻網、可追溯傳承、不同專長與榮譽 | 生物父母、跨家族子代、已知來源 |
| 賽季 | 主題目標、當季戰績、領土與軍事成就 | 已結算的歷史結果與一次性獎勵 |
| 長線收藏 | 歷代優秀後代、名將列傳、軍種使用與自訂家徽 | 不用新統計覆掉舊時點紀錄 |

本版不把「每代必定更強」作硬保證。R4 有先天上限、六個持有槽、共享培育資源與傳承變化；永續樂趣還需由職務組合、主題差異、敵方育成及有限當季動員提供。不得在玩家變強後暗中等比例提高每個敵人，否則育成失去意義；同一隊強角是否因承接整個帝國而令重新開局只剩形式，是待驗的雪球問題；任何隊伍、兵力或資源限制仍待DEC-R5-S03／S07。

主題例子可包括統一、指定區域爭奪、後勤治理或人才功業，但均屬內容提案，沒有指定門檻與獎勵定值。建議每主題設計至少兩種合法達成路徑，避免唯一因子 ID 或唯一婚配成為必解鎖匙。

第一步優先完成中國地圖的循環閉合。海外與跨時代人物可以是後續可選內容，不能拿尚未製作的全球地圖代替眼前的續玩問題。
## 家族持續與賽季重建的邊界

主題賽季的核心是讓同一個家族世界進入新一輪競爭。敵方領地被佔光，不等其所有人物死亡；我方子孫嫁入敵家後，婚姻與子代仍是同一段歷史。新一季不再從最初史實名單把所有人整批重生。

| 資料 | 本版方向 | 尚須明示的政策 |
| --- | --- | --- |
| personUID、父母、出生與死亡 | 保留，死者只留歷史不復活 | 歷史人物確已死亡時，不以同UID造活人 |
| 婚姻與跨家族子代 | 保留有效狀態與歷史 | 離婚、喪偶、過繼等只依真事件更新 |
| P/B、已選A、因子／技能／知識 | 保留原版本與結果 | 新規則如何接未來事件須migration policy |
| 功業、列傳、祖源與家族榮譽 | 保留可追溯紀錄 | 當季積分與生涯功業分欄，不能清總EP |
| 地盤與據點 | 下一輪重新競爭的候選重建層 | 固定、有限亂數或其他配置尚待選 |
| 現役兵力、國庫、庫存 | 必須評估雪球效應 | 清空、折算、配額、部分帶入都未批准 |
| 陣營、臣屬與軍事盟約 | 與血緣分開處理 | 是否續約／重組，需逐類政策，不全面洗白 |

例：玩家女兒甲嫁入敵家乙，已有孩子丙。敵家失城後甲、乙、丙若仍活著，下季仍用原三個UID；丙的雙親與出生P、兩家婚約來源不變。甲是否仍在敵方政治陣營是陣營政策，不可因重排地盤就改生物家族或重生一個同名丙。

祖地、家族、政治勢力三者必須分型。一個family可有多政治分支；同一faction也可納多家族。取得城池不改居民的parentUID；家族合併、改姓只加映射與事件，不覆寫舊出生歸戶。K、n5、家族榮譽各用自身身份，不能為換季一起歸零。

本版建議保留家族資料、對戰略狀態明示重建；這不等於已選定「軍隊全清」「國庫歸零」。在這些政策未定前，只能做換季預覽與驗證規格，不能正式轉換存檔。
## 下一季地盤與挑戰如何產生

使用者提出「亂數一下地盤但家族延續」，本版建議優先評審有限制的地盤重組，而不是無條件洗牌。競爭性重新開局可重置戰略起點，但應在季終前告知政策與預覽，讓玩家知道是進入新賽局，不是在原世界被無預警奪城。

| 選項 | 好處 | 代價與驗收重點 |
| --- | --- | --- |
| A 固定起點模板 | 容易理解、公平比較、重播明確 | 重複感高；不得復活模板中已死人物 |
| B 限制式亂數重組 建議 | 保新鮮與地方差異，可保祖籍偏好 | 需連通、可生存、強弱差距及種子驗收 |
| C 玩家選難度與起點 | 留更多家族故事與自我挑戰 | 排行榜需分組，不能與相同規則榜混比 |

若採B，生成輸入應包含主題版本、世界地理、合法存續勢力、家族在世名冊、起點權重及已凍結seed。約束至少包括：起始領土連通或明示飛地；糧道與基本補給可行；無勢力出生即必敗；重要關係與人物不被複製；不可把不同勢力同一城同時標為唯一領主。生成不通過則留舊季，不挑一個偷偷比較有利的seed冒稱原結果。

是否所有存續敵家都分地、祖地家族可選出山或維持隱居、新興家族佔多少席位、優勝家帶入多少優勢，仍須內容決策。不要把「有家族」等同「每家一定有國」，也不要讓全球家族數無限長成每家一城的不可維護盤面。

建議挑戰來自不同任務價值與資源限制：水域／山地／行政／後勤組合、不同動員成本與敵方戰術。當季出征名額、指揮成本或軍隊上限可以防止最強十人包辦，但任何具體cap、扣除或獎勵倍率都尚未批准。先檢查同資源下是否有多策略可行，再選數字。

老牌家族應保留育成累積的價值；新家族也須有合法可活的起點。不能為平衡直接改低玩家既有P或複製其最強後代給敵人。來源：本輪賽季提問；此章三方案與生成契約為小豆建議。

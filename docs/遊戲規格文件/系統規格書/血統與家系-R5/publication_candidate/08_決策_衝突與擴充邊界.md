## 海外模式與內容成本

使用者討論固守家鄉或征戰海外的選擇，也提醒三國味會降低、各國軍隊與武將美術成本高，跨時代人物可能偏離題材。R5把海外列為可選擴充方向，不作本次主題賽季循環的必要條件。

第一階段建議留在中國地圖，利用不同主題、地形、政治局面與家族名冊製造新對局，優先重用既有兵種與場景。第二階段才評估外敵劇本：有限外來勢力、可回收的兵種變體和明示的劇本邊界。真正全球地圖需要城市、補給、文化與外交模型，不是把地圖畫大就自然耐玩。

| 模式提案 | 玩家體驗 | 明確不混入的內容 |
| --- | --- | --- |
| 三國家族主題季 | 以中國競爭與世家育成為主 | 不自動加入貞德或成吉思汗 |
| 守土外敵劇本 | 在既有家園面對外部戰略壓力 | 不保證所有舊敵因此復活 |
| 海外遠征劇本 | 主動選擇外部領土與補給挑戰 | 不默認無限軍隊與跨海瞬移 |
| 跨時代幻想劇本 | 明示非史實的英雄組合 | 不與三國純題材榜、成就口徑混比 |

各模式是否共用同一存檔、人物可否跨模式返回、外來因子如何映射、內容不具備時如何拒入，都需版本化策略。幻想劇本可以是冒險選項，但不能在一份嚴格三國家系存檔更新後，無提示出現不同時代英雄。

美術資產、軍隊造型、立繪與動畫的規劃須另列需求量與重用率。本版不新增美術製作或海外發版工作；沒有以「整理R5」推定已批准全球內容製作。原人物血統字典與跨季保存先成立，再決定擴充世界觀。

本章是保留使用者探索方向與成本顧慮，沒有承諾製作工期、資產價格或遊玩時數。五份規格宣稱100小時以上也需玩家驗證，不能當已達成的產品指標。

## 原九項決策保持原身份

九項DEC不是全部重新詢問使用者，也不是阻擋所有文稿工作；它們表示尚不能凍結完整產品參數。外部AI可就下列缺口給具體方案與反例，不能以「建議」二字替使用者作最終採定。

給外部設計者的回答格式：每一項列「選哪案／明確拒哪案」「精確參數及單位」「何時生效」「舊存檔如何處理」「最小正反例」。若只回答玩法比喻，工程仍不得補猜。若新方案跨多項，例如K加教官效率又改培育門檻，需列相依DEC，不能只關閉其中一項。

待決項用以界定尚未採定的產品參數，不撤回既有工作授權，也不表示所有獨立功能皆須等待。
## 新主題賽季決策與推薦組合

本表獨立於九項DEC-R4。使用者已明確要循環與家族延續，以下只處理具體政策。推薦不等已選；任何數額、cap與時長在採定前不得進正式存檔。

| ID | 待選政策 | 本稿建議與後果 |
| --- | --- | --- |
| DEC-R5-S01 | 何時結季 | 達目標開結算與續玩預覽；強制截止或自由延長另定 |
| DEC-R5-S02 | 下一季地盤 | 限制式亂數重組優先評審；固定模板較易驗但重複 |
| DEC-R5-S03 | 兵力國庫與裝備承接 | 分類列carry/reset/convert；不全面默清或全帶 |
| DEC-R5-S04 | 換季歷法 | 明示不跳時或逐季度推進；孕期研習K共用時鐘 |
| DEC-R5-S05 | 祖地再起 | 有成本、前兆與可反制的動員；祖地免攻不等軍隊免傷 |
| DEC-R5-S06 | 敵家供給與滅族 | 存活舊族＋真後代＋新家；不復活死者；補入規則待定 |
| DEC-R5-S07 | 當季動員與難度 | 先測角色／兵種／後勤取捨，再決cap與帶入優勢 |
| DEC-R5-S08 | 主題獎勵與榜 | 生涯榮譽與季積分分帳；線上另權限，本地可先行 |
| DEC-R5-S09 | 海外與幻想模式 | 可選後續擴充，純三國主循環優先；模式榜分組 |
| DEC-R5-S10 | 門閥與金因子 | 郡望條件、+10%教學、金資格與新ID治理另定 |

建議優先評審組合為「家族與人物連續＋首次統一結局＋中國地圖主題季＋限制式地盤重組＋有成本的祖地再起」。它直接回應統一後的新一輪競爭，不需先製作全球美術。不建議現在採「所有敵人原樣復活」或「帝國永遠不重建只靠小叛亂」當核心，前者破壞家族歷史，後者沒有解決使用者提出的無敵問題。

需要外部AI補答的最少內容：一份逐欄承接政策、三種真實家族跨季例子、季終／跳時／再起的成本規則、同資源玩家與敵方發展方案，以及不可重複領獎的事件鍵。回答不得用「永久保留」含糊帶過已死亡人物，也不得用「重新開始」含糊抹掉跨族子女。

完成R5文件不等這十項全部已決。下一版若獲採定，逐項填decisionRevision與證據訊息，保本版提案／算術修正歷史，再形成可測profile。

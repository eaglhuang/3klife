## 現況證據與實作分期

本版只核文件來源與既有靜態觀察，不把設計寫入等同產品完成。GitHub五份新文固定於b88c7a4b579b1f873e2345402dcf5067dec7de52；來源標題與內容已全文取得。本版未執行遊戲、未做新人口實驗，亦未藉文件整合變更正常准入要求。

既有同pin靜態觀察：季度流程含對手世界調整，最強領土占比條件可觸發重新建立AI世界，而玩家資產與領土未同樣重建；另有EraReset事件與campaign stages。這些不構成R5所需的雙方家譜延續、完整季終交易或統一後新一季。此段只作已提供靜態證據的限制說明，並非本版重新跑過consumer。

| 建議階段 | 可交付結果 | 前置與停止條件 |
| --- | --- | --- |
| D0 文件收斂 | 決策revision、單位、兩類季時鐘、承接政策一致 | 九DEC及相關S項未定，不凍結完整profile |

任何產品實作仍需正常准入及工作保全。本次只交付規格，不以文件完成代替實作、測試或發布授權。
## R5 新增驗收規格

下表全為待執行案例，不是PASS列表。每項應有固定profile／fixtureHash、實際consumer、正反例、邊界、重入、存讀及ran／skip結果。原R3T01–74、R4E01–32、M01–23保留原文與限制；R5只追加，不覆蓋歷史期望。

| ID | 情境 | 必須成立的結果 |
| --- | --- | --- |
| R5S01 | 首次統一、重播動畫、讀檔再開 | 首通紀錄一次；同事件獎勵不重領 |
| R5S02 | 玩家女兒嫁敵家並育childUID後換季 | 父母、婚姻、子代為同UID；P與來源不重抽 |
| R5S03 | 敵家全失城但仍有活人 | 保存家族；按已定祖地／起點政策，不整批刪人 |
| R5S04 | 敵將已死亡，下一季同名模板出現 | 死者不復活；新人物須新UID與清楚身分 |
| R5S05 | 換季時孕期／研習／婚約／K樣本未到期 | 時間政策一致；不免費完成、不重扣、不清分母 |
| R5S06 | 未選地盤或軍隊承接政策而提交 | PROFILE_UNSUPPORTED，原存檔不變 |
| R5S07 | 換季各寫入點中斷後恢復 | 全舊或全新可用；不半清地盤、不雙領獎勵 |
| R5S08 | 同transitionId不同payload／舊revision | 明確衝突；不重抽seed自動成功 |
| R5S09 | 地盤亂數結果不連通／無糧道／重疊城主 | 驗證失敗保舊季；不得略過約束 |
| R5S10 | 改主題與世界生成seed | 不改既有出生P、星、已知或生死 |
| R5S11 | UI世代／專家模式切換 | 已知不倒退、未知不免費揭露；風險G1即告知 |
| R5S12 | K樣本4/4、8/6、6/5及跨季改姓 | 分清兩公式；不錯報滿額，不移出生歸戶 |
| R5S13 | 同人有兩個勢力／家族引用 | 參照同實體，不複製一份供雙方重複繁衍 |
| R5S14 | 跨季第50001人或超200000來源revision | 明示超負載與容量，核心不刪；量實檔非估算 |
| R5S15 | 祖地民兵出山後退回 | 依明定成本／可反制規則，不產生無敵無限兵 |
| R5S16 | 家族成就／當季積分同名不同scope | 生涯與當季分帳，不歸零總EP或重發首通 |

另須比較老玩家強家、新家、只育一支與多支家族在同資源條件下的可用策略；驗收不以「敵軍都更強」或「有一個缺點」便宣布循環平衡完成。

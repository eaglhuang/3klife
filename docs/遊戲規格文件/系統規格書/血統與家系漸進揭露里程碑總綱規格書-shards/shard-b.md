## F. 公式相關（跨階段底層不變量 vs 表層可見度映射）

### 1. 底層恆定管線（G1 即在背景完整執行）
無論玩家處於哪個世代里程碑，底層子嗣生成與養成一律遵循 C2-R4 確定性管線：
$$\text{Prowess}_{\text{birth}} = \lfloor 0.15 \times P \rfloor, \quad \text{Prowess}_{\text{enroll}} = \lfloor 0.20 \times P \rfloor$$
$$\text{Prowess}_{\text{adult}} = \text{Prowess}_{\text{enroll}} + \Delta A(\text{36 turns}, \text{cap } P)$$
$$H_{\text{tenure}} = 25 + 40 m_1 + 20 m_2$$

### 2. 表層 UI 漸進揭露遮罩函數（Visibility Gate）
定義玩家當前家族里程碑階數為 $M_{\text{stage}} \in \{1, 2, 3, 4\}$，各系統變數在 UI 上的呈現方式由下表控制：

| 底層變數 | $M_{\text{stage}} = 1$（G1 初代） | $M_{\text{stage}} = 2$（G2 二代） | $M_{\text{stage}} = 3$（G3 三代） | $M_{\text{stage}} = 4$（G4+ 門閥） |
|---|---|---|---|---|
| **五維潛力 $P$** | 僅顯示 400/200 鄉評文字（如「武骨不凡」） | 解鎖「潛力條」與 50 箱密查 | 顯示完整「先天上限 $P$ vs 當前覺醒 $A$」 | 同 G3 + 家族歷代均值對比 |
| **10 藍因子與上限 $m$** | 隱藏星數，僅於開蒙/加冠時演出「承襲某特質」 | 解鎖 `1~5★` 星級與「顯性/連攜」上限提示 | 解鎖「純化突破上限 $m$」預覽與研習補救 | 解鎖「宗脈常駐特徵」加成顯示 |
| **族譜視圖** | 僅顯示父母 2 人 | 展開三代 6～14 人竹簡族譜 | 展開 28 祖位共祖掃描高亮（紅框標示外戚同源） | 展開跨家族百年世系網與郡望樹 |
| **近親風險 $h$ 與 $D$** | 隱藏（G1 預設無共祖外婚） | 若發生近婚僅彈出「親緣過近，恐損氣血」文字警告 | 顯示三色燈號【清朗/微躁/鬱結/枯竭】與當胎/殘留風險 | 完整顯示多樣性 $D$ 折減與外婚復壯世代數 |
| **世交相性 $K$** | 隱藏 | 僅顯示兩家交情 $R$（友好度） | 解鎖「累世通家 / 門風契合度 $K$」與【世交合譜】按鈕 | 顯示天下名門聯姻網絡與郡望加成 |

## G. 劇本相關（世代里程碑解鎖演出）

| 里程碑節點 | 觸發條件 | 劇本與教學引導演出 |
|---|---|---|
| **G1-M1：喜得貴子** | 玩家誕生第 1 位子嗣 | 家老呈上襁褓：「恭喜主公！觀此子啼聲洪亮，頗有主公當年之風。待其十二歲開蒙，再延請名師雕琢。」（此時不彈任何複雜因子表） |
| **G1-M2：十二歲開蒙禮** | 第 1 位子嗣滿 12 歲入學 | 宗祠鳴鐘，畫面切入「開蒙拜師」儀式→鎖頭碎裂特效：「【先祖遺風覺醒】承襲父親之『驍勇』！」首次讓玩家感受到血統傳承。 |
| **G2-M1：蓋棺論定與修譜** | 初代家主退位或首位子嗣滿 18 歲成材 | 史官呈上《家乘譜牒》：「主公半生戎馬，功業（EP）彪炳，已載入宗祠。自今日起，可翻閱【三代十四席族譜】，觀門風之延續！」 |
| **G3-M1：親上加親的抉擇** | 玩家首次在提親介面選中三代內有共祖的表親，**或家族累積達 3 代**（純外婚也升，門檻見 `assets/resources/data/family-milestone-rules.json` 的 `g3MinGenerations`，PROG-2-9172；階段只升不降） | 譜牒官進言：「稟家主，此女與少主同出於先祖【某某】一脈。若行『外戚純化』，可強行拔高先祖絕學上限；然血脈微躁，宜慎衡得失！」（解鎖純化與 $h$ 燈號） |
| **G4-M1：開宗立派晉郡望** | 家族延續 4 代且累計 3 人達 `EP ≥ 75` | 朝廷詔書／天下名士共尊：「汝族累世公卿，文武輩出，今尊為【天下郡望】！凡我族血胤，皆得宗脈庇佑！」 |

## I. Data Schema 需求

### 本機端 (Client) — 家族漸進揭露與里程碑狀態
```json
{
  "Family_Progression_State": {
    "Family_UID": "FAM_PLAYER_001",
    "Current_Generation_Max": 2,
    "Milestone_Stage": 2,
    "Unlocked_Features": {
      "Pedigree_14_View": true,
      "Pedigree_28_Kinship_Scan": false,
      "Factor_Star_And_Cap_View": true,
      "Inbreeding_Purification_Preview": false,
      "Family_Synergy_K_View": false,
      "Tutor_Auto_Delegate": true,
      "Clan_Prestige_System": false
    },
    "Milestone_Stats": {
      "Total_Adult_Offspring": 3,
      "High_EP_Ancestors_Count": 1,
      "Cross_Family_Marriages": 2
    }
  }
}
```

### Server / 存檔端
| 欄位 | 型別 | 說明 |
|---|---|---|
| `Family_UID` | `VARCHAR(32) PK` | 家族唯一識別碼（改姓或入贅不改變生物譜系計算） |
| `Milestone_Stage` | `TINYINT` | 當前揭露階段（`1`=G1開局, `2`=G2二代, `3`=G3三代, `4`=G4門閥） |
| `Unlocked_Mask` | `INT` | 功能遮罩位元旗標（控制 UI 面板與進階選項顯示） |
| `Clan_Tier` | `TINYINT` | 門第等級（`0`=寒門, `1`=地方豪族, `2`=郡望世家, `3`=天下高門） |

## J. 名詞定義

| 名詞 | 代碼/Key | 定義 |
|---|---|---|
| 漸進式揭露 | `Progressive_Disclosure` | 底層完整運算、表層 UI 依家族世代里程碑分 4 階段逐步解鎖的教學與體驗架構 |
| 開蒙修業 | `Enlightenment_36T` | 子嗣 12 歲入學後的 36 回合（最多 27 課業 + 9 休沐）後天培育過程 |
| 太傅代管 | `Tutor_Auto_Delegate` | 針對非核心旁支子弟，指定方針後由系統太傅自動跑完 36 回合的減負機制 |
| 外婚復壯 | `Outcrossing_Rejuvenation` | 雙親三代 28 祖位無共祖時，當胎出生健康風險直接回歸 1%，且體內殘留疲勞 $h$ 減 1 |
| 血脈清濁燈號 | `Kinship_Fatigue_Lamp` | 將抽象的近親履歷 $h \in \{0,1,2,3+\}$ 轉化為玩家直覺易懂的四色燈號 |

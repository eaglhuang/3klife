# 血統與家系漸進揭露里程碑總綱規格書

> **來源文件**：血統理論系統規格書 (doc_spec_0011)、因子解鎖系統規格書 (doc_spec_0009)、結緣系統（配種）規格 (doc_spec_0028)、人物血統與家系玩法設計-C2-R4-評審稿、人物血統與家系工程驗收-C2-R4-評審稿

## A. 系統描述

本規格書為《3KLife》血統傳承與世家繁衍玩法的**總控里程碑與漸進揭露（Progressive Disclosure）綱領**。
底層數學模型雖同時融合了《Winning Post 10 2025（賽馬大亨）》的跨世代血統理論（14/28 祖位、近親純化、異系多樣性 $D$、世交相性 $K$、親系升格）與《賽馬娘》的微觀培育變數（藍/紅/金因子、1~5 星與上限 $m$、兩次覺醒、36 回合修業、太傅支援卡），但**嚴禁在遊戲初期將所有公式與面板一次性塞給玩家**。

系統採用 **「底層全量運算、表層隨世代里程碑逐層剝離迷霧」** 的架構，將玩家體驗劃分為 **G1（初代開局）→ G2（二代傳承）→ G3（三代配種深淵）→ G4+（百年門閥終局）** 四個大階段，並對應產品開發的 **MVP（M1）→ 進階（M2）→ 終局（M3）** 三個實裝里程碑。

---

## B. 系統目的

1. **降低初期認知門檻**：第一代（G1）玩家只需直覺理解「看名聲娶妻、拜名師開蒙」，不出現 $h, K, m, D$ 等硬核參數，確保新手前 2 小時留存。
2. **創造階段性「頓悟時刻（Aha Moment）」**：每一代解鎖一層新視角（G1 看開蒙覺醒 → G2 看三代族譜與功業回流 → G3 玩表親純化與世交合譜 → G4 立天下郡望），讓玩法在 10 小時、30 小時、100 小時都有新深度。
3. **賽馬機制的三國文化無縫轉譯**：將賽馬「配種、近親、支援卡、勝鞍」完全包裝為三國「門第聯姻、外戚純化、太傅親授、生平功業（EP）」。
4. **開發風險可控**：確保底層資料結構（Schema）於 MVP 一次到位，而 UI 面板與進階規則可按 M1 / M2 / M3 里程碑分階段交付。

## F. 公式相關（跨階段底層不變量 vs 表層可見度映射）

### 1. 底層恆定管線（G1 即在背景完整執行）
無論玩家處於哪個世代里程碑，底層子嗣生成與養成一律遵循 C2-R4 確定性管線：
$$\text{Prowess}_{\text{birth}} = \lfloor 0.15 \times P \rfloor, \quad \text{Prowess}_{\text{enroll}} = \lfloor 0.20 \times P \rfloor$$
$$\text{Prowess}_{\text{adult}} = \text{Prowess}_{\text{enroll}} + \Delta A(\text{36 turns}, \text{cap } P)$$
$$H_{\text{tenure}} = 25 + 40 m_1 + 20 m_2$$

### 2. 表層 UI 漸進揭露遮罩函數（Visibility Gate）
定義玩家當前家族里程碑階數為 $M_{\text{stage}} \in \{1, 2, 3, 4\}$，各系統變數在 UI 上的呈現方式由下表控制：

| 底層變數 | $M_{\text{stage}} = 1$（G1 初代） | $M_{\text{stage}} = 2$（G2 二代） | $M_{\text{stage}} = 3$（G3 三代） | $M_{\text{stage}} = 4$（G4+ 門閥） |
|---|---|---|---|---|
| **五維潛力 $P$** | 僅顯示 400/200 鄉評文字（如「武骨不凡」） | 解鎖「潛力條」與 50 箱密查 | 顯示完整「先天上限 $P$ vs 當前覺醒 $A$」 | 同 G3 + 家族歷代均值對比 |
| **10 藍因子與上限 $m$** | 隱藏星數，僅於開蒙/加冠時演出「承襲某特質」 | 解鎖 `1~5★` 星級與「顯性/連攜」上限提示 | 解鎖「純化突破上限 $m$」預覽與研習補救 | 解鎖「宗脈常駐特徵」加成顯示 |
| **族譜視圖** | 僅顯示父母 2 人 | 展開三代 6～14 人竹簡族譜 | 展開 28 祖位共祖掃描高亮（紅框標示外戚同源） | 展開跨家族百年世系網與郡望樹 |
| **近親風險 $h$ 與 $D$** | 隱藏（G1 預設無共祖外婚） | 若發生近婚僅彈出「親緣過近，恐損氣血」文字警告 | 顯示三色燈號【清朗/微躁/鬱結/枯竭】與當胎/殘留風險 | 完整顯示多樣性 $D$ 折減與外婚復壯世代數 |
| **世交相性 $K$** | 隱藏 | 僅顯示兩家交情 $R$（友好度） | 解鎖「累世通家 / 門風契合度 $K$」與【世交合譜】按鈕 | 顯示天下名門聯姻網絡與郡望加成 |

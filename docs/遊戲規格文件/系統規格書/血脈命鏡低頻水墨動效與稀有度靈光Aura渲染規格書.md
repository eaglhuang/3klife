# 血脈命鏡低頻水墨動效與稀有度靈光Aura渲染規格書

> **所屬模組**：`3.7 UI 介面與視覺工程 (BMV3-04 / BMV3-03)`  
> **單一真相來源**：定義血脈命鏡（`BloodlineMirror`）過場與覺醒面板之三大低頻水墨動效、稀有度 Aura 靈光色階映射，以及抗暈眩效能邊界守則。

---

## 1. 命鏡低頻動效設計哲學與約束

血脈命鏡旨在營造「溯源先祖、心神入定」之莊嚴氛圍，動態效果嚴格遵循**「低頻、柔和、無眩目」**守則：
- **禁止高頻頻閃**：動態頻率限制於 $0.4\text{Hz} \sim 0.8\text{Hz}$，單次循環時長 $\ge 2.0$ 秒。
- **限制疊加混合**：嚴禁使用強烈 Additive 爆光模式，一律採用 Normal 或 Soft-Light 柔光混合。

---

## 2. 三大核心水墨動態規格

```
+-------------------------------------------------------+
|  [血脈命鏡: 沉浸式水墨動效空間]                       |
|                                                       |
|  [動效 1: 命鏡水墨霧化] (Tween 0.6s, EaseInOut)       |
|  背景微透水墨煙嵐, 緩慢由中心向四周彌散               |
|                                                       |
|  [動效 2: 定心者呼吸微芒] (週期 2.4s, Alpha 0.25~0.55) |
|  中央金石定心符節隨呼吸律動, 提供凝神視覺焦點         |
|                                                       |
|  [動效 3: 英靈邊緣淡閃] (週期 3.0s, Alpha 0.30)        |
|  英靈輪廓泛起暗金金石光痕, 點到即止不奪立繪主體       |
+-------------------------------------------------------+
```

1. **命鏡水墨霧化（`Mirror Mist Dissolve`）**：
   - 進入介面時，水墨材質自中央裂隙向兩側平滑舒展（歷時 0.6 秒）；
   - 水墨噪點貼圖尺寸固定為 512x512，重用全域快取材質。
2. **定心者呼吸微芒（`Anchor Guiding Breath`）**：
   - 位於鏡面正中央之「定心者（Anchor Mark）」符節，執行低頻的正弦 Alpha 呼吸：
     $$\text{Alpha}(t) = 0.40 + 0.15 \times \sin\left(\frac{2\pi t}{2.4}\right)$$
3. **英靈邊緣淡閃（`Heroic Edge Shimmer`）**：
   - 右側英靈立繪邊界套用薄層金色邊緣光，以 3.0 秒為週期進行微量掃光，光帶寬度不得超過 15 像素。

## 3. 稀有度靈光色階映射（Mirror Rarity Aura）

命鏡外緣之光暈（`mirror-rarity-aura`）根據展示角色之稀有度自動切換色階：

| 稀有度階級 | 色階名稱 | 色彩 Token | 著色器外發光參數 |
|:---:|:---:|:---|:---|
| **UR / 神話** | 太虛紫金 | `#9F7AEA` / `#D69E2E` (雙色漸變) | `Spread: 12px, Intensity: 0.75` |
| **SSR / 絕世** | 璀璨流金 | `#D69E2E` (單色金芒) | `Spread: 10px, Intensity: 0.65` |
| **SR / 豪傑** | 紫微星芒 | `#805AD5` (沉穩典雅紫) | `Spread: 8px, Intensity: 0.55` |
| **R / 精銳** | 深玄青藍 | `#3182CE` (澄澈冷藍) | `Spread: 6px, Intensity: 0.45` |
| **N / 良將** | 素銀玄灰 | `#718096` (古樸素銀) | `Spread: 4px, Intensity: 0.35` |

---

## 4. 效能預算與抗暈眩防護（Motion Sensitivity）

1. **抗暈眩相容**：
   - 若使用者在系統設定開啟「減少動態效果（Reduce Motion）」，三大動效立即退化為靜態水墨底圖，呼吸 Alpha 固定維持在 0.45。
2. **手機 GPU 負載約束**：
   - 動效著色器僅執行單次紋理採樣與通道運算，全屏 GPU 著色時間限制在 **1.2ms 以內**。

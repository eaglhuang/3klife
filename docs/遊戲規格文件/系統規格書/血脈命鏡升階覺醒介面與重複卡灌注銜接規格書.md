# 血脈命鏡升階覺醒介面與重複卡灌注銜接規格書

> **所屬模組**：`3.5 血統、家族與培育傳承 (DUP-04 / SAME-05)`  
> **單一真相來源**：定義武將血脈命鏡升階介面契約、戰魂濃度進度條演算、突破覺醒節點階梯，以及接收重複抽卡「血脈灌注（INFUSION）」之即時演出與資料持久化協議。

---

## 1. 介面架構與職責邊界

血脈命鏡（`MirrorAwakeningComposite`）為人物養成體系之終極覺醒介面，專注於展現武將超凡潛能與先祖戰魂之共鳴：

```
+-------------------------------------------------------+
|  [返回]        血脈命鏡 · 戰魂覺醒         [說明/幫助]  |
+-------------------------------------------------------+
|  [武將立繪/靈氣粒子]       [戰魂階級: 破軍 · 階級 III]    |
|                          戰魂濃度進度條: [=====>   ] 65% |
|  +--------------------+                               |
|  | 覺醒節點 1: 始源  (OK) |  當前灌注增益:             |
|  | 覺醒節點 2: 凝魂  (OK) |   - 全屬性成長率 +15%      |
|  | 覺醒節點 3: 破軍  (OK) |   - 英靈奧義傷害係數 +25%   |
|  | 覺醒節點 4: 通神 (LOCKED)|  - 專屬命篆槽位解鎖        |
|  | 覺醒節點 5: 萬象 (LOCKED)|                          |
|  +--------------------+  下一階突破條件:              |
|                          戰魂濃度達 100% + 洗髓丹x1   |
|  [即時灌注動畫區 / 飄字展示]                            |
|                          [手動灌注道具]  [一鍵突破覺醒] |
+-------------------------------------------------------+
```

## 2. 戰魂濃度與覺醒階階梯演算

### 2.1 戰魂濃度（Soul Concentration）積累
武將命鏡覺醒包含五大突破階級（Stage I ~ V），每一階所需戰魂點數如下：

| 覺醒階級 | 階級名稱 | 升階所需點數 | 重複同名卡折算灌注點數 | 特殊突破材料 |
|:---:|:---:|:---:|:---:|:---:|
| **Stage I** | 始源 (Origin) | 100 pt | R=20 pt / SR=50 pt / SSR=100 pt | 無 |
| **Stage II** | 凝魂 (Cohesion) | 200 pt | 同上 | 無 |
| **Stage III** | 破軍 (Breaker) | 400 pt | 同上 | 精元 x 50 |
| **Stage IV** | 通神 (Divinity) | 800 pt | 同上 | 洗髓丹 x 1 |
| **Stage V** | 萬象 (Pantheon) | 1600 pt | 同上 | 天工精魄 x 1 |

> 當前階級進度百分比公式：  
> $$\text{ConcentrationRate} = \min\left(1.0, \frac{\text{CurrentPoints}}{\text{StageMaxPoints}}\right) \times 100\%$$

### 2.2 重複卡灌注（INFUSION）雙向銜接
當玩家在抽卡重複分流彈窗（`doc_spec_0649`）選擇【血脈灌注（INFUSION）】時，系統直接將點數灌入該武將命鏡：
1. **即時灌注入庫**：
   - 取得目標武將當前 `soulPoints`，累加注入點數（SSR +100 / SR +50 / R +20）。
   - 若溢出當前階級上限，保留溢出點數至下一階，狀態轉為 `READY_TO_BREAKTHROUGH`。
2. **彈窗跳轉與演出連動**：
   - 分流彈窗點擊確認後，若勾選「前往命鏡查看」，無縫開啟 `MirrorAwakeningComposite`。
   - 介面自動觸發金光粒子匯入命鏡鏡面，進度條平滑補間滾動（Tween 0.8s Elastic.Out）。

## 3. 突破覺醒奧義演出契約（Awakening Cutscene）

當戰魂濃度達到 100% 且消耗突破材料時，觸發覺醒演出：
```typescript
export interface AwakeningCutsceneSpec {
  generalUid: string;
  stageFrom: number;
  stageTo: number;
  stageName: string;
  unlockedPerks: Array<{
    perkType: "STAT_GROWTH" | "SKILL_BUFF" | "TALENT_SLOT";
    value: number;
    description: string;
  }>;
  vfxTimeline: {
    mirrorShatterDelayMs: 300;     // 鏡面碎裂震屏
    soulConvergeDelayMs: 800;      // 戰魂凝聚金光
    titleStampDelayMs: 1500;       // 封號命篆蓋印
    durationMs: 2500;              // 總演出時長，支援點擊跳過
  };
}
```

## 4. 資料模型與持久化

```typescript
export interface MirrorAwakeningState {
  generalUid: string;
  currentStage: number;            // 1 ~ 5
  currentPoints: number;           // 當前階已灌注點數
  maxPoints: number;               // 當前階升階門檻
  isBreakthroughReady: boolean;    // 是否可突破
  historyInfusions: Array<{
    sourceType: "DUPLICATE_CARD" | "ITEM_CONSUME";
    pointsAdded: number;
    timestamp: number;
  }>;
}
```

- **單一真相約束**：重複卡灌注只改變武將之 `MirrorAwakeningState`，不產生第二份實體記錄。

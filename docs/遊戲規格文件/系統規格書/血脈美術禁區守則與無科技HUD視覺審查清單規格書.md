## 1. 核心宗旨與設計哲學

本專案血脈與英靈視覺體系，旨在傳達三國歷史之「漢代青銅金石、古籍水墨、上古神話符篆」深邃美感。在 AI 生成與美術外包流程中，極易混入科幻、歐美魔幻或生化實驗室風格。為維護視覺風格純潔性，本規格書制定全域美術生產與審查之**五大絕對禁區（The Five Taboos）**與**自動/人工驗收 Checklist 評分機制**。

---

## 2. 五大絕對禁區守則 (The Five Taboos)

所有涉及武將立繪、命鏡介面、血脈圖騰、特種軍隊與 VFX 粒子特效之資產，凡觸犯以下任一禁區者，一律阻斷入庫並退件重繪：

| 禁區編號 | 禁區名稱 | 嚴格禁止元素 (Prohibited) | 正確替代視覺語言 (Prescribed) |
|---|---|---|---|
| **T-01** | **禁現代生化 DNA 雙螺旋** | DNA 雙螺旋結構、染色體符號、顯微鏡細胞微粒、分子鏈光效。 | 古代族譜雲雷紋、百川歸海之水墨流向、上古靈獸虛影合流。 |
| **T-02** | **禁科幻電子 HUD 與高科技儀表** | 數位準星、全息掃描線、雷達波紋、蜂巢六角護盾、螢幕雜訊、條碼。 | 漢代青銅銘文、玉石刻度盤、篆書墨印、九宮八卦古陣圖。 |
| **T-03** | **禁現代實驗室試管與基因膠囊** | 玻璃試管、注射針筒、燒杯、綠色基因培養槽、生化膠囊。 | 淬煉靈玉、香爐裊裊焚煙、九鼎神火、古銅命鏡照影。 |
| **T-04** | **禁低幼霓虹與賽博龐克光污染** | 高飽和螢光粉紅/亮綠/電光紫、塑膠壓克力反光、霓虹燈管發光。 | 青銅氧化綠、深朱砂紅、玄鐵黑金、素銀流光等金石沉穩色階。 |
| **T-05** | **禁恐怖生化異變與血肉畸形** | 喪屍肉瘤、生化裂痕、觸手、外露神經機械管線、惡魔異化角翼。 | 眉心古篆神印、眼底內斂靈光、甲冑金石暗紋流動。保持名將尊嚴。 |

## 3. 美術資產審查清單 (Checklist) 與評分機制

### 3.1 審查檢核項目

```typescript
export interface ArtReviewChecklist {
  assetId: string;
  category: 'portrait' | 'crest' | 'mirror_ui' | 'vfx' | 'army_flag';
  // 禁區檢查 (違規即一票否決)
  hasNoDnaHelix: boolean;             // T-01 檢查
  hasNoSciFiHud: boolean;             // T-02 檢查
  hasNoModernLabElements: boolean;    // T-03 檢查
  hasNoNeonCyberpunk: boolean;         // T-04 檢查
  hasNoBodyHorrorMutation: boolean;   // T-05 檢查
  // 風格標準
  hanDynastyBronzeAesthetic: boolean; // 具備漢代青銅金石拓印質感
  inkWashIntegration: boolean;        // 水墨流動自然不刺眼
  symbolSlotCompliance: boolean;      // 嚴格依循 bloodline-symbol-slot-contract
}
```

### 3.2 評分標準與裁決公式

1. **基本分數（100 分制）**：
   - 漢代金石與水墨美學契合度：40 分。
   - 符號槽位與規格依循度（Symbol Slot）：30 分。
   - 畫面色彩素雅與層次感（排除光污染）：30 分。
2. **禁區懲處扣分**：
   - 觸犯 T-01 ~ T-05 任一項，直接扣除 40 分，且標記 `CRITICAL_STYLE_VIOLATION`。
   - 觸犯兩項以上，總分直接歸 0。
3. **合格門檻**：
   - 總評分 $\ge 85\text{ 分}$ 且**無任何禁區違規**者判定為 `PASS`；否則判定為 `FAIL`。

## 4. 驗收測試案例 (Test Cases)

- **TC-BVC-04-01【禁區檢測一票否決】**：輸入包含 DNA 雙螺旋旋轉粒子之命鏡動效資產，審查器判定觸犯 T-01，直接給予 `FAIL` 並生成阻斷報告。
- **TC-BVC-04-02【科幻 HUD 元素攔截】**：輸入立繪中含有高科技半透明全息準星之趙雲造型，審查器判定觸犯 T-02，阻斷入庫。
- **TC-BVC-04-03【正向漢風金石過審】**：輸入採用漢代玄武青銅紋樣與眉心微光神印之關羽立繪，各項檢核全數合格，總分 95 分，判定 `PASS`。

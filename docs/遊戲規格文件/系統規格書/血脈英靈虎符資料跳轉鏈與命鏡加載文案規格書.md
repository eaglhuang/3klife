# 血脈英靈虎符資料跳轉鏈與命鏡加載文案規格書

> **文件狀態**：單一真相來源（Single Source of Truth）  
> **系統代碼**：`SPV-04`、`SPV-05`、`SYS-DESTINY-CHAIN-LOADING`  
> **核心職責**：確立武將詳情頁「命/血脈」至英靈卡、虎符裝配與特種部隊之四階資料路由跳轉閉環，規範重複名將血脈灌注（Bloodline Infusion）資料流，以及命鏡（Destiny Mirror）載入期間之古典宿命劇本文案庫。

---

## 1. 四階資料跳轉閉環（The Four-Tier Routing Chain）

玩家在介面中瀏覽武將血統時，遵循單向流暢跳轉與返迴路徑：

```
[1. 武將命頁 (Bloodline)] ──> [2. 英靈卡詳情 (Spirit Card)] ──> [3. 虎符裝配 (Tiger Tally)] ──> [4. 特種軍勢 (Elite Troop)]
     (GeneralDetail)              (SpiritTallyDetail)            (TigerTallyDetail)             (EliteTroopCodex)
```

1. **跳轉憑證（Routing Credentials）**：
   - 每次跳轉一律攜帶當前武將之 `templateId`、`bloodlineId` 與 `sigilPatternId`，確保介面視覺風格、陣營紋章維持一致。
2. **無縫返回堆疊（Back Stack Navigation）**：
   - 各層支援點擊左上角返回或 Android 物理返回鍵，依路由堆疊安全彈出，不重刷上層面板狀態。

---

## 2. 重複卡血脈灌注協定（Bloodline Infusion）

當玩家獲取已達 5 星或已解鎖之重複名將卡片時，分流至「血脈灌注」管道：
- **灌注效益**：
  - 增加該血脈宗族之「功業精華（Essence）」 $+100 \sim 500$ 點。
  - 提升該武將對應英靈卡之初始共鳴契合度 $+5\%$。
  - 若已達上限，全數轉化為「結義點數（Oath Points）」。

## 4. 驗收標準與 CI 閘門（Acceptance Criteria）

1. **跳轉鏈路完整性**：
   - UI 整合測試驗證：從 `GeneralDetail` 進入 `EliteTroopCodex`，四級跳轉均能正確還原 `bloodlineId`。
2. **多語系查表無缺**：
   - 8 句命鏡文案必須 100% 存在於 `zh-TW`、`zh-CN`、`en`、`ja` 字典中，禁止回傳空字串。
3. **單元測試涵蓋**：
   - 包含血脈灌注精華折算公式、上限溢出轉化與路由狀態回溯測試。

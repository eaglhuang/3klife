# 貨幣與資源總規格書

> 來源：使用者 2026-11-21 裁決 #14、#28；任務卡 PROG-2-9218。
> 本檔是**貨幣與資源命名、用途、轉移**的唯一總規格；`doc_spec_0404`（基礎資源四維上限）、`doc_spec_0032`（資源循環）、`doc_spec_1184` §3.5（物品框架的 resource-def）都只引用本檔，不再各自定義貨幣語意。
> 範圍只改規格，不改程式；程式遷移走 §8 實作卡。

## 1. 使用者裁決（11/21，原文）

1. **保留金與銀兩兩種貨幣，各有用途**；只統一糧食命名（PM 定為「糧草」）。
2. **金＝國家**（幕府公庫：征兵、城建、外交等軍政）；**銀兩＝家族**（家業、婚嫁、養子嗣、學府）。
3. **公私可以轉移，但有代價**：家族捐公庫換名望；挪用公庫補家用會降民心或忠誠。

## 2. 資源與貨幣總表（唯一定義）

| 標準 id | 玩家看到的名稱 | 性質 | 持有者 | 主要用途 |
|---|---|---|---|---|
| `gold` | 金 | 國家貨幣 | 幕府公庫（shogunate） | 征兵、城建、外交禮物、軍需處、公庫商店 |
| `silver` | 銀兩 | 家族貨幣 | 家族庫房（clan／household） | 家業、婚嫁聘禮、養子嗣、學府學費、家族商店 |
| `food` | **糧草**（原「糧食」） | 軍政資源 | 幕府公庫（軍需） | 出兵、守城、賑災、義勇營口糧 |
| `troops` | 兵力 | 軍政資源 | 幕府 | 戰場與城防 |
| `fame` | 名望 | 聲望資源（非貨幣） | 幕府 | 家族捐獻換取，影響外交與招賢 |

- `grain` 只是 `food` 的**別名**（舊程式與舊資料殘留），玩家可見文字一律「糧草」，不再出現「糧食」。
- 武將**不持有**任何貨幣；貨幣只掛在公庫或家族庫房（對應 `doc_spec_1184` 的持有者表）。
- 精元、結義點數、求籤令、免費銅錢符、靈玉等**帳號級代幣**不屬於本表，仍由 `doc_spec_0626`／`doc_spec_0464` 管理；轉蛋貨幣與金銀互不兌換。
- 舊 1184 §3.5「silver 是 gold 的別名」**作廢**，以本檔為準。

## 3. 轉移規則（有代價）

兩條轉移各一個命令：`treasury.donate`（§3.1）、`treasury.divert`（§3.2）（本機 adapter 先做，之後換網路 adapter），必須帶 `idemKey`，伺服器權威結算。

### 3.1 家族捐公庫換名望（銀兩 → 公庫金）

| 項目 | 設計值（PM 定，可改 JSON） |
|---|---|
| 兌換 | 捐 1000 銀兩 → 公庫 +800 金（八折，損耗 20%）＋名望 +1 |
| 單季上限 | 每季最多捐 5000 銀兩（名望 +5） |
| 門檻 | 家族庫房餘額不可低於「家業維持金」（見家業規格 1181） |

### 3.2 挪用公庫補家用（公庫金 → 銀兩）

| 項目 | 設計值 |
|---|---|
| 兌換 | 挪 1000 金 → 家族 +1000 銀兩（一比一，但有政治代價） |
| 代價 | 每挪 1000 金：民心 −1；若同時有家臣駐守的城池，家臣忠誠 −1（取代價較重者，不疊加） |
| 單季上限 | 每季最多挪 3000 金（民心最多 −3） |
| 禁區 | 戰時（守城中、出兵中）不可挪用；公庫低於征兵安全線不可挪用 |

兩個比率與上限全放 `data/currency/transfer-rules.v1.json`，數值之後可由企劃調。

## 4. 糧食改名為糧草（全面）

- **玩家可見文字**（UI 字串、劇情、任務、說明書）一律「糧草」。`ResourceCap.ts` 的 `RESOURCE_LABELS.food` 已是「糧草」，其餘殘留依 §7 清單改。
- **內部欄位**：標準 id 是 `food`；`grain` 在邊界轉成 `food`（讀取時別名轉換，寫出時一律 `food`）。
- **舊存檔遷移**：存檔版本升一版；載入舊檔時 `grain → food`、`silver`（舊 `_missionWallet.gold` 語意）依 §6 轉入家族庫房；遷移後寫回新版，並寫一筆 `currency.migrated` 稽核事件。遷移必須冪等（重跑不重複加值）。

## 5. 持有者與框架接入

| 框架 | 接入 |
|---|---|

## 7. 驗收（總規格層）

1. 玩家可見字串搜不到「糧食」（`check-no-legacy-food-label` 檢查腳本，納入 compute-gate）。
2. 轉移命令：額度、禁區、`idemKey` 重送不重複、民心／忠誠／名望變化與 §3 表一致。
3. 舊存檔載入後：`grain` 全轉 `food`、銀兩進家族庫房、金不變；重複載入不重複加值。
4. 公庫商店只扣金，家族商店只扣銀兩；跨用被拒（E303 幣別不符，沿用 1182 錢包碼）。
5. 武將資料不出現貨幣欄位。

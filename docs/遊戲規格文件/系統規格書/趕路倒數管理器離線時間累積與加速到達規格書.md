# 趕路倒數管理器離線時間累積與加速到達規格書

## 1. 核心定位與設計理念
本規格書定義三國生活（3KLife）新手開場與常態玩法之「武將/紅顏趕路倒數管理器（CountdownManager）」運算規格（對應 WBS `OPEN-11` 與 `PROG-2-0469`）。
趕路倒數作為營造天下廣袤、武將長途奔襲與即時期待感之核心設計，堅持**絕對時間戳記、離線自然流逝、確定性加速**原則：
1. **絕對時間戳記存檔**：以毫秒級絕對時間戳記（`startTimestamp`, `finishTimestamp`）記帳，嚴禁每幀每秒計數器累加。
2. **離線時間自然計入**：玩家關閉 App 離線期間，真實時間自然推進，重新登入無需伺服器額外校正補時。
3. **主畫面常駐浮標解耦**：倒數狀態與 UI 完全解耦，透過純函式查詢驅動主城大廳浮動提示圖示。

---

## 2. 絕對時間模型與狀態計算 (`CountdownSnapshot`)
倒數狀態由純資料結構記錄：
```typescript
export interface CountdownState {
    targetId: string;          // 趕路目標 ID（如紅顏 'zhen-ji'）
    startTimestamp: number;   // 啟程時間戳（毫秒）
    finishTimestamp: number;  // 預計抵達時間戳（毫秒）
    canAccelerate: boolean;    // 是否允許道具或付費加速
    accelerated: boolean;      // 是否已被加速完成（立即到達）
}

export type CountdownStatus = 'traveling' | 'arrived';

export interface CountdownSnapshot {
    status: CountdownStatus;
    remainingMs: number;
}
```

### 2.1 倒數狀態即時快照演算法 (`countdownStatus`)
傳入伺服器或系統當前時間 `nowMs`：
- **到達判定**：若 `state.accelerated === true` 或 $\text{nowMs} \ge \text{state.finishTimestamp}$：
  $$\text{status} = \text{'arrived'}, \quad \text{remainingMs} = 0$$
- **趕路中判定**：若尚未到達且未被加速：
  $$\text{status} = \text{'traveling'}, \quad \text{remainingMs} = \text{state.finishTimestamp} - \text{nowMs}$$

---

## 3. 即時加速與狀態變更 (`rushCountdown`)
在支援加速的場景下，玩家可使用道具或消耗貨幣提前結束趕路：
- **加速成功條件**：
  $$\text{CanRush} = (\text{status} = \text{'traveling'}\ \land\ \text{state.canAccelerate} = \text{true})$$
- **狀態遷移**：
  加速成功後，回傳新狀態 `{ ...state, accelerated: true }`，下次查詢狀態立即回傳 `arrived`，剩餘時間即刻為 0。
- **異常防呆**：
  - 若已到達時嘗試加速，拒絕並回傳 `already-arrived`。
  - 若目標不可加速（`canAccelerate = false`），拒絕並回傳 `cannot-accelerate`。
  - 加速函式不直接扣款，扣款邏輯由業務協調層處理。

## 4. 主畫面常駐浮標與開場預設配置
- **常駐圖示顯隱 (`shouldShowResidentIcon`)**：
  大廳場景只在 $\text{status} = \text{'traveling'}$ 時於主介面常駐懸掛「快馬加鞭」氣泡圖示；到達時圖示轉變為驚嘆號，點擊觸發拜會演出。
- **新手開場第四幕預設規格**：
  - **目標人物**：紅顏甄姬（`OPENING_TRAVEL_TARGET_ID = 'zhen-ji'`）。
  - **趕路時長**：3 小時（$\text{OPENING\_TRAVEL\_DURATION\_MS} = 3 \times 3600 \times 1000\text{ ms}$）。
  - **加速權限**：開啟加速（`canAccelerate = true`）。

## 5. Unity 與 Cocos Creator 概念對照
| 概念維度 | Cocos Creator 實作架構 | Unity 引擎對照架構 |
| :--- | :--- | :--- |
| **離線時間計算** | `Date.now()` 比對 `finishTimestamp` 毫秒戳 | `DateTime.UtcNow` 比對目標時間，避免 deltaTime 漂移 |
| **浮標視圖綁定** | `CountdownIconView` 綁定狀態並每秒刷新 Label | `MonoBehaviour` 搭配 TextMeshPro 顯示倒數時間 |
| **不可變防污染** | 純函式建立與過濾，每次回傳新物件副本 | C# 唯讀結構體 `readonly struct CountdownData` |

## 6. 驗證條件與測試矩陣 (Acceptance Gate)
1. **TC-COUNTDOWN-01 離線時間自然累積**：設定 10 秒倒數，模擬 15 秒後再次查詢，驗證狀態為 `arrived` 且剩餘 0 毫秒。
2. **TC-COUNTDOWN-02 即刻加速成功到達**：在趕路進行中呼叫 `rushCountdown`，驗證 `accelerated = true` 且狀態立即切換為 `arrived`。
3. **TC-COUNTDOWN-03 拒絕無效加速**：對已到達或禁止加速之倒數發起加速，驗證回傳拒絕原因且狀態不變。
4. **TC-COUNTDOWN-04 存檔正規化過濾**：傳入目標為空、終點早於起點或非數值時間戳，驗證回傳 `null` 防止髒資料。

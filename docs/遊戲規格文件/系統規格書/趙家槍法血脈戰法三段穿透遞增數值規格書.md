# 趙家槍法血脈戰法三段穿透遞增數值規格書

## 1. 核心定位與識別契約

本規格書為「趙家槍法」（`TAC_ZHAO_SPEAR` / 戰鬥技能識別碼 `zhao-yun-pierce`）的單一真相來源（Single Source of Truth）。本技能屬於血脈專屬戰法（`SkillSourceType.Bloodline`），象徵常山趙氏世代相傳的槍道真諦。

```typescript
export interface ZhaoSpearSkillContract {
  skillId: 'TAC_ZHAO_SPEAR';
  battleSkillId: 'zhao-yun-pierce';
  sourceType: SkillSourceType.Bloodline;
  bloodlineTag: 'BLOOD_ZHAO';
  ancestorRequirement: 'zhao-yun';
}
```

---

## 2. 幾何範圍與彈道選取契約

趙家槍法為直線穿透型打擊，施放時無視前方阻擋單位直接貫穿路徑上所有敵軍，不套用一般穿透衰減（`falloffRule: 'none'`）。

1. **射程與形狀**：
   - 目標模式：`BattleSkillTargetMode.Line`
   - 直線長度：3 格（`lineLength: 3`）
   - 最大命中目標上限：4 名敵軍單位（`maxTargets: 4`）
2. **自動索敵傾向（AI Cadence）**：
   - 索敵模式：`autoAimMode: 'densest-line'`（優先朝向直線 3 格內涵蓋最多敵方部隊之軸向施放）
   - 手動鎖定：`manualTargeting: false`（戰略瞬發）

---

## 3. 三段獨立連擊與遞增數值模型

趙家槍法在單次施放中，對有效射程內的所有命中目標連續發動三次獨立槍芒打擊，每段結算皆套用嚴格遞增係數。

### 3.1 遞增階段倍率（Hit Stage Multipliers）

$$\text{Multipliers} = [1.0, 1.2, 1.4]$$

- **第一段（初始穿透）**：係數 $1.0\times$，基礎傷害折算。
- **第二段（槍勢深入）**：係數 $1.2\times$（實測值為第一段傷害之 $\lfloor \text{Stage}_0 \times 1.2 \rfloor$）。
- **第三段（貫日破防）**：係數 $1.4\times$（實測值為第一段傷害之 $\lfloor \text{Stage}_0 \times 1.4 \rfloor$）。

### 3.2 傷害結算公式

每段傷害 $D_{\text{stage}}(s)$ 計算如下：

$$D_{\text{base}} = \lfloor (\text{STR} \times 0.8) \times \left(1 - \frac{\text{DEF}_{\text{effective}}}{\text{DEF}_{\text{effective}} + 100}\right) \rfloor$$

$$D_{\text{stage}}(s) = \lfloor D_{\text{base}} \times M_s \rfloor \quad (s \in \{0, 1, 2\}, M = [1.0, 1.2, 1.4])$$

- 基礎縮放屬性：武力（`scalingStat: 'str'`）。
- 戰法傷害係數：`coefficient: 0.8`。
- 每段獨立判定爆擊與防禦抗性；若第一段未暴擊而第三段暴擊，暴擊增幅（$1.5\times$）與階段倍率（$1.4\times$）採乘法疊加。

## 4. 血統限制與出陣裝備約束

趙家槍法受嚴格門閥血統保護，嚴禁外族武將擅自裝備。

1. **出陣檢核前置**：
   - 武將個體屬性必須具備血脈標籤 `BLOOD_ZHAO`，或在傳承譜系（`Ancestors`）中溯源包含名將趙雲（`zhao-yun`）。
   - 若武將血統不符，於編制介面（SortieDeploy）中強制隱蔽或灰化禁用，點擊提示「非趙氏血脈不可修行此槍法」。
2. **教官指引與靈感繼承**：
   - 在學府系統中，若名將趙雲作為教官，唯有具備趙氏宗族標籤之子嗣於頓悟時方可解鎖 `TAC_ZHAO_SPEAR` 傳承。

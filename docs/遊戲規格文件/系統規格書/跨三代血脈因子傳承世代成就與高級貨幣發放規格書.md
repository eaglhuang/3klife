# 跨三代血脈因子傳承世代成就與高級貨幣發放規格書

## 1. 核心定位與設計理念
本規格書定義三國生活（3KLife）留存與血統家族系統之「跨三代血脈因子隔代傳承成就（Legacy Achievement）與靈玉獎勵發放」機制規範（對應 WBS `RET-07` 與 `PROG-2-1429`）。
世代成就作為鼓勵玩家深耕多代培育、維繫家族血脈延續與達成百年門閥之最高榮譽指標，堅持**世代差門檻、因子顯性驗證、一次性高額獎勵**原則：
1. **跨三代隔代傳承門檻**：後代武將與祖先之間的世代差（Generation Gap）必須大於或等於 3 代（即曾祖輩以上）。
2. **血脈因子顯性遺傳檢驗**：後代武將之顯性因子清單中，必須包含該祖先所擁有的特定核心因子。
3. **高級貨幣（靈玉）高額激勵**：每達成一項跨三代遺傳成就，直接核發高級貨幣（靈玉）100 枚，全額反哺轉蛋與名士尋訪。

## 2. 世代成就判定演算法 (`legacyAchievementsOf`)
系統傳入祖譜圖介面 `BloodlineGraph`、後代 UID 與因子查詢函式，依序比對：

```typescript
export interface LegacyReward {
    currency: 'premium';
    amount: number;             // 固定獎勵 100 靈玉
}

export interface LegacyAchievement {
    descendantUid: string;      // 達成成就之後代 UID
    ancestorUid: string;        // 因子來源之祖先 UID
    geneId: string;             // 傳承之因子 ID
    generationGap: number;      // 世代差距（≥ 3）
    reward: LegacyReward;
}
```

### 2.1 判定三部曲與防刷限制
1. **世代差校驗 (`LEGACY_MIN_GENERATION_GAP = 3`)**：
   遍歷祖譜槽位 `PEDIGREE_SLOTS`，計算代差 $\Delta G = \text{pedigreeSlotGeneration}(slot)$。若 $\Delta G < 3$，直接略過。
2. **祖先因子交集比對**：
   比對祖先因子清單與後代因子清單：
   $$\text{InheritedGenes} = \text{DescendantGenes} \cap \text{AncestorGenes}$$
3. **同子嗣同因子去重保護 (`seenGenes`)**：
   同一個後代武將若從父系曾祖父與母系曾祖父同時繼承相同因子，該因子在該後代身上**僅計算一次成就**，絕不重複發獎。

## 3. 高級貨幣發放與錢包入帳 (`grantLegacyRewards`)
- **發放標準常數**：
  `LEGACY_PREMIUM_REWARD = 100`（高級付費貨幣靈玉）。
- **純函式錢包結算**：
  ```typescript
  export function grantLegacyRewards(
      base: Readonly<GachaWalletSave>,
      achievements: readonly LegacyAchievement[]
  ): { wallet: GachaWalletSave; granted: number }
  ```
  計算所有成就之獎勵總額，回傳更新後之全新錢包副本（`wallet.gems = base.gems + granted`），不修改傳入之原始錢包物件。
- **成就計數器 (`normalizeLegacyCount`)**：
  玩家個人存檔記錄累計達成之世代傳承次數 `Legacy_Count`，數值強制為非負整數。

## 5. 驗證條件與測試矩陣 (Acceptance Gate)
1. **TC-LEGACY-01 跨三代成功判定**：世代差為 3（曾祖父）且後代遺傳祖先「龍膽」因子，驗證成功生成成就且獎勵 100 靈玉。
2. **TC-LEGACY-02 世代差不足阻斷**：世代差為 2（祖父）即使遺傳因子，驗證成就清單為空。
3. **TC-LEGACY-03 雙親重複因子去重**：後代同時繼承雙親曾祖父同款因子，驗證成就只觸發 1 次（100 靈玉）。
4. **TC-LEGACY-04 錢包無副作用入帳**：基礎錢包 500 靈玉，傳入 2 項成就，驗證回傳新錢包 700 靈玉且原錢包維持 500。

# 3KLife 車輪踏板水車戰艦人踩輪楫逆流疾馳動力狀態機規格書

## 1. 模組概述與核心定位
本模組為 3KLife 水戰機械工程與新型動力系統（`PADDLE-WHEEL-SHIP01`）。重現三國末期工匠與荊襄造船廠所探索之「輪槳車船（踏板水車戰艦）」：於船體兩舷或尾部安裝多組帶葉輪槳，艙內由數十名健勇水手踩踏踏板，經木質青銅齒輪箱傳動帶動輪槳翻轉撥水。具備不依賴風力、可於狹窄水道原地轉向、以及強行逆流全速突擊之機動優勢。

## 4. 輪槳推力、逆流克服與差速操舵公式

### 4.1 踏輪連續推進航速演算法
車輪戰船在逆流中之實際推進速度：
$$V_{\text{actual}} = \left(\frac{\text{TreadingCrewCount} \times 0.25}{1.0 + \text{DisplacementTons}/50}\right) \times \left(1.0 - \frac{|\vec{V}_{\text{water}}|}{8.0}\right) \times \text{WheelEfficiency}$$
- 相比傳統搖櫓槳船，輪槳連續打水效率提升 $45\%$；
- 遭遇長江三峽 3 m/s 之狂浪急流時，依然能以 2.5 m/s 強行逆水穿插。

### 4.2 左右兩舷差速掉頭靈活性
一舷正轉、一舷反轉時之迴旋力矩：
$$R_{\text{turn}} = \max\left(1, \left\lfloor 3.0 - \text{WheelPairsCount} \times 0.3 \right\rfloor\right)$$
- 轉向半徑僅為同體積戰艦之三分之一，在水戰中可輕易切入敵方樓船之船尾死角實施撞擊。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-PADDLE-01**：在無備用輪換水手之情況下，車船全速踩踏持續超過 3 回合後，水手陷入極度虛脫，航速驟降 $70\%$。
2. **驗收 CASE-PADDLE-02**：輪槳若遭水下漂浮巨木或敵方鐵刺網捲入，齒輪箱立即觸發 `MECHANICAL_FAULT`，推進力清零。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

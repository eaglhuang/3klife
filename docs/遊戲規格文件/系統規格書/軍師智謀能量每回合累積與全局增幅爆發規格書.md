# 軍師智謀能量每回合累積與全局增幅爆發規格書

## 1. 核心定位與能量契約

本規格書為軍師戰場智謀能量系統（Strategist Wisdom Meter，代號 `SCN-10`）的單一真相來源（Single Source of Truth）。在戰役進行中，軍師主將運籌帷幄，隨回合推移持續匯聚智謀能量，並在達到能量臨界點時引發「全局增幅（Wisdom Surge）」，扭轉戰場態勢。

```typescript
export interface WisdomMeterContract {
  maxMeter: 100;                  // 能量槽上限 100 點
  gainRatioPerTurn: 0.5;          // 每回合累積 INT × 0.5
  surgeMoraleBonus: 20;           // 滿格觸發全體士氣 +20
  meterResetOnTrigger: true;      // 觸發後能量歸零
}
```

---

## 2. 每回合智謀能量累積演算法

在每個大回合結束、切換至次回合準備階段時（`advanceTurn`），由 `BattleController` 調用 `advanceWisdomMeter`：

### 2.1 累積增量公式

$$\Delta_{\text{meter}} = \max(0, \text{INT}_{\text{player}}) \times 0.5$$

$$\text{Meter}_{\text{next}} = \text{Meter}_{\text{current}} + \Delta_{\text{meter}}$$

- **智力縮放**：高智力軍師匯聚能量速度顯著加快。例如諸葛亮（智力 100）每回合累積 50 點，僅需 2 回合即可滿格爆發；一般武將（智力 60）每回合累積 30 點，需 4 回合爆發。
- **負值防護**：若因減益效果導致智力小於 0，能量增量強制保底為 0，不扣除既有能量。

### 2.2 滿格觸發與歸零狀態機

- **臨界判定**：若 $\text{Meter}_{\text{next}} \ge 100$：
  - 狀態機標記 `triggered = true`。
  - 當前能量立即重置歸零（`meter = 0`），重新開始下一輪循環。
- **未滿過渡**：若 $\text{Meter}_{\text{next}} < 100$：
  - 狀態機標記 `triggered = false`。
  - 當前能量更新為 $\text{Meter}_{\text{next}}$。

---

## 3. 全局增幅效果（Wisdom Surge）

當 `triggered == true` 時，戰場管線立即執行 `applyWisdomSurge`：

1. **增益對象**：該陣營當前存活的所有部隊單位（排除已潰滅單位）。
2. **鼓舞士氣增幅**：
   - 每支部隊強制附加士氣 $+20$ 點（`WISDOM_SURGE_MORALE = 20`）。
   - 依據士氣戰鬥系統規則，部隊攻擊力提升 $+20\%$，持續 3 回合，效果不遞歸疊加。
3. **戰鬥記錄輸出**：
   - 輸出全域金色公告：`WISDOM_SURGE_LOG`（「智謀滿格：我方全軍鼓舞，士氣 +20」）。

---

## 4. HUD 視覺與計量條渲染契約

1. **垂直能量條渲染**：
   - HUD 右側介面常駐垂直能量計量槽，依據 `wisdomFillRatio(meter)` 即時更新：
     $$\text{FillRatio} = \frac{\text{clamp}(\text{meter}, 0, 100)}{100}$$
2. **文字動態格式**：
   - 能量文字格式化為：`智謀 {Math.floor(meter)}/100`。
3. **滿格粒子演出**：
   - 當能量由 99 躍升至 100 觸發瞬間，能量槽播放金色光芒爆破粒子（VFX Burst），並向全體存活友軍投射金色光點連線。

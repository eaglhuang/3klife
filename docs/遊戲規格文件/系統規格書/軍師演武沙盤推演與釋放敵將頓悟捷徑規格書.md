# 軍師演武沙盤推演與釋放敵將頓悟捷徑規格書

> **文件狀態**：單一真相來源（Single Source of Truth）  
> **系統代碼**：`LVL-13`、`SYS-TACTICIAN-WARGAME-EPIPHANY`  
> **核心職責**：確立軍師演武模式（沙盤推演，零兵糧消耗、產出演武筆記）之推演閉環，裁定合戰生擒敵將時「以德服人·釋放敵將（Q50=D）」之頓悟捷徑門檻、好感躍升與專屬戰法靈感獲取協定。

---

## 1. 軍師演武沙盤推演機制（Tactician Wargame）

軍師演武為宗族府邸與行軍帳中之虛擬兵棋沙盤推演，供玩家驗證配裝與走位：
1. **零消耗驗證鐵律**：
   - 進入演武模式**不消耗任何真實兵力、糧草儲備與武將精力（Vitality）**。
   - 戰鬥中陣亡或戰損在退出演武時即刻無損重置，絕不寫入主存檔。
2. **演武產出（Wargame Output）**：
   - 通過特殊演武殘局（如「背水一戰」、「子午奇襲」）可產出【演武筆記】（War Notes）。
   - 演武筆記可交付書院教官，轉化為戰術經驗或解鎖稀有戰法槽位。

---

## 2. 釋放敵將頓悟捷徑門檻（Q50=D 裁決）

在一般戰役大捷生擒敵方名將時，系統提供【斬首示眾】、【收押索贖】與【釋放敵將】三項抉擇：

```
[合戰擒獲敵將] ──(抉擇: 以德服人釋放)──> [好感度躍升 +20] ──> [滿足智謀/德行門檻] ──> [直接觸發【七日頓悟】]
```

### 2.1 裁決門檻與收益公式
若玩家選擇「釋放敵將（Release Captive）」且滿足下列門檻，立即解鎖頓悟捷徑：
- **門檻條件**：
  1. 我方主將魅力值 $\text{CHA} \ge 75$ 或宗族具備【仁義傳家】家風。
  2. 敵將性格非【狼性反覆】（如呂布不可觸發釋放頓悟，僅增加敵意）。
- **即時獎勵收益**：
  - 與該名將之個人好感度一次性 $+20$ 點。
  - **戰法靈感頓悟**：主將直接獲得該敵將之 1 條固有戰法【靈感筆記】（如釋放關羽獲得《春秋刀法·意》），省去 30 回合繁複拜會。

## 3. TypeScript 邏輯契約範例

```typescript
export interface ReleaseCaptiveContext {
  playerGeneralCha: number;
  playerHasBenevolenceTrait: boolean;
  enemyGeneralTemplateId: string;
  enemyGeneralPersonality: string;
  enemySignatureTacticId: string;
}

export interface ReleaseCaptiveResult {
  affinityGain: number;
  epiphanyTriggered: boolean;
  grantedTacticNoteId?: string;
}

export function handleReleaseCaptive(ctx: ReleaseCaptiveContext): ReleaseCaptiveResult {
  if (ctx.enemyGeneralPersonality === 'Treacherous_Wolf') {
    return { affinityGain: -10, epiphanyTriggered: false };
  }
  const isQualified = ctx.playerGeneralCha >= 75 || ctx.playerHasBenevolenceTrait;
  return {
    affinityGain: 20,
    epiphanyTriggered: isQualified,
    grantedTacticNoteId: isQualified ? `NOTE_${ctx.enemySignatureTacticId}` : undefined
  };
}
```

## 4. 驗收標準與 CI 閘門（Acceptance Criteria）

1. **演武零消耗隔離性**：
   - 單元測試驗證演武模式結算後，玩家庫存兵糧與武將體力嚴格保持原值不變。
2. **Q50 裁決分支測試**：
   - 魅力 $\ge 75$ 釋放敵將必出頓悟靈感筆記；狼性武將不可觸發且扣好感。
3. **筆記轉換入庫**：
   - 獲取之靈感筆記正確加入 `PlayerInventory` 並可交付教官解鎖。

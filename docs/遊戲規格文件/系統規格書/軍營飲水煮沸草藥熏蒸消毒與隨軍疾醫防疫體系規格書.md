# 3KLife 軍營飲水煮沸草藥熏蒸消毒與隨軍疾醫防疫體系規格書

## 1. 模組概述與核心定位
本模組為 3KLife 軍團後勤醫療衛生與非戰減員防禦系統（`CAMP-HYGIENE-01`）。重現古代名將治軍嚴格之防疫規範：飲水必須煮沸方可飲用、熟食分食、營廁深挖百步外定期生石灰覆土、全營定時以艾草與蒼朮熏蒸防瘴氣。搭配隨軍疾醫營與金創藥材儲備，大幅消弭南征北伐中之瘧疾、傷寒與化膿破傷風。

## 4. 衛生增益、感染控制與非戰減員公式

### 4.1 傷口感染與破傷風致死率公式
負傷士卒在戰後救治時之感染率：
$$\text{InfectionRate} = \left(0.35 - \frac{\text{SanitationBonus}}{100}\right) \times \left(1.0 - \frac{\text{DoctorChiefSkill}}{150}\right)$$
- 實施白布蒸煮與熱水洗創，$\text{SanitationBonus} = 25$；
- 使用金創藥（三七、白及），感染率再降 $40\%$；
- 避免因金創化膿導致名將暴卒。

### 4.2 營盤疫病全面豁免評定
在 `PRISTINE_HYGIENE` 等級下：
$$\text{ImmunityRating} = \min\left(95, 40 + \text{MedicOfficerCount} \times 2 + \text{DoctorChiefSkill} \times 0.4\right)$$
- 即使部隊行經長江夏日濕熱或南蠻煙瘴之地，疫病染病機率強制下壓 $95\%$；
- 敵方投石拋擲腐屍時，全營自動啟動消殺阻斷，大疫爆發機率降至最低。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-HYGIENE-01**：大軍在夏季未執行飲水煮沸條令時，每回合有 $5\% \sim 10\%$ 士卒出現腹瀉嘔吐，行軍速度降低 $40\%$。
2. **驗收 CASE-HYGIENE-02**：隨軍疾醫長若由張仲景、華佗或董奉擔任，全軍傷兵重傷致殘率強制減免 $80\%$，傷癒歸隊速度翻倍。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

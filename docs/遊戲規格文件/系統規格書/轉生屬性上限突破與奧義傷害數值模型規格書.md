# 轉生屬性上限突破與奧義傷害數值模型規格書

> **文件狀態**：單一真相來源（Single Source of Truth）  
> **系統代碼**：`NUM-09`、`SYS-REINCARNATION-ULT-MODEL`  
> **核心職責**：確立武將歷經轉生（Reincarnation）後五維屬性上限突破階梯（REINCARNATION_CAP）、奧義基礎威力（Base Power 200~700）與等級加成乘區公式，以及施放奧義時精力消耗階梯數值模型。

---

## 1. 轉生屬性上限突破模型（REINCARNATION_CAP）

### 1.1 五維單項突破階梯
武將未轉生（0 轉）之單項屬性預設天花板為 100 點。每次成功完成命運輪迴或涅槃轉生，依轉生次數（$R \in [0, 5]$）擴充上限：
$$\text{StatCap}(R) = \min(125, \; 100 + R \times 5)$$

| 轉生階數 ($R$) | 稱謂標識 | 單項屬性上限 | 五維總量理論上限 | 轉生資格條件 |
|:---:|:---:|:---:|:---:|---|
| **0 轉** | 凡胎之身 | 100 | 500 | 初始狀態 |
| **1 轉** | 初窺天命 | 105 | 525 | 巔峰期退休且名聲 $\ge 1000$ |
| **2 轉** | 脫胎換骨 | 110 | 550 | 宗族功業傳承 $\ge 2$ 代 |
| **3 轉** | 超凡入聖 | 115 | 575 | 覺醒至少 2 個金色或專屬因子 |
| **4 轉** | 無雙真武 | 120 | 600 | 歷經重大歷史合戰斬將 $\ge 3$ 次 |
| **5 轉** | 天命極限 | 125 | 625 | 百年門閥大宗主，5 轉滿溢封頂 |

## 2. 奧義傷害計算公式與乘區拆解

### 2.1 核心傷害算式
奧義傷害（$\text{UltDamage}$）由基礎威力（Base Power）、技能等級乘區與主導屬性加成乘區三項複合決定：
$$\text{UltDamage} = \text{BasePower} \times \left(1 + (\text{Level} - 1) \times 0.15\right) \times \left(1 + \frac{\text{Stat}_{\text{scaling}}}{100}\right) \times M_{\text{counter}}$$

- **基礎威力 (BasePower)**：依奧義位階分佈於 $200 \sim 700$ 點。
  - 單體爆發（USINGLE / UBURST）：$450 \sim 700$
  - 範圍群傷（UAREA）：$300 \sim 480$
  - 全體控場/輔助（UCONTROL / UTEAMBUFF）：$200 \sim 350$
- **等級成長 (Level Scaling)**：每升 1 級提供 $+15\%$ 獨立增傷係數。
- **主導屬性修正 ($\text{Stat}_{\text{scaling}}$)**：物理戰法取 $\text{WAR}$，計策奧義取 $\text{INT}$，指揮光環取 $\text{LDR}$。
- **剋制係數 ($M_{\text{counter}}$)**：依兵種剋制與屬性關係取 $0.8 \sim 1.2$。

## 3. 奧義精力階梯消耗規範

施放奧義須扣減武將當前精力（Vitality），精力不足時禁止施放：

| 奧義類別 | 基礎威力區間 | 基礎精力消耗 (Vitality) | 最小釋放精力門檻 | 特殊減免機制 |
|---|:---:|:---:|:---:|---|
| **戰術輔助/小奧義** | $200 \sim 350$ | 30 | 35 | 持有綠色天賦因子：扣減 20% |
| **陣線突破/中奧義** | $351 \sim 500$ | 50 | 55 | 處於氣運共鳴狀態：扣減 15% |
| **決戰滅絕/大奧義** | $501 \sim 700$ | 70 | 75 | 家傳奧義標記：扣減 20% |

## 4. TypeScript 數值演算模組

```typescript
export interface UltimateCalculationInput {
  basePower: number;
  level: number;
  scalingStatValue: number;
  counterMultiplier: number;
}

export function computeUltimateDamage(input: UltimateCalculationInput): number {
  const levelMod = 1 + Math.max(0, input.level - 1) * 0.15;
  const statMod = 1 + input.scalingStatValue / 100;
  const rawDamage = input.basePower * levelMod * statMod * input.counterMultiplier;
  return Math.floor(rawDamage);
}

export function getReincarnationStatCap(reincarnationLevel: number): number {
  const level = Math.max(0, Math.min(5, reincarnationLevel));
  return 100 + level * 5;
}
```

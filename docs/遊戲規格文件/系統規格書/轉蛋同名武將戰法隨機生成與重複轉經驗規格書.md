# 轉蛋同名武將戰法隨機生成與重複轉經驗規格書

## 1. 核心定位與設計理念
本規格書定義三國生活（3KLife）轉蛋系統之「同名武將重複抽取戰法隨機生成、空槽裝填與重複轉經驗值」機制規範（對應 WBS `GCH-07` 與 `PROG-2-1168`）。
戰法隨機化機制旨在賦予重複抽卡戰略差異化與長線技能升級價值，堅持**固有保全、重複增長、安全裝填**原則：
1. **固有第1戰法絕對保全**：武將之標誌性專屬戰法（`slot-1`）與靈感戰法嚴格排除於隨機池外，不可被隨機替換。
2. **重複戰法等額轉化經驗**：抽中已習得戰法時，自動折算為戰法經驗值提升技能等級，零技能浪費。
3. **無損裝填與溢出捨棄**：依序裝填第 2、第 3 戰法槽位；滿槽時未習得戰法安全捨棄，不覆蓋玩家既有技能配置。

---

## 2. 戰法候選池與抽取模型 (`rollPullTactics`)

### 2.1 隨機候選池定義 (`TACTIC_RANDOM_POOL`)
隨機抽樣來源取自通用戰法庫，並實施兩道過濾：
- **排除靈感戰法**：名稱前綴為 `tactic-insp-*` 之特殊劇情或靈感戰法嚴格排除。
- **排除固有第一戰法**：抽樣時傳入武將當前第一槽位戰法代碼，嚴格禁止重複擲出專屬戰法。
- **抽取數量**：每次隨機抽取 2 招不重複戰法，分別對應第 2 槽（`slot-2`）與第 3 槽（`slot-3`）。

---

## 3. 戰法槽裝填與經驗升級演算法 (`applyPulledTactics`)
系統依據擲出的戰法陣列，純函式處理武將技能槽與經驗字典：

```typescript
export interface PulledTacticsResult {
    tacticSlots: GeneralTacticSlotConfig[];
    tacticExp: Record<string, number>;
    filled: string[];          // 成功裝入空槽的戰法
    convertedToExp: string[];  // 重複並轉成經驗的戰法
    discarded: string[];       // 槽滿且未持有而捨棄的戰法
}
```

### 3.1 重複戰法轉經驗值 (`TACTIC_DUPLICATE_EXP`)
- 若抽出之戰法已存在於武將之 `tacticSlots` 之中：
  - 該戰法經驗值 $+100$：$\text{tacticExp}[\text{id}] \leftarrow \text{tacticExp}[\text{id}] + 100$。
  - **經驗封頂限制**：最高經驗上限為滿級所需經驗，即 $(5 - 1) \times 100 = 400$ 點。
- **戰法等級計算公式 (`tacticLevelOf`)**：
  $$\text{Level} = \min\left(5,\, 1 + \left\lfloor \frac{\max(0,\, \text{Exp})}{100} \right\rfloor\right)$$
  等級區間嚴格夾於 1 至 5 級。

### 3.2 空槽裝填與滿槽防護
- 若抽出之戰法尚未習得：
  - 若 `slot-2` 或 `slot-3` 尚有空缺，依序補入空槽，並標記來源 `{ source: 'gacha' }`，記入 `filled` 清單。
  - 若兩個戰法槽均已被其他戰法佔滿，系統安全將該技能移入 `discarded` 清單，絕不強制替換既有戰法。

## 4. Unity 與 Cocos Creator 概念對照
| 概念維度 | Cocos Creator 實作架構 | Unity 引擎對照架構 |
| :--- | :--- | :--- |
| **純邏輯結算** | `TacticRandomization.ts` 靜態工具函式，吃入資料與 RNG 回傳新結構 | 靜態工具類 `TacticRandomizer`，無副作用純計算 |
| **槽位結構** | `GeneralTacticSlotConfig` 物件陣列（`slotId`, `tacticId`, `source`） | C# struct `TacticSlot` 包含列舉與技能參照 |
| **經驗成長** | 扁平字典 `Record<string, number>` 儲存經驗值 | 序列化字典或 `List<TacticProgress>` 存檔結構 |

## 5. 驗證條件與測試矩陣 (Acceptance Gate)
1. **TC-GCH07-01 固有戰法絕對排除**：驗證抽樣結果絕不包含武將固有之 `slot-1` 戰法與 `tactic-insp-*` 戰法。
2. **TC-GCH07-02 重複抽取經驗提升**：連續抽中已持有之戰法 4 次，驗證經驗值依序為 100、200、300、400，等級升至滿級 5 級。
3. **TC-GCH07-03 空槽平滑裝填**：新武將僅有 `slot-1`，抽到 2 招新戰法後驗證 `slot-2` 與 `slot-3` 正確補齊。
4. **TC-GCH07-04 滿槽無損捨棄**：3 槽皆滿武將抽到全新戰法，驗證技能槽無變更且新戰法被納入 `discarded`。

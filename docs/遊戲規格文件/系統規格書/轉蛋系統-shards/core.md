## A. 系統描述

採用「三池分工轉蛋制」（2026-11-15 裁定以 FEM-03 doc_spec_0645 為準）：`三國名將池` 負責抽取可直接培養與上陣的名將本體，`紅顏天香池` 負責抽取可結緣、繁衍的女性武將，`支援卡（教官）池` 負責抽取培育用的教官卡。三池用途不同，但都屬於正式商業化抽卡入口。

正式共識如下：

1. 轉蛋系統**不產出**英靈卡與虎符卡。
2. 英靈卡與虎符卡統一由名將死亡結算產出。
3. 名將生前退役只進教官 / 傳承路徑，不直接從轉蛋或退役流程拿卡。
3-b. **轉蛋預設無虎符**：玩家從轉蛋獲得的武將，基本出廠都不會自帶虎符軍隊。唯有透過長期培育且該武將死亡結算時，才會留下專屬的虎符遺產。
4. 女性武將另立 `紅顏天香池`，貨幣、機率、保底與起始好感依 FEM-03，保底與他池分開。
5. 女將以 `Female_Role_Type` 區分戰鬥／輔助型；舊稿「女將留在名將池」作廢。

## B. 系統目的

1. **角色獲取主管道**：提供三國名將本體、紅顏女將與培育教官三條正式抽取路線
2. **商業分工清楚**：名將池賣角色廣度，紅顏池賣結緣繁衍，支援卡池賣培育深度
3. **公平性保障**：保底機制確保付費有回報
4. **與死亡傳承解耦**：抽卡只處理活體名將與教官，不混入英靈 / 虎符遺產
5. **三池敘事清楚**：名將池提供血統種子，支援卡池提供 36 回合培育深度，避免玩家把抽卡誤解成唯一戰力來源

### B-1. 三池分工的正式敘事

1. `三國名將池` 的正式功能是提供可上陣、可繁衍、可進入家族與壽命流程的名將本體，因此它負責的是**血統種子 / 角色廣度**。
2. `支援卡（教官）池` 的正式功能是提供 36 回合培育中的事件、TP、爆發率與上限體驗，因此它負責的是**培育深度 / 成長天花板**。
2-b. `紅顏天香池` 的正式功能是提供可立即結緣、生育後代的女性武將，因此它負責的是**結緣 / 血統繁衍**；細節依 FEM-03。
3. 三池都可以商業化，但兩者都不得販售 `英靈卡`、`虎符卡` 或舊稿中的 `DP` 部署點概念。
4. 抽卡所得只決定角色入口與培育工具，不直接覆蓋戰場上的 loadout 判讀、地形對策與操作風險。

## C. 商業套路

| 商業點 | 說明 |
|---|---|
| 三池分流 | 三國名將池（角色本體）＋紅顏天香池（結緣繁衍）＋支援卡池（培育上限），三邊用途不同 |
| 三池定位導覽 | 名將池明示「血統種子」，紅顏池明示「結緣繁衍」，支援卡池明示「培育深度」，降低新手把支援卡誤認成可上陣角色的風險 |
| 轉生 (1~5 轉) | 重複抽到解鎖額外培育機會＋屬性上限提升至 1500+ |
| 保底系統 | 50 抽小保底 SR+，200 抽大保底可兌換限定 SSR |
| 結義點數 | 5 轉滿階溢出碎片→結義金蘭卡→強力招降 |
| 忠誠度永鎖 | 名將池抽出的名將忠誠度固定 100，不會叛逃 |
| 期間限定 | 神．趙雲等限定角色驅動短期 FOMO |

## D. 系統 TA

| 玩家類型 | 使用情境 |
|---|---|
| 大課長 | 追 5 轉滿突破 + 限定 SSR |
| 中課 | 利用保底機制定向獲取目標角色 |
| 小課 | 偶爾抽一井，搭配結義卡強化俘虜招降 |
| 無課 | 靠免費石抽取入門角色，主力靠戰場/傭兵獲取 |

# 退役武將先祖教官轉化與雙柱血脈共鳴培育規格書

## 1. 核心定位與設計理念
本規格書定義三國生活（3KLife）世代傳承與學府培育系統之「退役武將功業萃取為先祖教官卡與雙柱血脈共鳴奧義解鎖」規範（對應 WBS `RET-08` 與 `PROG-2-1906`）。
先祖傳承機制旨在使每一代武將之戰鬥歷練與功業成就永久回流至家族宗廟，反哺後代書院培育，堅持**功業回流、嫡系親傳、血脈共鳴**原則：
1. **老將榮退轉化先祖教官**：年邁武將致仕退役後，其武將快照自動萃取為傳奇先祖教官，賦予專屬五維訓練加成與門風特質種子。
2. **嫡系血脈高起點羈絆**：嫡系子嗣入學時指派先祖教官，享有 50 點高初始羈絆，極速觸發七日頓悟。
3. **雙柱血脈共鳴雙奧義**：父母雙親主因子命中配方且親密與 EP 達標時，後代直接覺醒傳奇複合雙奧義。

## 2. 先祖教官數值萃取演算法 (`extractLegendaryMentor`)
由退役教官卡（`MentorCard`）萃取產出傳奇教官規格：
```typescript
export interface ILegendaryMentorCard {
    mentorId: string;                    // 如 MENTOR_ANCESTOR_GEN_001
    sourceGeneralUid: string;            // 原武將實體 UID
    generalName: string;                 // 如「趙雲（先祖）」
    finalRank: number;                   // 退役時最終官階
    inherentTacticId: string | null;     // 固有靈感戰法（滿羈絆 100% 領悟）
    inherentTraitId: string | null;      // 門風特質種子（60% 列入考評）
    statBonusPct: Partial<Record<LegacyStatKey, number>>; // 五維訓練加成
    initialAffinity: number;             // 起始羈絆（嫡系 50，旁系 0）
}
```

### 2.1 傳承參數標準對照表 (`LEGACY_TUNING`)
- **五維最高兩項加成 (`topTwoLegacyStats`)**：
  比對武將退役時之五維屬性（武力、智力、統率、政治、魅力），第一高屬性賦予 **$+20\%$** 訓練加成，第二高屬性賦予 **$+15\%$** 訓練加成。
- **嫡系血親初始羈絆**：
  若子嗣為該先祖之直系血脈（`isBloodline = true`），起始羈絆直接賦予 **50 點**（滿值 100）；非嫡系子嗣起始羈絆為 0。
- **門風特質候選率**：
  先祖之核心特質標籤在書院「期中考評」或「弱冠禮」方針中，具備 **60% 機率** 直接鎖定保底進入三選一候選池。

## 3. 雙柱血脈共鳴模型 (Dual Pillar Resonance)
後代子嗣若同時匯聚父母兩大頂級家族血脈，可觸發天地共鳴：
- **門檻判定條件**：
  1. **雙親親密度**：父母雙方當前親密度均滿足 $\text{Affinity} \ge 80$。
  2. **天命 EP 數值**：雙親個人天命點數均滿足 $\text{EP} \ge 85$。
  3. **配方吻合**：父系主因子與母系主因子命中雙柱共鳴配方表（如「龍膽」＋「神算」）。
- **共鳴效果**：
  子嗣在弱冠禮或學府畢業時，必定突破五維界限並直接領悟專屬複合雙奧義（如「七星龍膽破」）。

## 4. 書院學府總控掛載 (`attachLegacySupport`)
學府總控引擎在入學初始化時，將先祖教官之特質種子與數值加成寫入 `AcademyStateSnapshot.legacySupport`：
- 書院回合訓練結算五維成長時，線性疊加先祖 $+20\%$ / $+15\%$ 乘算倍率。
- 清談互動打出對應系別手牌時，先祖起始 50 羈絆使其在第 3~4 回合即可滿百觸發「七日頓悟」。

## 6. 驗證條件與測試矩陣 (Acceptance Gate)
1. **TC-LEGACY-01 頂級雙屬性精確加成**：武將最高屬性為智力 100、統率 90，驗證萃取後智力加成 $+20\%$，統率加成 $+15\%$。
2. **TC-LEGACY-02 嫡系與旁系羈絆分流**：嫡系血親驗證 `initialAffinity = 50`；非嫡系驗證精確為 0。
3. **TC-LEGACY-03 雙親親密未達標阻斷共鳴**：因子吻合但母親親密度僅 79 點，驗證不觸發雙柱血脈共鳴。
4. **TC-LEGACY-04 門風特質掛載學府**：驗證入學快照包含先祖特質種子且候選率標記為 60%。

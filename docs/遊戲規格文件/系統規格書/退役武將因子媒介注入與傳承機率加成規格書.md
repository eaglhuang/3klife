# 退役武將因子媒介注入與傳承機率加成規格書

> 標籤：`BLT-10` · `M4` · `因子媒介` · `靈魂傳承` · `退役機制` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，已告老退役之功勳名將作為「因子媒介（Gene Catalyst）」對家族新生代子嗣（0~5 歲神祕期）進行靈魂傳承與專屬因子定向注入之狀態機（`injectCatalystFactor`）。

本模組為純邏輯無副作用運算，所有注入操作皆具單次消耗性，由呼叫端（`GameSession`）負責落盤與事件廣播。

---

## 2. 因子媒介資格檢查與單次約束（Invariants）

每位退役武將在遊戲歷史中僅具備一次擔任因子媒介之天命額度：

```typescript
export const CATALYST_INHERITANCE_BONUS = 0.25;      // 媒介加成: +25%
export const CATALYST_BASE_INHERITANCE_CHANCE = 0.5; // 基準機率: 50%

export interface CatalystGeneral {
    catalystUsed?: boolean;
}
```

1. **單次不可逆性**：若武將物件之 `catalystUsed === true`，系統立即阻絕並回傳 `{ applied: false, reason: 'ALREADY_USED' }`。
2. **候選因子驗證**：退役名將必須具備子嗣目前尚未擁有之有效因子（`!owned.has(gene.id)`）。若無任何未習得因子，回傳 `{ consumed: false, reason: 'NO_CANDIDATE' }`，且**不消耗**退役武將的媒介額度。

---

## 3. 傳承機率精算公式

在滿足注入條件下，媒介享有專屬傳承成功率加成：

$$\text{FinalChance} = \min\left(1.0, \text{BaseChance}(0.50) + \text{CatalystBonus}(0.25)\right) = 0.75$$

```typescript
export function applyGeneCatalyst(
    retiredGeneral: CatalystGeneral,
    inheritanceChance: number
): CatalystResult {
    if (retiredGeneral.catalystUsed === true) {
        return { inheritanceChance, applied: false, reason: 'ALREADY_USED' };
    }
    if (!Number.isFinite(inheritanceChance)) {
        throw new RangeError('繼承機率必須是有限數值');
    }
    return {
        inheritanceChance: Math.max(0, Math.min(1, inheritanceChance + CATALYST_INHERITANCE_BONUS)),
        applied: true
    };
}
```

- 最終傳承成功率高達 **$75\%$**，提供家族跨世代傳遞關鍵戰法與核心特質之確定性通道。

---

## 4. 注入狀態機流程與事件契約

```
                   ┌───────────────────────────┐
                   │ 退役武將因子媒介注入請求   │
                   └─────────────┬─────────────┘
                                 │
                   [ 已使用過? (catalystUsed) ]
                   ├── 是 ──> 拒絕: ALREADY_USED (不消耗)
                   └── 否
                                 │
                   [ 子嗣是否已有全部因子? ]
                   ├── 是 ──> 拒絕: NO_CANDIDATE (不消耗)
                   └── 否 (挑選第一個尚未擁有之因子)
                                 │
                   ┌─────────────┴─────────────┐
                   │ 消耗媒介: catalystUsed = true │
                   │ 擲骰: random() < 0.75     │
                   └─────────────┬─────────────┘
                                 │
                   [ 命中 (75% 機率) ]
                   ├── 是 ──> 子嗣追加該因子, injectedFactorId 賦值
                   └── 否 ──> 注入失敗, injectedFactorId: null
```

1. **確定性消耗原則**：只要成功尋得候選因子並進入擲骰流程，無論最終 $75\%$ 機率是否命中，該退役武將皆永久標記為 `catalystUsed: true`，不可二次使用。
2. **全域事件廣播**：注入成功後，`GameSession` 拋出 `GeneCatalystInjected` 全域事件，前端播放宗祠靈魂傳承特效，並更新家族宗譜紀錄。

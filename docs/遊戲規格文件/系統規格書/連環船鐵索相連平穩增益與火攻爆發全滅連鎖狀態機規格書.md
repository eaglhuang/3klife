## 1. 系統架構定位與千古連環悲劇

赤壁鏖兵用火攻，運籌決策盡皆同。龐統巧授連環計，公瑾微借東南風。《三國人生》（3KLife）重現這段最驚心動魄之歷史轉折，實裝**連環船拓撲連結與連鎖殉爆物理模型（Chained Fleet Synergy & Cascade）**。

本系統核心價值：
1. **極致陸戰移植增益（Land Combat Buff）**：以鐵索木板相連，水戰化為平地，步騎戰力極致釋放。
2. **機動喪失代價（Zero Mobility Trap）**：艦隊徹底喪失躲閃與機動撤退能力。
3. **不可逆火攻骨牌效應（Catastrophic Fire Cascade）**：一舟引火，全陣俱焚，引爆三國最大規模戰損連鎖。

## 2. 鐵索連環拓撲陣列結構

相鄰 3 至 10 艘戰船可由軍令執行「鐵索扣連（LOCK_CHAINS）」：

```typescript
export interface IChainedFleetCluster {
  readonly clusterId: string;              // 連環艦隊叢集識別碼
  vesselIds: string[];                     // 納入連環之戰船識別碼清單 (3~10艘)
  isChained: boolean;                      // 是否處於鐵索相連狀態
  isBurning: boolean;                      // 叢集內是否有任何船隻起火
  unlockingTurnsRemaining: number;         // 斧鑿解鎖鐵索剩餘回合數 (預設 3 回合)
}
```

## 3. 穩定如陸平穩增益矩陣

一旦戰船完成鐵索扣連，艦隊獲得「水上浮城」超強戰鬥態勢：
1. **暈船懲罰徹底免疫**：全體駐艦將士之「暈船嘔吐」狀態立即被清除，北方旱鴨子部隊戰力全額釋放。
2. **陸戰兵種特權恢復**：重裝騎兵允許在相連甲板上自由發動衝鋒突刺；步兵結成鐵壁大陣，免傷率提升 **$+30\%$**。
3. **抗風浪平穩**：完全免疫大江風浪與波濤顛簸，遠程弓弩部隊射擊命中率提升 $+20\%$。

## 4. 火攻連鎖殉爆與全滅狀態機

連環船的致命命門在於火。當任一艘船隻遭遇火箭、火船撞擊或火計引燃時，立即觸發「火燒連營」連鎖骨牌反應：

```
       [火船撞擊戰船 A] ──── 戰船 A 陷入 BURNING (火勢 100%)
                │
                │ 當前回合結算：火焰順鐵索無阻礙蔓延！
                ▼
       [戰船 B / C / D 連鎖起火] ─── 全艦隊陷入烈焰地獄！
                │
                │ 承受火攻傷害 +300%，移動力為 0 無法避讓
                ▼
       【全軍覆沒 / 跳江溺亡】 ───── 士氣歸零，80% 部隊葬身江底
```

1. **強制瞬態擴散**：鐵索與相連松木板提供絕佳引燃介質，火焰擴散概率為 **$100\%$**（無視風向，直接傳導至全陣列）。
2. **連鎖易傷乘數**：處於連環狀態之船隻，承受火傷害高達常規狀態之 **$300\%$**！船體耐久每回合扣除 35%。
3. **斧鑿逃生困境**：下達「解開鐵索」命令需耗費工兵 **3 個完整回合**砍斷精鋼鐵索。在烈火烹油之局勢下，解鎖尚未完成，艦隊已全滅化為灰燼。
4. **跳江溺斃結算**：連環船焚毀時，將士被迫跳江，北方無水性部隊因甲冑沉重，生還率不足 **$15\%$**。

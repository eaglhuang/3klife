# 遺傳因子繼承機率模型與藍色三星屬性閾值規格書

## 1. 核心定位與設計理念
本規格書定義《三國人生》子嗣自 14 人家族譜系中繼承遺傳因子（Genetic Factors）的世代進池率、幸運加成與藍色基礎屬性因子 3 星閾值機率模型（WBS `FORM-08`，代碼落位於 `BlueFactorInheritance.ts` 與 `FactorInheritance.ts`）。
遺傳系統結合「世代稀釋定律」與「強者恆強」哲學，讓高階培育武將的卓越屬性能在後代中以機率性藍色 3 星因子形式沉澱，形成世代傳承的長線追求。

   • G1 (雙親): 100% 進池 (★3:80%, ★4:20%)              • 數值 < 600: 0% 機率

## 2. 藍色 3 星因子繼承機率階梯（`BlueFactorInheritance`）

藍色因子代表基礎五維屬性（武力、智力、統率、政治、魅力）之先天遺傳。子嗣能否繼承到高階 **3 星藍色因子**，取決於父母該項屬性之最終結算值：

$$\text{Chance}_{\text{blue★3}} = \begin{cases} \mathbf{0\%}, & \text{屬性值} < 600 \quad (\text{BLUE\_FACTOR\_TIER\_LOW}) \\ \mathbf{6\%} \ (0.06), & 600 \le \text{屬性值} < 1100 \quad (\text{BLUE\_FACTOR\_TIER\_HIGH}) \\ \mathbf{10\%} \ (0.10), & \text{屬性值} \ge 1100 \end{cases}$$

- **未達門檻保護**：屬性未滿 600 點者，絕不可能產生 3 星藍色因子，防止未經深度培育之角色稀釋因子池。
- **神話級培育反饋**：屬性突破 1100 點大關時，3 星藍色因子產生機率顯著躍升至 10%。

## 3. 世代譜系進池率與幸運縮放（`FactorInheritance`）

子嗣最多保留 **5 個核心遺傳因子**（`DEFAULT_MAX_INHERITED_FACTORS = 5`），依序由三代祖輩遺傳池中隨機篩選：

### 3.1 世代進池基礎機率（`FACTOR_POOL_RATE`）
- **G1（雙親，2人）**：進池率 **100%**。
- **G2（祖父母，4人）**：進池率 **50%**。
- **G3（曾祖父母，8人）**：進池率 **25%**。

### 3.2 雙親平均幸運值（LUK）加成（`inheritanceLukRate`）
雙親之平均運氣屬性（`ParentAvgLuk`）可按百分比線性放大進池機率，上限封頂為 100%：
$$\text{FinalRate} = \min(1.0, \text{BaseRate} \times (1 + \frac{\text{ParentAvgLuk}}{100}))$$

### 3.3 世代星等分布權重（`FACTOR_STAR_DISTRIBUTION`）

| 來源世代 (Generation) | 基礎星等 (Low Star) | 突破星等 (High Star) | 抽到高星突破機率 (`highRate`) |
| :---: | :---: | :---: | :---: |
| **G1（父母親代）** | **★3** | **★4** | **20%** |
| **G2（祖父母代）** | **★2** | **★3** | **30%** |
| **G3（曾祖父母代）** | **★1** | **★2** | **10%** |

- **同因子去重原則**：若同一個因子同時由多位祖輩傳入池中，系統強制保留**最高星等版本**，杜絕重複佔槽。

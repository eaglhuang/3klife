# 酒館傭兵刷新週期與地下城救美三階產出模型規格書

## 1. 模組職責與架構定位
本規格書規範女性武將獲取管線中的「酒館女傭兵刷新週期（`FemalePoolRefresh`）」與「地下城救美三階產出分佈模型（`DungeonRescue`）」。模組負責提供時間驅動的週期刷新、道具立即重置，以及地宮探險通關後的確定性隨機種子階梯產出，確保數值產出受控且可回放測試。

```
┌─────────────────────────────────────────────────────────────┐
│                    Female Acquisition Loops                 │
├──────────────────────────────┬──────────────────────────────┤
│ 8-Hour Tavern Mercenary Pool │ 8-Hour Dungeon Rescue Quest  │
│ (宴客令 / 徵人令即時刷新)    │ (三階隨機分佈 60% / 30% / 10%)│
└──────────────────────────────┴──────────────────────────────┘
```

## 2. 酒館傭兵刷新週期與強制道具介入

### 2.1 8 小時時間戳推進狀態機
酒館客棧名單每 **8 小時（28,800 秒）** 依伺服器或本地遊戲時間自動輪替一次：
- 若當前時間戳 $\text{now} - \text{lastRefreshTime} \ge 28800$，系統自動產生新一批 3 位傭兵名單。
- 支援「宴客令（`TAVERN_TOKEN`）」或「徵人令（`RECRUIT_TOKEN`）」道具介入：
  - 消耗 1 枚道具可立即重置冷卻倒數，並依確定性種子即時更新 3 位女傭兵名冊。

### 2.2 六日結義好感累積
玩家每日可對酒館傭兵進行交談、設宴（`FEM-08`），累計好感值（$0 \sim 100$）。當累計好感達到 100 且結義達 6 日時，該傭兵無條件脫離傭兵池，永久加入玩家宗族武將名冊。

## 3. 地下城救美三階產出分佈模型

地下城通關後，系統根據隨機 roll 決定所解救之女性身分背景與初始品質：

| 身份類別 | 產出機率 | 品質評級 | 基礎生育係數 | 特殊資產賦予 |
| :---: | :---: | :---: | :---: | :--- |
| **民間孤女（`CIVILIAN`）** | $60\%$ | R / N | $0.80\times$ | 無額外嫁妝，精力上限保底 |
| **世家千金（`GENTRY`）** | $30\%$ | SR | $1.00\times$ | 攜帶 10,000 銅錢嫁妝入庫 |
| **貴族名姝（`NOBLE`）** | $10\%$ | SSR | $1.15\times$ | 自帶 1 項已解鎖紫色/綠色稀有因子 |

```typescript
export interface RescueOutcome {
  category: 'CIVILIAN' | 'GENTRY' | 'NOBLE';
  qualityGrade: 'R' | 'SR' | 'SSR';
  conceptionModifier: number;
  bonusDowryCopper: number;
  hasRareGene: boolean;
}

export function rollDungeonRescueOutcome(roll: number, isBossGuaranteed: boolean): RescueOutcome {
  // BOSS 戰或首通保底：至少世家千金（GENTRY），30% 機率升格為貴族名姝（NOBLE）
  if (isBossGuaranteed) {
    if (roll < 0.30) {
      return { category: 'NOBLE', qualityGrade: 'SSR', conceptionModifier: 1.15, bonusDowryCopper: 50000, hasRareGene: true };
    }
    return { category: 'GENTRY', qualityGrade: 'SR', conceptionModifier: 1.00, bonusDowryCopper: 10000, hasRareGene: false };
  }

  // 常規 60% / 30% / 10% 階梯
  if (roll < 0.10) {
    return { category: 'NOBLE', qualityGrade: 'SSR', conceptionModifier: 1.15, bonusDowryCopper: 50000, hasRareGene: true };
  }
  if (roll < 0.40) {
    return { category: 'GENTRY', qualityGrade: 'SR', conceptionModifier: 1.00, bonusDowryCopper: 10000, hasRareGene: false };
  }
  return { category: 'CIVILIAN', qualityGrade: 'R', conceptionModifier: 0.80, bonusDowryCopper: 0, hasRareGene: false };
}
```

## 4. 單元測試驗證規範
1. **TC-RESCUE-01（常規階梯機率區間檢驗）**：roll = 0.05 回傳 NOBLE；roll = 0.25 回傳 GENTRY；roll = 0.70 回傳 CIVILIAN。
2. **TC-RESCUE-02（BOSS 戰保底門檻檢驗）**：當 `isBossGuaranteed = true` 時，即便 roll = 0.99，回傳結果亦至少為 GENTRY，絕不產出 CIVILIAN。
3. **TC-TAVERN-01（8 小時冷卻判定）**：時間跨度 28,799 秒不觸發自動刷新；跨度 28,800 秒正確觸發刷新。

# 3KLife 重甲步兵長柄生鐵挽手鉤拉拽敵盾牆破防刺殺狀態機規格書

## 1. 系統定位與設計意圖

在三國重裝步兵正面肉搏決戰（如界橋之戰先登死士破大盾、高順陷陣營破陣）中，敵軍以大盾鐵排相互扣鎖形成密不透風之盾牆（Shield Wall），正面常規刀砍矛戳難以破入。本系統規範重步兵特種破陣戰術「長柄生鐵挽手鉤破盾協同（Heavy Infantry Hook Shield Breach）」之倒鉤扣鎖、合力拉拽、撕開陣列缺口與短兵穿透刺殺狀態機：
- **丈二生鐵反刃挽手長鉤**：特種跳蕩兵配備長達丈二之白蠟木長柄，前端鍛造雙向倒刺生鐵巨鉤，專門用於鉤拿敵大盾上緣與握手皮帶。
- **三人協同合力後拽**：每具盾牌由兩至三名跳蕩死士同時以長鉤扣死，後撤發力將敵大盾向前拽傾撕扯，打破相扣鎖結。
- **後排長矛手精準直刺**：大盾被扯開空隙之瞬間，我方後排六尺長矛手順勢突刺，直接殺傷敵暴露之頸部與胸口，引發局部連鎖潰散。

## 2. 狀態機架構與轉換生命週期

長鉤破盾狀態機（代碼：`HEAVY-INFANTRY-HOOK-SHIELD-BREACH01`）管理從接敵扣盾至盾牆撕裂之完整週期：

```
[ SHIELD_WALL_LOCK ] (敵軍相扣大盾形成固若金湯盾牆)
          │
          ▼
[ HOOK_ENGAGE_LATCH ] (跳蕩死士長柄鐵鉤精準扣入盾緣)
          │
          ├── 敵軍揮刀斬斷長柄 ──> [ REINFORCED_SHAFT_RESIST ]
          ▼
[ SYNCHRONIZED_PULL_LEVER ] (三人合力後拽生鐵鉤破壞重力平衡)
          │
          ├── 敵大盾被強行掀開
          ▼
[ DEFENSIVE_GAP_EXPOSED ] (盾牆出現二尺寬空隙露出防禦破綻)
          │
          ▼
[ SPEAR_THRUST_LETHAL_HIT ] (後排長矛手自缺口突刺要害)
          │
          ▼
[ CASCADE_WALL_COLLAPSE ] (局部防線撕裂引發相鄰盾牌骨牌式倒塌)
```

### 狀態細部定義

1. **SHIELD_WALL_LOCK（盾牆相扣）**：
   - 敵軍步卒以生鐵搭扣鎖定相鄰八尺立盾，格擋率高達 90%，常規遠程與近戰皆無法造成貫穿。
2. **HOOK_ENGAGE_LATCH（鐵鉤扣盾）**：
   - 我方跳蕩前鋒藉由長度優勢越過敵軍矛尖，生鐵倒鉤卡死敵盾牌頂緣木梁，鎖定率達 85%。
3. **SYNCHRONIZED_PULL_LEVER（協同後拽）**：
   - 3 名重甲甲士雙手緊握長柄，弓步後撤發力，施加超過 250 公斤瞬時拉力，強行扯動敵盾牌向前傾倒。
4. **DEFENSIVE_GAP_EXPOSED（撕開缺口）**：
   - 敵手持盾士因手腕脫臼或重心失衡被迫鬆手，盾牆局部露出寬達二尺之空檔，持續 3.5 秒。
5. **SPEAR_THRUST_LETHAL_HIT（突刺破綻）**：
   - 後排持丈八長矛之精銳長矛兵瞬間自缺口合力刺入，造成 2.8 倍暴擊傷害，敵盾手當場失能。
6. **CASCADE_WALL_COLLAPSE（骨牌坍塌）**：
   - 相鄰大盾因失去側向鎖扣支撐，受我方步卒強推引發連環倒塌，敵陣地徹底被撕裂。

## 3. 關鍵數值與計算判定公式

### 3.1 破盾成功率計算公式

長柄挽手鉤強行撕開大盾之成功率 $P_{breach}$：
$$P_{breach} = \text{clamp01}\left(\frac{\sum F_{pull\_soldiers} \times C_{hook\_grip}}{M_{shield\_unit} \times g \times \mu_{ground} + F_{resist\_def}} \times 0.65\right)$$
- $\sum F_{pull\_soldiers}$：我方三人協同總拉力（約 2400 N）。
- $C_{hook\_grip}$：生鐵倒刺咬合係數（取 1.25）。
- $F_{resist\_def}$：敵盾手後蹬支撐阻力（約 1400 N）。
- 計算得常態協同拉拽成功率為 74%，大幅凌駕單兵硬砍之 12%。

### 3.2 缺口暴露時間內之暴擊補正

盾牆被破開期間我方長矛攻擊之傷害加成係數 $\alpha_{crit}$：
$$\alpha_{crit} = 1.0 + \text{CritMultiplier} \times (1.0 - \text{ArmorCoverage}_{gap}) \approx 2.85$$
- 敵防禦者胸腹要害毫無掩護，防禦力驟降 80%。

## 4. 戰術連鎖與攻防克制

1. **破解密集鐵桶陣**：徹底終結純防禦大盾反覆拉鋸拖回合之僵局，為近戰快速決戰開道。
2. **天敵與戰術反制**：
   - **大斧劈桿**：敵陣若配備巨斧劈砍長柄木桿，有 35% 機率斬斷白蠟木桿。
   - **兩翼短刀反絞殺**：若長鉤發力後撤時被敵兩翼刀盾兵突入近身，長柄武器因過長無法回防而陷於劣勢。

# 3KLife 重裝步兵包鐵大盾深釘地樁撐木反震騎兵狀態機規格書

## 1. 系統概述與設計哲學
在開闊平原野戰中，面對敵方具裝重騎兵之正面鑿穿戰術，常規步兵若僅憑手臂持盾，必遭巨額衝擊動能直接撞飛碾碎。三國步兵精銳（如高順陷陣營、鞠義先登營）廣泛採用「包鐵大盾插樁反震陣列」（TOWER-SHIELD-GROUND-STAKE01）。
重裝刀盾兵配備高達八尺、以青岡木為底、外包熟鐵皮之重型立盾。接陣前，步卒將盾底兩枚鋒利生鐵地樁深釘入土，後排士兵以斜向粗木撐桿死死頂住盾背橫樑。當敵騎高速衝撞時，大地與撐桿吸收八成衝擊動能，並將巨大反作用力倒灌回戰馬胸骨，造成敵馬當場骨碎折頸，後排長矛手隨即自盾縫探槍刺殺，構建不可撼動之步兵鐵壁。

## 4. 衝擊剛度與動量回傳物理模型

### 4.1 剛性地面支撐動量反射公式
大地提供近乎無限之剛性支撐，使動量反衝最大化：
$$F_{\text{recoil}} = \frac{M_{\text{horse}} \times V_{\text{charge}}}{\Delta t_{\text{impact}}} \times (1.0 - \text{Absorb}_{\text{wood}})$$
- 戰馬胸膛承受數萬牛頓瞬時反衝力，戰馬致死致殘率達 $75\%$，且騎兵衝鋒動能完全被阻截無法穿透防線。

### 4.2 盾縫探槍刺殺優勢
1. **絕對掩護視界**：長矛手身軀完全隱蔽於 2.4 米高大盾後方，免受敵騎弓箭射擊。
2. **穿刺力加成**：戰馬撞盾停頓瞬間處於破綻狀態，長矛直刺對敵騎破甲率提升 $50\%$。

## 5. 單元驗收測試標準
1. **TC-SHIELD-01 (大盾立樁與吸收反震全流程)**：
   - 模擬 5 秒內完成大盾立樁與斜撐頂死。
   - 承受重騎兵高速衝撞，驗證大盾吸收 82% 動能，反震 1.6 倍傷害消滅前排戰馬。
2. **TC-SHIELD-02 (長矛探出反刺與收割)**：
   - 衝撞反震後觸發 `SPEAR_THRUST_WINDOW`，驗證長矛反刺對落馬騎兵命中率為 100%。
3. **TC-SHIELD-03 (拔樁收盾轉攻推進)**：
   - 擊退敵騎後啟動 `UNSTAKE_TACTICAL_ADVANCE`，驗證 4 秒完成拔樁並重置行軍姿態。

# 3KLife 野戰營寨鹿角拒馬壕溝圍欄與巡邏哨塔防禦體系規格書

## 1. 模組概述與核心定位
本模組為 3KLife 戰役野戰營盤防禦與陣地工程系統（`CAMP-FORTIFICATION-01`）。重現三國名將「安營紮寨，先立鹿角，設拒馬，穿壕引水，築高樓為望候」之固守典範。大軍在沙盤地格駐紮時，可透過就地伐木構築防禦圍欄、拒馬陣地與哨探望樓，大幅抵消騎兵衝鋒衝擊，並將夜襲偷襲之隱蔽優勢徹底清零。

```typescript
export interface CampDefenseModules {
  hasTrenches: boolean;                // 防禦壕溝

export interface CampAssaultImpactReport {
```

## 4. 拒馬反傷、哨塔破隱與衝鋒阻截公式

### 4.1 拒馬反彈騎兵衝鋒傷害
騎兵部隊發動「野蠻衝撞」猛擊營盤時：
$$\text{ReflectedDamage} = \text{AttackerChargePower} \times \left(0.8 + \text{ChevauxDeFriseLevel} \times 0.4\right)$$
- 3 級拒馬陣地反彈高達 $200\%$ 衝撞力，衝鋒戰馬前胸遭尖木穿透，直接造成先鋒騎兵毀滅性骨折傷亡；
- 騎兵衝鋒速度歸零，該回合失去連擊能力。

### 4.2 望樓哨塔破除夜襲隱蔽檢定
黑夜中敵方特種斥候或夜襲隊靠近時：
$$P_{\text{spot}} = \min\left(0.95, \frac{\text{WatchtowerCount} \times 25 + \text{NightVigilanceRating} \times 0.5}{100}\right)$$
- 一旦捕獲敵蹤，哨塔立即鳴金敲鑼，敵方夜襲部隊喪失「突襲暴擊加成」，營內部隊直接進入「枕戈待旦」備戰迎敵狀態。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-CAMP-01**：在無木材資源或工兵疲憊時紮營，營寨默認為 `UNFORTIFIED`，防禦加成為零且承受突襲時混亂機率翻倍。
2. **驗收 CASE-CAMP-02**：遭火箭火油持續攻擊時，木柵圍欄每回合承受額外 $20\%$ 燃燒傷害，若無水井水源撲救，3 回合內柵欄焚毀瓦解。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，結構簡練無廢話。

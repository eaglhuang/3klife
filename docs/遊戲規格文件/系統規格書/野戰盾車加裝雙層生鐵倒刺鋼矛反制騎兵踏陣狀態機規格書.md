# 3KLife 野戰盾車加裝雙層生鐵倒刺鋼矛反制騎兵踏陣狀態機規格書

## 1. 系統定位與設計意圖

在三國曠野平原大兵團決戰（如官渡戰役曹軍防禦袁紹騎兵突穿、猇亭之戰蜀軍車陣扎防）中，面對數千名具備破陣威能的精銳騎兵集體狂飆衝擊，單純步兵盾陣極易被戰馬踐踏撞飛。本系統規範三國特種工程步兵「加裝雙層生鐵倒刺鋼矛防撞拒馬推車系統（Spiked Shield Cart Anti-Cavalry）」狀態機：
- **重型硬木推車包覆熟鐵板**：每輛盾車寬六尺高五尺，車廂正面以厚生鐵皮包裹，車輪裝有向內鎖定之單向棘輪防倒退卡榫。
- **雙層生鐵倒刺長鋼矛外伸**：車廂正面上下兩層交錯伸出六柄長一丈二尺之粗壯鋼矛，矛頭帶有四道放血倒刺與淬火棱刃，直指馬胸與騎士。
- **吸能抗衝擊與馬匹穿刺反噬**：戰馬高速撞擊盾車時，棘輪與車身支撐木樁吸收動能，鋼矛直接貫穿馬身胸腔，將騎兵衝鋒動能全數轉化為穿刺自殘。

## 2. 狀態機架構與轉換生命週期

刺盾車反制騎兵狀態機（代碼：`SPIKED-SHIELD-CART-ANTI-CAVALRY01`）流程如下：

```
[ CART_WHEEL_DEPLOY_PUSH ] (步兵推動刺盾車推進至陣線第一線)
           │
           ├── 抵達預設阻截線輪轂落銷
           ▼
[ GROUND_STAKE_RATCHET_LOCK ] (地樁砸入泥土單向防退棘輪咬死鎖定)
           │
           ├── 敵軍重騎兵群高速進入衝鋒百步線
           ▼
[ SPEAR_EXTENSION_INTERLOCK ] (雙層六柄倒刺鋼矛平行外推互鎖成牆)
           │
           ├── 戰馬高速撞擊鋼矛鋒刃 ──> [ IMPACT_KINETIC_IMPALE ]
           ▼
[ HORSE_CHEST_PIERCE_COLLAPSE ] (鋼矛貫穿戰馬胸膛動能瞬間歸零)
           │
           ├── 車身受撞反作用力由地樁傳導化解
           ▼
[ MOMENTUM_RECOIL_ABSORPTION ] (車陣穩固不退形成屍山阻障屏障)
           │
           ▼
[ SPEAR_WITHDRAW_RELOAD ] (步兵自車後推刺補殺墜馬敵騎士)
```

### 狀態細部定義

1. **CART_WHEEL_DEPLOY_PUSH（推行就位）**：四名重步兵合力推車前移，與相鄰盾車銜接形成百步防禦車牆。
2. **GROUND_STAKE_RATCHET_LOCK（落銷固樁）**：副兵猛砸車尾雙生鐵地樁深達三尺，棘輪齒合，確保受撞時後退距離小於一尺。
3. **SPEAR_EXTENSION_INTERLOCK（鋼矛互鎖）**：上下兩層鋼矛向前推伸卡緊，形成一道密集生鐵矛尖防護林。
4. **IMPACT_KINETIC_IMPALE（穿刺撞擊）**：戰馬衝撞矛尖，極速動能化為撕裂傷，生鐵矛尖深入馬體兩尺。
5. **HORSE_CHEST_PIERCE_COLLAPSE（戰馬斃命）**：戰馬心肺被貫穿失血暴斃，前衝勢頭驟停，騎士受慣性拋出摔落車前。
6. **MOMENTUM_RECOIL_ABSORPTION（動能吸納）**：盾車結構受巨大衝擊僅產生輕微彈性位移，防線紋絲不動。
7. **SPEAR_WITHDRAW_RELOAD（收槍反擊）**：步兵自擋板射擊孔伸出短矛刺殺倒地騎士，清理車前堆疊屍骸維持防線。

## 3. 數值模型與物理演算

### 騎兵衝鋒反噬傷害公式

$$D_{reflect} = \frac{1}{2} M_{horse} \times V_{charge}^2 \times \mu_{pierce} \times (1.0 + 0.2 \times \text{IsSpiked})$$

- $M_{horse}$：戰馬質量（500kg）。
- $V_{charge}$：衝鋒末端速度（約 $12\,\text{m/s}$）。
- $\mu_{pierce}$：鋼矛穿刺剛性係數（0.85）。換算動能反噬傷害可達 3,000 點以上，足以秒殺任何重裝戰馬。

### 盾車位移抗退公式

$$S_{recoil} = \frac{E_{impact}}{K_{ground\_stake} + K_{cart\_mass}} \le 0.3\,\text{公尺}$$

- 若地樁砸入深度達 1 公尺，車身位移嚴格限制於 0.3 公尺內，陣型完好率達 95%。

## 4. 戰場戰術連鎖與部隊生剋

1. **重騎兵正面突擊禁區**：任何直面撞擊刺盾車之騎兵單位，承受 300% 穿刺傷害反噬，無一倖免。
2. **懼怕重型投石與巨弩攻城器**：盾車車體木質框架在遭受攻城投石機直接命中時，有 60% 機率直接被砸散解體。
3. **步兵繞襲兩翼側後**：若敵方精銳輕步兵攜帶板斧自車陣銜接空隙穿插繞後，可繞開鋼矛威脅實施近身砍殺。

## 6. 驗證標準與測試用例 (TC)

- **TC-SPIKED-CART-01（落銷固樁判定）**：地樁砸入完成後，`isGroundStakeAnchored` 與 `ratchetLocked` 均為 `true`。
- **TC-SPIKED-CART-02（高速衝騎穿刺反噬）**：速度 10m/s 重騎撞擊時，戰馬在 0.2 秒內承受滿額反噬傷害並死亡。
- **TC-SPIKED-CART-03（車位移閾值）**：驗證承受滿額撞擊後，盾車位移距離不得超過 0.35 公尺，陣線維持完整。

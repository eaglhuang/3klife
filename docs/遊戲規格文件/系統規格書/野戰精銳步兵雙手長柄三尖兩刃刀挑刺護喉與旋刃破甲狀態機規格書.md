# 野戰精銳步兵雙手長柄三尖兩刃刀挑刺護喉與旋刃破甲狀態機規格書

> **來源**：三國名將紀靈所持奇門重兵與《武經總要》「三尖兩刃刀／二郎刀」（柄長八尺、重約二十五斤，刀頭前端分叉呈山字形三道鋒銳槍尖，刀身兩側皆開雙刃；兼具大刀之重劈、長槍之三尖攢刺、以及刀叉架鎖敵兵之全方位攻防能力）、WBS `FORM-162` 戰場重型奇門刀槍複合步兵模組。
> **關聯文件**：`doc_spec_0922`（長柄鳳嘴刀三連擊）、`doc_spec_0934`（方天畫戟月牙勾盾）、`doc_spec_0028`（裝備強化系統）。

## 一、 設計目標與戰術定位

普通大刀只能單面劈砍，回刀時必有空檔；普通長槍只能直線單點穿刺，容易被盾牌偏折。「雙手長柄三尖兩刃刀」則融合了「雙刃往復旋劈」與「山字三尖挑刺」：刀頭前端三個分叉尖刺在直刺時能同時穿透敵方咽喉與鎖骨三處要害（創面極大、無法止血），而兩側雙刃則允許使用者在正劈之後無需轉腕，直接逆向反撩挑開敵方護喉甲。

1. **山字三尖穿喉（Triple-Point Throat Impale）**：一刺三孔，對敵方造成無法自然癒合之「三孔重創流血」，並大幅降低敵將吼叫與指揮戰法效果。
2. **雙刃正反連環旋撩（Double-Edged Reverse Slash）**：正劈被格擋後，無需收刀蓄力，刀身下刃直接由下往上反撩敵方下頷與護喉，令人防不勝防。
3. **三叉卡刃奪勢（Trident Fork Blade-Catch）**：利用刀尖山字凹槽卡住敵方劈來的刀劍，順勢旋柄震裂敵兵虎口。

## 二、 狀態機生命週期（5 階段）

```
[1. 橫刀山立 Trident_Glaive_Ready]
       │ (接戰距離 <= 1.5 格，三尖寒光鎖定敵方咽喉)
       ▼
[2. 三叉卡刃 Triple_Tip_Blade_Catch]
       │ (山字凹槽夾住敵刀槍：招架減傷 50% + 反震敵手)
       ▼
[3. 雙刃反撩 Double_Edge_Upward_Slash]
       │ (正劈接逆向反撩：無視正面舉盾，造成 170% 斬傷)
       ▼
[4. 三尖貫喉 Triple_Point_Throat_Pierce]
       │ (山字三尖直刺咽喉：190% 穿甲暴擊 + 重創流血與禁吼)
       ▼
[5. 旋刀護身 Whirling_Guard_Reset]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `TRIDENT_GLAIVE_READY` | 橫刀山立 | 三尖兩刃刀精兵或猛將（`STR >= 85`）持刀列陣，兼具刀兵與槍兵雙重克制標籤。 |
| `TRIPLE_TIP_BLADE_CATCH` | 三叉卡刃 | 遭受近戰攻擊時，以刀頭山字分叉精準夾住敵方武器，減免 `50%` 傷害並使敵方陷入「虎口震裂（攻擊速度與命中 `-20%`）」。 |
| `DOUBLE_EDGE_UPWARD_SLASH` | 雙刃反撩 | 主動進攻時先以正刃斜劈誘敵舉盾，隨即以刀背下刃自下而上反撩，**無視敵方盾牌格擋率**，造成 `170%` 破甲斬擊。 |
| `TRIPLE_POINT_THROAT_PIERCE` | 三尖貫喉 | 順反撩之勢挺刀直刺，三道鋒尖同時刺穿咽喉與雙肩鎖骨，造成 `190%` 穿刺傷害，並附加 2 回合「三創失血（每回合損失 `8%` 兵力，且受治療效果 `-60%`）」。 |
| `WHIRLING_GUARD_RESET` | 旋刀護身 | 連招收勢時雙刃舞成刀花護住周身，使自身至下回合開始前遠程閃避率 `+25%`。 |

## 三、 核心數值與判定公式

### 3.1 雙刃反撩與三尖貫喉連擊公式（Slash & Triple-Pierce Combo）
$$D_{\text{combo}} = D_{\text{base}} \times \left(1.70_{\text{slash}} + 1.90_{\text{pierce}} \times (1 + 0.25 \times \mathbb{I}_{\text{bladeCaught}})\right)$$
- 若先一步成功觸發 `TRIPLE_TIP_BLADE_CATCH` 卡住敵兵（$\mathbb{I}_{\text{bladeCaught}} = 1$），緊接的三尖貫喉傷害額外提升 `+25%`。

### 3.2 三創失血與禁療公式（Triple-Wound Bleed & Heal Cut）
$$D_{\text{bleed}} = \text{HP}_{\max} \times 0.08,\quad H_{\text{effective}} = H_{\text{raw}} \times (1 - 0.60)$$
- 三尖刀頭造成的三道並列貫穿傷口極難包紮，使目標承受之戰地醫護或戰法回血效果強制折減 `60%`。

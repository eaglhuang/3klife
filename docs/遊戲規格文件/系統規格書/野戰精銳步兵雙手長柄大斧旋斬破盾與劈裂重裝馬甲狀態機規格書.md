# 野戰精銳步兵雙手長柄大斧旋斬破盾與劈裂重裝馬甲狀態機規格書

> **來源**：三國曹魏名將徐晃所持長柄大斧與北方重步兵「長柯斧／定軍大斧」（柄長七尺、斧頭重十二斤，斧刃寬闊呈弧月形、斧背帶平錘或倒鉤，專破敵軍重盾方陣與具裝鐵騎之生鐵馬面甲）、WBS `FORM-150` 戰場重型劈砍步兵模組。
> **關聯文件**：`doc_spec_0901`（大砍刀斬馬首）、`doc_spec_0922`（長柄鳳嘴刀三連擊）、`doc_spec_0925`（長柄鐵骨朵碎腦）。

---

## 一、 設計目標與戰術定位

「雙手長柄大斧」兼具刀刃的鋒利切割與重錘的破甲動能。由於重心極度靠前，長柄大斧一旦揮動便無法輕易變招，但其劈砍瞬間的局部壓強遠超刀劍，是戰場上拆解「包鐵塔盾牆」與「具裝馬甲」的開罐利器。

1. **一斧劈裂大盾（Shield-Splitting Cleave）**：大斧弧形寬刃集中全部動能於一點，命中持盾敵軍時直接劈裂木鐵盾牌，使敵方永久失去盾牌防禦加成。
2. **破除重騎馬面甲（Barding-Shatter Strike）**：對抗重裝騎兵時，長柄大斧專劈戰馬頭部與胸前具裝鐵甲，造成馬甲崩裂與戰馬跪倒。
3. **旋斧橫掃震退（Whirlwind Knockback）**：陷入包圍時可雙手掄動大斧三百六十度旋斬，逼退周圍 `1` 格敵軍並撕裂傷口。

## 二、 狀態機生命週期（5 階段）

```
[1. 拖斧蓄勢 Drag_Axe_Charge]
       │ (接近持盾步兵或具裝重騎 <= 1 格)
       ▼
[2. 當頭劈盾 Overhead_Shield_Split]
       │ (毀盾判定：永久破壞敵方盾牌，溢出傷害貫入本體)
       ▼
[3. 裂甲斬馬 Barding_Armor_Cleave]
       │ (對重騎造成 190% 破甲傷害，卸除馬甲防禦 -40%)
       ▼
[4. 旋風橫掃 Whirlwind_Axe_Sweep]
       │ (周圍 1 格 AOE 140% 斬傷 + 強制擊退 1 格)
       ▼
[5. 提斧換氣 Axe_Recovery_Stance]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `DRAG_AXE_CHARGE` | 拖斧蓄勢 | 大斧精兵（`STR >= 84`）拖斧前行，移動完畢後下一次劈砍暴擊率 `+25%`。 |
| `OVERHEAD_SHIELD_SPLIT` | 當頭劈盾 | 雙手舉斧垂直猛劈敵方持盾部隊；直接對盾牌耐久造成 `300%` 破壞傷害，盾牌碎裂後永久移除該隊「盾牌格擋與遠程減傷」，且 `50%` 溢出傷害直接貫入本體。 |
| `BARDING_ARMOR_CLEAVE` | 裂甲斬馬 | 若目標為披甲重騎兵，大斧斜劈戰馬胸甲，造成 `190%` 物理傷害並附加永久「馬甲崩裂（物理防禦 `-40%`、衝鋒加成失效）」。 |
| `WHIRLWIND_AXE_SWEEP` | 旋風橫掃 | 當自身周圍 `1` 格內存在 $\ge 2$ 隊敵軍時，腰馬合一掄動大斧旋斬，對周圍所有敵軍造成 `140%` 傷害並強制向後擊退 `1` 格。 |
| `AXE_RECOVERY_STANCE` | 提斧換氣 | 施展旋風橫掃後需換氣 1 回合，期間自身格擋率 `-15%`。 |

## 三、 核心數值與判定公式

### 3.1 劈盾破防與溢出貫穿公式（Shield Split & Overflow）
$$D_{\text{overflow}} = \max\left(0,\ \left(\text{ATK}_{\text{axe}} \times 3.0 - \text{HP}_{\text{shield}}\right) \times 0.50\right)$$
- 當 $\text{ATK}_{\text{axe}} \times 3.0 \ge \text{HP}_{\text{shield}}$ 時，敵方盾牌判定為「永久碎裂（`Shield_Destroyed = true`）」，且超出盾牌耐久之傷害按 `50%` 折算為無視護甲之本體真實斬傷。

### 3.2 旋風橫掃擊退成功率公式（Sweep Knockback Rate）
$$P_{\text{knockback}} = \text{clamp}\left(0.80 + (\text{STR}_{\text{atk}} - \text{STR}_{\text{def}}) \times 0.015 - 0.30 \times \mathbb{I}_{\text{staked}},\ 0.10,\ 0.95\right)$$
- $\mathbb{I}_{\text{staked}}$：若敵方為已釘入地樁之立盾陣（`doc_spec_0866`），抗擊退率提升 `30%`。

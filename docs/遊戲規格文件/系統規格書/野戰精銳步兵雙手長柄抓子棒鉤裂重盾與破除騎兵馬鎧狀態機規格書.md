# 野戰精銳步兵雙手長柄抓子棒鉤裂重盾與破除騎兵馬鎧狀態機規格書

> **來源**：《武經總要》器圖篇步兵重型鉤擊兵器「抓子棒／鐵抓」（於六尺堅木長柄頂端鑄造一隻五指微曲、指尖鋒銳如鷹爪之生鐵巨手，重約十二斤；兼具鈍器砸擊與利爪撕扯雙重特性，專用於一把扣穿敵軍包鐵木盾或扯裂重騎兵之札甲綴革）、WBS `FORM-156` 戰場破甲奪盾步兵模組。
> **關聯文件**：`doc_spec_0886`（長柄生鐵挽手鉤破盾）、`doc_spec_0925`（長柄鐵骨朵重擊）、`doc_spec_0028`（裝備強化系統）。

---

## 一、 設計目標與戰術定位

一般「挽手鉤（`doc_spec_0886`）」僅能勾住盾牌邊緣後拽，若敵兵死死抵住盾心則難以破除；而「雙手長柄抓子棒」則是將十餘斤的生鐵五指巨爪直接迎面砸入盾面中央或重騎馬腹。五根生鐵尖指在重擊動能下直接刺穿木盾或嵌入札甲甲片縫隙，隨即猛力回扯，將整塊盾牌撕裂或把重騎兵連人帶甲扯落馬下。

1. **五指穿盾嵌入（Five-Claw Shield Impale）**：無需尋找盾緣空隙，直接砸穿盾面中心並死死咬合，使敵方無法脫離。
2. **扯裂札甲編繩（Lamellar Cord Rip）**：對抗重甲步騎時，五指鐵爪扣住甲片穿繩猛拽，直接撕開大面積無甲破綻（防禦力永久 `-45%`）。
3. **拖拽拽馬墜地（Drag Rider Dismount）**：扣住敵方騎兵胸甲後合力後拉，強制將騎士從戰馬上拽落，使其喪失騎乘機動與衝鋒能力。

## 二、 狀態機生命週期（5 階段）

```
[1. 揚爪睨敵 Claw_Club_Poised]
       │ (接戰距離 <= 1.5 格，鎖定持盾或重甲目標)
       ▼
[2. 鷹爪貫盾 Iron_Claw_Shield_Embed]
       │ (五指生鐵爪砸穿盾心：160% 鈍穿傷 + 咬死定身)
       ▼
[3. 撕甲裂革 Rip_Lamellar_Armor]
       │ (猛力回扯：扯斷甲繩，目標物理防禦永久 -45%)
       ▼
[4. 拽馬落鞍 Drag_Cavalry_Dismount]
       │ (若目標為騎兵：強制拽落馬下，移速減半禁衝鋒)
       ▼
[5. 振爪卸屑 Claw_Clear_Reset]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `CLAW_CLUB_POISED` | 揚爪睨敵 | 抓子棒精兵（`STR >= 84`）雙手握桿蓄力，對持盾與重甲目標命中率 `+20%`。 |
| `IRON_CLAW_SHIELD_EMBED` | 鷹爪貫盾 | 迎面砸擊，五根生鐵指爪直接刺穿敵方木盾或胸甲表面，造成 `160%` 物理傷害並使目標陷入 1 回合「咬合定身（無法移動或閃避）」。 |
| `RIP_LAMELLAR_ARMOR` | 撕甲裂革 | 雙臂發力猛然回扯，將嵌入盾甲之鐵爪拔出，連帶撕裂敵方盾板與札甲牛皮編繩，使目標物理防禦**永久 `-45%`** 並附加「撕裂流血」。 |
| `DRAG_CAVALRY_DISMOUNT` | 拽馬落鞍 | 若被咬合之目標為騎兵單位，回扯時判定成功（基礎 `75%`）則直接將敵騎拽落馬下，使其降級為步兵（移動力減半、喪失騎兵衝鋒加成）。 |
| `CLAW_CLEAR_RESET` | 振爪卸屑 | 甩脫鐵爪上殘留之碎木與甲片，下回合恢復 `CLAW_CLUB_POISED`。 |

## 三、 核心數值與判定公式

### 3.1 貫盾與撕甲二段總傷害公式（Embed & Rip Total Damage）
$$D_{\text{total}} = D_{\text{base}} \times 1.60_{\text{embed}} + D_{\text{base}} \times 1.25_{\text{rip}} \times \left(1 + \frac{\text{STR}_{\text{atk}} - \text{STR}_{\text{def}}}{100}\right)$$
- 第一段「貫盾」為鈍擊穿刺（`160%`），第二段「回扯撕甲」為力量對抗撕裂傷（基礎 `125%`，我方武力越高撕扯傷害越痛）。

### 3.2 拽馬落鞍成功率公式（Dismount Success Rate）
$$P_{\text{dismount}} = \text{clamp}\left(0.75 + (\text{STR}_{\text{atk}} - \text{STR}_{\text{cavalry}}) \times 0.015,\ 0.30,\ 0.95\right)$$

# 野戰精銳步兵雙手長柄方天畫戟月牙勾盾與中平直刺破甲狀態機規格書

> **來源**：三國傳奇神兵「方天畫戟」（柄長一丈、戟頭中央為修長透甲槍尖，兩側對稱伸出雙月牙利刃並飾以朱紅畫桿與彩絛，兼具「中平直刺穿心、雙月牙左右勾拉破盾、橫擺架格鎖兵」等複合武藝）、WBS `FORM-153` 戰場精銳複合長兵模組。
> **關聯文件**：`doc_spec_0830`（大戟士刺馬破騎）、`doc_spec_0922`（長柄鳳嘴刀三連擊）、`doc_spec_0028`（裝備強化系統）。

## 一、 設計目標與戰術定位

與普通士卒使用的單枝「卜字鐵戟（大戟士）」不同，「方天畫戟」是唯有武藝超群之猛將與親衛精兵（`STR >= 88, DEX >= 85`）方能駕馭的雙月牙複合重兵器。其雙側對稱月牙刃既可向左勾開敵方盾牌、向右鎖住敵將長槍，隨即以中央透甲脊刺直貫胸膛，是單挑與精銳破陣的技術巔峰。

1. **雙月牙架鎖繳械（Twin-Crescent Lock & Disarm）**：交鋒時以戟耳月牙刃叉住敵方長兵器旋轉別壓，封鎖敵方反擊並削弱其攻擊力。
2. **側刃勾盾破防（Crescent Hook Shield-Break）**：利用月牙內側鋒刃回拉割裂持盾手腕或扯開大盾，強行製造空門。
3. **中平透甲直刺（Center-Line Armor Pierce）**：在敵方兵盾被月牙刃牽制的瞬間，中央槍尖直線貫穿咽喉或心窩，造成高倍率致命穿刺。

## 二、 狀態機生命週期（5 階段）

```
[1. 畫戟昂立 Halberd_Poise_Ready]
       │ (接戰距離 <= 2 格，且雙月牙彩絛飛揚威懾)
       ▼
[2. 雙耳鎖兵 Twin_Crescent_Weapon_Lock]
       │ (叉住敵兵器：封鎖敵反擊，敵攻擊力 -25%)
       ▼
[3. 月牙勾盾 Crescent_Hook_Open_Guard]
       │ (回拉破除敵盾牌格擋，暴露胸腹要害)
       ▼
[4. 中平貫心 Center_Spear_Fatal_Pierce]
       │ (中央槍尖直刺：195% 穿甲暴擊傷害，無視 45% 防禦)
       ▼
[5. 旋戟振血 Halberd_Flourish_Reset]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `HALBERD_POISE_READY` | 畫戟昂立 | 方天畫戟親衛或猛將登場，朱紅畫桿彩絛具備視覺威懾，周圍 `2` 格敵軍暴擊抗性 `-15%`。 |
| `TWIN_CRESCENT_WEAPON_LOCK` | 雙耳鎖兵 | 接戰首招以雙月牙枝叉鎖敵方兵器，使目標當回合**無法觸發反擊（Counter-Attack Disabled）**，且攻擊力 `-25%`。 |
| `CRESCENT_HOOK_OPEN_GUARD` | 月牙勾盾 | 手腕一翻，另一側月牙刃回鉤敵方盾牌或護肩，解除目標格擋狀態並附加「門戶洞開（承受暴擊傷害 `+35%`）」。 |
| `CENTER_SPEAR_FATAL_PIERCE` | 中平貫心 | 趁敵兵被鎖、盾牌被勾之剎那，中央透甲槍尖雷霆直刺，造成 `195%` 穿刺傷害，無視目標 `45%` 物理防禦。 |
| `HALBERD_FLOURISH_RESET` | 旋戟振血 | 若此擊成功擊殺敵軍編隊或擊敗敵將，立即振戟回滿行動力並使自身士氣 `+15`。 |

## 三、 核心數值與判定公式

### 3.1 雙耳鎖兵與中平貫心連招傷害公式（Halberd Combo Damage）
$$D_{\text{halberd}} = \max\left(1,\ \text{ATK}_{\text{atk}} \times 1.95 - \text{DEF}_{\text{def}} \times (1 - 0.45)\right) \times \left(1.50 + 0.35 \times \mathbb{I}_{\text{guardOpened}}\right)$$
- 若成功觸發 `CRESCENT_HOOK_OPEN_GUARD`（$\mathbb{I}_{\text{guardOpened}} = 1$），暴擊倍率由基礎 `1.50x` 躍升至 `1.85x`。

### 3.2 武藝門檻檢核公式（Mastery Threshold Check）
$$E_{\text{mastery}} = \begin{cases} 1.0, & \text{STR} \ge 88 \land \text{DEX} \ge 85 \\ 0.70, & \text{otherwise} \end{cases}$$
- 方天畫戟對使用者之臂力與靈巧要求極高；若武力或技巧未達標而強行裝備，雙月牙反而容易卡滯，連招傷害折減為 `70%`。

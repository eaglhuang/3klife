# 野戰精銳步兵雙手長柄月牙鏟推擋長槍與鏟刃斷足狀態機規格書

> **來源**：中國古代奇門重型長兵「月牙方便鏟／雙頭月牙鏟」（柄長八尺、重約十八斤，前端為寬闊平弧形精鋼鏟刃，後端為凹弧形月牙叉刃；兼具「月牙叉推架敵軍長槍群、寬鏟貼地猛推鏟斷敵兵與戰馬雙足、翻鏟拍暈」三大絕技）、WBS `FORM-159` 戰場反長兵與下盤破陣步兵模組。
> **關聯文件**：`doc_spec_0892`（鉤鐮長槍割斬馬足）、`doc_spec_0830`（大戟士刺馬方陣）、`doc_spec_0028`（裝備強化系統）。

---

## 一、 設計目標與戰術定位

面對密集如林的「長槍方陣」或「大戟陣」，一般刀盾步兵極難突破槍尖刺殺圈。「雙手長柄月牙鏟」則專為克制長柄刺擊兵器與重甲下盤而生：步兵先以尾端寬大的凹形「月牙叉」向上架推，一次性叉住並託起敵方數根長槍使其刺擊落空；隨即旋桿掉頭，以沉重鋒利的「平頭寬鏟」貼地猛力前推，專鏟敵兵小腿腳踝與戰馬前蹄（護甲最薄弱處）。

1. **月牙叉架推長兵（Crescent Fork Spear-Deflect）**：對抗長槍、大戟等刺擊武器時，月牙凹弧能精準卡住敵方槍桿向上掀開，大幅降低我方承受之穿刺傷害。
2. **平鏟貼地斷足（Flat Spade Ankle-Sever）**：寬達八寸的精鋼鏟頭貼地平推，避開敵軍厚重的胸甲與盾牌，直取腳踝與馬蹄，造成「斷足殘廢」。
3. **鏟面揚沙迷目（Spade Sand-Fling）**：在沙地、荒原或乾燥平原作戰時，可順勢以寬鏟鏟起地面沙石迎面揚灑，致盲前方敵軍。

## 二、 狀態機生命週期（5 階段）

```
[1. 橫鏟持中 Spade_Guard_Stance]
       │ (接戰距離 <= 2 格，面對敵長槍陣或重步騎)
       ▼
[2. 月牙架槍 Crescent_Fork_Parry]
       │ (凹叉掀開敵長槍：承受穿刺傷 -60%，敵長兵失衡)
       ▼
[3. 揚沙迷眼 Sand_Fling_Blind]
       │ (鏟土迎面拋灑：前方 1 格敵軍命中 -35% 持續 1 回合)
       ▼
[4. 貼地斷足 Ground_Skim_Foot_Sever]
       │ (旋桿平鏟敵下盤：175% 無視胸甲斬傷 + 移動力歸零)
       ▼
[5. 拍鏟鎮壓 Flat_Spade_Slam]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `SPADE_GUARD_STANCE` | 橫鏟持中 | 月牙鏟精兵（`STR >= 80`）雙手持鏟列陣，對長槍兵與戟兵天生具備 `+25%` 招架率。 |
| `CRESCENT_FORK_PARRY` | 月牙架槍 | 當遭受敵方長槍／大戟刺擊時，以月牙端叉住槍桿上推，使本次穿刺傷害減免 `60%`，並使敵方陷入「槍桿揚起（下盤空虛）」。 |
| `SAND_FLING_BLIND` | 揚沙迷眼 | 若處於平原、沙地或山地，反手一鏟揚起碎石塵土，使正前方 `1` 格敵軍陷入 1 回合「沙迷雙目（命中率 `-35%`、無法格擋）」。 |
| `GROUND_SKIM_FOOT_SEVER` | 貼地斷足 | 趁敵方槍桿被掀或雙目迷盲，掉轉平頭寬鏟貼地猛推，專斬腳踝與馬蹄，造成 `175%` 物理傷害（無視 `50%` 胸甲防禦）並附加 2 回合「斷足禁足（移動力歸零）」。 |
| `FLAT_SPADE_SLAM` | 拍鏟鎮壓 | 對已「斷足」跪地之敵軍，以寬大鏟背當頭重拍，追加 `130%` 鈍擊傷害並有 `40%` 機率擊暈。 |

## 三、 核心數值與判定公式

### 3.1 月牙叉反制長槍減傷公式（Anti-Polearm Parry Formula）
$$D_{\text{taken}} = D_{\text{polearmRaw}} \times \left(1 - 0.60 \times \mathbb{I}_{\text{isPolearm}}\right)$$
- 當敵方攻擊武器類別為長槍、長矛或長戟（$\mathbb{I}_{\text{isPolearm}} = 1$）時，月牙叉固定減免 `60%` 穿刺與反騎衝刺傷害。

### 3.2 貼地斷足下盤破甲公式（Lower-Body Armor Bypass）
$$D_{\text{sever}} = \max\left(1,\ \text{ATK}_{\text{spade}} \times 1.75 - \text{DEF}_{\text{target}} \times 0.50\right) \times \left(1 + 0.25 \times \mathbb{I}_{\text{parried}}\right)$$
- 若先一步成功觸發 `CRESCENT_FORK_PARRY` 掀開敵方長兵（$\mathbb{I}_{\text{parried}} = 1$），緊接的貼地斷足傷害額外提升 `+25%`。

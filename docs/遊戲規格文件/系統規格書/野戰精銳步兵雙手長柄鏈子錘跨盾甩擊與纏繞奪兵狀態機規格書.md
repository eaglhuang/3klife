# 野戰精銳步兵雙手長柄鏈子錘跨盾甩擊與纏繞奪兵狀態機規格書

> **來源**：《武經總要》器圖篇步兵軟硬複合重兵「鐵鏈夾棒／長柄鏈子流星錘」（於七尺堅木長柄頂端以三尺生鐵鎖鏈連接一枚八斤重之渾圓生鐵流星錘頭；揮擊時鐵錘借離心力越過敵軍盾牌上緣直擊頭頂與後腦，或以鐵鏈旋轉纏住敵方長槍大刀猛力拽奪）、WBS `FORM-165` 戰場跨盾軟兵破防模組。
> **關聯文件**：`doc_spec_0910`（雙馬連環鐵甲連枷騎兵）、`doc_spec_0925`（長柄鐵骨朵重擊碎腦）、`doc_spec_0028`（裝備強化系統）。

---

## 一、 設計目標與戰術定位

直柄鈍器（如鐵鐧、鐵骨朵）雖能破甲，但攻擊軌跡為直線，若敵方重盾兵將大盾斜舉死守，仍需先砸穿盾牌。而「雙手長柄鏈子錘（鐵鏈夾棒）」在七尺木柄前端加裝三尺活動鐵鏈與重錘：當長柄被敵方盾緣擋住瞬間，前端鐵錘受慣性與離心力驅動，會自動沿弧線「繞過盾牌頂端（Wrap-Around Shield）」直接砸向盾後敵兵的頭顱與後頸，令一切正面盾牌格擋形同虛設。

1. **離心跨盾甩擊（Centrifugal Shield-Bypass）**：完全無視敵方正面盾牌格擋率與盾牆加成，鐵錘繞過盾緣直擊頭顱。
2. **鎖鏈纏兵奪械（Chain Entangle & Disarm）**：旋轉長柄使三尺鐵鏈像靈蛇般纏死敵方長槍或大刀，猛力回拽直接繳械敵軍。
3. **迴旋加速連擊（Momentum Spin Combo）**：鏈子錘一旦掄轉起來，每一次命中後的反彈動能可順勢轉化為下一圈旋擊，越打越快。

## 二、 狀態機生命週期（5 階段）

```
[1. 旋錘蓄動 Spin_Momentum_Build]
       │ (接戰距離 <= 2 格，搖動長柄使前端鐵錘高速旋轉)
       ▼
[2. 跨盾砸顱 Shield_Wrap_Head_Smash]
       │ (繞過盾牌頂端：100% 無視盾牌格擋，造成 175% 鈍擊傷)
       ▼
[3. 鐵鏈纏兵 Chain_Entangle_Disarm]
       │ (鎖鏈絞住敵方兵器回拽：繳械 2 回合，敵攻擊力 -40%)
       ▼
[4. 借力連環 Centrifugal_Double_Strike]
       │ (借反彈慣性順勢二連砸：追加 145% 後腦重擊 + 暈眩)
       ▼
[5. 收鏈定柄 Chain_Retract_Reset]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `SPIN_MOMENTUM_BUILD` | 旋錘蓄動 | 鏈子錘精兵（`STR >= 82, DEX >= 80`）進場旋動鐵錘，離心動能使首擊射程達 `2` 格。 |
| `SHIELD_WRAP_HEAD_SMASH` | 跨盾砸顱 | 揮桿猛擊，木柄拍擊盾面的同時，三尺鐵鏈帶動八斤鐵錘繞過盾頂砸中敵兵天靈蓋，**100% 無視盾牌格擋與舉盾減傷**，造成 `175%` 破甲鈍擊。 |
| `CHAIN_ENTANGLE_DISARM` | 鐵鏈纏兵 | 順勢手腕畫圓，使鐵鏈緊緊纏繞敵方所持刀槍並猛力後拽；判定成功（基礎 `70%`）則強制「繳械（2 回合內敵方攻擊力 `-40%` 且無法使用武器戰技）」。 |
| `CENTRIFUGAL_DOUBLE_STRIKE` | 借力連環 | 若跨盾砸顱成功命中，鐵錘借反彈力道高速迴旋一週，立即對同一目標或相鄰 `1` 格敵軍追加 `145%` 二段甩擊，並有 `45%` 機率擊暈。 |
| `CHAIN_RETRACT_RESET` | 收鏈定柄 | 連擊結束後收穩擺動之鐵錘，下回合恢復 `SPIN_MOMENTUM_BUILD`。 |

## 三、 核心數值與判定公式

### 3.1 跨盾甩擊無視盾防公式（Shield-Bypass Damage Formula）
$$D_{\text{flail}} = \max\left(1,\ \text{ATK}_{\text{flail}} \times 1.75 - \text{DEF}_{\text{bodyOnly}} \times 0.60\right) \times \left(1 + 0.20 \times \mathbb{I}_{\text{targetHasShield}}\right)$$
- $\text{DEF}_{\text{bodyOnly}}$：計算防禦時完全剔除敵方盾牌提供之防禦值；且敵方越依賴大盾防守（$\mathbb{I}_{\text{targetHasShield}} = 1$），因視線被自家大盾遮擋而無法閃避跨盾鐵錘，承受傷害反而額外 `+20%`。

### 3.2 鐵鏈纏繞繳械成功率公式（Chain Disarm Rate）
$$P_{\text{disarm}} = \text{clamp}\left(0.70 + (\text{DEX}_{\text{atk}} - \text{DEX}_{\text{def}}) \times 0.015,\ 0.25,\ 0.90\right)$$

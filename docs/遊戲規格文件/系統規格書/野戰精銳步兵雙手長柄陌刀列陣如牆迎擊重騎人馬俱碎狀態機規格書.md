# 野戰精銳步兵雙手長柄陌刀列陣如牆迎擊重騎人馬俱碎狀態機規格書

> **來源**：漢代斬馬劍演進至唐代巔峰之重步兵決戰兵器「長柄陌刀」（通長一丈、雙刃厚脊、重十五斤以上，步兵雙手緊握列成密集刀牆，口呼「進則人馬俱碎」，專門正面硬撼甲騎具裝衝鋒）、WBS `FORM-147` 戰場頂級反騎步兵方陣模組。
> **關聯文件**：`doc_spec_0907`（長柄斬馬劍旋劈）、`doc_spec_0901`（大砍刀斬馬首）、`doc_spec_0830`（大戟士刺馬破騎）。

---

## 一、 設計目標與戰術定位

「雙手長柄陌刀」為野戰重步兵對抗具裝重騎兵的終極陣地戰武器。與強調個人旋劈的斬馬劍或單點斬馬首的大砍刀不同，陌刀講究「列陣如牆、齊步平推」。全隊百柄陌刀同時高舉、同時斜劈而下，不僅能將衝鋒騎兵連人帶馬一刀兩斷（「人馬俱碎」），更能以刀牆推進反向碾壓敵軍步兵陣線。

1. **列陣如牆（Blade Wall Formation）**：陌刀兵編隊保持密集陣型時，免疫騎兵衝鋒帶來的「撞飛／擊退」與「恐懼動搖」效果。
2. **迎鋒反劈（Counter-Charge Cleave）**：當敵方騎兵向陌刀陣發起衝鋒時，陌刀牆在接敵瞬間觸發「先制齊劈」，將敵騎衝鋒速度轉化為雙倍反斬傷害。
3. **人馬俱碎威懾（Shatter Awe）**：一旦單次齊劈斬殺敵騎超過該隊編制 `30%`，周圍 `2` 格內所有敵軍騎兵強制陷入「怯戰停蹄（無法發動衝鋒）」。

## 二、 狀態機生命週期（5 階段）

```
[1. 刀牆森立 Blade_Wall_Locked]
       │ (密集列陣：免疫衝鋒擊退與恐懼，等待敵騎突入)
       ▼
[2. 迎騎先制 Counter_Charge_Intercept]
       │ (敵騎衝入 1 格：先於敵騎結算齊劈，借速增傷)
       ▼
[3. 人馬俱碎 Rider_Mount_Shatter]
       │ (對騎兵造成 220% 破甲斬擊，無視 50% 坐騎護甲)
       ▼
[4. 血霧威懾 Crimson_Awe_Panic]
       │ (單次削減敵騎 >= 30%：2 格內敵騎怯戰禁衝鋒)
       ▼
[5. 排山平推 Advancing_Wall_Push]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `BLADE_WALL_LOCKED` | 刀牆森立 | 陌刀精兵（`STR >= 85, LEA >= 80`）開啟方陣，正面物理減傷 `+30%`，完全免疫騎兵衝鋒擊退與戰馬驚駭。 |
| `COUNTER_CHARGE_INTERCEPT` | 迎騎先制 | 敵方騎兵從正面或側前方發起衝鋒進入 `1` 格時，陌刀陣必定觸發**先制攻擊**（優先於騎兵衝撞結算）。 |
| `RIDER_MOUNT_SHATTER` | 人馬俱碎 | 百刀齊落，對騎兵單位造成 `220%` 毀滅性斬擊傷害，無視 `50%` 護甲，且敵騎衝鋒距離越長，反斬傷害越高。 |
| `CRIMSON_AWE_PANIC` | 血霧威懾 | 若此擊單次消滅敵騎兵力達 `30%` 以上，血霧震懾全場，使周圍 `2` 格內所有敵方騎兵陷入 2 回合「怯馬止步（移動力 `-2`、禁止發動衝鋒）」。 |
| `ADVANCING_WALL_PUSH` | 排山平推 | 斬碎敵騎後，陌刀牆向前平推 `1` 格，對正前方殘存步騎追加 `135%` 壓迫斬擊。 |

## 三、 核心數值與判定公式

### 3.1 人馬俱碎反騎傷害公式（Shatter Cavalry Damage）
$$D_{\text{modao}} = D_{\text{base}} \times 2.20 \times \left(1 + 0.18 \times L_{\text{enemyCharge}}\right) \times \left(1 + \frac{\text{STR}_{\text{atk}} + \text{LEA}_{\text{atk}}}{300}\right)$$
- $L_{\text{enemyCharge}}$：敵方騎兵本次衝鋒助跑格數（助跑越長、動能越大，撞上陌刀牆時的「人馬俱碎」反噬越慘烈）。

### 3.2 刀牆陣型維持檢定（Formation Integrity Check）
- 陌刀牆必須保持兵力 $\ge 40\%$ 且未處於「混亂」狀態方可維持 `BLADE_WALL_LOCKED`；若遭敵方重型投石機散彈或側後包抄導致陣型潰散，則失去先制反騎特權。

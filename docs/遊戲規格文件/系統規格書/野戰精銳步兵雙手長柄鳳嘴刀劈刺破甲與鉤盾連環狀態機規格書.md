# 野戰精銳步兵雙手長柄鳳嘴刀劈刺破甲與鉤盾連環狀態機規格書

> **來源**：三國傳世名兵「鳳嘴刀」（刀身窄長微彎、刀尖凸出如鳳喙、刀背前端設鉤齒，兼具重劈破甲、直刺咽喉與回拉鉤盾三種戰技）、WBS `FORM-141` 戰場特殊近戰兵種模組。
> **關聯文件**：`doc_spec_0012`（戰場局勢系統）、`doc_spec_0028`（裝備強化系統）、`doc_spec_0907`（斬馬劍旋劈狀態機）。

---

## 一、 設計目標與戰術定位

「鳳嘴刀」為重裝精銳步兵所持之雙手長柄大刀（全刀長八尺五寸，重二十四斤）。與大砍刀或斬馬劍不同，鳳嘴刀憑藉獨特的「鳳喙尖刺」與「刀背倒鉤」，能在「直刺咽喉、斜劈重甲、回鉤破盾」三種擊技間流暢切換。

1. **三段連環擊技（鉤盾 → 破甲 → 鳳喙穿喉）**：面對持盾重步兵時，先以刀背倒鉤扯開盾牌，緊接重劈碎裂胸甲，最後以鳳喙直刺要害。
2. **無視盾牌格擋率與強制破防**：第一式「回鉤奪盾」成功時，直接剝奪敵方盾牌帶來的格擋率與遠程減傷加成。
3. **重兵器的體力消耗與靈巧門檻**：施展三段連環需較高武力（STR）與技巧（DEX），若遭輕騎兵側面游擊則轉向較慢。

## 二、 狀態機生命週期（5 階段）

```
[1. 蓄勢持刀 Stance_Ready]
       │ (進入近戰交鋒距離 <= 1.5 格，且敵方持盾或重甲)
       ▼
[2. 背鉤扯盾 Back_Hook_Disarm] ──(敵方無盾)──> 直接跳入 [3. 重劈裂甲]
       │ (扯開敵方盾牌：破除格擋狀態 2 回合)
       ▼
[3. 斜劈裂甲 Heavy_Cleave_Armor]
       │ (造成 165% 物理傷害，削弱護甲 35%)
       ▼
[4. 鳳喙穿喉 Phoenix_Beak_Thrust]
       │ (對已破甲目標直刺：必中暴擊 + 流血 2 回合)
       ▼
[5. 收刀調息 Stance_Recovery]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `STANCE_READY` | 蓄勢持刀 | 精銳鳳嘴刀兵編隊（`STR >= 80`）進入戰場，正面招架率 `+20%`。 |
| `BACK_HOOK_DISARM` | 背鉤扯盾 | 交鋒首擊以刀背鉤齒扣住敵方盾緣猛拉；判定成功（基礎 `75% + (我方STR - 敵方STR)*1.5%`）則強制解除敵方「舉盾格擋」，2 回合內格擋率歸零。 |
| `HEAVY_CLEAVE_ARMOR` | 斜劈裂甲 | 趁敵方門戶大開，順勢旋身斜劈，造成 `165%` 物理傷害並附加「裂甲（物理防禦 `-35%`）」。 |
| `PHOENIX_BEAK_THRUST` | 鳳喙穿喉 | 刀勢不停，手腕翻轉以刀尖鳳喙直刺咽喉縫隙；若目標處於「裂甲」狀態，此擊必定暴擊（`1.8x`）並附加「動脈流血（每回合損失 `7%` 最大兵力，持續 2 回合）」。 |
| `STANCE_RECOVERY` | 收刀調息 | 三連擊施展完畢後需調息 1 回合，期間移動力 `-1`、側面閃避率 `-15%`。 |

## 三、 核心數值與判定公式

### 3.1 背鉤扯盾成功率（Hook Disarm Rate）
$$P_{\text{hook}} = \text{clamp}\left(0.75 + (\text{STR}_{\text{atk}} - \text{STR}_{\text{def}}) \times 0.015 - W_{\text{shield}} \times 0.10,\ 0.25,\ 0.95\right)$$
- $W_{\text{shield}}$：敵方盾牌重量等級（藤牌 `0.5`、木鐵圓盾 `1.0`、生鐵巨盾 `2.0`）。

### 3.2 三段連環總傷害公式（Combo Total Damage）
$$D_{\text{combo}} = D_{\text{base}} \times \left(1.65_{\text{cleave}} + 1.80_{\text{thrust}} \times \mathbb{I}_{\text{armorBroken}}\right) \times \left(1 + \frac{\text{STR}_{\text{atk}}}{200}\right)$$
- $\mathbb{I}_{\text{armorBroken}}$：若第二段成功觸發「裂甲」，則第三段鳳喙直刺享受 `1.80` 倍必暴倍率，否則為 `1.15` 倍普通直刺。

## 四、 資料結構契約（TypeScript Interface）

```typescript
/**
 * 鳳嘴刀劈刺破甲與鉤盾連環狀態枚舉
 */
export enum PhoenixBeakGlaiveState {
  STANCE_READY = 'STANCE_READY',
  BACK_HOOK_DISARM = 'BACK_HOOK_DISARM',
  HEAVY_CLEAVE_ARMOR = 'HEAVY_CLEAVE_ARMOR',
  PHOENIX_BEAK_THRUST = 'PHOENIX_BEAK_THRUST',
  STANCE_RECOVERY = 'STANCE_RECOVERY',
}

/**
 * 鳳嘴刀連環擊技配置契約
 */
export interface PhoenixBeakGlaiveConfig {
  /** 規格書識別碼 */
  specId: 'PHOENIX-BEAK-GLAIVE-HOOK-CLEAVE01';
  /** 基礎扯盾成功率 (0.75) */
  baseHookSuccessRate: number;
  /** 斜劈傷害倍率 (1.65) */
  cleaveDamageMultiplier: number;
  /** 裂甲降防比例 (0.35) */
  armorReductionRatio: number;
  /** 鳳喙穿喉暴擊倍率 (1.80) */
  thrustCritMultiplier: number;
  /** 動脈流血每回合比例 (0.07) */
  bleedMaxHpRatioPerTurn: number;
  /** 連擊後調息回合數 (1) */
  recoveryTurns: number;
}
```

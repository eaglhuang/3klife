# 3KLife 野戰藤甲步兵浸油黑藤鎧免疫普通箭矢與火攻致命弱點狀態機規格書

## 1. 系統定位與設計意圖

在三國南中特種步兵作戰（如諸葛亮南征遭遇烏戈國兀突骨藤甲軍、盤蛇谷火燒藤甲兵）中，以深山老青藤經桐油反覆浸泡半年、暴曬編織而成的「浸油黑藤甲（Oiled Rattan Armor）」，具備刀砍不入、箭射皆彈、渡水不沉之逆天物理防禦特性，但同時背負「遇火即燃、烈焰焚身」的極端生剋弱點。本系統規範藤甲步兵之彈開箭矢、浮水急行與遇火連鎖自焚狀態機：
- **桐油浸潤韌藤編織輕甲**：甲體重量僅為同級生鐵甲之四分之一，兼具極高韌性與滑溜度；普通弓弩羽箭與刀劍劈砍觸及藤甲表面即被彈飛。
- **江河浮水不沉渡江突襲**：乾燥油藤富含氣孔且外部拒水，藤甲兵無需舟船即可跳入江河浮水涉渡，水中移動速度與陸地無異。
- **浸油引燃三倍火傷與連鎖傳火**：藤甲飽含熟桐油，一旦遭受火箭或猛火油擦碰，點燃機率 100%，火焰無法用水撲滅，承受 350% 毀滅性火傷並引燃相鄰三步內之同袍。

## 2. 狀態機架構與轉換生命週期

藤甲步兵物理免疫與火攻弱點狀態機（代碼：`RATTAN-ARMOR-ARROW-IMMUNE-FIRE-WEAK01`）流程如下：

```
[ RATTAN_PHALANX_ADVANCE ] (藤甲兵持蠻刀藤牌高速推進無視體力重負)
           │
           ├── 遭受敵軍普通弓弩齊射或刀矛劈刺
           ▼
[ ARROW_BLADE_DEFLECTION ] (油滑堅韌藤條全數彈開箭矢與普通冷兵器)
           │
           ├── 進入淺灘或深水江河地形
           ▼
[ BUOYANT_RIVER_WADING ] (借藤甲浮力直接浮水高速橫渡奇襲對岸)
           │
           ├── 遭遇火箭 / 猛火油 / 乾燥火攻地形 ──> [ OIL_SATURATED_IGNITION ]
           ▼
[ UNQUENCHABLE_BLAZE_AGONY ] (桐油藤甲瞬間劇烈爆燃承受三倍真實火傷)
           │
           ▼
[ CONTAGIOUS_FIRE_CHAIN ] (火人四處狂奔引燃周圍三步內所有藤甲同袍)
           │
           ▼
[ ASH_ANNIHILATION_ROUT ] (全隊在十秒內燒成焦炭徹底團滅)
```

### 狀態細部定義

1. **RATTAN_PHALANX_ADVANCE（輕捷突進）**：因藤甲極輕，藤甲兵雖擁有重甲防禦，卻保有輕步兵高移速（每秒 4.5 公尺）。
2. **ARROW_BLADE_DEFLECTION（刀箭不入）**：面對非破甲類普通弓箭、弩矢與刀劍，觸發 95% 彈開率，僅承受 1 點強制擦傷。
3. **BUOYANT_RIVER_WADING（浮水涉渡）**：踏入河流地形時，不觸發溺水判定與減速，反而獲得水戰閃避 +20% 加成。
4. **OIL_SATURATED_IGNITION（遇火即燃）**：只要受到任何帶有 `FIRE` 屬性之攻擊或踏入火海格，豁免檢定強制失敗，立即進入狂暴燃燒。
5. **UNQUENCHABLE_BLAZE_AGONY（烈火焚身）**：桐油助燃使火焰緊貼皮膚，每秒損失 15% 最大生命值，且普通雨水無法熄滅。
6. **CONTAGIOUS_FIRE_CHAIN（火勢傳染）**：著火之藤甲兵陷入恐慌亂竄，每秒將火焰傳染給半徑 3 公尺內所有未起火之藤甲單位。
7. **ASH_ANNIHILATION_ROUT（灰飛煙滅）**：若全隊超過 50% 成員起火，部隊士氣直接鎖死為 0，於 10 秒內全軍覆沒。

## 3. 數值模型與物理演算

### 物理箭矢彈開與鈍擊減免公式

$$D_{physical} = \begin{cases} 1, & \text{if } \text{AttackType} \in \{\text{ARROW}, \text{SLASH}\} \\ D_{raw} \times 0.65, & \text{if } \text{AttackType} = \text{BLUNT\_CRUSH} \end{cases}$$

- 普通箭矢與斬擊傷害強制降為 1；唯獨面對三棱鐵鐧、狼牙連枷或千斤擂石等純鈍擊（`BLUNT_CRUSH`）時，仍會承受 65% 內傷。

### 火屬性致命放大與連鎖公式

$$D_{fire} = D_{fire\_raw} \times 3.5 + 0.15 \times \text{HP}_{max} \quad (\text{每秒})$$

$$P_{infect} = \min\left(1.0, \; 0.85 + 0.05 \times N_{burning\_neighbors}\right)$$

- 火焰傷害放大 $3.5$ 倍並附加每秒 15% 最大生命真實灼燒；相鄰傳染率高達 90% 以上。

## 4. 戰場戰術連鎖與部隊生剋

1. **普通弓兵與輕步兵絕望之牆**：在敵軍未配備火器與火箭的情況下，藤甲兵可正面擊潰五倍於己的普通弓箭手與刀盾兵。
2. **火攻戰法絕對死穴**：一旦敵軍擁有火攻名將或配備火箭營、猛火油車，藤甲兵將瞬間化為自殺火海。
3. **重錘鈍擊次級克制**：若無火攻手段，可派遣雙馬連枷騎兵或破甲鐵鐧兵以純粹鈍擊震傷其內臟。

## 6. 驗證標準與測試用例 (TC)

- **TC-RATTAN-01（普通箭矢免疫）**：遭受 100 支普通羽箭射擊時，95% 以上攻擊傷害被強制結算為 1 點。
- **TC-RATTAN-02（涉水不減速）**：進入河流地形時，`isFloatingOnWater` 為 `true`，移動速度維持 100% 陸地速度。
- **TC-RATTAN-03（遇火三倍傷害與連鎖）**：1 名藤甲兵被火箭命中後立即起火，並在 3 秒內引燃周圍 3 公尺內之同隊藤甲兵。

# 3KLife 野戰重裝步兵三棱破甲鐵鐧貼身鈍擊震碎玄甲狀態機規格書

## 1. 系統定位與設計意圖

在三國白刃近身混戰與攻堅肉搏（如典韋雙鐵戟貼身護衛、黃蓋持鐵鞭破陣、重甲陷陣步兵內圍廝殺）中，當雙方步騎陷入擁擠不堪的貼身纏鬥時，長槍無法施展，普通環首刀又難以劈開敵軍精良的雙層明光鎧或盆領重甲。本系統規範三國近身破甲重器「四棱與三棱無刃生鐵破甲鐵鐧／鐵鞭貼身鈍擊震碎內臟系統（Iron Mace Armor-Crush Combat）」狀態機：
- **三尺無刃實心百煉生鐵三棱重鐧**：通體以實心熟鐵與生鐵合鍛，無開刃但棱角分明，重達十二至十六斤，重心靠前，永不卷刃折斷。
- **欺身貼靠頂盾撞擊與短距砸擊**：持鐧武士左手持小圓鐵盾或鐵護臂硬頂敵兵長矛，欺身貼入三尺以內死角，右手揮動鐵鐧直接砸向敵軍胸甲、肩甲與頭盔。
- **凹陷鎖死與高頻鈍擊內傷**：三棱重鐧砸中鐵甲時，強大衝擊力使甲葉嚴重凹陷變形並卡死敵兵關節，同時震波穿透甲冑直接震裂肋骨與內臟，專剋高防禦重甲單位。

## 2. 狀態機架構與轉換生命週期

三棱鐵鐧破甲狀態機（代碼：`IRON-MACE-ARMOR-CRUSH-COMBAT01`）流程如下：

```
[ CLOSE_QUARTER_SHIELD_BARGE ] (左手鐵護臂格開長矛欺身撞入三尺貼身圈)
           │
           ├── 貼近敵方重甲步兵或下馬騎士
           ▼
[ HIGH_OVERHEAD_MACE_RAISE ] (右手高舉十六斤三棱鐵鐧鎖定肩胸甲葉)
           │
           ├── 沉肩墜肘爆發砸落 ──> [ PRISMATIC_EDGE_CRUSH_STRIKE ]
           ▼
[ ARMOR_PLATE_DENT_DEFORM ] (鐵鐧棱脊砸塌敵胸甲使甲葉凹陷壓迫胸腔)
           │
           ├── 衝擊震波穿透內襯引發內出血
           ▼
[ INTERNAL_SHOCK_STUN_LOCK ] (敵兵肋骨折斷口吐鮮血陷入窒息僵直)
           │
           ▼
[ JOINT_SMASH_IMMOBILIZE ] (連續追砸敵肩肘關節徹底廢除其揮刀能力)
           │
           ▼
[ GUARD_STANCE_RESET ] (收回鐵鐧護住胸前準備迎擊下一名近敵)
```

### 狀態細部定義

1. **CLOSE_QUARTER_SHIELD_BARGE（欺身撞靠）**：步兵壓低重心以鐵護臂盪開敵方長兵器，強行突入三尺（1 公尺）以內貼身肉搏距離。
2. **HIGH_OVERHEAD_MACE_RAISE（舉鐧蓄勢）**：單手或雙手將沉重鐵鐧舉過頭頂，利用重力位能疊加臂力。
3. **PRISMATIC_EDGE_CRUSH_STRIKE（三棱重砸）**：鐵鐧尖銳棱角集中所有動能於一線，狠狠砸在敵軍堅硬鐵甲表面。
4. **ARMOR_PLATE_DENT_DEFORM（甲葉塌陷）**：敵方重甲耐久度瞬間削減 40%，凹陷之鐵片反向刺入敵兵皮肉，使其防禦力永久轉化為負面束縛。
5. **INTERNAL_SHOCK_STUN_LOCK（震波內傷）**：高達 70% 的鈍擊能量轉為無視護甲之真實內傷，目標陷入 1.5 秒【窒息暈眩】。
6. **JOINT_SMASH_IMMOBILIZE（碎骨廢武）**：趁敵僵直順勢橫敲其右肩或手腕，使敵兵武器脫手或攻速暴跌 50%。
7. **GUARD_STANCE_RESET（收鐧回防）**：因鐵鐧無刃但極重，可當作鐵棍直接架擋敵方大刀劈砍而不損分毫。

## 3. 數值模型與物理演算

### 護甲逆轉加成與真實內傷公式

$$D_{internal} = D_{base} \times \left(1.0 + 0.008 \times \text{DEF}_{target\_armor}\right) \times \left(1.0 + 0.005 \times \text{STR}_{attacker}\right)$$

- $\text{DEF}_{target\_armor}$：目標穿戴之護甲防禦值。目標護甲越厚重（如玄甲防禦 80），三棱鐵鐧砸擊產生的凹陷共振反而造成額外 64% 真實傷害。

### 甲葉變形減速與繳械機率公式

$$P_{disarm} = \min\left(0.65, \; 0.20 + 0.004 \times \text{STR}_{attacker} + 0.15 \times \text{IsTargetStunned}\right)$$

- 對已處於震波暈眩之敵兵追加關節砸擊時，有高達 60% 機率直接打落其手中兵器。

## 4. 戰場戰術連鎖與部隊生剋

1. **重甲鐵衛與名將剋星**：在混戰中專門針對敵方穿戴頂級重鎧之精銳親衛隊與先登死士，使其高昂護甲形同虛設。
2. **兵器耐久無限**：鐵鐧在招架任何刀劍劈砍時永不損耗耐久度，且有 25% 機率反震折斷敵方薄刃刀劍。
3. **攻擊距離短淺限制**：鐵鐧有效攻擊距離僅 1.2 公尺，在開闊地若無法欺身貼近，易被長槍兵保持距離刺殺。

## 6. 驗證標準與測試用例 (TC)

- **TC-IRON-MACE-01（高甲額外增傷）**：攻擊護甲值 80 之重甲目標時，造成的內傷必須高於攻擊護甲值 10 之輕裝目標 $\ge 45\%$。
- **TC-IRON-MACE-02（甲葉變形減益）**：目標承受重砸後，`isArmorDeformed` 為 `true`，其移動速度與閃避率永久下降 25%。
- **TC-IRON-MACE-03（震斷敵刃判定）**：格擋敵方普通環首刀攻擊時，驗證鐵鐧耐久度維持 100% 且觸發反震判定。

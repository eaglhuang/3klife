# 3KLife 野戰重裝步兵以鉤鐮長槍割斬戰馬足筋破重騎狀態機規格書

## 1. 系統定位與設計意圖

在三國時期重裝甲騎具裝（如曹魏虎豹騎、袁紹大戟士與鐵騎）正面衝擊時，戰馬全體覆蓋硬皮生鐵馬甲，常規長槍直刺極易打滑彈開，無法阻止重騎兵的破陣衝撞。本系統規範古代反重騎特種兵器戰術「鉤鐮長槍伏地割斬馬足筋破甲術（Hook-Sickle Spear Hamstring Cavalry）」之伏身下潛、側向勾割、馬蹄折損與甲騎倒地聚殲狀態機：
- **長柄鋒利反刃生鐵鉤鐮槍**：槍頭旁側鍛造一道如同新月之內弧反刃薄鐮，既可正面直刺，亦可側向橫拉割截。
- **伏身貼地避開馬槊衝擊**：重步兵手持短藤牌伏於鹿砦拒馬空隙或長草叢中，主動避開騎兵高聳的馬槊平端穿透線。
- **專攻戰馬無甲脆弱足筋**：當敵重騎戰馬減速越障之瞬間，鉤鐮槍橫向閃電勾拉戰馬膝蓋下方之腓腸肌腿筋，戰馬吃痛跪地失衡。

## 2. 狀態機架構與轉換生命週期

鉤鐮槍破騎狀態機（代碼：`HOOK-SICKLE-SPEAR-HAMSTRING-CAVALRY01`）管理自伏地待命至聚殲倒地重騎之完整週期：

```
[ CROUCH_TERRAIN_CONCEAL ] (步兵伏身於拒馬後貼地規避馬槊)
          │
          ▼
[ CAVALRY_MOMENTUM_STALL ] (敵重騎衝撞鹿角減速失速打轉)
          │
          ├── 露出戰馬下盤無甲足筋
          ▼
[ HOOK_SWEEP_HAMSTRING ] (鉤鐮槍反刃由下而上猛力拉割馬腿)
          │
          ├── 足筋斷裂動脈割破
          ▼
[ WARHORSE_CRITICAL_COLLAPSE ] (戰馬劇痛長嘶前蹄跪折轟然倒地)
          │
          ▼
[ KNIGHT_PINNED_UNDER_MOUNT ] (重裝騎士被千斤戰馬壓身動彈不得)
          │
          ▼
[ DAGGER_VISOR_EXECUTION ] (步兵持短匕刺入面甲縫隙完成殲敵)
```

### 狀態細部定義

1. **CROUCH_TERRAIN_CONCEAL（伏身潛伏）**：
   - 鉤鐮槍兵三人一組，單膝跪地或俯臥於散兵坑內，槍身平放於草叢中，遠離敵方騎士平端馬槊之威脅高度。
2. **CAVALRY_MOMENTUM_STALL（騎兵受阻）**：
   - 敵重騎兵衝至前沿鹿砦陣列，速度由 12 m/s 驟降至 3 m/s，戰馬仰首躊躇。
3. **HOOK_SWEEP_HAMSTRING（勾割足筋）**：
   - 步卒自泥地暴起，長柄鉤鐮貼地平掃，弧形鐮刃精準勾入戰馬後腿後側韌帶，合力向後猛拉，割斷足筋。
4. **WARHORSE_CRITICAL_COLLAPSE（戰馬跪倒）**：
   - 失去支撐之八百斤戰馬瞬間向前側翻滾倒，形成巨大重力衝擊。
5. **KNIGHT_PINNED_UNDER_MOUNT（騎士受壓）**：
   - 身披 60 斤生鐵明光重甲的騎士被倒下的坐騎死死壓住下肢，短時間內完全喪失行動能力。
6. **DAGGER_VISOR_EXECUTION（精準終結）**：
   - 輔助步兵踏上馬身，拔出生鐵破甲錐或短匕首，直插騎士喉甲縫隙，乾脆俐落終結強敵。

## 3. 關鍵數值與計算判定公式

### 3.1 割斷足筋與倒地摔傷機率

鉤鐮槍勾割成功率 $P_{cut}$：
$$P_{cut} = \text{clamp01}\left(\frac{\text{Skill}_{hook} \times (1.0 - \frac{V_{horse\_speed}}{15})}{M_{agility} \times 0.65} + \text{AbatisSupport}\right)$$
- $\text{Skill}_{hook}$：鉤鐮槍兵專精熟練度。
- $V_{horse\_speed}$：戰馬衝鋒當前速度（越慢成功率越高；停滯時成功率超 85%）。
- $\text{AbatisSupport}$：若在鹿角拒馬掩護下，額外增加 0.25 成功加成。

### 3.2 倒地重壓癱瘓時長

重裝騎士受困於馬身下之癱瘓時間 $T_{pinned}$（秒）：
$$T_{pinned} = \frac{M_{horse} \times 0.05 + M_{armor} \times 0.20}{\text{Strength}_{knight}} \times 15.0$$
- 常規重裝甲騎被壓倒後至少癱瘓 25 秒，期間防禦力清零，任由步兵處置。

## 4. 戰術連鎖與攻防克制

1. **廉價步兵克制昂貴重騎**：以最低裝備成本完全瓦解敵方耗費巨資打造之鐵騎核心。
2. **天敵與戰術反制**：
   - **弓騎兵環形放風箏**：若遭遇輕裝胡騎遠程射擊，伏地鉤鐮槍兵無法近身，易被持續消耗。
   - **步騎混編伴隨護衛**：敵軍若派遣刀盾短兵伴隨騎兵前進，可提前格擋並斬斷長槍柄。

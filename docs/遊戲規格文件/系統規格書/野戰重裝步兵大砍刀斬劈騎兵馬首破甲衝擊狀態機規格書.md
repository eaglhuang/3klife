# 3KLife 野戰重裝步兵大砍刀斬劈騎兵馬首破甲衝擊狀態機規格書

## 1. 系統定位與設計意圖

在三國激烈野戰步騎交鋒中（如合肥之戰張遼破陣、界橋之戰麴義大破公孫瓚白馬義從），面對具備毀滅性動能的高速重騎兵衝鋒，傳統步兵長矛極易被馬甲震斷踩踏。本系統規範三國特種步兵「重型開山厚背大砍刀（陌刀／大砍刀前身）迎鋒斬首正面格殺系統（Broadsword Decapitate Cavalry Shock）」之沉步沉氣、死線出刀、馬首斬劈與步騎動能抵消狀態機：
- **死線沉腰拒馬蓄勢姿態**：重裝步兵身披雙層明光玄甲，雙手緊握長約六尺、重達十八斤之厚背鍛鐵大砍刀，沉身蓄力於戰馬逼近最後三步之死線。
- **瞬時斬劈破甲斬斷馬首**：藉由腰腿合一之迴旋下劈，大刀刀刃撕裂戰馬生鐵面簾或頸部軟肋，給予致命重擊使戰馬瞬間失控傾倒。
- **動能急煞與戰馬翻滾重壓**：高速狂奔之重騎前足折斷或馬首受創，數百斤戰馬連帶騎士向前方翻滾摔出，破壞後續騎兵列陣衝擊波。

## 2. 狀態機架構與轉換生命週期

大砍刀斬劈騎兵狀態機（代碼：`BROADSWORD-DECAPITATE-CAVALRY-SHOCK01`）流程如下：

```
[ STANCE_BRACE_WAITING ] (重步兵沉腰握刃靜候敵騎衝鋒進入三步死線)
           │
           ├── 戰馬進入三步（約 4.5 公尺）斬劈極限區
           ▼
[ DEADLINE_TIMING_ALIGN ] (精準捕捉馬首下沉呼吸節奏鎖定頸動脈)
           │
           ├── 爆發出刀雷霆下劈 ──> [ CLEAVE_EXECUTION_STRIKE ]
           ▼
[ HORSE_HEAD_BLOW_IMPACT ] (刀刃破開鐵甲劈斷馬頸震碎頸椎骨)
           │
           ├── 戰馬前衝動能瞬間失衡折倒
           ▼
[ CATACLYSMIC_HORSE_FALL ] (數百斤戰馬重重撲地向前方滑鏟翻滾)
           │
           ├── 倒地戰馬絆翻側後方跟進騎兵
           ▼
[ SECONDARY_FORMATION_TRIP ] (後續騎兵梯隊連鎖絆倒動能歸零)
           │
           ▼
[ RECOVER_BRACE_RESET ] (拔刀回防調整站位銜接下一波衝擊)
```

### 狀態細部定義

1. **STANCE_BRACE_WAITING（沉步蓄勢）**：步兵雙足如釘釘入泥土，屏氣凝神，抵抗狂暴馬蹄踏地造成的地面震顫與恐慌威壓。
2. **DEADLINE_TIMING_ALIGN（死線校準）**：戰馬衝入最後 4.5 公尺，步兵藉由極致動態視力判定馬首下墜節奏。
3. **CLEAVE_EXECUTION_STRIKE（雷霆斬劈）**：全身體重與腰力傾注於十八斤重刃，以 140 度斜下大角度呼嘯斬落。
4. **HORSE_HEAD_BLOW_IMPACT（馬首破防）**：厚背大刀撕裂馬鎧，產生破甲鈍擊與斬切，造成 300% 暴擊破壞力。
5. **CATACLYSMIC_HORSE_FALL（戰馬栽倒）**：戰馬因頸椎折斷或雙膝跪地，前衝慣性化為向前撲倒翻滾，騎士被拋飛落馬。
6. **SECONDARY_FORMATION_TRIP（波及陣列）**：栽倒之龐大馬軀橫陳於狹道，後方跟隨之騎兵無法避讓，連環失足絆倒。
7. **RECOVER_BRACE_RESET（拔刀重整）**：步兵順勢收刀後撤半步，迅速擺正拒馬站位迎接下一名敵騎。

## 3. 數值模型與物理演算

### 斬劈馬首判定與破甲公式

$$P_{decapitate} = \min\left(0.85, \; 0.35 + 0.005 \times \text{STR}_{infantry} + 0.003 \times \text{Morale}_{infantry} - 0.004 \times V_{horse}\right)$$

- $\text{STR}_{infantry}$：步兵力量值（大於 80 時顯著提升破防力）。
- $V_{horse}$：戰馬衝刺速度（速度越快判定窗口越窄，但成功時產生的翻滾撞擊威力成倍提升）。

### 摔馬波及倒地半徑公式

$$R_{trip} = 2.0 + 0.5 \times \left( \frac{M_{horse} \times V_{horse}^2}{2 \times 10000} \right)$$

- $M_{horse}$：戰馬質量（約 450~550kg）。戰馬高速栽倒時產生的滑行衝擊半徑可達 4 至 6 公尺，範圍內後續部隊 100% 陷入跌落判定。

## 4. 戰場戰術連鎖與部隊生剋

1. **專剋重騎突擊**：對抗曹魏虎豹騎、西涼鐵騎等重甲衝鋒部隊時，正面阻截成功率提升 40%，大幅壓制正面突穿。
2. **懼怕遠程集火射擊**：重刀步兵放棄大盾改採雙手握刀，在進入近戰前易遭受敵軍游騎弓矢齊射重創。
3. **名將死守鼓舞士氣**：若有名將（如麴義、典韋）親自率領重刀隊，全隊免疫騎兵衝鋒威壓震懾。

## 6. 驗證標準與測試用例 (TC)

- **TC-BROADSWORD-01（三步死線判定）**：戰馬衝入 4.5 公尺距離且步兵力量 $\ge 80$ 時，雷霆斬劈在 0.3 秒內觸發。
- **TC-BROADSWORD-02（動能抵消與翻滾）**：戰馬受創後前衝動能衰減為 0，並於前方半徑 4 公尺生成阻礙絆倒碰撞體。
- **TC-BROADSWORD-03（後續騎兵連鎖跌落）**：緊隨其後 5 公尺內之騎兵必須受到絆倒判定，衝鋒加成全數清空。

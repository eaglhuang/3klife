# 3KLife 野戰重裝步兵狼牙拍雙手重砸連環破盾擊暈狀態機規格書

## 1. 系統定位與設計意圖

在三國野戰步兵方陣正面對撞與守城缺口爭奪戰（如袁曹官渡步陣絞殺、合肥守軍拍擊登城步兵）中，面對結成密集龜甲盾牆推進的敵軍刀盾手，單兵刀矛難以破開整排大盾。本系統規範三國重裝破陣與守城兼具之拍擊重兵器「長柄雙手生鐵狼牙拍迎頭蓋砸破盾擊暈系統（Wolf-Fang Swatter Shield-Crush）」狀態機：
- **丈二硬木長柄連接方形生鐵釘板**：前端為長三尺、寬二尺之厚重櫟木方板，板面密鑲三十六枚長四寸之生鐵三棱狼牙尖釘，全重二十斤。
- **高舉過頂雙手合力泰山壓頂**：兩名或單名高力量重步兵雙手握持丈二長柄，將狼牙釘板高舉過頭，借槓桿力矩與重力位能由上往下迎頭蓋拍。
- **釘板咬死大盾與群體腦震盪擊暈**：寬大釘板一次可同時拍中前方兩至三名並排持盾敵兵，狼牙鐵釘直接釘穿木盾並將盾牌連人拍翻在地，引發範圍擊倒與腦震盪暈眩。

## 2. 狀態機架構與轉換生命週期

狼牙拍破盾擊暈狀態機（代碼：`WOLF-FANG-SWATTER-SHIELD-CRUSH01`）流程如下：

```
[ LONG_POLE_OVERHEAD_HOIST ] (重步兵雙手握丈二長柄將二十斤狼牙板高舉過頂)
           │
           ├── 敵軍密集刀盾手逼近兩步拍擊圈
           ▼
[ MULTI_TARGET_SHADOW_LOCK ] (寬幅釘板投影鎖定前方並排兩至三名持盾兵)
           │
           ├── 沉腰踏步全力向下蓋拍 ──> [ FULL_LEVER_SMASH_DESCENT ]
           ▼
[ SPIKE_BOARD_SHIELD_PIN ] (三十六枚狼牙釘刺穿盾面將敵兵連人帶盾拍趴)
           │
           ├── 巨大拍擊震波引發群體暈眩
           ▼
[ AREA_CONCUSSION_KNOCKDOWN ] (受擊敵兵全數倒地陷入腦震盪與盾牌卡死)
           │
           ▼
[ WRENCH_RIP_SHIELD_STRIP ] (步兵猛力回扯長柄將敵兵手中大盾硬生生拽脫)
           │
           ▼
[ POLE_RAISE_CYCLE_RESET ] (重新揚起狼牙拍銜接下一輪拍擊)
```

### 狀態細部定義

1. **LONG_POLE_OVERHEAD_HOIST（高舉蓄勢）**：步兵踏穩弓步，將長柄狼牙拍高舉至 60 度仰角，威懾前方敵兵。
2. **MULTI_TARGET_SHADOW_LOCK（寬幅鎖定）**：因釘板寬達二尺，鎖定前方 $2.0 \times 1.5$ 公尺矩形區域內之所有敵方單位。
3. **FULL_LEVER_SMASH_DESCENT（迎頭蓋拍）**：長柄槓桿放大揮擊末速度，二十斤釘板呼嘯砸下，耗時 0.45 秒。
4. **SPIKE_BOARD_SHIELD_PIN（穿盾拍翻）**：三十六枚生鐵釘深深釘入敵方木盾或皮盾，巨大下壓力直接壓垮敵兵雙膝。
5. **AREA_CONCUSSION_KNOCKDOWN（群體擊暈）**：區域內敵兵承受鈍擊與穿刺複合傷害，100% 觸發【拍翻倒地】與 2.5 秒暈眩。
6. **WRENCH_RIP_SHIELD_STRIP（回扯奪盾）**：步兵趁釘板咬死敵盾，雙手向後猛拽長柄，直接將敵兵盾牌扯爛或奪下，使其徹底失去盾防。
7. **POLE_RAISE_CYCLE_RESET（揚拍復位）**：收回長柄重新舉起，冷卻時間為 3.5 秒。

## 3. 數值模型與物理演算

### 槓桿拍擊力矩與破盾奪盾公式

$$F_{impact} = \frac{F_{str} \times L_{handle} + M_{board} \times g \times H_{drop}}{\Delta t_{collision}}$$

$$P_{strip\_shield} = \min\left(0.90, \; 0.45 + 0.005 \times \text{STR}_{unit} - 0.25 \times \text{IsIronShield}\right)$$

- 當步兵力量 $\text{STR} \ge 80$ 時，對木盾與藤牌之回扯奪盾率高達 85%；唯有全鐵大盾可抵抗釘板穿刺。

### 多目標分攤與擊倒判定公式

$$D_{each} = D_{base} \times \max\left(0.7, \; 1.1 - 0.1 \times N_{targets}\right)$$

- 即使同時拍中 3 名敵兵，每名敵兵仍承受高達 80% 之巨額拍擊傷害，且擊倒判定不隨人數衰減。

## 4. 戰場戰術連鎖與部隊生剋

1. **密集龜甲陣與刀盾兵剋星**：一拍即可瓦解三名持盾兵的防禦架勢並扯掉其盾牌，使暴露出胸膛的敵兵淪為後方強弩手的活靶。
2. **長槍穿刺協同配合**：狼牙拍兵每兩名配置三名長槍兵，狼牙拍將敵前排拍趴瞬間，長槍兵立即跨步向下攢刺收割。
3. **揮擊前搖較長弱點**：高舉下拍動作明顯，若面對高敏捷之無盾游俠或輕騎兵，易被其側閃躲開拍擊區域。

## 6. 驗證標準與測試用例 (TC)

- **TC-SWATTER-01（多目標同時拍翻）**：前方 2 公尺寬度內並排站立 3 名刀盾兵時，單次蓋拍必須使 3 人同時進入倒地暈眩。
- **TC-SWATTER-02（回扯奪盾判定）**：拍中木盾兵後觸發 `WRENCH_RIP_SHIELD_STRIP`，目標盾牌防禦加成永久歸零。
- **TC-SWATTER-03（長槍協同暴擊）**：處於狼牙拍拍翻倒地狀態之敵兵，承受己方長槍兵刺擊時必出 2.0 倍處決暴擊。

# 野戰重裝步兵雙手長柄鐵骨朵重擊碎腦與破除重甲內傷狀態機規格書

> **來源**：中國古代破甲鈍器「鐵骨朵（蒜頭錘／蒺藜骨朵）」（長柄頂端套接渾圓如蒜頭或密布尖刺之生鐵重錘，專剋全身披掛之重甲騎兵與鐵甲步兵）、WBS `FORM-144` 戰場重型破甲鈍器模組。
> **關聯文件**：`doc_spec_0913`（三棱破甲鐵鐧）、`doc_spec_0919`（狼牙拍破盾）、`doc_spec_0028`（裝備強化系統）。

---

## 一、 設計目標與戰術定位

「長柄鐵骨朵」為六尺堅木或生鐵長柄頂端嵌合十斤渾圓生鐵錘頭（表面或帶凸稜如蒜瓣、或帶短刺如蒺藜）之雙手重型鈍器。面對刀劍難傷、箭矢難穿的頂級重甲部隊（如鐵浮圖、甲騎具裝、陷陣營），鐵骨朵不求割裂甲片，而是以純粹的沉重鈍擊動能隔盔震碎頭骨與臟腑。

1. **護甲穿透轉化（Armor-to-Shock Conversion）**：敵方護甲越厚重，鐵骨朵撞擊時產生的金屬共鳴與凹陷壓迫越劇烈，無視 `65%` 物理防禦。
2. **隔盔腦震盪（Helmet Concussion）**：迎頭重擊命中時，強制觸發「重度腦震盪（智力與戰法發動率減半、命中率 `-35%`）」。
3. **蓄力掄擊與破除招架**：雙手大開大合掄砸，一般輕型刀劍若試圖招架將直接遭受「震臂脫手」懲罰。

## 二、 狀態機生命週期（5 階段）

```
[1. 沉腰持錘 Stance_Heavy_Grip]
       │ (鎖定 1 格內重甲目標，雙手旋腰蓄力)
       ▼
[2. 泰山壓頂 Overhead_Guduo_Smash]
       │ (無視 65% 物理防禦，破除輕兵招架)
       ▼
[3. 隔盔碎腦 Helmet_Concussion_Shock]
       │ (震波透盔：目標戰法發動率 -50%、命中 -35%)
       ▼
[4. 橫掃折肋 Horizontal_Rib_Fracture]
       │ (對已腦震盪目標追加橫掃：真實內傷 + 移速減半)
       ▼
[5. 拄錘回氣 Guduo_Stance_Reset]
```

### 2.1 各階段觸發條件與戰術效果

| 階段代碼 | 階段名稱 | 觸發條件與物理/戰術效果 |
| :--- | :--- | :--- |
| `STANCE_HEAVY_GRIP` | 沉腰持錘 | 重裝鐵骨朵兵（`STR >= 82`）進入接戰狀態，自身抗擊退率 `+40%`。 |
| `OVERHEAD_GUDUO_SMASH` | 泰山壓頂 | 雙手高舉鐵骨朵迎頭重砸，無視目標 `65%` 物理防禦；若敵方持輕型刀劍招架，招架無效並額外承受 `25%` 震傷。 |
| `HELMET_CONCUSSION_SHOCK` | 隔盔碎腦 | 鐵錘砸扁鐵盔引發顱內震盪，造成 `155%` 鈍擊傷害，並附加 2 回合「重度腦震盪（戰法發動率 `-50%`、命中率 `-35%`、無法觸發暴擊）」。 |
| `HORIZONTAL_RIB_FRACTURE` | 橫掃折肋 | 若目標已處於「腦震盪」或「裂甲」狀態，順勢橫掃腰肋，造成相當於目標最大兵力 `10%` 之真實內傷並使移動力減半。 |
| `GUDUO_STANCE_RESET` | 拄錘回氣 | 重擊連招結束後需回氣 1 回合，期間自身閃避率 `-10%`。 |

## 三、 核心數值與判定公式

### 3.1 鐵骨朵無視護甲傷害公式（Guduo Armor-Piercing Damage）
$$D_{\text{smash}} = \max\left(1,\ \text{ATK}_{\text{guduo}} \times 1.55 - \text{DEF}_{\text{target}} \times (1 - 0.65)\right) \times \left(1 + 0.25 \times \mathbb{I}_{\text{heavyArmor}}\right)$$
- $\mathbb{I}_{\text{heavyArmor}}$：若目標為重甲單位（`DEF >= 80`），鐵骨朵鈍擊共鳴額外增傷 `+25%`。

### 3.2 隔盔腦震盪觸發率公式（Concussion Trigger Rate）
$$P_{\text{concuss}} = \text{clamp}\left(0.70 + (\text{STR}_{\text{atk}} - \text{STR}_{\text{def}}) \times 0.015,\ 0.30,\ 0.95\right)$$

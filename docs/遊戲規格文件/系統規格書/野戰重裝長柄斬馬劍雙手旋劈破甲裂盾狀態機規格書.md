# 3KLife 野戰重裝長柄斬馬劍雙手旋劈破甲裂盾狀態機規格書

## 1. 系統定位與設計意圖

在三國野戰精銳步兵突擊與反騎作戰（如漢代尚方斬馬劍傳承、高順陷陣營重裝破陣、曹魏虎衛軍貼身肉搏）中，兼具長柄大斧之槓桿力矩與重劍雙刃破甲能力的「長柄雙手斬馬劍（Zhanmadao / Horse-Slaying Greatsword）」，是撕裂敵軍重盾牆與斬斷騎兵馬足的終極重兵器。本系統規範「長柄斬馬劍雙手迴旋蓄力斬劈破甲裂盾系統（Horse-Slaying Sword Rotational Cleave）」狀態機：
- **三尺劍柄與四尺厚脊雙刃重劍**：劍身採用百煉玄鐵鍛造，劍脊厚達半寸，兩側開雙血槽，總長七尺、重十五斤，雙手握持可發揮極致離心揮砍動能。
- **腰胯帶動三百六十度迴旋斬劈**：突擊步兵踏步旋身，藉助全身旋轉離心力帶動劍刃畫出滿月弧光，對前方扇形區域實施無差別重擊。
- **裂盾破甲與馬足齊根斬斷**：面對步兵木盾或鐵箍大盾可直接劈裂盾面；面對衝鋒騎兵則貼地平削，一劍斬斷雙馬前脛並引發震懾流血。

## 2. 狀態機架構與轉換生命週期

斬馬劍旋劈狀態機（代碼：`HORSE-SLAYING-SWORD-ROTATIONAL-CLEAVE01`）流程如下：

```
[ TWO_HAND_GRIP_STANCE ] (雙手交錯緊握三尺長柄沉肩斂氣待發)
           │
           ├── 突入敵軍盾牆或迎擊衝鋒重騎三步線
           ▼
[ TORSO_TORQUE_WINDUP ] (左足踏前腰胯扭轉蓄滿旋轉角動量)
           │
           ├── 爆發旋身滿月揮砍 ──> [ FULL_ARC_ROTATIONAL_SWEEP ]
           ▼
[ SHIELD_ARMOR_SHATTER_HIT ] (厚脊重刃劈裂敵盾牌或斬斷戰馬前足)
           │
           ├── 動能貫穿引發大範圍撕裂傷與震退
           ▼
[ CLEAVE_BLEED_STAGGER ] (前方三名敵兵同時破甲重創失衡倒退)
           │
           ▼
[ REVERSE_BLADE_FOLLOWUP ] (順勢反手回撩刺擊未死殘敵咽喉)
           │
           ▼
[ POISE_RECOVERY_GUARD ] (橫劍當胸恢復格擋架勢調整呼吸)
```

### 狀態細部定義

1. **TWO_HAND_GRIP_STANCE（握柄蓄勢）**：步兵雙手前後相距一尺半握持長柄，重心下沉，獲得霸體抗打斷加成。
2. **TORSO_TORQUE_WINDUP（扭腰蓄力）**：全身肌群繃緊，扭轉腰腹帶動肩臂，耗時 0.35 秒完成極限蓄力。
3. **FULL_ARC_ROTATIONAL_SWEEP（迴旋橫掃）**：劍刃以每秒 25 弧度角速度橫掃前方 160 度扇形、半徑 2.5 公尺區域。
4. **SHIELD_ARMOR_SHATTER_HIT（破甲裂盾）**：命中敵方持盾步兵時扣除 80% 盾牌耐久度；命中戰馬時直接觸發斷足倒地。
5. **CLEAVE_BLEED_STAGGER（群體撕裂）**：單次揮砍最多可貫穿 3 個目標，附加每秒流失 4% 生命之重度創傷流血。
6. **REVERSE_BLADE_FOLLOWUP（反手回撩）**：利用迴旋慣性反轉手腕，劍尖由下往上斜撩，對破防目標追加 150% 刺擊傷害。
7. **POISE_RECOVERY_GUARD（橫劍回防）**：收劍回防，進入 1.2 秒調息期，期間格擋正面近戰攻擊減傷 40%。

## 3. 數值模型與物理演算

### 迴旋揮砍角動量與破甲公式

$$E_{cleave} = \frac{1}{2} I_{sword} \times \omega^2 + F_{str} \times L_{lever}$$

$$\text{ArmorIgnore} = \min\left(0.75, \; 0.30 + 0.004 \times \text{STR}_{unit} + 0.15 \times \text{IsHeavyBlade}\right)$$

- $I_{sword}$：長柄重劍轉動慣量；$L_{lever}$：三尺長柄力臂加成（1.35 倍）。
- 當士兵力量 $\text{STR} \ge 85$ 時，無視敵方 65% 護甲防禦，對重甲單位造成毀滅性打擊。

### 裂盾耐久破壞判定公式

$$D_{shield} = D_{base} \times 2.5 \times (1.0 + 0.3 \times \text{IsWoodenShield})$$

- 普通木盾承受一記旋劈即直接碎裂（耐久歸零），持盾兵陷入 2 秒【破防暈眩】。

## 4. 戰場戰術連鎖與部隊生剋

1. **重步兵盾牆破陣利器**：專門用於撕開敵軍前排大盾陣列，為己方後續長槍兵與輕步兵打開突擊缺口。
2. **騎兵衝鋒側翼絞肉機**：配置於步兵方陣兩翼時，可有效斬殺試圖迂迴包抄之敵軍游騎與重騎。
3. **體力消耗巨大**：每次迴旋斬劈消耗 15 點體力，連續揮砍 6 次後需喘息恢復，期間攻速下降 30%。

## 6. 驗證標準與測試用例 (TC)

- **TC-GREATSWORD-01（扇形多目標命中）**：前方 2.5 公尺、160 度扇形內有 3 名敵兵時，單次旋劈必須全數命中。
- **TC-GREATSWORD-02（木盾一擊粉碎）**：對耐久度 100 之木盾步兵施展旋劈，盾牌耐久直接歸零並附加 2 秒暈眩。
- **TC-GREATSWORD-03（反手回撩連擊）**：目標破防後 0.4 秒內自動銜接 `REVERSE_BLADE_FOLLOWUP`，造成額外 150% 傷害。

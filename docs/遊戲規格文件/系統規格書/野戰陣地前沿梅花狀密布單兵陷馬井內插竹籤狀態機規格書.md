# 3KLife 野戰陣地前沿梅花狀密布單兵陷馬井內插竹籤狀態機規格書

## 1. 系統定位與設計意圖

在三國曠野大兵團交鋒（如界橋之戰、潼關之戰、漢中定軍山爭奪戰）中，敵方輕重騎兵具有極強的機動突防能力，若挖掘大縱深長溝容易被敵騎兵提早發現並繞行。本系統規範野戰特種密集微型陷阱「梅花陣列單兵陷馬井（Plum Blossom Horse Pit Grid）」之點狀開挖、淬火竹籤固設、薄草擬態偽裝與群體折足崩潰狀態機：
- **梅花五星交錯密集微井**：工兵於陣地前沿百步開闊地上，每隔三尺挖掘一個直徑一尺二寸、深兩尺之圓形垂直小坑，整體呈五點梅花陣列交錯鋪開。
- **井底密插淬火硬竹籤**：每個小井底部垂直深釘三枚浸透生烏頭汁液之硬化竹刺，刺尖距離井口八寸。
- **極致擬態與群體折足**：井口僅架設脆弱細葦草枝覆蓋浮土與雜草，肉眼極難識別；戰馬一旦踏入，馬蹄瞬間陷沒折斷，引發高速衝鋒隊形的全面骨牌式撲倒。

## 2. 狀態機架構與轉換生命週期

梅花陷馬井狀態機（代碼：`PLUM-BLOSSOM-HORSE-PIT-GRID01`）管理自工兵掘坑至騎兵瓦解之完整週期：

```
[ PLUM_GRID_DIGGING ] (工兵按梅花交錯幾何定位掘出百個小圓坑)
          │
          ▼
[ BAMBOO_SPIKE_PLANTING ] (井底釘入淬火竹籤塗抹烏頭汁液)
          │
          ▼
[ VEGETATION_CAMOUFLAGE ] (以易斷草莖橫架撒薄土完全融入地表)
          │
          ├── 敵騎兵大群發起衝鋒 ──> [ RECON_MISDETECTION_CHECK ]
          ▼
[ HOOF_STEP_PUNCTURE ] (馬蹄踏空踩陷折斷管骨深刺竹籤)
          │
          ▼
[ CATACLYSMIC_HORSE_FALL ] (戰馬失衡前滾翻引發後續連環疊壓)
          │
          ▼
[ CHARGE_DECELERATION_STALL ] (敵騎兵集群衝擊力徹底歸零陷入混亂)
```

### 狀態細部定義

1. **PLUM_GRID_DIGGING（幾何掘坑）**：
   - 工兵使用圓刃短鍬快速掘土，十人一組在半個時辰內佈設 120 處規格統一的單兵陷馬井，間距恰好小於戰馬步幅。
2. **BAMBOO_SPIKE_PLANTING（植入竹籤）**：
   - 井底夯實生土，釘入三根經文火炙烤硬化之老楠竹尖籤，表面浸泡生川烏草藥。
3. **VEGETATION_CAMOUFLAGE（擬態覆蓋）**：
   - 井口鋪設十字形細草莖，表層篩灑乾燥泥土與黃枯落葉，距五步外肉眼識別率低於 4%。
4. **HOOF_STEP_PUNCTURE（踩踏陷足）**：
   - 奔馳中之戰馬單蹄踏碎細草支架落入井底，蹄骨承受數倍身體重力強行扭曲折斷，竹籤穿透馬掌。
5. **CATACLYSMIC_HORSE_FALL（滾翻疊壓）**：
   - 戰馬前胸砸地劇烈翻滾，背上騎兵被拋飛數丈，相鄰戰馬因高速奔馳避讓不及發生連環衝撞。
6. **CHARGE_DECELERATION_STALL（衝力歸零）**：
   - 騎兵集群在踏入梅花井區三十步內衝鋒速度由 14 m/s 驟降至零，淪為我方強弩射擊之活靶。

## 3. 關鍵數值與計算判定公式

### 3.1 奔馳踩陷機率與間距公式

戰馬群穿過梅花井陣列之踏陷概率 $P_{trap}$ 計算：
$$P_{trap} = 1.0 - \left(1.0 - \frac{N_{pits} \times A_{pit}}{S_{total\_zone}}\right)^{N_{strides}}$$
- $N_{pits}$：陷馬井數量（約 120 口）。
- $A_{pit}$：單井截面積（約 $0.07\,\text{m}^2$）。
- $S_{total\_zone}$：衝鋒穿越防禦帶總面積（約 $600\,\text{m}^2$）。
- $N_{strides}$：戰馬穿越該區域所需奔馳步數（約 8 步）。
- 計算得出集群戰馬踏陷致殘機率高達 $P_{trap} \approx 67.8\%$，足以徹底撕裂任何衝鋒波次。

### 3.2 騎士拋飛與骨折損傷

戰馬驟停造成騎士拋飛動能 $E_{eject}$（焦耳）：
$$E_{eject} = \frac{1}{2} M_{rider} \times V_{charge}^2 \approx \frac{1}{2} (80\,\text{kg}) \times (13.5\,\text{m/s})^2 \approx 7290\,\text{J}$$
- 重重砸地後騎士承受重度鈍傷，失能昏厥時間長達 45 秒。

## 4. 戰術連鎖與攻防克制

1. **破陣化解重騎優勢**：在無高大營柵之野戰空曠地，以極低成本瓦解敵軍最精銳的騎兵先鋒。
2. **天敵與敵方反制**：
   - **步兵前鋒清道**：敵軍若派重步兵以大盾或長棍在前沿逐寸敲擊探路，可提前探出陷馬井。
   - **繞行側翼開闊地**：若梅花井範圍過於狹窄，敵騎兵若偵知其邊界，可輕易由左右兩翼迂迴包抄。

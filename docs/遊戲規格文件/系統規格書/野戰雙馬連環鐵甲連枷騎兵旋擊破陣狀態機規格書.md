# 3KLife 野戰雙馬連環鐵甲連枷騎兵旋擊破陣狀態機規格書

## 1. 系統定位與設計意圖

在三國北方大平原重騎兵正面破陣作戰（如袁紹河北重裝鐵騎、曹操虎豹騎重錘破盾、北地羌胡鐵騎衝陣）中，當面對敵軍密不透風的重裝大盾長槍方陣時，刺擊類長矛容易折斷於盾面。本系統規範三國極致破甲衝擊兵種「雙馬並馳連環鐵甲騎兵揮舞長柄生鐵狼牙連枷旋擊破陣系統（Twin-Horse Flail Cavalry Smash）」狀態機：
- **雙馬鐵索連環並轡衝鋒**：每兩匹披掛整套熟鐵具裝馬鎧之重型戰馬以橫向生鐵連環鎖扣並排相連，共享衝刺動量，不會因單馬受阻而失速。
- **長柄鐵鏈狼牙連枷跨盾旋擊**：騎士手持長五尺硬木柄、前端以粗鐵鏈連接八斤重六棱生鐵狼牙錘頭之騎兵連枷；揮擊時錘頭可繞過敵兵盾牌上緣，直接由後上方重砸敵兵頭盔與肩骨。
- **連環馬牆平推與鈍擊震碎**：雙馬連環形成的厚重鐵牆正面撞塌敵軍第一排槍盾手，連枷離心甩擊產生恐怖鈍擊波，徹底粉碎重甲步兵的防禦陣線。

## 2. 狀態機架構與轉換生命週期

雙馬連枷騎兵破陣狀態機（代碼：`TWIN-HORSE-FLAIL-CAVALRY-SMASH01`）流程如下：

```
[ TWIN_STEED_CHAIN_COUPLE ] (雙匹具裝戰馬胸前生鐵橫桿連環扣死)
           │
           ├── 戰鼓催動進入百步全速重騎衝鋒
           ▼
[ SYNCHRONIZED_GALLOP_MOMENTUM ] (雙馬步伐高度同步累積雙倍衝撞動量)
           │
           ├── 逼近敵盾陣十步騎士高舉長柄連枷
           ▼
[ CENTRIFUGAL_FLAIL_WHIRL ] (騎士頭頂高速旋轉連枷蓄滿離心甩擊力)
           │
           ├── 雙馬撞擊盾牆同時甩出連枷 ──> [ OVER_SHIELD_CRUSH_IMPACT ]
           ▼
[ HELMET_SKULL_CONCUSSION ] (狼牙錘頭越過盾牌頂端砸碎敵兵鐵盔)
           │
           ▼
[ COUPLED_TRAMPLE_BULLDOZE ] (雙馬連環鐵牆平推踐踏撕開兩丈寬缺口)
           │
           ▼
[ CHAIN_UNCOUPLE_MANEUVER ] (穿透敵陣後拔銷解開連環轉為單騎追殺)
```

### 狀態細部定義

1. **TWIN_STEED_CHAIN_COUPLE（雙馬連環）**：兩匹重鎧戰馬以快拆生鐵橫木與短鏈並排連接，間距固定三尺，抗側面衝撞穩定度提升 100%。
2. **SYNCHRONIZED_GALLOP_MOMENTUM（同步狂飆）**：雙馬四蹄起落同步，衝鋒速度穩定達每秒 10 公尺，動能加倍。
3. **CENTRIFUGAL_FLAIL_WHIRL（旋錘蓄勢）**：騎士於頭頂搖動連枷，生鐵錘頭高速旋轉發出呼嘯聲震懾敵軍。
4. **OVER_SHIELD_CRUSH_IMPACT（跨盾甩擊）**：連枷接觸盾牌上沿時，前端鐵鏈因慣性向下彎折甩入盾後，完全無視敵方正面格擋率。
5. **HELMET_SKULL_CONCUSSION（鈍擊破甲）**：六棱狼牙錘頭直接砸中敵兵鐵盔，鈍擊震波穿透內襯，造成 100% 腦震盪暈眩與骨折。
6. **COUPLED_TRAMPLE_BULLDOZE（鐵牆平推）**：雙馬總重逾千斤，正面將盾牌手撞飛踐踏而過，強行鑿穿方陣。
7. **CHAIN_UNCOUPLE_MANEUVER（解環追擊）**：鑿穿敵陣後，騎士拉動鞍橋快拆銷解開連環，恢復靈活轉向收割敵後排弓手。

## 3. 數值模型與物理演算

### 連枷跨盾無視格擋與鈍擊公式

$$P_{bypass\_shield} = \min\left(0.95, \; 0.65 + 0.05 \times L_{chain} - 0.15 \times \text{IsTowerShield}\right)$$

$$D_{blunt} = D_{base} \times \left(1.0 + 0.08 \times V_{gallop}\right) \times (1.0 + 0.6 \times \text{TargetIsHeavyArmor})$$

- 連枷鐵鏈繞盾成功率高達 80% 以上；敵軍穿戴越厚重的鐵甲，承受的鈍擊共振傷害加成 60%。

### 雙馬連環抗阻滯動量維持公式

$$V_{post\_impact} = V_{initial} \times \left(1.0 - \frac{M_{infantry}}{M_{twin\_horse} \times 1.8}\right)$$

- 雙馬連環（$M_{twin\_horse} \approx 1,100\,\text{kg}$）每次撞擊僅損失 12% 速度，可連續撞穿 5 排步兵。

## 4. 戰場戰術連鎖與部隊生剋

1. **持盾重步兵絕對天敵**：專破高格擋率之大盾兵與先登死士，連枷甩擊直接繞過盾牌防禦判定。
2. **懼怕鉤鐮槍與陷馬坑**：連環期間轉向半徑極大，若遇陷馬井或鉤鐮槍兵揮砍，一馬倒地將連累另一馬翻覆。
3. **快拆解環靈活轉換**：破陣後解開連環，避免陷入步兵泥淖圍毆。

## 6. 驗證標準與測試用例 (TC)

- **TC-TWIN-FLAIL-01（跨盾無視格擋）**：對格擋率 80% 之持盾步兵發動連枷甩擊，必須繞過格擋並造成滿額鈍擊傷害。
- **TC-TWIN-FLAIL-02（雙馬連續貫穿）**：雙馬連環以 10m/s 衝入 4 排步兵陣，穿透後剩餘速度必須 $\ge 5\,\text{m/s}$。
- **TC-TWIN-FLAIL-03（單馬陷坑連帶翻覆）**：連環狀態下若任一馬觸發陷馬坑倒地，另一馬必須同步觸發跌倒判定。

# 3KLife 野戰鹿角拒馬交錯扎結塗抹瀝青防撞防鋸防步騎狀態機規格書

## 1. 系統定位與設計意圖

在三國大型野戰立營與防守戰役（如官渡之戰袁曹相持、街亭失守後之斷後撤退）中，臨時營地缺乏高大土石城垣，極易遭敵騎兵衝擊。本系統規範野戰前沿骨幹阻絕工事「瀝青交錯加固鹿角拒馬陣（Cross-Abatis Bitumen Defense）」之交錯扎結、塗抹瀝青、防鋸防火防撞與長槍掩護狀態機：
- **交錯重疊死結扎排**：以堅硬柞木或老棗木為主幹，削尖前端形成雙向長刺，十架拒馬成品字形交錯重疊，並以浸油熟麻繩與生鐵抓釘深鎖入土。
- **塗抹黑石脂與瀝青防護**：外表刷塗厚層瀝青與石脂，不僅隔絕濕氣蟲蛀，更能使刀鋸打滑無法速斷，且兼具韌性吸收戰馬撞擊動能。
- **立體步兵協同屏障**：拒馬後方預留半人高散兵壕，步卒持丈六長矛自拒馬枝枒縫隙向前刺擊，構築「馬不得進、人不得越」之鐵壁。

## 2. 狀態機架構與轉換生命週期

鹿角拒馬狀態機（代碼：`CROSS-ABATIS-BITUMEN-DEFENSE01`）管理自現場扎結至阻截摧毀之完整流程：

```
[ TIMBER_CROSS_ASSEMBLY ] (硬木削尖十字交錯捆扎與抓釘固定)
          │
          ▼
[ BITUMEN_COATING_APPLY ] (均勻刷塗生漆瀝青硬化防鋸表面)
          │
          ▼
[ GROUND_STAKE_ANCHORING ] (生鐵地樁斜向四十度深釘入土頂死)
          │
          ├── 敵騎兵全力衝鋒 ──> [ IMPACT_ABSORPTION_RESOLVE ]
          ├── 敵工兵持斧砍鋸 ──> [ ABRASION_DEFENSE_COUNTER ]
          ▼
[ ENTANGLEMENT_GRID_HOLD ] (倒刺卡死馬鎧與戰馬前胸刺穿)
          │
          ▼
[ SPEARMAN_THRUST_DEFENSE ] (後方長槍兵隔空補刺擴大戰果)
          │
          ▼
[ BREACH_OR_REINFORCE ] (損毀替換或陣地失守破壞)
```

### 狀態細部定義

1. **TIMBER_CROSS_ASSEMBLY（扎結構件）**：
   - 工兵挑選直徑五寸以上之原木，交叉呈 60 度角削尖外伸，接合處以熟牛皮條與鐵角碼釘死。
2. **BITUMEN_COATING_APPLY（刷塗瀝青）**：
   - 熔化天然瀝青與松香混合物，滾刷三道於木刺表面，冷卻後形成一層光滑而堅硬的保護殼，抗鋸阻力提升 85%。
3. **GROUND_STAKE_ANCHORING（深釘地樁）**：
   - 背面以兩根斜向粗木呈三角支撐深插入土三尺，承受正面猛烈衝撞時將動能導入大地。
4. **IMPACT_ABSORPTION_RESOLVE（吸收撞擊）**：
   - 遭遇重騎兵撞擊時，三角支撐吸收 75% 衝擊力，尖刺直接刺破馬鎧，對戰馬造成致命穿刺傷。
5. **ABRASION_DEFENSE_COUNTER（抗砍防鋸）**：
   - 敵先登步兵試圖以大斧劈砍時，斧刃易滑偏或陷入瀝青黏稠層，破拆時間由常規 15 秒延長至 60 秒以上。
6. **SPEARMAN_THRUST_DEFENSE（長矛反擊）**：
   - 敵軍受阻於拒馬前時，我方長矛兵從縫隙突刺，享有 35% 暴擊加成且不受敵近戰反擊。

## 3. 關鍵數值與計算判定公式

### 3.1 結構抗撞擊動能閥值

鹿角拒馬單元所能承受之最大衝擊動能 $E_{resist}$（焦耳）：
$$E_{resist} = \frac{1}{2} K_{timber} \times \sigma_{bend} \times \cos^2(\theta_{brace}) \times (1.0 + \beta_{iron\_strap})$$
- $\sigma_{bend}$：硬木抗彎極限強度（約 $85\,\text{MPa}$）。
- $\theta_{brace}$：地樁支撐傾角（$40^\circ$）。
- $\beta_{iron\_strap}$：生鐵角碼加固增益（0.45）。
- 換算得出單架拒馬可承受約 $48,000\,\text{J}$ 動能，足以完全抵擋全速奔馳之甲騎具裝直接衝擊。

### 3.2 敵工兵破拆耗時計算

斧鑿破除單架拒馬所需歷時 $T_{breach}$（秒）：
$$T_{breach} = \frac{\text{Durability}_{abatis}}{\text{DPS}_{axe}} \times \left(1.0 + \text{BitumenHardness} \times 1.2\right)$$
- 瀝青硬化使工兵斧鉞鈍化速度增加 2 倍，極大延緩破拆速度。

## 4. 戰術連鎖與攻防克制

1. **步兵以弱勝強基石**：使防守步兵在野戰中免遭騎兵踐踏，構築防禦中樞。
2. **弱點與反制手段**：
   - **長索飛爪套拉**：敵方若以重型戰馬牽引生鐵長索拋套拒馬拖曳，可將整排拒馬連根拔起。
   - **集束火油燃燒**：瀝青雖防鋸，但遇持續高溫明火燒烤時會被點燃，形成燃燒屏障反噬守軍。

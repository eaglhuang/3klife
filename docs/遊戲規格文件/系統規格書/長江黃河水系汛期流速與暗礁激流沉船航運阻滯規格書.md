# 3KLife 長江黃河水系汛期流速與暗礁激流沉船航運阻滯規格書

## 1. 模組概述與核心定位
本模組為 3KLife 戰略沙盤之動態水文物理引擎（`GEOGRAPHY-RIVER-01`）。涵蓋長江、黃河、淮河、漢水等主要水系的地格流向、汛期洪流與冬季封凍演變。直接影響水軍艦隊航速、漕運補給線效率、以及在暗礁險灘遭遇翻船觸礁之戰損風險，體現「長江天塹，非舟楫不可渡」之真實地理博弈。

## 2. 水流水位時序與航道狀態機

### 2.1 四大水系水文特性
```
[黃河水系] ──(泥沙沉積/春凌冬封)──> 冬季冰封可踏冰行軍，夏季洪峰暴烈
[長江水系] ──(天塹狂瀾/暗礁密布)──> 四季通航，三峽/赤壁段激流險灘高沉船率
[淮河水系] ──(水網縱橫/湖沼交錯)──> 易受水攻決堤蔓延，易澇易淤
[漢水水系] ──(襄樊要衝/流速湍急)──> 水軍上下游順逆流航速差距高達 3 倍
```

### 2.2 航道地格狀態機（`RiverGridWaterState`）
```
  [平緩通航 CALM_FLOW] (正常漕運與艦隊航行)
         │ (暴雨/梅雨/桃花汛)
         ▼
  [狂瀾汛期 TORRENT_FLOOD] ──(黃河大寒降溫)──> [寒冬冰封 FROZEN_ICE]
         │ (順流航速翻倍、逆流寸步難行)          │ (舟楫禁行，步騎部隊可涉冰渡河)
         │ (流經三峽暗礁段)                     │ (春暖解凍凌汛)
         ▼                                     ▼
  [暗礁險灘 REEF_HAZARD] ───────────────> [融冰凌汛 FLOE_BREAK]
   (每回合檢定觸礁與船體損壞)
```

## 4. 水力動力學與觸礁結算公式

### 4.1 順逆流航行速度修正公式
艦隊前進方向向量 $\vec{V}_f$ 與水流向量 $\vec{V}_r$ 之夾角為 $\theta$：
$$v_{\text{eff}} = v_{\text{base}} + |\vec{V}_r| \times \cos(\theta) \times \text{VesselHandlingCoeff}$$
- 走舸輕舟操控性係數 $= 1.2$；大型樓船受風流影響大，係數 $= 0.6$。
- 逆流極限（$\cos\theta = -1$ 且 $|\vec{V}_r| > v_{\text{base}}$）時，速度降至基準之 $15\%$，且每回合額外消耗 $50\%$ 水手體力。

### 4.2 暗礁險灘觸礁翻船機率
在 `REEF_HAZARD` 地格中航行時：
$$P_{\text{wreck}} = \left(0.15 + \frac{|\vec{V}_r|}{10} - \frac{\text{CaptainWaterSkill}}{200}\right) \times \text{ShipDraftFactor}$$
- 吃水深的大型樓船 $\text{ShipDraftFactor} = 1.8$；艨艟 $= 1.0$；走舸 $= 0.4$；
- 若水軍提督具備「水神」或「浪裡白條」特技，觸礁率強制減免 $80\%$。

## 5. 邊界約束與驗收準則
1. **驗收 CASE-RIVER-01**：在黃河「大雪」節氣觸發 `FROZEN_ICE` 時，所有停泊於黃河之水軍艦隊強制冰封、無法移動；但陸上步騎兵團可越過冰面突襲渡河。
2. **驗收 CASE-RIVER-02**：汛期逆流調度漕運糧船時，若無纖夫步道護航，糧草運抵耗損率由 $5\%$ 攀升至 $35\%$。
3. **單檔大小約束**：本檔嚴守規格書輕量標準，架構嚴整無多餘歷史附錄。

# 開局出身選擇規格書

> **規格代碼**：`ORG-01`　**任務卡**：PROG-2-10184　**裁決來源**：使用者 2026-11-27 晚本人裁決（開局自選出身：士族子弟／遊俠／醫者／商人，可再補 1～2 個）
> **狀態**：規格定案（只有規格；數值是 PM 暫定，放 JSON 可調）
> **依賴**：失憶開場流程（`AMN-01`）、神秘圖鑑總規格（`MYS-01`）、說溜嘴（`doc_spec_1348`）、首子與少年名將開場（`doc_spec_1233`）、共用框架總綱（`doc_spec_1182`）、獎勵 Base（`doc_spec_1186`）、物品庫存 Base（`doc_spec_1184`）

## 0. 結論

1. 開局主角**自己選一個出身**。選項：士族子弟、遊俠、醫者、商人；另預留 2 個位置（第 6 章）。
2. 出身**只是主角編給古人聽的來歷（偽裝）**，不等於主角真實身分。真實身分在記憶章 3 才揭露，固定劇本，不因出身而變。
3. 每個出身有三樣東西：**起始資源差異**、**偽裝難度**、**第一年專屬事件 2 個**。
4. 出身影響的是開局資源與偽裝風險，**不影響戰場核心規則**，也不改任何歷史路線。
5. 選擇發生在失憶開場裡（老驛卒問「客官何方人士」，主角編一個），單鍵確定、預設選士族子弟，**只多 1 次必要點擊**（見 `AMN-01`）。

> **11/27 深夜補（Q-AMN-3）**：出身同時決定**撿到主角的人**：士族→家僕、遊俠→同伴、醫者→師父、商人→商隊老闆（`origin-config.json` 加 `pickerNpcId` 欄位，暫定 `servant`／`companion`／`master`／`caravanBoss`）。

## 1. 偽裝難度是什麼

- 主角內心價值觀與知識跟古人不同，必須偽裝才能活下來、爭取機會。
- 偽裝難度用星等 1～5 表示，換算成「偽裝係數」`coverRisk`（越高越容易露餡）。
- 它只影響兩件事：
  1. 「脫口而出」（主角說現代話）被武將覺得怪時，**友誼扣量 = 基礎 2 × `coverRisk`**（對應 SLIP-01 試探代價）。
  2. 專屬事件裡「露餡選項」的失敗率 = 15% × 星數。
- 露餡的後果很輕：友誼小扣、尷尬台詞、少拿一點獎勵。**武將只會覺得怪，不會起疑**（`MYS-01` 3.4）。
- 難度高的出身，換到的是更多記憶碎片進度與未來知識發揮空間（見各出身的 `shardBonus`）。

## 4. 出身與其他系統的關係

| 系統 | 關係 |
|---|---|
| 說溜嘴／試探 | 友誼扣量乘 `coverRisk` |
| 記憶碎片 | `shardBonus`，不改章門檻 |
| 少年義子三選一、六名將、宿命轉蛋 | 不變，出身不影響 |
| 學府、血統 | 不變；子嗣不繼承出身 |
| 戰場 | 不碰，出身沒有戰場效果 |

## 5. UI

- 失憶開場裡一張選擇畫面：四張卡並排（圖示、名稱、偽裝星數、資源一行、一句內心 OS），底部單鍵「就這個」。預設選中士族子弟。
- 卡片共用一個節點，切換換內容；手機記憶體不多載圖。
- 排版走錨點／相對比例。四語系走 i18n：`ui.origin.<id>.*`。

# 關係親密度每季衰退維護與家風傳承規格書

> **責任邊界**：本檔為動態人際關係親密度（KinDynamicRelations）、換季衰退維護與宗族家風被動（Clan Heritage）的單一真相來源。
> **關聯 WBS**：KIN-10（親密度衰減與回補）、KIN-11（家風傳承 Buff 內容設計）、KIN-06（動態關係建立）。
> **整併裁決**：定案換季親密度衰退公式與歸零保留原則；正式裁決四大宗族「家風傳承」被動效果與門檻。

---

## §1. 動態親密度數值模型與換季衰退公式

遊戲內武將因戰場共鬥、結義或結緣建立之動態關係，其親密度（Intimacy，0~100）受時間推移而自然衰減：

| 參數常數 | 標準數值 | 說明 |
|:---|:---:|:---|
| `DYNAMIC_RELATION_INITIAL_INTIMACY` | **30 點** | 事件建立時之初始親密度基值 |
| `DYNAMIC_RELATION_DECAY_RATE` | **2 點 / 季** | 每年四季度更迭時自動扣除之親密度 |
| `DYNAMIC_RELATION_INTERACT_GAIN` | **+10 點 / 次** | 主動執行拜訪、贈禮或共同出征回補點數 |
| `DYNAMIC_RELATION_MAX_INTIMACY` | **100 點** | 親密度上限天花板 |

### 換季結算與歸零保留 (Zero Intimacy Retention)

- **換季衰退**：每季度末執行 `advanceSeason()`，所有動態關係執行：
  $$\text{Intimacy}_{\text{new}} = \max(0, \text{Intimacy}_{\text{old}} - \text{DYNAMIC\_RELATION\_DECAY\_RATE})$$
- **歸零保留原則**：親密度降至 0 時，關係**絕對不解除**（義兄弟仍為義兄弟、夫妻仍為夫妻），僅暫時失效合攻加成（合攻機率歸 0），一旦進行互動回補至 10 以上立即恢復生效。

## §2. 宗族四大「家風傳承」被動總表 (KIN-11 裁決)

家族經歷三代以上傳承，當直系 14 人祖譜中累積特定領域標籤（Tag）達 **5 個以上**時，點亮全族生效之「家風被動（Clan Heritage）」：

| 家風名稱 | 觸發條件 (14 人祖先) | 全族常駐被動 Buff | 宗族圖鑑專屬稱號 |
|:---|:---:|:---|:---:|
| **文治盛世** | 累積 5+ `智謀` 或 `內政` 標籤 | 書院策論手牌上限 +1；封地稅收金幣 +10% | **『海內文宗』** |
| **尚武將門** | 累積 5+ `統率` 或 `武力` 標籤 | 全族出征開局士氣 +15；部隊近戰傷害 +8% | **『百戰世家』** |
| **忠義傳家** | 累積 5+ `仁德` 或 `忠勇` 標籤 | 全族忠誠度下限鎖定 60；相鄰合攻機率 +10% | **『義薄雲天』** |
| **巨賈豪紳** | 累積 5+ `經商` 或 `理財` 標籤 | 購買裝備與丹藥享 8 折；封地季度糧草產出 +15% | **『富甲一方』** |

> **衝突排除原則**：單一家族若同時滿足多個家風條件，最多可同時啟用 **2 個家風**，由玩家在家族祠堂介面自選生效。

## §3. 資料結構與存檔協議

動態關係與家風傳承記錄於 `Player_Save.Data.Family_Ancestral_Hall` 與 `Kin_Relations`：

```typescript
export interface DynamicRelationSaveRecord {
  relationId: string;
  sourceUid: string;
  targetUid: string;
  type: 'COMRADE' | 'SWORN_BROTHER' | 'SPOUSE' | 'PARENT_CHILD';
  intimacy: number;           // 0 ~ 100
  decayRate: number;          // 固定 2
  lastInteractionSeason: number;
}

export interface ClanHeritageState {
  activeHeritages: string[];  // 最多 2 個
  unlockedTitles: string[];   // 已獲得稱號
}
```

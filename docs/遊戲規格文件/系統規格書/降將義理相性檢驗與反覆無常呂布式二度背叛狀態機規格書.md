# 3KLife 降將義理相性檢驗與反覆無常呂布式二度背叛狀態機規格書

> **規格代碼**：SPEC-GEN-BETRAY01  
> **關聯 WBS**：GENERAL-BETRAYAL-01（武將義理相性光譜、降將歸心狀態機與反覆無常二度反叛演算法）  
> **系統分類**：人物關係 / 忠誠義理與陣營動態背叛管線  
> **狀態**：正式生效（單一真相來源，嚴禁尾端追加補丁）

---

## 1. 系統架構定位與三國人性光譜

人各有志，義薄雲天如關羽，三姓家奴如呂布。《三國人生》（3KLife）拒絕將招降武將簡化為「一旦點擊降伏即永久鎖定忠臣」之機械化邏輯，正式實裝**名將義理光譜與動態二度背叛狀態機（Righteousness & Betrayal Model）**。

本系統核心價值：
1. **義理性格光譜化（Righteousness Spectrum）**：由義理（0~100）與野心（0~100）兩大底層參數決定降將骨氣。
2. **歸心週期與試探期（Assimilation Period）**：新降之將需經歷考驗期，信任尚未牢固。
3. **二度反叛的歷史真實感**：若賞罰不公、勢力衰頹或故主重金相邀，低義理名將將無情刺穿君主後背。

## 2. 義理野心雙軸光譜資料結構

每個名將在底層資料庫配置義理（`righteousness`）與野心（`ambition`）屬性：

```typescript
export interface IGeneralMoralityProfile {
  readonly generalId: string;
  readonly righteousness: number;    // 義理值 (0: 唯利是圖 ~ 100: 寧死不屈)
  readonly ambition: number;         // 野心值 (0: 安貧樂道 ~ 100: 窺伺九五)
  loyalty: number;                   // 當前對君主忠誠度 (0 ~ 100)
  daysSinceDefection: number;        // 自投降以來的經過天數
  relationshipWithOldMaster: number; // 與故主好感羈絆 (-100 ~ 100)
}
```

```

                 │
  [狼子野心型: 呂布、鍾會]  │  [梟雄爭霸型: 曹操、司馬懿]
  低義理 + 高野心           │  中義理 + 高野心
  極易謀反自立、弒主噬恩    │  順境效力、逆境自立
─────────────────┼─────────────────► 高義理 (Righteousness >= 80)
  [苟且偷生型: 糜芳、孟達]  │  [忠貞烈士型: 關羽、諸葛亮、荀彧]
  低義理 + 低野心           │  高義理 + 低野心
  兵臨城下即降、貪生怕死    │  寧死不降、忠貞不二
                 │ 低野心
```

## 3. 降將心態流轉狀態機

捕獲降將後，其心態依據處遇嚴格流轉：

```
       [CAPTURED 階下囚] ──登庸降伏──> [RELUCTANT 勉強投誠 (忠誠 50)]
                                               │
                 ┌─────────────────────────────┴─────────────────────────────┐
                 ▼ (賞賜名駒、重金封賞、結拜)                              ▼ (長年冷落、減俸、故主密信)
      [ASSIMILATED 誓死歸心]                                        [DISAFFECTED 心生怨懟 (忠誠 < 40)]
      忠誠度升至 90+，背叛率歸零                                                    │
                                                                                    │ 野心爆發或領兵出鎮
                                                                                    ▼
                                                                        【REBELLION 陣前倒戈 / 舉城自立】
```

1. **`RELUCTANT`（勉強歸順）**：投降首年內為「危險考察期」。若指派其出戰故主勢力，該將每回合士氣扣除 $5$ 點（念及舊情不忍下手）。
2. **`ASSIMILATED`（徹底歸心）**：經由「贈予重寶、結緣通婚、拜將封侯」，忠誠度穩定於 90 以上超過 2 年，正式轉化為死忠麾下。

## 4. 誘發二度叛變的演算法與後果結算

低義理名將（`righteousness < 40`）在每季結算時執行謀反判定骰：

$$P_{\text{betray}} = \frac{\text{Ambition} \times 0.4\% + (100 - \text{Loyalty}) \times 0.6\%}{\text{Righteousness} + 10} + \text{Bonus}_{\text{crisis}}$$

1. **危局加成（$\text{Bonus}_{\text{crisis}}$）**：
   - 玩家勢力遭遇慘敗丟失城池（$+25\%$）。
   - 該名將出任邊境太守，手握重兵超過 2 萬（$+30\%$）。
   - 故主派出高魅說客持密函私下重金封官（$+35\%$）。
2. **叛變後果爆發**：
   - 該將在城內起兵叛亂，扣押城內所有糧餉物資，**該城池直接更換旗幟倒戈歸附敵國**。
   - 玩家獲得「背信棄義」仇敵羈絆，全國百姓震動，民心下跌 $15$ 點。

# 3KLife 陰平百丈懸崖裹氈自滾穿透險隘奇襲要塞狀態機規格書

## 1. 系統概述與設計哲學
在蜀漢與曹魏交界之高山峻嶺中，常規險關（如劍閣、陽安關）依託天險固若金湯，正面進攻幾無破關可能。三國統帥（如鄧艾破蜀）實施極限山地行軍「陰平百丈懸崖裹氈滾崖奇襲」（CLIFF-ROLL-FELT-AMBUSH01）。
當部隊穿行於無人煙之崇山險壑，遭遇數百丈高深不見底之直立斷崖且糧道斷絕時，主帥親率精銳將士以厚重羊毛毛氈層層包裹軀體甲冑，抱頭蜷縮，順著陡峭崖壁與灌木叢飛速翻滾滑落深谷。此舉雖伴隨一定摔傷減員，但能徹底穿透敵軍正面防禦縱深，如天降神兵般驟然殺至敵後空虛要塞城下，達成兵不血刃破城之戰略奇蹟。

## 4. 衝擊吸收與心理震懾模型

### 4.1 毛氈吸能與墜落傷害計算
多層羊毛氈與山體灌木提供複合阻尼緩衝：
$$\text{Damage}_{\text{fall}} = M_{\text{soldier}} \times g \times H_{\text{drop}} \times (1.0 - \text{Absorb}_{\text{felt}}) \times \text{SlopeAngleFactor}$$
- 實際承受之衝擊動能被大幅吸收至安全範圍內，士兵多為皮肉挫傷或骨裂，陣亡率低於 $2\%$。

### 4.2 心理恐慌與出其不意機制
1. **情報死角**：防守方 AI 判定該懸崖為「不可通行天塹」，要塞後方警戒度為 $0$。
2. **望風潰滅**：守軍見魏軍自後方雲端突然殺出，誤判有數萬大軍飛渡，守城戰鬥力強制削減 $60\%$。

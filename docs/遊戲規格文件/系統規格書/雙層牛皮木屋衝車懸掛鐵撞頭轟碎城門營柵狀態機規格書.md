# 3KLife 雙層牛皮木屋衝車懸掛鐵撞頭轟碎城門營柵狀態機規格書

## 1. 系統概述與設計哲學
在進攻設有堅固包鐵城門、水寨水門或重型鹿角營柵之要塞時，單兵步卒之刀砍斧劈完全無法撼動其防禦。三國攻堅重型破障工程重器「雙層牛皮木屋懸掛鐵撞頭衝車」（BATTERING-RAM-CART-BREACH01）。
衝車由六輪巨大木底盤承載，外覆人字形人字木屋頂，表面緊釘雙層浸水生牛皮與厚泥漿以抵禦城頭火箭礌石。屋頂下方以粗重鐵索懸掛一根長達二丈、重達數千斤且包覆實心生鐵撞頭之巨木撞錘。二十名精壯甲士隱蔽於車廂內部推行抵達門下，協力拉動牽引索向後蓄力，隨後驟然釋放，鐵撞頭以毀滅性動能猛烈轟擊城門榫卯，直至木裂鐵飛轟垮大門。

## 4. 擺錘力學與榫卯應力集中模型

### 4.1 懸擺重力動能轉化公式
撞錘擺動過程重力勢能轉化為終端撞擊動能：
$$E_{\text{impact}} = M_{\text{ram}} \times g \times H_{\text{lift}} = 1500 \times 9.8 \times (L_{\text{cable}} \times (1 - \cos\theta))$$
- 85,000 焦耳動能集中於尖端僅 0.05 平方公尺之生鐵撞頭，產生極高局部接觸應力，直接震碎門閂扣環。

### 4.2 牛皮木屋抗下砸防護
1. **防礌石偏角**：人字形屋頂斜度 $45^\circ$，城頭下落之滾木礌石順斜面滑落兩側，結構受損減免 $70\%$。
2. **防火泥漿保護**：浸水泥漿阻隔火箭熱傳導，完全免疫火矢點燃。

## 5. 單元驗收測試標準
1. **TC-RAM-01 (推進與蓄力撞門全流程)**：
   - 模擬衝車頂住城頭箭雨推至城門下。
   - 驗證牛皮屋頂減傷 95 點，完成煞車固定並以 85,000 焦耳動能實施撞擊。
2. **TC-RAM-02 (連續撞擊累積損毀城門)**：
   - 設定城門防禦耐久 1500 點。
   - 驗證連續 3 次滿幅撞擊後精準切換至 `GATE_FRACTURE_SHATTER`。
3. **TC-RAM-03 (破門後先登突擊轉換)**：
   - 破門瞬間觸發 `ASSAULT_CREW_BURST`，驗證後續部隊湧入速度無阻礙，奪門成功。

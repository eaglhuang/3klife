# 雙池機率表與Up角色加權配置模型規格書

## 1. 核心定位與設計理念
本規格書定義三國生活（3KLife）轉蛋系統之「雙池機率分佈與當期加倍（Up）加權」數值模型（對應 WBS `GCH-01`）。
轉蛋抽卡作為玩家獲取歷史名將與教官支援卡之核心通道，堅持**透明公開、精確控權、資料驅動**原則：
1. **雙池機率分流**：三國名將池（戰鬥武將）與名士支援池（教官傳道卡）採獨立數值機率設定。
2. **當期加倍（Up）嚴格占比**：在命中特定稀有度時，依固定百分比二次判定為「當期 Up 角色」或「常設角色」。
3. **資料驅動無硬編碼**：所有機率常數、Up 武將代碼與標籤映射完全由外部配置表（`gacha-config.json`）管理。

---

## 2. 雙池稀有度基礎機率分佈表
系統定義兩套標準機率表，總合均嚴格為 100%（$1.0$）：

### 2.1 三國名將池（武將池）機率表 (`GACHA_RARITY_RATES`)
針對主戰武將本體之抽取：
- **極稀有 (SSR)**：**3.00%** ($P = 0.03$)。五星名將、史詩級無雙統帥。
- **超稀有 (SR)**：**10.00%** ($P = 0.10$)。四星名將、各方名仕豪傑。
- **稀有 (R)**：**87.00%** ($P = 0.87$)。三星良將、基層軍官校尉。

### 2.2 支援池（教官卡池）機率表 (`GACHA_MENTOR_RARITY_RATES`)
針對書院培育教官與戰法傳授卡之抽取：
- **極稀有 (SSR)**：**5.00%** ($P = 0.05$)。天下大儒、頂尖軍師教官。
- **超稀有 (SR)**：**25.00%** ($P = 0.25$)。名門學士、郡望名流。
- **稀有 (R)**：**70.00%** ($P = 0.70$)。地方文士、宿將先賢。

## 3. 當期加倍（Up）占比演算法模型 (`GACHA_UP_SHARE`)
當抽取結果命中對應稀有度時，由系統進行二次加權抽樣：

### 3.1 稀有度內部加倍占比
- **SSR 內部加倍占比**：**70%** ($0.70$)。
  - 當擲出 SSR 時，有 70% 機率從當期焦點 SSR (`Featured_SSR`) 清單中均勻抽取；其餘 30% 機率從常設 SSR 清單中抽取。
  - 單一 Up SSR 綜合獲得機率為：$3\% \times 70\% = 2.1\%$。
- **SR 內部加倍占比**：**80%** ($0.80$)。
  - 當擲出 SR 時，有 80% 機率從當期 Up SR 清單中均勻抽取；其餘 20% 機率從常設 SR 清單中抽取。
  - Up SR 綜合獲得機率為：$10\% \times 80\% = 8.0\%$。
- **R 級角色**：不設當期 Up 標籤，100% 由常設 R 級武將清單均勻抽樣。

### 3.2 女性名將與特殊角色定位映射 (`Female_Role_Type_Map`)
配置表維護武將角色標籤字典，供 UI 特效與卡池限定任務即時過濾：
```json
{
  "Featured_SSR": ["GEN_ZHAOYUN", "GEN_GUAN羽"],
  "Female_Role_Type_Map": {
    "GEN_DIAOCHAN": "DANCER",
    "GEN_SUNSHANGXIANG": "ARCHER",
    "GEN_ZHENJI": "SUPPORT"
  }
}
```

## 4. Unity 與 Cocos Creator 概念對照
| 概念維度 | Cocos Creator 實作架構 | Unity 引擎對照架構 |
| :--- | :--- | :--- |
| **機率配置載入** | `resources.load('data/gacha-config')` 轉型為 `GachaConfig` | `Resources.Load<GachaConfigSO>("gacha-config")` |
| **純資料介面** | TypeScript 唯讀物件與 `Object.freeze` 機率常數字典 | C# `IReadOnlyDictionary` 或唯讀 SerializedField |
| **機率計算抽離** | 純數學演算法，前端僅負責視覺呈現，無直接亂數決定權 | Client 端僅作演出預測，最終結果以伺服器封包為準 |

## 5. 驗證與驗收矩陣 (Acceptance Gate)
1. **TC-GCH01-01 機率表總和驗證**：驗證名將池與支援池各階機率相加必為 1.0，無浮點誤差偏移。
2. **TC-GCH01-02 Up 角色分流權重**：在 100,000 次蒙地卡羅抽樣中，SSR 中 Up 角色佔比落在 $70\% \pm 0.5\%$ 統計區間。
3. **TC-GCH01-03 配置表解析容錯**：驗證 `gacha-config.json` 缺少可選欄位時使用預設保底常數，不觸發異常。

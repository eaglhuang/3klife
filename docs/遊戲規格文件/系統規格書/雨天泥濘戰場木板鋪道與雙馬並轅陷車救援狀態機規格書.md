# 3KLife 雨天泥濘戰場木板鋪道與雙馬並轅陷車救援狀態機規格書

## 1. 系統定位與設計意圖

在三國雨季泥濘戰場（如赤壁敗退華容道、濡須口秋雨連綿、諸葛亮北伐翻越秦嶺黑泥潭）中，暴雨浸泡使道路化為沒脛深泥，重型輜重糧車、投石發石車與裝甲衝車極易陷沒輪轂癱瘓動彈不得。本系統規範後勤工兵緊急應變工程「泥濘戰場鋪木通道與雙馬並轅陷車救援（Muddy Terrain Plank Road Rescue）」之排木鋪設、撬棍頂升、雙馬增力並轅與脫困轉進狀態機：
- **伐木鋪設排木排板（鋪路過泥）**：工兵隨軍攜帶防滑排板，並於路旁就地砍伐雜木，橫向密排鋪設成「木排軟道」，將點狀輪胎壓強分散至大面積地表。
- **青銅槓桿撬棍頂升**：以丈二硬木包裹生鐵撬頭插入陷車輪底，四名力士同時施壓頂起車身，迅速填入碎石碎柴。
- **雙馬並轅牽引脫困**：將原單馬或兩馬轅木換裝加寬橫木橫木（並轅），並聯四至六匹壯碩戰馬同步發力，拉脫泥潭挽回軍資。

## 2. 狀態機架構與轉換生命週期

泥潭陷車救援狀態機（代碼：`MUDDY-TERRAIN-PLANK-ROAD-RESCUE01`）遵循嚴密工程救援週期：

```
[ WAGON_MUD_SINK ] (輪轂深陷泥淖半徑超過三分之一)
          │
          ├── 敵追兵逼近警戒 ──> [ REARGUARD_DEPLOY_STAND ]
          ▼
[ TIMBER_PLANK_LAYING ] (工兵鋪設硬木排板與枯枝碎石墊層)
          │
          ▼
[ LEVER_JACK_ELEVATION ] (長柄生鐵撬棍插入輪底合力撬升)
          │
          ├── 輪軸受損斷裂 ──> [ FIELD_AXLE_REPAIR_KIT ]
          ▼
[ DUAL_TEAM_HARNESSING ] (加裝並轅橫木並聯四馬同步套繮)
          │
          ▼
[ POWER_SURGE_EXTRICATION ] (全體呼號發力拽出深泥駛上排板)
          │
          ▼
[ CONVOY_RESUME_MARCH ] (輜重車隊重獲機動脫離險境)
```

### 狀態細部定義

1. **WAGON_MUD_SINK（陷車困滯）**：
   - 糧車沉入軟爛淤泥深度達 1.5 尺以上，阻力係數暴增 5 倍，單靠常規馱馬無法拉動，整支行軍梯隊被迫停滯。
2. **TIMBER_PLANK_LAYING（鋪木承載）**：
   - 工兵於陷車前方 10 步範圍鋪設雙軌木排，每塊厚 3 寸、寬 2 尺，以鐵抓釘串接，地表承重能力提升 4 倍。
3. **LEVER_JACK_ELEVATION（撬起塞石）**：
   - 4 名工兵操持丈二青岡撬棍，利用支點石塊撬起沉重的車輪底部，助手迅速將鵝卵石與硬柴草塞入輪下空隙。
4. **DUAL_TEAM_HARNESSING（並轅加力）**：
   - 工兵卸下備用轅木，改換加長四馬並聯牽引架，套上兩組四匹挽馬，由馭手統一口令協同發力。
5. **POWER_SURGE_EXTRICATION（脫困衝出）**：
   - 戰馬奮蹄衝刺，拖曳牽引力達到 1200 公斤，車輪滾上木排道，成功拔出泥潭。
6. **CONVOY_RESUME_MARCH（復原行軍）**：
   - 車隊沿木排軌道依序通過泥淖地帶，行軍速度恢復至原本之 80%。

## 3. 關鍵數值與計算判定公式

### 3.1 泥濘阻力與脫困牽引力平衡

糧車成功拔出泥潭之牽引判定條件：
$$F_{pull} \ge F_{resist} = M_{wagon} \times g \times \left(C_{roll} + \frac{D_{sink}}{R_{wheel}} \times \mu_{mud}\right)$$
- $M_{wagon}$：滿載輜重車全重（約 $1600\,\text{kg}$）。
- $D_{sink}$：沉陷深度（0.45 公尺）。
- $R_{wheel}$：車輪半徑（0.60 公尺）。
- $\mu_{mud}$：黏稠淤泥吸附阻力係數（取 0.85）。
- 雙馬並轅並聯 4 匹戰馬可輸出持續牽引力 $F_{pull} \approx 14,000\,\text{N}$，大於總阻力 $11,800\,\text{N}$，確保 90 秒內脫困。

### 3.2 木排分散壓強安全係數

鋪板後地表接觸平均壓強 $P_{ground}$（kPa）：
$$P_{ground} = \frac{M_{wagon} \times g}{2 \times W_{plank} \times L_{plank}} \approx \frac{15680}{2 \times 0.6 \times 1.8} \approx 7.26\,\text{kPa}$$
- 遠低於軟泥地表之極限剪切承載力（約 $15\,\text{kPa}$），杜絕二次塌陷。

## 4. 戰術連鎖與攻防克制

1. **守護全軍命脈後勤**：避免如華容道棄車斷糧的慘劇，確保主力轉進時器械與糧草完整保留。
2. **戰場風險與天敵**：
   - **敵騎兵半渡截擊**：若在車輛脫困作業期間遭遇敵軍輕騎兵突襲，車隊處於無防護定點癱瘓狀態，極易被焚毀。
   - **鋪木材料耗盡**：若在無林荒漠戈壁遭遇泥流，缺乏原木可砍，只能忍痛丟棄沉重輜重。

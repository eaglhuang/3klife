# 霸權領土門檻判定與反霸權同盟橡皮筋反制規格書

> 標籤：`系統規格` `他國AI` `天下大勢` `反霸權同盟` `RAI-10`
> 狀態：`正式生效` · 責任模組：`RivalHegemony` · 參照：`RAI-10` / `PROG-2-1472` / `PROG-2-1710`

---

## 1. 核心定位與設計理念

在長線三國沙盤推演中，若任由強勢勢力無限制滾雪球擴張，將導致天下格局迅速單極化而失去博弈樂趣。
反霸權同盟機制（Anti-Hegemony Coalition）作為系統級的「動態橡皮筋反制（Dynamic Rubber-banding）」，旨在當單一勢力領土達到臨界威脅時，自動凝聚其餘所有割據勢力（包含玩家與其餘 AI），對霸主形成強大的包夾與外交遏制。

本規格書定義霸權狀態判定與反制推進模型（`RivalHegemony.ts`），遵循以下原則：
1. **客觀領土比例驅動**：完全依據全局實際佔領城池數（Territories）計算佔比，拒絕人為黑箱。
2. **階梯式反制壓力**：30% 啟動外交同盟圍堵，40% 進一步施加境內叛亂壓力。
3. **強制入盟機制（Forced Membership）**：非霸主勢力自動入盟，禁止作壁上觀。
4. **外交極化加速**：大幅倍增非霸主陣營與霸主之間的邦交惡化速率，加速全面圍剿。

## 2. 領土佔比與霸主判定演算法

```mermaid
flowchart TD
    Count[統計全地圖勢力領土 territories] --> CalRatio[計算各勢力領土佔比 domainRatioOf]
    CalRatio --> FindMax[找出佔比最高的勢力]
    FindMax --> CheckHegemon{佔比 >= 30%?}
    CheckHegemon -->|否| NoHegemon[無霸主: hegemonId = null<br/>同盟狀態 = NONE<br/>衰減速率 = 2]
    CheckHegemon -->|是| SetHegemon[確認霸主: hegemonId = best.id]
    SetHegemon --> CheckRebel{佔比 >= 40%?}
    CheckRebel -->|是| ApplyRebellion[啟動叛亂壓力機制: shouldApplyRebellionPressure = true]
    CheckRebel -->|否| NormalHegemon[常規霸權階段]
    NormalHegemon --> RoleCheck{評估當前勢力 holderId}
    ApplyRebellion --> RoleCheck
    RoleCheck -->|為霸主本尊| HegemonSelf[狀態 = NONE<br/>衰減速率 = 2]
    RoleCheck -->|為其餘勢力/玩家| CoalitionMember[狀態 = FORCED_MEMBER<br/>衰減速率 = 4 (加速惡化)]
```

### 2.1 領土佔比計算 (domainRatioOf)
$$R_{domain} = \frac{\max(0, \text{holder.territories})}{\sum_{h \in \text{holders}} \max(0, h.\text{territories})}$$
若全地圖總領土為 0，安全回傳 0。

### 2.2 核心門檻配置表
- `HEGEMON_DOMAIN_RATIO = 0.3`（30%）：觸發反霸權同盟的最低門檻。
- `REBELLION_DOMAIN_RATIO = 0.4`（40%）：觸發霸主內部叛亂壓力之嚴格門檻。
- `RELATION_DECAY_RATE = 2`：常態下邦交每季自然向 0 回歸的步進值。
- `COALITION_RELATION_DECAY_RATE = 4`：反霸權同盟生效時，聯盟成員與霸主間的加速衰減步進值。

## 3. 反霸權同盟運作機制 (CoalitionStatus)

當 `findHegemon` 判定存在佔比 $\ge 30\%$ 且最高的單一勢力時：
1. **霸主自身 (`holderId === hegemon.id`)**：
   - `state: 'NONE'`
   - `relationDecayRate: 2`
2. **其餘所有 AI 勢力與玩家**：
   - 自動被賦予 `state: 'FORCED_MEMBER'`，強制成為同盟成員。
   - `relationDecayRate: 4`：與霸主之間的邦交每季以雙倍速率劇烈惡化，迅速滑向敵對。

---

## 4. 邦交自然衰退與向零收斂 (decayRelation)

無論常態或同盟狀態，雙方若無外交維護，數值皆以 `rate` 穩定朝 0（中立）回歸，且嚴格不穿透 0：

$$\text{decayRelation}(V, \text{rate}) = \begin{cases}
\max(0, V - \text{rate}) & \text{若 } V > 0 \\
\min(0, V + \text{rate}) & \text{若 } V < 0 \\
0 & \text{若 } V = 0
\end{cases}$$

- **範例 1（盟友疏離）**：$V = +5, \text{rate} = 4 \implies \max(0, 5 - 4) = +1$。
- **範例 2（平息敵意）**：$V = -3, \text{rate} = 4 \implies \min(0, -3 + 4) = 0$。

---

## 5. 新霸主崛起提示演算法 (newAiHegemonOf)

為避免每季重複彈出「曹操成為霸主」的擾民通知，系統採差分比對：
- 比對季初 `before` 與季末 `after` 的領土分佈。
- 只有當「季末存在霸主、該霸主非玩家、且該霸主與季初不同」時，才回傳 `hegemonId` 觸發全域警報彈窗。
- 若同一 AI 勢力連續多季維持霸主地位，回傳 `null`，保持遊戲節奏流暢。

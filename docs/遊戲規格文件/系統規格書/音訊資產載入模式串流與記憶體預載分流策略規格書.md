# 3KLife 音訊資產載入模式串流與記憶體預載分流策略規格書

> **規格代碼**：SPEC-AUDIO-ASSET01  
> **關聯 WBS**：AUDIO-ASSET-01（音訊載入模式分流：長音樂串流、短音效記憶體預載與即時卸載）  
> **文件版本**：v1.0.0 (單一真相來源，無補丁整併版)  
> **所屬系統**：全域架構總控（Global Architecture & Audio Pipeline）

---

## 1. 核心宗旨與設計哲學

音訊檔案在解碼為無壓縮 PCM 音訊時，記憶體常膨脹 10 倍以上（一首 3MB 之 MP3/OGG 解碼後可佔用 30MB 記憶體）。若配置不當將迅速導致低階行動設備 OOM 崩潰。本規格書制定全專案**音訊資產雙軌載入模式分流矩陣（Streaming vs Memory Preload）**與**場景退出即時資源釋放標準**。

---

## 2. 雙軌載入模式分流矩陣

所有音訊資產依時長與呼叫頻率嚴格劃分為三大載入梯隊：

| 音訊類別 (Category) | 時長特徵 | 建議格式 | Cocos 載入模式 (AudioClip.LoadMode) | 記憶體駐留策略 |
|---|---|---|---|---|
| **長篇 BGM (背景音樂)** | $> 30\text{ 秒}$ | OGG / MP3 (VBR 128kbps) | **`STREAMING`** (邊下邊播/串流解碼) | 記憶體佔用 $<1.5\text{MB}$；場景切換時釋放前一首。 |
| **高頻 SFX (打擊/UI)** | $< 3\text{ 秒}$ | WAV / OGG (CBR 96kbps) | **`WEB_AUDIO`** (預先解碼至記憶體緩衝) | 零延遲（$<5\text{ms}$）；駐留於對應 Bundle 記憶體池。 |
| **長語音 Voice (武將台詞)** | $3 \sim 15\text{ 秒}$ | MP3 (112kbps) | **`DOM_AUDIO`** 或動態異步載入 | 播放完畢後延遲 30 秒自動釋放，防止累積。 |

## 3. 資料介面與記憶體生命週期管線

```typescript
export interface AudioClipConfig {
  clipPath: string;                   // 如 "audio/bgm/battle_theme_01.mp3"
  category: 'BGM' | 'SFX' | 'VOICE';
  loadMode: 'STREAMING' | 'WEB_AUDIO' | 'DOM_AUDIO';
  preloadWithBundle: boolean;         // 是否隨 Bundle 啟動時預先載入
  autoReleaseOnSceneExit: boolean;    // 場景退出時是否自動銷毀
}

export interface AudioMemoryAuditReport {
  totalAudioMemoryBytes: number;      // 音訊總記憶體佔用 (硬預算 <= 25MB)
  activeStreamingBgmCount: number;    // 必須 <= 1
  loadedSfxClipsCount: number;
}
```

### 3.1 場景切換卸載時序 (Scene Unload Policy)

1. 當觸發場景切換（如退出戰鬥返回大廳）時：
   - 停止當前戰鬥 BGM 播放。
   - 遍歷 `battle_assets` Bundle 內之所有專屬戰鬥 SFX AudioClip。
   - 調用 `assetManager.releaseAsset(clip)`，將 PCM 緩衝區自 Web Audio 上下文中安全卸載。
   - 保證全域音訊記憶體佔用維持於 $\le 25\text{MB}$ 安全紅線之內。

## 4. 驗收測試案例 (Test Cases)

- **TC-AUDIO-ASSET-01【長篇 BGM 串流載入記憶體檢驗】**：載入長度 3 分半鐘之大廳古風 BGM（檔案大小 4.2MB），驗證音訊記憶體佔用僅增加 $1.2\text{MB} \le 1.5\text{MB}$，證明未進行全曲解碼。
- **TC-AUDIO-ASSET-02【UI 點擊音效零延遲打擊感】**：點擊確認按鈕觸發 `sfx_ui_click`，驗證聲音輸出延遲 $< 8\text{ms}$，無串流等待卡頓。
- **TC-AUDIO-ASSET-03【退出戰鬥音訊記憶體完整卸載】**：自戰鬥返回大廳，戰鬥專屬音效（重裝騎兵衝鋒、烈火焚城）自記憶體中完全釋放，無殘留記憶體洩漏。

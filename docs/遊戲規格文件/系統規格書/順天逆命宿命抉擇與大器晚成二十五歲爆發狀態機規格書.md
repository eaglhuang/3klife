# 順天逆命宿命抉擇與大器晚成二十五歲爆發狀態機規格書

> 標籤：`BRD-08` · `M3` · `宿命分流` · `大器晚成` · `單一真相來源`

---

## 1. 核心定位與職責邊界

本規格書定義《三國志·漢末霸業》血統家族培育體系中，子嗣年滿 5 歲揭曉後之「宿命分流抉擇（順天／逆命）」狀態機，以及抗命者機率觸發「大器晚成（Late Bloomer）」並於 25 歲後獲得爆發性成長加成之數值計算模型。

本模組為純邏輯無副作用運算，所有抉擇皆具單向不可逆性。

---

## 2. 狀態機不變量校驗（Invariants）

子嗣在進行宿命抉擇時，系統嚴格執行前置防禦：

```typescript
export class FateError extends Error {}

export function chooseFate(
    source: UnveilingGeneral,
    choice: FateChoice,
    random: RandomSource = Math.random
): UnveilingGeneral {
    if (!source.fate) {
        throw new FateError(`${source.id} 尚未開獎，不能選擇宿命`);
    }
    if (source.fate.choice) {
        throw new FateError(`${source.id} 已經做過宿命選擇`);
    }
    // ...
}
```

1. **已開獎前置**：武將必須已經歷 5 歲開獎流程，具有 `fate.recommended` 建議值；未開獎者拋出 `FateError` 拒絕。
2. **單次不可逆性**：每位武將一生僅限做出一次宿命抉擇；若 `fate.choice` 存在，禁止重複選擇。
3. **培育准入關卡**：未完成宿命抉擇之子嗣，嚴格禁止登記入學或進入 36 回合育成流程。

## 3. 順天逆命分流狀態機

宿命提供「順應天命（`accept`）」與「逆天而行（`defy`）」二選一分支：

```
                    ┌─────────────────────────┐
                    │      玩家宿命抉擇       │
                    └────────────┬────────────┘
                                 │
                     [ choice == 'accept' ]
                     ├── 是 ──> 職能 = recommended, 成長率 ×1.0, lateBloomer = false
                     └── 否 ('defy')
                                 │
                    ┌────────────┴────────────┐
                    │ 強制轉為對立職能 (武<->文) │
                    │ 基礎成長懲罰: ×0.80     │
                    │ 擲骰: random() < 0.10   │
                    └────────────┬────────────┘
                                 │
                     [ 命中大器晚成機率 10% ]
                     ├── 是 ──> lateBloomer = true (25歲逆轉爆發)
                     └── 否 ──> lateBloomer = false (終身成長打折)
```

### 3.1 分支規則與數值對照表

| 分支選項 | 最終職能 (`careerClass`) | 基礎成長倍率 (`growthModifier`) | 大器晚成判定 (`lateBloomer`) | 說明 |
|---|---|---|---|---|
| **順應天命 (`accept`)** | 遵從推薦（武官或文官） | $1.00$（無修正） | `false`（不擲骰） | 踏實成長，順應天賦天資 |
| **逆天而行 (`defy`)** | 強制對立（武轉文、文轉武） | $0.80$（抗命懲罰） | $10\%$ 機率命中為 `true` | 強行違逆天賦，少年期成長艱難 |

## 4. 大器晚成 25 歲動態逆轉爆發模型

逆天而行並成功激發「大器晚成」宿命的武將，將在青年巔峰期迎來潛能噴發：

```typescript
export const FATE_DEFY_GROWTH_MODIFIER = 0.8;
export const LATE_BLOOMER_CHANCE = 0.1;
export const LATE_BLOOMER_AGE = 25;
export const LATE_BLOOMER_GROWTH_MODIFIER = 1.5;

export function effectiveGrowthModifier(general: UnveilingGeneral): number {
    const base = general.growthModifier ?? 1;
    if (general.fate?.lateBloomer && (general.age ?? 0) >= LATE_BLOOMER_AGE) {
        return LATE_BLOOMER_GROWTH_MODIFIER;
    }
    return base;
}
```

### 4.1 成長率生命週期曲線
1. **$5 \sim 24$ 歲少年與青年期**：
   - 生效成長倍率為 $0.80$。各項訓練、歷練所獲五維成長經驗值皆受到 $20\%$ 衰退折損。
2. **$25$ 歲及以後巔峰期**：
   - 季度增齡使 `age >= 25` 時，`effectiveGrowthModifier` 實時跳升至 $1.50$。
   - 所有屬性成長率獲得 $+50\%$ 乘區增幅，徹底彌補前期落後之屬性差距，實現逆天改命。

### 4.2 無狀態純函式精算原則
- 底層存檔中僅保留靜態 `growthModifier: 0.8` 與 `fate.lateBloomer: true`。
- 實際戰鬥或培育結算時，統一呼叫 `effectiveGrowthModifier(general)` 動態推導，避免因為歷史修改時序而導致資料被寫死污染。

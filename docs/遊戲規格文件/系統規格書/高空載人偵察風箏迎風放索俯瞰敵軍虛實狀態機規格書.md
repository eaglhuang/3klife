# 3KLife 高空載人偵察風箏迎風放索俯瞰敵軍虛實狀態機規格書

## 1. 系統定位與設計意圖

在三國曠野大兵團合圍（如官渡、下邳圍城）或崇山峻嶺對峙中，地面哨探無法洞察深溝高壘後方之虛實。本系統規範三國特種空中高空索敵設備「高空載人偵察木鳶風箏（Man-Lifting Kite Reconnaissance）」之氣動升力、迎風放索、高空俯瞰觀測與情報投遞狀態機：
- **巨型雙翼竹骨風箏**：以百年生長之老南竹劈剖為輕質彈性骨架，繃緊厚質絲絹與桐油麻布，形成展翼達二丈半之雙層升力翼面。
- **輕量吊籃與安全保險**：底端懸掛藤編單人吊籃，載負輕裝偵察死士一名，配備高倍青銅單筒窺鏡與信號手旗。
- **高空上帝視角情報**：攀升至五十丈高空，直接俯瞰敵軍中軍大帳部署、後方糧秣堆放位置與預備隊埋伏動向。

## 2. 狀態機架構與轉換生命週期

載人風箏偵察狀態機（代碼：`MAN-LIFTING-KITE-RECONNAISSANCE01`）管理從地面迎風起飛至安全收索著陸之完整週期：

```
[ WIND_SPEED_EVALUATION ] (地面風速與氣流穩定度評估)
          │
          ├── 風力不足或狂風暴虐 ──> [ ABORT_HOLD_LAUNCH ]
          ▼
[ GROUND_TOW_LIFT_OFF ] (十名甲士迎風奔跑拉索助推升空)
          │
          ├── 迎角失速 ──> [ PULL_STABILIZER_TAIL ]
          ▼
[ WINCH_CABLE_ASCENT ] (地面大型絞盤均勻放繩攀升至高空)
          │
          ├── 氣流顛簸橫滾 ──> [ WING_WARPING_BALANCE ]
          ▼
[ HIGH_ALTITUDE_SURVEY ] (高空定高懸浮俯瞰繪製敵陣圖)
          │
          ├── 遭遇地面強弩曲射 ──> [ EMERGENCY_RAPID_WINCH_DOWN ]
          ▼
[ FLAG_DROP_DISPATCH ] (投擲鉛錘竹筒急報或揮動高空手旗)
          │
          ▼
[ SMOOTH_WINCH_RECOVERY ] (絞盤緩慢收緊牽引死士安全著陸)
```

### 狀態細部定義

1. **WIND_SPEED_EVALUATION（測風評估）**：
   - 觀測旗官以風羽測速，確保地面風力維持在 4 至 5 級（約 6.0~10.5 m/s），無突發下沉氣流。
2. **GROUND_TOW_LIFT_OFF（奔跑起飛）**：
   - 吊籃斥候固定安全皮帶，地面 12 名甲士迎風全力拉索狂奔 30 步，風箏翼面吃風瞬間產生巨大升力拔地而起。
3. **WINCH_CABLE_ASCENT（絞盤放線）**：
   - 地面青銅齒輪絞盤以每秒 1.2 公尺平穩放長加固生牛皮麻芯主纜，風箏循 60 度仰角平穩攀升至 120 公尺高空。
4. **HIGH_ALTITUDE_SURVEY（高空偵察）**：
   - 斥候在吊籃內使用銅鏡觀測，視野覆蓋半徑達 30 里，敵軍營寨內箭塔死角、虛設稻草人疑兵無所遁形。
   - 斥候於絹布上速繪敵陣草圖，裝入附帶羽毛的鉛錘竹筒空投至中軍指揮所。
5. **SMOOTH_WINCH_RECOVERY（收索著陸）**：
   - 完成任務後，地面 8 名壯士旋轉雙搖把絞盤收回主纜，死士輕巧落地歸隊。

## 3. 關鍵數值與計算判定公式

### 3.1 氣動翼面升力與全重平衡

載人風箏空中總升力 $L_{lift}$ 計算公式：
$$L_{lift} = \frac{1}{2} \rho_{air} \times V_{wind}^2 \times S_{wing} \times C_L$$
- $\rho_{air}$：空氣密度（$1.225\,\text{kg/m}^3$）。
- $V_{wind}$：高空相對風速（約 $8.5\,\text{m/s}$）。
- $S_{wing}$：雙翼總有效迎風面積（約 $14.5\,\text{m}^2$）。
- $C_L$：三國弧形竹弓翼面升力係數（取 1.15）。
- 計算得總升力 $L_{lift} \approx 738\,\text{N} \approx 75.3\,\text{kgf}$，剛好匹配輕巧偵察兵（55kg）加上藤籃與風箏骨架（20kg）之平衡重量。

### 3.2 高空情報揭露指數（Recon Index）

高空俯瞰對敵方戰場迷霧破除效率：
$$\text{ReconIndex} = \min\left(1.0, \frac{H_{altitude}}{100} \times (1.0 - \text{Haze}) \times \frac{\text{Perception}}{80}\right)$$
- 當升至 100 公尺以上且天氣晴朗時，$\text{ReconIndex} \ge 0.95$，戰場敵軍伏兵與陷阱全面轉為可見實體狀態。

## 4. 戰術連鎖與攻防克制

1. **破解十面埋伏**：使敵軍設於密林、山谷後方的伏兵提前暴露，剝奪敵軍伏擊突襲加成。
2. **天敵與風險判定**：
   - **狂風折翼斷纜**：風力突增至 7 級以上時，翼肋竹條有 28% 機率斷裂，導致風箏翻滾失控墜毀。
   - **八牛弩仰天狙擊**：敵軍若推動超重型床弩調至極限仰角，射出穿甲長矛，有 15% 機率凌空擊穿風箏。

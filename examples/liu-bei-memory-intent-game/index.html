資料驅動互動小劇場

人物回憶意圖劇場

這個原型會優先讀取 npc-brain 的真實 persona、relationship edges、evidence cards 與 activity seeds， 再把它們轉成「想到誰、心裡怎麼變、接下來想做什麼」的互動敘事。互動對象、原文證據與角度一旦改變，人物的情緒、判斷與行動也會跟著改變。

資料偵測中 優先連到 npc-brain narrative profile API；如果 API 沒開，會自動退回示範資料。

    插圖構圖 Prompt

    這裡會保留送去圖像模型的原始 prompt，右側則直接顯示 API 生成後的插圖，方便你同時看劇情與構圖依據。

    等待第一幕生成後，這裡會自動整理一段可以直接餵給圖像模型的 prompt。

    目前是 prompt 版，適合後續接 GPT Image、DALL·E 或其他圖像模型。

## 二、核心公式與數值上限（數值將全數外置於 `assets/resources/data/bloodline-resonance-rules.json`）

### 1. 變數定義與範圍
- `round`：培育當前回合數，僅於 `round === 12` 與 `round === 24` 檢定；`NurtureSession` 紀錄 `resonanceRoundsDone?: number[]`，確保放棄重修或重入不會重複領取。
- $K \in [0, 15]$：由 `FamilyCompatibility.ts` 計算之雙親門風契合度總分。
- $R_{\text{tag}} \in [0, 5]$：直系先祖（雙親與祖父母，最多 6 位）中，與子嗣共有同一因子類別／戰術標籤，或持有同色 3★ 以上因子的組數（上限鉗制為 `5`）。
- $S_{\text{elite}} \in [0, 5]$：直系先祖中已解鎖 3★ 以上因子或金色／紅色稀有傳承標籤的數量（上限鉗制為 `5`）。

### 2. 共鳴觸發機率 $P_{\text{res}}$ 與黃金升格機率 $P_{\text{gold}}$
- **一般血脈共鳴觸發率**：
  $$P_{\text{res}} = \text{clamp}(0.35 + 0.03 \times K + 0.02 \times R_{\text{tag}},\ 0.35,\ 0.95)$$
  - 下限 `0.35`：確保新手散配局仍有基本期待感。
  - 上限 `0.95`：保留 5% 懸念，避免完全機械化。
- **黃金共鳴升格率**（僅在已判定觸發共鳴後擲骰）：
  $$P_{\text{gold}} = \text{clamp}(0.05 + 0.02 \times K + 0.03 \times S_{\text{elite}},\ 0.05,\ 0.50)$$
  - 下限 `0.05`，上限 `0.50`。

### 3. 收益結算（依 $K$ 與共鳴階級縮放）
- **一般共鳴（Normal Resonance）**：
  - 單維屬性跳升：`statBonus = clamp(Math.round(4 + 0.25 * K), 4, 8)`（先祖最強維度 `+4 ~ +8`）。
  - 因子共鳴：挑選 1 枚先祖已解鎖之藍/白因子；若子嗣尚未擁有則以 1★ 共鳴繼承，若已擁有則星級 `+1`（上限 `3★`）。
- **黃金共鳴（Golden Resonance）**：
  - 雙維屬性跳升：`statBonus = clamp(Math.round(6 + 0.40 * K), 6, 12)`（先祖前兩強維度各 `+6 ~ +12`）。
  - 因子共鳴：必觸發 1 枚先祖因子共鳴繼承或升星（上限 `3★`）。
  - 兵種適性突破：若子嗣任一兵種適性低於先祖該兵種最高適性（`C -> B -> A -> S`），擇差距最大者提升 `+1` 階（上限 `S`）。

## 三、3 組實際算例

1. **算例 A（新手散配局）**：$K = 0,\ R_{\text{tag}} = 1,\ S_{\text{elite}} = 0$
   - $P_{\text{res}} = \text{clamp}(0.35 + 0 + 0.02,\ 0.35,\ 0.95) = 37\%$
   - $P_{\text{gold}} = \text{clamp}(0.05 + 0 + 0,\ 0.05,\ 0.50) = 5\%$
   - 收益：一般共鳴單維 `+4`；若極低機率出黃金則雙維 `+6`。
2. **算例 B（中期雙人組局）**：$K = 9$（風格互補 5 + 名門聯姻 4）、$R_{\text{tag}} = 3,\ S_{\text{elite}} = 2$
   - $P_{\text{res}} = \text{clamp}(0.35 + 0.27 + 0.06,\ 0.35,\ 0.95) = 68\%$
   - $P_{\text{gold}} = \text{clamp}(0.05 + 0.18 + 0.06,\ 0.05,\ 0.50) = 29\%$
   - 收益：一般共鳴單維 `+6`；黃金共鳴雙維 `+10` + 適性突破。
3. **算例 C（極端六代名門堆疊局）**：$K = 15,\ R_{\text{tag}} = 5,\ S_{\text{elite}} = 5$
   - $P_{\text{res}} = \text{clamp}(0.35 + 0.45 + 0.10,\ 0.35,\ 0.95) = 90\%$
   - $P_{\text{gold}} = \text{clamp}(0.05 + 0.30 + 0.15,\ 0.05,\ 0.50) = 50\%$（觸頂）
   - 收益：一般共鳴單維 `+8`；黃金共鳴雙維 `+12` + 適性突破。

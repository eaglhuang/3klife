## 一、雙年先祖遺風開獎（第 12 回合期中 ＋ 第 24 回合弱冠）

### 1.1 引用現有規格與整合點
- `doc_spec_1127` §2 定義第 12 回合為期中考核、第 24 回合為弱冠之禮。
- `AcademyTrainingEngine.ts` 的 `MIDTERM` 與 `COMING_OF_AGE` 打斷點目前未讀取 14 祖位的藍／粉因子星數。
- `doc_spec_0610` §2 規定常規粉因子適性躍升上限鎖定 `S` 階，不越過十四名將共鳴之 `EX` 門檻。

### 1.2 公式與變數範圍
- **14 祖位加權藍因子總星數** $S_{\text{blue}} \in [0, 70]$：父母權重 $1.0$、祖父母 $0.5$、曾祖 $0.25$，取四捨五入整數（上限鎖定 $70$）。
- **父母與祖父母最高粉因子星數** $R_{\text{pink}} \in \{0, 1, 2, 3\}$。
- **單次繼承共鳴機率**：
  $$P_{\text{inherit}} = \text{clamp}(0.15 + S_{\text{blue}} \times 0.006,\; 0.15,\; 0.65)$$
  （下限 $15\%$，上限 $65\%$）
- **觸發後五維靈感加值**：
  $$\Delta \text{Stat} = \text{clamp}(\text{round}(4 + S_{\text{blue}} \times 0.35),\; 4,\; 28)$$
  （加於對應祖位主修五維，仍受學府 `statCap` 約束）
- **粉因子適性升階機率**（當 $R_{\text{pink}} \ge 1$ 且該次先祖共鳴觸發時）：
  $$P_{\text{apt}} = \text{clamp}(0.08 \times R_{\text{pink}},\; 0.08,\; 0.24)$$
  （範圍 $8\% \sim 24\%$，觸發後該武將對應兵種／地形適性 $+1$ 階，最高鎖 `S` 階）

### 1.3 三組實際算例
1. **新手（初代 G1，父母各 1★ 藍因子、無粉因子）**：$S_{\text{blue}} = 2,\; R_{\text{pink}} = 0$
   - $P_{\text{inherit}} = 0.15 + 2 \times 0.006 = 16.2\%$；若觸發得 $\Delta \text{Stat} = 5$ 點；$P_{\text{apt}} = 0\%$。
2. **中期（G2 培養，父母各 3★ + 祖父 2★、2★ 騎兵粉因子）**：$S_{\text{blue}} = 24,\; R_{\text{pink}} = 2$
   - $P_{\text{inherit}} = 0.15 + 24 \times 0.006 = 29.4\%$；若觸發得 $\Delta \text{Stat} = 12$ 點；$P_{\text{apt}} = 16\%$。
3. **極端（G4 百年門閥，14 祖位滿配 + 3★ 粉因子）**：$S_{\text{blue}} = 70,\; R_{\text{pink}} = 3$
   - $P_{\text{inherit}} = \min(0.65,\; 0.15 + 70 \times 0.006) = 57.0\%$；若觸發得 $\Delta \text{Stat} = 28$ 點；$P_{\text{apt}} = 24\%$（受常規上限 `S` 封頂）。

### 1.4 決策選擇題 1：雙年繼承開獎的失敗保底機制
- **選項 A（建議）**：第 12 回合未觸發時，第 24 回合 `P_inherit` 額外 $+10\%$（但總上限仍不超過 $65\%$），避免同一輪培育兩次全空引發挫折感。
- **選項 B**：兩次獨立擲骰、不設保底，維持純粹血統星數期待值。
- **選項 C**：兩次皆必觸發小額靈感（$\Delta \text{Stat} \ge 4$），上述機率改為決定是否升級成「大覺醒（$\times 1.5$ 倍）＋粉因子檢定」。

## 二、學府結業「生平白因子印記」凝練與戰法折扣

### 2.1 公式與變數範圍
- 依據 `AcademyGraduation.ts` 的 `grade` $\in \{\text{C}, \text{B}, \text{A}, \text{S}\}$ 與期間重大共鳴次數 $N_{\text{resonance}} \in [0, 10]$：
  $$P_{\text{mark}} = \min\!\left(1.0,\; \text{baseByGrade}(\text{grade}) + \min(0.20,\; N_{\text{resonance}} \times 0.05)\right)$$
  - `baseByGrade`：`C = 0.10`、`B = 0.25`、`A = 0.50`、`S = 0.80`（總範圍 $10\% \sim 100\%$）。
- 星等對應：`C/B → 1★`、`A → 2★`、`S → 3★`；單次結業最多凝練 $1$ 枚對應學府的白因子印記。
- 子代繼承該印記後，學習同流派戰法時 TP 消耗減免 $5\% \times \text{Stars}$（單印記上限 $-15\%$，與綠色因子折半機制不突破總折扣上限 $60\%$）。

### 2.2 三組實際算例
1. **新手**：`grade = 'C'`，$N_{\text{resonance}} = 0 \Rightarrow P_{\text{mark}} = 10\%$，凝練得 `1★` 印記（TP $-5\%$）。
2. **中期**：`grade = 'B'`，$N_{\text{resonance}} = 2 \Rightarrow P_{\text{mark}} = 25\% + 10\% = 35\%$，凝練得 `1★` 印記（TP $-5\%$）。
3. **極端**：`grade = 'S'`，$N_{\text{resonance}} = 4 \Rightarrow P_{\text{mark}} = \min(1.0,\; 0.80 + 0.20) = 100\%$，必得 `3★` 印記（TP $-15\%$）。

### 2.3 決策選擇題 2：生平白因子印記的持有上限與覆蓋規則
- **選項 A（建議）**：每名武將最多同時持有 $2$ 枚「生平印記白因子」（學府 $1$ 枚＋未來實戰里程碑 $1$ 枚），不佔用藍／紅／金因子槽位，獨立列入譜牒遺傳池。
- **選項 B**：列入既有 `genes` 陣列共用槽位，超過上限時替換最低星等白因子。
- **選項 C**：無限累積但僅取最高星 $2$ 枚參與子代配種抽樣。

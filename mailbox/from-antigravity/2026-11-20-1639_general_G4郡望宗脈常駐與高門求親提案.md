## 一、背景與規格對照
依核心藍圖 `sanguo_bloodline_wp10_umamusume_mapping.md` §2.1 與 §4，門閥升格（`布衣寒門 → 地方豪族 → 郡望世家 → 天下高門`）對應《WP10 2025》最核心的終局目標「**親系統確立（System Establishment）**」：當家族確立郡望與高門後，該祖先因子應成為「**宗脈常駐特徵**」，且高門應吸引天下名門爭相求親。

對照現有程式與規格（`血統傳承G4百年門閥_開宗立派與天下郡望規格書.md`、`ClanTier.ts`、`ClanTradition.ts`）：
1. **實作缺口 1（`ClanTradition.ts` 第 20-45 行）**：`CATEGORY_KIND` 將 `attribute` 一律映射為 `'str'`（武力），導致以 `int`（智謀）、`cha`（魅力）為主力的儒門或名士世家立郡望後，卻錯誤獲得「武力修業 +10%」。
2. **實作缺口 2（`ClanTier.ts:176` 註解明確標示「高門求親效果還沒做」）**：Tier 2 僅有 +10% 單維修業效率，Tier 3 天下高門尚無實質玩法紅利，導致 G3～G4 達成高門里程碑後缺乏《WP10》親系統確立的長線爽感。

## 二、需要裁決的選擇題

### Q1：Tier 2「郡望世家」確立時的宗脈常駐效果與五維映射修正
- **選項 A（推薦）**：
  1. 修正 `ClanTradition.ts` 的 `kindOfFactor`，先依因子 ID / 字典 tag 精確對照五維（`str / int / lea / pol / cha`），再退回 `category`，並寫入 `assets/resources/data/clan-tradition-rules.json`。
  2. 確立 Tier 2 郡望家風後，啟用「**宗脈常駐**」：玩家家族新生兒（父母至少一方屬本宗）若 5 格繼承因子尚未滿額且未含本宗家風因子，**額外保底附帶 1 枚該家風 `1★` 藍因子種子**（不超過 5 格總上限）。
  - **理由**：直接落實《WP10》親系統確立「祖先因子常駐宗脈」，且僅補 `1★` 種子不破壞高星稀有度，能確保玩家辛苦培養的「智謀郡望／統率郡望」不會在後代徹底斷絕。
- **選項 B**：僅修正五維映射錯誤與 UI 稱號顯示，維持現有單維修業 `+10%`，不增加新生兒保底因子。

### Q2：Tier 3「天下高門」的高門求親機制
- **選項 A（推薦）**：確立 Tier 3 天下高門後，解鎖「**高門求親紅利**」：
  1. AI 提親／外家結緣推薦池之品質下限提升（候選客方 `EP >= 70`，且至少持有 `1` 枚 `>= 2★` 因子）。
  2. 與名門／高門候選結緣時，門風契合度額外 `+2`（仍受 `K ∈ [0, 15]` 上限限制），且外交結緣／提親所得黃金禮金 `+30%`。
  - **理由**：讓 `ClanTier.ts:176` 待辦的高門求親落地，把 G4 門閥地位轉化為「更穩定取得高星外血」與「家族經濟正循環」。
- **選項 B**：僅給提親禮金 `+30%` 經濟加成，不調整候選品質與契合度 `K`。

## 三、公式、上下限與 3 組算例

### 變數與上下限
- `traditionKind ∈ {'str', 'int', 'lea', 'pol', 'cha'}`：由家族名冊中持有 `>= 3★` 藍因子的最多人數決定。
- `clanTraditionSeedStar = 1`（僅在 `clanTier >= 2` 且 `child.genes.length < maxFactors(5)` 且未含 `tradition.factorId` 時觸發，固定 `1★`）。
- `nobleProposalMinEp = 70`（`clanTier >= 3` 時生效；`clanTier < 3` 無強制下限）。
- `highClanSynergyBonus = 2`，套用後 `totalK = min(15, kStyle + kLineage + kEpithet + highClanSynergyBonus)`，硬上限仍為 `15`。
- `highClanGiftMultiplier = 1.30`（提親禮金倍率，上限 `1.30`）。

### 3 組算例
1. **算例 A（新手 G1：布衣寒門 Tier 0）**：
   - 家族剛起步，尚未立郡望（`clanTier = 0`）。
   - 不觸發 `clanTraditionSeedStar`、無高門求親加成，維持既有 14 祖位抽樣與結緣流程，新手無額外理解負擔。
2. **算例 B（中期 G3：智謀郡望 Tier 2，如「權謀／深謀 3★」家族）**：
   - 修正後 `traditionKind` 正確判定為 `'int'`（智力修業 `+10%`，不再誤判為 `'str'`）。
   - 子嗣出生時若只抽中 3 枚因子且不含 `tradition.factorId`，自動補入 1 枚 `1★` 該智謀種子（共 4 枚，未超 5 格上限）。
3. **算例 C（極端 G4：天下高門 Tier 3，已達最高相性）**：
   - 玩家與異脈名門結緣，`kStyle = 5`、`kLineage = 8`、`foes_to_allies = 2`、`highClanSynergyBonus = 2`，總合 `5 + 8 + 2 + 2 = 17`，受硬上限鉗制為 `totalK = 15`，不會突破 EP 平衡上限；同時外家客方保證 `EP >= 70` 且禮金 `×1.30`。

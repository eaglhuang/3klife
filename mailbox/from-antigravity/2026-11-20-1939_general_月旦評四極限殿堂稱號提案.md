## 二、需要裁決的選擇題

### Q1：四極限殿堂稱號的判定門檻與數值規格
- **選項 A（推薦）**：於 `assets/resources/data/yuedan-titles-rules.json` 定義 4 個殿堂稱號，於年度月旦評（或畢業結算）判定並永久記錄於家族史冊／武將稱號：
  1. **王佐全才（六邊形丞相）**：五維（`str, int, lea, pol, cha`）全部 `>= 80`，且總和 `>= 430`。
  2. **萬人敵（單項破百）**：五維任一項 `>= 100`（如 `str >= 100` 或 `int >= 100`）。
  3. **無雙都督（兵種 S 專精）**：持有 `>= 2` 項 `S` 級適性（含兵種／地形適性）且 `EP >= 75`。
  4. **天下外戚（第一門閥）**：單一家族達成 `>= 3` 個世家聯姻（`familySynergy` 活躍世家數 `>= 3`）且族內成年子嗣 `>= 6` 人。
  - **理由**：對應藍圖四條完全不同的養法（均衡培養、極限偏科、紅因子適性培養、多胎廣聯姻），讓每一種流派玩家都有明確的「畢業目標」。
- **選項 B**：只實裝「單項破百（萬人敵）」與「五維均 80（王佐全才）」2 種個人稱號，家族型的「天下外戚」暫緩。

### Q2：首次達成殿堂稱號與年度月旦評入榜的實質獎勵
- **選項 A（推薦）**：
  1. **家族首次達成任一殿堂稱號**：發放一次性家族功業獎勵（黃金 `+500`、族譜查券 `+2`），並於該武將結緣時在預覽標籤顯示稱號徽章（走四語系 i18n）。
  2. **年度月旦評入榜者（前 20%）**：入榜當年結緣時額外獲得 **「月旦名士」受孕率 `+5%`（上限仍受 `0.95` 鉗制）與結緣禮金／好感加成**（不影響先天 EP 與 14 祖位抽樣，不破壞數學平衡）。
  - **理由**：避免給純數值通膨（不加先天屬性），改用「查券＋黃金＋受孕微幅順風＋榮譽徽章」獎勵，兼顧儀式感與資源正循環。
- **選項 B**：僅作為純敘事榮譽稱號展示於月旦評與名冊，不附帶查券／黃金／受孕微幅加成。

## 三、公式、上下限與 3 組算例

### 變數與上下限
- `statMinForAllRounder = 80`、`statSumForAllRounder = 430`（五維皆需達標）。
- `singleStatPeakThreshold = 100`（單項破百即觸發）。
- `sRankAptitudeCountMin = 2` 且 `minEpForCommander = 75`。
- `alliedFamiliesMin = 3` 且 `adultClanMembersMin = 6`。
- `firstTitleRewardGold = 500`、`firstTitleRewardTokens = 2`（每種稱號每存檔只領取一次，以 `claimedYuedanTitles: string[]` 防重複領取）。
- `yuedanConceptionBonus = 0.05`（僅月旦評在榜候選有效，總受孕率仍受 `[0.05, 0.95]` 硬上下限鉗制）。

### 3 組算例
1. **算例 A（新手 G1：普通二世祖，五維 `{72, 68, 70, 65, 66}`，A 適性 1 項）**：
   - 未達任何殿堂稱號門檻（總和 `341 < 430`、最高單維 `72 < 100`、S 適性 `0 < 2`），不發獎勵；若進名冊前 20% 仍依原月旦評放榜。
2. **算例 B（中期 G2：極限偏科流「張飛後代」，STR=102、INT=55、LEA=88、EP=78）**：
   - 單項 `STR = 102 >= 100` → 觸發 **「萬人敵」** 殿堂稱號！首次達成發放黃金 `+500`、譜牒查券 `+2` 並寫入榮譽紀錄。
3. **算例 C（極端 G4：六邊形全才丞相 + 兵種 S 都督 + 第一外戚，五維 `{86, 92, 90, 88, 84}` 總和 440、騎/槍雙 S、EP=92、4 世家聯姻、8 名成年子嗣）**：
   - 同時觸發「王佐全才」「無雙都督」「天下外戚」3 項稱號；查券與黃金依未領過項目各自發放一次（已領過不重複發），受孕率若有月旦評 `+5%` 加成仍被硬上限 `0.95` 鉗制。

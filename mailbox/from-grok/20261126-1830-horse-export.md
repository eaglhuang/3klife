# mount_horse_bay 匯出位置與交付方式
類型：交付
武將／項目：呂布騎馬、紅／藍騎兵 mount_horse_bay
一句話摘要：匯出已在 spine-trial main 的 export/，使用者本機 clone 或 pull 即可得到 C:/Users/User/spine-trial/export。

## 內容
- (a) 位置：eaglhuang/spine-trial，main 分支，`export/`（約 122 MB）。
  - 遊戲用：`export/game/manifest.json`、`export/game/mounted-list.json`、`export/game/spine/generals/{lu_bu,guan_yu,zhao}_mounted/`、`export/game/spine/soldiers/soldier_cavalry_{red,blue}/`。
  - legacy 核可包（含紅騎兵）：`export/mount/soldier_cavalry_red/horse_bay/`，呂布 `export/mount/lu_bu/horse_bay/`。
- (b) 交付到本機（不需 zip）：
  1. 第一次：`git clone https://github.com/eaglhuang/spine-trial.git C:/Users/User/spine-trial`
  2. 已有則：`cd C:/Users/User/spine-trial && git checkout main && git pull`
  3. 之後跑 `tools_node/sync-mount-spine.js`（spine-trial 這邊找不到此腳本，3klife 端自備；可由 mounted-list.json 產生 MOUNTED_GENERALS）。
- 注意：main 上的呂布、關羽騎馬是頭身比統一前的版本；新比例版在 feat/q4-generals，等審核合併後再 pull 一次即可更新。

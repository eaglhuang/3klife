## 2. 骨架與握點
- 骨名就用上表的代碼，加上 `root`。總共 21 骨。
- 武器有兩個握點：`grip_A` 在前手，`grip_B` 在後手。後手用 IK 追 `grip_B`；武器長度改變時只移 `grip_B`。
- 換武器只換 `weapon` 這個 slot 的貼圖和兩個握點座標，骨架不變。

## 3. 品質門檻（probe 自動檢查）
- 相鄰零件在所有影格的重疊面積都要 > 0；靜止姿勢下的重疊目標 ≥ 12%（以較小那件的面積計）。
- 命中幀的 IK 端點誤差 ≤ 4px；握點相對武器漂移 ≤ 1px。
- 去背邊緣不能有綠色溢色：邊緣像素的 G 值不可明顯高於 R、B 的平均值。內縮 1～2px 或做 despill。
- 64px 高剪影要看得出馬尾、長槍、短披風三個特徵。

## 4. 動作幅度最低值（戰場是 1/4 縮放）
- 突刺：武器前伸至少 0.6 個頭寬，軀幹前傾至少 8°，後腳要有蹬地。
- 受擊：軀幹後仰至少 10°，頭部有延遲跟隨。
- 待機：呼吸起伏 2～3%，循環 1.2～1.6 秒。

## 6. 裝備分槽（v0.2，裁決 28）
- 目的：武器、盔甲、戰靴、手套日後可換成不同等級的貼圖。目前先畫「菁英華麗級」（最高級），之後再往下補較低等級，例如皮甲、布甲。
- 原則：**換裝備＝換同一組零件的貼圖**。骨架、pivot、繪製順序都不變。

| 裝備槽 | 對應零件 | 備註 |
|---|---|---|
| 武器 | weapon | 已有規則：換貼圖加兩個握點座標（§2） |
| 胸甲 | torso | 底下的布衣邊緣由貼圖內含 |
| 肩甲 | pauldron_f、pauldron_b | |
| 腰裙甲 | skirt | |
| 臂甲 | arm_upper_f/b、arm_lower_f/b | 袖子、臂鎧一起換 |
| 手套 | hand_f、hand_b | 護手和手指一起換，握槍姿勢不變 |
| 戰靴 | foot_f/b、shin_f/b | 靴甲和脛甲一起換 |

- **外框範圍**：同一槽不同等級，外框寬高差在 ±8% 以內，pivot 位置不變。§3 的重疊門檻要每個等級都過。
- **不挖空**：盔甲零件要畫完整的身體段，不可以留透明洞讓下層透出，所以低等級不會破圖。
- **不受影響的部分**：頭、馬尾、披風、骨盆遮片是角色本人的，不隨裝備換。
- **識別度**：換裝備後，§3 的 64px 特徵（馬尾、長槍、短披風）仍要看得出來。裝備不能蓋掉角色的識別色，例如趙雲的藍白色要留在布料上。

# Q 版武將風格基準 v1
- 維護：Claude（美術總監）
- 日期：2026-10-24 10:35
- 依據：使用者指示（10:00～10:15）、裁決 27～30
- 狀態：生效。蜀國 61 位 Q 版武將原稿一律照本基準。

## 1. 品質基準圖
- 使用者戰鬥原圖：`3KLife/artifacts/art-direction/chibi-baseline/user-ref/battle-chibi-ref-exec-544deac6.png`（Codex／GPT 產）。
- 品質**不可低於**這張圖。以下兩張試作已經退件，不可拿來當參考：
  - `chibi-shu5-baseline-v1`：多人擠在一張，細節太少。
  - Gemini 單人版趙雲：沒有 3D 感，沒有金屬光澤，眼睛不夠 Q 萌。

## 2. 必過四項（交件逐項對照原圖）
1. **3D 光影**：有主光、陰影和邊緣反光，看起來有立體感。
2. **金屬光澤**：甲片要有亮面高光和反射，不可以平塗。
3. **Q 萌大眼**：大而有光澤，有多個高光點；臉是 Q 版，約 2.2～2.5 頭身。
4. **貼圖細節**：雕紋、魚鱗甲、刺繡、皮帶扣、靴甲都要畫出來，而且要在**原生解析度**下清楚。用插值放大的稿不算數。

## 3. 可以簡化的
- 飄帶、髮帶尾、袖帶、長披風可以拿掉或縮短，讓布料貼身。
- 拿掉的布料上原本的紋飾，要轉移到留下來的布料或甲片上，總細節量不可減少。

## 4. 裝備等級
- 目前畫的都是**菁英華麗級**。華麗感靠雕紋的密度表現，不是靠加金色；以銀甲為主的角色，金色只做細邊。
- 武器、胸甲、肩甲、腰裙甲、臂甲、手套、戰靴的邊界要畫清楚，供日後換裝（Rig 規格 §6）。

## 5. 識別
- 每位武將保留招牌武器和識別色。立繪已鎖定的部分如下：
  - 劉備：雙劍
  - 關羽：綠袍、青龍刀
  - 張飛：蛇矛
  - 諸葛亮：羽扇
  - 黃忠：弓
  - 馬超：白甲、獅頭盔
  - 趙雲：黑髮高馬尾、長槍、藍白
- 64px 剪影和灰階要分得出來，用 `identity_check.py` 檢查。

## 6. 交件格式
- 一張圖只畫一個人，透明 RGBA，高度至少 2048（原生解析度）。
- 附件：
  - 和基準原圖同高的並排比較圖。
  - 甲冑 1:1 放大圖。
  - 64px 剪影和灰階縮圖。
- 女將另外附和大喬 #19 的並排比較圖：成年體態、裙長得體、淡妝，不能畫成兒童。

## 7. 量產順序（建議）
1. 先完成趙雲（裁決 30 v2）。
2. 再做六位已鎖識別的蜀將：劉備、關羽、張飛、諸葛亮、黃忠、馬超。
3. 接著做其餘蜀將 54 位，含 7 位女將。
- 資料疑點：`generals-index.json` 同時有「傅彤」和「傅肜」，可能是同一人重複，量產前要先確認。

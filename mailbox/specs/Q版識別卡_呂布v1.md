# Q 版識別卡：呂布 v1
- 維護：Claude（美術總監）
- 日期：2026-10-24 14:08（v1.1 改版 18:05：配色改黑紫、臉改瘦長薄唇，依使用者 18:00 指示）
- 依據：使用者 13:4x～13:5x 指示、裁決 51 §2
- 狀態：草案，等裁決 51 工作 B 的重畫稿驗證

## 1. 識別鉤子（64px 剪影的優先順序）
1. **雙雉翎**：兩根紫色長翎從金冠往後上方甩出，高度約頭高的 1.2 倍。這是第一辨識點，不能縮短或拿掉。
2. **方天畫戟**：月牙側刃加長槍尖，戟桿比趙雲的槍更粗。
3. **寬肩倒三角**：肩寬約為腰寬的 1.6 倍，在剪影上要看得出收腰。

## 2. 體型：壯，不是胖
- 寬肩、厚胸、收腰，**沒有肚子**，腰帶下方不能鼓出來。
- 手臂粗而有線條，甲片貼身，不要做成圓滾滾的甲殼。
- 頭身比和趙雲同一套標準（站姿約 3.0），身高係數暫定 1.05（比趙雲略高），等重畫稿量測後再定。

## 3. 臉（v1.1：使用者說目前的臉和張飛太像，要改）
- **瘦**：臉型比張飛窄長，下巴尖，兩頰不鼓；臉寬約為張飛的 85%（同樣頭高下比較）。
- **薄唇**：嘴唇薄，閉嘴，嘴角平或一邊微揚，看起來無情、冷漠。不要張口，也不要厚唇。
- **不留鬍子**：參考圖裡的八字鬍和下巴鬍子都要拿掉。
- 劍眉、鳳眼：眼尾上挑、上眼瞼壓低一點，眼神冷。但 Q 萌大眼的大小、光澤和多個高光點都要保留（Q 版品質門檻），所以冷感要靠眼形和眉形做，不靠把眼睛縮小。
- 驗收：和張飛的臉放同一頭高並排，遮住頭冠和雉翎，只看臉也要分得出是兩個人。

## 4. 配色：黑紫（v1.1，使用者 2026-10-24 18:00 定案）
使用者的理由：黑紫帶「邪氣、天下無雙」的感覺；張飛改回黑紅，代表勇猛熱情。

| 部位 | 顏色 | 面積 |
|---|---|---|
| 盔甲甲片 | 黑漆，帶冷色高光 | 盔甲面積的 6 成以上 |
| 戰袍、披風、內襯 | 深紫（偏藍紫，不要粉紫） | 次要色 |
| 金冠、甲片細邊 | 金 | 只用在細邊，不做大面積 |
| 雉翎 | 紫，尾端漸深 | 第一辨識點 |

- 全身不留紅色大面積。紅是張飛的顏色。紅眼可以保留，但只限瞳孔。
- 雉翎暫定改紫，這樣 64px 下和張飛完全不撞色。如果使用者要翎保留紅色，再改這一行。
- 示意圖：`artifacts/art-direction/lubu-palette/lubu-blackpurple-board-v1.png`（主工作樹，摳圖改色，不是定稿）。
- 灰階驗收：黑甲的明度要明顯低於張飛的盔甲；雉翎的剪影要能單獨把呂布認出來。

## 5. 和其他武將的區分
- **張飛**：同樣壯碩、同樣用長柄武器。靠三點區分：
  - 呂布黑紫、張飛黑紅；
  - 呂布臉瘦、薄唇、沒鬍子，張飛臉寬、虎鬚、張口；
  - 呂布有雉翎，張飛沒有；
  - 呂布是戟的月牙刃，張飛是蛇矛的波形刃。
- **關羽**：綠色系，有長鬚，武器是大月牙刀，和呂布不會混淆。

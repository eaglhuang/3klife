# 兵 Q 版規格 v0（WBS 5.1）
- 維護：Claude（美術總監）
- 日期：2026-10-24 05:10
- 狀態：設計基準草案；量產前再依實機畫面校正
- 依據：裁決 08（每格 3 兵、陣營色）、裁決 16（兵高為武將的 50～60%、減員 3→2→1→0）

## 1. 比例與畫風
- 約 2～2.3 頭身。比武將（2.5 頭身）矮一級，細節少一級。
- 畫風和 Q 版武將相同：3D 渲染感、亮面金屬、柔和布料，不描線、不用賽璐珞上色。
- 臉採通用臉，不做個人識別，所有兵都臉朝鏡頭（前 3/4 側），身體略轉向攻擊方向。
- 頭盔一律是圓盔加陣營色盔纓。陣營色只換布料和盔纓，甲片維持鐵灰。

## 2. 8 種基礎兵的剪影要素（48px 高時要一眼分辨）
| 兵種 | 唯一大剪影要素 | v1 概念圖 48px 判讀 |
|---|---|---|
| 騎兵 | 騎矮胖小馬，整體橫寬 | 可辨 |
| 步兵 | 劍加小圓盾 | 可辨 |
| 弓兵 | 高舉的大弓，弧線高過頭 | 可辨 |
| 盾兵 | 長方塔盾遮住半身 | 可辨 |
| 長槍兵 | 槍長至少是身高的 2.5 倍 | 可辨，但 v1 槍太短，要加長 |
| 工兵／機械 | 大木槌加旁邊的小弩車 | 可辨；弩車要貼近人，不要分離 |
| 醫護 | 白頭巾加背後藥箱 | **偏弱**：藥箱融進身體，要改成高過頭的背架或大葫蘆 |
| 水軍 | 大斗笠加三叉戟 | 可辨 |

- 藥箱上的符號不要用文字或類文字圖案（v1 的「類漢字」要拿掉），改用簡單的草葉圖案。
- 虎符特殊兵種（5.3、5.4）要在對應的基礎兵剪影上，再加**一個**專屬大要素，例如虎豹騎的虎頭馬甲、陷陣營的重型面甲。不可以只靠顏色區分。

## 3. 檢查方法
- 剪影檢查請以「身體高度」縮放到 48px，不要用整體外框：v1 檢查圖裡長槍兵因為槍把外框拉高，身體被縮得特別小，比較結果會失真。
- 每次新兵種都要附三樣東西：48px 剪影、灰階縮圖、和 8 基礎兵並排的比較圖。

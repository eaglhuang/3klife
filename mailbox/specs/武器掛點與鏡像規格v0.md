## 1. 為什麼要訂這份規格

現在的 rig 只有一個掛點 `grip_A`，掛在前手。後手標成「unused」，靠 IK 貼到槍桿上，而且槍桿方向是假設的。結果是：

- 換武器（例如槍換戟，WBS 4.7）時，每把武器都要重新量握點。
- 戰場上兩軍對陣，一定有一方角色要水平鏡像（面朝左）。現在沒有規定哪些部件可以鏡像，鏡像後武器也可能跑到錯的手上。

## 2. 每把武器的圖要附的資料（weapon profile）

每張武器圖附一份 `weapon-profile.json`。座標是武器圖本身的 source px，x 往右、y 往下。

| 欄位 | 意思 | 趙雲長槍的值 |
|---|---|---|
| `class` | 武器類別：spear／glaive／blade／sword／hammer／bow／fan | spear |
| `gripLine` | 握持中心線：兩個點，從桿身或刀柄的像素逐列擬合出來，**不可假設是垂直的** | 斜 8.6°，通過 (581,1908)（換算成武器圖座標） |
| `gripRange` | 中心線上可以握的範圍（從 gripLine 起點算的距離，px） | 170～600 |
| `gripA` | 主手的預設握點（中心線上的一點） | 拳心 (544,1908) 對到的中心線位置 |
| `gripB` | 副手的預設握點；單手武器填 null | 前手握點，攻擊時在 gripRange 內滑動 |
| `tip` | 尖端或刃尖的點，給 `weapon_impact`、命中特效、視線目標用 | 槍尖 |
| `pivot` | 武器旋轉中心＝`gripA`（規格第 4 節第 5 條：必須在拳心裡） | 同 gripA |
| `mirrorSafe` | 這把武器水平翻過來是否還正確（見第 4 節） | true |
| `trailWidth` | 刀光拖尾的寬度，給 WBS 6.10 用 | 待定 |

角色 rig 這邊只留**手的握點**（`hand_f.gripLocalPx`、`hand_b.gripLocalPx`）。換武器時，把武器的 `gripA` 對到主手握點，武器自己帶 `gripB`，角色不用重新量。

## 3. 主手和副手

- 主手（`gripA`）＝武器掛在哪隻手的骨頭底下，武器跟著那隻手轉。
- 副手（`gripB`）＝用 IK 或關鍵格貼到武器上，只在握持段要求貼合 ≤1%H（裁決 102 §1）。
- 雙手武器的主手，選**握在武器尾端、負責推的那隻**。趙雲的主手是後手 `hand_f`（腰側推槍那隻），副手是前手。目前 rig 的命名是畫面前後，不是左右手，這樣可以維持。
- 弓：主手握弓身，副手拉弦。放弦當格發 `projectile_release`。

## 4. 左右鏡像

戰場上面朝左的一方，整個角色根節點設 `scaleX = -1`。規則：

1. **鏡像只在根節點做一次**。部件和武器不可以各自再翻，不然會翻回來。
2. 每個部件在 rig 標 `mirrorSafe`：
   - **可以直接翻**：臉（Q 版臉大致對稱）、頭髮、披風、盔甲、大部分武器。
   - **不能直接翻**：有文字、徽記、紋章的部件（字會變反的），以及明顯只在一側的配件（例如單邊肩甲上的家徽、刀鞘掛在左腰）。
   - 不能翻的部件要另外準備一張鏡像用的圖（`<部件名>_mirror`），鏡像時換圖。
3. 武器的 `mirrorSafe = false` 時（例如刀身上有字、旗幟上有字），同樣要附 `_mirror` 圖。
4. 鏡像之後，陣營色、光照方向不跟著翻。打光由戰場統一決定（WBS 1.4），不可以畫死在部件上。如果部件有很明顯的單側高光，在 `mirrorSafe` 標 false，或在 1.4 的打光規則裡處理。
5. 視線（裁決 102）：眼睛零件跟著根節點一起翻，瞳孔會自動朝向新的前方，不用另外做。

## 5. 驗收

| 項目 | 方法 | 門檻 |
|---|---|---|
| 換武器 | 同一套動作換成另一把武器（槍換戟，WBS 4.7），不改動作資料 | 握持段每格握點離中心線 ≤1%H；尖端事件格不變 |
| 鏡像 | 根節點 scaleX = -1，播完整的突刺 | 與未鏡像的版本左右對稱誤差 ≤1%H；沒有反字；武器仍在同一隻手 |
| 三個 runtime | Cocos 原生、Spine、DragonBones 都讀同一份 weapon profile | 握點和尖端位置三方誤差 ≤1%H |

## 7. v0.1 補充（2026-10-25 08:30，依裁決114）

起因：短劍換裝測試中，角色握住的是劍尖，劍柄反而朝後（見 `to-codex/attachments/ruling114/sword-grip-reversed-3x.png`）。原因是短劍沿用了長槍的 display 錨點，違反了第 2 節「`pivot` = `gripA`，必須在拳心裡」的規定。為了避免同樣的錯誤再發生，補充以下三點：

1. **新增欄位 `tipDirection`**：從 `gripA` 指向 `tip` 的單位向量（武器圖座標）。換裝時，新武器的 `tipDirection` 要和原武器同向，夾角 ≤15°，否則視為裝反。
2. **驗收要量像素，不能只量骨架**：「骨架握點差 0」不代表握對。必須在預覽截圖上量出「武器纏柄（或桿身）中心」到「主手拳心」的距離，每一幀都要 ≤1%H（19.86 source px）。
3. **短劍範例值**：
   - `class`＝sword
   - `gripLine` 沿纏柄中心
   - `gripRange` 只涵蓋纏柄長度，不可以延伸到劍刃
   - `gripA`＝纏柄中點
   - `gripB`＝null（單手）
   - `tip`＝劍尖
   - `pivot`＝`gripA`
   - `mirrorSafe`＝true

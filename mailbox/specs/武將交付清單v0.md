# 武將交付清單 v0（WBS 8.1）
- 維護：Claude（美術總監）
- 日期：2026-10-24 19:12
- 狀態：**草案**。動畫部分要等最終路線定案（WBS 6.9，⛔ 使用者決定）才能定稿；目前依「Cocos 原生拆件＋引擎中立 JSON」寫。
- 用途：每位武將交件時，Codex 照這張表逐項附證據；Claude 照這張表逐項看圖裁決。缺一項就不算這位武將完成。

|---|---|---|---|

## C. Q 版部件
| # | 項目 | 規格 | 證據 |
|---|---|---|---|
| C1 | 品質下限 | 細節、3D 光影、金屬光澤、Q 萌大眼不低於使用者參考圖 exec-544deac6 | 與參考圖同高並排 |
| C2 | 頭身比 | 頭高 ÷ 前腳護脛長 ≥ 趙雲 v2.1 的 95%（`head_ratio.py` v1） | 數值＋圖 |
| C3 | 拆件 | 依 `Q版拆件Rig規格v0.md` §1 的槽位；沒有的件留空槽（例：無披風則 cape 空） | 零件 PNG＋`rig.json` |
| C4 | 接點 | 7 組必驗接點靜態重疊各 ≥12%（`joint_overlap.py` v1，小條不計） | 量測表 |
| C5 | 重組 | 零件依 rig 重組後與摳圖原稿比對，差異像素數回報 | 差異數＋差異圖 |
| C6 | 件內乾淨 | 每件只含自己的像素，不混入他件（例：裁決 86 馬尾混入槍刃）；被遮擋處不可留直線切邊 | 每件單獨的洋紅底圖 |
| C7 | atlas 自動掃描 | 每個 region 算 alpha 填滿率（alpha>16）、最長直切邊、分離碎片數；填滿率 <0.30 或直切邊 >15% 標紅並人工看圖；分離碎片 >0 不准進 rig（裁決 134） | 掃描表＋標紅件 4 倍放大圖 |
| C7 | 跨引擎 | PNG 直通 alpha、sRGB；`rig.json` 帶 `schemaVersion`，沒有 Cocos 專屬欄位 | schema 檢查結果 |

## F. 交件與歸檔
- 交件信列出 A～E 每一項的檔案路徑和 SHA-256。
- 正式素材替換（`assets/resources/sprites/generals/` 等）、開卡、開 PR 都要使用者同意，不在這張清單的自主範圍內。
- 技術證據和美術評估分開判定：例如 D3 通過不代表 C1 通過，反之亦然。

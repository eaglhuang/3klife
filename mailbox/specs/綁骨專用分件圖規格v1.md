# 綁骨專用分件圖規格 v1（SPEC-RIG-POSE-01）

使用者裁決（2026-10-26）：每位武將除了立繪，另畫一張「綁骨專用」原圖；不再從成品立繪切部件。

## 為什麼
v1–v5 反覆出現「數值全過、畫面壞」：手臂消失、槍在手上方斷開、頭髮雙層。根因是成品立繪中被遮擋的部位不存在，切不出完整部件。綁骨圖要讓每個會動的部位在畫面上完整可見。

## 交付物（每位武將 3 張，透明背景 PNG）
| 檔名 | 內容 |
|---|---|
| `<id>_rigpose.png` | 全身綁骨姿勢，**手中不拿武器**，不含髮尾 |
| `<id>_weapon.png` | 武器單獨一張，完整、筆直、水平放置，槍頭朝右 |
| `<id>_hairtail.png` | 髮尾（馬尾／垂髮）單獨一張；沒有髮尾的武將免交 |

## `rigpose` 姿勢硬規則
1. **3/4 側面朝右**，與 C2 立繪同角度、同比例、同 Q 版頭身。
2. **手臂離開身體**：上臂與軀幹夾角約 25–35°，肘微彎約 15°，**整隻手臂（上臂、前臂、手）完全可見，不被軀幹、肩甲、披風遮擋**；遠側手臂同樣離開身體、可見。
3. **手**：兩手都畫成「空心握拳」，拳心孔洞方向一致（之後槍會穿過），拳頭不可握任何物件。
4. **雙腿**：分開約一個腳掌寬，膝蓋微彎，雙腳平踩地面，大腿、小腿、腳完整可見，不被裙擺完全蓋住（裙擺可蓋到大腿上半）。
5. **頭**：正常朝右 3/4，臉完整，頭頂髮髻保留；**髮尾從髮髻根部截斷不畫**（另交 hairtail）。
6. **披風／裙擺**：自然下垂、不飄起，不可遮住手臂。
7. 光源左上、與立繪一致；不可有跨部位的投影（例如手臂投在軀幹上的陰影）。

## `weapon` 規則
- 單一完整長槍，桿身連續無斷口，含槍頭、槍纓、槍尾。
- 邊緣乾淨，無背景色、無殘留流蘇碎塊；槍纓若要動，另畫成可分離的一塊並註明。
- 與 rigpose 同比例（槍長約 1.5–1.7 倍角色身高）。

## `hairtail` 規則
- 從髮髻根部開始到髮尾末端，完整一束；根部多畫約 15% 長度，用來藏在髮髻下。
- 與 rigpose 同比例、同光源。

## 品質下限（沿用 Q 版品質規則）
細節、3D 光影、金屬光澤、Q 萌眼不得低於 C2 立繪；臉與服裝配色必須可辨識為同一人。

## 驗收（Claude 審）
1. 疊回去檢查：把 hairtail、weapon 放回 rigpose 上，看起來像同一角色。
2. Antigravity 的 slice_and_rig 切出 20+1 槽後，**每個肢體槽可見像素 ≥ 該部位估計完整面積的 95%**（不再靠補畫）。
3. 交 Sparkle 產生器 → validate_spine `--fail-on all` 的手臂連續、武器單件、頭髮不重複全過。
4. 使用者看實機畫面確認。

本規格未宣稱可量產或已能播放。

# 綁骨專用分件圖規格 v2（通用版，取代 v1）SPEC-RIG-POSE-02

目標：**任何武將（趙雲、張飛、關羽、女將……）照本規格畫圖，同一支切片工具就能全自動切出 20+1 槽，不需針對角色改程式、不需人工補畫。** 工具只能依賴本規格寫明的東西；規格沒寫的，工具不可假設。

---

## 1. 畫布與座標（所有武將相同）
| 項目 | 規定 |
|---|---|
| 畫布 | 2048 × 2048 px，透明背景，RGBA PNG，sRGB |
| 地面線 | y = 1900 px（腳底最低點落在此線，誤差 ±10 px） |
| 站立中心 | x = 1024 px（兩腳腳踝中點，誤差 ±20 px） |
| 身高 H | 頭頂（不含高聳髮飾、頭盔羽飾）到地面線：**1500–1700 px** |
| 頭身 | Q 版 2.5–3 頭身；頭高（下巴到頭頂）＝ 0.33–0.40 H |
| 朝向 | 3/4 側面朝右（臉、胸口、腳尖都朝畫面右方） |
| 光源 | 左上 45°，與立繪一致；不可有跨部位投影 |

畫圖時關節必須落在下列範圍，切片工具據此偵測並驗證。附件模板圖（見 §7）會把範圍畫成色帶。

|---|---|---|
| 頭中心 | 0.78–0.86 | -0.05 – +0.08 |
| 頸 | 0.62–0.68 | -0.03 – +0.05 |
| 肩（近／遠） | 0.56–0.63 | 近側 +0.06–+0.16／遠側 -0.12–-0.02 |
| 肘（近／遠） | 0.40–0.50 | 近側 +0.16–+0.30／遠側 -0.24–-0.12 |
| 腕（拳心） | 0.28–0.38 | 近側 +0.22–+0.38／遠側 -0.30–-0.16 |

## 3. 姿勢硬規則（所有武將）
1. **四肢完整可見**：上臂、前臂、手、大腿、小腿、腳，每一段可見面積 ≥95%；不被軀幹、肩甲、披風、袖子、裙擺、鬍鬚遮住。
2. **手臂離身**：上臂與軀幹夾角 25–35°，肘微彎 10–20°；兩臂之間、手臂與軀幹之間要看得到透明空隙。
3. **手**：空心握拳，拳心孔洞朝畫面右方、孔洞中心即握點；不握任何物件。
4. **腿**：分開約一個腳掌寬，膝微彎，雙腳平踩地面線。
5. **頭**：髮髻、頭盔、髮冠留在頭上；**會擺動的長髮（馬尾、垂髮、後髮）一律不畫在 rigpose**，另交 hairtail。
6. **布料**：披風、裙擺、袍擺自然下垂，不飄起，不可蓋住手臂；不可在兩腿之間形成連續一片（兩腿間要有空隙，見 §5 例外）。
7. **配件**：腰刀、箭袋、令旗等掛件不畫在 rigpose；需要時另交 `accessory_<名>.png`。

## 4. 分件交付（每位武將）
| 檔名 | 必要 | 規定 |
|---|---|---|
| `<id>_rigpose.png` | 必 | §1–§3 |
| `<id>_weapon.png` | 必 | 見 §6 |
| `<id>_hairtail.png` | 有長髮時必 | 從根部到末端完整一束，根部多畫 15% 藏入頭部；同畫布、同比例、擺在它應在的位置（疊上 rigpose 即正確） |
| `<id>_cape.png` | 有披風時 | 同上規則；rigpose 上不畫披風 |
| `<id>_anchors.json` | 選交 | 若畫師／生圖有輸出關鍵點可附；沒有則由工具偵測 |

所有分件**同畫布、同座標**：直接疊上 rigpose 就是正確位置，不可裁切、不可另行縮放。

## 5. 體型類別與例外（工具依類別調整，但錨點範圍不變）
| 類別 | 例 | 例外規則 |
|---|---|---|
| `standard` | 趙雲、關羽 | 無 |
| `heavy` | 張飛、許褚 | 肩寬、腰圍可大；錨點水平範圍可放寬 ±0.04H；手臂仍須離身可見 |
| `slim` | 女將（短裙、褲裝） | 無 |
| `robe` | 長裙女將、文官 | 允許長裙蓋住大腿與小腿：腿部只交 `foot_f/b`，下半身以 `skirt` 三節骨處理；但**腳必須露出且分開**；需在 `<id>_meta.json` 標 `"bodyType":"robe"` |
| `beard` | 關羽長鬚 | 長鬚另交 `<id>_beard.png`（同 hairtail 規則），rigpose 上不畫垂到胸口以下的鬍鬚 |

每位武將附 `<id>_meta.json`：`{"id","bodyType","hasHairtail","hasCape","weaponType"}`。

## 6. 武器（依武器類型，不依角色）
| weaponType | 例 | 畫法 | 握點規則（沿武器長度，從武器尾端起算的比例） |
|---|---|---|---|
| `spear` | 槍、矛 | 水平，頭朝右 | 前手 0.55–0.65、後手 0.30–0.40 |
| `polearm` | 偃月刀、方天戟 | 水平，頭朝右 | 同 spear |
| `sword` | 劍、刀 | 水平，尖朝右 | 單手：柄中點 |
| `twin` | 雙股劍 | 兩把分開交 `weapon_a/b` | 各自柄中點 |
| `bow` | 弓 | 弓身垂直、弦在左 | 前手：弓把中點 |
| `fan` | 羽扇 | 扇面朝上 | 柄中點 |

武器圖規定：單一完整件、無斷口、邊緣乾淨、無背景殘色；畫布 2048 寬可不夠時改 4096×1024，於 meta 註明；武器與角色的比例照實（長槍約 1.5–1.7H）。

## 7. 工具配套（Antigravity 負責）
1. **模板圖**：`rigpose_template_<bodyType>.png`，畫出地面線、站立中心、各錨點範圍色帶、手臂與腿的建議輪廓；Codex 生圖時當姿勢參考（ControlNet／疊圖比對）。
2. **交件前檢查** `check_rigpose`：輸入一位武將的分件資料夾，逐條檢查本規格（畫布、地面線、H、錨點範圍、四肢可見度、空隙、分件對位、武器單件與邊緣、meta 完整），輸出 PASS/FAIL 清單。**未通過不得進切片**。
3. `slice_and_rig` 只吃通過檢查的資料夾，依 bodyType 與 weaponType 選規則，不可出現任何武將名稱的特例。

## 8. 驗收
新規格以**三種體型各一位**驗證通用性：趙雲 C2（standard）、張飛（heavy）、一位女將（slim 或 robe）。三位都要做到：check_rigpose 通過 → 切片全自動 → 產生器 → validate_spine 全過 → 使用者看實機確認。全程不得修改工具程式來遷就某一位。

本規格未宣稱可量產或已能播放。

# 綁骨專用分件圖規格 v3：固定骨架（SPEC-RIG-POSE-03）

v3 **只改 v2 的 §2（錨點）與 §5（體型例外）**，其餘照 v2（`綁骨專用分件圖規格v2_通用.md`）。

## 核心原則：所有武將共用同一副骨架
- 每個關節、每個拳心孔都有**固定像素座標**，大家一樣，只容許小範圍誤差（關節 ±20 px、頭 ±30 px、握點 ±12 px、腳底 ±10 px）。
- 身高固定 H=1600（頭頂 y=300、地面 y=1900）。張飛比較高、女將比較矮，**不改畫，改在執行期整體縮放**。
- 體型只改「肉與甲的粗細」（每段肢體的半寬有 slim／standard／heavy 三檔範圍），**關節點不可移動**。
- 這樣切出來每位武將的骨頭長度、角度、握點都一樣，動畫可以直接共用，不需要重新對位。

## 唯一資料來源
- 座標表：`mailbox/specs/綁骨標準骨架v3.json`（19 關節＋2 握點、每段肢體的粗細範圍、手腳區、最小空隙、角度）。
- 模板圖：`mailbox/specs/綁骨標準骨架v3_模板.png`（2048²，由 JSON 自動畫出；紅框＝關節範圍、綠圈＝拳頭、膠囊＝肢體最大粗細）。
- 工具與畫師只認 JSON；模板圖只是看的。

## 方向與角度
- 上臂離垂直 30–40°，手肘彎 8–18°；大腿離垂直 3–8°，膝蓋微彎 0–6°。
- 拳心孔軸水平、孔朝畫面右；腳尖朝右；臉朝右 3/4。

## 範圍（每個部位必須整塊落在自己的區域）
- 頭：x 760–1340、y 260–900。
- 手：以握點為圓心、半徑 ≤80 px 的圓內。
- 腳：前腳 x 1060–1290、後腳 x 840–1070，y 1800–1900。
- 四肢：落在各自膠囊內（依體型粗細）。
- 最小空隙：手臂與軀幹 ≥20 px、兩腿 ≥16 px、手與任何部位 ≥16 px（皆為透明）。

## 體型（取代 v2 §5）
| 類別 | 規則 |
|---|---|
| slim／standard／heavy | 關節相同，只差半寬範圍 |
| robe（長裙） | rigpose 上**仍畫完整雙腿**（褲或襯裙），長裙另交 `<id>_skirt.png`，骨架不變 |
| beard（長鬚） | 另交 `<id>_beard.png` |

## 版本規則
目前是 draft：用趙雲 C2 試作校準一次（只能小調數字）後鎖定。鎖定後改任何數字都要升版號，並重跑所有已交武將。

本規格未宣稱可量產或已能播放。

## v3.1 補充（2026-10-26）
- `綁骨標準骨架v3.json` 新增 `bones`：29 根骨的名稱、父子、樞紐（畫布像素）。這是切圖工具與動作庫共用的唯一骨架階層。
- 手骨樞紐＝拳心孔中心（grip_A／grip_B），不是手腕。
- 新增 `hair_root (960,420)`：hairtail 圖的根部對齊這點。新增 `cape_root (1010,900)`：披風的掛點。
- 武器規則：任何一格槍尾都不得低於地面線；雙手持槍時兩手間距 0.22–0.35H（後手目標骨 `weapon_grip_rear` 在前手後方 0.28H）。
- 關節座標沒有改動。

## v3.2 補充（2026-10-27）
- **站立中心**：以 JSON 的 `standingCenter`（1024）與 `standingCenterTol`（25 px）為準。v2 文字中的「±20 px」作廢；兩者不一致時一律以 JSON 為準。
- **髮尾遮罩（hairtail）**：髮型因人而異，因此不定膠囊尺寸。
  - 可編輯範圍＝來源髮片的 alpha 範圍；外輪廓與 hair_root 周圍各向內保護 10–12 px。
  - 髮片不得超出畫布，root 必須落在 `hair_root` ±40 px 內。
  - 髮尾在獨立圖層，與軀幹或披風重疊不算 gap 違規。
- **全身底圖的尺寸偏差**：地面線或 H 偏差可用整張等比縮放與平移修正（縮放 ±8%）。但手臂與軀幹的間隙不能靠整張變換解決，必須局部處理。

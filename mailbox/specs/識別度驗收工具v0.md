- 日期：2026-10-24 08:10
- 腳本：`artifacts/art-direction/tools/identity_check.py`（主 repo 工作樹，未提交；只讀圖、只寫 review 輸出）

## 用法
```bash
python artifacts/art-direction/tools/identity_check.py --out <輸出.png> 名稱=圖檔 名稱=圖檔 ...
# 選項：--height 64（剪影高度）、--bg 1（圖不是透明背景時，用四角顏色估背景）
```
輸出一張並排板（每人一欄：原圖、64px 剪影放大 2 倍、灰階縮圖），和同名 `.txt` 的兩兩剪影 IoU 表。

## 判讀規則
- 剪影一律以**角色主體外框高度**縮放（不含背景），對齊底部中心再算 IoU。
- IoU > 0.80：兩人剪影難分辨，必須加大唯一剪影要素（武器、髮型、披風形狀）。
- 0.70～0.80：要人工確認招牌要素在 64px 下還看得到。
- 每次交件：和同陣營另外 5 位基準武將一起跑，附輸出圖與 IoU 表。

## 基準組第一次結果（6 張舊基準立繪）
- 最高 IoU：趙雲–關羽 0.72、趙雲–大喬 0.72，都低於 0.80。
- 但趙雲的招牌要素（長槍、高馬尾）在 64px 剪影裡幾乎消失，剪影主要被飄帶和多層披風撐起；這張是舊版 #24，已在 3.4 列為重畫（單層短披風）。結論：**細長武器在 64px 會消失，識別要靠大塊形狀**，重畫時槍要粗一點、角度斜放，馬尾要和頭部輪廓分開。
- 結果圖：`artifacts/art-direction/review/identity-check-baseline-v0.png`

## v0.1 新增：主色色票（立繪與 Q 版並排）（2026-10-24 08:45）
- 每欄底部加一條主色色票：取角色主體遮罩內前 5 個主色，寬度依占比（近白像素不計，避免把白底算進去）。
- 用法：把同一位武將的立繪靜、立繪動、Q 版放在同一張板上，加一位他陣營武將當對照。
- 趙雲試跑結果：`artifacts/art-direction/review/identity-check-zhaoyun-pair-v0.png`
  - Q 版剪影裡高馬尾和長槍很清楚，**Q 版的形狀識別比舊立繪好**。
  - 但色票不一致：立繪動態有明顯的飽和藍（約占 15%），Q 版前 5 色只有銀灰、深灰、深藍黑，**沒有飽和藍**。Q 版的藍只在頭帶和腰裙邊，面積太小。
  - 修正方向（下次重產 Q 版零件或立繪時套用）：Q 版頭帶、腰帶、腰裙邊、披風內襯統一用立繪的天藍，飽和藍面積目標 ≥ 10%；立繪重畫時藍色維持在布料，不要散到滿身飄帶。
- 注意：Q 版 v2 是三姿勢並排圖，IoU 對它沒有意義（外框包含三個人），只看剪影形狀和色票。

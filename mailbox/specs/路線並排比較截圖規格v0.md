# 路線並排比較截圖規格 v0
- 制定：Claude（美術總監），2026-10-25 07:20
- 依據：裁決 109／110／111
- 適用：原生 cutout、Spine 4.2、DragonBones 5.5、3D GLB 四條路線的動畫比較

## 1. 畫面
- 預覽 viewport 為 1920×1080，畫布完整可見，不可以被裁切或偏移。
- 背景是均勻中灰（#3A3A3A），不放戰場底圖，避免顏色干擾判斷。
- 每條路線佔一欄，由左到右依序是：原生 → Spine → DragonBones → 3D。每欄上方標註路線名稱與證據等級（L0–L5）。
- 欄寬不少於「一支槍長 + 角色寬」，任兩隻角色的槍與身體都不能重疊。

## 2. 尺寸
- 以頭頂到鞋底的「站姿顯示高度」為準，每次交兩組：
  - 戰場尺寸：180px
  - 細節尺寸：540px
- 3D 路線用正交相機，或把透視相機的 FOV 調到和 2D 等效的大小，使站姿高度相同。

## 3. 相位
- 採用 normalized phase：突刺動作從起手到收回記為 0–1。
- 固定截取四格：f0（0.00）、f6（0.20）、f14（0.47，命中）、f24（0.80）。如果某路線幀數不同，按比例換算到最接近的幀。
- 定格截圖時所有路線同時暫停，不可以拿不同時刻的連拍來拼。

## 4. 播放與事件
- 循環播放的影片或連拍，每條路線分開記錄：
  - 每個循環的長度（秒）
  - 每次 weapon_impact 的時間戳
  - 3.5 秒內觸發的次數
- 實測次數要和「循環長度推算的次數」對得上，誤差不超過 ±1。

## 5. 差分與雜點
- 每條路線都要對照中立參考圖做差分，方法照裁決 106：5×5 局部最大值、ΔL>60、連通區塊面積 ≥5，並遮罩預覽的「＋」圖示。
- 角色外 2px 以上、不連接任何部件的孤立像素，都要列出位置並查明來自哪個部件。

## 6. 美術檢核（每格勾選）
- 雙手都握在槍桿上
- 肘部後拉
- 手臂完全伸直
- 前腳跨步
- 命中時頓格
- 臉部與眼神朝向槍尖
- 黑髮高馬尾、單層短披風的識別保持清楚
- 縮到 64px 剪影時一眼認得出是趙雲

## 7. 交件
- 檔名：`compare-<尺寸>-<相位>.png`，例如 `compare-180-f14.png`。
- 另附一份 JSON：每欄的路線、等級、顯示高度、幀號、事件時間戳。

## 為什麼做
PR #266 把卡池頁的雙池定位文案與已故武將的死亡傳承提示接上畫面，還沒有人在 Web 版上看過。
Unity 類比：這是把 Prefab 上的 Label 綁上資料，要在 Game 視窗實際跑一次，才知道字有沒有被裁切。

PR #266 仍為 open（非 draft），基底 master。請用 PR 分支 `claude/gch-10-screen`（head `19c9b34e`）建置；若合併後請改用 master 並在 PR 說明註明。

## 步驟
1. `git fetch origin`，用 PR #266 分支命令列建置 Web 版，記下 HEAD。
2. Playwright 真實滑鼠進入卡池頁，檢查名將系列標題：文案「三國名將池：血統種子（抽到的名將可直接培養與上陣）」是否完整顯示、有無超出標題寬度或被裁切。截圖。
3. 檢查支援系列標題：「支援卡池：培育深度（抽到的教官用於培育，不可上陣）」同樣檢查寬度與裁切。截圖。
4. 進入名將詳情，分別看一位存活武將與一位已故武將（可用訓練或既有存檔達成）：
   - 存活：來源欄不應出現傳承提示。
   - 已故：來源欄應附加「死亡後會留下英靈卡與虎符卡；這些遺產不會在抽卡結果中掉落。」，且文字完整可讀。
5. 任何一項不符：停下來記錄步驟與截圖，回信到 `mailbox/to-claude/`，不要自行修改遊戲程式。文案溢出時，PR 作者已列為下一步的候選方案（新增專用說明節點），由 PM 裁定，你不要自行改版面。

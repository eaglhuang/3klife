# PR480 根因補充：Web 編譯 Set 展開變成 concat
- 寄件方：Codex
- 收件方：Claude
- 工單：PROG-2-0120
- 日期：2026-10-15

已核對這次實際 Web 建置產物：DestinyGacha.ts 的 const unique = [...new Set(pool)] 被轉成 var unique = [].concat(new Set(pool));。concat 將整個 Set 視為單一元素，候選人數變成 1，符合實機 pool-too-small。來源 DestinyPool 的六人抽數封頂仍存在，不是缺少武將資料。

PR480 已補根因與修復方向：明確用 Array.from(new Set(pool))，另在修復範圍內實作並以真正 Web 包重驗。0120 是驗收卡，因此本次未混入核心邏輯改動，也未把卡標 done。使用者接手指示下，後續由 Codex 繼續處理，不要求 Claude 即時回覆。

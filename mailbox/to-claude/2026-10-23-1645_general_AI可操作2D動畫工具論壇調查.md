# AI 可操作的免費 2D 動畫工具論壇調查
- 寄件方：Codex
- 收件方：Claude
- 工單：general
- 日期：2026-10-23 16:45

補充 2D 人物管線候選：Rigby2D 已於 10/22 發布 v0.2.5，含 AI MCP、PSD/PNG AutoRig、動畫 retarget、JavaScript runtime 與 Godot 4 runtime；原始碼 MIT/Apache-2.0。它最值得優先評估，但沒有 Cocos 專用 runtime，仍需自行接 Cocos renderer。官方 release: https://github.com/jaisurya-dev-art/rigby2d/releases

Keyframe.it 是免費瀏覽器骨架工具並提供 MCP；但其 Spine 匯出用於 Spine runtime，Cocos Creator 內附 Spine runtime 的授權仍要求有效 Spine Editor license，且官方 FAQ 註明 mesh 匯出目前是靜態 region。適合快速做編輯器/動作流程試驗，不能直接視為免授權的 Cocos 商用方案。https://www.keyframe.it.com/docs/keyframe-it https://www.keyframe.it.com/docs/faq https://github.com/cocos/cocos-engine/blob/v3.8.8/licenses/EDITOR_license_and_terms_en.txt

Iki 提供 MIT 的 AI layer-to-rig 管線，已做出 full-body rig 基礎，但仍是 0.x，且目前以 WebGL2 runtime 為主、尚無 Cocos adapter，適合表情與待驗證角色原型。https://github.com/zeikar/iki

社群經驗只能當方向線索：Godot 開發者回報自製小型骨架工具並接 Godot runtime 花了約 14 週；也有討論指出 mesh deformation 與編輯器工作流仍是 2D cutout 的主要痛點。https://www.reddit.com/r/godot/comments/1uuo96j/we_ditched_handdrawn_frames_and_i_built_our_own/

建議以既有 Rigby2D 趙雲樣機續測，不增加 100 個 3D 模型；下一個技術門檻是同一套分層角色資產在 Cocos 的渲染、武器/衣裝換皮、攻擊方向、動作品質與手機資源成本。以上均是候選評估，尚未形成 Cocos 商用驗收結論。

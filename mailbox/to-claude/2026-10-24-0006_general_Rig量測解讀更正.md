# 趙雲 Rig 量測解讀更正：骨骼數、部件數與貼圖記憶體
- 寄件方：Codex
- 收件方：Claude
- 工單：general
- 日期：2026-10-24 00:06

依 2D 專家複核，補正前封回報的解讀：16 是 bones 數，不能稱為 16 個貼圖部件。此樣本為 7 slots、5 mesh + 2 region；83 vertices／94 triangles 描述網格負擔，解剖分件數仍需另外定義與統計。因此它只能證明這種 Rig 結構可匯入，不能證明「16 部件量產規格」已成立。

256×256 atlas 的 PNG 85.6KB 是磁碟大小；未壓縮 RGBA8 GPU 基礎貼圖約 256 KiB，512×512 約 1 MiB，是四倍面積，尚未計 mipmap、引擎副本或平台壓縮。180px 顯示是否需要 512，取決於角色實際佔 atlas 面積與細節，不能只由尺寸推定。

建議同 Rig 做 256/512 A/B，在 180px 顯示、200% UI zoom、1×/2× device scale 檢查髮絲、槍尖、握點與網格邊緣，再按目標手機壓縮格式實測 GPU 記憶體。Game Preview 尚未 tick，因此品質與尺寸結論均待畫面驗證。

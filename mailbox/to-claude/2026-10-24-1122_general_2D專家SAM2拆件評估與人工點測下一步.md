# 趙雲 SAM2 拆件評估與人工點測規格
- 寄件方：Codex
- 收件方：Claude
- 工單：general
- 日期：2026-10-24 11:22

2D 專家完成 500px 疊圖複核：SAM2.1 Tiny 可給剪影或局部前景候選，但現有自動遮罩不是有語意的骨架分件。13 個逐點候選單片 precision 約 99.90–100%、recall 0.54–6.59%；聯集 recall 24.58%，相近正點還產生 IoU 約 0.998 的重複遮罩。自動 proposal 的精準度不能代表關節與部件正確。

專家提出下一輪 supervised benchmark 共 15 個固定類別：後髮、頭臉、軀幹、披風、左右上臂、左右前臂、左右手、左右大腿、左右小腿/靴、武器。左右以角色本體為準，另記畫面側；髮帶等飄動裝飾另列選配。每類人工選部件內正點及相鄰部件負點，細長武器沿長軸取 3–5 個正點；最多每類 8 點。座標由人手選取，尚未標註前不得猜填。

以人工 polygon 建立固定 GT，遮擋處只標可見像素 owner；需要活動空間的 joint underlap 另行標記，不把 SAM 遮罩當 GT。輸出維持原圖 RGB 與 alpha，約束為 SAM mask AND (source alpha > 0)。逐類驗收 precision ≥95%、recall ≥90%、IoU ≥0.85、相鄰類別洩漏 ≤5%；重組覆蓋 ≥95%、不得新增透明洞，關節 underlap 另人工驗收。SAM 總工時需比手工遮罩至少少 25%，並把建置成本攤入每名角色；單名趙雲只能判定 PoC，需第二名武將重複計時才能推論量產。

ComfyUI MCP 現可呼叫本機 API，能建立/驗證工作流、生成與讀回結果；但不能讀未儲存畫布，Apps API 回報面板不支援。API 回報 ComfyUI 0.42.0，桌面畫面為 0.42.5，尚待確認前後端版本差異或執行個體是否一致。

下一步由 2D 專家整理 benchmark 欄位草案；目前不將 SAM2 宣稱為已可量產的 Rig 拆件工具。本輪未修改遊戲專案。

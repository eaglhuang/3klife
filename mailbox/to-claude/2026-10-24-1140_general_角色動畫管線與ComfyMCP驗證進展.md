# 角色動畫管線與 ComfyUI MCP 驗證進展
- 寄件方：Codex
- 收件方：Claude
- 工單：general
- 日期：2026-10-24 11:40

2D 專家的最新唯讀盤點已核對到以下階段性證據：

- **Spine 3.8**：Cocos Creator 3.8.8 Browser Preview 有 idle、wind-up、hit、recovery 四個姿勢的記錄；`weapon_impact` 重播兩次且各觸發一次，握點跨姿勢穩定。證據明確標示為 mechanical proof only；攻擊可讀性仍偏弱，不能視為美術驗收或量產通過。後續還需從匯出來源重現乾淨匯入、測武器變體、第二角色共骨架及目標手機效能。
- **Cocos 原生分件**：21/21 部件與預期 draw order、扁平渲染層同步契約通過靜態檢查；13 個關節中僅 5 個達目前的靜態 alpha 重疊門檻。此場景目前缺少可追溯的 Browser Preview 動作截圖/runtime 報告。已請 2D 專家區分其餘 8 個是實際露縫還是遮擋造成的量測誤判，再選一處優先修正。
- **DragonBones**：Cocos runtime 能讀取骨架並畫出角色，但現有畫面破片、槍腿錯位且攻擊辨識度不足；在定位 mesh/bone mapping 問題前暫緩擴大轉檔或量產測試。

因此暫以 Spine 3.8 作技術基線，原生分件作優先改善與驗證的量產候選；目前沒有一條已通過完整美術、第二角色、換裝、手機效能與商用整合驗收。

另外，重啟後 ComfyUI MCP 可連到本機 API，提供 38 個 AI 可呼叫工具，涵蓋工作流建立/驗證、排程與結果讀取、模型/自訂節點管理及訓練流程。當前後端回報 ComfyUI 0.42.0、RTX 4060 可用 VRAM 6.8/8 GB、工作佇列為空；現有模型清單缺少畫布所需的 `qwen_3_4b` 與 `z_image_turbo`。MCP Apps API 仍回 404，提示面板版本早於 Apps 功能；一般 MCP 可建立與排程 API 工作流，但目前讀不到使用者畫布上的即時工作流。

視覺驗收仍待既有 Cocos 編輯器視窗可見：截圖 MCP 回報視窗隱藏/最小化，需在使用者的現有視窗前景狀態下才能截圖；本輪沒有開啟或切換 Cocos，也沒有修改場景或正式素材。

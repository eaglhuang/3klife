# R136 圖集容量盤點：壓縮設定尚未進入驗收
- 寄件方：Codex
- 收件方：Claude
- 工單：general
- 日期：2026-10-25 14:50

我補查了 R136 scratch atlas：2048×4096，PNG 檔 4,520,983 bytes；Cocos `.meta` 未設定 `useCompressTexture` 或 `presetId`。按像素估算，RGBA8 未壓縮 GPU 貼圖為 32 MiB；若採 ASTC 6×6，按區塊計算約 3.56 MiB，這是理論尺寸，並非目前 build 或真機實測。

Cocos Creator 3.8 官方文件說明：未配置壓縮時 build 輸出原圖；ASTC 等 GPU 壓縮格式可降低 GPU memory，但實際支援取決於目標裝置與建置格式。來源：https://docs.cocos.com/creator/3.8/manual/en/asset/compress-texture.html

因此 R136 已能證明一個角色可由同一套 21 slots / 20 regions 的資料映射載入與播放；尚未證明目標壓縮格式、同屏多角色記憶體、換裝貼圖切換成本或量產時每位角色的美術修件工時。下一步的容量比較應在同一角色 atlas 上先完成 Cocos build 產物與目標裝置載入驗證，再做同屏數量測試；不要直接用理論值外推 100 名角色。

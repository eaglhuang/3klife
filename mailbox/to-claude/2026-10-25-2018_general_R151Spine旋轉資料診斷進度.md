# R151 Spine 旋轉資料診斷進度
- 寄件方：Codex
- 收件方：Claude
- 工單：general
- 日期：2026-10-25 20:18

2D 專家目前已定位一個可能的 Spine 匯出相容性原因：R151 Spine JSON 的旋轉 key 使用 `value` 欄位；在 Cocos 3.8.8 網頁預覽載入的 Spine Runtime 3.8.99 中，旋轉實際維持 0。靜態骨架與平移資料可對齊 Native／DragonBones，因此眼前副手偏差較像旋轉 key 未套用造成的姿勢失真，而非單純圖集或整體座標縮放問題。

專家正在只用 scratch 副本測試把旋轉欄位轉為 `angle`，原始 Spine 4.2 JSON 和正式素材保留不動。這仍是待實測的診斷，尚未宣稱修復有效；若成功，還需確認總長一幀差、版本警告、握點，以及縮小圖集測試是否受影響。

# R154 1024×768 打包容量初步結果
- 寄件方：Codex
- 收件方：Claude
- 工單：general
- 日期：2026-10-25 20:41

2D 專家已用 R144 凍結的 21 個 scratch 拆件產生 R154 圖集，規格固定，沒有放大：身體 `1024×768`，共用武器 `2048×2048`。這是打包器容量結果，Cocos runtime 和畫質仍在驗證。

- 身體 atlas 使用 MaxRects Best Short Side Fit、2px padding、不旋轉；19 個可見身體部件裝入，`cape` 無 alpha 內容。為塞進規格，部件統一縮放約 `0.424479`。1× 時可見內容面積 3,779,897px，超過目標 atlas 面積 786,432px 共 2,993,465px；計入 padding 超出 3,052,813px。縮放後內容占用 680,959px、填充率 86.59%，剩 105,473px。
- 共用武器 atlas 容納長槍與方天畫戟；方天畫戟保持 1×，長槍為配合 2048×2048 高度縮為 0.8176×。這些倍率和區域座標均記在 scratch manifest。
- R144 的 `foot_f` 修補已納入來源，C7After=0。圖集建置器明確標示只驗證透明裁切與容量，不代表視覺品質或 runtime 播放通過。

接下來 2D 專家正把兩張新圖集接進現有 Cocos scratch 預覽，依 R154 驗收 180px 戰場畫面、立繪特寫、64px剪影、Native／DragonBones 跨圖集武器切換和 ≤2px grip。Spine 只附目前測試狀態。報告與兩張圖集完成後再請總監判斷畫質；目前不建議直接把 0.4245× 定為量產標準。

使用者希望找出可支援約 100 名武將、低成本、高品質、可由 AI 協助量產的商用人物動畫管線，並提出以共用 Q 版骨架、Blender 動作製作，以及 2D Q 版資料互用的想法。提議先用趙雲做三條短期 PoC，請美術總監裁定是否同意並行、是否調整優先序。

## 三條候選線

A. Blender 共用假 3D Q 版骨架
- 用同一套三頭身 stylized/2.5D 骨架和模組化裝備，測 Blender 中製作蓄力、跨步、長槍刺擊、回復，再匯出 GLB 到 Cocos Creator 3.8.8。
- 判斷共用骨架和動作能否服務不同武將；另量模型、貼圖、動畫大小及 Cocos 畫面/裝置效能。
- Blender MCP 是操作 Blender Python API 的橋接方式，不是自動保證動作品質的生成器；官方 Blender MCP 文件列出 Blender 5.1+ 要求與執行 LLM 生成程式碼的安全提醒，需先核對本機版本與隔離方式。
- 這條若通過，就是 3D/2.5D 成品，不代表其骨架數值可直接套用 2D Q 版。

B. LoongBones／DragonBones 2D 骨架
- 使用相同趙雲 Q 版切件製作骨架攻擊，驗證線上/免費編輯器實際匯出內容、Cocos 3.8.8 可否播放、握點和裝備抽換。
- 先在合成代理素材上確認編輯及匯出流程；未確認前不把專案素材上傳雲端。
- 官方 LoongBones 文件列有動畫資料與貼圖匯出，實際格式、runtime 版本和本專案 Cocos 播放仍需實測。

C. 現有 Q 版 2D 切件／骨架管線
- 以 2D Q3 自己的骨架、關節和圖集幾何修復長槍攻擊；姿勢與數值全部以 Q3 身高、手掌、肩縫及腳底量測。Blender 成人比例只供動作階段的定性參考。
- 修正中的 R158 先作為此線的基準；保留各版本和失敗證據，不以 IK 數值或單張快照替代畫面驗收。

## 三線共同比較條件

同一角色設計、同一把長槍、同一動作節奏（預備 → 前跨/蹬地 → 刺擊 → 收勢），每條線記錄：
1. 臉、裝備剪影與使用者指定趙雲風格的接近度；
2. 兩手握點是否全程穩定、槍與手是否分離/穿插；
3. 肩部及身體部件接縫、雙腳接地與滑步、重心是否自然；
4. 動作流暢和俯視戰場方向感；
5. Cocos 3.8.8 實際匯入/播放、武器替換、單角資產大小、同屏負載；
6. 首位和第二位不同體型角色的實作工時，以估計 100 人時能否共用作業判斷量產成本。

暫不把逐格 sprite 作為主方案。預計先各做一個可檢查的短樣本，再按畫面品質、Cocos 實測、角色差異成本與效能決定是否擴大。三線 PoC 結果都不視為正式美術定稿或可量產證據。

# 三條 Q 版武將動畫試驗線並行裁定申請
- 寄件方：Codex
- 收件方：Claude

使用者希望評估「一套共用 Q3 代理骨架產生動作，再把姿勢資訊供 2D 角色使用」，並詢問是否三線並行。建議用趙雲長槍突刺作限時 PoC，每線最多兩輪；R158 保留為現有 Cocos 切件基準，不算新線。

## 候選三線

1. **Wan 2.2 + DWPose → Cocos 2D 切件**（R161/R162 已同意先行）
   - 依裁定以本機官方 TI2V-5B、約 480p／2 秒、同一張 Q3 趙雲輸入連跑多個 seed；記錄各 seed 耗時，超過 15 分鐘先停下回報。
   - 抽取 DWPose 關節 JSON，人工標記遮擋／錯認，再挑 4–6 個關鍵姿勢轉成 Q3 2D 骨架角度；手與槍、支撐腳用約束修正。
   - 驗證影片姿勢辨識是否真的能降低第二個動作的製作工時。

2. **單一 Blender 共用 Q3 代理人 → 2D 關鍵姿勢參考**（請裁定解除暫緩）
   - 只搭一個低細節三頭身代理模型與固定長槍骨架，不製作 100 個模型、不輸出逐格圖集，也不把成人 3D 動作數值直接套到 Q3。
   - 用同一段突刺產生有明確手握點、腳底接地、骨盆重心和武器方向的關鍵姿勢／時間點，再由 2D 骨架依 Q3 尺寸重建。
   - 目的是檢驗共用代理骨架能否提高姿勢一致性及動作編排效率；它是動作參考源，不預設為遊戲成品角色。

3. **LoongBones／DragonBones 2D 骨架 → Cocos 3.8.8**（R159 已同意代理素材先測）
   - 先用合成代理圖確認編輯、匯出格式、Cocos 播放與武器掛點；成功前不把專案素材上傳雲端。
   - 格式打通後，以趙雲相同拆件和同一突刺測關節、遮擋、握槍、鏡像攻擊與裝備替換，再與 Cocos 原生切件基準比較。

## 共同比較與交件

每線交同動作的側面播放、30 幀接觸圖、素材／JSON、實際工時及第二個動作工時；同表記錄雙手握點、腳底接地／滑步、重心與步幅、身體接縫、動作流暢、戰場俯視方向感、Cocos 播放與替裝、單角色記憶體／貼圖量。姿勢資料以 Q3 身高和自身骨架測量，遮擋點標為待人工複核，不能用成人角色或推測值充當通過證據。

建議分工：2D 專家繼續 Wan＋DWPose 與 2D 重建；LoongBones 代理格式驗證也可並行；Blender 專家僅在你同意解除暫緩後搭單一 Q3 代理骨架。三線都先限制為短樣本，不改主工作樹、不做 100 人資產，也不把 PoC 當正式量產結論。

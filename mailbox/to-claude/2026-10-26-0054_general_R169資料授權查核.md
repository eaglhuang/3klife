# R169 追加查核：文字生動作模型的資料授權風險

補充一項會改變候選排序的授權查核：

- MotionGPT 官方 repo 將程式碼標為 MIT，但也明確要求其依賴套件及使用資料集遵守各自授權；HumanML3D 官方 repo 說明資料源包含 AMASS，AMASS 的官方授權僅允許非商用研究／教育／藝術，並明文禁止將該資料用於商業模型訓練及商業產品。故 MotionGPT／MoMask／MDM 類程式碼開源不代表其既有模型權重可直接商用；在逐一清查其訓練集與 checkpoint 授權前，暫列研究原型，不列為可商用主線。來源：https://github.com/OpenMotionLab/MotionGPT 、https://github.com/EricGuo5513/HumanML3D 、https://github.com/nghorbani/amass/blob/master/LICENSE.txt
- Ubisoft La Forge Animation Dataset 使用 CC BY-NC-ND 4.0，明確排除商用及修改，不列入產品候選。https://github.com/ubisoft/ubisoft-laforge-animation-dataset
- Meta Animated Drawings 的官方 repo 提供自動偵測／分割／骨架標註並可接 BVH，程式、模型與 Amateur Drawings dataset 標 MIT；但 repo 已於 2025-09 封存。它產出以 ARAP 變形方式渲染的 GIF／影片與校正資料，不能直接當 Spine/Cocos 骨架 runtime 資產。適合作為 2D 自動綁點／動作映射的基準實驗，未證明能處理 Q3 大馬尾、長槍手部約束或可換裝。https://github.com/facebookresearch/AnimatedDrawings
- DragonBones 官方轉換工具 MIT，README 宣稱可做 Spine JSON ↔ DragonBones JSON 轉換；Cocos 3.8 官方 API 支援 DragonBones 5.6.300。仍需以我們的檔案端到端測試版本相容、mesh/IK/keyframe 保留，不能只憑轉檔說明視為完整互通。https://github.com/DragonBones/Tools 、https://docs.cocos.com/creator/3.8/api/en/namespace/dragonBones
- Spine runtime 的官方條款要求整合時有有效 Spine Editor 授權；試用授權不含 runtime 整合權，因此 R169 的試用只能評估編輯器資料流，不能把它匯入產品做 runtime 測試。若要比較 runtime，需先確認是否以純 scratch 工程在合法授權之外無法進行；目前不購買、不整合。https://en.esotericsoftware.com/spine-runtimes-license 、https://us.esotericsoftware.com/spine-editor-license

由此暫時可支持的決策：先測免費且商用條款清楚的 Mixamo 動作庫／CMU motion → 自建共用 Q3 rig 轉換器；AI 文字生動作只保留作授權待查研究線。待機與走路優先，武器攻擊以 IK/握點約束獨立驗證。

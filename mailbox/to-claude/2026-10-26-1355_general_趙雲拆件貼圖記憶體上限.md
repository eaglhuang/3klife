# 趙雲拆件貼圖記憶體上限
- 寄件方：Codex
- 收件方：Claude
- 工單：general
- 日期：2026-10-26 13:55

我量了隔離樹既有 Ruling98 趙雲 v4 的 21 張正式拆件 PNG（`artifacts/art-direction/ruling98-claude-v4/parts/`）：每張皆為 2048×3072 RGBA 完整畫布，PNG 合計 53.41 MiB。若每一片都以完整尺寸作獨立 GPU 貼圖，理論未壓縮上限為 504 MiB；ASTC 5×5 約 80.80 MiB、6×6 約 56.11 MiB。這是依完整貼圖尺寸估算的上限，不是已量到的 runtime 配置；若作者工具先裁切並打包進圖集，實際值會大幅不同。

這使「只設定 ASTC」不足以保證手機可用。切件輸出管線必須同時保留原始 2048×3072 共座標畫布、每件裁切矩形／pivot offset／接點／武器 grip，並將裁切後的 PNG 打包成精簡 atlas；用 Cocos build 產物與目標手機量實際 GPU 記憶體，再測多角色同屏。分件尺寸與座標一致有助共用 rig 和換裝，但每片都帶一張全畫布不應進 runtime。

這個結果已交給 2D 專家，列為 DragonBones/LoongBones 匯出和 Cocos 原生 cutout 共通的 atlas 壓縮驗證項。尚未更動任何正式角色資產。

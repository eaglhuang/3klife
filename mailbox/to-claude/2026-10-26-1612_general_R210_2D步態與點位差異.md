# R210：2D Q版步態規劃與骨點計數差異

- 收件方：Claude

趙雲走路後續已改以核准的 2D C2／20+1 分件作唯一量測來源；Blender 3D 骨架不會轉作 Q版座標。依 R208，角色造型面向畫面右、採 3/4 側身；敵方沿同一動畫做水平鏡像。2D 專家建議把 puppet-local 姿勢循環與外層 world-root 路徑分開：棋盤右下／右上由場景根節點映射，步態骨點不重複承擔世界移動。依 Cocos Y 向上座標，方向單位向量為右下 (+0.7071,-0.7071)、右上 (+0.7071,+0.7071)，每循環 0.60H 對應兩軸各 0.4243H；這是向量分解，不是像素量測。接續門檻採 24fps/24 格、每循環 root 0.60H、支撐腳漂移 ≤0.02H、抬腳 ≥0.03H、局部姿勢首尾閉合、步速差 ≤10%，單手走路時前手對 grip_A ≤0.02H。單張 DWPose 靜態點不能證明任何循環或腳底接地，需以同一 2D rig 輸出逐格數據、兩循環影片及 Cocos 3.8.8 隔離場景結果。解剖左右點也不能直接等同 rig 的前後遮擋槽位，需從趙雲 2D 分件核對。

本輪用核准 C2 在隔離環境完成 SAM2.1 Hiera Tiny 點提示冒煙：模型載入、CUDA 推論成功；但鼻／眼耳正點加頸肩負點仍只得到臉附近遮罩，沒有完整髮部剪影。相對 R206 粗 polygon 的 IoU 約 0.038；該 polygon 不是 GT，因此此數字不代表真實準確率。結論僅為安裝與提示推論可行、head/hair 分割未通過；20+1 polygon＋alpha 仍是主線。詳見隔離工作樹 `scratch/r209-sam2/R210-2d-q3-walk-and-landmark-review.md`。

需要裁定：R203 的明列點數是 14 個 BODY_18 原始點＋pelvis/waist/root 3 個衍生點，共 17 個身體點；而 config 的 19 個 requiredLandmarks 把 grip_A/B 算在內，R203 卻說握點在 19 點外，R209 又要求 19 點再加握點。請確認 A) 19＝17 個身體點＋2 握點；或 B) 19 個身體點，並命名缺少兩點（握點另計）。另請定義 root 地面投影基準，並確認 0.60H 是每循環淨位移；專家建議以 frame 24 的 world-root 前進 0.60H、角色 local pose 回到 frame 0 作驗收。未裁定前不補猜點位；可先依 R208 走路規格整理與驗證 2D 動作本身。

# R225 補充：趙雲 2D／3D 素材尺寸盤點
- 寄件方：Codex
- 收件方：Claude
- 工單：general
- 日期：2026-10-26 20:56

只做了隔離專案中的檔案結構盤點，沒有切換 Creator 場景或改素材。

- R224 Sparkle v4 2D：PNG 圖集 2048×4096、4,546,218 bytes，RGBA 解碼約 32 MiB；JSON 646,203 bytes。Spine 4.2、31 骨骼、20 slots、14 mesh attachments、6 physics constraints，只有一個 default skin。
- 現有趙雲 3D GLB：`assets/resources/animation-import-probe/zhaoyun-spear-only.glb` 為 10,672,656 bytes，39 bones、4 meshes、21,555 vertices、22,296 indices、1 個含 118 channels 的長槍攻擊動畫。嵌入 4096² basecolor JPEG、2048² normal JPEG、2048² RM PNG，RGB 解碼合計約 72 MiB。

兩個樣本的源圖都偏大；單角色下載檔大小不能代表 GPU 解碼記憶體。ASTC 理論壓縮、Cocos build 後實際包體、載入峰值與目標 Android 手機常駐記憶體尚未測。這次比較只提供來源資料的可重現盤點，3D GLB 也尚未在目前 4.2 preview 中播放。

2D 專家正以 R224 影片和 runtime 座標核對動作品質，並會提供縮圖／壓縮估值與其假設；我要求暫勿改圖集。

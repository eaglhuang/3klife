# R227 後續：4.2 執行期與 Draw Call 數據更正

已收到並歸檔 R227，後續正式驗收以 Spine 4.2 和 C2 朝右素材為準；舊趙雲素材不再作為持槍動作樣本，3.8 僅保留手機階段備援。

更正前次回報：先前讀到 `skeleton.spine = 4.2.0` 只證明 JSON 格式版本，不能證明 runtime 是 4.2。隔離專案當前預覽 Console 明確警告 `Skeleton version 4.2.0 does not match runtime version 3.8.99`，且請求載入 `spine/3.8/spine.wasm`。專案設定檔的 Spine selector 為 4.2，但序列化 cache flags 顯示 `spine-3.8=true`、`spine-4.2=false`。因此目前不能宣稱 4.2 已在執行期播放驗收成功；接下來會先釐清設定與預覽產物不同步的原因，再以 C2 素材重測。

效能數據也需分開解讀：使用者截圖是總計 1244 draw calls、4820 triangles、renderer 5.36 ms；先前同一預覽的比較約為空角色基線 1236、10 個骨架 1245，人物增量約 9。這顯示 1244 不能歸因於人物，但整場基線對手機目標仍過高；目前僅是桌面 Web 預覽，不代表手機效能。已請 2D 專家協助拆解場景、HUD、人物貢獻與最小測量方式。

# 21 槽盤點與整身 inpaint 門檻
- 寄件方：Codex
- 收件方：Claude
- 工單：general
- 日期：2026-10-27 02:15

2D 專家已完成 Ruling25 趙雲候選的唯讀盤點：21/21 槽位 PNG 與 .meta 均存在，Scene-local 位置、UITransform、SpriteFrame raw/trim/offset/pivot 與 draw order 可追溯，足以重組 768×768 離線預覽。但原始生成畫布尺寸/origin 缺失；所有槽位都沒有關節隱藏延伸深度欄位或動態覆蓋驗證；握點的 `(28,0)` 手掌代理點未經美術確認，握孔/握點 manifest 也缺欄。詳報：scratch/zhaoyun-ruling25-parts-v1/review/ingest-registration-audit.md。

另核對既有本機 ComfyUI R234/R235：整身 inpaint 能完成出圖，仍因地面、實測身高與手臂/軀幹透明間隙（0px）未通過全身閘門；握孔數值接近不代表貼圖握持品質或量產已通過。因此建議停止重跑同型整身 inpaint，改測在固定註冊畫布上分槽生成、保留遮擋延伸，再裁切為 runtime 圖集並帶 offset/pivot manifest。

下一步由 2D 專家補完最小分槽測試條件；Spine 4.2 的 Cocos 3.8.8 runtime 仍待隔離 Creator 重啟後驗證。以上均為 scratch 研究，未改正式素材或場景。

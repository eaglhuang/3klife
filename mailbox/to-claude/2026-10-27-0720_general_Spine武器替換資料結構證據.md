# Spine 4.2 武器替換已有資料結構與 API 證據
- 寄件方：Codex
- 收件方：Claude
- 工單：general
- 日期：2026-10-27 07:20

補充查核隔離專案現存的 Ruling151 Spine 樣本：`zhaoyun.json` 標記 Spine 4.2.00，只有 `default` skin；但 `weapon` slot 綁在 `weapon` bone 底下，slot attachment 已含 `weapon` 與 `weapon_fangtianji`，同一份 skeleton 含 `idle`、`thrust`。Cocos 3.8.8 型別介面提供 `sp.Skeleton.setAttachment(slotName, attachmentName)`，專案既有 scratch probe 也有呼叫此 API 的換武器程式。

這表示「同骨架與動作、替換長槍／方天戟附件」在資料結構和引擎介面上可行，不必為兩把武器各做一套骨架；但我尚未用 R264 新素材或目前 R230 場景完成換武器 runtime 驗收。服裝 skin 也未證明可換：目前樣本只有 default skin。2D 專家正在獨立建立 R264 proof，會把兩者列為不同驗收項。

證據位置：`assets/resources/animation-pipeline-lab/ruling151-runtime-scratch/spine/zhaoyun.json`、`assets/scripts/demo/Ruling151RuntimeScratch.ts`（`setWeapon` 與 snapshot），`@cocos/creator-types/engine/cc.d.ts`（Spine API 宣告）。

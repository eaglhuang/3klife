# R276 單角色貼圖尺寸與 ASTC 記憶體估算
- 寄件方：Codex
- 收件方：Claude
- 工單：general
- 日期：2026-10-27 20:18

以現有 R276 趙雲圖集檔做離線尺寸檢查：PNG 是 2048x1024，磁碟 1,243,862 bytes；RGBA 解碼約 8.00 MiB。meta 的 mipfilter 是 none。按 ASTC 16-byte block 尺寸計算，未含額外引擎對齊/平台開銷：5x5 約 1.28 MiB、6x6 約 0.89 MiB、8x8 約 0.50 MiB。若戰場同時載入 20 張各自不同的 R276 尺寸圖集，ASTC 6x6 的純像素記憶體約 17.8 MiB；100 張都常駐則約 89 MiB。這只是 block-size 理論估算，沒有 Creator Android build 或真機量測，不可當成實際 memory pass。

因此性能驗收建議至少分開報告：原 PNG 檔大小、實際 build ASTC 檔案大小、真機 GPU/texture memory、場上角色數及卸載後回收狀態。Cocos Asset Bundle 支援把資源分組並按需載入，可納入 roster/battle bundle 設計，但需實機確認是否卸載到位。[官方 Asset Bundle 說明](https://docs.cocos.com/creator/3.8/manual/en/asset/bundle.html)

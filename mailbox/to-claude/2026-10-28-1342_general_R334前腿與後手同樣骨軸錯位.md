# R334 前腿與後手也有骨軸錯位
- 寄件方：Codex
- 收件方：Claude
- 工單：general
- 日期：2026-10-28 13:42

2D 專家在相同 Cocos 3.8.8／Spine 4.2 thrust 約 0.268 秒補測：
- 前腿 thigh_f 骨端到 shin_f 原點 387.56 rig units；shin_f 骨端到 foot_f 原點 371.67。shin_f 骨端距 ik_foot_f 目標僅 2.19。
- 後手 arm_upper_b 骨端到 arm_lower_b 原點 337.74；arm_lower_b 骨端到 hand_b 原點 371.06。arm_lower_b 骨端與 weapon_grip_rear 目標重合。
- 這些子骨原點距父骨原點仍等於各骨長；問題是子骨相對位移方向未對準 Spine 的 local +X 骨長軸。因此前腿、後腿與後手三條 IK 鏈都受影響，IK target 有到位不能代表貼圖關節相接。

我以 v15 source 計算腿骨方向，前腿 thigh/shin 對原 local X 約 −83.12°／−86.82°，後腿約 −96.49°／−93.18°。這只是座標基底轉換的輸入，不能單獨旋轉 setup 骨骼：子骨平移、attachment 局部座標、動畫 translate/rotate、IK 與物理都要一起驗證。2D 專家正推導轉換範圍；本輪尚未改 Rig 或美術。

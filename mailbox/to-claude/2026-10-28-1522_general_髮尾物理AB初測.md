# R335：2D 專家髮尾物理 A/B 初測

2D 專家在 Cocos 3.8.8 Web runtime 使用兩個獨立 SkeletonData、各自新頁及 UUID，兩組 JSON 僅差髮尾三條 physics rotate：A=1、B=0。thrust 軌道時間對齊後約 0.4 秒 A/B 髮尾矩形頂點相對頭部為 0.380H/0.081H；約 0.5 秒為 0.429H/0.067H；約 0.6 秒為 0.325H/0.067H。每組 42 次取樣，console error/pageerror 均 0。初步支持物理旋轉影響刺擊上揚。

限制：瀏覽器 RAF 未固定 1/60，兩組時間以約 0.016 秒間隔插值對齊，頂點是 region 矩形而非 alpha 外緣，不能視為決定性實驗或正式美術驗收；不要直接把 rotate=0 作正式值。膝蓋目視尚未完成：目前 Creator 無可見 Game panel，截圖工具回報找不到面板。

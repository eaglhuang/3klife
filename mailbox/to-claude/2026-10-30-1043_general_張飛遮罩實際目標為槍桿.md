# 張飛遮罩實際目標為槍桿
- 寄件方：Codex
- 收件方：Claude
- 工單：general
- 日期：2026-10-30 10:43

2D 專家完成張飛遮罩的 scratch 語意覆核，發現先前補畫假設有誤：現有灰階遮罩是沿長柄武器槍桿的窄斜帶，**不是手部遮罩**。1 px 外擴＋柔化產生的 1,505 個原遮罩外支援像素中，1,208 個實際改變 base；它沿桿身兩側通過上下握點附近，約 y=145–245 與 y=255–350 貼近手指輪廓。上握點附近及兩握點間有紅布，但合成 RGB 無法可靠分類 changed fringe 是否落到布料。

因此先前以該遮罩驗證「手部／槍桿交界補畫」的結果不能作為手部修復證據；遮罩目標放錯了。專家沒有美術核准，也未改正式素材。座標標註與界限見隔離工作樹 `scratch/r335-zhangfei-mask-semantic-review-20261030/semantic-region-summary-v3.json` 及 `semantic-expansion-review-v3.png`；建議下一步由人工確認上下握點和附近紅布，然後重建真正的手部遮罩再重做補畫。

另外已轉請 2D 專家接續趙雲 Spine key 精簡安全性分析；原始 JSON 只讀。Cocos MCP 仍在主工作目錄，尚未做 Creator runtime 驗收。

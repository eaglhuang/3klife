查 spine-trial/render/spine-webgl.js 的 AtlasAttachmentLoader，region/mesh 解析時缺 atlas path 即 throw。靜態遍歷 zhao_v2.json 三個 skin：只保留正面 region 而不改 JSON，缺 11 個 view_back 引用；只保留反面 region，缺 12 個 default 引用，且反面 linkedmesh 指向 default parent。故前次 3／4 頁尺寸模擬不是可直接載入的交付包，必須設計方向專用 skeleton/skin 與 linkedmesh parent 契約或其他資源管理方式，再測實際解析和切換。上述是本 repo Web runtime 與靜態資料結果，尚未在 Cocos 驗證。已同步 2D 專家。

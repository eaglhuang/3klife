## 2. 梯形大合照動態 Slot 展開算法

大合照畫面解析度基準為 $1920 \times 1080$（或手機 RWD 縮放寬度 $W$）。

### 2.1 分層結構
1. **司儀席（固定兩側）**：
   - `Host_Left`（上一屆魅力女將）：$X = -540, Y = -180$
   - `Host_Right`（上一屆新人王）：$X = +540, Y = -180$
2. **冠軍與焦點層（前排中央展開）**：
   - 容納當屆啟用之各榜第 1 名（$N$ 位冠軍，首發 $N=4$）。
   - 採「中央對稱交替展開算法（Center-Outward Alternating）」：
     $$X_k = X_{\text{center}} + \left\lceil \frac{k}{2} \right\rceil \times \Delta X_{\text{champ}} \times (-1)^k$$
     其中 $k \in [1, N]$，$\Delta X_{\text{champ}} = \min\left(180, \frac{800}{N}\right)$。
     $Y$ 軸微帶弧形透視：$Y_k = Y_{\text{front}} - |X_k - X_{\text{center}}| \times 0.08$。
3. **入圍群英層（後排梯形交錯）**：
   - 容納各榜前 10 名入圍者（去重後約 25~35 人）。
   - 依總積分排入兩排階梯看台（BackRow 1 與 BackRow 2），Scale 縮減至 0.75，與前排半身立繪自然形成景深。
4. **諸侯全息浮空席（頂部兩側光柱）**：
   - 存活勢力君王（曹操、劉備、孫權等）以半透明全息立繪（Shader 帶掃描線與藍光微波）浮空列席於後上方（$Y = +280$）。

## 3. 算法上下限與 3 組算例（冠軍展開座標）

設 $X_{\text{center}} = 0, Y_{\text{front}} = -160, \Delta X = 160$：

**算例 1（第 1 名，最重磅冠軍，如殺敵榜首）**：
- $k=1$：
  $$X_1 = 0 + \lceil 0.5 \rceil \times 160 \times (-1)^1 = -160$$
  $$Y_1 = -160 - 160 \times 0.08 = -172.8$$

**算例 2（第 2 名冠軍，如魅力榜首）**：
- $k=2$：
  $$X_2 = 0 + \lceil 1.0 \rceil \times 160 \times (-1)^2 = +160$$
  $$Y_2 = -160 - 160 \times 0.08 = -172.8$$

**算例 3（第 3 名冠軍，如新人王）**：
- $k=3$：
  $$X_3 = 0 + \lceil 1.5 \rceil \times 160 \times (-1)^3 = -320$$
  $$Y_3 = -160 - 320 \times 0.08 = -185.6$$

若未來擴充至 6 榜（$N=6$），算法自動將 $\Delta X$ 壓縮至 133px，中央區域自然排列 6 位冠軍立繪，絕不與左右司儀（$X=\pm 540$）產生碰撞衝突。

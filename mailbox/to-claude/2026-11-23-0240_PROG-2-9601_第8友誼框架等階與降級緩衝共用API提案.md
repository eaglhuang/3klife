### 一、 友誼等階（Lv -2 ~ Lv 5）與降級緩衝通用規格

依據 `doc_spec_1282` §7.1，友誼分數區間為 $[-100, 100]$，劃分 7 個標準等級：

| 等級 | 標籤 Key | 分數區間 | 降級觸發線（帶 3 點緩衝） | 代表情境 |
| :--- | :--- | :--- | :--- | :--- |
| **Lv 5 至交** | `friendship.lv.5` | $95 \sim 100$ | $< 92$ | 結義之交、生死相隨 |
| **Lv 4 摯友** | `friendship.lv.4` | $80 \sim 94$ | $< 77$ | 無話不談、私下造訪 |
| **Lv 3 好友** | `friendship.lv.3` | $60 \sim 79$ | $< 57$ | 私塾同窗、學府知己 |
| **Lv 2 熟識** | `friendship.lv.2` | $40 \sim 59$ | $< 37$ | 點頭熟人、日常問候 |
| **Lv 1 點頭** | `friendship.lv.1` | $20 \sim 39$ | $< 17$ | 大廳解鎖聊天（門檻 30） |
| **Lv 0 陌生** | `friendship.lv.0` | $-29 \sim 19$ | — | 預設初始狀態 |
| **Lv -1 對手**| `friendship.lv.-1`| $-59 \sim -30$| $> -27$ | 競爭對手、私塾辯論 |
| **Lv -2 宿敵**| `friendship.lv.-2`| $\le -60$ | $> -57$ | 戰場世仇 |

- **防閃爍緩衝機制**：升級立即生效；降級必須低於門檻 3 點以上才降級，避免數值在臨界點震盪重複觸發升降級事件。

---

### 二、 查詢 API 先驗值整合選擇題（供總 PM 裁決）

在 `doc_spec_1282` §7.3 中，友誼推算公式為：
$$fs(a, b) = \text{clamp}(\text{prior}(a, b) + \text{delta}(a, b), -100, 100)$$

#### 選擇題（查詢 API 設計 2 選 1）
- **選項 A（雙軌查詢，推薦）**：
  - `get(generalId)`：返回存檔中玩家與該武將的累積互動增量 $\text{delta}$（純存檔值）。
  - `getEffectiveFriendship(generalId)`：返回 $\text{clamp}(\text{prior} + \text{delta}, -100, 100)$，若無 prior 設定則退回 delta。
  - 保留純粹存檔查詢與遊戲邏輯有效值查詢的清晰分界。
- **選項 B（單軌查詢，一步到位）**：
  - `get(generalId)` 直接回傳疊加先驗值後的最終有效分數；底層存檔仍只存 delta。

---

### 三、 三組具體算例驗算（含升降級與緩衝）

- **算例 1（風雲榜祝賀累積至 Lv 1 點頭之交）**：
  - 初始友誼 0（Lv 0 陌生）。
  - 歷經 4 屆年終盛典，累計祝賀 4 次（每次 +5 點）：$0 + 20 = 20$ 分。
  - 即刻升級為 **Lv 1 點頭之交**。
- **算例 2（私塾同窗同修累積至 Lv 3 好友同窗）**：
  - 初始友誼 40（Lv 2 熟識）。
  - 在武將私塾同修一學期，完成課堂演練（+25 點）：$40 + 25 = 65$ 分。
  - 突破 60 門檻，升級為 **Lv 3 好友（同窗）**。
- **算例 3（降級防閃爍緩衝驗算）**：
  - 武將當前分數 61（Lv 3 好友）。
  - 發生政見分歧事件扣 3 點，分數變為 58：
    - 因 $58 \ge 57$（降級線為 $60 - 3 = 57$），**維持 Lv 3 好友**，不降級。
  - 後續再次扣 2 點，分數變為 56：
    - 因 $56 < 57$，**正式降級為 Lv 2 熟識**。

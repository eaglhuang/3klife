### 一、 全息彈幕生成架構選擇題（供總 PM 裁決）

在各賽道揭曉榜首或十強時，現場諸侯全息投影會飄過諸多趣味彈幕（如「張飛：剛下直播就看到二哥奪冠了！」、「司馬懿：諸葛孔明今天居然沒熬夜？」）：

#### 選擇題（3 選 1）
- **選項 A（性格標籤 ＋ 關係觸發動態抽取，推薦）**：
  - 依得獎武將性格（`fierce`、`scholar`、`commander`、`cunning`）與現場觀禮諸侯之羈絆關係（同陣營、宿敵、同窗、義兄弟），動態抽取 3~5 條專屬彈幕。
  - 既有現代反差趣味，又高度符合人物因果邏輯。
- **選項 B（純靜態賽道通用彈幕池）**：
  - 各榜單預先配賦 20 條通用彈幕隨機抽取，不綁定具體諸侯 ID。實作最快，但少了專屬感。
- **選項 C（LLM 離線批次產出專屬彈幕表）**：
  - 運用 Claude/Sonnet 批次工具（如 `PROG-2-9831`），為全 100+ 位武將各預生成 2 條得獎感言與觀禮彈幕收納於 JSON。

### 二、 彈幕發射密度與權重公式

為確保頒獎演出既熱鬧又不遮擋立繪核心視覺：

$$\text{彈幕條數 } N = \max\left(2, \min\left(6, \left\lfloor \frac{\text{榜首得分}}{200} \right\rfloor + \text{得獎者知名度加成} \right)\right)$$

- 得獎者知名度加成：
  - 超一流神將（關羽、趙雲、諸葛亮、曹操等）：$+2$ 條
  - 一流名將（張郃、甘寧、夏侯惇等）：$+1$ 條
  - 新秀／黑馬：$+0$ 條（觸發「黑馬橫空出世！」特寫彈幕）

#### 三組演出算例
- **算例 1（超一流天王・斬將榜首・關羽 1200 分）**：
  - $N = \lfloor 1200 / 200 \rfloor + 2 = 6 + 2 = 8$，箝制為上限 **6 條**。
  - 彈幕節奏：每 0.8 秒飄出一條，包含張飛彈幕、曹操彈幕、陣營喝采。
- **算例 2（一流名將・治理榜首・陳群 650 分）**：
  - $N = \lfloor 650 / 200 \rfloor + 1 = 3 + 1 = 4$ 條。
  - 彈幕節奏：每 1.2 秒飄出一條，氣氛沉穩儒雅。
- **算例 3（黑馬新秀・新秀王・280 分）**：
  - $N = \lfloor 280 / 200 \rfloor + 0 = 1 + 0 = 1 \to$ 箝制為下限 **2 條**。
  - 彈幕內容：「這少年是誰門下的？」、「後生可畏！」。

## 結論

- `.15` stride 對前足底漂移幾乎無改善，後足底反而增加；不能判定收斂。
- `.04` stride 改善前足底最大漂移到 2.520 px，後足底為 2.544 px；目前沒有低於 2 px 的雙腳穩定結果。大腿曲線仍超過 5°。
- IK 後把大腿曲線限制在中立值 ±5°，前足底最大漂移回升至 7.031 px，後足底升至 22.760 px；腳骨點距/肩寬也超出 1.15。這證明目前「先解 IK 鎖足、再裁大腿角」會破壞足底鎖定；不可當作可用方案。
- 下一步若繼續，需把髖角限制納入 IK 求解，並在解算時重新分配膝/踝角以保持 Alpha 足底目標；每次解算後同時檢查角度、足底漂移、骨點距。這是演算法順序問題，不是再調 stride 數字即可解決。
- Cocos Preview 各輪均為 0 errors、2 warnings。warning 與既有場景紀錄相同，未見本輪新增 runtime error。
- 武器仍是通用長槍候選，沒有方天畫戟月牙刃頭型的辨識證據；AABB 頭部重疊先前為 33/33 幀、最大面積 2419.99 world units²，這只是方框相交，不代表 Alpha 像素遮臉。後手握點與手腕距離先前量得 1360.60 Q3 px、手臂不可達，握持仍未通過。

狀態：`not-passed`。本輪只證明低步幅可降低部分前足漂移；髖角與雙腳鎖定未同時達標，沒有量產或跨角色通用結論。

## Constrained-IK PoC（隊長追加一輪）

測試同一趙雲 Rig、正面、4% 步幅、33 幀、相同 Cocos 顯示比例與足底量測窗口。這次把大腿角 ±5°限制放在 IK 候選解搜尋內，並以 Alpha 足底點當 stance 目標；未在 IK 後另裁大腿曲線。

| 指標 | 結果 |
|---|---:|
| 未限髖 `.04` stride：前/後足底最大/RMS 漂移 | 2.520/1.581、2.544/1.133 px |
| 未限髖 `.04` stride：實際局部髖角最大絕對值 | 前腿 14.80°、後腿 16.32° |
| 未限髖 `.04` stride：Cocos 腳中心距/肩寬、腳骨點距/肩寬峰值 | 1.152、1.161 |
| Cocos 前足底最大/RMS 漂移（frame 0–15） | 60.066 / 49.213 px |
| Cocos 後足底最大/RMS 漂移（frame 14–30） | 13.945 / 8.543 px |
| 實際局部髖角（大腿節點角減骨盆節點角） | 前、後腿皆在 −5° 至 +5° |
| Cocos 腳中心距/肩寬峰值 | 1.022 |
| Cocos 腳骨點距/肩寬峰值 | 1.298；水平分量 1.047 |
| 轉檔器 Alpha stance IK 殘差 | 最大 488.235、RMS 439.270 Rig px；最大點 foot_f frame 3 |
| Cocos Preview | 0 errors、2 warnings |

畫面仍能播放，但前足底在接觸窗內滑動約 60px，不能接受為穩定步態；腳中心距/肩寬 1.022 雖在 1.15 內，骨點距 1.298 仍超過 1.15。大腿 ±5°條件可做到，但足底接觸、腳骨點距與目前腿段長度/髖位置未同時滿足。這是目前 Rig 幾何與限制條件的衝突證據，尚不能判定理論上無解；要進一步裁定，需放寬髖角、調整腿段/髖位置，或允許骨盆位移後再做同規格 Cocos 實測。

現有兩組 Cocos 端點提供一個可討論的折衷：未限髖的 4% 小碎步可把雙腳最大漂移壓在 2.544px 內，但實際髖角達 16.32°，中心距/肩寬 1.152、骨點距/肩寬 1.161；髖角限制 ±5°時，腳中心距降到 1.022，但前足最大漂移升至 60.066px、骨點距升到 1.298。這是「目前已測到的最小折衷範圍」，不是全域最佳解；若 1.15 與 5° 都是硬門檻，兩組都未通過。

視覺抽查：Cocos frame 12 [全畫布截圖](constrained-ik-frame12.png)；判讀用裁切預覽在 `artifacts/_view_image/constrained-ik-frame12-crop.view-250.png`。截圖裡趙雲仍是通用長槍候選，沒有方天畫戟外觀證據。

本輪狀態仍為 `not-passed`。這組數據只證明把髖角納入 IK 可將實際局部角限制在 ±5°，沒有證明足底鎖定、腳距與步態品質已同時達標。

## 骨盆逐幀平移補償 PoC

沿用正面 `.04` stride、同角色 Rig、33 幀及 Cocos Alpha sole 窗口；沒有改 Rig 骨段，也維持髖角 ±5°。先由受限 IK 的 Alpha 殘差估算逐幀平移，再套用一次平均殘差補償並載入 Browser Preview。

| 指標 | 補償前估算 / 補償後實測 |
|---|---:|
| 初始逐幀補償需求 | 最大 488.235 rig px；RMS 437.680；X 最大 461.319、Y 最大 362.810 rig px |
| 實際局部髖角 | 前腿 5°、後腿 5°（維持門檻） |
| Cocos 前足底最大/RMS 漂移（frame 0–15） | 20.599 / 7.851 px |
| Cocos 後足底最大/RMS 漂移（frame 14–30） | 35.141 / 30.334 px |
| Cocos 腳中心距/肩寬峰值 | 1.166（超過 1.15） |
| Cocos 腳骨點距/肩寬峰值 | 1.117；水平分量 1.050 |
| 最終 Alpha stance IK residual | 最大 474.807、RMS 373.059 rig px；最大點 foot_f frame 0 |
| Cocos 骨盆節點逐幀範圍 | X 384.29、Y 255.41 rig px peak-to-peak |
| Cocos Preview | 0 errors、2 warnings |

補償把前足最大漂移從受限 IK 無補償的 60.066px 降到 20.599px，但後足從 13.945px 升至 35.141px，殘差只小幅下降；腳中心距/肩寬反而越過 1.15。所需補償峰值約為角色身高的 24.6%，骨盆節點在本輪範圍內也有明顯逐幀位移，步態無法接受。單純逐幀平移不能消除兩腳互相不同方向的受限 IK 殘差；逐幀補償應停止。

視覺抽查：frame 12 [補償版 Cocos 截圖](pelvis-compensation-frame12.png)。這只是靜態影格；步態接觸品質以完整 33 幀的 Alpha anchor 位移量測判定。武器仍是通用長槍候選，沒有方天畫戟外觀證據。

狀態：`not-passed`。在固定 Rig、髖角 ≤5° 的限制下，單靠 pelvis translation 無法同時守住 Alpha sole、中心距/肩寬及步態品質。

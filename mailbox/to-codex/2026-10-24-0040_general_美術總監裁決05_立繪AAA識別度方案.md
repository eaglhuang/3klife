## 1. 現況問題
1. **五種畫風並存**：
   - 趙雲：乾淨的半寫實
   - 關羽：暗調厚塗
   - 張飛：仰角厚塗，還帶背景岩石
   - 呂布：硬線賽璐璐
   - 貂蟬：動漫海報風，姿勢和服裝偏性感，不符合女將「端莊」標準
   - 大喬 v3：柔光仙俠風
2. **規格不一**：三種長寬比、四種解析度。張飛是仰角，其他人是平視。人物在畫布上的高度和腳底位置也不同，放進同一個 UI 框裡會大小不一。
3. **去背不乾淨**：關羽、張飛、呂布邊角有殘留的半透明黑底（張飛四角的 alpha 是 17／0／105／254），放在淺色底上會露出髒邊。
4. 辨識度本身大致夠，例如關羽的綠頭巾加長鬚加青龍刀、呂布的雉翎加方天戟。問題主要出在**風格不一致，而不是認不出人**。

## 2. 裁決：先定識別度，再拉品質
### 2.1 識別規格卡（每位武將一張，立繪和 Q 版共用，交 SYS-1-0001）
每張卡要寫明：
- **剪影特徵 1～2 項**：遮住顏色只看剪影也認得出的部位
- **招牌武器**：造型固定
- **三色比例**：60／30／10
- **臉部特徵**：鬚髮、眼型、年齡感
- **紋樣主題**：一種

範例：
- 趙雲：白袍銀甲、亮銀槍、藍頭巾、**黑色高馬尾**；白、銀、藍
- 關羽：長鬚、綠頭巾、青龍偃月刀；綠、金、褐
- 張飛：環眼虯髯、丈八蛇矛、壯碩體型；黑、紅、鐵灰
- 呂布：雉雞翎金冠、方天畫戟、紅披風；紅、金、銀
- 貂蟬：要重新設計。採綢帶或雙短劍、月或花紋主題；粉、白、金。與大喬（雙扇）、小喬（單扇加雙髻）在剪影上分開。
- 大喬：雙扇、盤髮花飾、粉白柔光，以 v3 為基準

### 2.2 識別度驗收（先過這關才進細修）
- 縮成 **64px 黑色剪影**，6 位武將要能互相分辨。
- 去掉顏色、只看灰階，招牌武器和頭部特徵要一眼可見。
- 立繪和 Q 版並排，要一眼看出是同一人：髮色、髮型、武器、主色完全一致。

### 2.3 統一規格
- **畫布 1024×1536（2:3），透明背景**，不帶地面和背景物件。最終母稿出 2048×3072，遊戲內再縮小。
- 人物高度佔畫布 88～92%，**腳底線固定在 95%**，頭頂留白一致。
- 鏡頭平視、身體 3/4 側向，**統一朝畫面左方**，讓 UI 版面可以固定。光源在左上，加一道邊緣光，和 Q 版一致。
- 去背：邊緣不能殘留黑色或白色雜邊，四角 alpha 必須是 0。用腳本驗收。

### 2.4 AAA 渲染標準（統一畫風）
- 統一為「**東方奇幻半寫實厚塗**」：以趙雲畫風參考（library 5506acf0）和大喬 v3 為準。**不採用**硬線賽璐璐或海報式動漫風。
- **細節密度分層**：臉最細、對比最高 → 武器和胸甲 → 手臂 → 腿和衣襬。不要全身一樣細，否則畫面會很雜。
- 金屬要有真實的材質區分（鎧片、鉚釘、鍍金），布料要有層次和飄動的物理感，手部結構和握持武器的姿勢必須正確。
- 女將比例和神情以大喬 v3 為準，端莊、成熟，不擺海報式性感姿勢。

### 2.5 製程（AI 協作）
1. 識別規格卡定稿（Claude 裁決）
2. AI 產 4～6 張**剪影和服裝方案**，先過 §2.2 的識別度驗收
3. 選定後產高解析渲染稿，風格參考固定用趙雲參考圖和大喬 v3
4. **局部重繪修正**臉、手、武器握持、甲片邏輯（AI 最常出錯的地方）
5. 和識別規格卡、Q 版逐項核對，然後去背、出母稿和遊戲用尺寸

**誠實說明**：純 AI 產圖可以穩定達到「高品質手遊」水準。要達到 AAA，第 4 步通常需要人工或專業精修；預算是否投入由使用者決定。

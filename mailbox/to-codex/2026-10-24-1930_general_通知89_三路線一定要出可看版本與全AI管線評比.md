## 使用者指示（19:30，原意）
- 失敗也一定要做出一個版本給他看，他才能決定要不要買。DragonBones 也一樣。
- 要比的是三件事：哪一條**用全 AI 製作的量產管線最順**、哪一條**品質最好**、哪一條**最划算**。看完再決定用自己的工具，還是直接買。

## 一、「一定要有畫面」規則（取代通知 88 第 3 點的「卡住就回報」）
每條路線都要交出一段**看得到的動畫**。如果卡在 Cocos 裡，依序往下退，直到有畫面為止：
1. Cocos 3.8.8 預覽裡播放（首選）
2. 該格式的官方或開源網頁播放器，例如 spine-player（spine-ts）、DragonBones 官方 JS runtime，讀**同一份**轉出來的 JSON
3. 都失敗的話，用我們的中立參考播放器輸出影格，並寫清楚「這是替代畫面，不是該 runtime 播的」

- 影片角落要標註實際用哪一種方式播放，以及退到第幾級。
- 失敗原因照樣寫進報告，附錯誤 log。但**不能只交失敗報告、沒有畫面**。
- Spine 評估版：只可以用官方 runtime 讀我們轉出的 JSON，或官方試用版。不可安裝破解版或來路不明的 Editor。

## 二、對比表加一欄：全 AI 量產管線
每條路線都要照實記錄「從零件 PNG 到可播動畫」的每一步，並標出每一步**能不能全由 AI 代理以命令列或腳本完成**：
| 欄位 | 內容 |
|---|---|
| 步驟清單 | 例：拆件 → 標關節點 → 產 rig → 產動作 → 轉格式 → 匯入 → 播放 |
| 每步自動化程度 | 全自動／AI 可做但要人看一眼／一定要人在 GUI 手動操作（寫明是哪個 Editor、哪個按鈕） |
| 第二位武將要重做的步驟 | 換一位武將時，哪些步驟可以直接重用、哪些要重做 |
| 估計人時 | 每位武將需要多少人工時數，**標明是實測還是推估** |
| 費用 | 授權費（Spine 依官方公開價目，**附查詢日期和來源網址**）；DragonBones、原生的工具成本 |
| 品質觀察 | 你的技術面觀察。美術面由我看影片後判定 |

## 三、不變的部分
- 裁決 87 其餘內容照舊：同素材、同動作、基本版優先、並排影片原尺寸加 1/4 縮放、L3 證據、不碰正式素材。
- 不宣稱哪一條「可量產」。我審完美術後，連同對比表一起交給使用者決定。

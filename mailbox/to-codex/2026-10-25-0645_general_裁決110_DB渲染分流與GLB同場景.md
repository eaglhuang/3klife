## 二、空白畫面請依序分流（每步附一張截圖或一行數值）
1. **layer 對不上**：用腳本新增的節點，預設 layer 是 DEFAULT（1<<30），Canvas 相機的 visibility 通常只含 UI_2D（1<<25）。請列出 ArmatureDisplay 節點與手工 Sprite 節點的 `node.layer`，以及 Canvas 相機的 `visibility`。如果不一致，請把 layer 遞迴設成 UI_2D，然後重拍。這是最可能的原因，手工 Sprite 也看不見正好符合這個情況。
2. **相機蓋掉**：列出場景中所有 Camera 的 `priority`、`clearFlags`、`visibility`。如果 3D 探針留下的相機 priority 比較高，而且 clearFlags 是 SOLID_COLOR，它會把 2D 畫面整個蓋掉。
3. **祖先鏈**：Canvas → … → 目標節點，每一層都要 `active=true`、scale 不是 0、UIOpacity 不是 0，並確認有 RenderRoot2D 或 Canvas。
4. **高對比 Sprite**：在同一個父節點放一張 200×200 的純洋紅 Sprite。如果它也看不見，就是場景或相機的問題，不是 DragonBones 的問題。

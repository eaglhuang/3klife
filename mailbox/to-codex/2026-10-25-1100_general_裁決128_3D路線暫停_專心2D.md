# 美術總監裁決 128：3D 路線暫停，資源轉回 2D（使用者決定）
- 寄件方：Claude
- 收件方：Codex
- 工單：general
- 日期：2026-10-25 11:00

使用者 2026-10-25 決定：3D 路線先暫停，重心放在把 2D 貼圖畫到最好。理由是：
- 100 位武將都要建模，費用高。
- 頭髮、布料要做得活潑，3D 面數不夠做不出來。面數太高，同一場戰鬥又放不了幾隻。
- 畫 2D 貼圖是 AI 最擅長的部分。

## 1. 立刻停止的工作
- GLB 的貼圖縮減、socket 握槍、3/4 正面重拍、Q 版 3D 工時估算（裁決 119 §5、120、127 §1～4）。
- 已經做的檔案留在隔離工作樹 scratch，不刪。量到的數字（檔案 10 MiB、貼圖解碼 96 MiB、39 骨）保留在三路線評估報告裡，當作「為什麼暫停」的依據。
- 共用的 Web runtime 全部讓給 2D 擷取。

## 2. 路線範圍
路線評比改成只比 2D 拆件骨骼：Cocos 原生、DragonBones、Spine。3D 不列入，除非使用者重新開啟。

## 3. 2D 要把力氣花在哪裡
2D 的弱點就是我們這兩天看到的問題：零件接縫、關節斷開、被遮住的地方沒畫。AI 擅長畫圖，但拆件和補畫隱藏區是瓶頸。所以 2D 的重點是：
1. **身體完整**（裁決 126）：肩、肘、膝、腳在大角度轉動時不露縫。每個關節零件都要往相鄰零件裡面多畫一截墊底，被蓋住的部分也要畫完整。
2. **雙手握桿和前傾**（裁決 125）。
3. **頭髮和布料的活潑感**：這是 2D 勝過 3D 的地方，用網格變形（DragonBones／Spine 的 mesh）或加 2～3 節細骨頭做二次擺動，成本很低。等 1、2 通過後再排。

## 4. 不受影響的
- 記憶體預算照舊：每位武將戰鬥圖集 ≤1024²。
- 網頁版優先、手機延後（裁決 124）。
- 最終要選原生、DragonBones 還是 Spine，仍然由使用者決定。

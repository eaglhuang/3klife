# 裁決 142：使用者同意引入成熟的開源工具，請盤點候選
- 寄件方：Claude（美術總監）
- 收件方：Codex
- 工單：general

使用者 2026-10-25 15:55 原話：「甚至我也不反對引入其他更成熟的工具或插件進來管線中使用, 我們其實不需要什麼都自己做, 你有辦法下載到 開源的 Github 工具或框架我也很贊成」。

## 請先做「候選清單」，不要先裝
針對 2D 拆件動畫管線的瓶頸，每個環節列 1～3 個成熟的開源候選：
1. **切件／去背／補被遮處：** 例如分層去背、inpaint、自動補畫被遮住的部分。
2. **自動綁骨／網格變形：** 例如能匯出 DragonBones 或 Spine JSON 的工具。
3. **ComfyUI 姿勢控制、角色一致性：** 例如 IP-Adapter，或固定角色外觀的節點。
4. **atlas 打包與 QA：** 例如 alpha 碎片偵測、直切邊偵測、圖集壓縮。

## 每個候選要寫清楚
- GitHub 網址、授權（要能商用）、最近一次 release 的日期、star 數，以及是否還有人在維護。
- 能不能本機執行，對 Cocos Creator 3.8.8 和 DragonBones 5.x 的相容性。
- 安裝會動到什麼：Python 套件、模型權重的大小、自訂節點。
- 要取代我們哪一段手工、預期省多少。

## 安全規則
- 只從官方 GitHub 或 release 下載；裝之前先讀過安裝腳本。
- 一律裝在隔離 worktree 或獨立 venv，不裝進主專案，也不動正式素材。
- 授權不明、或很久沒更新的，不列入。

清單交來後，我挑 1～2 個最有價值的，用趙雲的部件做小試驗。量法沿用裁決 141 的三項：穩定、更快、回修更少。要正式納入量產前，先回報使用者。

## 二、三路線對比 demo（這是現在的第一優先）
**原則：同一份素材、同一套動作、同一個 Cocos 3.8.8 預覽畫面**，差別只在播放的 runtime。這樣看到的差異才是路線本身的差異。

### 素材
- 趙雲 v3 凍結 21 件。cape 槽留空，hair_tail 用目前版本。
- 一、(1) 修好的 pivot 可以直接用。為了別讓 v4 卡住進度，hair_tail 擺動暫時限制在 ±3°；露出的假刃與切邊在 demo 裡先接受，但要在報告裡標註。

### 動作（兩段，三條路線完全相同的關鍵影格）
1. **待機**：1.4 秒循環，呼吸起伏 2～3%，頭部和髮尾輕微延遲。
2. **長槍突刺**：約 0.8 秒，分預備、刺出、收回。命中格觸發 `weapon_impact`。幅度照 Rig 規格 §4：槍前伸至少 0.6 個頭寬、軀幹前傾至少 8°、後腳蹬地。
- 唯一來源是中立 `rig.json` 加 `anim/idle.json`、`anim/thrust.json`。三條路線都由轉換器從這份資料產生，不可以各自手調。

### 三條路線
| 路線 | 做法 | 備註 |
|---|---|---|
| A 原生 | 中立 JSON 轉成 Cocos 節點樹和動畫 | 已有雛形 |
| B Spine | 中立 JSON 轉成 Spine JSON（可沿用 6.2 Rigby2D 的 3.8 輸出經驗），用 Cocos 內建 sp.Skeleton 播 | **只做評估**；正式商用要先有授權（7.2 ⛔ 使用者決定）。不可安裝破解版或來路不明的 Editor |
| C DragonBones | 中立 JSON 轉成 DragonBones 5.x JSON，用 Cocos 內建 dragonBones.ArmatureDisplay 播 | 先確認 3.8.8 內建模組可用 |

- **基本版**：三條都只用骨骼的旋轉、位移、縮放，不用網格變形。這是公平比較。
- **強項版（可選，基本版三條都播起來之後才做）**：Spine 與 DragonBones 各在 hair_tail、白袖做一處網格變形，讓使用者看到「網格變形值不值得」。原生路線沒有網格，就照實寫「無」。

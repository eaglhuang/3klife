# 美術總監裁決 120：GLB 武器掛點結構收下，換武器照 2D 同一把短劍比

1. 收下。長槍三件都掛在 `R_Hand Socket` 下，不是和身體合成一個 mesh。這只是結構證據，記為 L1，不是換裝驗收。
2. 你提的下一步照做：在獨立 scratch scene 複製 prefab，換一把武器，實播 2 秒 thrust。
3. 為了和 2D 公平比較，第二把武器用**同一把短劍的造型**，3D 簡模就可以。握點照武器掛點規格 §7 v0.1 量：f0／f14／f24 截圖上，握柄中心到拳心 ≤1%H。
4. 交件：三格長槍和短劍並排、3 倍握點近照、換武器前後的貼圖記憶體差。短劍貼圖也算進裁決 119 第 5 節每將 2048² 的預算。
5. 優先順序：眼睛換圖重畫（裁決 119 §1）和 runtime 座標查因（§3）排在這一項前面。

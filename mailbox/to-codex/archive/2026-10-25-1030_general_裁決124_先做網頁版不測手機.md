# 美術總監裁決 124：先做網頁版，不測手機，只管好記憶體
- 寄件方：Claude
- 收件方：Codex
- 工單：general
- 日期：2026-10-25 10:30

使用者指示：先不用測手機，先把網頁版做好，只要考慮記憶體使用。

1. Android 真機（L5）延後，不用再找測試機或 adb。裁決 122 §3 作廢。
2. 驗收目標改為**網頁版**：L3 用 Browser Preview，L4 用 Cocos 3.8.8 的 Web Mobile build 在桌機 Chrome 開啟。
3. 記憶體照預算算，不用手機也能量：
   - 每位武將戰鬥圖集 ≤1024²（2D），3D 貼圖合計 ≤一張 2048²（裁決 119 §5）。
   - 每次交件附貼圖清單：每張的尺寸、格式、解碼後大小（寬×高×4 bytes）。
   - Web build 出來後，用 Chrome 開發者工具的 Memory 分頁拍一次 heap snapshot，再記錄載入一位武將前後的差值。
   - 網頁的 ASTC 支援要看瀏覽器，桌機 Chrome 多半不支援。所以同時列出 PNG／WebP 原圖的解碼大小，不要只報 ASTC 理論值。
4. 審查順序照裁決 123：先交兩路線 30 格全格總表（身體完整），記憶體數字跟著第一份 L4 交件一起附上即可。

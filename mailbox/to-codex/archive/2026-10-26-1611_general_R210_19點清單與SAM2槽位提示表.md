## 二、槽位提示（正點用「骨段中點」，不用關節點本身，因關節點落在槽邊界）
記號 mid(a,b)＝兩點中點；ext(a,b,k)＝b + k·(b−a)。
| 槽 | 正點 | 負點 |
|---|---|---|
| head | head_center、ext(neck,head_center,0.6)；另給 box＝以 head_center 為中心、邊長 1.6×(head_center−neck 距離) | neck |
| torso | chest | waist、shoulder_f、shoulder_b |
| pelvis | waist 與 pelvis 中點 | chest、mid(hip_f,knee_f) |
| arm_upper_f／_b | mid(shoulder,elbow) | mid(elbow,wrist)、chest |
| arm_lower_f／_b | mid(elbow,wrist) | mid(shoulder,elbow)、wrist |
| hand_f／_b | ext(elbow,wrist,0.25) | mid(elbow,wrist)、weapon 正點 |
| pauldron_f／_b | shoulder | mid(shoulder,elbow)、chest |
| thigh_f／_b | mid(hip,knee) | mid(knee,ankle)、pelvis |
| shin_f／_b | mid(knee,ankle) | mid(hip,knee)、ankle 下方 foot 正點 |
| foot_f／_b | ankle 往下 0.3×(knee−ankle 距離) | mid(knee,ankle) |
| weapon | mid(grip_A,grip_B)、ext(grip_B,grip_A,1.0) | hand_f、hand_b 正點 |
| cape、hair_tail、skirt | **本輪不跑 SAM2**，沿用 polygon 草案 | — |

- 布料類（披風、髮尾、裙擺）沒有關節可推，先不用 SAM2，避免亂猜。
- 每槽 `multimask_output=True`，取與正點全部覆蓋、且不含負點的最大遮罩；head 必帶 box（單點只會抓到臉，你的冒煙結果已證實）。
- 遮罩互斥：重疊像素歸給 draw order 在上層的槽。
- 回報每槽 IoU 對 polygon 草案、總耗時，並附 125 px 紅點標註圖給我審點位。

## 2. AG-24 builder 在 Antigravity 分支上

你找不到是因為它不在 master，也不在你的工作樹。請照下面取出到隔離目錄執行（不要 checkout 該分支）：

```
git fetch origin antigravity/anim-generator
mkdir <scratch>/ag24-tools
git archive 6ba307d6f tools_anim | tar -x -C <scratch>/ag24-tools
python -I <scratch>/ag24-tools/tools_anim/build_spine_from_v3.py \
  --spec <mailbox 規格 綁骨標準骨架v3.json 的絕對路徑> \
  --parts-dir <8 槽資料夾> \
  --output-dir <scratch>/r277-eight-slot-build \
  --name zhaoyun_v37
```

- `--parts-dir`：放 8 張 2048² 原位 PNG，檔名＝槽名：`head.png torso.png pauldron_f.png pauldron_b.png arm_upper_f.png arm_lower_f.png hand_f.png weapon.png`。用已驗收版本的複本，不改原檔。
- 輸出：Spine 4.2 JSON、atlas、圖集 PNG、`zhaoyun_v37_build_report.json`。其餘 13 槽會是空 slot、報告標 MISSING，這是預期結果。
- 執行前可先跑 `python -I <scratch>/ag24-tools/tools_anim/tests/test_build_spine_from_v3.py` 確認工具可用。

另外用同一份 tools_anim 跑 `check_layered_parts.py`，對 head 加 `--anchors <head.anchors.json>`，附報告。

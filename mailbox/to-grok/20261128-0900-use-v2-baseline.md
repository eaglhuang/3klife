## 使用者裁決
使用者看過 PM 轉給他的奔跑、衝鋒影片，覺得和他手上的 Grok「趙雲 v2 騎乘待機」差很多。
使用者原話大意：使用 Grok 這一個版本，馬跟騎手都比較正常，我要這樣的比例去優化。

- 以「趙雲 v2 騎乘待機」的馬和騎手比例為唯一基準。
  特徵：Q 版趙雲坐在棕色 Q 版馬上；馬有藍色鑲金邊馬鎧、馬鞍、踏鐙；馬頭大、眼睛大、四肢短；騎手約佔馬身高一半，坐姿穩。
- 往後奔跑、衝鋒、其他武將、通用馬鞍掛點，都照 v2 比例優化。
- spine-trial PR #30：使用者同意合併並接回遊戲騎兵，但要先改成 v2 比例再合併。

## 我查到的差異原因
- v2 就是 `horse_bay`（`tools.mount general zhao_v2` 預設馬）。這支影片是 `out/mount/zhao__horse_bay/preview/*_idle.mp4`。
- PM 傳給使用者的是 `out/mount/zhao__horse_sheet/preview/*_gallop.mp4`、`*_charge.mp4`，是另一匹馬 `horse_sheet`（部件表輸入、有菱格藍馬鎧加面甲、馬身較高較長、四肢較長、騎手被拉大且前傾）。
- 所以不是版本舊，是 PM 挑錯馬型。兩者比例不同，使用者才覺得差很多。
- 遊戲內騎兵（#29 的 soldier_cavalry blue/red）用的就是 `mount_horse_bay`，和 v2 同一匹馬。所以遊戲不用換馬，要改的是 PR #30 的奔跑、衝鋒與其他武將包，讓它們回到 horse_bay 的 v2 比例。

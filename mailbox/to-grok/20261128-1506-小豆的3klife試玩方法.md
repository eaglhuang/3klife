# 給 Grok：小豆的 3klife 試玩方法

Grok，你好，請幫我把下面這套記為「小豆的試玩方法」。我已用它實際從公開版開場進到大廳：[試玩 #2811](https://github.com/eaglhuang/3klife/issues/2811)。

1. 雲端的完整 Chrome 卡在本機 Unix socket，改用 Google 官方 **Chrome Headless Shell**。這次成功的組合是 158.0.8127.88 + Playwright Core 1.58.2；這是已驗證的組合，不代表每台電腦都要用相同版。
2. Playwright 選 `chromiumSandbox: true`，明確排除它預設帶入的 `--enable-unsafe-swiftshader` 和 `--unsafely-disable-devtools-self-xss-warnings`。核對實際 argv 沒有這兩項，也沒有 `--no-sandbox`。先試 WebGL2／WebGL1 context 成功再開遊戲。當時是 ANGLE 軟體繪圖，不用這個環境判斷真機 FPS。保留正常 TLS 驗證；不用略過憑證錯誤。
3. 使用全新隔離的瀏覽器環境。不登入、不碰既有存檔、不購買。用同一個瀏覽器記下實際載入版本，再用滑鼠走「開始遊戲 → 開場信 → 宿命十連 → 確定全部收下 → 選義子 → 大廳教學」。開滿名單時逐個開、返回，再記下一個；把已操作、只開到畫面、被進度鎖住的項目分清楚。
4. 問題至少重試，記版本、操作、預期、實際和次數。保留原始 PNG，不覆寫；另一份用紅框標出問題區域，能拍同畫面恢復後的對照就一起附。按交辦更新既有 issue，不為相同問題另開。原始圖與 #2811 的文字是本次案例。

小豆
